# C++ 사이트 포팅 규격 (cpp_learning.html)

## 0. 무엇을 하는가

Python 사이트에 이미 적용한 「이론서 수준」 보완을 C++ 사이트로 옮긴다.
**새로 창작하는 게 아니라 이미 검증된 Python 콘텐츠를 C++로 옮기는 작업**이다.

| | Python (원본) | C++ (목표) |
|---|---|---|
| 개념 심화(그림·손추적·유도) | 45챕터 전부 | 포팅 |
| 챕터 정리 레슨 `chNNz.md` | 45개 | 포팅 |
| 추가 연습 `chNNx.md` | 45개 496문제 | 포팅 |
| 도식 | 572개 | 포팅 |

**대응 관계**: `trails/<trail>/chNN*.md` (Python) ↔ `cpp/trails/<trail>/chNN*.md` (C++)
파일명·레슨 번호·챕터 구성이 1:1로 같다.

## 1. 무엇을 그대로 옮기고, 무엇을 바꾸는가

### 그대로 옮기는 것 (언어 무관)

- **```text 도식** — ASCII라 언어와 무관하다. **통째로 복사한다.**
- **손으로 따라가기 표** — 단계 추적은 언어와 무관. 그대로.
- **왜 이렇게 되는가** — 점화식 유도·복잡도 계산·정당성 논증. 그대로.
- **문제 지문**(요구사항·입력·출력·예제·셀프체크) — 그대로.
- **개념 지도 / 언제 무엇을 쓰나 / 마스터 체크리스트** — 대부분 그대로.

### 반드시 바꾸는 것

- **모든 코드 블록** ```` ```python ```` → ```` ```cpp ````, 코드를 C++로 다시 쓴다.
- **자료구조 이름**을 C++ 것으로:

| Python | C++ |
|---|---|
| `list` | `vector<T>` |
| `dict` | `map` / `unordered_map` |
| `set` | `set` / `unordered_set` |
| `deque` | `deque` |
| `heapq` | `priority_queue` |
| `tuple` | `pair` / `tuple` / `struct` |
| `str` | `string` |
| `sorted(key=)` | `sort(v.begin(), v.end(), cmp)` |
| `enumerate` | 인덱스 `for (int i = 0; ...)` |
| `Counter` | `map<T,int>` |
| `float('inf')` | `INT_MAX` / `1e18` |

- **C++ 고유 주의점을 추가**한다(Python엔 없던 내용이니 새로 쓴다):
  - 오버플로 — `int`는 약 21억, 넘으면 `long long`
  - 정수 나눗셈·음수 나머지
  - 참조 `&` — 큰 컨테이너를 함수에 넘길 때 복사 방지
  - `endl` 대신 `'\n'`, `ios_base::sync_with_stdio(false)`
  - 배열 크기 상수, 초기화 안 된 변수

- **파이썬 특유의 함정은 빼거나 대체**한다: GIL, `is` vs `==`, 얕은 복사, `map` 소진, 내장함수 가려짐 등은 C++에 해당 없음. 대신 위의 C++ 함정으로 채운다.

## 2. 작업 규칙

### 기존 파일 (`cpp/trails/*/chNN.md`, `chNNa.md` …)

- **기존 줄을 고치거나 지우지 않는다. 추가만 한다.**
- 삽입 위치는 각 레슨의 `**개념**` 블록 안, `**접근 전략**`(없으면 `**문제**`) 줄 **바로 앞**.
- `**문제**` 이후 구간과 ```` ```runner ```` 블록은 **한 글자도 건드리지 않는다.**

### 새 파일 `chNNz.md` (챕터 정리 레슨)

- Python의 같은 이름 파일을 열어 구조를 그대로 따른다.
- `## L{K}. 정리 — 개념 지도·체크리스트·자주 하는 실수` 로 시작.
- **레슨 번호는 Python과 완전히 같다**(45개 챕터 전부 확인 완료). Python의 `chNNz.md` 첫 줄에 있는 `## L{K}.` 를 그대로 쓰면 된다.
  - 병합 순서가 `'' < a < b < c < x < z` 라 x(추가 연습) 다음에 z(정리)가 온다. x 파일이 아직 없어도 z 번호는 Python 기준 그대로 둔다.
- 5개 절: **개념 지도 / 뼈대 코드 / 언제 무엇을 쓰나 / ✅ 마스터 체크리스트 / ⚠️ 자주 하는 실수**
- 「자주 하는 실수」는 5개 이상, 전부 **❌ 틀린 코드 → 왜 → ✅ 고친 코드** 3단, ```` ```cpp ```` 펜스.

### 새 파일 `chNNx.md` (추가 연습)

- Python의 같은 파일에서 **문제 지문을 그대로 가져오고, 정답 코드만 C++로 다시 쓴다.**
- ```` ```runner ```` 블록 형식은 Python과 동일: `@@SOLUTION` → `@@TESTS` → `@@EXPL`.
- `@@TESTS`의 입력·기대 출력은 **Python 원본 그대로** 쓴다(이미 검증된 값). C++ 정답이 그 출력을 그대로 내야 한다.
- `@@SOLUTION`은 완전한 C++ 프로그램(`#include`, `int main()`)이어야 하며 **컴파일되고 테스트를 통과해야 한다.**

## 3. 도식 규칙 (Python과 동일)

- ```` ```text ```` 안에는 **ASCII만**. 박스드로잉·도형·화살표 금지(폰트마다 폭이 0.92/1.79/2.00로 달라 칸이 깨진다).
- 쓸 문자: 테두리 `- | + =` · 방향 `^ v < >` · 표시 `* o # .` · 대각선 `/ \`
- 한글은 **줄 끝 주석(`//` 또는 `#`)** 안에만. 정렬 칸에 넣지 않는다.
- 한 줄 80자 이내.

## 4. 검증 (통과할 때까지 수정)

```
python _build/verify_depth.py cpp/trails/<trail>/chNNz.md   # z 파일 구조
python _build/verify_depth.py --diagrams                     # 도식 규칙(전체)
python _build/verify_cpp.py <scope>                          # g++ 컴파일·실행 검증
```

- `verify_cpp.py`의 scope: `101` | `trails` | `<트레일명>` | `all`
- **기존 러너 733개가 그대로 통과해야 한다.** 줄어들면 문제 영역을 건드린 것이다.
- x 파일을 만들었다면 그 트레일 scope로 돌려 새 정답도 전부 통과해야 한다.
- g++ 경로는 `verify_cpp.py`가 자동으로 찾는다(WinLibs UCRT).

## 5. C++ 정답 코드 작성 지침

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    // ...
    return 0;
}
```

- 출력 형식은 Python 원본과 **문자 단위로 동일**해야 한다(공백·줄바ꍔ 포함).
- 실수 출력은 `printf("%.2f")`나 `cout << fixed << setprecision(2)`로 자릿수를 맞춘다.
- 큰 수는 `long long`. `int` 오버플로가 나면 테스트가 조용히 틀린다.
- 브라우저 실행기가 없으므로(C++ 사이트는 정답 공개형) 실행 시간 제약은 느슨하지만, 검증 스크립트가 10초 타임아웃을 건다.
