# Ch2. 입출력 — Codetree 101 스터디 가이드

> 언어 C++ · 4개 레슨 · 개념 4 / 문제 11

## 📌 챕터 개요
`cout`을 이용한 출력 형식 조정(값을 `<<`로 이어 붙이기, 구분자·개행 넣기, `<iomanip>`로 소수점 자릿수 지정, 이스케이프 시퀀스)과 `cin`을 이용한 입력 처리(`>>` 연산자, 여러 값·여러 줄 입력)를 배웁니다. 입력받은 값을 알맞은 자료형(`int`, `double`, `char`, `string`)의 변수로 받고, 계산 결과를 정해진 포맷(소수점 자릿수, 구분자 등)에 맞춰 출력하는 것이 핵심 목표입니다. 마지막에는 합·평균 계산 같은 실전 입출력 연습으로 마무리합니다.

## 📖 개념 정리 (레슨별)

### L1. 출력
**핵심 개념**

- `cout`은 `<<` 연산자로 여러 값을 이어서 출력합니다. 값 사이에 넣고 싶은 구분자나 공백도 직접 `<<`로 끼워 넣습니다.
- 소수점 포맷, 이스케이프 시퀀스로 출력 형태를 자유롭게 다듬습니다.

**문법/사용법**

- 여러 값 출력 : `cout << a << b << c;` 처럼 `<<`로 계속 이어 붙임. 값 사이 공백이 필요하면 `<< " "`를 직접 넣어야 함(자동 공백 없음).
- 구분자 삽입 : 값 사이에 `<< "-" <<` 처럼 원하는 문자열을 끼워 넣음.
- 개행 : 줄을 바꾸려면 `<< "\n"` 또는 `<< endl`을 붙임. 붙이지 않으면 다음 출력이 같은 줄에 이어짐.
- 소수점 포맷 : `#include <iomanip>` 후 `cout << fixed << setprecision(n);` → 이후 실수는 소수 n자리까지 반올림해 표시.
- 이스케이프 시퀀스 : `"\n"`(줄바꿈), `"\t"`(탭) 등.

**예시**
```cpp
#include <iostream>
#include <iomanip>
using namespace std;
int main() {
    cout << "2024" << "-" << "04" << "-" << "27" << "\n"; // 2024-04-27
    cout << "apple" << ", "; cout << "banana" << "\n";     // apple, banana
    double pi = 3.141592;
    cout << "pi: " << fixed << setprecision(2) << pi << "\n"; // pi: 3.14
    cout << "1 + 1 = " << 1 + 1 << "\n";                   // 1 + 1 = 2
    return 0;
}
```

**주의·흔한 실수**

- `cout`은 값 사이에 공백을 자동으로 넣지 않음. 공백이 필요하면 반드시 `<< " "`를 직접 넣어야 함.
- 개행(`"\n"`)을 빠뜨리면 다음 출력이 같은 줄에 붙어 버림.
- `fixed`/`setprecision`은 한 번 설정하면 이후 출력에 계속 적용됨(상태가 유지됨). 필요한 시점 이후에 지정하는 것을 기억.

### L2. 입력 입문
**핵심 개념**

- `cin >> 변수`는 사용자로부터 값을 받아 **변수의 자료형에 맞게** 자동 변환해 담습니다.
- 정수는 `int`, 실수는 `double`로 변수를 선언해 두면 그 형태로 읽힙니다.

**문법/사용법**

- `int x; cin >> x;` : 한 값을 정수로 받음.
- `double y; cin >> y;` : 한 값을 실수로 받음.
- `cin >>`는 공백·개행을 건너뛰고 다음 값을 읽음.

**예시**
```cpp
#include <iostream>
using namespace std;
int main() {
    int age;
    cin >> age;
    cout << "your age is " << age << "\n";

    double height;
    cin >> height;
    cout << "your height is " << height << "\n";
    return 0;
}
```

**주의·흔한 실수**

- 변수 자료형을 잘못 고르면 값이 깨짐(예: 실수를 `int`로 받으면 소수부가 잘림).
- `cin >>`는 공백을 기준으로 토큰을 나누므로, 공백이 포함된 한 줄 전체를 받으려면 `getline(cin, s)`를 써야 함.
- 문자열은 `#include <string>` 후 `string s; cin >> s;`로 받음(공백 전까지 한 단어).

### L3. 입력 (여러 줄·한 줄 다중 입력)
**핵심 개념**

- `cin >>`는 공백과 개행을 똑같이 구분자로 취급하므로, 여러 줄이든 한 줄 여러 값이든 `>>`를 연달아 쓰면 순서대로 받습니다.
- 한 줄에 공백으로 여러 값이 와도 `cin >> a >> b >> c;` 한 줄로 나눠 받을 수 있습니다.

**문법/사용법**

- 여러 값 한 번에 : `cin >> a >> b >> c;` (공백·개행 모두 구분자).
- 문자열 다중 입력 : `string a, b, c; cin >> a >> b >> c;`.
- 형 변환은 자동 : `int num1, num2; cin >> num1 >> num2;` 로 받으면 바로 정수 계산 가능.

**예시**
```cpp
#include <iostream>
#include <string>
using namespace std;
int main() {
    string a, b, c;
    cin >> a >> b >> c;           // "apple banana cherry"
    cout << a << " " << b << " " << c << "\n";

    int num1, num2;
    cin >> num1 >> num2;          // "10 20"
    cout << "sum is " << num1 + num2 << "\n"; // 30
    return 0;
}
```

**주의·흔한 실수**

- 받을 변수 개수보다 입력 값이 적으면 나머지 변수는 값이 채워지지 않음.
- `cin >> s`는 공백 전까지만 읽으므로, 한 줄 전체(공백 포함)가 필요하면 `getline`을 써야 함.
- 계산하려면 처음부터 `int`/`double` 변수로 받아야 함. `string`으로 받으면 `+`가 문자열 이어붙이기가 됨.

### L4. 입출력 연습
**핵심 개념**

- 입력받은 수로 합과 평균을 계산하는 실전 패턴을 익힙니다.
- C++의 나눗셈 `/`는 피연산자가 모두 정수면 몫만 남는 **정수 나눗셈**이 됨에 주의합니다. 소수까지 필요한 평균은 한쪽을 실수로 만들어야 합니다.

**문법/사용법**

- 합 : `int total = num1 + num2;`
- 평균(실수) : `double average = total / 2.0;` (분모를 `2.0`으로 써서 실수 나눗셈 유도).
- 평균(정수) : 나누어떨어짐이 보장되면 `int average = total / 2;` 로 몫을 그대로 사용.
- 출력 포맷 : `cout << fixed << setprecision(1) << average;` 로 소수 자릿수 지정.

**연산자 활용 예시**

- 이 레슨은 변수와 연산자를 이용한 계산이 핵심 주제로, 합·평균 외에 다양한 산술 연산을 활용합니다.
- BMI 계산 예: `double bmi = weight / (height * height);` → `cin`으로 받은 실수에 `/`와 곱셈을 조합해 실생활 계산 수행. (C++에는 거듭제곱 연산자가 없어 `height * height`처럼 곱하거나 `<cmath>`의 `pow`를 씁니다.)

**예시**
```cpp
#include <iostream>
#include <iomanip>
using namespace std;
int main() {
    double num1, num2;
    cin >> num1 >> num2;
    double total = num1 + num2;
    cout << "sum: " << total << "\n";
    cout << "avg: " << fixed << setprecision(2) << total / 2 << "\n";
    return 0;
}
```

**주의·흔한 실수**

- 정수끼리 `/`하면 몫만 남음. 평균처럼 소수가 필요하면 `total / 2.0`처럼 실수 나눗셈을 써야 함(예: `int` 7과 3의 평균을 `/2`로 하면 `5.0`이 아니라 `5`가 됨).
- 평균 출력 시 요구된 소수 자릿수 포맷(`setprecision`)을 정확히 맞춰야 함(예: `15` → `15.0`).

## 🧩 문제 채점용 정리

### 1) 변수 출력하기 3 (Easy · 10XP · 정답률 86%)
- **요구사항**: 변수 a, b, c에 각각 1, 2, 'C'를 넣고 지정 형식으로 출력.
- **입력**: 없음.
- **출력**: a, b, c 값을 순서대로 출력하되 사이에 `->`를 포함.
- **예제**: (입력 없음) → `1->2->C`
- **제한**: Time 5000 ms / Memory 288 MiB
- **연습 개념**: `cout`에 구분자 문자열 끼워 넣기.
- **셀프체크 포인트**: 값 사이에 `->`를 직접 넣어 한 줄로 출력했는가.

```runner
@@SOLUTION
#include <iostream>
using namespace std;
int main() {
    int a = 1;
    int b = 2;
    char c = 'C';
    cout << a << "->" << b << "->" << c << "\n";
    return 0;
}
@@TESTS
--IN

--OUT
1->2->C
@@EXPL
**접근 방법**: 값 사이에 `->`를 끼워 한 줄로 출력하는 문제이므로, `cout`으로 값과 `"->"`를 번갈아 `<<`로 이어 붙이면 됩니다.

**코드 진행 과정**

- 변수 `a`, `b`, `c`에 각각 `1`, `2`, `'C'`를 대입합니다. 여기서 `a`, `b`는 `int`(정수), `c`는 `char`(문자)입니다.
- `cout << a << "->" << b << "->" << c << "\n";`처럼 값과 구분자 `"->"`를 번갈아 이어 붙이면 `1->2->C`가 한 줄로 출력됩니다.

**스스로 재작성할 때 생각 순서**

- C++의 `cout`은 값 사이에 자동으로 공백을 넣지 않는다는 점을 먼저 떠올립니다.
- 따라서 원하는 구분자 `->`를 값 사이마다 직접 `<< "->"`로 넣어 줍니다.
- 마지막에 `<< "\n"`으로 줄을 마무리하는 것을 잊지 않습니다.
```

### 2) 세 정수형 변수 선언 (Easy · 10XP · 정답률 87%)
- **요구사항**: 정수 변수 3개에 7, 23, 30을 대입하고 변수로 덧셈식을 완성해 출력.
- **입력**: 없음.
- **출력**: `7 + 23 = 30` 형식.
- **예제**: (입력 없음) → `7 + 23 = 30`
- **제한**: Time 5000 ms / Memory 288 MiB
- **연습 개념**: 변수 선언 + 출력 문자열 구성.
- **셀프체크 포인트**: 숫자와 기호(`+`, `=`) 사이 공백까지 정확히 맞췄는가.

```runner
@@SOLUTION
#include <iostream>
using namespace std;
int main() {
    int a = 7;
    int b = 23;
    int c = 30;
    cout << a << " + " << b << " = " << c << "\n";
    return 0;
}
@@TESTS
--IN

--OUT
7 + 23 = 30
@@EXPL
**접근 방법**: 세 정수 변수를 선언하고, 변수와 기호를 섞어 `7 + 23 = 30` 형태의 식으로 출력하는 문제입니다. 공백까지 직접 `cout`에 넣어 줍니다.

**코드 진행 과정**

- `a`, `b`, `c`에 각각 `7`, `23`, `30`을 대입합니다.
- `cout << a << " + " << b << " = " << c << "\n";`처럼 변수와 `" + "`, `" = "`를 이어 붙입니다. 기호 양옆의 공백을 문자열 안에 포함해 두면 `7 + 23 = 30`이 그대로 완성됩니다.

**스스로 재작성할 때 생각 순서**

- 출력할 문장을 조각으로 나눕니다: `a`, `+`, `b`, `=`, `c`.
- C++은 값 사이에 자동 공백이 없으므로, 기호와 공백을 `" + "`, `" = "`처럼 한 덩어리 문자열로 만들어 끼웁니다.
- 값과 문자열을 `<<`로 순서대로 이어 붙이면 문장이 완성됨을 확인합니다.
```

### 3) 달에서 무게 구하기 (Easy · 10XP · 정답률 81%)
- **요구사항**: 추의 무게(13)와 달 중력 비율(0.165)을 변수에 저장, 곱셈식과 결과를 출력.
- **입력**: 없음.
- **출력**: 곱셈식과 결과 출력, 실수값은 모두 소수점 여섯째 자리까지 표현.
- **예제**: (입력 없음) → `13 * 0.165000 = 2.145000`
- **제한**: Time 5000 ms / Memory 288 MiB
- **연습 개념**: `fixed`/`setprecision(6)`로 소수점 포맷.
- **셀프체크 포인트**: `0.165`도 `0.165000`처럼 6자리로 채워 출력했는가.

```runner
@@SOLUTION
#include <iostream>
#include <iomanip>
using namespace std;
int main() {
    int weight = 13;
    double ratio = 0.165;
    double result = weight * ratio;
    cout << weight << " * " << fixed << setprecision(6) << ratio
         << " = " << result << "\n";
    return 0;
}
@@TESTS
--IN

--OUT
13 * 0.165000 = 2.145000
@@EXPL
**접근 방법**: 실수값을 항상 소수점 여섯째 자리까지 표시해야 하므로 `<iomanip>`의 `fixed`와 `setprecision(6)`을 사용합니다.

**코드 진행 과정**

- `weight`에 `13`(정수), `ratio`에 `0.165`(실수)를 저장하고, `double result = weight * ratio;`로 곱셈 결과 `2.145`를 구합니다.
- 출력 도중 `<< fixed << setprecision(6)`을 넣으면 그 이후 실수는 소수 6자리로 표시됩니다. 정수 `weight`는 그대로, `ratio`와 `result`는 6자리로 채워져 `13 * 0.165000 = 2.145000`이 됩니다.

**스스로 재작성할 때 생각 순서**

- 출력 형식 `수 * 수 = 수`를 `cout` 뼈대로 먼저 잡습니다.
- "모든 실수는 6자리까지"라는 조건을 보고, 실수를 출력하기 직전에 `fixed << setprecision(6)`을 한 번 설정합니다(이후 계속 적용됨).
- `0.165`도 6자리로 채우면 뒤에 0이 붙어 `0.165000`이 된다는 점을 확인합니다.
```

### 4) 점수 입출력 (Easy · 10XP · 정답률 79%)
- **요구사항**: 점수 N을 입력받아 지정 포맷으로 출력.
- **입력**: 첫 줄에 정수 N (1 ≤ N ≤ 1000).
- **출력**: `Your score is N point.` 형식.
- **예제**: `143` → `Your score is 143 point.`
- **제한**: Time 1000 ms / Memory 64 MiB
- **연습 개념**: `cin >>`로 정수 입력, 문자열과 변수 함께 출력.
- **셀프체크 포인트**: 마침표(`.`) 포함 여부, 공백 위치가 정확한가.

```runner
@@SOLUTION
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    cout << "Your score is " << n << " point." << "\n";
    return 0;
}
@@TESTS
--IN
143
--OUT
Your score is 143 point.
--IN
1000
--OUT
Your score is 1000 point.
@@EXPL
**접근 방법**: 정수 하나를 입력받아 정해진 문장 안에 끼워 출력합니다. `cin >> n`과 `cout`을 씁니다.

**코드 진행 과정**

- `int n; cin >> n;`으로 한 값을 정수로 읽습니다.
- `cout << "Your score is " << n << " point." << "\n";`에서 `n` 자리에 값이 들어가고, 마침표까지 그대로 출력됩니다.

**스스로 재작성할 때 생각 순서**

- 고정된 문장 틀 `Your score is __ point.`을 먼저 적습니다.
- 빈칸에 들어갈 값이 입력받은 정수임을 확인하고, 그 자리에서 `cout`을 끊어 `<< n <<`으로 값을 끼웁니다.
- 문장 끝 마침표와 단어 사이 공백을 예제와 한 글자도 다르지 않게 맞춥니다.
```

### 5) 입력받아 계산 (Easy · 10XP · 정답률 90%)
- **요구사항**: 정수 a를 입력받아 a+2를 출력.
- **입력**: 첫 줄에 정수 a (1 ≤ a ≤ 100).
- **출력**: 계산 후 정수 값.
- **예제**: `18` → `20`
- **제한**: Time 1000 ms / Memory 80 MiB
- **연습 개념**: 정수 입력 후 산술 연산.
- **셀프체크 포인트**: 값을 `int`로 받아 숫자 덧셈이 되도록 했는가.

```runner
@@SOLUTION
#include <iostream>
using namespace std;
int main() {
    int a;
    cin >> a;
    cout << a + 2 << "\n";
    return 0;
}
@@TESTS
--IN
18
--OUT
20
--IN
100
--OUT
102
@@EXPL
**접근 방법**: 입력을 정수로 받은 뒤 2를 더해 출력하는 기본 산술 문제입니다.

**코드 진행 과정**

- `int a; cin >> a;`로 입력을 정수 변수에 담습니다. `int`로 받았기 때문에 뒤의 `+`가 숫자 덧셈으로 동작합니다.
- `cout << a + 2 << "\n";`로 `a`에 2를 더한 정수를 출력합니다. 입력 `18`이면 `20`이 나옵니다.

**스스로 재작성할 때 생각 순서**

## ✅ 마스터 체크리스트
- [ ] `cout <<`로 여러 값을 이어 출력하고, 값 사이 공백·구분자를 직접 넣을 수 있다.
- [ ] `"\n"` 또는 `endl`로 줄을 바꾸고, 생략하면 같은 줄에 이어짐을 안다.
- [ ] `<iomanip>`의 `fixed`와 `setprecision(n)`으로 소수 자릿수를 지정한다.
- [ ] 이스케이프 시퀀스 `"\n"`, `"\t"`의 출력 효과를 안다.
- [ ] `cin >> 변수`가 변수 자료형에 맞게 값을 읽어옴을 이해한다.
- [ ] `cin >>`는 공백·개행을 모두 구분자로 보므로 여러 줄·한 줄 다중 입력을 함께 받는다.
- [ ] `cin >> a >> b >> c`로 한 번에 여러 값을 받는다.
- [ ] 계산이 필요하면 처음부터 `int`/`double` 변수로 받는다.
- [ ] 소수 자릿수 포맷을 요구사항에 맞게 정확히 맞춘다.
- [ ] 합·평균 계산에서 정수 나눗셈(`/`)과 실수 나눗셈(`/2.0`) 차이를 안다.

## ⚠️ 자주 하는 실수
- **자동 공백 기대**: `cout << a << b`는 값이 붙어 나옴. 공백이 필요하면 `<< " "`를 직접 넣어야 함.
- **개행 누락**: 각 줄 끝에 `"\n"`/`endl`을 붙이지 않아 출력이 한 줄에 붙어 버림.
- **정수/실수 나눗셈 혼동**: 평균에서 `total / 2`처럼 정수끼리 나눠 소수부가 잘림(`7/2`→`3`). 소수가 필요하면 `total / 2.0`.
- **소수 자릿수 불일치**: `15` → `15.00`, 평균 `5` → `5.0`처럼 `setprecision`으로 요구된 자릿수를 채우지 않음.
- **반올림 자리올림 간과**: `577.999564`를 셋째 자리로 반올림하면 `578.000`이 되는 경우를 놓침.
- **`setprecision` 위치·상태 착각**: 한 번 설정하면 이후 출력에 계속 적용됨. `fixed` 없이 `setprecision`만 쓰면 유효숫자 개수로 동작해 결과가 달라짐.
- **자료형 선택 실수**: 계산할 값을 `string`으로 받아 `+`가 문자열 이어붙이기가 되거나, 실수를 `int`로 받아 소수부가 잘림.
- **출력 포맷 세부 누락**: 마침표, 공백, 화살표(`->`) 등 문자 하나까지 예제와 일치시켜야 채점 통과.
```
