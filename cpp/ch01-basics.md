# Ch1. 기본 — Codetree 101 스터디 가이드
> 언어 C++ · 4개 레슨 · 개념 4 / 문제 4

## 📌 챕터 개요
프로그래밍을 처음 시작할 때 필요한 기본기를 다룬다. 화면에 값을 내보내는 `cout`, 데이터를 담아두는 변수, 값의 종류를 규정하는 기본 자료형(int/double/bool/char), 그리고 값을 계산·비교·결합하는 연산자까지가 학습 대상이다.
학습 목표: (1) 문자열과 숫자를 올바르게 출력할 수 있다. (2) 변수에 값을 저장·변경·복사하는 흐름을 이해한다. (3) 자료형과 형 변환 규칙을 안다. (4) 산술/비교/논리 연산자를 상황에 맞게 사용한다.

## 📖 개념 정리 (레슨별)

### L1. 출력 입문
**핵심 개념**: `cout`은 `<<`(스트림 삽입 연산자)로 넘긴 값을 화면에 내보내는 표준 출력 스트림이다. 결과 확인, 디버깅, 메시지 표시에 쓰인다. `cout`을 쓰려면 맨 위에 `#include <iostream>`가 필요하고, `std::` 없이 짧게 쓰려면 `using namespace std;`를 선언한다.
**문법/사용법**:

- 문자열(여러 글자)은 큰따옴표 `" "`로 감싼다. 문자 하나(char)는 작은따옴표 `' '`로 감싼다. C++에서 둘은 서로 다르다.
- 숫자(정수·실수)는 따옴표 없이 그대로 넣는다.
- `cout`은 자동으로 줄바꿈하지 않는다. 줄을 바꾸려면 `<<`로 개행 문자 `"\n"`(또는 `endl`)을 직접 붙여야 한다.
- `<<`는 여러 개를 이어 쓸 수 있다: `cout << "합: " << 13 << "\n";`
- `//` 뒤의 내용은 주석으로, 실행되지 않는다(설명·메모용). 여러 줄 주석은 `/* ... */`.

**예시**:
```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << "\n"; // 문자열 출력
    cout << 100 << "\n";              // 정수 출력 -> 100
    cout << 3.14 << "\n";             // 실수 출력 -> 3.14
    cout << "첫 번째 줄" << "\n";
    cout << "두 번째 줄" << "\n";     // 서로 다른 두 줄로 출력됨
    // cout << "이 줄은 주석이라 실행 안 됨";
    return 0;
}
```
**주의·흔한 실수**:

- `"\n"`을 빠뜨리면 여러 출력이 한 줄에 붙어 나온다. C++의 `cout`은 자동 개행을 하지 않는다.
- 문자열에 따옴표를 빠뜨리면 변수 이름으로 해석되어 컴파일 오류가 난다.
- 숫자를 따옴표로 감싸면 "숫자 모양의 문자열"이 되어 이후 계산이 안 된다.
- 문자 하나에 큰따옴표(`"A"`)를 쓰면 문자열, 작은따옴표(`'A'`)를 쓰면 char다. 문자 변수(char)에 담을 때는 작은따옴표를 쓴다.

### L2. 변수
**핵심 개념**: 변수는 데이터를 저장하는 메모리 공간에 붙인 이름이다. 이름을 통해 저장된 값을 읽고 바꿀 수 있다. C++은 변수를 처음 만들 때 자료형을 함께 적어 선언한다: `int a = 3;`.
**문법/사용법**:

- 선언 형태는 `자료형 이름 = 값;`이다. 예) `int num = 12;`, `double price = 3.14;`.
- 대입 연산자 `=`는 수학의 등호가 아니라 "오른쪽 값을 왼쪽 변수에 저장하라"는 명령이다. (왼쪽=변수명, 오른쪽=값)
- 이미 선언한 변수에는 자료형 없이 이름만 써서 다시 대입한다: `num = 20;`. 값이 덮어써진다.
- 명명 규칙: 알파벳·숫자·밑줄(`_`) 사용 가능 / 숫자로 시작 불가 / 대소문자 구분(`age`와 `Age`는 다름) / 예약어(`for`, `if`, `else`, `int` 등) 사용 불가 / 의미 있는 이름 권장.

**주요 자료형 (미리 보기)**:

지금은 `int`/`double`/`bool`/`char`/`string` 다섯만 기억하면 충분하다.

먼저 익힐 것 (핵심)

- 정수형 `int`: 소수점 없는 수. 예) `int num = 12;` — 바로 다음 L3에서 깊게 다룸
- 실수형 `double`: 소수점 있는 수. 예) `double price = 3.14;` — L3에서 다룸
- 불리언 `bool`: 참(`true`)/거짓(`false`). 예) `bool isStudent = true;` — L3에서 다룸
- 문자형 `char`: 작은따옴표로 감싼 문자 하나. 예) `char grade = 'A';`
- 문자열 `string`: 큰따옴표로 감싼 여러 문자. 예) `string fruit = "banana";` (`#include <string>` 필요) — Ch7에서 깊게 다룸

나중에 배울 것 (지금은 이름만)

- 배열 `array`: 같은 자료형 값을 여러 개 순서대로 담는 묶음. 예) `int nums[3] = {1, 3, 5};` — Ch6에서 깊게 다룸
- 부호 없는 정수 `unsigned`, 큰 정수 `long long` 등: 표현 범위가 다른 정수 계열 — 필요할 때 다룸

**예시**:
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int a = 3;
    cout << a << "\n";     // 3
    a = 10;                // 값을 덮어씀 (자료형 없이 이름만)
    cout << a << "\n";     // 10

    string name = "홍길동";
    bool isStudent = true;
    cout << name << "\n";       // 홍길동
    cout << isStudent << "\n";  // 1  (bool은 true=1, false=0으로 출력)
    return 0;
}
```
**주의·흔한 실수**:

- `a = b`는 "a와 b가 같다"가 아니라 "b의 값을 a에 넣는다"이다. 방향(오른쪽→왼쪽)에 주의.
- 변수를 선언하지 않고 바로 사용하려 하면 컴파일 오류가 난다. C++은 반드시 먼저 선언해야 한다.
- 이미 선언한 변수에 다시 `int a = 10;`처럼 자료형을 붙이면 "중복 선언" 오류다. 재대입은 이름만 쓴다(`a = 10;`).
- 대소문자를 섞어 쓰면 서로 다른 변수로 취급되니 일관성 있게 작성.

### L3. 기본 자료형
**핵심 개념**: 자료형은 값의 종류와 처리 방식을 규정한다. 기본은 정수형(int), 실수형(double), 불리언형(bool), 문자형(char)이다.
**문법/사용법**:

- **int(정수형)**: 소수점 없는 정수(양수·음수·0). `10 + 3` → `13`.
- **double(실수형)**: 소수점 포함 실수. `cout`은 기본적으로 유효숫자 6자리까지 출력한다(`3.14`는 `3.14`, `1.0/3.0`은 `0.333333`).
- **bool(불리언형)**: `true` / `false`만 가짐. 조건·논리 판단에 사용. `cout`으로 출력하면 `true`는 `1`, `false`는 `0`으로 나온다.
- **char(문자형)**: 작은따옴표로 감싼 문자 하나. 예) `char c = 'A';`.
- **형 변환**:
  - double → int (`(int)`): 소수점 이하를 **버림(반올림 아님, 0 방향으로 절삭 = truncate)**: `(int)3.14` → `3`, `(int)4.99` → `4`, `(int)-4.99` → `-4`.
  - 이 "0 방향 잘라내기"는 floor(내림, 더 작은 정수 쪽)와 음수에서 갈린다: `(int)-2.99` → `-2`(0 쪽)이지만 내림은 `-3`(작은 쪽). 지금은 `(int)`(truncate)만 기억하면 된다.
  - int → double: 정수를 실수 자리에 쓰면 자동으로 실수가 된다: `(double)5` → `5`(값 `5.0`, 출력은 `5`).
  - 정수 → bool: `0`만 `false`, 그 외 전부 `true` (`(bool)-5` → `true`).
  - bool → 정수: `(int)true` → `1`, `(int)false` → `0`.

**예시**:
```cpp
#include <iostream>
using namespace std;

int main() {
    cout << (int)4.99 << "\n";   // 4  (버림)
    cout << (int)-2.99 << "\n";  // -2 (0 방향 절삭)
    cout << (double)5 << "\n";   // 5  (값은 5.0이지만 cout 기본 출력은 5)
    cout << (bool)0 << "\n";     // 0  (false)
    cout << (int)true << "\n";   // 1
    return 0;
}
```
**주의·흔한 실수**:

- `(int)`가 반올림이라고 착각하지 말 것. `(int)4.99`는 `5`가 아니라 `4`.
- 음수 절삭 방향에 유의: `(int)-2.99`는 `-3`이 아니라 `-2`.
- `(bool)0`만 `false`이고, `(bool)-5`처럼 0이 아닌 값은 전부 `true`.
- bool 값을 `cout`으로 출력하면 글자 `true`/`false`가 아니라 숫자 `1`/`0`이 나온다.

### L4. 연산자
**핵심 개념**: 연산자는 값을 계산·비교·결합하거나 변수 값을 간결하게 갱신한다. 크게 산술 / 비교 / 논리 / 복합대입 4종.

**산술 연산자**

| 연산자 | 의미 | 예시 | 결과 |
|--------|------|------|------|
| `+` | 덧셈 | `10 + 3` | `13` |
| `-` | 뺄셈 | `10 - 3` | `7` |
| `*` | 곱셈 | `10 * 3` | `30` |
| `/` | 나눗셈(정수끼리는 몫) | `9 / 3` | `3` |
| `/` | 나눗셈(실수가 섞이면 실수) | `9.0 / 2` | `4.5` |
| `%` | 나머지(정수끼리만) | `10 % 3` | `1` |

- **정수 나눗셈 주의**: `int / int`는 소수점을 버린 **몫**을 준다. `10 / 3` → `3`(3.333…이 아님), `35 / 8` → `4`. 실수 결과가 필요하면 한쪽을 double로: `10.0 / 3` → `3.33333`.
- int와 double를 섞으면 자동으로 double 결과가 된다: `5 + 3.2` → `8.2`.
- `%`(나머지)는 정수끼리만 쓸 수 있다. 실수에는 사용할 수 없다.

**비교 연산자** (결과는 `bool`, 출력 시 `1`/`0`)

| 연산자 | 의미 | 예시 | 결과 |
|--------|------|------|------|
| `==` | 같다 | `5 == 5` | `true`(1) |
| `!=` | 다르다 | `5 != 3` | `true`(1) |
| `<` `>` | 작다 / 크다 | `5 > 3` | `true`(1) |
| `<=` `>=` | 이하 / 이상 | `5 <= 3` | `false`(0) |

- 범위 검사는 `&&`로 나눠 쓴다(연쇄 비교 문법은 없다): `17 < age && age < 23`.

**논리 연산자**

| 연산자 | 의미 | 참이 되는 조건 |
|--------|------|----------------|
| `&&` | 그리고(AND) | 양쪽 모두 true |
| `\|\|` | 또는(OR) | 하나라도 true |
| `!` | 부정(NOT) | 반대로 뒤집음 |

**복합 대입 연산자** (`a = a + 3`을 `a += 3`으로 축약)

| 연산자 | 예시 (초깃값) | 결과 |
|--------|----------------|------|
| `+=` | `int x = 10; x += 5;` | `15` |
| `-=` | `int x = 10; x -= 3;` | `7` |
| `*=` | `int x = 4;  x *= 3;` | `12` |
| `/=` | `int x = 20; x /= 4;` | `5` (int 몫) |
| `/=` | `int x = 20; x /= 3;` | `6` (int 몫, 소수점 버림) |
| `%=` | `int x = 20; x %= 6;` | `2` |
| `++` | `int x = 5;  x++;` | `6` (1 증가) |
| `--` | `int x = 5;  x--;` | `4` (1 감소) |

**주의·흔한 실수**:

- 정수끼리의 `/`는 몫만 준다(`9 / 3` → `3`, `7 / 2` → `3`). 실수 결과가 필요하면 한쪽을 `double`로 만든다(`7.0 / 2` → `3.5`).
- `==`(비교)와 `=`(대입)을 혼동하지 말 것. 조건에서 `=`를 쓰면 대입이 되어 버려 논리 오류가 난다.
- `%`(나머지)는 정수끼리만 가능하다. 실수에는 쓸 수 없다.

## 🧩 문제 채점용 정리

### 1) 2줄 출력 (Easy · 10XP · 정답률 81%)
- **요구사항**: `Hello`와 `World`를 각각 한 줄씩 출력하는 프로그램을 작성한다.
- **입력**: 없음.
- **출력**: 첫 줄에 `Hello`, 둘째 줄에 `World`.
- **예제**: 출력
  ```
  Hello
  World
  ```
- **제한**: Time 5000ms / Memory 288 MiB.
- **연습 개념**: `cout` 기본 출력, `"\n"`으로 줄바꿈.
- **셀프체크 포인트**: 두 단어를 한 줄에 붙여 쓰지 않았는지, 대소문자(H, W 대문자)와 철자를 정확히 맞췄는지 확인. 각 줄 끝에 `"\n"`을 붙여 줄이 나뉘는지 점검(C++ `cout`은 자동 개행하지 않음).

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    cout << "Hello" << "\n";
    cout << "World" << "\n";
    return 0;
}
@@TESTS
--IN
--OUT
Hello
World
@@EXPL
`cout`은 `<<`로 넘긴 값을 화면에 출력한다. 자동으로 줄을 바꾸지 않으므로, 줄을 나누려면 각 출력 끝에 개행 문자 `"\n"`을 직접 붙여야 한다.

- `cout << "Hello" << "\n";` → `Hello`를 출력하고 줄을 바꾼다.
- `cout << "World" << "\n";` → 다음 줄에 `World`를 출력한다.

문자열은 반드시 큰따옴표로 감싸고, 대소문자(H, W)와 철자를 예제와 똑같이 맞춘다. 줄이 나뉘어야 하는 곳마다 `"\n"`을 빠뜨리지 않았는지 확인하면 쉽다.
```

### 2) 문자 변경하기 (Easy · 10XP · 정답률 81%)
- **요구사항**: 변수 `a`에 먼저 `C`를 넣고, 그 뒤 다시 `a`에 `T`를 넣은 다음 `a`를 출력한다.
- **입력**: 없음.
- **출력**: 첫 줄에 변수 `a`의 최종 값.
- **예제**: 출력 `T`
- **제한**: Time 5000ms / Memory 288 MiB.
- **연습 개념**: 변수 대입과 값 덮어쓰기(재대입).
- **셀프체크 포인트**: 나중에 대입한 값이 이전 값을 덮어쓴다는 점이 핵심. 최종 출력이 `C`가 아니라 `T`가 되어야 함. 문자 하나는 `char`이므로 작은따옴표(`'T'`)로 감싸야 함.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    char a = 'C';
    a = 'T';
    cout << a << "\n";
    return 0;
}
@@TESTS
--IN

--OUT
T
@@EXPL
이 문제는 **변수 재대입(덮어쓰기)** 개념을 확인한다. 같은 변수에 값을 다시 넣으면 이전 값은 사라지고 마지막 값만 남는다.

- `char a = 'C';` → 문자형 변수 `a`에 문자 `'C'`를 저장한다(선언 + 초기화).
- `a = 'T';` → 같은 변수 `a`에 `'T'`를 다시 저장한다. 이때 자료형은 다시 적지 않고 이름만 쓴다. 이 순간 앞의 `'C'`는 덮어써져 사라진다.
- `cout << a << "\n";` → 현재 `a`의 값인 `T`를 출력한다.

스스로 다시 짤 때는 이렇게 생각한다.

- 대입은 항상 "오른쪽 값을 왼쪽 변수에 넣는 명령"이며, 나중 대입이 이긴다는 점을 떠올린다.
- 문자 하나는 `char`이므로 작은따옴표(`'T'`)로 감싼다. 큰따옴표(`"T"`)는 문자열이라 char에 담을 수 없다.
- 재대입할 때 `char a = 'T';`처럼 자료형을 또 붙이면 중복 선언 오류다. 이름만 쓴다.
- 출력은 마지막에 남은 값 기준이라는 것을 기억하고, `C`가 아니라 `T`가 나오는지 검산한다.
```

### 3) 변수 값 복사하기 3 (Easy · 10XP · 정답률 83%)
- **요구사항**: 정수 `a`, `b`, `c`에 각각 `1`, `5`, `3`을 넣고 → `c`의 값을 `a`에 복사 → `a`에는 `a + c`를, `b`에는 `b - c`를 대입 → 모든 연산 후 `a`, `b`, `c`를 차례로 출력한다.
- **입력**: 없음.
- **출력**: `a`, `b`, `c`를 한 줄에 하나씩(총 3줄).
- **예제**: 출력
  ```
  6
  2
  3
  ```
  (검산: `c=3`을 `a`에 복사 → `a=3`; `a = a + c = 3 + 3 = 6`; `b = b - c = 5 - 3 = 2`; `c=3` 그대로 → `6, 2, 3`)
- **제한**: Time 5000ms / Memory 384 MiB.
- **연습 개념**: 변수 복사, 순차적 대입, 연산 순서 추적.
- **셀프체크 포인트**: 연산 순서가 결과를 좌우한다. `c`를 `a`에 복사한 "이후"의 `a` 값으로 `a + c`를 계산해야 함(원래 `a=1`이 아님). `b - c`에 쓰이는 `c`는 여전히 `3`인지 확인.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int a = 1;
    int b = 5;
    int c = 3;
    a = c;
    a = a + c;
    b = b - c;
    cout << a << "\n";
    cout << b << "\n";
    cout << c << "\n";
    return 0;
}
@@TESTS
--IN

--OUT
6
2
3
@@EXPL
이 문제는 **변수 복사와 순차 대입**을 손으로 추적하는 연습이다. 각 줄이 실행될 때 변수 값이 어떻게 바뀌는지 순서대로 따라가는 것이 핵심이다.

- `int a = 1; int b = 5; int c = 3;`으로 초기화한다.
- `a = c;` → `c`의 값 `3`을 `a`에 복사한다. 이제 `a=3` (원래의 `1`은 사라짐).
- `a = a + c;` → 지금의 `a=3`과 `c=3`을 더해 `a=6`이 된다. 여기서 `a`는 반드시 복사 "이후"의 값이어야 한다.
- `b = b - c;` → `5 - 3 = 2`이므로 `b=2`. 이때 `c`는 계속 `3`이다.
- `c`는 처음부터 끝까지 대입된 적이 없으므로 `3` 그대로다.
- 마지막에 `a`, `b`, `c`를 한 줄씩 출력하면 `6`, `2`, `3`.

스스로 다시 짤 때는 이렇게 생각한다.

- 종이에 `a b c` 세 칸을 그려두고, 한 줄 실행할 때마다 값을 지우고 새로 적는다.
- `a = c;`처럼 복사가 나오면 "그 순간의 오른쪽 값"을 왼쪽에 넣는다는 것을 명심한다.
- 이후 계산은 항상 "지금 저장돼 있는 최신 값"으로 한다. 원래 초깃값(`a=1`)을 다시 쓰지 않는다.
```

### 4) 사칙연산 연습 (Easy · 10XP · 정답률 87%)
- **요구사항**: `a`에 `5`, `b`에 `30`을 넣고 둘의 합을 `c`에 저장한 뒤, `c`를 `8`로 나눈 **몫**과 **나머지**를 출력한다.
- **입력**: 없음.
- **출력**: 첫 줄에 몫, 둘째 줄에 나머지.
- **예제**: 출력
  ```
  4
  3
  ```
  (검산: `c = 5 + 30 = 35`; `35 / 8 = 4`(정수 몫), `35 % 8 = 3`)
- **제한**: Time 100ms / Memory 128 MiB.
- **연습 개념**: 산술 연산, 정수 나눗셈 `/`(몫)과 나머지 `%`의 구분.
- **셀프체크 포인트**: C++에서 정수끼리의 `/`는 몫을 준다(`35 / 8` → `4`, `4.375`가 아님). 몫과 나머지의 출력 순서를 뒤바꾸지 않았는지 확인.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int a = 5;
    int b = 30;
    int c = a + b;
    cout << c / 8 << "\n";
    cout << c % 8 << "\n";
    return 0;
}
@@TESTS
--IN

--OUT
4
3
@@EXPL
이 문제는 **정수 나눗셈 `/`(몫)과 나머지 `%`의 구분**을 연습한다. C++에서 정수끼리 `/`를 하면 소수점을 버린 몫이, `%`를 하면 나머지가 나온다.

- `int a = 5; int b = 30;`을 저장하고 `int c = a + b = 35;`를 만든다.
- `c / 8` → `35`를 `8`로 나눈 정수 몫. `8 * 4 = 32`, `8 * 5 = 40`은 넘으므로 몫은 `4`. (정수끼리라 소수점은 버려진다.)
- `c % 8` → 나눈 뒤 남는 나머지. `35 - 32 = 3`이므로 `3`.
- 몫을 먼저, 나머지를 그다음 줄에 출력한다.

스스로 다시 짤 때는 이렇게 생각한다.

- C++에서는 `int / int`가 곧 몫이다. 실수 결과가 필요하면 한쪽을 `double`로 만들어야 하지만, 여기서는 몫이 필요하므로 정수 그대로 둔다.
- 합을 담는 중간 변수 `c`를 만들어 두면 식이 깔끔해진다.
- 출력 순서(몫 → 나머지)를 문제 요구대로 맞췄는지 마지막에 다시 확인한다.
```

## ✅ 마스터 체크리스트
- [ ] `cout`으로 문자열과 숫자를 각각 올바른 형식(따옴표 유무)으로 출력할 수 있다.
- [ ] `cout`이 자동 개행하지 않음을 이해하고 `"\n"`으로 여러 줄 출력을 만들 수 있다.
- [ ] 변수를 자료형과 함께 선언·대입하고, 재대입으로 값을 덮어쓸 수 있다.
- [ ] 변수 간 값 복사와 순차 연산의 결과를 손으로 추적할 수 있다.
- [ ] int / double / bool / char의 차이를 알고 알맞게 선언할 수 있다.
- [ ] `(int)`(버림), `(double)`, `(bool)` 형 변환 규칙을 정확히 안다.
- [ ] 정수 `/`(몫)와 실수 나눗셈, `%`(나머지)를 구분해 쓸 수 있다.
- [ ] 비교/논리/복합대입 연산자의 결과를 예측할 수 있다.

## ⚠️ 자주 하는 실수
- 각 출력 끝에 `"\n"`을 빠뜨려 여러 줄이 한 줄로 붙어 나오는 경우(C++ `cout`은 자동 개행 안 함).
- 숫자를 따옴표로 감싸 문자열로 만들어 버려 이후 계산이 안 되는 경우.
- 문자 하나에 큰따옴표(`"T"`)를 써서 char 변수에 담으려다 오류가 나는 경우(char는 작은따옴표 `'T'`).
- 변수를 선언 없이 바로 쓰거나, 재대입 시 자료형을 또 붙여 중복 선언 오류가 나는 경우.
- `(int)`를 반올림으로 착각(`(int)4.99`는 `4`), 음수 절삭 방향 혼동(`(int)-2.99`는 `-2`).
- 실수 결과가 필요한데 정수끼리 `/`를 써서 몫만 나오는 경우(한쪽을 `double`로 만들어야 함).
- `=`(대입)과 `==`(비교)를 혼동하는 경우.
- 변수 복사·순차 대입 문제에서 "복사 이후"가 아닌 원래 값으로 계산하는 순서 실수.
- 여러 줄 출력이 필요한데 한 줄로 붙여 출력하거나, 출력 순서를 뒤바꾸는 경우.
