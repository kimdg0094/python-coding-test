# Ch3. 조건문 1 — Codetree 101 스터디 가이드

> 언어 C++ · 4개 레슨 · 개념 4 / 문제 8

## 📌 챕터 개요

프로그램이 상황에 따라 다른 동작을 하도록 만드는 조건문을 배웁니다. 참/거짓으로 평가되는 조건식을 세우고, `if` / `if-else` / `if-else if-else` 구조로 코드 흐름을 분기하는 법을 익힙니다. 비교 연산자와 중괄호 블록 규칙을 정확히 이해해 단일 조건부터 다중 조건 분기까지 안정적으로 처리하는 것이 목표입니다.

## 📖 개념 정리 (레슨별)

### L1. 조건문 입문

**핵심 개념**

- 조건문은 "특정 조건이 참일 때만 특정 코드를 실행"하도록 하는 구조입니다. 덕분에 상황마다 다른 동작을 하는 유연한 프로그램을 만들 수 있습니다.
- 조건문은 크게 두 부분으로 나뉩니다: (1) 참(true)/거짓(false)으로 평가되는 **조건**, (2) 조건이 참일 때 수행할 **동작**.
- 예: "온도가 30도 이상이면 에어컨을 켠다" → 조건은 "온도 ≥ 30", 동작은 "에어컨 켜기".

**문법/사용법**

- 이 레슨은 개념 소개 단계로, 구체적 문법보다 "언제·왜 조건문이 필요한가"에 초점을 둡니다.
- 다양한 상황 처리, 유연성 향상, 불필요한 실행 방지(효율성)라는 세 가지 이유로 조건문이 쓰입니다.

**예시**
```cpp
#include <iostream>
using namespace std;

int main() {
    // 아이디어: 온도가 30 이상이면 에어컨을 켠다
    int temp = 32;
    if (temp >= 30) {
        cout << "air on" << "\n";
    }
    return 0;
}
```

**주의·흔한 실수**

- 조건은 반드시 true/false로 판정 가능한 표현식이어야 합니다. 단순 값(예: 그냥 숫자)만으로는 "무엇을 판별하는지" 명확히 설계해야 합니다.
- 예시 문제(짝수/홀수 판별)에서는 나머지 연산 `n % 2 == 0` 같은 참/거짓 조건을 세우는 감각을 먼저 익히세요.

### L2. If

**핵심 개념**

- `if 문`은 하나의 조건을 평가하여 **참일 때만** 해당 코드 블록을 실행합니다. 거짓이면 그 블록을 건너뜁니다.
- 조건에는 비교 연산자로 만든 논리 표현식을 사용합니다: `==`, `!=`, `<`, `>`, `<=`, `>=`.

**문법/사용법**
```cpp
if (조건) {
    실행할 동작
}
```

- `if (조건)` 다음의 **중괄호 `{ }`** 안에 실행할 블록을 적습니다. C++는 중괄호로 코드 블록을 구분합니다.
- 조건이 거짓이면 중괄호 블록을 통째로 건너뛰고, 그 뒤 코드로 넘어갑니다.

**예시**
```cpp
#include <iostream>
using namespace std;

int main() {
    int age;
    cin >> age;

    if (age >= 18) {
        cout << "adult" << "\n";
        cout << "good" << "\n";
    }

    cout << "check done" << "\n";
    // age=20 -> adult / good / check done
    // age=10 -> check done  (if 블록은 건너뜀)
    return 0;
}
```

**주의·흔한 실수**

- 실행할 문장이 두 줄 이상이면 반드시 `{ }`로 묶어야 합니다. 중괄호를 생략하면 `if` 바로 다음 한 문장만 조건에 묶이고 나머지는 항상 실행되어 버그가 됩니다.
- 어디까지가 조건부 블록이고 어디부터가 조건과 무관한 코드인지, 중괄호 범위로 명확히 구분하세요.
- 같음 비교는 `==`이며 대입 연산자 `=`와 혼동하지 않도록 주의합니다. `if (x = 5)`처럼 쓰면 대입이 되어 항상 참으로 취급됩니다.

### L3. Else

**핵심 개념**

- `if-else`는 "조건이 참이면 A, 거짓이면 B"처럼 **두 갈래 중 하나**를 반드시 실행하는 구조입니다.
- 조건이 true면 `if` 블록, false면 `else` 블록이 실행됩니다.

**문법/사용법**
```cpp
if (조건) {
    조건이 true일 때 실행할 코드
} else {
    조건이 false일 때 실행할 코드
}
```

- `else`에는 조건을 붙이지 않습니다(그냥 `else { ... }`). "그 외 모든 경우"를 담당합니다.
- `else`는 선택 사항입니다. 참일 때만 처리하면 되는 경우 `if`만 써도 됩니다.

**예시**
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string weather = "sunny";
    if (weather == "rain") {
        cout << "take umbrella" << "\n";
    } else {
        cout << "wear a hat" << "\n";
    }
    // 출력: wear a hat
    return 0;
}
```

**주의·흔한 실수**

- `else`는 바로 앞의 `if`와 짝을 이룹니다. `if` 블록과 `else` 블록의 중괄호 범위를 정확히 맞추세요.
- `else` 뒤에 조건을 적지 않도록 주의하세요(조건이 필요하면 `else if`를 씁니다).
- 참일 때와 거짓일 때 동작을 모두 정의하고 싶다면 `else`를 함께 써서 흐름을 명확히 만드세요.

### L4. Else If

**핵심 개념**

- `if-else if-else`는 여러 조건을 **위에서 아래로 순차 검사**하여, 처음으로 참이 된 블록 하나만 실행하는 다중 분기 구조입니다.
- 위쪽 `if`가 참이면 그 블록만 실행하고 나머지는 건너뜁니다. 거짓이면 다음 `else if`를 확인하며, 모두 거짓이면 `else`가 실행됩니다.

**문법/사용법**
```cpp
if (조건1) {
    조건1이 true일 때 실행할 코드
} else if (조건2) {
    조건1이 false이고 조건2가 true일 때 실행할 코드
} else if (조건3) {
    앞 조건이 모두 false이고 조건3이 true일 때 실행할 코드
} else {
    모든 조건이 false일 때 실행할 코드
}
```

- `else if`와 `else`는 선택적입니다. `if`+`else if`만, 또는 `if`+`else`만 쓰는 형태도 가능합니다.

**예시**
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string weather = "snow";
    string activity;
    if (weather == "sunny") {
        activity = "walk in the park";
    } else if (weather == "rain") {
        activity = "watch a movie at home";
    } else if (weather == "snow") {
        activity = "go skiing";
    } else {
        activity = "read a book at a cafe";
    }
    cout << "today's activity: " << activity << "\n";
    // 출력: today's activity: go skiing
    return 0;
}
```

**주의·흔한 실수**

- 조건은 순서대로 평가되므로 **범위가 좁은(엄격한) 조건을 위에, 넓은 조건을 아래에** 두어야 합니다. 예: 등급 판정에서 90 이상을 60 이상보다 먼저 검사해야 합니다.
- 한 번 참이 되면 이후 `else if`/`else`는 검사하지 않습니다. 여러 개의 독립적인 `if`를 나열하는 것과 동작이 다릅니다.
- 경계값(예: `>=` vs `>`)을 문제 조건에 맞게 정확히 설정하세요.

## 🧩 문제 채점용 정리

### 1) 음수 구별하기 (Easy · 10XP · 정답률 79%)
- **요구사항**: 정수 하나를 입력받아 그대로 출력하고, 그 값이 음수이면 추가로 표시합니다.
- **입력**: 첫 줄에 정수 N.
- **출력**: 첫째 줄에 입력받은 정수를 출력. 그 정수가 음수이면 둘째 줄에 `minus`를 추가 출력.
- **예제**: `-13` → `-13` / `minus`  |  `15` → `15`
- **제한**: −100 ≤ N ≤ 100 · Time 1000 ms · Memory 80 MiB
- **연습 개념**: `if`(단일 조건)
- **셀프체크 포인트**: 음수 판정 조건(`N < 0`)에서 0을 음수로 처리하지 않는지 확인. 양수/0일 때는 둘째 줄을 아예 출력하지 않아야 함.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    cout << n << "\n";
    if (n < 0) {
        cout << "minus" << "\n";
    }
    return 0;
}
@@TESTS
--IN
-13
--OUT
-13
minus
--IN
15
--OUT
15
--IN
0
--OUT
0
@@EXPL
접근: 값을 먼저 그대로 출력한 뒤, "음수일 때만" 한 줄을 더 붙이는 문제이므로 `else`가 필요 없는 단일 `if` 구조로 풉니다.

코드 진행:

- `cin >> n;`으로 정수 하나를 읽습니다.
- `cout << n << "\n";`으로 입력값을 무조건 먼저 출력합니다.
- `if (n < 0)`이 참일 때만 `cout << "minus" << "\n";`을 실행합니다. 0이나 양수면 이 블록을 건너뜁니다.

다시 짤 때 생각 순서:

- "항상 하는 일(값 출력)"과 "조건부로 하는 일(minus 출력)"을 구분합니다.
- 음수 기준을 `< 0`으로 잡아 0이 걸리지 않게 합니다(0은 음수가 아님).
- 조건부 출력은 `else` 없이 `if` 하나로 충분하다는 점을 떠올립니다.
```

### 2) 비교 연산 (Easy · 10XP · 정답률 84%)

- **입력**: 첫 줄에 정수 A, B가 공백으로 구분되어 주어짐.
- **출력**: 6줄에 걸쳐 1/0 출력 — ① A≥B ② A>B ③ B≥A ④ B>A ⑤ A==B ⑥ A!=B
- **예제**: `4 3` → `1 / 1 / 0 / 0 / 0 / 1`  |  `3 3` → `1 / 0 / 1 / 0 / 1 / 0`
- **제한**: 1 ≤ A,B ≤ 100 · Time 1000 ms · Memory 80 MiB
- **연습 개념**: 비교 연산자, 조건식 결과
- **셀프체크 포인트**: 각 비교 연산자(`>=`, `>`, `==`, `!=`)를 정확히 매칭했는지, 출력 순서가 문제에 명시된 6개 순서와 일치하는지 확인. C++에서 비교식은 `bool`이며 출력하면 1/0이 됩니다.

```runner
접근: 여섯 가지 비교식의 참/거짓을 그대로 1/0으로 출력하는 문제입니다. `if` 분기 없이 비교식 결과를 그대로 출력하면 간단합니다.

코드 진행:

- `cin >> a >> b;`로 한 줄에 들어온 두 값을 읽습니다.
- 각 비교식(`a >= b`, `a > b`, `b >= a`, `b > a`, `a == b`, `a != b`)은 `bool` 값(true/false)을 만듭니다.

- 문제에 명시된 여섯 개 순서를 그대로 지켜 한 줄씩 출력합니다.

- 먼저 두 정수를 읽는 코드를 만듭니다.
- 요구된 여섯 비교를 순서표대로 나열합니다.
- 비교식을 `cout`으로 출력하면 자동으로 1/0이 나온다는 점을 기억합니다(괄호로 감싸 우선순위를 명확히).
```

### 3) 시험 통과 여부 확인하기 (Easy · 10XP · 정답률 73%)
- **요구사항**: 점수를 입력받아 통과 여부를 판정하고, 미통과 시 통과까지 부족한 점수를 안내합니다.
- **입력**: 첫 줄에 정수 N.
- **출력**: N이 80 이상이면 `pass`. 그렇지 않으면 부족한 점수를 계산해 `x more score` 형식으로 출력.
- **예제**: `87` → `pass`  |  `57` → `23 more score`
- **제한**: 0 ≤ N ≤ 100 · Time 1000 ms · Memory 80 MiB
- **연습 개념**: `if-else`
- **셀프체크 포인트**: 기준값 80은 통과(경계 포함, `>= 80`)임에 유의. 부족 점수는 `80 - N`. 출력에서 숫자와 `more score` 사이 공백/형식을 정확히 맞추세요.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    if (n >= 80) {
        cout << "pass" << "\n";
    } else {
        cout << (80 - n) << " more score" << "\n";
    }
    return 0;
}
@@TESTS
--IN
87
--OUT
pass
--IN
57
--OUT
23 more score
--IN
80
--OUT
pass
@@EXPL
접근: "통과냐 아니냐" 두 갈래로 나뉘므로 `if-else` 구조가 딱 맞습니다. 통과 기준(80 이상)을 경계 포함으로 잡는 것이 핵심입니다.

코드 진행:

- `cin >> n;`으로 점수를 읽습니다.
- `if (n >= 80)`이면 `pass`를 출력합니다. 80은 통과이므로 `>=`를 씁니다.
- `else`(80 미만)에서는 부족 점수 `80 - n`을 계산해 출력합니다.
- C++에서는 `cout << (80 - n) << " more score"`처럼 숫자와 문자열을 `<<`로 이어 붙이면 됩니다. 별도의 문자열 변환을 할 필요가 없습니다.

다시 짤 때 생각 순서:

- 두 경우(통과/미통과)를 먼저 나눕니다.
- 경계값 80이 어느 쪽인지 결정해 `>=`인지 `>`인지 정합니다(문제상 80은 통과).
- 미통과 출력은 "부족 점수 + 고정 문구"이므로, `<<`로 정수와 문자열을 순서대로 연결합니다.
```

### 4) 비교에 따른 연산 (Easy · 10XP · 정답률 78%)
- **요구사항**: 두 정수 a, b 중 a가 b보다 크면 두 수의 곱을, 아니면 b를 a로 나눈 몫을 출력합니다.
- **입력**: 첫 줄에 정수 a, b가 공백으로 구분되어 주어짐.
- **출력**: a>b이면 `a*b`, 그렇지 않으면 `b / a`(몫)를 출력.
- **예제**: `10 5` → `50`  |  `3 10` → `3`
- **제한**: 1 ≤ a,b ≤ 100 · Time 1000 ms · Memory 80 MiB
- **연습 개념**: `if-else`, 정수 나눗셈 몫 연산
- **셀프체크 포인트**: "곱"과 "나눈 몫"의 방향(b ÷ a)에 주의. C++에서 정수끼리의 `/`는 몫(정수 나눗셈)입니다. 두 번째 예제에서 10 / 3 = 3이 맞는지 검산해 보세요.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    if (a > b) {
        cout << a * b << "\n";
    } else {
        cout << b / a << "\n";
    }
    return 0;
}
@@TESTS
--IN
10 5
--OUT
50
--IN
3 10
--OUT
3
--IN
4 4
--OUT
1
@@EXPL
접근: a와 b의 크기 관계에 따라 서로 다른 계산을 하는 문제이므로 `if-else`로 두 경우를 나눕니다. 나눗셈 방향(b를 a로 나눔)과 정수 나눗셈을 정확히 쓰는 것이 관건입니다.

코드 진행:

- `cin >> a >> b;`로 두 정수를 읽습니다.
- `if (a > b)`이면 두 수의 곱 `a * b`를 출력합니다.
- 그렇지 않으면(a가 b보다 크지 않으면) `else`에서 `b / a`를 출력합니다. C++에서 정수끼리의 `/`는 소수점을 버린 몫입니다.
- 예: `3 10`은 a>b가 거짓이므로 `10 / 3 = 3`. `4 4`도 a>b가 거짓이라 `4 / 4 = 1`.

다시 짤 때 생각 순서:

- 조건은 "a가 b보다 큰가?" 하나뿐이므로 `if-else` 한 쌍으로 충분합니다.
- 참일 때 곱, 거짓일 때 몫이라는 대응을 명확히 적어 둡니다.
- 정수형끼리 `/`를 쓰면 자동으로 몫이 나오므로, 나누는 방향이 `b / a`임을 문제에서 다시 확인합니다.
```

### 5) 특정 조건 두 정수 비교 (Easy · 10XP · 정답률 78%)
- **요구사항**: 두 정수 A, B에 대해 두 판정 결과를 한 줄에 공백으로 구분해 출력합니다.
- **입력**: 첫 줄에 정수 A, B가 공백으로 구분되어 주어짐.
- **출력**: (첫째 값) A<B이면 1, 아니면 0 / (둘째 값) A==B이면 1, 아니면 0 — 두 값을 공백으로 구분해 한 줄에 출력.
- **예제**: `8 10` → `1 0`  |  `15 15` → `0 1`
- **제한**: 1 ≤ A,B ≤ 100 · Time 1000 ms · Memory 64 MiB
- **연습 개념**: 비교 연산, 한 줄 출력 형식
- **셀프체크 포인트**: 두 결과를 세로가 아닌 **한 줄에 공백으로** 출력해야 함. C++에서는 값 사이에 `<< " " <<`로 공백을 직접 넣어 한 줄에 출력할 수 있습니다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << (a < b) << " " << (a == b) << "\n";
    return 0;
}
@@TESTS
--IN
8 10
--OUT
1 0
--IN
15 15
--OUT
0 1
--IN
20 7
--OUT
0 0
@@EXPL
접근: 두 판정 결과(A<B, A==B)를 각각 1/0으로 만든 뒤 한 줄에 공백으로 붙여 출력하는 문제입니다. 비교식이 `bool`이라는 점과 한 줄 출력 형식이 핵심입니다.

코드 진행:

- `cin >> a >> b;`로 두 정수를 읽습니다.
- `a < b`와 `a == b`는 각각 `bool` 값이 되고, `cout`으로 출력하면 1/0으로 찍힙니다.
- `cout << (a < b) << " " << (a == b) << "\n";`처럼 두 값 사이에 `" "`를 끼워 넣으면 `1 0`처럼 한 줄에 공백으로 구분되어 출력됩니다.

다시 짤 때 생각 순서:

- 필요한 두 조건을 먼저 적습니다: "A가 B보다 작은가", "A와 B가 같은가".
- 각 비교식을 그대로 출력하면 1/0이 됩니다(별도 변환 불필요).
- 한 줄에 공백 구분 출력은 값 사이에 `<< " " <<`를 직접 넣어 만든다는 점을 기억합니다.
```

### 6) 물의 상태 (Easy · 10XP · 정답률 70%)
- **요구사항**: 물의 온도에 따라 상태를 세 가지로 분류해 출력합니다.
- **입력**: 첫 줄에 정수 온도 n.
- **출력**: 0℃ 미만이면 `ice`, 100℃ 이상이면 `vapor`, 그 외에는 `water`.
- **예제**: `-13` → `ice`  |  `98` → `water`
- **제한**: −200 ≤ n ≤ 200 · Time 1000 ms · Memory 80 MiB
- **연습 개념**: `if-else if-else`(3분기)
- **셀프체크 포인트**: 경계 조건에 주의 — 0은 `water`(미만이 아님), 100은 `vapor`(이상 포함). 조건 순서를 잘 배치해 세 구간이 겹치거나 빠지지 않게 하세요.

```runner
@@SOLUTION
#include <iostream>

int main() {

    if (n < 0) {
        cout << "ice" << "\n";

        cout << "vapor" << "\n";
    } else {
        cout << "water" << "\n";
    }
    return 0;
}
@@TESTS
--IN
-13
--OUT
ice
--IN
98
--OUT
water
--IN
100
--OUT
vapor
@@EXPL
접근: 온도를 세 구간(빙점 아래 / 끓는점 위 / 그 사이)으로 나누는 문제이므로 `if-else if-else` 3분기가 적합합니다. 경계값(0과 100)을 어느 구간에 넣을지가 핵심입니다.

코드 진행:

- `cin >> n;`으로 온도를 읽습니다.
- `if (n < 0)`이면 `ice`. 0은 포함되지 않으므로 0은 여기서 걸리지 않습니다.
- `else if (n >= 100)`이면 `vapor`. 100은 포함(이상)이라 `>=`를 씁니다.
- 위 두 조건이 모두 거짓인 나머지(0 이상 100 미만)는 `else`에서 `water`.

다시 짤 때 생각 순서:

- 세 구간의 경계를 먼저 그려 봅니다: `< 0`, `0 이상 100 미만`, `100 이상`.
- 각 경계값(0, 100)이 어느 쪽에 속하는지 문제에서 확인해 `<`와 `>=`를 정확히 선택합니다.
- 가운데 구간은 조건을 따로 쓰지 않고 `else`로 처리하면 겹침/누락 없이 깔끔합니다.
```

### 7) 살 수 있는 물건 (Easy · 10XP · 정답률 77%)

### 8) 등급 매기기 (Easy · 10XP · 정답률 87%)
- **요구사항**: 시험 점수를 입력받아 구간별 등급(A~F)을 출력합니다.
- **입력**: 첫 줄에 정수 N.
- **출력**: 90 이상 A, 80 이상 B, 70 이상 C, 60 이상 D, 60 미만 F.
- **예제**: `91` → `A`  |  `76` → `C`
- **제한**: 0 ≤ N ≤ 100 · Time 1000 ms · Memory 64 MiB
- **연습 개념**: `if-else if-else`(다중 구간 분기)
- **셀프체크 포인트**: 높은 등급부터(`>= 90` → `>= 80` → …) 순서대로 검사해야 함. 각 경계는 "이상"이며, 마지막은 `else`(60 미만)로 F를 처리하세요.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    if (n >= 90) {
        cout << "A" << "\n";
    } else if (n >= 80) {
        cout << "B" << "\n";
    } else if (n >= 70) {
        cout << "C" << "\n";
    } else if (n >= 60) {
        cout << "D" << "\n";
    } else {
        cout << "F" << "\n";
    }
    return 0;
}
@@TESTS
--IN

--OUT

--IN

--OUT

--IN

@@EXPL
접근: 점수 구간을 다섯 등급으로 나누는 전형적인 `if-else if-else` 다중 분기 문제입니다. 높은 등급부터 검사해야 각 구간이 정확히 하나만 걸립니다.

코드 진행:

- `cin >> n;`으로 점수를 읽습니다.
- `n >= 90`부터 위에서 아래로 검사합니다. 처음 참이 되는 조건 하나만 실행되고 나머지는 건너뜁니다.
- 예를 들어 76은 90/80은 거짓이고 `>= 70`에서 참이 되어 `C`가 나옵니다.
- 60 미만은 어떤 `else if`도 걸리지 않으므로 `else`에서 `F`를 출력합니다.

다시 짤 때 생각 순서:

- 각 등급의 하한선(90, 80, 70, 60)을 큰 값부터 나열합니다.
- 높은 기준부터 `if`/`else if`로 쌓으면, 낮은 조건이 위쪽 점수를 가로채지 않습니다.
- 모든 경계가 "이상"이므로 `>=`를 쓰고, 마지막 60 미만은 조건 없이 `else`로 처리합니다.
```

## ✅ 마스터 체크리스트

- [ ] 참/거짓으로 평가되는 조건식을 비교 연산자로 만들 수 있다
- [ ] `if` 블록의 중괄호 `{ }` 규칙을 이해하고 두 줄 이상일 때 반드시 묶을 수 있다
- [ ] `if-else`로 두 갈래 분기를 구현할 수 있다
- [ ] `if-else if-else`로 3개 이상 다중 분기를 구현할 수 있다
- [ ] 조건의 경계값(`>=` vs `>`, 포함/미포함)을 정확히 설정할 수 있다
- [ ] 다중 분기에서 조건 순서(좁은 조건 → 넓은 조건)를 올바르게 배치할 수 있다
- [ ] `cout << x << " " << y`로 한 줄 공백 구분 출력을 만들 수 있다
- [ ] 정수 나눗셈 몫(`/`)과 나머지(`%`)를 조건과 함께 활용할 수 있다

## ⚠️ 자주 하는 실수

- **중괄호 누락**: `if`/`else if`/`else` 뒤에 실행 문장이 두 줄 이상인데 `{ }`로 묶지 않으면, 바로 다음 한 문장만 조건에 묶이고 나머지는 항상 실행되어 버그가 됩니다.
- **`=`와 `==` 혼동**: 같음 비교는 `==`. 조건식에 대입 연산자 `=`를 쓰면(`if (x = 5)`) 대입이 되어 항상 참으로 취급됩니다.
- **경계값 처리 오류**: "이상/이하"(포함)와 "초과/미만"(미포함)을 헷갈려 80점이 통과인지, 0℃가 ice인지 등을 잘못 판정하는 경우가 많습니다.
- **다중 분기 조건 순서 오류**: `if-else if-else`는 위에서부터 먼저 참이 되는 하나만 실행됩니다. 넓은 조건(예: 60 이상)을 위에 두면 90점도 D로 잘못 분류됩니다. 엄격한 조건을 먼저 배치하세요.
- **독립적인 `if` 남발**: 서로 배타적인 분기인데 `else if` 대신 별도 `if`를 나열하면 조건이 중복 실행되어 결과가 어긋날 수 있습니다.
- **출력 형식 불일치**: 줄바꿈 vs 공백 구분, 문자열 대소문자(`pass`, `ice`, `no` 등)를 문제 명세와 정확히 일치시키세요.
