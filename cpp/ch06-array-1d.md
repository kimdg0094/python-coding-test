# Ch6. 1차원 배열 — Codetree 101 스터디 가이드

> 언어 C++ · 2개 레슨 · 개념 2 / 문제 4

## 📌 챕터 개요

여러 개의 값을 순서대로 담는 1차원 배열을 배웁니다. 배열의 선언·인덱싱·수정과 for문으로 배열을 순회·가공하는 방법을 익히고, `cin`으로 여러 값을 입력받아 배열에 저장하는 관용구를 학습합니다. 학습 목표는 (1) 배열에 값을 저장하고 인덱스로 접근·수정하기, (2) 여러 값을 한 번에 입력받아 배열로 처리하기, (3) for문으로 배열을 변환하며 문제를 해결하는 것입니다.

## 📖 개념 정리 (레슨별)

### L1. 1차원 배열 입문

**핵심 개념**

- 배열은 같은 자료형의 여러 값을 순서대로 저장하는 자료구조이며, `자료형 이름[크기];` 형태로 선언합니다(예: `int a[5];`).
- 한 배열은 한 가지 자료형만 담습니다(`int a[5]`는 정수만, `char c[5]`는 문자만). 서로 다른 자료형을 섞어 담을 수는 없습니다.
- 각 요소는 인덱스(위치)를 가지며 인덱스는 0부터 시작합니다. 크기가 `n`인 배열의 유효 인덱스는 `0`부터 `n-1`까지입니다.
- 선언과 동시에 초기값을 줄 수 있습니다: `int a[5] = {3, 1, 4, 5, 9};`. 배열의 크기(요소 개수)는 선언할 때 정한 상수입니다.

**문법/사용법**

- 선언: `int a[5];`(값 미정), `int a[5] = {3, 1, 4, 5, 9};`(초기화), `char c[10];`(문자 10개)
- 접근/수정: `a[i]`로 읽기, `a[i] = 값;`으로 변경 (인덱스는 0부터 `n-1`까지)
- 크기: 선언 시 정한 상수를 그대로 사용합니다(예: 10개짜리면 반복 범위를 `0`~`9`로 둡니다). 문자열이 아닌 배열에는 `.size()` 같은 메서드가 없습니다.
- 순회: `for (int i = 0; i < n; i++)`로 인덱스를 돌며 `a[i]`에 접근
- 입력: `cin >> a[i];`로 한 요소씩 입력받기(공백/개행으로 구분된 값을 순서대로 읽음)

**예시**

```cpp
#include <iostream>
using namespace std;

int main() {
    int a[5] = {3, 1, 4, 5, 9};
    cout << a[0] << "\n";     // 3
    cout << a[4] << "\n";     // 9
    a[1] = 10;                // 요소 수정
    for (int i = 0; i < 5; i++) {
        cout << a[i] << " ";  // 3 10 4 5 9
    }
    cout << "\n";
    return 0;
}
```

**주의·흔한 실수**

- 인덱스는 0부터 시작 — 3번째 요소는 `a[2]`입니다.
- 크기가 `n`인 배열의 유효 인덱스는 `0`~`n-1`입니다. `a[n]`처럼 범위를 벗어난 인덱스에 접근하면 친절한 오류 없이 잘못된 값이 나오거나 프로그램이 비정상 종료될 수 있어 더 조심해야 합니다.
- 배열 크기는 선언 시 정한 상수이므로, 필요한 최대 크기를 넉넉히 잡아 두고 실제 사용 개수(`n`)를 별도 변수로 관리하는 방식을 자주 씁니다.
- `char` 배열과 `int` 배열은 서로 다릅니다. 문자를 다룰 땐 `char`, 정수를 다룰 땐 `int`로 선언합니다.

### L2. 1차원 배열 응용

**핵심 개념**

- for문으로 배열의 각 요소를 순서대로 처리하며 연산·변환을 수행합니다.
- 여러 값을 한 줄(또는 여러 줄)에 입력받아 배열에 채우는 관용구를 익힙니다.
- 인덱스를 마지막부터 감소시키며 도는 역순 순회로 배열을 뒤에서부터 처리합니다.

**문법/사용법**

- 인덱스 순회: `for (int i = 0; i < n; i++)` → `a[i]`로 요소와 위치 모두 활용
- 역순 순회: `for (int i = n - 1; i >= 0; i--)` → 마지막 요소부터 첫 요소까지 거꾸로 처리
- 여러 값 입력: 개수 `n`을 먼저 읽고 `for (int i = 0; i < n; i++) cin >> a[i];`로 채우기 (`cin >>`은 공백·개행을 모두 구분자로 처리하므로 한 줄에 나열돼 있든 줄마다 있든 순서대로 읽힘)
- 공백 구분 출력: 값 뒤에 공백을 붙이거나(`cout << a[i] << " ";`), 마지막 값 뒤 공백을 피하려면 `if (i < n - 1) cout << " ";`처럼 구분자를 요소 사이에만 넣기
- 붙여서 출력: 구분자 없이 `cout << a[i];`를 반복하면 값이 이어 붙어 나옴(문자를 이어 붙일 때 유용)

**예시**

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;                     // 개수
    int nums[100];
    for (int i = 0; i < n; i++) {
        cin >> nums[i];           // 여러 정수 입력받기
    }
    for (int i = 0; i < n; i++) {
        cout << nums[i] * 2;      // 각 값을 2배
        if (i < n - 1) cout << " ";
    }
    cout << "\n";                 // 예: "10 20 30" -> "20 40 60"
    return 0;
}
```

**주의·흔한 실수**

- 순회 범위는 항상 `0`부터 `n-1`까지 — 조건을 `i <= n`으로 쓰면 범위를 벗어난 인덱스에 접근하게 됩니다.
- 역순 순회는 시작값(`n-1`), 종료 조건(`i >= 0`), 감소(`i--`) 세 가지를 정확히 맞춰야 합니다. 종료 조건을 `i > 0`으로 두면 첫 요소(인덱스 0)를 빠뜨립니다.
- `cin >>`은 앞뒤 공백·개행을 알아서 건너뛰므로, 값들이 한 줄에 있든 여러 줄에 나뉘어 있든 같은 방식으로 순서대로 읽을 수 있습니다.
- 출력 형식(공백 구분/붙이기)은 요구사항에 맞춰야 합니다. 채점은 보통 줄 끝 공백을 무시하지만, 확실히 하려면 요소 사이에만 구분자를 넣습니다.

## 🧩 문제 채점용 정리

### 1) 배열의 합 계산하기 (Easy · 10XP · 정답률 93%)

- **요구사항**: 배열 A를 `[3, 1, 4, 5, 9]`로 선언·저장한 뒤, 1번·3번·4번 인덱스에 저장된 값의 합을 출력합니다.
- **입력**: 입력이 주어지지 않습니다.
- **출력**: A의 1번·3번·4번 인덱스 값의 합.
- **예제**: (입력 없음) → `15`
- **제한**: Time Limit 1000 ms / Memory Limit 128 MiB
- **연습 개념**: 배열 선언·초기화, 인덱싱(0부터 시작)
- **셀프체크 포인트**: 인덱스 1·3·4는 각각 값 1·5·9임을 확인(1+5+9=15). "1번째"가 아니라 "인덱스 1"임에 유의.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int A[5] = {3, 1, 4, 5, 9};
    cout << A[1] + A[3] + A[4] << "\n";
    return 0;
}
@@TESTS
--IN

--OUT
15
@@EXPL
접근 방법: 배열을 문제에서 준 값 그대로 선언하고, 필요한 인덱스의 요소를 직접 꺼내 더합니다. 입력이 없는 고정값 문제라 계산은 인덱싱만으로 끝납니다.

코드 진행 과정:

- `int A[5] = {3, 1, 4, 5, 9};`로 배열을 만듭니다. 인덱스는 0부터라 값은 A[0]=3, A[1]=1, A[2]=4, A[3]=5, A[4]=9입니다.
- 요구된 1·3·4번 인덱스 값은 각각 1, 5, 9이므로 `A[1] + A[3] + A[4]`는 15입니다.
- `cout`으로 15를 출력하고 `"\n"`으로 줄을 마칩니다.

다시 작성할 때 생각 순서:

- 배열을 초기값과 함께 그대로 선언한다.
- "인덱스 1·3·4"가 몇 번째 값인지 0부터 세어 확인한다(1번째가 아님).
- 세 값을 인덱싱으로 꺼내 더한 뒤 출력한다.
```

### 2) 배열 채우고 출력하기 (Easy · 10XP · 정답률 87%)

- **요구사항**: 문자 10개를 저장하는 배열을 만들어 10개의 문자를 입력받고, 입력 순서의 역순으로 출력합니다.
- **입력**: 첫 줄에 10개의 문자가 공백으로 구분되어 주어집니다.
- **출력**: 입력받은 순서의 역순으로(공백 없이 이어 붙여) 출력합니다.
- **예제**: `L E B R O S C O D E` → `EDOCSORBEL`
- **제한**: Time Limit 1000 ms / Memory Limit 80 MiB
- **연습 개념**: `cin >>`으로 여러 값 입력, 배열 역순 순회(인덱스를 마지막부터 감소)
- **셀프체크 포인트**: 출력이 공백 없이 붙어 나오는지 확인. 역순은 `for (int i = 9; i >= 0; i--)`처럼 인덱스를 마지막부터 순회한다. 공백 없이 이어 붙이려면 구분자 없이 `cout << arr[i];`를 반복한다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    char arr[10];
    for (int i = 0; i < 10; i++) {
        cin >> arr[i];
    }
    for (int i = 9; i >= 0; i--) {
        cout << arr[i];
    }
    cout << "\n";
    return 0;
}
@@TESTS
--IN
L E B R O S C O D E
--OUT
EDOCSORBEL
--IN
A B C D E F G H I J
--OUT
JIHGFEDCBA
@@EXPL
접근 방법: 공백으로 구분된 문자들을 `cin >>`으로 한 글자씩 `char` 배열에 담고, 마지막 요소부터 첫 요소까지 거꾸로 순회하며 한 문자씩 공백 없이 이어 출력합니다.

코드 진행 과정:

- `char arr[10];`로 문자 10개짜리 배열을 만듭니다. `cin >> arr[i]`는 공백을 구분자로 처리해 `L`, `E`, `B` ...를 순서대로 한 칸씩 저장합니다.
- `for (int i = 9; i >= 0; i--)`는 인덱스를 9, 8, ..., 1, 0 순으로 만들어 마지막부터 순회합니다.
- `cout << arr[i];`는 구분자 없이 각 문자를 그대로 이어 붙여 출력합니다.
- 마지막에 `cout << "\n";`으로 줄바꿈을 한 번 넣어 줄을 마칩니다.

다시 작성할 때 생각 순서:

- 문자 10개를 담을 `char arr[10]`을 선언하고 `cin >>`으로 하나씩 채운다.
- 역순 출력이 핵심이니 `for (int i = 9; i >= 0; i--)`로 뒤에서부터 인덱스를 돈다.
- 공백 없이 붙여야 하므로 구분자 없이 `cout << arr[i];`만 하고, 끝에 줄바꿈만 한 번 추가한다.
```

### 3) 제곱하여 출력하기 (Easy · 10XP · 정답률 90%)

- **요구사항**: N개의 원소가 주어지면 각 원소를 제곱하여 입력 순서대로 출력합니다.
- **입력**: 첫 줄에 원소 개수 N, 둘째 줄에 N개의 원소가 공백으로 구분되어 주어집니다.
- **출력**: 각 원소를 제곱한 결과를 입력 순서대로 공백으로 구분하여 출력합니다.
- **예제**: `3 / 1 8 5` → `1 64 25` · `2 / 10 4` → `100 16`
- **제한**: 1≤N≤100, 1≤주어지는 수≤100 · Time Limit 1000 ms / Memory Limit 80 MiB
- **연습 개념**: 여러 정수 입력(`cin >>` 반복), for문 변환, 공백 구분 출력
- **셀프체크 포인트**: 결과를 공백으로 구분해 한 줄에 출력하는지 확인. 요소 사이에만 공백을 넣어(`if (i < n - 1) cout << " ";`) 마지막 값 뒤 공백을 피하면 깔끔하다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int arr[100];
    for (int i = 0; i < n; i++) {
        cin >> arr[i];
    }
    for (int i = 0; i < n; i++) {
        cout << arr[i] * arr[i];
        if (i < n - 1) cout << " ";
    }
    cout << "\n";
    return 0;
}
@@TESTS
--IN
3
1 8 5
--OUT
1 64 25
--IN
2
10 4
--OUT
100 16
@@EXPL
접근 방법: 개수 N을 읽은 뒤 정수 배열을 입력받고, for문으로 각 원소를 제곱해 공백으로 구분하며 한 줄에 출력합니다.

코드 진행 과정:

- `cin >> n;`으로 첫 줄의 개수를 읽습니다. 이 값은 이후 순회 범위(`i < n`)로 쓰입니다.
- `for (int i = 0; i < n; i++) cin >> arr[i];`로 둘째 줄의 정수들을 배열에 채웁니다. `cin >>`이 공백을 구분자로 처리하므로 한 줄에 나열된 값을 순서대로 읽습니다.
- 다시 `for`로 요소를 순서대로 돌며 `arr[i] * arr[i]`를 계산해 출력하고, 마지막 값이 아닐 때만(`i < n - 1`) 공백을 붙여 값 사이를 구분합니다.
- `cout << "\n";`으로 줄을 마칩니다.

다시 작성할 때 생각 순서:

- 입력이 두 줄임을 파악한다: 개수 한 줄, 값 한 줄.
- 개수 `n`을 읽고 반복으로 배열을 채운다.
- 각 원소를 제곱해 공백 구분으로 출력한다(요소 사이에만 공백).
```

### 4) 일의 자리 배열 (Easy · 10XP · 정답률 88%)

- **요구사항**: 10 미만 정수 두 개를 첫째·둘째 항으로 두고, 세 번째 항부터는 전전항+전항의 합의 일의 자리(합 % 10)로 채워 총 10개를 차례로 출력합니다.
- **입력**: 첫 줄에 첫째 항, 둘째 항이 공백으로 구분되어 주어집니다.
- **출력**: 첫 줄에 10개의 숫자를 공백으로 구분하여 출력합니다.
- **예제**: `2 5` → `2 5 7 2 9 1 0 1 1 2` (예: 넷째 항은 5+7=12의 일의 자리인 2)
- **제한**: 0≤주어지는 정수≤9 · Time Limit 1000 ms / Memory Limit 80 MiB
- **연습 개념**: 배열 초기값 설정 후 반복으로 채우기, 인덱스 접근(`arr[i-1]`, `arr[i-2]`), 나머지 연산 `% 10`
- **셀프체크 포인트**: "합의 일의 자리"이므로 `(전전항 + 전항) % 10`을 저장했는지, 총 개수가 정확히 10개인지 확인.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int arr[10];
    cin >> arr[0] >> arr[1];
    for (int i = 2; i < 10; i++) {
        arr[i] = (arr[i - 1] + arr[i - 2]) % 10;
    }
    for (int i = 0; i < 10; i++) {
        cout << arr[i];
        if (i < 9) cout << " ";
    }
    cout << "\n";
    return 0;
}
@@TESTS
--IN
2 5
--OUT
2 5 7 2 9 1 0 1 1 2
--IN
7 3
--OUT
7 3 0 3 3 6 9 5 4 9
@@EXPL
접근 방법: 처음 두 항을 배열의 0·1번 인덱스에 넣고, 세 번째 항부터는 바로 앞 두 항의 합을 10으로 나눈 나머지를 계속 채워 총 10개를 만든 뒤 공백 구분으로 출력합니다.

코드 진행 과정:

- `int arr[10];`로 10칸짜리 배열을 만들고 `cin >> arr[0] >> arr[1];`로 첫째·둘째 항을 받습니다.
- `for (int i = 2; i < 10; i++)`은 인덱스 2부터 9까지, 즉 8번 반복해 나머지 8칸을 채웁니다.
- 각 단계에서 `arr[i] = (arr[i-1] + arr[i-2]) % 10;` — 바로 앞 항과 전전 항의 합의 일의 자리 — 를 저장합니다. 예: 인덱스 2는 (5+2)%10=7, 인덱스 3은 (7+5)%10=2.
- 완성된 배열을 `for`로 돌며 값을 출력하고, 마지막 값이 아닐 때만(`i < 9`) 공백을 넣어 구분합니다.

다시 작성할 때 생각 순서:

- 초기 두 항을 배열의 0·1번 칸에 담아 시작한다.
- 몇 개를 더 채워야 하는지 세어(10 - 2 = 8) 반복 범위를 `i = 2`부터 `i < 10`으로 정한다.
- 새 항은 "직전 두 항의 합의 일의 자리"이므로 `arr[i-1] + arr[i-2]`에 `% 10`을 적용해 저장한다.
- 마지막에 10개를 공백 구분으로 출력한다.
```

## ✅ 마스터 체크리스트

- [ ] `자료형 이름[크기];`로 배열을 선언하고 인덱스(0부터 `n-1`)로 요소를 읽고 수정할 수 있다
- [ ] `int a[5] = {...};`처럼 선언과 동시에 초기화할 수 있다
- [ ] `for (int i = 0; i < n; i++) cin >> a[i];`로 여러 값을 배열로 입력받을 수 있다
- [ ] `for (int i = 0; i < n; i++)`와 역순 `for (int i = n - 1; i >= 0; i--)`를 상황에 맞게 선택한다
- [ ] for문으로 각 요소를 변환(제곱·2배 등)하며 배열을 가공할 수 있다
- [ ] 결과를 공백 구분(요소 사이에만) 또는 이어 붙이기 등 요구된 형식으로 출력할 수 있다
- [ ] 나머지 연산(`% 10`)과 이전 항 참조(`arr[i-1]`, `arr[i-2]`)로 수열형 배열을 채울 수 있다

## ⚠️ 자주 하는 실수

- 인덱스를 1부터로 착각 — 배열 인덱스는 0부터 시작하며, "N번 인덱스"와 "N번째"는 다릅니다.
- 범위 초과 인덱스 접근 — 크기 `n` 배열의 유효 범위는 `0`~`n-1`인데 `a[n]`에 접근하면 조용히 잘못된 값이 나오거나 프로그램이 비정상 종료될 수 있습니다.
- 순회 조건을 `i <= n`으로 써서 한 칸 넘어가거나, 역순에서 종료 조건을 `i > 0`으로 두어 첫 요소를 빠뜨림.
- 자료형 혼동 — 문자를 다룰 땐 `char`, 정수를 다룰 땐 `int`로 선언해야 합니다.

- 수열형 문제에서 "합 자체"를 저장하고 일의 자리(`% 10`)를 빠뜨림.
