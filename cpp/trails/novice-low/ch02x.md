## L7. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch02(입출력)의 핵심을 **반복 훈련**하고, 코딩테스트 단골 유형으로 **확장**하는 연습 세트다. 입력을 "어떤 자료형의 변수로 받아 어떻게 계산할지"를 매 문제마다 먼저 정하는 습관을 들인다.
- **반복 훈련 개념**: 아래 다섯 가지를 소재만 바꿔 여러 번 다시 쓴다.

- 정수·실수 한 개 — `int n; cin >> n;`, `double x; cin >> x;`. C++은 변수의 자료형에 맞춰 `>>` 가 알아서 값을 만들어 주므로 따로 변환하는 단계가 없다. 대신 **읽기 전에 자료형을 정해야** 한다. 소수점이 올 수 있으면 처음부터 `double` 로 받는다.
- 한 줄에 여러 값 — `cin >> a >> b;` 한 문장이면 끝난다. `>>` 는 값 앞뒤의 공백을 알아서 건너뛴다.
- 여러 줄 — `>>` 에게는 공백과 줄바꿈이 똑같은 "값과 값 사이"다. 그래서 두 줄에 하나씩 들어와도 `cin >> a >> b;` 로 읽힌다. 읽는 순서가 곧 변수 순서다.
- 문자열 — `string s; cin >> s;` 는 다음 공백 앞까지 한 덩어리를 읽는다. 첫 글자는 `s[0]`(자료형은 `char`), 이어 붙이기는 `+`. 공백까지 포함한 한 줄 전체가 필요하면 `getline(cin, s)`.
- 특정 구분자 — 구분 문자를 `char` 변수로 받아 흘려보내거나(`cin >> h >> c >> m;`), `getline(cin, s, ',')` 로 그 문자 앞까지 잘라 읽는다. 어느 쪽이든 구분 문자는 값에 남지 않는다.

- **코딩테스트 출제 맵**: 백준 「단계별로 풀어보기」의 '입출력과 사칙연산' 단계(A+B, 자릿수 계산, 시간 계산)와 '문자열' 단계의 앞부분, solved.ac CLASS 1의 입출력 문제가 이 챕터 수준이다. 조건문·반복문 없이 "읽고 → 계산하고 → 출력"만으로 푼다.
- **문제 구성표**:

**문제**

**1) 만 원 내고 거스름돈** · Easy

- **요구사항**: 물건 값을 입력받아, 10000원을 냈을 때 받을 거스름돈을 출력한다.
- **입력**: 1 이상 10000 이하의 정수(물건 값) 하나가 한 줄에 주어진다.
- **출력**: `10000 - 물건값` 을 한 줄에 출력한다.
- **예제**: `3500` → `6500` · `10000` → `0`
- **셀프체크**: `int` 변수로 받았는가? 빼는 순서가 "낸 돈 - 물건 값"인가? 물건 값이 딱 10000이면 `0` 이 나오는가?

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int price;
    cin >> price;
    cout << 10000 - price << "\n";
    return 0;
}
@@TESTS
--IN
3500
--OUT
6500
--IN
10000
--OUT
0
--IN
1
--OUT
9999
@@EXPL
(1) 접근·핵심 아이디어

- 거스름돈은 "낸 돈에서 물건 값을 뺀 값"이다. 낸 돈 10000은 고정이므로 입력은 물건 값 하나뿐이다.
- C++은 `int price;` 라고 자료형을 정해 두면 `cin >> price;` 가 읽어 들인 글자를 알아서 정수로 만들어 준다. 글자를 숫자로 바꾸는 변환 단계를 따로 쓸 필요가 없다.
- 뺄셈은 순서가 중요하다. `price - 10000` 으로 쓰면 부호가 반대가 된다.

(2) 코드 단계별

- `int price;` — 담을 자료형을 먼저 정한다. `cin >> price;` — 한 줄을 읽어 정수로 담는다.
- `cout << 10000 - price << "\n";` — 고정된 10000에서 물건 값을 뺀 결과를 출력한다. `3500` 이면 `6500`, `10000` 이면 `0`, `1` 이면 `9999`.

(3) 스스로 다시 짤 때 생각 순서

- "입력이 몇 개, 어떤 자료형?" → 정수 하나 → `int` 변수 하나 + `cin >>`.
- "무엇에서 무엇을 빼지?" → 낸 돈에서 물건 값을. 고정값 10000은 코드에 직접 적는다.
- C++ 함정: `int price;` 만 써 놓고 `cin >> price;` 를 빼먹으면 쓰레기 값이 그대로 계산에 들어가 결과가 매번 달라진다. 오류 메시지가 없으니 더 위험하다.
- 경계값(물건 값 10000, 1)에서 결과가 `0`, `9999` 로 자연스러운지 확인한다.
```

**2) 정사각형 넓이** · Easy

- **요구사항**: 정사각형 한 변의 길이(실수)를 입력받아 넓이(한 변 × 한 변)를 출력한다.
- **입력**: 0보다 크고 100 이하인 실수 하나가 한 줄에 주어진다. 소수점이 없는 형태(예: `3`)로 들어올 수도 있다.
- **출력**: 넓이를 한 줄에 출력한다.
- **예제**: `2.5` → `6.25` · `3` → `9`
- **셀프체크**: `double` 로 받았는가(`int` 로 받으면 `2.5` 에서 `.5` 가 버려지고 다음 입력까지 망가진다)? 입력 `3` 의 넓이가 `9.0` 이 아니라 `9` 로 나오는 이유를 설명할 수 있는가? 소수점 아래 자릿수를 맞춰야 하는 문제였다면 무엇을 써야 하는지 떠올릴 수 있는가?

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    double side;
    cin >> side;
    cout << side * side << "\n";
    return 0;
}
@@TESTS
--IN
2.5
--OUT
6.25
--IN
3
--OUT
9
--IN
0.5
--OUT
0.25
@@EXPL
(1) 접근·핵심 아이디어

- 정사각형 넓이는 한 변을 두 번 곱한 값이다. 입력 하나를 `double` 로 받아 자기 자신과 곱한다.
- 소수점이 있을 수도, 없을 수도 있는 입력은 `double` 로 받아야 안전하다. `int` 로 받으면 `>>` 가 `2` 까지만 읽고 `.5` 를 입력 버퍼에 남겨 다음 읽기를 망가뜨린다. 오류 없이 조용히 틀리는 함정이다.
- `cout` 은 실수를 **유효숫자 여섯 자리**까지 보여 주고, 필요 없는 소수점과 뒤따르는 0은 지운다. 그래서 `3.0 * 3.0` 의 결과인 `9.0` 은 화면에 `9` 로 나온다. 값이 정수로 바뀐 것이 아니라 **표시만 짧아진 것**이다.

(2) 코드 단계별

- `double side; cin >> side;` — `2.5` 는 `2.5` 로, `3` 은 `3.0` 으로 들어온다.
- `cout << side * side << "\n";` — 실수끼리 곱하므로 결과도 실수다. `2.5 * 2.5 = 6.25`, `3.0 * 3.0 = 9.0`, `0.5 * 0.5 = 0.25`.
- 화면에는 `6.25`, `9`, `0.25` 가 나온다. `6.25` 와 `0.25` 는 소수 부분이 있으니 그대로 보이고, `9.0` 만 `.0` 이 지워진다.

(3) 스스로 다시 짤 때 생각 순서

- "소수점이 올 수 있나?" → 그렇다 → `double`.
- 넓이 공식을 그대로 옮긴다: `side * side`.
- 출력 모양을 미리 예상한다. 딱 떨어지는 값은 `9` 처럼 정수같이 보이는 것이 C++의 정상 동작이다.
- 문제가 `9.00` 처럼 자릿수를 지정했다면 그때는 `<iomanip>` 을 포함하고 `cout << fixed << setprecision(2) << side * side;` 로 모양을 고정한다. 자릿수 요구가 없으면 이 문제처럼 그냥 출력한다.
```

**3) 직사각형 넓이와 둘레** · Easy

- **요구사항**: 직사각형의 가로와 세로(정수)를 한 줄에 입력받아, 첫 줄에 넓이, 둘째 줄에 둘레를 출력한다. 둘레는 `2 × (가로 + 세로)` 다.
- **입력**: 1 이상 100 이하의 정수 두 개(가로, 세로)가 공백을 사이에 두고 한 줄에 주어진다.
- **출력**: 첫째 줄에 넓이, 둘째 줄에 둘레를 출력한다.
- **예제**: `3 4` → `12 / 14` (두 줄)
- **예제**: `5 5` → `25 / 20` (두 줄)
- **셀프체크**: `cin >> w >> h;` 한 문장으로 두 값을 받았는가? 둘레에서 `2 * (w + h)` 처럼 괄호를 썼는가(괄호가 없으면 `2 * w + h` 가 되어 틀린다)?

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int w, h;
    cin >> w >> h;
    cout << w * h << "\n";
    cout << 2 * (w + h) << "\n";
    return 0;
}
@@TESTS
--IN
3 4
--OUT
12
14
--IN
5 5
--OUT
25
20
--IN
1 1
--OUT
1
4
@@EXPL
(1) 접근·핵심 아이디어

- 한 줄에 두 값이 공백으로 들어오지만 C++에서는 나누는 작업이 따로 필요 없다. `cin >> w >> h;` 가 공백을 알아서 건너뛰며 값을 하나씩 읽는다.
- 넓이는 곱, 둘레는 "두 변의 합의 2배"다. 합을 먼저 계산해야 하므로 괄호로 묶는다.

(2) 코드 단계별

- `int w, h;` — 두 정수 변수를 한 문장에 선언한다.
- `cin >> w >> h;` — `"3 4"` 에서 `w` 에 3, `h` 에 4가 들어간다. `>>` 를 이어 쓴 순서가 곧 읽는 순서다.
- `cout << w * h << "\n";` — 넓이 `12`. `cout << 2 * (w + h) << "\n";` — 괄호 안 `3 + 4 = 7` 을 먼저 구한 뒤 2배 → `14`.
- `1 1` 처럼 가장 작은 입력에서도 넓이 `1`, 둘레 `4` 가 정상적으로 나온다.

(3) 스스로 다시 짤 때 생각 순서

- "값이 몇 개, 어떤 자료형?" → 정수 두 개 → `int w, h;` 뒤에 `cin >> w >> h;`.
- 둘레 공식을 옮길 때 덧셈이 곱셈보다 먼저 되도록 괄호를 넣는다.
- C++ 함정: `w`, `h` 가 최대 100이라 `w * h` 는 최대 10000이므로 `int` 로 충분하다. 하지만 값이 수만을 넘어가는 문제라면 곱셈 결과가 `int` 범위(약 21억)를 넘을 수 있으니 `long long` 을 떠올려야 한다.
```

**4) 성과 이름 순서 바꿔 출력** · Easy

- **요구사항**: 첫째 줄에 성, 둘째 줄에 이름이 주어진다. `이름 성` 순서로 공백 한 칸을 두고 한 줄에 출력한다.
- **입력**: 첫째 줄에 성(공백 없는 문자열), 둘째 줄에 이름(공백 없는 문자열)이 주어진다.
- **출력**: 이름, 성 순서로 공백 하나를 두고 한 줄에 출력한다.
- **예제**: `Kim`(줄1) `Minsu`(줄2) → `Minsu Kim` · `Lee`(줄1) `A`(줄2) → `A Lee`
- **셀프체크**: 두 변수를 `string` 으로 선언했는가? 먼저 읽은 것이 성, 나중에 읽은 것이 이름인데 출력 순서를 뒤집었는가? 두 값 사이 공백을 `<< " " <<` 로 직접 넣었는가?

```runner
@@SOLUTION
#include <iostream>
#include <string>
using namespace std;

int main() {
    string last, first;
    cin >> last >> first;
    cout << first << " " << last << "\n";
    return 0;
}
@@TESTS
--IN
Kim
Minsu
--OUT
Minsu Kim
--IN
Lee
A
--OUT
A Lee
--IN
Park
Jiwoo
--OUT
Jiwoo Park
@@EXPL
(1) 접근·핵심 아이디어

- `>>` 에게는 공백과 줄바꿈이 똑같은 구분자다. 그래서 두 줄에 하나씩 들어와도 `cin >> last >> first;` 한 문장으로 읽힌다. 첫 번째 `>>` 가 첫째 줄(성), 두 번째가 둘째 줄(이름)을 가져간다.
- 글자를 담을 자료형은 `string` 이다. `<string>` 을 포함한다.
- 출력은 읽은 순서와 반대(이름 → 성)다. 두 값 사이 공백은 `<< " " <<` 로 직접 넣는다.

(2) 코드 단계별

- `string last, first;` — 두 문자열 변수를 선언한다.
- `cin >> last >> first;` — `last` 에 `"Kim"`, `first` 에 `"Minsu"`.
- `cout << first << " " << last << "\n";` — 이름을 앞에, 공백 한 칸, 성을 뒤에 두어 `Minsu Kim`. 한 글자짜리 이름 `A` 도 똑같이 동작한다.

(3) 스스로 다시 짤 때 생각 순서

- "줄이 두 개" → 그래도 `>>` 두 번이면 된다. 변수 이름은 뜻이 드러나게 `last`, `first`.
- "숫자로 쓸 일이 있나?" → 없다 → `string` 그대로.
- C++ 함정: `cin >> s` 는 **공백 앞까지만** 읽는다. 성이나 이름에 공백이 섞여 있다면 `getline(cin, s)` 로 한 줄 전체를 받아야 한다. 이 문제는 공백이 없다고 했으니 `>>` 로 충분하다.
```

**5) 두 단어 붙여 하나로** · Easy

- **요구사항**: 한 줄에 공백으로 구분된 두 단어를 입력받아, 두 단어를 빈틈없이 붙인 한 단어를 출력한다.
- **입력**: 공백 없는 두 단어가 공백 하나를 사이에 두고 한 줄에 주어진다.
- **출력**: 두 단어를 이어 붙인 문자열을 한 줄에 출력한다.
- **예제**: `sun flower` → `sunflower` · `note book` → `notebook`
- **셀프체크**: 두 변수를 `string` 으로 선언했는가? 사이에 `" "` 를 끼우지 않고 `a + b` 로 곧장 붙였는가? 결과에 공백이 남아 있지 않은가?

```runner
@@SOLUTION
#include <iostream>
#include <string>
using namespace std;

int main() {
    string a, b;
    cin >> a >> b;
    cout << a + b << "\n";
    return 0;
}
@@TESTS
--IN
sun flower
--OUT
sunflower
--IN
note book
--OUT
notebook
--IN
a b
--OUT
ab
@@EXPL
(1) 접근·핵심 아이디어

- `cin >> a >> b;` 는 숫자만을 위한 것이 아니다. `string` 변수에도 똑같이 쓰이고, 공백을 기준으로 한 덩어리씩 읽어 준다.
- "빈틈없이 붙이기"는 `string` 끼리의 `+` 다. `cout << a << " " << b;` 처럼 공백을 끼우면 `sun flower` 가 되어 틀린다.

(2) 코드 단계별

- `string a, b;` 뒤 `cin >> a >> b;` — `"sun flower"` 에서 `a` 에 `"sun"`, `b` 에 `"flower"`.
- `cout << a + b << "\n";` — 두 문자열을 이어 `sunflower`. 한 글자짜리 `a b` 도 `ab` 로 붙는다.

(3) 스스로 다시 짤 때 생각 순서

- "한 줄에 두 조각" → `cin >> a >> b;`.
- "숫자 계산이 필요한가?" → 아니다 → `string` 으로 둔다.
- "띄울까 붙일까?" → 붙인다 → `+`. 띄우려면 `<< " " <<` 였다(Ch01 L3).
- C++ 함정: `+` 로 이어 붙이려면 적어도 한쪽이 `string` 이어야 한다. `cout << "sun" + "flower";` 처럼 문자열 리터럴끼리 더하면 주소 계산으로 해석되어 컴파일 오류가 난다.
```

**6) 두 자리 수 뒤집기** · Medium

- **요구사항**: 두 자리 정수를 입력받아 십의 자리와 일의 자리를 서로 바꾼 수를 출력한다. 예를 들어 `72` 는 `27` 이 된다. 일의 자리가 `0` 인 `40` 은 뒤집으면 `04` 이므로 앞의 0이 사라진 `4` 를 출력한다.
- **입력**: 10 이상 99 이하의 정수 하나가 한 줄에 주어진다.
- **출력**: 자릿수를 뒤집은 정수를 한 줄에 출력한다.
- **예제**: `72` → `27` · `40` → `4`
- **셀프체크**: 십의 자리는 `n / 10`(정수끼리의 나눗셈이므로 몫), 일의 자리는 `n % 10` 이다. 뒤집은 수는 `(일의 자리) * 10 + (십의 자리)` 로 다시 조립한다. 글자를 뒤집는 것이 아니라 숫자를 계산으로 만들기 때문에 `40` 이 `04` 가 아니라 `4` 가 되는가?

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int tens = n / 10;
    int ones = n % 10;
    cout << ones * 10 + tens << "\n";
    return 0;
}
@@TESTS
--IN

--OUT

--IN

--OUT

--IN

--OUT

--IN

--OUT

@@EXPL
(1) 접근·핵심 아이디어

- 두 자리 수를 "십의 자리"와 "일의 자리"로 분리한 뒤, 역할을 바꿔 다시 조립한다. 분리는 `/`(몫)와 `%`(나머지), 조립은 `* 10 +` 다.
- C++에서 `int / int` 는 **정수 나눗셈**이라 소수점 아래가 버려진다. `72 / 10` 은 `7.2` 가 아니라 `7` 이다. 자릿수를 다룰 때는 이 성질이 그대로 쓸모가 된다.
- 글자를 뒤집는 것이 아니라 숫자를 계산으로 만들기 때문에, 일의 자리가 0이면 뒤집은 수의 십의 자리가 0이 되어 자연스럽게 사라진다(`0 * 10 + 4 = 4`).

(2) 코드 단계별

- `int n; cin >> n;` — 정수로 읽는다.
- `int tens = n / 10;` — `72 / 10 = 7`(십의 자리). `int ones = n % 10;` — `72 % 10 = 2`(일의 자리).
- `cout << ones * 10 + tens << "\n";` — `2 * 10 + 7 = 27`. `40` 은 `0 * 10 + 4 = 4`, `99` 는 `9 * 10 + 9 = 99`, `10` 은 `0 * 10 + 1 = 1`.

(3) 스스로 다시 짤 때 생각 순서

- "자릿수를 다루는 문제" → `/ 10` 과 `% 10` 부터 떠올린다.
- 분리한 두 값을 변수에 담아 두면 조립식이 읽기 쉽다.
- C++ 함정: 음수가 들어오면 `/` 와 `%` 가 "작은 쪽으로 내림"이 아니라 **0 쪽으로 자르기**로 동작한다. `-7 / 10` 은 `-1` 이 아니라 `0` 이고, `-7 % 10` 은 `3` 이 아니라 `-7` 이다. 즉 나머지의 부호는 왼쪽 값을 따라간다. 이 문제는 입력이 10 이상이라 걱정할 필요가 없지만, 음수가 섞이는 문제에서는 반드시 확인해야 한다.
- 경계값 `10`, `40`(일의 자리 0)과 `99`(두 자리 같음)를 손으로 검산한다.
```

**7) 시각을 분으로** · Medium

- **예제**: `2:30` → `150` · `0:0` → `0`
- **셀프체크**: 콜론을 `char` 변수로 받아 흘려보냈는가? 시와 분을 모두 `int` 로 받았는가? 시에 60을 곱한 뒤 분을 더했는가(반대로 하면 틀린다)?

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int h, m;
    char colon;
    cin >> h >> colon >> m;
    cout << h * 60 + m << "\n";
    return 0;
}
@@TESTS
--IN

--OUT

--IN

--OUT

--IN

(1) 접근·핵심 아이디어

- 시각을 분으로 바꾸려면 "1시간 = 60분"이므로 시에 60을 곱하고 분을 더한다.
- 입력이 `2:30` 처럼 붙어 있으므로 `cin >> h` 는 `2` 까지 읽고 `:` 앞에서 멈춘다. 남은 `:` 를 `char` 변수로 한 번 받아 치워야 그다음 `>>` 가 `30` 을 읽을 수 있다.
- 받아 낸 콜론은 쓰지 않고 버린다. "구분 문자를 흘려보내는" 전형적인 C++ 입력 패턴이다.

(2) 코드 단계별

- `int h, m; char colon;` — 시·분과 구분 문자를 담을 변수를 준비한다.
- `cin >> h >> colon >> m;` — `"2:30"` 에서 `h` 에 2, `colon` 에 `':'`, `m` 에 30이 들어간다.
- `cout << h * 60 + m << "\n";` — `2 * 60 + 30 = 150`. `0:0` 은 `0`, 하루의 마지막 `23:59` 는 `23 * 60 + 59 = 1439`.

(3) 스스로 다시 짤 때 생각 순서

- "구분 문자가 무엇?" → `:` → 그 자리를 `char` 하나로 받아 넘긴다. `scanf("%d:%d", &h, &m)` 로 형식을 직접 적어도 되고, `getline(cin, s, ':')` 로 잘라 읽어도 된다.
- 단위 변환 공식(시 × 60 + 분)을 그대로 옮긴다. 곱셈이 덧셈보다 먼저 계산되므로 괄호는 필요 없다.
- C++ 함정: 콜론을 받는 `>> colon` 을 빼먹으면 `cin >> m` 이 `:` 에서 곧바로 실패한다. 이때 `m` 은 0이 되고 오류 메시지는 나오지 않아 조용히 틀린 답이 나온다.
```

**8) 체중 변화량 한 자리로** · Medium

- **요구사항**: 지난달 몸무게와 이번 달 몸무게(실수)를 두 줄로 입력받아, "이번 달 - 지난달"을 소수점 아래 첫째 자리까지 출력한다. 줄었으면 음수가 나온다.
- **입력**: 첫째 줄에 지난달 몸무게, 둘째 줄에 이번 달 몸무게가 실수로 주어진다.
- **출력**: 변화량을 소수점 아래 첫째 자리까지 한 줄에 출력한다.
- **예제**: `64.8`(줄1) `65.3`(줄2) → `0.5` · `70.2`(줄1) `70.0`(줄2) → `-0.2`
- **셀프체크**: 두 값 모두 `double` 로 받았는가? `65.3 - 64.8` 을 그냥 출력하면 `0.5` 처럼 보이지만 실제로는 미세한 오차가 섞여 있다. `fixed << setprecision(1)` 로 자릿수를 고정했는가? 두 값이 같으면 `0` 이 아니라 `0.0` 이 나오는가?

```runner
@@SOLUTION
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double before, after;
    cin >> before >> after;
    double diff = after - before;
    cout << fixed << setprecision(1) << diff << "\n";
    return 0;
}
@@TESTS
--IN

--OUT

--IN

--OUT

--IN

(1) 접근·핵심 아이디어

- 두 줄에 하나씩 들어오지만 `>>` 는 줄바꿈도 공백처럼 건너뛰므로 `cin >> before >> after;` 한 문장이면 된다. 소수가 있으므로 둘 다 `double` 이다.
- 실수끼리 빼면 2진 저장 방식 때문에 `0.5000000000000071` 같은 아주 작은 오차가 생긴다. `fixed << setprecision(1)` 로 소수점 아래 첫째 자리까지만 보여 주면 깔끔해진다.
- "이번 달 - 지난달" 순서를 지켜야 줄었을 때 음수가 된다.

(2) 코드 단계별

- `double before, after; cin >> before >> after;` — 첫째 줄이 지난달, 둘째 줄이 이번 달.
- `double diff = after - before;` — 순서대로 뺀다. `65.3 - 64.8` 은 약 `0.5`, `70.0 - 70.2` 는 약 `-0.2`.
- `cout << fixed << setprecision(1) << diff << "\n";` — 첫째 자리까지 반올림해 `0.5`, `-0.2`. 같은 값이면 `0.0`.

(3) 스스로 다시 짤 때 생각 순서

- "줄이 두 개, 실수" → `double` 두 개에 `cin >> a >> b;`.
- 뺄셈 순서를 문제 문장에서 확인한다(나중 값 - 이전 값).
- C++ 함정: `fixed` 없이 `cout << diff;` 라고만 쓰면 `0.5`, `-0.2` 까지는 맞아 보여도 값이 딱 떨어질 때 `0.0` 이 아니라 `0` 으로 나와 틀린다. 자릿수가 정해진 문제는 반드시 `fixed << setprecision(N)` 이나 `printf("%.1f")` 를 쓴다.
```

**9) 이름 이니셜 만들기** · Medium

- **입력**: 공백 없는 두 단어(이름, 성)가 공백 하나를 사이에 두고 한 줄에 주어진다. 각 단어는 최소 한 글자다.

- **예제**: `Minsu Kim` → `M.K.` · `ann lee` → `a.l.`
- **셀프체크**: 첫 글자는 `[0]` 으로 꺼낸다(1이 아니다). `s[0]` 의 자료형이 `string` 이 아니라 `char` 라는 점을 확인했는가? 마침표를 `<< '.'` 로 사이에 끼웠는가? 대소문자는 입력 그대로인가? 한 글자짜리 단어에서도 되는가?

```runner

#include <iostream>

(1) 접근·핵심 아이디어

- 한 줄의 두 단어를 `cin >> first >> last;` 로 받고, 각 단어의 첫 글자를 `[0]` 으로 꺼낸다. 인덱스는 0부터 시작한다.
- `first[0]` 의 자료형은 `char`(글자 하나)다. `cout <<` 에 넘기면 그 글자가 그대로 출력된다.

(2) 코드 단계별

- `string first, last; cin >> first >> last;` — `"Minsu Kim"` 에서 `first` 에 `"Minsu"`, `last` 에 `"Kim"`.
- `first[0]` 은 `'M'`, `last[0]` 은 `'K'`.
- `cout << first[0] << '.' << last[0] << '.' << "\n";` — 네 조각을 차례로 흘려보내 `M.K.`. 소문자 `ann lee` 는 그대로 `a.l.`, 한 글자 `X Y` 도 `X.Y.`.

(3) 스스로 다시 짤 때 생각 순서

- "각 단어의 첫 글자" → `[0]`. 결과는 `char` 다.

- C++ 함정 2: `first[0] + last[0]` 은 두 글자의 코드값을 더한 정수가 된다. 글자를 잇는 연산이 아니다.
```

**10) 주문서 한 줄 처리** · Hard

- **요구사항**: 첫째 줄에 `상품명,수량,단가` 가 쉼표로 구분되어 주어지고, 둘째 줄에 할인율(실수)이 주어진다. 첫 줄에는 `상품명 금액`(금액 = 수량 × 단가, 정수)을 공백으로 띄워 출력하고, 둘째 줄에는 할인을 적용한 금액(금액 × (1 - 할인율))을 소수점 아래 첫째 자리까지 출력한다.
- **입력**: 첫째 줄은 `Pen,3,500` 처럼 상품명(공백 없는 문자열), 수량(정수), 단가(정수)가 쉼표로 구분된다. 쉼표 앞뒤에 공백은 없다. 둘째 줄은 0.0 이상 0.9 이하의 실수 할인율이며 `0` 처럼 소수점 없이 올 수도 있다.
- **출력**: 첫째 줄에 `상품명 금액`, 둘째 줄에 할인 후 금액을 소수점 아래 첫째 자리까지 출력한다.
- **예제**: `Pen,3,500`(줄1) `0.1`(줄2) → `Pen 1500 / 1350.0` (두 줄)
- **예제**: `Milk,2,2500`(줄1) `0`(줄2) → `Milk 5000 / 5000.0` (두 줄)
- **셀프체크**: 상품명은 쉼표 앞까지만 읽어야 하는데 `cin >> item` 은 공백이 나올 때까지 읽으므로 `Pen,3,500` 전체를 가져간다. `getline(cin, item, ',')` 로 쉼표까지만 잘라 읽었는가? 수량·단가 사이의 쉼표를 `char` 변수로 흘려보냈는가? 할인율은 `double` 로 받았는가? `1 - rate` 를 괄호로 묶어 먼저 계산했는가? 할인율 `0` 일 때 둘째 줄이 `5000` 이 아니라 `5000.0` 인가?

```runner

(1) 접근·핵심 아이디어

- 한 줄 안에 문자열과 숫자가 쉼표로 섞여 있다. `>>` 는 공백만 구분자로 보므로 쉼표를 스스로 처리하지 못한다. 조각마다 읽는 방법을 달리해야 한다.
- 상품명은 `getline(cin, item, ',')` 로 **쉼표 앞까지** 잘라 읽는다. 세 번째 인자가 "여기까지"를 뜻하는 구분 문자이고, 그 쉼표는 입력에서 소비되어 값에는 남지 않는다.
- 남은 `3,500` 은 `cin >> qty >> comma >> price;` 로 읽는다. 가운데 쉼표를 `char` 로 받아 흘려보내는 것이 요령이다.
- 할인 후 금액은 "금액 × (1 - 할인율)"이다. `1 - rate` 를 먼저 계산해야 하므로 괄호가 필요하다. `int * double` 이므로 결과는 `double` 이고, `fixed << setprecision(1)` 로 모양을 고정한다.

(2) 코드 단계별

- `string item; getline(cin, item, ',');` — `"Pen,3,500"` 에서 `item` 에 `"Pen"` 만 들어간다.
- `int qty, price; char comma; cin >> qty >> comma >> price;` — `qty` 에 3, `comma` 에 `','`, `price` 에 500.
- `double rate; cin >> rate;` — 둘째 줄 할인율. `"0"` 도 `0.0` 으로 잘 받는다.
- `int amount = qty * price;` → `1500`(정수). `double pay = amount * (1 - rate);` → `1500 * 0.9 = 1350.0`.
- `cout << item << " " << amount << "\n";` → `Pen 1500`. `cout << fixed << setprecision(1) << pay << "\n";` → `1350.0`. 할인율 `0` 이면 `5000.0`, `0.5` 면 `15000.0`.

(3) 스스로 다시 짤 때 생각 순서

- 입력 모양을 먼저 그린다: 줄1은 쉼표 구분 세 조각(글자·수·수), 줄2는 실수 하나.
- 조각마다 "무슨 자료형으로 받을까, 구분 문자를 어떻게 치울까"를 정한다. `getline(..., ',')` 과 `char` 흘려보내기 두 가지면 대부분 해결된다.
- C++ 함정 1: `getline` 과 `>>` 를 섞어 쓸 때는 순서에 주의한다. `>>` 뒤에 곧바로 `getline(cin, s)` 를 쓰면 앞 줄에 남은 줄바꿈을 빈 줄로 읽어 버린다. 이 풀이는 `getline` 이 먼저라 문제가 없다.
- C++ 함정 2: `pay` 를 `int` 로 선언하면 소수 부분이 잘려 `1350` 이 되고 자릿수 지정으로도 살릴 수 없다. 실수 계산 결과는 `double` 변수에 담는다.
```
