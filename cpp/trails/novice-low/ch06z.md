## L18. 정리 — 개념 지도·체크리스트·자주 하는 실수

**개념**

Ch6에서 배운 것은 결국 한 문장으로 줄어든다. **바깥 `for`가 줄을 만들고, 안쪽 `for`가 그 줄의 칸을 만든다.** 그 위에서 "한 줄에 몇 칸인가"와 "그 칸에 무엇을 찍는가"를 따로 정하기만 하면, 이 챕터의 모든 문제가 같은 틀로 풀린다.

여기에 C++이라서 하나가 더 붙는다. **`cout`은 아무것도 자동으로 붙여 주지 않는다.** 값 사이의 공백도, 줄 끝의 줄바꿈도 전부 직접 써야 한다. 그래서 "무엇을 찍는가"에는 "구분자를 어떻게 넣는가"까지 포함된다.

**개념 지도**

```text
  Ch6 core :  for i ( row )  ->  for j ( column )  ->  cout << c;
                                                  ->  cout << "\n";

  decide 1 : HOW MANY cells in this row      ( inner loop condition )
  +- fixed w                -> rectangle                   L1
  +- i + 1   /   n - i      -> right triangle              L2  L3
  +- 2*i + 1  ( + spaces )  -> centered pyramid , diamond   L4  L5
  +- always n , use if      -> border , diagonal , checker  L5  L6  L7

  decide 2 : WHAT to put in each cell        ( the printed value )
  +- "*"                    -> star patterns               L1..L7
  +- j    or    i           -> column / row number         L8  L11
  +- cnt  ( cnt++ )         -> running number              L10
  +- i + j   ,   i * j      -> formula table , times table L9  L12
  +- setw(w)                -> aligned columns             L14
  +- (char)('A' + k)        -> alphabet                    L15

  decide 3 : REPEAT the whole drawing        ( test cases )
  +- for (int t = 0; t < T; t++)                           L16
```

세 결정은 서로 독립이다. 모양(decide 1)을 그대로 두고 값(decide 2)만 바꾸면 별 삼각형이 숫자 삼각형이 되고, 알파벳 삼각형이 된다.

정렬이 필요한 도형은 한 줄을 두 덩어리로 쪼개는 것이 전부다.

```text
  one line  =  [ spaces ]  +  [ content ]     # 두 덩어리의 합이 그 줄의 폭

    right aligned ( n = 4 )         centered ( n = 3 )
      i=1     . . . *                 i=0     . . *
      i=2     . . * *                 i=1     . * * *
      i=3     . * * *                 i=2     * * * * *
      i=4     * * * *
    spaces = n - i                  spaces = n - 1 - i
    stars  = i                      stars  = 2*i + 1
    sum    = n   ( constant )       center = column n-1   ( constant )
```

`.`은 실제로는 공백이다. 오른쪽 맞춤은 두 덩어리의 **합**이 일정하고, 가운데 정렬은 별 덩어리의 **한가운데 열**이 일정하다. 무엇이 고정되는지만 알면 식이 저절로 나온다.

변수를 어디에 선언하느냐가 곧 초기화 횟수라는 점도 이 챕터의 축이다.

```text
  int cnt = 1;                   // (A) 전체에서 1 번   -> 1 .. n*n
  for (int t = 0; t < T; t++) {
      int cnt = 1;               // (B) 케이스마다 1 번 -> 케이스별 1 부터
      for (int i = 0; i < n; i++) {
          int cnt = 1;           // (C) 줄마다 1 번     -> 매 줄 1 부터
          for (int j = 0; j < n; j++) { ... }
      }
  }
```

C++에서는 `{}` 안에서 선언한 변수가 그 블록을 벗어나면 사라진다. 그래서 (B)와 (C)는 매 회차 **새 변수**가 생겼다 사라지는 것이고, 바깥의 `cnt`와는 이름만 같은 다른 변수다.

**뼈대 코드**

이 챕터 유형을 만나면 아래 골격 중 하나를 그대로 꺼내 쓰고, `<-` 표시된 자리만 문제에 맞춰 고친다.

① 기본 틀 — 모든 줄의 칸 수가 같은 도형

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;                          // <- 문제마다 바뀜 (입력 형태)
    for (int i = 0; i < n; i++) {      // 바깥: 줄
        for (int j = 0; j < n; j++) {  // <- 문제마다 바뀜 (한 줄의 칸 수)
            cout << "*";               // <- 문제마다 바뀜 (찍을 것)
        }
        cout << "\n";                  // 줄바꿈은 항상 안쪽 for '밖'
    }
    return 0;
}
```

② 줄마다 칸 수가 달라지는 도형

```cpp
int n;
cin >> n;
for (int i = 0; i < n; i++) {          // i = 0 .. n-1
    int cells = i + 1;                 // <- i+1 / n-i / 2*i / 2*i+1
    for (int j = 0; j < cells; j++) {
        cout << "*";
    }
    cout << "\n";
}
```

③ 정렬이 있는 도형 — 공백 덩어리 + 내용 덩어리

```cpp
int n;
cin >> n;
for (int i = 0; i < n; i++) {
    int spaces = n - 1 - i;            // <- 문제마다 바뀜 (앞 공백 개수)
    int stars = 2 * i + 1;             // <- 문제마다 바뀜 (내용 개수)
    for (int j = 0; j < spaces; j++) cout << " ";
    for (int j = 0; j < stars; j++) cout << "*";
    cout << "\n";
}
```

④ 조건으로 칸을 채우기 — 테두리·대각선·무늬

```cpp
int n;
cin >> n;
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {      // 범위는 항상 0..n-1 로 고정한다
        if (i == 0 || i == n - 1 || j == 0 || j == n - 1) {   // <- 조건
            cout << "*";
        } else {
            cout << " ";               // 두 가지 모두 한 글자씩 (폭 유지)
        }
    }
    cout << "\n";
}
```

⑤ 숫자 채우기 — 카운터·공식·폭 정렬

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int cnt = 1;                       // 이어지는 번호면 반복문 '밖'에서 선언
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            int value = cnt;           // <- cnt / i+j / i*j / i / j
            cout << setw(4) << value;  // <- 폭, 구분자
            cnt++;
        }
        cout << "\n";
    }
    return 0;
}
```

⑥ 테스트 케이스 반복

```cpp
int T;
cin >> T;
for (int t = 0; t < T; t++) {
    int n;
    cin >> n;                          // <- 케이스마다 새로 읽는다
    int cnt = 1;                       // <- 케이스마다 초기화할 것은 여기에
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) cout << "*";
        cout << "\n";
    }
    cout << "\n";                      // <- 케이스 구분 빈 줄 (형식에 따라)
}
```

**언제 무엇을 쓰나**

| 상황 | 고르는 것 | 이유 | 총 출력 칸 |
| --- | --- | --- | --- |
| 모든 줄의 칸 수가 같다 | 안쪽 조건 `j < w` 고정 | 줄 번호와 무관하게 개수가 정해진다 | `h × w` |
| 줄마다 칸 수가 늘거나 줄어든다 | `j < i + 1` 또는 `j < n - i` | 안쪽 횟수를 바깥 변수에 연동한다 | `n(n+1)/2` |
| 도형을 가운데·오른쪽에 맞춘다 | [공백 `for`] + [내용 `for`] | 한 줄이 두 덩어리로 쪼개진다 | `n²` 안팎 |
| 위아래로 대칭이다 | 반복문 두 개, 아래쪽은 `i < n - 1` | 가운데 줄이 두 번 나오는 것을 막는다 | `2n-1`줄 |
| 칸마다 찍을지가 규칙으로 갈린다 | 안쪽 `j < n` 고정 + `if`/`else` | 칸 수를 유지해야 열이 밀리지 않는다 | `n²` |
| 번호가 줄을 넘어 이어진다 | `cnt`를 반복문 밖에서 선언 | 선언 위치가 곧 초기화 횟수다 | `n²` |
| 칸의 값이 위치만으로 정해진다 | `i`·`j` 공식 (`i+j`, `i*j`, `j*h+i+1`) | 카운터 없이 바로 계산된다 | `n²` |
| 자릿수가 달라도 세로줄을 맞춰야 한다 | `setw(w)` (`<iomanip>`) | 모든 칸이 같은 폭을 차지한다 | `n²` |
| 문자를 규칙적으로 찍는다 | `(char)('A' + k % 26)` | 코드값이 연속이라 덧셈이 통한다 | `n²` |
| 같은 처리를 여러 케이스에 반복한다 | 맨 바깥에 `for (int t = 0; ...)` | 안쪽 코드를 그대로 재사용한다 | `T × n²` |
| 출력이 수만 줄로 많다 | `endl` 대신 `'\n'` | `endl`은 매번 버퍼를 비워 느리다 | — |

**✅ 마스터 체크리스트**

- [ ] 설명할 수 있다: 바깥 `for`와 안쪽 `for`가 각각 무엇을 담당하는지, 그리고 `cout << "\n";`이 왜 안쪽 `for` 밖에 있어야 하는지.
- [ ] 설명할 수 있다: `cout`이 값 사이에 공백을 자동으로 넣지 않는다는 사실이 코드에 주는 영향.
- [ ] 설명할 수 있다: `endl`과 `'\n'`의 차이와, 출력이 많을 때 어느 쪽을 써야 하는지.
- [ ] 설명할 수 있다: "안쪽 반복 횟수를 바깥 변수에 연동한다"는 말의 뜻과, `i+1`·`n-i`·`2*i+1`이 각각 어떤 모양을 만드는지.
- [ ] 설명할 수 있다: 안쪽 반복이 `i`에 매달릴 때 총 실행 횟수가 왜 `1+2+…+n = n(n+1)/2`가 되는지.
- [ ] 설명할 수 있다: 가운데 정렬에서 앞 공백 `n-1-i`와 별 `2*i+1`을 쓰면 왜 한가운데가 항상 같은 열에 오는지.
- [ ] 설명할 수 있다: 가운데 정렬 도형의 별 개수가 왜 홀수여야 하는지.
- [ ] 설명할 수 있다: 위아래 대칭 도형에서 아래쪽 반복 조건이 왜 `i < n - 1`이어야 하는지.
- [ ] 설명할 수 있다: 조건으로 칸을 채울 때 안쪽 반복 범위를 왜 건드리면 안 되는지, `if`의 두 가지에서 왜 각각 한 글자씩 찍어야 하는지.
- [ ] 설명할 수 있다: `i == j`, `j == n-1-i`, `(i+j) % 2`가 각각 어떤 무늬를 만드는지와 그 이유.
- [ ] 설명할 수 있다: `cnt`를 반복문 밖·바깥 `for` 안·안쪽 `for` 안에 선언했을 때 결과가 어떻게 달라지는지, 그리고 블록을 벗어난 변수가 왜 사라지는지.
- [ ] 설명할 수 있다: 초기값 없이 선언한 `int` 변수에 무엇이 들어 있는지와, 그것이 왜 위험한지.
- [ ] 설명할 수 있다: 세로 우선 번호 공식 `value = j*h + i + 1`이 어떻게 유도되는지.
- [ ] 설명할 수 있다: 구구단에서 두 `for`의 순서를 바꾸면 왜 출력이 세로에서 가로로 바뀌는지.
- [ ] 설명할 수 있다: `setw(w)`가 세로줄을 맞추는 원리, 값 하나에만 적용된다는 성질, 폭을 "자릿수 + 1"로 잡는 이유.
- [ ] 설명할 수 있다: `cout << 'A' + 1;`이 왜 글자가 아니라 숫자를 찍는지와, `(char)` 캐스팅이 필요한 이유.
- [ ] 설명할 수 있다: 케이스 반복이 붙었을 때 입력 읽기와 변수 선언을 각각 어디에 두어야 하는지.

**⚠️ 자주 하는 실수**

**1) 줄바꿈을 안쪽 `for` 안에 넣는다**

```cpp
// ❌ 틀린 코드
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 4; j++) {
        cout << "*";
        cout << "\n";        // 안쪽 for '안'
    }
}
```

왜: 별 하나를 찍을 때마다 줄이 바뀐다. 3×4 사각형이 아니라 별 한 개짜리 줄이 12개 나온다. 줄바꿈은 "한 줄이 끝났을 때" 한 번이어야 한다.

```cpp
// ✅ 고친 코드
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 4; j++) {
        cout << "*";
    }
    cout << "\n";            // 안쪽 for '밖', 바깥 for '안'
}
```

**2) 안쪽 반복 범위를 바깥 변수에 연동하지 않는다**

```cpp
// ❌ 틀린 코드
int n = 4;
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {    // 항상 n 개
        cout << "*";
    }
    cout << "\n";
}
```

왜: 삼각형을 원했는데 모든 줄이 `n`개라 사각형이 나온다. "줄마다 개수가 다르다"는 조건이 코드에 전혀 반영되지 않았다.

```cpp
// ✅ 고친 코드
int n = 4;
for (int i = 0; i < n; i++) {
    for (int j = 0; j < i + 1; j++) {   // 1, 2, 3, 4 개
        cout << "*";
    }
    cout << "\n";
}
```

**3) `i < n`과 `i <= n`을 혼동한다**

```cpp
// ❌ 틀린 코드
int n = 3;
for (int i = 0; i < n; i++) {          // i = 0, 1, 2
    for (int j = 0; j < 2 * i; j++) {  // 0, 2, 4 개 -> 첫 줄이 비어 버린다
        cout << "*";
    }
    cout << "\n";
}
```

왜: 문제는 "`i`번째 줄에 `2*i`개"이고 줄 번호를 1부터 센다. 그런데 시작값이 0이라 첫 줄이 0개가 된다. 공식이 1-기준이면 반복도 1-기준으로 맞춰야 한다.

```cpp
// ✅ 고친 코드
int n = 3;
for (int i = 1; i <= n; i++) {         // i = 1, 2, 3
    for (int j = 0; j < 2 * i; j++) {  // 2, 4, 6 개
        cout << "*";
    }
    cout << "\n";
}
```

**4) 카운터를 안쪽 블록에서 선언한다**

```cpp
// ❌ 틀린 코드
int n = 3;
for (int i = 0; i < n; i++) {
    int cnt = 1;                       // 줄마다 새 변수가 생긴다
    for (int j = 0; j < n; j++) {
        cout << cnt << ' ';
        cnt++;
    }
    cout << "\n";
}
```

왜: 바깥 `for`의 `{}` 안에서 선언했으므로 매 줄 새 `cnt`가 만들어지고 1로 시작한다. `1 2 3` / `1 2 3` / `1 2 3`이 나온다. "전체에 걸쳐 이어지는 번호"가 되려면 선언이 반복문 밖에 딱 한 번이어야 한다.

```cpp
// ✅ 고친 코드
int n = 3;
int cnt = 1;                           // 반복문 '밖'에서 한 번만
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        cout << cnt << ' ';
        cnt++;
    }
    cout << "\n";
}
```

**5) 초기값 없이 변수를 선언한다**

```cpp
// ❌ 틀린 코드
int cnt;                               // 쓰레기 값이 들어 있다
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        cout << cnt << ' ';
        cnt++;
    }
    cout << "\n";
}
```

왜: C++은 초기값을 주지 않은 지역 변수를 0으로 만들어 주지 않는다. 그 자리에 남아 있던 값이 그대로 쓰이므로 실행할 때마다 결과가 달라진다. 파이썬에는 아예 없던 상태다.

```cpp
// ✅ 고친 코드
int cnt = 1;                           // 세는 변수는 반드시 초기값을 준다
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        cout << cnt << ' ';
        cnt++;
    }
    cout << "\n";
}
```

**6) 대칭 도형에서 가운데 줄을 두 번 출력한다**

```cpp
// ❌ 틀린 코드
int n = 3;
for (int i = 0; i < n; i++) {          // 별 1, 2, 3 개
    for (int j = 0; j < i + 1; j++) cout << "*";
    cout << "\n";
}
for (int i = 0; i < n; i++) {          // 별 3, 2, 1 개 -> 3 이 또 나온다
    for (int j = 0; j < n - i; j++) cout << "*";
    cout << "\n";
}
```

왜: 위쪽 반복이 이미 별 `n`개짜리 줄을 찍었는데 아래쪽이 다시 `n`개부터 시작한다. 가장 넓은 줄이 두 번 나와 대칭이 깨지고, 줄 수도 `2n-1`이 아니라 `2n`이 된다.

```cpp
// ✅ 고친 코드
int n = 3;
for (int i = 0; i < n; i++) {          // 별 1, 2, 3 개
    for (int j = 0; j < i + 1; j++) cout << "*";
    cout << "\n";
}
for (int i = 0; i < n - 1; i++) {      // 별 2, 1 개
    for (int j = 0; j < n - 1 - i; j++) cout << "*";
    cout << "\n";
}
```

**7) 조건으로 칸을 채울 때 `else`를 빠뜨린다**

```cpp
// ❌ 틀린 코드
int n = 4;
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        if (i == j) {
            cout << "*";
        }
    }
    cout << "\n";
}
```

왜: 조건이 거짓인 칸에서 아무것도 찍히지 않아 그 칸이 통째로 사라진다. 뒤 칸이 왼쪽으로 밀려 모든 줄이 `*` 하나짜리가 되고, 대각선이 세로줄처럼 보인다.

```cpp
// ✅ 고친 코드
int n = 4;
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        if (i == j) {
            cout << "*";
        } else {
            cout << " ";               // 거짓일 때도 한 글자 (폭 유지)
        }
    }
    cout << "\n";
}
```

**8) 문자 계산에서 `(char)` 캐스팅을 빠뜨린다**

```cpp
// ❌ 틀린 코드
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        cout << 'A' + j;               // 65 66 67 이 찍힌다
    }
    cout << "\n";
}
```

왜: `'A' + j`는 문자끼리의 계산이 아니라 **정수 계산**이다. `cout`은 그 정수를 그대로 내보내므로 알파벳이 아니라 코드값이 나온다.

```cpp
// ✅ 고친 코드
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        cout << (char)('A' + j);       // A B C
    }
    cout << "\n";
}
```

**9) 케이스마다 입력을 다시 읽지 않는다**

```cpp
// ❌ 틀린 코드
int T, n;
cin >> T;
cin >> n;                              // 한 번만 읽음
for (int t = 0; t < T; t++) {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) cout << "*";
        cout << "\n";
    }
    cout << "\n";
}
```

왜: 두 번째 케이스부터 첫 케이스의 `n`을 그대로 쓴다. 케이스마다 값이 달라지는 입력은 반드시 케이스 반복 **안**에서 읽어야 한다.

```cpp
// ✅ 고친 코드
int T;
cin >> T;
for (int t = 0; t < T; t++) {
    int n;
    cin >> n;                          // 케이스마다 새로 읽는다
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) cout << "*";
        cout << "\n";
    }
    cout << "\n";
}
```

**다음 챕터로**

여기서 익힌 "바깥은 행, 안쪽은 열"이라는 감각은 그대로 2차원 격자 문제의 기초가 된다. 지금은 계산한 값을 바로 화면에 찍었지만, 다음 단계에서는 그 값을 배열에 **저장해 두고** 나중에 꺼내 쓴다. 값을 담을 자리가 필요해지는 셈이고, 그 준비가 바로 이어지는 1차원 배열 챕터다. C++에서는 그 자리를 직접 잡아야 하므로, 크기와 초기화라는 두 가지 숙제가 함께 따라온다.
