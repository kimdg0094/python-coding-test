> 언어 C++

> 개요: 여러 개의 값을 하나의 이름으로 묶어 다루는 "1차원 배열"을 배운다. 한 줄에 여러 값을 입력받아 배열에 담고, 인덱스로 원하는 값을 꺼내며, 개수 세기·탐색·최댓값/최솟값 같은 기본 처리를 익힌다.

## L1. 한 줄에 여러 개 입력

**개념**

- 지금까지는 값을 하나씩 입력받았지만, 이제 한 줄에 공백으로 구분된 여러 값을 한꺼번에 받아 "배열"에 담는다.

- 배열(array)은 여러 값을 순서대로 묶어 하나의 이름으로 다루는 상자다. C++에서는 크기가 변하는 배열로 `vector`를 자주 쓴다. 예: `vector<int> arr = {10, 20, 30};`

- `cin >> x`는 공백·개행을 건너뛰고 다음 정수 하나를 읽는다. 이걸 `while (cin >> x)`로 반복하면 입력에 남은 정수를 끝까지(입력이 끝날 때까지) 하나씩 읽어 들일 수 있다.

- 읽은 값을 배열 뒤에 붙일 때는 `arr.push_back(x)`를 쓴다. 그러면 배열이 한 칸씩 커진다.

- 배열에 값이 몇 개 들어 있는지는 `arr.size()`로 알 수 있다.

- 배열을 출력할 때는 원소를 하나씩 꺼내 `cout`으로 내보낸다. 값 사이에 공백을 넣고 싶으면 첫 값 앞에는 공백을 두지 않도록 `if (i > 0) cout << " ";`처럼 처리한다.

- `for` 조건에서 `i < arr.size()`라고만 쓰면 `i`(정수)와 `size()`의 결과(음수가 없는 정수)의 종류가 달라 컴파일러가 경고를 낼 수 있다. `(double)`처럼 괄호로 자료형을 앞에 붙이는 형변환을 `size()` 결과에도 적용해 `(int)arr.size()`로 맞춰 주면 이 경고를 피할 수 있다.

```cpp
// "3 5 7" 을 입력하면
vector<int> arr;
int x;
while (cin >> x) {
    arr.push_back(x);        // arr = {3, 5, 7}
}
cout << arr.size();          // 3
for (int i = 0; i < (int)arr.size(); i++) {
    if (i > 0) cout << " ";
    cout << arr[i];          // 3 5 7  (공백으로 구분)
}
```

> 선행: `vector<int>`는 "정수를 담는, 크기가 변하는 배열"이라고 이해하면 된다. `push_back`으로 뒤에 값을 계속 붙일 수 있고, `[i]`로 i번째 값을 꺼낸다.

**그림으로 보기**

한 줄의 정수들이 `vector<int>`가 되기까지의 단계다. 화살표 하나가 문장 하나에 대응한다.

```text
   input line               3 5 7          # 한 줄에 정수 세 개
      |
      |  cin >> x        # 정수 하나씩 , 공백과 개행은 건너뛴다
      v
   x = 3   ->   x = 5   ->   x = 7         # 같은 변수를 계속 다시 쓴다
      |
      |  arr.push_back(x)
      v
   arr   :  +-----+-----+-----+
            |  3  |  5  |  7  |            # vector 는 뒤로 자란다
            +-----+-----+-----+
   index :     0     1     2
      |
      +--  arr.size()  ->  3
      +--  arr[0]      ->  3
      +--  arr[2]      ->  7
```

**손으로 따라가기**

입력 `3 5 7`에 대해 `while (cin >> x)`가 도는 동안 `arr`가 자라는 과정이다.

| 단계 | `cin >> x` | x | 실행 | 그 직후 arr | arr.size() |
| --- | --- | --- | --- | --- | --- |
| 시작 | — | — | — | `{}` | 0 |
| 1 | 성공 | 3 | `push_back(3)` | `{3}` | 1 |
| 2 | 성공 | 5 | `push_back(5)` | `{3, 5}` | 2 |
| 3 | 성공 | 7 | `push_back(7)` | `{3, 5, 7}` | 3 |
| 4 | 실패 | — | 반복 종료 | `{3, 5, 7}` | 3 |

4단계에서 더 읽을 값이 없어 `cin >> x`가 거짓이 되고, 그 순간 반복이 끝난다.

**왜 이렇게 되는가**

- `cin >> x`는 값을 읽는 동시에 "읽기에 성공했는가"를 참·거짓으로 돌려준다. 그래서 `while (cin >> x)` 한 줄이 "남은 값이 있는 동안 계속"이라는 뜻이 된다. 값이 몇 개 들어올지 몰라도 되는 이유다.
- `push_back`은 언제나 **맨 뒤**에 한 칸을 붙인다. 앞 칸의 인덱스는 변하지 않으므로 입력 순서가 곧 인덱스 순서가 된다.
- `arr.size()`가 돌려주는 것은 보통 정수가 아니라 **음수가 없는 정수**(부호 없는 정수)다. 그래서 배열이 비었을 때 `arr.size() - 1`은 `-1`이 아니라 아주 큰 수가 된다. 빈 배열에서 `for (int i = 0; i <= arr.size() - 1; i++)`라고 쓰면 멈추지 않고 20억 번쯤 도는 사고가 난다. `(int)arr.size()`로 감싸 두면 이 사고를 막을 수 있다.
- 값 사이 공백을 `cout << arr[i] << " ";`로 넣으면 마지막 값 뒤에도 공백이 하나 붙는다. 채점이 엄격하면 이것 때문에 틀린다. `if (i > 0) cout << " ";`처럼 **값 앞에** 넣으면 맨 앞에만 붙지 않아 형식이 정확해진다.
- 값이 하나뿐이어도 `arr`는 원소 한 개짜리 배열이 되고 `size()`는 1이다. 따로 예외 처리를 하지 않아도 된다.
- 배열을 통째로 화면에 내보내는 기능은 C++에 없다. `cout << arr;`는 아예 컴파일되지 않으므로, 반드시 반복문으로 한 칸씩 꺼내 찍는다.

**문제**

**1) 세 수 그대로 출력** · Easy

- **요구사항**: 한 줄에 공백으로 구분된 정수 3개를 입력받아, 그대로 다시 출력하는 프로그램을 작성한다.
- **입력**: 첫 줄에 정수 3개가 공백으로 구분되어 주어진다.
- **출력**: 입력받은 세 수를 공백으로 구분해 한 줄에 출력한다.
- **예제**: `10 20 30` → `10 20 30`   /   `-1 0 5` → `-1 0 5`
- **셀프체크**: 값 사이에는 공백을 하나씩만 넣고, 맨 앞이나 맨 뒤에 불필요한 공백이 붙지 않게 한다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    cout << a << " " << b << " " << c << "\n";
    return 0;
}
@@TESTS
--IN
10 20 30
--OUT
10 20 30
--IN
-1 0 5
--OUT
-1 0 5
@@EXPL
접근: 값이 정확히 3개이므로 변수 3개로 받아 공백을 끼워 그대로 출력하면 된다.

코드 진행

- `cin >> a >> b >> c;`는 공백을 건너뛰며 정수 세 개를 차례로 `a`, `b`, `c`에 읽어 넣는다.
- `cout << a << " " << b << " " << c;`로 값 사이에 공백을 직접 넣어 이어 붙인다.
- 끝에 `"\n"`을 붙여 줄을 바꾼다.

재작성 사고 순서

- 값의 개수가 정해져 있으면(3개) 변수 3개로 바로 받는 것이 가장 간단하다.
- `cin >> a >> b >> c`는 공백/개행 구분에 상관없이 정수 세 개를 순서대로 읽는다.
- 출력에서 값 사이 공백은 `<< " "`로 직접 끼워 넣는다.
```

**2) 입력 개수 세기** · Easy

- **요구사항**: 한 줄에 공백으로 구분된 정수들이 주어진다(몇 개인지 미리 알 수 없다). 몇 개가 입력되었는지 세어 출력한다.
- **입력**: 첫 줄에 정수 여러 개가 공백으로 구분되어 주어진다.
- **출력**: 입력된 정수의 개수를 출력한다.
- **예제**: `4 8 15 16 23 42` → `6`   /   `7` → `1`
- **셀프체크**: 몇 개인지 미리 모르니 하나 읽을 때마다 세는 변수를 1 늘린다. 값이 하나만 들어와도 개수는 1이다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int x, count = 0;
    while (cin >> x) {
        count++;
    }
    cout << count << "\n";
    return 0;
}
@@TESTS
--IN
4 8 15 16 23 42
--OUT
6
--IN
7
--OUT
1
@@EXPL
접근: 몇 개가 들어올지 미리 모르므로, 입력을 끝까지 읽으며 하나 읽을 때마다 세는 변수를 1 늘린다.

코드 진행

- `count = 0`으로 세기 변수를 0에서 시작한다.
- `while (cin >> x)`는 읽을 정수가 남아 있는 동안 참이 되어 반복하고, 더 읽을 값이 없으면(입력 끝) 거짓이 되어 멈춘다.
- 반복마다 `count++`로 하나씩 센다.
- 값이 6개면 `6`, 값이 1개("7")여도 한 번 읽어 `count`는 `1`이 된다.

재작성 사고 순서

- "개수를 센다"는 말이 나오면 0에서 시작하는 세기 변수를 먼저 떠올린다.
- 개수를 모를 때는 `while (cin >> x)`로 입력이 끝날 때까지 반복해서 읽는다.
- 값이 1개일 때도 반복이 한 번 돌아 자연히 1이 되므로 특별한 예외 처리가 필요 없다.
```

**3) 전부 더하기** · Medium

- **요구사항**: 한 줄에 공백으로 구분된 정수들을 입력받아, 모든 수의 합을 출력한다.
- **입력**: 첫 줄에 정수 여러 개가 공백으로 구분되어 주어진다.
- **출력**: 모든 수를 더한 값을 출력한다.
- **예제**: `1 2 3 4` → `10`   /   `-5 5 10` → `10`
- **셀프체크**: 합을 담을 변수를 0으로 시작해 읽은 값을 하나씩 더한다. 음수가 섞여도 그대로 더하면 된다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int x, total = 0;
    while (cin >> x) {
        total += x;
    }
    cout << total << "\n";
    return 0;
}
@@TESTS
--IN
1 2 3 4
--OUT
10
--IN
-5 5 10
--OUT
10
@@EXPL
접근: 합을 담을 그릇(변수)을 0으로 준비하고, 값을 하나씩 읽으며 그릇에 더한다.

코드 진행

- `total = 0`으로 합을 0에서 시작한다(아직 아무것도 안 더한 상태).
- `while (cin >> x)`로 정수를 끝까지 하나씩 읽는다.
- 읽을 때마다 `total += x;`로 누적한다.
- 반복이 끝나면 `total`에 전체 합이 남고, 그것을 출력한다.
- `-5 + 5 + 10`처럼 음수가 섞여도 `+=`가 그대로 처리해 `10`이 된다.

재작성 사고 순서

- "모두 더하기"는 누적 변수 패턴이다: 0으로 시작 → 읽으며 더하기 → 출력.
- 시작값을 0으로 두는 것이 핵심이다(1로 두면 답이 어긋난다).
- 반복 안에서 새 값을 더하고, 반복 밖에서 결과를 출력한다는 위치 구분을 챙긴다.
```

## L2. 인덱스 참조

**개념**

- 배열의 각 값에는 순서 번호가 붙어 있는데, 이 번호를 인덱스(index)라 한다.

- 인덱스는 0부터 시작한다. `vector<int> arr = {10, 20, 30};`이면 `arr[0]`은 10, `arr[1]`은 20, `arr[2]`는 30이다.

- 마지막 값의 인덱스는 `arr.size() - 1`이다. 위 예에서 마지막은 `arr[2]` (= `arr[arr.size()-1]`).

- 없는 인덱스를 참조하면 잘못된 동작이 일어난다. 크기가 3인 배열에서 `arr[3]`은 존재하지 않으므로 접근하면 안 된다(음수 인덱스도 쓰지 않는다).

- 인덱스로 값을 바꿀 수도 있다. `arr[1] = 99;`는 두 번째 값을 99로 교체한다.

```cpp
vector<int> arr = {10, 20, 30};
cout << arr[0];                 // 10
cout << arr[arr.size() - 1];    // 30
arr[1] = 99;                    // arr = {10, 99, 30}
```

**그림으로 보기**

배열은 칸이 늘어선 상자다. 번호는 0부터 붙고, 칸 밖에는 아무 보호막이 없다.

```text
   index :     0      1      2      3
             +------+------+------+------+
   value :   |  10  |  20  |  30  |  40  |
             +------+------+------+------+
                                     ^
                                     +-- arr[arr.size()-1] , the last

   arr.size() = 4
   arr[0]  = 10            arr[3]  = 40
   arr[4]  = ? ? ?         # 칸 밖 , 오류 없이 쓰레기 값을 읽는다
   arr[-1] = ? ? ?         # C++ 에는 뒤에서 세기가 없다 , 역시 칸 밖
```

**손으로 따라가기**

`{10, 20, 30, 40}`에서 양 끝 값을 맞바꾸는 과정이다. 임시 변수가 왜 필요한지 한 줄씩 본다.

| 단계 | 실행 | tmp | arr |
| --- | --- | --- | --- |
| 0 | 시작 | — | `{10, 20, 30, 40}` |
| 1 | `int tmp = arr[0];` | 10 | `{10, 20, 30, 40}` |
| 2 | `arr[0] = arr[3];` | 10 | `{40, 20, 30, 40}` |
| 3 | `arr[3] = tmp;` | 10 | `{40, 20, 30, 10}` |

1단계를 빼고 `arr[0] = arr[3];`부터 하면 10이 사라져 3단계에서 되돌릴 수 없다.

**왜 이렇게 되는가**

- 칸이 `n`개일 때 번호를 0부터 붙이면 `0, 1, …, n-1`로 정확히 `n`개가 나온다. 그래서 마지막 칸은 `n - 1`, 곧 `arr.size() - 1`이다.
- 1부터 붙였다면 마지막이 `n`이 되어 보기에는 깔끔하지만, "앞에 몇 칸이 지나갔는가"를 세는 계산이 어긋난다. 0-기준에서는 `arr[i]` 앞에 정확히 `i`칸이 있다는 성질이 언제나 성립한다.
- 사람이 "K번째"라고 말할 때는 1부터 세므로 인덱스는 `K - 1`이다. 이 1칸 차이가 배열 문제에서 가장 흔한 오차다. `arr[k]`라고 쓰면 한 칸씩 밀린 답이 나온다.
- **여기서 C++은 파이썬과 결정적으로 다르다.** 파이썬은 `arr[4]`에서 곧바로 `IndexError`를 내고 멈추고, `arr[-1]`을 "뒤에서 첫 번째"로 해석해 준다. C++의 `[]`는 아무 검사도 하지 않는다. 칸 밖을 읽으면 그 자리에 우연히 있던 값을 그대로 돌려주고, 칸 밖에 쓰면 남의 자리를 덮어쓴다. **오류 메시지가 없다는 점이 더 위험하다.** 어제는 맞다가 오늘 틀리는 코드가 대개 여기서 나온다.
- 그래서 C++에서는 인덱스 범위를 코드가 직접 지켜야 한다. 반복 조건을 `i < (int)arr.size()`로 정확히 쓰는 습관이 곧 안전장치다.
- 인덱스는 값을 꺼내는 것뿐 아니라 넣는 데도 쓴다. `arr[1] = 99;`처럼 왼쪽에 쓰면 그 칸의 값이 교체된다. 두 칸을 맞바꿀 때 임시 변수가 필요한 이유가 여기 있다. 한쪽을 먼저 덮어쓰면 원래 값이 사라지기 때문이다.

**문제**

**1) 첫 값과 끝 값** · Easy

- **요구사항**: 한 줄에 공백으로 구분된 정수들을 입력받아, 첫 번째 값과 마지막 값을 한 줄에 공백으로 구분해 출력한다.
- **입력**: 첫 줄에 정수 여러 개가 공백으로 구분되어 주어진다(최소 1개).
- **출력**: 첫 번째 값과 마지막 값을 공백으로 구분해 출력한다.
- **예제**: `3 6 9 12` → `3 12`   /   `7` → `7 7`
- **셀프체크**: 마지막 값의 인덱스는 `size()-1`. 값이 하나뿐이면 첫 값과 끝 값이 같은 값이다.

```runner
@@SOLUTION
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> arr;
    int x;
    while (cin >> x) {
        arr.push_back(x);
    }
    cout << arr[0] << " " << arr[arr.size() - 1] << "\n";
    return 0;
}
@@TESTS
--IN
3 6 9 12
--OUT
3 12
--IN
7
--OUT
7 7
@@EXPL
접근: 첫 값은 인덱스 0, 마지막 값은 인덱스 `arr.size() - 1`로 바로 꺼낸다.

코드 진행

- `while (cin >> x)`로 값을 끝까지 읽어 `arr`에 담는다.
- `arr[0]`은 언제나 첫 번째 값이다.
- 마지막 값의 인덱스는 개수보다 1 작으므로 `arr[arr.size() - 1]`로 꺼낸다.
- 두 값 사이에 `<< " "`로 공백을 끼워 함께 출력한다.
- 값이 1개면 `arr[0]`과 `arr[arr.size()-1]`이 같은 자리를 가리켜 `7 7`이 나온다.

재작성 사고 순서

- "첫 값과 끝 값"을 각각 어떤 인덱스로 부를지 먼저 정한다: 0과 `size()-1`.
- 끝 값 인덱스를 `arr.size() - 1`로 쓰면 값이 몇 개든 자동으로 맞는다.
- C++에는 음수 인덱스가 없으므로 마지막은 항상 `size()-1`로 가리킨다.
```

**2) K번째 값 꺼내기** · Medium

- **요구사항**: 정수 여러 개와 위치 번호 K가 주어진다. 앞에서 K번째 값을 출력한다(1번째, 2번째 … 처럼 사람이 세는 방식).
- **입력**: 첫 줄에 정수 여러 개가 공백으로 구분되어 주어진다. 둘째 줄에 정수 K가 주어진다(1 이상, 개수 이하).
- **출력**: 앞에서 K번째 값을 출력한다.
- **예제**: `10 20 30 40`(줄1) `3`(줄2) → `30`   /   `5 8 13`(줄1) `1`(줄2) → `5`
- **셀프체크**: 사람이 세는 "K번째"는 인덱스로는 `K-1`이다. 이 1칸 차이를 놓치면 엉뚱한 값이 나온다.

```runner
@@SOLUTION
#include <iostream>
#include <vector>
#include <sstream>
#include <string>
using namespace std;

int main() {
    string line;
    getline(cin, line);
    vector<int> arr;
    stringstream ss(line);
    int x;
    while (ss >> x) {
        arr.push_back(x);
    }
    int k;
    cin >> k;
    cout << arr[k - 1] << "\n";
    return 0;
}
@@TESTS
--IN
10 20 30 40
3
--OUT
30
--IN
5 8 13
1
--OUT
5
@@EXPL
**이 풀이의 새 문법**

- `#include <sstream>`, `stringstream ss(line);`: 문자열 `line`을 `cin`처럼 `>>`로 나눠 읽을 수 있게 담는 도구. 한 줄만 먼저 떼어 낸 뒤 그 줄 안에서 공백 구분 값을 꺼낼 때 쓴다.

접근: 사람이 세는 "K번째"와 컴퓨터의 인덱스는 1칸 차이가 난다. 인덱스는 0부터 시작하므로 K번째는 `arr[K-1]`이다.

코드 진행

- 첫 줄은 길이가 정해지지 않았으니 `getline`으로 한 줄을 통째로 읽는다.
- `stringstream ss(line)`에 그 줄을 담고 `while (ss >> x)`로 공백 단위 정수를 꺼내 `arr`에 담는다(둘째 줄은 건드리지 않도록 첫 줄만 따로 처리).
- 둘째 줄의 K는 `cin >> k`로 받는다.
- K번째 값은 인덱스 `K-1`에 있으므로 `arr[k - 1]`로 꺼내 출력한다.
- 예: K가 3이면 `arr[2]`인 30, K가 1이면 `arr[0]`인 5.

재작성 사고 순서

- 입력이 두 줄이고 첫 줄 길이가 가변이면, 첫 줄만 `getline`으로 떼어 내 `stringstream`으로 쪼갠다.
- "1부터 세는 위치 → 인덱스"는 항상 1을 빼는 것으로 기억한다.
- `arr[k]`로 쓰면 한 칸씩 밀려 틀리므로 `k - 1`을 꼭 챙긴다.
```

**3) 양 끝 값 교환** · Medium

- **요구사항**: 정수 여러 개를 입력받아, 첫 값과 마지막 값의 자리를 서로 바꾼 뒤 전체를 공백으로 구분해 출력한다.
- **입력**: 첫 줄에 정수 여러 개(최소 2개)가 공백으로 구분되어 주어진다.
- **출력**: 첫 값과 끝 값을 바꾼 배열을 공백으로 구분해 한 줄에 출력한다.
- **예제**: `1 2 3 4 5` → `5 2 3 4 1`   /   `8 9` → `9 8`
- **셀프체크**: 두 변수 교환하듯 `arr[0]`과 `arr[size()-1]`을 맞바꾼다. 값이 정확히 2개일 때도 잘 되는지 확인한다.

```runner
@@SOLUTION
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> arr;
    int x;
    while (cin >> x) {
        arr.push_back(x);
    }
    int last = arr.size() - 1;
    int temp = arr[0];
    arr[0] = arr[last];
    arr[last] = temp;
    for (int i = 0; i < (int)arr.size(); i++) {
        if (i > 0) cout << " ";
        cout << arr[i];
    }
    cout << "\n";
    return 0;
}
@@TESTS
--IN
1 2 3 4 5
--OUT
5 2 3 4 1
--IN
8 9
--OUT
9 8
@@EXPL
접근: 두 자리 값을 맞바꾸려면, 한쪽 값을 임시 상자에 잠깐 넣어 두고 옮긴다.

코드 진행

- `while (cin >> x)`로 값을 끝까지 읽어 `arr`에 담는다.
- 마지막 자리 인덱스를 `last = arr.size() - 1`로 구한다.
- `temp = arr[0]`으로 첫 값을 임시로 보관한다(안 하면 덮어써져 사라진다).
- `arr[0] = arr[last];`로 첫 자리에 마지막 값을 넣는다.
- `arr[last] = temp;`로 마지막 자리에 보관해 둔 옛 첫 값을 넣는다.
- 마지막에 배열을 공백으로 이어 출력한다.

재작성 사고 순서

- 두 값 교환은 "임시 변수에 대피 → 한쪽 덮기 → 대피본으로 반대쪽 채우기" 3단계다.
- 임시 변수 없이 `arr[0] = arr[last]`부터 하면 첫 값을 잃어버린다는 점을 기억한다.
- 값이 2개뿐이어도 인덱스 0과 `size()-1`(=1)이 서로 다른 자리라 그대로 동작한다.
```

## L3. 배열 만들기

**개념**

- 처음부터 값이 정해진 배열뿐 아니라, 계산으로 새 배열을 "만들어" 채울 수도 있다.

- 빈 배열은 `vector<int> arr;`로 시작한다. 여기에 `arr.push_back(값)`을 하면 맨 뒤에 값이 하나씩 추가된다.

- 정해진 개수만큼 채울 때는 반복문과 함께 쓴다. `for`로 돌면서 `push_back`하면 배열이 점점 커진다.

- 같은 값으로 채운 배열을 한 번에 만들 수도 있다. `vector<int> zeros(5, 0);`는 크기 5를 모두 0으로 채운 배열이다.

```cpp
vector<int> arr;
for (int i = 1; i < 4; i++) {
    arr.push_back(i * i);       // arr = {1, 4, 9}
}

vector<int> zeros(5, 0);        // {0, 0, 0, 0, 0}
```

**그림으로 보기**

`push_back`은 언제나 맨 뒤에 한 칸을 붙인다. 앞쪽 칸의 인덱스는 그대로 유지된다.

```text
   vector<int> arr;          [ ]
   arr.push_back(1)          [ 1 ]
   arr.push_back(4)          [ 1 , 4 ]
   arr.push_back(9)          [ 1 , 4 , 9 ]
                               ^   ^   ^
                               0   1   2       # 인덱스는 그대로
```

크기를 미리 정해 두고 만드는 방법도 있다. 두 방법은 "칸이 언제 생기는가"가 다르다.

```text
   vector<int> a;            size 0    # push_back 으로 한 칸씩 자란다
   vector<int> b(5, 0);      size 5    # 처음부터 0 이 다섯 칸
   int c[5] = {0};           size 5    # 고정 크기 , 자라지 않는다
   int d[5];                 size 5    # 값은 쓰레기 , 초기화 안 됨

   b[2] = 7;   ->   b = [ 0 , 0 , 7 , 0 , 0 ]      # 있는 칸을 고친다
   a[2] = 7;   ->   ? ? ?                          # 칸이 없다 , 위험
```

**왜 이렇게 되는가**

- `vector<int> b(5, 0);`는 "0을 5칸"이라는 뜻이다. 크기가 정해져 있으면 이 방법이 낫다. `[i]`로 아무 칸에나 바로 값을 넣을 수 있기 때문이다.
- 반대로 `vector<int> a;`는 칸이 하나도 없는 상태다. `a[2] = 7;`은 없는 칸에 쓰는 것이라 오류 없이 엉뚱한 메모리를 건드린다. 빈 배열에는 반드시 `push_back`으로 칸을 먼저 만들어야 한다.
- 고정 크기 배열을 `int d[5];`처럼 `= {0}` 없이 선언하면 각 칸에 **초기화되지 않은 쓰레기 값**이 남아 있다. 파이썬에는 아예 없는 상태다. 합을 구하는데 실행할 때마다 답이 달라진다면 대개 초기화를 빠뜨린 것이다.
- **파이썬과 반대인 점이 하나 있다.** 파이썬에서 `b = a`는 같은 리스트에 이름을 하나 더 붙이는 것이라 `b`를 고치면 `a`도 바뀐다. C++의 `vector<int> b = a;`는 **값을 전부 복사**한다. 그래서 `b[0] = 99;`를 해도 `a`는 그대로다. 파이썬의 얕은 복사 함정이 C++ `vector`에는 없다.
- 대신 다른 대가가 따라온다. 복사는 공짜가 아니다. 원소가 `n`개면 복사도 `n`번이다. 함수에 배열을 넘길 때 `void f(vector<int> v)`라고 쓰면 부를 때마다 통째로 복사된다. 고칠 필요가 없으면 `void f(const vector<int>& v)`, 고쳐야 하면 `void f(vector<int>& v)`처럼 `&`를 붙여 **원본을 그대로 가리키게** 한다.
- 2차원도 마찬가지다. `vector<vector<int>> g(n, vector<int>(m, 0));`는 안쪽 `vector<int>(m, 0)`을 `n`번 **복사**하므로 행마다 독립된 배열이 된다. 파이썬 `[[0]*m]*n`에서 한 칸만 바꿔도 모든 행이 같이 바뀌던 사고는 일어나지 않는다.

**문제**

**1) 제곱 리스트 만들기** · Easy

- **요구사항**: 정수 N을 입력받아, 1부터 N까지 각 수의 제곱을 순서대로 공백으로 구분해 출력한다.

- **출력**: 1², 2², …, N²을 공백으로 구분해 한 줄에 출력한다.
- **예제**: `4` → `1 4 9 16`   /   `1` → `1`
- **셀프체크**: 1부터 N까지 반복하며 제곱을 출력한다. N이 1이면 값이 1개만 나와야 한다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        if (i > 1) cout << " ";

@@TESTS
--IN
4
--OUT
1 4 9 16
--IN
1
--OUT
1
@@EXPL
접근: 1부터 N까지 각 수의 제곱을 차례로 출력한다. 값 사이에만 공백을 끼운다.

코드 진행

- `cin >> n;`으로 개수 N을 받는다.
- `for (int i = 1; i <= n; i++)`은 i가 1, 2, …, N을 차례로 돈다(끝값 N을 포함하려고 `i <= n`).

- 매 반복마다 `cout << i * i;`로 제곱값을 출력한다.

재작성 사고 순서

- "1부터 N까지"를 반복하려면 `for (int i = 1; i <= n; i++)`를 먼저 떠올린다.
- 값을 만들 때마다 바로 출력해도 되고, 배열에 담았다가 출력해도 된다.
- 제곱은 `i * i`. N이 1이면 반복이 한 번 돌아 `1` 하나만 나온다.
```

**2) 입력값을 두 배로** · Medium

**3) 거꾸로 채우기** · Medium

```runner
#include <iostream>

- `cin >> n;`으로 N을 받는다.
- `for (int i = n; i >= 1; i--)`는 i가 N에서 시작해 1씩 줄며 1까지 돈다(`i >= 1`이 조건).
- 첫 값(i가 N) 앞에는 공백을 두지 않고, 그 뒤부터 `if (i < n) cout << " ";`로 공백을 먼저 찍는다.
- 매 반복마다 `cout << i;`로 큰 수부터 차례로 출력한다.

재작성 사고 순서

- "거꾸로 내려간다"는 신호가 오면 `for`의 증감식을 `i--`로, 시작을 큰 값으로 잡는다.
- 1까지 포함하려면 조건을 `i >= 1`로 둔다는 규칙을 챙긴다.
- N이 1이면 반복이 한 번만 돌아 `1` 하나만 나온다.
```

## L4. Count 배열

**개념**

- "각 값이 몇 번 나왔는지"를 세고 싶을 때, 값 자체를 인덱스로 삼는 세기용 배열(카운트 배열)을 쓴다.

- 예를 들어 0~5 사이 숫자만 나온다면 크기 6인 배열을 모두 0으로 만들고(`int cnt[6] = {0};`), 값 v가 나올 때마다 `cnt[v]++`를 한다.

- 이렇게 하면 `cnt[3]`은 "3이 몇 번 나왔는가"를 뜻하게 된다.

- 카운트 배열의 크기는 "나올 수 있는 가장 큰 값 + 1" 이상이어야 그 값을 인덱스로 쓸 수 있다.

- C++에서 배열을 `= {0}`으로 초기화하면 모든 칸이 0으로 채워진다. 초기화를 빼먹으면 쓰레기 값이 남아 결과가 어긋난다.

```cpp
int data[6] = {1, 3, 3, 5, 1, 3};
int cnt[6] = {0};              // 인덱스 0~5 사용
for (int i = 0; i < 6; i++) {
    cnt[data[i]]++;            // 값 자체를 인덱스로
}
// cnt = {0, 2, 0, 3, 0, 1}
cout << cnt[3];               // 3  (3이 세 번)
```

**그림으로 보기**

값 자체를 인덱스로 삼는다. 값 `v`를 만나면 `cnt[v]` 칸을 1 늘린다.

```text
   data   :  1  3  3  5  1  3       // 값 v 마다 cnt[v]++

   index  :      0     1     2     3     4     5
              +-----+-----+-----+-----+-----+-----+
   cnt    :   |  0  |  2  |  0  |  3  |  0  |  1  |
              +-----+-----+-----+-----+-----+-----+

   cnt[1] = 2      cnt[3] = 3      cnt[5] = 1
   cnt[0] = cnt[2] = cnt[4] = 0    ( never appeared )
```

**손으로 따라가기**

`int data[6] = {1, 3, 3, 5, 1, 3};`, `int cnt[6] = {0};`으로 시작한다.

| 단계 | v | 늘리는 칸 | 그 직후 cnt |
| --- | --- | --- | --- |
| 시작 | — | — | `{0, 0, 0, 0, 0, 0}` |
| 1 | 1 | `cnt[1]` | `{0, 1, 0, 0, 0, 0}` |
| 2 | 3 | `cnt[3]` | `{0, 1, 0, 1, 0, 0}` |
| 3 | 3 | `cnt[3]` | `{0, 1, 0, 2, 0, 0}` |
| 4 | 5 | `cnt[5]` | `{0, 1, 0, 2, 0, 1}` |
| 5 | 1 | `cnt[1]` | `{0, 2, 0, 2, 0, 1}` |
| 6 | 3 | `cnt[3]` | `{0, 2, 0, 3, 0, 1}` |

원소를 한 번씩만 보고도 모든 값의 등장 횟수를 동시에 얻었다.

**왜 이렇게 되는가**

- 값 `v`가 몇 번 나왔는지 알려면 보통 배열 전체를 다시 훑어야 한다. 값을 인덱스로 쓰면 `cnt[v]`라는 **한 번의 접근**으로 끝난다. 이것이 카운트 배열의 이점이다.
- 대신 조건이 붙는다. 값이 인덱스가 되어야 하므로 값은 0 이상의 정수여야 하고, 배열 크기는 "나올 수 있는 최댓값 + 1" 이상이어야 한다. 최댓값이 100이면 인덱스 100을 써야 하므로 크기는 101이다.
- 한 번도 안 나온 값의 칸에는 `= {0}`으로 만들 때 넣어 둔 0이 그대로 남는다. 그래서 "0번 등장"이 따로 처리하지 않아도 저절로 표현된다.
- 여기서 C++만의 함정이 둘이다. 첫째, `int cnt[101];`처럼 `= {0}`을 빠뜨리면 칸에 쓰레기 값이 들어 있어 세기 결과가 매번 달라진다. 둘째, 값이 크기를 넘어도(`cnt[200]++`) 오류가 나지 않고 남의 메모리를 조용히 망가뜨린다. 파이썬이라면 `IndexError`로 즉시 알려 줬을 일이다.
- 고정 크기 배열의 크기는 컴파일할 때 정해지는 상수여야 한다. `int n; cin >> n; int cnt[n];`는 표준 문법이 아니다. `const int SIZE = 101; int cnt[SIZE] = {0};`처럼 넉넉한 상수로 잡거나, 크기를 실행 중에 정해야 하면 `vector<int> cnt(n + 1, 0);`을 쓴다.
- 최다 등장 값을 찾을 때 인덱스 0부터 훑고 갱신 조건을 `>`(같으면 갱신 안 함)로 두면, 동점일 때 먼저 본 작은 숫자가 그대로 남는다. "동점이면 작은 값"이라는 조건이 부등호 하나로 지켜진다.
- 원소가 `m`개, 배열 크기가 `S`일 때 세는 데 `m`번, 결과를 훑는 데 `S`번이면 끝난다.

**문제**

**1) 숫자별 등장 횟수** · Medium

- **요구사항**: 0 이상 9 이하의 정수들이 한 줄에 공백으로 주어진다. 0부터 9까지 각 숫자가 몇 번 나왔는지 순서대로 출력한다.
- **입력**: 첫 줄에 0~9 사이 정수 여러 개가 공백으로 구분되어 주어진다.
- **출력**: 0이 나온 횟수부터 9가 나온 횟수까지, 총 10개의 수를 공백으로 구분해 한 줄에 출력한다.
- **예제**: `1 3 3 5 1` → `0 2 0 2 0 1 0 0 0 0`   /   `9 9 9` → `0 0 0 0 0 0 0 0 0 3`
- **셀프체크**: 크기 10인 카운트 배열을 0으로 초기화한다. 한 번도 안 나온 숫자의 자리는 0이 그대로 남아야 한다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int cnt[10] = {0};
    int v;
    while (cin >> v) {
        cnt[v]++;
    }
    for (int i = 0; i < 10; i++) {
        if (i > 0) cout << " ";
        cout << cnt[i];
    }
    cout << "\n";
    return 0;
}
@@TESTS
--IN
1 3 3 5 1
--OUT
0 2 0 2 0 1 0 0 0 0
--IN
9 9 9
--OUT
0 0 0 0 0 0 0 0 0 3
@@EXPL
접근: 값 자체를 인덱스로 삼는 "세기용 배열"을 만들어, 값이 나올 때마다 그 자리를 1 늘린다.

코드 진행

- `int cnt[10] = {0};`으로 0부터 9까지 셀 자리 10칸을 모두 0으로 준비한다.
- `while (cin >> v)`로 값을 하나씩 읽어 `cnt[v]++`로 그 값의 칸을 1 늘린다(예: v가 3이면 `cnt[3]`이 증가).
- 반복이 끝나면 `cnt`에는 각 숫자의 등장 횟수가 담긴다.
- `for`로 0의 횟수부터 9의 횟수까지 10개를 공백으로 출력한다. 안 나온 자리는 0 그대로다.

재작성 사고 순서

- "각 숫자가 몇 번?"이라는 질문은 카운트 배열 패턴이다: 0으로 채운 배열 → 값 자리 +1.
- 셀 수 있는 최대 숫자가 9이므로 크기는 `9 + 1 = 10`이어야 한다.
- 값을 인덱스로 바로 쓰는 `cnt[v]++`가 핵심이다. 출력은 배열 전체를 훑어 찍으면 된다.
```

**2) 가장 많이 나온 숫자** · Hard

- **요구사항**: 0 이상 9 이하의 정수들이 주어진다. 가장 많이 등장한 숫자를 출력한다. 최다 등장 숫자가 여럿이면 그중 가장 작은 숫자를 출력한다.
- **입력**: 첫 줄에 0~9 사이 정수 여러 개가 공백으로 구분되어 주어진다.
- **출력**: 가장 많이 나온 숫자를 출력한다.
- **예제**: `1 3 3 5 1 3` → `3`   /   `2 2 7 7 1` → `2`
- **셀프체크**: 카운트 배열을 만든 뒤 인덱스 0부터 훑어 최대 횟수를 찾는다. 0부터 순서대로 보면 "동점이면 작은 숫자"가 자연히 지켜진다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int cnt[10] = {0};
    int v;
    while (cin >> v) {
        cnt[v]++;
    }
    int best = 0;
    for (int d = 0; d < 10; d++) {
        if (cnt[d] > cnt[best]) {
            best = d;
        }
    }
    cout << best << "\n";
    return 0;
}
@@TESTS
--IN
1 3 3 5 1 3
--OUT
3
--IN
2 2 7 7 1
--OUT
2
@@EXPL
접근: 먼저 카운트 배열로 각 숫자의 횟수를 센 뒤, 0부터 훑으며 가장 큰 횟수를 가진 숫자를 고른다.

코드 진행

- `int cnt[10] = {0};`을 만들고 `cnt[v]++`로 0~9의 등장 횟수를 센다.
- `best = 0`으로 "지금까지 가장 많은 숫자"를 0번으로 가정한다.
- `for (int d = 0; d < 10; d++)`로 0부터 9까지 보며, `cnt[d] > cnt[best]`(더 많으면)일 때만 `best = d`로 갱신한다.
- 부등호가 "더 클 때"만 갱신이므로, 횟수가 같으면 먼저 본(더 작은) 숫자가 그대로 남는다. 그래서 동점이면 작은 숫자가 답이 된다.
- 마지막에 `best`를 출력한다.

재작성 사고 순서

- "가장 많이 나온 값"은 카운트 → 최대 찾기 두 단계로 나눈다.
- 최대 찾기는 후보 하나(`best`)를 두고 더 나은 것이 오면 갈아끼우는 패턴이다.
- 동점 시 작은 값을 원하면 인덱스를 0부터 훑고, 부등호를 `>`(같으면 갱신 안 함)로 두면 자연히 지켜진다.
```

**3) 중복 여부 판정** · Hard

- **요구사항**: 0 이상 100 이하의 정수들이 주어진다. 같은 수가 두 번 이상 나온 적이 있으면 `YES`, 모든 수가 서로 다르면 `NO`를 출력한다.
- **입력**: 첫 줄에 0~100 사이 정수 여러 개가 공백으로 구분되어 주어진다.
- **출력**: 중복이 있으면 `YES`, 없으면 `NO`를 출력한다.
- **예제**: `3 1 4 1 5` → `YES`   /   `3 1 4 5` → `NO`
- **셀프체크**: 값이 100까지 나올 수 있으니 카운트 배열 크기는 101이어야 한다. 세는 도중 어떤 값의 횟수가 2가 되는 순간 중복이다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int cnt[101] = {0};
    bool dup = false;
    int v;
    while (cin >> v) {
        cnt[v]++;
        if (cnt[v] >= 2) {
            dup = true;
        }
    }
    if (dup) {
        cout << "YES" << "\n";
    } else {
        cout << "NO" << "\n";
    }
    return 0;
}
@@TESTS
--IN
3 1 4 1 5
--OUT
YES
--IN
3 1 4 5
--OUT
NO
@@EXPL
접근: 값이 나올 때마다 카운트 배열에서 세고, 어떤 값의 횟수가 2가 되는 순간 "중복 있음"으로 기록한다.

코드 진행

- 값이 0~100까지 가능하므로 `int cnt[101] = {0};`(크기 101)을 준비한다.
- `bool dup = false;`로 "아직 중복 못 봄" 표시를 둔다.
- `while (cin >> v)` 안에서 `cnt[v]++`로 세고, 바로 `if (cnt[v] >= 2)`로 확인해 2 이상이면 `dup = true`.
- 반복이 끝난 뒤 `dup`이 참이면 `YES`, 아니면 `NO`를 출력한다.

재작성 사고 순서

- "중복이 있나?"는 각 값의 횟수를 세다가 2가 되는지 보는 문제다.
- 카운트 배열 크기는 나올 수 있는 최댓값 + 1이어야 한다(100까지면 101).
- 참/거짓 깃발(`dup`) 변수를 두고, 한 번이라도 조건을 만족하면 `true`로 바꿔 끝에서 판정하는 패턴을 익힌다.
```

## L5. 탐색

**개념**

- 탐색은 배열을 처음부터 하나씩 살펴보며 원하는 값을 찾는 것이다.

- 특정 값 x가 배열에 있는지, 있다면 몇 번째(인덱스)에 있는지를 반복문으로 확인한다.

- 인덱스가 필요하면 `for (int i = 0; i < (int)arr.size(); i++)`로 돌며 `arr[i]`를 x와 비교한다. 처음 찾은 위치를 기억하고 `break`로 멈추면 된다.

- 값을 못 찾는 경우도 반드시 생각한다. 끝까지 봐도 없으면 "없음"으로 처리한다(보통 `-1`로 표시).

- 조건에 맞는 값의 개수를 세는 것도 일종의 탐색이다(예: 짝수의 개수).

```cpp
vector<int> arr = {10, 20, 30, 40};
int x = 30;
int pos = -1;                   // 못 찾았다는 표시로 -1 사용
for (int i = 0; i < (int)arr.size(); i++) {
    if (arr[i] == x) {
        pos = i;
        break;
    }
}
cout << pos;                    // 2
```

**그림으로 보기**

`break`가 있느냐 없느냐가 "처음"과 "마지막"을 가른다. `arr = {7, 3, 7, 1, 7}`, `x = 7`인 경우다.

```text
   arr :  7  3  7  1  7
   idx :  0  1  2  3  4
          ^     ^     ^        # x 와 같은 값이 있는 자리
          |           |
          |           +-- no break : pos is overwritten -> 4+1 = 5
          +-- with break : stops right here             -> 0+1 = 1
```

**손으로 따라가기**

`arr = {10, 20, 30, 20}`, `x = 20`으로 "처음 위치"를 찾는다.

| 단계 | i | arr[i] | `arr[i] == x` | pos | 다음 동작 |
| --- | --- | --- | --- | --- | --- |
| 시작 | — | — | — | -1 | 반복 시작 |
| 1 | 0 | 10 | 거짓 | -1 | 계속 |
| 2 | 1 | 20 | 참 | 2 | `break` |

답은 `2`. `break`를 빼면 인덱스 3에서 조건이 다시 참이 되어 `pos`가 `4`로 덮이고, 그것이 곧 "마지막 위치" 풀이가 된다.

**왜 이렇게 되는가**

- "못 찾음"을 `-1`로 표시하는 이유는 그 값이 **정답으로는 절대 나올 수 없기** 때문이다. 위치를 1부터 세면 답은 1 이상이므로 `-1`과 겹치지 않는다. 만약 `0`을 못 찾음 표시로 쓴다면, 위치를 0부터 세는 문제에서는 진짜 답과 구별되지 않는다.
- `pos`를 `-1`로 두는 것에는 C++에서 한 가지 이점이 더 있다. 나중에 `arr[pos]`를 실수로 읽더라도 인덱스 `-1`은 명백히 잘못된 값이라 문제를 빨리 알아챌 수 있다. 반대로 `pos = 0`으로 두면 0번 칸을 정상적으로 읽어 버려 틀린 줄도 모른다.
- 값만 필요할 때는 `for (int v : arr)`처럼 범위 기반 반복이 짧고 안전하다. 하지만 **위치가 필요하면** `for (int i = 0; i < (int)arr.size(); i++)`로 돌아야 한다. `arr[i]`로 값을, `i`로 위치를 동시에 쓸 수 있기 때문이다.
- 개수 세기는 `break` 없이 끝까지 돌아야 한다. 조건에 맞는 것을 하나 찾고 멈추면 나머지를 세지 못한다. "찾으면 멈춘다"와 "끝까지 센다"는 목적이 다르므로 `break`의 유무로 구분된다.
- 부등호도 문제 문장 그대로 옮긴다. "보다 크다(초과)"는 `>`, "이상"은 `>=`다. 기준값과 같은 값을 세느냐 마느냐가 여기서 갈린다.
- `break`는 자기를 감싼 **가장 안쪽 반복 하나**만 빠져나온다. 이중 반복 안에서 `break`를 쓰면 바깥 반복은 계속 돈다. 이 챕터에서는 반복이 한 겹이라 문제가 없지만, 2차원으로 넘어가면 반드시 기억해야 할 성질이다.

**문제**

**1) 값의 위치 찾기** · Medium

- **요구사항**: 정수 여러 개와 찾을 값 x가 주어진다. x가 처음 나타나는 위치(1부터 세는 번째)를 출력하고, 없으면 `-1`을 출력한다.
- **입력**: 첫 줄에 정수 여러 개가 공백으로 구분되어 주어진다. 둘째 줄에 찾을 값 x가 주어진다.
- **출력**: x가 처음 나오는 위치(1번째부터). 없으면 `-1`.
- **예제**: `10 20 30 20`(줄1) `20`(줄2) → `2`   /   `1 2 3`(줄1) `9`(줄2) → `-1`
- **셀프체크**: 인덱스 i에서 찾으면 사람이 세는 위치는 `i+1`이다. 같은 값이 여러 번 있어도 "처음" 위치에서 멈춰야 한다.

```runner
@@SOLUTION
#include <iostream>
#include <vector>
#include <sstream>
#include <string>
using namespace std;

int main() {
    string line;
    getline(cin, line);
    vector<int> arr;
    stringstream ss(line);
    int t;
    while (ss >> t) {
        arr.push_back(t);
    }
    int x;
    cin >> x;
    int pos = -1;
    for (int i = 0; i < (int)arr.size(); i++) {
        if (arr[i] == x) {
            pos = i + 1;
            break;
        }
    }
    cout << pos << "\n";
    return 0;
}
@@TESTS
--IN
10 20 30 20
20
--OUT
2
--IN
1 2 3
9
--OUT
-1
@@EXPL
접근: 처음부터 인덱스 순서로 훑다가 x와 같은 값을 만나면 그 위치를 기록하고 곧바로 멈춘다.

코드 진행

- 첫 줄을 `getline`+`stringstream`으로 정수 배열로 만들고, 둘째 줄의 x를 `cin >> x`로 받는다.
- `pos = -1`로 "아직 못 찾음"을 표시한다(끝까지 없으면 이 값이 답).
- `for (int i = 0; i < (int)arr.size(); i++)`로 인덱스 0부터 순서대로 본다.
- `arr[i] == x`이면 사람이 세는 위치 `i + 1`을 `pos`에 넣고 `break`로 반복을 멈춘다(처음 위치만 필요하므로).
- 마지막에 `pos`를 출력한다.

재작성 사고 순서

- "처음 위치 찾기"는 못 찾음 표시(-1)로 시작 → 순서대로 비교 → 첫 일치에서 멈춤 순서다.
- 인덱스 i를 사람 위치로 바꿀 때 `+1`을 잊지 않는다.
- `break`가 있어야 같은 값이 뒤에 또 있어도 "처음" 위치를 지킨다.
```

**2) 조건에 맞는 개수 세기** · Medium

- **요구사항**: 정수 여러 개와 기준값 t가 주어진다. t보다 큰 값이 몇 개인지 세어 출력한다.
- **입력**: 첫 줄에 정수 여러 개가 공백으로 구분되어 주어진다. 둘째 줄에 기준값 t가 주어진다.
- **출력**: t보다 큰 값의 개수를 출력한다.
- **예제**: `5 10 15 20`(줄1) `10`(줄2) → `2`   /   `1 2 3`(줄1) `100`(줄2) → `0`
- **셀프체크**: t와 "같은" 값은 세지 않는다(초과만). 조건에 맞는 값이 하나도 없으면 0이 나와야 한다.

```runner
@@SOLUTION
#include <iostream>
#include <vector>
#include <sstream>
#include <string>
using namespace std;

int main() {
    string line;
    getline(cin, line);
    vector<int> arr;
    stringstream ss(line);
    int v;
    while (ss >> v) {
        arr.push_back(v);
    }
    int t;
    cin >> t;
    int count = 0;
    for (int i = 0; i < (int)arr.size(); i++) {
        if (arr[i] > t) {
            count++;
        }
    }
    cout << count << "\n";
    return 0;
}
@@TESTS
--IN

10
--OUT
2
--IN
1 2 3
100
--OUT
0
@@EXPL
접근: 배열을 하나씩 보며 기준값 t보다 "큰" 값일 때만 세는 변수를 1 늘린다.

코드 진행

- 첫 줄을 `getline`+`stringstream`으로 배열로, 둘째 줄의 t를 `cin >> t`로 받는다.
- `count = 0`으로 세기 변수를 0에서 시작한다.
- `for`로 값을 하나씩 보며 `if (arr[i] > t)`(초과일 때만) `count++`.
- 조건은 `>`이므로 t와 같은 값은 세지 않는다(예: t가 10이면 15와 20만 세어 2).
- 하나도 맞지 않으면 `count`는 0 그대로다.

재작성 사고 순서

- "조건에 맞는 개수"는 0에서 시작하는 세기 변수 + 조건 만족 시 +1 패턴이다.
- "보다 크다(초과)"는 `>`, "이상"은 `>=`로 부등호를 정확히 고른다.
- 조건에 맞는 값이 없어도 시작값 0이 그대로 답이 되므로 예외 처리가 필요 없다.
```

**3) 특정 값이 마지막으로 나온 위치** · Hard

- **요구사항**: 정수 여러 개와 값 x가 주어진다. x가 "마지막으로" 나타나는 위치(1부터 세는 번째)를 출력하고, 없으면 `-1`을 출력한다.
- **입력**: 첫 줄에 정수 여러 개가 공백으로 구분되어 주어진다. 둘째 줄에 값 x가 주어진다.
- **출력**: x가 마지막으로 나오는 위치(1번째부터). 없으면 `-1`.
- **예제**: `7 3 7 1 7`(줄1) `7`(줄2) → `5`   /   `4 5 6`(줄1) `4`(줄2) → `1`
- **셀프체크**: 처음 만나면 멈추지 말고 끝까지 훑으며 찾을 때마다 위치를 갱신한다. 그래야 "마지막" 위치가 남는다.

```runner
@@SOLUTION

#include <vector>
#include <sstream>
#include <string>

int main() {

    stringstream ss(line);
    int t;

    }
    int x;
    cin >> x;

    for (int i = 0; i < (int)arr.size(); i++) {

            pos = i + 1;
        }

--OUT
5
--IN

@@EXPL
접근: "마지막" 위치를 찾으려면 중간에 멈추지 말고 끝까지 훑으며, x를 만날 때마다 위치를 덮어써 갱신한다.

코드 진행

- 첫 줄을 `getline`+`stringstream`으로 배열로, 둘째 줄의 x를 `cin >> x`로 받는다.
- `pos = -1`로 "아직 못 찾음"을 표시한다.
- `for`로 처음부터 끝까지 인덱스를 본다.
- `arr[i] == x`일 때마다 `pos = i + 1`로 위치를 갱신한다. `break`가 없으므로 뒤에서 다시 나오면 더 큰 위치로 덮인다.
- 반복이 끝나면 마지막에 만난 위치가 `pos`에 남고, 그것을 출력한다.

재작성 사고 순서

- "처음 위치"와 "마지막 위치"의 차이는 `break`의 유무다: 처음은 첫 일치에서 멈추고, 마지막은 멈추지 않고 계속 갱신한다.
- 못 찾을 때를 대비해 시작값 -1을 둔다.
- 값을 만날 때마다 덮어쓰므로, 마지막으로 덮인 값이 자연히 "마지막" 위치가 된다.
```

## L6. Min/Max

**개념**

- 배열에서 가장 작은 값(최솟값)과 가장 큰 값(최댓값)을 찾는 기본 처리다.

- 직접 찾으려면 첫 값을 "현재 최댓값/최솟값"으로 두고, 나머지를 하나씩 비교하며 더 크면(또는 더 작으면) 갱신한다.

- 처음 기준을 아주 큰 수나 아주 작은 수로 잡는 대신 "배열의 첫 값"으로 두면 음수만 있어도 안전하다.

- C++에도 `max(a, b)`, `min(a, b)`(헤더 `<algorithm>`) 같은 함수가 있지만, 여기서는 반복문으로 직접 갱신하는 방법을 익힌다.

```cpp
vector<int> arr = {4, 9, 2, 7};
int mx = arr[0];
for (int i = 0; i < (int)arr.size(); i++) {
    if (arr[i] > mx) mx = arr[i];
}
cout << mx;                     // 9
```

**손으로 따라가기**

`arr = {4, 9, 2, 7}`에서 최댓값과 최솟값을 한 번의 순회로 함께 갱신한다.

| 단계 | v | `v > mx` | `v < mn` | mx | mn |
| --- | --- | --- | --- | --- | --- |
| 시작 | — | — | — | 4 | 4 |
| 1 | 4 | 거짓 | 거짓 | 4 | 4 |
| 2 | 9 | 참 → 갱신 | 거짓 | 9 | 4 |
| 3 | 2 | 거짓 | 참 → 갱신 | 9 | 2 |
| 4 | 7 | 거짓 | 거짓 | 9 | 2 |

최댓값 9, 최솟값 2. 차는 `9 - 2 = 7`이다.

**그림으로 보기**

시작 기준을 무엇으로 잡느냐가 정답을 가른다. 모두 음수인 배열에서 확인해 보자.

```text
   arr = { -3, -8, -1 }

   mx = 0        ->  no value is > 0   ->  mx stays 0     # 틀린 답
   mx = 999999   ->  no value is > it  ->  mx stays big   # 틀린 답
   mx = arr[0]   ->  -3  ...  -1       ->  mx = -1        # 맞는 답
```

**왜 이렇게 되는가**

- 시작 기준을 `arr[0]`으로 두는 이유는 그 값이 **실제로 배열 안에 있는 값**이기 때문이다. 답이 배열 밖의 값으로 새어 나갈 수 없다.
- 상수로 시작하면 그 상수보다 모든 값이 작거나 큰 경우에 답이 상수 그대로 남는다. 배열에 없던 값이 답이 되어 버리는 것이다. 입력 범위를 안다면 상수도 쓸 수 있지만, `arr[0]`은 범위를 몰라도 언제나 안전하다.
- C++에는 `<climits>`의 `INT_MIN`·`INT_MAX`가 있어 `mx = INT_MIN;`으로 시작할 수도 있다. 다만 값이 `long long` 범위까지 갈 수 있는 문제에서 `INT_MIN`을 쓰면 그것보다 더 작은 값이 존재해 틀린다. `arr[0]`으로 시작하면 자료형이 무엇이든 이 걱정이 없다.
- 갱신 조건을 `>`로 두면 같은 값이 와도 바꾸지 않으므로, 최댓값이 여러 번 나올 때 **처음** 위치가 살아남는다. `>=`로 바꾸면 마지막 위치가 남는다. L5의 `break` 유무와 같은 구조의 선택이다.
- 최댓값과 최솟값을 각각 따로 구하면 배열을 두 바퀴 돌아야 하지만, 두 `if`를 한 반복 안에 넣으면 한 바퀴로 끝난다. 원소가 `n`개면 비교는 `2n`번이다.
- 값이 하나뿐이면 반복이 한 번 돌면서 자기 자신과 비교하므로 최댓값과 최솟값이 같아진다. 예외 처리를 따로 넣지 않아도 되는 이유다.
- `arr[0]`으로 시작하는 코드에는 전제가 하나 있다. 배열이 **비어 있지 않아야** 한다. 비어 있으면 `arr[0]` 자체가 칸 밖 접근이라 조용히 쓰레기 값을 읽는다. 입력 개수가 0일 수 있는 문제라면 그 경우를 따로 처리한다.

**문제**

**1) 최댓값과 최솟값** · Easy

- **요구사항**: 정수 여러 개를 입력받아, 최댓값과 최솟값을 한 줄에 공백으로 구분해 출력한다.
- **입력**: 첫 줄에 정수 여러 개(최소 1개)가 공백으로 구분되어 주어진다.
- **출력**: 최댓값과 최솟값을 공백으로 구분해 출력한다.
- **예제**: `4 9 2 7` → `9 2`   /   `-3 -8 -1` → `-1 -8`
- **셀프체크**: 값이 모두 음수여도 올바르게 나오는지 확인한다. 값이 1개면 최댓값과 최솟값이 같다.

```runner
@@SOLUTION
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> arr;
    int x;
    while (cin >> x) {
        arr.push_back(x);
    }
    int mx = arr[0];
    int mn = arr[0];
    for (int i = 0; i < (int)arr.size(); i++) {
        if (arr[i] > mx) mx = arr[i];
        if (arr[i] < mn) mn = arr[i];
    }
    cout << mx << " " << mn << "\n";
    return 0;
}
@@TESTS
--IN
4 9 2 7
--OUT
9 2
--IN
-3 -8 -1
--OUT
-1 -8
@@EXPL
접근: 첫 값을 최댓값이자 최솟값의 시작 기준으로 두고, 나머지를 비교하며 더 크면 최댓값을, 더 작으면 최솟값을 갱신한다.

코드 진행

- `while (cin >> x)`로 값을 끝까지 읽어 `arr`에 담는다.
- `mx = arr[0]`, `mn = arr[0]`으로 둘 다 첫 값으로 시작한다(실제 값 중 하나라 안전하다).
- `for` 안에서 `if (arr[i] > mx) mx = arr[i];`(더 크면 최댓값 갱신), `if (arr[i] < mn) mn = arr[i];`(더 작으면 최솟값 갱신).
- 반복이 끝나면 `mx`에 최댓값, `mn`에 최솟값이 남는다.
- `cout << mx << " " << mn;`으로 공백을 두고 함께 출력한다. 값이 모두 음수여도 `-1 -8`처럼 올바르게 나온다.

재작성 사고 순서

- 최댓/최솟값 찾기는 "첫 값을 기준으로 잡고, 더 나은 값이 오면 갱신"하는 패턴이다.
- 시작 기준을 아주 큰/작은 상수 대신 `arr[0]`으로 두면 음수만 있어도 안전하다.
- 최댓값과 최솟값 갱신을 같은 반복 안에서 각각 `if`로 처리하면 한 번의 순회로 둘 다 구한다.
```

**2) 최댓값의 위치** · Medium

- **요구사항**: 정수 여러 개를 입력받아, 최댓값이 처음 나타나는 위치(1부터 세는 번째)를 출력한다.
- **입력**: 첫 줄에 정수 여러 개(최소 1개)가 공백으로 구분되어 주어진다.
- **출력**: 최댓값이 처음 나오는 위치(1번째부터)를 출력한다.
- **예제**: `3 8 5 8 1` → `2`   /   `10` → `1`
- **셀프체크**: 최댓값을 먼저 구한 뒤 그 값이 처음 나오는 위치를 찾는다. 최댓값이 여러 번 있어도 "처음" 위치여야 한다.

```runner
@@SOLUTION
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> arr;
    int x;
    while (cin >> x) {
        arr.push_back(x);
    }
    int mx = arr[0];
    for (int i = 0; i < (int)arr.size(); i++) {
        if (arr[i] > mx) mx = arr[i];
    }
    int pos = 0;
    for (int i = 0; i < (int)arr.size(); i++) {
        if (arr[i] == mx) {
            pos = i + 1;
            break;
        }
    }
    cout << pos << "\n";
    return 0;
}
@@TESTS
--IN
3 8 5 8 1
--OUT
2
--IN
10
--OUT
1
@@EXPL
접근: 두 단계로 나눈다. 먼저 최댓값이 얼마인지 구하고, 그다음 그 값이 처음 나오는 위치를 찾는다.

코드 진행

- `while (cin >> x)`로 값을 끝까지 읽어 `arr`에 담는다.
- `mx = arr[0]`으로 시작해 `if (arr[i] > mx) mx = arr[i];`로 최댓값을 구한다.
- 위치 찾기: `for`로 인덱스를 훑다가 `arr[i] == mx`이면 `pos = i + 1`을 넣고 `break`로 멈춘다(처음 위치만 필요).
- 예: `3 8 5 8 1`의 최댓값은 8, 처음 8은 인덱스 1이므로 위치 2.
- 값이 1개면 그 값이 최댓값이고 위치는 1이 된다.

재작성 사고 순서

- "최댓값의 위치"는 값 구하기 + 위치 찾기 두 단계로 쪼갠다.
- 위치 찾기는 처음 일치에서 `break`로 멈춰야 "처음" 위치가 된다.
- 인덱스 i를 사람 위치로 바꿀 때 `+1`을 잊지 않는다.
```

**3) 최댓값과 최솟값의 차** · Medium

- **요구사항**: 정수 여러 개를 입력받아, 최댓값에서 최솟값을 뺀 값을 출력한다.
- **입력**: 첫 줄에 정수 여러 개(최소 1개)가 공백으로 구분되어 주어진다.
- **출력**: (최댓값 − 최솟값)을 출력한다.
- **예제**: `4 9 2 7` → `7`   /   `5 5 5` → `0`
- **셀프체크**: 모든 값이 같으면 차가 0이다. 음수가 섞여도 (큰 값 − 작은 값)이라 결과는 0 이상이다.

```runner
@@SOLUTION
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> arr;
    int x;
    while (cin >> x) {
        arr.push_back(x);
    }
    int mx = arr[0];
    int mn = arr[0];
    for (int i = 0; i < (int)arr.size(); i++) {
        if (arr[i] > mx) mx = arr[i];
        if (arr[i] < mn) mn = arr[i];
    }
    cout << mx - mn << "\n";
    return 0;
}
@@TESTS
--IN
4 9 2 7
--OUT
7
--IN
5 5 5
--OUT
0
@@EXPL
접근: 최댓값과 최솟값을 각각 구한 뒤, 큰 값에서 작은 값을 빼면 된다.

코드 진행

- `while (cin >> x)`로 값을 끝까지 읽어 `arr`에 담는다.
- `mx`, `mn`을 모두 `arr[0]`으로 시작한다.
- `for` 안에서 `if (arr[i] > mx) mx = arr[i];`로 최댓값을, `if (arr[i] < mn) mn = arr[i];`로 최솟값을 갱신한다.
- 한 번의 순회로 두 값을 모두 구한 뒤 `cout << mx - mn;`으로 차를 출력한다.
- `4 9 2 7`이면 최댓 9, 최솟 2라 `9 - 2 = 7`. 모든 값이 같으면(`5 5 5`) 최댓=최솟=5라 차가 0.

재작성 사고 순서

- "차"를 구하려면 최댓값과 최솟값이 먼저 필요하다는 걸 떠올린다.
- 둘 다 `arr[0]`을 기준으로 시작해 한 번의 반복 안에서 각각 갱신한다.
- 결과는 항상 큰 값에서 작은 값을 빼므로 0 이상이 된다(모두 같으면 0).
```
