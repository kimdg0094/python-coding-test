## L7. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch7(1차원 배열)의 핵심을 **반복 훈련**하고, 코딩테스트 단골 유형으로 **확장**하는 연습 세트다. 배열로 받기·인덱스·새 배열 만들기·카운트 배열·탐색·최댓/최솟값을 소재만 바꿔 다시 짜 보고, 회전·누적 합·두 배열 비교 같은 배열 단골 유형까지 이어 간다.
- **반복 훈련 개념**
- 한 줄 → 배열: `getline(cin, line);` 로 한 줄을 떼고 `stringstream ss(line); while (ss >> x) arr.push_back(x);`, 개수는 `arr.size()`
- 인덱스 참조: 앞에서 K번째는 `arr[k - 1]`, 뒤에서 K번째는 `arr[(int)arr.size() - k]`
- 새 배열 만들기: `vector<int> res;` 로 시작해 `res.push_back(v)`, 출력은 `if (i > 0) cout << ' ';` 로 값 사이에만 공백을 끼운다
- 카운트/표시 배열: `vector<int> cnt(101, 0);` 뒤 `cnt[v]++` — 값 자체를 인덱스로 쓴다
- 탐색·갱신: `for (int i = 0; i < (int)arr.size(); i++)` 안에서 `if (arr[i] == x)` 또는 `if (v < mn) mn = v;`
- 누적: `int total = 0;` 으로 시작해 `total += v`, 누적 합 배열은 `prefix.push_back(total)`
- **`.size()`는 음수가 없는 정수를 돌려준다**: 배열이 비었을 때 `arr.size() - 1`은 -1이 아니라 어마어마하게 큰 수가 된다. 뺄셈이나 `int` 변수와의 비교에 쓸 때는 `(int)arr.size()`로 형을 맞춘다.
- **범위 밖 인덱스는 조용히 틀린다**: `arr[-1]`은 마지막 값이 아니고, `arr[arr.size()]`도 오류를 내지 않는다. 둘 다 엉뚱한 메모리를 읽어 쓰레기값이 나오거나 프로그램이 죽는다. 마지막 값은 `arr.back()`, 첫 값은 `arr.front()`.
- **코딩테스트 출제 맵**: 백준 「단계별로 풀어보기」의 '1차원 배열'·'누적 합' 단계, solved.ac CLASS 1~2의 배열 순회·빈도 세기 유형, NeetCode 150의 'Arrays & Hashing'(두 배열의 공통 원소·빠진 수 찾기).
- **문제 구성표**

**문제**

**1) 양수·음수·0 개수** · Easy

- **요구사항**: 정수의 개수 N이 먼저 주어지고, 다음 줄에 N개의 정수가 주어진다. 양수·음수·0의 개수를 각각 세어 한 줄에 공백으로 구분해 출력한다.
- **입력**: 첫 줄에 정수 N (1 ≤ N ≤ 100). 둘째 줄에 N개의 정수가 공백으로 구분되어 주어진다(각 값은 -1000 이상 1000 이하).
- **출력**: `양수 개수 음수 개수 0의 개수` 순서로 공백으로 구분해 출력한다.
- **예제**: `5`(줄1) `3 -1 0 2 -5`(줄2) → `2 2 1`   ·   `1`(줄1) `0`(줄2) → `0 0 1`
- **셀프체크**: 0은 양수도 음수도 아니다. `>`, `<`, 나머지(else) 세 갈래로 정확히 나뉘는지, 셋의 합이 N과 같은지 확인한다. 개수 N이 먼저 주어지므로 `cin >> n;` 으로 받은 뒤 그 횟수만큼 값을 읽으면 된다.

```runner
@@SOLUTION
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> arr;
    for (int i = 0; i < n; i++) {
        int v;
        cin >> v;
        arr.push_back(v);
    }
    int pos = 0;
    int neg = 0;
    int zero = 0;
    for (int i = 0; i < (int)arr.size(); i++) {
        if (arr[i] > 0) {
            pos++;
        } else if (arr[i] < 0) {
            neg++;
        } else {
            zero++;
        }
    }
    cout << pos << ' ' << neg << ' ' << zero << '\n';
    return 0;
}
@@TESTS
--IN
5
3 -1 0 2 -5
--OUT
2 2 1
--IN
1
0
--OUT
0 0 1
--IN
3
4 4 4
--OUT
3 0 0
@@EXPL
(1) 접근·핵심 아이디어

- 값의 개수 N이 먼저 주어지는 형식이다. `cin >> n;`으로 개수를 받은 뒤 `for`를 n번 돌며 `cin >> v;`로 값을 하나씩 읽어 배열에 담으면 된다. `>>`는 공백과 줄바꿈을 똑같이 "값 사이의 구분"으로 보므로 줄이 나뉘어 있어도 그대로 읽힌다.
- 세 종류를 세야 하니 세기 변수를 3개 두고, 값마다 어느 갈래인지 판단해 해당 변수만 1 늘린다.

(2) 코드 단계별

- `cin >> n;`으로 개수를 받고, `for (int i = 0; i < n; i++)` 안에서 `arr.push_back(v)`로 값을 배열 뒤에 하나씩 붙인다.
- `pos`, `neg`, `zero`를 모두 0으로 초기화한다. 초기화를 빼면 쓰레기값에서 세기 시작해 결과가 엉망이 된다.
- `for (int i = 0; i < (int)arr.size(); i++)`로 배열을 훑는다. `size()`는 음수가 없는 정수라 `int i`와 그냥 비교하면 컴파일러가 경고를 내므로 `(int)`로 맞춰 준다.
- `arr[i] > 0` → 양수, `else if (arr[i] < 0)` → 음수, 나머지 `else`는 0뿐이다. `else if` 대신 독립된 `if`를 세 번 쓰면 조건이 겹칠 때 두 번 세어질 수 있으니 갈래는 하나로 이어 붙인다.
- 마지막에 `cout << pos << ' ' << neg << ' ' << zero << '\n';`으로 값 사이에 공백을 직접 끼워 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- 입력 형식을 먼저 확인한다: "개수 한 줄 + 값들 한 줄" → 개수를 받고 그만큼 반복.
- 분류가 몇 갈래인지 세고(3갈래), 갈래 수만큼 세기 변수를 둔다.
- 0이 어느 갈래에 들어가는지 명확히 한다. N=1이고 값이 0뿐인 경계값으로 검산한다.
```

**2) 뒤에서 K번째 값** · Easy

- **요구사항**: 정수 여러 개와 위치 번호 K가 주어진다. 뒤에서 K번째 값을 출력한다(뒤에서 1번째는 마지막 값).
- **입력**: 첫 줄에 정수 여러 개가 공백으로 구분되어 주어진다. 둘째 줄에 정수 K (1 이상, 개수 이하).
- **출력**: 뒤에서 K번째 값을 출력한다.
- **예제**: `10 20 30 40`(줄1) `1`(줄2) → `40`   ·   `5 8 13`(줄1) `3`(줄2) → `5`
- **셀프체크**: 마지막 값의 인덱스는 `arr.size() - 1`이고, 뒤에서 K번째는 거기서 `K - 1`만큼 앞이다. 정리하면 인덱스 `arr.size() - K`. K가 개수와 같으면 첫 값이 나와야 한다.

```runner
@@SOLUTION
#include <iostream>
#include <vector>
#include <string>
#include <sstream>
using namespace std;

int main() {
    string line;
    getline(cin, line);
    vector<int> arr;
    stringstream ss(line);
    int x;
    while (ss >> x) {
        arr.push_back(x);
    }
    int k;
    cin >> k;
    cout << arr[(int)arr.size() - k] << '\n';
    return 0;
}
@@TESTS
--IN
10 20 30 40
1
--OUT
40
--IN
5 8 13
3
--OUT
5
--IN
9
1
--OUT
9
@@EXPL
(1) 접근·핵심 아이디어

- 앞에서 K번째가 `arr[k - 1]`이었다면, 뒤에서 K번째는 끝에서부터 거꾸로 센다. 마지막 값의 인덱스 `size - 1`에서 `K - 1`을 빼면 `size - K`가 된다.
- 예를 들어 값이 4개일 때 뒤에서 1번째는 인덱스 `4 - 1 = 3`(마지막), 뒤에서 4번째는 `4 - 4 = 0`(첫 값)이다.

(2) 코드 단계별

- 첫 줄은 값의 개수가 정해져 있지 않으므로 `getline(cin, line);`으로 한 줄을 통째로 떼어 낸다. 그러면 둘째 줄의 K까지 함께 빨려 들어가는 일이 없다.
- `stringstream ss(line);`에 그 줄을 담고 `while (ss >> x) arr.push_back(x);`로 공백 단위 정수를 꺼내 배열에 담는다. `<sstream>`을 포함해야 쓸 수 있다.
- 둘째 줄의 K는 값 하나이므로 `cin >> k;`로 받는다.
- `arr[(int)arr.size() - k]`로 바로 꺼내 출력한다. `(int)` 없이 `arr.size() - k`라고 쓰면 **음수가 없는 정수끼리의 뺄셈**이라, K가 개수보다 크기라도 하면 결과가 음수가 아니라 천문학적인 인덱스가 되어 엉뚱한 메모리를 읽는다.
- 값이 1개고 K=1이면 인덱스 `1 - 1 = 0`이라 그 값이 그대로 나온다.

(3) 스스로 다시 짤 때 생각 순서

- "뒤에서 K번째"를 인덱스 식으로 옮긴다: 마지막 인덱스 `size - 1`에서 `K - 1`을 뺀다 → `size - K`.
- 음수 인덱스는 없다. `arr[-1]`은 마지막 값이 아니라 범위 밖이라 아무 검사 없이 엉뚱한 값을 읽는다. 마지막 값이 필요하면 `arr.back()`을 쓴다.
- K=1이면 마지막, K=개수면 첫 값이 나오는지 두 끝으로 검산한다.
```

**3) 거꾸로 담기** · Easy

- **요구사항**: 정수 여러 개를 입력받아, 순서를 뒤집은 새 배열을 만들어 공백으로 구분해 출력한다.
- **입력**: 첫 줄에 정수 여러 개(최소 1개)가 공백으로 구분되어 주어진다.
- **출력**: 입력의 역순을 공백으로 구분해 한 줄에 출력한다.
- **예제**: `1 2 3 4` → `4 3 2 1`   ·   `7` → `7`
- **셀프체크**: 마지막 인덱스 `size - 1`부터 0까지 거꾸로 돌며 새 배열에 `push_back`한다. 반복 조건이 `i >= 0`이어야 인덱스 0이 포함된다. 값이 1개면 그대로 나온다.

```runner
@@SOLUTION
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> arr;
    int x;
    while (cin >> x) {
        arr.push_back(x);
    }
    vector<int> rev;
    for (int i = (int)arr.size() - 1; i >= 0; i--) {
        rev.push_back(arr[i]);
    }
    for (int i = 0; i < (int)rev.size(); i++) {
        if (i > 0) {
            cout << ' ';
        }
        cout << rev[i];
    }
    cout << '\n';
    return 0;
}
@@TESTS
--IN
1 2 3 4
--OUT
4 3 2 1
--IN
7
--OUT
7
--IN
5 5 6
--OUT
6 5 5
@@EXPL
(1) 접근·핵심 아이디어

- 뒤집기는 "마지막 값부터 첫 값까지 순서대로 꺼내 새 배열 뒤에 붙이기"다. 빈 배열 + `push_back` 패턴에 인덱스를 거꾸로 도는 반복을 결합한다.
- 입력이 한 줄뿐이고 뒤에 다른 값이 없으므로 `while (cin >> x)`로 입력이 끝날 때까지 정수를 읽으면 된다.

(2) 코드 단계별

- `vector<int> arr;`로 빈 배열을 만들고 `while (cin >> x) arr.push_back(x);`로 채운다. 읽기에 실패하면(입력 끝) 조건이 거짓이 되어 반복이 멈춘다.
- 결과를 담을 `vector<int> rev;`를 준비한다.
- `for (int i = (int)arr.size() - 1; i >= 0; i--)`: 값이 4개면 i는 3, 2, 1, 0 순서다. 여기서 `(int)`가 중요하다. `arr.size() - 1`을 그대로 쓰면 형이 음수가 없는 정수라, 나중에 `i >= 0` 비교가 항상 참이 되는 식으로 뒤틀릴 수 있다.
- 조건을 `i > 0`으로 쓰면 인덱스 0이 빠져 한 개 모자란 결과가 나온다. 끝값을 포함해야 하므로 `i >= 0`이다.
- 출력은 `if (i > 0) cout << ' ';`로 값 사이에만 공백을 끼우고 마지막에 `'\n'`을 붙인다.

(3) 스스로 다시 짤 때 생각 순서

- "거꾸로"라는 말이 나오면 시작값 `size - 1`, 조건 `i >= 0`, 갱신 `i--` 세 가지를 정확히 정한다.
- 크기에서 1을 빼는 순간 `(int)`로 형을 맞추는 습관을 들인다. 빈 배열에서 `size() - 1`은 0이 아니라 거대한 수다.
- 값이 1개일 때와, 같은 값이 여러 개일 때(`5 5 6` → `6 5 5`)로 검산한다.
```

**4) 홀수 번째 값의 합** · Easy

- **요구사항**: 정수 여러 개를 입력받아, 1번째·3번째·5번째 … 처럼 홀수 번째 자리에 있는 값들의 합을 출력한다(사람이 세는 방식으로 1번째부터).
- **입력**: 첫 줄에 정수 여러 개(최소 1개)가 공백으로 구분되어 주어진다.
- **출력**: 홀수 번째 값들의 합을 출력한다.
- **예제**: `1 2 3 4 5` → `9`   ·   `10 20` → `10`
- **셀프체크**: 사람이 세는 "1번째"는 인덱스 0이다. 즉 홀수 번째 자리는 인덱스가 짝수(0, 2, 4, …)인 자리다. 이 어긋남을 놓치면 정반대 값들을 더하게 된다.

```runner
@@SOLUTION
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> arr;
    int x;
    while (cin >> x) {
        arr.push_back(x);
    }
    int total = 0;
    for (int i = 0; i < (int)arr.size(); i++) {
        if (i % 2 == 0) {
            total += arr[i];
        }
    }
    cout << total << '\n';
    return 0;
}
@@TESTS
--IN
1 2 3 4 5
--OUT
9
--IN
10 20
--OUT
10
--IN
7
--OUT
7
--IN
-3 5 -3
--OUT
-6
@@EXPL
(1) 접근·핵심 아이디어

- "몇 번째 자리인가"가 조건이므로 값이 아니라 인덱스를 돌아야 한다. `for (int i = 0; i < (int)arr.size(); i++)`로 인덱스를 돌면서 `arr[i]`를 참조한다.
- 사람이 세는 홀수 번째(1, 3, 5번째)는 인덱스로는 0, 2, 4 — 짝수다. 따라서 조건은 `i % 2 == 0`이다.

(2) 코드 단계별

- `while (cin >> x)`로 값을 모두 읽어 배열에 담고 `int total = 0;`으로 시작한다.
- `for (int i = 0; i < (int)arr.size(); i++)`로 인덱스를 0부터 끝까지 돈다. 조건에 `<=`를 쓰면 `arr[size]`라는 범위 밖 칸을 읽게 되는데, 이는 오류로 잡히지 않고 쓰레기값을 더해 버린다. 그래서 반드시 `<`다.
- `i % 2 == 0`일 때만 `total += arr[i];`. 인덱스 0, 2, 4의 값 1, 3, 5가 더해져 9가 된다.
- 반복이 끝나면 `total`을 출력한다. 음수가 섞여도 그대로 더하면 된다(`-3 5 -3` → -6).

(3) 스스로 다시 짤 때 생각 순서

- 조건이 "값"에 대한 것인지 "자리"에 대한 것인지 구분한다 → 자리 → 인덱스 반복.
- 사람 기준 번째와 인덱스가 1 어긋난다는 점을 먼저 정리한다: 홀수 번째 = 짝수 인덱스.
- 갱신을 `i += 2`로 두어 2칸씩 건너뛰어도 같은 결과가 나온다. 값이 1개일 때 그 값이 그대로 나오는지 검산한다.
```

**5) 같은 자리 비교** · Easy

- **요구사항**: 길이가 같은 두 정수 배열이 두 줄로 주어진다. 같은 자리(같은 인덱스)에 같은 값이 들어 있는 자리가 몇 개인지 출력한다.
- **입력**: 첫 줄과 둘째 줄에 각각 정수 여러 개가 공백으로 구분되어 주어진다. 두 줄의 개수는 같다(최소 1개).
- **출력**: 값이 같은 자리의 개수를 출력한다.
- **예제**: `1 2 3 4`(줄1) `1 5 3 9`(줄2) → `2`   ·   `1 2`(줄1) `3 4`(줄2) → `0`
- **셀프체크**: 두 배열을 각각 다른 이름으로 받아야 한다. 인덱스 i를 돌며 `a[i]`와 `b[i]`를 나란히 비교한다. 같은 자리가 하나도 없으면 0이다.

```runner
@@SOLUTION
#include <iostream>
#include <vector>
#include <string>
#include <sstream>
using namespace std;

int main() {
    string line1, line2;
    getline(cin, line1);
    getline(cin, line2);
    vector<int> a;
    vector<int> b;
    int x;
    stringstream s1(line1);
    while (s1 >> x) {
        a.push_back(x);
    }
    stringstream s2(line2);
    while (s2 >> x) {
        b.push_back(x);
    }
    int same = 0;
    for (int i = 0; i < (int)a.size(); i++) {
        if (a[i] == b[i]) {
            same++;
        }
    }
    cout << same << '\n';
    return 0;
}
@@TESTS
--IN
1 2 3 4
1 5 3 9
--OUT
2
--IN
1 2
3 4
--OUT
0
--IN
7
7
--OUT
1
@@EXPL
(1) 접근·핵심 아이디어

- 두 배열을 "같은 자리끼리" 비교하려면 인덱스 i를 공통으로 쓰며 `a[i]`와 `b[i]`를 함께 본다. 값을 하나씩 꺼내는 범위 기반 `for (int v : a)`로는 b의 같은 자리를 짚을 수 없다.
- 조건(같다)에 맞을 때만 세기 변수를 1 늘리는 누적 패턴이다.

(2) 코드 단계별

- 두 줄 모두 길이가 정해져 있지 않으므로 `getline`으로 한 줄씩 떼어 낸 뒤 각각 `stringstream`으로 쪼갠다. `while (cin >> x)`로 한꺼번에 읽으면 두 줄이 한 덩어리로 섞여 어디서 끊어야 할지 알 수 없다.
- `stringstream s1(line1);`, `stringstream s2(line2);`처럼 줄마다 따로 만든다. 하나를 재사용하려면 내용과 상태를 다시 맞춰 줘야 해서 새로 만드는 편이 안전하다.
- `int same = 0;`으로 시작한다.
- `for (int i = 0; i < (int)a.size(); i++)`로 인덱스를 돌며 `a[i] == b[i]`이면 `same++`. 두 배열의 길이가 같으므로 `a.size()`만 써도 안전하다. 만약 b가 더 짧다면 `b[i]`가 범위 밖이 되어 조용히 쓰레기값과 비교하게 된다.
- 반복이 끝나면 `same`을 출력한다. `1 2 3 4`와 `1 5 3 9`는 인덱스 0과 2가 같아 2다.

(3) 스스로 다시 짤 때 생각 순서

- "두 배열의 같은 자리"라는 말이 나오면 인덱스 반복을 고른다.
- 비교 대상이 값 자체인지 자리인지 헷갈리지 않는다 — 여기서는 같은 자리의 값끼리다.
- 하나도 같지 않은 경우(0)와 값이 1개인 경우로 검산한다.
```

**6) 빠진 번호 찾기** · Medium

- **요구사항**: 1부터 N까지의 번호표 중 하나가 빠진 채 N-1개가 순서 없이 주어진다. 빠진 번호를 출력한다.
- **입력**: 첫 줄에 정수 N (2 ≤ N ≤ 100). 둘째 줄에 1 이상 N 이하의 서로 다른 정수 N-1개가 공백으로 구분되어 주어진다.
- **출력**: 빠진 번호 하나를 출력한다.
- **예제**: `5`(줄1) `2 5 1 4`(줄2) → `3`   ·   `2`(줄1) `2`(줄2) → `1`
- **셀프체크**: 크기 N+1인 표시 배열을 0으로 만들고, 나온 번호의 자리를 1로 표시한다. 그다음 1부터 N까지 훑어 표시가 0인 번호가 답이다. 인덱스 0은 쓰지 않으므로 크기를 N이 아니라 N+1로 잡아야 한다.

```runner
@@SOLUTION
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> seen(n + 1, 0);
    for (int i = 0; i < n - 1; i++) {
        int v;
        cin >> v;
        seen[v] = 1;
    }
    for (int num = 1; num <= n; num++) {
        if (seen[num] == 0) {
            cout << num << '\n';
        }
    }
    return 0;
}
@@TESTS
--IN
5
2 5 1 4
--OUT
3
--IN
2
2
--OUT
1
--IN
4
1 2 3
--OUT
4
@@EXPL
(1) 접근·핵심 아이디어

- "어떤 번호가 나왔는가"를 기억하는 데 카운트 배열의 변형인 표시 배열을 쓴다. 번호 자체를 인덱스로 삼아 `seen[v] = 1`로 표시하면, 나중에 1부터 N까지 훑으며 표시가 없는 번호를 바로 찾을 수 있다.
- 번호가 1부터 N까지이므로 인덱스 N까지 써야 한다. 배열 크기는 `N + 1`(인덱스 0은 비워 둔다).

(2) 코드 단계별

- `cin >> n;`으로 N을 받는다.
- `vector<int> seen(n + 1, 0);`은 "크기 n+1을 전부 0으로" 만든다는 뜻이다. 두 번째 인자를 빼면 `vector<int> seen(n + 1);`도 0으로 채워지지만, 값을 명시해 두면 의도가 분명해진다. 반대로 크기를 주지 않고 `vector<int> seen;`으로 만들면 칸이 하나도 없어서 `seen[v] = 1`이 범위 밖 쓰기가 된다.
- 값은 N-1개이므로 `for (int i = 0; i < n - 1; i++)` 안에서 `cin >> v;` 후 `seen[v] = 1;`.
- `for (int num = 1; num <= n; num++)`로 1부터 N까지 보며 `seen[num] == 0`인 번호를 출력한다. 빠진 번호는 정확히 하나이므로 출력도 한 번이다.
- N=2에 `2`만 있으면 `seen[1]`이 0이라 1이 답, `1 2 3`만 있고 N=4면 4가 답이다.

(3) 스스로 다시 짤 때 생각 순서

- "무엇이 나왔는지 기억"이 필요하면 값을 인덱스로 쓰는 표시 배열을 떠올린다.
- 배열 크기는 "나올 수 있는 가장 큰 값 + 1". N을 그대로 쓰면 `seen[N]`이 범위 밖이 되는데, 이 실수는 오류 메시지 없이 통과했다가 답만 틀리게 나오기도 한다.
- 표시 후 1~N을 순서대로 훑는다. 빠진 번호가 1(맨 앞)이나 N(맨 뒤)인 경계값으로 검산한다.
```

**7) 왼쪽으로 K칸 회전** · Medium

- **요구사항**: 정수 여러 개와 K가 주어진다. 배열을 왼쪽으로 K칸 회전한 결과를 출력한다. 왼쪽으로 1칸 회전하면 첫 값이 맨 뒤로 가고 나머지는 한 칸씩 앞으로 당겨진다.
- **입력**: 첫 줄에 정수 여러 개(최소 1개)가 공백으로 구분되어 주어진다. 둘째 줄에 정수 K (0 ≤ K ≤ 100).
- **출력**: 회전한 배열을 공백으로 구분해 한 줄에 출력한다.
- **예제**: `1 2 3 4 5`(줄1) `2`(줄2) → `3 4 5 1 2`   ·   `1 2 3`(줄1) `3`(줄2) → `1 2 3`
- **셀프체크**: 새 배열의 i번째 값은 원래 배열의 `(i + K)`번째 값인데, 끝을 넘으면 앞으로 돌아와야 하므로 `(i + K) % 길이`를 쓴다. K가 길이와 같거나 더 크면 `%` 덕분에 자동으로 처리된다.

```runner
@@SOLUTION
#include <iostream>
#include <vector>
#include <string>
#include <sstream>
using namespace std;

int main() {
    string line;
    getline(cin, line);
    vector<int> arr;
    stringstream ss(line);
    int x;
    while (ss >> x) {
        arr.push_back(x);
    }
    int k;
    cin >> k;
    int n = (int)arr.size();
    vector<int> rot;
    for (int i = 0; i < n; i++) {
        rot.push_back(arr[(i + k) % n]);
    }
    for (int i = 0; i < n; i++) {
        if (i > 0) {
            cout << ' ';
        }
        cout << rot[i];
    }
    cout << '\n';
    return 0;
}
@@TESTS
--IN
1 2 3 4 5
2
--OUT
3 4 5 1 2
--IN
1 2 3
3
--OUT
1 2 3
--IN
4 7
5
--OUT
7 4
--IN
9
100
--OUT
9
@@EXPL
(1) 접근·핵심 아이디어

- 왼쪽으로 K칸 회전하면 새 배열의 0번 자리에는 원래 K번 값이, 1번 자리에는 K+1번 값이 온다. 즉 새 인덱스 i ↔ 원래 인덱스 `i + K`다.
- `i + K`가 길이를 넘으면 앞으로 감아 돌아야 한다. 나머지 연산 `(i + K) % n`이 0 ~ n-1 범위로 되돌려 준다. 이 한 식으로 K가 길이보다 큰 경우까지 모두 해결된다.

(2) 코드 단계별

- 첫 줄을 `getline` + `stringstream`으로 배열 `arr`에 담고, 둘째 줄의 K를 `cin >> k;`로 받는다.
- `int n = (int)arr.size();`로 길이를 `int` 변수에 담아 둔다. 이렇게 해 두면 이후의 `%` 계산과 `for` 조건이 모두 `int`끼리라 형이 섞이는 문제가 생기지 않는다.
- `for (int i = 0; i < n; i++)` 안에서 `rot.push_back(arr[(i + k) % n]);`: 길이 5, K=2면 i=0→2, 1→3, 2→4, 3→5%5=0, 4→6%5=1 순서로 값을 가져온다.
- 출력은 값 사이에만 공백을 넣고 마지막에 `'\n'`. K=3, 길이 3이면 `(i + 3) % 3 = i`라 원래와 같고, 길이 2에 K=5면 `5 % 2 = 1`칸 회전과 같다.
- `k`가 음수라면 `%`의 결과도 음수가 되어 범위 밖 인덱스가 된다. 이 문제는 K가 0 이상이라 안전하지만, 음수가 섞이는 문제에서는 `((i + k) % n + n) % n`처럼 한 번 더 감아 준다.

(3) 스스로 다시 짤 때 생각 순서

- 원래 배열의 값을 직접 옮기려 하지 말고, "새 배열의 i번 자리에 원래 몇 번 값이 오나"를 식으로 적는다 → `i + K`.
- 인덱스가 길이를 넘는 경우를 떠올리고 `% n`으로 감는다.
- K=0(그대로), K=길이(그대로), K>길이(나머지만큼 회전), 값 1개(항상 그대로)로 검산한다.
```

**8) 누적 합 리스트** · Medium

- **요구사항**: 정수 여러 개를 입력받아, 각 자리까지의 합(첫 값, 첫 두 값의 합, 첫 세 값의 합, …)을 담은 새 배열을 만들어 공백으로 구분해 출력한다.
- **입력**: 첫 줄에 정수 여러 개(최소 1개)가 공백으로 구분되어 주어진다.
- **출력**: 누적 합을 순서대로 공백으로 구분해 한 줄에 출력한다.
- **예제**: `1 2 3 4` → `1 3 6 10`   ·   `-1 1 -1 1` → `-1 0 -1 0`
- **셀프체크**: 합을 담는 변수 하나를 0으로 시작해 값을 더할 때마다 "그 시점의 합"을 새 배열에 붙인다. 더하기 전이 아니라 더한 뒤에 붙여야 첫 항이 첫 값과 같아진다. 음수가 섞이면 누적 합이 줄어들 수도 있다.

```runner
@@SOLUTION
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> arr;
    int x;
    while (cin >> x) {
        arr.push_back(x);
    }
    vector<int> prefix;
    int total = 0;
    for (int i = 0; i < (int)arr.size(); i++) {
        total += arr[i];
        prefix.push_back(total);
    }
    for (int i = 0; i < (int)prefix.size(); i++) {
        if (i > 0) {
            cout << ' ';
        }
        cout << prefix[i];
    }
    cout << '\n';
    return 0;
}
@@TESTS
--IN
1 2 3 4
--OUT
1 3 6 10
--IN
-1 1 -1 1
--OUT
-1 0 -1 0
--IN
5
--OUT
5
@@EXPL
(1) 접근·핵심 아이디어

- 누적 합(접두합)은 "앞에서부터 여기까지 더한 값"을 자리마다 기록한 것이다. 합계 구하기(`total += arr[i]`)와 새 배열 만들기(`push_back`)를 한 반복 안에서 함께 하면 된다.
- i번째 누적 합은 i-1번째 누적 합에 i번째 값을 더한 것이므로, 매번 처음부터 다시 더할 필요 없이 `total` 하나를 계속 키워 가면 된다.

(2) 코드 단계별

- 입력을 배열로 받고 `vector<int> prefix;`, `int total = 0;`을 준비한다.
- `for (int i = 0; i < (int)arr.size(); i++)` 안에서 먼저 `total += arr[i];`로 현재 값까지 더한다.
- 바로 `prefix.push_back(total);`로 "여기까지의 합"을 새 배열에 붙인다. 순서를 바꿔 먼저 붙이면 첫 항이 0이 되어 어긋난다.
- 출력은 값 사이에만 공백을 끼우고 마지막에 `'\n'`. `1 2 3 4`는 1, 1+2=3, 3+3=6, 6+4=10이 된다.
- 누적 합은 값이 계속 커지는 계산이라 자료형을 살펴야 한다. `int`는 약 21억까지만 담고, 넘으면 조용히 음수로 뒤집힌다. 값이 크거나 개수가 많은 문제라면 `long long total = 0;`과 `vector<long long> prefix;`로 바꾼다. 이 문제는 값이 작아 `int`로 충분하다.

(3) 스스로 다시 짤 때 생각 순서

- "각 자리까지의 합"이라는 말이 나오면 누적 변수 + 새 배열 패턴을 떠올린다.
- 반복 안의 두 동작 순서를 정한다: 더하기 → 기록하기.
- 값이 1개면 결과도 그 값 하나, 음수가 섞이면 줄었다 늘었다 하는지(`-1 0 -1 0`)로 검산한다.
```

**9) 최솟값의 마지막 위치** · Medium

- **요구사항**: 정수 여러 개를 입력받아, 최솟값이 "마지막으로" 나타나는 위치(1부터 세는 번째)를 출력한다.
- **입력**: 첫 줄에 정수 여러 개(최소 1개)가 공백으로 구분되어 주어진다.
- **출력**: 최솟값이 마지막으로 나오는 위치(1번째부터)를 출력한다.
- **예제**: `4 1 3 1 2` → `4`   ·   `2 2 2` → `3`
- **셀프체크**: 최솟값을 갱신하는 조건을 `<`가 아니라 `<=`로 두면, 같은 최솟값을 다시 만날 때마다 위치가 뒤쪽으로 덮여 "마지막" 위치가 남는다. 모든 값이 같으면 마지막 자리가 답이다.

```runner
@@SOLUTION
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> arr;
    int x;

(1) 접근·핵심 아이디어

- 최솟값 찾기(첫 값을 기준으로 잡고 더 작은 값이 오면 갱신)와 위치 기록을 한 번의 순회로 처리한다. 값을 갱신할 때 위치 `i + 1`도 함께 저장한다.
- "마지막 위치"가 필요하므로 같은 값을 다시 만났을 때도 갱신해야 한다. 그래서 부등호가 `<`(처음 위치)가 아니라 `<=`(마지막 위치)다.

- `for (int i = 0; i < (int)arr.size(); i++)`로 인덱스를 돌며 `arr[i] <= mn`이면 `mn = arr[i];`, `pos = i + 1;`.
- `4 1 3 1 2`에서 인덱스 1의 1로 갱신(pos 2), 인덱스 3의 1도 `<=`라 다시 갱신(pos 4). 끝까지 돌면 pos는 4다.
- `2 2 2`는 매번 `<=`가 참이라 pos가 1, 2, 3으로 덮여 3이 남는다.
- `arr[0]`을 쓰기 전에 배열이 비어 있지 않은지 따져야 한다. 빈 배열에 `arr[0]`을 하면 오류 없이 쓰레기값을 읽는다. 이 문제는 값이 최소 1개라고 보장되어 있다.

(3) 스스로 다시 짤 때 생각 순서

- 최솟값과 위치를 같이 들고 다닌다: 갱신할 때 두 변수를 함께 바꾼다.
- "처음"이면 `<`, "마지막"이면 `<=` — 부등호 하나가 답을 가른다는 것을 기억한다.
- 값이 1개(위치 1), 모두 같은 값(마지막 자리), 최솟값이 맨 끝에 있는 경우로 검산한다.
```

**10) 점수 등수 매기기** · Medium

- **요구사항**: 여러 명의 점수가 주어진다. 각 사람의 등수를 순서대로 출력한다. 등수는 "자기보다 높은 점수의 사람 수 + 1"이며, 점수가 같으면 같은 등수다(예: 1등이 둘이면 다음은 3등).
- **입력**: 첫 줄에 정수 여러 개(최소 1개, 최대 100개)가 공백으로 구분되어 주어진다.
- **출력**: 입력 순서대로 각 사람의 등수를 공백으로 구분해 한 줄에 출력한다.
- **예제**: `90 80 90 70` → `1 3 1 4`   ·   `5 5 5` → `1 1 1`
- **셀프체크**: 사람 i마다 다른 모든 사람 j를 돌며 `arr[j] > arr[i]`인 수를 세면 된다(이중 반복). 같은 점수는 세지 않으므로(`>`) 동점자가 같은 등수가 된다. 정렬 없이 풀 수 있다.

```runner
@@SOLUTION
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> arr;
    int x;
    while (cin >> x) {
        arr.push_back(x);
    }
    int n = (int)arr.size();
    vector<int> rank;
    for (int i = 0; i < n; i++) {
        int r = 1;
        for (int j = 0; j < n; j++) {
            if (arr[j] > arr[i]) {
                r++;
            }
        }
        rank.push_back(r);
    }
    for (int i = 0; i < n; i++) {
        if (i > 0) {
            cout << ' ';
        }
        cout << rank[i];
    }
    cout << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- 등수의 정의를 그대로 코드로 옮긴다: "나보다 높은 점수가 몇 명인가 + 1". 사람마다 전체를 한 번씩 훑어야 하므로 배열 위의 이중 반복이 된다(Ch6의 2중 for를 배열에 적용).
- 비교 조건을 `>`로 두면 같은 점수는 세지 않아, 동점자끼리 같은 등수가 되고 그다음 등수는 자동으로 건너뛴다(1, 1, 3처럼).

(2) 코드 단계별

- 입력을 배열로 받고 길이를 `int n`에 담은 뒤 결과 배열 `vector<int> rank;`를 준비한다.
- 바깥 `for (int i = 0; i < n; i++)`가 "등수를 구할 사람", 안쪽 `for (int j = 0; j < n; j++)`가 "비교 대상 전체"다. 사람마다 `int r = 1;`로 새로 시작한다. `r`을 안쪽 for 앞, 바깥 for 안에서 선언했기 때문에 사람이 바뀔 때마다 자동으로 1로 되돌아간다.
- `arr[j] > arr[i]`일 때만 `r++`. 자기 자신(`j == i`)은 같은 값이라 세어지지 않으니 따로 빼지 않아도 된다.
- 안쪽 반복이 끝나면 `rank.push_back(r);`. 마지막에 값 사이 공백을 넣어 출력한다.
- 값이 100개면 비교는 100×100=10,000번이다. 이 규모는 순식간에 끝나지만, 개수가 수만 개로 커지면 이 방식은 느려진다는 점은 기억해 둔다.

(3) 스스로 다시 짤 때 생각 순서

- 등수 정의를 말로 적고 그대로 "세기" 문제로 바꾼다.
- 사람마다 세기 변수 `r`을 1로 다시 놓는 위치(바깥 for 안, 안쪽 for 앞)를 지킨다. 바깥에 선언해 두면 앞 사람의 값이 그대로 이어져 등수가 계속 커진다.
- 동점(`5 5 5` → 모두 1등), 한 명(1등), 오름차순 입력(`10 20 30` → 3 2 1)으로 검산한다.
```

**11) 두 리스트 공통 원소** · Hard

- **요구사항**: 0 이상 100 이하의 정수로 이루어진 두 배열이 두 줄로 주어진다. 두 배열 모두에 들어 있는 값을 중복 없이 오름차순으로 출력한다. 공통 값이 하나도 없으면 `-1`을 출력한다.
- **입력**: 첫 줄과 둘째 줄에 각각 0~100 사이 정수 여러 개(최소 1개)가 공백으로 구분되어 주어진다. 두 줄의 개수는 달라도 된다.
- **출력**: 공통 값을 오름차순으로 공백으로 구분해 한 줄에 출력한다. 없으면 `-1`.
- **예제**: `3 1 4 1 5`(줄1) `5 9 2 6 5 3`(줄2) → `3 5`   ·   `1 2`(줄1) `3 4`(줄2) → `-1`
- **셀프체크**: 배열마다 크기 101인 표시 배열을 만들어 나온 값을 1로 표시한 뒤, 0부터 100까지 순서대로 훑으며 둘 다 1인 값을 새 배열에 담는다. 0부터 훑으므로 정렬 없이도 오름차순이 되고, 표시 배열이라 같은 값이 여러 번 나와도 한 번만 출력된다.

```runner
- "양쪽에 모두 있는 값"을 찾으려면 각 배열에 어떤 값이 있는지 기억해야 한다. 값의 범위가 0~100으로 작으므로 값을 인덱스로 쓰는 표시 배열 두 개(`ina`, `inb`)를 만들면, 값 v가 양쪽에 있는지는 `ina[v] == 1 && inb[v] == 1` 한 줄로 확인된다.

- `common.size() == 0`이면 `-1`, 아니면 값 사이에 공백을 넣어 출력한다. 비었는지 확인할 때 `size() - 1` 같은 뺄셈을 쓰지 않는 편이 안전하다. 빈 배열에서는 그 값이 음수가 아니라 거대한 수가 되기 때문이다. `common.empty()`라고 써도 같은 뜻이다.
- `7 7`과 `7`은 표시가 한 번만 되어 `7` 하나가 나온다.

(3) 스스로 다시 짤 때 생각 순서

- "포함 여부"를 빠르게 묻고 싶다 → 값 범위가 작으면 표시 배열.
- 두 배열이므로 표시 배열도 두 개. 크기는 "최댓값 + 1".
- 결과를 값 순서로 훑으면 오름차순·중복 제거가 공짜로 된다. 공통이 없는 경우(-1), 0과 100 같은 양 끝 값이 공통인 경우로 검산한다.
```

**12) 구간 합 질의** · Hard

- **요구사항**: 정수 배열과 질의 개수 Q가 주어지고, 이어서 Q개의 줄에 구간 `l r`(1부터 세는 번째, l ≤ r)이 주어진다. 각 구간에 대해 l번째부터 r번째까지 값의 합을 한 줄에 하나씩 출력한다.
- **입력**: 첫 줄에 정수 여러 개(최소 1개, 최대 100개)가 공백으로 구분되어 주어진다. 둘째 줄에 정수 Q (1 ≤ Q ≤ 50). 이어서 Q개의 줄에 두 정수 `l r` (1 ≤ l ≤ r ≤ 개수).
- **출력**: Q개의 줄. 각 줄에 해당 구간의 합.
- **예제**: `5 4 3 2 1`(줄1) `3`(줄2) `1 3`(줄3) `2 4`(줄4) `5 5`(줄5) → `12`(줄1) `9`(줄2) `1`(줄3)   ·   `7`(줄1) `1`(줄2) `1 1`(줄3) → `7`
- **셀프체크**: 질의마다 구간을 매번 더해도 되지만, 누적 합 배열 `prefix`를 한 번 만들어 두면 구간 합이 `prefix[r] - prefix[l - 1]` 뺄셈 한 번으로 나온다. `prefix[0] = 0`을 두면 l=1일 때 `prefix[0]`을 빼도 값이 어긋나지 않는다. 질의 줄은 Q번 반복해서 읽어야 한다.

```runner
@@SOLUTION
#include <iostream>
#include <vector>
#include <string>
#include <sstream>
using namespace std;

int main() {
    string line;
    getline(cin, line);
    vector<int> arr;
    stringstream ss(line);
    int x;
    while (ss >> x) {
        arr.push_back(x);
    }
    int n = (int)arr.size();
    vector<int> prefix(n + 1, 0);
    for (int i = 0; i < n; i++) {
        prefix[i + 1] = prefix[i] + arr[i];
    }
    int q;
    cin >> q;
    for (int t = 0; t < q; t++) {
        int l, r;
        cin >> l >> r;
        cout << prefix[r] - prefix[l - 1] << '\n';
    }
    return 0;
}

(1) 접근·핵심 아이디어

- 구간 합을 여러 번 물어보면 매번 반복으로 더하는 대신, "처음부터 i번째까지의 합"을 미리 담은 누적 합 배열을 한 번만 만들어 둔다. 그러면 l~r의 합은 (1~r의 합) − (1~l-1의 합), 즉 `prefix[r] - prefix[l - 1]`이다.
- 앞에 0을 하나 두어 `prefix[0] = 0`, `prefix[i]` = 1번째~i번째의 합이 되게 만들면, 사람이 세는 번째(1부터)와 인덱스가 딱 맞아 l=1일 때도 특별 처리가 필요 없다.

(2) 코드 단계별

- 첫 줄을 `getline` + `stringstream`으로 배열 `arr`에 담고 길이를 `int n`에 저장한다.
- `vector<int> prefix(n + 1, 0);`으로 크기 n+1 배열을 0으로 만든다. 크기를 n으로 잡으면 `prefix[n]`이 범위 밖이 되고, 그 실수는 오류 없이 통과했다가 마지막 질의만 이상한 값을 내놓는다.
- `for (int i = 0; i < n; i++)`로 `prefix[i + 1] = prefix[i] + arr[i];`를 채운다. `5 4 3 2 1`이면 `prefix`는 `0 5 9 12 14 15`.
- `cin >> q;`로 질의 개수를 받고, `for (int t = 0; t < q; t++)`로 Q번 반복하며 매번 `cin >> l >> r;`로 두 값을 읽는다. `>>`가 줄바꿈을 알아서 건너뛰므로 질의가 몇 줄로 나뉘어 있든 순서대로 읽힌다.
- 각 질의에서 `prefix[r] - prefix[l - 1]`을 출력한다. `1 3`은 12 − 0 = 12, `2 4`는 14 − 5 = 9, `5 5`는 15 − 14 = 1.
- 값이나 개수가 커지는 문제라면 누적 합이 `int` 범위(약 21억)를 넘길 수 있다. 그때는 `vector<long long> prefix(n + 1, 0);`으로 바꾼다.

(3) 스스로 다시 짤 때 생각 순서

- "구간 합을 여러 번" → 누적 합 배열을 먼저 만든다. 앞에 0을 하나 두는 크기 n+1 방식이 인덱스 계산을 가장 단순하게 만든다.
- 질의는 줄마다 하나씩이므로 Q번 반복해 읽는다는 입력 구조를 놓치지 않는다.
- l=1(맨 앞부터), l=r(한 칸), 음수가 섞인 구간으로 뺄셈 식이 맞는지 검산한다.
```
