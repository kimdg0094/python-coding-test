## L10. 정리 — 개념 지도·체크리스트·자주 하는 실수

**개념**

이 챕터에서 배운 것을 한자리에 모아 정리한다. 새 문법은 없다. 대신 **어디에 무엇이 있는지 지도를 그리고**, 실제로 코드를 쓸 때 바로 꺼내 쓸 뼈대를 정리하고, 입문자가 반드시 한 번은 겪는 실수를 미리 겪어 본다.

**개념 지도**

Ch01은 결국 세 단계다. **값을 만들고 → 상자에 담고 → 화면에 보여 준다.** C++에서는 상자를 만들 때 자료형을 먼저 적는다는 점만 더해진다.

```text
  make a value    ->    keep it in a box    ->    show it

  +------------+        +--------------+          +----------------+
  | 5          |  ====> |  int x;      |  =====>  | cout << x      |
  | 5.0        | assign |   +------+   |   read   | cout << a << b |
  | "five"     |        |   |  5   |   |          | setprecision   |
  +------------+        |   +------+   |          +----------------+
     L1  L2             +--------------+             L1  L3  L4
                          L2 L5 L6 L7 L8
```

가운데 "상자" 단계가 이 챕터의 절반을 차지한다. 상자 안 값이 바뀌는 방법이 레슨 순서대로 하나씩 늘어난다.

```text
  how a box changes                              lesson
  -------------------------------------------    ------
  int x = 10;            declare and fill        L2
  x = 20;                overwrite               L5
  x = x + 5;             read, compute, store    L5
  x += 5;                same thing, shorter     L5
  b = a;                 copy from another box   L6
  c = a + b;             build a new value       L6
  t = a; a = b; b = t;   swap with a spare box   L7 L8
  x = y = 0;             same value into 2 boxes L8
```

출력 단계에서 C++이 파이썬과 갈리는 지점은 하나다. **아무것도 자동으로 넣어 주지 않는다.** 공백도 줄바꿈도 사람이 넣는다.

```text
  two things on one line

        cout << a << b;              cout << a << " " << b;
              |                              |
      nothing in between                a space you typed
              |                              |
      any types are fine               any types are fine
              |                              |
   "Age:" , 20  ->  Age:20         "Age:" , 20  ->  Age: 20

  // C++ never inserts a space or a newline by itself
```

값을 이어 붙일 때 `+` 를 쓸 수 있는 경우는 제한적이다. 헷갈리면 전부 `<<` 로 통일하면 된다.

```text
  gluing with +

  string a = "Sea", b = "side";
  a + b            ->  "Seaside"        // ok: a is a string
  "Sea" + "side"   ->  compile error    // two literals cannot be added
  "Age: " + 20     ->  DANGEROUS        // moves the pointer, not a join

  cout << "Age: " << 20;                // always safe
```

**뼈대 코드**

이 챕터 유형을 만나면 아래 다섯 개 중 하나를 골라 값만 바꾸면 된다.

```cpp
// 1) 정해진 문장을 그대로 출력하기
#include <iostream>
using namespace std;

int main() {
    cout << "first line" << "\n";     // <- 문제마다 바뀜
    cout << "second line" << "\n";    // <- 문제마다 바뀜
    return 0;
}
// 문장 안에 " 를 넣어야 하면 \" 로 적는다: cout << "He said \"hi\"";
```

```cpp
// 2) 값을 변수에 담고 라벨을 붙여 출력하기
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "Pen";                    // <- 문제마다 바뀜 (문자열)
    int price = 1200;                       // <- 문제마다 바뀜 (정수)
    double weight = 8.5;                    // <- 문제마다 바뀜 (실수)
    cout << "Item: " << name << "\n";       // 공백은 직접 넣는다
    cout << "Price: " << price << "\n";
    cout << "Weight: " << weight << "\n";
    return 0;
}
```

```cpp
// 3) 계산한 뒤 소수점 자릿수를 고정해 출력하기
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int total = 1200 * 3;                   // <- 문제마다 바뀜
    double pay = total * 0.9;               // 실수를 곱하면 결과도 실수
    cout << total << "\n";                  // 정수는 그대로 (.0 이 안 붙는다)
    cout << fixed << setprecision(1);       // <- 자릿수도 문제마다 바뀜
    cout << pay << "\n";
    return 0;
}
```

```cpp
// 4) 같은 변수를 덮어쓰며 여러 줄 출력하기 (케이스 형식)
#include <iostream>
using namespace std;

int main() {
    int a = 3, b = 4;                       // <- 문제마다 바뀜
    cout << "Case #1: " << a + b << "\n";
    a = 10;                                 // 새 변수를 만들지 않고 덮어쓴다
    b = 5;
    cout << "Case #2: " << a + b << "\n";
    return 0;
}
```

```cpp
// 5) 두 값 교환 — 임시 변수 세 줄
int temp = a;        // 곧 사라질 값을 먼저 보관 (자료형은 a 와 같게)
a = b;
b = temp;
// 표준 함수 swap(a, b); 도 안에서 똑같은 세 줄을 한다
```

**언제 무엇을 쓰나**

| 상황 | 고르는 것 | 이유 | 복잡도 |
|------|-----------|------|--------|
| 여러 값을 한 줄에 이어 출력 | `cout << a << b;` | `<<` 는 얼마든지 이어 쓸 수 있다 | O(1) |
| 값 사이를 한 칸 띄울 때 | `cout << a << " " << b;` | 공백은 자동으로 생기지 않는다 | O(1) |
| 줄을 바꿔야 할 때 | `cout << "\n";` | 줄바꿈도 하나의 글자다 | O(1) |
| 출력이 아주 많을 때 | `endl` 대신 `"\n"` | `endl` 은 매번 버퍼를 비워 느리다 | O(1) |
| 문자열끼리 붙일 때 | `string s = a; s + b` | 한쪽이 `string` 이어야 `+` 가 이어 붙이기다 | O(길이) |
| 문자열과 숫자를 함께 | `<<` 로 이어 쓰기 | `+` 로 섞으면 위험하게 오동작한다 | O(1) |
| 소수점 자릿수를 맞출 때 | `fixed << setprecision(n)` | `fixed` 가 있어야 "소수점 아래" 자릿수다 | O(1) |
| 정수를 있는 그대로 보여 줄 때 | `cout << n;` | 정수에는 자릿수 설정이 영향을 주지 않는다 | O(1) |
| 큰 값이 될 수 있을 때 | `long long` | `int` 는 약 21억에서 값이 뒤집힌다 | O(1) |
| 값을 통째로 새 값으로 | `x = 새 값;` | 이전 값은 덮어써져 사라진다 | O(1) |
| 지금 값을 이용해 바꿀 때 | `x += 1;` (= `x = x + 1;`) | 오른쪽을 먼저 계산한 뒤 다시 담는다 | O(1) |
| 두 값을 맞바꿀 때 | `temp` 를 쓴 세 줄 | 덮어써져 사라질 값을 먼저 보관한다 | O(1) |
| 여러 변수에 같은 값을 넣을 때 | `x = y = 0;` | 두 변수를 연결하는 게 아니라 각각 넣는다 | O(1) |

**✅ 마스터 체크리스트**

- [ ] 설명할 수 있다: `cout <<` 가 하는 일과 하지 않는 일은 각각 무엇인가.
- [ ] 설명할 수 있다: 왜 `"\n"` 을 빠뜨리면 두 출력이 한 줄에 붙는가.
- [ ] 설명할 수 있다: `endl` 과 `"\n"` 의 차이는 무엇이며 왜 `"\n"` 을 권하는가.
- [ ] 설명할 수 있다: 큰따옴표 `"a"` 와 작은따옴표 `'a'` 는 각각 어떤 자료형인가.
- [ ] 설명할 수 있다: `5`, `5.0`, `"5"` 는 각각 어떤 자료형이며 무엇이 달라지는가.
- [ ] 설명할 수 있다: `=` 가 "같다"가 아니라 무엇을 뜻하며, 왜 `5 = x;` 는 오류인가.
- [ ] 설명할 수 있다: `int n = 3.7;` 이 왜 오류가 아니라 `3` 이 되는가.
- [ ] 설명할 수 있다: `int x;` 라고만 선언한 변수를 바로 쓰면 왜 위험한가.
- [ ] 설명할 수 있다: `"Age: " + 20` 이 왜 컴파일 오류보다 더 위험한가.
- [ ] 설명할 수 있다: `setprecision(2)` 를 `fixed` 없이 쓰면 무엇이 달라지는가.
- [ ] 설명할 수 있다: `0.1 + 0.2` 가 왜 정확히 `0.3` 이 아닌가.
- [ ] 설명할 수 있다: `x = x + 1;` 이 실행되는 순서를 세 단계로 나누면 무엇인가.
- [ ] 설명할 수 있다: `b = a;` 뒤에 `a` 를 바꾸면 왜 `b` 는 그대로인가.
- [ ] 설명할 수 있다: 교환할 때 임시 변수가 왜 필요하며, 무엇을 지키기 위한 것인가.
- [ ] 설명할 수 있다: `x = y = 0;` 이 두 변수를 연결하는 것이 아닌 이유는 무엇인가.

**⚠️ 자주 하는 실수**

**(1) 줄바꿈을 빠뜨린다**

```cpp
// ❌ 틀린 코드
cout << "Hello";
cout << "World";        // HelloWorld
```

왜: `cout` 은 줄을 바꾸지 않는다. 사람이 `"\n"` 을 넣지 않으면 다음 출력이 같은 줄에 그대로 이어 붙는다.

```cpp
// ✅ 고친 코드
cout << "Hello" << "\n";
cout << "World" << "\n";
```

**(2) 문자열 안의 큰따옴표를 그대로 쓴다**

```cpp
// ❌ 틀린 코드
cout << "He said "hi"" << "\n";
```

왜: 컴파일러는 두 번째 `"` 에서 문자열이 끝났다고 판단한다. 남은 `hi""` 를 해석할 수 없어 컴파일 오류가 난다.

```cpp
// ✅ 고친 코드
cout << "He said \"hi\"" << "\n";     // 안쪽 따옴표는 \" 로
```

**(3) 문자열과 숫자를 `+` 로 잇는다**

```cpp
// ❌ 틀린 코드
int age = 20;
cout << "Age: " + age << "\n";        // 오류가 아니라 오동작
```

왜: 이 `+` 는 이어 붙이기가 아니라 **문자열의 시작 위치를 20칸 옮기라**는 뜻으로 해석된다. 글자가 이상하게 잘리거나 프로그램이 예측 불가능하게 동작한다.

```cpp
// ✅ 고친 코드
int age = 20;
cout << "Age: " << age << "\n";       // 이어 쓸 때는 언제나 <<
```

**(4) 공백을 두 번 넣는다**

```cpp
// ❌ 틀린 코드
int temp = 36;
cout << "Temperature: " << " " << temp << "\n";   // 공백 2칸
```

왜: 문자열 끝에 이미 공백이 있는데 `<< " " <<` 로 한 칸을 더 넣었다. 정답과 한 글자가 어긋나 오답이 된다.

```cpp
// ✅ 고친 코드
int temp = 36;
cout << "Temperature: " << temp << "\n";          // 공백 1칸
```

**(5) `fixed` 없이 `setprecision` 만 쓴다**

```cpp
// ❌ 틀린 코드
double pi = 3.14159;
cout << setprecision(2) << pi << "\n";    // 3.1
```

왜: `fixed` 가 없으면 숫자는 "소수점 아래 자릿수"가 아니라 **전체 유효숫자 개수**를 뜻한다. 그래서 `3.14` 가 아니라 `3.1` 이 나온다.

```cpp
// ✅ 고친 코드
double pi = 3.14159;
cout << fixed << setprecision(2) << pi << "\n";   // 3.14
```

**(6) 정수끼리 나눠 놓고 실수 상자에 담는다**

```cpp
// ❌ 틀린 코드
int total = 7;
double avg = total / 2;      // 3, not 3.5
cout << fixed << setprecision(2) << avg << "\n";   // 3.00
```

왜: 오른쪽이 **이미 정수 나눗셈으로 끝난 뒤** 결과가 복사된다. 실수 상자에 담는다고 잘려 나간 소수가 돌아오지는 않는다.

```cpp
// ✅ 고친 코드
int total = 7;
double avg = total / 2.0;    // 나누기 전에 한쪽을 실수로
cout << fixed << setprecision(2) << avg << "\n";   // 3.50
```

**(7) 임시 변수 없이 교환한다**

```cpp
// ❌ 틀린 코드
int a = 10, b = 20;
a = b;                       // 여기서 10이 사라진다
b = a;                       // b 에는 20이 다시 들어간다
cout << a << " " << b << "\n";   // 20 20
```

왜: 대입은 덮어쓰기다. `a = b;` 를 하는 순간 `a` 의 10은 복사본이 없어 되찾을 수 없다.

```cpp
// ✅ 고친 코드
int a = 10, b = 20;
int temp = a;                // 사라질 값을 먼저 보관
a = b;
b = temp;
cout << a << " " << b << "\n";   // 20 10
```

**(8) 계산만 하고 다시 담지 않는다**

```cpp
// ❌ 틀린 코드
int count = 0;
count + 1;                   // 계산만 하고 버린다
cout << count << "\n";       // 0
```

왜: 값이 바뀌는 순간은 그 변수가 `=` 의 **왼쪽**에 나올 때뿐이다. 오른쪽에서만 쓰인 계산 결과는 어디에도 담기지 않고 사라진다.

```cpp
// ✅ 고친 코드
int count = 0;
count = count + 1;           // 또는 count += 1; / count++;
cout << count << "\n";       // 1
```

**(9) 초기화하지 않은 변수를 바로 쓴다**

```cpp
// ❌ 틀린 코드
int sum;                     // 상자를 만들기만 했다
sum = sum + 10;              // 쓰레기 값에 10을 더한다
cout << sum << "\n";         // 실행할 때마다 답이 달라진다
```

왜: C++은 선언만 한 지역 변수를 0으로 채워 주지 않는다. 상자에는 그 자리에 남아 있던 **아무 의미 없는 값**이 들어 있다.

```cpp
// ✅ 고친 코드
int sum = 0;                 // 선언과 동시에 시작값을 정한다
sum = sum + 10;
cout << sum << "\n";         // 10
```

**다음 챕터로**

- Ch01에서는 값을 **코드 안에 직접 적었다.** Ch02에서는 그 값을 사람이 키보드로 넣어 준다(`cin >>`).
- 이때 값을 어떤 자료형의 상자로 받느냐가 곧 "어떻게 읽을지"를 정한다. 이 챕터에서 익힌 "자료형이 다르면 같은 기호의 뜻이 달라진다"는 감각이 곧바로 필요해진다.
- 출력 쪽 도구(`cout <<` 이어 쓰기, `fixed << setprecision`)는 이후 모든 챕터에서 그대로 쓰인다. 지금 확실히 굳혀 두면 다시 배울 일이 없다.
