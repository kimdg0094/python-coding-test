## L13. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch4(조건문)의 핵심을 **반복 훈련**하고, 코딩테스트 단골 유형으로 **확장**하는 연습 세트다. 새 문법은 없다. 지금까지 배운 `if / else if / else`, 삼항 연산자, `&& / ||`, 중첩 조건문만으로 14문제를 푼다.

- **반복 훈련 개념**
- `if / else` 두 갈래: 조건이 참이면 위 중괄호, 아니면 아래 중괄호 — `if (m >= p) { ... } else { ... }`
- 삼항 연산자: 값 하나를 한 줄로 고르기, 조건이 **맨 앞** — `cout << (h >= 140 ? "ride" : "wait") << "\n";`
- `else if` 사슬: 구간을 **한쪽 방향으로** 차례로 걸러 각 줄은 경계 하나만 신경 쓰기 — `if (t >= 28) { ... } else if (t >= 20) { ... } else if (t >= 10) { ... } else { ... }`
- `&& / ||` 혼합: "그리고"는 `&&`, "또는"은 `||`, 섞이면 **괄호**로 묶기 — `(y % 4 == 0 && y % 100 != 0) || y % 400 == 0`
- 중첩 조건문: 먼저 큰 갈래를 나누고 그 안에서 다시 세분 — `if (avg >= 70) {` 안에 `if (inc <= 3) {` …

- **C++에서 특히 조심할 것**
- 비교는 `==`, 대입은 `=`. `if (x = 5)`는 오류가 아니라 **경고만** 내고 항상 참이 된다.
- 연쇄 비교 `3 < x < 7`은 컴파일은 되지만 `(3 < x) < 7`, 즉 `0 또는 1 < 7`이라 **항상 참**이다. 반드시 `3 < x && x < 7`로 쪼갠다.
- 중괄호를 빼면 바로 다음 **한 문장만** 조건에 묶인다. `if (c);`처럼 세미콜론을 찍으면 빈 문장이 몸통이 된다.
- 정수끼리의 `/`는 소수점을 **버린다**. 나눗셈이 섞이면 결과 자릿수를 먼저 확인한다.

- **코딩테스트 출제 맵**: 이 챕터의 유형은 백준 「단계별로 풀어보기」의 '조건문' 단계(윤년·알람 시계·사분면·시험 성적 류)와 solved.ac CLASS 1(세 수 비교·날짜 계산 류)에 그대로 등장한다. 이 레슨의 유형 확장 문제는 그 대표 유형을 소재와 수치를 새로 만들어 재구성한 것이다.

**문제**

**1) 거스름돈 계산** · Easy

- **요구사항**: 물건 가격과 손님이 낸 돈을 입력받는다. 낸 돈이 가격 이상이면 거스름돈(낸 돈 − 가격)을 출력하고, 낸 돈이 부족하면 `short` 를 출력하라.
- **입력**: 한 줄에 정수 두 개 `p m` (가격 `p`, 낸 돈 `m`, 공백으로 구분, 0 ≤ p, m ≤ 100000)
- **출력**: 거스름돈(정수) 또는 `short` 한 줄
- **예제**: `3500 5000` → `1500` · `4000 4000` → `0` · `5000 3000` → `short`
- **셀프체크**: 딱 맞게 냈을 때(`4000 4000`)는 부족이 아니라 거스름돈 `0` 이다. 조건에 `>` 가 아니라 `>=` 를 썼는가? 계산 결과는 `cout << m - p` 처럼 따옴표 없이, 글자 그대로 찍을 값은 `cout << "short"` 처럼 큰따옴표로 감싼다. C++에서 작은따옴표 `'short'` 는 문자 하나를 뜻하므로 문자열에 쓸 수 없다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int p, m;
    cin >> p >> m;
    if (m >= p) {
        cout << m - p << "\n";
    } else {
        cout << "short" << "\n";
    }
    return 0;
}
@@TESTS
--IN
3500 5000
--OUT
1500
--IN
4000 4000
--OUT
0
--IN
5000 3000
--OUT
short
@@EXPL
(1) 접근·핵심 아이디어

- "낼 수 있다 / 없다" 두 갈래뿐이므로 `if / else` 하나로 끝난다. 갈래를 가르는 기준은 "낸 돈이 가격 이상인가"다.
- 함정은 경계값이다. 낸 돈과 가격이 같으면 부족한 게 아니라 거스름돈이 0원인 정상 상황이므로, 조건은 `m >= p` 여야 한다.

(2) 코드 단계별

- 한 줄에 두 수가 오지만 `cin >> p >> m;` 한 줄이면 공백을 알아서 건너뛰며 둘 다 읽는다. 파이썬처럼 문자열을 잘라 변환하는 단계가 없다.
- `if (m >= p) {` 가 참이면 `cout << m - p << "\n";` 로 거스름돈을 계산해 숫자로 출력한다.
- 거짓이면 `else {` 안에서 `cout << "short" << "\n";` 로 문자열을 출력한다.
- 조건은 소괄호 `( )` 안에, 실행할 코드는 중괄호 `{ }` 안에 둔다. 중괄호를 빼도 한 문장이면 동작하지만, 나중에 줄을 추가할 때 조용히 망가지므로 처음부터 감싸 두는 편이 안전하다.

(3) 스스로 다시 짤 때 생각 순서

- 결과가 두 종류(숫자 / 문자열)임을 확인하고 `if / else` 로 정한다.
- "같을 때"를 어느 쪽에 넣을지 먼저 결정한다 → 거스름돈 0 쪽이므로 `>=`.
- `4000 4000` 을 넣어 `0` 이 나오는지 검산하면 부등호 실수를 바로 잡을 수 있다.
- C++ 함정 하나 더. 비교를 `if (m = p)` 로 잘못 쓰면 대입이 되어 오류 없이 컴파일되고, `p` 가 0이 아닌 한 항상 참이 된다. 컴파일러가 경고를 주더라도 실행은 되므로 스스로 `==` 와 `=` 를 구분하는 습관이 필요하다.
```

**2) 놀이기구 탑승 안내** · Easy

- **요구사항**: 놀이기구의 키 제한은 140cm 이상이다. 키를 입력받아 탈 수 있으면 `ride`, 아니면 `wait` 를 출력하라. 반드시 삼항 연산자를 사용한다.
- **입력**: 정수 `h` 한 개 (키, cm 단위, 50 ≤ h ≤ 250)
- **출력**: `ride` 또는 `wait` 한 줄
- **예제**: `152` → `ride` · `139` → `wait` · `140` → `ride`
- **셀프체크**: C++ 삼항 연산자는 `조건 ? 참일_때 : 거짓일_때` 순서로, 조건이 **맨 앞**에 온다. `cout` 에 넣을 때는 반드시 괄호로 감싼다 — `<<` 가 `?:` 보다 먼저 묶여서 `cout << h >= 140 ? ...` 는 뜻이 완전히 달라진다. 경계 140은 "이상"이므로 탈 수 있다(`>=`).

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int h;
    cin >> h;
    cout << (h >= 140 ? "ride" : "wait") << "\n";
    return 0;
}
@@TESTS
--IN
152
--OUT
ride
--IN
139
--OUT
wait
--IN
140
--OUT
ride
@@EXPL
(1) 접근·핵심 아이디어

- 결과가 두 문자열 중 하나이므로 삼항 연산자로 값을 골라 바로 출력에 넣을 수 있다. `if / else` 다섯 줄이 한 줄로 줄어든다.
- "140 이상"이라는 말은 경계 140을 포함한다. 그래서 조건은 `h > 140` 이 아니라 `h >= 140` 이다.

(2) 코드 단계별

- `cin >> h;` 로 키를 정수로 읽는다.
- `h >= 140 ? "ride" : "wait"` — 조건이 참이면 `?` 뒤의 값 `"ride"`, 거짓이면 `:` 뒤의 값 `"wait"` 가 선택된다.
- 이 표현식 전체가 값 하나가 되므로 그대로 `cout << (...) << "\n";` 안에 넣는다.
- 괄호가 핵심이다. `<<` 의 우선순위가 `?:` 보다 높아서 괄호가 없으면 `(cout << h) >= 140` 부터 계산되어 의도한 동작이 나오지 않는다.

(3) 스스로 다시 짤 때 생각 순서

- "결과가 값 두 개 중 하나"이면 삼항 연산자를 떠올린다.
- 조건을 맨 앞에 쓰고(`h >= 140 ?`), 참일 때 값을 `?` 뒤에, 거짓일 때 값을 `:` 뒤에 둔다.
- 출력문에 넣을 때 괄호를 씌웠는지 확인한다.
- 경계 140과 바로 아래 139를 넣어 결과가 갈리는지 확인한다.
```

**3) 두 수의 차이** · Easy

- **요구사항**: 정수 두 개를 입력받아 큰 수에서 작은 수를 뺀 값(두 수의 차이, 항상 0 이상)을 출력하라. 삼항 연산자를 사용한다.
- **입력**: 한 줄에 정수 두 개 `a b` (공백 구분, −1000 ≤ a, b ≤ 1000)
- **출력**: 두 수의 차이(0 이상의 정수) 한 줄
- **예제**: `3 10` → `7` · `10 3` → `7` · `-4 -9` → `5` · `6 6` → `0`
- **셀프체크**: 어느 쪽이 큰지에 따라 빼는 순서가 바뀐다. 음수끼리(`-4 -9`)도 큰 수(−4)에서 작은 수(−9)를 빼야 `5` 가 나온다. 같은 수면 0이다. 삼항 연산자의 두 갈래는 타입이 같아야 하는데, 여기서는 양쪽 다 `int` 라 문제없다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << (a >= b ? a - b : b - a) << "\n";
    return 0;
}
@@TESTS
--IN
3 10
--OUT
7
--IN
10 3
--OUT
7
--IN
-4 -9
--OUT
5
--IN
6 6
--OUT
0
@@EXPL
(1) 접근·핵심 아이디어

- "큰 수 − 작은 수"는 어느 쪽이 큰지에 따라 계산식이 두 가지다. `a` 가 크거나 같으면 `a - b`, 아니면 `b - a`. 값 두 개 중 하나를 고르는 상황이므로 삼항 연산자가 딱 맞는다.
- 두 수가 같을 때는 어느 식을 써도 0이므로 `>=` 와 `>` 둘 다 정답이 되지만, 같은 경우까지 명시적으로 왼쪽 식에 포함시키는 `>=` 가 읽기에 안전하다.

(2) 코드 단계별

- `cin >> a >> b;` 로 두 정수를 읽는다. `-4` 처럼 앞에 부호가 붙어 있어도 `int` 로 정상 변환된다.
- `a >= b ? a - b : b - a` — `a >= b` 가 참이면 `a - b`, 거짓이면 `b - a` 가 값으로 선택된다.
- 그 값을 바로 출력한다. 결과는 항상 0 이상이다.
- 표준 라이브러리를 쓴다면 `abs(a - b)` 한 줄로도 되지만, 여기서는 조건으로 갈래를 고르는 연습이 목적이다.

(3) 스스로 다시 짤 때 생각 순서

- "빼는 순서가 조건에 따라 달라진다"를 인식하고, 두 식을 먼저 써 둔다.
- 조건을 맨 앞에 두고 `?` 와 `:` 로 두 식을 잇는다.
- 음수 예제 `-4 -9` 로 검산한다. −4가 더 크므로 `-4 - (-9) = 5` 가 맞는지 손으로 확인한다.
```

**4) 기온별 옷차림 안내** · Easy

- **요구사항**: 기온을 입력받아 옷차림을 안내한다. 28도 이상이면 `hot`, 20도 이상 28도 미만이면 `warm`, 10도 이상 20도 미만이면 `cool`, 10도 미만이면 `cold` 를 출력하라.
- **입력**: 정수 `t` 한 개 (기온, −30 ≤ t ≤ 45)
- **출력**: `hot`, `warm`, `cool`, `cold` 중 한 줄
- **예제**: `31` → `hot` · `20` → `warm` · `10` → `cool` · `-5` → `cold`
- **셀프체크**: 높은 기온부터 `>=` 로 검사하면 각 줄에 하한만 쓰면 된다. 경계값 28·20·10이 각각 위쪽 구간에 속하는지 확인. 낮은 기온부터 `>=` 로 쓰면 모든 값이 첫 조건에 걸려 오답이 난다. 또 `else if` 로 잇지 않고 `if` 만 네 번 쓰면 31도에서 네 줄이 다 나올 수 있다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int t;
    cin >> t;
    if (t >= 28) {
        cout << "hot" << "\n";
    } else if (t >= 20) {
        cout << "warm" << "\n";
    } else if (t >= 10) {
        cout << "cool" << "\n";
    } else {
        cout << "cold" << "\n";
    }
    return 0;
}
@@TESTS
--IN
31
--OUT
hot
--IN
20
--OUT
warm
--IN
10
--OUT
cool
--IN
-5
--OUT
cold
@@EXPL
(1) 접근·핵심 아이디어

- 구간이 넷이므로 `if / else if / else if / else` 사슬로 나눈다. 핵심은 **높은 기온부터** 검사하는 것이다. 그러면 앞 조건에서 걸러진 값은 자동으로 제외되어 각 줄에 하한 조건 하나만 쓰면 된다.
- 예를 들어 두 번째 줄 `else if (t >= 20)` 에 도달한 값은 이미 `t >= 28` 이 거짓이었으므로 자연히 20 이상 28 미만이다. "28 미만"을 따로 쓸 필요가 없다.

(2) 코드 단계별

- `cin >> t;` 로 기온을 읽는다. 음수 기온도 정수로 잘 읽힌다.
- `if (t >= 28)` → `hot`. 여기서 참이면 나머지 줄은 검사조차 하지 않는다.
- `else if (t >= 20)` → `warm`, `else if (t >= 10)` → `cool`. 각각 위 조건이 거짓이었던 값만 도달한다.
- 셋 다 거짓이면(10 미만) `else` 에서 `cold`.
- C++에는 파이썬의 `elif` 라는 한 단어가 없다. `else` 뒤에 다시 `if` 를 붙인 `else if` 두 단어이며, 사실은 `else` 의 몸통 자리에 `if` 문 하나가 들어간 형태다. 그래서 사슬이 길어져도 중괄호 짝만 맞으면 된다.

(3) 스스로 다시 짤 때 생각 순서

- 구간의 경계(28, 20, 10)를 큰 순서로 나열한다.
- 위에서부터 `t >= 경계` 를 `if / else if` 로 잇고, 마지막 남은 구간은 `else` 로 처리한다.
- 경계값 세 개(28, 20, 10)를 하나씩 넣어 각각 위쪽 구간(`hot`, `warm`, `cool`)에 들어가는지 검산한다. 순서를 거꾸로(10부터) 쓰면 31도도 `cool` 이 되어 버리는 점이 함정이다.
```

**5) 우산과 외투** · Easy

- **요구사항**: 비 예보(1이면 비, 0이면 맑음)와 추위 예보(1이면 추움, 0이면 안 추움)를 입력받는다. 비가 오면 `umbrella`, 추우면 `coat` 를 각각 한 줄씩 출력하라. 둘 다 해당하면 두 줄(우산 먼저), 둘 다 아니면 아무것도 출력하지 않는다.

- **출력**: 해당하는 준비물을 각각 한 줄씩 (없으면 출력 없음)
- **예제**: `1 1` → `umbrella / coat` (두 줄) · `0 1` → `coat` · `0 0` → (출력 없음) · `1 0` → `umbrella`

int main() {

- "비가 오는가"와 "추운가"는 동시에 참일 수 있고, 각각 따로 판단해야 한다. 이런 상황은 `if / else if` 가 아니라 **독립된 `if` 두 개**다. `else if` 는 위 조건이 참이면 아래를 건너뛰기 때문에 `1 1` 에서 외투가 사라진다.

(2) 코드 단계별

- `cin >> rain >> cold;` 로 두 값을 읽는다.
- 첫 번째 `if (rain == 1)` 이 참이면 `umbrella` 를 출력한다.
- 두 번째 `if (cold == 1)` 은 첫 번째 결과와 상관없이 **다시** 검사되어 참이면 `coat` 를 출력한다.
- 출력 순서는 코드의 순서(우산 → 외투)를 그대로 따른다.
- C++ 함정. 첫 번째 `if` 뒤에 세미콜론을 찍어 `if (rain == 1);` 이라고 쓰면 "참일 때 아무것도 안 한다"는 완전한 문장이 되어, 그 아래 중괄호 블록이 조건과 무관하게 항상 실행된다. 오류가 나지 않으므로 눈으로 찾아야 한다.

(3) 스스로 다시 짤 때 생각 순서

- "두 조건이 동시에 참일 수 있는가?"를 먼저 묻는다 → 그렇다면 `else if` 금지, 독립 `if`.
- 요구된 출력 순서대로 `if` 를 배치한다.
- `1 1` 로 두 줄이 모두 나오는지, `0 0` 으로 아무것도 안 나오는지 두 극단을 검산한다.
```

**6) 운전면허 필기·실기** · Easy

- **요구사항**: 운전면허 필기 점수와 실기 점수를 입력받아, 두 과목 **모두** 60점 이상이면 `pass`, 하나라도 60점 미만이면 `fail` 을 출력하라.
- **입력**: 한 줄에 정수 두 개 `written practical` (각각 0 이상 100 이하)
- **출력**: `pass` 또는 `fail` 한 줄
- **예제**: `70 65` → `pass` · `60 60` → `pass` · `90 59` → `fail` · `59 100` → `fail`

@@SOLUTION
#include <iostream>

int main() {

        cout << "fail" << "\n";
    }
    return 0;
}
@@TESTS

--OUT

--IN

--OUT

--IN

(1) 접근·핵심 아이디어

- 두 과목이 **둘 다** 기준을 넘어야 하므로 두 비교를 `&&` 로 잇는다. `&&` 는 하나라도 거짓이면 전체가 거짓이 되어, 한 과목만 잘 봐도 `fail` 이 된다.
- 경계 60은 "이상"이라 통과이므로 두 비교 모두 `>=` 를 쓴다.

(2) 코드 단계별

- `cin >> written >> practical;` 로 두 점수를 읽는다.
- `written >= 60 && practical >= 60` — 각 과목을 **따로** 60과 비교하고 `&&` 로 묶는다. 비교식을 양쪽에 완전하게 쓰는 것이 중요하다.
- 참이면 `pass`, 아니면 `else` 로 `fail`.
- C++에서 `&&` 는 왼쪽이 거짓이면 오른쪽을 아예 계산하지 않는다(단축 평가). 지금은 결과에 영향이 없지만, 오른쪽에 나눗셈이나 함수 호출이 들어가는 문제에서는 이 성질이 방어 장치가 된다.

(3) 스스로 다시 짤 때 생각 순서

- "모두 = `&&`, 하나라도 = `||`" 규칙을 먼저 떠올린다.
- 각 과목의 비교식을 완전한 형태(`변수 >= 60`)로 두 개 쓰고 `&&` 로 잇는다.
- 한쪽만 통과하는 입력(`90 59`, `59 100`)이 둘 다 `fail` 로 나오는지, 경계 `60 60` 이 `pass` 인지 검산한다.
```

**7) 윤년 판별** · Medium

- **요구사항**: 연도를 입력받아 윤년이면 `1`, 아니면 `0` 을 출력하라. 윤년은 "4의 배수이면서 100의 배수가 아닌 해" 또는 "400의 배수인 해"다.
- **입력**: 정수 `y` 한 개 (1 ≤ y ≤ 4000)
- **출력**: `1` 또는 `0` 한 줄
- **예제**: `2024` → `1` · `1900` → `0` · `2000` → `1` · `2023` → `0`
- **셀프체크**: 조건을 말로 먼저 정리한다 — "(4의 배수 그리고 100의 배수 아님) 또는 (400의 배수)". `&&` 부분을 괄호로 묶었는가? 1900은 4의 배수지만 100의 배수라 평년, 2000은 100의 배수지만 400의 배수라 윤년이다. 이 두 해로 검산하지 않으면 틀린 조건도 2024에서는 맞아 보인다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int y;
    cin >> y;
    if ((y % 4 == 0 && y % 100 != 0) || y % 400 == 0) {
        cout << 1 << "\n";
    } else {
        cout << 0 << "\n";
    }
    return 0;
}
@@TESTS
--IN
2024
--OUT
1
--IN
1900
--OUT
0
--IN
2000
--OUT
1
--IN
2023
--OUT
0
@@EXPL
(1) 접근·핵심 아이디어

- 윤년 규칙은 세 조건의 조합이다. "4의 배수" 그리고 "100의 배수가 아님"이 함께 성립하거나, 그것과 별개로 "400의 배수"이면 윤년이다. 즉 `(A && B) || C` 꼴이다.
- `&&` 가 `||` 보다 먼저 계산되므로 괄호를 빼도 결과는 같지만, 의도를 분명히 하기 위해 `&&` 묶음에 괄호를 친다. 배수 판정은 나머지 `%` 가 0인지로, "배수가 아님"은 `!= 0` 으로 쓴다.

(2) 코드 단계별

- `cin >> y;` 로 연도를 읽는다.
- `y % 4 == 0 && y % 100 != 0` — 4로는 나누어떨어지고 100으로는 나누어떨어지지 않는지 확인한다. 이 묶음을 괄호로 감싼다.
- `|| y % 400 == 0` — 400의 배수는 앞 묶음과 상관없이 윤년이다.
- 전체가 참이면 `1`, 아니면 `0` 을 출력한다. 여기서 `1` 과 `0` 은 문자열이 아니라 정수 값이므로 따옴표를 붙이지 않는다.
- 참고로 C++에서는 조건식 자체가 0 또는 1의 값을 가지므로, 이 문제는 `cout << (조건) << "\n";` 한 줄로도 같은 답이 나온다. 다만 지금은 `if / else` 로 갈래를 명시하는 연습이 목적이다.

(3) 스스로 다시 짤 때 생각 순서

- 규칙을 "(무엇 그리고 무엇) 또는 무엇" 꼴로 말로 먼저 적는다.
- "그리고" 묶음을 괄호로 감싸고, "또는"으로 나머지를 붙인다.
- 2024(윤년)만으로는 부족하다. 1900(100의 배수 → 평년)과 2000(400의 배수 → 윤년)을 반드시 넣어 세 조건이 모두 작동하는지 검산한다.
```

**8) 알람 시계 앞당기기** · Medium

- **요구사항**: 알람 시각(시 `H`, 분 `M`)을 입력받아, 그보다 45분 이른 시각을 출력하라. 24시간제이며, 0시에서 앞으로 넘어가면 전날 23시가 된다.
- **입력**: 한 줄에 정수 두 개 `H M` (0 ≤ H ≤ 23, 0 ≤ M ≤ 59)
- **출력**: 앞당긴 시각을 `시 분` 형태로 공백으로 구분해 한 줄에 출력
- **예제**: `10 50` → `10 5` · `8 20` → `7 35` · `0 30` → `23 45` · `12 45` → `12 0`
- **셀프체크**: 분이 45 이상이면 그냥 45를 빼면 된다. 45 미만이면 시가 하나 줄고 분은 `M + 15` 가 된다(60을 빌려 오므로 `M - 45 + 60`). 시가 0일 때 1을 빼면 −1이 아니라 23이어야 한다(경계 함정). `12 45` 는 정확히 45분이므로 `12 0`. 두 값 사이의 공백은 C++에서 자동으로 붙지 않으므로 `<< " " <<` 로 직접 넣는다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int h, m;
    cin >> h >> m;
    if (m >= 45) {
        m = m - 45;
    } else {
        m = m + 15;
        if (h == 0) {
            h = 23;
        } else {
            h = h - 1;
        }
    }
    cout << h << " " << m << "\n";
    return 0;
}
@@TESTS
--IN
10 50
--OUT
10 5
--IN
8 20
--OUT
7 35
--IN
0 30
--OUT
23 45
--IN
12 45
--OUT
12 0
@@EXPL
(1) 접근·핵심 아이디어

- 45분을 빼는 일은 "분이 충분한가"로 크게 갈린다. 분이 45 이상이면 시는 그대로 두고 분에서 45만 뺀다. 45 미만이면 시에서 1시간(60분)을 빌려 와야 하므로 분은 `M - 45 + 60`, 즉 `M + 15` 가 되고 시는 1 줄어든다.
- 시를 1 줄일 때 0시는 −1시가 아니라 23시가 되어야 한다. 그래서 "빌려 오는 갈래" 안에서 다시 `h == 0` 인지 나누는 **중첩 조건문**이 필요하다.

(2) 코드 단계별

- `cin >> h >> m;` 로 두 값을 읽는다.
- `if (m >= 45) {` 이면 `m = m - 45;`. 시는 건드리지 않는다.
- `} else {` 이면 `m = m + 15;` 로 분을 고치고, 그 중괄호 **안에서** 다시 `if (h == 0) { h = 23; } else { h = h - 1; }` 로 시를 고친다.
- 중첩 관계를 정하는 것은 들여쓰기가 아니라 중괄호다. 안쪽 `if` 를 바깥 `else` 의 중괄호 안에 두지 않으면 분이 45 이상일 때도 시가 바뀌어 버린다.
- 마지막에 `cout << h << " " << m << "\n";` 으로 두 값을 공백으로 구분해 한 줄에 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "분이 모자라는가"를 바깥 조건으로 세운다(`m >= 45`).
- 모자랄 때 분은 `+15`, 시는 `-1` 이라는 두 가지 수정을 적고, 시 수정 안에 0시 예외를 중첩 `if` 로 넣는다.
- `0 30` (자정 넘김), `12 45` (딱 45분) 두 경계로 검산한다. 특히 `h - 1` 만 쓰면 `0 30` 에서 `-1 45` 가 나오는 것이 이 문제의 핵심 함정이다.
- 나머지 연산으로 한 번에 처리하려 한다면 조심해야 한다. C++의 `%` 는 왼쪽이 음수면 음수를 돌려주므로 `(h - 1) % 24` 는 `h` 가 0일 때 23이 아니라 −1이다. 파이썬과 결과가 다른 대표적인 자리다.
```

**9) 사분면 찾기** · Medium

- **요구사항**: 좌표 평면 위의 점 (x, y)가 어느 사분면에 있는지 번호를 출력하라. x > 0, y > 0 이면 1사분면, x < 0, y > 0 이면 2사분면, x < 0, y < 0 이면 3사분면, x > 0, y < 0 이면 4사분면이다. x와 y는 0이 아니다.
- **입력**: 한 줄에 정수 두 개 `x y` (−100 ≤ x, y ≤ 100, 둘 다 0이 아님)
- **출력**: 사분면 번호(1, 2, 3, 4 중 하나) 한 줄
- **예제**: `3 7` → `1` · `-2 5` → `2` · `-4 -1` → `3` · `6 -9` → `4`
- **셀프체크**: 각 사분면은 x의 부호와 y의 부호 **두 조건이 동시에** 맞아야 하므로 `&&` 로 묶는다. 세 사분면을 `if / else if` 로 검사하면 남는 하나는 `else` 로 처리해도 된다(x, y가 0이 아니라는 조건 덕분).

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int x, y;
    cin >> x >> y;
    if (x > 0 && y > 0) {
        cout << 1 << "\n";
    } else if (x < 0 && y > 0) {
        cout << 2 << "\n";
    } else if (x < 0 && y < 0) {
        cout << 3 << "\n";
    } else {
        cout << 4 << "\n";
    }
    return 0;
}
@@TESTS
--IN
3 7
--OUT
1
--IN
-2 5
--OUT
2
--IN
-4 -1
--OUT
3
--IN
6 -9
--OUT
4
@@EXPL
(1) 접근·핵심 아이디어

- 사분면은 x의 부호와 y의 부호 조합으로 정해진다. 조합은 (+,+), (−,+), (−,−), (+,−) 네 가지이고 서로 겹치지 않으므로 `if / else if / else if / else` 로 나눈다.
- 각 갈래는 부호 두 개가 **동시에** 맞아야 하므로 `&&` 로 잇는다. x, y가 0이 아니라는 조건이 있어 축 위의 점은 고려하지 않아도 되고, 마지막 조합은 `else` 로 받을 수 있다.

(2) 코드 단계별

- `cin >> x >> y;` 로 두 좌표를 읽는다. 음수 좌표도 그대로 읽힌다.
- `if (x > 0 && y > 0)` → 1사분면. `else if (x < 0 && y > 0)` → 2사분면. `else if (x < 0 && y < 0)` → 3사분면.
- 세 조건이 모두 거짓이면 남는 조합은 (x > 0, y < 0) 하나뿐이므로 `else` 에서 4를 출력한다.
- `&&` 를 `&` 하나로 잘못 쓰면 비트 연산자가 되어 뜻이 달라진다. 지금 값이 0/1이라 결과가 우연히 같아 보일 수 있으니 습관적으로 `&&` 를 쓴다.

(3) 스스로 다시 짤 때 생각 순서

- 부호 조합 네 가지를 표로 적고, 각 조합을 `&&` 조건 하나로 옮긴다.
- 세 조합을 `if / else if` 로 쓰고 마지막은 `else` 로 처리한다. 네 번째까지 굳이 조건을 쓰려면 `else if (x > 0 && y < 0)` 으로 써도 된다.
- 네 사분면 예제를 하나씩 넣어 `&&` 의 양쪽 부등호 방향이 맞는지 검산한다. 특히 3사분면 `-4 -1` 처럼 둘 다 음수인 경우가 빠지지 않았는지 확인한다.
```

**10) 세 수의 중간값** · Medium

- **요구사항**: 서로 다른 정수 세 개를 입력받아, 크기 순으로 나열했을 때 가운데에 오는 수(두 번째로 큰 수)를 출력하라.
- **입력**: 한 줄에 정수 세 개 `a b c` (공백 구분, −1000 ≤ 각 값 ≤ 1000, 세 수는 서로 다름)
- **출력**: 중간값 한 줄
- **예제**: `3 9 5` → `5` · `10 2 7` → `7` · `-1 -8 -3` → `-3` · `1 2 3` → `2`
- **셀프체크**: 어떤 수가 중간값이려면 "나머지 둘 중 하나보다는 크고 다른 하나보다는 작아야" 한다. `a` 가 중간인 경우는 두 가지("b보다 크고 c보다 작다" 또는 "b보다 작고 c보다 크다")이므로 `&&` 로 만든 조건 두 개를 `||` 로 잇는다. **`b < a < c` 처럼 한 번에 이어 쓰면 안 된다** — C++은 이것을 `(b < a) < c` 로 해석해 0 또는 1과 c를 비교하므로 거의 항상 참이 되고, 컴파일 오류도 나지 않는다. 음수 예제로 부등호 방향을 검산한다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    if ((a > b && a < c) || (a < b && a > c)) {
        cout << a << "\n";
    } else if ((b > a && b < c) || (b < a && b > c)) {
        cout << b << "\n";
    } else {
        cout << c << "\n";
    }
    return 0;
}
@@TESTS
--IN
3 9 5
--OUT
5
--IN
10 2 7
--OUT
7
--IN
-1 -8 -3
--OUT
-3
--IN
1 2 3
--OUT
2
@@EXPL
(1) 접근·핵심 아이디어

- 세 수 중 가운데 값은 "하나보다는 크고 다른 하나보다는 작은 수"다. `a` 가 그런 수가 되는 방법은 "b보다 크고 c보다 작다"와 "b보다 작고 c보다 크다" 두 가지이므로, 각각을 `&&` 로 만들고 둘을 `||` 로 잇는다.
- `a` 가 아니면 `b` 를 같은 방식으로 검사하고, 둘 다 아니면 남는 `c` 가 중간값이다. 세 수가 서로 다르다는 조건 덕분에 "같은 경우"를 고민하지 않아도 된다.
- 이 문제의 진짜 함정은 조건을 쓰는 방식이다. 수학에서 쓰는 `b < a < c` 를 그대로 옮기면 C++은 왼쪽부터 묶어 `(b < a) < c` 로 계산한다. `b < a` 의 값은 0 아니면 1이고, c가 1보다 크기만 하면 전체가 참이 된다. 컴파일도 되고 실행도 되기 때문에 발견이 가장 늦는 종류의 버그다. 반드시 `b < a && a < c` 로 쪼갠다.

(2) 코드 단계별

- `cin >> a >> b >> c;` 로 세 정수를 읽는다.
- `(a > b && a < c) || (a < b && a > c)` — 괄호 안이 각각 "b보다 크고 c보다 작다", "b보다 작고 c보다 크다"이다. 하나라도 참이면 `a` 가 중간값.
- `else if` 에서 `b` 에 대해 똑같은 모양의 조건을 검사한다.
- 둘 다 아니면 `else` 에서 `c` 를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "중간값 = 한쪽보다 크고 다른 쪽보다 작다"를 말로 정리한다.
- 부등호가 두 번 나오면 반드시 비교 두 개로 쪼개 `&&` 로 잇는다. 이어 쓰기는 C++에서 뜻이 달라진다.
- 한 변수에 대해 가능한 두 배치를 `&&` 조건 두 개로 쓰고 `||` 로 묶는다. `&&` 가 `||` 보다 먼저 계산되기는 하지만, 의도를 보이기 위해 괄호를 친다.
- `a` 가 답인 경우, `b` 가 답인 경우, `c` 가 답인 경우(예: `3 9 5`)를 하나씩 넣어 세 갈래가 모두 실행되는지 검산한다.
```

**11) 교통카드 버스 요금** · Medium

- **요구사항**: 승객의 나이와 교통카드 사용 여부(1이면 카드, 0이면 현금)를 입력받아 버스 요금을 출력하라. 8세 미만 또는 65세 이상은 무료(`0`)다. 8세 이상 18세 이하는 카드 `800`, 현금 `1000`. 19세 이상 64세 이하는 카드 `1300`, 현금 `1500`.
- **입력**: 한 줄에 정수 두 개 `age card` (0 ≤ age ≤ 120, card는 0 또는 1)
- **출력**: 요금(정수) 한 줄
- **예제**: `15 1` → `800` · `30 0` → `1500` · `70 0` → `0` · `19 1` → `1300`
- **셀프체크**: 무료 조건은 두 구간(어린이·노인)이므로 `||` 로 묶어 맨 앞에서 걸러낸다. 그다음 나이로 청소년/성인을 가르고, **각 갈래 안에서** 카드 여부를 다시 나눈다(중첩). 경계 8, 18, 19, 65를 검산.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int age, card;
    cin >> age >> card;
    if (age < 8 || age >= 65) {
        cout << 0 << "\n";
    } else if (age <= 18) {
        if (card == 1) {
            cout << 800 << "\n";
        } else {
            cout << 1000 << "\n";
        }
    } else {
        if (card == 1) {
            cout << 1300 << "\n";
        } else {
            cout << 1500 << "\n";
        }
    }
    return 0;
}
@@TESTS
--IN
15 1
--OUT
800
--IN
30 0
--OUT
1500
--IN
70 0
--OUT
0
--IN
19 1
--OUT
1300
@@EXPL
(1) 접근·핵심 아이디어

- 요금은 "나이 구간"으로 먼저 갈리고, 그 안에서 "카드/현금"으로 다시 갈린다. 두 단계로 나뉘는 판단이므로 바깥은 `if / else if / else`, 안쪽은 중첩 `if / else` 로 구성한다.
- 무료 구간이 어린이(8 미만)와 노인(65 이상) 둘이라 연속하지 않는다. "또는" 관계이므로 `||` 로 묶어 맨 앞에서 한 번에 처리하면 나머지 갈래가 단순해진다.

(2) 코드 단계별

- `cin >> age >> card;` 로 두 값을 읽는다.
- `if (age < 8 || age >= 65)` → `0`. 이 조건을 통과하지 못한 값은 자동으로 8 이상 64 이하다.
- `else if (age <= 18)` → 청소년. 그 중괄호 안에서 `card == 1` 이면 `800`, 아니면 `1000`.
- `else` → 성인(19~64). 그 중괄호 안에서 `card == 1` 이면 `1300`, 아니면 `1500`.
- 안쪽 `if / else` 를 바깥 갈래의 중괄호 안에 제대로 넣었는지 확인한다. 중괄호를 빼고 늘어놓으면 마지막 `else` 가 어느 `if` 와 짝인지 눈으로는 알기 어려워지고, C++은 "가장 가까운 짝 없는 `if`"와 묶어 버린다.

(3) 스스로 다시 짤 때 생각 순서

- 판단이 몇 단계인지 먼저 센다 → 나이 구간(1단계), 결제 수단(2단계).
- 흩어진 무료 구간은 `||` 로 묶어 맨 앞에 두고, 남은 나이를 `else if` 하나로 청소년/성인으로 가른다.
- 각 나이 갈래 안에 카드 여부 `if / else` 를 넣는다. `70 0` (노인은 현금이어도 무료), `19 1` (성인 시작 경계)로 검산한다.
```

**12) 삼각형 각도 판별** · Medium

- **요구사항**: 삼각형의 세 각을 입력받는다. 세 각의 합이 180이 아니면 `error` 를 출력한다. 합이 180이면, 세 각이 모두 60이면 `equilateral`, 두 각만 같으면 `isosceles`, 세 각이 모두 다르면 `scalene` 을 출력하라.
- **입력**: 한 줄에 정수 세 개 `a b c` (각각 1 이상 178 이하)
- **출력**: `error`, `equilateral`, `isosceles`, `scalene` 중 한 줄
- **예제**: `60 60 60` → `equilateral` · `50 50 80` → `isosceles` · `30 60 90` → `scalene` · `60 70 60` → `error`
- **셀프체크**: 합 검사를 **맨 먼저** 해야 한다. `60 70 60` 은 두 각이 같지만 합이 190이라 `error` 다. 정삼각형 검사(`&&` 셋)를 이등변 검사(`||` 셋)보다 위에 둬야 한다. 순서를 바꾸면 정삼각형도 이등변으로 잡힌다. "셋이 모두 같다"를 `a == b == c` 로 쓰면 안 된다 — `(a == b) == c` 가 되어 뜻이 달라지고도 컴파일된다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    if (a + b + c != 180) {
        cout << "error" << "\n";
    } else if (a == 60 && b == 60 && c == 60) {
        cout << "equilateral" << "\n";
    } else if (a == b || b == c || a == c) {
        cout << "isosceles" << "\n";
    } else {
        cout << "scalene" << "\n";
    }
    return 0;
}
@@TESTS
--IN
60 60 60
--OUT
equilateral
--IN
50 50 80
--OUT
isosceles
--IN
30 60 90
--OUT
scalene
--IN
60 70 60
--OUT
error
@@EXPL
(1) 접근·핵심 아이디어

- 판단 순서가 결과를 좌우한다. 먼저 "삼각형이 맞는가(합 180)"를 걸러야 하고, 그다음 좁은 조건(정삼각형: 세 각 모두 60)부터 넓은 조건(이등변: 두 각만 같음) 순서로 검사한다.
- 정삼각형은 세 각이 **모두** 60이므로 `&&`, 이등변은 어느 두 각이든 **하나라도** 같으면 되므로 `||` 다. 정삼각형은 이등변 조건도 만족하므로 반드시 정삼각형을 위에 둔다.

(2) 코드 단계별

- `cin >> a >> b >> c;` 로 세 각을 읽는다.
- `if (a + b + c != 180)` → `error`. 이 줄이 맨 위에 있어야 `60 70 60` 같은 입력이 이등변으로 새지 않는다.
- `else if (a == 60 && b == 60 && c == 60)` → `equilateral`. 비교식 세 개를 완전하게 쓰고 `&&` 로 잇는다. `a == b == c` 로 줄여 쓰면 `(a == b)` 의 결과 0/1을 `c` 와 비교하게 되어 60에서는 거짓이 되어 버린다.
- `else if (a == b || b == c || a == c)` → `isosceles`. 세 쌍(a·b, b·c, a·c)을 모두 비교해야 한다.
- 남은 경우는 세 각이 모두 다르므로 `else` → `scalene`.

(3) 스스로 다시 짤 때 생각 순서

- "조건이 겹치는가"를 먼저 본다 → 정삼각형이 이등변에 포함되므로 좁은 쪽을 위에.
- 무효 입력(`error`)을 맨 앞에서 걸러 나머지 갈래가 유효한 삼각형만 다루게 한다.
- `60 70 60` (같은 각이 있지만 합이 틀림)과 `60 60 60` (이등변 조건도 참이지만 정삼각형이어야 함)으로 순서가 맞는지 검산한다.
```

**13) 장학금 심사** · Hard

- **요구사항**: 평균 점수 `avg`, 봉사 시간 `vol`, 소득 분위 `inc`(1~10, 숫자가 작을수록 저소득)를 입력받아 장학금 종류를 출력한다. 평균이 70 미만이면 무조건 `none`. 평균이 70 이상이면 소득 분위가 3 이하일 때 `full`, 그렇지 않으면 평균이 90 이상이거나 봉사 시간이 30 이상일 때 `half`, 둘 다 아니면 `none`.
- **입력**: 한 줄에 정수 세 개 `avg vol inc` (0 ≤ avg ≤ 100, 0 ≤ vol ≤ 200, 1 ≤ inc ≤ 10)
- **출력**: `full`, `half`, `none` 중 한 줄
- **예제**: `75 10 2` → `full` · `92 0 6` → `half` · `80 10 8` → `none` · `69 50 1` → `none`
- **셀프체크**: 바깥 조건(평균 70 이상)을 통과한 사람만 안쪽 심사를 받는다. `69 50 1` 은 소득 분위도 낮고 봉사도 많지만 평균이 미달이라 `none` 이다. 안쪽 `half` 조건은 "이거나"이므로 `||`. 경계 70, 90, 30, 3을 각각 검산. `avg` 는 이미 계산된 평균 점수를 정수로 받는 것이므로, 여기서 정수 나눗셈을 걱정할 일은 없다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int avg, vol, inc;
    cin >> avg >> vol >> inc;
    if (avg >= 70) {
        if (inc <= 3) {
            cout << "full" << "\n";
        } else if (avg >= 90 || vol >= 30) {
            cout << "half" << "\n";
        } else {
            cout << "none" << "\n";
        }
    } else {
        cout << "none" << "\n";
    }
    return 0;
}
@@TESTS
--IN
75 10 2
--OUT
full
--IN
92 0 6
--OUT
half
--IN
80 10 8
--OUT
none
--IN
69 50 1
--OUT
none
@@EXPL
(1) 접근·핵심 아이디어

- 규칙이 "먼저 평균으로 자격을 거르고, 자격자 안에서 다시 등급을 나눈다"는 2단계 구조다. 이런 단계형 판단은 바깥 `if` 의 중괄호 안에 `if / else if / else` 를 넣는 중첩 조건문이 가장 읽기 쉽다.
- 안쪽 등급은 좁은 조건(`full`: 소득 분위 3 이하)을 먼저, 그다음 `half` 조건을 검사한다. `half` 조건은 "평균 90 이상 **이거나** 봉사 30 이상"이므로 `||` 로 잇는다.
- 함정은 바깥 조건이다. 안쪽 조건을 아무리 잘 만족해도 평균이 70 미만이면 안쪽에 들어가지도 못한다(`69 50 1`).

(2) 코드 단계별

- `cin >> avg >> vol >> inc;` 로 세 값을 읽는다.
- 바깥 `if (avg >= 70) {` 으로 자격을 가른다. 거짓이면 바깥 `else` 에서 바로 `none`.
- 자격자 안에서 `if (inc <= 3)` → `full`. 이 조건이 참이면 아래 `half` 는 검사하지 않는다.
- `else if (avg >= 90 || vol >= 30)` → `half`. 둘 중 하나만 만족해도 된다.
- 둘 다 아니면 안쪽 `else` 에서 `none`. 안쪽 블록 전체가 바깥 `if` 의 중괄호 안에 들어 있어야 한다. 파이썬과 달리 들여쓰기는 소속을 정하지 않으므로, 중괄호 짝을 눈으로 세는 습관이 필요하다.

(3) 스스로 다시 짤 때 생각 순서

- 규칙을 "자격 조건 → 등급 조건" 두 층으로 나눠 적는다.
- 바깥 `if / else` 로 자격을 가르고, 자격 통과 블록의 중괄호 안에 등급 `if / else if / else` 를 넣는다.
- 안쪽 조건의 "이거나"를 `||` 로 옮기고, `92 0 6` (평균만으로 half), `80 10 8` (둘 다 미달 → none), `69 50 1` (바깥 탈락)으로 각 경로를 검산한다.
```

**14) 다음 날 날짜** · Hard

- **요구사항**: 월 `m` 과 일 `d` 를 입력받아 그 다음 날의 월과 일을 출력하라. 윤년은 고려하지 않는다(2월은 28일까지). 1·3·5·7·8·10·12월은 31일, 4·6·9·11월은 30일까지 있다. 12월 31일의 다음 날은 1월 1일이다.
- **입력**: 한 줄에 정수 두 개 `m d` (1 ≤ m ≤ 12, 1 ≤ d ≤ 그 달의 마지막 날)
- **출력**: 다음 날의 `월 일` 을 공백으로 구분해 한 줄에 출력
- **예제**: `3 15` → `3 16` · `4 30` → `5 1` · `2 28` → `3 1` · `12 31` → `1 1`
- **셀프체크**: 먼저 "이번 달의 마지막 날"을 월에 따라 정하고(2월 → 28, 30일 달은 `||` 로 묶기, 나머지 → 31), 그다음 `d` 가 마지막 날보다 작으면 일만 +1, 마지막 날이면 다음 달 1일로 넘긴다. 12월만 예외로 1월 1일(중첩). `4 30` 이 `4 31` 이 되지 않는지 검산. 중간 변수 `last` 는 모든 갈래에서 값을 받아야 한다 — C++은 초기화하지 않은 지역 변수를 0으로 채워 주지 않고 쓰레기 값이 그대로 남는다.

@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int m, d;
    cin >> m >> d;
    int last = 31;
    if (m == 2) {
        last = 28;
    } else if (m == 4 || m == 6 || m == 9 || m == 11) {
        last = 30;
    } else {
        last = 31;
    }
    if (d < last) {
        cout << m << " " << d + 1 << "\n";
    } else {
        if (m == 12) {
            cout << 1 << " " << 1 << "\n";
        } else {
            cout << m + 1 << " " << 1 << "\n";
        }
    }
    return 0;
}

(1) 접근·핵심 아이디어

- 문제를 두 단계로 쪼갠다. (a) 이번 달은 며칠까지 있는가 → 변수 `last` 에 담는다. (b) 오늘이 마지막 날인가 → 아니면 일만 1 늘리고, 맞으면 다음 달 1일로 넘긴다.
- (a)에서 30일까지인 달은 4, 6, 9, 11월 네 개라 "이거나"가 반복되므로 `||` 로 묶는다. 2월은 따로, 나머지는 모두 31일이라 `else` 로 처리하면 조건이 짧아진다.
- (b)에서 달을 넘길 때 12월만 예외(다음 해 1월)라 중첩 `if / else` 가 필요하다.

(2) 코드 단계별

- `cin >> m >> d;` 로 두 값을 읽는다.
- `int last = 31;` 로 선언과 동시에 값을 넣어 둔다. 아래 세 갈래가 모두 `last` 에 대입하므로 논리적으로는 초기값이 필요 없지만, 갈래 하나를 지우거나 조건을 잘못 써서 어느 갈래에도 걸리지 않는 순간 쓰레기 값이 그대로 쓰인다. 선언할 때 초기화하는 습관이 이 사고를 막는다.
- `if (m == 2)` → `last = 28;`. `else if (m == 4 || m == 6 || m == 9 || m == 11)` → `last = 30;`. `else` → `last = 31;`. 각 비교에 `m ==` 를 빠짐없이 붙인다. `m == 4 || 6 || 9 || 11` 로 줄여 쓰면 `6` 이 0이 아니라 항상 참이 되어 모든 달이 30일이 된다. 컴파일은 성공한다.
- `if (d < last)` 이면 같은 달이므로 `cout << m << " " << d + 1 << "\n";`. `<<` 보다 `+` 가 먼저 계산되므로 `d + 1` 은 괄호 없이도 의도대로 출력된다.
- 아니면(마지막 날) 안쪽에서 `if (m == 12)` → `1 1`, `else` → `m + 1` 과 `1`.

(3) 스스로 다시 짤 때 생각 순서

- "마지막 날을 먼저 구한다"는 중간 변수를 두는 발상이 핵심이다. 조건을 한 번에 다 쓰려 하지 말고 `last` 로 나눠 생각한다.
- 마지막 날 판정은 `d < last` 와 그 반대로 두 갈래, 그 안에서 12월 예외를 중첩으로 처리한다.
- 네 가지 경계를 검산한다: 평범한 날(`3 15`), 30일 달의 끝(`4 30`), 2월 끝(`2 28`), 연말(`12 31`). `||` 목록에서 달 하나를 빠뜨리면 `4 30` 이 `4 31` 로 나오는 것이 이 문제의 함정이다.
