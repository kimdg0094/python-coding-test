## L9. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch01(출력)의 핵심을 **반복 훈련**하고, 코딩테스트 단골 유형으로 **확장**하는 연습 세트다. 입력은 여전히 없고, 값은 코드 안에 직접 정한다.
- **반복 훈련 개념**: 아래 다섯 가지를 소재만 바꿔 여러 번 다시 쓴다.

- 따옴표와 이스케이프 — C++ 문자열은 **항상 큰따옴표** `"..."` 다. 문장 안에 `"` 가 있으면 `\"` 로 이스케이프하거나 원시 문자열 `R"(...)"` 로 감싼다. 작은따옴표 `'a'` 는 글자 하나(`char`)라서 문장을 감쌀 수 없다.
- 이어 붙이기와 띄우기 — `cout << a << b` 는 값을 **빈틈없이** 이어 붙인다. 사이를 띄우려면 `<< " " <<` 로 공백을 직접 넣는다. `string` 끼리는 `+` 로도 이어 붙일 수 있다(숫자와는 섞을 수 없다).
- 소수점 자릿수 — `cout << fixed << setprecision(2) << x` 또는 `printf("%.2f", x)` 로 소수점 아래 자릿수를 고정한다. `<iomanip>` 이 필요하고, `fixed`·`setprecision` 은 한 번 걸면 그다음 출력에도 계속 남는다.
- 값 변경 — `x += 1`, `x -= 3`, `x *= 2` 는 "지금 값으로 계산한 결과를 다시 담기"다.
- 여러 변수 다루기 — C++엔 `a, b = b, a` 같은 동시 대입이 없다. 두 값을 맞바꾸려면 `swap(a, b)` 나 임시 변수를 쓰고, 같은 값을 여러 변수에 넣을 때는 `x = y = 0` 처럼 이어 쓴다(두 변수가 각자 자기 값을 갖는다).

- **코딩테스트 출제 맵**: 백준 「단계별로 풀어보기」의 '입출력과 사칙연산' 단계(정해진 문장·그림을 한 글자도 틀리지 않게 출력, 실수 형식 출력)와 solved.ac CLASS 1의 출력 문제들이 이 챕터 수준이다. 뒤 단계의 `Case #k:` 형식 출력도 지금 문법으로 미리 연습한다.

**문제**

**1) 서점 안내문 출력** · Easy

- **요구사항**: 서점 입구에 붙일 안내문 세 줄을 화면에 그대로 출력하라. 첫째 줄에 큰따옴표가 들어 있다는 점에 주의한다.
- **입력**: 없음
- **출력**: 아래 세 줄을 순서대로, 기호·공백·대소문자까지 똑같이
- **예제**: (입력 없음) → `Welcome to "Book Corner" / Open 10:00 - 20:00 / Closed on Monday`
- **셀프체크**: 문장 안의 큰따옴표를 `\"` 로 적었는가(작은따옴표로 감싸는 방법은 C++에 없다)? `10:00 - 20:00` 의 하이픈 앞뒤 공백이 한 칸씩인가? 각 줄 끝에 `"\n"` 을 붙여 세 줄로 나뉘었는가?

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    cout << "Welcome to \"Book Corner\"" << "\n";
    cout << "Open 10:00 - 20:00" << "\n";
    cout << "Closed on Monday" << "\n";
    return 0;
}
@@TESTS
--IN

--OUT
Welcome to "Book Corner"
Open 10:00 - 20:00
Closed on Monday
--IN

--OUT
Welcome to "Book Corner"
Open 10:00 - 20:00
Closed on Monday
@@EXPL
(1) 접근·핵심 아이디어

- 정해진 문장을 그대로 보여 주는 문제이므로 줄 수만큼 `cout` 을 쓴다. `cout` 은 자동으로 줄을 바꾸지 않으니 줄마다 `"\n"` 을 붙인다.
- 첫째 줄 안에 큰따옴표 `"` 가 들어 있다. 그냥 `"Welcome to "Book Corner""` 라고 쓰면 컴파일러가 두 번째 `"` 에서 문자열이 끝났다고 보고 오류를 낸다.
- C++ 문자열은 큰따옴표로만 감쌀 수 있다. 작은따옴표 `'...'` 는 글자 하나를 담는 `char` 라서 대신 쓸 수 없다. 그래서 안쪽 따옴표 앞에 역슬래시를 붙여 `\"` 로 적는다.
- 원시 문자열 `R"(Welcome to "Book Corner")"` 를 써도 같은 결과가 나온다. 이스케이프가 많아질 때 편한 방법이다.

(2) 코드 단계별

- `cout << "Welcome to \"Book Corner\"" << "\n";` — `\"` 두 개가 화면에는 `"` 한 글자씩으로 나온다. 역슬래시는 출력되지 않는다.
- `cout << "Open 10:00 - 20:00" << "\n";` — 콜론과 하이픈은 문자열 안에서 특별한 뜻이 없다. 공백 개수만 예시와 맞춘다.
- `cout << "Closed on Monday" << "\n";` — 셋째 줄. 이 줄의 `"\n"` 까지 넣어야 출력이 줄바꿈으로 끝난다.

(3) 스스로 다시 짤 때 생각 순서

- "몇 줄?" → 세 줄 → `cout` 세 번, 줄마다 `"\n"`.
- "각 줄 안에 큰따옴표가 있나?" → 첫째 줄에 있으니 그 두 개만 `\"` 로 바꾼다.
- 출력 결과를 예시와 한 글자씩 대조한다. 특히 공백과 대문자. 역슬래시가 화면에 보인다면 `\\"` 처럼 두 번 적은 실수다.
```

**2) 상품 정보 카드** · Easy

- **요구사항**: 상품 이름 `Pen`(문자열), 가격 `1200`(정수), 무게 `8.5`(실수)를 각각 변수 `name`, `price`, `weight` 에 담고, 라벨을 붙여 세 줄로 출력하라.
- **입력**: 없음 (값은 코드 안에 직접 정한다)
- **출력**: 첫 줄 `Item: Pen`, 둘째 줄 `Price: 1200`, 셋째 줄 `Weight: 8.5`
- **예제**: (입력 없음) → `Item: Pen / Price: 1200 / Weight: 8.5`
- **셀프체크**: 세 값을 자료형에 맞게 담았는가(`string name`, `int price`, `double weight`)? C++엔 자동으로 끼어드는 공백이 없으니 라벨 문자열 끝에 공백 한 칸을 직접 넣었는가? `cout` 안에 값을 직접 쓰지 않고 변수 이름을 썼는가?

```runner
@@SOLUTION
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "Pen";
    int price = 1200;
    double weight = 8.5;
    cout << "Item: " << name << "\n";
    cout << "Price: " << price << "\n";
    cout << "Weight: " << weight << "\n";
    return 0;
}
@@TESTS
--IN

--OUT
Item: Pen
Price: 1200
Weight: 8.5
--IN

--OUT
Item: Pen
Price: 1200
Weight: 8.5
@@EXPL
(1) 접근·핵심 아이디어

- 값 세 개를 각각 자료형에 맞는 변수에 담고, 출력할 때 라벨 문자열과 변수를 `<<` 로 이어 붙인다.
- C++의 `<<` 는 값을 **빈틈없이** 이어 붙인다. 라벨과 값 사이를 한 칸 띄우고 싶으면 라벨 문자열 끝에 공백을 직접 넣어 `"Item: "` 처럼 쓴다. 공백을 빠뜨리면 `Item:Pen` 이 되어 틀린다.
- `<<` 는 자료형을 가리지 않는다. `string`·`int`·`double` 을 같은 방식으로 넘길 수 있다.

(2) 코드 단계별

- `string name = "Pen";` — 글자가 여럿이므로 `string`. `<string>` 을 포함한다.
- `int price = 1200;` — 소수점 없는 정수. `double weight = 8.5;` — 소수점 있는 실수.
- `cout << "Item: " << name << "\n";` — 라벨·값·줄바꿈을 차례로 흘려보내 `Item: Pen`. 나머지 두 줄도 같은 모양이다.
- `cout << weight` 는 `8.5` 로 나온다. C++ 기본 출력은 유효숫자 여섯 자리까지 보여 주고 필요 없는 0은 지우므로, 소수 부분이 있으면 그대로 보인다.

(3) 스스로 다시 짤 때 생각 순서

- 담을 값이 셋 → 변수 셋, 각각 `string`/`int`/`double`.
- "라벨 뒤 공백은 누가 넣지?" → 내가 넣는다. `<<` 가 값 사이에 공백을 끼워 주는 일은 절대 없다.
- 세 줄이니 `cout` 세 번, 각 줄 끝에 `"\n"`.
```

**3) 글자 덧셈과 숫자 덧셈** · Easy

- **요구사항**: 문자열 `"7"` 과 `"3"` 을 변수 `s1`, `s2` 에, 정수 `7` 과 `3` 을 변수 `n1`, `n2` 에 담아라. 첫 줄에 `s1 + s2` 의 결과를, 둘째 줄에 `n1 + n2` 의 결과를 출력하라.
- **입력**: 없음
- **출력**: 첫 줄은 문자열끼리 더한 결과, 둘째 줄은 정수끼리 더한 결과
- **예제**: (입력 없음) → `73 / 10`
- **셀프체크**: 같은 `+` 인데 결과가 `73` 과 `10` 으로 다른 이유를 설명할 수 있는가? `s1`, `s2` 를 `string` 으로 선언했는가(문자열 리터럴끼리 `"7" + "3"` 은 컴파일 오류다)? 문자열과 정수를 섞어 `s1 + n1` 처럼 더하면 컴파일 오류가 난다는 점을 확인했는가?

```runner
@@SOLUTION
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s1 = "7";
    string s2 = "3";
    int n1 = 7;
    int n2 = 3;
    cout << s1 + s2 << "\n";
    cout << n1 + n2 << "\n";
    return 0;
}
@@TESTS
--IN

--OUT
73
10
--IN

--OUT
73
10
@@EXPL
(1) 접근·핵심 아이디어

- `+` 는 양쪽 값의 자료형에 따라 다르게 동작한다. `string` 끼리는 "이어 붙이기", 숫자끼리는 "덧셈"이다.
- `string("7") + string("3")` 은 글자 `7` 뒤에 글자 `3` 을 붙여 `"73"` 이 되고, `7 + 3` 은 계산되어 `10` 이 된다.
- 화면에 `7` 로 똑같이 보여도 따옴표 유무에 따라 전혀 다른 값이라는 점이 핵심이다.

(2) 코드 단계별

- `string s1 = "7";`, `string s2 = "3";` — 따옴표가 있고 `string` 으로 받았으니 문자열이다.
- `int n1 = 7;`, `int n2 = 3;` — 따옴표가 없으니 정수.
- `cout << s1 + s2 << "\n";` — 문자열 잇기 → `73`. `cout << n1 + n2 << "\n";` — 정수 덧셈 → `10`.

(3) 스스로 다시 짤 때 생각 순서

- 값을 담기 전에 "이건 글자인가 숫자인가?" 를 먼저 정하고 자료형을 고른다.
- C++ 함정 1: 변수 없이 `cout << "7" + "3";` 이라고 쓰면 안 된다. 문자열 리터럴은 `string` 이 아니라 문자 배열이라 `+` 가 주소 계산이 되어 컴파일 오류가 난다. 적어도 한쪽이 `string` 이어야 이어 붙이기가 된다.
- C++ 함정 2: `'7' + '3'` 처럼 작은따옴표로 쓰면 글자 하나(`char`)의 코드값끼리 더해져 `106` 이 나온다. 문자열은 반드시 큰따옴표다.
- 결과가 `73` 인지 `10` 인지 보고, 자료형을 반대로 담지 않았는지 검산한다.
```

**4) 같은 값, 다른 자릿수** · Easy

- **요구사항**: 변수 `speed` 에 `12.3456` 을 담고, 첫 줄에는 소수점 아래 첫째 자리까지, 둘째 줄에는 소수점 아래 셋째 자리까지 출력하라.
- **입력**: 없음
- **출력**: 첫 줄은 소수점 아래 1자리, 둘째 줄은 소수점 아래 3자리
- **예제**: (입력 없음) → `12.3 / 12.346`
- **셀프체크**: 둘째 줄은 넷째 자리 `6` 때문에 셋째 자리가 `5` 에서 `6` 으로 올라간다. `12.345` 라고 적지 않았는가? 첫 줄은 둘째 자리 `4` 가 5 미만이라 그대로 `12.3` 인가? `fixed` 없이 `setprecision` 만 쓰면 "유효숫자" 자릿수가 되어 다른 결과가 나온다는 점을 확인했는가?

```runner
@@SOLUTION
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double speed = 12.3456;
    cout << fixed << setprecision(1) << speed << "\n";
    cout << setprecision(3) << speed << "\n";
    return 0;
}
@@TESTS
--IN

--OUT
12.3
12.346
--IN

--OUT
12.3
12.346
@@EXPL
(1) 접근·핵심 아이디어

- 값은 하나지만 보여 주는 자릿수만 다르게 한다. 변수는 그대로 두고 `setprecision` 의 숫자만 바꾼다.
- `fixed` 는 "소수점 아래 자릿수를 세겠다"는 선언이고, `setprecision(N)` 이 그 자릿수 `N` 을 정한다. 둘 다 `<iomanip>` 에 있다.
- `setprecision` 은 "잘라 버리기"가 아니라 "반올림"이다. 잘려 나가는 첫 자리가 5 이상이면 위 자리가 하나 올라간다.

(2) 코드 단계별

- `double speed = 12.3456;` — 실수를 담는다.
- `cout << fixed << setprecision(1) << speed << "\n";` — 소수점 아래 1자리. 둘째 자리 `4` 는 5 미만이라 `12.3`.
- `cout << setprecision(3) << speed << "\n";` — `fixed` 는 한 번 걸면 계속 유지되므로 다시 쓸 필요가 없다. 넷째 자리 `6` 이 5 이상이라 셋째 자리 `5` 가 `6` 으로 올라 `12.346`.

(3) 스스로 다시 짤 때 생각 순서

- "몇 자리까지?" 를 줄마다 정한다 → `setprecision(1)`, `setprecision(3)`.
```

**7) 같은 값을 두 변수에** · Medium

- **요구사항**: `x = y = 7;` 로 두 변수에 같은 값을 한 번에 넣는다. 그다음 `x` 에 1을 더하고 첫 줄에 `x`, `y` 를 출력하라. 이어서 `y` 를 2배로 만들고 둘째 줄에 다시 `x`, `y` 를 출력하라. 각 줄은 공백 한 칸으로 띄운다.

- **예제**: (입력 없음) → `8 7 / 8 14`
- **셀프체크**: `x = y = 7;` 은 두 변수를 "묶는" 것이 아니라 값 `7` 을 각자의 저장 공간에 복사해 넣는 것이다. `x` 를 바꿨을 때 `y` 가 따라 바뀌지 않았는가? `y *= 2;` 뒤에도 `x` 는 그대로 `8` 인가? 두 값 사이 공백을 `<< " " <<` 로 직접 넣었는가?

```runner
@@SOLUTION

    int x, y;
    x = y = 7;
    x += 1;
    cout << x << " " << y << "\n";
    y *= 2;
    cout << x << " " << y << "\n";
    return 0;

@@TESTS
--IN

--OUT

8 14
--IN

--OUT

@@EXPL
(1) 접근·핵심 아이디어

- `x = y = 7;` 은 오른쪽부터 묶여 `x = (y = 7);` 로 해석된다. 먼저 `y` 에 7이 들어가고, 그 결과값 7이 다시 `x` 에 **복사**된다.
- 그래서 두 변수는 서로 연결되지 않는다. 각자 자기 저장 공간에 7을 하나씩 갖는다. 한쪽을 바꿔도 다른 쪽은 영향을 받지 않는다.
- C++에서 두 이름이 정말 같은 저장 공간을 가리키게 하려면 참조 `int &x = y;` 를 써야 한다. 이 문제는 그런 경우가 아니다.

(2) 코드 단계별

- `int x, y;` — 두 변수를 선언한다. `x = y = 7;` — `y` 에 7, 이어서 `x` 에도 7.
- `x += 1;` — `x` 만 `7 + 1 = 8`. `y` 는 그대로 7. 출력 → `8 7`.
- `y *= 2;` — `y` 만 `7 * 2 = 14`. `x` 는 그대로 8. 출력 → `8 14`.
- 값 사이 공백은 `<< " " <<` 로 직접 넣는다. 빼먹으면 `87` 처럼 붙어 나온다.

(3) 스스로 다시 짤 때 생각 순서

- "같은 값을 여러 변수에" → 선언한 뒤 `x = y = 값;` 한 줄.
- 이후 값 변경은 각 변수에 따로 일어난다고 생각하고 표를 그려 본다: `(7,7) → (8,7) → (8,14)`.
- 만약 `8 8` 이나 `16 14` 가 나왔다면 두 변수를 하나로 묶어 생각한 착각이거나, 참조 `int &y = x;` 로 선언한 경우다.
```

**8) 0.1 더하기 0.2의 정체** · Medium

- **요구사항**: 변수 `total` 에 `0.1 + 0.2` 의 결과를 담고, 첫 줄에는 `total` 을 **되살릴 수 있는 최대 자릿수(유효숫자 17자리)** 로, 둘째 줄에는 소수점 아래 첫째 자리까지, 셋째 줄에는 소수점 아래 둘째 자리까지 출력하라.

```runner
- `cout << fixed << setprecision(1) << total << "\n";` — 이제 `fixed` 를 걸어 "소수점 아래 자릿수" 모드로 바꾼다. 첫째 자리까지 반올림 → `0.3`.

(3) 스스로 다시 짤 때 생각 순서

- 실수 계산 결과를 그대로 믿지 않는다. `double` 에는 항상 미세한 오차가 있고, 화면에 안 보인다고 없는 것이 아니다.

- C++ 함정: `setprecision` 은 `fixed` 유무에 따라 뜻이 완전히 달라진다. `fixed` 없으면 "전체 유효숫자", 있으면 "소수점 아래 자릿수"다. 이 문제는 두 모드를 한 프로그램에서 모두 쓴다.
```

**9) 날짜와 시각 구분자 출력** · Medium

- **요구사항**: 연·월·일을 `y = 2026`, `m = 8`, `d = 28` 로, 시·분을 `h = 14`, `mi = 30` 으로 정한다. 첫 줄에 날짜를 `2026-8-28` 형식으로, 둘째 줄에 시각을 `14:30` 형식으로 출력하라. C++엔 값 사이 구분자를 한 번에 지정하는 옵션이 없으므로 `cout << y << '-' << m << '-' << d` 처럼 구분 문자를 직접 끼워 넣는다.
- **입력**: 없음
- **출력**: 첫 줄 `-` 로 이은 날짜, 둘째 줄 `:` 로 이은 시각
- **예제**: (입력 없음) → `2026-8-28 / 14:30`
- **셀프체크**: 값 사이에 구분 문자만 들어가고 공백은 없는가? 월 `8` 은 `08` 이 아니라 `8` 로 나온다(정수를 그대로 출력하므로). 시각 줄은 `':'` 로 바꿨는가?

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int y = 2026, m = 8, d = 28;
    int h = 14, mi = 30;
    cout << y << '-' << m << '-' << d << "\n";
    cout << h << ':' << mi << "\n";
    return 0;
}
@@TESTS
--IN

--OUT
2026-8-28
14:30
--IN

--OUT
2026-8-28
14:30
@@EXPL
(1) 접근·핵심 아이디어

- C++의 `<<` 는 넘긴 값을 순서대로 빈틈없이 이어 붙인다. 그래서 값 사이에 무엇을 넣을지는 전적으로 내가 정한다. 공백을 원하면 `" "`, 하이픈을 원하면 `'-'` 를 사이에 끼운다.
- "값 사이 구분자"를 한 번에 지정하는 옵션은 없다. 대신 자료형을 신경 쓸 필요도 없다. 숫자와 구분 문자를 그냥 나란히 흘려보내면 된다.
- 문자열 `+` 로 이으려면 숫자를 `to_string` 으로 바꿔야 하지만, `<<` 는 그럴 필요가 없다.

(2) 코드 단계별

- `int y = 2026, m = 8, d = 28;` — 한 문장에 세 변수를 선언·초기화한다. `int h = 14, mi = 30;` 도 같은 방식.
- `cout << y << '-' << m << '-' << d << "\n";` — 세 값 사이에 `-` 가 들어가 `2026-8-28`.
- `cout << h << ':' << mi << "\n";` — 두 값 사이에 `:` 가 들어가 `14:30`.
- `'-'` 는 글자 하나(`char`), `"-"` 는 문자열이다. `cout <<` 에 넘기면 화면 결과는 같다.

(3) 스스로 다시 짤 때 생각 순서

- "값 사이에 무엇이 들어가야 하지?" → 그 문자를 `<<` 로 사이에 끼운다. 맨 앞·맨 뒤에는 붙이지 않는다.
- C++ 함정: `cout << y << '-' << m;` 대신 `cout << y - m;` 처럼 쓰면 뺄셈이 되어 버린다. 구분 문자는 반드시 따옴표로 감싼다.
- `8` 이 `08` 로 나오길 기대했다면 틀린다. 자릿수를 채우려면 `setw(2) << setfill('0')` 이 필요하지만 이 문제는 그렇지 않다.
```

**10) 로봇 명함 출력** · Medium

**11) 장바구니 영수증** · Hard

- **요구사항**: 사과 한 개 `1200` 원을 `3` 개, 우유 한 개 `2500` 원을 `2` 개 산다. 변수 `apple`, `n_apple`, `milk`, `n_milk` 에 값을 담고, 품목별 금액(단가 × 개수)을 새 변수에 구한 뒤 합계를 구한다. 마지막으로 합계에 10% 할인을 적용한 금액(합계 × `0.9`)을 소수점 아래 첫째 자리까지 출력한다. 출력은 아래 네 줄 형식을 따른다.
- **입력**: 없음
- **출력**: 첫 줄 `apple 개수 금액`, 둘째 줄 `milk 개수 금액`, 셋째 줄 `total 합계`, 넷째 줄 `pay 할인후금액(소수점 아래 1자리)`
- **예제**: (입력 없음) → `apple 3 3600 / milk 2 5000 / total 8600 / pay 7740.0`
- **셀프체크**: 품목 금액을 변수에 먼저 담고 그 변수를 합계와 출력에 재사용했는가? 합계는 `int` 로 `8600`, 할인 후 금액은 `double` 로 `7740.0` 이 나오는 이유(정수 × 실수 = 실수)를 설명할 수 있는가? 넷째 줄에만 `fixed << setprecision(1)` 을 적용했는가? 값 사이 공백을 직접 넣었는가?

```runner
@@SOLUTION
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int apple = 1200;
    int n_apple = 3;
    int milk = 2500;
    int n_milk = 2;
    int sub_apple = apple * n_apple;
    int sub_milk = milk * n_milk;
    int total = sub_apple + sub_milk;
    double pay = total * 0.9;
    cout << "apple " << n_apple << " " << sub_apple << "\n";
    cout << "milk " << n_milk << " " << sub_milk << "\n";
    cout << "total " << total << "\n";
    cout << "pay " << fixed << setprecision(1) << pay << "\n";
    return 0;
}
@@TESTS
--IN

--OUT
apple 3 3600
milk 2 5000
total 8600
pay 7740.0
--IN

--OUT
apple 3 3600
milk 2 5000
total 8600
pay 7740.0
@@EXPL
(1) 접근·핵심 아이디어

- 영수증은 "단가 × 개수 → 품목 금액 → 합계 → 할인" 순서로 값이 이어진다. 앞 단계 결과를 변수에 담아 두면 다음 단계에서 그대로 쓸 수 있고, 출력에도 재사용할 수 있다.
- `int` 끼리 곱하고 더한 값은 `int` 로 남지만, `0.9` 같은 `double` 을 곱하는 순간 결과가 `double` 로 승격된다. 그래서 `pay` 만 `double` 로 선언한다.
- 라벨·개수·금액 사이 공백은 `<< " " <<` 로 직접 넣는다.

(2) 코드 단계별

- `int apple = 1200; int n_apple = 3; int milk = 2500; int n_milk = 2;` — 단가와 개수를 담는다.
- `int sub_apple = apple * n_apple;` → `3600`, `int sub_milk = milk * n_milk;` → `5000`.
- `int total = sub_apple + sub_milk;` → `8600`. 앞에서 만든 변수 두 개를 더한다.
- `double pay = total * 0.9;` → `int * double` 이므로 오른쪽이 `double` 로 계산된다. 값은 7740에 아주 가까운 실수다.
- `cout << "pay " << fixed << setprecision(1) << pay << "\n";` — 첫째 자리까지 고정해 `7740.0`. 여기서 `fixed` 를 처음 걸었으므로 앞의 정수 세 줄은 영향을 받지 않는다.

(3) 스스로 다시 짤 때 생각 순서

- 필요한 값(단가 2개, 개수 2개)을 먼저 변수로 만든다.
- 계산 순서를 적어 본다: 품목 금액 → 합계 → 할인. 각 단계 결과를 변수에 담는다.
- C++ 함정 1: `pay` 를 `int` 로 선언하면 소수 부분이 잘려 `7740` 이 되고 `.1f` 로도 살릴 수 없다. 실수가 필요한 변수는 `double` 로 선언한다.
- C++ 함정 2: `fixed` 를 프로그램 맨 앞에서 걸면 `total` 도 `8600` 이 아니라 다른 모양으로 나올 수 있다. 정수 출력에는 영향이 없지만, 실수 출력이 앞에 섞여 있으면 자릿수가 어긋나므로 필요한 줄 직전에 거는 습관이 안전하다.
```

**12) 동시 대입 두 단계 추적** · Hard

- **요구사항**: `x = 3`, `y = 5` 로 시작한다. 규칙 A를 한 번 적용한 뒤 `x`, `y` 를 한 줄에 출력하고, 이어서 규칙 B를 한 번 적용한 뒤 다시 한 줄에 출력하라. 규칙 A: 새 `x` 는 옛 `y`, 새 `y` 는 옛 `x` 와 옛 `y` 의 곱. 규칙 B: 새 `x` 는 옛 `x` 와 옛 `y` 의 합, 새 `y` 는 옛 `x`. C++엔 두 변수를 한 줄에 한꺼번에 바꾸는 문법이 없으므로, **오른쪽 값을 먼저 임시 변수에 모두 담은 뒤** `x`, `y` 에 옮겨야 한다.
- **입력**: 없음
- **출력**: 첫 줄 규칙 A 적용 후 `x y`, 둘째 줄 규칙 B 적용 후 `x y` (공백 한 칸)
- **예제**: (입력 없음) → `5 15 / 20 5`
- **셀프체크**: 규칙 A에서 `x * y` 는 옛 값 `3 * 5 = 15` 로 계산되는가(`x = y;` 를 먼저 해 버리면 `5 * 5 = 25` 로 틀린다)? 규칙 B에서 새 `y` 는 이미 바뀐 `x` 가 아니라 규칙 B 직전의 `x`(=5)인가? 두 단계의 값을 표로 따라가 보았는가?

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int x = 3, y = 5;
    int nx, ny;

    nx = y;
    ny = x * y;
    x = nx;
    y = ny;
    cout << x << " " << y << "\n";

    nx = x + y;
    ny = x;
    x = nx;
    y = ny;
    cout << x << " " << y << "\n";
    return 0;
}
@@TESTS
--IN

--OUT
5 15
20 5
--IN

--OUT
5 15
20 5
@@EXPL
(1) 접근·핵심 아이디어

- 이 문제의 규칙은 "오른쪽을 전부 **옛 값**으로 먼저 계산한 다음, 그 결과를 왼쪽에 한꺼번에 넣는다"는 뜻이다.
- C++의 대입은 한 문장에 하나씩 순서대로 일어난다. 그래서 `x = y; y = x * y;` 라고 쓰면 두 번째 문장에서 이미 바뀐 `x`(=5)가 쓰여 `25` 라는 엉뚱한 값이 나온다.
- 해결책은 임시 변수다. 오른쪽 결과 두 개를 `nx`, `ny` 에 먼저 담아 두면 옛 값이 보존되고, 그다음 `x`, `y` 에 옮기면 된다.
- 값만 맞바꾸는 단순한 경우(`x` 와 `y` 를 교환)라면 표준 라이브러리의 `swap(x, y)` 한 줄로 끝난다. 하지만 이 문제처럼 계산이 섞이면 임시 변수를 직접 써야 한다.

(2) 코드 단계별

- `int x = 3, y = 5;` — 시작값. `int nx, ny;` — 옛 값으로 계산한 결과를 잠시 담을 그릇.
- 규칙 A: `nx = y;` → 5, `ny = x * y;` → `3 * 5 = 15`. 이 두 줄이 끝날 때까지 `x`, `y` 는 아직 옛 값이다. 이어서 `x = nx; y = ny;` → `x` 는 5, `y` 는 15. 출력 → `5 15`.
- 규칙 B: 지금 `x` 는 5, `y` 는 15. `nx = x + y;` → `5 + 15 = 20`, `ny = x;` → 5. 옮기면 `x` 는 20, `y` 는 5. 출력 → `20 5`.

(3) 스스로 다시 짤 때 생각 순서

- 각 규칙마다 "이 줄 시작 시점의 `x`, `y`" 를 먼저 종이에 적는다.
- 오른쪽 식을 그 값으로 모두 계산해 임시 변수에 담고, 그다음에야 `x`, `y` 를 덮어쓴다. **계산과 대입을 분리**하는 것이 핵심이다.
- C++ 함정: 한 문장에 같은 변수를 두 번 바꾸려고 `x = y, y = x * y;` 처럼 쉼표 연산자를 쓰면 왼쪽부터 순서대로 실행되므로 결과가 똑같이 틀린다. 쉼표는 동시 대입이 아니다.
- 규칙 A에서 `25` 가 나왔다면 새 `x` 로 곱한 착각이고, 규칙 B에서 `20 20` 이 나왔다면 새 `x` 를 `y` 에 넣은 착각이다.
```
