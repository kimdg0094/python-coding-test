## L4. 정리 — 개념 지도·체크리스트·자주 하는 실수

**개념**

Ch03의 도구는 기호 다섯 개(`+`, `-`, `*`, `/`, `%`)와 괄호가 전부입니다. 그런데 입문자가 가장 많이 틀리는 곳도 바로 여기입니다. **`/` 가 몫인지 소수인지**와 **어디를 먼저 계산할지** 두 가지에서 갈리기 때문입니다. 이 둘을 지도와 표로 못 박아 둡니다.

**개념 지도**

연산자는 크게 두 갈래입니다. 하나는 "나눗셈이 무엇을 돌려주는가", 다른 하나는 "어느 순서로 계산하는가"입니다.

```text
                  numbers  ->  operators  ->  a number

                       +   -   *
                           |
             +-------------+--------------+
        which division?               which order?
             |                            |
     +-------+--------+           *  /  %        first
   7 / 3   7 / 3.0   7 % 3        +  -           later
     |        |        |          ( )            forces the order
     2      2.33333    1
    int     double    int         // example: 7 and 3
```

C++에서 `/` 의 뜻을 정하는 것은 **양쪽 값의 자료형**입니다. 이 한 줄이 이 챕터의 절반입니다.

```text
  int  /  int     ->  quotient only, decimals are cut away
  int  /  double  ->  real division
  double / int    ->  real division

  int a = 7, b = 2;
  a / b        ->  3        // both int
  a / 2.0      ->  3.5      // one side is double
  (double)a/b  ->  3.5      // cast one side first
```

`/` 와 `%` 는 늘 짝으로 움직입니다. 둘을 합치면 원래 수가 정확히 복원됩니다.

```text
  a  ==  (a / b) * b  +  (a % b)          always true for int

  137 seconds into minutes and seconds

  137 / 60   ->  2         // how many full minutes
  137 % 60   ->  17        // seconds left over
    2 * 60 + 17  =  137    // check: nothing lost
```

합과 평균은 "먼저 모아서 하나로 만들고, 그다음 개수로 나눈다"는 한 가지 흐름입니다.

```text
  a  b  c                     total = a + b + c
  +-+-+-+
  |1|2|4|  --- add --->       7
  +-+-+-+                      |
                      +--------+--------+
                    / 3               / 3.0
                      2                 2.33333
                     int              double     // count = 3 values
```

**뼈대 코드**

이 챕터 문제는 아래 네 가지 뼈대 중 하나에 값만 갈아 끼우면 됩니다.

```cpp
// 1) 두 수를 받아 여러 결과를 줄마다 출력하기
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << "\n";       // <- 문제마다 바뀜
    cout << a - b << "\n";       // 뺄셈은 "앞 - 뒤" 순서를 지킨다
    cout << a * b << "\n";
    return 0;
}
```

```cpp
// 2) 몫과 나머지로 단위 쪼개기 (시간·묶음·거스름돈)
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int big = n / 60;            // <- 나누는 단위가 문제마다 바뀜
    int small = n % 60;
    cout << big << " " << small << "\n";
    return 0;
}
```

```cpp
// 3) 합과 평균 구하기
#include <iostream>
using namespace std;

int main() {
    int a, b, c;                 // <- 값 개수만큼 변수를 늘린다
    cin >> a >> b >> c;
    int total = a + b + c;       // 합을 먼저 변수에 담는다
    double avg = total / 3.0;    // <- 나누는 수는 "값의 개수"
    cout << total << "\n";
    cout << avg << "\n";
    return 0;
}
```

```cpp
// 4) 공식을 그대로 옮기고 자릿수를 맞춰 출력하기
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double x;
    cin >> x;
    double result = (x * 9 / 5) + 32;   // <- 공식이 문제마다 바뀜
    cout << fixed << setprecision(2);   // <- 자릿수도 문제마다 바뀜
    cout << result << "\n";
    return 0;
}
```

**언제 무엇을 쓰나**

| 상황 | 고르는 것 | 이유 | 복잡도 |
|------|-----------|------|--------|
| 소수까지 정확한 나눗셈 | `a / 2.0`, `(double)a / b` | 한쪽이 실수여야 소수 나눗셈이 된다 | O(1) |
| 정수 결과만 필요하다 | `int` 끼리 `a / b` | 소수점 아래를 잘라 몫만 남긴다 | O(1) |
| 남는 양이 궁금하다 | `a % b` | 나누고 남은 값을 준다 | O(1) |
| 단위를 쪼갠다(초→분·초) | `/ 단위` 와 `% 단위` | 큰 단위는 몫, 남는 것은 나머지 | O(1) |
| 짝수·배수 여부를 본다 | `n % 2`, `n % k` | 나머지가 `0` 이면 나누어떨어진다 | O(1) |
| 자릿수를 뽑는다 | `/ 10`, `% 10` | 10묶음의 개수와 남는 낱개 | O(1) |
| 소수 평균이 필요하다 | `total / 개수.0` 형태 | 나누는 수를 실수로 써야 소수가 남는다 | O(1) |
| 정수 평균이 필요하다 | `int` 끼리 `total / 개수` | 소수점 아래를 버려 정수로 나온다 | O(1) |
| 합 전체를 나눠야 한다 | `total` 에 담고 `total / n` | 괄호를 빠뜨릴 자리가 아예 없어진다 | O(1) |
| 계산 순서를 바꿔야 한다 | `( )` 로 묶기 | 곱셈·나눗셈이 먼저라는 기본 순서를 덮어쓴다 | O(1) |
| 출력 자릿수가 정해져 있다 | `fixed << setprecision(2)` | `fixed` 가 있어야 소수점 아래 자릿수다 | O(1) |
| 합이 커질 수 있다 | `long long total` | `int` 는 약 21억에서 값이 뒤집힌다 | O(1) |
| 음수가 섞인 나눗셈 | 부호를 먼저 확인 | `-7 / 2` 는 `-3`, `-7 % 2` 는 `-1` 이다 | O(1) |

**✅ 마스터 체크리스트**

- [ ] 설명할 수 있다: 같은 `/` 가 왜 어떤 때는 `3`, 어떤 때는 `3.5` 를 주는가.
- [ ] 설명할 수 있다: `7 / 2`, `7 / 2.0`, `7 % 2` 의 결과와 자료형이 각각 무엇인가.
- [ ] 설명할 수 있다: `double r = a / b;` 가 왜 소수를 되살리지 못하는가.
- [ ] 설명할 수 있다: `(double)a / b` 와 `a / 2.0` 이 같은 일을 하는 이유는 무엇인가.
- [ ] 설명할 수 있다: 정수 나눗셈이 어느 쪽으로 자르며, `-7 / 2` 가 왜 `-3` 인가.
- [ ] 설명할 수 있다: `-7 % 2` 가 왜 `-1` 이며, 나머지가 음수일 수 있는 이유는 무엇인가.
- [ ] 설명할 수 있다: `a == (a / b) * b + (a % b)` 가 왜 항상 성립하는가.
- [ ] 설명할 수 있다: `137` 초를 분과 초로 나눌 때 어디에 `/` 를, 어디에 `%` 를 쓰는가.
- [ ] 설명할 수 있다: `2 + 3 * 4` 가 왜 `20` 이 아니라 `14` 인가.
- [ ] 설명할 수 있다: `a + b + c / 3.0` 이 평균이 아닌 이유를 계산 순서로.
- [ ] 설명할 수 있다: 평균에서 나누는 수를 무엇으로 정하는가.
- [ ] 설명할 수 있다: 합을 `total` 변수에 먼저 담으면 어떤 실수가 줄어드는가.
- [ ] 설명할 수 있다: `cout` 이 실수를 기본으로 어떻게 보여 주며, 왜 `20.0` 이 `20` 으로 나오는가.
- [ ] 설명할 수 있다: 합이 `int` 범위를 넘으면 무슨 일이 일어나는가.

**⚠️ 자주 하는 실수**

**(1) 정수끼리 나눠 놓고 실수 상자에 담는다**

```cpp
// ❌ 틀린 코드
int a = 7, b = 2;
double r = a / b;
cout << r << "\n";           // 3
```

왜: 오른쪽이 **이미 정수 나눗셈으로 끝난 뒤** 결과가 복사됩니다. 실수 상자에 담는다고 잘려 나간 소수가 돌아오지는 않습니다.

```cpp
// ✅ 고친 코드
int a = 7, b = 2;
double r = (double)a / b;    // 나누기 전에 한쪽을 실수로
cout << r << "\n";           // 3.5
```

**(2) 평균에서 괄호를 빠뜨린다**

```cpp
// ❌ 틀린 코드
int a = 10, b = 20, c = 30;
cout << a + b + c / 3.0 << "\n";     // 40
```

왜: `/` 가 `+` 보다 먼저 계산되어 `c` 만 3으로 나뉩니다. `10 + 20 + 10.0` 이 되어 평균과 전혀 다른 값이 나옵니다.

```cpp
// ✅ 고친 코드
int a = 10, b = 20, c = 30;
int total = a + b + c;               // 합을 먼저 하나의 값으로 만든다
cout << total / 3.0 << "\n";         // 20
```

**(3) 나누는 수를 값의 개수와 다르게 쓴다**

```cpp
// ❌ 틀린 코드
int a = 3, b = 5, c = 8, d = 4;
int total = a + b + c + d;
cout << total / 3.0 << "\n";         // 값은 4개인데 3으로 나눴다
```

왜: 평균은 "합 ÷ **값의 개수**"입니다. 개수를 잘못 세면 식의 모양은 맞아도 답이 틀립니다.

```cpp
// ✅ 고친 코드
int a = 3, b = 5, c = 8, d = 4;
int total = a + b + c + d;
cout << total / 4.0 << "\n";
```

**(4) 뺄셈·나눗셈의 순서를 뒤집는다**

```cpp
// ❌ 틀린 코드
int a = 2, b = 5;
cout << b - a << "\n";               // 3 ("앞 - 뒤" 를 요구했는데 뒤집었다)
```

왜: `+` 와 `*` 는 순서를 바꿔도 결과가 같지만, `-` 와 `/` 는 다릅니다. 문제가 정한 순서를 그대로 옮겨야 합니다.

```cpp
// ✅ 고친 코드
int a = 2, b = 5;
cout << a - b << "\n";               // -3
```

**(5) 출력 자릿수를 맞추지 않는다**

```cpp
// ❌ 틀린 코드
double x = 0.1 + 0.2;
cout << x << "\n";                   // 0.3 처럼 보이지만 자릿수가 정해지지 않았다
```

왜: `cout` 의 기본 출력은 유효숫자 여섯 자리까지입니다. 문제가 "소수점 아래 2자리"를 요구하면 그 모양을 직접 정해 줘야 합니다.

```cpp
// ✅ 고친 코드
#include <iomanip>
double x = 0.1 + 0.2;
cout << fixed << setprecision(2) << x << "\n";    // 0.30
```

**(6) 나머지가 항상 0 이상이라고 생각한다**

```cpp
// ❌ 틀린 생각
int n = -7;
cout << n % 2 << "\n";               // 1 이 나올 것이라 기대했지만 -1
```

왜: C++의 정수 나눗셈은 몫을 **0 쪽으로** 자릅니다. 그 결과 `-7 / 2` 는 `-3` 이고, `-3 * 2 + (-1) = -7` 을 맞추려면 나머지가 `-1` 이어야 합니다.

```cpp
// ✅ 고친 코드
int n = -7;
int r = n % 2;                       // -1
if (r < 0) r += 2;                   // 0 이상으로 맞추고 싶을 때만
cout << r << "\n";                   // 1
```

**(7) 나누는 수가 `0` 이 될 수 있는데 그냥 나눈다**

```cpp
// ❌ 틀린 코드
int a, b;
cin >> a >> b;
cout << a / b << "\n";               // b 가 0 이면 프로그램이 죽는다
```

왜: 어떤 수도 0으로 나눌 수 없습니다. `/` 와 `%` 모두 오른쪽이 `0` 이면 친절한 오류 메시지 없이 그 자리에서 비정상 종료됩니다.

```cpp
// ✅ 고친 코드
// 문제 조건에 "사람 수는 1 이상" 처럼 적혀 있는지 먼저 확인한다.
int a, b;
cin >> a >> b;                       // b >= 1 이 보장될 때만 안전하다
cout << a / b << "\n";
```

**(8) 합이 `int` 범위를 넘는다**

```cpp
// ❌ 틀린 코드
int a = 2000000000, b = 2000000000;
int total = a + b;
cout << total << "\n";               // 음수가 나온다
```

왜: `int` 는 약 21억까지만 담습니다. 넘으면 오류가 아니라 값이 뒤집혀 **조용히 틀린 답**이 나옵니다.

```cpp
// ✅ 고친 코드
long long a = 2000000000, b = 2000000000;
long long total = a + b;
cout << total << "\n";               // 4000000000
```

**다음 챕터로**

- Ch01~Ch03으로 "읽고 → 계산하고 → 출력한다"는 한 줄 흐름이 완성되었습니다. 여기까지는 코드가 위에서 아래로 한 번만 흐릅니다.

- 지금 익힌 "먼저 계산되는 덩어리를 눈으로 찾는 습관"과 "자료형이 연산의 뜻을 정한다"는 감각은 식이 길어질수록 더 중요해집니다.
