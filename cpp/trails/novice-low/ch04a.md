> 언어 C++

> 개요: 이 챕터에서는 조건에 따라 프로그램의 흐름을 나누는 방법을 배운다. 주어진 값이 참인지 거짓인지 따져서 서로 다른 코드를 실행하는 if 계열 문법과 삼항 연산자를 익힌다.

## L1. if 조건문

**개념**

- `if`는 "만약 ~라면"이라는 뜻으로, 어떤 조건이 참일 때만 특정 코드를 실행한다.

- 조건이 거짓이면 그 안의 코드는 건너뛰고 아무 일도 일어나지 않는다.

- 형식은 `if (조건) { ... }` 으로 쓴다. 조건은 소괄호 `( )` 안에 넣고, 참일 때 실행할 코드는 중괄호 `{ }` 로 감싼다.

- 중괄호를 생략하면 바로 다음 한 문장만 조건에 묶인다. 처음에는 항상 `{ }` 로 감싸는 습관을 들이면 실수가 준다.

- 조건에는 비교 결과가 들어간다. 예를 들어 `a > 10`은 a가 10보다 크면 참, 아니면 거짓이다.

> 선행: `endl`은 `"\n"`처럼 줄을 바꾸는 또 다른 방법이다. `cout << ... << endl;`로 쓰면 값 출력 후 줄바꿈까지 해 준다. 이 챕터부터는 `"\n"` 대신 `endl`을 주로 쓴다.

```cpp
int score = 85;
if (score >= 60) {
    cout << "합격" << endl;
}
// 조건이 참이므로 "합격"이 출력된다
```

```cpp
int temp = 5;
if (temp > 30) {
    cout << "덥다" << endl;
}
cout << "끝" << endl;
// 조건이 거짓이므로 "덥다"는 건너뛰고, "끝"만 출력된다
```

> 선행: 비교 결과를 만드는 `>`, `>=`, `<`, `<=`, `==`(같다), `!=`(다르다) 기호를 조건에 쓴다. 자세한 규칙은 뒤 레슨에서 다시 정리한다. 여기서는 "크다/작다/같다"를 판단하는 도구로만 사용한다.

**문제**

**1) 양수 판별** · Easy

- **요구사항**: 정수 하나를 입력받아, 그 수가 0보다 크면 `positive`를 출력하는 프로그램을 작성하라. 0보다 크지 않으면 아무것도 출력하지 않는다.
- **입력**: 정수 `n` 한 개
- **출력**: `n`이 양수일 때만 `positive` 한 줄
- **예제**: `7` → `positive`
- **예제**: `-3` → (출력 없음)
- **셀프체크**: 0을 입력하면 아무것도 출력되지 않아야 한다(0은 양수가 아님).

```runner
@@SOLUTION
#include <iostream>
using namespace std;
int main(){
    int n;
    cin >> n;
    if (n > 0) {
        cout << "positive" << endl;
    }
    return 0;
}
@@TESTS
--IN
7
--OUT
positive
--IN
-3
--OUT
--IN
0
--OUT
@@EXPL
"양수일 때만" 실행하는 전형적인 단일 `if` 문제다. 조건이 참일 때만 코드가 돌고, 거짓이면 아무 출력도 없어야 한다.

- `cin >> n;` 으로 정수 `n`을 읽는다.
- `if (n > 0)` 으로 0보다 큰지만 검사한다. `>=`가 아니라 `>`인 이유는 0이 양수가 아니기 때문이다.
- 조건이 참일 때만 중괄호 안의 `cout << "positive"`가 실행된다.

스스로 다시 짤 때는 (1) 무엇을 입력받는가 → 정수 하나, (2) 언제만 출력하는가 → "0보다 클 때만", (3) 그 조건을 `n > 0`으로 옮기고 출력을 중괄호 안에 넣기, 순서로 생각하면 된다. 경계값 0이 출력에서 빠지는지 꼭 확인한다.
```

**2) 통과 안내** · Easy

- **요구사항**: 시험 점수를 입력받아 60점 이상이면 축하 메시지 두 줄을 출력하는 프로그램을 작성하라.
- **입력**: 정수 점수 `score` 한 개
- **출력**: `score`가 60 이상이면 `Pass`와 `Congratulations` 두 줄, 아니면 아무것도 출력하지 않음
- **예제**: `72` → `Pass` / `Congratulations` (두 줄)
- **예제**: `50` → (출력 없음)
- **셀프체크**: 정확히 60점도 통과여야 한다(`>=` 사용). 두 줄 모두 같은 `if`의 중괄호 안에 들어 있는지 확인.

```runner
@@SOLUTION
#include <iostream>
using namespace std;
int main(){
    int score;
    cin >> score;
    if (score >= 60) {
        cout << "Pass" << endl;
        cout << "Congratulations" << endl;
    }
    return 0;
}
@@TESTS
--IN
72
--OUT
Pass
Congratulations
--IN
50
--OUT
--IN
60
--OUT
Pass
Congratulations
@@EXPL
한 `if` 안에서 여러 줄을 실행하는 연습이다. 조건이 참이면 중괄호 안 두 줄이 모두 실행되고, 거짓이면 둘 다 건너뛴다.

- `score`를 정수로 읽는다.
- `if (score >= 60)` 으로 60 이상인지 검사한다. 경계값 60도 통과여야 하므로 `>`가 아니라 `>=`를 쓴다.
- 참일 때 실행할 두 줄 `cout << "Pass"`와 `cout << "Congratulations"`를 **같은 중괄호 `{ }`** 안에 넣는다. 같은 블록에 있어야 둘 다 이 `if`에 묶인다.

다시 짤 때는 (1) 조건은 하나(60 이상)뿐이라 단일 `if`, (2) 참일 때 출력이 두 줄이니 `cout`을 두 번, (3) 두 출력을 같은 중괄호 안에 넣기, 순으로 생각한다. 중괄호를 빼고 한 줄만 묶으면 두 번째 줄이 조건 밖으로 빠져 항상 출력되니 주의한다.
```

**3) 배수 알림** · Medium

- **요구사항**: 정수 하나를 입력받아 그 수가 3의 배수이면 `multiple`을 출력하는 프로그램을 작성하라.
- **입력**: 정수 `n` 한 개
- **출력**: `n`이 3으로 나누어떨어지면 `multiple`, 아니면 아무것도 출력하지 않음
- **예제**: `9` → `multiple`
- **예제**: `10` → (출력 없음)
- **예제**: `0` → `multiple`
- **셀프체크**: 나누어떨어짐은 나머지가 0인지로 확인한다(`n % 3 == 0`). 0은 3으로 나누면 나머지가 0이므로 `multiple`이 맞다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;
int main(){
    int n;
    cin >> n;
    if (n % 3 == 0) {
        cout << "multiple" << endl;
    }
    return 0;
}
@@TESTS
--IN
9
--OUT
multiple
--IN
10
--OUT
--IN
0
--OUT
multiple
@@EXPL
"나누어떨어지는가"는 나머지 연산자 `%`로 판단한다. 어떤 수를 3으로 나눈 나머지가 0이면 3의 배수다.

- 정수 `n`을 읽는다.
- `n % 3` 은 `n`을 3으로 나눈 나머지다. 이 값이 `0`이면 배수이므로 `if (n % 3 == 0)` 으로 검사한다.
- 참일 때만 `cout << "multiple"`을 실행한다. 배수가 아니면 아무것도 출력하지 않는다.

다시 짤 때는 (1) 배수 판정 = 나머지 0, (2) 나머지는 `%`, (3) `== 0` 비교를 조건에 넣기, 순으로 떠올린다. 0도 3으로 나눈 나머지가 0이라 `multiple`이 나온다는 점을 헷갈리지 말자.
```

## L2. if else 조건문

**개념**

- `else`는 "그렇지 않으면"이라는 뜻으로, `if`의 조건이 거짓일 때 실행할 코드를 적는다.

- `if`와 `else` 중 **정확히 하나만** 실행된다. 둘 다 실행되거나 둘 다 건너뛰는 일은 없다.

- `else`에는 조건을 붙이지 않는다. `else { ... }` 처럼 바로 중괄호만 쓴다.

- `else`는 반드시 짝이 되는 `if` 바로 뒤에 온다. 보통 `if`의 닫는 중괄호 `}` 다음에 `else`를 이어 쓴다.

```cpp
int score = 40;
if (score >= 60) {
    cout << "합격" << endl;
} else {
    cout << "불합격" << endl;
}
// 조건이 거짓이므로 else 쪽 "불합격"이 출력된다
```

**문제**

**1) 홀짝 판별** · Easy

- **요구사항**: 정수 하나를 입력받아 짝수이면 `even`, 홀수이면 `odd`를 출력하는 프로그램을 작성하라.
- **입력**: 정수 `n` 한 개
- **출력**: `even` 또는 `odd` 중 한 줄
- **예제**: `4` → `even`
- **예제**: `7` → `odd`
- **예제**: `0` → `even`
- **셀프체크**: 짝수는 2로 나눈 나머지가 0이다(`n % 2 == 0`). 음수 짝수(예: -6)도 `even`이어야 한다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;
int main(){
    int n;
    cin >> n;
    if (n % 2 == 0) {
        cout << "even" << endl;
    } else {
        cout << "odd" << endl;
    }
    return 0;
}
@@TESTS
--IN
4
--OUT
even
--IN
7
--OUT
odd
--IN
-6
--OUT
even
@@EXPL
두 갈래 중 정확히 하나만 출력하는 `if / else`의 기본형이다. 짝수 판정은 2로 나눈 나머지로 한다.

- 정수 `n`을 읽는다.
- `n % 2 == 0` 이면 짝수이므로 `if` 쪽에서 `even`을 출력한다.
- 아니면(홀수) `else` 쪽에서 `odd`를 출력한다. `if`와 `else`는 반드시 하나만 실행된다.

다시 짤 때는 (1) 결과가 두 종류 → `if/else`, (2) 가르는 기준은 "2로 나눈 나머지가 0인가", (3) 참이면 even, 나머지는 else로 odd, 순으로 생각한다. C++에서 짝수(양·음 모두)는 `n % 2`가 0이므로 `-6`도 그대로 `even`이 된다.
```

**2) 합격 여부** · Easy

- **요구사항**: 점수를 입력받아 60점 이상이면 `Pass`, 그렇지 않으면 `Fail`을 출력하라.
- **입력**: 정수 점수 `score` 한 개
- **출력**: `Pass` 또는 `Fail` 중 한 줄
- **예제**: `85` → `Pass`
- **예제**: `59` → `Fail`
- **예제**: `60` → `Pass`
- **셀프체크**: 경계값 60은 통과다. 59와 60에서 결과가 갈리는지 꼭 확인.

```runner
@@SOLUTION
#include <iostream>
using namespace std;
int main(){
    int score;
    cin >> score;
    if (score >= 60) {
        cout << "Pass" << endl;
    } else {
        cout << "Fail" << endl;
    }
    return 0;
}
@@TESTS
--IN
85
--OUT
Pass
--IN
59
--OUT
Fail
--IN
60
--OUT
Pass
@@EXPL
합격/불합격처럼 결과가 정확히 두 가지인 상황은 `if / else`로 딱 나눈다.

- `score`를 정수로 읽는다.
- `if (score >= 60)` 이 참이면 `Pass`를 출력한다. 경계 60이 합격이므로 `>=`를 쓴다.
- 아니면 `else`에서 `Fail`을 출력한다.

다시 짤 때는 (1) 두 갈래이니 `if/else`, (2) 기준선 60을 포함할지 결정 → 포함이니 `>=`, (3) 참=Pass, 나머지=Fail. 60과 59가 서로 다른 결과로 갈리는지 두 경계값으로 검산하면 부등호 실수를 잡을 수 있다.
```

**3) 둘 중 큰 수** · Medium

- **요구사항**: 두 정수를 입력받아 더 큰 값을 출력하라. 두 값이 같으면 그 값을 그대로 출력한다.
- **입력**: 정수 두 개 `a`, `b` (공백으로 구분)
- **출력**: 더 큰 값 한 줄
- **예제**: `3 8` → `8`
- **예제**: `10 10` → `10`
- **예제**: `-2 -5` → `-2`
- **셀프체크**: `a >= b`로 나누면 같을 때도 올바르게 처리된다. 음수 비교(-2와 -5에서 -2가 크다)에 주의.

```runner
@@SOLUTION
#include <iostream>
using namespace std;
int main(){
    int a, b;
    cin >> a >> b;
    if (a >= b) {
        cout << a << endl;
    } else {
        cout << b << endl;
    }
    return 0;
}
@@TESTS
--IN
3 8
--OUT
8
--IN
10 10
--OUT
10
--IN
-2 -5
--OUT
-2
@@EXPL
공백으로 붙은 두 수를 각각 정수로 읽은 뒤, 큰 쪽을 고르는 `if / else` 문제다.

- `cin >> a >> b;` 는 공백/줄바꿈으로 구분된 두 정수를 차례로 `a`, `b`에 담는다. 공백 처리를 `cin`이 알아서 하므로 따로 자를 필요가 없다.
- `if (a >= b)` 이면 `a`가 크거나 같으니 `a`를 출력한다.
- 아니면 `b`를 출력한다. 같을 때(`a == b`)는 `a >= b`가 참이 되어 그 값(a=b)을 그대로 내보내므로 문제 없다.

다시 짤 때는 (1) 입력이 두 정수 → `cin >> a >> b`로 한 번에 받기, (2) 큰 값 선택은 두 갈래 `if/else`, (3) 같을 때를 놓치지 않으려면 `>`가 아니라 `>=`. 음수끼리 비교(-2 > -5)에서도 부등호 방향이 그대로 성립함을 확인한다.
```

## L3. 삼항 연산자

**개념**

- 삼항 연산자는 `if else`를 한 줄로 짧게 쓰는 표현식이다.

- 형식은 `조건 ? 참일_때_값 : 거짓일_때_값` 이다. 물음표 `?` 앞에 조건, 뒤에 참일 때 값, 콜론 `:` 뒤에 거짓일 때 값을 적는다.

- 결과가 하나의 **값**으로 나오기 때문에, 변수에 저장하거나 바로 출력할 수 있다.

- 조건이 참이면 `?` 뒤의 값, 거짓이면 `:` 뒤의 값이 선택된다.

```cpp
int n = 7;
string result = (n % 2 == 0) ? "even" : "odd";
cout << result << endl;
// n이 홀수라 조건이 거짓 → "odd"가 result에 담겨 출력된다
```

```cpp
int a = 3;
int b = 8;
cout << (a > b ? a : b) << endl;
// 조건이 거짓이므로 b, 즉 8이 출력된다
```

**문제**

**1) 절댓값** · Easy

- **요구사항**: 정수 하나를 입력받아 절댓값(부호를 뗀 크기)을 출력하라. 반드시 삼항 연산자를 사용한다.
- **입력**: 정수 `n` 한 개
- **출력**: `n`의 절댓값 한 줄
- **예제**: `-6` → `6`
- **예제**: `9` → `9`
- **예제**: `0` → `0`
- **셀프체크**: `n`이 음수이면 `-n`, 아니면 `n`을 고른다. 0은 그대로 0이어야 한다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;
int main(){
    int n;
    cin >> n;
    cout << (n < 0 ? -n : n) << endl;
    return 0;
}
@@TESTS
--IN
-6
--OUT
6
--IN
9
--OUT
9
--IN
0
--OUT
0
@@EXPL
삼항 연산자 `조건 ? 참일_때_값 : 거짓일_때_값` 으로 값 하나를 골라 바로 출력한다.

- 정수 `n`을 읽는다.
- 절댓값은 음수일 때 부호만 뒤집으면 된다. `n`이 음수(`n < 0`)면 `-n`(부호를 뒤집어 양수), 아니면 `n` 그대로가 정답이다.
- 이 선택을 `n < 0 ? -n : n` 한 줄로 쓰고 `cout`으로 출력한다.

다시 짤 때는 (1) 결과가 두 값 중 하나 → 삼항, (2) 가르는 조건은 "음수인가"(`n < 0`), (3) 참일 때 `-n`, 거짓일 때 `n`을 `?`와 `:` 자리에 배치. 0은 `n < 0`이 거짓이라 `n`이 그대로 나와 0이 된다는 점을 확인한다.
```

**2) 양수·음수·0 대신 부호 문자** · Medium

- **요구사항**: 정수 하나를 입력받아 0 이상이면 `+`, 음수이면 `-`를 출력하라. 삼항 연산자를 사용한다.
- **입력**: 정수 `n` 한 개
- **출력**: `+` 또는 `-` 한 줄
- **예제**: `5` → `+`
- **예제**: `-1` → `-`
- **예제**: `0` → `+`
- **셀프체크**: 0은 `+` 쪽이다(조건을 `n >= 0`으로). 세 갈래가 아니라 두 갈래 문제임에 주의.

```runner
@@SOLUTION

    cin >> n;
    cout << (n >= 0 ? "+" : "-") << endl;
    return 0;

@@EXPL
0을 양수 쪽에 포함시켜 두 갈래로만 나누는 삼항 연산자 문제다.

- 정수 `n`을 읽는다.
- 0 이상이면 `+`, 음수이면 `-` 이므로 조건을 `n >= 0`으로 잡는다. 0을 어느 쪽에 둘지가 핵심인데, 문제가 "0 이상이면 +"라 했으니 `>=`가 맞다.
- 삼항으로 `n >= 0 ? "+" : "-"` 를 만들고 그대로 `cout` 한다. 출력이 문자이므로 큰따옴표를 붙인다.

다시 짤 때는 (1) 결과가 두 문자 중 하나 → 삼항, (2) 경계 0을 + 쪽에 넣어야 하니 `n >= 0`, (3) 참일 때 `"+"`, 아니면 `"-"`. 세 갈래(양/음/0)로 착각하지 말고 두 갈래로 묶는 것이 이 문제의 요령이다.
```

**3) 더 짧은 문자열** · Hard

- **요구사항**: 두 개의 단어를 입력받아 길이가 더 짧은 단어를 출력하라. 길이가 같으면 첫 번째 단어를 출력한다. 삼항 연산자를 사용한다.
- **입력**: 공백으로 구분된 문자열 두 개 `s`, `t`
- **출력**: 더 짧은 문자열 한 줄
- **예제**: `apple sky` → `sky`
- **예제**: `cat dog` → `cat`
- **예제**: `hi hello` → `hi`
- **셀프체크**: 문자열 길이는 `s.size()`로 잰다. 길이가 같은 `cat dog`에서는 첫 번째 `cat`이 나와야 하므로 조건을 `s.size() <= t.size()`로 잡는다.

```runner
@@SOLUTION
#include <iostream>
#include <string>
using namespace std;
int main(){
    string s, t;
    cin >> s >> t;
    cout << (s.size() <= t.size() ? s : t) << endl;
    return 0;
}
@@TESTS
--IN
apple sky
--OUT
sky
--IN
cat dog
--OUT
cat
--IN
hi hello
--OUT
hi
@@EXPL
길이를 비교해 더 짧은 문자열을 삼항으로 고른다. 길이가 같을 때 첫 번째를 고르게 부등호를 설계하는 것이 포인트다.

- `cin >> s >> t;` 로 두 단어를 각각 `string`인 `s`, `t`에 담는다. 문자열이므로 숫자 변환은 하지 않는다.
- `s.size()`는 `s`의 글자 수다. `s`가 더 짧거나 같으면(`s.size() <= t.size()`) `s`를, 아니면 `t`를 고른다.
- 이 선택을 `s.size() <= t.size() ? s : t` 한 줄로 쓰고 출력한다.

다시 짤 때는 (1) 두 문자열 입력 → `cin >> s >> t`로 분리, (2) 비교 대상은 값이 아니라 길이 `.size()`, (3) 같을 때 첫 번째를 원하니 `<`가 아니라 `<=`. `cat dog`처럼 길이가 같은 경우로 부등호를 검산하면 실수를 잡을 수 있다.
```

> 선행: 글자 수를 세는 `문자열.size()`를 사용한다. 문자열은 Ch2에서 입력받아 보았고, 여기서는 길이만 비교에 쓴다.

## L4. if else if else 조건문

**개념**

- 갈래가 셋 이상일 때는 `else if`를 사용한다.

- 위에서부터 조건을 차례로 검사하다가 **처음으로 참이 되는 갈래 하나만** 실행하고 나머지는 건너뛴다.

- `if`로 시작해서 가운데에 `else if`, 맨 끝에 `else`(어느 조건도 아닐 때)를 둔다.

- 순서가 중요하다. 위쪽 조건이 먼저 참이 되면 아래는 검사조차 하지 않는다.

- `else if`에는 조건이 붙지만 `else`에는 조건이 없다.

```cpp
int score = 75;
if (score >= 90) {
    cout << "A" << endl;
} else if (score >= 60) {
    cout << "B" << endl;
} else {
    cout << "F" << endl;
}
// 90 이상은 아니지만 60 이상이라 "B"가 출력된다
```

**문제**

**1) 부호 판별** · Easy

- **요구사항**: 정수 하나를 입력받아 양수이면 `positive`, 음수이면 `negative`, 0이면 `zero`를 출력하라.
- **입력**: 정수 `n` 한 개
- **출력**: `positive`, `negative`, `zero` 중 한 줄
- **예제**: `12` → `positive`
- **예제**: `-4` → `negative`
- **예제**: `0` → `zero`
- **셀프체크**: 세 갈래가 겹치지 않게 나뉘는지 확인. `else`는 남은 경우(0) 하나만 담당한다.

```runner
@@SOLUTION

    int n;
    cin >> n;
    if (n > 0) {
        cout << "positive" << endl;
    } else if (n < 0) {
        cout << "negative" << endl;
    } else {
        cout << "zero" << endl;
    }
    return 0;
}
@@TESTS

--OUT

--IN

--OUT

--IN

--OUT
zero
@@EXPL
갈래가 셋(양수/음수/0)이므로 `if - else if - else`로 나눈다. 위에서부터 검사해 처음 참인 하나만 실행된다.

- 정수 `n`을 읽는다.
- 먼저 `n > 0`이면 `positive`.
- 아니면 `else if (n < 0)`으로 음수를 걸러 `negative`.
- 위 둘 다 아니라면 남은 경우는 0뿐이므로 `else`에서 `zero`를 낸다. 0은 굳이 조건을 쓰지 않아도 `else`가 자연히 담당한다.

다시 짤 때는 (1) 서로 겹치지 않는 세 경우 → `if/else if/else`, (2) 양수·음수를 조건으로 잡고, (3) 나머지 하나(0)는 `else`에 맡긴다. `n == 0`을 굳이 조건으로 쓰지 않는 편이 간결하고, 세 갈래가 빠짐없이·겹침없이 나뉘는지 확인한다.
```

**2) 성적 등급** · Medium

- **요구사항**: 0~100 사이 점수를 입력받아 등급을 출력하라. 90 이상은 `A`, 80 이상은 `B`, 70 이상은 `C`, 그 미만은 `D`.

```runner
- `score`를 읽는다.
- `score >= 90`이면 `A`. 이 조건이 참이면 아래는 검사하지 않는다.
- 아니면 `else if (score >= 80)`으로 `B`. 90 이상은 이미 위에서 걸러졌으니 여기 오는 값은 90 미만이라 자연히 80~89만 남는다.
```

```runner
- `age`를 읽는다.
- `age < 8`이면 어린이 무료 `0`.
- 아니면(8 이상) `else if (age < 14)`로 `5000`. 8 미만은 이미 걸러졌으니 여기 오는 값은 8~13이다.
- `else if (age < 65)`로 `10000`(14~64), 나머지(65 이상)는 `else`로 `0`.

다시 짤 때는 (1) 나이 구간이 이어지니 `else if` 사슬, (2) 낮은 나이부터 `<` 상한으로 순서대로 걸러 각 줄을 단순하게, (3) 마지막 열린 구간(65 이상)은 `else`. 출력이 숫자라 `cout << 0`처럼 따옴표 없이 쓰고, 14=10000·65=0 경계를 검산한다.
```

## L5. if else if else if else 조건문

**개념**

- `else if`는 필요한 만큼 여러 번 이어 붙일 수 있다. 갈래가 넷, 다섯 개여도 방식은 같다.

- 여전히 위에서부터 검사해 **처음 참이 되는 하나만** 실행한다. 아무 조건도 참이 아니면 `else`가 실행된다.

- 조건 순서를 잘못 두면 특정 갈래가 절대 실행되지 않을 수 있으니, 범위가 겹칠 때는 순서에 특히 주의한다.

```cpp
int n = 3;
if (n == 1) {
    cout << "one" << endl;
} else if (n == 2) {
    cout << "two" << endl;
} else if (n == 3) {
    cout << "three" << endl;
} else {
    cout << "many" << endl;
}
// n이 3이라 세 번째 else if가 참 → "three"
```

**문제**

**1) 숫자를 영어로** · Easy

- **요구사항**: 1부터 3까지의 정수를 입력받아 각각 `one`, `two`, `three`로 출력하라. 그 외의 수이면 `unknown`을 출력한다.
- **입력**: 정수 `n` 한 개
- **출력**: `one`, `two`, `three`, `unknown` 중 한 줄
- **예제**: `2` → `two`
- **예제**: `3` → `three`
- **예제**: `9` → `unknown`
- **셀프체크**: 각 갈래는 `==`로 정확히 하나의 값만 잡는다. 4 이상이나 0 이하는 모두 `unknown`.

```runner
@@SOLUTION
#include <iostream>
using namespace std;
int main(){
    int n;
    cin >> n;
    if (n == 1) {
        cout << "one" << endl;
    } else if (n == 2) {
        cout << "two" << endl;
    } else if (n == 3) {
        cout << "three" << endl;
    } else {
        cout << "unknown" << endl;
    }
    return 0;

@@TESTS

--OUT

--IN

--IN

--IN

@@EXPL
정확히 하나의 값에 대응시키는 문제라, 범위(`>=`)가 아니라 같음(`==`)으로 각 갈래를 잡는다.

- 정수 `n`을 읽는다.
- `n == 1`이면 `one`, `else if (n == 2)`면 `two`, `else if (n == 3)`면 `three`.
- 1·2·3 어느 것도 아니면(4 이상이든 0 이하든) `else`가 모두 받아 `unknown`을 낸다.

다시 짤 때는 (1) 값마다 결과가 정해져 있으니 `==` 비교의 `else if` 사슬, (2) 다룰 값(1,2,3)을 하나씩 나열, (3) 그 밖의 모든 경우는 `else` 하나로 몰아 `unknown`. 크기 비교가 아니라 값 일치가 기준임을 헷갈리지 말자. `==`(같음)를 `=`(대입)로 잘못 쓰지 않도록 주의한다.
```

**2) 계절 판별** · Medium

- **요구사항**: 월(1~12)을 입력받아 계절을 출력하라. 3~5월은 `spring`, 6~8월은 `summer`, 9~11월은 `fall`, 그 외(12, 1, 2월)는 `winter`.
- **입력**: 정수 월 `m` 한 개 (1~12)
- **출력**: 계절 이름 한 줄
- **예제**: `4` → `spring`
- **예제**: `7` → `summer`
- **예제**: `11` → `fall`
- **예제**: `12` → `winter`
- **셀프체크**: 겨울(12,1,2)은 연속 구간이 아니므로 마지막 `else`로 처리하면 깔끔하다. 각 구간의 시작·끝(3, 5, 8, 9 등) 경계를 검산.

```runner
@@SOLUTION

using namespace std;

        cout << "spring" << endl;
    } else if (m >= 6 && m <= 8) {
        cout << "summer" << endl;
    } else if (m >= 9 && m <= 11) {
        cout << "fall" << endl;
    } else {
        cout << "winter" << endl;
    }

@@TESTS

--IN

각 계절이 월 범위로 정해지는데, 겨울(12,1,2)만 연속 구간이 아니다. 연속인 세 계절을 조건으로 잡고 나머지를 `else`로 몰면 깔끔하다.

- 정수 `m`을 읽는다.
- C++에서는 `3 <= m <= 5`처럼 한 번에 쓸 수 없으므로 `m >= 3 && m <= 5`처럼 `&&`(그리고)로 두 조건을 잇는다. 봄(3~5), 여름(6~8), 가을(9~11)을 각각 이렇게 검사한다.
- 12·1·2는 흩어져 있어 조건으로 묶기 번거로우므로, 위 세 조건에 걸리지 않은 나머지를 `else`에서 `winter`로 처리한다.

다시 짤 때는 (1) 범위별 결과이니 `else if` 사슬, (2) 연속 구간인 봄·여름·가을을 `m >= 시작 && m <= 끝`으로, (3) 흩어진 겨울은 굳이 조건화하지 말고 `else`에 맡긴다. 각 구간의 경계(5→봄, 6→여름 등)를 검산해 겹치거나 빠진 달이 없는지 확인한다.
```

**3) 가위바위보 판정** · Hard

- **요구사항**: 나(`me`)와 상대(`you`)가 낸 것을 정수로 입력받는다. 0은 가위, 1은 바위, 2는 보다. 내가 이기면 `win`, 지면 `lose`, 비기면 `draw`를 출력하라.
- **입력**: 정수 두 개 `me`, `you` (공백으로 구분, 각각 0/1/2)
- **출력**: `win`, `lose`, `draw` 중 한 줄
- **예제**: `1 0` → `win`  (바위가 가위를 이김)
- **예제**: `0 1` → `lose` (가위가 바위에게 짐)
- **예제**: `2 2` → `draw`
- **예제**: `0 2` → `win`  (가위가 보를 이김)
- **셀프체크**: 먼저 같으면 `draw`를 처리하고, 이기는 세 경우(바위·가위, 보·바위, 가위·보)를 `else if`로 나열한 뒤 나머지를 `lose`로 두면 갈래가 겹치지 않는다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;
int main(){
    int me, you;
    cin >> me >> you;
    if (me == you) {
        cout << "draw" << endl;
    } else if (me == 1 && you == 0) {
        cout << "win" << endl;
    } else if (me == 2 && you == 1) {
        cout << "win" << endl;
    } else if (me == 0 && you == 2) {
        cout << "win" << endl;
    } else {
        cout << "lose" << endl;
    }
    return 0;
}
@@TESTS
--IN
1 0
--OUT
win
--IN
0 1
--OUT
lose
--IN
2 2
--OUT
draw
--IN
0 2
--OUT
win
@@EXPL
경우의 수가 많아 보이지만, "먼저 비김을 걸러내고 → 이기는 경우만 나열 → 나머지는 지는 것"으로 정리하면 갈래가 겹치지 않는다.

- 두 정수 `me`, `you`를 `cin >> me >> you`로 받는다.
- 먼저 `me == you`면 무조건 `draw`. 이걸 맨 앞에 두면 이후 조건에서 비김을 신경 쓰지 않아도 된다.
- 내가 이기는 경우는 딱 셋: 바위(1)로 가위(0), 보(2)로 바위(1), 가위(0)로 보(2). 각각 `me == ? && you == ?`로 `else if`에 나열하고 `win`을 낸다. `&&`는 두 조건이 모두 참일 때만 참이다.
- 비김도 승리도 아니면 남는 건 지는 경우뿐이니 `else`에서 `lose`.

다시 짤 때는 (1) 같으면 draw를 최상단에서 처리, (2) 이기는 조합 세 가지를 `&&`로 명시, (3) 나머지 전부 `else`=lose로 몰기. 이기는 경우만 외워 두면 지는 경우를 일일이 쓰지 않아도 되어 실수가 준다.
```

## L6. if if 조건문

**개념**

- `if`를 여러 개 나란히 쓰면(각각 독립된 `if`), 각 조건을 **따로따로** 검사한다.

- `if else if`와의 결정적 차이: `if else if`는 하나만 실행되지만, 여러 개의 `if`는 참인 것이 여러 개면 **여러 개가 모두 실행**된다.

- 조건들이 서로 배타적이지 않고(동시에 참일 수 있고) 각각 독립적으로 판단해야 할 때 유용하다.

```cpp
int n = 15;
if (n % 3 == 0) {
    cout << "fizz" << endl;
}
if (n % 5 == 0) {
    cout << "buzz" << endl;
}
// 15는 3의 배수이자 5의 배수라 "fizz"와 "buzz"가 둘 다 출력된다
```

```cpp
int n = 9;
if (n % 3 == 0) {
    cout << "fizz" << endl;
}
if (n % 5 == 0) {
    cout << "buzz" << endl;
}
// 9는 3의 배수라 "fizz"만 출력된다 (5의 배수는 아님)
```

**문제**

**1) 배수 표시** · Easy

- **요구사항**: 정수 하나를 입력받아, 2의 배수이면 `two`를, 3의 배수이면 `three`를 출력하라. 두 조건을 각각 독립된 `if`로 검사한다.
- **입력**: 정수 `n` 한 개
- **출력**: 해당하는 단어를 각각 한 줄씩 (해당 없으면 출력 없음)
- **예제**: `6` → `two` / `three` (두 줄)
- **예제**: `4` → `two`
- **예제**: `5` → (출력 없음)
- **셀프체크**: 6처럼 둘 다 배수이면 두 줄 모두 나와야 한다. `else if`로 쓰면 `three`가 빠지므로 반드시 두 개의 `if`를 쓴다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;
int main(){
    int n;
    cin >> n;
    if (n % 2 == 0) {
        cout << "two" << endl;
    }
    if (n % 3 == 0) {
        cout << "three" << endl;
    }
    return 0;
}
@@TESTS
--IN
6
--OUT
two
three
--IN
4
--OUT
two
--IN
5
--OUT
@@EXPL
두 조건이 동시에 참일 수 있고, 각각 독립적으로 판단해야 하므로 `else if`가 아니라 **독립된 두 `if`**를 쓴다.

- 정수 `n`을 읽는다.
- 첫 번째 `if (n % 2 == 0)` 이 참이면 `two`를 출력한다.
- 두 번째 `if (n % 3 == 0)` 은 앞의 결과와 상관없이 **다시** 검사되어, 참이면 `three`를 출력한다.
- 6은 두 조건 모두 참이라 두 줄, 4는 앞만 참이라 한 줄, 5는 둘 다 거짓이라 아무것도 안 나온다.

다시 짤 때는 (1) 두 판정이 서로 배타적이지 않음을 인식 → `else if` 금지, (2) 각 배수 검사를 독립된 `if`로, (3) 순서는 요구대로 2 먼저·3 나중. `else if`로 쓰면 2의 배수일 때 3 검사를 건너뛰어 6에서 `three`가 빠지는 점이 이 문제의 함정이다.
```

**2) 통과 조건 점검** · Medium

- **요구사항**: 국어 점수와 수학 점수를 입력받는다. 각 과목이 40점 이상이면 그 과목명을 출력한다. 국어가 통과면 `korean`, 수학이 통과면 `math`를 (해당하는 것만) 출력하라.
- **입력**: 정수 두 개 `kor`, `math` (공백으로 구분)
- **출력**: 통과한 과목명을 각각 한 줄씩 (국어를 먼저 검사)
- **예제**: `50 30` → `korean`
- **예제**: `20 90` → `math`
- **예제**: `70 40` → `korean` / `math` (두 줄)
- **예제**: `10 10` → (출력 없음)
- **셀프체크**: 두 조건은 독립적이다. 40은 통과(`>=`). 둘 다 통과면 두 줄, 둘 다 실패면 아무것도 출력하지 않는다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;
int main(){
    int kor, math;
    cin >> kor >> math;
    if (kor >= 40) {
        cout << "korean" << endl;
    }
    if (math >= 40) {
        cout << "math" << endl;
    }
    return 0;
}
@@TESTS
--IN
50 30
--OUT
korean
--IN
20 90
--OUT
math
--IN
70 40
--OUT
korean
math
@@EXPL
두 과목의 통과 여부를 각각 따로 판단해야 하므로, 앞 문제와 같이 독립된 두 `if`를 쓴다.

- `cin >> kor >> math`로 두 점수를 받는다.
- 첫 번째 `if (kor >= 40)` 이 참이면 `korean`. 경계 40이 통과이므로 `>=`.
- 두 번째 `if (math >= 40)` 은 별개로 검사되어 참이면 `math`. 국어를 먼저 검사하라 했으니 순서를 지킨다.
- 둘 다 통과면 두 줄, 하나만이면 한 줄, 둘 다 실패면 출력이 없다.

다시 짤 때는 (1) 두 판정이 독립적이니 각각의 `if`, (2) 통과 기준 40 포함 → `>=`, (3) 출력 순서를 국어→수학으로 맞추기. `70 40`처럼 둘 다 통과하는 입력으로 두 줄이 순서대로 나오는지 검산한다.
```

**3) FizzBuzz 한 수** · Hard

- **요구사항**: 정수 하나를 입력받는다. 3의 배수이면 `Fizz`, 5의 배수이면 `Buzz`를 (해당하는 것을 순서대로 한 줄씩) 출력한다. 만약 3과 5 어느 쪽의 배수도 아니면 그 수 자체를 출력하라.
- **입력**: 정수 `n` 한 개
- **출력**: 규칙에 따른 출력 (아래 예제 참고)
- **예제**: `9` → `Fizz`
- **예제**: `10` → `Buzz`
- **예제**: `15` → `Fizz` / `Buzz` (두 줄)
- **예제**: `7` → `7`
- **셀프체크**: `Fizz`/`Buzz`는 독립된 두 `if`로 각각 검사한다. 다만 "둘 다 아닐 때만 숫자 출력"은 두 `if`가 모두 거짓이었는지 별도로 판단해야 한다(예: 참인 것이 하나라도 있었는지 기록해 두고 마지막에 확인). 15에서 두 줄, 7에서 숫자 한 줄이 나오는지 검산.

```runner
@@SOLUTION
#include <iostream>
using namespace std;
int main(){
    int n;
    cin >> n;
    bool printed = false;
    if (n % 3 == 0) {
        cout << "Fizz" << endl;
        printed = true;
    }
    if (n % 5 == 0) {
        cout << "Buzz" << endl;
        printed = true;
    }
    if (printed == false) {
        cout << n << endl;
    }
    return 0;
}
@@TESTS
--IN
9
--OUT
Fizz
--IN
10
--OUT
Buzz
--IN
15
--OUT
Fizz
Buzz
--IN
7
--OUT
7
@@EXPL
독립된 두 `if`로 Fizz/Buzz를 각각 출력하되, "둘 다 아니면 숫자"라는 마지막 규칙은 앞의 두 `if`가 하나라도 실행됐는지를 기억해 두는 방식으로 푼다.

- `printed`라는 참/거짓(`bool`) 변수를 만들어 처음엔 `false`(아직 아무것도 안 찍음)로 둔다.
- `if (n % 3 == 0)` 이면 `Fizz`를 찍고 `printed = true`로 표시를 켠다.
- `if (n % 5 == 0)` 이면 `Buzz`를 찍고 역시 `printed = true`로 켠다. 두 `if`는 독립이라 15처럼 둘 다면 두 줄이 나온다.
- 마지막에 `if (printed == false)` 면 앞에서 아무것도 안 찍혔다는 뜻이므로 그제야 숫자 `n`을 출력한다.

다시 짤 때는 (1) Fizz·Buzz는 겹칠 수 있으니 독립된 두 `if`, (2) "무언가 찍혔는가"를 기록할 깃발 변수 `printed`를 두고 찍을 때마다 `true`로 갱신, (3) 세 번째 `if`에서 깃발이 아직 `false`일 때만 숫자를 출력. 15(두 줄)와 7(숫자 한 줄) 두 극단으로 깃발 로직을 검산한다.
```

> 선급: 세 번째 문제의 "둘 다 아닐 때" 판단은, 앞의 두 `if`가 실행됐는지를 표시해 두는 방식으로 해결할 수 있다. 이때 참/거짓을 담는 `bool` 변수와 그 갱신은 Ch4에서 배운 조건문과 Ch1의 변수 값 변경만으로 충분히 구현된다.
