> 개요: 이 챕터에서는 숫자를 계산하는 연산자(더하기, 빼기, 곱하기, 나누기, 나눗셈의 몫과 나머지)를 배우고, 이를 이용해 여러 값의 합과 평균을 구하는 방법을 익힙니다.

## L1. 사칙연산

**개념**

- 사칙연산은 컴퓨터에게 계산을 시키는 가장 기본 도구입니다. C++은 숫자와 연산자만 있으면 우리 대신 계산을 해 줍니다.
- 기본 연산자는 다음과 같습니다.

- `+` : 더하기 (덧셈)
- `-` : 빼기 (뺄셈)
- `*` : 곱하기 (곱셈), 학교에서 쓰던 `×` 대신 별표를 씁니다.
- `/` : 나누기. C++에서는 나누는 두 값이 모두 정수면 결과도 정수(몫)가 됩니다. 예: `int`끼리 `10 / 4`는 `2`입니다. 소수 결과가 필요하면 한쪽을 실수(`double`)로 만들어야 합니다. 예: `10 / 4.0`은 `2.5`.

- 정수끼리 나눌 때 유용한 두 연산이 있습니다.

- `/` : 정수끼리면 몫만 구하기 (소수점 아래를 버림). 예: `int`끼리 `7 / 2`는 `3`.
- `%` : 나머지 구하기. 예: `7 % 2`는 `1`.

- 곱셈·나눗셈이 덧셈·뺄셈보다 먼저 계산됩니다. 순서를 바꾸고 싶으면 소괄호 `( )`로 묶습니다. 예: `2 + 3 * 4`는 `14`, `(2 + 3) * 4`는 `20`.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 7;
    int b = 3;
    cout << a + b << "\n";        // 10
    cout << a - b << "\n";        // 4
    cout << a * b << "\n";        // 21
    cout << a / (double)b << "\n"; // 2.33333 (한쪽을 실수로 만들면 소수 나눗셈)
    cout << a / b << "\n";        // 2  (정수끼리라 몫만)
    cout << a % b << "\n";        // 1  (나머지)
    return 0;
}
```

- 정수 나눗셈과 소수 나눗셈의 차이를 꼭 기억하세요. `int`끼리 `a / b`는 몫(`2`)이고, 소수 결과가 필요하면 `a / (double)b`처럼 한쪽을 실수로 바꿔야 합니다(`2.33333`).
- `cout`은 실수(`double`)를 기본적으로 유효숫자 6자리까지 출력하고, `20.0`처럼 값이 딱 떨어지면 `.0`을 붙이지 않고 `20`으로 보여 줍니다.

> 선행: 입력값을 정수로 받을 때는 `int n; cin >> n;` 형태를 씁니다(Ch2에서 배움). 한 줄에 두 값을 공백으로 받을 때는 `int a, b; cin >> a >> b;` 처럼 `>>`를 이어 쓰면 공백으로 구분된 값이 차례로 들어갑니다(Ch2에서 배움). `cin >>`은 공백을 알아서 건너뛰므로 따로 잘라 줄 필요가 없습니다.

**문제**

**1) 두 수의 계산기** · Easy

- **요구사항**: 두 정수를 입력받아 합, 차, 곱을 차례로 출력하는 프로그램을 작성합니다.
- **입력**: 한 줄에 두 정수가 공백으로 구분되어 주어집니다.
- **출력**: 첫째 줄에 두 수의 합, 둘째 줄에 차(앞의 수 - 뒤의 수), 셋째 줄에 곱을 출력합니다.
- **예제**: `7 3` → `10` / `4` / `21` (세 줄)
- **예제**: `10 4` → `14` / `6` / `40` (세 줄)
- **셀프체크**: 차는 "뒤 - 앞"이 아니라 "앞 - 뒤" 순서인지 확인하세요. 곱셈 기호는 `×`가 아니라 `*`입니다. 각 줄 끝에 `"\n"`을 붙여 줄이 나뉘는지 점검합니다(`cout`은 자동 개행하지 않음).

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << "\n";
    cout << a - b << "\n";
    cout << a * b << "\n";
    return 0;
}
@@TESTS
--IN
7 3
--OUT
10
4
21
--IN
10 4
--OUT
14
6
40
@@EXPL
접근: 한 줄에 두 정수가 공백으로 들어오므로 `cin >>`으로 차례대로 받은 뒤, 합·차·곱을 순서대로 한 줄씩 출력합니다.

- `int a, b; cin >> a >> b;`: `cin >>`은 공백을 알아서 건너뛰며 두 정수를 각각 `a`, `b`에 담습니다. 처음부터 정수로 받으므로 따로 변환할 필요가 없습니다.
- `cout << a + b << "\n";` → 합, `cout << a - b << "\n";` → 차(앞의 수 - 뒤의 수), `cout << a * b << "\n";` → 곱을 각각 한 줄씩 출력합니다.
- `"\n"`을 붙여야 줄이 나뉩니다. C++의 `cout`은 자동으로 줄을 바꾸지 않습니다.

재작성 순서: (1) 두 정수를 `cin >> a >> b`로 받는다 → (2) 합·차·곱을 순서대로 `cout` 세 번 한다. 차는 반드시 `a - b`(앞 - 뒤), 곱셈 기호는 `*`를 씁니다.
```

**2) 몫과 나머지** · Medium

- **요구사항**: 사탕 개수와 사람 수를 입력받아, 한 사람이 몇 개씩 가질 수 있는지와 남는 사탕이 몇 개인지 출력합니다.
- **입력**: 한 줄에 사탕 개수와 사람 수가 공백으로 구분되어 주어집니다. (사람 수는 1 이상)
- **출력**: 첫째 줄에 한 사람이 갖는 사탕 수, 둘째 줄에 남는 사탕 수를 출력합니다.
- **예제**: `17 5` → `3` / `2` (두 줄)
- **예제**: `20 4` → `5` / `0` (두 줄)
- **셀프체크**: 한 사람이 갖는 개수는 정수끼리의 `/`(몫)로 구합니다. 남는 개수는 `%`로 구합니다. 딱 나누어떨어지면 나머지가 `0`이어야 합니다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a / b << "\n";
    cout << a % b << "\n";
    return 0;
}
@@TESTS
--IN
17 5
--OUT
3
2
--IN
20 4
--OUT
5
0
@@EXPL
접근: 사탕을 사람 수로 똑같이 나눌 때, 한 사람이 갖는 개수는 "몫"이고 남는 사탕은 "나머지"입니다. 정수끼리의 `/`는 몫, `%`는 나머지를 줍니다.

- `int a, b; cin >> a >> b;`로 사탕 개수와 사람 수를 정수로 받습니다.
- `a / b`: `a`와 `b`가 모두 `int`라서 결과도 정수, 즉 소수점 아래를 버린 몫이 됩니다. 그래서 "한 사람이 온전히 갖는 개수"가 됩니다.
- `a % b`: 나눈 뒤 남는 값이라 "남는 사탕 수"가 됩니다. 딱 나누어떨어지면 `0`이 나옵니다.
- 몫을 먼저, 나머지를 그다음 줄에 출력합니다.

재작성 순서: (1) 두 정수를 `cin >>`으로 받는다 → (2) 정수 나눗셈 `/`로 몫을 구해 출력 → (3) `%`로 나머지를 구해 출력. 소수 결과가 나오지 않도록 두 값 모두 `int`인지 확인합니다.
```

**3) 온도 변환** · Medium

- **요구사항**: 섭씨 온도를 입력받아 화씨 온도로 변환해 출력합니다. 변환식은 화씨 = 섭씨 × 9 / 5 + 32 입니다.
- **입력**: 섭씨 온도(정수) 한 개가 주어집니다.
- **출력**: 화씨 온도를 한 줄에 출력합니다.
- **예제**: `25` → `77`
- **예제**: `100` → `212`
- **셀프체크**: 정수끼리 `9 / 5`를 하면 `1`이 되어 잘못 계산됩니다. 반드시 `9.0 / 5`처럼 한쪽을 실수로 만들어 소수 나눗셈이 되게 합니다. `cout`은 실수라도 값이 딱 떨어지면 `77`처럼 `.0` 없이 출력합니다. 곱셈·나눗셈이 덧셈보다 먼저 계산되므로 `c * 9.0 / 5 + 32`는 괄호 없이도 올바르게 계산됩니다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int c;
    cin >> c;
    double f = c * 9.0 / 5 + 32;
    cout << f << "\n";
    return 0;
}
@@TESTS
--IN
25
--OUT
77
--IN
100
--OUT
212
@@EXPL
접근: 주어진 변환식 화씨 = 섭씨 × 9 / 5 + 32 를 그대로 코드로 옮기되, 정수 나눗셈이 되지 않도록 한쪽을 실수로 만듭니다.

- `int c; cin >> c;`: 섭씨 온도를 한 개 정수로 받습니다.
- `c * 9.0 / 5 + 32`: `c * 9.0`이 먼저(실수 곱셈), 그 결과를 `/ 5`(실수 나눗셈), 마지막으로 `+ 32`가 계산됩니다. `9.0`을 써서 소수 나눗셈이 되게 하는 것이 핵심입니다. 만약 `9 / 5`처럼 정수끼리 나누면 `1`이 되어 결과가 틀립니다.
- `double f`에 담아 출력하면, `cout`은 값이 딱 떨어지는 `77.0`을 `77`처럼 `.0` 없이 보여 줍니다.

재작성 순서: (1) 섭씨 온도를 정수로 받는다 → (2) 공식을 `c * 9.0 / 5 + 32`로 계산해 `double` 변수에 담는다 → (3) 그 값을 출력한다. 정수 나눗셈을 피하려고 `9.0`을 쓰는 점을 잊지 않습니다.
```

## L2. 합과 평균

**개념**

- 여러 개의 값을 다룰 때 가장 많이 하는 계산이 "합(모두 더한 값)"과 "평균(합을 개수로 나눈 값)"입니다.
- 합은 `+`로 모두 더하면 됩니다. 예: 세 수 `a, b, c`의 합은 `a + b + c`.
- 평균은 "합 ÷ 개수"입니다. 개수가 3개면 합을 `3`으로 나눕니다.

- 평균을 구할 때 나눗셈 종류를 상황에 맞게 고릅니다.

- 소수까지 정확한 평균이 필요하면 소수 나눗셈이 되게 합니다. 예: `(a + b + c) / 3.0`처럼 나누는 수를 실수(`3.0`)로 씁니다.
- 소수를 버리고 정수 평균만 필요하면 정수끼리 나눕니다. 예: `(a + b + c) / 3` (모두 `int`).

- 괄호가 중요합니다. `a + b + c / 3.0`은 `c`만 나누므로 틀립니다. 반드시 `(a + b + c) / 3.0`처럼 합 전체를 괄호로 묶으세요.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10, b = 20, c = 30;
    int total = a + b + c;      // 60
    double avg = total / 3.0;   // 20
    cout << total << "\n";      // 60
    cout << avg << "\n";        // 20  (cout은 20.0을 20으로 출력)
    return 0;
}
```

- 합을 먼저 변수에 담아 두면(`total`) 평균을 구할 때 다시 쓸 수 있어 편리하고 실수도 줄어듭니다.
- `cout`은 실수(`double`)를 유효숫자 6자리까지 출력합니다. 예: `1 + 2 + 4 = 7`의 평균 `7 / 3.0`은 `2.33333`으로 나옵니다.

**문제**

**1) 세 수의 합과 평균** · Easy

- **요구사항**: 세 정수를 입력받아 합과 평균을 출력합니다. 평균은 소수까지 정확하게 구합니다.
- **입력**: 한 줄에 세 정수가 공백으로 구분되어 주어집니다.
- **출력**: 첫째 줄에 세 수의 합, 둘째 줄에 평균을 출력합니다.
- **예제**: `10 20 30` → `60` / `20` (두 줄)
- **예제**: `1 2 4` → `7` / `2.33333` (두 줄)
- **셀프체크**: 평균은 합 전체를 괄호로 묶어 `(a + b + c) / 3.0`로 계산했는지 확인하세요. 나누는 수를 `3.0`으로 써야 소수 나눗셈이 됩니다. `cout`은 실수라도 딱 떨어지면 `20`처럼 `.0` 없이, 나누어떨어지지 않으면 `2.33333`처럼 6자리로 출력합니다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    int total = a + b + c;
    double avg = total / 3.0;
    cout << total << "\n";
    cout << avg << "\n";
    return 0;
}
@@TESTS
--IN
10 20 30
--OUT
60
20
--IN
1 2 4
--OUT
7
2.33333
@@EXPL
접근: 세 정수를 받아 먼저 합을 구해 변수에 담고, 그 합을 개수 3으로 나눠 평균을 구합니다. 소수까지 정확한 평균이 필요하므로 `3.0`으로 나눠 소수 나눗셈이 되게 합니다.

- `int a, b, c; cin >> a >> b >> c;`로 세 정수를 받습니다.
- `int total = a + b + c;`: 세 수를 모두 더한 합을 변수에 담아 둡니다.
- `double avg = total / 3.0;`: 합을 개수 3으로 나눕니다. 나누는 수를 `3.0`(실수)으로 써서 소수 나눗셈이 됩니다. 만약 `total / 3`처럼 정수끼리 나누면 소수점 아래가 버려집니다.
- 합을 먼저, 평균을 그다음 줄에 출력합니다. `cout`은 `20.0`은 `20`으로, 나누어떨어지지 않는 값은 `2.33333`처럼 6자리로 보여 줍니다.

재작성 순서: (1) 세 정수를 `cin >>`으로 받는다 → (2) 합을 `total`에 담는다 → (3) `total / 3.0`으로 평균을 구한다 → (4) 합, 평균 순으로 출력한다. 나누는 수를 `3.0`으로 쓰는 것(또는 합 전체를 괄호로 묶는 것)을 잊지 않습니다.
```

**2) 두 과목 평균 점수** · Easy

- **요구사항**: 국어 점수와 영어 점수를 입력받아 두 과목의 평균을 출력합니다.
- **입력**: 한 줄에 두 정수(국어, 영어)가 공백으로 구분되어 주어집니다.
- **출력**: 두 과목 평균을 한 줄에 출력합니다.
- **예제**: `90 80` → `85`
- **예제**: `85 100` → `92.5`
- **셀프체크**: 개수가 2개이므로 `2.0`으로 나눕니다. `(k + e) / 2.0` 형태로 괄호를 빠뜨리지 않았는지, 나누는 수를 실수로 썼는지 확인하세요.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int k, e;
    cin >> k >> e;
    double avg = (k + e) / 2.0;
    cout << avg << "\n";
    return 0;
}
@@TESTS
--IN
90 80
--OUT
85
--IN
85 100
--OUT
92.5
@@EXPL
접근: 두 점수를 받아 합을 개수 2로 나눠 평균을 구합니다. 소수 평균이 필요하므로 `2.0`으로 나누고, 합 전체를 괄호로 묶습니다.

- `int k, e; cin >> k >> e;`로 국어·영어 점수를 정수로 받습니다.
- `(k + e) / 2.0`: 두 점수를 먼저 더한 뒤 `2.0`으로 나눕니다. 괄호가 없으면 `e`만 나눠지므로 괄호가 꼭 필요하고, 나누는 수가 `2.0`(실수)이라 소수 나눗셈이 됩니다.
- `cout << avg`: 평균을 출력합니다. `90 80`이면 딱 떨어지는 `85.0`이 `85`로, `85 100`이면 `92.5`로 나옵니다.

재작성 순서: (1) 두 점수를 `cin >>`으로 받는다 → (2) `(k + e) / 2.0`으로 평균을 구한다 → (3) 출력한다. 나누는 수는 값의 개수인 2이되 소수 나눗셈이 되도록 `2.0`으로 쓰고, 합 전체를 괄호로 감싸는 것을 잊지 않습니다.
```

**3) 네 수의 합과 정수 평균** · Medium

- **요구사항**: 네 정수를 입력받아 합과 "정수 평균(소수점 아래를 버린 평균)"을 출력합니다.
- **입력**: 한 줄에 네 정수가 공백으로 구분되어 주어집니다.
- **출력**: 첫째 줄에 네 수의 합, 둘째 줄에 정수 평균을 출력합니다.
- **예제**: `10 20 30 40` → `100` / `25`
- **예제**: `3 5 8 4` → `20` / `5`
- **셀프체크**: 정수 평균이므로 정수끼리 나눕니다. `(a + b + c + d) / 4`로 구하며, `4.0`이 아니라 `4`를 써서 정수 나눗셈이 되게 합니다. 결과에 `.0`이 붙지 않아야 합니다(예: `25`, `5`).

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int a, b, c, d;
    cin >> a >> b >> c >> d;
    int total = a + b + c + d;
    int avg = total / 4;
    cout << total << "\n";
    cout << avg << "\n";
    return 0;
}
@@TESTS
--IN
10 20 30 40
--OUT
100
25
--IN
3 5 8 4
--OUT
20
5
@@EXPL
접근: 네 정수의 합을 구한 뒤, 소수점 아래를 버린 정수 평균이 필요하므로 정수끼리 나눕니다.

- `int a, b, c, d; cin >> a >> b >> c >> d;`로 네 정수를 받습니다.
- `int total = a + b + c + d;`: 네 수를 모두 더해 합을 변수에 담습니다.
- `int avg = total / 4;`: 합을 개수 4로 나눕니다. `total`도 `4`도 `int`라서 결과가 정수, 즉 소수점 아래를 버린 몫이 됩니다. 결과를 `int`에 담으므로 `.0`이 붙지 않습니다.
- 합을 먼저, 정수 평균을 그다음 줄에 출력합니다.

재작성 순서: (1) 네 정수를 `cin >>`으로 받는다 → (2) 합을 `total`에 담는다 → (3) `total / 4`로 정수 평균을 구한다 → (4) 합, 평균 순으로 출력한다. 소수를 버려야 하므로 `4.0`이 아니라 `4`로 나눠 정수 나눗셈이 되게 하는 점이 핵심입니다.
```
