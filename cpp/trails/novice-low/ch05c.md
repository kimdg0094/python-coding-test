## L13. continue문

**개념**

- `continue`는 반복문 안에서 만나면, 현재 반복(회차)의 남은 부분을 **건너뛰고** 곧바로 다음 반복으로 넘어가게 하는 명령이다.
- 반복문 자체를 멈추는 것이 아니라, "이번 회차만 여기서 그만하고 다음으로" 하는 의미다. 반복은 계속된다.
- 주로 특정 조건일 때만 처리를 건너뛰고 싶을 때 `if`와 함께 쓴다.
- `for`에서 `continue`를 만나면 증감식(예: `i++`)을 실행한 뒤 다음 회차로 가고, `while`에서 `continue`를 만나면 곧바로 조건 검사부터 다시 시작한다.

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        if (i == 3) {
            continue;   // i가 3이면 아래 출력을 건너뛴다
        }
        cout << i << " ";
    }
    // 출력: 1 2 4 5 (3은 건너뜀)
    return 0;
}
```

주의: `while`에서 `continue`를 쓸 때, 증가/감소 코드보다 위에서 건너뛰면 값이 안 바뀌어 무한 반복이 될 수 있으니 순서에 유의한다. (`for`는 `continue`가 걸려도 증감식이 자동 실행되지만, `while`은 그렇지 않다.)

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 0;
    while (i < 5) {
        i++;            // 먼저 값을 바꿔 두고
        if (i == 3) {
            continue;   // 그다음 건너뛴다 (안 그러면 3에서 멈춘 채 무한반복)
        }
        cout << i << " ";
    }
    // 출력: 1 2 4 5
    return 0;
}
```

**그림으로 보기**

```text
   for (int i = 1; i <= 5; i++)
        |
        v
   +-------------+  true
   |  i == 3 ?   |--------> continue --+    // skip the rest
   +------+------+                     |
          | false                      |
          v                            |
       cout << i;                      |
          |                            |
          +--------> i++, next pass <--+    // the loop keeps going

   i    :  1   2   3   4   5
   out  :  1   2   .   4   5               // '.' = skipped
```

**왜 이렇게 되는가**

- `continue`는 반복을 끝내지 않는다. **이번 회차의 남은 줄만** 건너뛰고 다음 회차로 넘어간다.

- `if (조건) { continue; }` 뒤에 오는 코드는 "조건이 거짓인 회차"에서만 실행된다. 결과만 보면 `if (!조건) { ... }` 블록 안에 넣은 것과 같다. 걸러 낼 조건이 여러 개일 때 `continue`를 나열하면 중괄호가 깊어지지 않아 읽기 쉽다.

- `for`와 `while`에서 `continue`가 뛰는 자리가 다르다는 점이 C++의 핵심 차이다. `for`는 **증감식을 실행한 뒤** 조건 검사로 가고, `while`은 **곧바로** 조건 검사로 간다.

```text
   for (init; cond; step)          while (cond)
   +----------------------+        +----------------------+
   | body ... continue ---+--+     | body ... continue ---+--+
   +----------------------+  |     +----------------------+  |
             |               |               |               |
             v               |               v               |
           step  <-----------+             cond  <-----------+
             |                               ^
             v                               |
           cond                        step never ran !
```

- 그래서 `while`에서는 증감 줄보다 위에서 `continue`하면 값이 그대로인 채 조건 검사로 돌아가 **같은 회차가 영원히 반복된다.** `while`에서는 증감을 `continue`보다 위에 둔다.

```cpp
// 함정: while 에서 증감이 continue 아래에 있다
int i = 0;
while (i < 5) {
    if (i == 3) { continue; }   // i 를 안 바꾼 채 조건 검사로 - 무한 반복
    cout << i << " ";
    i++;
}

// 고침: 값을 먼저 바꿔 두고 건너뛴다
int j = 0;
while (j < 5) {
    j++;
    if (j == 3) { continue; }
    cout << j << " ";           // 1 2 4 5
}
```

**문제**

**1) 3의 배수만 건너뛰기** · Easy

- **요구사항**: 1부터 N까지의 정수 중에서 3의 배수가 아닌 수만 한 줄에 하나씩 출력하는 프로그램을 작성하라. 반드시 `continue`를 사용한다.
- **입력**: 정수 N (1 이상 20 이하)
- **출력**: 3의 배수가 아닌 수를 작은 것부터 한 줄에 하나씩
- **예제**: `7` → `1` `2` `4` `5` `7` (각각 다른 줄) / `3` → `1` `2`
- **셀프체크**: 3의 배수 조건은 `i % 3 == 0`. 3, 6도 빠져야 한다. N 자신이 3의 배수면 마지막 줄에 없어야 한다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        if (i % 3 == 0) {
            continue;
        }
        cout << i << "\n";
    }
    return 0;
}
@@TESTS
--IN
7
--OUT
1
2
4
5
7
--IN
3
--OUT
1
2
@@EXPL
(1) 접근 개념

- 1부터 N까지 순서대로 보되, "3의 배수만 빼고 나머지는 출력"이 목표다. 이럴 때 `continue`가 딱 맞는다: 3의 배수일 때만 이번 회차의 출력을 건너뛰고 다음 수로 넘어간다.

(2) 코드 진행

- `for (int i = 1; i <= n; i++)`로 1부터 N까지 하나씩 i에 담는다.
- `if (i % 3 == 0)`이면 `continue` — 아래 `cout << i`를 실행하지 않고 다음 i로 간다.
- 3의 배수가 아니면 `continue`를 지나쳐 `cout << i << "\n"`이 실행된다.

(3) 스스로 다시 짤 때 생각 순서

- 먼저 "언제 건너뛸까?"를 정한다 → 3의 배수일 때.
- 그 조건을 `if`로 쓰고 그 안에 `continue`를 둔다.
- 건너뛰지 않는 나머지 경우에 출력이 오도록 `cout`은 `if` 블록 바깥, 반복문 안에 둔다.
```

**2) 특정 숫자 빼고 합** · Medium

- **요구사항**: 1부터 N까지의 정수를 더하는데, 그중 K는 더하지 않고 건너뛴 합을 출력하라. 건너뛸 때 `continue`를 사용한다.
- **입력**: 두 정수 N, K가 공백을 사이에 두고 한 줄에 주어진다. (1 ≤ K ≤ N ≤ 100)
- **출력**: K를 뺀 나머지 수들의 합
- **예제**: `5 2` → `13` (1+3+4+5=13) / `4 4` → `6` (1+2+3=6)
- **셀프체크**: 합을 담을 변수를 0으로 시작. `i == K`일 때만 `continue`. K가 N과 같은 경계도 정확히 빠지는지 확인.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int n, k;
    cin >> n >> k;
    int total = 0;
    for (int i = 1; i <= n; i++) {
        if (i == k) {
            continue;
        }
        total += i;
    }
    cout << total << "\n";
    return 0;
}
@@TESTS
--IN
5 2
--OUT
13
--IN
4 4
--OUT
6
@@EXPL
(1) 접근 개념

- 1부터 N까지 더하되 K 하나만 빼는 문제다. "K일 때만 더하기를 건너뛴다"를 `continue`로 표현한다.

(2) 코드 진행

- 한 줄에 온 두 수를 `cin >> n >> k`로 각각 정수 n, k에 읽는다(공백은 cin이 자동으로 건너뛴다).
- 합을 담을 `total`을 0으로 시작한다.
- `for (int i = 1; i <= n; i++)`로 1..N을 돌며, `i == k`면 `continue`로 더하기를 건너뛴다.
- 그 외에는 `total += i`로 누적한 뒤, 반복이 끝나면 `total`을 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- 한 줄에 두 정수가 오면 `cin >> n >> k` 한 문장으로 둘 다 읽을 수 있다(공백 자동 처리).
- 누적합은 항상 0에서 시작한다는 걸 먼저 떠올린다.
- "빼야 할 값(K)만 건너뛴다"를 `if (i == k) continue;`로 쓰고, 더하기는 그 아래에 둔다.
```

**3) 짝수 자리 건너뛰기** · Medium

- **요구사항**: 1부터 N까지 세는데, "홀수 번째로 만나는 수"만 출력한다. 즉 1은 출력, 2는 건너뛰기, 3은 출력, 4는 건너뛰기 식이다. `continue`로 짝수 자리를 건너뛴다.
- **입력**: 정수 N (1 이상 20 이하)
- **출력**: 홀수 번째 수들을 공백으로 구분해 한 줄에 출력 (마지막에 공백/줄바꿈 형식은 자유)
- **예제**: `6` → `1 3 5` / `1` → `1`
- **셀프체크**: 여기서 "짝수 번째"는 값이 짝수인 것과 같다(1부터 1씩 세므로). 하지만 함정: 만약 시작을 0이나 다른 수부터 세면 결과가 달라진다. 지금은 1부터 세므로 값이 짝수인 것을 건너뛰면 된다.

```runner
@@SOLUTION
#include <iostream>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    string result = "";
    for (int i = 1; i <= n; i++) {
        if (i % 2 == 0) {
            continue;
        }
        if (result == "") {
            result = to_string(i);
        } else {
            result = result + " " + to_string(i);
        }
    }
    cout << result << "\n";
    return 0;
}
@@TESTS
--IN
6
--OUT
1 3 5
--IN
1
--OUT
1
@@EXPL
**이 풀이의 새 문법**

- `to_string(값)`: 정수 등을 문자열(`string`)로 바꿔 주는 함수. `#include <string>`이 필요하다.

(1) 접근 개념

- 1부터 세면서 짝수 번째(= 값이 짝수)는 건너뛰고 홀수만 공백으로 이어 붙여 한 줄에 출력한다. 건너뛰기는 `continue`, 한 줄 출력은 문자열을 만들어 마지막에 한 번만 `cout` 하는 방식이 깔끔하다.

(2) 코드 진행

- 결과를 담을 빈 문자열 `result`를 준비한다.
- 1..N을 돌며 `i % 2 == 0`이면 `continue`로 건너뛴다.
- 남은 홀수는 문자열에 붙인다. 아직 비어 있으면 그냥 그 수를(`to_string(i)`로 문자열로 바꿔), 이미 값이 있으면 앞에 공백을 넣어 이어 붙인다(그래야 수 사이에만 공백이 들어간다).
- 반복이 끝나면 완성된 `result`를 한 번 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "짝수 번째 = 값이 짝수"임을 확인하고 건너뛸 조건을 `i % 2 == 0`으로 정한다.
- 한 줄에 공백으로 이어 붙이려면 "첫 값이냐 아니냐"를 구분해 공백을 앞에 붙일지 정한다.
- 숫자를 문자열에 붙일 때는 `to_string`으로 바꿔야 한다. 반복 안에서 계속 출력하지 않고, 문자열을 다 만든 뒤 마지막에 한 번만 출력한다.
```

## L14. break문

**개념**

- `break`는 반복문을 **즉시 완전히 끝내고** 반복문 밖으로 빠져나오는 명령이다.
- `continue`가 "이번 회차만 건너뛰기"라면, `break`는 "반복 자체를 그만두기"다.
- 원하는 값을 찾았거나, 더 반복할 필요가 없을 때 `if`와 함께 자주 쓴다.
- `break`를 만나면 뒤에 남은 반복 값들은 아예 실행되지 않는다.

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i < 100; i++) {
        if (i == 4) {
            break;      // i가 4가 되는 순간 반복 종료
        }
        cout << i << " ";
    }
    // 출력: 1 2 3 (4 이후는 실행되지 않음)
    return 0;
}
```

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 1;
    while (true) {          // 조건이 항상 참이라도
        cout << i << " ";
        if (i == 3) {
            break;          // 조건을 만족하면 빠져나온다
        }
        i++;
    }
    // 출력: 1 2 3
    return 0;
}
```

**그림으로 보기**

```text
   for (int i = 1; i < 100; i++)
        |
        v
   +-------------+  true
   |  i == 4 ?   |--------> break ---------+   // leave the loop
   +------+------+                         |
          | false                          |
          v                                |
       cout << i;                          |
          |                                v
          +--------> next i           after the loop

   i    :  1   2   3   4   5 ... 99
   out  :  1   2   3   X   .     .            // X = break, . = never
```

**왜 이렇게 되는가**

- `continue`와 `break`의 차이는 "어디로 뛰는가" 하나다. `continue`는 이번 회차의 끝(다음 값)으로, `break`는 **반복문 전체의 밖**으로 뛴다.

- 그래서 `break` 뒤의 남은 값들은 아예 만들어지지도 않는다. "찾으면 끝"인 문제에서 검사 횟수를 크게 줄여 준다.

- `break`는 자기가 속한 **가장 안쪽 반복문 하나**만 빠져나온다. 반복이 겹쳐 있으면 바깥 반복은 계속 돈다.

- `while (true)`처럼 스스로 멈추지 않는 반복에서는 `break`가 유일한 출구다.

- C++ 함정. `break`는 `switch` 안에서는 "이 `case`를 끝낸다"는 뜻이다. 반복문 안의 `switch` 안에서 `break`를 쓰면 반복문이 아니라 `switch`만 빠져나온다.

```cpp
// 함정: switch 안의 break 는 반복문을 끝내지 않는다
for (int i = 1; i <= 5; i++) {
    switch (i) {
        case 3:
            break;          // switch 만 빠져나온다 - 반복은 계속된다
    }
    cout << i << " ";       // 1 2 3 4 5  (3에서 멈추지 않는다)
}

// 반복문을 끝내려면 switch 밖에서 판단한다
for (int i = 1; i <= 5; i++) {
    if (i == 3) { break; }
    cout << i << " ";       // 1 2
}
```

**문제**

**1) 처음으로 넘는 순간** · Easy

- **요구사항**: 1부터 순서대로 정수를 출력하다가, 출력할 수가 N을 넘는 순간(N보다 커지면) 반복을 멈추는 프로그램을 작성하라. `break`를 사용한다.
- **입력**: 정수 N (1 이상 50 이하)
- **출력**: 1부터 N까지 한 줄에 하나씩. (N을 넘는 순간 멈추므로 결과적으로 1..N이 출력된다)
- **예제**: `3` → `1` `2` `3` / `1` → `1`
- **셀프체크**: "N을 넘으면 멈춘다"는 조건을 `i > N`으로 잡되, 넘은 그 값은 출력하지 않아야 한다. 출력 후 검사할지, 검사 후 출력할지 순서 주의.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int i = 1;
    while (true) {
        if (i > n) {
            break;
        }
        cout << i << "\n";
        i++;
    }
    return 0;
}
@@TESTS
--IN
3
--OUT
1
2
3
--IN
1
--OUT
1
@@EXPL
(1) 접근 개념

- 1부터 세다가 "N을 넘는 순간" 멈춘다. 넘은 값은 출력하면 안 되므로, 출력하기 전에 먼저 "이 값이 N을 넘었는지" 검사하고, 넘었으면 `break`로 빠져나온다.

(2) 코드 진행

- i를 1로 시작하고 `while (true)`로 무한 반복을 연다.
- 매 회차 맨 앞에서 `if (i > n) break;` — i가 N보다 크면 즉시 반복을 끝낸다(그래서 넘은 값은 출력되지 않는다).
- 넘지 않았으면 `cout << i << "\n"`으로 출력하고 `i++`로 다음 수로 넘어간다.

(3) 스스로 다시 짤 때 생각 순서

- "출력하면 안 되는 값"이 있으면 검사를 출력보다 앞에 둔다.
- 종료 조건 `i > n`을 반복 시작 부분에서 확인하고 참이면 `break`.
- 마지막에 `i++`를 잊지 말 것(안 하면 무한 반복).
```

**2) 첫 배수 찾기** · Medium

- **요구사항**: N보다 큰 정수 중에서 K의 배수가 처음으로 나오는 수를 찾아 출력하라. N+1부터 하나씩 검사하다가 찾으면 `break`로 멈춘다.
- **입력**: 두 정수 N, K가 공백을 사이에 두고 주어진다. (1 ≤ N ≤ 1000, 2 ≤ K ≤ 100)
- **출력**: N보다 큰 K의 배수 중 가장 작은 수
- **예제**: `10 4` → `12` / `12 4` → `16`
- **셀프체크**: "N보다 큰"이므로 N 자신은 후보가 아니다. `12 4`에서 12는 제외되고 다음 배수 16이 답. 배수 판정은 `i % K == 0`.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int n, k;
    cin >> n >> k;
    int i = n + 1;
    while (true) {
        if (i % k == 0) {
            cout << i << "\n";
            break;
        }
        i++;
    }
    return 0;
}
@@TESTS
--IN
10 4
--OUT
12
--IN
12 4
--OUT
16
@@EXPL
(1) 접근 개념

- "N보다 큰 K의 배수 중 가장 작은 수"를 찾는다. N 다음 수(N+1)부터 하나씩 올라가며 처음으로 K의 배수가 되는 순간을 잡으면 그게 가장 작은 답이다. 찾는 즉시 `break`.

(2) 코드 진행

- 두 수를 `cin >> n >> k`로 읽는다.
- 후보를 `i = n + 1`부터 시작한다(N 자신은 후보 아님).
- `while (true)` 안에서 `i % k == 0`이면 그 i를 출력하고 `break`한다.
- 아니면 `i++`로 다음 후보로 올라간다.

(3) 스스로 다시 짤 때 생각 순서

- "N보다 큰"이니 시작을 N이 아니라 N+1로 잡는다.
- 배수 판정은 `i % k == 0`.
- 작은 것부터 검사하니 처음 만난 배수가 곧 최솟값 → 찾자마자 출력하고 `break`.
```

**3) 누적합이 처음 넘을 때까지** · Hard

- **요구사항**: 1, 2, 3, ... 을 차례로 더해 나가다가, 누적 합이 처음으로 M 이상이 되는 순간의 "마지막으로 더한 수"를 출력하라. `break`를 사용한다.
- **입력**: 정수 M (1 이상 10000 이하)
- **출력**: 누적 합이 M 이상이 되게 만든, 마지막으로 더한 수
- **예제**: `10` → `4` (1+2+3+4=10, 여기서 처음 10 이상) / `6` → `3` (1+2+3=6)
- **셀프체크**: 합 변수를 0으로 시작하고 i를 1부터 더한다. `total >= M`이 되는 순간의 i가 답. `10`은 1+2+3=6(부족)→+4=10(도달)이라 4. `M=1`이면 1을 더하는 순간 도달하므로 답은 1.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int m;
    cin >> m;
    int total = 0;
    int i = 0;
    while (true) {
        i++;
        total += i;
        if (total >= m) {
            cout << i << "\n";
            break;
        }
    }
    return 0;
}
@@TESTS
--IN
10
--OUT
4
--IN
6
--OUT
3
@@EXPL
(1) 접근 개념

- 1, 2, 3, ...을 순서대로 더해 가다가 누적 합이 처음 M 이상이 되는 순간을 잡는다. 그 순간 "마지막으로 더한 수"가 답이므로, 더한 직후에 합을 검사한다.

(2) 코드 진행

- `total`을 0, `i`를 0으로 시작한다.
- `while (true)` 안에서 먼저 `i++`로 더할 다음 수를 만들고, `total += i`로 누적한다.
- `total >= m`이면 방금 더한 i를 출력하고 `break`.

(3) 스스로 다시 짤 때 생각 순서

- "마지막으로 더한 수"가 답이니, i를 1 늘리고 → 더하고 → 검사하는 순서로 둔다.
- 검사는 더한 뒤에 해야 그 회차의 i가 답이 된다.
- M=1이면 첫 회차(1을 더함)에서 바로 도달 → 답 1이 되는지 머릿속으로 확인.
```

## L15. Infinite Loop

**개념**

- 무한 루프(Infinite Loop)는 종료 조건 없이 **끝없이 반복되는** 반복문이다. 보통 `while (true)`로 만든다.
- `while (true)`는 조건이 항상 참이므로 스스로 멈추지 않는다. 반드시 안에서 `break`로 빠져나갈 길을 만들어야 한다.
- "언제 멈출지 미리 정하기 어렵고, 반복 도중의 상황을 보고 멈추고 싶을 때" 유용하다.
- `break` 없이 무한 루프를 만들면 프로그램이 영원히 멈추지 않으니(실수), 항상 종료 조건을 챙긴다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int count = 0;
    while (true) {
        count++;
        cout << count << " ";
        if (count == 5) {
            break;          // 5까지 세고 종료
        }
    }
    // 출력: 1 2 3 4 5
    return 0;
}
```

> 선행: 입력을 여러 번 받는 문제에서는 반복 안에서 매번 `cin`으로 값을 받아 처리하고, 특정 값이 들어오면 `break`로 멈추는 방식으로 무한 루프를 자주 쓴다.

**그림으로 보기**

```text
   while (true) {                     // condition is always true
   +--------------------+
   |   body             |
   |   if (done) {      |
   |       break; ------+------> out of the loop
   |   }                |
   |   ( more body )    |
   +---------+----------+
             |
             +--> back to the top, forever
```

`while (true)` 자체에는 멈추는 장치가 없다. **반드시 도달하는 `break`가 하나 있어야** 반복이 끝난다.

**손으로 따라가기**

위 예시(`count`를 세다 5에서 멈추기)를 회차별로 본다.

| 회차 | 회차 시작 `count` | `count++` 후 | 출력 | `count == 5` | 행동 |
| --- | --- | --- | --- | --- | --- |
| 1 | 0 | 1 | `1` | 거짓 | 다시 위로 |
| 2 | 1 | 2 | `2` | 거짓 | 다시 위로 |
| 3 | 2 | 3 | `3` | 거짓 | 다시 위로 |
| 4 | 3 | 4 | `4` | 거짓 | 다시 위로 |
| 5 | 4 | 5 | `5` | 참 | `break` |

`break` 검사가 출력 **뒤**에 있어서 5도 찍히고 나서 멈춘다. 검사를 출력 앞으로 옮기면 5가 빠진다.

**왜 이렇게 되는가**

- `while (조건)`은 종료 판단이 **맨 위 한 곳**에서만 일어난다. `while (true)` + `break`는 그 판단을 본문 아무 자리로나 옮길 수 있게 해 준다.

- 그래서 "값을 일단 받아 보고 나서 끝낼지 정한다"처럼 **한 번은 반드시 실행해야 하는** 상황에 잘 맞는다.

- 대신 종료 지점이 눈에 덜 띈다. 무한 루프를 쓸 때는 `break`가 몇 개이고 각각 언제 걸리는지를 손으로 확인하는 습관이 필요하다.

- C++에서는 `for (;;)`도 `while (true)`와 완전히 같은 무한 루프다. 조건 칸을 비우면 참으로 취급하기 때문이다. 둘 중 아무거나 써도 되지만 뜻이 분명한 `while (true)`를 권한다.

```cpp
// 함정: break 로 가는 길이 조건에 막혀 도달하지 못한다
int count = 0;
while (true) {
    count += 2;                     // 2씩 늘어난다
    if (count == 5) { break; }      // 5를 정확히 밟지 못해 영원히 참이 안 된다
}
// 고침: 종료 검사는 부등호로
int c2 = 0;
while (true) {
    c2 += 2;
    if (c2 >= 5) { break; }         // 밟든 건너뛰든 넘어서면 멈춘다
}
```

**문제**

**1) 5의 배수가 나올 때까지** · Easy

- **요구사항**: `while (true)`로 무한 루프를 만들고, 1부터 1씩 증가시키며 출력하다가 5의 배수를 만나면 그 수까지 출력하고 멈춰라.
- **입력**: 없음
- **출력**: `1` `2` `3` `4` `5` (각각 다른 줄)
- **예제**: (입력 없음) → `1` `2` `3` `4` `5`
- **셀프체크**: 5의 배수(`i % 5 == 0`)를 만나면 그 수를 출력한 뒤 `break`. 출력과 검사의 순서를 바꾸면 5가 빠지거나 6까지 나올 수 있으니 확인.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {

    while (true) {
        cout << i << "\n";
        if (i % 5 == 0) {

    }
    return 0;
}
@@TESTS
--IN

--OUT
1
2
3

@@EXPL
(1) 접근 개념

- 입력 없이 1부터 세며 출력하다가 5의 배수를 "출력까지 한 뒤" 멈춘다. 그래서 먼저 출력하고, 그 값이 5의 배수인지 검사해 맞으면 `break`한다.

(2) 코드 진행

- i를 1로 시작하고 `while (true)`로 무한 반복을 연다.
- 매 회차 `cout << i << "\n"`으로 먼저 출력한다.
- 그다음 `if (i % 5 == 0) break;` — 방금 출력한 수가 5의 배수면 멈춘다.
- 아니면 `i++`로 다음 수로 넘어간다.

(3) 스스로 다시 짤 때 생각 순서

- "그 수까지 출력하고 멈춘다"이므로 출력 → 검사 순서로 둔다.
- 종료 조건은 `i % 5 == 0`.

```

**2) 목표값에 도달하기** · Medium

- **요구사항**: 0에서 시작해 매번 K씩 더해가며 값을 출력한다. 값이 T 이상이 되면 그 값을 출력하고 무한 루프를 멈춰라. `while (true)`와 `break`를 사용한다.
- **입력**: 두 정수 K, T가 공백을 사이에 두고 주어진다. (1 ≤ K ≤ 100, 0 ≤ T ≤ 1000)
- **출력**: 0, K, 2K, ... 를 T 이상이 될 때까지 한 줄에 하나씩 출력
- **예제**: `3 10` → `0` `3` `6` `9` `12` / `5 5` → `0` `5`
- **셀프체크**: 값 변수를 0으로 시작. 매 회차에 출력 후 `value >= T`이면 `break`. `3 10`에서 9는 아직 10 미만이라 출력 후 계속, 12에서 처음 10 이상이 되어 출력하고 멈춘다. `5 5`는 0(미만)→5(도달)이라 0과 5만 나온다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int k, t;
    cin >> k >> t;
    int value = 0;
    while (true) {
        cout << value << "\n";
        if (value >= t) {
            break;
        }
        value += k;
    }
    return 0;
}
@@TESTS
--IN
3 10
--OUT
0
3
6
9
12
--IN
5 5
--OUT
0
5
@@EXPL
(1) 접근 개념

- 0에서 시작해 K씩 더한 값을 모두 출력하되, 값이 T 이상이 되면 그 값까지 찍고 멈춘다. 0부터 반드시 출력해야 하므로 "출력 → 검사 → 증가" 순서가 자연스럽다.

(2) 코드 진행

- 두 수를 `cin >> k >> t`로 읽고 `value`를 0으로 시작한다.
- `while (true)`에서 먼저 `cout << value << "\n"`으로 현재 값을 출력한다.
- `value >= t`이면 `break`(방금 T에 도달/초과한 값까지 출력됨).
- 아니면 `value += k`로 다음 값을 만든다.

(3) 스스로 다시 짤 때 생각 순서

- "0도 출력해야 한다"를 먼저 떠올려 출력을 회차 맨 앞에 둔다.
- 종료 판정 `value >= t`는 출력한 뒤에 하고, 참이면 `break`.
- 증가 `value += k`는 검사 뒤(계속 도는 경우)에만 실행되게 배치한다.
```

**3) 자릿수 세기** · Hard

- **요구사항**: 양의 정수 N의 자릿수(몇 자리 수인지)를 구하라. N을 10으로 계속 나누어(정수 나눗셈) 0이 될 때까지 세면 자릿수가 된다. `while (true)`와 `break`로 구현한다.
- **입력**: 양의 정수 N (1 이상 1,000,000 이하)
- **출력**: N의 자릿수
- **예제**: `7` → `1` / `100` → `3` / `9999` → `4`
- **셀프체크**: 세는 변수를 0으로 시작하고, 매번 자릿수를 1 늘린 뒤 `n /= 10`. N이 0이 되면 `break`. 함정: N이 처음부터 0이 되지 않게, 한 자리 수(예 7)도 반드시 1이 나와야 한다. C++에서 `int / int`는 몫만 남는 정수 나눗셈이다(선행: Ch3 사칙연산에서 배운 몫 연산).

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int count = 0;
    while (true) {
        count++;
        n /= 10;
        if (n == 0) {
            break;
        }
    }
    cout << count << "\n";
    return 0;
}
@@TESTS
--IN
7
--OUT
1
--IN
9999
--OUT
4
@@EXPL
(1) 접근 개념

- 자릿수는 "10으로 몇 번 나눠야 0이 되는가"와 같다. 나눌 때마다 자리 하나가 사라지므로, 나눈 횟수를 세면 그게 자릿수다. 한 자리 수도 한 번은 나눠야 0이 되므로 최소 1이 나온다.

(2) 코드 진행

- `count`를 0으로 시작한다.
- `while (true)`에서 먼저 `count++`로 이번에 자리 하나를 세고, `n /= 10`으로 맨 끝 자리를 없앤다(C++의 정수 나눗셈이라 소수점이 버려진다).
- 나눈 결과 `n == 0`이면 `break`.
- 반복이 끝나면 `count`가 자릿수다.

(3) 스스로 다시 짤 때 생각 순서

- "10으로 나눈 횟수 = 자릿수"라는 관계를 먼저 세운다.
- 세기(`count++`)와 나누기(`n /= 10`)를 한 회차에 함께 하고, 그 뒤에 0인지 검사한다.
- 세기를 나누기보다 앞에 둬야 7 같은 한 자리 수도 1로 세어진다.
```

## L16. 언제 끝날지 모르는 상황에서의 loop

**개념**

- 반복 횟수를 미리 알 수 없고, **입력이나 조건에 따라 끝나는 시점이 달라지는** 반복을 말한다.
- 이럴 때는 `for`(정해진 횟수)보다 `while`이 자연스럽다. "특정 조건이 될 때까지 계속"을 표현한다.
- 대표 방식 1: `while` 조건에 종료 기준을 직접 쓴다. 예) `while (x != 0)` (0이 들어오면 멈춤).
- 대표 방식 2: `while (true)`로 돌리다가 종료 신호(특정 입력 값 등)를 만나면 `break`.
- 종료를 알리는 특별한 값을 "감시 값(센티넬)"이라고 부르며, 그 값 자체는 보통 처리하지 않고 멈춘다.

```cpp
// 0이 입력되면 종료, 그전까지 입력한 수를 모두 더하기
#include <iostream>
using namespace std;

int main() {
    int total = 0;
    while (true) {
        int n;
        cin >> n;
        if (n == 0) {       // 0은 종료 신호(더하지 않음)
            break;
        }
        total += n;
    }
    cout << total << "\n";
    return 0;
}
```

> 선행: 입력이 몇 개 올지 모를 때는 위처럼 무한 루프 안에서 매번 `cin`으로 받고, 약속된 종료 값이 오면 멈춘다.

**그림으로 보기**

```text
   input stream :  5   3   2   0   (no more)
                   |   |   |   |
                   v   v   v   v
   total        :  5   8   10  --            // 0 is NOT added
                                |
                                +--> break, then print total = 10
```

종료를 알리는 값(여기서는 `0`)은 데이터가 아니라 **신호**다. 그래서 처리하지 않고 그 자리에서 빠져나온다.

**손으로 따라가기**

| 회차 | 읽은 값 | `n == 0` | 행동 | 회차 끝 `total` |
| --- | --- | --- | --- | --- |
| 1 | 5 | 거짓 | 더하기 | 5 |
| 2 | 3 | 거짓 | 더하기 | 8 |
| 3 | 2 | 거짓 | 더하기 | 10 |
| 4 | 0 | 참 | `break` | 10 (그대로) |

종료 검사가 더하기보다 **앞**에 있어야 신호 값이 결과에 섞이지 않는다.

**왜 이렇게 되는가**

- 반복 횟수를 미리 셀 수 있으면 `for`, 없으면 `while`이다. 판단 기준은 "반복을 시작하기 전에 총 횟수를 적을 수 있는가" 하나다.

- 감시 값 방식은 데이터 안에 "끝"이라는 신호를 섞어 보내는 것이다. 신호는 처리 대상이 아니므로, 읽자마자 검사하고 빠져나가야 한다.

- `while (true)` + `break` 대신 `while (n != 0)`으로 쓸 수도 있다. 다만 그러려면 첫 값을 반복 밖에서 미리 한 번 읽어 둬야 해서 읽는 코드가 두 군데로 갈라진다. 입문 단계에서는 `while (true)` 쪽이 실수가 적다.

- C++ 함정. 감시 값이 아예 없이 입력이 끝나 버리는 경우가 있다. 이때 `cin >> n;`은 실패하고 `n`을 **바꾸지 않은 채** 돌아오므로, 마지막 값이 그대로 남아 무한 반복이 된다. 입력이 끝날 때까지 읽는 문제에서는 `cin >> n` 자체를 조건으로 쓴다.

```cpp
// 감시 값이 있을 때: 신호를 만나면 멈춘다
int total = 0;
while (true) {
    int n;
    cin >> n;
    if (n == 0) { break; }
    total += n;
}

// 감시 값이 없을 때: 더 읽을 것이 없으면 cin 이 거짓이 된다
int total2 = 0, x;
while (cin >> x) {          // 입력이 끝나면 조건이 거짓
    total2 += x;
}
```

```runner
(2) 코드 진행

- 합 `total`을 0으로 시작한다.
```

**2) 목표 점수 도달까지 라운드 수** · Medium

- **요구사항**: 매 라운드마다 얻은 점수를 한 줄에 하나씩 입력받아 누적한다. 누적 점수가 처음으로 G 이상이 되면 몇 번째 라운드였는지(라운드 수)를 출력하라.
- **입력**: 첫 줄에 목표 점수 G (1 이상 10000 이하). 다음 줄부터 각 라운드 점수(정수)가 한 줄에 하나씩 주어진다. 목표 도달 전까지 입력은 충분히 주어진다고 가정한다.
- **출력**: 누적 점수가 G 이상이 된 시점의 라운드 번호
- **예제**: `G=10`, 점수 `4` `3` `5` → `3` (4→7→12, 3라운드에서 처음 10 이상) / `G=5`, 점수 `5` → `1`
- **셀프체크**: 라운드 수를 세는 변수를 매 입력마다 1 늘린다. `total >= G`가 되는 순간 `break` 후 라운드 수 출력. G에 딱 맞게 도달해도(예: 정확히 10) 포함이다.

```runner
(2) 코드 진행

- 첫 줄에서 목표 `g`를 읽고, `total`과 `rounds`를 0으로 시작한다.

(3) 스스로 다시 짤 때 생각 순서

- 누적한 뒤에 `>= g`를 검사해야 그 라운드가 도달 라운드로 잡힌다.
```

**3) 몸무게가 목표 이하가 될 때까지** · Hard

- **요구사항**: 현재 몸무게 W에서 매주 P만큼 줄어든다. 몸무게가 목표 T 이하가 되려면 몇 주가 걸리는지 출력하라. (한 주가 지날 때마다 W가 P씩 감소)
- **입력**: 세 정수 W, T, P가 공백을 사이에 두고 주어진다. (1 ≤ T ≤ W ≤ 1000, 1 ≤ P ≤ 100)
- **출력**: W가 T 이하가 되는 데 필요한 최소 주 수
- **예제**: `100 90 3` → `4` (100→97→94→91→88, 4주째에 90 이하) / `50 50 5` → `0` (이미 목표 이하)
- **셀프체크**: 주 수를 0으로 시작. 시작부터 이미 `W <= T`면 0주다(반복 안 돎). 그 외에는 매주 `W -= P` 하고 주 수 1 증가, `W <= T`가 되면 멈춘다. `100 90 3`은 91까지는 90 초과라 계속, 88에서 도달해 4주. 정확히 T가 되어도 도달로 본다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int w, t, p;
    cin >> w >> t >> p;
    int weeks = 0;
    while (true) {
        if (w <= t) {
            break;
        }
        w -= p;
        weeks++;
    }
    cout << weeks << "\n";
    return 0;
}
@@TESTS
--IN
100 90 3
--OUT
4
--IN
50 50 5
--OUT
0
@@EXPL
(1) 접근 개념

- 매주 P만큼 줄여 목표 T 이하가 되는 데 걸리는 주 수를 센다. "이미 목표 이하면 0주"라는 경계가 있으므로, 회차 시작에서 먼저 `w <= t`인지 검사하고 참이면 바로 멈춘다.

(2) 코드 진행

- 세 수를 `cin >> w >> t >> p`로 읽고 `weeks`를 0으로 시작한다.
- `while (true)`에서 먼저 `if (w <= t) break;` — 이미(또는 이번에) 목표 이하면 끝낸다.
- 아니면 `w -= p`로 한 주 감량하고 `weeks++`로 주 수를 센다.
- 반복이 끝나면 `weeks`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "시작부터 조건을 만족할 수 있다"면 검사를 회차 맨 앞(감량 전)에 둔다.
- 감량과 세기를 한 회차에 함께 하되, 다음 회차 시작의 검사로 종료를 판단한다.
- `50 50 5`처럼 처음부터 `w <= t`면 한 번도 안 줄이고 0이 나오는지 확인.
```

## L17. 단 하나라도 만족하는 경우

**개념**

- 여러 값 중에서 "**하나라도** 어떤 조건을 만족하는 게 있는가?"를 확인하는 패턴이다. (수학의 "존재한다"에 해당)
- 방법: 먼저 "없다"고 가정하는 표시 변수(플래그)를 준비한다. 예) `bool found = false;`.
- 반복하며 조건을 만족하는 값을 하나라도 만나면 `found = true`로 바꾸고, 더 볼 필요가 없으면 `break`로 멈춰도 된다.
- 반복이 끝난 뒤 `found`가 참이면 "하나라도 있음", 거짓이면 "하나도 없음"이다.
- 핵심: 하나만 찾으면 결론이 나므로, 굳이 끝까지 다 보지 않아도 된다(`break`로 효율적).

```cpp
// 1..N 중에 7의 배수가 하나라도 있는가?
#include <iostream>
using namespace std;

int main() {
    int N = 20;
    bool found = false;
    for (int i = 1; i <= N; i++) {
        if (i % 7 == 0) {
            found = true;
            break;
        }
    }
    if (found) {
        cout << "YES" << "\n";
    } else {
        cout << "NO" << "\n";
    }
    return 0;
}
```

> 선행: 참/거짓을 담는 값은 `true`/`false`이며(Ch4 조건문에서 사용), 이런 표시 변수를 흔히 "플래그"라 부른다. C++에서는 `bool` 타입에 담는다.

**그림으로 보기**

```text
   N = 9 , looking for a divisor among 2 .. N-1
   i        :  2       3       4  ...  8
   9 % i    :  1       0       .       .      // '.' = not reached
   found    :  F       T      (break)
                       ^
                       one hit is enough -> stop early
```

**왜 이렇게 되는가**

- "하나라도 있는가"는 하나만 찾으면 답이 정해진다. 그래서 플래그를 `false`(아직 없음)로 시작하고, 찾는 순간 `true`로 뒤집은 뒤 `break`한다.

- 반복이 끝까지 돌았는데도 플래그가 `false`라면, 그것은 "**하나도** 없었다"는 증거다. 끝까지 돌았다는 사실 자체가 결론의 근거가 된다.

- 초기값과 찾는 방향은 항상 반대다. `false`로 시작해 `true`를 찾는다. 초기값을 `true`로 두면 아무것도 검사하지 않은 상태가 이미 "찾았다"가 되어 버린다.

- `break`는 답을 바꾸지 않고 **속도만** 바꾼다. 빼도 정답은 같지만 검사 횟수가 크게 늘어난다.

- C++ 함정. 플래그를 반복문 **안에서** 선언하면 매 회차 새로 태어나므로 결과가 남지 않는다. 게다가 반복 뒤에서 쓰려 하면 컴파일 오류가 난다. 플래그는 반복 **밖**에서 만든다.

```cpp
// 함정: 플래그를 반복 안에서 선언했다
for (int i = 2; i < 9; i++) {
    bool found = false;          // 매 회차 false 로 되돌아간다
    if (9 % i == 0) { found = true; break; }
}
// cout << found;                // error: 'found' was not declared in this scope

// 고침: 반복 밖에서 선언한다
bool found = false;
for (int i = 2; i < 9; i++) {
    if (9 % i == 0) { found = true; break; }
}
cout << (found ? "YES" : "NO") << endl;
```

- 참·거짓을 담는 변수는 `bool`을 쓴다. `int found = 0;`으로도 되지만 `if (found = 1)`처럼 `=`를 하나만 쓰는 실수가 섞이기 쉬우니 `bool`이 안전하다.

**문제**

**1) 소수(prime) 판별** · Medium

- **요구사항**: 정수 N이 소수인지 판별하라. 2부터 N-1까지 중 N을 나누어떨어지게 하는 수가 "하나라도" 있으면 소수가 아니다.
- **입력**: 정수 N (2 이상 1000 이하)
- **출력**: 소수면 `YES`, 아니면 `NO`
- **예제**: `7` → `YES` / `9` → `NO` (9는 3으로 나누어떨어짐) / `2` → `YES`
- **셀프체크**: 나누어떨어지는 수를 하나라도 만나면 `break`. `2`는 `for (i = 2; i < 2; ...)`가 한 번도 안 돌아 나누는 수가 없으니 소수. 플래그 초기값과 최종 판정 방향을 헷갈리지 말 것.

```runner
@@SOLUTION

            break;
        }
    }
    if (found) {
        cout << "NO" << "\n";
    } else {
        cout << "YES" << "\n";
    }
    return 0;
}
@@TESTS

@@EXPL
(1) 접근 개념

- 소수는 2부터 N-1까지 중 N을 나누어떨어지게 하는 수가 "하나도" 없는 수다. 그런 수가 하나라도 있으면 소수가 아니므로, "약수를 찾았는가"를 플래그로 표시하고 찾는 즉시 `break`.

(2) 코드 진행

- `bool found = false`로 "아직 약수 못 찾음" 상태에서 시작한다.

- 반복 후 `found`가 참이면 약수가 있으니 `NO`, 거짓이면 소수라 `YES`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "하나라도 있으면"이므로 플래그를 false로 두고 조건 만족 시 true + break.
- 판정 방향에 주의: 약수를 "찾으면" 소수가 아님(NO)이다.
- N=2는 `for (i = 2; i < 2; ...)`가 조건이 처음부터 거짓이라 한 번도 안 돌아 found가 false → YES가 되는지 확인.
```

**2) 특정 숫자 포함 여부** · Easy

- **요구사항**: 정수 N을 입력받아, 그 수의 각 자리 숫자 중에 K라는 숫자가 하나라도 들어 있는지 판별하라.
- **입력**: 두 정수 N, K가 공백을 사이에 두고 주어진다. (1 ≤ N ≤ 1,000,000, 0 ≤ K ≤ 9)
- **출력**: 포함되어 있으면 `YES`, 아니면 `NO`
- **예제**: `3428 2` → `YES` / `555 4` → `NO` / `70 0` → `YES`
- **셀프체크**: `n % 10`으로 맨 끝 자리를 얻고 `n /= 10`으로 자리를 줄이며 검사(선행: L15에서 쓴 방식). 한 자리라도 K와 같으면 발견. `70 0`처럼 0을 찾는 경우도 정확히 잡히는지 확인.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int n, k;
    cin >> n >> k;
    bool found = false;
    while (true) {
        int digit = n % 10;
        if (digit == k) {
            found = true;
            break;
        }
        n /= 10;
        if (n == 0) {
            break;
        }
    }
    if (found) {
        cout << "YES" << "\n";
    } else {
        cout << "NO" << "\n";
    }
    return 0;
}
@@TESTS
--IN
3428 2
--OUT
YES
--IN
555 4
--OUT
NO
@@EXPL
(1) 접근 개념

- N의 각 자리 숫자를 하나씩 꺼내 K와 같은 게 하나라도 있는지 본다. 맨 끝 자리는 `n % 10`, 자리를 줄이는 건 `n /= 10`(L15에서 쓴 방식). 찾으면 즉시 멈춘다.

(2) 코드 진행

- `bool found = false`로 시작한다.
- `while (true)`에서 `int digit = n % 10`으로 끝자리를 얻고, `digit == k`면 `found = true`, `break`.
- 아니면 `n /= 10`으로 끝자리를 없앤 뒤, `n == 0`이면(자리 다 봤음) `break`.
- 반복 후 `found`에 따라 `YES`/`NO`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- 자릿수 분해는 "끝자리 얻기(% 10) → 자리 줄이기(/ 10)"의 반복이다.
- "하나라도"이므로 K와 같은 자리를 만나면 true + break.
- 0을 찾는 경우(예 70의 0)도, 자리가 실제로 0이면 `digit == k`로 잡히는지 확인한다.
```

**3) 세 수 중 짝수가 있나** · Easy

- **요구사항**: 세 정수를 한 줄에 공백으로 입력받아, 이 중 짝수가 하나라도 있으면 `YES`, 셋 다 홀수면 `NO`를 출력하라.

```runner
(2) 코드 진행

(3) 스스로 다시 짤 때 생각 순서

- 여러 값을 같은 방식으로 검사할 땐 배열 `arr[3] = {a, b, c}`에 담아 `for`로 도는 게 편하다.
- 짝수 판정 `x % 2 == 0`은 C++에서 음수에도 그대로 통한다(-4 % 2 == 0).
```

## L18. 모두 만족하는 경우

**개념**

- 여러 값이 "**모두** 어떤 조건을 만족하는가?"를 확인하는 패턴이다. (수학의 "모든"에 해당)
- 방법: 먼저 "모두 만족한다"고 가정하는 플래그를 준비한다. 예) `bool all_ok = true;`.
- 반복하며 조건을 **어기는** 값을 하나라도 만나면 `all_ok = false`로 바꾸고 `break`한다. (하나라도 어기면 "모두"는 깨진다)
- 반복이 끝난 뒤 `all_ok`가 참이면 "모두 만족", 거짓이면 "그렇지 않음"이다.
- "하나라도(L17)"와 정반대 시선: L17은 "만족하는 걸 찾으면 성공", L18은 "어기는 걸 찾으면 실패".

```cpp
// 1..N 이 모두 3의 배수인가? (당연히 대부분 아님 → false)
#include <iostream>
using namespace std;

int main() {
    int N = 5;
    bool all_ok = true;
    for (int i = 1; i <= N; i++) {
        if (i % 3 != 0) {       // 조건을 어기는 값 발견
            all_ok = false;
            break;
        }
    }
    if (all_ok) {
        cout << "YES" << "\n";
    } else {
        cout << "NO" << "\n";
    }
    return 0;
}
```

**그림으로 보기**

```text
   'at least one' (L17)          vs      'all' (L18)
   start : flag = false                  start : flag = true
   scan  : look for a HIT                scan  : look for a MISS
   hit   : flag = true,  break           miss  : flag = false, break
   end   : flag stays false              end   : flag stays true

   nums   :  2   3   4
   even?  :  T   F   .                   // '.' = not reached
   all_ok :  T   F  (break)
```

**왜 이렇게 되는가**

- "모든 값이 P다"의 반대는 "P가 아닌 값이 **하나라도** 있다"이다. 그래서 "모두"는 언제나 "하나라도"를 뒤집어 구현한다. 어기는 값 하나만 찾으면 결론이 난다.

- 그래서 초기값이 `true`다. 아직 아무것도 검사하지 않았다면 "어긴 것이 하나도 없다"가 참이기 때문이다. 값이 0개인 경우에도 이 규칙이 그대로 맞는다.

- 조건을 그대로 쓰지 말고 **어기는 조건**으로 뒤집어 쓰는 것이 요령이다. "모두 짝수"를 확인할 때 실제로 검사하는 것은 `x % 2 != 0`(홀수)이다.

- 이웃한 두 값을 비교할 때는 검사 횟수가 값의 개수보다 하나 적다. 값이 `n`개면 이웃 쌍은 `n - 1`개이기 때문이다.

- C++ 함정. 조건을 뒤집을 때 `!`를 붙이는 자리를 헷갈리기 쉽다. `!(x % 2 == 0)`과 `x % 2 != 0`은 같지만, `!x % 2 == 0`은 `(!x) % 2 == 0`으로 읽혀 전혀 다른 뜻이 된다. `!`가 `%`보다 먼저 계산되기 때문이다.

```cpp
int x = 3;
cout << (!x % 2 == 0) << endl;      // (!3) % 2 == 0 -> 0 % 2 == 0 -> 1 (참)
cout << (!(x % 2 == 0)) << endl;    // 의도한 '짝수가 아니다' -> 1
cout << (x % 2 != 0) << endl;       // 가장 읽기 쉬운 형태 -> 1
```

- 드 모르간 법칙도 함께 기억해 두면 편하다. `!(A && B)`는 `!A || !B`, `!(A || B)`는 `!A && !B`다. "모두 만족"의 반대가 "하나라도 어김"이라는 말을 기호로 적은 것이 이것이다.

**문제**

**1) 모두 짝수인가** · Easy

**2) 오름차순으로 정렬돼 있나** · Medium

**3) N이 K의 거듭제곱인가** · Hard

- **요구사항**: 정수 N이 K의 거듭제곱(K, K², K³, ...) 중 하나인지 판별하라. N을 K로 계속 나누어(정수 나눗셈이 아니라 나누어떨어지는지) 결국 1이 되는지 확인한다. 나누는 도중 한 번이라도 나누어떨어지지 않으면 아니다.
- **입력**: 두 정수 N, K가 공백을 사이에 두고 주어진다. (1 ≤ N ≤ 1,000,000, 2 ≤ K ≤ 100)
- **출력**: 거듭제곱이면 `YES`, 아니면 `NO`
- **예제**: `27 3` → `YES` (3×3×3) / `16 2` → `YES` / `12 2` → `NO` (12→6→3, 3은 2로 안 나눠짐) / `1 5` → `YES` (K⁰=1로 봄)
- **셀프체크**: N을 K로 나누어떨어지는 동안 계속 `n /= K` 하고, 나누어떨어지지 않으면 `break`. 마지막에 N이 1이면 거듭제곱. 함정: `N=1`은 어떤 K에 대해서도 처음부터 1이라 `YES`. "모두 만족(매 단계 나누어떨어짐)"이 지켜져야 1에 도달함을 이해할 것.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int n, k;
    cin >> n >> k;
    bool all_ok = true;
    while (n != 1) {
        if (n % k != 0) {
            all_ok = false;
            break;
        }
        n /= k;
    }
    if (all_ok) {
        cout << "YES" << "\n";
    } else {
        cout << "NO" << "\n";
    }
    return 0;
}
@@TESTS
--IN
27 3
--OUT
YES
--IN
12 2
--OUT
NO
@@EXPL
(1) 접근 개념

- N이 K의 거듭제곱이면, K로 계속 나누어떨어지며 결국 1이 된다. 반대로 나누는 도중 한 번이라도 나누어떨어지지 않으면 거듭제곱이 아니다. "매 단계 나누어떨어짐(모두 만족)"이 1에 도달하기 위한 조건이다.

(2) 코드 진행

- 두 수를 `cin >> n >> k`로 읽고 `bool all_ok = true`로 시작한다.
- `while (n != 1)`로 n이 1이 될 때까지 반복한다.
- 회차마다 `n % k != 0`이면 나누어떨어지지 않는 것이라 `all_ok = false`, `break`.
- 나누어떨어지면 `n /= k`로 한 단계 줄인다.
- 반복 후 `all_ok`가 참이면(도중에 안 깨지고 n이 1까지 감) `YES`, 아니면 `NO`.

(3) 스스로 다시 짤 때 생각 순서

- "거듭제곱 = K로 계속 나눠 1 되기"라는 관계를 먼저 세운다.
- 나누기 전에 나누어떨어지는지(`n % k`) 검사해 어기면 실패로 확정.
- N=1이면 `while (n != 1)`이 처음부터 거짓 → 한 번도 안 돌고 all_ok가 true라 YES가 되는지 확인.
```
