> 개요: 이 챕터에서는 화면에 값을 보여 주는 `cout`을 익히고, 값을 담아 두는 변수와 기본 자료형, 여러 값을 원하는 형식으로 출력하는 법, 그리고 변수의 값을 바꾸고 옮기고 서로 교환하는 방법까지 배운다.

## L1. 기본 출력

**개념**

- 프로그램이 만든 결과를 사람이 볼 수 있게 화면에 보여 주는 것을 "출력"이라고 한다.
- C++에서는 `cout` 에 `<<`(스트림 삽입 연산자)로 값을 넘겨 출력한다. `cout` 을 쓰려면 맨 위에 `#include <iostream>` 이 필요하고, `std::` 없이 짧게 쓰려면 `using namespace std;` 를 선언한다.
- 글자(문자열)를 그대로 출력하려면 큰따옴표 `"..."` 로 감싼다. (문자 하나만 담는 `char` 는 작은따옴표 `'...'` 를 쓴다.)
- 숫자는 따옴표 없이 그대로 쓴다. `cout << 10;` 은 `10` 을 출력한다.
- `cout` 은 자동으로 줄을 바꾸지 않는다. 줄을 바꾸려면 개행 문자 `"\n"` 을 직접 붙여야 한다. 그래서 두 줄로 나오게 하려면 각 출력 끝에 `"\n"` 을 넣는다.
- 모든 실행 코드는 `int main() { ... return 0; }` 안에 쓴다.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello" << "\n";
    cout << 2025 << "\n";
    return 0;
}
```

위 코드의 출력:

```
Hello
2025
```

**그림으로 보기**

`cout <<` 는 값을 화면 쪽으로 흘려보내기만 한다. 줄을 바꾸는 일은 하지 않는다. 아래에서 `[NL]` 은 눈에 보이지 않는 줄바꿈 글자다.

```text
  code                          what cout sends out
  ---------------------------   --------------------------
  cout << "Hello";              H e l l o
  cout << "Hello" << "\n";      H e l l o [NL]
  cout << 2025 << "\n";         2 0 2 5 [NL]
```

`"\n"` 을 빠뜨리면 다음 출력이 같은 줄에 그대로 이어 붙는다. 자동으로 줄이 바뀌지 않는다는 점이 가장 중요하다.

```text
  cout << "Hello";        cout << "Hello" << "\n";
  cout << "World";        cout << "World" << "\n";

  screen                  screen
  +------------+          +------------+
  | HelloWorld |          | Hello      |
  +------------+          | World      |
                          +------------+
```

따옴표는 화면에 나오지 않는다. "여기부터 여기까지가 글자다"라고 컴파일러에게 알려 주는 표시일 뿐이다.

```text
  cout << "Hello";
          ^     ^
          |     + string ends here
          + string starts here

  cout << 2025;        // no quotes -> a number, not letters
```

**왜 이렇게 되는가**

- 컴파일러는 코드를 왼쪽부터 읽다가 `"` 를 만나면 "여기서 문자열이 시작된다"고 판단하고, 다음 `"` 를 만날 때까지를 한 덩어리 글자로 취급한다.
- 그래서 `cout << "He said "hi"";` 는 두 번째 `"` 에서 문자열이 끝났다고 보고, 남은 `hi""` 를 무엇으로 읽어야 할지 몰라 컴파일 오류를 낸다. 안쪽 따옴표를 그대로 찍고 싶으면 `\"` 로 적는다: `cout << "He said \"hi\"";`
- C++은 따옴표 종류에 따라 자료형이 달라진다. 큰따옴표 `"a"` 는 문자열, 작은따옴표 `'a'` 는 글자 하나(`char`)다. 그래서 `'ab'` 처럼 두 글자를 작은따옴표로 감싸면 안 된다.
- `cout` 이 줄을 바꾸지 않는 이유: `<<` 는 "받은 값을 그대로 출력 스트림에 넣어라"라는 요청일 뿐이라, 사람이 넣지 않은 글자를 마음대로 덧붙이지 않는다. 줄바꿈도 하나의 글자(`\n`)이므로 직접 넣어야 한다.
- `endl` 도 줄을 바꾸지만 매번 출력 버퍼를 비우는(flush) 일까지 한다. 출력이 수만 줄이 되면 이 비우기 때문에 눈에 띄게 느려지므로, 코딩테스트에서는 `"\n"` 을 쓰는 습관이 좋다.
- 숫자에 따옴표를 붙이지 않는 이유도 같다. 따옴표를 붙이면 "계산할 수 있는 수"가 아니라 "그냥 그렇게 생긴 글자"가 되어 버린다.

## L2. 변수와 자료형

**개념**

- 변수는 값을 담아 두는 "이름표가 붙은 상자"다. C++은 변수를 처음 만들 때 자료형을 함께 적어 선언한다. `int x = 5;` 는 `int`(정수)형 상자 `x` 에 값 `5` 를 넣는 것이다.
- `=` 는 "같다"가 아니라 "오른쪽 값을 왼쪽 이름에 넣어라"라는 뜻이다. (이걸 대입이라 한다.)
- 변수에 담긴 값은 그 이름만 써서 다시 꺼내 쓸 수 있다. `cout << x;` 는 `x` 가 담고 있는 값을 출력한다.
- 값에는 종류가 있고 이를 "자료형"이라 한다. 기초 자료형 세 가지:

- 정수형(int): 소수점이 없는 수. 예: `3`, `-7`, `0`
- 실수형(double): 소수점이 있는 수. 예: `3.14`, `-0.5`, `2.0`
- 문자열(string): 큰따옴표로 감싼 글자. 예: `"hi"`, `"12"` (`#include <string>` 이 필요하다.)

- 같은 겉모습이라도 자료형이 다를 수 있다. `5` 는 정수(int), `5.0` 은 실수(double), `"5"` 는 문자열(string)이다.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int age = 20;
    double pi = 3.14;
    string name = "Ann";
    cout << name << "\n";
    cout << age << "\n";
    return 0;
}
```

출력:

```
Ann
20
```

**그림으로 보기**

변수는 "이름표가 붙은 상자"다. C++은 상자를 만들 때 **어떤 종류의 값이 들어갈지(자료형)를 먼저 적는다.** 상자 안에는 값이, 상자 밖에는 이름과 자료형이 붙는다.

```text
  int age = 20;       double pi = 3.14;   string name = "Ann";

  +---------+         +---------+         +---------+
  |   20    |         |  3.14   |         |  "Ann"  |
  +---------+         +---------+         +---------+
      age                  pi                name        // name tag
      int                double              string      // data type
```

겉모습이 비슷해도 상자의 종류가 다르면 할 수 있는 일이 달라진다.

```text
   5     -> int     a number. 5 + 5 is 10
   5.0   -> double  a number that carries a decimal point
  "5"    -> string  letters. one "5" glued to another gives "55"
  '5'    -> char    ONE letter, kept as its code number 53
```

상자에는 정해진 크기가 있다. 크기를 넘는 값을 넣으면 오류가 나는 게 아니라 **값이 조용히 망가진다.**

```text
  int        about -2100000000 .. 2100000000
  long long  about -9200000000000000000 .. 9200000000000000000

  int a = 3000000000;         // too big -> wraps around, wrong value
  long long b = 3000000000;   // fits
```

**왜 이렇게 되는가**

- `int x = 5;` 의 `=` 는 수학의 "같다"가 아니라 **명령**이다. "오른쪽 값을 만들어 왼쪽 상자에 넣어라."
- 방향이 정해져 있다는 뜻이다. 그래서 `5 = x;` 는 오류다(왼쪽에는 이름이 와야 한다). 반대로 수학에서는 말이 안 되는 `x = x + 1;` 이 코드에서는 자연스럽다(L5에서 다룬다).
- C++이 자료형을 먼저 적게 하는 이유: 컴파일러는 상자를 만들 때 **몇 바이트를 잡을지, 그 안의 비트를 어떻게 읽을지**를 미리 정해 두어야 한다. 그래야 실행 중에 종류를 확인하는 비용이 사라져 빠르다.
- 그 대가로 종류가 다른 값을 넣으면 **말없이 맞춰 버린다.** `int n = 3.7;` 은 오류가 아니라 소수점 아래를 잘라 `3` 이 된다. 반올림이 아니라 버림이라는 점이 중요하다.
- 같은 `+` 기호도 자료형에 따라 뜻이 달라진다. `5 + 5` 는 `10` 이지만, `string` 끼리의 `+` 는 뒤에 이어 붙이기라 `"5"` 와 `"5"` 를 더하면 `"55"` 가 된다.
- 값을 넣지 않고 `int x;` 라고만 선언하면 상자 안에는 **아무 의미 없는 쓰레기 값**이 들어 있다. 실행할 때마다 값이 달라질 수 있으므로, 선언과 동시에 초기값을 적는 습관이 안전하다.

**문제**

```runner
(1) 접근 개념: 세 개의 값을 각각 이름표가 붙은 변수에 담고, 그 이름으로 다시 꺼내 출력한다. 값의 종류(문자열·정수·실수)에 맞게 자료형을 골라 선언한다.

(2) 코드 진행

- 각 값의 자료형(문자열·정수·실수)에 맞춰 `string`/`int`/`double` 을 고른다.
- 출력은 값이 아니라 변수 이름으로 한다(변수를 쓰는 목적).
```

**2) 자료형 구분하기** · Easy

- **요구사항**: 값 `7`(정수), `7.0`(실수), `"7"`(문자열)을 각각 변수에 담고, 세 값을 세 줄로 출력하라.
- **입력**: 없음
- **출력**: 세 줄에 걸쳐 각 변수의 값
- **예제**: (입력 없음) → 
```
7
7
7
```
- **셀프체크**: 정수 `7`, 문자열 `"7"` 은 화면에 똑같이 `7` 로 보인다. C++에서 `double` 값 `7.0` 은 `cout` 기본 출력이 소수점 없는 `7` 로 나온다는 점에 유의한다.

```runner
@@SOLUTION
#include <iostream>
#include <string>
using namespace std;

int main() {
    int a = 7;
```

## L3. 출력 형식

**개념**

- 한 줄에 여러 값을 함께 보여 주고 싶을 때, `cout` 에서 `<<` 로 값을 계속 이어 쓰면 된다. 예: `cout << "a" << "b";` → `ab`
- C++의 `<<` 는 값 사이에 공백을 자동으로 넣지 않는다. 값 사이를 띄우고 싶으면 공백 문자열 `" "` 를 직접 끼워 넣어야 한다. 예: `cout << "a" << " " << "b";` → `a b`
- 문자열과 숫자를 섞어서 이어 써도 된다. 자료형이 달라도 `<<` 로 이으면 함께 출력된다.
- 문자열끼리는 `+` 로 이어 붙일 수도 있다. 이때는 공백이 들어가지 않는다. 예: `string s = string("a") + "b";` → `ab`
- 정리하면, C++에서는 공백을 넣고 싶을 때 `<< " " <<` 로 직접 끼워 넣는다. 공백이 자동으로 생기지 않는다는 점에 유의한다.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "Ann";
    int age = 20;
    cout << name << " " << age << "\n";
    cout << "Age: " << age << "\n";
    return 0;
}
```

출력:

```
Ann 20
Age: 20
```

**그림으로 보기**

`<<` 는 값을 하나씩 차례로 흘려보낼 뿐, 값 **사이**에 아무것도 넣지 않는다. 공백이 필요하면 사람이 직접 끼워 넣어야 한다. 아래 칸 하나가 화면의 글자 한 칸이다.

```text
  string a = "Sea", b = "side";

  cout << a << " " << b;    +-+-+-+-+-+-+-+-+
                            |S|e|a| |s|i|d|e|   // the space was typed
                            +-+-+-+-+-+-+-+-+
                             0 1 2 3 4 5 6 7

  cout << a << b;           +-+-+-+-+-+-+-+
                            |S|e|a|s|i|d|e|     // nothing in between
                            +-+-+-+-+-+-+-+
                             0 1 2 3 4 5 6
```

라벨을 붙일 때 공백이 두 칸이 되는 사고는 여기서 생긴다. 문자열 안에도 공백을 넣고 `<< " " <<` 도 함께 쓴 경우다.

```text
  cout << "Age:" << " " << 20;    ->  A g e : _ 2 0     // _ marks a space
                                              ^
                                              from << " "

  cout << "Age: " << " " << 20;   ->  A g e : _ _ 2 0   // two spaces: wrong
                                              ^ ^
                                              | + from << " "
                                              + typed inside the string
```

`<<` 는 왼쪽부터 차례로 처리된다. 줄바꿈도 그 줄에서 흘려보낸 하나의 글자일 뿐이다.

```text
  cout << "a" << "b" << "\n" << "c";

  step 1  send  a
  step 2  send  b
  step 3  send  newline
  step 4  send  c

  screen
  +------+
  | ab   |
  | c    |
  +------+
```

**왜 이렇게 되는가**

- `cout << x` 는 "`cout` 에 `x` 를 흘려보내라"는 연산이고, 그 결과가 **다시 `cout`** 이다. 그래서 `cout << a << b` 는 `(cout << a) << b` 로 읽히며 얼마든지 이어 쓸 수 있다.
- 스트림은 받은 글자를 그대로 내보낼 뿐, 값 사이에 무엇을 넣을지 스스로 정하지 않는다. 그래서 공백은 언제나 사람이 `<< " " <<` 로 넣는다. 자동 공백이 없으니 두 칸이 되는 사고도 "내가 두 번 넣었나"만 확인하면 된다.
- 문자열끼리 `+` 로 잇는 것은 **한쪽이 `string` 일 때만** 된다. `"a" + "b"` 처럼 큰따옴표 리터럴 두 개를 더하면 컴파일 오류다. `string s = "a";` 로 만들어 두고 `s + "b"` 라고 쓰면 된다.
- 더 위험한 것은 `"Age: " + 20` 이다. 이건 컴파일 오류가 아니라 **문자열의 시작 위치를 20칸 옮기라**는 뜻으로 해석되어, 글자가 이상하게 잘려 나오거나 프로그램이 예측 불가능하게 동작한다.
- 정리하면 값을 나열해 보여 줄 때는 `<<` 하나로 통일하는 것이 가장 안전하다. 자료형이 섞여 있어도 `<<` 는 각 값을 알아서 글자로 바꿔 차례로 내보낸다.

## L4. 소수점 맞춰 출력

**개념**

- 실수를 출력할 때 소수점 아래 자릿수를 정해서 깔끔하게 보여 주고 싶을 때가 있다.
- C++에서는 `<iomanip>` 헤더의 `fixed` 와 `setprecision(n)` 을 함께 쓴다. `cout << fixed << setprecision(2);` 는 "이후 실수를 소수점 아래 2자리 고정 형식으로 출력하라"는 뜻이다.
- `fixed` 는 "소수점 아래 자릿수를 고정" 하라는 설정이고, `setprecision(2)` 의 숫자가 소수점 아래 자릿수다.
- 지정한 자릿수에 맞춰 반올림된다. 예: `3.14159` 를 `setprecision(2)` 로 하면 `3.14`.
- 정해진 자릿수보다 짧으면 `0` 으로 채운다. 예: `2.5` 를 `fixed << setprecision(3)` 로 하면 `2.500`.

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double pi = 3.14159;
    cout << fixed << setprecision(2) << pi << "\n";
    cout << fixed << setprecision(4) << pi << "\n";
    return 0;
}
```

출력:

```
3.14
3.1416
```

> 선행: `fixed` 와 `setprecision` 은 한 번 설정하면 이후 출력에 계속 적용된다. 지금은 "소수점 자릿수 맞추기" 용도로만 쓴다.

**그림으로 보기**

소수점 아래 자리에 번호를 매겨 두면 `setprecision` 이 무엇을 보고 결정하는지 눈에 보인다. **남길 자리 바로 다음 자리**가 5 이상이면 올림, 아니면 버림이다.

```text
  double pi = 3.14159;

        3 . 1 4 1 5 9
            ^ ^ ^ ^ ^
            1 2 3 4 5      // position after the decimal point

  fixed << setprecision(2)   keep 1..2 -> pos 3 = 1 -> 1 < 5  -> down
                             result: 3.14

  fixed << setprecision(4)   keep 1..4 -> pos 5 = 9 -> 9 >= 5 -> up
                             result: 3.1416      // pos 4 becomes 6
```

자리가 모자랄 때는 `0` 으로 채운다. 값이 커지는 게 아니라 보이는 모양만 채워진다.

```text
  double price = 5;    fixed << setprecision(2)  ->  5 . 0 0
                                                         ^ ^
                                                         filled with 0

  double v = 2.5;      fixed << setprecision(3)  ->  2 . 5 0 0
```

`fixed` 를 빼면 숫자의 뜻이 완전히 달라진다. `fixed` 가 있어야 "소수점 아래 자릿수"이고, 없으면 "전체 유효숫자 개수"다.

```text
  double x = 3.14159;

  cout << x;                              3.14159   // default: 6 digits
  cout << setprecision(2) << x;           3.1       // 2 digits in total
  cout << fixed << setprecision(2) << x;  3.14      // 2 after the dot
```

한 번 설정하면 그 뒤의 출력에 계속 적용된다는 점도 기억한다.

```text
  cout << fixed << setprecision(2);

  cout << 1.5 << "\n";        1.50
  cout << 2 << "\n";          2       // an int is not affected
  cout << 3.14159 << "\n";    3.14    // the setting is still on
```

**왜 이렇게 되는가**

- 컴퓨터는 실수를 2진수(0과 1)로 저장한다. 10진수 `0.1` 을 2진수로 옮기면 `0.0001100110011...` 처럼 **끝없이 반복**되는 수라, 정해진 칸 안에 다 담지 못하고 어딘가에서 잘라야 한다.
- 10진수로 `1/3` 을 적으면 `0.3333...` 이 되어 유한한 칸에 정확히 못 적는 것과 똑같은 사정이다. 잘린 만큼 아주 작은 오차가 남는다.
- 그래서 `0.1 + 0.2` 를 자릿수를 늘려 찍어 보면 `0.3` 이 아니라 `0.30000000000000004` 가 나온다. C++의 버그가 아니라 저장 방식의 결과다.
- `fixed << setprecision(N)` 으로 자릿수를 정해 출력하면 오차가 붙어 있는 꼬리가 잘려 나가 사람이 기대하는 모양이 된다. 코딩테스트에서 실수 답에 "소수점 아래 N자리까지"라는 조건이 붙는 이유가 바로 이것이다.
- `setprecision` 은 변수 값을 바꾸지 않는다. **보여 주는 모양만** 바꾼다. 출력한 뒤에도 `pi` 는 여전히 `3.14159` 다.
- 자릿수를 맞추기 전에 **계산 자체가 정수 나눗셈으로 잘리지 않았는지** 먼저 확인해야 한다. `cout << fixed << setprecision(2) << 1 / 2;` 는 `0.50` 이 아니라 `0` 이다. `1 / 2` 가 정수끼리의 나눗셈이라 이미 `0` 이 된 뒤이기 때문이다.

## L5. 변수 값 변경

**개념**

- 이미 선언한 변수에는 값을 다시 대입해서 언제든 바꿀 수 있다. 상자에 들어 있던 값을 빼고 새 값을 넣는 것과 같다. 재대입할 때는 자료형을 다시 적지 않고 이름만 쓴다: `x = 20;`.
- 나중에 대입한 값이 이전 값을 덮어쓴다. 마지막으로 넣은 값만 남는다.
- 같은 변수를 계산에 써서 새 값을 만들 수도 있다. `x = x + 1;` 은 "지금 `x` 값에 1을 더한 결과를 다시 `x` 에 넣어라"라는 뜻이다.
- 이때 오른쪽이 먼저 계산되고, 그 결과가 왼쪽 변수에 대입된다.
- 자주 쓰는 축약: `x += 1;` 은 `x = x + 1;` 과 같다. `-=`, `*=` 도 같은 방식이며, `x++;` 은 1 증가와 같다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 10;
    x = 20;      // 값이 20으로 바뀜
    x = x + 5;   // 20 + 5 = 25
    cout << x << "\n";
    return 0;
}
```

출력:

```
25
```

**그림으로 보기**

상자는 하나뿐이다. 새 값을 넣으면 들어 있던 값은 그 자리에서 사라진다. 다시 넣을 때는 자료형을 적지 않고 이름만 쓴다.

```text
  int x = 10;     x = 20;         x = x + 5;
  +------+        +------+        +------+
  |  10  |  --->  |  20  |  --->  |  25  |
  +------+        +------+        +------+
     x               x               x
                 // 10 is gone   // 20 + 5 first, then stored
```

`x = x + 5;` 한 줄은 사실 세 단계다. 오른쪽을 먼저 계산해 손에 들고, 그다음 상자에 넣는다.

```text
  x = x + 5;

  step 1  read the box     x -> 20
  step 2  compute right    20 + 5 -> 25      // x is still 20 here
  step 3  store into x     x <- 25           // now the box holds 25

  x += 5;    is a short way of writing exactly the same three steps
```

**손으로 따라가기**

`count` 를 0에서 시작해 1씩 세 번 더하는 과정이다. 각 줄에서 "오른쪽 계산"은 **아직 바뀌기 전의 값**으로 이루어진다는 점을 확인한다.

| 단계 | 실행한 줄 | 계산 전 `count` | 오른쪽 계산 | 계산 후 `count` |
|------|-----------|-----------------|-------------|-----------------|
| 1 | `int count = 0;` | (없음) | `0` | `0` |
| 2 | `count = count + 1;` | `0` | `0 + 1 = 1` | `1` |
| 3 | `count = count + 1;` | `1` | `1 + 1 = 2` | `2` |
| 4 | `count = count + 1;` | `2` | `2 + 1 = 3` | `3` |

마지막 줄의 `count` 가 `3` 이므로 `cout << count;` 는 `3` 을 출력한다.

**왜 이렇게 되는가**

- `x = x + 1;` 이 처음에 이상해 보이는 이유는 `=` 를 "같다"로 읽기 때문이다. 수학에서 `x = x + 1` 은 성립할 수 없는 식이다.
- 코드에서 `=` 는 **왼쪽으로 값을 밀어 넣는 화살표**다. 실행 순서가 정해져 있다: ① 오른쪽 식을 계산한다(이때 `x` 는 아직 옛 값) ② 그 결과를 왼쪽 상자에 넣는다.
- 그래서 옛 값과 새 값이 한 줄 안에 공존할 수 있다. `x = x * 2;` 도 "지금 값을 두 배로 만들어 다시 담아라"라는 뜻이 된다.
- `+=`, `-=`, `*=`, `++` 는 이 순서를 그대로 줄여 쓴 것뿐이다. 새로운 규칙이 아니라 같은 동작의 짧은 표기다.
- C++에서 특히 조심할 것은 `=` 와 `==` 다. `=` 는 값을 넣는 것이고 `==` 는 같은지 묻는 것이다. 두 글자를 하나로 잘못 쓰면 오류가 아니라 **뜻이 다른 코드**가 되어 조용히 틀린다.
- `x = x * 2;` 를 계속 반복해 값이 21억을 넘으면 `int` 상자가 감당하지 못하고 값이 음수로 뒤집힌다. 커질 수 있는 값은 처음부터 `long long` 으로 선언한다.

**문제**

## L6. 다른 변수로부터 값 변경

**개념**

- 한 변수의 값을 다른 변수에 그대로 옮겨 담을 수 있다. `b = a;` 는 "`a` 의 현재 값을 `b` 에 넣어라"라는 뜻이다.
- 이때 값이 복사되어 들어간다. 대입 이후 `a` 가 바뀌어도 이미 복사된 `b` 는 영향을 받지 않는다.
- 여러 변수를 조합해 새 값을 만들 수도 있다. `c = a + b;` 는 `a` 와 `b` 의 값을 더해 `c` 에 넣는다.
- 오른쪽 식이 먼저 계산되고, 그 결과가 왼쪽 변수에 대입된다는 원칙은 항상 같다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5;
    int b = a;    // b에 5가 복사됨
    a = 100;      // a만 바뀜
    cout << a << "\n";
    cout << b << "\n";
    return 0;
}
```

출력:

```
100
5
```

**그림으로 보기**

`b = a;` 는 상자를 공유하는 게 아니라, `a` 안의 값을 **복사해서** `b` 라는 다른 상자에 넣는 것이다. 상자는 처음부터 끝까지 두 개다.

```text
  step 1: int a = 5;   step 2: int b = a;    step 3: a = 100;

  +-----+              +-----+ +-----+       +-----+ +-----+
  |  5  |              |  5  | |  5  |       | 100 | |  5  |
  +-----+              +-----+ +-----+       +-----+ +-----+
     a                    a       b             a       b
                          +-copy--+          // only a changed
```

`c = a + b;` 도 같은 순서다. 오른쪽에서 값을 읽어 계산한 뒤, 그 결과만 새 상자에 넣는다. 재료가 된 `a`, `b` 는 그대로 남는다.

```text
  int a = 6, b = 4;

  +-----+   +-----+
  |  6  |   |  4  |        read
  +-----+   +-----+
     a         b
     +----+----+
        6 + 4
          |
          v
      +------+
      |  10  |             // a and b are untouched
      +------+
          c
```

**왜 이렇게 되는가**

- 대입은 언제나 "오른쪽 -> 왼쪽" 한 방향이다. `b = a;` 를 실행하는 순간 하는 일은 딱 하나, **그 시점의 `a` 값을 읽어 `b` 상자에 써 넣는 것**이다.
- 그 뒤로 두 이름 사이에는 아무 연결도 남지 않는다. 연결선을 만든 게 아니라 값을 한 번 베낀 것이기 때문이다. 그래서 `a = 100;` 을 해도 `b` 는 복사하던 순간의 `5` 를 그대로 갖고 있다.
- 반대로 `b = a;` 를 **한 번 더** 실행하면 그때의 `a` 값이 다시 복사되어 `b` 도 `100` 이 된다. 값은 "복사한 시점"에만 옮겨진다.
- C++은 이 "값을 통째로 베낀다"는 규칙을 큰 값에도 똑같이 적용한다. `string t = s;` 도 글자 전체를 복사한다. 편하지만 값이 크면 복사 비용이 든다는 점은 뒤 챕터에서 다시 만난다.
- 정리하면 값이 바뀌는 순간은 오직 그 변수가 `=` 의 왼쪽에 나올 때뿐이다. 이 원칙 하나로 L7(교환)과 L8(여러 값 옮기기)이 모두 설명된다.

## L7. 두 변수 값을 교환

**개념**

- 두 변수의 값을 맞바꾸는 것을 "교환(swap)"이라 한다. `a` 에는 `b` 의 값, `b` 에는 `a` 의 값이 들어가게 만든다.
- 그냥 `a = b;` 를 먼저 하면 `a` 의 원래 값이 사라져서 잃어버린다. 그래서 임시 변수가 필요하다.
- 방법: 임시 변수 `temp` 에 `a` 를 잠시 넣어 두고 → `a = b;` → `b = temp;` 순서로 옮긴다.
- 임시 변수는 값을 잠깐 보관하는 "임시 상자"다. 교환이 끝나면 더는 신경 쓰지 않아도 된다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 1;
    int b = 2;
    int temp = a;   // temp에 1을 보관
    a = b;          // a는 이제 2
    b = temp;       // b는 보관해 둔 1
    cout << a << " " << b << "\n";
    return 0;
}
```

출력:

```
2 1
```

**그림으로 보기**

먼저 **왜 임시 변수가 필요한지**부터 그림으로 본다. `a = b;` 를 먼저 하면 `a` 에 들어 있던 값이 덮어써져 영영 사라진다.

```text
  wrong:  a = b;  first

  +---+ +---+          +---+ +---+
  | 1 | | 2 |   --->   | 2 | | 2 |      // the old 1 is lost
  +---+ +---+          +---+ +---+
    a     b              a     b
                       // b = a now gives 2, not 1
```

임시 상자에 먼저 옮겨 두면 잃어버릴 값이 없다. 세 단계를 그대로 따라가 보자.

```text
  step 0        step 1        step 2        step 3
  (start)       temp = a;     a = b;        b = temp;

  +---++---+    +---++---+    +---++---+    +---++---+
  | 1 || 2 |    | 1 || 2 |    | 2 || 2 |    | 2 || 1 |
  +---++---+    +---++---+    +---++---+    +---++---+
    a    b        a    b        a    b        a    b

                +---+         +---+         +---+
                | 1 |         | 1 |         | 1 |
                +---+         +---+         +---+
                 temp          temp          temp
```

**손으로 따라가기**

`a = 10`, `b = 20` 을 교환하는 과정이다. 매 줄에서 **어떤 상자가 바뀌는지** 한 칸씩 확인한다.

| 단계 | 실행한 줄 | `a` | `b` | `temp` | 설명 |
|------|-----------|-----|-----|--------|------|
| 0 | (시작) | 10 | 20 | (없음) | 두 값이 제자리에 있다 |
| 1 | `int temp = a;` | 10 | 20 | 10 | `a` 값을 임시 상자에 복사(원본은 그대로) |
| 2 | `a = b;` | 20 | 20 | 10 | `a` 의 10이 덮어써지지만 `temp` 에 살아 있다 |
| 3 | `b = temp;` | 20 | 10 | 10 | 보관해 둔 10을 `b` 로 옮긴다 |

3단계가 끝나면 `a` 는 20, `b` 는 10이 되어 `cout << a << " " << b;` 가 `20 10` 을 출력한다. `temp` 에 남은 값은 더 쓰지 않으므로 신경 쓰지 않아도 된다.

**왜 이렇게 되는가**

- 대입은 "복사해서 덮어쓰기"다. 덮어쓰는 순간 그 자리에 있던 값은 **다른 어딘가에 복사본이 없으면 되찾을 방법이 없다.**
- 그래서 교환의 규칙은 하나로 정리된다. **덮어쓰기 때문에 사라질 값을 먼저 다른 곳에 복사해 둔다.**
- 세 변수를 한 칸씩 미는 경우도 같은 규칙이다. 마지막에 필요한 원래 값 하나만 `temp` 에 지켜 두면, 나머지는 앞에서부터 순서대로 밀면 된다.
- `temp` 의 자료형은 옮길 값과 같아야 한다. `double` 값을 `int temp` 에 넣으면 소수점 아래가 잘려 나가 원래 값을 되찾을 수 없다. 그래서 `int temp = a;` 처럼 `a` 와 같은 자료형으로 선언한다.
- C++ 표준 라이브러리에는 같은 일을 하는 `swap(a, b);` 가 있다. 하지만 그 안에서 하는 일은 정확히 위 세 줄이다. 원리를 알고 나서 쓰는 도구다.

**문제**

**3) 세 변수 자리 옮기기** · Hard

```runner
(1) 접근 개념: 세 값을 왼쪽으로 한 칸씩 돌린다(`a←b`, `b←c`, `c←원래 a`). 마지막에 필요한 원래 `a` 를 잃지 않도록 먼저 임시 변수에 보관한다.

- 덮어쓰기로 사라질 값(원래 `a`)을 먼저 임시 변수에 지킨다.
- 왼쪽으로 밀듯 `a←b`, `b←c` 순으로 옮긴다.
- 마지막 빈 자리 `c` 에 보관해 둔 원래 `a` 를 넣는다.
```


## L8. 변수값 동시에 복사

**개념**

- C++에서는 `a, b = b, a` 처럼 한 줄에 여러 변수를 동시에 대입하는 문법이 없다. 대신 값을 옮기려면 순서대로 하나씩 대입한다.
- 그래서 두 값을 맞바꿀 때는 임시 변수를 쓴다. `int temp = a; a = b; b = temp;` 처럼 옛 값을 먼저 보관한 뒤 옮긴다. (표준 함수 `swap(a, b);` 도 있지만, 여기서는 임시 변수로 원리를 익힌다.)
- 여러 변수를 한 줄에 선언하며 대입할 수는 있다. `int a = 1, b = 2;` 는 `a` 에 `1`, `b` 에 `2` 를 넣는다.
- 여러 변수에 같은 값을 넣고 싶으면 `int x = 0, y = 0;` 처럼 각각 초기화하거나, 이미 선언했다면 `x = y = 0;` 으로 한꺼번에 대입할 수도 있다. (`=` 는 오른쪽에서 왼쪽으로 처리되어 `y = 0` 의 결과가 다시 `x` 에 들어간다.)

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 3, b = 7;
    int temp = a;   // 임시 변수로 교환
    a = b;
    b = temp;
    cout << a << " " << b << "\n";
    return 0;
}
```

출력:

```
7 3
```

**그림으로 보기**

C++에는 두 변수를 한 줄에 맞바꾸는 문법이 없다. 대입은 언제나 한 번에 하나씩, 위에서 아래로 일어난다. 그래서 **사라질 값을 먼저 임시 상자에 세워 두는 일**을 사람이 직접 해야 한다.

```text
  int a = 1, b = 2;        goal:  a <- b,  b <- a + b

  wrong: one at a time, no backup
     a = b;          // a is now 2, the old 1 is GONE
     b = a + b;      // 2 + 2 = 4        ->  "2 4"   (wrong)

  right: park the value that dies
     int t = a;      // t = 1
     a = b;          // a = 2
     b = t + b;      // 1 + 2 = 3        ->  "2 3"   (correct)
```

교환도 같은 그림이다. 두 상자를 맞바꾸는 데 필요한 것은 세 번의 대입뿐이다.

```text
  int a = 8, b = 3;        goal: swap

  stage 1   int t = a;       t <- 8    // park the value that dies
  stage 2   a = b;           a <- 3
  stage 3   b = t;           b <- 8

  +---+ +---+          +---+ +---+
  | 8 | | 3 |   --->   | 3 | | 8 |
  +---+ +---+          +---+ +---+
    a     b              a     b
```

여러 변수에 같은 값을 넣는 `x = y = 0;` 은 **오른쪽에서 왼쪽으로** 처리된다.

```text
  x = y = 0;

  step 1   y = 0            y <- 0
  step 2   x = (that 0)     x <- 0

  +---+ +---+
  | 0 | | 0 |     // two separate boxes
  +---+ +---+
    x     y       // changing x later does NOT touch y
```

**손으로 따라가기**

`a = 1`, `b = 2` 에서 `a` 에는 `b` 를, `b` 에는 옛 `a + b` 를 넣는 과정이다. 임시 변수 `t` 가 옛 `a` 를 지키는 것을 확인한다.

| 단계 | 실행한 줄 | `a` | `b` | `t` | 설명 |
|------|-----------|-----|-----|-----|------|
| 0 | (시작) | 1 | 2 | (없음) | 옛 값이 그대로 있다 |
| 1 | `int t = a;` | 1 | 2 | 1 | 곧 사라질 `a` 를 먼저 보관 |
| 2 | `a = b;` | 2 | 2 | 1 | `a` 의 1은 사라지지만 `t` 에 있다 |
| 3 | `b = t + b;` | 2 | 3 | 1 | 옛 `a`(= `t`)와 옛 `b` 를 더한다 |

결과는 `a = 2`, `b = 3` 이라 `cout << a << " " << b;` 가 `2 3` 을 출력한다. 1단계를 빼고 `b = a + b;` 를 하면 `a` 가 이미 2로 바뀐 뒤라 `4` 가 되어 답이 달라진다.

**왜 이렇게 되는가**

- 한 줄에 여러 대입을 동시에 하는 문법이 없으므로, "옛 값을 먼저 모아 둔다"는 일을 임시 변수가 대신한다. 원리는 임시 상자 하나이고, 그 상자를 사람이 보이게 쓰는 것뿐이다.
- 그래서 규칙은 하나다. **한 줄을 실행하기 전에, 그 줄에서 덮어써질 값이 뒤에서 또 쓰이는지 확인한다.** 쓰인다면 임시 변수가 필요하다.
- `int a = 1, b = 2;` 는 동시 대입이 아니라 **한 줄에 두 개를 선언한 것**이다. 왼쪽부터 차례로 만들어지며, 두 상자 사이에는 아무 관계도 없다.
- 함정 하나: `a, b = b, a;` 라고 쓰면 C++에서도 컴파일이 된다. 하지만 이때 쉼표는 "왼쪽을 계산해 버리고 오른쪽을 계산하라"는 전혀 다른 연산자라, 실제로는 `b = b` 만 일어나고 교환은 일어나지 않는다. 오류가 나지 않으므로 더 위험하다.
- `x = y = 0;` 이 되는 이유는 대입 자체가 값을 남기기 때문이다. `y = 0` 이 끝나면 그 자리에 `0` 이 남고, 그것이 다시 `x` 에 들어간다. 두 상자를 연결하는 것이 아니라 값을 각각 넣는 것이다(L6의 복사 독립성과 같다).

**문제**

**1) 한 줄로 두 값 대입** · Easy

- **요구사항**: `a`, `b` 에 각각 `5`, `9` 를 한 줄의 선언으로 넣고, 한 줄에 공백으로 띄워 출력하라.
- **입력**: 없음
- **출력**: `a`, `b` 를 공백 한 칸을 두고 한 줄에
- **예제**: (입력 없음) → `5 9`
- **셀프체크**: `int a = 5, b = 9;` 처럼 한 줄에 두 변수를 선언·초기화했는가? 각 변수에 알맞은 값이 짝지어졌는가?

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int a = 5, b = 9;
    cout << a << " " << b << "\n";
    return 0;
}
@@TESTS
--IN

--OUT
5 9
@@EXPL
(1) 접근 개념: C++에서는 한 줄에 여러 변수를 선언하며 초기화할 수 있다. `int a = 5, b = 9;` 는 `a` 에 `5`, `b` 에 `9` 를 넣는다(쉼표로 구분).

(2) 코드 진행

- `int a = 5, b = 9;` — 한 번의 `int` 선언에서 두 변수를 각각 초기화한다.
- `cout << a << " " << b << "\n";` — 사이에 `" "` 를 끼워 `5 9` 를 한 줄에 출력한다.

(3) 재작성 사고 순서

- "여러 변수를 한 줄에?" → `int a = 5, b = 9;` 처럼 쉼표로 나열한다.
- 각 변수 = 각 값이 짝지어지도록 순서를 맞춘다.
- 출력은 `<<` 로 이으면서 사이에 `" "` 를 넣어 공백 한 칸을 둔다.
```

**2) 임시 변수로 교환** · Medium

- **요구사항**: `a = 8`, `b = 3` 을 임시 변수를 이용해 교환한 뒤 한 줄에 공백으로 띄워 출력하라.
- **입력**: 없음
- **출력**: 교환된 `a`, `b` 를 공백을 두고 한 줄에
- **예제**: (입력 없음) → `3 8`
- **셀프체크**: 임시 변수에 옛 값을 보관한 뒤 옮겼는가? `a = b;` 를 먼저 해서 `8` 을 잃어버리지 않았는가?

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int a = 8;
    int b = 3;
    int temp = a;
    a = b;
    b = temp;
    cout << a << " " << b << "\n";
    return 0;
}
@@TESTS
--IN

--OUT
3 8
@@EXPL
(1) 접근 개념: C++에는 `a, b = b, a` 같은 동시 대입 문법이 없으므로, 임시 변수에 옛 값을 보관한 뒤 순서대로 옮겨 두 값을 맞바꾼다.

(2) 코드 진행

- `int a = 8;`, `int b = 3;` 으로 시작한다.
- `int temp = a;` — `a` 의 `8` 을 임시 변수에 보관한다.
- `a = b;` — `a` 에 `b` 의 `3` 을 넣는다. 원래 `8` 은 `temp` 에 있다.
- `b = temp;` — `b` 에 보관해 둔 `8` 을 넣는다.
- `cout << a << " " << b << "\n";` — `3 8`.

(3) 재작성 사고 순서

- "임시 변수로 교환" → 보관(temp=a) → 옮김(a=b) → 되돌림(b=temp).
- 덮어쓰기 전에 잃어버릴 값을 먼저 지켜 둔다.
- 결과를 손으로 따라가 확인한다.
```

**3) 순서에 따른 교환 함정** · Hard

- **요구사항**: `a = 1`, `b = 2` 로 시작한다. `a` 에는 원래 `b` 의 값을, `b` 에는 원래 `a + b` 의 값을 넣어라. 즉 임시 변수로 옛 값을 보관해 두 값을 동시에 바꾼 것처럼 계산한 뒤, `a` 와 `b` 를 한 줄에 공백으로 띄워 출력하라.
- **입력**: 없음
- **출력**: 대입 후의 `a`, `b` 를 공백을 두고 한 줄에
- **예제**: (입력 없음) → `2 3`
- **셀프체크**: 두 대입에 모두 "옛날 값"을 써야 한다. 즉 새 `a`(=원래 b=2)와 새 `b`(=원래 a+b=1+2=3)를 옛 값으로 계산한다. 만약 `a` 를 먼저 바꾼 뒤 `a + b` 를 계산했다면 `2+2=4` 가 되어 틀린다. 옛 값을 임시 변수에 보관했는가?

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int a = 1;
    int b = 2;
    int oldA = a;
    int oldB = b;
    a = oldB;
    b = oldA + oldB;
    cout << a << " " << b << "\n";
    return 0;
}
@@TESTS
--IN

--OUT
2 3
@@EXPL
(1) 접근 개념: `a, b = b, a + b` 처럼 오른쪽을 모두 "옛 값"으로 먼저 계산한 뒤 왼쪽에 담는 동시 대입 문법은 C++에 없으므로, 옛 값을 임시 변수에 먼저 복사해 두고 그 옛 값으로 두 대입을 계산해 같은 효과를 낸다.

(2) 코드 진행

- `int a = 1;`, `int b = 2;` 로 시작한다.
- `int oldA = a;`, `int oldB = b;` — 대입 전 옛 값을 보관한다. `oldA = 1`, `oldB = 2`.
- `a = oldB;` — 새 `a` 는 옛 `b` 값 `2`.
- `b = oldA + oldB;` — 새 `b` 는 옛 `a` + 옛 `b` = `1 + 2 = 3`. (여기서 `a` 는 이미 2로 바뀌었지만, 옛 값을 따로 보관해 두었기 때문에 섞이지 않는다.)
- `cout << a << " " << b << "\n";` — `2 3`.

(3) 재작성 사고 순서

- "오른쪽은 전부 옛 값으로 계산" 이 핵심이다. 그러려면 대입을 시작하기 전에 옛 값을 임시 변수에 복사해 둔다.
- 만약 옛 값을 보관하지 않고 `a = b; b = a + b;` 처럼 짜면, 두 번째 줄의 `a` 가 이미 2로 바뀌어 `2 + 2 = 4` 가 되어 틀린다.
- 옛 값(`oldA`, `oldB`)만으로 두 결과를 만든 뒤 확인한다.
```
