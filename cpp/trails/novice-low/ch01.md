> 개요: 이 챕터에서는 화면에 값을 보여 주는 `cout`을 익히고, 값을 담아 두는 변수와 기본 자료형, 여러 값을 원하는 형식으로 출력하는 법, 그리고 변수의 값을 바꾸고 옮기고 서로 교환하는 방법까지 배운다.

## L1. 기본 출력

**개념**

- 프로그램이 만든 결과를 사람이 볼 수 있게 화면에 보여 주는 것을 "출력"이라고 한다.
- C++에서는 `cout` 에 `<<`(스트림 삽입 연산자)로 값을 넘겨 출력한다. `cout` 을 쓰려면 맨 위에 `#include <iostream>` 이 필요하고, `std::` 없이 짧게 쓰려면 `using namespace std;` 를 선언한다.
- 글자(문자열)를 그대로 출력하려면 큰따옴표 `"..."` 로 감싼다. (문자 하나만 담는 `char` 는 작은따옴표 `'...'` 를 쓴다.)
- 숫자는 따옴표 없이 그대로 쓴다. `cout << 10;` 은 `10` 을 출력한다.
- `cout` 은 자동으로 줄을 바꾸지 않는다. 줄을 바꾸려면 개행 문자 `"\n"` 을 직접 붙여야 한다. 그래서 두 줄로 나오게 하려면 각 출력 끝에 `"\n"` 을 넣는다.
- 모든 실행 코드는 `int main() { ... return 0; }` 안에 쓴다.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello" << "\n";
    cout << 2025 << "\n";
    return 0;
}
```

위 코드의 출력:

```
Hello
2025
```

## L2. 변수와 자료형

**개념**

- 변수는 값을 담아 두는 "이름표가 붙은 상자"다. C++은 변수를 처음 만들 때 자료형을 함께 적어 선언한다. `int x = 5;` 는 `int`(정수)형 상자 `x` 에 값 `5` 를 넣는 것이다.
- `=` 는 "같다"가 아니라 "오른쪽 값을 왼쪽 이름에 넣어라"라는 뜻이다. (이걸 대입이라 한다.)
- 변수에 담긴 값은 그 이름만 써서 다시 꺼내 쓸 수 있다. `cout << x;` 는 `x` 가 담고 있는 값을 출력한다.
- 값에는 종류가 있고 이를 "자료형"이라 한다. 기초 자료형 세 가지:

- 정수형(int): 소수점이 없는 수. 예: `3`, `-7`, `0`
- 실수형(double): 소수점이 있는 수. 예: `3.14`, `-0.5`, `2.0`
- 문자열(string): 큰따옴표로 감싼 글자. 예: `"hi"`, `"12"` (`#include <string>` 이 필요하다.)

- 같은 겉모습이라도 자료형이 다를 수 있다. `5` 는 정수(int), `5.0` 은 실수(double), `"5"` 는 문자열(string)이다.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int age = 20;
    double pi = 3.14;
    string name = "Ann";
    cout << name << "\n";
    cout << age << "\n";
    return 0;
}
```

출력:

```
Ann
20
```

## L3. 출력 형식

**개념**

- 한 줄에 여러 값을 함께 보여 주고 싶을 때, `cout` 에서 `<<` 로 값을 계속 이어 쓰면 된다. 예: `cout << "a" << "b";` → `ab`
- C++의 `<<` 는 값 사이에 공백을 자동으로 넣지 않는다. 값 사이를 띄우고 싶으면 공백 문자열 `" "` 를 직접 끼워 넣어야 한다. 예: `cout << "a" << " " << "b";` → `a b`
- 문자열과 숫자를 섞어서 이어 써도 된다. 자료형이 달라도 `<<` 로 이으면 함께 출력된다.
- 문자열끼리는 `+` 로 이어 붙일 수도 있다. 이때는 공백이 들어가지 않는다. 예: `string s = string("a") + "b";` → `ab`
- 정리하면, C++에서는 공백을 넣고 싶을 때 `<< " " <<` 로 직접 끼워 넣는다. 공백이 자동으로 생기지 않는다는 점에 유의한다.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "Ann";
    int age = 20;
    cout << name << " " << age << "\n";
    cout << "Age: " << age << "\n";
    return 0;
}
```

출력:

```
Ann 20
Age: 20
```

- **출력**: 이름과 점수를 공백 한 칸을 두고 한 줄에
- **예제**: (입력 없음) → `Kim 95`
- **셀프체크**: C++에서는 공백이 자동으로 들어가지 않으므로 `<< " " <<` 로 공백을 직접 하나 끼워 넣어야 한다. 공백을 두 칸 넣지 않았는가?

```runner

(2) 코드 진행
```

## L4. 소수점 맞춰 출력

**개념**

- 실수를 출력할 때 소수점 아래 자릿수를 정해서 깔끔하게 보여 주고 싶을 때가 있다.
- C++에서는 `<iomanip>` 헤더의 `fixed` 와 `setprecision(n)` 을 함께 쓴다. `cout << fixed << setprecision(2);` 는 "이후 실수를 소수점 아래 2자리 고정 형식으로 출력하라"는 뜻이다.
- `fixed` 는 "소수점 아래 자릿수를 고정" 하라는 설정이고, `setprecision(2)` 의 숫자가 소수점 아래 자릿수다.
- 지정한 자릿수에 맞춰 반올림된다. 예: `3.14159` 를 `setprecision(2)` 로 하면 `3.14`.
- 정해진 자릿수보다 짧으면 `0` 으로 채운다. 예: `2.5` 를 `fixed << setprecision(3)` 로 하면 `2.500`.

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double pi = 3.14159;
    cout << fixed << setprecision(2) << pi << "\n";
    cout << fixed << setprecision(4) << pi << "\n";
    return 0;
}
```

출력:

```
3.14
3.1416
```

> 선행: `fixed` 와 `setprecision` 은 한 번 설정하면 이후 출력에 계속 적용된다. 지금은 "소수점 자릿수 맞추기" 용도로만 쓴다.

**문제**

- **입력**: 없음
- **출력**: 소수점 아래 2자리로 반올림한 값
- **예제**: (입력 없음) → `3.14`
- **셀프체크**: 셋째 자리 `1` 은 버림, 결과가 `3.14` 인가? `fixed << setprecision(2)` 를 정확히 썼는가?

```runner

@@EXPL
(1) 접근 개념: 실수를 소수점 아래 정해진 자릿수까지만 보여 준다. `fixed << setprecision(2)` 를 설정하면 소수점 아래 2자리로 반올림해 출력한다.

(2) 코드 진행

- `cout << fixed << setprecision(2) << pi << "\n";` — `fixed` 로 소수점 아래 고정 형식을, `setprecision(2)` 로 2자리를 지정한다.

(3) 재작성 사고 순서
```

## L5. 변수 값 변경

**개념**

- 이미 선언한 변수에는 값을 다시 대입해서 언제든 바꿀 수 있다. 상자에 들어 있던 값을 빼고 새 값을 넣는 것과 같다. 재대입할 때는 자료형을 다시 적지 않고 이름만 쓴다: `x = 20;`.
- 나중에 대입한 값이 이전 값을 덮어쓴다. 마지막으로 넣은 값만 남는다.
- 같은 변수를 계산에 써서 새 값을 만들 수도 있다. `x = x + 1;` 은 "지금 `x` 값에 1을 더한 결과를 다시 `x` 에 넣어라"라는 뜻이다.
- 이때 오른쪽이 먼저 계산되고, 그 결과가 왼쪽 변수에 대입된다.
- 자주 쓰는 축약: `x += 1;` 은 `x = x + 1;` 과 같다. `-=`, `*=` 도 같은 방식이며, `x++;` 은 1 증가와 같다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 10;
    x = 20;      // 값이 20으로 바뀜
    x = x + 5;   // 20 + 5 = 25
    cout << x << "\n";
    return 0;
}
```

출력:

```
25
```

**문제**

**1) 값 덮어쓰기** · Easy

- **요구사항**: 변수 `n` 에 `3` 을 넣은 뒤, 다시 `8` 을 넣고, 최종 값을 출력하라.
- **입력**: 없음
- **출력**: 마지막으로 대입된 값
- **예제**: (입력 없음) → `8`
- **셀프체크**: 마지막에 넣은 값만 남는다. `3` 이 출력되면 순서나 대입이 잘못된 것이다. 재대입 시 자료형을 또 붙이지 않았는가?

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int n = 3;
    n = 8;
    cout << n << "\n";
    return 0;
}
@@TESTS
--IN

--OUT
8
@@EXPL
(1) 접근 개념: 같은 변수에 값을 다시 대입하면 이전 값이 덮어써진다. 마지막으로 넣은 값만 남는다는 사실을 확인한다.

(2) 코드 진행

- `int n = 3;` — 변수 `n` 에 `3` 이 들어간다(선언 + 초기화).
- `n = 8;` — 같은 `n` 에 `8` 을 넣으면 이전의 `3` 은 사라진다. 재대입이므로 자료형(`int`)을 다시 쓰지 않고 이름만 쓴다.
- `cout << n << "\n";` — 현재 `n` 의 값 `8` 이 출력된다.

(3) 재작성 사고 순서

- 대입은 "상자의 내용을 새 값으로 교체"하는 동작이다.
- 여러 번 대입하면 순서상 마지막 값만 남는다.
- 재대입에는 이름만 쓴다(`int n = 8;` 처럼 자료형을 또 붙이면 중복 선언 오류).
```

**2) 자기 자신을 이용해 증가** · Medium

- **요구사항**: 변수 `count` 를 `0` 으로 시작해, 값을 1씩 세 번 더한 뒤 최종 값을 출력하라.
- **입력**: 없음
- **출력**: 세 번 더한 최종 값
- **예제**: (입력 없음) → `3`
- **셀프체크**: `count = count + 1;` (또는 `count += 1;`)을 세 번 실행하면 `0→1→2→3`. 결과가 `3` 인가?

```runner
@@SOLUTION
#include <iostream>

    int count = 0;
    count = count + 1;
    count = count + 1;
    count = count + 1;

    return 0;

@@TESTS
--IN

--OUT
3
@@EXPL
(1) 접근 개념: 변수 자기 자신을 계산에 써서 값을 늘린다. `count = count + 1;` 은 "지금 값에 1을 더한 결과를 다시 담아라"라는 뜻이다. 오른쪽이 먼저 계산된다.

(2) 코드 진행

- `int count = 0;` 으로 시작한다.
- 첫 번째 `count = count + 1;` → 오른쪽 `0 + 1 = 1` 을 계산해 `count` 에 넣는다. `count` 는 1.
- 두 번째 → `1 + 1 = 2`. 세 번째 → `2 + 1 = 3`.

(3) 재작성 사고 순서

- 각 줄에서 오른쪽(옛 값 + 1)을 먼저 계산하고 그 결과를 다시 변수에 넣는다.
- `0→1→2→3` 처럼 값의 흐름을 손으로 따라가 본다.
```

## L6. 다른 변수로부터 값 변경

**개념**

- 한 변수의 값을 다른 변수에 그대로 옮겨 담을 수 있다. `b = a;` 는 "`a` 의 현재 값을 `b` 에 넣어라"라는 뜻이다.
- 이때 값이 복사되어 들어간다. 대입 이후 `a` 가 바뀌어도 이미 복사된 `b` 는 영향을 받지 않는다.
- 여러 변수를 조합해 새 값을 만들 수도 있다. `c = a + b;` 는 `a` 와 `b` 의 값을 더해 `c` 에 넣는다.
- 오른쪽 식이 먼저 계산되고, 그 결과가 왼쪽 변수에 대입된다는 원칙은 항상 같다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5;
    int b = a;    // b에 5가 복사됨
    a = 100;      // a만 바뀜
    cout << a << "\n";
    cout << b << "\n";
    return 0;
}
```

출력:

```
100
5
```

## L7. 두 변수 값을 교환

**개념**

- 두 변수의 값을 맞바꾸는 것을 "교환(swap)"이라 한다. `a` 에는 `b` 의 값, `b` 에는 `a` 의 값이 들어가게 만든다.
- 그냥 `a = b;` 를 먼저 하면 `a` 의 원래 값이 사라져서 잃어버린다. 그래서 임시 변수가 필요하다.
- 방법: 임시 변수 `temp` 에 `a` 를 잠시 넣어 두고 → `a = b;` → `b = temp;` 순서로 옮긴다.
- 임시 변수는 값을 잠깐 보관하는 "임시 상자"다. 교환이 끝나면 더는 신경 쓰지 않아도 된다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 1;
    int b = 2;
    int temp = a;   // temp에 1을 보관
    a = b;          // a는 이제 2
    b = temp;       // b는 보관해 둔 1
    cout << a << " " << b << "\n";
    return 0;
}
```

출력:

```
2 1
```

**문제**

**1) 두 값 맞바꾸기** · Easy

- **요구사항**: 변수 `a = 10`, `b = 20` 의 값을 서로 교환한 뒤 한 줄에 공백으로 띄워 출력하라.
- **입력**: 없음
- **출력**: 교환된 `a`, `b` 를 공백 한 칸을 두고 한 줄에
- **예제**: (입력 없음) → `20 10`
- **셀프체크**: 임시 변수를 썼는가? `a = b;` 를 먼저 해서 `10` 을 잃어버리지 않았는가?

```runner
@@EXPL
(1) 접근 개념: 두 변수의 값을 맞바꾼다(교환). 그냥 `a = b;` 를 먼저 하면 `a` 의 원래 값이 사라지므로, 임시 변수에 잠깐 보관해 둔다.

(2) 코드 진행

- `int a = 10;`, `int b = 20;` 으로 시작한다.
- `int temp = a;` — `a` 의 값 `10` 을 임시 변수에 보관한다.
```

## L8. 변수값 동시에 복사

**개념**

- C++에서는 `a, b = b, a` 처럼 한 줄에 여러 변수를 동시에 대입하는 문법이 없다. 대신 값을 옮기려면 순서대로 하나씩 대입한다.
- 그래서 두 값을 맞바꿀 때는 임시 변수를 쓴다. `int temp = a; a = b; b = temp;` 처럼 옛 값을 먼저 보관한 뒤 옮긴다. (표준 함수 `swap(a, b);` 도 있지만, 여기서는 임시 변수로 원리를 익힌다.)
- 여러 변수를 한 줄에 선언하며 대입할 수는 있다. `int a = 1, b = 2;` 는 `a` 에 `1`, `b` 에 `2` 를 넣는다.
- 여러 변수에 같은 값을 넣고 싶으면 `int x = 0, y = 0;` 처럼 각각 초기화하거나, 이미 선언했다면 `x = y = 0;` 으로 한꺼번에 대입할 수도 있다. (`=` 는 오른쪽에서 왼쪽으로 처리되어 `y = 0` 의 결과가 다시 `x` 에 들어간다.)

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 3, b = 7;
    int temp = a;   // 임시 변수로 교환
    a = b;
    b = temp;
    cout << a << " " << b << "\n";
    return 0;
}
```

출력:

```
7 3
```

**문제**

**1) 한 줄로 두 값 대입** · Easy

- **요구사항**: `a`, `b` 에 각각 `5`, `9` 를 한 줄의 선언으로 넣고, 한 줄에 공백으로 띄워 출력하라.
- **입력**: 없음
- **출력**: `a`, `b` 를 공백 한 칸을 두고 한 줄에
- **예제**: (입력 없음) → `5 9`
- **셀프체크**: `int a = 5, b = 9;` 처럼 한 줄에 두 변수를 선언·초기화했는가? 각 변수에 알맞은 값이 짝지어졌는가?

```runner
@@SOLUTION

@@TESTS
--IN

--OUT

@@EXPL
(1) 접근 개념: C++에서는 한 줄에 여러 변수를 선언하며 초기화할 수 있다. `int a = 5, b = 9;` 는 `a` 에 `5`, `b` 에 `9` 를 넣는다(쉼표로 구분).

(2) 코드 진행

- `int a = 5, b = 9;` — 한 번의 `int` 선언에서 두 변수를 각각 초기화한다.

- "여러 변수를 한 줄에?" → `int a = 5, b = 9;` 처럼 쉼표로 나열한다.
```

- **출력**: 교환된 `a`, `b` 를 공백을 두고 한 줄에
- **예제**: (입력 없음) → `3 8`
- **셀프체크**: 임시 변수에 옛 값을 보관한 뒤 옮겼는가? `a = b;` 를 먼저 해서 `8` 을 잃어버리지 않았는가?

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int a = 8;
    int b = 3;
    int temp = a;
    a = b;
    b = temp;
    cout << a << " " << b << "\n";
    return 0;
}
@@TESTS
--IN

--OUT
3 8
@@EXPL
(1) 접근 개념: C++에는 `a, b = b, a` 같은 동시 대입 문법이 없으므로, 임시 변수에 옛 값을 보관한 뒤 순서대로 옮겨 두 값을 맞바꾼다.

(2) 코드 진행

- `int a = 8;`, `int b = 3;` 으로 시작한다.
- `int temp = a;` — `a` 의 `8` 을 임시 변수에 보관한다.
- `a = b;` — `a` 에 `b` 의 `3` 을 넣는다. 원래 `8` 은 `temp` 에 있다.
- `b = temp;` — `b` 에 보관해 둔 `8` 을 넣는다.
- `cout << a << " " << b << "\n";` — `3 8`.

(3) 재작성 사고 순서

- "임시 변수로 교환" → 보관(temp=a) → 옮김(a=b) → 되돌림(b=temp).
- 덮어쓰기 전에 잃어버릴 값을 먼저 지켜 둔다.
- 결과를 손으로 따라가 확인한다.
```

**3) 순서에 따른 교환 함정** · Hard

- **요구사항**: `a = 1`, `b = 2` 로 시작한다. `a` 에는 원래 `b` 의 값을, `b` 에는 원래 `a + b` 의 값을 넣어라. 즉 임시 변수로 옛 값을 보관해 두 값을 동시에 바꾼 것처럼 계산한 뒤, `a` 와 `b` 를 한 줄에 공백으로 띄워 출력하라.
- **입력**: 없음
- **출력**: 대입 후의 `a`, `b` 를 공백을 두고 한 줄에
- **예제**: (입력 없음) → `2 3`
- **셀프체크**: 두 대입에 모두 "옛날 값"을 써야 한다. 즉 새 `a`(=원래 b=2)와 새 `b`(=원래 a+b=1+2=3)를 옛 값으로 계산한다. 만약 `a` 를 먼저 바꾼 뒤 `a + b` 를 계산했다면 `2+2=4` 가 되어 틀린다. 옛 값을 임시 변수에 보관했는가?

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int a = 1;
    int b = 2;
    int oldA = a;
    int oldB = b;
    a = oldB;
    b = oldA + oldB;
    cout << a << " " << b << "\n";
    return 0;
}
@@TESTS
--IN

--OUT
2 3
@@EXPL
(1) 접근 개념: `a, b = b, a + b` 처럼 오른쪽을 모두 "옛 값"으로 먼저 계산한 뒤 왼쪽에 담는 동시 대입 문법은 C++에 없으므로, 옛 값을 임시 변수에 먼저 복사해 두고 그 옛 값으로 두 대입을 계산해 같은 효과를 낸다.

(2) 코드 진행

- `int a = 1;`, `int b = 2;` 로 시작한다.
- `int oldA = a;`, `int oldB = b;` — 대입 전 옛 값을 보관한다. `oldA = 1`, `oldB = 2`.
- `a = oldB;` — 새 `a` 는 옛 `b` 값 `2`.
- `b = oldA + oldB;` — 새 `b` 는 옛 `a` + 옛 `b` = `1 + 2 = 3`. (여기서 `a` 는 이미 2로 바뀌었지만, 옛 값을 따로 보관해 두었기 때문에 섞이지 않는다.)
- `cout << a << " " << b << "\n";` — `2 3`.

(3) 재작성 사고 순서

- "오른쪽은 전부 옛 값으로 계산" 이 핵심이다. 그러려면 대입을 시작하기 전에 옛 값을 임시 변수에 복사해 둔다.
- 만약 옛 값을 보관하지 않고 `a = b; b = a + b;` 처럼 짜면, 두 번째 줄의 `a` 가 이미 2로 바뀌어 `2 + 2 = 4` 가 되어 틀린다.
- 옛 값(`oldA`, `oldB`)만으로 두 결과를 만든 뒤 확인한다.
```
