## L8. 정리 — 개념 지도·체크리스트·자주 하는 실수

**개념**

Ch02는 문법이 많은 챕터가 아니다. 도구는 `cin >>` 하나이고, 나머지는 **어떤 자료형의 상자로 받을 것인가**를 고르는 일이다. 어려운 것은 "이 문제의 입력이 어떤 모양인가"를 읽고 그 모양에 맞는 상자와 개수를 정하는 판단이다. 그 판단을 지도와 표로 굳혀 둔다.

**개념 지도**

C++의 입력은 파이썬보다 단계가 하나 적다. **읽으면서 곧바로 자료형에 맞게 변환**되므로 따로 바꿔 주는 칸이 없다.

```text
  read a value    ->    it is already typed    ->    compute & print

  +-------------+       +-------------------+       +--------------+
  | cin >> n;   |  -->  | int / double      |  -->  | + - * / %    |
  | one value   |       | string / char     |       | cout << ...  |
  | at a time   |       | (no convert step) |       |              |
  +-------------+       +-------------------+       +--------------+
     L1 L3 L4 L6            L1 L2 L5 L6                 L1 .. L6

  // the type of the variable decides HOW the letters are read
```

문제를 읽고 가장 먼저 정할 것은 "값이 몇 개이고 무엇으로 나뉘어 있는가"다. 네 가지 모양뿐이다.

```text
  input shape                  what to write
  --------------------------   -----------------------------------
  one value, one line          int n;      cin >> n;
      12                       double x;   cin >> x;
                               string s;   cin >> s;

  several values, one line     int a, b;   cin >> a >> b;
      3 5

  several values, separator    int y, m, d;  char s1, s2;
      2026-07-01               cin >> y >> s1 >> m >> s2 >> d;

  several values, many lines   int a, b;   cin >> a >> b;
      4                        // exactly the same code
      9
```

상자를 고르는 기준은 하나다. **이 값으로 계산할 것인가, 글자로 다룰 것인가.**

```text
              what will you do with the value?
                          |
          +---------------+---------------+
     compute with it?                show or cut it?
          |                               |
     int  or  double                 string  or  char
          |                               |
   int    : whole numbers        string : a word, s[0], s.size()
   double : has a decimal point  char   : one letter, a code number
```

**뼈대 코드**

입력 모양을 확인했으면 아래 다섯 개 중 하나를 골라 이름과 개수만 바꾼다.

```cpp
// 1) 값 하나를 받기
#include <iostream>
using namespace std;

int main() {
    int n;                     // <- 실수면 double, 글자면 string
    cin >> n;
    cout << n + 1 << "\n";     // <- 문제마다 바뀜
    return 0;
}
```

```cpp
// 2) 한 줄에 공백으로 붙어 온 여러 값 받기
#include <iostream>
using namespace std;

int main() {
    int a, b;                  // <- 값 개수만큼 변수를 늘린다
    cin >> a >> b;             // >> 도 같은 개수만큼
    cout << a + b << "\n";     // <- 문제마다 바뀜
    return 0;
}
```

```cpp
// 3) 정해진 문자로 구분된 값 받기
#include <iostream>
using namespace std;

int main() {
    int y, m, d;
    char s1, s2;               // 구분 문자를 받아서 버리는 상자
    cin >> y >> s1 >> m >> s2 >> d;   // <- 구분자 개수만큼 char
    cout << y << " " << m << " " << d << "\n";
    return 0;
}
```

```cpp
// 4) 여러 줄에 걸쳐 값 받기 (한 줄일 때와 코드가 같다)
#include <iostream>
using namespace std;

int main() {
    int a, b, c;               // <- 값 개수만큼 변수를 늘린다
    cin >> a >> b >> c;
    cout << a << " " << b * 2 << " " << c << "\n";
    return 0;
}
```

```cpp
// 5) 글자를 받아 그대로 다루기
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;                  // 한 단어를 그대로 받는다
    cout << s[0] << "\n";      // 첫 글자 (char 한 개)
    cout << "[" << s << "]" << "\n";   // <- 앞뒤 글자는 문제마다 바뀜
    return 0;
}
```

**언제 무엇을 쓰나**

| 상황 | 고르는 것 | 이유 | 복잡도 |
|------|-----------|------|--------|
| 정수 하나를 받는다 | `int n; cin >> n;` | 상자가 `int` 라서 숫자로 읽힌다 | O(1) |
| 소수점이 들어올 수 있다 | `double x; cin >> x;` | `int` 로 받으면 `.` 앞에서 잘린다 | O(1) |
| 단어·글자를 받는다 | `string s; cin >> s;` | 이미 글자라 변환이 필요 없다 | O(길이) |
| 한 글자만 받는다 | `char c; cin >> c;` | 코드 번호를 담는 작은 정수 상자다 | O(1) |
| 한 줄에 값이 여러 개(공백) | `cin >> a >> b;` | `>>` 가 공백을 알아서 건너뛴다 | O(1) |
| 값이 여러 줄에 나뉘어 있다 | `cin >> a >> b;` | 줄바꿈도 `>>` 에게는 그냥 구분자다 | O(1) |
| `-`, `:` 로 구분되어 있다 | `char` 로 받아 버리기 | 구분 문자를 치워야 다음 값이 읽힌다 | O(1) |
| 자른 값을 계산에 쓴다 | 처음부터 `int` 로 받기 | 받는 상자가 곧 변환이다 | O(1) |
| 앞의 `0` 을 없애고 싶다 | `int` 로 받기 | 수로 읽으면 앞의 0은 값에 기여하지 않는다 | O(1) |
| 앞의 `0` 을 유지해야 한다 | `string` 으로 받기 | 정수로 바꾸는 순간 모양이 사라진다 | O(길이) |
| 첫 글자만 필요하다 | `s[0]` | 인덱스는 0부터 시작한다 | O(1) |
| 문자 하나를 수로 바꾼다 | `s[0] - '0'` | 코드 번호의 차이가 곧 그 숫자다 | O(1) |
| 자릿수를 뽑는다 | `n / 10`, `n % 10` | 10묶음의 개수와 남는 낱개 | O(1) |
| 값 사이를 공백으로 출력 | `cout << a << " " << b;` | 공백은 자동으로 생기지 않는다 | O(1) |

**✅ 마스터 체크리스트**

- [ ] 설명할 수 있다: `cin >> n` 이 왜 따로 형 변환을 하지 않아도 되는가.
- [ ] 설명할 수 있다: 같은 `72` 를 `int` 로 받을 때와 `string` 으로 받을 때 무엇이 달라지는가.
- [ ] 설명할 수 있다: `cin >>` 가 값을 읽기 전에 무엇을 건너뛰는가.
- [ ] 설명할 수 있다: `int` 로 `4.2` 를 받으면 변수와 버퍼에 각각 무엇이 남는가.
- [ ] 설명할 수 있다: `double` 로 받은 `4` 가 왜 화면에는 `4` 로만 보이는가.
- [ ] 설명할 수 있다: 한 줄에 있는 두 값과 두 줄에 있는 두 값의 코드가 왜 같은가.
- [ ] 설명할 수 있다: 읽을 값이 부족하면 C++에서 무슨 일이 일어나는가.
- [ ] 설명할 수 있다: 선언만 하고 읽지 않은 변수를 쓰면 왜 위험한가.
- [ ] 설명할 수 있다: `12:30` 을 `cin >> a >> b;` 로 읽으면 왜 실패하는가.
- [ ] 설명할 수 있다: 구분 문자를 `char` 로 받는 것이 무엇을 해결해 주는가.
- [ ] 설명할 수 있다: `07` 을 정수로 읽으면 왜 `7` 이 되는가.
- [ ] 설명할 수 있다: 문자열의 첫 글자가 왜 `s[1]` 이 아니라 `s[0]` 인가.
- [ ] 설명할 수 있다: 범위를 벗어난 `s[5]` 가 파이썬과 어떻게 다르게 동작하는가.
- [ ] 설명할 수 있다: `'7'` 과 `7` 의 차이는 무엇이고 `'7' - '0'` 은 왜 `7` 인가.
- [ ] 설명할 수 있다: `72 / 10` 과 `72 % 10` 이 각각 어느 자리 숫자를 주는가.

**⚠️ 자주 하는 실수**

**(1) 화살표 방향을 거꾸로 쓴다**

```cpp
// ❌ 틀린 코드
int n;
cin << n;                 // 컴파일 오류
```

왜: `cin` 은 값을 **가져오는** 쪽이라 화살표가 변수 쪽(`>>`)으로 향한다. `<<` 는 `cout` 으로 값을 **내보낼** 때 쓴다.

```cpp
// ✅ 고친 코드
int n;
cin >> n;                 // 입력은 >>
cout << n << "\n";        // 출력은 <<
```

**(2) 선언만 하고 읽지 않은 채 계산한다**

```cpp
// ❌ 틀린 코드
int a, b;
cout << a + b << "\n";    // 쓰레기 값끼리 더한다
```

왜: C++은 선언만 한 지역 변수를 0으로 채워 주지 않는다. 값을 넣기 전에는 그 자리에 남아 있던 아무 값이나 들어 있어 실행할 때마다 답이 달라진다.

```cpp
// ✅ 고친 코드
int a, b;
cin >> a >> b;            // 먼저 값을 채운다
cout << a + b << "\n";
```

**(3) 소수가 들어올 수 있는데 `int` 로 받는다**

```cpp
// ❌ 틀린 코드
int x;
cin >> x;                 // 입력 "4.2" -> x = 4, 버퍼에 ".2" 가 남는다
```

왜: `>>` 는 정수로 읽을 수 있는 데까지만 읽고 멈춘다. 오류가 나지 않아 눈치채기 어렵고, 남은 `.2` 가 다음 입력까지 망가뜨린다.

```cpp
// ✅ 고친 코드
double x;
cin >> x;                 // "4" 도 "4.2" 도 받아 준다
```

**(4) 구분 문자를 치우지 않는다**

```cpp
// ❌ 틀린 코드
int a, b;
cin >> a >> b;            // 입력 "12:30" -> a = 12, b 는 못 읽는다
```

왜: `:` 는 숫자가 아니라서 `>>` 가 그 앞에서 멈추고 버퍼에 그대로 남긴다. 다음 `>>` 도 같은 자리에서 또 멈추므로 그 뒤로는 아무것도 읽히지 않는다.

```cpp
// ✅ 고친 코드
int a, b;
char sep;
cin >> a >> sep >> b;     // sep 이 ':' 를 받아 치운다
```

**(5) 값 개수와 변수 개수를 다르게 쓴다**

```cpp
// ❌ 틀린 코드
int a, b;
cin >> a >> b;            // 입력이 "1 2 3" 이면 3 이 남아 버린다
```

왜: `>>` 는 부른 횟수만큼만 읽는다. 남은 값은 조용히 버려지고, 반대로 값이 모자라면 그 변수는 쓰레기 값을 그대로 갖는다.

```cpp
// ✅ 고친 코드
int a, b, c;
cin >> a >> b >> c;       // 값 개수만큼 변수와 >> 를 맞춘다
```

**(6) 인덱스를 1부터 센다**

```cpp
// ❌ 틀린 코드
string s;
cin >> s;                 // 예: cat
cout << s[1] << "\n";     // a  (둘째 글자)
```

왜: 인덱스는 "맨 앞에서 몇 칸 떨어져 있는가"라서 첫 글자가 0번이다. 길이가 3이면 마지막은 `s[2]` 이고, `s[3]` 은 오류가 아니라 **옆 메모리를 읽는** 더 위험한 동작이 된다.

```cpp
// ✅ 고친 코드
string s;
cin >> s;
cout << s[0] << "\n";     // c
```

**(7) `char` 로 받은 숫자를 그대로 계산한다**

```cpp
// ❌ 틀린 코드
char c;
cin >> c;                 // 입력 "7"
cout << c + 1 << "\n";    // 56
```

왜: `char` 는 글자의 **코드 번호**를 담는다. `'7'` 의 코드는 55라서 1을 더하면 56이 된다.

```cpp
// ✅ 고친 코드
char c;
cin >> c;
cout << (c - '0') + 1 << "\n";   // 8
```

**(8) 숫자를 `string` 으로 받아 더한다**

```cpp
// ❌ 틀린 코드
string a, b;
cin >> a >> b;            // 입력 "3 5"
cout << a + b << "\n";    // 35
```

왜: 오류가 나지 않고 **조용히 틀린 답**이 나오기 때문에 더 위험하다. `string` 끼리의 `+` 는 덧셈이 아니라 이어 붙이기다.

```cpp
// ✅ 고친 코드
int a, b;
cin >> a >> b;
cout << a + b << "\n";    // 8
```

**다음 챕터로**

- Ch02는 "값을 어떻게 안으로 들여올 것인가"였다. Ch03은 들여온 값으로 **무엇을 계산할 것인가**를 다룬다.
- 특히 `/` 와 `%` 는 이 챕터에서 자릿수를 뽑을 때 맛만 봤고, Ch03에서 정수 나눗셈과 소수 나눗셈의 차이를 제대로 정리한다.
- 입력 뼈대(`int n; cin >> n;`, `cin >> a >> b;`)는 이후 모든 챕터의 첫 두 줄이 된다. 손이 기억할 때까지 반복해 두면 이후에는 문제의 알맹이에만 집중할 수 있다.
