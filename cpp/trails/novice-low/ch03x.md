## L3. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch03(연산자)의 핵심을 **반복 훈련**하고, 코딩테스트 단골 유형으로 **확장**하는 연습 세트입니다. 조건문·반복문 없이 연산자만으로 답을 만드는 문제들입니다.
- **반복 훈련 개념**: 아래 다섯 가지를 소재만 바꿔 여러 번 다시 씁니다.

- 사칙연산 — `a + b`, `a - b`, `a * b`, `a / b`. C++의 `/` 는 **양쪽이 모두 정수면 정수 나눗셈**이라 소수점 아래를 버립니다(`7 / 2` 는 `3`). 소수까지 필요하면 한쪽을 실수로 만듭니다: `(double)a / b`.
- 몫과 나머지 — 정수끼리의 `a / b` 가 몫, `a % b` 가 나머지입니다. "몇 묶음과 몇 개가 남는가"를 셀 때 씁니다. `%` 는 정수 전용이라 `double` 에는 쓸 수 없습니다.
- 우선순위와 괄호 — 곱셈·나눗셈이 덧셈·뺄셈보다 먼저. 순서를 바꾸려면 `(a + b) * c` 처럼 괄호로 묶습니다.
- 합과 평균 — `total = a + b + c` 로 합을 먼저 담고, `total / 3` 으로 평균을 구합니다. `total` 이 `int` 면 이 나눗셈도 정수 나눗셈이 되어 소수가 사라지니, 평균이 필요하면 `double` 로 계산합니다.
- 소수점 출력(Ch01) — `cout << fixed << setprecision(2) << x` 또는 `printf("%.2f", x)` 로 소수점 아래 자릿수를 고정해 출력합니다.

- **코딩테스트 출제 맵**: 백준 「단계별로 풀어보기」의 '입출력과 사칙연산' 단계(A/B, 나머지, 사칙연산, 시간 계산)와 solved.ac CLASS 1이 이 챕터 수준입니다. 『이것이 취업을 위한 코딩테스트다』 '그리디' 파트의 거스름돈 문제도 조건문·반복문 없이 `/`·`%` 만으로 축소해 연습합니다.
- **문제 구성표**:

**문제**

**1) 나눗셈 두 가지** · Easy

- **요구사항**: 두 정수를 입력받아 첫째 줄에 실수 나눗셈 결과, 둘째 줄에 정수 나눗셈 결과(몫)를 출력합니다. C++의 `a / b` 는 양쪽이 정수면 몫만 남기므로, 실수 결과가 필요한 첫째 줄은 `(double)a / b` 로 계산합니다.
- **입력**: 한 줄에 두 정수 `a b` 가 공백으로 구분되어 주어집니다. (`b` 는 1 이상)
- **출력**: 첫째 줄에 실수 나눗셈 결과, 둘째 줄에 몫을 출력합니다.
- **예제**: `7 2` → `3.5 / 3` (두 줄)
- **예제**: `8 4` → `2 / 2` (두 줄)
- **셀프체크**: 첫째 줄에서 `(double)` 캐스팅을 빠뜨리면 `3.5` 가 아니라 `3` 이 나온다는 점을 확인했는가? 딱 나누어떨어지는 `8 4` 에서는 두 줄이 똑같이 `2` 로 보이는데, 그래도 첫째 줄은 `double`, 둘째 줄은 `int` 다. 화면 모양만으로는 자료형을 알 수 없다는 점을 이해했는가? `1 3` 의 첫째 줄이 `0.333333` 에서 끊기는 이유를 설명할 수 있는가?

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << (double)a / b << "\n";
    cout << a / b << "\n";
    return 0;
}
@@TESTS
--IN
7 2
--OUT
3.5
3
--IN
8 4
--OUT
2
2
--IN
1 3
--OUT
0.333333
0
@@EXPL
(1) 접근·핵심 아이디어

- C++의 `/` 는 하나뿐이지만 양쪽 자료형에 따라 뜻이 갈립니다. **정수 ÷ 정수**면 소수점 아래를 버린 몫이 나오고, 한쪽이라도 실수면 소수까지 계산한 실수가 나옵니다.
- 그래서 실수 결과가 필요하면 `(double)a / b` 로 한쪽을 실수로 바꿔 줍니다. 캐스팅은 `/` 보다 먼저 적용되므로 괄호를 더 씌울 필요는 없습니다.
- 같은 두 수로 둘을 나란히 출력해 차이를 눈으로 확인하는 문제입니다.

(2) 코드 단계별

- `int a, b; cin >> a >> b;` — 두 정수를 받습니다.
- `cout << (double)a / b << "\n";` — 실수 나눗셈입니다. `7 / 2 = 3.5`, `8 / 4 = 2.0`, `1 / 3 = 0.333...`.
- `cout << a / b << "\n";` — 여기서는 `a`, `b` 가 모두 `int` 라 정수 나눗셈이 됩니다. `7 / 2 = 3`, `8 / 4 = 2`, `1 / 3 = 0`.
- 출력 모양에서 두 가지를 확인합니다. 첫째, `cout` 은 실수를 **유효숫자 여섯 자리**까지만 보여 주므로 `1.0 / 3` 이 `0.333333` 에서 끊깁니다. 둘째, 필요 없는 소수점과 뒤따르는 0은 지우므로 `8 4` 의 실수 결과 `2.0` 이 `2` 로 나옵니다. 값이 바뀐 게 아니라 표시가 짧아진 것뿐입니다.

(3) 스스로 다시 짤 때 생각 순서

- "소수가 필요한가, 몫만 필요한가?" 를 문제마다 먼저 정합니다. C++에서는 이 판단이 곧 캐스팅 여부입니다.
- C++ 함정 1: `double q = a / b;` 라고 쓰면 오른쪽이 먼저 정수 나눗셈으로 계산된 뒤 `3` 이 `3.0` 으로 담깁니다. 캐스팅은 **나누기 전에**, 즉 피연산자 하나에 붙여야 합니다.
- C++ 함정 2: `8 4` 에서 두 줄이 똑같이 `2` 로 보인다고 해서 둘이 같은 계산인 것은 아닙니다. 화면만 보고 자료형을 판단하면 안 됩니다. 자릿수를 눈에 보이게 고정하려면 `<iomanip>` 을 포함하고 `cout << fixed << setprecision(n)` 을 씁니다.
- `1 3` 처럼 앞이 작은 경우 몫이 `0` 이 되는 것도 정상임을 확인합니다.
```

**2) 초를 분과 초로** · Easy

- **요구사항**: 초 단위 시간을 입력받아 "몇 분 몇 초"인지 두 값을 공백으로 구분해 출력합니다.
- **입력**: 0 이상 10000 이하의 정수(초)가 한 줄에 주어집니다.
- **출력**: 분과 초를 공백 하나를 두고 한 줄에 출력합니다.
- **예제**: `150` → `2 30` · `59` → `0 59`
- **셀프체크**: 분은 `n / 60`(정수끼리의 나눗셈이므로 몫), 초는 `n % 60`(나머지)입니다. 60초 미만이면 분이 `0` 인가? `3600` 처럼 딱 떨어지면 초가 `0` 인가? 두 값 사이 공백을 `<< " " <<` 로 직접 넣었는가?

```runner

@@TESTS

(1) 접근·핵심 아이디어

- 1분은 60초입니다. 초를 60으로 나눈 몫이 "분", 나머지가 "남은 초"입니다.
- C++에서 `int / int` 는 자동으로 몫만 남기므로 "소수점 아래 버리기"를 위한 별도의 연산자나 함수가 필요 없습니다. `/` 하나가 그 일을 그대로 해 줍니다.
- "몇 묶음이 되고 몇 개가 남는가"는 `/` 와 `%` 의 대표 쓰임입니다. 조건문 없이 두 연산자만으로 답이 나옵니다.

(2) 코드 단계별

- `int n; cin >> n;` — 초를 정수로 받습니다.
- `n / 60` — `150 / 60 = 2`(분). `n % 60` — `150 % 60 = 30`(초).
- `cout << n / 60 << " " << n % 60 << "\n";` — 사이에 공백을 직접 넣어 `2 30`. `59` 는 `0 59`, `3600` 은 `60 0`, `0` 은 `0 0` 이 됩니다.

(3) 스스로 다시 짤 때 생각 순서

- "단위가 큰 쪽(분)은 몫, 작은 쪽(초)은 나머지"로 정리합니다.
- 나누는 수는 단위 사이의 배수(60)입니다.
- C++ 함정: `n` 을 `double` 로 선언하면 `/` 가 실수 나눗셈이 되어 `2.5` 가 나오고, `%` 는 아예 컴파일되지 않습니다. 자릿수·단위 분리는 반드시 정수형으로 합니다.
- 경계값: 60 미만(분이 0), 60의 배수(초가 0), 0(둘 다 0)을 손으로 검산합니다.
```

**3) 평균 속력** · Easy

- **요구사항**: 이동 거리(km)와 걸린 시간(시간)을 입력받아 평균 속력(거리 ÷ 시간)을 출력합니다. 정수끼리 나누면 몫만 남으므로 `(double)d / t` 로 실수 나눗셈을 합니다.

- **출력**: 거리를 시간으로 나눈 값을 한 줄에 출력합니다.
- **예제**: `150 2` → `75` · `100 3` → `33.3333`
- **셀프체크**: 속력은 소수까지 필요하므로 정수 나눗셈이 되지 않도록 `(double)` 을 붙였는가? `100 / 3` 의 결과가 `33.3333` 에서 끊기는 이유(`cout` 의 기본 유효숫자 여섯 자리)를 설명할 수 있는가? 딱 나누어떨어지는 `150 2` 가 `75.0` 이 아니라 `75` 로 나오는 것이 정상임을 이해했는가?

```runner
#include <iostream>

@@TESTS

(1) 접근·핵심 아이디어

- 평균 속력은 "거리 ÷ 시간"입니다. 소수가 나올 수 있으므로 정수 나눗셈이 되지 않게 `(double)d / t` 로 계산합니다.
- 반올림 자릿수를 정하지 않은 문제이므로 `cout` 의 기본 설정에 맡깁니다. `cout` 은 실수를 **유효숫자 여섯 자리**까지 보여 주고, 필요 없는 소수점과 뒤따르는 0은 지웁니다.
- 그래서 `100 / 3` 은 `33.3333` 에서 끊기고, 딱 떨어지는 `150 / 2` 는 `75.0` 이 아니라 `75` 로 나옵니다. 두 경우 모두 값이 바뀐 것이 아니라 표시 방식일 뿐입니다.

(2) 코드 단계별

- `int d, t; cin >> d >> t;` — 거리와 시간을 정수로 받습니다.
- `cout << (double)d / t << "\n";` — `(double)d` 로 왼쪽을 실수로 만든 뒤 나눕니다. `150 / 2 = 75.0`, `100 / 3 = 33.3333...`, `0 / 5 = 0.0`.
- 화면에는 `75`, `33.3333`, `0` 이 나옵니다. 유효숫자 여섯 자리라 `33.3333` 은 소수점 아래 네 자리까지만 보입니다(앞의 `33` 두 자리를 포함해 여섯 자리).

(3) 스스로 다시 짤 때 생각 순서

- "결과가 소수일 수 있나?" → 그렇다 → 한쪽을 `double` 로 캐스팅합니다.
- 나누는 순서(거리 ÷ 시간)를 확인합니다. 반대로 하면 뜻이 달라집니다.
- C++ 함정: `(double)(d / t)` 라고 괄호를 잘못 치면 정수 나눗셈이 먼저 끝난 뒤 실수로 바뀌므로 `33` 이 나옵니다. 캐스팅은 나누기 **전에**, 즉 피연산자 하나에 붙여야 합니다.
- 출력 자릿수를 문제가 지정했다면 `<iomanip>` 을 포함하고 `cout << fixed << setprecision(n)` 으로 고정합니다. 지정이 없는 이 문제에서는 기본 모양 그대로 둡니다.
- 거리 `0` 이면 결과도 `0`, 시간은 0이 아니라는 조건(0으로 나누면 실수 나눗셈에서는 `inf`, 정수 나눗셈에서는 프로그램이 죽습니다)을 확인합니다.
```

**4) 체질량지수 두 자리** · Easy

- **요구사항**: 키(m, 실수)와 몸무게(kg, 실수)를 입력받아 체질량지수 `몸무게 ÷ (키 × 키)` 를 소수점 아래 둘째 자리까지 출력합니다.
- **입력**: 한 줄에 실수 두 개 `키 몸무게` 가 공백으로 구분되어 주어집니다. (키는 0보다 큼, 소수점 없는 형태로 올 수도 있음)
- **출력**: 체질량지수를 소수점 아래 둘째 자리까지 한 줄에 출력합니다.
- **예제**: `1.75 70` → `22.86` · `1.6 51.2` → `20.00`
- **셀프체크**: 두 값 모두 `double` 로 받았는가? `w / (h * h)` 처럼 분모를 괄호로 묶었는가(괄호가 없으면 `w / h * h` 가 되어 왼쪽부터 계산돼 틀린다)? 결과가 딱 20이어도 `fixed` 덕분에 `20.00` 으로 두 자리를 채우는가?

```runner
@@SOLUTION
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double h, w;
    cin >> h >> w;
    double bmi = w / (h * h);
    cout << fixed << setprecision(2) << bmi << "\n";
    return 0;
}
@@TESTS
--IN
1.75 70
--OUT
22.86
--IN
1.6 51.2
--OUT
20.00
--IN
1.8 90
--OUT
27.78
@@EXPL
(1) 접근·핵심 아이디어

- 공식 "몸무게 ÷ (키 × 키)"를 그대로 옮깁니다. 곱셈과 나눗셈은 우선순위가 같아 왼쪽부터 계산되므로, 분모 전체가 먼저 계산되도록 괄호로 묶어야 합니다.
```

**5) 다섯 명의 키 합과 평균** · Medium

```runner
(3) 스스로 다시 짤 때 생각 순서

- "값이 몇 개?" → 다섯 → 변수 다섯, `>>` 다섯 번.

- C++ 함정: 키를 `int` 로 받아 `int total` 에 담았다면 `total / 5` 가 정수 나눗셈이 되어 소수가 사라집니다. 평균이 필요하면 합 자체를 `double` 로 두거나 `total / 5.0` 으로 나눕니다.
```

**6) 정육면체 부피와 겉넓이** · Medium

- **요구사항**: 정육면체 한 변의 길이(정수)를 입력받아 첫째 줄에 부피(한 변의 세제곱), 둘째 줄에 겉넓이(한 변의 제곱 × 6)를 출력합니다. C++에는 거듭제곱 연산자가 없으므로 `a * a * a`, `6 * a * a` 처럼 직접 곱합니다.

```runner
- 식을 옮길 때 "무엇이 먼저 계산되어야 하나?" 를 정하고, 먼저 계산할 부분을 괄호로 묶습니다.
```

**8) 동전 최소 개수** · Hard

- **요구사항**: 거스름돈(10의 배수)을 입력받아 500원, 100원, 10원 동전으로 거슬러 줄 때 각 동전의 최소 개수를 출력합니다. 큰 동전부터 최대한 많이 쓰면 개수가 최소가 됩니다. 조건문과 반복문 없이 정수 나눗셈 `/` 와 나머지 `%` 만으로 풉니다.
- **입력**: 0 이상 100000 이하이며 10의 배수인 정수 하나가 한 줄에 주어집니다.
- **출력**: 500원 개수, 100원 개수, 10원 개수를 공백으로 구분해 한 줄에 출력합니다.
- **예제**: `1730` → `3 2 3` · `990` → `1 4 9`
- **셀프체크**: 500원 개수는 `n / 500`, 그다음 남은 돈은 `n % 500` 입니다. 남은 돈으로 100원 개수와 나머지를 구하고, 마지막 남은 돈으로 10원 개수를 구합니다. 매 단계 "남은 돈"을 변수에 다시 담았는가? `0` 이면 `0 0 0`, `500` 이면 `1 0 0` 인가?

```runner
@@SOLUTION

int main() {

    int c500 = n / 500;
    n = n % 500;
    int c100 = n / 100;
    n = n % 100;
    int c10 = n / 10;
    cout << c500 << " " << c100 << " " << c10 << "\n";
    return 0;
}
@@TESTS

(1) 접근·핵심 아이디어

- 동전 개수를 최소로 하려면 큰 동전부터 최대한 많이 씁니다. "최대한 몇 개"는 정수 나눗셈 `/`, "그러고 남은 돈"은 나머지 `%` 입니다.
- `n` 이 `int` 이므로 `n / 500` 은 자동으로 몫만 남깁니다. 별도의 버림 처리가 필요 없습니다.
- 이 과정을 500 → 100 → 10 순서로 세 번 반복합니다. 반복문 없이도 같은 두 줄을 세 번 쓰면 됩니다. 핵심은 매 단계 남은 돈을 변수 `n` 에 다시 담아(Ch01 값 변경) 다음 단계가 그 값을 쓰게 하는 것입니다.

(2) 코드 단계별

- `int n; cin >> n;` — 거스름돈 `1730`.
- `int c500 = n / 500;` → `3`. `n = n % 500;` → 남은 돈 `230`.
- `int c100 = n / 100;` → `2`. `n = n % 100;` → 남은 돈 `30`.
- `int c10 = n / 10;` → `3`. 10의 배수이므로 더 남는 돈은 없습니다.
- `cout << c500 << " " << c100 << " " << c10 << "\n";` → `3 2 3`. `990` 은 `1`, 남은 `490` → `4`, 남은 `90` → `9`. `0` 은 모든 단계가 `0`, `500` 은 `1 0 0`.

(3) 스스로 다시 짤 때 생각 순서

- 동전을 큰 것부터 나열하고, 각 동전마다 "개수 = 남은 돈 / 동전", "남은 돈 = 남은 돈 % 동전" 두 줄을 씁니다. C++에서는 `n /= 500;` 이 아니라 `n %= 500;` 이 "남은 돈"이라는 점에 주의합니다.
- 남은 돈을 새 변수가 아니라 같은 `n` 에 덮어써야 다음 단계가 이어집니다. 원래 `n` 으로 계속 계산하면 개수가 중복됩니다.
- C++ 함정: 여기서 `n` 을 `double` 로 선언하면 `/` 가 실수 나눗셈이 되어 `3.46` 같은 값이 나오고 `%` 는 컴파일조차 되지 않습니다. 동전·자릿수 문제는 정수형으로 시작합니다.
- 경계값 `0`(모두 0)과 `500`(첫 동전 하나로 끝)을 손으로 검산합니다.
```
