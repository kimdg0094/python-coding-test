## L15. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch9(문자열)의 핵심을 **반복 훈련**하고, 코딩테스트 단골 유형으로 **확장**하는 연습 세트다. 문자열을 한 글자씩 순회하며 세고·판별하고·고치거나 새로 만들어 내는 기본기를 소재만 바꿔 여러 번 다시 쓴 뒤, 카이사르 암호·연속 글자 압축·최다 빈도 글자·아나그램 같은 단골 유형까지 이어 간다.

- **반복 훈련 개념**:
  - 순회하며 세기: `for (char c : s)` 안에서 `if (string("aeiou").find(c) != string::npos) cnt++;`
  - 글자 종류 판별: 소문자 `'a' <= c && c <= 'z'`, 대문자 `'A' <= c && c <= 'Z'`, 숫자 `'0' <= c && c <= '9'`
  - 제자리 수정과 새 문자열: `s[0] = 'x';`로 원본을 고치거나, 길이가 달라지면 `string result = "";`에서 `result += 글자;`
  - 아스키 계산: `(char)((c - 'a' + k) % 26 + 'a')`처럼 `char`를 정수처럼 빼고 더한 뒤 `(char)`로 되돌린다
  - 부분 문자열·비교·변환: `s.substr(i, p.size()) == p`, `reverse(s.begin(), s.end())`, `c - '0'`, `to_string(cnt)`

- **C++ 문자열에서 특히 조심할 것**:
  - **C++ `string`은 가변이다 — 파이썬과 정반대다.** 파이썬에서는 `s[0] = "x"`가 곧바로 `TypeError`라 "새 문자열을 만든다"가 유일한 길이었지만, C++에서는 `s[0] = 'x';`가 그대로 동작하고 원본이 실제로 바뀐다. 그래서 이 레슨의 문제들은 "제자리로 고칠까, 새로 만들까"를 매번 고를 수 있다. 길이가 그대로면 제자리, 길이가 달라지면 새 문자열이 편하다. 원본을 나중에 또 써야 하면 `string t = s;`로 사본을 만들어 고친다(`=`가 값을 통째로 복사하므로 사본은 완전히 독립이다).
  - `s.size()`와 `s.length()`는 **부호 없는 정수**를 돌려준다. `s.size() - p.size()`에서 `p`가 더 길면 음수가 아니라 40억이 넘는 값이 되어 반복이 폭주한다. 크기는 먼저 `int n = s.size();`로 받아 두고 계산은 `int`로 한다.
  - `s.find(t)`는 못 찾으면 `string::npos`를 돌려준다. 이건 -1이 아니라 **부호 없는 최댓값**이라 `if (s.find(t) < 0)`은 절대 참이 되지 않는다. 반드시 `!= string::npos` / `== string::npos`로 비교한다.
  - `s.substr(pos, len)`의 둘째 인자는 "끝 위치"가 아니라 **길이**다. `pos == s.size()`면 빈 문자열이 나오지만 `pos > s.size()`면 `out_of_range` 예외를 던진다.
  - `s[i]`는 범위를 검사하지 않는다. `i`가 크거나 음수여도 오류 없이 통과하고 쓰레기 값이 나온다. 검사를 원하면 `s.at(i)`를 쓴다.
  - `char`는 작은따옴표, `string`은 큰따옴표다. `s[i] = "x";`는 컴파일 오류이고, `"ab" + "cd"`처럼 리터럴끼리 `+`하는 것도 안 된다(한쪽은 `string`이어야 한다).

- **코딩테스트 출제 맵**: 백준 「단계별로 풀어보기」의 '문자열' 단계(글자 세기·아스키·단어 다루기), solved.ac CLASS 1~2의 문자열 문제, NeetCode 150의 'Arrays & Hashing'(아나그램·빈도 세기를 이 수준에서는 26칸 배열로 푼다), 프로그래머스 「코딩테스트 고득점 Kit」 '해시' 유형의 입문 형태가 여기서 시작된다.

**문제**

**1) 모음 개수 세기** · Easy

- **요구사항**: 소문자로만 이루어진 문자열을 입력받아, 모음(`a`, `e`, `i`, `o`, `u`)이 모두 몇 번 나오는지 출력한다.
- **입력**: 한 줄에 공백 없는 소문자 문자열 `s`(길이 1 이상 100 이하).
- **출력**: 모음의 개수(정수).
- **예제**: `banana` → `3` · `rhythm` → `0`
- **셀프체크**: 모음 다섯 개를 `if (c == 'a' || c == 'e' || ...)`로 늘어놓아도 되지만, 모음을 모아 둔 `string vowels = "aeiou";`에 `vowels.find(c) != string::npos`를 쓰면 짧다. 이때 `find`의 결과를 `>= 0`으로 검사하면 **항상 참**이 되니 반드시 `!= string::npos`로 비교할 것. 모음이 하나도 없으면 0이 나와야 하므로 `cnt`는 0에서 시작.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;
    string vowels = "aeiou";
    int cnt = 0;
    for (char c : s) {
        if (vowels.find(c) != string::npos) {
            cnt++;
        }
    }
    cout << cnt << '\n';
    return 0;
}
@@TESTS
--IN
banana
--OUT
3
--IN
rhythm
--OUT
0
--IN
aeiou
--OUT
5
@@EXPL
(1) 접근·핵심 아이디어

- "특정 글자 개수 세기"의 확장으로, 찾는 글자가 한 개가 아니라 다섯 개(모음)다. 글자마다 "이 글자가 모음인가?"를 물어 참이면 센다.
- 모음 다섯 개를 `string vowels = "aeiou";` 한 줄에 모아 두면, "이 글자가 그 안에 있는가"는 `vowels.find(c)` 한 번으로 끝난다. 조건 다섯 개를 `||`로 잇는 것과 결과가 같다.

(2) 코드 단계별

- 문자열 `s`를 `cin >> s;`로 받는다(공백이 없다고 했으므로 이걸로 충분하다). `cnt = 0`으로 시작한다.
- `for (char c : s)`로 글자를 하나씩 꺼낸다. 값을 고치지 않으므로 복사로 받아도 되고, `for (char c : s)`가 가장 읽기 쉽다.
- `vowels.find(c) != string::npos`이면 `cnt++`. `find`는 찾은 위치를 돌려주고, 못 찾으면 `string::npos`를 돌려준다.
- 순회가 끝나면 `cnt`를 출력한다. `rhythm`처럼 모음이 없으면 0이 그대로 남는다.

(3) 스스로 다시 짤 때 생각 순서

- 무엇을 세나 → 모음인 글자. 카운터 0에서 시작.
- 모음 판별을 어떻게 짧게 쓰나 → 모음을 모은 문자열에 `find`. 대문자 모음까지 세야 한다면 `"aeiouAEIOU"`로 늘리면 된다.
- **`npos` 함정** → `string::npos`는 -1이 아니라 부호 없는 정수의 최댓값이다. `if (vowels.find(c) >= 0)`은 못 찾았을 때도 참이라 모든 글자를 세어 버린다. 비교는 언제나 `!= string::npos`.
- 언제 찍나 → 순회가 끝난 뒤 한 번.
```

**2) 섞인 문자열의 숫자 합** · Easy

- **요구사항**: 영문자와 숫자가 섞인 문자열에서 숫자 글자만 골라, 그 값들을 모두 더해 출력한다. 숫자 글자가 하나도 없으면 `0`을 출력한다.
- **입력**: 한 줄에 공백 없는 문자열 `s`(길이 1 이상 100 이하, 영문자와 숫자만 포함).
- **출력**: 숫자 글자 값의 합(정수).
- **예제**: `a1b2c3` → `6` · `abc` → `0`
- **셀프체크**: 숫자 글자인지 판별은 `'0' <= c && c <= '9'`. 글자를 값으로 바꿀 때는 `c - '0'`을 쓴다(`'7' - '0'`이 7). 판별 없이 그냥 `total += c;`를 하면 `char`의 아스키 코드가 통째로 더해져 엉뚱한 값이 나오고, 컴파일 오류조차 나지 않으니 더 위험하다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;
    int total = 0;
    for (char c : s) {
        if ('0' <= c && c <= '9') {
            total += c - '0';
        }
    }
    cout << total << '\n';
    return 0;
}
@@TESTS
--IN
a1b2c3
--OUT
6
--IN
abc
--OUT
0
--IN
9x9
--OUT
18
@@EXPL
(1) 접근·핵심 아이디어

- 각 자리 숫자의 합(L12)과 같은 누적이지만, 이번엔 영문자가 섞여 있어 "숫자 글자인가?"를 먼저 걸러야 한다. 거른 글자만 값으로 바꿔 더한다.
- 숫자 글자 판별은 아스키 순서를 이용한 범위 비교 `'0' <= c && c <= '9'`다. `'0'`부터 `'9'`까지 코드가 이어져 있으므로 이 비교 하나로 열 개의 숫자 글자를 모두 잡는다.

(2) 코드 단계별

- 문자열 `s`를 받고 `total = 0`으로 시작한다.
- `for (char c : s)`로 글자를 하나씩 꺼내, `'0' <= c && c <= '9'`일 때만 `total += c - '0';`.
- `c - '0'`이 왜 값이 되는가 → `char`는 정수처럼 계산된다. `'9'`는 57, `'0'`은 48이므로 `'9' - '0'`은 9다. 아스키 코드가 연속이라 이 뺄셈이 곧 자릿값이 된다.
- 영문자는 조건에 걸리지 않아 건너뛴다. 순회 후 `total`을 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- 무엇을 더하나 → 숫자 글자의 값. 그러니 "판별 → 변환 → 누적" 세 단계.
- 판별을 빼먹으면 → 영문자의 아스키 코드까지 더해져 `abc`가 294가 된다. 파이썬처럼 예외로 알려 주지 않으므로 직접 거르는 수밖에 없다.
- `- '0'`을 빼먹으면 → `'1'`이 49로 더해진다. 이것도 조용히 틀린다.
- 숫자가 없으면 → `total`이 0으로 남아 그대로 정답.
```

**3) 대문자와 소문자 개수** · Easy

- **요구사항**: 문장을 입력받아 대문자의 개수와 소문자의 개수를 공백으로 구분해 한 줄에 출력한다. 공백·숫자·기호는 어느 쪽에도 세지 않는다.
- **입력**: 한 줄에 문자열 `s`(길이 1 이상 100 이하, 공백 포함 가능).
- **출력**: `대문자개수 소문자개수` 형태의 한 줄.
- **예제**: `Hello World` → `2 8` · `12345` → `0 0`
- **셀프체크**: 공백이 들어 있으므로 `cin >> s`가 아니라 `getline(cin, s)`로 한 줄을 통째로 받아야 한다(`cin >> s`는 공백에서 끊겨 `Hello`만 읽는다). 대문자는 `'A' <= c && c <= 'Z'`, 소문자는 `'a' <= c && c <= 'z'`. 공백은 둘 다 아니므로 자동으로 빠진다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    getline(cin, s);
    int up = 0;
    int low = 0;
    for (char c : s) {
        if ('A' <= c && c <= 'Z') {
            up++;
        } else if ('a' <= c && c <= 'z') {
            low++;
        }
    }
    cout << up << ' ' << low << '\n';
    return 0;
}
@@TESTS
--IN
Hello World
--OUT
2 8
--IN
12345
--OUT
0 0
--IN
ABC
--OUT
3 0
@@EXPL
(1) 접근·핵심 아이디어

- 글자마다 "대문자인가, 소문자인가, 둘 다 아닌가"를 판별해 해당 카운터를 올린다. 한 글자는 세 경우 중 하나에만 속하므로 `if / else if`로 이어 쓴다.
- 대문자와 소문자는 아스키 범위가 따로 있다(`'A'`=65~`'Z'`=90, `'a'`=97~`'z'`=122). 범위 비교 두 개로 판별한다.

(2) 코드 단계별

- 공백이 섞인 한 줄이므로 `getline(cin, s);`로 받는다. `cin >> s`는 공백을 구분자로 보고 첫 단어에서 멈춘다.
- 카운터 `int up = 0;`, `int low = 0;`을 준비한다.
- `for (char c : s)`로 글자를 순회하며 `'A' <= c && c <= 'Z'`면 `up++`, 아니고 `'a' <= c && c <= 'z'`면 `low++`.
- 공백·숫자는 두 조건 모두 거짓이라 아무것도 하지 않는다.
- `cout << up << ' ' << low << '\n';`으로 두 수 사이에 공백 하나를 직접 넣어 출력한다. C++의 `<<`는 값 사이에 공백을 자동으로 넣어 주지 않는다.

(3) 스스로 다시 짤 때 생각 순서

- 입력에 공백이 있나 → 있으면 `getline`. 이 판단을 먼저 한다.
- 카운터가 몇 개 필요한가 → 두 개(대·소). 셋째 경우는 그냥 무시.
- 판별 범위를 어떻게 쓰나 → `'A' <= c && c <= 'Z'`(작은따옴표 = `char` 하나). 표준 함수 `isupper(c)`, `islower(c)`를 써도 같다.
- 출력 형식 → 사이 공백을 직접 `' '`로 넣는다.
```

**4) 양 끝 글자 맞바꾸기** · Easy

- **요구사항**: 공백 없는 문자열의 첫 글자와 마지막 글자를 서로 맞바꾼 결과를 출력한다. 길이가 1이면 원래 문자열을 그대로 출력한다.
- **입력**: 한 줄에 공백 없는 문자열 `s`(길이 1 이상 50 이하).
- **출력**: 양 끝 글자를 맞바꾼 문자열.
- **예제**: `apple` → `eppla` · `ab` → `ba`
- **셀프체크**: **C++ `string`은 가변이다.** 파이썬처럼 조각을 이어 붙일 필요 없이 `swap(s[0], s[n-1]);` 한 줄로 두 글자를 제자리에서 맞바꾸면 된다. 이 방식이면 길이 1일 때 같은 칸끼리 교환해 아무 일도 일어나지 않으므로 예외 처리가 저절로 해결된다. 대신 `int n = s.size();`처럼 크기를 **`int`로 받아 두는** 습관을 들이자 — `s.size() - 1`을 그대로 쓰면 부호 없는 계산이 되어, 빈 문자열이 들어올 수 있는 문제에서 거대한 인덱스로 변한다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;
    int n = s.size();
    swap(s[0], s[n - 1]);
    cout << s << '\n';
    return 0;
}
@@TESTS
--IN
apple
--OUT
eppla
--IN
ab
--OUT
ba
--IN
x
--OUT
x
@@EXPL
(1) 접근·핵심 아이디어

- **이 문제가 파이썬과 C++이 갈리는 지점이다.** 파이썬 문자열은 불변이라 `s[0] = ...`이 오류였고, 그래서 "마지막 글자 + 가운데 + 첫 글자"를 이어 붙인 새 문자열을 만들어야 했다. C++ `string`은 가변이라 칸을 직접 바꿀 수 있다.
- 두 칸의 값을 서로 바꾸는 일은 `swap(s[0], s[n-1]);` 한 줄이다. 손으로 쓰면 `char t = s[0]; s[0] = s[n-1]; s[n-1] = t;` 세 줄인데, 임시 변수 없이 `s[0] = s[n-1]; s[n-1] = s[0];`로 쓰면 첫 줄에서 원래 첫 글자가 사라져 두 칸이 같은 글자가 되는 고전적인 함정에 빠진다.

(2) 코드 단계별

- 문자열 `s`를 받고 `int n = s.size();`로 길이를 `int`에 담는다.
- `swap(s[0], s[n - 1]);` — `s[0]`과 `s[n-1]`은 문자열 안의 실제 칸을 가리키므로, 교환하면 `s` 자체가 바뀐다.
- `cout << s << '\n';`으로 바뀐 원본을 그대로 출력한다.
- 길이 1일 때: `n - 1 == 0`이라 `swap(s[0], s[0])`이 되어 아무 변화가 없다. 문제가 요구한 "그대로 출력"이 저절로 만족된다.

(3) 스스로 다시 짤 때 생각 순서

- 길이가 변하나 → 변하지 않는다. 그러면 제자리 수정이 가장 짧다. 길이가 변하는 문제(삽입·삭제·압축)라면 새 문자열을 쌓는 편이 낫다.
- 두 값을 바꾸려면 → `swap`, 또는 임시 변수 한 개. 임시 변수 없이 두 줄로 쓰면 반드시 틀린다.
- 조각을 이어 붙이는 방식으로 풀면 → `s.substr(n-1) + s.substr(1, n-2) + s[0]` 꼴이 되는데, 길이 1에서 `s.substr(1, ...)`이 빈 문자열이 되어 같은 글자 두 개(`xx`)가 나온다. 파이썬 풀이가 예외 처리를 따로 둔 이유가 그것이고, 제자리 교환을 쓰면 그 예외가 사라진다.
- 크기를 어떻게 들고 다니나 → `int n = s.size();`. `s.size() - 1`을 식 안에서 바로 쓰지 않는다.
```

**5) 붙어 있는 같은 글자 쌍** · Easy

- **요구사항**: 문자열에서 바로 옆 글자와 같은 자리가 몇 곳인지 센다. 즉 `s[i]`와 `s[i+1]`이 같은 `i`의 개수를 출력한다.
- **입력**: 한 줄에 공백 없는 문자열 `s`(길이 1 이상 100 이하).
- **출력**: 같은 글자가 붙어 있는 쌍의 개수.
- **예제**: `aabbcc` → `3` · `abc` → `0`
- **셀프체크**: `s[i+1]`을 보므로 `i`는 `n - 2`까지만 가야 한다. 반복 조건은 `i < n - 1`이고, 이때 `n`은 반드시 `int n = s.size();`로 받아 둔 값이어야 한다. `i < s.size() - 1`로 바로 쓰면 부호 없는 계산이라 빈 문자열에서 반복이 폭주한다. `aaaa`는 (0,1), (1,2), (2,3) 세 쌍이라 3이다. 길이 1이면 반복이 한 번도 돌지 않아 0.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;
    int n = s.size();
    int cnt = 0;
    for (int i = 0; i < n - 1; i++) {
        if (s[i] == s[i + 1]) {
            cnt++;
        }
    }
    cout << cnt << '\n';
    return 0;
}
@@TESTS
--IN
aabbcc
--OUT
3
--IN
abc
--OUT
0
--IN
aaaa
--OUT
3
--IN
a
--OUT
0
@@EXPL
(1) 접근·핵심 아이디어

- 이웃한 두 글자를 비교해야 하므로 `for (char c : s)`(글자만 꺼냄)로는 부족하고, 인덱스 `i`로 돌며 `s[i]`와 `s[i+1]`을 함께 봐야 한다.
- 마지막 글자는 오른쪽 이웃이 없다. 그래서 `i`의 범위를 하나 줄여 `i < n - 1`로 두는 것이 이 문제의 핵심 경계 처리다.

(2) 코드 단계별

- 문자열 `s`를 받고 `int n = s.size();`, `int cnt = 0;`.
- `for (int i = 0; i < n - 1; i++)`: `i`는 0부터 `n - 2`까지. `s[i] == s[i + 1]`이면 `cnt++`.
- 순회 후 `cnt` 출력. `aaaa`는 겹치는 쌍을 각각 세어 3이 된다.
- 범위를 하나 줄이지 않으면 `s[n]`을 읽는데, C++은 이걸 막지 않는다. `string`은 끝에 `'\0'`을 두고 있어 대개 죽지 않고 조용히 "다른 글자"로 판정될 뿐이라 버그를 알아채기 어렵다.

(3) 스스로 다시 짤 때 생각 순서

- 비교 대상이 "이웃 두 글자" → 인덱스 순회 필요.
- 마지막 인덱스에서 `s[i+1]`이 범위를 넘지 않게 → 조건을 `i < n - 1`로.
- **`n`을 `int`로 받아 두는 이유** → `i < s.size() - 1`은 `size()`가 부호 없는 값이라, 길이 0에서 `-1`이 40억대 양수로 변해 반복이 끝나지 않는다. 이 문제는 길이 1 이상이 보장되지만, 습관은 안전한 쪽으로 들이는 게 낫다.
- 길이 1 입력 → `n - 1 == 0`이라 반복 없음, 0 출력.
```

**6) 카이사르 암호** · Medium

- **요구사항**: 소문자와 공백으로 된 문장과 정수 `k`를 입력받아, 각 소문자를 알파벳에서 `k`칸 뒤 글자로 바꾼 암호문을 출력한다. `z`를 넘어가면 `a`부터 다시 이어진다(예: `y`를 3칸 밀면 `b`). 공백은 그대로 둔다.
- **입력**: 첫 줄에 문장 `s`(길이 1 이상 100 이하, 소문자와 공백), 둘째 줄에 정수 `k`(0 ≤ k ≤ 25).
- **출력**: 암호문 한 줄.
- **예제**: `abc xyz / 3` → `def abc` · `hello / 0` → `hello`
- **셀프체크**: `c + k`만 하면 `z` 근처에서 알파벳 밖 기호가 나온다. `a`를 0으로 보는 번호 `c - 'a'`에 `k`를 더하고 `% 26`으로 한 바퀴 돌린 뒤 다시 `'a'`를 더해 글자로 되돌린다. 계산은 `int`로 일어나므로 결과를 다시 칸에 넣을 때 `(char)`로 되돌려야 한다. 문장에 공백이 있으니 `getline`으로 받고, 길이가 변하지 않으므로 **제자리 수정**이 자연스럽다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    getline(cin, s);
    int k;
    cin >> k;
    int n = s.size();
    for (int i = 0; i < n; i++) {
        if ('a' <= s[i] && s[i] <= 'z') {
            s[i] = (char)((s[i] - 'a' + k) % 26 + 'a');
        }
    }
    cout << s << '\n';
    return 0;
}
@@TESTS
--IN
abc xyz
3
--OUT
def abc
--IN
hello
0
--OUT
hello
--IN
z
1
--OUT
a
@@EXPL
(1) 접근·핵심 아이디어

- 글자를 밀려면 글자를 숫자처럼 다뤄야 한다. C++에서는 `char`가 곧 작은 정수라 `ord` 같은 함수 없이 그냥 빼고 더하면 된다. 다만 `z`(122) 다음이 `a`(97)로 이어지게 하려면 "알파벳 안에서의 번호"(`a`=0 ~ `z`=25)로 바꾼 뒤 `% 26`을 적용해야 한다.
- 즉 한 글자의 변환은 네 단계다: 번호 만들기 `s[i] - 'a'` → `k` 더하기 → `% 26`으로 되돌리기 → `+ 'a'` 후 `(char)`로 글자 복원.
- **길이가 변하지 않으므로 새 문자열이 필요 없다.** C++ `string`은 가변이라 `s[i]`에 바로 새 글자를 써넣으면 된다. 파이썬에서 `result = ""`부터 쌓아 올렸던 이유(불변)는 C++에 해당하지 않는다.

(2) 코드 단계별

- 문장에 공백이 있으므로 `getline(cin, s);`로 한 줄을 받고, 그다음 줄의 `k`는 `cin >> k;`로 받는다.
- `for (int i = 0; i < n; i++)`에서 `'a' <= s[i] && s[i] <= 'z'`인 글자만 바꾼다. 공백은 조건에 걸리지 않아 손대지 않으므로, 파이썬 풀이의 `else` 분기(공백을 그대로 붙이기)가 필요 없다.
- `s[i] = (char)((s[i] - 'a' + k) % 26 + 'a');` — 괄호 안은 전부 `int` 계산이다. `(char)` 캐스팅을 빼도 대개 컴파일되지만, 의도를 드러내기 위해 붙인다.
- 예제 1의 `x`: 번호 23 + 3 = 26 → `26 % 26 = 0` → `a`. `k = 0`이면 모든 글자가 제자리라 원문 그대로다.

(3) 스스로 다시 짤 때 생각 순서

- 입력에 공백이 있나 → `getline`. `getline` 다음에 `cin >>`를 쓰는 순서는 안전하지만, 반대 순서(`cin >> k;` 다음 `getline`)라면 남아 있는 줄바꿈 때문에 빈 줄을 읽으니 주의.
- 글자를 밀려면 → `char`를 정수처럼 계산. 어떤 기준으로 → `'a'`를 0으로 두는 번호(`% 26`을 쓰기 위해).
- 되돌아가는 처리 → `% 26`. 이걸 빼면 `'z' + 1`이 `'{'`가 된다.
- 새 문자열이 필요한가 → 길이가 그대로니 필요 없다. 제자리에서 고친다.
```

**7) 연속 글자 압축** · Medium

- **요구사항**: 문자열에서 같은 글자가 연속으로 이어진 구간을 `글자+개수`로 줄여 쓴 압축 문자열을 출력한다. 개수가 1이어도 `1`을 붙인다.
- **입력**: 한 줄에 공백 없는 소문자 문자열 `s`(길이 1 이상 100 이하).
- **출력**: 압축된 문자열 한 줄.
- **예제**: `aaabbc` → `a3b2c1` · `abc` → `a1b1c1`
- **셀프체크**: 결과의 길이가 원본과 다르므로 이번에는 **새 문자열을 쌓는 쪽**이 맞다(제자리 수정으로는 길이를 늘릴 수 없다). "현재 글자"와 "몇 개째인지"를 변수로 들고 다니다가 다른 글자를 만나면 그때까지의 결과를 붙인다. 순회가 끝난 뒤 **마지막 구간은 아직 안 붙어 있으므로** 반복 밖에서 한 번 더 붙여야 한다. 개수는 정수라 `to_string(cnt)`로 바꿔 이어 붙인다. `aabaa`는 `a2b1a2`로, 떨어진 같은 글자는 합치지 않는다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;
    int n = s.size();
    string result = "";
    char cur = s[0];
    int cnt = 1;
    for (int i = 1; i < n; i++) {
        if (s[i] == cur) {
            cnt++;
        } else {
            result += cur;
            result += to_string(cnt);
            cur = s[i];
            cnt = 1;
        }
    }
    result += cur;
    result += to_string(cnt);
    cout << result << '\n';
    return 0;
}
@@TESTS
--IN
aaabbc
--OUT
a3b2c1
--IN
abc
--OUT
a1b1c1
--IN
zzzz
--OUT
z4
--IN
aabaa
--OUT
a2b1a2
@@EXPL
(1) 접근·핵심 아이디어

- 문자열을 앞에서부터 읽으며 "지금 이어지고 있는 글자 `cur`"와 "그 글자가 몇 개째인지 `cnt`"를 기억한다. 같은 글자면 `cnt`만 늘리고, 다른 글자를 만나면 지금까지의 구간을 `cur`과 `to_string(cnt)`로 결과에 붙인 뒤 새 구간을 시작한다.
- 구간은 "다음 글자가 다를 때" 마무리되므로, 맨 마지막 구간은 반복 안에서 절대 붙지 않는다. 반복이 끝난 뒤 한 번 더 붙이는 것이 이 유형의 대표 함정이다.
- 결과 길이가 원본과 달라지므로 제자리 수정은 쓸 수 없다. 빈 문자열에서 시작해 `+=`로 쌓아 간다.

(2) 코드 단계별

- `string result = "";`, `char cur = s[0];`, `int cnt = 1;`로 시작한다(첫 글자는 이미 한 개 세어 둔 상태).
- `for (int i = 1; i < n; i++)`: 둘째 글자부터. `s[i] == cur`면 `cnt++`, 아니면 `result += cur; result += to_string(cnt);` 후 `cur = s[i]; cnt = 1;`.
- 반복이 끝나면 남아 있는 마지막 구간을 같은 방식으로 한 번 더 붙인다.
- `result`를 출력한다. `zzzz`는 반복 안에서 한 번도 붙이지 않고 마지막 처리에서 `z4`가 된다.

(3) 스스로 다시 짤 때 생각 순서

- 결과 길이가 바뀌나 → 바뀐다. 그러면 새 문자열에 쌓는다.
- 무엇을 기억하며 읽나 → 현재 글자(`char`)와 연속 개수(`int`).
- 언제 결과에 붙이나 → 글자가 바뀌는 순간 + 반복 끝난 뒤 한 번.
- 개수를 붙일 때 → `to_string(cnt)`로 문자열로 바꾼다. `result += cnt;`라고 쓰면 컴파일은 되지만 `int`가 `char`로 변환되어 아스키 3번 문자 같은 것이 붙는다. 이건 오류가 아니라 조용한 버그다.
- `result = result + cur;`보다 `result += cur;` → 앞은 매번 문자열 전체를 복사하고 뒤는 한 글자만 덧붙인다.
```

**8) 가장 많이 나온 글자** · Medium

- **요구사항**: 소문자 문자열에서 가장 많이 등장한 글자와 그 횟수를 출력한다. 횟수가 같은 글자가 여러 개면 알파벳 순으로 가장 앞선 글자를 답한다.
- **입력**: 한 줄에 공백 없는 소문자 문자열 `s`(길이 1 이상 100 이하).
- **출력**: `글자 횟수` 형태의 한 줄.
- **예제**: `banana` → `a 3` · `zzyy` → `y 2`
- **셀프체크**: 글자별 횟수를 담을 26칸 배열을 `int cnt[26] = {0};`으로 만든다. 중괄호 초기화를 빼먹고 `int cnt[26];`이라고만 쓰면 26칸이 쓰레기 값으로 시작해 결과가 매번 달라진다. 글자 `c`의 칸 번호는 `c - 'a'`다. 최댓값을 찾을 때 `a`부터 `z` 순으로 보며 `>`(초과)로만 갱신하면 동률일 때 먼저 본 글자(알파벳 앞)가 남는다. 칸 번호를 글자로 되돌릴 땐 `(char)('a' + 번호)`.

```runner
    string s;

    for (char c : s) {
        cnt[c - 'a']++;
    }
    int best = 0;

        }
    }
    cout << (char)('a' + best) << ' ' << cnt[best] << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- Ch7에서 배운 "숫자별 등장 횟수" 배열을 글자에 적용한다. 소문자는 26종이므로 26칸 배열을 두고, 글자를 `c - 'a'`로 0~25 번호로 바꿔 그 칸을 1씩 올린다.

- `zzyy`는 y·z가 2번씩이지만 y(24번 칸)를 먼저 보고 z(25번)는 `>`가 아니라 갱신되지 않아 `y 2`.

(3) 스스로 다시 짤 때 생각 순서

- 횟수를 어디에 담나 → 글자 종류 수(26)만큼의 배열. 칸 번호 = `c - 'a'`. `{0}` 초기화 필수.

- 번호를 글자로 되돌리기 → `(char)('a' + 번호)`. 캐스팅을 빼면 숫자가 찍힌다.
```

**9) 단어마다 뒤집기** · Medium

- **요구사항**: 공백 하나로 구분된 여러 단어로 된 문장을 입력받아, 단어의 순서는 그대로 두고 각 단어의 글자 순서만 뒤집어 출력한다.
- **입력**: 한 줄에 문장 `s`(단어 1개 이상 20개 이하, 단어는 소문자, 단어 사이 공백 하나).
- **출력**: 각 단어를 뒤집은 문장 한 줄(단어 사이 공백 하나).
- **예제**: `hello world` → `olleh dlrow` · `abc` → `cba`
- **셀프체크**: 파이썬의 `split()`에 해당하는 것은 `stringstream`이다. `getline`으로 한 줄을 받아 `istringstream ss(s);`에 넣고 `while (ss >> word)`로 꺼내면 공백을 기준으로 단어가 하나씩 나온다. 단어 뒤집기는 `reverse(w.begin(), w.end());`로 제자리에서 한다(파이썬의 `[::-1]`처럼 새 문자열을 만들지 않아도 된다). 결과를 이어 붙일 때 첫 단어 앞이나 마지막 단어 뒤에 공백이 남지 않도록, 둘째 단어부터만 앞에 공백을 붙인다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    getline(cin, s);
    istringstream ss(s);
    vector<string> words;
    string w;
    while (ss >> w) {
        words.push_back(w);
    }
    string result = "";
    for (int i = 0; i < (int)words.size(); i++) {
        if (i > 0) {
            result += ' ';
        }
        string t = words[i];
        reverse(t.begin(), t.end());
        result += t;
    }
    cout << result << '\n';
    return 0;
}
@@TESTS
--IN
hello world
--OUT
olleh dlrow
--IN
abc
--OUT
cba
--IN
ab cd ef
--OUT
ba dc fe
@@EXPL
(1) 접근·핵심 아이디어

- 문장 전체를 뒤집으면 단어 순서까지 바뀌므로, 먼저 단어로 쪼갠 뒤 단어 하나씩만 뒤집어야 한다.
- C++에는 파이썬의 `split()` 같은 한 방 메서드가 없다. 대신 `istringstream`에 문자열을 넣으면 `cin >>`와 똑같이 `>>`로 공백 단위 토큰을 꺼낼 수 있다. 이것이 표준적인 "문자열 쪼개기"다.
- 뒤집기는 `reverse(t.begin(), t.end());`. 두 반복자 사이를 제자리에서 뒤집으므로 새 문자열이 필요 없다.

(2) 코드 단계별

- `getline(cin, s);`로 한 줄을 받고 `istringstream ss(s);`를 만든다.
- `while (ss >> w)`로 단어를 하나씩 꺼내 `words`에 담는다. `>>`가 더 읽을 것이 없으면 거짓이 되어 반복이 끝난다.
- `result = ""`에서 시작해 `i > 0`일 때만 먼저 공백을 붙인다. 이렇게 하면 첫 단어 앞에는 공백이 없고 단어 사이에만 공백이 하나씩 들어간다.
- 단어를 `string t = words[i];`로 복사해 `reverse`한 뒤 `result += t;`. 복사본을 뒤집었으므로 `words`의 원본은 그대로 남는다(원본이 필요 없다면 `reverse(words[i].begin(), words[i].end());`로 바로 뒤집어도 된다).
- 끝나면 `result` 출력.

(3) 스스로 다시 짤 때 생각 순서

- 무엇을 뒤집나 → 단어 각각. 그러니 먼저 단어로 쪼갠다.
- 쪼개는 도구는 → `istringstream` + `>>`. 공백이 여러 개여도 알아서 건너뛴다.
- 공백을 언제 넣나 → 단어와 단어 "사이"에만. 둘째 단어부터 앞에 붙이는 방식이 가장 간단.
- 반복 조건에서 `words.size()`를 쓸 때 → `int i`와 비교하려면 `(int)words.size()`로 캐스팅한다. 캐스팅 없이 비교하면 부호가 다르다는 경고가 뜨고, 크기가 0일 때 `size() - 1` 같은 식이 위험해진다.
- 단어가 하나뿐이면 → 공백이 한 번도 안 붙어 뒤집은 단어만 나온다.
```

**10) 두 문자열의 공통 글자** · Medium

- **요구사항**: 소문자 문자열 두 개를 입력받아, 두 문자열 모두에 등장하는 글자를 알파벳 순으로 중복 없이 이어서 출력한다. 공통 글자가 하나도 없으면 `NONE`을 출력한다.
- **입력**: 두 줄에 각각 공백 없는 소문자 문자열 `a`, `b`(길이 1 이상 100 이하).
- **출력**: 공통 글자를 알파벳 순으로 붙인 문자열, 없으면 `NONE`.
- **예제**: `apple / pear` → `aep` · `abc / xyz` → `NONE`
- **셀프체크**: 입력을 순회하면 순서·중복 처리가 번거롭다. 대신 `a`부터 `z`까지 알파벳 26자를 `(char)('a' + i)`로 만들어 순서대로 돌며 두 문자열 모두에 있는 글자만 붙이면 알파벳 순·중복 없음이 저절로 해결된다. 포함 여부는 `a.find(c) != string::npos`로 확인한다. **`npos`는 -1이 아니라 부호 없는 최댓값**이므로 `a.find(c) >= 0`은 언제나 참이 되어 전부 통과시켜 버린다. 결과가 빈 문자열이면 `NONE`.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    string a, b;
    cin >> a;
    cin >> b;
    string result = "";
    for (int i = 0; i < 26; i++) {
        char c = (char)('a' + i);
        if (a.find(c) != string::npos && b.find(c) != string::npos) {
            result += c;
        }
    }
    if (result == "") {
        cout << "NONE" << '\n';
    } else {
        cout << result << '\n';
    }
    return 0;
}

(1) 접근·핵심 아이디어

- "알파벳 순, 중복 없이"라는 조건을 보면, 입력 문자열이 아니라 **알파벳 자체**를 `a`부터 `z`까지 순서대로 훑는 편이 낫다. 각 글자에 대해 "두 문자열 모두에 있는가"만 물으면 순서와 중복 문제가 사라진다.
- 알파벳 글자는 `(char)('a' + i)`(`i`는 0~25)로 만들 수 있고, 포함 여부는 `find`로 확인한다.

(2) 코드 단계별

- 두 문자열 `a`, `b`를 받고 `string result = "";`.
- `for (int i = 0; i < 26; i++)`: `char c = (char)('a' + i);`로 이번 글자를 만든다.

(3) 스스로 다시 짤 때 생각 순서

- 출력 순서 조건이 있으면 → 그 순서대로 "후보"를 돌리는 방법을 먼저 생각한다.
- 후보 만들기 → `(char)('a' + i)`. 확인 → `find` 두 번을 `&&`로.
- **`npos` 함정** → `find`의 반환형은 `size_t`(부호 없음)다. `!= string::npos`가 유일하게 옳은 비교이고, `>= 0`이나 `!= -1` 같은 습관은 못 찾은 경우를 걸러 내지 못하거나 컴파일러 경고를 부른다.
- 빈 결과 처리 → `result == ""`(또는 `result.empty()`)로 확인해 `NONE`. 빈 문자열을 그냥 출력하면 빈 줄이 나와 틀린다.
```

**11) 부분 문자열 등장 횟수** · Medium

- **요구사항**: 문자열 `s`와 찾을 문자열 `p`를 입력받아, `s` 안에서 `p`가 몇 번 나타나는지 출력한다. 겹치는 경우도 각각 센다(`aaaa`에서 `aa`는 3번).
- **입력**: 첫 줄에 문자열 `s`, 둘째 줄에 문자열 `p`(둘 다 공백 없는 소문자, 길이 1 이상 100 이하).
- **출력**: 등장 횟수(정수). `p`가 `s`보다 길면 `0`.
- **예제**: `aaaa / aa` → `3` · `banana / ana` → `2`
- **셀프체크**: 시작 위치 `i`마다 `s.substr(i, m)`을 잘라 `p`와 비교한다. 시작 위치는 `0`부터 `n - m`까지이므로 조건은 `i + m <= n`. **여기서 두 길이를 `int n = s.size(); int m = p.size();`로 받아 두는 것이 핵심이다.** `i < s.size() - p.size() + 1`처럼 쓰면 `p`가 더 길 때 부호 없는 뺄셈이 40억대 양수로 변해 반복이 폭주하고, `substr`이 `out_of_range` 예외로 죽는다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    string s, p;
    cin >> s;
    cin >> p;
    int n = s.size();
    int m = p.size();
    int cnt = 0;
    for (int i = 0; i + m <= n; i++) {
        if (s.substr(i, m) == p) {
            cnt++;
        }
    }
    cout << cnt << '\n';
    return 0;
}

--IN

@@EXPL
(1) 접근·핵심 아이디어

- 한 글자 찾기(L6)를 여러 글자로 확장한 것이다. 시작 위치 `i`를 하나씩 옮기며 `p`와 같은 길이의 조각 `s.substr(i, m)`을 잘라 `==`로 비교한다.
- `substr`의 둘째 인자는 "끝 위치"가 아니라 **길이**다. 파이썬의 `s[i:i+len(p)]`와 세는 법이 다르니 `s.substr(i, i + m)`이라고 쓰지 않도록 주의한다.
- 겹침도 세야 하므로 찾았다고 `m`만큼 건너뛰지 않고 `i`를 항상 1씩 옮긴다.

(2) 코드 단계별

- `s`, `p`를 받고 **길이를 먼저 `int`로 받는다**: `int n = s.size(); int m = p.size();`.
- `for (int i = 0; i + m <= n; i++)`: 마지막 시작 위치는 `n - m`(거기서 `m`글자를 자르면 딱 끝에 닿는다). 조건을 `i + m <= n` 꼴로 쓰면 뺄셈이 없어 음수 걱정도 사라진다.
- `s.substr(i, m) == p`이면 `cnt++`.
- 반복 후 `cnt` 출력. `banana`/`ana`는 `i = 1`과 `i = 3`에서 일치해 2.
- `p`가 `s`보다 길면 `i = 0`에서 이미 `0 + m > n`이라 반복이 한 번도 돌지 않고 0이 나온다.

(3) 스스로 다시 짤 때 생각 순서

- 비교 단위 → 길이 `m`의 조각. `substr(시작, 길이)`로 자른다.
- 시작 위치 범위 → `0 ~ n - m`. 조건은 `i + m <= n`.
- **`.size()` 함정** → `s.size() - p.size()`는 부호 없는 계산이라 `p`가 더 길면 음수가 아니라 거대한 양수가 된다. 이 한 줄 때문에 프로그램이 멈추거나 예외로 죽는다. 길이는 반드시 `int`에 담아 두고 계산한다.
- 더 짧게 쓰려면 → `s.find(p, i)`를 반복해 위치를 옮겨 가며 세는 방법도 있다. 이때도 `!= string::npos` 비교를 잊지 않는다.
```

**12) 글 속 숫자 덩어리의 합** · Hard

- **요구사항**: 영문자와 숫자가 섞인 문자열에서, 연속으로 붙어 있는 숫자 글자들을 하나의 수로 본다(`ab12cd3x`에는 12와 3이 있다). 그런 수들을 모두 더한 값을 출력한다. 숫자가 하나도 없으면 `0`.
- **입력**: 한 줄에 공백 없는 문자열 `s`(길이 1 이상 100 이하, 영문자와 숫자만 포함).
- **출력**: 숫자 덩어리들의 합(정수).
- **예제**: `ab12cd3x` → `15` · `abc` → `0`
- **셀프체크**: 숫자 글자를 만날 때마다 지금 만들고 있는 수 `num`을 `num * 10 + (c - '0')`으로 키운다(`1` 다음 `2`를 만나면 `1*10 + 2 = 12`). 영문자를 만나면 `num`을 합에 넣고 `num = 0`으로 되돌린다. 문자열이 숫자로 끝나면 마지막 수가 아직 합에 안 들어갔으므로 **반복이 끝난 뒤 한 번 더** 넣는다. `07`처럼 앞에 0이 붙어도 이 계산은 7이 된다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;
    long long total = 0;
    long long num = 0;
    for (char c : s) {
        if ('0' <= c && c <= '9') {
            num = num * 10 + (c - '0');
        } else {
            total += num;
            num = 0;
        }
    }
    total += num;

(1) 접근·핵심 아이디어

- 2번 문제(숫자 글자 합)와 다른 점은 붙어 있는 숫자들이 한 개의 수라는 것이다. 그래서 글자 하나를 바로 더하지 않고, "만드는 중인 수"에 자릿수로 붙여 나간다: 새 숫자 글자가 오면 `num = num * 10 + (c - '0')`.
- 수가 끝나는 시점은 "숫자가 아닌 글자를 만났을 때"와 "문자열이 끝났을 때" 두 가지다. 후자를 놓치면 `100`처럼 숫자로 끝나는 입력에서 0이 나온다.

(2) 코드 단계별

- `total`(합)과 `num`(만드는 중인 수)을 0으로 시작한다.
- `for (char c : s)`에서 숫자 글자면 `num = num * 10 + (c - '0');`, 아니면 `total += num; num = 0;`.
- 영문자가 연달아 나오면 `num`이 0인 채로 더해져 합이 변하지 않는다(문제없음).
- 반복이 끝난 뒤 `total += num;`으로 마지막 수를 반영하고 출력한다. `7a07b`는 7, 07(=7), 그리고 끝의 0이 더해져 14.

(3) 스스로 다시 짤 때 생각 순서

- 여러 자리 수를 어떻게 만들까 → 왼쪽 자리부터 `*10` 하며 붙이기.
- 수가 끝나는 순간은 언제인가 → 숫자 아닌 글자 + 문자열 끝. 두 곳 모두에서 합에 넣고 0으로 초기화.
- **자료형을 무엇으로 하나** → 제약만 보면 길이 100짜리 입력이 전부 숫자일 수 있고, 그러면 100자리 수라 `int`(약 21억)는 물론 `long long`(약 9.2 × 10^18)으로도 담지 못한다. 실제 테스트는 작은 수만 나오지만, `num * 10 + ...`처럼 자릿수를 붙여 올리는 계산을 보면 오버플로를 먼저 떠올리는 습관을 들이자. 파이썬 정수에는 크기 제한이 없어 아예 생각할 필요가 없던 부분이다.
- 검산 → `100`(숫자로 끝남), `abc`(숫자 없음), `7a07b`(앞자리 0)로 세 경우를 확인.
```

**13) 아나그램 판정** · Hard

- **요구사항**: 소문자 문자열 두 개를 입력받아, 한쪽의 글자 순서를 재배열해 다른 쪽과 똑같이 만들 수 있으면(같은 글자를 같은 개수만큼 가지면) `YES`, 아니면 `NO`를 출력한다.
- **입력**: 두 줄에 각각 공백 없는 소문자 문자열 `a`, `b`(길이 1 이상 100 이하, 길이가 서로 다를 수 있음).
- **출력**: `YES` 또는 `NO`.
- **예제**: `listen / silent` → `YES` · `aab / abb` → `NO`
- **셀프체크**: 글자별 개수가 모두 같은지 보면 된다. 26칸 배열 하나에 `a`의 글자는 `+1`, `b`의 글자는 `-1` 하면, 아나그램일 때 모든 칸이 0이 된다. 길이가 다르면 어느 칸인가 0이 아니게 되어 자동으로 `NO`. `int cnt[26] = {0};`의 `= {0}`을 빼먹으면 쓰레기 값에서 시작해 정답이 나올 리 없다. 정렬(`sort`)을 쓰면 더 짧지만, 이 방법이면 정렬 없이도 충분하다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    string a, b;
    cin >> a;
    cin >> b;
    int cnt[26] = {0};
    for (char c : a) {
        cnt[c - 'a']++;
    }
    for (char c : b) {
        cnt[c - 'a']--;
    }
    bool ok = true;
    for (int i = 0; i < 26; i++) {
        if (cnt[i] != 0) {
            ok = false;
        }
    }
    if (ok) {
        cout << "YES" << '\n';
    } else {
        cout << "NO" << '\n';
    }
    return 0;
}

(1) 접근·핵심 아이디어

- 아나그램은 "글자의 순서만 다르고 종류와 개수는 같다"는 뜻이다. 그러니 순서는 무시하고 글자별 개수만 비교하면 된다.
- 개수 비교는 8번 문제의 26칸 배열을 재활용한다. 배열을 두 개 만들어 칸마다 비교해도 되지만, 하나에 `+1`/`-1`로 상쇄시키면 "전부 0인가"만 확인하면 되어 더 간단하다.

(2) 코드 단계별

- `int cnt[26] = {0};`. `a`의 글자는 `cnt[c - 'a']++`, `b`의 글자는 같은 칸에 `--`.
- `bool ok = true;`로 두고 `for (int i = 0; i < 26; i++)`으로 26칸을 모두 보며 `cnt[i] != 0`인 칸이 하나라도 있으면 `ok = false;`.
- `ok`에 따라 `YES`/`NO` 출력. `aab`/`abb`는 a 칸이 +1, b 칸이 -1로 남아 `NO`.
- 길이가 다른 `ab`/`abc`는 c 칸이 -1로 남아 자연스럽게 `NO`가 된다(길이 비교를 따로 하지 않아도 된다).

(3) 스스로 다시 짤 때 생각 순서

- 순서를 무시하고 비교하려면 → 개수로 바꿔 비교.
- 두 개수 표를 어떻게 비교하나 → 한 표에 더하고 빼서 0인지 확인(또는 두 표를 칸마다 `==`).
- 판정 변수 → `bool ok = true;`로 시작해 하나라도 어긋나면 `false`. 반복 끝난 뒤 한 번만 출력.
- 다른 풀이 → `sort(a.begin(), a.end()); sort(b.begin(), b.end());` 후 `a == b`. C++ `string`이 가변이라 이렇게 원본을 정렬해 버릴 수 있다는 점이 파이썬(`sorted(a) == sorted(b)`로 새 리스트를 만들어야 하는)과 다르다. 원본이 뒤에 또 필요하면 사본을 정렬한다.
```

**14) 가장 긴 연속 구간** · Hard

- **요구사항**: 문자열에서 같은 글자가 끊기지 않고 가장 길게 이어진 구간을 찾아, 그 글자와 길이를 출력한다. 가장 긴 길이가 여러 구간에서 나오면 먼저 나온 구간을 답한다.
- **입력**: 한 줄에 공백 없는 소문자 문자열 `s`(길이 1 이상 100 이하).
- **출력**: `글자 길이` 형태의 한 줄.
- **예제**: `aabbbcc` → `b 3` · `aabb` → `a 2`
- **셀프체크**: 7번 압축 문제처럼 "현재 글자·현재 연속 길이"를 추적하면서, 한 글자를 처리할 때마다 현재 길이가 지금까지의 최대를 **초과**하는지 확인해 최대 글자·길이를 갱신한다. `>=`로 쓰면 동률에서 뒤 구간이 이겨 버린다. 상태 변수는 `char best_c`, `int best_len` 두 종류이니 자료형을 헷갈리지 말 것. 길이 1 입력은 첫 글자가 곧 답(`z` → `z 1`).

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;
    int n = s.size();
    char best_c = s[0];
    int best_len = 1;
    char cur_c = s[0];
    int cur_len = 1;
    for (int i = 1; i < n; i++) {
        if (s[i] == cur_c) {
            cur_len++;
        } else {
            cur_c = s[i];
            cur_len = 1;
        }
        if (cur_len > best_len) {
            best_len = cur_len;
            best_c = cur_c;
        }
    }
    cout << best_c << ' ' << best_len << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- 연속 구간을 추적하는 방법은 압축 문제와 같다: 현재 글자 `cur_c`와 현재 연속 길이 `cur_len`을 들고 가며, 같은 글자면 길이를 늘리고 다른 글자면 새 구간을 시작한다.
- 여기에 "최대 갱신"을 결합한다. 매 글자마다 `cur_len`이 `best_len`보다 크면 최대를 바꾼다. 동률에서 먼저 나온 구간을 지키려면 `>`(초과)로만 갱신한다.

(2) 코드 단계별

- 첫 글자로 `best_c`, `cur_c`(둘 다 `char`)를, 길이 1로 `best_len`, `cur_len`(둘 다 `int`)을 초기화한다. 이렇게 하면 길이 1 입력도 반복 없이 정답이 준비된다.
- `for (int i = 1; i < n; i++)`: `s[i] == cur_c`면 `cur_len++`, 아니면 `cur_c = s[i]; cur_len = 1;`.
- 같은 반복 안에서 바로 `cur_len > best_len`을 확인해 `best_len`, `best_c`를 함께 갱신한다. 구간이 끝나기를 기다릴 필요 없이 길이가 늘 때마다 확인하면 마지막 구간도 놓치지 않는다.
- 반복 후 `cout << best_c << ' ' << best_len << '\n';`. `best_c`는 `char`이므로 글자로 찍히고, `best_len`은 `int`라 수로 찍힌다. 두 값 사이의 공백은 직접 넣는다.

(3) 스스로 다시 짤 때 생각 순서

- 상태 변수 4개 → 현재 글자·현재 길이, 최대 글자·최대 길이. 초기값은 첫 글자와 1.
- 자료형을 섞지 않기 → 글자는 `char`, 길이는 `int`. `best_c`를 `int`로 두면 출력이 숫자가 되어 버린다.
- 갱신 시점 → 글자를 처리한 직후 매번(마지막 구간 누락 방지). 갱신 조건 → 동률 규칙에 맞춰 `>`.
- 검산 → `aabb`(동률은 앞 구간), `abc`(전부 길이 1이면 첫 글자), `z`(길이 1).
```
