> 개요: 이 챕터에서는 프로그램이 사용자로부터 값을 받아오는 "입력"을 배운다. 정수·실수·문자열을 어떻게 읽고, 한 줄에 여러 값이 있을 때나 여러 줄에 걸쳐 있을 때 어떻게 나눠 받는지 익힌다.

## L1. 정수 입력

**개념**

- 프로그램이 사용자가 키보드로 넣어 준 값을 받아오는 것을 "입력"이라고 한다.
- C++에서는 `#include <iostream>` 후 `std::cin`으로 값을 읽는다. `cin >> n`은 공백(스페이스·줄바꿈)을 건너뛰며 값 하나를 읽는다.
- 받을 변수의 자료형에 맞춰 알아서 변환된다. `int n; cin >> n;`처럼 `int`로 선언하면 키보드의 글자 `3`이 숫자 3으로 바로 들어온다. 따로 형 변환을 감쌀 필요가 없다.
- 자리 숫자를 뽑을 때 쓰는 연산 두 가지: `/`는 정수끼리면 나눗셈의 몫(소수점 아래 버림), `%`는 나머지다. 예: `72 / 10`은 `7`(십의 자리), `72 % 10`은 `2`(일의 자리).

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;        // 한 줄(공백까지)을 읽어 정수로 n에 저장
    cout << n + 1;   // 이제 숫자처럼 계산할 수 있다
    return 0;
}
```

- 주의: `int`끼리의 `/`는 몫만 남긴다. 예를 들어 `7 / 2`는 `3`이지 `3.5`가 아니다. 소수 결과가 필요하면 실수형을 써야 한다(다음 레슨).

**그림으로 보기**

키보드로 친 것은 언제나 "글자"다. `cin >>` 는 그 글자를 **받는 변수의 자료형에 맞춰** 읽어 주는 다리 역할을 한다. 어떤 상자로 받느냐가 곧 "어떻게 읽을지"를 정한다.

```text
  you type:      7 2 [ENTER]

  buffer holds   7 2 [NL]                 // still just letters

  int n;     cin >> n;   ->   72          // a number: can be added
  string s;  cin >> s;   ->   "72"        // letters: cannot be added

  n + 1      ->  73                       // real addition
  s + "1"    ->  "721"                    // glued, not 73
```

`/` 와 `%` 는 초등학교 나눗셈 그림 그대로다. 위에 남는 것이 몫, 아래에 남는 것이 나머지다.

```text
  72 divided by 10

          7        <- 72 / 10  : the quotient  -> the tens digit
        +------
   10   |  72
        |  70      // 10 * 7
        +------
        |   2      <- 72 % 10  : the remainder -> the ones digit
```

**왜 이렇게 되는가**

- `cin >> n` 이 따로 형 변환을 하지 않아도 되는 이유: 받을 상자의 자료형이 이미 `int` 라고 적혀 있기 때문이다. `>>` 는 그 자료형을 보고 "숫자로 읽어라"라는 규칙을 고른다. 자료형을 먼저 적게 하는 C++의 방식이 여기서 이득이 된다.
- 반대로 `string s; cin >> s;` 로 받으면 같은 `72` 라도 글자 두 개로 남는다. `"72"` 와 `72` 는 생김새만 같을 뿐 완전히 다른 값이다.
- `cin >>` 는 값을 읽기 전에 앞에 있는 공백·줄바꿈을 모두 건너뛴다. 그래서 값이 한 줄에 있든 여러 줄에 있든 같은 코드로 읽힌다(L3, L4에서 다시 본다).
- 정수로 읽을 수 없는 글자가 오면 `cin` 은 실패 상태가 되고 변수에는 값이 들어가지 않는다. 그 뒤의 모든 `>>` 도 아무 일도 하지 않으므로, 입력 형식이 문제에 적힌 대로인지 먼저 확인한다.
- `/` 로 십의 자리가 나오는 이유: 두 자리 수 `72` 는 `10 * 7 + 2` 로 쓸 수 있다. 10으로 나눈 몫이 곧 "10이 몇 묶음 들어 있는가"이므로 십의 자리 숫자와 같아진다.
- `%` 로 일의 자리가 나오는 이유도 같다. 10묶음을 모두 덜어내고 남은 것이 곧 일의 자리다. 세 자리 수라면 `% 10` 은 여전히 일의 자리, `/ 100` 은 백의 자리가 된다.
- 단, `/` 가 몫이 되는 것은 **양쪽이 모두 정수일 때**다. 한쪽이라도 `double` 이면 소수 나눗셈이 되어 `72 / 10.0` 은 `7.2` 가 된다.

## L2. 실수 입력

**개념**

- 소수점이 있는 수(예: 3.14, 0.5)를 "실수"라고 한다.
- C++에서 실수를 담는 자료형은 `double`이다. `double x; cin >> x;`처럼 선언하면 `3.5` 같은 입력이 실수로 들어온다.
- 소수점이 없는 `4`를 넣어도 `double`로 받으면 값은 `4.0`이 되어 소수 계산을 이어 갈 수 있다.

```cpp
#include <iostream>
using namespace std;

int main() {
    double x;
    cin >> x;        // "3.5" 같은 값을 실수 3.5로 읽음
    cout << x * 2;   // 7
    return 0;
}
```

- 주의: C++의 `cout`은 실수를 출력할 때 필요 없는 소수점과 뒤따르는 0을 붙이지 않는다. 그래서 값이 딱 떨어지면 `5.0`이 아니라 `5`로, `7.0`이 아니라 `7`로 출력된다. 반대로 `4.5`처럼 소수 부분이 있으면 `4.5` 그대로 나온다.
- 정리: `double`이라도 화면에는 정수처럼 보일 수 있다. `5.0 * 2 = 10`은 `10`, `2.5 + 0.5 = 3`은 `3`으로 출력된다.

**그림으로 보기**

같은 한 줄을 `int` 로 받느냐 `double` 로 받느냐에 따라 결과가 이렇게 갈린다. **`double` 이 받아 주는 범위가 더 넓다.**

```text
  the line you type    int n; cin >> n;      double x; cin >> x;
  ------------------   -------------------   --------------------
  4                    4                     4
  4.2                  4  then it stops      4.2
  -3                   -3                    -3
  0                    0                     0

  // int stops at the '.', so ".2" is left behind in the buffer
```

`double` 은 소수 부분을 값 안에 갖고 있지만, `cout` 은 필요 없는 `.0` 을 붙이지 않는다. 그래서 화면만 보고는 자료형을 알 수 없다.

```text
  double x = 4;

  cout << x;                              ->  4
  cout << fixed << setprecision(1) << x;  ->  4.0

  // the value never changed. only the way it is shown changed
```

**왜 이렇게 되는가**

- `int` 로 `4.2` 를 받아도 그 자리에서 오류가 나지 않는다는 점이 가장 조심할 부분이다. `>>` 는 **정수로 읽을 수 있는 데까지만** 읽고 멈춘다. 그래서 `n` 에는 `4` 가 들어가고 `.2` 는 입력 버퍼에 그대로 남는다.
- 남은 `.2` 는 다음 `cin >>` 를 망가뜨린다. 다음이 정수라면 `.` 에서 곧바로 실패하기 때문이다. **오류 없이 조용히 틀리는** 전형적인 함정이라, 소수점이 들어올 수 있으면 처음부터 `double` 로 받는다.
- `double` 이 정수 모양의 입력도 받아 주는 이유: 정수는 소수 부분이 0인 실수로 볼 수 있어 손실 없이 담긴다. 반대 방향(실수를 정수 상자에)은 소수 부분이 갈 곳이 없어 잘린다.
- `cout` 이 `4.0` 을 `4` 로 보여 주는 이유: 기본 출력 방식이 "유효숫자 여섯 자리까지 보여 주고, 필요 없는 0은 지운다"이기 때문이다. 값이 바뀐 게 아니라 표시가 짧아진 것뿐이다.
- 그래서 문제가 `4.0` 처럼 소수점을 요구하면 `fixed` 와 `setprecision` 으로 모양을 직접 정해 줘야 한다(Ch01 L4).
- `double` 도 무한히 정확하지는 않다. 2진수로 저장하는 과정에서 아주 작은 오차가 생기므로, 두 실수가 정확히 같은지 따지는 코드보다 자릿수를 정해 출력하는 쪽이 안전하다.

- **입력**: `4` 또는 `4.2` 처럼 소수점이 있을 수도, 없을 수도 있는 수 하나가 주어진다.
- **출력**: 입력값 + 0.5 를 한 줄에 출력한다.
- **예제**: `4` → `4.5` / `2.5` → `3`
- **셀프체크**: 소수점 없는 `4`도 `double`로 받으면 문제없이 계산된다. 결과가 딱 떨어지면 `.0` 없이 나온다는 점을 예상했는가?

```runner
@@SOLUTION

    double x;
    cin >> x;
    cout << x + 0.5 << "\n";
    return 0;

@@TESTS

--OUT
4.5
--IN

--OUT

--IN

@@EXPL
접근: 입력을 실수로 받아 0.5를 더한다. 소수점이 없는 입력도 `double`이면 문제없다.

- `double x; cin >> x;`는 `4`도 `4.0`으로, `2.5`도 `2.5`로 받아 준다.
- `cout << x + 0.5;`로 0.5를 더한 값을 출력한다.
- `4 + 0.5 = 4.5`, `10 + 0.5 = 10.5`처럼 소수 부분이 있으면 그대로 나온다. `2.5 + 0.5 = 3.0`은 딱 떨어져 C++이 `.0`을 떼고 `3`으로 출력한다.

다시 짤 때 순서: (1) 소수점 유무와 상관없이 `double`로 읽는다 → (2) `+ 0.5` → (3) 출력한다.
```

## L3. 공백을 사이에 두고 입력

**개념**

- 한 줄에 값이 여러 개, 공백으로 나뉘어 들어오는 경우가 많다. 예: `3 5`.
- C++의 `cin >>`은 원래 공백을 알아서 건너뛴다. 그래서 문자열을 따로 자를 필요 없이, `>>`를 값 개수만큼 연달아 쓰면 된다.
- 값이 2개면 변수도 2개를 준비해 차례로 받는다. 자주 쓰는 형태는 다음과 같다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;   // "3 5" -> a=3, b=5
    cout << a + b;   // 8
    return 0;
}
```

- `cin >> a >> b;`는 첫 값을 `a`, 다음 값을 `b`에 넣는다. 값들이 공백으로 붙어 있어도, 여러 줄에 나뉘어 있어도 똑같이 동작한다(`>>`가 공백·줄바꿈을 모두 구분자로 본다).

**그림으로 보기**

한 줄에 값이 여러 개 있어도 자르는 단계가 필요 없다. `>>` 가 **공백을 만나면 알아서 값 하나를 끊기** 때문이다.

```text
  you type:        3   5
                    ^ spaces

  buffer:   3 [SP] [SP] [SP] 5 [NL]

  cin >> a;   skip the spaces, read digits, stop at a space  ->  a = 3
  cin >> b;   skip the spaces, read digits, stop at [NL]     ->  b = 5

  // spaces are not values. they only mark where one value ends
```

받을 변수의 개수만큼 `>>` 를 이어 쓰면 된다. 값이 세 개면 변수도 세 개다.

```text
  input line     code                     result
  ------------   ----------------------   ---------------------
  3 5            cin >> a >> b;           a=3  b=5
  1 2 3          cin >> a >> b;           a=1  b=2, "3" left over
  1 2 3          cin >> a >> b >> c;      a=1  b=2  c=3
  3 5            cin >> a >> b >> c;      c never gets a value
```

**손으로 따라가기**

입력 `10 -4` 로 합을 구하는 과정이다. 각 줄이 끝난 뒤 변수에 무엇이 들어 있는지, 그리고 버퍼에 무엇이 남았는지를 함께 적는다.

| 단계 | 실행한 줄 | `a` | `b` | 버퍼에 남은 것 |
|------|-----------|-----|-----|----------------|
| 0 | `int a, b;` | 쓰레기 값 | 쓰레기 값 | `10 -4[NL]` |
| 1 | `cin >> a;` | `10` | 쓰레기 값 | ` -4[NL]` |
| 2 | `cin >> b;` | `10` | `-4` | `[NL]` |
| 3 | `cout << a + b;` | `10` | `-4` | `10 + (-4) = 6` 출력 |

0단계를 보면 알 수 있듯, 값을 읽기 전의 변수는 **아무 값이나 들어 있는 상태**다. 읽기 전에 계산하면 실행할 때마다 답이 달라진다.

**왜 이렇게 되는가**

- `>>` 는 값을 읽기 전에 **앞쪽 공백류(스페이스·탭·줄바꿈)를 전부 건너뛴다.** 그래서 공백이 한 칸이든 세 칸이든 결과가 같다. 입력에 공백이 두 칸 들어 있어도 안전한 이유다.
- 값을 다 읽으면 **구분자는 버퍼에 그대로 남긴다.** 다음 `>>` 가 다시 건너뛰기부터 시작하므로 문제가 되지 않는다.
- `cin >> a >> b;` 를 이어 쓸 수 있는 이유는 `cin >> a` 의 결과가 다시 `cin` 이기 때문이다. 출력의 `cout << a << b` 와 완전히 같은 구조다.
- 읽을 값이 부족하면 프로그램이 오류를 내는 게 아니라, `cin` 이 실패 상태가 되고 그 변수는 값을 받지 못한 채 넘어간다. 파이썬처럼 즉시 알려 주지 않으므로 값 개수를 코드와 맞춰 두어야 한다.
- 그래서 문제를 읽을 때 **"값이 모두 몇 개인가"** 를 먼저 세는 것이 코드를 쓰기 전 첫 단계가 된다. 줄이 몇 개로 나뉘어 있는지는 `>>` 에게 중요하지 않다.

## L4. 2개의 줄에 걸쳐 입력

**개념**

- 값이 한 줄이 아니라 여러 줄에 나뉘어 들어올 때가 있다. 예를 들어 첫 줄에 하나, 둘째 줄에 하나.
- 다행히 C++의 `cin >>`은 공백뿐 아니라 줄바꿈도 구분자로 본다. 그래서 두 줄로 나뉜 값도 `cin >> a >> b;` 한 번으로 받을 수 있다.
- 물론 아래처럼 `>>`를 나눠 써도 동일하게 동작한다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a;        // 첫째 줄의 값을 a에
    cin >> b;        // 둘째 줄의 값을 b에
    cout << a + b;
    return 0;
}
```

- 핵심: `cin >>`은 읽을 위치를 기억하고 있다가, 다음에 나오는 값 하나를 순서대로 가져온다. 줄이 몇 개든 값 개수만큼 `>>`로 받으면 된다.

**그림으로 보기**

`>>` 는 "줄" 단위가 아니라 **"값" 단위로 떼어 간다.** 줄바꿈은 값과 값을 가르는 표시일 뿐이다.

```text
  input                what each >> takes

  +----------+
  | 4        |  <--  1st >>   ->  a = 4
  +----------+
  | 9        |  <--  2nd >>   ->  b = 9
  +----------+
  | 2        |       (no 3rd >> : this line stays unread)
  +----------+
```

그래서 같은 두 값이 한 줄에 있든 두 줄에 있든 **코드가 똑같다.** 값의 배치가 바뀌어도 고칠 것이 없다.

```text
  3 5          on ONE line     ->   cin >> a >> b;

  3
  5            on TWO lines    ->   cin >> a >> b;    // the same code

  // >> treats space, tab and newline all as "end of one value"
```

**왜 이렇게 되는가**

- `cin` 은 "지금까지 읽은 위치" 표시(커서)를 하나 갖고 있다. `>>` 가 불릴 때마다 그 위치에서 공백류를 건너뛰고, 값 하나를 읽고, 커서를 그 값 바로 뒤에 세워 둔다.
- 그래서 **호출 순서가 곧 값의 순서**다. 첫 `>>` 가 첫째 값, 두 번째 `>>` 가 둘째 값이다. 줄 번호가 아니라 값 번호로 세는 것이 C++ 방식이다.
- 필요한 것보다 적게 읽으면 남은 값은 읽히지 않은 채 남는다(오류는 나지 않는다). 반대로 더 많이 읽으려 하면 읽을 값이 없어 `cin` 이 실패 상태가 되고, 그 뒤의 모든 `>>` 도 아무 일도 하지 않는다.
- 실패해도 프로그램이 멈추지 않는다는 점이 위험하다. 변수에 값이 안 들어간 채로 계속 실행되어 **틀린 답을 조용히 출력**하기 때문이다. 값 개수와 `>>` 개수를 눈으로 맞춰 두는 습관이 필요하다.
- 줄 끝의 줄바꿈은 값에 포함되지 않는다. 그래서 `4` 를 읽으면 줄바꿈이 섞이지 않은 수 `4` 가 들어가고, 바로 계산에 쓸 수 있다.

**문제**

**1) 두 줄의 합** · Easy

```runner
- `cin >> a >> b;`는 첫 값을 `a`, 다음 값을 `b`에 넣는다. 값들이 서로 다른 줄에 있어도 상관없다.
- 두 변수를 `int`로 선언했으니 그대로 숫자로 다룬다.
- `cout << a + b;`로 합을 출력한다.

다시 짤 때 순서: (1) 두 변수를 준비한다 → (2) `cin >> a >> b;`로 두 값을 받는다 → (3) 더해서 출력한다. 줄이 나뉘어 있어도 `>>`가 알아서 처리한다.
```

```runner
- 첫째·셋째는 그대로 두고 가운데만 `b * 2`로 두 배를 만든다.
- 값 사이마다 공백 `" "`을 끼워 출력하면 `1 4 3`이 된다. `b`가 `0`이면 `0 * 2 = 0`이라 그대로 `0`이 출력된다.

다시 짤 때 순서: (1) 세 값을 순서대로 `a`, `b`, `c`로 받는다 → (2) 출력할 때 가운데만 `* 2` → (3) 값 사이에 공백을 끼워 출력한다.
```

## L5. 문자, 문자열 입력

**개념**

- 숫자가 아니라 글자나 단어를 받을 때는 `std::string` 자료형을 쓴다. `#include <string>` 후 `string s; cin >> s;`로 받는다.
- "문자열"은 글자들이 이어진 값이고(예: `"apple"`), "문자"는 그중 한 글자를 뜻한다. 한 글자는 `char` 자료형이다.
- `cin >> s`는 공백을 구분자로 보기 때문에 공백 없는 한 단어를 읽어 온다.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;        // 한 단어를 문자열로 받는다
    cout << s;       // 받은 그대로 출력
    return 0;
}
```

- 문자열의 몇 번째 글자를 꺼내려면 대괄호와 번호(인덱스)를 쓴다. 번호는 0부터 시작한다: 첫 글자는 `s[0]`. 이때 `s[0]`은 문자열이 아니라 `char`(한 글자)다.

```cpp
string s;
cin >> s;            // 예: cat
cout << s[0];        // c (첫 글자)
```

> 선행: 인덱스로 글자를 꺼내는 것은 뒤 챕터에서 더 자세히 다룬다. 여기서는 "첫 글자 = `s[0]`" 정도만 사용한다.

**그림으로 보기**

문자열은 글자가 한 칸씩 늘어선 줄이고, 각 칸에는 **0부터 시작하는 번호**가 붙어 있다.

```text
  string s = "apple";

  +---+---+---+---+---+
  | a | p | p | l | e |
  +---+---+---+---+---+
    0   1   2   3   4        <- index (starts at 0, not 1)
    ^               ^
    s[0] = 'a'      s[4] = 'e'     // 5 letters -> last index is 4
```

숫자로 쓸 값과 글자로 쓸 값은 받는 상자가 다르다. 받는 자료형이 곧 "어떻게 읽을지"를 정한다.

```text
  typed line     string s; cin >> s;    int n; cin >> n;
  ------------   --------------------   ---------------------
  cat            "cat"   ok             fails, n keeps garbage
  7              "7"     ok             7       ok

  // here "7" is a letter, not a number. "7" + "7" is "77", not 14
```

`string` 과 `char` 는 다른 자료형이다. 한 글자만 담는 `char` 는 그 글자의 코드 번호를 갖고 있다.

```text
  string s = "cat";     char c = s[0];

  +-----------+         +---+
  |  c  a  t  |         | c |
  +-----------+         +---+
      s (3 letters)      c (1 letter, code 99)

  cout << c;          ->  c         // shown as a letter
  cout << c + 0;      ->  99        // the code number behind it
  cout << '7' - '0';  ->  7         // digit char turned into a number
```

**왜 이렇게 되는가**

- 인덱스가 1이 아니라 0에서 시작하는 이유: 번호를 "몇 번째"가 아니라 **"맨 앞에서 몇 칸 떨어져 있는가(거리)"** 로 읽으면 자연스럽다. 첫 글자는 0칸 떨어져 있으므로 0번이다.
- 이 규칙 덕분에 길이가 5인 문자열의 마지막 번호는 5가 아니라 **4** 가 된다. C++에서 `s[5]` 를 쓰면 파이썬처럼 오류를 내 주지 않고 **옆 메모리를 그대로 읽는다.** 값이 이상해지거나 프로그램이 갑자기 죽는데, 원인이 그 줄에 보이지 않아 찾기 어렵다.
- 그래서 인덱스를 쓸 때는 `s.size()` 로 길이를 먼저 확인하는 습관이 안전하다. 마지막 글자는 언제나 `s[s.size() - 1]` 이다.
- `char` 가 수처럼 계산되는 이유: `char` 는 글자에 붙은 **코드 번호**를 담는 작은 정수 상자다. `'a'` 는 97, `'0'` 은 48이다. 그래서 `'7' - '0'` 이 수 `7` 이 되는 계산이 성립한다.
- 숫자 문제에서 `int` 대신 `string` 으로 받으면 오류가 아니라 **조용히 틀린 답**이 나온다는 점이 더 위험하다. 값을 받을 때마다 "이 값은 계산에 쓸 것인가, 보여 줄 글자인가"를 먼저 정한다.
- `cin >> s` 는 공백을 값의 끝으로 보므로 **한 단어만** 읽는다. 공백이 포함된 문장 전체가 필요하면 다른 방법이 필요하다(뒤 챕터에서 다룬다).

## L6. 특정 문자를 사이에 두고 입력

**개념**

- 값들이 공백이 아니라 다른 특정 문자로 나뉘어 들어올 때가 있다. 예를 들어 날짜 `2026-07-01`은 `-`로, 시간 `12:30`은 `:`로 구분된다.
- 이럴 때 C++에서는 간단히, 값 사이에 낀 구분 문자를 임시 `char` 변수로 "받아서 버리는" 방법을 쓸 수 있다. `cin >> a >> sep >> b;`처럼 하면 가운데 `:`나 `-`가 `sep`에 담기고 나머지 숫자가 `a`, `b`에 들어간다.
- `>>`는 자료형에 맞춰 읽으므로, 정수 변수 `a`는 숫자 부분만 읽고 구분 문자 앞에서 멈춘다. 그 구분 문자를 `char`로 한 번 읽어 넘기면 다음 숫자를 이어 읽을 수 있다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    char sep;
    cin >> a >> sep >> b;   // "12:30" -> a=12, sep=':', b=30
    cout << a + b;          // 42
    return 0;
}
```

- 구분 문자를 담은 `sep`은 출력에 쓰지 않으면 그냥 버려지는 셈이다. 필요한 건 숫자 `a`, `b`뿐이다.

**그림으로 보기**

구분 문자는 값이 아니라서 계산에 쓸 일이 없다. 하지만 버퍼에는 분명히 들어 있으므로 **누군가 읽어서 치워야** 다음 값을 읽을 수 있다. 그 역할을 `char` 변수 하나가 맡는다.

```text
  input:  2 0 2 6 - 0 7 - 0 1 [NL]

  cin >> y;    reads 2026, stops at '-'       y  = 2026
  cin >> s1;   takes that '-' out of the way   s1 = '-'
  cin >> m;    reads 07                        m  = 7
  cin >> s2;   takes the second '-'            s2 = '-'
  cin >> d;    reads 01                        d  = 1

  // s1 and s2 are thrown away. only y, m, d are used
```

구분 문자를 읽어 치우지 않으면 다음 `>>` 가 그 자리에서 막힌다.

```text
  int a, b;
  cin >> a >> b;             input "12:30"

  cin >> a   ->  12          buffer left:  ":30[NL]"
  cin >> b   ->  fails       ':' is not a digit, nothing is read
                             b keeps its garbage value

  char sep;
  cin >> a >> sep >> b;      ->  a=12  sep=':'  b=30     // ok
```

정수로 읽는 순간 앞의 `0` 은 사라진다. 모양이 아니라 값이 되기 때문이다.

```text
  "07"  as text     0 7      two letters, the 0 is shown
   07   as int        7      the 0 adds nothing to the size

  cout << m;      ->  7      // not 07
```

**왜 이렇게 되는가**

- `>>` 는 자료형에 맞는 글자만 읽고, 맞지 않는 글자를 만나면 **거기서 멈추고 그 글자를 버퍼에 남긴다.** 정수를 읽는 중에 `-` 나 `:` 를 만나면 더 읽지 않는다.
- 남은 구분 문자는 저절로 사라지지 않는다. 다음 `>>` 도 같은 자리에서 같은 글자를 만나 또 멈추므로, 치우지 않으면 그 뒤로는 아무것도 읽히지 않는다.
- `char` 로 한 글자만 읽으면 그 글자가 버퍼에서 빠져나가 길이 열린다. 값으로 쓸 것이 아니므로 변수 이름을 `sep` 처럼 "버릴 것"임이 드러나게 짓는다.
- 주의할 점 하나: 숫자 앞의 `-` 는 부호로도 읽힌다. `10-3` 을 `cin >> a >> sep >> b;` 로 읽으면 `a = 10`, `sep = '-'`, `b = 3` 이지만, `cin >> a >> b;` 로만 읽으면 `a = 10`, `b = -3` 이 된다. 무엇을 구분자로 볼지는 코드가 정한다.
- `07` 이 `7` 이 되는 이유: `07` 은 글자 두 개지만, **수로 읽으면 맨 앞의 0은 크기에 아무 기여를 하지 않는다.** 정수가 되는 순간 값은 7이고, 다시 출력하면 `07` 이 아니라 `7` 로 나온다.
- 자리 맞춤이 있는 `07` 모양을 그대로 유지해야 한다면 정수로 바꾸지 말고 `string` 으로 받거나, 출력할 때 `setw(2) << setfill('0')` 으로 모양을 만든다.

**문제**

**1) 콜론으로 나눈 두 수의 합** · Easy

**2) 날짜 분리** · Medium

- **요구사항**: `연-월-일` 형태의 날짜를 입력받아, 연·월·일을 공백으로 구분해 한 줄에 출력한다.

- **셀프체크**: `07`을 `int`로 읽으면 `7`이 된다(앞의 0이 사라짐). 예제 출력이 `7`, `1`인 이유를 확인.

```runner
접근: `-`를 `char`로 두 번 읽어 넘기고, 세 숫자만 받아 출력한다.

- `cin >> y >> sep1 >> m >> sep2 >> d;`는 숫자-구분자-숫자-구분자-숫자 순서로 읽는다. `"2026-07-01"`이 `y=2026`, `m=7`, `d=1`이 된다.
- `int`로 읽을 때 앞의 0은 자동으로 사라진다. 그래서 `"07"`은 `7`, `"01"`은 `1`이다. 그래서 예제 출력이 `7`, `1`이다.
- 세 값 사이에 공백 `" "`을 끼워 출력한다.

다시 짤 때 순서: (1) 정수 세 개와 `char` 두 개를 준비한다 → (2) 숫자-`-`-숫자-`-`-숫자 순서로 읽는다 → (3) 세 값을 공백을 끼워 출력한다.
```

**3) 쉼표로 나눈 세 수 중 최댓값** · Hard

- **요구사항**: `,`로 구분된 세 정수를 입력받아, 가장 큰 값을 출력한다.
- **입력**: `a,b,c` 형태로 세 정수가 쉼표로 구분되어 한 줄에 주어진다. (쉼표 앞뒤에 공백은 없다)
- **출력**: 세 수 중 가장 큰 값을 한 줄에 출력한다.
- **예제**: `3,9,5` → `9` / `-1,-4,-2` → `-1`
- **셀프체크**: `,`를 `char`로 읽어 넘기고 세 정수를 받는다. 셋 중 최댓값 비교는 크기를 하나씩 견주면 된다. 음수만 있을 때도 맞는지 확인.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    char sep1, sep2;
    cin >> a >> sep1 >> b >> sep2 >> c;
    int biggest = a;
    if (b > biggest) biggest = b;
    if (c > biggest) biggest = c;
    cout << biggest << "\n";
    return 0;
}
@@TESTS
--IN
3,9,5
--OUT
9
--IN
-1,-4,-2
--OUT
-1
--IN
7,7,2
--OUT
7
@@EXPL
접근: `,`를 `char`로 넘기며 세 정수를 받은 뒤, 크기를 하나씩 견주며 최댓값을 갱신한다.

- `cin >> a >> sep1 >> b >> sep2 >> c;`로 `"3,9,5"`를 `a=3`, `b=9`, `c=5`로 받는다. 가운데 두 개의 `,`는 `char`로 읽어 넘긴다.
- 먼저 첫 값 `a`를 임시 최댓값 `biggest`로 둔다.
- `if (b > biggest)`이면 `biggest`를 `b`로 바꾸고, 다시 `if (c > biggest)`이면 `c`로 바꾼다. 이렇게 하나씩 견주면 셋 중 가장 큰 값이 남는다. 음수만 있는 `-1,-4,-2`에서도 가장 큰 `-1`이 잘 남는다.
- `cout << biggest;`로 출력한다.

다시 짤 때 순서: (1) 세 정수와 구분용 `char` 두 개를 준비해 숫자-`,`-숫자-`,`-숫자로 읽는다 → (2) 첫 값을 최댓값 후보로 잡는다 → (3) 나머지를 하나씩 비교해 더 크면 후보를 갱신한다 → (4) 최종 후보를 출력한다.
```
