> 개요: 이 챕터에서는 같은 동작을 여러 번 되풀이하는 "반복문"을 배운다. 특히 `for`와 `while`로 정해진 구간을 1씩 또는 2씩, 늘리거나 줄이며 순회하는 가장 기본적인 방법을 익힌다.

## L1. for문 a → b 1씩 증가

**개념**

- 반복문은 "같은 일을 여러 번 하는" 문법이다. 손으로 하나씩 쓰는 대신 컴퓨터가 대신 반복한다.

- C++의 기본 `for`는 `for (초기식; 조건식; 증감식)` 세 부분으로 이루어진다. 초기식에서 카운터 변수를 만들고, 조건식이 참인 동안 반복하며, 매 반복 끝에 증감식이 실행된다.

- `for (int i = a; i < b; i++)` 형태로 쓰면, `i`가 `a`부터 시작해 `b`가 되기 직전(`b-1`)까지 1씩 늘어나며 중괄호 `{ }` 안의 코드가 반복된다. 조건이 `i < b`라 **`b`는 포함되지 않는다**(끝은 열려 있다).

- 반복될 코드는 중괄호 `{ }`로 묶는다. 한 줄이면 중괄호를 생략할 수도 있지만, 초보 단계에서는 항상 `{ }`로 감싸는 습관을 들이는 것이 안전하다.

```cpp
// 1부터 5까지 출력
for (int i = 1; i < 6; i++) {   // 6은 포함되지 않으므로 1,2,3,4,5
    cout << i << "\n";
}
// 출력: 1 2 3 4 5 (각각 줄바꿈)
```

- `a`부터 `b`까지(양 끝 모두 포함) 돌고 싶다면 조건을 `i <= b`로 쓰거나 `i < b+1`로 쓴다. 마지막 값을 놓치기 쉬우니 주의한다.

> 핵심 정리 (반열림):
>
> - `i < b`는 끝 `b` **바로 앞에서 멈춘다**. 즉 `b`는 나오지 않는다.
> - 끝 값 `b`까지 **포함**하고 싶으면 조건을 `i <= b`로 쓴다.

**문제**

**1) 1부터 N까지 출력** · Easy

- **요구사항**: 정수 `N`을 입력받아 1부터 N까지의 정수를 한 줄에 하나씩 순서대로 출력하는 프로그램을 작성하시오.
- **입력**: 첫 줄에 정수 `N` (1 ≤ N ≤ 100)
- **출력**: 1부터 N까지의 정수를 한 줄에 하나씩 출력
- **예제**: `5` → `1` / `2` / `3` / `4` / `5` (5줄), `1` → `1` (1줄)
- **셀프체크**: 조건을 `i < N`으로 쓰면 N이 빠진다. N까지 포함하려면 `i <= N`.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int N;
    cin >> N;
    for (int i = 1; i <= N; i++) {
        cout << i << "\n";
    }
    return 0;
}
@@TESTS
--IN
5
--OUT
1
2
3
4
5
--IN
1
--OUT
1
@@EXPL
(1) 접근: 1부터 N까지 한 줄에 하나씩 출력한다. 반복문의 가장 기본형으로, 조건식의 끝값을 정확히 잡는 게 핵심이다.

(2) 코드 진행:

- `cin >> N`으로 정수 N을 입력받는다.
- `for (int i = 1; i <= N; i++)` — i를 1부터 시작해 N까지(포함) 1씩 늘린다. 끝을 포함하려면 조건을 `i <= N`으로 둔다. `i < N`이면 N이 빠진다.
- 반복 안에서 `cout << i << "\n";`로 현재 값을 출력한다. `"\n"`이 줄바꿈이므로 한 줄에 하나씩 나온다.
- N=1이면 1 하나만 출력된다.

(3) 스스로 짤 때 생각 순서: "N까지 세야 한다 → 조건은 `i <= N`" → "각 값을 `cout`으로 한 줄씩" → "중괄호로 반복 안 표시". 만약 `i < N`으로 쓰면 N이 빠지니, 끝값 포함 조건 `<=`를 습관으로 챙긴다.
```

**2) A부터 B까지 합** · Medium

- **요구사항**: 두 정수 `A`, `B`(A ≤ B)를 입력받아 A부터 B까지 모든 정수의 합을 구해 출력하시오.
- **입력**: 첫 줄에 공백을 사이에 두고 `A B` (−100 ≤ A ≤ B ≤ 100)
- **출력**: A부터 B까지의 합 (한 줄)
- **예제**: `1 10` → `55`, `3 5` → `12` (3+4+5=12)
- **셀프체크**: 끝 값 B까지 더해야 하므로 조건은 `i <= B`. 합을 담을 변수는 반복 시작 전에 0으로 초기화했는가.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int A, B;
    cin >> A >> B;
    int total = 0;
    for (int i = A; i <= B; i++) {
        total = total + i;
    }
    cout << total << "\n";
    return 0;
}
@@TESTS
--IN
1 10
--OUT
55
--IN
3 5
--OUT
12
--IN
-2 2
--OUT
0
@@EXPL
(1) 접근: A부터 B까지 모든 정수를 하나씩 더한다. 합을 담을 그릇을 미리 0으로 두고, 반복하며 각 값을 더해 나간다.

(2) 코드 진행:

- `cin >> A >> B;`로 한 줄에 공백으로 들어온 두 정수를 차례로 받는다. `cin`은 공백을 자동으로 건너뛴다.
- `int total = 0;` — 합 그릇을 0으로 초기화한다. 이걸 반복 밖(시작 전)에 두는 게 중요하다. 안에 두면 매번 0으로 지워진다.
- `for (int i = A; i <= B; i++)` — A부터 B까지(포함) 훑는다. 조건을 `i <= B`로 둬야 B가 더해진다.
- 반복 안에서 `total = total + i;`로 현재 값을 그릇에 더한다.
- A가 음수여도 그대로 동작한다. 예: -2..2는 -2+-1+0+1+2 = 0.
- 반복이 끝나면 `total`을 출력한다.

(3) 스스로 짤 때 생각 순서: "합 그릇 0으로 준비(반복 밖)" → "A부터 B까지, 끝 포함이라 `i <= B`" → "훑으며 그릇에 더하기" → "합 출력". 초기화 위치와 끝 조건 두 가지만 실수하지 않으면 된다.
```

**3) N까지의 홀수만 출력** · Medium

- **요구사항**: 정수 `N`을 입력받아 1부터 N까지 중 **홀수만** 한 줄에 하나씩 출력하시오.
- **입력**: 첫 줄에 정수 `N` (1 ≤ N ≤ 100)
- **출력**: 1부터 N 이하의 홀수를 작은 것부터 한 줄에 하나씩 출력
- **예제**: `7` → `1` / `3` / `5` / `7`, `6` → `1` / `3` / `5`
- **셀프체크**: 1씩 증가하며 돌되, 홀수 판별은 배운 조건문(`if`)과 나머지(`%`)로 한다. N이 짝수일 때 N은 출력되지 않아야 한다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int N;
    cin >> N;
    for (int i = 1; i <= N; i++) {
        if (i % 2 == 1) {
            cout << i << "\n";
        }
    }
    return 0;
}
@@TESTS
--IN
7
--OUT
1
3
5
7
--IN
6
--OUT
1
3
5
@@EXPL
(1) 접근: 1부터 N까지 모두 훑되, 각 값이 홀수일 때만 출력한다. "훑기(반복)"와 "고르기(조건)"를 합친 문제다.

(2) 코드 진행:

- `for (int i = 1; i <= N; i++)` — 1부터 N까지(포함) 하나씩 훑는다. 조건을 `i <= N`으로 둬야 N까지 나온다.
- 반복 안에서 `if (i % 2 == 1)` — i를 2로 나눈 나머지가 1이면 홀수다. 이때만 `cout << i << "\n";`.
- 짝수면 나머지가 0이라 조건이 거짓이 되어 출력하지 않고 넘어간다.
- N이 짝수(예: 6)면 6은 홀수가 아니라 출력되지 않는다.

(3) 스스로 짤 때 생각 순서: "1부터 N까지 다 훑자" → "홀수만 걸러야 하니 `i % 2 == 1` 검사" → "통과하면 출력". `cout`이 `if`의 중괄호 안에 있어야 조건을 만족할 때만 나온다는 점을 확인한다.
```


## L2. for문 a → b 2씩 증가

**개념**

- `for`의 세 번째 부분(증감식)을 바꾸면 간격(step)을 조절할 수 있다. `i += 2`(또는 `i = i + 2`)로 쓰면 **2씩 더하며** 진행한다.

- `for (int i = a; i < b; i += 2)`는 `a, a+2, a+4, ...`로 진행하고, 조건이 `i < b`라 `b`는 여전히 포함되지 않는다(끝은 열려 있다).

- 증감식을 `i++`로 두면 자동으로 1씩이다. `i++`와 `i += 1`은 같은 뜻이다.

```cpp
// 0부터 10 미만까지 2씩
for (int i = 0; i < 10; i += 2) {
    cout << i << "\n";
}
// 출력: 0 2 4 6 8  (10은 포함되지 않음)
```

- 마지막에 도달하는 값이 정확히 `b`가 아닐 수 있음에 주의한다. 예를 들어 `for (int i = 1; i <= 6; i += 2)`는 `1, 3, 5`이고 그다음 값 7은 6을 넘으므로 나오지 않는다.

**문제**

**1) 1부터 시작하는 홀수 출력** · Easy

- **요구사항**: 정수 `N`을 입력받아 1부터 N 이하의 홀수를 한 줄에 하나씩 출력하시오. (이번에는 간격을 이용한다.)
- **입력**: 첫 줄에 정수 `N` (1 ≤ N ≤ 100)
- **출력**: 1, 3, 5, ... 형태로 N을 넘지 않는 홀수를 한 줄에 하나씩
- **예제**: `9` → `1` / `3` / `5` / `7` / `9`, `8` → `1` / `3` / `5` / `7`
- **셀프체크**: `for (int i = 1; i <= N; i += 2)`. N이 홀수면 N까지 나오고, 짝수면 N 바로 앞 홀수까지 나온다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int N;
    cin >> N;
    for (int i = 1; i <= N; i += 2) {
        cout << i << "\n";
    }
    return 0;
}
@@TESTS
--IN
9
--OUT
1
3
5
7
9
--IN
8
--OUT
1
3
5
7
@@EXPL
(1) 접근: 앞 레슨에서는 `if`로 홀수를 걸렀지만, 이번엔 간격(step)을 이용한다. 1에서 시작해 2씩 늘리면 조건문 없이도 홀수만 나온다.

(2) 코드 진행:

- `for (int i = 1; i <= N; i += 2)` — 1에서 시작해 2씩 늘리며 N까지(포함) 훑는다. 증감식 `i += 2`가 "2씩 증가"를 뜻한다.
- 조건을 `i <= N`으로 둬야 N이 홀수일 때 N도 포함된다.
- 반복 안에서 `cout << i << "\n";`로 1, 3, 5, …를 한 줄씩 출력한다.
- N이 짝수(예: 8)면 7까지 출력되고 다음 값 9는 `9 <= 8`이 거짓이라 나오지 않는다. 즉 N 바로 앞 홀수까지.

(3) 스스로 짤 때 생각 순서: "홀수 = 1부터 2씩" → "N까지 포함하려면 조건 `i <= N`" → "각 값 한 줄씩 출력". 같은 결과를 `if (i % 2 == 1)`로도 낼 수 있지만, 간격을 쓰면 판별이 필요 없다는 걸 비교해 본다.
```

**2) A부터 B까지 2씩 건너뛰며 합** · Medium

- **요구사항**: 두 정수 `A`, `B`(A ≤ B)를 입력받아 A에서 시작해 2씩 커지는 값들(B를 넘지 않는 것까지)의 합을 출력하시오.
- **입력**: 첫 줄에 `A B` (1 ≤ A ≤ B ≤ 100)
- **출력**: A, A+2, A+4, ... 중 B 이하인 값들의 합
- **예제**: `1 10` → `25` (1+3+5+7+9), `2 8` → `20` (2+4+6+8)
- **셀프체크**: 끝을 포함하려면 조건 `i <= B`. A가 홀수인지 짝수인지에 따라 더해지는 값이 달라진다. B가 정확히 마지막 항이 되지 않을 수도 있다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int A, B;
    cin >> A >> B;
    int total = 0;
    for (int i = A; i <= B; i += 2) {
        total = total + i;
    }
    cout << total << "\n";
    return 0;
}
@@TESTS
--IN
1 10
--OUT
25
--IN
2 8
--OUT
20
@@EXPL
(1) 접근: A에서 시작해 2씩 커지는 값들 중 B를 넘지 않는 것까지 더한다. 증감식을 `i += 2`로 두어 2씩 건너뛴다.

(2) 코드 진행:

- `cin >> A >> B;`로 두 정수를 받는다.
- 합을 담을 `int total = 0;`을 준비한다.
- `for (int i = A; i <= B; i += 2)` — A에서 시작해 2씩 늘리며 B까지(포함) 훑는다. 조건을 `i <= B`로 둬야 B가 항에 들어올 때 놓치지 않는다.
- 반복 안에서 `total = total + i;`로 각 값을 더한다.
- 예: `1 10`이면 1,3,5,7,9를 더해 25. 다음 값 11은 10을 넘어 포함되지 않으므로 B(10)가 마지막 항이 아니다.
- 반복이 끝나면 `total`을 출력한다.

(3) 스스로 짤 때 생각 순서: "2씩 건너뛰기 → 증감식 `i += 2`" → "B 포함하려면 조건 `i <= B`" → "합 그릇 0 준비" → "훑으며 더하기". 시작값 A가 짝수면 짝수만, 홀수면 홀수만 더해진다는 점을 떠올리면 결과를 검산하기 쉽다.
```

**3) 짝수의 개수 세기** · Hard

- **요구사항**: 정수 `N`을 입력받아 1부터 N까지 중 짝수의 개수를 구해 출력하시오. 단, 2씩 증가하는 반복으로 직접 세어 구하시오(공식 사용 금지).
- **입력**: 첫 줄에 정수 `N` (1 ≤ N ≤ 1000)
- **출력**: 1부터 N까지의 짝수 개수 (한 줄)
- **예제**: `10` → `5` (2,4,6,8,10), `7` → `3` (2,4,6), `1` → `0`
- **셀프체크**: 2부터 시작해 2씩 증가시키며 개수를 센다. N이 1이면 짝수가 없어 0이 나와야 한다. 세는 변수는 0으로 초기화한다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int N;
    cin >> N;
    int count = 0;
    for (int i = 2; i <= N; i += 2) {
        count = count + 1;
    }
    cout << count << "\n";
    return 0;
}
@@TESTS
--IN
10
--OUT
5
--IN
7
--OUT
3
--IN
1
--OUT
0
@@EXPL
(1) 접근: 1부터 N까지 중 짝수의 개수를 공식 없이 직접 센다. 짝수는 2, 4, 6, …이므로 2부터 2씩 훑으며 한 개 지날 때마다 세면 된다.

(2) 코드 진행:

- 개수를 담을 `int count = 0;`을 준비한다.
- `for (int i = 2; i <= N; i += 2)` — 2에서 시작해 2씩 늘리며 N까지(포함) 짝수만 훑는다. 조건을 `i <= N`으로 둬야 N이 짝수일 때 N도 포함된다.
- 반복 안에서 `count = count + 1;`로 짝수 하나를 지날 때마다 1씩 센다. 값 자체는 쓰지 않고 "몇 번 돌았나"만 센다.
- N=1이면 시작부터 `2 <= 1`이 거짓이라 반복이 한 번도 돌지 않아 count는 0.
- 반복이 끝나면 `count`를 출력한다.

(3) 스스로 짤 때 생각 순서: "짝수만 훑자 → 2부터 2씩" → "셀 그릇 0 준비" → "짝수를 지날 때마다 +1" → "개수 출력". 값을 더하는 게 아니라 횟수를 센다는 점이 합 문제와 다르다.
```


## L3. for문 b → a 1씩 감소

**개념**

- 큰 수에서 작은 수로 **거꾸로** 돌 때는 증감식을 `i--`(또는 `i -= 1`)로 주고, 조건도 방향에 맞게 바꾼다.

- `for (int i = b; i > a; i--)`는 `b`에서 시작해 1씩 줄이며 진행한다. 조건이 `i > a`라 `a`는 포함되지 않는다. 즉 값은 `b, b-1, ..., a+1`까지다.

- `a`까지(포함) 내려가고 싶다면 조건을 `i >= a`로 써야 한다. `>=`(크거나 같음)을 써야 `a`까지 나온다.

```cpp
// 5부터 1까지 거꾸로
for (int i = 5; i >= 1; i--) {   // 조건 i >= 1이라 1까지 포함, 5,4,3,2,1
    cout << i << "\n";
}
// 출력: 5 4 3 2 1
```

- 감소 반복에서는 증감식을 `i--`로 두는 것과 조건 부호를 `>`/`>=`로 바꾸는 것을 함께 챙긴다. 방향과 부호가 어긋나면 무한 반복이 되기 쉽다.

**문제**

**1) N부터 1까지 거꾸로 출력** · Easy

- **요구사항**: 정수 `N`을 입력받아 N부터 1까지 한 줄에 하나씩 내림차순으로 출력하시오.
- **입력**: 첫 줄에 정수 `N` (1 ≤ N ≤ 100)
- **출력**: N, N−1, ..., 1을 한 줄에 하나씩
- **예제**: `5` → `5` / `4` / `3` / `2` / `1`, `1` → `1`
- **셀프체크**: 1까지 포함하려면 조건을 `i >= 1`로 둔다. 증감식 `i--`를 잊지 않았는가.

```runner

int main() {
    int N;
    cin >> N;
    for (int i = N; i >= 1; i--) {
        cout << i << "\n";
    }
    return 0;
}
@@TESTS

--OUT

3

1
--IN

@@EXPL
(1) 접근: N부터 1까지 거꾸로 출력한다. 거꾸로 돌 때는 증감식을 `i--`로 주고, 조건 부호를 조심해서 정한다.

(2) 코드 진행:

- `for (int i = N; i >= 1; i--)` — N에서 시작해 1씩 줄인다. 증감식 `i--`가 "1씩 감소"를 뜻한다.
- 조건을 `i >= 1`로 둔 이유: 1까지 포함해야 하기 때문이다. `i > 1`로 쓰면 1이 빠진다.
- 반복 안에서 `cout << i << "\n";`로 N, N−1, …, 1을 한 줄씩 출력한다.
- i가 0이 되면 `0 >= 1`이 거짓이라 반복이 끝난다.
- N=1이면 1 하나만 출력된다.

(3) 스스로 짤 때 생각 순서: "거꾸로니까 증감식은 `i--`" → "1까지 보여야 하니 조건은 `i >= 1`" → "각 값을 한 줄씩 출력". 증감식을 `i++`로 두면(방향이 어긋나면) 조건이 계속 참이라 무한 반복이 된다는 점을 기억한다.
```

## L4. while문 a → b 1씩 증가

**개념**

- `while (조건)`은 "조건이 참인 동안" 중괄호 안의 코드를 계속 반복한다. `for`와 달리 카운터 값을 우리가 직접 관리한다.

- 보통 세 단계로 쓴다: (1) 시작값을 변수에 넣는다 → (2) `while`에 끝 조건을 적는다 → (3) 반복 안에서 변수를 직접 1 늘린다.

- 변수를 늘리는 줄(`i = i + 1;` 또는 `i++;`)을 빼먹으면 조건이 영원히 참이라 끝나지 않는다(무한 반복). 이 "값을 바꿔 주는 코드"를 절대 잊지 않는다.

```cpp
// 1부터 5까지 출력 (while 버전)
int i = 1;
while (i <= 5) {      // i가 5 이하인 동안 반복
    cout << i << "\n";
    i = i + 1;        // 이 줄이 없으면 무한 반복
}
// 출력: 1 2 3 4 5
```

- `a`부터 `b`까지 포함하려면 조건을 `i <= b`로 쓴다. `i < b`로 쓰면 마지막 `b`가 빠진다.

**문제**

**1) 1부터 N까지 출력 (while)** · Easy

- **요구사항**: 정수 `N`을 입력받아 1부터 N까지 한 줄에 하나씩 출력하시오. 반드시 `while`을 사용한다.
- **입력**: 첫 줄에 정수 `N` (1 ≤ N ≤ 100)
- **출력**: 1부터 N까지 한 줄에 하나씩
- **예제**: `4` → `1` / `2` / `3` / `4`, `1` → `1`
- **셀프체크**: 시작값 초기화, 끝 조건 `i <= N`, 반복 안에서 `i` 증가 — 세 가지가 모두 있는가.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int N;
    cin >> N;
    int i = 1;
    while (i <= N) {
        cout << i << "\n";
        i = i + 1;
    }
    return 0;
}
@@TESTS
--IN
4
--OUT
1
2
3
4
--IN
1
--OUT
1
@@EXPL
(1) 접근: 1부터 N까지 출력하는 for문을 while로 바꾼다. while은 "시작값 → 끝조건 → 증가" 세 부분을 우리가 직접 챙겨야 한다.

(2) 코드 진행:

- `int i = 1;`로 시작값을 잡는다.
- `while (i <= N)` — i가 N 이하인 동안 반복. N까지 포함하려면 `<=`를 쓴다(`<`면 N이 빠짐).
- 반복 안에서 `cout << i << "\n";`로 현재 값을 출력하고, `i = i + 1;`로 값을 늘린다.
- 이 증가 줄을 빼먹으면 조건이 영원히 참이라 무한 반복이 된다.
- i가 N+1이 되면 조건이 거짓이 되어 반복이 끝난다.

(3) 스스로 짤 때 생각 순서: "시작은 1" → "언제까지? i가 N 이하인 동안" → "매번 출력하고 1 늘리기". for문의 세 부분(초기식·조건식·증감식)을 while의 세 곳(선언·조건·본문 끝)으로 옮긴다고 생각하면 헷갈리지 않는다.
```

**2) 1부터 N까지 합 (while)** · Medium

- **요구사항**: 정수 `N`을 입력받아 1부터 N까지의 합을 `while`로 구해 출력하시오.
- **입력**: 첫 줄에 정수 `N` (1 ≤ N ≤ 1000)
- **출력**: 1부터 N까지의 합 (한 줄)
- **예제**: `10` → `55`, `100` → `5050`
- **셀프체크**: 합 변수와 세는 변수 두 개가 필요하다. 둘 다 반복 전에 초기화했는가. `i`를 늘리는 줄이 합을 더한 뒤에 오는가.

```runner

int main() {

    cin >> N;
    int total = 0;
    int i = 1;
    while (i <= N) {
        total = total + i;
        i = i + 1;
    }
    cout << total << "\n";
    return 0;
}
@@TESTS
--IN
10
--OUT
55
--IN
100
--OUT
5050
@@EXPL
(1) 접근: 1부터 N까지 하나씩 더한다. while로 값을 직접 관리하므로 "합을 담는 변수"와 "지금 더할 값 i" 두 개가 필요하다.

(2) 코드 진행:

- `int total = 0;`으로 합 그릇을, `int i = 1;`로 첫 값을 준비한다. 둘 다 반복 시작 전에 초기화한다.
- `while (i <= N)` — i가 N 이하인 동안 반복.
- 반복 안에서 먼저 `total = total + i;`로 현재 값을 더한다.
- 그다음 `i = i + 1;`로 다음 값으로 넘어간다. 더한 뒤에 늘려야 N까지 빠짐없이 더해진다.
- 반복이 끝나면 `total`을 출력한다.

(3) 스스로 짤 때 생각 순서: "합 그릇 0, 셀 값 1 준비" → "N 이하인 동안 반복" → "그릇에 i 더하기 → i 늘리기 순서 지키기" → "합 출력". 순서를 바꿔 i를 먼저 늘리면 1이 빠지고 N이 하나 더 더해지니 주의한다.
```

**3) 자릿수 세기** · Hard

- **요구사항**: 양의 정수 `N`을 입력받아 그 수가 몇 자리 수인지 출력하시오. `N`을 10으로 계속 나누는 방식으로 세시오.
- **입력**: 첫 줄에 정수 `N` (1 ≤ N ≤ 1,000,000,000)
- **출력**: 자릿수 (한 줄)

```runner
        N = N / 10;
        count = count + 1;
    }
    cout << count << "\n";
    return 0;
}
@@TESTS
--IN
7
--OUT
1
--IN
100
--OUT
3
--IN
4096
--OUT

@@EXPL

(2) 코드 진행:

- 자릿수를 셀 `int count = 0;`을 준비한다.
- `while (N > 0)` — N이 0보다 큰 동안 반복.
- 반복 안에서 `N = N / 10;` — 정수끼리의 나눗셈은 몫만 남으므로 맨 뒷자리를 하나 떼어낸다. 예: 4096 → 409 → 40 → 4 → 0.

(3) 스스로 짤 때 생각 순서: "자릿수 = 10으로 몇 번 나누면 0이 되나" → "셀 그릇 0 준비" → "N이 0보다 큰 동안 반복" → "매번 `/ 10` 하고 카운트 +1" → "카운트 출력". C++에서 정수 `/`가 몫만 남긴다는 점이 핵심이다.
```

## L5. while문 a → b 2씩 증가

**개념**

- `while`에서 2씩 증가는 변수를 늘리는 줄을 `i = i + 2;`(또는 `i += 2;`)로 바꾸기만 하면 된다. 시작값과 조건은 목적에 맞게 정한다.

- 2씩 늘리므로 마지막에 `i`가 정확히 `b`가 되지 않고 `b`를 살짝 넘어서 멈출 수 있다. 조건은 여전히 `i <= b`로 두면 안전하다.

```cpp
// 1부터 10 이하까지 2씩 (while 버전)
int i = 1;
while (i <= 10) {
    cout << i << "\n";
    i = i + 2;
}
// 출력: 1 3 5 7 9  (다음은 11이라 조건에 걸려 멈춤)
```

- 짝수만 돌고 싶으면 시작값을 짝수(예: `int i = 2;`)로 두면 된다. 시작값에 따라 홀수열/짝수열이 갈린다.

```runner
1
@@EXPL
(1) 접근: 1부터 N 이하의 홀수를 while로 출력한다. 홀수는 1, 3, 5, …이므로 1에서 시작해 2씩 늘리면 계속 홀수만 나온다.

(2) 코드 진행:

- `int i = 1;`로 첫 홀수를 시작값으로 잡는다.
- `while (i <= N)` — i가 N 이하인 동안 반복.
- 반복 안에서 `cout << i << "\n";`로 출력하고 `i = i + 2;`로 다음 홀수로 넘어간다.
- N이 짝수(예: 10)면 i가 9까지 출력된 뒤 다음 값 11이 `11 <= 10`에 걸려 멈춘다. 즉 마지막 홀수는 N−1.

(3) 스스로 짤 때 생각 순서: "첫 홀수는 1" → "N 이하인 동안" → "출력하고 2씩 더하기". `for (int i = 1; i <= N; i += 2)`와 완전히 같은 일을, 값을 손으로 관리하는 while로 옮긴 것뿐이다.
```

**2) 짝수의 합 (while)** · Medium

- **요구사항**: 정수 `N`을 입력받아 1부터 N까지 중 짝수들의 합을 `while`로 구해 출력하시오.
- **입력**: 첫 줄에 정수 `N` (1 ≤ N ≤ 1000)
- **출력**: N 이하 짝수들의 합 (한 줄)
- **예제**: `10` → `30` (2+4+6+8+10), `9` → `20` (2+4+6+8), `1` → `0`
- **셀프체크**: 시작값을 2로 두고 `i = i + 2`. N이 1이면 반복 조건이 처음부터 거짓이라 합은 0이어야 한다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int N;
    cin >> N;
    int total = 0;
    int i = 2;
    while (i <= N) {
        total = total + i;
        i = i + 2;
    }
    cout << total << "\n";
    return 0;
}
@@TESTS
--IN
10
--OUT
30
--IN
9
--OUT
20
--IN
1
--OUT
0
@@EXPL
(1) 접근: 1부터 N까지 중 짝수만 더한다. 짝수는 2, 4, 6, …이므로 시작값을 2로 두고 2씩 늘리면 판별 없이 짝수만 훑을 수 있다.

(2) 코드 진행:

- 합을 담을 `int total = 0;`, 훑을 값 `int i = 2;`로 초기화한다.
- `while (i <= N)` — i가 N 이하인 동안 반복.
- 반복 안에서 `total = total + i;`로 현재 짝수를 더하고, `i = i + 2;`로 다음 짝수로 넘어간다.
- N이 1이면 시작부터 `2 <= 1`이 거짓이라 반복이 한 번도 돌지 않아 total은 0 그대로.
- 반복이 끝나면 `total`을 출력한다.

(3) 스스로 짤 때 생각 순서: "짝수만 더하고 싶다 → 2부터 2씩 훑으면 자동으로 짝수" → "합 그릇 0으로 준비" → "N 이하인 동안 더하고 2씩 전진" → "합 출력". `if`로 짝수를 걸러도 되지만, 시작값과 간격으로 처리하면 조건문이 필요 없다.
```

**3) A에서 시작해 K를 넘어서기 직전까지** · Hard

- **요구사항**: 두 정수 `A`, `K`를 입력받아, `A`에서 시작해 2씩 더한 값을 한 줄에 하나씩 출력하되 `K`를 초과하는 값은 출력하지 않고 멈추시오.
- **입력**: 첫 줄에 `A K` (0 ≤ A ≤ K ≤ 100)
- **출력**: A, A+2, A+4, ... 중 K 이하인 값들을 한 줄에 하나씩
- **예제**: `3 12` → `3` / `5` / `7` / `9` / `11`, `4 4` → `4`
- **셀프체크**: 조건은 `i <= K`. A가 짝수인지 홀수인지에 따라 결과 수열이 달라진다. A와 K가 같으면 A 한 번만 출력된다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int A, K;
    cin >> A >> K;
    int i = A;
    while (i <= K) {
        cout << i << "\n";
        i = i + 2;
    }
    return 0;
}
@@TESTS
--IN
3 12
--OUT
3
5
7
9
11
--IN
4 4
--OUT
4
@@EXPL
(1) 접근: A에서 시작해 2씩 더한 값을 출력하되, K를 넘으면 멈춘다. while의 조건 `i <= K`가 곧 "K를 넘어서기 직전까지"라는 뜻이다.

(2) 코드 진행:

- `cin >> A >> K;`로 두 정수를 받는다.
- 훑을 값을 `int i = A;`로 시작한다.
- `while (i <= K)` — i가 K 이하인 동안 반복. i가 K를 초과하는 순간 조건이 거짓이 되어 그 값은 출력되지 않는다.
- 반복 안에서 `cout << i << "\n";`로 출력하고 `i = i + 2;`로 2 늘린다.
- 예: A=3, K=12면 3,5,7,9,11까지 나오고 다음 값 13은 `13 <= 12`에 걸려 멈춘다.

(3) 스스로 짤 때 생각 순서: "시작은 A" → "K 이하인 동안만" → "출력하고 2 더하기". 시작값 A가 짝수면 짝수열, 홀수면 홀수열이 나온다는 점을 떠올리면 결과를 예측하기 쉽다.
```


## L6. while문 b → a 1씩 감소

**개념**

- 거꾸로 내려갈 때는 변수를 줄이는 줄을 `i = i - 1;`(또는 `i--;`)로 쓰고, 끝 조건도 방향에 맞게 바꾼다.

- 큰 값 `b`에서 시작해 작은 값 `a`까지 내려가려면 조건을 `i >= a`로 둔다. `>=`(크거나 같음)을 써야 `a`까지 포함된다.

```cpp
// 5부터 1까지 거꾸로 (while 버전)
int i = 5;
while (i >= 1) {      // i가 1 이상인 동안 반복
    cout << i << "\n";
    i = i - 1;
}
// 출력: 5 4 3 2 1
```

- 방향이 바뀌었으니 조건 부호도 반대다. 증가일 때 `<=`였다면 감소일 때는 `>=`가 자연스럽다. 부호를 헷갈리면 무한 반복이 되기 쉽다.

- 값을 줄이는 줄(`i = i - 1;`)을 빠뜨리면 조건이 계속 참이라 끝나지 않는다.

**문제**

**1) N부터 1까지 (while)** · Easy

- **요구사항**: 정수 `N`을 입력받아 N부터 1까지 한 줄에 하나씩 내림차순으로 `while`을 사용해 출력하시오.
- **입력**: 첫 줄에 정수 `N` (1 ≤ N ≤ 100)
- **출력**: N, N−1, ..., 1을 한 줄에 하나씩
- **예제**: `5` → `5` / `4` / `3` / `2` / `1`, `1` → `1`
- **셀프체크**: 조건 `i >= 1`, 감소 `i = i - 1`. 시작값을 N으로 두었는가.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int N;
    cin >> N;
    int i = N;
    while (i >= 1) {
        cout << i << "\n";
        i = i - 1;
    }
    return 0;
}
@@TESTS
--IN
5
--OUT
5
4
3
2
1
--IN
1
--OUT
1
@@EXPL
(1) 접근: N부터 1까지 거꾸로 세는 것을 while로 한다. for의 `for (int i = N; i >= 1; i--)`를 while로 옮기면 "시작값·끝조건·감소" 세 부분으로 나뉜다.

(2) 코드 진행:

- `int i = N;`으로 시작값을 잡는다.
- `while (i >= 1)` — i가 1 이상인 동안 반복. 1까지 포함해야 하므로 `>=`를 쓴다.
- 반복 안에서 먼저 `cout << i << "\n";`로 현재 값을 출력한다.
- 그다음 `i = i - 1;`로 값을 1 줄인다. 이 줄을 빼면 조건이 계속 참이라 무한 반복.
- i가 0이 되면 `0 >= 1`이 거짓이라 반복이 끝난다.

(3) 스스로 짤 때 생각 순서: "시작은 N" → "언제까지? i가 1 이상인 동안" → "매번 출력하고 나서 1 줄이기". 방향이 거꾸로면 조건 부호가 `>=`, 증감이 `i - 1`로 바뀐다는 점만 기억한다.
```

**2) 역순 곱(팩토리얼)** · Medium

- **요구사항**: 정수 `N`을 입력받아 N부터 1까지 곱한 값(N!)을 `while`로 구해 출력하시오.
- **입력**: 첫 줄에 정수 `N` (1 ≤ N ≤ 12)
- **출력**: N × (N−1) × ... × 1 (한 줄)
- **예제**: `5` → `120` (5×4×3×2×1), `1` → `1`, `3` → `6`
- **셀프체크**: 곱을 담는 변수는 0이 아니라 **1**로 초기화해야 한다(0으로 두면 결과가 항상 0). 조건 `i >= 1`, 감소 `i = i - 1`.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int N;
    cin >> N;
    int result = 1;
    int i = N;
    while (i >= 1) {
        result = result * i;
        i = i - 1;
    }
    cout << result << "\n";
    return 0;
}
@@TESTS
--IN
5
--OUT
120
--IN
1
--OUT
1
--IN
3
--OUT
6
@@EXPL
(1) 접근: N × (N−1) × … × 1을 구하려면 N부터 1까지 내려가며 하나씩 곱해 나가면 된다. 합이 아니라 곱이므로 시작값을 0이 아닌 1로 둔다.

(2) 코드 진행:

- `int result = 1;`로 초기화한다. 곱셈의 시작은 1이어야 어떤 값을 곱해도 그대로 반영된다(0이면 무엇을 곱해도 0).
- `int i = N;`으로 시작해 `while (i >= 1)`로 1까지 반복한다.
- 반복 안에서 `result = result * i;`로 현재 값을 곱한다. 예: N=5면 result가 1→5→20→60→120.
- `i = i - 1;`로 값을 줄인다.
- 반복이 끝나면 `result`를 출력한다. (N ≤ 12이므로 12! = 479001600, int 범위 안에 들어간다.)

(3) 스스로 짤 때 생각 순서: "곱을 모을 그릇을 1로 준비" → "N에서 1까지 훑기(감소 while)" → "매번 그릇에 i를 곱하기" → "i 줄이기" → "그릇 출력". 합 문제와 딱 두 가지만 다르다 — 초기값 1, 연산은 `*`.
```

**3) 두 수 사이 카운트다운 합** · Hard

- **요구사항**: 두 정수 `A`, `B`(A ≤ B)를 입력받아 B부터 A까지 1씩 줄이며 그 값이 짝수일 때만 더한 합을 `while`로 출력하시오.
- **입력**: 첫 줄에 `A B` (1 ≤ A ≤ B ≤ 100)
- **출력**: A 이상 B 이하의 짝수들의 합 (한 줄)
- **예제**: `1 6` → `12` (6+4+2), `3 3` → `0` (3은 홀수), `2 2` → `2`
- **셀프체크**: 시작값 B, 조건 `i >= A`, 감소 `i = i - 1`. 짝수 판별은 조건문과 `%`로 한다. 구간에 짝수가 없으면 0이 나와야 한다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int A, B;
    cin >> A >> B;
    int total = 0;
    int i = B;
    while (i >= A) {
        if (i % 2 == 0) {
            total = total + i;
        }
        i = i - 1;
    }
    cout << total << "\n";
    return 0;
}
@@TESTS
--IN
1 6
--OUT
12
--IN
3 3
--OUT
0
--IN
2 2
--OUT
2
@@EXPL
(1) 접근: B에서 A까지 1씩 내려가며(감소 while), 그 값이 짝수일 때만 합에 더한다. 두 가지가 겹친 문제다 — "역순으로 훑기"와 "짝수만 고르기".

(2) 코드 진행:

- `cin >> A >> B;`로 두 정수를 받는다.
- 합을 담을 `int total = 0;`, 훑을 값 `int i = B;`로 시작한다.
- `while (i >= A)`로 A 이상인 동안 반복한다. A까지 포함해야 하므로 부호는 `>=`.
- 반복 안에서 `if (i % 2 == 0)`이면(짝수이면) `total`에 더한다. 홀수면 건너뛴다.
- 그다음 반드시 `i = i - 1;`로 값을 줄인다. 이 줄이 없으면 무한 반복.
- 반복이 끝나면 `total`을 출력한다. 짝수가 하나도 없으면 `total`은 0 그대로다.

(3) 스스로 짤 때 생각 순서: "어디서 시작? B" → "언제까지? i가 A 이상인 동안" → "매번 뭘 하지? 짝수면 더하기" → "값 줄이기 잊지 말기" → "다 끝나고 합 출력". 초기값 0과 감소 줄만 챙기면 된다.
```
