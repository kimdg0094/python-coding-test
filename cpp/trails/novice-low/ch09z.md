## L16. 정리 — 개념 지도·체크리스트·자주 하는 실수

**개념**

- 이 레슨은 새로 풀 것을 내지 않는다. Ch9에서 배운 도구들이 어떤 뼈대 위에 놓여 있는지 한 장으로 정리하고, 바로 꺼내 쓸 템플릿과 자주 밟는 지뢰를 모아 둔다.

- 이 챕터를 관통하는 사실은 하나다. **C++ `string`은 바꿀 수 있다(가변).** `s[0] = 'x';`가 그대로 동작하고 원본이 실제로 바뀐다. 파이썬 문자열이 불변이라 "고친다·지운다·민다"가 전부 "새 문자열을 만든다"였던 것과 정반대다.

- 그래서 C++에서는 방식을 **고를 수 있다.** 원본이 더 필요 없으면 제자리에서 고치고, 원본을 남겨야 하면 사본을 뜨거나 새 문자열을 만든다. 대신 "원본을 지키는 일"이 자동이 아니라 내 책임이 된다.

**개념 지도**

문자열 문제는 크게 네 갈래로 갈라졌다가, 결과를 만들어 낼 때 다시 "새 문자열 조립" 또는 "제자리 수정"으로 모인다.

```text
            string : a row of letter boxes  ( MUTABLE in C++ )
                                  |
    +---------------+-------------+-------------+---------------+
    |               |                           |               |
 L1/L2 input     L4 scan                 L5/L8/L9 substr   L10-L13 convert
 getline(cin,s)  for (char c : s)        s.substr(p, len)  char <-> int
 s.size()        for (int i = 0; ...)    delete , rotate   stoi , to_string
    |               |                           |               |
    +---------------+-------------+-------------+---------------+
                                  |
            L7 "edit" : two ways , pick one
               A) in place  :  s[i] = c;
               B) build new :  string r = "";  r += s[i];
                                  |
                   L14 compare :  ==   <   >   ( ascii order )
```

왼쪽 두 갈래는 **읽기**(세기·찾기·판별), 오른쪽 두 갈래는 **만들기**(자르기·붙이기·변환)다. 읽기만 하면 원본 하나로 끝나고, 만들기가 섞이면 결과를 담을 변수가 따로 필요하다.

번호를 세는 법이 파이썬과 다른 점이 이 챕터에서 가장 자주 헷갈리는 곳이다.

```text
 s = "apple"
      +---+---+---+---+---+
      | a | p | p | l | e |
      +---+---+---+---+---+
   i    0   1   2   3   4      s[i] : one letter , s[5] is out of range
                               C++ has NO negative index
 python  s[a:b]        ->  cut points , length is b - a
 C++     s.substr(p, n) ->  start p , take n letters
         s.substr(1, 3)  ==  python s[1:4]   ->  "ppl"
         s.substr(p)     ->  from p to the end
         p == s.size()   ->  ""            ( ok )
         p >  s.size()   ->  throws     # 파이썬은 조용히 빈 문자열을 준다
```

아스키 코드는 세 구간이 각각 끊기지 않고 이어져 있다는 성질이 전부다.

```text
 code:   48  49  50  ...  57     65  66  ...  90     97  98  ... 122
 char:  '0' '1' '2'  ... '9'    'A' 'B'  ... 'Z'    'a' 'b'  ... 'z'
         |                       |                   |
         +-- digits (10)         +-- upper (26)      +-- lower (26)

  '7' - '0' = 7        # 구간 안에서 몇 번째인가
  'a' - 'A' = 32       # 대문자와 소문자의 거리
  (char)('a' + 3) = 'd'
  cout << 'a' + 3;  ->  100     # 캐스팅을 빼면 숫자가 나온다
```

**뼈대 코드**

```cpp
// 1) 순회하며 세기 / 판별하기 (읽기 전용)
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    getline(cin, s);
    int cnt = 0;                       // 세는 변수는 반드시 0 으로 시작
    for (char c : s) {                 // 자리 번호가 필요 없으면 이 형태
        if (c == 'a') {                // <- 문제마다 바뀜 (세는 조건)
            cnt++;
        }
    }
    cout << cnt << "\n";
    return 0;
}
```

```cpp
// 2) 인덱스로 순회하며 새 문자열 만들기 (수정·치환)
string s;
getline(cin, s);
string result = "";                    // 빈 문자열에서 시작
for (int i = 0; i < (int)s.size(); i++) {   // 자리 번호가 조건에 들어가면
    if (i % 2 == 0) {                  // <- i == p / s[i] == 'a' 등
        result += '*';                 // <- 문제마다 바뀜 (넣을 글자)
    } else {
        result += s[i];                // += 는 복사 없이 한 글자를 덧붙인다
    }
}
cout << result << "\n";
```

```cpp
// 3) 제자리에서 고치기 (원본이 더 필요 없을 때)
string s;
getline(cin, s);
for (int i = 0; i < (int)s.size(); i++) {
    if ('a' <= s[i] && s[i] <= 'z') {  // 구간 검사부터 (아닌 글자는 그대로)
        s[i] = s[i] - 32;              // 소문자 -> 대문자
    }
}
cout << s << "\n";
```

```cpp
// 4) 위치 찾기 (첫 등장 / 마지막 등장)
string s;
getline(cin, s);
char target = 'n';
int pos = -1;                          // 못 찾았을 때의 답
for (int i = 0; i < (int)s.size(); i++) {
    if (s[i] == target) {
        pos = i;
        break;                         // <- 마지막 등장을 원하면 이 줄만 지운다
    }
}
cout << pos << "\n";
```

```cpp
// 5) substr 로 조립 (삭제 · 밀기) 과 수 변환
string s;
getline(cin, s);
int n = (int)s.size();
int i = 2;
cout << s.substr(0, i) + s.substr(i + 1) << "\n";   // i 번째 글자 삭제

int k = 7;
k = k % n;                             // 큰 k 를 길이 안으로 줄인다 (필수)
cout << s.substr(k) + s.substr(0, k) << "\n";       // 왼쪽 k 칸 밀기
cout << s.substr(n - k) + s.substr(0, n - k) << "\n";  // 오른쪽 k 칸 밀기

cout << to_string(12345).size() << "\n";   // 자릿수 = 문자열 길이
cout << stoi("007") + 1 << "\n";           // 앞의 0 은 수로 바꾸면 사라진다
```

**언제 무엇을 쓰나**

| 상황 | 고르는 것 | 이유 | 복잡도 |
| --- | --- | --- | --- |
| 공백 없는 한 덩어리 입력 | `cin >> s` | 공백에서 끊어도 상관없다 | O(n) |
| 공백이 있는 문장 입력 | `getline(cin, s)` | 줄 끝까지 통째로 받는다 | O(n) |
| 수를 읽은 뒤 문장을 읽는다 | 사이에 `cin.ignore();` | 남은 줄바꿈을 버려야 한다 | O(1) |
| 글자 값만 필요 | `for (char c : s)` | 자리 번호가 필요 없음 | O(n) |
| 자리 번호가 조건에 들어감 | `for (int i = 0; i < (int)s.size(); i++)` | `i == p`, `i % 2` 같은 조건 | O(n) |
| 원본이 더 필요 없다 | 제자리 수정 `s[i] = c;` | 복사가 없어 짧고 빠르다 | O(n) |
| 원본을 남겨야 한다 | `string t = s;` 로 사본 | `=`가 값을 통째로 복사한다 | O(n) |
| 처음 등장 위치 | 순회 + `break` | 찾는 즉시 멈춰야 첫 위치 | O(n) |
| 마지막 등장 위치 | 순회 + 계속 갱신 | 끝까지 가야 마지막이 남음 | O(n) |
| 연속한 한 덩어리 | `s.substr(p, len)` | 반복 없이 통째로 자름 | O(len) |
| 한 글자 삭제 | `s.substr(0,i) + s.substr(i+1)` | 좌우 조각을 다시 붙임 | O(n) |
| 결과를 한 글자씩 쌓는다 | `result += c;` | `result = result + c`는 매번 복사 | O(n) |
| 문자열 회전 | `k % n` 후 `substr` 2조각 | 길이마다 제자리로 돌아옴 | O(n) |
| 글자 ↔ 코드 | `(int)c` / `(char)k` | `char`가 곧 작은 정수 | O(1) |
| 수 ↔ 글자 | `stoi` / `to_string` | 계산은 수, 자르기·세기는 글자 | O(자릿수) |
| 한 자리 숫자 글자의 값 | `c - '0'` | 구간 시작에서 몇 칸인지 | O(1) |
| 두 문자열의 순서 | `<`, `>` (양쪽이 `string`일 때) | 앞 글자부터 코드 비교 | O(n) |

**✅ 마스터 체크리스트**

- [ ] 설명할 수 있다: `cin >> s`와 `getline(cin, s)`가 한 줄을 어디까지 읽는지와, 언제 어느 쪽을 써야 하는지.
- [ ] 설명할 수 있다: `cin >> n;` 뒤에 `getline`을 부르면 왜 빈 줄이 읽히는지와, `cin.ignore();`가 하는 일.
- [ ] 설명할 수 있다: `s.size()`와 마지막 인덱스의 관계, 그리고 `s[s.size()]`가 왜 위험한지.
- [ ] 설명할 수 있다: C++에 음수 인덱스가 없다는 것과, 뒤에서 두 번째 글자를 어떻게 가리키는지.
- [ ] 설명할 수 있다: `s.substr(p, len)`의 둘째 인자가 길이라는 것과, 파이썬 `s[a:b]`를 어떻게 옮기는지.
- [ ] 설명할 수 있다: `substr`의 `p`가 `size()`와 같을 때와 클 때의 차이, 그리고 파이썬과 반응이 어떻게 다른지.
- [ ] 설명할 수 있다: C++ `string`이 가변이라는 말의 뜻과, `s[0] = 'x';`가 왜 동작하는지.
- [ ] 설명할 수 있다: 원본을 남겨야 할 때 `string t = s;`가 왜 안전한 사본이 되는지.
- [ ] 설명할 수 있다: `result = result + c`와 `result += c`의 비용 차이가 어디서 생기는지.
- [ ] 설명할 수 있다: 문자열 리터럴끼리 `+`를 쓸 수 없는 이유와 그 회피 방법.
- [ ] 설명할 수 있다: 첫 등장 찾기와 마지막 등장 찾기의 코드 차이가 `break` 한 줄인 이유.
- [ ] 설명할 수 있다: 문자열 밀기에서 `k % n`이 필요한 이유와, 빠뜨렸을 때 C++에서 무슨 일이 일어나는지.
- [ ] 설명할 수 있다: `(char)`와 `(int)` 캐스팅이 각각 무엇을 하는지, 그리고 `cout << 'A' + 1;`이 왜 숫자를 찍는지.
- [ ] 설명할 수 있다: 대소문자 변환에서 32를 더하고 빼는 근거와, 구간 검사가 반드시 필요한 이유.
- [ ] 설명할 수 있다: `'a' <= c <= 'z'`를 C++에서 쓰면 왜 판별이 무력해지는지.
- [ ] 설명할 수 있다: `stoi("12a")`가 파이썬 `int("12a")`와 어떻게 다르게 동작하는지.
- [ ] 설명할 수 있다: 자릿수를 `to_string(n).size()`로 셀 수 있는 이유와, 음수에서 어긋나는 이유.
- [ ] 설명할 수 있다: 문자열 크기 비교가 사전 순이 되는 두 규칙(처음 다른 자리, 그리고 접두사일 때).

**⚠️ 자주 하는 실수**

**(1) 수를 읽은 뒤 `cin.ignore()`를 빠뜨린다**

```cpp
// ❌ 틀린 코드
int n;
cin >> n;
string s;
getline(cin, s);                       // 남아 있던 줄바꿈을 읽고 끝난다
cout << s << "\n";                     // 빈 줄이 출력된다
```

왜: `cin >> n;`은 숫자만 가져가고 그 뒤의 줄바꿈을 입력에 남긴다. 곧바로 `getline`을 부르면 그 줄바꿈을 만나 "빈 줄"을 읽는다. 파이썬 `input()`에는 없던 단계다.

```cpp
// ✅ 고친 코드
int n;
cin >> n;
cin.ignore();                          // 남은 줄바꿈 한 글자를 버린다
string s;
getline(cin, s);
cout << s << "\n";
```

**(2) `char`와 문자열을 섞어 비교한다**

```cpp
// ❌ 틀린 코드
string s = "apple";
if (s[0] == "a") {                     // char 와 문자열을 비교 -> 컴파일 오류
    cout << "yes\n";
}
```

왜: `s[0]`은 글자 하나(`char`)이고 `"a"`는 문자열이다. 자료형이 달라 비교할 수 없다. 글자 하나는 작은따옴표로 쓴다.

```cpp
// ✅ 고친 코드
string s = "apple";
if (s[0] == 'a') {                     // 작은따옴표 : char 끼리 비교
    cout << "yes\n";
}
```

**(3) 파이썬식 구간 검사를 그대로 옮긴다**

```cpp
// ❌ 틀린 코드
for (int i = 0; i < (int)s.size(); i++) {
    if ('a' <= s[i] <= 'z') {          // 언제나 참이 되어 버린다
        s[i] = s[i] - 32;
    }
}
```

왜: C++은 `'a' <= s[i] <= 'z'`를 `('a' <= s[i]) <= 'z'`로 읽는다. 앞의 결과 1 또는 0을 `'z'`(122)와 비교하니 항상 참이다. 그래서 숫자·공백까지 32를 빼 버린다.

```cpp
// ✅ 고친 코드
for (int i = 0; i < (int)s.size(); i++) {
    if ('a' <= s[i] && s[i] <= 'z') {  // && 로 두 조건을 나눠 쓴다
        s[i] = s[i] - 32;
    }
}
```

**(4) 문자 계산에서 `(char)` 캐스팅을 빠뜨린다**

```cpp
// ❌ 틀린 코드
char c = 'a';
cout << c + 3 << "\n";                 // 100 이 출력된다
```

왜: `c + 3`은 정수 계산이고 `cout`은 그 정수를 그대로 내보낸다. `char`가 곧 작은 정수라는 성질 때문에 생기는, C++에서 가장 흔한 문자 관련 오답이다.

```cpp
// ✅ 고친 코드
char c = 'a';
cout << (char)(c + 3) << "\n";         // d
```

**(5) 밀기에서 `k % n`을 빠뜨린다**

```cpp
// ❌ 틀린 코드
string s = "abcde";                    // 길이 5
int k = 7;
cout << s.substr(k) + s.substr(0, k);  // substr(7) 은 예외를 던진다
```

왜: `substr`의 시작 위치가 길이를 넘으면 예외가 발생해 프로그램이 그대로 멈춘다. 파이썬은 조용히 빈 문자열을 주고 원본을 출력했지만, C++은 요란하게 죽는다.

```cpp
// ✅ 고친 코드
string s = "abcde";
int n = (int)s.size();
int k = 7;
k = k % n;                             // 한 바퀴(=n칸)는 제자리
cout << s.substr(k) + s.substr(0, k);  // "cdeab"
```

**(6) 문자열 리터럴끼리 `+`로 잇는다**

```cpp
// ❌ 틀린 코드
cout << "score: " + 90 << "\n";        // 이어붙이기가 아니다
cout << "ab" + "cd" << "\n";           // 컴파일 오류
```

왜: 큰따옴표로 쓴 값은 아직 `string`이 아니다. `+`가 이어붙이기가 되려면 최소 한쪽이 `string`이어야 하고, 수를 붙이려면 `to_string`으로 바꿔야 한다.

```cpp
// ✅ 고친 코드
cout << string("score: ") + to_string(90) << "\n";   // score: 90
cout << string("ab") + "cd" << "\n";                 // abcd
```

**(7) 결과를 담지 않고 계산만 한다**

```cpp
// ❌ 틀린 코드
string s = "banana";
s.substr(0, 3);                        // 결과를 아무 데도 담지 않았다
cout << s << "\n";                     // banana : 아무것도 바뀌지 않는다
```

왜: `substr`는 원본을 건드리지 않고 **새 문자열을 돌려주는** 도구다. 돌려준 값을 변수에 담거나 바로 출력해야 의미가 있다. 반대로 `s[i] = c;`나 `s.erase(...)`는 원본을 실제로 바꾼다. 두 종류를 구분해 두면 헷갈리지 않는다.

```cpp
// ✅ 고친 코드
string s = "banana";
string t = s.substr(0, 3);             // 다시 담거나
cout << t << "\n";                     // ban
cout << s.substr(0, 3) << "\n";        // 반환값을 바로 쓴다
```

**(8) 대소문자 무시 비교에서 원본을 덮어쓴다**

```cpp
// ❌ 틀린 코드
string a = "cat", b = "Car";
for (int i = 0; i < (int)a.size(); i++) a[i] = tolower(a[i]);
for (int i = 0; i < (int)b.size(); i++) b[i] = tolower(b[i]);  // 원본이 사라졌다
if (a < b) cout << a << "\n";
else cout << b << "\n";                // car 가 출력된다 (기대: Car)
```

왜: C++ `string`은 가변이라 원본 변수를 소문자로 바꾸면 대문자 정보가 실제로 사라진다. 파이썬 `lower()`는 새 문자열을 돌려주어 원본이 저절로 남았지만, 여기서는 직접 지켜야 한다.

```cpp
// ✅ 고친 코드
string a = "cat", b = "Car";
string la = a, lb = b;                 // 비교용 사본을 따로 둔다
for (int i = 0; i < (int)la.size(); i++) la[i] = tolower(la[i]);
for (int i = 0; i < (int)lb.size(); i++) lb[i] = tolower(lb[i]);
if (la < lb) cout << a << "\n";        // 출력은 언제나 원본
else cout << b << "\n";                // Car
```

**(9) `size()`를 정수처럼 빼서 쓴다**

```cpp
// ❌ 틀린 코드
string s = "";                         // 비어 있을 수 있다
for (int i = 0; i <= s.size() - 1; i++) {
    cout << s[i];                      // 반복이 끝나지 않는다
}
```

왜: `size()`는 음수가 없는 정수라 `0 - 1`이 `-1`이 아니라 아주 큰 수가 된다. 조건이 계속 참이라 문자열 밖을 끝없이 읽는다.

```cpp
// ✅ 고친 코드
string s = "";
for (int i = 0; i < (int)s.size(); i++) {   // 빼지 말고 '<' 로 비교한다
    cout << s[i];
}
```

**다음 챕터로**

- "원본을 지킬지 고칠지 스스로 고른다"는 감각은 이후 배열 가공·정렬·집계에서 그대로 쓰인다. C++에서는 값 복사가 기본이라, 사본을 뜨는 비용과 `&`로 원본을 가리키는 선택이 늘 함께 따라온다.

- 한 글자씩 훑으며 세고 판별하는 순회 뼈대는 문자열 압축·암호·빈도 세기 같은 단골 유형의 공통 출발점이다. 거기에 Ch7의 카운트 배열을 얹으면 "글자별 등장 횟수"가 바로 나온다.
