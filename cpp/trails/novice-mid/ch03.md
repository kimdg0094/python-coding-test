> 개요: 데이터를 정해진 기준으로 줄 세우는 "정렬"을 배운다. 단일 값 정렬에서 출발해, 여러 필드를 하나로 묶는 "객체" 표현을 익히고, 마지막에는 정렬 기준(비교 함수)을 자유자재로 지정해 다중 조건 정렬까지 다룬다.

## L1. 일반 정렬

**개념**

- 정렬(sort)은 데이터를 오름차순 또는 내림차순 등 "정해진 순서"로 재배치하는 것이다. 순위 매기기, 중앙값 찾기, 중복 제거, 이분 탐색 준비 등 수많은 문제의 첫 단추가 된다.
- C++에서는 `<algorithm>`의 `std::sort`를 쓴다. `sort(v.begin(), v.end())`는 `vector`를 그 자리에서 오름차순으로 바꾼다(원본을 정렬된 상태로 덮어쓴다). 반환값은 없다.
- 내림차순은 세 번째 인자로 비교 함수 `greater<int>()`를 넘긴다. 기본은 오름차순이다.

```cpp
vector<int> a = {5, 2, 9, 1};
sort(a.begin(), a.end());              // a = {1, 2, 5, 9}
sort(a.begin(), a.end(), greater<int>());  // a = {9, 5, 2, 1}
```

- 원본 순서를 나중에 다시 써야 하면 사본을 만들어 정렬한다: `vector<int> b = a; sort(b.begin(), b.end());`. 그러면 `a`는 그대로 남는다.
- 정렬 후에는 인덱스 접근이 강력해진다. `v[0]`은 최솟값, `v[v.size()-1]`은 최댓값, `v[k-1]`은 k번째로 작은 값이다.
- 중복 제거가 필요하면 정렬한 뒤 `unique`로 이웃한 중복을 뒤로 몰고 `erase`로 잘라낸다: `sort(...); v.erase(unique(v.begin(), v.end()), v.end());`. `unique`는 "정렬된 상태"를 전제로 이웃 중복만 없애므로 반드시 먼저 정렬해야 한다.

**접근 전략**

- "가장 크다/작다", "k번째", "순위", "중앙값", "정렬된 상태에서 이웃끼리 비교"라는 신호가 보이면 먼저 정렬을 떠올린다. 정렬해 두면 원하는 값이 특정 인덱스에 "고정"된다.
- 전형적 절차: (1) 입력을 `vector`로 받는다 → (2) `sort`로 오름/내림 정렬한다 → (3) 필요한 인덱스나 앞쪽 몇 개를 뽑는다.
- 원본을 뭉개면 안 되는 상황이면 `sort` 전에 사본을 떠 둔다. `std::sort`는 제자리(in-place) 정렬이라 원본을 그대로 덮어쓰기 때문이다.
- 복잡도: `std::sort`는 비교 기반으로 원소 N개에 O(N log N). N이 수십만이어도 충분히 빠르다. 정렬 후 인덱스 접근은 O(1).

**문제**

**1) 중복 없는 오름차순** · Easy

- **요구사항**: 정수 N개가 주어질 때, 중복을 제거하고 오름차순으로 출력한다.
- **입력**: 첫 줄에 N. 둘째 줄에 정수 N개(공백 구분).
- **출력**: 중복이 제거된 값들을 오름차순으로 한 줄에 공백으로 구분해 출력.
- **예제**: `6 / 5 3 3 1 5 2` → `1 2 3 5`
- **예제**: `4 / 7 7 7 7` → `7`
- **셀프체크**: 모두 같은 수면 한 개만 남는가. 출력 사이 공백 형식이 맞는가(끝에 불필요한 공백/줄바꿈 주의). `unique`는 정렬된 상태에서만 이웃 중복을 없애므로 반드시 먼저 정렬해야 한다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    sort(a.begin(), a.end());
    a.erase(unique(a.begin(), a.end()), a.end());
    for (int i = 0; i < (int)a.size(); i++) {
        if (i > 0) cout << ' ';
        cout << a[i];
    }
    cout << '\n';
    return 0;
}
@@TESTS
--IN
6
5 3 3 1 5 2
--OUT
1 2 3 5
--IN
4
7 7 7 7
--OUT
7
@@EXPL
(1) 접근·핵심 아이디어

- 중복 제거는 "정렬 후 `unique`+`erase`" 관용구로 한다. `unique`는 정렬된 배열에서 이웃한 같은 값을 하나로 접어 뒤로 몰고, 새 끝 위치를 돌려준다. 그 위치부터 끝까지를 `erase`로 잘라낸다.
- `unique`는 "이웃 중복"만 없애므로, 반드시 먼저 `sort`로 같은 값끼리 붙여 놓아야 한다. 그러면 정렬 + 중복 제거가 한 번에 끝난다.

(2) 코드 단계별

- `cin >> n`으로 개수를 읽고, `vector<int> a(n)`에 정수 N개를 담는다.
- `sort(a.begin(), a.end())`로 오름차순 정렬한다.
- `a.erase(unique(a.begin(), a.end()), a.end())`로 중복을 제거한다.
- 인덱스로 순회하며 첫 원소 앞에는 공백을 두지 않고, 둘째 원소부터 앞에 공백을 찍어 "공백 구분 한 줄"을 만든다. 끝에 불필요한 공백이 붙지 않는다.

(3) 스스로 다시 짤 때 생각 순서

- "중복 없이" → `sort` + `unique`/`erase` 관용구를 떠올린다.
- "오름차순" → `unique`는 정렬을 전제로 한다는 점을 기억하고 반드시 `sort`를 먼저 한다.
- "공백 구분 한 줄" → `if (i > 0) cout << ' '` 로 원소 사이에만 공백을 넣는다.
```

**2) k번째로 작은 수** · Easy

- **요구사항**: 정수 N개와 k가 주어질 때, 정렬했을 때 k번째로 작은 값을 출력한다(중복도 하나의 자리로 센다).
- **입력**: 첫 줄에 N과 k. 둘째 줄에 정수 N개.
- **출력**: k번째로 작은 값 하나.
- **예제**: `6 3 / 7 2 9 4 4 1` → `4`  (정렬: 1 2 4 4 7 9, 3번째는 4)
- **예제**: `5 1 / 10 8 6 4 2` → `2`
- **셀프체크**: k는 1부터 시작하므로 인덱스는 `k-1`이다(off-by-one 함정). 중복이 있어도 자리 수로 세는지 확인. k=N일 때 최댓값이 되는가.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, k;
    cin >> n >> k;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    sort(a.begin(), a.end());
    cout << a[k - 1] << '\n';
    return 0;
}
@@TESTS
--IN
6 3
7 2 9 4 4 1
--OUT
4
--IN
5 1
10 8 6 4 2
--OUT
2
@@EXPL
(1) 접근·핵심 아이디어

- 정렬해 두면 "k번째로 작은 값"이 특정 인덱스에 고정된다. 오름차순 정렬 후 앞에서 k번째를 뽑으면 된다.
- 핵심 함정은 인덱스다. k는 1부터 세지만 `vector` 인덱스는 0부터이므로 `a[k-1]`이다.

(2) 코드 단계별

- `cin >> n >> k`로 개수와 k를 함께 읽는다.
- `vector<int> a(n)`에 정수 N개를 담는다.
- `sort(a.begin(), a.end())`로 오름차순 정렬한다(중복은 각각 하나의 자리로 남는다).
- `a[k-1]`이 k번째로 작은 값이다. 예: 정렬 `1 2 4 4 7 9`에서 3번째는 인덱스 2 → `4`.

(3) 스스로 다시 짤 때 생각 순서

- "k번째로 작은" → 오름차순 정렬을 먼저 떠올린다.
- "1부터 세는 k" → 인덱스는 `k-1`이라는 off-by-one을 항상 확인한다.
- 검산: k=1이면 최솟값(`a[0]`), k=N이면 최댓값(`a[n-1]`)이 나오는지 머릿속으로 대입해 본다.
```

**3) 상위 3개의 합** · Medium

- **요구사항**: 정수 N개 중 가장 큰 3개의 합을 출력한다. (N은 3 이상)
- **입력**: 첫 줄에 N. 둘째 줄에 정수 N개.
- **출력**: 최댓값 3개의 합.
- **예제**: `6 / 10 20 5 8 30 15` → `65`  (내림차순 30 20 15 ... 상위 3개 합 65)
- **예제**: `3 / -1 -2 -3` → `-6`
- **셀프체크**: 내림차순 정렬 후 앞의 세 개의 합을 쓰면 간단하다. 음수만 있어도 "가장 큰 3개"를 고르는 게 맞는지(값이 큰 순서). 같은 값이 여러 개여도 각각을 하나의 자리로 세는지 확인.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    sort(a.begin(), a.end(), greater<int>());
    long long sum = 0;
    for (int i = 0; i < 3; i++) sum += a[i];
    cout << sum << '\n';
    return 0;
}
@@TESTS
--IN
6
10 20 5 8 30 15
--OUT
65
--IN
3
-1 -2 -3
--OUT
-6
@@EXPL
(1) 접근·핵심 아이디어

- "가장 큰 3개"는 내림차순 정렬 후 맨 앞 세 개다. `sort(..., greater<int>())`로 큰 값을 앞으로 보낸 뒤 앞 세 개를 더한다.
- 음수만 있어도 "값이 큰 순서"의 상위 3개를 고르는 규칙은 동일하다. 예: `-1 -2 -3` → 상위 3개는 전부이므로 합 `-6`.

(2) 코드 단계별

- `vector<int> a(n)`에 정수 N개를 담는다.
- `sort(a.begin(), a.end(), greater<int>())`로 내림차순 정렬한다. 이제 큰 값이 앞쪽에 온다.
- `sum`을 `long long`으로 두고(합이 int 범위를 넘을 수 있으므로 안전) 앞 세 개 `a[0]`, `a[1]`, `a[2]`를 더한다.
- 같은 값이 여러 개여도 각각 하나의 자리로 세므로 그대로 더하면 된다.

(3) 스스로 다시 짤 때 생각 순서

- "가장 큰 K개" → 내림차순 정렬 + 앞에서 K개 더하기를 떠올린다.
- N이 항상 3 이상이므로 `a[0..2]` 접근은 안전하다(범위 밖 접근 걱정 없음).
- 음수 케이스로 "큰 순서"의 의미를 검산한다. 합은 `long long`으로 받아 오버플로를 예방한다.
```


## L2. 객체

**개념**

- 실전 데이터는 값 하나가 아니라 "여러 필드가 묶인 한 덩어리"인 경우가 많다. 예: 학생 = (이름, 점수), 상품 = (이름, 가격, 재고). 이렇게 관련된 값들을 하나로 묶은 것을 여기서는 "객체"라 부른다.
- C++에서 필드 2개짜리 가장 가벼운 묶음은 `pair`다. `first`, `second`로 필드에 접근한다.

```cpp
pair<string, int> student = {"kim", 90};  // (이름, 점수)
string name = student.first;   // "kim"
int score = student.second;    // 90

vector<pair<string,int>> students = {{"kim",90},{"lee",85},{"park",90}};  // 객체들의 vector
for (auto& s : students) cout << s.first << ' ' << s.second << '\n';
```

- 필드가 3개 이상이거나 이름으로 부르고 싶으면 `struct`를 정의해 가독성을 높인다.

```cpp
struct Student { string name; int score; };
Student s = {"kim", 90};
cout << s.name << ' ' << s.score << '\n';
```

- "무엇이 몇 번 나왔는가" 같은 집계에는 `map<키, int>`를 쓴다. `m[key]++`는 키가 없으면 값이 0으로 자동 생성된 뒤 1 증가하므로 빈도 세기에 편하다. 게다가 `std::map`은 키를 오름차순으로 정렬해 보관한다.

```cpp
map<string,int> count;
for (auto& w : words) count[w]++;   // 없던 키는 0에서 시작해 +1
```

**접근 전략**

- "여러 정보가 한 사람/한 항목에 붙어 다닌다"면 값을 따로따로 여러 `vector`에 나눠 담지 말고 한 `pair`/`struct`로 묶어 한 `vector`에 담는다. 그래야 나중에 통째로 정렬·이동해도 필드가 어긋나지 않는다.
- 필드가 2개고 위치가 명확하면 `pair`, 필드가 많거나 이름으로 다뤄야 읽기 좋으면 `struct`를 고른다.
- "가장 ~한 항목"을 찾을 때는 (1) 기준 필드의 최댓/최솟값을 먼저 구하고 (2) 그 값을 가진 항목(들)을 걸러낸다. 동점 처리 규칙(예: 이름이 앞선 것)을 문제에서 반드시 확인한다.
- 빈도/집계는 `map` 한 번 순회로 O(N log N). 그 뒤 최댓값 찾기도 항목 수에 비례한다. `map`이 키를 정렬해 두는 성질은 동점 시 "사전순 먼저"를 공짜로 얻는 데 쓸 수 있다.

**문제**

**1) 최고 점수 학생** · Easy

- **요구사항**: 학생들의 (이름, 점수)가 주어질 때, 최고 점수를 받은 학생의 이름을 출력한다. 동점이면 이름이 사전순으로 가장 앞선 학생을 출력한다.
- **입력**: 첫 줄에 N. 다음 N줄에 각 줄마다 이름과 점수.
- **출력**: 조건을 만족하는 학생 이름 하나.
- **예제**: `3 / kim 90 / lee 85 / park 90` → `kim`  (최고 90점은 kim, park 동점 → 사전순 kim)
- **예제**: `2 / bob 70 / amy 70` → `amy`
- **셀프체크**: (이름, 점수)를 `pair`로 묶어 `vector`에 담았는가. 최고 점수를 먼저 구한 뒤 그 점수인 학생들 중에서 이름을 비교하는가. 점수를 `int`로 읽어 숫자로 비교하는가(문자열 비교 함정).

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<pair<string, int>> students(n);
    for (int i = 0; i < n; i++) {
        string name;
        int score;
        cin >> name >> score;
        students[i] = {name, score};
    }
    int best = students[0].second;
    for (auto& s : students) best = max(best, s.second);
    string ans = "";
    for (auto& s : students) {
        if (s.second == best) {
            if (ans == "" || s.first < ans) ans = s.first;
        }
    }
    cout << ans << '\n';
    return 0;
}
@@TESTS
--IN
3
kim 90
lee 85
park 90
--OUT
kim
--IN
2
bob 70
amy 70
--OUT
amy
@@EXPL
(1) 접근·핵심 아이디어

- 각 학생을 `pair<string,int>`(이름, 점수)로 묶어 한 `vector`에 담는다. 그래야 필드가 어긋나지 않는다.
- "최고 점수 + 동점이면 이름 사전순"은 두 단계로 나눈다. (1) 먼저 최고 점수를 구하고 (2) 그 점수를 가진 학생 이름들 중 사전순으로 가장 작은 것을 고른다.

(2) 코드 단계별

- N줄을 읽으며 `cin >> name >> score`로 이름과 점수를 각각 받는다. 점수는 `int`로 읽어 숫자 비교가 되게 한다(문자열 비교 함정 방지).
- 첫 번째 순회로 `best`(최고 점수)를 `max`로 구한다.
- 두 번째 순회에서 `s.second == best`인 학생만 보고, 아직 답이 없거나(`ans == ""`) 지금 이름이 더 작으면(`s.first < ans`) 답을 갱신한다. 최종적으로 사전순 가장 앞선 이름이 남는다.

(3) 스스로 다시 짤 때 생각 순서

- "가장 ~한 항목" → 기준 값(최고 점수)을 먼저 구한다.
- "동점 처리" → 그 값을 가진 후보만 걸러 두 번째 기준(이름)으로 최솟값을 찾는다.
- 점수는 반드시 `int`로 읽어 비교(문자열 "9" > "85" 같은 오류 방지).
```

**2) 가장 많이 나온 단어** · Medium

- **요구사항**: 단어 N개가 주어질 때, 가장 많이 등장한 단어를 출력한다. 최다 빈도가 여럿이면 사전순으로 가장 앞선 단어를 출력한다.
- **입력**: 첫 줄에 N. 다음 N개의 단어(줄 단위 또는 공백 구분).
- **출력**: 단어 하나.
- **예제**: `6 / apple banana apple cherry banana apple` → `apple`  (apple 3, banana 2, cherry 1)
- **예제**: `4 / dog cat cat dog` → `cat`  (dog 2, cat 2 동점 → 사전순 cat)
- **셀프체크**: `map`으로 빈도를 세었는가. 동점일 때 "빈도가 큰 것 우선, 같으면 이름 작은 것"이라는 두 기준을 함께 처리하는가. 빈도가 아니라 등장 순서로 착각하지 않았는가.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<string> words(n);
    for (int i = 0; i < n; i++) cin >> words[i];
    map<string, int> count;
    for (auto& w : words) count[w]++;
    string bestWord = "";
    int bestFreq = -1;
    for (auto& kv : count) {
        if (kv.second > bestFreq) {
            bestFreq = kv.second;
            bestWord = kv.first;
        }
    }
    cout << bestWord << '\n';
    return 0;
}
@@TESTS
--IN
6
apple banana apple cherry banana apple
--OUT
apple
--IN
4
dog cat cat dog
--OUT
cat
@@EXPL
(1) 접근·핵심 아이디어

- 빈도 세기는 `map<string,int>` 한 번 순회로 끝난다. `count[w]++` — 없던 키는 0에서 시작해 +1.
- 우승자는 두 기준을 함께 본다: 빈도가 큰 것 우선, 같으면 이름이 사전순으로 작은 것. 여기서 `std::map`이 키를 오름차순(사전순)으로 순회한다는 성질을 이용한다. 사전순으로 훑으면서 `kv.second > bestFreq`(엄격한 초과)일 때만 갱신하면, 빈도가 같은 경우에는 먼저 만난(=사전순 앞선) 단어가 유지된다.

(2) 코드 단계별

- 단어 N개를 `vector`로 읽고, `count[w]++`로 빈도 `map`을 채운다.
- `bestFreq`를 -1로 초기화한 뒤 `map`을 사전순으로 순회한다.
- `kv.second > bestFreq`(엄격한 초과)일 때만 최댓값을 갱신하므로, 빈도가 같은 뒤 단어는 갱신되지 않아 사전순 먼저 단어가 살아남는다.
- 최종 `bestWord`가 답이다.

(3) 스스로 다시 짤 때 생각 순서

- "가장 많이" → 빈도 `map`부터 만든다.
- "동점 처리" → `map`의 정렬 순회 + "엄격한 초과 비교"로 사전순 우선을 얻는다. `>=`로 하면 동점일 때 뒤 단어로 덮여버리니 주의.
- 작은 케이스(dog·cat 동점)로 사전순 먼저가 나오는지 반드시 검산한다.
```

**3) 재고 부족 상품 집계** · Medium

- **요구사항**: 상품들의 (이름, 가격, 재고)가 주어진다. 재고가 임계값 T 미만인 상품의 "개수"와 그런 상품들의 "가격 합"을 출력한다.
- **입력**: 첫 줄에 N과 T. 다음 N줄에 이름 가격 재고.
- **출력**: 부족 상품 개수와 가격 합(공백 구분).
- **예제**: `3 5 / pen 100 2 / book 300 10 / ink 50 4` → `2 150`  (재고 2, 4가 5 미만 → pen, ink / 개수 2, 가격 100+50=150)
- **예제**: `2 1 / a 10 0 / b 20 5` → `1 10`
- **셀프체크**: 각 상품의 (이름, 가격, 재고) 세 필드를 제대로 나눠 읽었는가. "T 미만"이 `< T`인지 `<= T`인지 정확히 구분했는가(경계 함정). 조건을 만족하는 항목만 골라 개수와 합을 동시에 누적했는가.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, t;
    cin >> n >> t;
    int cnt = 0;
    long long total = 0;
    for (int i = 0; i < n; i++) {
        string name;
        int price, stock;
        cin >> name >> price >> stock;
        if (stock < t) {
            cnt++;
            total += price;
        }
    }
    cout << cnt << ' ' << total << '\n';
    return 0;
}
@@TESTS
--IN
3 5
pen 100 2
book 300 10
ink 50 4
--OUT
2 150
--IN
2 1
a 10 0
b 20 5
--OUT
1 10
@@EXPL
(1) 접근·핵심 아이디어

- 상품마다 세 필드 `이름 가격 재고`를 읽어 조건 `재고 < T`를 확인한다.
- "T 미만"은 `< T`이지 `<= T`가 아니다. 경계 함정이 핵심. 예: T=5면 재고 5는 포함되지 않고, 재고 2·4만 부족으로 센다.
- 조건을 만족하는 항목에 대해 개수와 가격 합을 동시에 누적한다.

(2) 코드 단계별

- `cin >> n >> t`로 상품 수와 임계값을 읽는다.
- 누적 변수 `cnt`(개수)를 0, `total`(가격 합)을 `long long` 0으로 초기화한다(합이 커질 수 있어 안전).
- 각 줄에서 `cin >> name >> price >> stock`으로 세 필드를 나눠 읽는다.
- `if (stock < t)`일 때만 `cnt++`, `total += price`로 함께 누적한다.
- 마지막에 `cout << cnt << ' ' << total`로 공백 구분 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "조건을 만족하는 것만 집계" → 누적 변수 초기화 후 루프 안에서 `if`로 걸러 누적.
- 부등호 방향("미만" = `<`)을 문제 문장에서 그대로 옮긴다. `<=`와 혼동하지 않기.
- 개수와 합을 각각 다른 루프로 두 번 돌 필요 없이 한 번에 처리한다.
```


## L3. 객체 정렬

**개념**

- 객체(`pair`·`struct`)를 정렬할 때, "무엇을 기준으로 줄 세울지"를 정해 주어야 한다. C++에서는 `std::sort`의 세 번째 인자로 "비교 함수"를 넘긴다. 비교 함수는 두 원소 `a`, `b`를 받아 "`a`가 `b`보다 앞에 와야 하면 `true`"를 돌려준다. 보통 람다(`[](...) { ... }`)로 짧게 쓴다.

```cpp
vector<pair<string,int>> data = {{"kim",90},{"lee",85},{"park",88}};
// 점수 오름차순 -> lee, park, kim
sort(data.begin(), data.end(), [](const pair<string,int>& a, const pair<string,int>& b) {
    return a.second < b.second;   // a.second가 작으면 a가 앞
});
```

- 람다 `[](const auto& a, const auto& b){ return a.second < b.second; }`는 "이름 없는 1회용 비교 함수"다. `<`(작으면 앞)이면 오름차순, `>`(크면 앞)이면 내림차순이 된다.
- 여러 기준을 동시에 쓰려면 "1순위가 같을 때만 2순위를 비교"하도록 단계적으로 반환한다. 1순위로 우열이 갈리면 거기서 결정하고, 같을 때만 2순위를 본다.

```cpp
// 점수 내림차순, 점수가 같으면 이름 오름차순
sort(data.begin(), data.end(), [](const pair<string,int>& a, const pair<string,int>& b) {
    if (a.second != b.second) return a.second > b.second;  // 1순위: 점수 내림
    return a.first < b.first;                              // 2순위: 이름 오름
});
```

- 각 순위의 방향은 부등호로 정한다. 오름차순이면 `<`, 내림차순이면 `>`. 필드마다 방향이 달라도 순위별로 부등호를 따로 쓰면 되므로 자유롭게 조합할 수 있다.

**접근 전략**

- 문제의 정렬 규칙을 "1순위는 무엇, 같으면 2순위는 무엇, 또 같으면 3순위는 무엇" 형태로 말로 먼저 정리한다. 그 순서대로 비교 함수 안에서 `if (1순위가 다르면) return 1순위 비교;` … 마지막에 `return 최하위 비교;`로 옮기면 그대로 코드가 된다.
- 각 순위마다 오름차순이면 `<`, 내림차순이면 `>`를 쓴다. 필드가 문자열이든 정수든 방향만 맞추면 된다.
- 언제 쓰나: 랭킹표 만들기, 동점자 처리, 구간을 시작점 기준으로 줄 세우기, "길이 먼저 그다음 사전순" 같은 복합 정렬. 실전 정렬 문제의 대부분이 이 다중 키 패턴이다.
- 주의점: 비교 함수의 "필드·부등호 방향"이 규칙과 정확히 일치하는지 예제로 검산한다. 복잡도는 여전히 O(N log N)이며, 비교는 필요할 때마다 두 원소를 놓고 이뤄진다.

**문제**

**1) 성적 순위표** · Medium

**2) 키·몸무게 줄 세우기** · Medium

**3) 단어 정렬: 길이 먼저, 같으면 사전순** · Medium

- **요구사항**: 단어 N개를 길이 오름차순으로, 길이가 같으면 사전순으로 정렬해 출력한다.
- **입력**: 첫 줄에 N. 다음 N개의 단어.
- **출력**: 정렬된 순서대로 각 단어를 공백으로 구분해 한 줄에 출력.
- **예제**: `5 / banana apple kiwi fig pear` → `fig kiwi pear apple banana`  (길이 3,4,4,5,6 / 길이 4인 kiwi·pear는 사전순)
- **예제**: `3 / bb aa cc` → `aa bb cc`  (모두 길이 2 → 사전순)
- **셀프체크**: 비교 함수가 "길이(오름) → 사전순(오름)" 순서를 지켰는가. 길이가 같은 단어들끼리만 사전순이 되는지 예제로 확인. 중복 단어가 있으면 각각을 그대로 출력하는가(중복 제거 요구가 없음에 주의).

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<string> words(n);
    for (int i = 0; i < n; i++) cin >> words[i];
    sort(words.begin(), words.end(), [](const string& a, const string& b) {
        if (a.size() != b.size()) return a.size() < b.size(); // 길이 오름
        return a < b;                                         // 사전순 오름
    });
    for (int i = 0; i < (int)words.size(); i++) {
        if (i > 0) cout << ' ';
        cout << words[i];
    }
    cout << '\n';
    return 0;
}
@@TESTS
--IN

banana apple kiwi fig pear
--OUT
fig kiwi pear apple banana
--IN
3

--OUT
aa bb cc
@@EXPL
(1) 접근·핵심 아이디어

- 정렬 규칙: 1순위 길이 오름차순, 같으면 2순위 사전순(오름차순). 둘 다 오름차순이라 모두 `<`를 쓴다.
- 비교 함수에서 길이가 다르면 `a.size() < b.size()`로 결판내고, 길이가 같을 때만 `a < b`(문자열 사전순 비교)로 넘어간다 — 정확히 원하는 순서다.

(2) 코드 단계별

- 단어 N개를 `vector<string>`으로 읽는다.
- 비교 람다에서 `a.size() != b.size()`면 길이 비교(`a.size() < b.size()` → 짧은 게 앞).
```
