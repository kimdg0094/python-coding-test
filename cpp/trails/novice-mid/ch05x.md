## L4. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch05(시뮬레이션 II)의 핵심을 **반복 훈련**하고, 코딩테스트 단골 유형으로 **확장**하는 연습 세트다. 최장 연속 구간, 값을 인덱스로 쓰는 배열 기록, dx dy 격자 이동을 소재와 조건을 바꿔 여러 번 다시 짜 본다.
- **반복 훈련 개념**:
  - 최장 연속 구간: `if (조건) cur++; else cur = 1;` 뒤에 `best = max(best, cur)`
  - 가변 창(window): `while (s > k) { s -= a[left]; left++; }`
  - 배열 기록: `vector<int> last(1001, -1)`, `vector<vector<int>> first(n + 1, vector<int>(m + 1, -1))`처럼 값·좌표를 인덱스로 삼아 정보 저장
  - dx dy 이동: `int dx[4] = {-1, 1, 0, 0};` `int dy[4] = {0, 0, -1, 1};` 로 두고 `nr = r + dx[k], nc = c + dy[k]` 후 `1 <= nr && nr <= n && 1 <= nc && nc <= m` 경계 검사
  - 시계 방향 회전: 방향 배열을 북·동·남·서 순서로 두고 `d = (d + 1) % 4`(우회전), `d = (d + 3) % 4`(좌회전). C++의 `%`는 음수를 음수로 돌려주므로 `(d - 1) % 4`는 -1이 될 수 있다 — 반드시 `+3`으로 감싼다.
- **코딩테스트 출제 맵**: 삼성 SW 역량테스트의 '시뮬레이션' 유형(명령어 처리·회전·격자 이동의 축소판), 『이것이 취업을 위한 코딩테스트다』의 '구현' 파트(상하좌우 이동·방향 전환), NeetCode 150의 'Sliding Window'(가변 창 최장 구간).
- **문제 구성표**:

| # | 문제 | 난이도 | 반복 개념 | 유형 |
|---|------|--------|-----------|------|
| 1 | 가장 긴 같은 문자 구간 | Easy | cur/best 연속 길이 | 반복 훈련 |
| 2 | 마지막으로 본 위치 | Easy | 값 → 마지막 인덱스 기록 | 반복 훈련 |

**문제**

**1) 가장 긴 같은 문자 구간** · Easy

- **요구사항**: 소문자 문자열에서 같은 문자가 연속으로 가장 길게 이어지는 구간을 찾아, 그 문자와 길이를 출력하라. 최대 길이가 같은 구간이 여럿이면 가장 앞에 나오는 구간을 고른다.
- **입력**: 한 줄에 문자열 s (1 ≤ 길이 ≤ 1000, 소문자만).
- **출력**: `문자 길이`를 공백으로 구분해 한 줄.
- **예제**: `aabbbcc` → `b 3` · `abc` → `a 1`
- **셀프체크**: `s[i] == s[i-1]`이면 `cur++`, 아니면 `cur = 1`로 다시 시작했는가. `cur > best`일 때만 갱신해야 동점에서 앞 구간이 유지된다(`>=`면 뒤 구간으로 바뀜). 길이 1 문자열이나 모두 다른 문자열은 첫 글자와 1이 나와야 한다. 반복 조건은 `i < (int)s.size()`처럼 캐스팅해 두는 습관을 들인다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;

    int best = 1;
    char bestCh = s[0];
    int cur = 1;
    for (int i = 1; i < (int)s.size(); i++) {
        if (s[i] == s[i - 1]) {
            cur++;
        } else {
            cur = 1;
        }
        if (cur > best) {
            best = cur;
            bestCh = s[i];
        }
    }
    cout << bestCh << ' ' << best << '\n';
    return 0;
}
@@TESTS
--IN
aabbbcc
--OUT
b 3
--IN
abc
--OUT
a 1
--IN
zzzz
--OUT
z 4
--IN
aabb
--OUT
a 2
@@EXPL
(1) 접근·핵심 아이디어

- L1의 "이웃한 두 원소만 비교"하는 최장 연속 패턴을 문자에 적용한다. 조건은 `s[i] == s[i-1]`(같은 문자가 이어짐)이고, 끊기면 자기 자신부터 길이 1로 다시 센다.
- 문자도 함께 답해야 하므로 `best`를 갱신하는 순간의 문자 `s[i]`를 `bestCh`에 같이 저장한다. C++의 `char`는 정수형이지만 `cout`에 넣으면 문자로 출력된다.

(2) 코드 단계별

- `best = 1, bestCh = s[0], cur = 1`로 시작(문자열이 최소 한 글자이므로 `s[0]`은 안전하다).
- `i`를 1부터 돌며 같으면 `cur++`, 다르면 `cur = 1`.
- `cur > best`일 때만 `best`와 `bestCh`를 갱신하고 마지막에 `bestCh << ' ' << best`로 출력.

(3) 스스로 다시 짤 때 생각 순서

- "연속 조건이 무엇인가?" → 이웃이 같은 문자. "끊기면 몇에서 시작?" → 1.
- 함정: 동점 처리. `aabb`에서 `a 2`가 나와야 하므로 엄격 부등호 `>`로만 갱신한다.
- C++ 함정: `s.size()`는 부호 없는 `size_t`다. `i < s.size()`는 컴파일 경고를 부르고, `s.size() - 1`은 빈 문자열에서 0이 아니라 거대한 수로 뒤집힌다. `(int)s.size()`로 받아 두면 이런 사고가 없다.
- `bestCh`를 `int`로 선언하면 문자가 아니라 아스키 숫자(예: 98)가 찍히므로 반드시 `char`로 둔다.
```

**2) 마지막으로 본 위치** · Easy

- **요구사항**: 정수 N개가 순서대로 주어진다(위치는 1번부터). 이어서 Q개의 질의가 오는데, 각 질의 값이 마지막으로 등장한 위치를 출력하라. 한 번도 등장하지 않았으면 -1.
- **입력**: 첫 줄 N (1 ≤ N ≤ 100000), 둘째 줄 N개의 정수(0 ≤ 값 ≤ 1000), 셋째 줄 Q (1 ≤ Q ≤ 1000), 넷째 줄 Q개의 질의 값(0 ≤ 값 ≤ 1000).
- **출력**: 질의마다 마지막 등장 위치(1-based) 또는 -1을 한 줄에 하나씩.
- **예제**: `5 / 3 7 3 9 7 / 3 / 3 7 1` → `3 / 5 / -1` · `1 / 5 / 1 / 5` → `1`
- **셀프체크**: `vector<int> last(1001, -1)`로 -1 초기화하고, 값을 읽을 때마다 `last[v] = i`로 덮어쓰면 자동으로 "마지막" 위치가 남는다. 위치를 1번부터 세는지(0-based 아님) 확인. 값 0과 1000이 인덱스 범위 안에 들어오려면 크기는 1000이 아니라 1001이어야 한다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    vector<int> last(1001, -1);
    for (int i = 1; i <= n; i++) {
        int v;
        cin >> v;
        last[v] = i;
    }

    int q;
    cin >> q;
    for (int t = 0; t < q; t++) {
        int v;
        cin >> v;
        cout << last[v] << '\n';
    }
    return 0;
}

(1) 접근·핵심 아이디어

- L2의 배열 기록에서 "마지막 위치" 변형이다. 값의 범위가 0~1000으로 작으므로 크기 1001의 `vector<int>`를 만들고, 값을 읽을 때마다 `last[v] = 현재 위치`로 덮어쓴다. 나중에 읽은 값이 앞의 것을 덮으므로 배열에는 항상 마지막 위치만 남는다.
- 질의는 배열을 한 번 인덱싱하면 O(1)이라, N이 커도 질의 처리는 빠르다.

(2) 코드 단계별

- `vector<int> last(1001, -1)`: 두 번째 인자가 초기값이다. -1은 "한 번도 안 나옴".
- 위치 `i`를 1부터 N까지 돌며 `last[v] = i`.
- 질의마다 `last[v]`를 `'\n'`과 함께 출력.

(3) 스스로 다시 짤 때 생각 순서

- "무엇을 인덱스로?" → 값. "무엇을 기록?" → 위치. "겹치면?" → 덮어쓰기 = 마지막.
- 함정: 초기값을 0으로 두면 "위치 0"과 "없음"이 구분되지 않는다 → -1 사용.
- C++ 함정: `int last[1001];`처럼 선언만 하면 지역 배열은 **초기화되지 않은 쓰레기 값**이 들어 있다. `vector<int> last(1001, -1)`이나 `fill(last, last + 1001, -1)`로 반드시 채운다.
- 값 1000이 들어오므로 배열 크기는 1001. 1000으로 잡으면 `last[1000]`이 범위를 벗어나는데, C++은 경고 없이 조용히 남의 메모리를 건드린다.
- N이 10만이라 `endl`을 쓰면 매번 버퍼를 비워 느려진다. `'\n'`과 `sync_with_stdio(false)`를 쓴다.
```

**3) 격자 산책 명령** · Easy

- **요구사항**: N×M 격자(행 1..N, 열 1..M)에서 로봇이 시작 칸 `(r, c)`에 있다. 명령 문자열의 각 글자 U(위), D(아래), L(왼쪽), R(오른쪽)에 따라 한 칸씩 이동하되, 격자 밖으로 나가는 명령은 무시한다. 모든 명령 후의 위치와 무시된 명령의 개수를 출력하라.
- **입력**: 첫 줄 `N M` (1 ≤ N, M ≤ 100), 둘째 줄 시작 위치 `r c`, 셋째 줄 명령 문자열(길이 1~1000, U/D/L/R만).
- **출력**: `r c 무시횟수`를 공백으로 구분해 한 줄.
- **예제**: `3 4 / 1 1 / RRDDLU` → `2 2 0` · `2 2 / 1 1 / UULL` → `1 1 4`
- **셀프체크**: 명령 문자를 `string("UDLR").find(ch)`로 방향 인덱스로 바꾸고 `int dx[4] = {-1, 1, 0, 0}`, `int dy[4] = {0, 0, -1, 1}`을 같은 순서로 두었는가. 경계 검사는 1-based이므로 `1 <= nr && nr <= n`. 1×1 격자는 모든 명령이 무시되어야 한다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, r, c;
    cin >> n >> m >> r >> c;
    string cmds;
    cin >> cmds;

    string dirs = "UDLR";
    int dx[4] = {-1, 1, 0, 0};
    int dy[4] = {0, 0, -1, 1};

    int ignored = 0;
    for (char ch : cmds) {
        int k = (int)dirs.find(ch);
        int nr = r + dx[k];
        int nc = c + dy[k];
        if (1 <= nr && nr <= n && 1 <= nc && nc <= m) {
            r = nr;
            c = nc;
        } else {
            ignored++;
        }
    }
    cout << r << ' ' << c << ' ' << ignored << '\n';
    return 0;
}
@@TESTS

--IN

--IN

--IN

@@EXPL
(1) 접근·핵심 아이디어

- L3의 dx dy 기법을 "명령어 → 방향 인덱스" 변환과 결합한다. 문자 U/D/L/R을 `dirs.find(ch)`로 0~3의 인덱스로 바꾸면, 이동은 `(r + dx[k], c + dy[k])` 두 줄이다.
- 이동 후보가 격자 밖이면 위치를 바꾸지 않고 무시 횟수만 센다.

(2) 코드 단계별

- `string dirs = "UDLR"`, `dx = {-1, 1, 0, 0}`, `dy = {0, 0, -1, 1}`을 같은 순서로 정의.
- 범위 기반 for `for (char ch : cmds)`로 명령을 하나씩 꺼내 `k = dirs.find(ch)`로 방향을 얻고 `(nr, nc)` 계산.
- `1 <= nr && nr <= n && 1 <= nc && nc <= m`이면 이동, 아니면 `ignored++`.
- 최종 `r c ignored` 출력.

(3) 스스로 다시 짤 때 생각 순서

- "방향을 데이터로": 문자 → 인덱스 → dx/dy. if 4개를 쓰지 않는다.
- 함정: dx/dy 순서가 `dirs`와 어긋나면 위아래가 뒤바뀐다. 1-based 경계는 `1 <= x && x <= n`이다.
- C++ 함정: `string::find`는 못 찾으면 `string::npos`(부호 없는 최댓값)를 돌려준다. 그대로 `dx[k]`에 넣으면 엄청난 인덱스가 되어 프로그램이 터진다. 입력이 U/D/L/R만이라 여기선 안전하지만, 보장이 없으면 `if (k == (int)string::npos) continue;` 같은 방어를 넣는다.
- C++엔 파이썬의 연쇄 비교 `1 <= nr <= n`이 없다. 그렇게 쓰면 `(1 <= nr) <= n` 즉 `0 또는 1 <= n`으로 해석되어 **항상 참**이 된다. 반드시 `&&`로 두 번 쓴다.
```

**4) 합이 K 이하인 최장 구간** · Medium

- **요구사항**: 양의 정수 배열에서 원소 합이 K 이하인 연속 구간 중 가장 긴 것의 길이를 구하라. 그런 구간이 없으면(모든 원소가 K보다 크면) 0.
- **입력**: 첫 줄 `N K` (1 ≤ N ≤ 100000, 1 ≤ K ≤ 10^9), 둘째 줄 N개의 양의 정수(각 1 이상 10^6 이하).
- **출력**: 최장 구간의 길이 한 줄.
- **예제**: `6 8 / 3 1 4 1 5 9` → `3` · `4 2 / 5 6 7 8` → `0`
- **셀프체크**: 오른쪽 끝을 한 칸씩 늘리며 합을 더하고, 합이 K를 넘는 동안 왼쪽 끝을 밀어 빼는 가변 창을 썼는가(원소가 모두 양수라 창이 줄면 합이 반드시 줄어든다). 원소 하나가 K보다 크면 `left`가 `right`를 지나 창 길이가 0이 되는 것이 정상. 누적 합은 최대 10^5 × 10^6 = 10^11이라 `int`로는 넘친다 — `long long`을 썼는가.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    long long k;
    cin >> n >> k;

    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    int left = 0;
    long long s = 0;
    int best = 0;
    for (int right = 0; right < n; right++) {
        s += a[right];
        while (s > k) {
            s -= a[left];
            left++;
        }
        int length = right - left + 1;
        if (length > best) best = length;
    }
    cout << best << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- L1-3 "한 번 뒤집기"와 같은 가변 길이 슬라이딩 창이다. 조건이 "0의 개수 ≤ 1"에서 "합 ≤ K"로 바뀌었을 뿐이다. 오른쪽 끝 `right`를 늘려 합을 더하고, 합이 K를 넘는 동안 왼쪽 끝 `left`를 밀어 합을 뺀다.
- 모든 원소가 양수이므로 창을 줄이면 합이 반드시 줄어 while 루프가 끝난다(음수가 섞이면 이 방법은 성립하지 않는다).

(2) 코드 단계별

- `left = 0`, `long long s = 0`, `best = 0`.
- `right`마다 `s += a[right]`, `while (s > k) { s -= a[left]; left++; }`.
- 현재 창 길이 `right - left + 1`로 `best` 갱신.

(3) 스스로 다시 짤 때 생각 순서

- "조건 위반이면 왼쪽을 민다"의 조건만 바꾼다. 매 위치에서 창은 항상 유효한 상태로 유지된다.
- 함정: 원소 하나가 K보다 크면 `left`가 `right + 1`까지 가서 길이 0 — 이것이 "구간 없음"을 자연스럽게 처리한다.
- C++ 함정 ①: `int s`로 두면 최악 10^11에서 오버플로가 나 합이 음수로 돌아가고, `while (s > k)`가 돌지 않아 답이 조용히 커진다. 컴파일 오류도 경고도 없으니 **범위 계산을 먼저** 하는 습관이 답이다.
- C++ 함정 ②: `k`를 `int`로 읽어도 10^9까지는 들어가지만, `s > k` 비교에서 `int`가 `long long`으로 승격되므로 결과는 같다. 그래도 헷갈리지 않게 K도 `long long`으로 통일한다.
- 넷째 테스트처럼 전부 1이고 K=5면 길이 5.
```

**5) 지그재그 최장 구간** · Medium

- **요구사항**: 정수 배열에서 이웃한 원소의 차이 부호가 계속 번갈아 바뀌는(오르고 내리고 오르고 ..., 또는 내리고 오르고 ...) 연속 구간 중 가장 긴 것의 길이를 구하라. 이웃이 같은 값이면 그 자리에서 끊긴다. 길이 1 구간은 항상 지그재그로 본다.
- **입력**: 첫 줄 N (1 ≤ N ≤ 100000), 둘째 줄 N개의 정수.
- **출력**: 최장 지그재그 구간의 길이 한 줄.
- **예제**: `7 / 1 5 2 8 3 3 4` → `5` · `4 / 1 2 3 4` → `2`
- **셀프체크**: 직전 차이의 부호 `prevSgn`(1, -1, 또는 0=없음)를 들고 가며, 이번 부호가 0이면 `cur = 1`, `prevSgn`과 다르거나 `prevSgn`이 0이면 `cur++`, 같으면 `cur = 2`(직전 원소와 나로 새 구간 시작)로 처리했는가. 단조 증가 배열은 답 2, 모두 같은 값이면 1, N=1이면 1.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    int best = 1;
    int cur = 1;
    int prevSgn = 0;
    for (int i = 1; i < n; i++) {
        int d = a[i] - a[i - 1];
        int sgn;
        if (d > 0) sgn = 1;
        else if (d < 0) sgn = -1;
        else sgn = 0;

        if (sgn == 0) {
            cur = 1;
        } else if (prevSgn == 0 || sgn != prevSgn) {
            cur++;
        } else {
            cur = 2;
        }
        prevSgn = sgn;
        if (cur > best) best = cur;
    }
    cout << best << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- 최장 연속 패턴의 조건 변형이다. 이번 조건은 "이웃 차이의 부호가 직전 부호와 다르다"이므로, 직전 부호 `prevSgn`을 상태로 함께 들고 가야 한다.
- 끊길 때 다시 시작하는 길이가 두 가지다: 같은 값(부호 0)이면 이어질 수 없으니 1, 부호가 같아서 끊기면 직전 원소와 현재 원소 두 개는 이미 한 차이를 이루므로 2.

(2) 코드 단계별

- `best = cur = 1`, `prevSgn = 0`(아직 차이 없음).
- `d = a[i] - a[i-1]`의 부호 `sgn`을 1/-1/0으로 정한다.
- `sgn == 0`이면 `cur = 1`; `prevSgn == 0`이거나 `sgn != prevSgn`이면 `cur++`; 그 외(같은 부호)면 `cur = 2`.
- `prevSgn = sgn`으로 갱신 후 `best` 유지.

(3) 스스로 다시 짤 때 생각 순서

- "조건이 직전 상태에 의존한다" → 상태 변수(`prevSgn`)를 하나 더 든다.
- 함정: 같은 값 뒤에는 `prevSgn = 0`이 되어 다음 차이가 어떤 부호든 새 구간(길이 2)을 만들 수 있어야 한다(다섯째 테스트의 `2 5 1`). 단조 증가는 첫 차이만 인정되어 2. N=1이면 루프 없이 1.
- C++ 함정 ①: 부호를 `d / abs(d)`로 구하려 하면 `d == 0`에서 0으로 나눠 프로그램이 죽는다. if 세 갈래가 안전하다.
- C++ 함정 ②: `using namespace std;` 아래에서 변수 이름을 `prev`로 두면 `std::prev`와 이름이 겹친다. 컴파일은 되지만 읽기 어렵고, `count`·`distance`·`size` 같은 이름은 상황에 따라 실제 충돌을 일으킨다. `prevSgn`처럼 한 단어를 덧붙이는 편이 안전하다.
- 원소가 `int` 범위 양끝(예: -2×10^9와 2×10^9)이면 `a[i] - a[i-1]`이 오버플로한다. 이 문제는 값 범위가 작아 안전하지만, 차이를 구할 땐 항상 범위를 확인한다.
```

**6) 가장 가까운 재등장** · Medium

- **요구사항**: 정수 배열에서 같은 값이 두 번 나타나는 위치 쌍 중, 두 위치의 거리(인덱스 차이)가 가장 작은 값을 구하라. 같은 값이 두 번 이상 나오는 경우가 없으면 -1.
- **입력**: 첫 줄 N (1 ≤ N ≤ 100000), 둘째 줄 N개의 정수(0 ≤ 값 ≤ 1000).
- **출력**: 최소 거리 한 줄(없으면 -1).
- **예제**: `7 / 4 1 4 2 1 1 3` → `1` · `4 / 1 2 3 4` → `-1`
- **셀프체크**: 값별 "마지막 등장 위치" 배열을 두고, 값을 볼 때마다 `현재 위치 - last[v]`를 후보로 삼은 뒤 `last[v]`를 현재 위치로 갱신했는가(직전 등장과의 거리만 보면 충분하다 — 더 앞의 등장은 거리가 더 크다). 이웃한 두 값이 같으면 답은 1로 더 작아질 수 없다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    vector<int> last(1001, -1);
    int best = -1;
    for (int i = 0; i < n; i++) {
        int v;
        cin >> v;
        if (last[v] != -1) {
            int gap = i - last[v];
            if (best == -1 || gap < best) best = gap;
        }
        last[v] = i;
    }
    cout << best << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- L2의 "마지막 위치 기록"을 그대로 쓴다. 어떤 값 `v`가 다시 나왔을 때, 가장 가까운 이전 등장은 언제나 "직전 등장"이므로 `i - last[v]`만 후보로 보면 된다. 모든 이전 등장을 비교할 필요가 없다.
- 배열을 한 번 훑으며 후보의 최솟값을 유지하면 O(N)이다.

(2) 코드 단계별

- `vector<int> last(1001, -1)`, `best = -1`.
- 값 `v`를 읽어 `last[v] != -1`이면 `gap = i - last[v]`로 `best`를 갱신(첫 후보면 그대로 채택).
- 갱신 순서 주의: 후보를 본 뒤에 `last[v] = i`로 덮어쓴다.

(3) 스스로 다시 짤 때 생각 순서

- "무엇을 기록?" → 값별 마지막 인덱스. "언제 답 후보?" → 다시 나올 때.
- 함정: `last[v] = i`를 먼저 하면 거리가 항상 0이 되어 틀린다. 최솟값 초기값을 -1(없음)로 두고 첫 후보에서 무조건 채택. 값 0도 나올 수 있으므로 "없음"은 0이 아니라 -1로 표시.
- C++ 함정: 최솟값 초기값을 `INT_MAX`로 두는 흔한 패턴을 쓰면 "끝까지 후보가 없었다"를 따로 판별해 -1을 찍어야 한다. 여기서는 `best == -1`이라는 하나의 상태로 "아직 없음"과 출력값을 동시에 표현해 코드를 줄였다.
- 값이 0~1000이라 배열로 충분하다. 값 범위가 넓으면 `unordered_map<int,int> last;`로 바꾸면 되고, 이때 `last.count(v)`로 존재 여부를 먼저 확인해야 한다(없는 키를 `[]`로 읽으면 0이 **삽입**된다).
```

**7) 회전 로봇** · Medium

- **요구사항**: N×M 격자에 빈 칸 `.`과 장애물 `#`이 있다. 로봇은 시작 칸에서 북쪽(위)을 바라보고 있다. 명령 `F`는 바라보는 방향으로 한 칸 전진(다음 칸이 격자 밖이거나 장애물이면 제자리), `L`은 왼쪽으로 90도 회전, `R`은 오른쪽으로 90도 회전이다. 모든 명령 후의 위치와 바라보는 방향(N/E/S/W)을 출력하라.
- **입력**: 첫 줄 `N M` (1 ≤ N, M ≤ 50), 이어 N줄의 격자(각 줄은 `.`/`#` M글자, 공백 없음), 다음 줄 시작 위치 `r c`(1-based, 항상 빈 칸), 마지막 줄 명령 문자열(길이 1~1000, F/L/R만).
- **출력**: `r c 방향` 한 줄.
- **예제**: `3 3 / ... / .#. / ... / 3 1 / FFRFF` → `1 3 E` · `2 2 / .. / .. / 1 1 / LF` → `1 1 W`
- **셀프체크**: 방향 배열을 시계 순서(북·동·남·서)로 두면 우회전은 `(d + 1) % 4`, 좌회전은 `(d + 3) % 4`. C++의 `%`는 음수를 음수로 돌려주므로 `(d - 1) % 4`를 쓰면 -1이 나와 배열 밖을 읽는다. 전진이 막히면 방향은 그대로 두고 위치만 유지했는가. 격자는 `vector<string>`이라 `grid[nr - 1][nc - 1]`로 0-based 변환해 읽어야 한다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    vector<string> grid(n);
    for (int i = 0; i < n; i++) cin >> grid[i];

    int r, c;
    cin >> r >> c;
    string cmds;
    cin >> cmds;

    int dx[4] = {-1, 0, 1, 0};
    int dy[4] = {0, 1, 0, -1};
    string names = "NESW";
    int d = 0;

    for (char ch : cmds) {
        if (ch == 'L') {
            d = (d + 3) % 4;
        } else if (ch == 'R') {
            d = (d + 1) % 4;
        } else {
            int nr = r + dx[d];
            int nc = c + dy[d];
            if (1 <= nr && nr <= n && 1 <= nc && nc <= m && grid[nr - 1][nc - 1] == '.') {
                r = nr;
                c = nc;
            }
        }
    }
    cout << r << ' ' << c << ' ' << names[d] << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

(2) 코드 단계별

(3) 스스로 다시 짤 때 생각 순서

- "회전은 방향 배열의 순서가 규칙" → 배열을 시계 순으로 나열하는 것이 첫 결정.
- 함정: 입력은 1-based, `vector<string>`은 0-based → `-1` 변환. 막힌 전진에서 방향은 유지(셋째 테스트 `3 2 N`). 넷째 테스트처럼 회전만 연속으로 해도 위치는 그대로다.
- **C++ 함정(핵심)**: 좌회전을 `(d - 1) % 4`로 쓰면 안 된다. C++의 `%`는 나머지 부호를 **피제수 쪽**에 맞추므로 `(0 - 1) % 4`가 파이썬처럼 3이 아니라 **-1**이다. `dx[-1]`은 배열 밖 접근이고, 오류 없이 쓰레기 값을 읽어 로봇이 엉뚱한 곳으로 간다. `(d + 3) % 4` 또는 `((d - 1) % 4 + 4) % 4`로 쓴다.
- 조건에서 `&&`의 순서도 의미가 있다. 경계 검사를 먼저 하고 `grid[nr-1][nc-1]`을 마지막에 두면, 범위를 벗어난 인덱스를 애초에 읽지 않는다(단축 평가).
```

**8) 벽 만나면 우회전** · Hard

- **요구사항**: N×M 격자에 빈 칸 `.`과 벽 `#`이 있다. 로봇은 시작 칸에서 북쪽을 바라보고 총 K번 "한 칸 이동"을 시도한다. 매 이동에서 바라보는 방향의 다음 칸이 격자 안의 빈 칸이면 그 칸으로 이동한다. 막혀 있으면(격자 밖 또는 벽) 오른쪽으로 90도 회전한 뒤 다시 시도하는데, 네 방향을 모두 돌아도 갈 수 없으면 그 자리에서 완전히 멈춘다(남은 이동은 하지 않음). 과정에서 로봇이 밟은 서로 다른 칸의 수(시작 칸 포함)와 최종 위치를 출력하라.
- **입력**: 첫 줄 `N M K` (1 ≤ N, M ≤ 50, 0 ≤ K ≤ 1000), 이어 N줄의 격자(공백 없음), 마지막 줄 시작 위치 `r c`(1-based, 빈 칸).
- **출력**: `칸수 r c` 한 줄.
- **예제**: `3 3 5 / ... / ... / ... / 1 1` → `6 3 2` · `1 1 3 / . / 1 1` → `1 1 1`
- **셀프체크**: 이동 한 번 안에서 "막히면 회전 후 재시도"를 최대 4번까지 도는 안쪽 while을 두었는가. 4번 모두 실패했을 때 바깥 루프도 `break`로 끝냈는가. 방문 여부를 `vector<vector<bool>> seen`에 기록해 같은 칸을 두 번 세지 않았는가. 첫 예제: (1,1)에서 북이 막혀 동으로 (1,2),(1,3), 다시 막혀 남으로 (2,3),(3,3), 막혀 서로 (3,2) → 6칸.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, k;
    cin >> n >> m >> k;
    vector<string> grid(n);
    for (int i = 0; i < n; i++) cin >> grid[i];

    int r, c;
    cin >> r >> c;

    int dx[4] = {-1, 0, 1, 0};
    int dy[4] = {0, 1, 0, -1};

    vector<vector<bool>> seen(n + 1, vector<bool>(m + 1, false));
    seen[r][c] = true;
    int cnt = 1;
    int d = 0;

    for (int step = 0; step < k; step++) {
        int tries = 0;
        while (tries < 4) {
            int nr = r + dx[d];
            int nc = c + dy[d];
            if (1 <= nr && nr <= n && 1 <= nc && nc <= m && grid[nr - 1][nc - 1] == '.') {
                r = nr;
                c = nc;
                if (!seen[r][c]) {
                    seen[r][c] = true;
                    cnt++;
                }
                break;
            }
            d = (d + 1) % 4;
            tries++;
        }
        if (tries == 4) break;
    }
    cout << cnt << ' ' << r << ' ' << c << '\n';
    return 0;
}

@@EXPL
(1) 접근·핵심 아이디어

- L3-3 "달팽이 채우기"의 "막히면 회전"을 일반화한 것이다. 달팽이는 한 번만 돌면 반드시 갈 수 있었지만, 여기서는 벽 때문에 여러 번 돌 수도 있고 사방이 막힐 수도 있으므로 "회전 시도 횟수 `tries`"를 세어 4번이면 멈춘다.
- 밟은 칸 수는 L2의 마킹 배열을 2차원으로 쓴 `seen[r][c]`로 센다. 같은 칸을 다시 밟아도 카운트는 늘지 않는다.

(2) 코드 단계별

- 방향 배열을 북·동·남·서로 두고 `d = 0`. `seen[r][c] = true, cnt = 1`로 시작 칸을 먼저 기록.
- 이동 K번: 안쪽 while에서 다음 칸이 유효하면 이동·마킹 후 `break`, 아니면 `d = (d + 1) % 4; tries++;`.
- while이 `tries == 4`로 끝났으면 사방이 막힌 것이므로 바깥 for도 `break`.
- `cnt r c` 출력.

(3) 스스로 다시 짤 때 생각 순서

- "한 번의 이동 = 최대 4번의 방향 시도" 구조를 먼저 그린다. 성공하면 방향은 회전한 상태 그대로 유지된다.
- 함정: 시작 칸을 세는 것을 잊으면 1 부족. 1×1 격자나 사방이 벽이면 첫 이동에서 4번 실패 → 즉시 종료(둘째 테스트). 셋째 테스트처럼 두 칸을 왕복하면 K가 커도 칸 수는 2. 넷째 테스트처럼 벽이 없으면 가장자리를 계속 돌며 100번 이동 후 위치를 그대로 시뮬레이션해야 한다(규칙으로 예측하지 말 것).
- C++ 함정 ①: 안쪽 `break`는 **while만** 빠져나온다. 바깥 for까지 끝내려면 `tries == 4`를 다시 검사해야 한다. 파이썬처럼 `for ... else`가 없기 때문이다.
- C++ 함정 ②: `vector<vector<bool>>`은 비트로 압축된 특수 구현이라 원소의 참조를 얻을 수 없다(`bool& x = seen[r][c];`가 컴파일되지 않는다). 값을 읽고 쓰는 데는 문제가 없지만, 참조가 필요하면 `vector<vector<char>>`를 쓴다.
- C++ 함정 ③: 크기를 `(n+1) x (m+1)`로 잡아야 1-based 인덱스 `seen[n][m]`이 유효하다. `(n) x (m)`으로 잡으면 마지막 행·열에서 범위를 벗어난다.
```

**9) 첫 방문 시각 지도** · Hard

- **요구사항**: N×M 격자에 빈 칸 `.`과 벽 `#`이 있다. 로봇은 시각 0에 시작 칸에 있고, 명령 문자열의 각 글자(U/D/L/R)를 순서대로 하나씩 수행하며 명령마다 시각이 1씩 흐른다. 이동이 격자 밖이거나 벽이면 제자리에 머무르지만 시각은 흐른다. 모든 명령 후, 각 칸을 "처음 방문한 시각"으로 채운 지도를 출력하라(시작 칸은 0, 한 번도 방문하지 않은 칸은 -1).
- **입력**: 첫 줄 `N M` (1 ≤ N, M ≤ 30), 이어 N줄의 격자(공백 없음), 다음 줄 시작 위치 `r c`(1-based, 빈 칸), 마지막 줄 명령 문자열(길이 1~500).
- **출력**: N줄, 각 줄에 M개의 정수를 공백으로 구분.
- **예제**: `2 3 / ... / .#. / 1 1 / RRDLU` → `0 1 2 / -1 -1 3` · `1 1 / . / 1 1 / UD` → `0`
- **셀프체크**: 시각 `t`는 이동 성공 여부와 무관하게 명령마다 1 증가시켰는가. 이미 방문한 칸(`first != -1`)에 다시 들어가도 값을 덮어쓰지 않았는가. 첫 예제에서 4번째 명령 L은 벽 `(2,2)`에 막히고 5번째 U는 이미 방문한 `(1,3)`이라 지도에 반영되지 않는다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    vector<string> grid(n);
    for (int i = 0; i < n; i++) cin >> grid[i];

    int r, c;
    cin >> r >> c;
    string cmds;
    cin >> cmds;

    string dirs = "UDLR";
    int dx[4] = {-1, 1, 0, 0};
    int dy[4] = {0, 0, -1, 1};

    vector<vector<int>> first(n + 1, vector<int>(m + 1, -1));
    first[r][c] = 0;

    int t = 0;
    for (char ch : cmds) {
        t++;
        int k = (int)dirs.find(ch);
        int nr = r + dx[k];
        int nc = c + dy[k];
        if (1 <= nr && nr <= n && 1 <= nc && nc <= m && grid[nr - 1][nc - 1] == '.') {
            r = nr;
            c = nc;
            if (first[r][c] == -1) first[r][c] = t;
        }
    }

    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (j > 1) cout << ' ';
            cout << first[i][j];
        }
        cout << '\n';
    }
    return 0;
}

(1) 접근·핵심 아이디어

- 3번의 명령 이동에 L2의 "배열 기록"을 2차원으로 결합한다. 기록할 정보는 "처음 방문한 시각"이므로, 초기값 -1로 채운 `vector<vector<int>> first`를 두고 칸에 들어갈 때 `first[r][c] == -1`일 때만 현재 시각을 적는다.
- 시각은 명령의 순번이다. 벽에 막혀 제자리여도 명령은 소비되므로 `t`는 매 명령 증가한다.

(2) 코드 단계별

- `vector<vector<int>> first(n + 1, vector<int>(m + 1, -1))`로 1-based 크기를 잡고 시작 칸 `first[r][c] = 0`, `t = 0`.
- 명령마다 `t++`, 방향 인덱스로 `(nr, nc)` 계산, 격자 안이고 `.`이면 이동.
- 이동한 칸이 미방문(-1)이면 `first[r][c] = t`.
- 행마다 첫 칸이 아니면 앞에 공백을 붙여 출력하고, 행 끝에 `'\n'`.

(3) 스스로 다시 짤 때 생각 순서

- "무엇을 언제 기록?" → 칸에 들어가는 순간, 아직 -1일 때만 시각을 기록(덮어쓰기 금지).
- 함정: 막힌 명령에서도 `t`는 흘러야 한다(첫 예제의 L이 4를 소비해 이후 방문은 5부터). 시작 칸은 0으로 미리 적어야 나중에 되돌아와도 덮이지 않는다. 셋째 테스트처럼 되돌아온 칸은 처음 시각(1)이 유지된다.
- C++ 함정 ①: 2차원 벡터 초기화 문법이 헷갈리기 쉽다. `vector<vector<int>> f(행, vector<int>(열, 초기값))` — 바깥 크기가 행, 안쪽 생성자가 한 행의 내용이다. `vector<vector<int>> f(행, 열)`로 쓰면 전혀 다른 뜻이 되어 컴파일 오류가 난다.
- C++ 함정 ②: 파이썬의 `' '.join(...)`이 없으므로 구분자를 직접 다뤄야 한다. 매번 뒤에 공백을 붙이면 줄 끝에 공백이 남는다. `if (j > 1) cout << ' ';`처럼 **앞에** 붙이는 방식이 깔끔하다.
- 변수 이름 `first`는 `std::first`와 충돌하지 않지만, `pair`의 멤버 이름과 같아 헷갈릴 수 있다. 규모가 커지면 `firstSeen` 같은 이름을 쓴다.
```

**10) 오목판 최장 줄** · Hard

- **요구사항**: N×M 오목판에 검은 돌 `B`, 흰 돌 `W`, 빈 칸 `.`이 있다. 같은 색 돌이 가로·세로·대각선(↘)·역대각선(↙) 중 한 방향으로 연속해 놓인 가장 긴 줄의 길이를 구하라. 돌이 하나도 없으면 0.
- **입력**: 첫 줄 `N M` (1 ≤ N, M ≤ 50), 이어 N줄의 판(각 줄 M글자, 공백 없음).
- **출력**: 가장 긴 같은 색 줄의 길이 한 줄.
- **예제**: `4 4 / B... / .B.. / ..B. / W..B` → `4` · `3 3 / ... / ... / ...` → `0`
- **셀프체크**: 네 방향 `int dx[4] = {0, 1, 1, 1}`, `int dy[4] = {1, 0, 1, -1}`(오른쪽·아래·↘·↙)만 보면 충분하다 — 반대 방향은 같은 줄을 반대편 끝에서 세는 것이라 중복이다. 각 돌에서 방향마다 "같은 색이 계속되는 동안" while로 뻗어 나가며 경계 검사를 했는가. ↙ 방향은 열이 감소하므로 `nc >= 0` 검사가 필요하다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    vector<string> grid(n);
    for (int i = 0; i < n; i++) cin >> grid[i];

    int dx[4] = {0, 1, 1, 1};
    int dy[4] = {1, 0, 1, -1};

    int best = 0;
    for (int r = 0; r < n; r++) {
        for (int c = 0; c < m; c++) {
            if (grid[r][c] == '.') continue;
            for (int k = 0; k < 4; k++) {
                int length = 1;
                int nr = r + dx[k];
                int nc = c + dy[k];
                while (0 <= nr && nr < n && 0 <= nc && nc < m && grid[nr][nc] == grid[r][c]) {
                    length++;
                    nr += dx[k];
                    nc += dy[k];
                }
                if (length > best) best = length;
            }
        }
    }
    cout << best << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- L1의 "연속 길이 세기"를 L3의 dx dy로 2차원 네 방향에 적용한다. 각 돌을 출발점으로 삼아 한 방향으로 같은 색이 이어지는 동안 한 칸씩 전진하며 길이를 센다.
- 방향은 오른쪽·아래·↘·↙ 네 개만 본다. 왼쪽·위·↖·↗은 같은 줄을 반대편에서 세는 것이라 결과가 같다.

(2) 코드 단계별

- `dx = {0, 1, 1, 1}`, `dy = {1, 0, 1, -1}`.
- 모든 칸 `(r, c)`에 대해 빈 칸이면 `continue`, 돌이면 네 방향 각각 `length = 1`에서 시작.
- while 조건 "격자 안 and 같은 색"이 참인 동안 `length++`, `nr += dx[k]`, `nc += dy[k]`.
- `best` 갱신 후 출력.

(3) 스스로 다시 짤 때 생각 순서

- "각 칸에서 각 방향으로 뻗기" → 3중 루프 + while. 판이 50×50이라 총 1만 번의 뻗기로 충분히 빠르다.
- **C++ 함정(핵심)**: ↙ 방향은 `nc`가 줄어든다. `0 <= nc` 검사를 빼면 `grid[nr][-1]`이 되는데, `string::operator[]`의 인자는 부호 없는 `size_t`라 -1이 거대한 수로 바뀌어 **정의되지 않은 동작**이 된다. 파이썬처럼 반대편을 읽어 주는 게 아니라 운이 나쁘면 그대로 죽는다.
- while 조건에서 경계 검사를 `grid[nr][nc]` 접근보다 **먼저** 써야 한다. `&&`는 앞이 거짓이면 뒤를 평가하지 않으므로(단축 평가) 이 순서가 곧 안전장치다.
- 돌이 없으면 루프가 갱신을 못 해 0, 돌 하나면 1. 셋째 테스트에서 `WWWW`(4)가 `BBB`(3)보다 길다.
- 행 크기를 `grid.size()`로 읽어 `r < grid.size()`로 비교하면 부호 있는/없는 비교 경고가 뜬다. `int n`을 따로 들고 쓰는 편이 깔끔하다.
```
