> 개요: 규칙이 정해진 과정을 코드로 그대로 흉내 내는 "시뮬레이션"의 첫 장이다. 날짜·시간처럼 자릿수마다 올림이 다른 값을 다루는 법, 임의 진법으로 수를 바꾸는 법, 그리고 1차원 구간과 2차원 사각형을 배열 위에 "칠하며" 겹침·넓이를 세는 기법을 익힌다.

## L1. 날짜와 시간 계산

**개념**

- 날짜·시간 계산은 "자릿수마다 올림 규칙이 다른 수 체계"를 다루는 문제다. 초는 60이 되면 분으로, 분은 60이 되면 시로, 시는 24가 되면 일로 넘어간다. 달마다 일수가 다르고, 윤년이면 2월이 하루 늘어난다. 이 불규칙성을 사람이 손으로 하듯 코드로 그대로 재현하는 것이 핵심이다.

- 가장 강력한 무기는 "모든 것을 하나의 기준 단위로 환산"하는 것이다. 시:분:초를 전부 "총 초"로, 날짜를 "기준일로부터 며칠"로 바꾸면, 덧셈·뺄셈·비교가 그냥 정수 연산이 된다. 계산이 끝나면 다시 사람이 읽는 형태로 복원한다. C++의 정수 나눗셈 `/`는 몫, `%`는 나머지를 주므로 환산·복원이 그대로 맞아떨어진다.

```cpp
// 시:분:초 <-> 총 초 상호 변환
int toSec(int h, int m, int s) {
    return h * 3600 + m * 60 + s;
}

void fromSec(int total, int& h, int& m, int& s) {
    total %= 24 * 3600;         // 하루로 감싸기(음수 방지는 아래 참고)
    h = total / 3600;
    m = (total % 3600) / 60;
    s = total % 60;
}

// 윤년 판정: 4의 배수 & (100의 배수 아님) 또는 400의 배수
bool isLeap(int y) {
    return (y % 4 == 0 && y % 100 != 0) || (y % 400 == 0);
}

// 어떤 해 m월의 일수
int daysInMonth(int y, int m) {
    int d[] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
    if (m == 2 && isLeap(y)) return 29;
    return d[m - 1];
}
```

**접근 전략**

- 핵심 아이디어는 "환산 → 정수 연산 → 복원" 3단계다. 문제가 요구하는 계산(더하기, 두 시각 차이, 대소 비교)은 모두 총 초 또는 총 일수로 바꾼 뒤 정수로 처리하면 실수가 거의 없다. 자릿수별로 올림/빌림을 직접 처리하려 들면 경계에서 반드시 실수한다.

- 요일은 "기준일의 요일 + 경과 일수를 7로 나눈 나머지"로 구한다. 요일 이름 배열을 만들어 두고 `(기준요일 + 경과일) % 7`로 인덱싱한다. 하루 넘김이 있는 시각 덧셈은 총 초에 더한 뒤 `/ 86400`으로 "며칠 넘어갔는지", `% 86400`으로 "그날의 시각"을 분리한다.

- 언제 쓰나: 알람/타이머, 근무시간 정산, D-day, 며칠 뒤 요일, 특정 규칙의 주기적 사건 등. 주의점 — C++의 `%`는 음수 피연산자에서 음수 결과를 줄 수 있으므로, "빌림"이 필요한 뺄셈은 부호를 먼저 정리하거나 결과가 음수면 주기를 더해 보정하자. 달·윤년 경계(2/28→3/1, 12/31→1/1), "당일 포함/제외"(N일째 vs N일 후)를 문제에서 정확히 읽어야 한다. 복잡도는 대부분 O(1)이나, 하루씩 세며 진행하면 O(경과 일수)이므로 큰 범위면 환산식을 써야 한다.

**문제**

**1) 지구 반대편 알람** · Easy

- **요구사항**: 현재 시각(시 h, 분 m)에서 정확히 `k`분이 지난 뒤의 시각을 구하라. `k`는 하루(1440분)를 넘을 수 있다. 며칠 넘어갔는지와, 그날의 시:분을 함께 출력한다.

- **입력**: 첫 줄에 `h m` (0 ≤ h < 24, 0 ≤ m < 60), 둘째 줄에 정수 `k` (0 ≤ k ≤ 1,000,000).

- **출력**: `경과일수 시 분`을 공백으로 구분해 한 줄.

- **예제**: `23 50` / `25` → `1 0 15`

- **예제**: `14 30` / `3000` → `2 16 30`

- **셀프체크**: 총 분으로 환산했는가? `일수 = 총분 / 1440`, `시 = (총분 % 1440) / 60`. 자정을 딱 넘길 때(예 23:50+25=00:15) 시가 24가 아니라 0이 되는지 확인. 세 값을 공백으로만 구분해 그대로 출력하면 되는지(자리 패딩 요구 없음) 문제 형식을 다시 읽자.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    int h, m, k;
    cin >> h >> m >> k;
    int total = h * 60 + m + k;
    int days = total / 1440;
    int rest = total % 1440;
    cout << days << " " << rest / 60 << " " << rest % 60 << "\n";
    return 0;
}
@@TESTS
--IN
14 30
3000
--OUT
2 16 30
--IN
23 50
25
--OUT
1 0 15
@@EXPL
(1) 접근·핵심 아이디어

- 시:분을 자릿수별로 올림 처리하지 말고 "총 분"이라는 하나의 정수로 환산한다. 현재 시각을 `h*60+m` 분으로 바꾸고 `k`를 더하면, 그 뒤엔 그냥 정수 나눗셈 두 번이면 답이 나온다.
- 하루는 1440분이므로 `총분 / 1440`이 "며칠 넘어갔는지", `총분 % 1440`이 "그날의 시각(분)"이다.

(2) 코드 단계별

- `h m`과 `k`를 `cin`으로 읽어 `total = h*60 + m + k`로 총 분을 구한다.
- `days = total / 1440`으로 경과 일수를 구한다(정수 나눗셈=몫).
- `rest = total % 1440`이 그날의 분이므로, 시는 `rest / 60`, 분은 `rest % 60`.
- `경과일수 시 분`을 공백으로 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "모든 것을 총 분으로" → 더하기 → `/1440`로 날짜 분리, `%1440`로 시각 분리 → 시/분은 60으로 다시 나눔.
- 검산: `14:30 + 3000분` = 2일 뒤 `16:30`, `23:50 + 25분` = 다음날 `00:15`(경과일수 1)인지 손으로 확인.
```

**2) 무슨 요일일까** · Medium

- **요구사항**: 어떤 해의 1월 1일이 "월요일"이라고 알려져 있다. 같은 해의 `m`월 `d`일이 무슨 요일인지 구하라. (그 해는 입력으로 주는 연도 `y`를 따르며, 윤년일 수 있다.)

- **입력**: 한 줄에 `y m d` (1 ≤ m ≤ 12, 유효한 날짜).

- **출력**: 요일을 한글 한 글자로. 월/화/수/목/금/토/일 중 하나.

- **예제**: `2024 1 1` → `월`

- **예제**: `2024 3 1` → `금`

- **셀프체크**: 1월 1일을 "그 해의 1일째"로 보고, `m월 d일`이 며칠째인지(day-of-year)를 먼저 구한다. 2024-03-01은 31+29+1=61일째다. 요일은 `(day_of_year - 1) % 7`로 월요일 기준 인덱싱(1일째면 오프셋 0=월). 윤년일 때만 2월을 29로 바꾸는 분기를 넣었는지 확인. `daysInMonth`를 재사용하면 깔끔하다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

bool isLeap(int y) {
    return (y % 4 == 0 && y % 100 != 0) || (y % 400 == 0);
}

int daysInMonth(int y, int m) {
    int d[] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
    if (m == 2 && isLeap(y)) return 29;
    return d[m - 1];
}

int main() {
    int y, m, d;
    cin >> y >> m >> d;
    int doy = d;
    for (int mm = 1; mm < m; mm++) doy += daysInMonth(y, mm);
    string names[] = {"월", "화", "수", "목", "금", "토", "일"};
    cout << names[(doy - 1) % 7] << "\n";
    return 0;
}
@@TESTS
--IN
2024 1 1
--OUT
월
--IN
2024 3 1
--OUT
금
@@EXPL
(1) 접근·핵심 아이디어

- 1월 1일을 "그 해의 1일째"로 두면, `m월 d일`이 몇 일째(day-of-year)인지만 구하면 요일이 바로 나온다.
- 1월 1일이 월요일(오프셋 0)이므로, `(day_of_year - 1) % 7`이 곧 요일 인덱스다. `{"월","화",...,"일"}` 배열로 인덱싱한다.

(2) 코드 단계별

- `isLeap(y)`: 4의 배수이고 100의 배수가 아니거나, 400의 배수면 윤년.
- `daysInMonth(y, m)`: 기본 일수 배열을 두고, 2월이면서 윤년일 때만 29를 반환.
- `doy = d`에서 시작해 `1`월부터 `m-1`월까지의 일수를 더해 day-of-year를 완성한다.
- `(doy - 1) % 7`로 요일 이름 배열을 인덱싱해 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "1일째 = 월요일" 기준을 못박는다 → day-of-year를 구한다(앞 달들의 일수 합 + d) → `(doy-1)%7`로 요일.
- 검산: 2024-03-01 = 31+29+1 = 61일째, `(61-1)%7 = 60%7 = 4` → index 4 = 금.
```

**3) 근무시간 정산** · Medium

- **요구사항**: 하루 동안 여러 번 출근·퇴근을 반복한 기록이 있다. 각 기록은 `출근시각 퇴근시각`(시:분:초)이며, 항상 출근 ≤ 퇴근이고 같은 날 안에서 일어난다. 총 근무시간을 `시:분:초` 형태로 출력하라.

- **입력**: 첫 줄에 기록 수 `n`. 이어지는 `n`개 줄에 각각 `h1 m1 s1 h2 m2 s2`.

- **출력**: 총 근무시간을 `HH:MM:SS`처럼 두 자리씩 채워 한 줄.

- **예제**: `2` / `09 00 00 12 30 30` / `13 00 00 18 00 00` → `08:30:30`

- **예제**: `1` / `08 15 40 08 16 10` → `00:00:30`

- **셀프체크**: 각 구간을 총 초 차이로 바꿔 누적한 뒤, 마지막에 시:분:초로 복원했는가? 합이 하루를 넘을 수도 있으니 시(hour) 부분은 `% 24`를 하면 안 된다(그냥 `총초 / 3600`). 두 자리 패딩은 `<iomanip>`의 `setw(2)` + `setfill('0')`. 초 30 하나짜리 예제로 자리 올림 없는 최소 케이스를 검증하자.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int total = 0;
    for (int i = 0; i < n; i++) {
        int h1, m1, s1, h2, m2, s2;
        cin >> h1 >> m1 >> s1 >> h2 >> m2 >> s2;
        total += (h2 * 3600 + m2 * 60 + s2) - (h1 * 3600 + m1 * 60 + s1);
    }
    int h = total / 3600;
    int m = (total % 3600) / 60;
    int s = total % 60;
    cout << setfill('0') << setw(2) << h << ":"
         << setw(2) << m << ":" << setw(2) << s << "\n";
    return 0;
}
@@TESTS
--IN
1
08 15 40 08 16 10
--OUT
00:00:30
--IN
2
09 00 00 12 30 30
13 00 00 18 00 00
--OUT
08:30:30
@@EXPL
(1) 접근·핵심 아이디어

- 각 근무 구간을 "총 초"로 환산해 차이(`퇴근초 - 출근초`)를 누적하면, 자릿수별 올림/빌림 없이 정수 덧셈만으로 총 근무시간이 나온다.
- 마지막에 누적 초를 다시 시:분:초로 복원하되, 하루를 넘을 수 있으므로 시(hour)에는 `%24`를 하지 않는다(그냥 `총초 / 3600`).

(2) 코드 단계별

- 기록 수 `n`을 읽는다.
- 각 줄에서 `h1 m1 s1 h2 m2 s2`를 읽어 두 시각을 각각 총 초로 만들고 그 차이를 `total`에 더한다(`cin >> int`는 `08` 같은 앞자리 0도 8진수가 아닌 10진수로 읽는다).
- `h = total / 3600`, `m = (total % 3600) / 60`, `s = total % 60`으로 복원.
- `setfill('0')`와 `setw(2)`로 각 값을 두 자리씩 패딩해 `HH:MM:SS`로 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "각 구간을 총 초로" → 차이를 누적 → 시/분/초로 복원 → 두 자리 패딩.
- 검산: 30초 한 건짜리 최소 케이스가 `00:00:30`으로 나오는지 확인해 패딩·복원 로직을 검증. 둘째 예제는 3:30:30 + 5:00:00 = `08:30:30`.
```

## L2. Notation

**개념**

- Notation은 "같은 수를 다른 진법(base)으로 표기"하는 문제다. 우리가 쓰는 10진법은 자리마다 10의 거듭제곱을 뜻하지만, 2진법은 2의 거듭제곱, 16진법은 16의 거듭제곱이다. 컴퓨터 내부(2진), 색상 코드(16진), 각종 인코딩에서 끊임없이 등장한다. 진법 변환의 뼈대는 두 방향이다: (1) 임의 진법 → 10진, (2) 10진 → 임의 진법.

- 10진으로 바꿀 때는 "왼쪽 자리부터 읽으며 base를 곱하고 자릿값을 더한다"(호너의 방식). 임의 진법으로 바꿀 때는 "base로 나눈 나머지를 거꾸로 모은다". 10을 넘는 진법은 나머지가 10~35가 되므로 `A~Z`로 표기한다. C++에서는 문자↔값 매핑을 `std::string DIGITS`로 두고, `DIGITS.find(ch)`로 값을, `DIGITS[v]`로 문자를 얻는다.

```cpp
string DIGITS = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ";

// 임의 진법 문자열 s(base b) -> 10진 정수
long long toDecimal(const string& s, int b) {
    long long val = 0;
    for (char ch : s)
        val = val * b + (long long)DIGITS.find(ch);   // 왼쪽부터 누적
    return val;
}

// 10진 정수 n -> base b 문자열
string toBase(long long n, int b) {
    if (n == 0) return "0";
    string res = "";
    while (n > 0) {
        res = string(1, DIGITS[n % b]) + res;          // 나머지를 앞에 붙임
        n /= b;
    }
    return res;
}
```

**접근 전략**

- 핵심 아이디어: 서로 다른 두 진법 사이 변환은 "10진을 다리(bridge)로" 삼는다. base A → 10진 → base B. 이 두 함수만 정확히 구현하면 어떤 진법 쌍이든 조합으로 해결된다. 새 자료구조가 필요 없고, 문자↔숫자 매핑 테이블(`DIGITS`) 하나면 충분하다.

- 전형 절차: (1) 입력 문자열을 위에서 아래 자리로 순회하며 10진 값 누적, (2) 그 10진 값을 목표 base로 나눗셈 반복하며 나머지를 앞쪽에 쌓기, (3) 0을 특수 처리(빈 문자열 방지). 문자↔값 변환은 `DIGITS.find(ch)`와 `DIGITS[v]`로 통일하면 대문자·숫자를 한 번에 처리한다.

- 언제 쓰나: 진법 변환, 자릿수 합/자릿수 판정, "k진법으로 회문인가", 커스텀 인코딩. 주의점 — n=0은 반드시 `"0"`을 반환(루프를 아예 안 돌아 빈 문자열이 되는 함정). 입력에 소문자가 섞이면 대문자로 정규화. C++ 기본 정수는 범위가 제한되므로 큰 값이 예상되면 `long long`을 쓰고, 자리 수가 매우 크면 문자열 길이는 `O(log_b n)`, 변환 비용도 그에 비례한다.

**문제**

**1) 진법 변환기** · Easy

- **요구사항**: 어떤 수를 `a`진법으로 표기한 문자열이 주어진다. 이 수를 `b`진법 표기로 바꿔 출력하라. (2 ≤ a, b ≤ 36, 10 이상 자리는 대문자 `A~Z`.)

- **입력**: 한 줄에 `a b s` (s는 a진법 표기 문자열, 대문자·숫자로만 구성).

- **출력**: b진법 표기 문자열 한 줄.

- **예제**: `2 8 1010` → `12`

- **예제**: `16 2 FF` → `11111111`

- **셀프체크**: `1010`(2진)=10(10진)=`12`(8진)이 맞는지 손으로 검산. `FF`(16진)=255=`11111111`(2진). 다리로 쓴 10진 값을 중간에 출력해 확인하는 습관을 들이자. 결과가 0일 때(입력이 `0`) `"0"`이 나오는지 경계 확인.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

string DIGITS = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ";

long long toDecimal(const string& s, int b) {
    long long val = 0;
    for (char ch : s)
        val = val * b + (long long)DIGITS.find(ch);
    return val;
}

string toBase(long long n, int b) {
    if (n == 0) return "0";
    string res = "";
    while (n > 0) {
        res = string(1, DIGITS[n % b]) + res;
        n /= b;
    }
    return res;
}

int main() {
    int a, b;
    string s;
    cin >> a >> b >> s;
    cout << toBase(toDecimal(s, a), b) << "\n";
    return 0;
}
@@TESTS
--IN
2 8 1010
--OUT
12
--IN
16 2 FF
--OUT
11111111
@@EXPL
(1) 접근·핵심 아이디어

- 서로 다른 두 진법 사이 변환은 "10진을 다리로" 삼는다: a진법 문자열 → 10진 정수 → b진법 문자열.
- 문자↔값 매핑은 `DIGITS` 문자열 하나로 통일한다(`DIGITS.find(ch)`로 값, `DIGITS[v]`로 문자).

(2) 코드 단계별

- `toDecimal(s, b)`: 문자열을 왼쪽부터 순회하며 `val = val*b + 자릿값`(호너의 방식)으로 10진 값을 누적.
- `toBase(n, b)`: `n`을 `b`로 나눈 나머지를 앞쪽에 붙이며 몫이 0이 될 때까지 반복. `n==0`이면 `"0"`을 특수 반환.
- 입력 `a b s`를 읽어 `toBase(toDecimal(s, a), b)`로 한 번에 변환해 출력.

(3) 스스로 다시 짤 때 생각 순서

- "두 방향 함수만 정확히" → a진→10진(왼쪽부터 누적) → 10진→b진(나머지를 앞에 쌓기, 0 특수처리) → 조합.
- 검산: `1010`(2진)=10 → 8진 `12`; `FF`(16진)=255 → 2진 `11111111`.
```

**2) k진법 자릿수 합** · Medium

- **요구사항**: 10진수 `n`을 `k`진법으로 바꿨을 때, 각 자리 숫자(값)의 합을 10진수로 출력하라. 예를 들어 16진법에서 `1E`의 자릿수 합은 1+14=15다.

- **입력**: 한 줄에 `n k` (0 ≤ n ≤ 1,000,000, 2 ≤ k ≤ 36).

- **출력**: 자릿수 값의 합(10진) 한 줄.

- **예제**: `30 16` → `15`

- **예제**: `255 16` → `30`

- **셀프체크**: 문자로 만들 필요 없이 `n을 k로 나눈 나머지`를 그대로 더해 나가면 자릿수 값의 합이 된다(굳이 `A~Z`로 바꿨다가 되돌리지 말 것). 30=`1E`(16진)→1+14=15, 255=`FF`→15+15=30. n=0이면 `while (n > 0)` 루프를 아예 돌지 않아 합이 0으로 그대로 남는다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    long long n;
    int k;
    cin >> n >> k;
    long long s = 0;
    while (n > 0) {
        s += n % k;
        n /= k;
    }
    cout << s << "\n";
    return 0;
}
@@TESTS
--IN
30 16
--OUT
15
--IN
255 16
--OUT
30
@@EXPL
(1) 접근·핵심 아이디어

- k진법 표기의 각 자릿수 "값"은 `n`을 `k`로 나눈 나머지들이다. 문자(`A~Z`)로 바꿀 필요 없이 나머지를 그대로 더하면 자릿수 값의 합이 된다.

(2) 코드 단계별

- `n k`를 읽는다.
- `n > 0` 동안 `s += n % k`로 나머지를 더하고 `n /= k`로 자리를 내린다.
- `n`이 0이면 루프를 돌지 않으므로 합은 초기값 0이 그대로 남는다(별도 분기 불필요).
- 누적한 `s`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "표기 문자열을 만들지 말고 나머지만 더한다" → `n%k` 누적, `n/=k` 반복 → n=0은 루프 미진입으로 자동 처리.
- 검산: 30 = 1E(16진) → 1+14 = 15; 255 = FF → 15+15 = 30.
```

**3) 진법 회문 판정** · Medium

- **요구사항**: 10진수 `n`이 있다. `2`진법부터 `k`진법까지 각각 표기했을 때, 그 표기 문자열이 회문(앞뒤 대칭)이 되는 진법이 몇 개인지 세어 출력하라.

- **입력**: 한 줄에 `n k` (1 ≤ n ≤ 100,000, 2 ≤ k ≤ 36).

- **출력**: 회문이 되는 진법의 개수 한 줄.

- **예제**: `5 5` → `2`

- **예제**: `15 5` → `2`

- **셀프체크**: base 2부터 k까지 각각 표기 문자열을 만들고, 뒤집은 문자열(`rbegin()..rend()`)과 같은지로 판정한다. 첫 예제에서 5는 2진 `101`(회문 O), 3진 `12`(X), 4진 `11`(회문 O), 5진 `10`(X)이라 2개. 함정 — base가 `n`보다 크면 표기가 한 자리가 되어 자동으로 회문이 된다(한 글자는 항상 대칭). k가 크면 이런 "한 자리 회문"이 무더기로 세어질 수 있으니, 문제가 이를 포함하는지 배제하는지 정의를 못박고 카운트하자. (이 예제들은 k=5로 작아 한 자리 케이스가 없다.)

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

string DIGITS = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ";

string toBase(long long n, int b) {
    if (n == 0) return "0";
    string res = "";
    while (n > 0) {
        res = string(1, DIGITS[n % b]) + res;
        n /= b;
    }
    return res;
}

bool isPalindrome(const string& s) {
    string t(s.rbegin(), s.rend());
    return s == t;
}

int main() {
    long long n;
    int k;
    cin >> n >> k;
    int cnt = 0;
    for (int base = 2; base <= k; base++) {
        string s = toBase(n, base);
        if (isPalindrome(s)) cnt++;
    }
    cout << cnt << "\n";
    return 0;
}
@@TESTS
--IN
5 5
--OUT
2
--IN
15 5
--OUT
2
@@EXPL
(1) 접근·핵심 아이디어

- base 2부터 k까지 순회하며 각 진법으로 표기한 문자열을 만들고, 뒤집은 문자열과 같은지로 회문 여부를 판정해 개수를 센다.
- 한 자리 표기(base > n)는 자동으로 회문이지만, 예제는 k=5로 작아 그런 케이스가 없다.

(2) 코드 단계별

- `toBase(n, b)`: 나머지를 앞에 붙여 b진법 표기 문자열을 만든다(0은 `"0"`).
- `isPalindrome(s)`: `string t(s.rbegin(), s.rend())`로 뒤집은 문자열을 만들어 원본과 비교한다.
- `n k`를 읽고 `base`를 2..k로 돌며 표기 `s`를 구해 회문이면 카운트를 늘린다.
- 최종 카운트를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "각 진법 표기를 만들어 회문 검사" → base 루프 → toBase → 뒤집어 비교.
- 검산: 5 → 2진 `101`(O), 3진 `12`(X), 4진 `11`(O), 5진 `10`(X) = 2개.
```

## L3. 구간 칠하기

**개념**

- 구간 칠하기는 1차원 직선(또는 배열) 위에서 여러 개의 구간 `[a, b]`를 "칠하고", 그 결과로 몇 칸이 칠해졌는지·어디가 겹쳤는지·가장 많이 겹친 곳은 몇 겹인지 등을 세는 문제다. 시뮬레이션의 전형으로, "칠한다"는 행위를 배열에 직접 기록하는 것이 출발점이다.

- 가장 직관적인 방법은 "칸 배열(count array)"이다. 좌표 범위만큼 `vector<int>`를 잡고, 각 구간에 대해 `a`부터 `b`까지 `+1` 한다. 이 배열을 훑으면 칠해진 칸 수(값>0), 겹친 칸 수(값≥2), 최대 겹침(최댓값)을 한 번에 구할 수 있다.

```cpp
// 좌표가 1..L 정수 칸이고 구간이 [a,b] 포함일 때
int L = 10;
vector<int> cnt(L + 2, 0);
for (auto& iv : intervals) {
    int a = iv.first, b = iv.second;
    for (int x = a; x <= b; x++) cnt[x]++;   // a..b 칸을 모두 칠함
}

int painted = 0, overlap = 0, maxLayer = 0;
for (int x = 1; x <= L; x++) {
    if (cnt[x] > 0) painted++;                // 칠해진 칸
    if (cnt[x] >= 2) overlap++;               // 겹친 칸
    maxLayer = max(maxLayer, cnt[x]);         // 최대 겹침 두께
}
```

- 좌표가 매우 커서 칸 배열을 못 만들 땐 "이벤트 스위핑"을 쓴다. 각 구간을 시작 `+1`·끝 `-1` 이벤트로 바꿔 좌표순으로 정렬한 뒤, 훑어가며 현재 덮인 두께(`cover`)를 갱신하고 두께가 1 이상인 구간의 길이만 더한다.

```cpp
// 반열림 구간 [a, b) 들의 덮인 총 길이 (좌표가 커도 동작)
vector<pair<long long,int>> events;
for (auto& iv : intervals) {
    events.push_back({iv.first, +1});   // 구간 시작: 두께 +1
    events.push_back({iv.second, -1});  // 구간 끝:   두께 -1
}
sort(events.begin(), events.end());     // 좌표순 정렬(Ch3), 같은 좌표면 -1이 먼저

long long cover = 0, prev = 0, covered = 0;
bool started = false;
for (auto& e : events) {
    long long x = e.first;
    if (cover > 0 && started) covered += x - prev;  // 덮여 있던 구간 길이 누적
    cover += e.second;                               // 두께 갱신
    prev = x;
    started = true;
}
```

**접근 전략**

- 핵심 아이디어: "구간의 겹침을 직접 계산하려 하지 말고, 좌표 하나하나에 표시를 남긴 뒤 세라." 겹치는 경우를 경우의 수로 나누면 금방 복잡해지지만, 각 칸에 몇 번 칠해졌는지 누적해 두면 어떤 질문(총 넓이, 겹침, 두께)이든 배열을 한 번 훑어 답한다. 좌표가 작을 때(수천~수만) 가장 쉽고 확실하다.

- 좌표가 매우 크거나(예 10^9) "칸"이 아니라 연속 구간의 길이를 물으면, 칸 배열은 불가능하다. 이때는 "이벤트/스위핑"을 쓴다: 각 구간을 `(시작, +1)`, `(끝, -1)` 이벤트로 만들고 좌표순 정렬 후, 진행하며 덮인 두께(cover)가 1 이상인 구간의 길이를 누적한다. 반열림 구간 `[a, b)`로 다루면 경계 처리가 깔끔하다. C++의 `pair` 정렬은 같은 좌표에서 `-1`(끝)이 `+1`(시작)보다 먼저 오므로 맞닿는 경계가 이중 계산되지 않는다.

- 언제 쓰나: 칠하기/도로 포장/조명 커버리지/예약 시간 겹침. 주의점 — "포함 구간 `[a,b]`"인지 "반열림 `[a,b)`"인지에 따라 `+1` 범위와 길이 계산이 달라진다. 칸 배열 방식 복잡도는 O(구간수 × 평균길이) 또는 차이배열을 쓰면 O(구간수 + 좌표범위). 스위핑은 O(구간수 log 구간수). 좌표가 10^9까지 크면 `long long`을 쓴다.

> 선행: 정렬(Ch3)을 이벤트 정렬에 사용한다. 좌표를 키로 오름차순 정렬하면 된다.

**문제**

**1) 페인트 롤러** · Easy

- **요구사항**: 길이 `L`인 울타리의 칸은 1..L로 번호가 매겨진다. `n`번 페인트칠을 하며, 각 칠은 구간 `[a, b]`의 칸을 모두 칠한다. 마지막에 최소 한 번이라도 칠해진 칸의 개수를 출력하라.

- **입력**: 첫 줄 `L n`. 이어 `n`개 줄에 `a b` (1 ≤ a ≤ b ≤ L).

- **출력**: 칠해진 칸의 수 한 줄.

- **예제**: `10 3` / `1 3` / `2 5` / `7 8` → `7`

- **예제**: `5 2` / `1 5` / `2 4` → `5`

- **셀프체크**: 겹친 칸을 두 번 세지 않았는가? 칸 배열에서 `값>0`인 칸의 개수를 세면 자동으로 중복이 제거된다. 첫 예제는 칠해진 칸이 {1,2,3,4,5,7,8}=7개. `a==b`인 한 칸 칠도 정상 처리되는지 확인.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    int L, n;
    cin >> L >> n;

        int a, b;
        cin >> a >> b;
        for (int x = a; x <= b; x++) cnt[x]++;
    }
    int painted = 0;
    for (int x = 1; x <= L; x++) if (cnt[x] > 0) painted++;
    cout << painted << "\n";
    return 0;
}
@@TESTS

@@EXPL
(1) 접근·핵심 아이디어

- 겹침을 머리로 계산하지 말고 "칸 배열(count array)"에 직접 칠한 뒤 센다. 각 구간 `[a,b]`의 칸마다 `+1`을 하고, 마지막에 `값 > 0`인 칸의 개수를 세면 중복이 자동으로 제거된다.

(2) 코드 단계별

- `L n`을 읽고 `cnt`를 `L+2` 크기의 `vector<int>`로 0 초기화한다(1..L 인덱싱 여유).
- `n`개 구간마다 `a..b`를 순회하며 `cnt[x]++`.
- `1..L`에서 `cnt[x] > 0`인 칸의 수를 세어 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "칸에 표시 → 값>0을 센다" → 배열 초기화 → 구간마다 +1 → 조건 카운트.
- 검산: `1 3`,`2 5`,`7 8` → 칠해진 칸 {1,2,3,4,5,7,8} = 7.
```

**2) 겹친 층 세기** · Medium

- **요구사항**: 위와 같은 울타리에서 `n`번 칠한 뒤, "정확히 `k`번 칠해진 칸"의 개수를 출력하라.

- **입력**: 첫 줄 `L n k`. 이어 `n`개 줄에 `a b`.

- **출력**: 정확히 k번 칠해진 칸의 수 한 줄.

- **예제**: `10 3 2` / `1 3` / `2 5` / `7 8` → `2`

- **예제**: `10 3 1` / `1 3` / `2 5` / `7 8` → `5`

- **셀프체크**: "정확히 k"는 `값 == k`로 판정한다(≥k 아님). 첫 예제에서 각 칸 두께는 1:1, 2:2, 3:2, 4:1, 5:1, 6:0, 7:1, 8:1이라 정확히 2인 칸은 {2,3}=2개. k=0을 물으면 한 번도 안 칠해진 칸을 세는 것도 성립하는지 범위(1..L 전체)를 훑는지 확인.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    int L, n, k;
    cin >> L >> n >> k;
    vector<int> cnt(L + 2, 0);
    for (int i = 0; i < n; i++) {
        int a, b;
        cin >> a >> b;
        for (int x = a; x <= b; x++) cnt[x]++;
    }
    int result = 0;
    for (int x = 1; x <= L; x++) if (cnt[x] == k) result++;
    cout << result << "\n";
    return 0;
}
@@TESTS
--IN

1 3
2 5
7 8
--OUT
2
--IN
10 3 1
1 3
2 5
7 8
--OUT
5
@@EXPL
(1) 접근·핵심 아이디어

- L3-1과 같은 칸 배열을 만든 뒤, "정확히 k번 칠해진 칸"은 `값 == k`로 판정한다(`>= k`가 아님).

(2) 코드 단계별

- `L n k`를 읽고 `cnt`를 0으로 초기화.
- `n`개 구간마다 `a..b`에 `+1`.
- `1..L`에서 `cnt[x] == k`인 칸 수를 세어 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "칸에 두께를 쌓고 == k를 센다" → 배열 채우기 → 정확 일치 카운트.
- 검산: 두께가 1:1,2:2,3:2,4:1,5:1,6:0,7:1,8:1 → k=2인 칸은 {2,3} = 2; k=1인 칸은 {1,4,5,7,8} = 5.
```

**3) 전광판 커버리지** · Hard

- **요구사항**: 수직선 위에 `n`개의 조명 구간이 반열림 `[a, b)`로 주어진다(좌표가 최대 10^9까지 커서 칸 배열을 만들 수 없다). 최소 한 개의 조명이 비추는 구간들의 "총 길이"를 출력하라.

- **입력**: 첫 줄 `n`. 이어 `n`개 줄에 `a b` (0 ≤ a < b ≤ 10^9).

- **출력**: 덮인 총 길이(정수) 한 줄.

- **예제**: `3` / `1 4` / `2 6` / `8 10` → `7`

- **예제**: `2` / `0 5` / `5 10` → `10`

- **셀프체크**: 좌표가 크므로 반드시 이벤트 스위핑. `(a,+1),(b,-1)`을 좌표순 정렬하고, 이전 좌표에서 현재 좌표까지의 길이를 "그 구간의 덮임 두께가 1 이상일 때만" 더한다. 첫 예제는 [1,6)이 이어져 5, [8,10)이 2, 합 7. 둘째 예제처럼 `5`에서 맞닿는(겹치지 않는) 경계에서 길이를 이중으로 더하지 않는지가 함정 — `pair` 정렬에서 같은 좌표의 `-1`이 `+1`보다 먼저 처리되어 두께가 0으로 떨어지는 순간이 정확히 처리되는지 검증.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<pair<long long, int>> events;
    for (int i = 0; i < n; i++) {
        long long a, b;
        cin >> a >> b;
        events.push_back({a, 1});
        events.push_back({b, -1});
    }
    sort(events.begin(), events.end());
    long long cover = 0, prev = 0, covered = 0;
    bool started = false;
    for (auto& e : events) {
        long long x = e.first;
        int delta = e.second;
        if (cover > 0 && started) covered += x - prev;
        cover += delta;
        prev = x;
        started = true;
    }
    cout << covered << "\n";
    return 0;
}
@@TESTS

2 6
8 10
--OUT

--IN

--OUT

@@EXPL
(1) 접근·핵심 아이디어

- 좌표가 최대 10^9라 칸 배열은 불가능하므로 "이벤트 스위핑"을 쓴다. 각 반열림 구간 `[a,b)`를 시작 `+1`·끝 `-1` 이벤트로 바꿔 좌표순으로 정렬한다.
- 진행하며 현재 덮임 두께 `cover`를 유지하고, 두께가 1 이상인 구간의 길이만 누적한다.

(2) 코드 단계별

- 각 구간을 `{a, +1}`, `{b, -1}`로 만들어 `events`에 넣고 `sort`로 좌표순 정렬(`pair` 정렬은 같은 좌표면 `-1`이 `+1`보다 먼저 처리되어 맞닿는 경계가 이중 계산되지 않는다).
- 이벤트를 순회하며 `cover > 0`이면 이전 좌표 `prev`부터 현재 `x`까지 길이 `x - prev`를 `covered`에 더한다(`started`로 첫 이벤트 이전은 건너뛴다).
- 그 뒤 `cover += delta`로 두께를 갱신하고 `prev = x`.
- 좌표가 10^9까지 커지므로 `long long`으로 오버플로를 방지하고 `covered`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "구간을 이벤트로 → 정렬 → 훑으며 두께>0인 구간 길이 누적" → 길이 더하기는 두께 갱신 "전에" 하는 순서 주의.
- 검산: [1,4)+[2,6)이 이어져 [1,6)=5, [8,10)=2 → 7; [0,5)+[5,10)은 맞닿아 [0,10)=10(이중 계산 없음).
```

## L4. 사각형 칠하기

**개념**

- 사각형 칠하기는 L3을 2차원으로 올린 것이다. 격자(2D 배열) 위에서 여러 개의 축에 나란한 사각형 `(r1,c1)-(r2,c2)`를 칠하고, 칠해진 칸 수·겹친 칸 수·색이 마지막에 무엇인지 등을 센다. 화면 렌더링, 영역 도색, 지도 위 영역 표시의 축소판이다.

- 기본기는 "2차원 카운트 격자"다. `grid[r][c]`에 몇 번 칠해졌는지 누적한다. 사각형 하나를 칠하는 것은 이중 for로 `r1..r2`, `c1..c2`를 `+1` 하는 것이다. 색을 다루면 `+1` 대신 색 번호를 대입하는데, 이때는 "나중에 칠한 색이 이긴다(last wins)"는 순서가 중요해진다. C++에서는 `vector<vector<int>>`로 격자를 잡는다.

```cpp
// 행 1..N, 열 1..M. 사각형 (r1,c1)-(r2,c2) 포함 영역을 칠함
vector<vector<int>> grid(N + 1, vector<int>(M + 1, 0));
for (auto& rc : rects) {
    for (int r = rc.r1; r <= rc.r2; r++)
        for (int c = rc.c1; c <= rc.c2; c++)
            grid[r][c]++;                        // 칠한 횟수 누적
}

int painted = 0, overlap = 0;
for (int r = 1; r <= N; r++)
    for (int c = 1; c <= M; c++) {
        if (grid[r][c] > 0) painted++;
        if (grid[r][c] >= 2) overlap++;
    }
```

**접근 전략**

- 핵심 아이디어: L3과 똑같이 "겹침을 머리로 계산하지 말고 격자에 찍고 세라." 2차원이라 순회가 이중 for로 늘어날 뿐 원리는 같다. 총 칠해진 칸(값>0), 겹친 칸(값≥2), 특정 횟수 칸(값==k), 색별 칸 수 등 어떤 질문이든 격자를 한 번 훑으면 답한다.

- 색이 등장하면 "칠하는 순서"가 결과를 바꾼다. 뒤에 칠한 사각형이 앞의 것을 덮으므로 입력 순서대로 대입하면 자연히 last-wins가 된다. "가장 위에 보이는 색이 X인 칸 수"는 대입을 다 끝낸 뒤 격자에서 색별로 세면 된다. 겹침 넓이를 이론적으로 구하려면 두 사각형 교집합은 `[max(r1), min(r2)] × [max(c1), min(c2)]`이며 이 구간이 유효할 때만(시작≤끝) 존재한다 — 격자를 못 쓸 만큼 클 때 이 공식을 쓴다.

- 언제 쓰나: 도색/스티커/영역 겹침/화면 버퍼 시뮬레이션. 주의점 — 좌표 인덱스를 0-based로 줄지 1-based로 줄지 통일(여기선 1-based로 여유 칸 확보). 격자 크기 `N×M`이 수백~수천이면 이중 순회 O(사각형수 × 넓이)가 무난하지만, `N,M`이 매우 크면 2차원 차이배열(imos)로 O(사각형수 + N·M)로 줄인다. 색별 카운트는 `std::map<int,int>`를 쓰면 색 번호가 커도 되고, 순회 시 키가 오름차순이라 동점 타이브레이크가 쉽다.

> 선행: 2차원 배열(격자 순회, 행·열 인덱싱)은 이미 익힌 것으로 전제한다.

**문제**

**1) 도화지 칠하기** · Easy

- **요구사항**: `N×M` 도화지의 칸은 행 1..N, 열 1..M이다. `n`개의 사각형 `(r1,c1,r2,c2)`를 칠한다. 최소 한 번이라도 칠해진 칸의 개수를 출력하라.

- **입력**: 첫 줄 `N M n`. 이어 `n`개 줄에 `r1 c1 r2 c2` (1 ≤ r1 ≤ r2 ≤ N, 1 ≤ c1 ≤ c2 ≤ M).

- **출력**: 칠해진 칸의 수 한 줄.

- **예제**: `5 5 2` / `1 1 3 3` / `2 2 4 5` → `17`

- **예제**: `3 3 1` / `1 1 3 3` → `9`

- **셀프체크**: 겹친 칸을 한 번만 세는가(값>0 판정으로 자동 처리)? 첫 예제는 9칸 + 12칸 - 겹침 4칸 = 17. 사각형이 도화지 밖으로 나가지 않는다는 제약을 믿되, `r2,c2`까지 포함하는 범위(`r <= r2`, `c <= c2`)를 빠뜨리지 않았는지 확인.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    int N, M, n;
    cin >> N >> M >> n;
    vector<vector<int>> grid(N + 1, vector<int>(M + 1, 0));
    for (int i = 0; i < n; i++) {
        int r1, c1, r2, c2;
        cin >> r1 >> c1 >> r2 >> c2;
        for (int r = r1; r <= r2; r++)
            for (int c = c1; c <= c2; c++)
                grid[r][c]++;
    }
    int painted = 0;
    for (int r = 1; r <= N; r++)
        for (int c = 1; c <= M; c++)
            if (grid[r][c] > 0) painted++;
    cout << painted << "\n";
    return 0;
}
@@TESTS

@@EXPL
(1) 접근·핵심 아이디어

- L3의 1차원 칸 배열을 2차원 격자로 올린다. `grid[r][c]`에 칠한 횟수를 누적하고, 마지막에 `값 > 0`인 칸의 수를 세면 겹침이 자동으로 한 번만 세어진다.

(2) 코드 단계별

- `N M n`을 읽고 `(N+1) x (M+1)` 격자를 0으로 만든다(1-based 인덱싱).
- 사각형마다 `r1..r2`, `c1..c2`를 이중 for로 순회하며 `grid[r][c]++`.
- `1..N x 1..M` 전체에서 `grid[r][c] > 0`인 칸을 세어 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "격자에 찍고 값>0을 센다" → 격자 초기화 → 사각형마다 이중 for로 +1 → 조건 카운트.
- 검산: 9칸 + 12칸 - 겹친 4칸(행2..3 × 열2..3) = 17.
```

**2) 정확히 두 번 칠해진 칸** · Medium

- **요구사항**: 위와 같은 도화지에서 `n`개 사각형을 칠한 뒤, "정확히 2번 칠해진 칸"의 개수와 "가장 많이 겹친 칸의 겹침 횟수"를 공백으로 구분해 출력하라.

- **입력**: 첫 줄 `N M n`. 이어 `n`개 줄에 `r1 c1 r2 c2`.

- **출력**: `정확히2번칸수 최대겹침` 한 줄.

- **예제**: `5 5 2` / `1 1 3 3` / `2 2 4 5` → `4 2`

- **예제**: `4 4 3` / `1 1 2 2` / `2 2 3 3` / `1 1 4 4` → `6 3`

- **셀프체크**: 카운트 격자에서 `값==2`인 칸 수와 `max`를 동시에 구한다. 첫 예제의 겹침 영역은 행 2..3 × 열 2..3 = 4칸이고 그 두께는 2이므로 `4 2`. 둘째 예제는 세 번째 사각형(1,1,4,4)이 전체를 한 겹 더 덮으므로, (2,2) 칸은 세 사각형 모두에 들어가 두께 3이 되고, 정확히 2인 칸은 6개가 된다 — 격자를 직접 그려 검산하자.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    int N, M, n;
    cin >> N >> M >> n;
    vector<vector<int>> grid(N + 1, vector<int>(M + 1, 0));
    for (int i = 0; i < n; i++) {
        int r1, c1, r2, c2;
        cin >> r1 >> c1 >> r2 >> c2;
        for (int r = r1; r <= r2; r++)
            for (int c = c1; c <= c2; c++)
                grid[r][c]++;
    }
    int two = 0, mx = 0;
    for (int r = 1; r <= N; r++)
        for (int c = 1; c <= M; c++) {
            if (grid[r][c] == 2) two++;
            if (grid[r][c] > mx) mx = grid[r][c];
        }
    cout << two << " " << mx << "\n";
    return 0;
}

(1) 접근·핵심 아이디어

- 카운트 격자를 만든 뒤 한 번 훑으며 두 값을 동시에 구한다: `값 == 2`인 칸의 수(정확히 두 번), 그리고 격자의 최댓값(최대 겹침 두께).

(2) 코드 단계별

- `N M n`과 사각형들을 읽어 `grid[r][c]++`로 누적한다.
- `1..N x 1..M`을 순회하며 `grid[r][c] == 2`면 `two`를 늘리고, `grid[r][c] > mx`면 `mx`를 갱신한다.
- `two mx`를 공백으로 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "격자 채우기 → 한 번 훑으며 ==2 카운트와 max 동시 추적."
- 검산: 첫 예제는 겹침 4칸(행2..3 × 열2..3), 최대 두께 2 → `4 2`. 둘째 예제는 (1,1,4,4)가 전체를 덮어 (2,2)는 세 사각형 모두 포함(두께 3), 정확히 2인 칸이 6개 → `6 3`.
```

**3) 겹쳐 칠한 색** · Hard

- **요구사항**: `N×M` 도화지에 `n`개의 색칠 명령 `(r1,c1,r2,c2,color)`가 순서대로 주어진다. 나중 명령이 앞의 색을 덮는다. 모든 명령 후, 칠해진 색 중 "가장 많은 칸을 차지한 색"의 색 번호와 그 칸 수를 출력하라. (칠해지지 않은 칸은 세지 않는다.)

- **입력**: 첫 줄 `N M n`. 이어 `n`개 줄에 `r1 c1 r2 c2 color` (color는 1 이상의 정수).

- **출력**: `색번호 칸수` 한 줄. (동점이면 색 번호가 작은 것을 출력.)

- **예제**: `5 5 2` / `1 1 3 3 1` / `2 2 4 5 2` → `2 12`

- **예제**: `3 3 2` / `1 1 3 3 5` / `2 2 2 2 7` → `5 8`

- **셀프체크**: 누적(+1)이 아니라 "대입"이며 순서가 핵심이다 — 뒤 명령이 이긴다. 첫 예제에서 색2는 12칸(2..4행 × 2..5열)을 그대로 차지하고, 색1은 원래 9칸 중 겹친 4칸을 색2에 빼앗겨 5칸만 남는다. 따라서 최대는 색2의 12칸. 마지막에 색별로 칸을 센 뒤(0=미도색 제외) 최댓값을 고르되, 동점 시 색 번호가 작은 쪽을 선택하는 타이브레이크를 넣었는지 확인(`std::map`은 키가 오름차순이라 `>`로만 갱신하면 자동으로 작은 번호가 이긴다).

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    int N, M, n;
    cin >> N >> M >> n;
    vector<vector<int>> grid(N + 1, vector<int>(M + 1, 0));
    for (int i = 0; i < n; i++) {
        int r1, c1, r2, c2, color;
        cin >> r1 >> c1 >> r2 >> c2 >> color;
        for (int r = r1; r <= r2; r++)
            for (int c = c1; c <= c2; c++)
                grid[r][c] = color;
    }
    map<int, int> counts;
    for (int r = 1; r <= N; r++)
        for (int c = 1; c <= M; c++) {
            int col = grid[r][c];
            if (col != 0) counts[col]++;
        }
    int bestColor = -1, bestCnt = -1;
    for (auto& kv : counts) {
        if (kv.second > bestCnt) {
            bestCnt = kv.second;
            bestColor = kv.first;
        }
    }
    cout << bestColor << " " << bestCnt << "\n";
    return 0;
}

--IN

(1) 접근·핵심 아이디어

- 이번엔 누적(+1)이 아니라 색 번호를 "대입"한다. 입력 순서대로 대입하면 뒤 명령이 앞을 덮어 자연히 last-wins가 된다.
- 모든 명령 후 격자를 훑어 색별 칸 수를 세고(0=미도색 제외), 가장 많은 색을 고른다. 동점이면 색 번호가 작은 쪽.

(2) 코드 단계별

- 격자를 0으로 초기화하고, 명령마다 `r1..r2 x c1..c2`에 `grid[r][c] = color`를 대입한다.
- 격자를 순회하며 `col != 0`인 칸을 `map<int,int> counts`에 누적한다.
- `map`은 키(색 번호)가 오름차순으로 순회되므로, `counts[col] > bestCnt`일 때만 갱신하면 동점이면 먼저 나온(작은 번호) 색이 유지된다.
```
