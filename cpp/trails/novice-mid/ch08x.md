## L3. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch08(완전탐색 III)의 핵심 — "상황 하나를 가정하고 끝까지 진행해 검증하는" 완전탐색과 "탐색의 기준을 더 작은 축으로 새로 잡는" 완전탐색 — 을 **반복 훈련**하고, 시뮬레이션형 코딩테스트 단골 유형으로 **확장**하는 연습 세트다.
- **반복 훈련 개념**:
  - 시작값 가정 → 도미노 전개 → 검증: `for (int x = 1; x <= H; x++) { int cur = x; for (int v : d) { cur += v; if (범위 밖) break; } }`
  - 시작점·방향을 전부 시도한 뒤 시뮬레이션: `for (시작 칸) for (int dir = 0; dir < 4; dir++) { int x = sx, y = sy; while (진행 가능) { x += dx[dir]; y += dy[dir]; } }`
  - 첫 선택만 가정하면 나머지가 결정: `for (int first = 0; first < 2; first++) { ... for (int i = 1; i < N; i++) 앞칸 상태를 보고 강제 결정 }`
  - 기준 좌표·기준 값을 입력에서 뽑아 고정: `for (int i = 0; i < N; i++) { int x0 = xs[i]; ... 나머지는 세기만 }`
  - 기준을 "어떤 원소가 최솟값인가"로 바꾸기: `for (int i = 0; i < N; i++) 왼쪽·오른쪽으로 h[i] 이상인 동안 확장`
- **C++에서 특히 조심할 것**:
  - `s.size()`·`v.size()`는 **부호 없는 정수**다. `i < (int)s.size()`처럼 캐스팅하거나 `int n = s.size();`로 받아 두어야 `i >= 0` 비교가 안전하다. `0 <= i < n`을 파이썬처럼 이어 쓸 수 없으니 `i >= 0 && i < n`로 나눠 쓴다.
  - 배열 첨자는 범위를 넘겨도 예외가 나지 않는다. 파이썬의 `IndexError`가 없으므로 `while` 조건에서 **범위 검사를 벽 검사보다 먼저** 두는 습관이 곧 안전장치다.
  - `vector`는 **값 복사**다. `vector<int> cur = base;`는 새 배열을 만들지만, 파이썬의 `cur = base`는 같은 리스트를 가리킨다. "가정마다 상태를 새로 복사"하는 코드가 C++에서는 저절로 된다.
  - `map`은 키 정렬 순서로 순회하고 `unordered_map`은 순서 보장이 없다. 또 `unordered_map`은 `pair` 키를 그대로 못 쓴다(해시가 없어 **컴파일 에러**) — 좌표·방향을 키로 쓸 땐 `map`이 편하다.
- **코딩테스트 출제 맵**: 삼성 SW 역량테스트의 '시뮬레이션' 유형(격자 위 이동·회전), 백준 「단계별로 풀어보기」의 '브루트 포스' 단계, NeetCode 150의 'Greedy'(원형 주유소)에서 이 유형이 등장한다.

**문제**

**1) 차이 목록으로 수열 복원** · Easy

- **요구사항**: 길이 n인 수열이 있는데 첫 항만 모른다. 대신 이웃한 항의 차이 목록 d_1, ..., d_(n-1)이 주어진다(`a[i+1] = a[i] + d_i`). 모든 항이 **1 이상 H 이하**가 되도록 하는 **첫 항 a[1]의 후보 개수**를 구하라.
- **입력**: 첫 줄에 n과 H (2 ≤ n ≤ 100, 1 ≤ H ≤ 1000). 둘째 줄에 n-1개의 정수 d_i (각 |값| ≤ 100).
- **출력**: 조건을 만족하는 첫 항의 개수.
- **예제**: `4 10 / 3 -5 4` → `5` (첫 항 x면 수열은 x, x+3, x-2, x+2 → x는 3~7) · `3 5 / 10 -10` → `0`
- **셀프체크**: 차이의 부호가 섞여 있으면 수열이 단조가 아니므로 양 끝만 검사하면 틀린다 — 가정마다 항을 **끝까지 전개**하며 모든 항을 검사해야 한다. 도중에 범위를 벗어나면 즉시 `break`로 버린다. `break`는 **가장 안쪽 반복 하나만** 빠져나오므로, 실패 여부를 `bool ok`에 담아 바깥에서 다시 판단해야 한다. 차이가 전부 0이면 첫 항 1..H 전부가 답(넷째 테스트).

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, H;
    cin >> n >> H;
    vector<int> d(n - 1);
    for (int i = 0; i < n - 1; i++) cin >> d[i];

    int count = 0;
    for (int x = 1; x <= H; x++) {
        int cur = x;
        bool ok = true;
        for (int i = 0; i < n - 1; i++) {
            cur += d[i];
            if (cur < 1 || cur > H) {
                ok = false;
                break;
            }
        }
        if (ok) count++;
    }
    cout << count << '\n';
    return 0;
}
@@TESTS

(1) 접근·핵심 아이디어

- 첫 항 x 하나만 정하면 나머지 항은 차이 목록으로 도미노처럼 전부 정해진다. 그러니 가정할 미지수는 첫 항 하나이고, 후보는 1..H다.
- 앞 챕터의 등차수열과 달리 차이의 부호가 섞이므로 수열이 단조가 아니다. 양 끝만 봐서는 안 되고, 각 가정마다 실제로 항을 전개하며 모든 항이 1..H인지 검사한다.

(2) 코드 단계별

- `n`, `H`를 읽고 `vector<int> d(n - 1)`을 만들어 차이를 채운다. 크기를 미리 주면 `d[i]`로 바로 대입할 수 있다.
- `x`를 1..H로 가정하고 `int cur = x;`에서 출발해 `d[i]`를 차례로 더한다.
- 더할 때마다 `cur < 1 || cur > H`이면 이 가정은 실패이므로 `ok = false;` 후 `break`.
- 끝까지 살아남으면 `count++`. 마지막에 `count`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "하나만 정하면 나머지가 다 정해지는 값" → 첫 항. 후보 범위 1..H.
- 단조가 아니므로 항을 끝까지 전개해 전부 검사(O(H·n)).
- C++의 `break`는 안쪽 `for` 하나만 끊는다. 두 겹 반복에서 "실패했음"을 바깥으로 전달하려면 `bool ok` 같은 깃발이 필요하다.
- 값 범위: `cur`는 최대 1000 + 100·99 = 10900이라 `int`로 충분하다. 차이가 크거나 항이 많은 변형이라면 `long long`을 먼저 의심한다.
- 차이가 전부 0(답 H), 도저히 못 맞추는 경우(답 0)로 경계 검산.
```

**2) 복도 청소 로봇의 방향 고르기** · Easy

- **요구사항**: 일직선 복도가 문자열로 주어진다. `S`는 로봇의 시작 칸(정확히 하나), `D`는 먼지, `#`은 벽, `.`은 빈 칸이다. 로봇은 **왼쪽 또는 오른쪽 중 한 방향**을 골라 그 방향으로만 직진하며, 벽을 만나거나 복도 끝에 닿으면 멈춘다. 지나간 칸의 먼지를 모두 치울 때, 치울 수 있는 먼지 수의 **최댓값**을 구하라.
- **입력**: 한 줄에 복도 문자열 (길이 1 이상 100 이하, `S`·`D`·`#`·`.`로만 구성).
- **출력**: 치울 수 있는 먼지 수의 최댓값.
- **예제**: `D.D#S.DDD` → `3` (왼쪽은 바로 벽, 오른쪽으로 3개) · `DD.S.#DD` → `2` (오른쪽은 벽 너머 먼지를 못 치움)
- **셀프체크**: 방향 두 가지를 모두 가정해 각각 시뮬레이션하고 더 큰 쪽을 답으로 한다. C++에서는 `0 <= pos < n`을 한 줄로 못 쓰므로 `pos >= 0 && pos < n`으로 나눠 쓰고, **범위 검사를 벽 검사보다 먼저** 둬야 한다(`&&`는 왼쪽이 거짓이면 오른쪽을 아예 평가하지 않는 단축 평가라 `s[pos]` 접근이 막힌다). 길이는 `int n = s.size();`로 받아 `size_t`와 `int` 비교 경고를 피한다. `S`만 있거나 양쪽이 벽이면 0.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;
    int n = (int)s.size();

    int start = 0;
    for (int i = 0; i < n; i++) {
        if (s[i] == 'S') start = i;
    }

    int best = 0;
    for (int step = -1; step <= 1; step += 2) {
        int pos = start + step;
        int cnt = 0;
        while (pos >= 0 && pos < n && s[pos] != '#') {
            if (s[pos] == 'D') cnt++;
            pos += step;
        }
        if (cnt > best) best = cnt;
    }
    cout << best << '\n';
    return 0;
}
@@TESTS

--IN

--OUT

--IN

@@EXPL
(1) 접근·핵심 아이디어

- 답을 좌우하는 선택은 "어느 방향으로 갈 것인가" 하나뿐이고 경우는 왼쪽/오른쪽 둘이다. 각 방향을 가정한 뒤 규칙대로 끝까지 직진하는 시뮬레이션을 돌려 결과를 비교한다.
- 직진은 `pos`를 `step`(-1 또는 +1)만큼 반복해서 옮기는 것이며, 멈춤 조건은 "복도 밖" 또는 "벽"이다.

(2) 코드 단계별

- `cin >> s`로 문자열을 읽는다(공백이 없는 한 줄이라 `getline`이 필요 없다). 길이는 `int n = (int)s.size();`로 받아 둔다.
- `S`의 위치 `start`를 한 번 훑어 찾는다.
- `for (int step = -1; step <= 1; step += 2)`는 -1과 +1만 도는 관용구다. `pos = start + step`부터 `pos >= 0 && pos < n && s[pos] != '#'`인 동안 전진한다.
- 지나는 칸이 `'D'`면 `cnt++`. 문자 비교는 `'D'`처럼 **작은따옴표**를 쓴다 — C++에서 `"D"`는 문자열이라 `char`와 비교되지 않는다.
- 방향별 결과 중 큰 값을 `best`에 남겨 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "가정할 것" = 방향(2가지). 각 가정마다 시뮬레이션.
- `while` 조건은 `범위 → 내용` 순서. `&&`의 단축 평가 덕분에 이 순서만 지키면 잘못된 첨자 접근이 없다. 순서를 뒤집으면 C++은 오류를 내지 않고 **엉뚱한 메모리를 읽는다** — 파이썬처럼 예외가 나지 않으니 더 위험하다.
- 양쪽이 모두 벽이거나 시작 칸이 끝에 붙어 있는 경우(0)로 경계 검산.
```

**3) 가장 많은 점을 지나는 세로선** · Easy

- **요구사항**: 좌표평면 위 N개의 점이 주어진다. 세로선 `x = c` 하나를 그어 그 위에 놓이는 점의 개수를 **최대**로 만들고 싶다. 최대 개수를 만드는 c와 그 개수를 출력하라. 최대를 만드는 c가 여러 개면 **가장 작은 c**를 택한다.
- **입력**: 첫 줄에 N (1 ≤ N ≤ 200). 이어 N줄에 각 점의 x y (각 |값| ≤ 1000).
- **출력**: `c 개수`를 공백으로 구분해 한 줄에.
- **예제**: `5 / 1 2 / 3 4 / 1 7 / 3 1 / 3 3` → `3 3` · `4 / 2 0 / 5 0 / 2 9 / 5 9` → `2 2` (x=2와 x=5가 2개씩이라 작은 2)
- **셀프체크**: c의 후보는 실수 전체가 아니라 **점들의 x좌표뿐**이다(점이 없는 x에 선을 그으면 0개). 후보마다 같은 x를 가진 점을 세면 O(N^2). 동률일 때 더 작은 c로 바꾸는 조건을 빠뜨리지 않았는가? 파이썬은 `best_c = None`으로 "아직 없음"을 표현하지만 C++ `int`에는 그런 값이 없다 — `bestCnt = 0`으로 두면 첫 후보의 개수가 반드시 1 이상이라 무조건 갱신되므로 안전하다. N=1이면 그 점의 x와 1.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    vector<int> xs(N), ys(N);
    for (int i = 0; i < N; i++) cin >> xs[i] >> ys[i];

    int bestC = 0;
    int best = 0;
    for (int i = 0; i < N; i++) {
        int c = xs[i];
        int cnt = 0;
        for (int j = 0; j < N; j++) {
            if (xs[j] == c) cnt++;
        }
        if (cnt > best || (cnt == best && c < bestC)) {
            best = cnt;
            bestC = c;
        }
    }
    cout << bestC << ' ' << best << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- "어느 c에 선을 긋나"를 실수 전체에서 찾을 수는 없다. 하지만 점이 하나도 없는 c는 답이 될 수 없으므로, 기준 값 c의 후보를 **입력에 등장한 x좌표들**로 새로 잡으면 후보가 N개로 줄어든다.
- 각 후보 c를 고정하면 나머지는 "x가 c인 점 세기"라는 단순 계산이다.

(2) 코드 단계별

- `vector<int> xs(N), ys(N)`을 만들어 좌표를 읽는다(y는 이 문제에서 쓰이지 않지만 입력 형식대로 읽어야 스트림이 어긋나지 않는다).
- 각 점 i의 `xs[i]`를 후보 `c`로 고정하고, 모든 점 j에 대해 `xs[j] == c`인 개수 `cnt`를 센다.
- `cnt > best`이거나, `cnt == best`인데 `c`가 더 작으면 `best`, `bestC`를 갱신한다.
- `bestC << ' ' << best`로 한 줄에 출력한다. 파이썬 `print(a, b)`가 자동으로 넣어 주던 공백을 C++에서는 **직접 넣어야** 한다 — 빠뜨리면 `31`처럼 붙어 나온다.

(3) 스스로 다시 짤 때 생각 순서

- 탐색 축을 "실수 c"에서 "입력에 있는 x값"으로 갈아끼운다.
- 후보를 고정한 뒤 세기만 하면 됨 → O(N^2).
- 동률 규칙(가장 작은 c)을 갱신 조건에 명시한다. `bestCnt = 0` 초기값이 "아직 후보 없음" 역할을 대신하므로 별도의 깃발이 필요 없다.
- N=1과 음수 좌표로 검산.
```

**4) 원형 주유소 출발점 찾기** · Medium

- **요구사항**: 원형 도로에 1번부터 N번까지 주유소가 순서대로 있다. i번 주유소에서는 gas_i만큼 주유할 수 있고, i번에서 다음 주유소(N번 다음은 1번)까지 가는 데 cost_i만큼의 연료가 든다. 빈 탱크로 어떤 주유소에서 출발해 도착할 때마다 주유하며 **한 바퀴 돌아 출발점으로 돌아올 수 있는** 출발 주유소 번호 중 **가장 작은 것**을 구하라. 불가능하면 `-1`.
- **입력**: 첫 줄에 N (1 ≤ N ≤ 100). 둘째 줄에 N개의 gas_i, 셋째 줄에 N개의 cost_i (각 0 이상 1000 이하).
- **출력**: 가장 작은 출발 번호. 없으면 `-1`.
- **예제**: `5 / 1 2 3 4 5 / 3 4 5 1 2` → `4` · `3 / 2 3 4 / 3 4 3` → `-1`
- **셀프체크**: 출발점을 1..N으로 **하나씩 가정**하고, 각 가정에서 N칸을 진행하며 탱크가 음수가 되는 순간 실패로 버린다. 원형 인덱스는 `(start + step) % N`인데, C++의 `%`는 왼쪽이 음수면 **결과도 음수**다(파이썬은 항상 양수). 여기서는 `start`, `step`이 모두 0 이상이라 안전하지만, 반대 방향으로 도는 변형에서는 `(i % N + N) % N`이 필요하다. 오름차순으로 가정하다 첫 성공에서 멈추면 "가장 작은 번호"가 보장된다. N=1이면 gas ≥ cost인지만 보면 된다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    vector<int> gas(N), cost(N);
    for (int i = 0; i < N; i++) cin >> gas[i];
    for (int i = 0; i < N; i++) cin >> cost[i];

    int ans = -1;
    for (int start = 0; start < N; start++) {
        int tank = 0;
        bool ok = true;
        for (int step = 0; step < N; step++) {
            int i = (start + step) % N;
            tank += gas[i] - cost[i];
            if (tank < 0) {
                ok = false;
                break;
            }
        }
        if (ok) {
            ans = start + 1;
            break;
        }
    }
    cout << ans << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- 답을 좌우하는 미지수는 "어디서 출발하나" 하나다. 출발점을 정하면 나머지는 규칙대로 N칸을 진행하는 시뮬레이션으로 자동 결정된다.
- 그래서 출발점 N가지를 전부 가정하고, 각 가정마다 탱크를 0에서 시작해 주유·소비를 반복하며 음수가 되는지 검사한다. 전체 O(N^2)으로 N ≤ 100이면 충분하다.

(2) 코드 단계별

- N과 `gas`, `cost` 두 배열을 읽는다. 입력이 줄로 나뉘어 있어도 `cin >>`은 공백·줄바꿈을 똑같이 건너뛰므로 줄 구분을 신경 쓸 필요가 없다.
- `start`를 0..N-1로 가정한다. `tank = 0`에서 `step`을 0..N-1로 돌며 `i = (start + step) % N`번 주유소에서 `tank += gas[i] - cost[i]`.
- `tank < 0`이 되면 이 출발점은 실패(`ok = false`, `break`).
- N칸을 모두 통과하면 `ans = start + 1`로 두고 바깥 반복도 `break`. 오름차순 가정이므로 첫 성공이 최소 번호다.

(3) 스스로 다시 짤 때 생각 순서

- "가정할 것" = 출발점(N가지). 각 가정 = 한 바퀴 시뮬레이션.
- 원형 인덱스는 `% N`. C++의 `%`는 피연산자가 음수면 결과가 음수라는 점을 기억해 두고, 음수가 섞일 수 있으면 `(i % N + N) % N`으로 감싼다.
- `tank`는 최대 1000·100 = 10만이라 `int`면 충분하다. 값이 1e9급이라면 누적합에서 `long long`이 필요해진다.
- 가장 작은 번호가 필요하니 오름차순으로 훑다 첫 성공에서 멈춘다. 불가능(-1)·N=1 검산.
```

**5) 격자 직진 코인 줍기** · Medium

- **요구사항**: N×M 격자가 주어진다. `.`은 빈 칸, `#`은 벽, `C`는 코인이 놓인 칸이다. 로봇을 **벽이 아닌 아무 칸**에 놓고 **상·하·좌·우 중 한 방향**을 정하면, 로봇은 그 방향으로 벽이나 격자 밖에 닿을 때까지 직진하며 지나는 칸(시작 칸 포함)의 코인을 모두 줍는다. 시작 칸과 방향을 잘 골랐을 때 주울 수 있는 코인 수의 **최댓값**을 구하라.
- **입력**: 첫 줄에 N과 M (1 ≤ N, M ≤ 10). 이어 N줄에 길이 M의 문자열.
- **출력**: 코인 수의 최댓값. 놓을 수 있는 칸이 없으면 0.
- **예제**: `3 4 / C.C# / .#C. / CCCC` → `4` (셋째 행 왼쪽 끝에서 오른쪽으로) · `2 2 / ## / ##` → `0`
- **셀프체크**: 시작 칸(벽 제외) × 방향 4가지를 **전부** 시도한다. 격자는 `vector<string> g(N)`로 받으면 `g[r][c]`가 그대로 `char`가 된다. 직진은 `dx`/`dy` 배열로 `x += dx[d]`, `y += dy[d]`를 반복하고, 멈춤 조건은 "격자 밖" 또는 "벽" — 범위 검사를 먼저 해야 잘못된 첨자 접근이 없다. 시작 칸의 코인도 세야 한다(넷째 테스트: 대각선은 안 되므로 1).

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, M;
    cin >> N >> M;
    vector<string> g(N);
    for (int i = 0; i < N; i++) cin >> g[i];

    int dx[4] = {-1, 1, 0, 0};
    int dy[4] = {0, 0, -1, 1};

    int best = 0;
    for (int r = 0; r < N; r++) {
        for (int c = 0; c < M; c++) {
            if (g[r][c] == '#') continue;
            for (int d = 0; d < 4; d++) {
                int x = r, y = c;
                int cnt = 0;
                while (x >= 0 && x < N && y >= 0 && y < M && g[x][y] != '#') {
                    if (g[x][y] == 'C') cnt++;
                    x += dx[d];
                    y += dy[d];
                }
                if (cnt > best) best = cnt;
            }
        }
    }
    cout << best << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- 결과를 좌우하는 선택은 "시작 칸"과 "방향" 둘이지만, 둘 다 후보가 작다(칸 ≤ 100, 방향 4). 모든 (시작 칸, 방향) 조합을 가정하고 각각 직진 시뮬레이션을 돌려 최댓값을 취한다.
- 직진 시뮬레이션은 dx/dy 기법 그대로다. 현재 칸이 격자 안이고 벽이 아닌 동안 코인을 세고 한 칸 전진한다.

(2) 코드 단계별

- 격자는 `vector<string> g(N)`로 읽는다. `cin >> g[i]`는 공백 없는 한 줄을 통째로 담아 주고, `g[x][y]`로 문자에 바로 접근할 수 있다.
- 방향 배열은 `int dx[4] = {-1, 1, 0, 0};`처럼 고정 크기 배열로 두는 것이 가장 간단하다(상·하·좌·우).
- 벽이 아닌 칸 (r, c)마다, 방향 d마다 `x = r, y = c`에서 출발해 `while (범위 안 && 벽 아님)` 동안 코인이면 `cnt++`, 그다음 `x += dx[d]; y += dy[d];`.
- 각 시뮬레이션의 `cnt`로 `best`를 갱신하고 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "가정할 것" = 시작 칸 × 방향(4). 후보가 작으니 전부 시도.
- 한 가정의 처리 = dx/dy 직진 `while`. 조건은 `x >= 0 && x < N && y >= 0 && y < M && 벽 아님` 순서 — 네 개의 범위 검사를 먼저 통과해야 `g[x][y]`를 읽는다.
- `x`, `y`를 `while` 안이 아니라 **바깥에서 선언**해야 반복 후에도 값이 남는다. C++은 블록 안에서 선언한 변수가 블록을 벗어나면 사라진다.
- 시작 칸 코인 포함, 벽뿐인 격자(0), 1행 격자로 검산.
```

**6) K×K 정사각형 안의 점 최대** · Medium

- **요구사항**: 좌표평면 위 N개의 점이 있다. 한 변의 길이가 K인 정사각형(변이 축과 평행, 경계 포함)을 하나 놓아 **안에 들어오는 점의 개수를 최대**로 만들어라. 정사각형의 왼쪽 아래 꼭짓점 (x0, y0)은 **어떤 점의 x좌표**와 **어떤 점의 y좌표**(서로 다른 점이어도 됨)로 잡는 것으로 충분하다.
- **입력**: 첫 줄에 N과 K (1 ≤ N ≤ 100, 1 ≤ K ≤ 1000). 이어 N줄에 각 점의 x y (각 0 이상 1000 이하).
- **출력**: 정사각형 안에 들어오는 점 수의 최댓값.
- **예제**: `5 2 / 0 0 / 1 1 / 2 2 / 5 5 / 6 6` → `3` · `3 5 / 0 5 / 5 0 / 5 5` → `3` (x0는 첫째 점, y0는 둘째 점에서 가져와 (0,0)에 놓는다)
- **셀프체크**: 기준 좌표 후보를 "점들의 x좌표 × 점들의 y좌표"로 잡아야 한다 — x와 y를 같은 점에서만 가져오면 둘째 예제처럼 답을 놓친다. 파이썬의 `x0 <= x <= x0+K` 같은 **연쇄 비교는 C++에 없다**. `x0 <= xs[p] && xs[p] <= x0 + K`처럼 `&&`로 이어 써야 하며, 그냥 옮겨 쓰면 `(x0 <= x) <= x0+K`가 되어 0/1과 비교하는 엉뚱한 식이 된다(경고 없이 컴파일될 수도 있다). 점이 K보다 멀리 떨어져 있으면 답은 1(셋째 테스트).

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, K;
    cin >> N >> K;
    vector<int> xs(N), ys(N);
    for (int i = 0; i < N; i++) cin >> xs[i] >> ys[i];

    int best = 0;
    for (int i = 0; i < N; i++) {
        for (int j = 0; j < N; j++) {
            int x0 = xs[i];
            int y0 = ys[j];
            int cnt = 0;
            for (int p = 0; p < N; p++) {
                if (x0 <= xs[p] && xs[p] <= x0 + K &&
                    y0 <= ys[p] && ys[p] <= y0 + K) {
                    cnt++;
                }
            }
            if (cnt > best) best = cnt;
        }
    }
    cout << best << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- 정사각형을 놓을 수 있는 위치는 무한하지만, 답을 바꾸지 않고 정사각형을 왼쪽·아래로 밀면 왼쪽 변은 어떤 점의 x에, 아래 변은 어떤 점의 y에 닿는다. 그래서 **기준 좌표 후보를 (점들의 x) × (점들의 y)** 로 새로 잡으면 N^2개만 보면 된다.
- 기준을 고정하면 나머지는 "정사각형 안에 있는 점 세기"라는 단순 계산이다. 전체 O(N^3)으로 N ≤ 100이면 충분하다.

(2) 코드 단계별

- N, K와 각 점의 `xs`, `ys`를 읽는다.
- 모든 i, j에 대해 `x0 = xs[i]`, `y0 = ys[j]`를 정사각형의 왼쪽 아래 꼭짓점으로 고정한다.
- 모든 점 p에 대해 `x0 <= xs[p] && xs[p] <= x0 + K && y0 <= ys[p] && ys[p] <= y0 + K`이면 `cnt++`. 네 개의 부등식을 `&&`로 이어 붙인 것이 파이썬 연쇄 비교의 정확한 대응이다.
- `cnt`의 최댓값 `best`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "어디에 놓나"라는 무한한 축을 "점들의 x × 점들의 y"라는 유한한 기준으로 갈아끼운다.
- x와 y 후보는 서로 다른 점에서 가져와도 된다는 점을 놓치지 않는다(둘째 예제).
- 연쇄 비교 금지 — 부등식마다 `&&`. 좌표가 1e9급이면 `x0 + K`에서 `int` 오버플로가 날 수 있으니 그때는 `long long`으로 올린다.
- 경계 포함(≤)과 K가 작아 점 하나만 들어가는 경우(답 1)로 검산.
```

**7) 가장 넓은 직사각형: 최소 막대를 기준으로** · Medium

- **요구사항**: 너비 1인 막대 N개가 나란히 서 있고 높이가 주어진다. **연속한 막대들**을 골라 그 안에 완전히 들어가는 직사각형을 그리면, 넓이는 `(고른 구간의 최소 높이) × (구간 길이)`다. 만들 수 있는 직사각형 넓이의 **최댓값**을 구하라. 구간을 전부 나열하지 말고 "어떤 막대가 최솟값이 되는가"를 기준으로 생각해 보라.
- **입력**: 첫 줄에 N (1 ≤ N ≤ 200). 둘째 줄에 N개의 높이 (각 1 이상 1000 이하).
- **출력**: 직사각형 넓이의 최댓값.
- **예제**: `6 / 2 1 5 6 2 3` → `10` (높이 5·6 두 개로 5×2) · `3 / 4 4 4` → `12`
- **셀프체크**: 막대 i를 "구간의 최솟값"으로 고정하면, 그 구간은 i에서 왼쪽·오른쪽으로 **높이가 h[i] 이상인 동안** 최대한 넓힌 것이 가장 넓다. 같은 높이(`>=`)도 포함해 넓혀야 둘째 예제가 12가 된다. 확장 시 `l - 1 >= 0`, `r + 1 < N`처럼 인덱스 범위 검사를 `&&`의 **왼쪽**에 두었는가? N=1이면 그 막대 높이가 답. 높이·길이가 커지는 변형(높이 1e9, N 1e5)에서는 넓이가 `int`를 넘으므로 `long long`이 필요하다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    vector<int> h(N);
    for (int i = 0; i < N; i++) cin >> h[i];

    long long best = 0;
    for (int i = 0; i < N; i++) {
        int l = i;
        while (l - 1 >= 0 && h[l - 1] >= h[i]) l--;
        int r = i;
        while (r + 1 < N && h[r + 1] >= h[i]) r++;
        long long area = (long long)h[i] * (r - l + 1);
        if (area > best) best = area;
    }
    cout << best << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- 구간(시작, 끝)을 전부 나열하고 각 구간의 최솟값을 구하면 O(N^3)이다. 축을 바꾼다: 모든 직사각형은 "어떤 막대 하나가 최솟값 역할"을 하므로, **최솟값이 되는 막대 i**를 기준으로 잡으면 후보는 N개뿐이다.
- 막대 i가 최솟값이면 구간은 i에서 좌우로 `h >= h[i]`인 동안 최대한 넓혀야 가장 넓다. 그러면 넓이는 `h[i] × 길이`로 바로 나온다. 전체 O(N^2).

(2) 코드 단계별

- N과 높이 배열 `h`를 읽고 `long long best = 0;`으로 시작한다.
- 각 i에 대해 `l = i`에서 `l - 1 >= 0 && h[l - 1] >= h[i]`인 동안 왼쪽으로, `r = i`에서 `r + 1 < N && h[r + 1] >= h[i]`인 동안 오른쪽으로 넓힌다. 범위 검사가 앞에 있어야 `h[-1]`을 읽지 않는다.
- `area = (long long)h[i] * (r - l + 1)`. **곱하기 전에** 한쪽을 `long long`으로 캐스팅하는 것이 핵심이다 — `(long long)(h[i] * (r-l+1))`처럼 곱한 뒤 캐스팅하면 이미 `int`에서 넘쳐 버린 값을 옮기는 셈이라 소용없다.
- `best`를 갱신하고 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "구간 쌍"이 아니라 "최솟값이 되는 막대"를 축으로 삼는다.
- 기준을 고정하면 좌우 확장은 `while` 두 개. 각 `while`의 첫 조건은 항상 인덱스 범위.
- 넓이는 곱이므로 자릿수가 두 배가 된다. 습관적으로 `long long`과 곱셈 전 캐스팅을 챙긴다.
- 같은 높이 포함(`>=`), N=1, 단조 감소 배열로 검산.
```

**8) 램프 전부 켜기: 첫 스위치만 가정** · Hard

- **요구사항**: 일렬로 놓인 N개의 램프 상태가 0(꺼짐)/1(켜짐) 문자열로 주어진다. i번 스위치(1 ≤ i ≤ N)를 누르면 **i-1, i, i+1번 램프**의 상태가 뒤집힌다(범위 밖은 무시). 스위치를 눌러 **모든 램프를 켜는 최소 누름 횟수**를 구하라. 불가능하면 `-1`. (같은 스위치를 두 번 누르는 것은 의미가 없다.)
- **입력**: 한 줄에 램프 상태 문자열 (길이 1 이상 100 이하, `0`과 `1`로만 구성).
- **출력**: 최소 누름 횟수. 불가능하면 `-1`.
- **예제**: `1001` → `4` · `0000` → `2` (1번과 4번 스위치)
- **셀프체크**: 1번 스위치를 누를지 말지 **두 가지만 가정**하면, 그다음부터는 "i-1번 램프가 꺼져 있으면 i번 스위치를 반드시 눌러야 한다"는 규칙으로 나머지 선택이 도미노처럼 강제된다(i번 램프 왼쪽을 고칠 수 있는 마지막 스위치가 i번이므로). 끝까지 진행한 뒤 **마지막 램프**가 켜져 있는지로 성공을 판정한다. 가정마다 상태 배열을 새로 만들어야 하는데, C++의 `vector`는 대입이 곧 **값 복사**라 `for` 안에서 새로 선언하기만 하면 자동으로 분리된다(파이썬에서 `state = base`로 쓰면 같은 리스트를 가리켜 섞인다). 문자 → 숫자 변환은 `s[i] - '0'`. 두 가정 모두 실패하면 `-1`, 이미 전부 켜져 있으면 0(셋째 테스트).

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;
    int N = (int)s.size();

    int best = -1;
    for (int first = 0; first < 2; first++) {
        vector<int> state(N);
        for (int i = 0; i < N; i++) state[i] = s[i] - '0';

        int presses = 0;
        if (first == 1) {
            presses = 1;
            for (int k = 0; k <= 1; k++) {
                if (k < N) state[k] = 1 - state[k];
            }
        }
        for (int i = 1; i < N; i++) {
            if (state[i - 1] == 0) {
                presses++;
                for (int k = i - 1; k <= i + 1; k++) {
                    if (k < N) state[k] = 1 - state[k];
                }
            }
        }
        if (state[N - 1] == 1) {
            if (best == -1 || presses < best) best = presses;
        }
    }
    cout << best << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- 스위치 N개를 누를지 말지 전부 가정하면 2^N이라 너무 많다. 그런데 **1번 스위치만 가정**하면 나머지는 자동으로 정해진다: i번 스위치를 정할 차례에 i-1번 램프가 꺼져 있다면, 그 램프를 뒤집을 수 있는 스위치는 이제 i번뿐이므로 반드시 눌러야 하고, 켜져 있다면 누르면 안 된다.
- 즉 가정은 2가지(1번을 누른다/안 누른다)뿐이고, 각 가정을 왼쪽에서 오른쪽으로 전개한 뒤 마지막 램프가 켜져 있는지로 검증한다. 두 가정 중 성공한 것들의 최소 횟수가 답이다.

(2) 코드 단계별

- `for (int first = 0; first < 2; first++)` 안에서 `vector<int> state(N)`을 **매번 새로 선언**하고 `s[i] - '0'`으로 채운다. C++ 컨테이너는 값 의미론이라 이 선언 하나로 가정 사이의 간섭이 끊긴다.
- `first == 1`이면 1번 스위치를 눌러 램프 0, 1번(0부터 셈)을 뒤집고 `presses = 1`.
- i를 1..N-1로 돌며 `state[i-1] == 0`이면 i번 스위치를 눌러 `i-1, i, i+1`을 뒤집고(`k < N` 검사) `presses++`. `i-1`은 항상 0 이상이라 아래쪽 검사는 필요 없다.
- 전개가 끝난 뒤 `state[N-1] == 1`이면 성공 — `best`를 더 작은 값으로 갱신. 두 가정 모두 실패면 `best`는 `-1` 그대로.
- 뒤집기는 `state[k] = 1 - state[k]`. `state[k] ^= 1`(XOR)도 같은 뜻인데, `^`는 비교 연산자보다 **우선순위가 낮으므로** `if (state[k] ^ 1 == 0)`처럼 쓰면 `1 == 0`이 먼저 계산된다. 비트 연산은 괄호로 감싸는 습관을 들인다.

(3) 스스로 다시 짤 때 생각 순서

- "하나만 정하면 나머지가 강제되는 선택"을 찾는다 → 1번 스위치.
- 가정 2개 × 왼쪽부터 강제 전개 O(N) → 전체 O(N).
- 마지막 램프로 성공 판정. 상태 배열은 가정마다 새로 선언(C++은 값 복사라 저절로 분리), 길이 1·이미 전부 켜짐 검산.
```

**9) 구슬 굴리기: 막히면 오른쪽으로** · Hard

- **요구사항**: N×M 격자(`.` 빈 칸, `#` 벽)에 구슬을 **빈 칸 아무 곳**에 놓고 **상·우·하·좌 중 한 방향**으로 굴린다. 구슬은 한 번에 한 칸씩, 최대 K번 이동한다. 이동 규칙: 현재 방향의 다음 칸이 격자 안의 빈 칸이면 그 칸으로 이동(이동 1회 소모). 아니면 **시계 방향으로 90도 회전**(상→우→하→좌→상)하며, 회전은 이동 횟수를 소모하지 않는다. 한 칸에서 네 방향 모두 막혀 4번 연속 회전하면 그 자리에서 멈춘다. 시작 칸과 방향을 잘 골랐을 때, 구슬이 **지나간 서로 다른 칸의 수**(시작 칸 포함)의 최댓값을 구하라.
- **입력**: 첫 줄에 N, M, K (1 ≤ N, M ≤ 8, 0 ≤ K ≤ 50). 이어 N줄에 길이 M의 문자열.
- **출력**: 서로 다른 방문 칸 수의 최댓값. 빈 칸이 없으면 0.
- **예제**: `3 3 5 / ... / .#. / ...` → `6` · `1 4 10 / ....` → `4` (왕복하지만 서로 다른 칸은 4개)
- **셀프체크**: 시작 칸 × 방향 4가지를 전부 시도하고, 각 시도마다 **방문 배열을 새로** 만든다. C++에서는 `vector<vector<bool>> visited(N, vector<bool>(M, false));`를 반복문 안에서 선언하면 매번 새로 0으로 채워진다(선언을 밖으로 빼면 이전 시도의 흔적이 남는다). 종료 조건은 "이동 K회 소모" 또는 "연속 회전 4회"이며, 이동에 성공하면 연속 회전 횟수를 0으로 되돌려야 한다. 되돌아온 칸은 다시 세지 않는다. K=0이면 답은 1(셋째 테스트).

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, M, K;
    cin >> N >> M >> K;
    vector<string> g(N);
    for (int i = 0; i < N; i++) cin >> g[i];

    int dx[4] = {-1, 0, 1, 0};
    int dy[4] = {0, 1, 0, -1};

    int best = 0;
    for (int sr = 0; sr < N; sr++) {
        for (int sc = 0; sc < M; sc++) {
            if (g[sr][sc] == '#') continue;
            for (int sd = 0; sd < 4; sd++) {
                vector<vector<bool>> visited(N, vector<bool>(M, false));
                int x = sr, y = sc, d = sd;
                visited[x][y] = true;
                int cnt = 1;
                int moves = 0;
                int turns = 0;
                while (moves < K && turns < 4) {
                    int nx = x + dx[d];
                    int ny = y + dy[d];
                    if (nx >= 0 && nx < N && ny >= 0 && ny < M && g[nx][ny] == '.') {
                        x = nx;
                        y = ny;
                        moves++;
                        turns = 0;
                        if (!visited[x][y]) {
                            visited[x][y] = true;
                            cnt++;
                        }
                    } else {
                        d = (d + 1) % 4;
                        turns++;
                    }
                }
                if (cnt > best) best = cnt;
            }
        }
    }
    cout << best << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- 결과를 좌우하는 것은 "시작 칸"과 "시작 방향"인데 후보가 작다(칸 ≤ 64, 방향 4). 모든 조합을 가정하고 규칙대로 K번 이동하는 시뮬레이션을 돌려 최댓값을 취하는 삼성 스타일 문제의 축소판이다.
- 시뮬레이션의 핵심은 규칙을 정확히 옮기는 것이다: 다음 칸이 갈 수 있으면 이동(이동 횟수 +1, 연속 회전 0으로 초기화), 아니면 시계 방향 회전(연속 회전 +1). 종료는 이동 K회 또는 연속 회전 4회.

(2) 코드 단계별

- 방향 배열을 시계 방향 순서(상·우·하·좌)로 두면 오른쪽 회전이 `d = (d + 1) % 4` 한 줄이 된다.
- 빈 칸마다, 방향마다 `vector<vector<bool>> visited(N, vector<bool>(M, false));`를 **반복문 안에서** 선언한다. 생성자가 매번 전체를 `false`로 채우므로 따로 초기화 코드가 필요 없다. 밖에서 한 번 만들고 재사용하려면 `assign(N, vector<bool>(M, false))`으로 명시적으로 지워야 한다.
- `moves < K && turns < 4`인 동안: 다음 칸이 격자 안의 `'.'`이면 이동하고 `moves++`, `turns = 0`, 새 칸이면 `cnt++`. 아니면 회전하고 `turns++`.
- 각 시도의 `cnt`로 `best`를 갱신해 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "가정할 것" = 시작 칸 × 방향. 각 가정 = 규칙 시뮬레이션.
- 방향 배열을 회전 순서대로 두면 회전이 `(d+1) % 4` 한 줄.
- 이동 성공 시 연속 회전 리셋. 방문 배열은 시도마다 새로 — C++에서는 "반복문 안 선언"이 곧 초기화다.
- `vector<vector<bool>>`은 비트로 압축 저장되는 특수화라 `visited[x][y]`가 진짜 `bool&`를 돌려주지 않는다. 참조로 받아 쓰려는 코드(`bool& v = visited[x][y];`)는 컴파일되지 않으니, 값으로 읽고 값으로 쓰거나 `vector<vector<char>>`를 쓴다.
- K=0(답 1)·전부 벽(답 0)으로 검산.
```

**10) 한 직선 위에 놓인 점의 최대 개수** · Hard

- **요구사항**: 좌표평면 위 서로 다른 N개의 점이 주어진다. 한 직선 위에 놓이는 점의 개수의 **최댓값**을 구하라. 모든 점 쌍으로 직선을 만들지 말고, **기준점 하나를 고정**한 뒤 다른 점들을 "기준점에서 본 방향"으로 묶어 세는 방식으로 풀라.
- **입력**: 첫 줄에 N (1 ≤ N ≤ 100). 이어 N줄에 각 점의 x y (각 |값| ≤ 1000, 모든 점은 서로 다름).
- **출력**: 한 직선 위에 놓이는 점 수의 최댓값 (N=1이면 1).
- **예제**: `5 / 0 0 / 1 1 / 2 2 / 3 1 / 4 0` → `3` · `4 / 0 0 / 0 5 / 0 9 / 3 3` → `3` (세로선 x=0)
- **셀프체크**: 기준점 i에서 점 j로의 방향 (dx, dy)는 최대공약수로 나눠 기약 형태로 만들어야 (2,4)와 (1,2)가 같은 방향으로 묶인다. 또 기준점 양쪽에 있는 점은 (1,1)과 (-1,-1)처럼 부호만 다르므로 **부호를 통일**(dx>0, 또는 dx=0이면 dy>0)해야 같은 직선으로 묶인다(셋째 테스트). 방향을 세는 그릇은 `map<pair<int,int>, int>`가 알맞다 — `unordered_map`은 `pair` 키의 해시가 없어 **컴파일 자체가 안 된다**. 세로선은 dx=0이라 나눗셈 없이 처리되는지 확인. 최댓값은 "같은 방향 점 수 + 기준점 1".

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int gcdOf(int a, int b) {
    while (b != 0) {
        int t = a % b;
        a = b;
        b = t;
    }
    return a;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    vector<int> xs(N), ys(N);
    for (int i = 0; i < N; i++) cin >> xs[i] >> ys[i];

    int best = 1;
    for (int i = 0; i < N; i++) {
        map<pair<int, int>, int> count;
        for (int j = 0; j < N; j++) {
            if (j == i) continue;
            int dx = xs[j] - xs[i];
            int dy = ys[j] - ys[i];
            int g = gcdOf(abs(dx), abs(dy));
            dx /= g;
            dy /= g;
            if (dx < 0 || (dx == 0 && dy < 0)) {
                dx = -dx;
                dy = -dy;
            }
            pair<int, int> key(dx, dy);
            count[key]++;
            if (count[key] + 1 > best) best = count[key] + 1;
        }
    }
    cout << best << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- "어느 두 점이 직선을 만드나"를 축으로 잡고 나머지 점의 일직선 여부를 검사하면 O(N^3)이다. 축을 **기준점 하나**로 바꾸면, 기준점을 지나는 직선은 "기준점에서 본 방향"으로 구별되므로, 다른 점들을 방향별로 묶어 세기만 하면 된다. 전체 O(N^2 log N).
- 방향 (dx, dy)는 최대공약수로 나눠 기약 형태로 만들고(같은 직선 위의 점은 배율만 다르다), 기준점 양쪽 점이 (1,1)·(-1,-1)로 갈리지 않도록 부호를 통일한다. 한 방향의 점 수 + 1(기준점)이 그 직선 위의 점 수다.

(2) 코드 단계별

- 유클리드 호제법으로 `gcdOf`를 직접 만든다(C++17이면 `<numeric>`의 `std::gcd`도 쓸 수 있다). **음수를 넘기면 안 되므로** `abs(dx)`, `abs(dy)`를 넘긴다 — C++의 `%`는 음수 피연산자에서 음수를 돌려줘 호제법이 어그러진다.
- 기준점 i마다 `map<pair<int,int>, int> count;`를 새로 만든다. `pair`는 `<` 연산자가 정의돼 있어 `map`의 키로 바로 쓸 수 있다.
- 다른 점 j에 대해 `(dx, dy)`를 구해 `g`로 나눈다. `g`가 dx·dy를 정확히 나누므로 `int` 나눗셈의 **0 방향 절삭**(파이썬의 `//`는 내림)이 문제 되지 않는다. 나머지가 있는 나눗셈이었다면 `-7 / 2`가 C++에서는 -3, 파이썬에서는 -4로 갈린다.
- `dx < 0 || (dx == 0 && dy < 0)`이면 부호를 뒤집어 통일한 뒤 `count[key]++`.
- `count[key] + 1`로 `best`를 갱신한다. `best`는 1에서 시작하므로 N=1도 처리된다.

(3) 스스로 다시 짤 때 생각 순서

- 축을 "점 쌍"에서 "기준점 + 방향"으로 갈아끼운다.
- 방향 정규화 = gcd로 나누기 + 부호 통일. 둘 중 하나라도 빠지면 같은 직선이 갈라진다.
- `map`의 `[]`는 **없는 키를 조용히 만들어 0으로 채운다**. 파이썬 `dict`가 `KeyError`를 던지는 것과 정반대라, `count[key]++`가 곧 `count.get(key, 0) + 1`이다. 편리하지만 "있는지 확인만 하려고" `if (count[key])`라고 쓰면 그 순간 키가 생겨 원소 수가 늘어난다 — 존재 확인은 `count.count(key)`나 `count.find(key) != count.end()`로 한다.
- 세로선(dx=0), 기준점 양쪽에 점이 있는 경우, N=1로 검산.
```
