## L3. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch07(완전탐색 II)의 핵심 — "물체를 고르는" 완전탐색과 "정답 값을 직접 대입하는" 완전탐색 — 을 **반복 훈련**하고, 코딩테스트 단골 유형으로 **확장**하는 연습 세트다.
- **반복 훈련 개념**:
  - 하나 빼기: N개 중 하나를 제외한 나머지를 평가 — `for (int skip = 0; skip < N; skip++) { ... if (i != skip) ... }`
  - 둘 고르기: 서로 다른 두 위치 `i<j`의 모든 쌍 — `for (int i = 0; i < N; i++) for (int j = i + 1; j < N; j++)`
  - 셋 고르기: 삼중 중첩 for로 모든 세 개 조합 — `for (int k = j + 1; k < N; k++)`
  - 부분집합(비트마스크): 2^N개 조합 — `for (int mask = 0; mask < (1 << N); mask++) { if (mask & (1 << i)) ... }`
  - 값 기준 완전탐색: 답이 될 값 v를 [lo, hi]에서 훑으며 판정 — `for (int v = lo; v <= hi; v++) if (check(v)) ans = v;`
- **C++ 비트 연산 주의**:
  - **`&`는 `==`·`!=`보다 우선순위가 낮다.** `mask & 1 == 0`은 `mask & (1 == 0)` 즉 `mask & 0`으로 묶여 항상 0이다. 파이썬과 정반대이니 `(mask & 1) == 0`처럼 **괄호 필수**.
  - 켜진 비트 수는 직접 세지 말고 `__builtin_popcount(mask)`(64비트는 `__builtin_popcountll`).
  - `1 << n`은 n이 31 이상이면 `int`가 넘친다 → `1LL << n`. 이때 검사식도 `mask & (1LL << i)`로 함께 바꿔야 한다.
  - C++엔 `itertools`가 없다. 조합은 중첩 for나 비트마스크로, 순열이 필요하면 `next_permutation(v.begin(), v.end())`를 쓴다 — **정렬된 상태에서 시작해야** 모든 순열이 나온다.
- **코딩테스트 출제 맵**: 백준 「단계별로 풀어보기」의 '브루트 포스' 단계, 프로그래머스 「코딩테스트 고득점 Kit」의 '완전탐색', 『이것이 취업을 위한 코딩테스트다』의 '구현' 파트에서 이 유형이 그대로 등장한다.
- **문제 구성표**:

**문제**

**1) 한 장을 빼면 합이 딱 맞는다** · Easy

- **요구사항**: N장의 카드에 정수가 적혀 있다. 정확히 **한 장을 빼서** 남은 카드 합이 T가 되게 하려 한다. 빼야 하는 카드의 번호(1부터 시작)를 구하라. 가능한 카드가 여러 장이면 **가장 작은 번호**, 불가능하면 `-1`.
- **입력**: 첫 줄에 N과 T (1 ≤ N ≤ 100, |T| ≤ 10^6). 둘째 줄에 N개의 정수 (각 |값| ≤ 10^4).
- **출력**: 빼야 하는 카드 번호. 없으면 `-1`.
- **예제**: `5 10 / 1 2 3 4 5` → `5` (전체 15에서 5를 빼면 10) · `4 6 / 2 2 2 2` → `1` (아무 장이나 되지만 가장 작은 번호)
- **셀프체크**: 매번 N-1개를 다시 더하지 말고 `전체합 - a[skip]`으로 O(1)에 판정하는가? 조건을 만족하는 첫 번호에서 `break`하면 "가장 작은 번호"가 자동으로 보장된다. N=1이면 한 장을 빼고 남은 합은 0이다. 전체 합은 최대 100 × 10^4 = 10^6이라 `int`로 충분하다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, T;
    cin >> N >> T;
    vector<int> a(N);
    int total = 0;
    for (int i = 0; i < N; i++) {
        cin >> a[i];
        total += a[i];
    }

    int ans = -1;
    for (int skip = 0; skip < N; skip++) {
        if (total - a[skip] == T) {
            ans = skip + 1;
            break;
        }
    }
    cout << ans << '\n';
    return 0;
}
@@TESTS
--IN
5 10
1 2 3 4 5
--OUT
5
--IN
4 6
2 2 2 2
--OUT
1
--IN
3 100
1 2 3
--OUT
-1
--IN
1 0
7
--OUT
1
@@EXPL
(1) 접근·핵심 아이디어

- "하나를 뺀다"는 N가지 경우뿐이다. 빼는 카드 `skip`을 0부터 N-1까지 하나씩 가정하고, 그때 남는 합이 T인지 검사하는 물체 단위 완전탐색이다.
- 남는 합은 매번 다시 더할 필요 없이 `total - a[skip]`으로 즉시 계산된다. 이렇게 하면 전체 O(N)이다.

(2) 코드 단계별

- N, T와 카드 배열 `a`를 읽으면서 `total`도 함께 누적한다(입력 루프 한 번으로 끝난다).
- `skip`을 0..N-1로 돌며 `total - a[skip] == T`이면 `ans = skip + 1`(1부터 시작하는 번호)로 두고 `break`한다.
- 앞에서부터 훑다가 처음 만족하는 곳에서 멈추므로 자동으로 가장 작은 번호가 된다. 끝까지 없으면 `ans`는 `-1` 그대로.

(3) 스스로 다시 짤 때 생각 순서

- "빼는 카드 하나"가 완전탐색의 대상 → 후보 N개.
- 각 후보의 평가는 `total - a[skip]` 한 번의 뺄셈.
- 가장 작은 번호가 필요하면 오름차순으로 훑다 첫 성공에서 멈추고, 실패 시 `-1`을 잊지 않는다. N=1(남는 합 0)도 자연스럽게 처리되는지 확인.
- C++ 함정: `total`을 선언만 하고 `= 0`을 빠뜨리면 지역 변수는 쓰레기 값에서 시작한다. 파이썬에는 없는 실수이고, 컴파일러는 경고만 줄 뿐 막아 주지 않는다.
- 값 범위가 커지면(예: N이 10^5, 값이 10^9) `total`이 `int`를 넘긴다. 누적 변수는 항상 "개수 × 최댓값"을 먼저 계산해 자료형을 고른다.
```

**2) 곱이 정확히 K인 카드 쌍** · Easy

- **요구사항**: N개의 양의 정수가 적힌 카드가 있다. **서로 다른 두 장(위치 기준)** 을 골라 두 수의 곱이 정확히 K가 되는 **쌍의 개수**를 구하라. 같은 값이 여러 장이면 각각 다른 카드로 센다.
- **입력**: 첫 줄에 N과 K (2 ≤ N ≤ 200, 1 ≤ K ≤ 10^6). 둘째 줄에 N개의 정수 (각 1 이상 1000 이하).
- **출력**: 곱이 K인 쌍의 개수.
- **예제**: `5 12 / 3 4 2 6 12` → `2` (3×4, 2×6) · `4 4 / 2 2 2 1` → `3` (2가 세 장이라 2×2 쌍이 3개)
- **셀프체크**: `j`를 `i + 1`부터 돌려 (i, j)와 (j, i)를 두 번 세지 않았는가? 같은 카드를 두 번 쓰는 (i, i)는 제외해야 한다. 값이 같은 카드도 위치가 다르면 서로 다른 쌍이다. 곱은 최대 1000 × 1000 = 10^6이라 `int`로 안전하다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, K;
    cin >> N >> K;
    vector<int> a(N);
    for (int i = 0; i < N; i++) cin >> a[i];

    int cnt = 0;
    for (int i = 0; i < N; i++) {
        for (int j = i + 1; j < N; j++) {
            if (a[i] * a[j] == K) cnt++;
        }
    }
    cout << cnt << '\n';
    return 0;
}
@@TESTS
--IN
5 12
3 4 2 6 12
--OUT
2
--IN
4 4
2 2 2 1
--OUT
3
--IN
2 5
1 1
--OUT
0
--IN
3 1
1 1 1
--OUT
3
@@EXPL
(1) 접근·핵심 아이디어

- 두 장을 고르는 모든 방법은 N(N-1)/2가지뿐이다. 중첩 for로 i<j인 모든 쌍을 나열하고 곱이 K인지 검사하는 "둘 고르기" 완전탐색이다.
- 곱은 순서가 없으므로 (i, j)와 (j, i)는 같은 쌍이다. 안쪽 반복을 `i + 1`부터 시작하면 중복 없이 한 번씩만 본다.

(2) 코드 단계별

- N, K와 배열 `a`를 읽는다.
- 바깥 `i`는 0..N-1, 안쪽 `j`는 `i + 1`..N-1로 돌며 `a[i] * a[j] == K`이면 `cnt`를 1 올린다.
- 마지막에 `cnt`를 출력한다. N=2이면 쌍이 하나뿐이고, 곱이 K가 아니면 0이다.

(3) 스스로 다시 짤 때 생각 순서

- "서로 다른 두 장" → 위치 쌍 (i, j), i<j.
- 안쪽 반복 시작을 `i + 1`로 두어 중복·자기 자신 제거.
- 값이 같아도 위치가 다르면 별개 쌍임을 기억한다(둘째 예제의 3개).
- C++ 함정: `a[i] * a[j]`는 `int × int = int`로 계산된다. 값이 10^5씩만 되어도 곱이 10^10이라 `int`를 넘겨 음수가 되고, `== K`가 조용히 거짓이 된다. 그럴 땐 `(long long)a[i] * a[j]`처럼 **곱하기 전에** 한쪽을 넓혀야 한다. `(long long)(a[i] * a[j])`는 이미 넘친 뒤라 소용없다.
```

**3) M개 이상을 나누는 가장 큰 수** · Easy

- **요구사항**: N개의 양의 정수가 있다. 정수 v(1 이상)를 고르면 "v의 배수"인 원소들이 v로 나누어떨어진다. 나누어떨어지는 원소가 **M개 이상**이 되는 v 중 **가장 큰 값**을 구하라. (v=1은 항상 모든 원소를 나누므로 답은 반드시 존재한다.)
- **입력**: 첫 줄에 N과 M (1 ≤ M ≤ N ≤ 100). 둘째 줄에 N개의 정수 (각 1 이상 1000 이하).
- **출력**: 조건을 만족하는 가장 큰 v.
- **예제**: `5 3 / 12 18 6 9 7` → `6` (v=6이면 12, 18, 6의 3개) · `4 2 / 5 7 11 13` → `1`
- **셀프체크**: v의 후보 범위를 1..`*max_element(a.begin(), a.end())`로 잡았는가(그보다 큰 v는 아무것도 못 나눈다)? 조건은 "M개 **이상**"이라 등호를 포함해야 한다. M=N이면 답은 모든 수의 최대공약수와 같아진다(넷째 테스트).

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, M;
    cin >> N >> M;
    vector<int> a(N);
    for (int i = 0; i < N; i++) cin >> a[i];

    int hi = *max_element(a.begin(), a.end());
    int ans = 1;
    for (int v = 1; v <= hi; v++) {
        int cnt = 0;
        for (int i = 0; i < N; i++) {
            if (a[i] % v == 0) cnt++;
        }
        if (cnt >= M) ans = v;
    }
    cout << ans << '\n';
    return 0;
}
@@TESTS
--IN
5 3
12 18 6 9 7
--OUT
6
--IN
4 2
5 7 11 13
--OUT
1
--IN
1 1
20
--OUT
20
--IN
3 3
8 12 20
--OUT
4
@@EXPL
(1) 접근·핵심 아이디어

- 답은 조합이 아니라 "하나의 값 v"다. v가 정해지면 배열을 한 번 훑어 배수 개수를 세는 것으로 판정이 끝나므로, 값 기준 완전탐색이 맞는다.
- v의 후보는 1부터 배열의 최댓값까지면 충분하다. 최댓값보다 큰 v는 어떤 원소도 나누지 못한다.

(2) 코드 단계별

- N, M과 배열 `a`를 읽고 `hi = *max_element(a.begin(), a.end())`로 상한을 잡는다(`max_element`는 **반복자**를 돌려주므로 앞에 `*`를 붙여 값을 꺼낸다).
- `ans = 1`로 시작한다(v=1은 항상 조건을 만족).
- `v`를 1..hi로 훑으며 `a[i] % v == 0`인 원소 수 `cnt`를 센다.
- `cnt >= M`이면 `ans = v`로 덮어쓴다. 오름차순으로 훑으므로 마지막에 남는 값이 조건을 만족하는 최대 v다.

(3) 스스로 다시 짤 때 생각 순서

- "답 = 값 하나(v)"임을 알아채고 후보 범위 [1, max]를 정한다.
- 판정 함수: v의 배수 개수 ≥ M (등호 포함).
- 최대를 원하니 오름차순으로 훑으며 만족할 때마다 덮어쓴다. M=N이면 최대공약수가 나오는지로 검산.
- C++ 함정 ①: `v`가 0이 되면 `% v`에서 0으로 나눠 프로그램이 즉시 죽는다. 후보를 1부터 시작하는 것이 문법이 아니라 **안전** 문제이기도 하다.
- C++ 함정 ②: 값에 음수가 섞이면 `%`의 결과도 음수가 될 수 있다(`-7 % 3 == -1`, 파이썬은 2). 여기서는 전부 양수라 안전하지만, 나머지로 판정할 때는 음수 입력 가능성을 항상 확인한다.
- `max_element`를 쓰지 않고 직접 최댓값 루프를 돌려도 된다. 다만 초기값을 0이 아니라 `a[0]`으로 두는 습관이 안전하다.
```

**4) 세 상자 무게 한도 맞추기** · Medium

- **요구사항**: N개의 상자 무게가 주어진다. **정확히 3개**를 골라 무게 합이 한도 W **이하**이면서 **최대**가 되게 하라. 그 최대 합과, 그 합을 만드는 **조합의 개수**(위치가 다르면 다른 조합)를 함께 출력한다. 세 개를 골라 W 이하가 되는 방법이 하나도 없으면 `-1`만 출력한다.
- **입력**: 첫 줄에 N과 W (3 ≤ N ≤ 30, 1 ≤ W ≤ 10^5). 둘째 줄에 N개의 무게 (각 1 이상 10^4 이하).
- **출력**: `최대합 조합수`를 공백으로 구분해 한 줄에. 불가능하면 `-1`.
- **예제**: `5 20 / 5 6 7 8 9` → `20 2` (5+6+9, 5+7+8) · `4 10 / 4 4 4 4` → `-1`
- **셀프체크**: 삼중 for의 시작을 `j = i+1`, `k = j+1`로 두어 같은 상자를 두 번 쓰거나 순서만 다른 조합을 중복 세지 않았는가? "더 큰 합"을 찾으면 개수를 1로 **리셋**하고, "같은 합"이면 개수만 올려야 한다. 같은 무게의 상자 여러 개는 위치별로 다른 조합이다(셋째 테스트: 4가 네 개면 4+4+4 조합이 4가지).

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, W;
    cin >> N >> W;
    vector<int> w(N);
    for (int i = 0; i < N; i++) cin >> w[i];

    int best = -1;
    int ways = 0;
    for (int i = 0; i < N; i++) {
        for (int j = i + 1; j < N; j++) {
            for (int k = j + 1; k < N; k++) {
                int s = w[i] + w[j] + w[k];
                if (s > W) continue;
                if (s > best) {
                    best = s;
                    ways = 1;
                } else if (s == best) {
                    ways++;
                }
            }
        }
    }

    if (best == -1) {
        cout << -1 << '\n';
    } else {
        cout << best << ' ' << ways << '\n';
    }
    return 0;
}

(1) 접근·핵심 아이디어

- 세 개를 고르는 조합은 N(N-1)(N-2)/6개로, N ≤ 30이면 4060개뿐이다. 삼중 for로 i<j<k인 모든 조합을 나열하는 "셋 고르기" 완전탐색이다.
- 제약(합 ≤ W)으로 거른 뒤, 목표(합 최대)를 갱신하되 "최댓값을 만드는 조합의 개수"도 함께 관리한다. 최댓값이 바뀌면 개수를 1로 리셋, 같으면 1을 더한다.

(2) 코드 단계별

- N, W와 무게 배열 `w`를 읽고 `best = -1`, `ways = 0`으로 시작한다.
- `i < j < k` 삼중 반복으로 세 상자 합 `s`를 만든다. `s > W`면 `continue`로 버린다.
- `s > best`면 새 최댓값이므로 `best = s; ways = 1;`. `s == best`면 `ways++`.
- 끝까지 `best`가 -1이면 조합이 없었던 것이므로 `-1`, 아니면 `best ways`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "정확히 3개" → 삼중 for, 각 반복의 시작을 앞 인덱스 +1로.
- 제약과 목표를 분리: 한도 초과는 스킵, 통과한 것 중 최대 갱신.
- 최대와 개수를 함께 갱신할 때 "리셋 vs 증가" 두 갈래를 정확히 나눈다. 전부 초과하는 경우의 `-1` 처리도 잊지 않는다.
- C++ 함정 ①: `if / else if`의 순서가 곧 논리다. `else if`를 그냥 `if`로 쓰면 `s > best`로 리셋한 직후 같은 반복에서 `s == best`가 참이 되어 `ways`가 2로 늘어난다.
- C++ 함정 ②: 출력이 두 갈래(`-1` 한 개 / 값 두 개)라 형식이 다르다. 한 곳에서 `cout`을 두 번 나눠 쓰면 공백·줄바꿈이 어긋나기 쉬우니, 분기마다 완결된 한 줄을 찍는다.
- 합은 최대 3 × 10^4로 `int` 안이다. 상자 수나 무게 상한이 커지면 `long long`을 검토한다.
```

**5) 하나를 빼서 오름차순 만들기** · Medium

- **요구사항**: 길이 N의 수열이 있다. **정확히 한 원소를 제거**해서 남은 수열이 **순증가**(각 원소가 바로 앞 원소보다 큼)가 되게 하려 한다. 제거했을 때 조건을 만족하는 **위치의 개수**를 구하라.
- **입력**: 첫 줄에 N (2 ≤ N ≤ 200). 둘째 줄에 N개의 정수 (각 |값| ≤ 10^4).
- **출력**: 조건을 만족하는 제거 위치의 개수.
- **예제**: `5 / 1 3 2 4 5` → `2` (3을 빼거나 2를 빼면 됨) · `4 / 1 2 3 4` → `4` (어느 것을 빼도 순증가)
- **셀프체크**: 판정은 "순증가"이므로 같은 값이 이어지면 실패다(`>=`로 검사). 이미 순증가인 수열은 어느 원소를 빼도 만족하므로 답이 N이 된다. N=2이면 하나를 빼고 남는 원소가 1개뿐이라 항상 순증가 → 답 2(넷째 테스트, 값이 같아도). 남은 수열을 새 `vector`에 모아 판정하면 코드가 가장 단순하다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    vector<int> a(N);
    for (int i = 0; i < N; i++) cin >> a[i];

    int cnt = 0;
    for (int skip = 0; skip < N; skip++) {
        vector<int> b;
        for (int i = 0; i < N; i++) {
            if (i != skip) b.push_back(a[i]);
        }
        bool ok = true;
        for (int i = 1; i < (int)b.size(); i++) {
            if (b[i - 1] >= b[i]) {
                ok = false;
                break;
            }
        }
        if (ok) cnt++;
    }
    cout << cnt << '\n';
    return 0;
}
@@TESTS

--OUT

--IN

--OUT

--IN
5

--OUT

--IN

--OUT

@@EXPL
(1) 접근·핵심 아이디어

- 제거할 위치 `skip`은 N가지뿐이다. 각 가정마다 그 원소를 뺀 새 수열 `b`를 만들고, 인접한 원소가 모두 `앞 < 뒤`인지 한 번 훑어 판정하는 "하나 빼기 + 판정 함수" 완전탐색이다.
- 전체 비용은 N(가정) × N(판정) = O(N^2)으로, N ≤ 200이면 충분하다.

(2) 코드 단계별

- N과 수열 `a`를 읽고 `cnt = 0`으로 시작한다.
- `skip`을 0..N-1로 돌며, `vector<int> b;`를 **루프 안에서 새로** 만들고 `i != skip`인 원소만 `push_back`한다.
- `b`의 인접쌍을 검사해 `b[i-1] >= b[i]`가 하나라도 있으면 `ok = false`로 실패 처리한다.
- 실패 없이 끝나면 `cnt++`. 마지막에 `cnt`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "정확히 하나 제거" → 제거 위치가 완전탐색 대상, 후보 N개.
- 각 후보의 판정은 "순증가인가?" — 인접쌍 전부 `<`, 같으면 실패.
- 이미 정렬된 수열(답 N), 완전 역순(답 0), 길이 2(항상 답 2) 같은 경계로 검산한다.
- C++ 함정 ①: `b`를 루프 **밖**에 선언하면 앞 가정의 원소가 남아 계속 쌓인다. 밖에 두려면 매 가정마다 `b.clear()`를 호출해야 한다. 파이썬에서 `b = []`로 새로 만드는 것과 같은 뜻이다.
- C++ 함정 ②: `b.size()`는 부호 없는 `size_t`다. `i < (int)b.size()`로 캐스팅하거나 `i < b.size()`에서 `i`도 부호 없는 타입으로 맞춘다. 특히 `b.size() - 1`은 `b`가 비었을 때 0이 아니라 거대한 수가 된다.
- N=2일 때 `b`의 길이는 1이라 판정 루프가 한 번도 돌지 않고 자동 통과한다 — 이것이 넷째 테스트의 답 2다.
```

**6) 두 선수 시너지 최대** · Medium

- **요구사항**: N명의 선수가 있고 각 선수는 공격력 a와 수비력 b를 가진다. **서로 다른 두 명**을 골라 팀을 만들면 시너지는 `(첫째 공격력 × 둘째 수비력) + (둘째 공격력 × 첫째 수비력)`이다. 가능한 두 명 조합 중 시너지의 **최댓값**을 구하라.
- **입력**: 첫 줄에 N (2 ≤ N ≤ 100). 이어 N줄에 각 선수의 a와 b (각 0 이상 100 이하).
- **출력**: 시너지의 최댓값.
- **예제**: `3 / 1 5 / 4 2 / 3 3` → `22` (1번·2번: 1×2 + 4×5) · `2 / 0 0 / 5 5` → `0`
- **셀프체크**: 시너지 식은 두 사람을 바꿔도 같은 값이므로 `i<j`만 보면 된다. 최댓값 초기값을 0으로 두면 모든 값이 0인 경우와 구별이 안 되니, C++엔 `None`이 없으므로 `INT_MIN`(또는 첫 쌍의 값)으로 시작해 첫 쌍에서 반드시 갱신되게 한다. 두 속성(a, b)은 각각 `vector<int>` 두 개로 받거나 `vector<pair<int,int>>` 하나로 받는다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    vector<int> a(N), b(N);
    for (int i = 0; i < N; i++) cin >> a[i] >> b[i];

    int best = INT_MIN;
    for (int i = 0; i < N; i++) {
        for (int j = i + 1; j < N; j++) {
            int s = a[i] * b[j] + a[j] * b[i];
            if (s > best) best = s;
        }
    }
    cout << best << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- 두 명을 고르는 조합 N(N-1)/2개를 전부 나열하고 각 조합의 시너지를 계산하는 "둘 고르기" 완전탐색이다. N ≤ 100이면 약 5000쌍으로 충분히 빠르다.
- 시너지 식 `a[i]*b[j] + a[j]*b[i]`는 i와 j를 바꿔도 값이 같으므로 i<j인 쌍만 보면 중복 없이 전부 본 것이다.

(2) 코드 단계별

- N을 읽고, 이어지는 N줄에서 `cin >> a[i] >> b[i]`로 두 값을 한 번에 받는다(`cin`은 공백과 줄바꿈을 똑같이 구분자로 본다 — 줄 단위로 나눠 읽을 필요가 없다).
- `best = INT_MIN`으로 시작해, `i < j` 이중 반복에서 시너지 `s`를 계산한다.
- `s > best`면 `best = s`로 갱신한다. 첫 쌍에서 반드시 값이 들어가므로 전부 0인 경우도 0이 정확히 출력된다.
- `best`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "서로 다른 두 명" → 위치 쌍 (i, j), i<j.
- 각 쌍의 평가식을 문제 그대로 옮긴다(교차 곱의 합).
- 최댓값 초기값은 `INT_MIN`(또는 첫 쌍 값)으로 두어 0·음수 상황에서도 안전하게.
- C++ 함정 ①: 파이썬의 `None` 대신 쓰는 `INT_MIN`은 `<climits>`에 있고 `bits/stdc++.h`에 포함되어 있다. 다만 `INT_MIN`에서 무언가를 빼면 곧바로 오버플로이므로, 감시값은 비교에만 쓴다.
- C++ 함정 ②: 값이 0 이상 100이라 곱의 합이 최대 2만이지만, 속성 값이 10^5씩만 되어도 `a[i]*b[j]`가 `int`를 넘긴다. 곱셈이 들어가면 자료형 범위를 먼저 점검한다.
- `vector<int> a(N), b(N);`처럼 한 줄에 두 벡터를 선언할 수 있다. 크기 인자는 각각 따로 붙여야 한다.
```

**7) 화분 물 배급 상한 정하기** · Medium

- **요구사항**: N개의 화분이 각각 r_i만큼의 물을 원한다. 물탱크에는 B만큼의 물이 있다. **상한 v**(0 이상 정수)를 정하면 각 화분에는 `min(r_i, v)`만큼 준다. 준 물의 총량이 **B 이하**가 되는 v 중 **가장 큰 값**을 구하라. 단, v가 모든 요구량 이상이면 결과는 같으므로 답은 `max(r_i)`를 넘지 않는 것으로 한다.
- **입력**: 첫 줄에 N과 B (1 ≤ N ≤ 100, 0 ≤ B ≤ 10^5). 둘째 줄에 N개의 요구량 (각 1 이상 1000 이하).
- **출력**: 총량 ≤ B를 만족하는 가장 큰 상한 v.
- **예제**: `4 30 / 20 5 15 10` → `8` (v=8: 8+5+8+8=29 ≤ 30, v=9: 32 초과) · `3 100 / 10 20 30` → `30` (전부 다 줘도 60 ≤ 100)
- **셀프체크**: 각 화분의 기여는 `min(r[i], v)`다 — `<algorithm>`의 `min`은 두 인자의 **타입이 같아야** 하므로 `min(r[i], v)`처럼 둘 다 `int`로 맞췄는가? v의 후보는 0..max(r)이며, B=0이면 v=0만 가능(셋째 테스트). v를 올릴수록 총량은 줄지 않으므로 "만족하는 가장 큰 v"를 오름차순 덮어쓰기로 찾을 수 있다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, B;
    cin >> N >> B;
    vector<int> r(N);
    for (int i = 0; i < N; i++) cin >> r[i];

    int hi = *max_element(r.begin(), r.end());
    int ans = 0;
    for (int v = 0; v <= hi; v++) {
        int total = 0;
        for (int i = 0; i < N; i++) {
            total += min(r[i], v);
        }
        if (total <= B) ans = v;
    }
    cout << ans << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- 답은 "상한 v"라는 하나의 정수 값이다. v를 정하면 총량은 `sum(min(r_i, v))`로 단순 계산되므로, 후보 v를 0부터 max(r)까지 직접 대입하는 값 기준 완전탐색이 맞는다.
- v가 커질수록 총량은 단조 증가(줄지 않음)한다. 따라서 "총량 ≤ B"를 만족하는 v는 앞쪽에 몰려 있고, 그중 가장 큰 값이 답이다. 이 단조성은 나중에 이분탐색으로 v 범위를 줄일 때의 발판이 된다.

(2) 코드 단계별

- N, B와 요구량 배열 `r`을 읽고 `hi = *max_element(...)`로 후보 상한을 잡는다.
- `ans = 0`으로 시작한다(v=0은 총량 0이라 항상 만족).
- `v`를 0..hi로 훑으며, 각 화분에 `min(r[i], v)`를 더해 `total`을 만든다.
- `total <= B`이면 `ans = v`로 덮어쓴다. 오름차순이므로 마지막 덮어쓴 값이 최대 v.
- `ans`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "답 = 상한 값 하나"를 알아채고 후보 범위 [0, max(r)]를 잡는다.
- 판정: `sum(min(r_i, v)) <= B` — 요구량을 넘겨 주지 않도록 `min` 절단.
- 만족하는 최대 v를 오름차순 덮어쓰기로 찾고, B=0·전부 다 줄 수 있는 경우를 경계로 검산.
- C++ 함정 ①: `std::min`은 템플릿이라 **두 인자의 타입이 같아야** 한다. `min(r[i], (long long)v)`처럼 한쪽만 넓히면 "no matching function" 컴파일 오류가 난다. `min<long long>(r[i], v)`처럼 타입을 명시하거나 둘 다 같은 타입으로 맞춘다.
- C++ 함정 ②: `total`은 최대 100 × 1000 = 10^5로 `int` 안이지만, 화분 수나 요구량이 커지면 넘친다. 누적 변수는 늘 "개수 × 최댓값"을 계산해 본다.
- C++ 함정 ③: 후보 v는 0부터 시작해야 한다. 1부터 돌면 B=0인 셋째 테스트에서 `ans`가 초기값 그대로 남아 우연히 맞지만, 초기값을 -1로 바꾸는 순간 틀린다.
```

**8) 서로 싫어하는 쌍 없이 최대 초대** · Hard

- **요구사항**: 1번부터 N번까지 N명의 친구가 있고, 서로 싫어하는 M쌍이 주어진다. 파티에 초대할 사람들을 고르되, **싫어하는 두 사람을 동시에 초대할 수 없다**. 초대할 수 있는 **최대 인원**과, 그 인원을 달성하는 **초대 집합의 개수**를 구하라.
- **입력**: 첫 줄에 N과 M (1 ≤ N ≤ 12, 0 ≤ M ≤ 30). 이어 M줄에 서로 싫어하는 두 사람의 번호 x y (x ≠ y, 같은 쌍은 한 번만 주어진다).
- **출력**: `최대인원 집합수`를 공백으로 구분해 한 줄에.
- **예제**: `4 2 / 1 2 / 3 4` → `2 4` ({1,3}, {1,4}, {2,3}, {2,4}) · `5 2 / 1 5 / 2 3` → `3 4`
- **셀프체크**: 부분집합(mask)마다 M쌍을 전부 검사해 "둘 다 켜진 쌍"이 하나라도 있으면 버려야 한다. 검사는 `(mask & (1 << x)) && (mask & (1 << y))` — `&`가 `&&`·비교보다 우선순위가 낮으므로 **각 항에 괄호**를 친다. 인원 수는 `__builtin_popcount(mask)`. 최대 인원이 갱신되면 집합 수를 1로 리셋하고, 같으면 1을 더한다. M=0이면 전원 초대가 유일한 답(넷째 테스트). 모두가 서로 싫어하면 1명씩 N가지(셋째 테스트).

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, M;
    cin >> N >> M;
    vector<int> px(M), py(M);
    for (int i = 0; i < M; i++) {
        int x, y;
        cin >> x >> y;
        px[i] = x - 1;
        py[i] = y - 1;
    }

    int best = 0;
    int ways = 0;
    for (int mask = 0; mask < (1 << N); mask++) {
        bool ok = true;
        for (int i = 0; i < M; i++) {
            if ((mask & (1 << px[i])) != 0 && (mask & (1 << py[i])) != 0) {
                ok = false;
                break;
            }
        }
        if (!ok) continue;

        int size = __builtin_popcount(mask);
        if (size > best) {
            best = size;
            ways = 1;
        } else if (size == best) {
            ways++;
        }
    }
    cout << best << ' ' << ways << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- "각 사람을 초대한다/안 한다"는 부분집합 선택이므로 비트마스크로 2^N개를 전부 나열한다. N ≤ 12면 4096개뿐이다.
- 각 mask에 대해 (a) 제약 검사: 싫어하는 쌍 (x, y)의 두 비트가 모두 켜져 있으면 무효, (b) 통과한 mask의 인원(켜진 비트 수)으로 최대 인원과 그 개수를 갱신한다. 세 요소(부분집합 나열·제약 검사·최대와 개수 동시 갱신)가 결합된 문제다.

(2) 코드 단계별

- N, M을 읽고 싫어하는 쌍을 0부터 시작하는 번호로 `px`, `py`에 담는다(입력이 1-based이므로 `-1`).
- `mask`를 0..2^N-1로 돌며, 모든 쌍에 대해 두 비트가 동시에 켜졌는지 검사해 하나라도 걸리면 `ok = false`.
- 통과한 mask는 `__builtin_popcount(mask)`로 인원 `size`를 구하고, `size > best`면 `best = size; ways = 1;`, `size == best`면 `ways++`.
- `best ways`를 출력한다. mask=0(아무도 초대 안 함)도 후보에 들어가지만, 1명짜리 집합이 항상 유효하므로 최종 best는 1 이상이다.

(3) 스스로 다시 짤 때 생각 순서

- "초대한다/안 한다" → 부분집합 → 비트마스크 순회.
- 제약은 "쌍의 두 비트가 동시에 켜짐"이 없어야 함 — 쌍 목록을 한 번씩 검사.
- 최대와 개수를 함께 갱신할 때 "리셋 vs 증가"를 구분하고, M=0(전원)·완전 충돌(1명씩)로 검산한다.
- **C++ 함정(핵심)**: `mask & (1 << x) != 0`이라고 쓰면 `!=`가 먼저 묶여 `mask & 1`이 된다. `&`는 비교 연산자보다 **우선순위가 낮다** — 파이썬과 정반대다. `(mask & (1 << x)) != 0`처럼 괄호를 치거나, 조건에 그대로 `if (mask & (1 << x))`로 쓴다.
- C++ 함정 ②: `__builtin_popcount`는 `unsigned int`(32비트)용이다. 64비트 마스크는 `__builtin_popcountll`을 써야 한다. GCC·Clang 확장이라 다른 컴파일러에서는 `bitset<32>(mask).count()`로 대체한다.
- C++ 함정 ③: 변수 이름 `size`는 `using namespace std;` 아래에서 `std::size`(C++17)와 이름이 겹칠 수 있다. 여기서는 지역 변수가 이겨 문제없지만, 헷갈리면 `sz`처럼 바꾼다.
- N이 커져 31을 넘으면 `1 << N`이 `int`를 넘긴다. 그때는 `mask`를 `long long`으로 두고 `1LL << N`, 검사식도 `1LL << x`로 함께 바꿔야 한다.
```

**9) 우표로 만들 수 없는 최소 요금** · Hard

- **요구사항**: N장의 우표가 있고 각 우표의 액면가가 주어진다. 우표를 **골라 붙여**(각 우표는 최대 한 번, 하나도 안 붙이면 요금 0) 만들 수 있는 요금이 있다. 우표 조합으로 **만들 수 없는 가장 작은 양의 정수 요금**을 구하라.
- **입력**: 첫 줄에 N (1 ≤ N ≤ 12). 둘째 줄에 N개의 액면가 (각 1 이상 100 이하).
- **출력**: 만들 수 없는 가장 작은 양의 정수.
- **예제**: `4 / 1 2 2 6` → `12` (1~11은 전부 가능, 전체 합이 11) · `3 / 2 3 5` → `1`
- **셀프체크**: 먼저 모든 부분집합의 합을 표시하고(`vector<char> can`), 그다음 1부터 올라가며 처음 만들 수 없는 값을 찾는 두 단계다. 배열 크기를 `전체 합 + 2`로 잡아야 "전체 합 + 1"(모든 값이 가능한 경우의 답)까지 인덱스가 존재한다 — C++은 범위를 벗어나도 오류를 내지 않고 조용히 남의 메모리를 읽으니 크기 계산이 곧 안전장치다. 액면가에 1이 없으면 답은 1이다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    vector<int> a(N);
    int total = 0;
    for (int i = 0; i < N; i++) {
        cin >> a[i];
        total += a[i];
    }

    vector<char> can(total + 2, 0);
    for (int mask = 0; mask < (1 << N); mask++) {
        int s = 0;
        for (int i = 0; i < N; i++) {
            if ((mask & (1 << i)) != 0) s += a[i];
        }
        can[s] = 1;
    }

    int v = 1;
    while (can[v]) v++;
    cout << v << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- "어떤 우표를 붙이나"는 부분집합 선택이므로 비트마스크로 2^N개 조합의 합을 전부 구할 수 있다. 여기까지가 물체 단위 완전탐색이다.
- 그다음 "만들 수 없는 최소 양의 정수"는 값 v를 1부터 올라가며 `can[v]`를 확인하는 값 기준 탐색이다. 두 완전탐색을 이어 붙인 구조라 Hard로 분류했다.

(2) 코드 단계별

- N과 액면가 배열 `a`, 전체 합 `total`을 준비하고 길이 `total + 2`의 `vector<char> can(total + 2, 0)`을 만든다.
- `mask`마다 켜진 비트의 액면가를 더해 합 `s`를 만들고 `can[s] = 1`로 표시한다(mask=0은 합 0).
- `v = 1`부터 `can[v]`가 참인 동안 1씩 올린다. 처음 거짓이 되는 `v`가 답이다.
- 모든 값이 가능하면 `v`는 `total + 1`에서 멈추는데, 배열 크기를 `total + 2`로 잡았으므로 인덱스 초과가 없다.

(3) 스스로 다시 짤 때 생각 순서

- 1단계: 부분집합 합을 전부 표시(2^N × N).
- 2단계: 1부터 값을 훑어 첫 구멍을 찾기.
- 배열 크기(전체 합 + 2)와 "1이 없으면 답 1", "전부 가능하면 답 total + 1" 경계를 확인한다.
- **C++ 함정(핵심)**: `while (can[v]) v++;`는 배열 끝을 지나도 멈추지 않는다. 파이썬이라면 `IndexError`로 알려 주지만 C++은 조용히 남의 메모리를 읽어 "우연히 0이 아닌 값"에서 무한히 전진할 수 있다. **끝에 반드시 0인 칸이 있도록** 크기를 `total + 2`로 잡는 것이 이 코드의 안전장치다.
- C++ 함정 ②: `vector<bool>`은 비트로 압축된 특수 구현이라 `bool&`를 얻을 수 없고 접근이 느리다. 단순 표시 배열은 `vector<char>`가 무난하다.
- C++ 함정 ③: `(mask & (1 << i)) != 0`의 괄호. `mask & (1 << i) != 0`은 `!=`가 먼저 묶여 `mask & 1`이 되므로 0번 우표만 계속 더한다.
- `vector<char> can(total + 2, 0)`처럼 **초기값 0을 명시**한다. 크기만 주면 `vector`는 0으로 채워 주지만, 같은 자리에 `char can[...]`처럼 배열을 쓰면 쓰레기 값이 남는다.
```

**10) 부호를 붙여 목표 만들기** · Hard

- **요구사항**: N개의 양의 정수가 순서대로 있다. 각 수 앞에 `+` 또는 `-`를 하나씩 붙여 전체를 더한 결과가 정확히 T가 되게 하려 한다. 단, **`-`를 붙이는 수는 최대 K개**까지만 허용한다. 조건을 만족하는 부호 배치의 **개수**를 구하라.
- **입력**: 첫 줄에 N, K, T (1 ≤ N ≤ 12, 0 ≤ K ≤ N, |T| ≤ 10^4). 둘째 줄에 N개의 정수 (각 1 이상 100 이하).
- **출력**: 조건을 만족하는 부호 배치의 개수.
- **예제**: `3 3 2 / 1 2 3` → `1` (+1 -2 +3) · `4 4 0 / 1 1 1 1` → `6` (넷 중 둘에 `-`를 붙이는 방법 수)
- **셀프체크**: "각 수에 `-`를 붙인다/안 붙인다"는 부분집합 선택이다 — mask의 켜진 비트를 `-`로 해석하면 된다. 켜진 비트 수(`-`의 개수)가 K를 넘으면 무효이며, 개수는 `__builtin_popcount(mask)`로 바로 얻을 수 있다. T가 음수인 경우(넷째 테스트)와 K=0(전부 `+`만 가능)도 같은 코드로 처리되는지 확인. 비트 검사는 `(mask & (1 << i)) != 0`처럼 괄호를 친다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, K, T;
    cin >> N >> K >> T;
    vector<int> a(N);
    for (int i = 0; i < N; i++) cin >> a[i];

    int cnt = 0;
    for (int mask = 0; mask < (1 << N); mask++) {
        int s = 0;
        for (int i = 0; i < N; i++) {
            if ((mask & (1 << i)) != 0) s -= a[i];
            else s += a[i];
        }
        int neg = __builtin_popcount(mask);
        if (neg <= K && s == T) cnt++;
    }
    cout << cnt << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- 부호 배치는 수마다 두 갈래(`+`/`-`)이므로 총 2^N가지다. "`-`를 붙일 수의 집합"을 고른다고 보면 부분집합 문제이고, mask의 i번째 비트가 켜지면 `a[i]`를 빼고 꺼지면 더하는 것으로 재해석할 수 있다.
- 여기에 "`-` 개수 ≤ K"라는 제약이 추가된다. 켜진 비트 수는 `__builtin_popcount(mask)` 한 번으로 얻는다. 부분집합 나열 + 합 계산 + 개수 제약이 결합된 문제다.

(2) 코드 단계별

- N, K, T와 배열 `a`를 읽고 `cnt = 0`으로 시작한다.
- `mask`마다 `s = 0`에서 시작해, 비트가 켜진 i는 `s -= a[i]`, 꺼진 i는 `s += a[i]`로 누적한다.
- `neg = __builtin_popcount(mask)`로 `-`의 개수를 얻는다.
- `neg <= K`이고 `s == T`이면 `cnt++`.
- `cnt`를 출력한다. T가 음수여도 `s`는 음수가 될 수 있으므로 별도 처리는 필요 없다.

(3) 스스로 다시 짤 때 생각 순서

- "각 수에 부호 하나" → 2^N → `-`를 붙일 집합을 비트마스크로.
- 각 mask에서 합을 누적하고, `-` 개수는 popcount로 한 번에.
- 제약(개수 ≤ K)과 목표(합 == T)를 둘 다 통과할 때만 센다. K=0·T 음수·N=1로 검산.
- **C++ 함정(핵심)**: `mask & (1 << i) != 0`은 `mask & ((1 << i) != 0)` = `mask & 1`로 묶인다. `&`가 `!=`보다 우선순위가 낮기 때문이며, 파이썬은 반대다. `(mask & (1 << i)) != 0`으로 괄호를 치거나 `if (mask & (1 << i))`로 쓴다.
- C++ 함정 ②: `T`를 음수로 읽는 데는 문제가 없다. 다만 `s`를 `unsigned`로 두면 음수가 거대한 양수로 뒤집혀 `s == T` 비교가 영원히 거짓이 된다. 부호가 섞이는 누적은 반드시 부호 있는 정수로.
- C++ 함정 ③: N이 커지면 `1 << N`이 `int` 범위를 넘는다. N ≥ 31이면 `mask`를 `long long`으로 두고 `1LL << N`, 검사식의 `1LL << i`까지 함께 고쳐야 한다. 한쪽만 바꾸면 조용히 틀린다.
- 합의 범위는 12 × 100 = 1200이라 `int`로 충분하다. 값 상한이 커지면 `long long`을 검토한다.
```
