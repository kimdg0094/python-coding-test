## L5. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch04(시뮬레이션 I)의 핵심을 **반복 훈련**하고, 코딩테스트 단골 유형으로 **확장**하는 연습 세트다. 날짜·시간 환산, 진법 변환, 1차원 구간 칠하기, 2차원 사각형 칠하기·겹침을 소재만 바꿔 여러 번 다시 짜 본다.
- **반복 훈련 개념**:
  - 시간 환산 → 정수 연산 → 복원: `total = h*60 + m`, `h = total / 60`, `m = total % 60`, 하루 감싸기 `% 1440`. C++의 `/`는 정수끼리면 몫이라 파이썬 `//`와 같지만, **음수에 `%`를 쓰면 C++은 음수를 돌려준다**(파이썬은 항상 0 이상). 시간을 뒤로 감을 때는 `((t % 1440) + 1440) % 1440`으로 감싼다.
  - 날짜 계산: `days_in_month(y, m)`으로 달 경계·윤년을 넘기고, 요일은 `(기준요일 + 경과일) % 7`
  - 진법 → 10진: `val = val * base + (int)DIGITS.find(ch)`(왼쪽 자리부터 누적). 자릿수가 많으면 `val`을 `long long`으로.
  - 1차원 칸 배열: `vector<int> cnt(L + 2, 0);` 후 `for (int x = a; x <= b; x++) cnt[x]++;`. C++의 지역 배열 `int cnt[1005];`는 **자동으로 0이 되지 않는다** — 쓰레기 값으로 시작하므로 `vector`의 초기값이나 `memset`/`fill`로 반드시 0을 채운다.
  - 2차원 격자 칠하기와 겹침: `vector<vector<int>> grid(N+2, vector<int>(M+2, 0));`에 `grid[r][c]++` 또는 대입. 네 방향은 `int dr[4] = {-1,1,0,0}, dc[4] = {0,0,-1,1};`. 두 사각형 교집합은 `[max(시작), min(끝)]`, 넓이 곱은 좌표가 크면 `long long`.
- **코딩테스트 출제 맵**: 『이것이 취업을 위한 코딩테스트다』의 '구현' 파트(시각·날짜·좌표 시뮬레이션), 백준 「단계별로 풀어보기」의 '1차원 배열'·'2차원 배열' 단계(칠하기·겹침), solved.ac CLASS 2의 진법·달력 문제들.
- **문제 구성표**:

**문제**

**1) 다음 버스 시각** · Easy

- **요구사항**: 버스는 00:00부터 정확히 `k`분 간격으로 출발한다(00:00, 00:k, 00:2k, ...). 현재 시각이 `h`시 `m`분일 때 다음 버스의 출발 시각과 기다려야 하는 분 수를 구하라. 현재 시각에 정확히 버스가 출발하면 대기 0분이며, 다음 버스가 자정을 넘기면 00:00처럼 다음날 시각으로 출력한다.
- **입력**: 한 줄에 `h m k` (0 ≤ h < 24, 0 ≤ m < 60, 1 ≤ k ≤ 720, k는 1440의 약수).
- **출력**: `HH:MM 대기분` 한 줄. 시·분은 두 자리로 채운다.
- **예제**: `08 07 15` → `08:15 8` · `23 58 5` → `00:00 2`
- **셀프체크**: 대기 시간은 `(k - total % k) % k`로 구했는가(바깥 `% k`가 있어야 정각일 때 0이 된다). 자정을 넘는 경우 `% 1440`으로 감쌌는가. 두 자리 패딩을 `printf("%02d:%02d %d\n", ...)`나 `cout << setw(2) << setfill('0')`로 시와 분 **모두**에 적용했는가(`setw`는 다음 출력 하나에만 적용되므로 시·분에 각각 붙여야 한다). `08`처럼 앞에 0이 붙은 입력을 `cin >> int`로 읽으면 그냥 8이 되는 것을 확인했는가.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    int h, m, k;
    cin >> h >> m >> k;
    int total = h * 60 + m;
    int wait = (k - total % k) % k;
    int nxt = (total + wait) % 1440;
    printf("%02d:%02d %d\n", nxt / 60, nxt % 60, wait);
    return 0;
}
@@TESTS
--IN
08 07 15
--OUT
08:15 8
--IN
23 58 5
--OUT
00:00 2
--IN
10 30 15
--OUT
10:30 0
--IN
0 0 720
--OUT
00:00 0
@@EXPL
(1) 접근·핵심 아이디어

- 시:분을 "자정부터 몇 분"이라는 정수 `total`로 환산하면, 다음 버스는 "`total` 이상인 가장 작은 k의 배수"다. 나머지 `total % k`가 0이면 지금이 정각이고, 아니면 `k - 나머지`만큼 기다린다.
- 도착 시각이 1440분을 넘으면 자정을 지난 것이므로 `% 1440`으로 감싸 다음날 시각으로 돌린다.

(2) 코드 단계별

- `total = h*60 + m`으로 총 분 환산. `h`가 두 자리 문자열 `08`이어도 `cin >> h`는 정수 8로 읽는다.
- `wait = (k - total % k) % k`: 정각이면 `k - 0 = k`가 되는데 바깥 `% k`가 그것을 0으로 만든다. 여기서는 `total`이 항상 0 이상이라 C++의 `%`도 파이썬과 같은 값을 준다. 만약 시간을 **뒤로** 감아 음수가 생긴다면 C++의 `%`는 음수를 돌려주므로 `((t % k) + k) % k`로 감싸야 한다.
- `nxt = (total + wait) % 1440`으로 다음 버스 시각(분)을 구하고, `/ 60`·`% 60`으로 시·분 복원.
- 출력은 `printf("%02d:%02d %d\n", ...)`. `%02d`는 "두 칸을 0으로 채운 정수". `cout`으로 하려면 `cout << setfill('0') << setw(2) << nxt / 60 << ':' << setw(2) << nxt % 60 << ' ' << wait << '\n'`처럼 `setw`를 시와 분에 **각각** 붙여야 한다(`setw`는 바로 다음 출력 하나에만 적용된다).
- `printf`와 `cout`을 섞어 쓰면서 `ios_base::sync_with_stdio(false)`를 켜면 출력 순서가 어긋날 수 있다. 여기서는 `printf`만 쓰므로 그 줄을 두지 않았다.

(3) 스스로 다시 짤 때 생각 순서

- "총 분으로 환산 → 다음 k의 배수 → 1440 감싸기 → 복원" 순서를 그대로 코드로.
- 함정: 정각일 때 대기 0(바깥 `% k`), 23:58 + 2분 = 00:00(감싸기), `0 0 720`처럼 자정 정각도 대기 0, 그리고 패딩을 두 칸 모두에.
```

**2) 색상 코드 RGB 분해** · Easy

- **요구사항**: 웹 색상 코드는 `#RRGGBB` 형태로, 두 자리 16진수 세 개가 각각 빨강·초록·파랑의 밝기(0~255)를 나타낸다. 색상 코드가 주어지면 세 값을 10진수로 출력하라. 16진 문자는 대문자·소문자가 섞여 올 수 있다.
- **입력**: 한 줄에 `#`으로 시작하는 7글자 색상 코드(16진 숫자 `0~9`, `a~f`, `A~F`).
- **출력**: `R G B` 세 정수를 공백으로 구분해 한 줄.
- **예제**: `#1A2B3C` → `26 43 60` · `#ffffff` → `255 255 255`
- **셀프체크**: 소문자를 `toupper`로 정규화한 뒤 `DIGITS.find(ch)`로 자릿값을 얻었는가(`find`는 `size_t`를 돌려주므로 `(int)`로 캐스팅해서 쓰고, 못 찾으면 `string::npos`라는 거대한 값이 온다는 걸 아는가)? `#`을 떼고 2글자씩(`s.substr(0,2)`, `s.substr(2,2)`, `s.substr(4,2)` 또는 인덱스 두 개) 잘랐는가? `substr`의 두 번째 인자는 **끝 위치가 아니라 길이**임을 확인했는가(파이썬 슬라이스와 다르다)? `#000000`이 `0 0 0`으로 나오는지 확인.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    const string DIGITS = "0123456789ABCDEF";
    string s;
    cin >> s;
    if (s[0] == '#') s = s.substr(1);
    for (int i = 0; i < (int)s.size(); i++) s[i] = (char)toupper((unsigned char)s[i]);
    vector<int> vals;
    for (int i = 0; i < 6; i += 2) {
        int v = 0;
        for (int j = i; j < i + 2; j++) v = v * 16 + (int)DIGITS.find(s[j]);
        vals.push_back(v);
    }
    for (int i = 0; i < (int)vals.size(); i++) {
        if (i > 0) cout << ' ';
        cout << vals[i];
    }
    cout << '\n';
    return 0;
}
@@TESTS
--IN
#1A2B3C
--OUT
26 43 60
--IN
#ffffff
--OUT
255 255 255
--IN
#000000
--OUT
0 0 0
--IN
#0a0B10
--OUT
10 11 16
@@EXPL
(1) 접근·핵심 아이디어

- 색상 코드는 "16진수 세 개를 이어 붙인 문자열"이다. `#`을 떼고 두 글자씩 잘라 각각을 16진 → 10진으로 바꾸면 끝난다.
- 16진 → 10진은 L2의 `val = val * base + 자릿값` 누적을 base=16으로 쓴 것이다. 문자↔값 매핑은 `DIGITS.find(ch)`(파이썬 `str.index`에 해당).

(2) 코드 단계별

- `s.substr(1)`로 `#`을 뗀다. `substr(시작, 길이)`이며 길이를 생략하면 끝까지다 — 파이썬의 `s[1:]`과 모양은 비슷해도 두 번째 인자의 뜻이 다르니 주의(`substr(2, 4)`는 "2번부터 4글자"이지 "2번부터 4번 앞까지"가 아니다).
- 대문자 정규화: `toupper`는 `<cctype>`의 함수로 `int`를 받고 `int`를 돌려준다. 음수 문자 코드가 들어가면 정의되지 않은 동작이므로 `(unsigned char)`로 감싸고 결과를 `(char)`로 되돌리는 것이 안전한 관용구다.
- `DIGITS.find(s[j])`는 찾은 위치를 `size_t`로 준다. 여기서는 항상 찾으므로 `(int)`로 캐스팅해 계산에 넣는다. 못 찾으면 `string::npos`(부호 없는 최댓값)가 오므로, 입력이 신뢰할 수 없다면 `if (pos == string::npos)` 검사를 넣어야 한다.
- 두 글자씩 누적해 `vals`에 담고, `i > 0`일 때만 앞에 공백을 찍어 줄 끝 공백 없이 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "어디서 자르나?" → 2글자씩 3조각. "어떻게 바꾸나?" → base 16 누적.
- 함정: 소문자 입력(`#ffffff`)은 정규화 없이는 `find`가 실패해 `npos`가 섞인다. `substr`의 두 번째 인자는 길이. `#000000`처럼 0이 섞여도 누적식은 그대로 동작한다.
```

**3) 가장 긴 빈 틈** · Easy

- **요구사항**: 길이 `L`의 도로(칸 1..L)에 `n`개의 공사 구간 `[a, b]`가 표시된다. 공사 구간이 하나도 없는 칸들이 연속으로 이어진 "빈 틈" 중 가장 긴 것의 길이를 출력하라. 빈 칸이 없으면 0.
- **입력**: 첫 줄 `L n` (1 ≤ L ≤ 1000, 0 ≤ n ≤ 100). 이어 `n`개 줄에 `a b` (1 ≤ a ≤ b ≤ L).
- **출력**: 가장 긴 빈 틈의 길이 한 줄.
- **예제**: `10 2 / 2 3 / 7 8` → `3` · `5 1 / 1 5` → `0`
- **셀프체크**: 칸 배열을 `vector<int> cnt(L + 2, 0)`처럼 **0으로 초기화**했는가(`int cnt[1005];`를 함수 안에 선언하면 쓰레기 값으로 시작해 답이 매번 달라진다). 구간을 칠한 뒤 1..L을 훑으며 "값이 0이면 `cur++`, 아니면 `cur = 0`"으로 연속 길이를 세고 최댓값을 갱신했는가. 크기를 `L + 2`로 잡아 인덱스 `L`까지 안전한가. `n = 0`이면 답이 `L` 전체인지, 전부 칠해지면 0이 나오는지 확인.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    int L, n;
    cin >> L >> n;
    vector<int> cnt(L + 2, 0);
    for (int i = 0; i < n; i++) {
        int a, b;
        cin >> a >> b;
        for (int x = a; x <= b; x++) cnt[x]++;
    }
    int best = 0, cur = 0;
    for (int x = 1; x <= L; x++) {
        if (cnt[x] == 0) {
            cur++;
            if (cur > best) best = cur;
        } else {
            cur = 0;
        }
    }
    cout << best << '\n';
    return 0;
}
@@TESTS
--IN
10 2
2 3
7 8
--OUT
3
--IN
5 1
1 5
--OUT
0
--IN
6 0
--OUT
6
--IN
8 3
1 1
4 4
8 8
--OUT
3
@@EXPL
(1) 접근·핵심 아이디어

- L3의 칸 배열에 구간을 그대로 칠한 뒤, 이번에는 "칠해진 칸"이 아니라 "칠해지지 않은 칸이 연속으로 몇 개 이어지는가"를 센다. 배열을 한 번 훑으며 현재 연속 길이 `cur`와 최댓값 `best`를 유지하면 된다.

(2) 코드 단계별

- `vector<int> cnt(L + 2, 0)`을 만든다. 두 번째 인자 `0`이 초기값이다. C++의 지역 배열 `int cnt[1005];`는 초기화되지 않아 쓰레기 값이 들어 있고, 파이썬의 `[0] * n`처럼 자동으로 0이 되지 않는다. `vector`를 쓰거나 `fill(cnt, cnt + 1005, 0)`으로 직접 채운다(전역 배열이라면 자동으로 0이다).
- 각 구간 `a..b`를 `for (int x = a; x <= b; x++) cnt[x]++`로 칠한다. 파이썬의 `range(a, b+1)`은 끝이 열려 있어 `+1`이 필요했지만, C++의 `x <= b`는 끝을 포함하므로 `+1`을 붙이지 않는다. 여기서 `x < b`로 쓰면 마지막 칸을 빠뜨린다.
- `x`를 1..L로 돌며 `cnt[x] == 0`이면 `cur++`하고 `best`를 갱신, 칠해진 칸을 만나면 `cur = 0`으로 끊는다.
- `best` 출력.

(3) 스스로 다시 짤 때 생각 순서

- "칠하기 → 빈 칸 연속 길이 세기"의 두 단계로 나눈다.
- 함정: 배열 0 초기화, 끝을 포함하는 `<=` 루프, `n = 0`이면 구간 입력이 없으므로 루프가 0번 돌아도 동작해야 하고 답은 `L`. 전부 칠해지면 `cur`가 한 번도 늘지 않아 0.
```

**4) 두 날짜 사이 일수** · Medium

- **요구사항**: 두 날짜 `y1 m1 d1`과 `y2 m2 d2`가 주어진다(둘째 날짜가 첫째 날짜와 같거나 나중). 첫째 날짜에서 둘째 날짜까지 며칠이 지나는지 출력하라(같은 날이면 0, 다음 날이면 1). 윤년 규칙(4의 배수이면서 100의 배수가 아니거나, 400의 배수)을 따른다.
- **입력**: 두 줄에 각각 `y m d` (1 ≤ y ≤ 3000, 유효한 날짜).
- **출력**: 경과 일수 한 줄.
- **예제**: `2024 2 28 / 2024 3 1` → `2` · `2023 12 31 / 2024 1 1` → `1`
- **셀프체크**: 각 날짜를 "1년 1월 1일부터 며칠째"라는 총 일수로 환산해 빼면 달·해 경계를 따로 처리할 필요가 없다. `days_in_month` 안의 월별 일수 배열은 0-based이므로 `d[m - 1]`로 접근했는가(1-based로 착각해 `d[m]`을 쓰면 한 달씩 밀리고 12월에서는 범위 밖을 읽는다). `is_leap`의 반환 타입이 `bool`인가. 2024년(윤년)의 2/28 → 3/1은 2/29를 지나므로 2일, 1900년(100의 배수라 평년)의 2/28 → 3/1은 1일인지 확인.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

bool is_leap(int y) {
    return (y % 4 == 0 && y % 100 != 0) || (y % 400 == 0);
}

int days_in_month(int y, int m) {
    int d[12] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
    if (m == 2 && is_leap(y)) return 29;
    return d[m - 1];
}

int to_days(int y, int m, int d) {
    int total = 0;
    for (int yy = 1; yy < y; yy++) total += is_leap(yy) ? 366 : 365;
    for (int mm = 1; mm < m; mm++) total += days_in_month(y, mm);
    return total + d;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    int y1, m1, d1, y2, m2, d2;
    cin >> y1 >> m1 >> d1;
    cin >> y2 >> m2 >> d2;
    cout << to_days(y2, m2, d2) - to_days(y1, m1, d1) << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- L1의 "환산 → 정수 연산" 원칙을 날짜에 적용한다. 각 날짜를 "1년 1월 1일을 1일째로 하는 총 일수"로 바꾸면 두 날짜의 차이는 뺄셈 한 번이다. 달 경계·해 경계·윤년을 경우별로 나눌 필요가 없다.
- 총 일수 = (이전 해들의 일수 합) + (같은 해 이전 달들의 일수 합) + 일.

(2) 코드 단계별

- `is_leap`은 반환 타입이 `bool`. `(y % 4 == 0 && y % 100 != 0) || (y % 400 == 0)`을 그대로 돌려준다. 괄호를 빼도 `&&`가 `||`보다 먼저 묶이지만, 의도를 드러내려면 괄호를 쓰는 편이 낫다.
- `days_in_month`: 월별 일수를 `int d[12]`에 담고 `d[m - 1]`로 꺼낸다. 배열은 0-based이므로 1월이 인덱스 0이다. 이 `-1`을 빠뜨리면 모든 달이 한 칸씩 밀리고 `m = 12`에서는 `d[12]`라는 범위 밖을 읽어 쓰레기 값이 나온다(C++은 경고 없이 읽는다).
- `to_days(y, m, d)`: `1..y-1`년은 윤년 여부에 따라 366/365를 더하고, `1..m-1`월은 `days_in_month`로 더한 뒤 `d`를 더한다. 삼항 연산자 `is_leap(yy) ? 366 : 365`가 파이썬의 `366 if ... else 365`에 해당한다.
- 최대값 어림: 3000년이면 약 1,095,000일이라 `int`(약 21억)로 충분하다.
- 두 날짜의 `to_days` 차이를 출력한다. 연도 상한 3000이라 해를 하나씩 더하는 루프도 순식간이다.

(3) 스스로 다시 짤 때 생각 순서

- "날짜 두 개 → 각각 총 일수 → 빼기". 기준일은 아무거나 좋지만 두 날짜에 같은 기준을 써야 한다.
- 함정: 배열 인덱스 `m - 1`, 2/29가 사이에 끼는지(윤년), 100의 배수 해(1900)는 평년, 같은 날이면 0.
```

**5) 가장 작은 유효 진법** · Medium

- **요구사항**: 숫자·대문자로 이루어진 문자열 `s`가 어떤 진법의 표기라고 한다. 모든 자릿값(0~9, A=10, ..., Z=35)이 유효하려면 진법은 "가장 큰 자릿값 + 1" 이상이어야 하고, 진법은 최소 2다. `s`를 표기할 수 있는 가장 작은 진법과, 그 진법으로 읽었을 때의 10진 값을 출력하라.
- **입력**: 한 줄에 `s` (길이 1~10, `0~9`·`A~Z`로만 구성).
- **출력**: `진법 10진값` 한 줄.
- **예제**: `12` → `3 5` · `Z` → `36 35`
- **셀프체크**: 10진 값을 `long long`으로 잡았는가 — 36진 10자리는 최대 36^10 ≈ 3.6×10^15로 `int`(약 21억)를 한참 넘는다. `int`로 짜면 예외 없이 값이 뒤집혀 **조용히 틀린다**. 가장 큰 자릿값을 `DIGITS.find`로 찾고 `+1` 한 값이 2보다 작으면 2로 올렸는가(`0`, `1`처럼 자릿값이 0·1뿐인 경우). `find`의 결과를 `(int)`로 캐스팅했는가? 누적은 그 진법으로 `val = val * base + 자릿값`을 왼쪽부터. `1010`은 2진법으로 10, `A0`은 11진법으로 110.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    const string DIGITS = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ";
    string s;
    cin >> s;
    int mx = 0;
    for (int i = 0; i < (int)s.size(); i++) {
        int v = (int)DIGITS.find(s[i]);
        if (v > mx) mx = v;
    }
    int base = mx + 1;
    if (base < 2) base = 2;
    long long val = 0;
    for (int i = 0; i < (int)s.size(); i++) {
        val = val * base + (int)DIGITS.find(s[i]);
    }
    cout << base << ' ' << val << '\n';
    return 0;
}
@@TESTS

--OUT

--IN

--OUT

--IN

--OUT

--IN

--OUT

--IN

--OUT

@@EXPL
(1) 접근·핵심 아이디어

- 어떤 진법 `b`에서 쓸 수 있는 자릿값은 `0..b-1`이다. 따라서 문자열 안의 가장 큰 자릿값이 `mx`이면 진법은 최소 `mx + 1`이어야 한다. 단 진법은 2 이상이므로 `mx`가 0이면 2로 올린다.
- 진법이 정해지면 L2의 왼쪽부터 누적(`val * base + 자릿값`)으로 10진 값을 만든다.

(2) 코드 단계별

- 문자열을 한 번 훑어 `(int)DIGITS.find(s[i])`의 최댓값 `mx`를 구한다. `find`는 `size_t`(부호 없음)를 돌려주므로 `int v`에 받을 때 캐스팅한다.
- `base = mx + 1`, 2보다 작으면 2로 보정.
- 다시 한 번 훑으며 `val = val * base + 자릿값` 누적.
- **타입이 이 문제의 핵심 함정이다.** `val`을 `int`로 두면 36진 10자리(약 3.6×10^15)에서 넘친다. C++의 정수 오버플로는 예외를 던지지 않고 값을 조용히 감아 버리므로, 테스트에서 우연히 작은 입력만 보면 끝까지 모른 채 지나간다. 파이썬 정수는 자동으로 커지지만 C++은 타입을 처음부터 넉넉히 잡아야 한다.
- `val * base`가 `long long × int`이면 `long long`으로 계산되므로 여기서는 추가 캐스팅이 필요 없다. 반대로 `int * int`를 `long long`에 담기만 하면 **곱셈이 이미 `int`로 끝난 뒤**라 늦다 — 그럴 땐 `1LL * a * b`로 승격시킨다.

(3) 스스로 다시 짤 때 생각 순서

- "진법은 자릿값이 결정한다" → 최대 자릿값 찾기 → 최소 2 보정 → 누적 변환. 누적하기 전에 최댓값을 어림해 타입부터 고른다.
- 함정: `0`만 있으면 `mx + 1 = 1`이므로 보정이 꼭 필요하다. `A0`처럼 큰 자릿값이 앞에 오면 `mx = 10 → base 11`, 값은 `10*11 + 0 = 110`.
```

**6) 두 직사각형 겹침 넓이** · Medium

- **요구사항**: 좌표평면에 축과 나란한 직사각형 두 개가 각각 왼쪽 아래 `(x1, y1)`과 오른쪽 위 `(x2, y2)`로 주어진다. 두 직사각형이 겹치는 부분의 넓이를 출력하라. 변이나 꼭짓점만 맞닿으면 겹침 넓이는 0이다. 좌표가 매우 커서 격자를 만들 수 없다.
- **입력**: 두 줄에 각각 `x1 y1 x2 y2` (0 ≤ x1 < x2 ≤ 10^9, 0 ≤ y1 < y2 ≤ 10^9).
- **출력**: 겹치는 넓이(정수) 한 줄.
- **예제**: `0 0 4 4 / 2 2 6 6` → `4` · `0 0 2 2 / 2 0 4 2` → `0`
- **셀프체크**: 넓이가 최대 약 10^18이라 **`long long`이 필수**임을 확인했는가 — 폭과 높이를 `int`로 두고 `w * h`를 계산하면 곱셈이 `int`로 끝난 뒤 넘쳐서, `long long` 변수에 담아도 이미 늦다. 겹치는 구간은 x축에서 `[max(x1, x3), min(x2, x4)]`, y축에서도 마찬가지다. `min`/`max`의 두 인자 타입이 같은가(`int`와 `long long`을 섞으면 컴파일 오류). 두 폭이 모두 양수일 때만 곱하고, 하나라도 0 이하면 0을 출력했는가(맞닿는 경우 폭이 정확히 0). 한 사각형이 다른 것 안에 완전히 들어가면 작은 쪽 넓이가 나오는지 확인.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    long long x1, y1, x2, y2, x3, y3, x4, y4;
    cin >> x1 >> y1 >> x2 >> y2;
    cin >> x3 >> y3 >> x4 >> y4;
    long long w = min(x2, x4) - max(x1, x3);
    long long h = min(y2, y4) - max(y1, y3);
    if (w > 0 && h > 0) cout << w * h << '\n';
    else cout << 0 << '\n';
    return 0;
}
@@TESTS

2 2 6 6
--OUT

--IN
0 0 2 2
2 0 4 2
--OUT

--IN
0 0 10 10
3 3 4 4
--OUT

--IN
0 0 1000000000 1000000000
1 1 999999999 999999999
--OUT

@@EXPL
(1) 접근·핵심 아이디어

- 좌표가 10^9까지라 L4처럼 격자에 칠할 수 없다. 대신 L4 접근 전략에 나온 교집합 공식을 쓴다. 축에 나란한 두 사각형의 겹침은 "x 구간의 교집합 × y 구간의 교집합"이고, 각 축의 교집합은 `[max(시작), min(끝)]`이다.
- 교집합 폭이 0 이하이면 그 축에서 겹치지 않는다는 뜻이므로 넓이는 0이다.

(2) 코드 단계별

- 좌표를 처음부터 `long long`으로 읽는다. 넓이가 최대 `10^9 × 10^9 = 10^18`인데 `int` 상한은 약 2.1×10^9, `long long` 상한은 약 9.2×10^18이다. 파이썬 정수는 얼마든지 커지지만 C++은 여기서 타입을 잘못 고르면 넷째 테스트가 음수나 엉뚱한 값으로 나온다.
- 흔한 실수: `int w, h;`로 두고 `long long area = w * h;`라고 쓰는 것. 대입은 곱셈이 **끝난 뒤**의 일이라 이미 `int`에서 넘친 값을 옮길 뿐이다. 인자 중 하나라도 `long long`이어야 곱셈 자체가 64비트로 계산된다(급하면 `1LL * w * h`).
- `w = min(x2, x4) - max(x1, x3)`, `h = min(y2, y4) - max(y1, y3)`. `std::min`/`std::max`는 두 인자 타입이 정확히 같아야 하므로 좌표를 전부 `long long`으로 통일해 두면 편하다.
- `w > 0 && h > 0`일 때만 `w * h`, 아니면 0.

(3) 스스로 다시 짤 때 생각 순서

- "겹침 = 각 축 교집합의 곱". 교집합 구간은 시작은 더 큰 쪽, 끝은 더 작은 쪽.
- 먼저 답의 최대 크기를 어림해 타입을 정한다(10^18 → `long long`) → 그다음 공식을 쓴다.
- 함정: 변이 맞닿으면 `w`나 `h`가 정확히 0이라 0을 출력해야 하고, 서로 떨어져 있으면 음수가 나오므로 `> 0` 검사가 둘 다 필요하다. 포함 관계면 자연히 작은 사각형의 넓이.
```

**7) 이중 예약 분 세기** · Medium

- **요구사항**: 회의실 예약 `n`건이 각각 시작 `h1:m1`부터 끝 `h2:m2` 직전까지(반열림 구간, 끝 시각은 포함하지 않음)로 주어진다. 하루(00:00~24:00) 중 두 건 이상이 동시에 잡혀 있는 시간이 총 몇 분인지 출력하라.
- **입력**: 첫 줄 `n` (1 ≤ n ≤ 100). 이어 `n`개 줄에 `h1 m1 h2 m2` (시작 < 끝, 0 ≤ h1 < 24, 0 ≤ h2 ≤ 24, `h2 = 24`이면 `m2 = 0`).
- **출력**: 이중 예약된 총 분 수 한 줄.
- **예제**: `2 / 9 0 10 30 / 10 0 11 0` → `30` · `3 / 9 0 12 0 / 10 0 11 0 / 10 30 13 0` → `120`
- **셀프체크**: 하루를 1440개의 "분 칸"으로 보고 각 예약의 `[시작분, 끝분)`에 `+1` 했는가 — 반열림이므로 루프 조건이 `t < e`(끝 미포함)여야 하고, `t <= e`로 쓰면 1분씩 더 세어진다. `vector<int> cnt(1440, 0)`으로 0 초기화했는가. 마지막에 `cnt[t] >= 2`인 분의 개수를 센다. 10:00에 끝나고 10:00에 시작하는 두 예약은 겹치지 않아야 한다. `h2 = 24`면 `e = 1440`이라 인덱스 1439까지만 칠해지는가.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> cnt(1440, 0);
    for (int i = 0; i < n; i++) {
        int h1, m1, h2, m2;
        cin >> h1 >> m1 >> h2 >> m2;
        int s = h1 * 60 + m1;
        int e = h2 * 60 + m2;
        for (int t = s; t < e; t++) cnt[t]++;
    }
    int ans = 0;
    for (int t = 0; t < 1440; t++) {
        if (cnt[t] >= 2) ans++;
    }
    cout << ans << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- L1의 시간 환산과 L3의 칸 배열을 합친다. 하루는 1440분이므로 크기 1440의 벡터를 "분 칸"으로 두고, 각 예약을 `[시작분, 끝분)`으로 환산해 그 칸들에 `+1`을 쌓는다.
- 다 쌓은 뒤 두께가 2 이상인 칸의 개수가 곧 "이중 예약된 분 수"다.

(2) 코드 단계별

- `vector<int> cnt(1440, 0)` — 크기와 초기값을 함께 준다. C++ 배열은 자동으로 0이 되지 않으므로 이 초기값이 중요하다.
- 예약마다 `s = h1*60 + m1`, `e = h2*60 + m2`를 구하고 `for (int t = s; t < e; t++) cnt[t]++`. 반열림 구간이므로 **`t < e`** 다. 앞 문제(구간이 닫혀 있던 3번)에서는 `x <= b`였다는 점과 대비해 두면 헷갈리지 않는다.
- `h2 = 24`면 `e = 1440`이라 마지막으로 칠해지는 인덱스가 1439다. 만약 `t <= e`로 썼다면 `cnt[1440]`이라는 범위 밖을 건드려 조용히 다른 메모리를 망가뜨렸을 것이다.
- `cnt[t] >= 2`인 `t`의 개수를 세어 출력.

(3) 스스로 다시 짤 때 생각 순서

- "시각을 분 인덱스로 → 구간 칠하기 → 두께 ≥ 2 카운트".
- 함정: 끝 시각은 포함하지 않으므로 루프는 `t < e`. 그래서 10:00에 끝나는 예약과 10:00에 시작하는 예약은 겹치지 않는다(넷째 테스트가 0). 배열 크기 1440과 인덱스 상한 1439의 관계를 늘 확인한다.
```

**8) k일 뒤 날짜와 요일** · Hard

- **요구사항**: 어떤 날짜 `y`년 `m`월 `d`일과 그 날의 요일 번호 `w`(0=월요일, 1=화, ..., 6=일요일)가 주어진다. 정확히 `k`일 뒤의 날짜와 요일을 구하라. 달·해 경계와 윤년을 정확히 넘겨야 한다.
- **입력**: 첫 줄 `y m d w` (1 ≤ y ≤ 3000, 유효한 날짜, 0 ≤ w ≤ 6). 둘째 줄 `k` (0 ≤ k ≤ 100000).
- **출력**: `y m d 요일`을 공백으로 구분해 한 줄. 요일은 `MON TUE WED THU FRI SAT SUN` 중 하나.
- **예제**: `2024 2 28 2 / 2` → `2024 3 1 FRI` · `2023 12 31 6 / 1` → `2024 1 1 MON`
- **셀프체크**: 요일은 날짜와 무관하게 `(w + k) % 7`로 바로 나온다. 여기서는 `w + k`가 항상 0 이상이라 안전하지만, **날짜를 거꾸로 세는 문제라면 C++의 `%`가 음수를 돌려줘** `names[-1]` 같은 범위 밖 접근이 된다는 것을 아는가(그때는 `((w + k) % 7 + 7) % 7`). 날짜는 "이번 달에 남은 일수"보다 `k`가 크면 다음 달 1일로 점프하며 `k`를 줄이고, 그렇지 않으면 `d += k`로 끝낸다. 12월에서 다음 달로 넘어갈 때 `m = 1, y += 1`을 했는가. `k = 0`이면 입력 날짜 그대로인지, 2024-02-28에서 2일 뒤가 3월 1일(윤년)인지 확인.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

bool is_leap(int y) {
    return (y % 4 == 0 && y % 100 != 0) || (y % 400 == 0);
}

int days_in_month(int y, int m) {
    int d[12] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
    if (m == 2 && is_leap(y)) return 29;
    return d[m - 1];
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    int y, m, d, w, k;
    cin >> y >> m >> d >> w;
    cin >> k;
    string names[7] = {"MON", "TUE", "WED", "THU", "FRI", "SAT", "SUN"};
    int nw = ((w + k) % 7 + 7) % 7;
    while (k > 0) {
        int remain = days_in_month(y, m) - d;
        if (k <= remain) {
            d += k;
            k = 0;
        } else {
            k -= remain + 1;
            d = 1;
            m += 1;
            if (m == 13) {
                m = 1;
                y += 1;
            }
        }
    }
    cout << y << ' ' << m << ' ' << d << ' ' << names[nw] << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- 요일과 날짜를 분리해서 푼다. 요일은 7일 주기이므로 `(w + k) % 7` 한 줄로 끝난다.
- 날짜는 하루씩 세면 `k`가 10만이라도 되지만, "달 단위 점프"가 더 깔끔하다. 이번 달에 남은 일수 `remain = days_in_month - d`보다 `k`가 작거나 같으면 같은 달 안에서 끝나고, 크면 다음 달 1일로 넘어가면서 `k`에서 `remain + 1`(오늘 이후 남은 날 + 1일로 가는 하루)을 뺀다.

(2) 코드 단계별

- `nw = ((w + k) % 7 + 7) % 7`로 요일 인덱스를 먼저 구해 둔다(뒤에서 `k`를 소모하므로 순서 주의). 이 문제의 `k`는 0 이상이라 `(w + k) % 7`만으로도 충분하지만, **C++의 `%`는 왼쪽이 음수면 음수를 돌려준다**(`-1 % 7`은 파이썬에서 `6`, C++에서는 `-1`). 인덱스로 쓸 값에는 `((x % n) + n) % n` 감싸기를 습관으로 두면 `names[-1]` 같은 사고를 막는다. 같은 이유로 방향 배열에서 `dr[(dir - 1) % 4]`는 `dir = 0`에서 `dr[-1]`이 되어 위험하고, `dr[(dir + 3) % 4]`로 써야 한다.
- `while (k > 0)`: `remain`을 계산해 같은 달이면 `d += k; k = 0;`, 아니면 `k -= remain + 1; d = 1; m += 1;`, 13월이 되면 `m = 1; y += 1;`.
- 요일 이름은 `string names[7]`에 담아 `names[nw]`로 꺼낸다. C 스타일 배열이라 인덱스가 0~6을 벗어나면 아무 검사 없이 엉뚱한 메모리를 읽는다.
- `k`가 10만이어도 달 단위로 점프하므로 반복은 3,300번 정도다.

(3) 스스로 다시 짤 때 생각 순서

- "요일은 % 7, 날짜는 달 단위 점프". `k`를 소모하기 전에 요일부터 계산하고, 인덱스로 쓸 나머지는 음수가 될 수 있는지 점검한다.
- 함정: 다음 달로 넘어갈 때 빼는 양은 `remain`이 아니라 `remain + 1`(1일 자체로 가는 하루). 12→1월에서 연도 증가. `k = 0`이면 루프가 돌지 않아 그대로 출력. 2월 말은 `days_in_month`가 윤년을 알아서 처리한다.
```

**9) 스티커 합집합의 넓이와 둘레** · Hard

- **요구사항**: `N×M` 격자(행 1..N, 열 1..M)에 `n`장의 직사각형 스티커 `(r1, c1, r2, c2)`를 붙인다. 스티커는 겹칠 수 있다. 붙이고 난 뒤 스티커로 덮인 영역의 "넓이(덮인 칸 수)"와 "둘레 길이(덮인 칸과 덮이지 않은 칸 또는 격자 밖이 맞닿는 변의 개수)"를 출력하라.
- **입력**: 첫 줄 `N M n` (1 ≤ N, M ≤ 100, 0 ≤ n ≤ 50). 이어 `n`개 줄에 `r1 c1 r2 c2` (1 ≤ r1 ≤ r2 ≤ N, 1 ≤ c1 ≤ c2 ≤ M).
- **출력**: `넓이 둘레` 한 줄.
- **예제**: `5 5 1 / 2 2 3 4` → `6 10` · `5 5 2 / 1 1 2 2 / 2 2 3 3` → `7 12`
- **셀프체크**: 격자를 `vector<vector<int>> grid(N+2, vector<int>(M+2, 0))`처럼 한 겹 크게, 그리고 0으로 초기화해 만들었는가 — 그러면 상하좌우 이웃을 볼 때 경계 검사 없이 "밖은 0"으로 처리된다. 네 방향을 `dr[4]`, `dc[4]` 배열로 돌며 `grid[r+dr[k]][c+dc[k]] == 0`인 개수를 둘레에 더했는가. 2×3 사각형 하나는 넓이 6, 둘레 10. 두 스티커가 한 칸만 겹치는 둘째 예제는 넓이 4+4-1=7. `n = 0`이면 `0 0`.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    int N, M, n;
    cin >> N >> M >> n;
    vector<vector<int>> grid(N + 2, vector<int>(M + 2, 0));
    for (int i = 0; i < n; i++) {
        int r1, c1, r2, c2;
        cin >> r1 >> c1 >> r2 >> c2;
        for (int r = r1; r <= r2; r++) {
            for (int c = c1; c <= c2; c++) grid[r][c] = 1;
        }
    }
    int dr[4] = {-1, 1, 0, 0};
    int dc[4] = {0, 0, -1, 1};
    int area = 0, perim = 0;
    for (int r = 1; r <= N; r++) {
        for (int c = 1; c <= M; c++) {
            if (grid[r][c] == 1) {
                area++;
                for (int k = 0; k < 4; k++) {
                    if (grid[r + dr[k]][c + dc[k]] == 0) perim++;
                }
            }
        }
    }
    cout << area << ' ' << perim << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- 넓이는 L4 그대로 "격자에 찍고 1인 칸을 센다". 겹친 칸은 대입(`= 1`)이므로 자동으로 한 번만 세어진다.
- 둘레는 "덮인 칸의 각 변 중, 반대편이 덮이지 않은 변"의 개수다. 덮인 칸마다 상하좌우 이웃을 보고 이웃이 0이면 그 변은 바깥 경계이므로 둘레에 1을 더한다. 겹친 스티커의 내부 경계는 양쪽이 모두 1이라 세어지지 않는다.

(2) 코드 단계별

- `vector<vector<int>> grid(N + 2, vector<int>(M + 2, 0))` — 바깥 한 겹을 여유로 두고 전부 0으로 초기화한다. 이 한 겹이 "인덱스 초과"와 "밖은 미도색"을 동시에 해결한다. C++의 `vector`는 범위 검사를 하지 않으므로, 여유 테두리 없이 `grid[r-1][c]`를 `r = 0`에서 부르면 범위 밖 메모리를 읽는다(파이썬처럼 `IndexError`가 나거나 음수 인덱스로 반대편을 읽는 게 아니라, 그냥 정의되지 않은 동작이다).
- 스티커마다 `r1..r2 × c1..c2`에 1을 **대입**한다. 누적(`++`)이 아니라 대입이어야 `== 1` 판정이 겹친 칸에서도 그대로 성립한다.
- 네 방향은 `int dr[4] = {-1, 1, 0, 0}; int dc[4] = {0, 0, -1, 1};`로 묶어 `for (int k = 0; k < 4; k++)` 한 줄로 돈다. 시뮬레이션 문제의 표준 장치다. 방향을 회전시킬 때는 `(k + 1) % 4`(시계)와 `(k + 3) % 4`(반시계)를 쓴다 — `(k - 1) % 4`는 `k = 0`에서 `-1`이 되어 `dr[-1]`이라는 범위 밖 접근이 된다(파이썬이었다면 마지막 원소를 읽어 우연히 맞았을 자리다).
- 1..N × 1..M을 훑으며 `grid[r][c] == 1`이면 `area++`, 이웃 네 칸 중 0인 개수를 `perim`에 더한다.

(3) 스스로 다시 짤 때 생각 순서

- "넓이 = 1인 칸 수, 둘레 = 1인 칸의 0인 이웃 변 수". 여유 테두리로 경계 검사를 없앤다.
- 함정: 격자 전체를 덮으면 둘레는 격자 테두리 `2(N+M)`(넷째 테스트 16). 떨어진 두 칸은 각각 4변씩 8. `n = 0`이면 둘 다 0. 방향 배열의 음수 나머지.
```

**10) 동시 점등 최장 구간** · Hard

- **요구사항**: `n`개의 조명이 각각 `h1:m1`부터 `h2:m2` 직전까지(반열림) 켜진다. 하루(00:00~24:00) 중 "동시에 켜진 조명이 `k`개 이상"인 상태가 연속으로 가장 길게 이어지는 구간을 찾아, 그 시작 시각과 길이(분)를 출력하라. 길이가 같은 구간이 여럿이면 시작 시각이 가장 이른 것을 고른다. 그런 구간이 없으면 `NONE`.
- **입력**: 첫 줄 `n k` (1 ≤ n ≤ 100, 1 ≤ k ≤ n). 이어 `n`개 줄에 `h1 m1 h2 m2` (시작 < 끝, `h2 = 24`이면 `m2 = 0`).
- **출력**: `HH:MM 길이` 한 줄(시각은 두 자리 패딩), 또는 `NONE`.
- **예제**: `3 2 / 9 0 12 0 / 10 0 11 0 / 11 30 13 0` → `10:00 60` · `2 1 / 0 0 1 0 / 23 0 24 0` → `00:00 60`
- **셀프체크**: 분 칸 배열에 두께를 쌓은 뒤, `cnt[t] >= k`인 분이 연속되는 길이를 `cur`로 세고 `cur > best`일 때만 갱신했는가(`>=`로 갱신하면 동점에서 늦은 구간이 선택된다). 시작 시각은 `t - cur + 1`. 두 자리 패딩을 `printf("%02d:%02d %d\n", ...)`로 시·분 모두에 적용했는가. `NONE`을 출력할 때 `best`가 0 그대로인지로 판별했는가. 첫 예제는 10:00~11:00(두께 2)이 60분, 11:30~12:00이 30분이라 `10:00 60`.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, k;
    cin >> n >> k;
    vector<int> cnt(1440, 0);
    for (int i = 0; i < n; i++) {
        int h1, m1, h2, m2;
        cin >> h1 >> m1 >> h2 >> m2;
        int s = h1 * 60 + m1;
        int e = h2 * 60 + m2;
        for (int t = s; t < e; t++) cnt[t]++;
    }
    int best = 0, best_start = -1, cur = 0;
    for (int t = 0; t < 1440; t++) {
        if (cnt[t] >= k) {
            cur++;
            if (cur > best) {
                best = cur;
                best_start = t - cur + 1;
            }
        } else {
            cur = 0;
        }
    }
    if (best == 0) printf("NONE\n");
    else printf("%02d:%02d %d\n", best_start / 60, best_start % 60, best);
    return 0;
}

(1) 접근·핵심 아이디어

- 7번과 같은 "분 칸 배열"에 두께를 쌓은 뒤, 이번에는 3번처럼 "조건(두께 ≥ k)을 만족하는 칸이 연속으로 몇 개 이어지는가"를 센다. 세 개념(시간 환산·구간 칠하기·연속 길이)의 결합이다.
- 최장 구간의 시작 시각은 "현재 칸 `t`에서 길이 `cur`만큼 되돌아간 곳" `t - cur + 1`이며, 이를 다시 시:분으로 복원한다.

(2) 코드 단계별

- 조명마다 `[시작분, 끝분)`에 `+1`을 쌓는다. 반열림이므로 루프는 `t < e`.
- `t`를 0..1439로 돌며 `cnt[t] >= k`이면 `cur++`, 아니면 `cur = 0`. `cur > best`일 때만 `best`와 `best_start = t - cur + 1`을 갱신한다. 엄격한 `>`가 "길이가 같으면 이른 쪽"이라는 규칙을 자동으로 만든다.
- `best == 0`이면 `NONE`, 아니면 `best_start`를 `/ 60`, `% 60`으로 복원해 `printf("%02d:%02d %d\n", ...)`로 두 자리 패딩 출력.
- 이 풀이는 출력이 전부 `printf`이므로 `ios_base::sync_with_stdio(false)`를 켜지 않았다. `cout`과 `printf`를 섞으면서 동기화를 끄면 두 버퍼가 따로 비워져 출력 순서가 뒤바뀔 수 있다.
- 값이 작으므로(최대 1440) 타입은 전부 `int`로 충분하다.

(3) 스스로 다시 짤 때 생각 순서

- "칠하기 → 조건 칸 연속 길이 → 시작 위치 복원". 동점 규칙(가장 이른 시작)은 "엄격히 클 때만 갱신"으로 자동 처리된다.
- 함정: 둘째 예제처럼 00:00~01:00과 23:00~24:00이 같은 60분이면 먼저 만난 00:00이 남아야 한다. 넷째 테스트처럼 9:00~10:00과 10:00~11:00은 반열림이라 맞닿아 하나의 120분 구간이 된다. 조건을 만족하는 분이 하나도 없으면 `best`가 0 그대로라 `NONE`.
```
