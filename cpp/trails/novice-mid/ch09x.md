## L5. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch09(케이스별로 나누기)의 핵심 — 겹치는 경우 정리, 결과로부터 원인 추론, 좋은 전략만 추려내기, 가능한 상황 나열 — 을 **반복 훈련**하고, 조건 분기가 핵심인 코딩테스트 단골 유형으로 **확장**하는 연습 세트다.
- **반복 훈련 개념**:
  - 구간의 교집합·합집합: 교집합 길이 `max(0, min(e) - max(s))`, 합집합은 `sort` 후 `if (s <= curE) curE = max(curE, e);`
  - 포함-배제: `|A∪B∪C| = |A|+|B|+|C| - |A∩B| - |B∩C| - |A∩C| + |A∩B∩C|`, 배수 개수는 `N / lcm`(정수 나눗셈)
  - 역추론 + 검증: 식을 미지수에 대해 풀고(`long long a = (S + D) / 2;`) 정수·범위 조건을 마지막에 확인
  - 좋은 전략 추리기: 극단(정렬 후 양 끝)만 후보 — `max(a[n-1]*a[n-2]*a[n-3], a[0]*a[1]*a[n-1])`
  - 가능한 상황 나열: 서로 배타적이고 전부를 덮는 `if / else if / else` 사슬, 검사 순서가 곧 정의
- **C++에서 특히 조심할 것**:
  - **음수 나머지** — C++의 `%`는 왼쪽이 음수면 결과도 음수다(`-3 % 2`는 -1, 파이썬은 1). 홀짝 판정은 `x % 2 == 1`이 아니라 `x % 2 != 0`으로 써야 음수에서도 맞는다.
  - **정수 나눗셈 방향** — `-7 / 2`는 C++에서 -3(0 쪽 절삭), 파이썬에서 -4(내림)다. 나누어떨어지는 경우에만 두 언어가 일치한다.
  - **오버플로** — `int`는 약 21억까지다. 세 수의 곱, `x * y`로 만드는 lcm, 합계 누적은 습관적으로 `long long`을 쓰고 **곱하기 전에** 캐스팅한다.
  - `sort`는 **제자리 정렬**이라 원본이 바뀐다. 파이썬 `sorted(B)`처럼 "정렬본을 따로" 두려면 `vector<int> S = B; sort(S.begin(), S.end());`로 복사부터 한다.
  - `vector`끼리는 `==`로 내용 비교가 되지만, 날 배열(`int a[10]`)끼리의 `==`는 **주소 비교**라 의도한 결과가 나오지 않는다.
- **코딩테스트 출제 맵**: NeetCode 150의 'Intervals'(구간 병합·겹침), 『이것이 취업을 위한 코딩테스트다』의 '구현'·'그리디' 파트, solved.ac CLASS 2의 조건 분기·수학 문제에서 이 유형이 등장한다.
- **문제 구성표**:

**문제**

**1) 전원이 동시에 접속한 시간** · Easy

- **요구사항**: N명이 각각 접속 시각 s부터 종료 시각 e까지 온라인이다(분 단위, 구간 [s, e]). **N명 모두가 동시에** 온라인인 시간의 길이(분)를 구하라. 그런 시간이 없으면 0.
- **입력**: 첫 줄에 N (1 ≤ N ≤ 50). 이어 N줄에 s e (0 ≤ s < e ≤ 1440).
- **출력**: 전원 동시 접속 시간의 길이.
- **예제**: `3 / 60 180 / 120 240 / 100 200` → `60` (120~180) · `2 / 0 100 / 100 200` → `0` (한 점에서 맞닿아도 길이는 0)
- **셀프체크**: 여러 구간의 교집합은 "가장 늦은 시작 ~ 가장 이른 끝"이다. 끝이 시작보다 앞서면 음수가 되므로 `max(0, ...)`로 막아야 한다. C++의 `max`는 **두 인자의 타입이 같아야** 하므로 `max(0, hi - lo)`처럼 둘 다 `int`인지 확인한다(`long long`이 섞이면 `max(0LL, ...)`). N=1이면 그 구간 길이 그대로.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    vector<int> ss(N), ee(N);
    for (int i = 0; i < N; i++) cin >> ss[i] >> ee[i];

    int lo = ss[0];
    int hi = ee[0];
    for (int i = 0; i < N; i++) {
        if (ss[i] > lo) lo = ss[i];
        if (ee[i] < hi) hi = ee[i];
    }
    cout << max(0, hi - lo) << '\n';
    return 0;
}
@@TESTS

@@EXPL
(1) 접근·핵심 아이디어

- 모두가 동시에 온라인인 시간 = 모든 구간의 교집합이다. 교집합의 시작은 "가장 늦은 시작", 끝은 "가장 이른 끝"이므로 구간을 하나씩 보며 최대 시작과 최소 끝만 유지하면 된다.
- 겹치지 않는 경우 `hi < lo`가 되어 길이가 음수로 나오므로, `max(0, 길이)`로 잘라 0을 답한다. 한 점에서 맞닿는 경우(둘째 예제)도 길이 0이다.

(2) 코드 단계별

- N을 읽고 `ss`, `ee` 두 배열에 구간을 담는다.
- `lo`, `hi`를 첫 구간의 값으로 초기화한다. `INT_MIN`/`INT_MAX`로 시작해도 되지만 첫 원소로 초기화하는 쪽이 오버플로 걱정이 없다.
- 구간을 차례로 보며 `ss[i] > lo`면 `lo = ss[i]`, `ee[i] < hi`면 `hi = ee[i]`로 갱신한다. `lo = max(lo, ss[i]);`로 써도 같다.
- `max(0, hi - lo)`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "겹치는 부분"을 구하는 문제 → 교집합 = [max 시작, min 끝].
- 교집합이 비면 길이가 음수 → 0으로 절단하는 것이 함정.
- `max`/`min`은 템플릿이라 인자 타입이 다르면 컴파일 오류가 난다. 섞였다면 한쪽을 캐스팅하거나 `max<long long>(a, b)`처럼 타입을 명시한다.
- 맞닿는 경우(0)와 N=1(구간 길이 그대로)로 검산.
```

**2) 합과 차로 두 자연수 복원** · Easy

- **요구사항**: 두 자연수 a, b(각 1 이상)가 있었는데 값을 잊어버렸고, 합 S = a + b와 차 D = a − b만 기억한다. a와 b를 복원하라. 조건을 만족하는 자연수 쌍이 없으면 `-1`.
- **입력**: 한 줄에 S와 D (2 ≤ S ≤ 10^9, |D| ≤ 10^9).
- **출력**: `a b`를 공백으로 구분해 한 줄에. 불가능하면 `-1`.
- **예제**: `10 4` → `7 3` · `7 2` → `-1` (S+D가 홀수라 정수 해가 없음)
- **셀프체크**: 두 식을 더하면 `2a = S + D`, 빼면 `2b = S − D`. S+D가 홀수면 정수 해가 없고, 짝수여도 a나 b가 0 이하이면 자연수가 아니다(셋째 테스트: b=0). D가 음수면 a < b인 정상적인 경우다(넷째 테스트). **C++ 함정 둘**: S+D는 최대 2×10^9로 `int` 한계(약 2.147×10^9)에 아슬아슬하니 `long long`으로 받는다. 그리고 S+D가 음수일 수 있으므로 홀짝 판정을 `(S + D) % 2 == 1`로 쓰면 안 된다 — 음수 홀수는 C++에서 `-1`이 나온다. `!= 0`으로 비교해야 안전하다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    long long S, D;
    cin >> S >> D;

    if ((S + D) % 2 != 0) {
        cout << -1 << '\n';
        return 0;
    }

    long long a = (S + D) / 2;
    long long b = (S - D) / 2;
    if (a >= 1 && b >= 1) {
        cout << a << ' ' << b << '\n';
    } else {
        cout << -1 << '\n';
    }
    return 0;
}
@@TESTS

--IN

--OUT

--IN

--OUT

@@EXPL
(1) 접근·핵심 아이디어

- 관찰(합과 차)로부터 원인(원래 두 수)을 역으로 알아내는 추론 문제다. 정방향 규칙 `S = a + b`, `D = a − b`를 미지수에 대해 풀면 `a = (S + D) / 2`, `b = (S − D) / 2`로 후보가 단 하나 나온다.
- 후보가 나왔다고 끝이 아니다. 문제의 도메인 제약(정수이고 1 이상)을 통과하는지 검증해야 하며, 어긋나면 "복원 불가(-1)"다.

(2) 코드 단계별

- `long long S, D;`로 받는다. 값 자체는 `int`에 들어가지만 `S + D`가 2×10^9까지 커져 `int` 한계를 넘길 수 있다. 입력 변수를 처음부터 넓게 잡는 것이 가장 안전한 습관이다.
- `(S + D) % 2 != 0`이면 정수 해가 없으므로 `-1`. `== 1`로 쓰면 S+D가 음수 홀수일 때 `%`가 `-1`을 내놓아 조건이 거짓이 되고, 그대로 나눗셈으로 진행해 틀린 답을 출력한다.
- `a = (S + D) / 2`, `b = (S - D) / 2`를 계산한다(S+D가 짝수면 S−D도 짝수이므로 나누어떨어져 절삭 방향이 문제 되지 않는다).
- `a >= 1 && b >= 1`이면 `a << ' ' << b`, 아니면 `-1`.

(3) 스스로 다시 짤 때 생각 순서

- 관찰 → 식 세우기 → 미지수에 대해 풀기.
- 정수 조건(홀짝)과 범위 조건(≥ 1)을 순서대로 검증하는 것이 함정.
- 입력 범위를 보고 "더하면 넘치는가"를 먼저 계산해 타입을 정한다.
- 홀짝은 `% 2 != 0`. D가 음수인 경우와 b=0이 되는 경계로 검산.
```

**3) 곱의 부호만 알아내기** · Easy

- **요구사항**: N개의 정수를 모두 곱한 값의 **부호**만 알아내라. 실제로 곱하지 말고 케이스를 나누어 판정한다.
- **입력**: 첫 줄에 N (1 ≤ N ≤ 50). 둘째 줄에 N개의 정수 (각 |값| ≤ 10^9).
- **출력**: 곱이 0이면 `0`, 양수면 `+`, 음수면 `-`.
- **예제**: `3 / -2 5 -3` → `+` · `4 / 1 -1 0 9` → `0`
- **셀프체크**: 케이스는 "0이 하나라도 있음 / 없으면 음수 개수가 홀수 / 짝수" 세 가지로 서로 배타적이고 전부를 덮는다. 0 검사를 **먼저** 해야 한다(0이 있으면 음수 개수와 무관). 양수는 부호에 영향이 없으므로 세지 않아도 된다. 실제로 곱하면 안 되는 이유가 C++에서는 더 절실하다 — 값이 10^9급이라 두 개만 곱해도 `int`는 물론 `long long`(약 9.2×10^18)도 금세 넘긴다. 출력은 `"+"`/`"-"` 문자열이나 `'+'`/`'-'` 문자 어느 쪽으로 해도 되지만 `cout << 0`과 `cout << '0'`은 같은 결과다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    int neg = 0;
    bool zero = false;
    for (int i = 0; i < N; i++) {
        int x;
        cin >> x;
        if (x == 0) {
            zero = true;
        } else if (x < 0) {
            neg++;
        }
    }

    if (zero) {
        cout << 0 << '\n';
    } else if (neg % 2 == 1) {
        cout << "-" << '\n';
    } else {
        cout << "+" << '\n';
    }
    return 0;
}
@@TESTS
--IN

--OUT

--IN

1 -1 0 9
--OUT
0
--IN
1
-7
--OUT

--IN
2
3 4
--OUT
+
@@EXPL
(1) 접근·핵심 아이디어

- 곱의 부호는 두 정보로 결정된다: 0이 포함되어 있는가, 음수가 몇 개인가(홀수면 음수, 짝수면 양수). 양수는 부호를 바꾸지 않는다.
- 케이스를 "0 있음 → 0", "음수 홀수 → −", "그 외 → +"로 나누면 배타적이고 빠짐없다. 0 판정이 다른 두 케이스보다 우선한다는 순서가 핵심이다.

(2) 코드 단계별

- 값을 배열에 담을 필요도 없다. 읽으면서 바로 `x == 0`이면 `zero = true`, `x < 0`이면 `neg++`.
- `zero`면 `0`, 아니면 `neg % 2`로 `-`/`+`를 출력한다.
- 여기서 `neg`는 개수라 항상 0 이상이므로 `% 2 == 1`을 써도 안전하다. 음수가 들어올 수 있는 값이라면 `% 2 != 0`으로 써야 한다는 점을 구분해 두자.

(3) 스스로 다시 짤 때 생각 순서

- "케이스를 가르는 축"을 먼저 정한다 → 0의 존재, 음수 개수의 홀짝.
- 검사 순서: 0 → 홀짝. 순서가 바뀌면 `0 × (음수)`가 `-`로 잘못 나온다.
- "실제로 곱하지 않는다"는 요구는 오버플로 회피이기도 하다. 부호만 필요하면 부호만 추적한다.
- N=1(음수 하나)·양수만 있는 경우로 검산.
```

**4) 겹치는 예약 덩어리 세기** · Medium

- **요구사항**: 수직선 위에 N개의 예약 구간 [s, e]가 있다. 서로 겹치거나 **끝점이 맞닿는** 구간들은 하나의 덩어리로 이어진다. 덩어리의 **개수**와 **가장 긴 덩어리의 길이**를 구하라.
- **입력**: 첫 줄에 N (1 ≤ N ≤ 100). 이어 N줄에 s e (0 ≤ s < e ≤ 10^4).
- **출력**: `덩어리수 최장길이`를 공백으로 구분해 한 줄에.
- **예제**: `4 / 1 3 / 2 6 / 8 10 / 15 18` → `3 5` ([1,6], [8,10], [15,18]) · `3 / 0 5 / 5 9 / 9 12` → `1 12` (맞닿아 하나로 이어짐)
- **셀프체크**: 시작 기준 정렬 후 "현재 덩어리의 끝 `curE`"를 유지하며, 새 구간의 시작이 `curE` **이하**(맞닿음 포함)면 병합하고 끝을 `max`로 늘린다. 구간은 `vector<pair<int,int>>`에 담고 `sort`하면 `pair`의 기본 비교(첫 원소 먼저, 같으면 둘째)가 파이썬 튜플 정렬과 똑같이 동작한다. 완전히 포함되는 구간([1,10] 안의 [2,3])은 끝을 줄이면 안 된다(넷째 테스트). 마지막 덩어리를 반복이 끝난 뒤 한 번 더 집계하는 것을 잊지 말 것.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    vector<pair<int, int>> segs(N);
    for (int i = 0; i < N; i++) cin >> segs[i].first >> segs[i].second;

    sort(segs.begin(), segs.end());

    int groups = 0;
    int longest = 0;
    int curS = segs[0].first;
    int curE = segs[0].second;
    for (int i = 1; i < N; i++) {
        int s = segs[i].first;
        int e = segs[i].second;
        if (s <= curE) {
            if (e > curE) curE = e;
        } else {
            groups++;
            if (curE - curS > longest) longest = curE - curS;
            curS = s;
            curE = e;
        }
    }
    groups++;
    if (curE - curS > longest) longest = curE - curS;

    cout << groups << ' ' << longest << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- 겹치는 구간을 하나로 합치는 합집합 문제다. 시작점 기준으로 정렬하면, 각 구간은 "현재 덩어리에 붙는다" 또는 "새 덩어리를 시작한다" 둘 중 하나의 케이스로만 떨어진다.
- 붙는 조건은 `s <= curE`(맞닿음 포함). 붙을 때 덩어리의 끝은 `max(curE, e)`로만 늘려야 하고, 완전히 포함된 구간 때문에 끝이 줄어들면 안 된다.

(2) 코드 단계별

- 구간을 `vector<pair<int,int>>`로 읽는다. `segs[i].first`가 시작, `.second`가 끝이다. `sort(segs.begin(), segs.end())`는 비교자를 주지 않아도 시작점 오름차순(같으면 끝점 오름차순)으로 정렬한다.
- 첫 구간을 현재 덩어리 `curS`, `curE`로 둔다.
- 두 번째 구간부터: `s <= curE`면 `curE = max(curE, e)`. 아니면 현재 덩어리를 집계(개수 +1, 최장 갱신)하고 새 덩어리로 교체.
- 반복이 끝난 뒤 마지막 덩어리를 한 번 더 집계하고 `groups << ' ' << longest`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- 정렬 → 스위핑 → "붙는다 / 새로 시작" 두 케이스.
- 맞닿음 포함(`<=`), 끝은 `max`로만 갱신, 마지막 덩어리 집계 — 세 가지 함정.
- 정렬 기준을 직접 정해야 한다면 `sort(v.begin(), v.end(), [](auto& a, auto& b){ return a.second < b.second; })`처럼 람다를 준다. 이때 비교자는 **strict weak ordering**이어야 하므로 `<=`를 쓰면 안 된다 — 같은 값끼리 "둘 다 앞선다"가 되어 런타임 오류로 죽는다.
- N=1과 하나에 전부 포함되는 경우로 검산.
```

**5) 어느 배수도 아닌 수 세기** · Medium

- **요구사항**: 1 이상 N 이하의 정수 중 a의 배수도, b의 배수도, c의 배수도 **아닌** 수의 개수를 구하라. N이 크므로 반복문으로 세지 말고 포함-배제로 계산한다.
- **입력**: 한 줄에 N a b c (1 ≤ N ≤ 10^9, 1 ≤ a, b, c ≤ 1000).
- **출력**: 조건을 만족하는 수의 개수.
- **예제**: `10 2 3 5` → `2` (1, 7) · `20 4 6 10` → `12`
- **셀프체크**: 세 집합의 합집합 크기는 `|A|+|B|+|C| − |A∩B| − |B∩C| − |A∩C| + |A∩B∩C|`. 교집합의 배수 개수는 곱이 아니라 **최소공배수**로 나눠야 한다(4와 6의 공배수는 24가 아니라 12의 배수). C++에서 lcm은 `x * y / gcd(x, y)`인데 이대로 쓰면 곱이 먼저 계산돼 넘칠 수 있다 — `x / gcd(x, y) * y`처럼 **먼저 나누고 곱하는** 순서로, 게다가 `long long`으로 쓴다. a=b=c처럼 같은 수가 들어와도 식이 그대로 맞는지(넷째 테스트), 전부 1이면 답이 0인지(셋째 테스트) 확인.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

long long gcdOf(long long x, long long y) {
    while (y != 0) {
        long long t = x % y;
        x = y;
        y = t;
    }
    return x;
}

long long lcmOf(long long x, long long y) {
    return x / gcdOf(x, y) * y;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    long long N, a, b, c;
    cin >> N >> a >> b >> c;

    long long ab = lcmOf(a, b);
    long long bc = lcmOf(b, c);
    long long ac = lcmOf(a, c);
    long long abc = lcmOf(ab, c);

    long long bad = N / a + N / b + N / c - N / ab - N / bc - N / ac + N / abc;
    cout << N - bad << '\n';
    return 0;
}
@@TESTS

--OUT

--IN

--OUT

--IN
1 1 1 1
--OUT
0
--IN

--OUT

@@EXPL
(1) 접근·핵심 아이디어

- "어느 배수도 아닌 수" = N − (a·b·c 중 하나라도의 배수인 수). 후자는 세 집합의 합집합이라 단순 합산하면 겹치는 수가 여러 번 세어진다. 3집합 포함-배제로 겹침을 정리한다.
- k의 배수 개수는 `N / k`(정수 나눗셈)이고, 두 수의 공배수는 lcm의 배수이므로 교집합 항은 `N / lcm`으로 계산한다. N이 10^9라도 전부 O(1) 계산이다.

(2) 코드 단계별

- 유클리드 호제법으로 `gcdOf`를 만들고 `lcmOf(x, y) = x / gcdOf(x, y) * y`로 정의한다. **나누기를 먼저** 하는 이 순서가 중요하다. `x * y / gcd`는 수학적으로 같지만 `x * y`가 중간에 넘칠 수 있다.
- 쌍의 lcm 세 개와 셋의 lcm(`lcmOf(ab, c)`)을 구한다. 세 수가 모두 1000 근처의 서로소면 abc가 10^9에 가까워지므로 `long long`이 필요하다.
- `bad = N/a + N/b + N/c − N/ab − N/bc − N/ac + N/abc`.
- `N − bad`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "하나라도 해당"은 합집합 → 포함-배제, 3집합이면 항이 7개.
- 교집합은 곱이 아닌 lcm — 가장 흔한 실수.
- lcm 계산은 `나누고 나서 곱하기` + `long long`. C++17이라면 `<numeric>`의 `std::lcm`을 써도 되지만, 이 순서 문제를 알고 쓰는 것과 모르고 쓰는 것은 다르다.
- 같은 수가 반복되거나 전부 1인 경계로 검산.
```

**6) 뒤집힌 구간 찾기** · Medium

- **요구사항**: 서로 다른 정수로 이루어진 오름차순 배열이 있었는데, 누군가 **연속한 구간 하나를 뒤집어** 지금의 배열 B가 되었다(구간 길이 1이면 변화 없음). B를 보고 원래대로 되돌리기 위해 뒤집어야 할 구간 `[l, r]`(1부터 시작하는 번호)을 찾아라. B가 이미 오름차순이면 `0 0`, 구간 하나를 뒤집어서는 정렬이 안 되면 `-1`.
- **입력**: 첫 줄에 N (1 ≤ N ≤ 100). 둘째 줄에 서로 다른 N개의 정수.
- **출력**: `l r` 또는 `0 0` 또는 `-1`.
- **예제**: `6 / 1 5 4 3 2 6` → `2 5` · `5 / 3 1 2 5 4` → `-1`
- **셀프체크**: 원래 배열은 B의 정렬본이다. 파이썬 `sorted(B)`는 새 리스트를 돌려주지만 C++ `sort`는 **제자리 정렬**이라 원본이 사라진다 — `vector<int> S = B;`로 복사한 뒤 `S`만 정렬해야 B와 비교할 수 있다. 정렬본과 다른 **첫 위치 l과 마지막 위치 r**을 찾으면 후보 구간은 그것뿐이지만, 그 구간을 실제로 뒤집어 정렬본과 같은지 **재현 검증**해야 한다(둘째 예제는 다른 위치가 [1,5]이지만 뒤집어도 정렬이 안 된다). 뒤집기는 `reverse(v.begin()+l, v.begin()+r+1)`로, **끝은 하나 뒤**를 가리키는 반열림 구간임에 주의. 배열 비교는 `vector`끼리 `==`로 하면 내용 비교가 된다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    vector<int> B(N);
    for (int i = 0; i < N; i++) cin >> B[i];

    vector<int> S = B;
    sort(S.begin(), S.end());

    int l = 0;
    while (l < N && B[l] == S[l]) l++;
    if (l == N) {
        cout << 0 << ' ' << 0 << '\n';
        return 0;
    }

    int r = N - 1;
    while (B[r] == S[r]) r--;

    vector<int> C = B;
    reverse(C.begin() + l, C.begin() + r + 1);
    if (C == S) {
        cout << l + 1 << ' ' << r + 1 << '\n';
    } else {
        cout << -1 << '\n';
    }
    return 0;
}

--IN

(1) 접근·핵심 아이디어

- 결과 B에서 "무슨 일이 있었나"를 역으로 추론한다. 원래 상태는 정렬본 S이므로, B와 S가 다른 자리들이 곧 뒤집힌 구간의 흔적이다. 다른 자리의 첫 위치 l과 마지막 위치 r 사이가 유일한 후보다.
- 후보를 얻었다고 끝이 아니다. `[l, r]`을 실제로 뒤집어 S와 같아지는지 재현 검증해야 한다. 다른 자리가 l..r 안에 있어도 그 안의 순서가 "정확히 뒤집힌 형태"가 아닐 수 있기 때문이다(둘째 예제).

(2) 코드 단계별

- `vector<int> S = B;`로 복사한 뒤 `sort(S.begin(), S.end())`. 복사를 건너뛰고 `sort(B...)`를 부르면 비교 대상인 원본이 사라진다.
- 앞에서부터 `B[l] == S[l]`인 동안 l을 올린다. `l == N`이면 이미 정렬 → `0 0`.
- 뒤에서부터 `B[r] == S[r]`인 동안 r을 내린다(l에서 이미 다른 자리가 있으므로 r ≥ l에서 멈춘다 — 그래서 아래쪽 범위 검사가 필요 없다).
- `C = B`를 복사해 `reverse(C.begin() + l, C.begin() + r + 1)`로 뒤집는다. STL의 구간은 `[first, last)` 반열림이라 **끝을 하나 더** 줘야 r까지 포함된다.
- `C == S`면 `l+1 r+1`, 아니면 `-1`. `vector`의 `==`는 원소를 하나씩 비교한다.

(3) 스스로 다시 짤 때 생각 순서

- "원래 상태"를 먼저 복원(정렬)하고 관찰과 비교해 달라진 범위를 찾는다.
- 파이썬 `sorted`(새 리스트) vs C++ `sort`(제자리) 차이를 의식해 복사부터 한다.
- 후보는 하나뿐이지만 반드시 재현해서 검증한다.
- 반열림 구간 `+1`, 이미 정렬(0 0), 전체 뒤집힘(1 N), 검증 실패(-1)로 검산.
```

**7) 세 수의 곱 최대: 후보는 양 끝뿐** · Medium

- **요구사항**: N개의 정수(음수 포함 가능) 중 **서로 다른 세 개**를 골라 곱을 최대로 만들어라. 모든 세 개 조합을 보지 말고, 정렬 후 "좋은 후보"만 비교해서 풀라.
- **입력**: 첫 줄에 N (3 ≤ N ≤ 200). 둘째 줄에 N개의 정수 (각 |값| ≤ 1000).
- **출력**: 세 수 곱의 최댓값.
- **예제**: `5 / 1 2 3 4 5` → `60` · `5 / -10 -9 1 2 3` → `270` (음수 둘 × 가장 큰 양수)
- **셀프체크**: 최대 곱은 "가장 큰 세 수의 곱" 또는 "가장 작은 두 수(큰 음수 둘) × 가장 큰 수" 둘 중 하나다 — 다른 조합은 이 둘 중 하나에 지배당한다. 파이썬의 `a[-1]`, `a[-2]` 같은 **음수 인덱스는 C++에 없다**. `a[n-1]`, `a[n-2]`, `a[n-3]`으로 바꿔 써야 하며, 실수로 `a[-1]`을 쓰면 오류 없이 배열 앞쪽의 엉뚱한 메모리를 읽는다. 곱은 세 번 겹치므로 `long long`으로 계산한다(1000^3 = 10^9은 `int`에 겨우 들어가지만 값이 조금만 커져도 넘친다). 전부 음수면 "가장 큰 세 수"가 답(셋째 테스트). 0이 섞이면 0이 답일 수 있다(넷째 테스트).

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    vector<long long> a(N);
    for (int i = 0; i < N; i++) cin >> a[i];

    sort(a.begin(), a.end());

    long long c1 = a[N - 1] * a[N - 2] * a[N - 3];
    long long c2 = a[0] * a[1] * a[N - 1];
    cout << max(c1, c2) << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- 세 개 조합을 전부 보면 O(N^3)이지만, 곱을 최대로 만드는 조합은 극단값에서만 나온다. 양수끼리 크게 만들려면 가장 큰 셋, 음수 둘을 곱해 양수로 만들려면 가장 작은 둘 + 가장 큰 하나. 이 두 후보 외의 조합은 둘 중 하나로 바꿔도 손해가 없으므로(교환 논증) 볼 필요가 없다.
- 전부 음수일 때도 "가장 큰 셋"(절댓값이 가장 작은 셋)이 후보 1에 들어 있어 같은 식으로 처리된다.

(2) 코드 단계별

- 배열을 `vector<long long>`으로 받아 오름차순 정렬한다. 처음부터 넓은 타입으로 받으면 곱셈마다 캐스팅을 신경 쓸 필요가 없다.
- `c1 = a[N-1] * a[N-2] * a[N-3]`(최대 셋), `c2 = a[0] * a[1] * a[N-1]`(최소 둘 × 최대 하나).
- `max(c1, c2)`를 출력한다. 두 값 모두 `long long`이라 `max`의 타입 추론이 어긋나지 않는다.

(3) 스스로 다시 짤 때 생각 순서

- "좋은 후보만 남기기": 정렬 후 양 끝 조합 두 개만.
- 파이썬의 뒤에서 세는 인덱스를 `N-1`, `N-2`, `N-3`으로 번역한다. N ≥ 3이 보장돼야 `a[N-3]`이 유효하다는 점도 확인.
- 곱셈이 세 번이면 자릿수가 세 배 — 타입부터 넓힌다.
- 전부 음수(답이 음수), 0 포함, N=3(두 후보가 같은 조합)으로 검산.
```

**8) 두 구간의 관계 분류** · Hard

- **요구사항**: 닫힌 구간 A = [a1, b1]과 B = [a2, b2] 쌍이 Q개 주어진다. 각 쌍의 관계를 다음 여섯 가지 중 정확히 하나로 분류하라. `SAME`(완전히 같음), `APART`(떨어져 있음, 공통점 없음), `TOUCH`(끝점 하나에서만 만남), `CONTAIN`(A가 B를 포함, 같지는 않음), `INSIDE`(A가 B 안에 포함, 같지는 않음), `CROSS`(일부만 겹침).
- **입력**: 첫 줄에 Q (1 ≤ Q ≤ 50). 이어 Q줄에 a1 b1 a2 b2 (0 ≤ a1 < b1 ≤ 1000, 0 ≤ a2 < b2 ≤ 1000).
- **출력**: Q줄에 각 쌍의 분류 문자열.
- **예제**: `3 / 1 4 3 8 / 1 5 5 9 / 2 4 1 9` → `CROSS / TOUCH / INSIDE` · `3 / 1 5 1 5 / 1 5 2 5 / 1 2 5 7` → `SAME / CONTAIN / APART`
- **셀프체크**: 여섯 케이스가 배타적이고 전부를 덮게 하려면 **검사 순서**가 정의의 일부다: 같음 → 떨어짐 → 맞닿음 → 포함 → 안에 포함 → 나머지(부분 겹침). 예를 들어 [1,5]와 [2,5]는 끝점 5를 공유하지만 맞닿음(`b1 == a2` 또는 `b2 == a1`)이 아니라 포함이다. 같음을 포함보다 먼저 검사해야 `CONTAIN`으로 새지 않는다. C++에서는 `else if` 사슬이 파이썬 `elif`와 정확히 같은 역할을 한다 — `if`만 나열하면 조건이 겹쳐 여러 줄이 출력된다.

```runner
@@SOLUTION
#include <bits/stdc++.h>

(1) 접근·핵심 아이디어

- 두 구간의 위치 관계는 겹침 판정(`b1 < a2 || b2 < a1`이면 안 겹침)에서 출발해, 겹치는 경우를 다시 "끝점만 공유 / 한쪽이 다른 쪽을 포함 / 일부만 겹침"으로 세분하는 케이스 나열 문제다.
- 여섯 케이스가 서로 배타적이면서 전부를 덮도록 만드는 열쇠는 검사 순서다. 앞 조건에서 걸러진 것을 전제로 뒤 조건을 단순하게 쓸 수 있다: 같음을 먼저 빼면 포함 조건에 `<=`를 써도 `SAME`과 겹치지 않고, 떨어짐·맞닿음을 먼저 빼면 마지막 `else`가 정확히 "일부만 겹침"이 된다.

(2) 코드 단계별

- 각 쌍에 대해 `a1 == a2 && b1 == b2`면 `SAME`.
- `b1 < a2 || b2 < a1`이면 `APART`(공통점 없음).
- `b1 == a2 || b2 == a1`이면 `TOUCH`(앞에서 떨어짐이 걸러졌으므로 이 등호는 정확히 한 점 공유).
- `a1 <= a2 && b2 <= b1`이면 `CONTAIN`, `a2 <= a1 && b1 <= b2`면 `INSIDE`, 나머지는 `CROSS`.
- 결과를 줄마다 `cout << ans << '\n'`으로 출력한다. `endl`은 매번 출력 버퍼를 비워 느리므로 반복 출력에서는 `'\n'`을 쓴다.

(3) 스스로 다시 짤 때 생각 순서

- 큰 분기: 안 겹침(떨어짐/맞닿음) vs 겹침(같음/포함/부분).
- 검사 순서를 정의의 일부로 삼고, 각 단계에서 "앞에서 무엇이 걸러졌나"를 의식한다. `else if` 사슬이어야 이 전제가 성립한다.
- 논리 연산자는 `and`/`or`가 아니라 `&&`/`||`. 그리고 `&`(비트 AND)는 `==`보다 **우선순위가 낮아** `a & 1 == 1`이 `a & (1 == 1)`로 묶인다 — 파이썬과 반대이니 비트 연산은 괄호로 감싼다.
- [1,5]·[2,5]처럼 끝점을 공유하지만 포함인 경우, 한 점 맞닿음, 완전 동일로 검산.
```

**9) 영수증으로 주차 시간 범위 추론** · Hard

- **요구사항**: 주차장 요금은 이렇다. 주차 시간이 **30분 이하**면 기본요금 B원. 30분을 넘기면 초과분 **10분마다**(10분 미만도 10분으로 올림) U원씩 추가된다. 단, 하루 요금은 **최대 M원**을 넘지 않는다. 영수증에 요금 F원이 찍혀 있을 때, 주차 시간(1분 이상 1440분 이하의 정수)으로 가능한 **최솟값과 최댓값**을 구하라. 그런 시간이 없으면 `-1`.
- **입력**: 한 줄에 B U M F (1 ≤ B ≤ M ≤ 10^5, 1 ≤ U ≤ 10^4, 0 ≤ F ≤ 10^6).
- **출력**: `최소분 최대분`을 공백으로 구분해 한 줄에. 불가능하면 `-1`.
- **예제**: `1000 500 5000 2000` → `41 50` (초과 2단위: 초과분 11~20분) · `1000 500 5000 5000` → `101 1440` (상한 도달)
- **셀프체크**: 정방향 규칙(시간 → 요금)을 케이스 세 개(기본 / 초과 단위 계산 / 상한 절단)로 정확히 세운 뒤, 시간 후보 1..1440을 **전부 대입해 요금이 F인 것의 최소·최대**를 취하는 역추론이다. 올림은 `(t - 30 + 9) / 10` — C++ 정수 나눗셈이 0 방향 절삭이라 **피제수가 양수일 때만** 이 관용구가 올림이 된다(`t > 30`인 가지 안에서만 쓰므로 안전). 요금은 `B + units*U`가 최대 10^5 + 141×10^4 ≈ 1.5×10^7로 `int`에 들어가지만, 단위 요금이 커지는 변형이면 `long long`을 쓴다. 기본요금과 같은 F는 1~30분(셋째 테스트), 어느 단위에도 안 맞는 F는 `-1`(넷째 테스트).

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    long long B, U, M, F;
    cin >> B >> U >> M >> F;

    long long lo = -1;
    long long hi = -1;
    for (int t = 1; t <= 1440; t++) {
        long long fee;
        if (t <= 30) {
            fee = B;
        } else {
            long long units = (t - 30 + 9) / 10;
            fee = B + units * U;
            if (fee > M) fee = M;
        }
        if (fee == F) {
            if (lo == -1) lo = t;
            hi = t;
        }
    }

    if (lo == -1) {
        cout << -1 << '\n';
    } else {
        cout << lo << ' ' << hi << '\n';
    }
    return 0;
}

@@EXPL
(1) 접근·핵심 아이디어

- 관찰(요금 F)로부터 원인(주차 시간)을 추론한다. 요금 규칙을 역으로 풀어 식으로 만들 수도 있지만 케이스(기본/초과/상한)마다 식이 달라 실수하기 쉽다. 대신 원인의 후보가 1..1440분으로 유한하므로, **정방향 규칙을 정확히 세운 뒤 모든 후보를 대입해 검증**하는 것이 안전하다.
- 정방향 규칙은 세 케이스다: 30분 이하는 B, 초과분은 10분 단위 올림 × U를 더하되, M을 넘으면 M으로 절단.

(2) 코드 단계별

- B, U, M, F를 `long long`으로 읽고 `lo = hi = -1`로 시작한다.
- t를 1..1440으로 돌며 요금을 계산한다: `t <= 30`이면 B, 아니면 `units = (t - 30 + 9) / 10`, `fee = B + units*U`, `fee > M`이면 `fee = M`.
- 올림 관용구 `(x + d - 1) / d`는 x가 0 이상일 때만 성립한다. C++ 나눗셈은 음수에서 0 쪽으로 절삭하므로 음수 피제수에 그대로 쓰면 결과가 어긋난다 — 여기서는 `t > 30`이므로 `t - 30`이 항상 양수라 안전하다.
- `fee == F`이면 첫 t를 `lo`에, 매번 `hi`를 갱신한다(오름차순이므로 마지막이 최대).
- `lo`가 -1이면 불가능, 아니면 `lo << ' ' << hi`.

(3) 스스로 다시 짤 때 생각 순서

- 정방향 규칙을 케이스별로 먼저 정확히 세운다(올림, 상한).
- 후보가 유한하면 역산 대신 전수 대입으로 검증하는 것이 안전.
- 올림 나눗셈은 피제수의 부호를 확인하고 쓴다. 음수까지 다뤄야 하면 `floor`/`ceil`을 직접 구현하거나 조건 분기를 둔다.
- 기본요금 구간(1~30), 상한 구간(끝이 1440), 불가능(-1)으로 검산.
```

**10) 상점 하나 건너뛰기 최소 이동** · Hard

- **요구사항**: 수직선 위 원점 0에서 출발해 N개의 상점(좌표 x_i)을 방문한다. 순서는 자유이고 마지막에 돌아올 필요는 없다. 단, **최대 한 곳은 건너뛰어도** 된다. 필요한 **최소 이동 거리**를 구하라. 모든 건너뛰기 후보를 보지 말고 "좋은 후보"만 비교해서 풀라.
- **입력**: 첫 줄에 N (1 ≤ N ≤ 100). 둘째 줄에 N개의 정수 좌표 (각 |값| ≤ 10^4).
- **출력**: 최소 이동 거리.
- **예제**: `4 / -3 5 -8 2` → `11` (−8을 건너뛰고 −3 → 5: 3+3+5) · `3 / 4 9 1` → `4` (9를 건너뛰면 4까지만)
- **셀프체크**: 가장 왼쪽 상점 L(≤ 0)과 가장 오른쪽 상점 R(≥ 0)이 정해지면 최소 거리는 `min(2|L| + R, 2R + |L|)`(가까운 쪽을 먼저 다녀온다)이다. 중간 상점을 건너뛰어도 L, R이 그대로라 이득이 없으므로, 건너뛸 후보는 **가장 왼쪽 또는 가장 오른쪽** 둘뿐이다. 파이썬의 `xs[1:]`·`xs[:-1]` 같은 슬라이스는 C++에 없으니 **구간 [lo, hi]를 인덱스로 넘기는 함수**로 바꾼다. 이때 벡터는 `const vector<int>&`(참조)로 받아야 호출할 때마다 통째로 복사되지 않는다. 모든 상점이 한쪽에만 있으면 L 또는 R이 0이 되어 식이 자연스럽게 "가장 먼 상점까지"가 된다. N=1이면 그 하나를 건너뛰어 0(구간이 비면 `lo > hi`로 판정).

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

long long cost(const vector<int>& xs, int lo, int hi) {
    if (lo > hi) return 0;
    long long L = min(0, xs[lo]);
    long long R = max(0, xs[hi]);
    return min(2 * (-L) + R, 2 * R + (-L));
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    vector<int> xs(N);
    for (int i = 0; i < N; i++) cin >> xs[i];

    sort(xs.begin(), xs.end());

    long long skipLeft = cost(xs, 1, N - 1);
    long long skipRight = cost(xs, 0, N - 2);
    cout << min(skipLeft, skipRight) << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- 상점 집합이 정해지면 이동 거리는 양 끝 L, R로만 결정된다: 한쪽을 먼저 갔다 돌아와 반대쪽으로 가므로 `min(2|L| + R, 2R + |L|)`. 이 값은 |L|과 R이 작을수록 좋다.
- "무엇을 건너뛸까"는 N가지지만, 중간 상점을 건너뛰면 L, R이 안 바뀌어 이득이 없다. 즉 가장 왼쪽 또는 가장 오른쪽을 건너뛰는 두 전략만 좋은 후보이고, 나머지는 지배당하므로 버린다. 건너뛰기는 손해가 없으므로 "안 건너뛰기"도 볼 필요가 없다.

(2) 코드 단계별

- 좌표를 정렬한다.
- `cost(const vector<int>& xs, int lo, int hi)`는 정렬된 배열의 구간 `[lo, hi]`만 상점으로 볼 때의 비용이다. `lo > hi`면 상점이 없으니 0. 파이썬 슬라이스를 그대로 옮기려다 `vector<int> sub(xs.begin()+1, xs.end())`처럼 새 벡터를 만들면 복사 비용이 붙고 인덱스도 헷갈린다 — 구간을 넘기는 쪽이 깔끔하다.
- `L = min(0, xs[lo])`, `R = max(0, xs[hi])`로 두고 `min(2·(−L) + R, 2R + (−L))`을 돌려준다. `min(0, xs[lo])`는 둘 다 `int`라 타입이 맞고, 결과를 `long long`에 담아 이후 계산을 넓은 타입으로 끌고 간다.
- `cost(xs, 1, N-1)`(가장 왼쪽 제외)과 `cost(xs, 0, N-2)`(가장 오른쪽 제외) 중 작은 값을 출력한다. N=1이면 각각 `lo=1 > hi=0`, `lo=0 > hi=-1`이라 둘 다 0이 되어 답 0이 자연히 나온다.

(3) 스스로 다시 짤 때 생각 순서

- 결과를 결정하는 요소(L, R)를 먼저 찾고 비용식을 세운다.
- 후보 N개 중 지배당하는 것(중간 상점)을 논리로 제거해 2개만 남긴다.
- 슬라이스 대신 인덱스 구간. 큰 컨테이너는 `const ...&`로 받아 복사를 막는다.
- 한쪽에만 있는 경우(L 또는 R이 0), N=1(빈 구간 → 0), 양쪽 대칭으로 검산.
```
