## L5. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch2(Backtracking)의 4대 틀 — K개 중 하나를 N번(중복 선택·조건부 가지치기), N개 중 M개(조합·부분집합), 순열(`used[]`) — 을 소재를 바꿔 **반복 훈련**하고, 코딩테스트 단골인 괄호 생성·N-Queen·부분집합 분할·연산자 끼워넣기·격자 경로·미니 스도쿠로 **확장**하는 연습 세트다. 모든 문제는 `next_permutation` 같은 표준 알고리즘에 기대지 않고 재귀로 직접 짜는 것을 기본으로 한다.

- **반복 훈련 개념**
- K^N 틀 + 국소 제약: depth번째 칸에 후보를 놓되 직전 값과의 관계로 걸러 내기 — `for (int v = 1; v <= K; v++) { if (bad(prev, v)) continue; rec(depth + 1, v); }`
- 누적 제약·상한 가지치기: 합/비용이 이미 넘었거나, 남은 걸 다 더해도 최선을 못 넘으면 진입 전에 자르기 — `if (cur + rest[idx] <= best) return;`
- 부분집합(고른다/안 고른다) 이분 재귀: 원소마다 두 갈래로 내려가 2^N 경우를 만든다 — `rec(i + 1, s + a[i]); rec(i + 1, s);`
- 순열 `used[]` + 복원: 쓴 원소를 표시하고 돌아올 때 반드시 되돌리기 — `used[i] = true; rec(d + 1); used[i] = false;`
- 격자·판 위의 되돌리기: 방문 표시나 놓은 값을 재귀 뒤에 원상복구해야 다음 가지가 깨끗하다 — `visited[nr][nc] = true; rec(nr, nc); visited[nr][nc] = false;`
- 재귀 상태를 어디에 둘 것인가: C++에는 파이썬의 `nonlocal`이 없다. 카운터·최선값·경로는 **전역(또는 `main` 밖 파일 스코프) 변수**에 두거나 참조 인자로 넘긴다. 경로는 전역 `vector`에 `push_back` / `pop_back` 짝으로 관리한다.
- 정답 모으기: 파이썬은 `res.append(path[:])`처럼 **복사본을 떠야** 했지만 C++의 `res.push_back(path)`는 벡터 대입이 곧 값 복사라 별칭 함정이 아예 없다. 대신 그 복사 비용은 실제로 발생하므로, 답이 수만 개면 `res`에 쌓지 말고 찾는 즉시 출력하는 쪽이 낫다.

- **코딩테스트 출제 맵**: 이 챕터 유형은 백준 「단계별로 풀어보기」의 '백트래킹' 단계(N과 M 시리즈·N-Queen·스도쿠·연산자 끼워넣기 류), NeetCode 150의 'Backtracking'(Subsets·Permutations·Generate Parentheses·N-Queens 류), 삼성 SW 역량테스트의 '백트래킹' 유형(팀 나누기·연산자 배치 류)에 그대로 등장한다. 아래 유형 확장 문제는 그 대표 유형을 소재·수치·조건을 새로 만들어 이 챕터 수준으로 재구성한 것이다.

**문제**

**1) 홀짝 교대 수열 개수** · Easy

- **요구사항**: 1부터 K까지의 정수 중 하나를 N번 골라 길이 N인 수열을 만든다. 단, 인접한 두 항의 홀짝(짝수/홀수)이 서로 **달라야** 한다. 조건을 만족하는 수열의 개수를 구하라.
- **입력**: 한 줄에 K N (1 ≤ K ≤ 9, 1 ≤ N ≤ 8).
- **출력**: 조건을 만족하는 수열의 개수.
- **예제**: `3 2` → `4` · `1 3` → `0` · `4 1` → `4`
- **셀프체크**: 첫 항은 제약이 없으므로 초기 `prev_parity`를 0도 1도 아닌 값(예: -1)으로 넘겼는가? `3 2`는 (홀, 짝) 2×1개 + (짝, 홀) 1×2개 = 4. K=1이면 홀수뿐이라 N ≥ 2에서 0. 검산 공식: 홀수 개수 o, 짝수 개수 e일 때 N=4면 o·e·o·e + e·o·e·o = 2·o²·e²(`4 4` → 2·4·4 = 32).

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int K, N;
long long cnt = 0;          // 개수는 넉넉히 long long

void rec(int depth, int prev_parity) {
    if (depth == N) {
        cnt++;
        return;
    }
    for (int v = 1; v <= K; v++) {
        if (v % 2 == prev_parity) continue;   // 직전 항과 홀짝이 같으면 금지
        rec(depth + 1, v % 2);
    }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> K >> N;
    rec(0, -1);             // -1: 첫 항은 제약 없음
    cout << cnt << '\n';
    return 0;
}
@@TESTS

--OUT
4
--IN
1 3
--OUT
0
--IN
4 1
--OUT
4
--IN
4 4
--OUT
32
@@EXPL
(1) 접근·핵심 아이디어

- "K개 중 하나를 N번" 틀에 국소 제약(직전 항과의 관계)이 붙은 형태다. 직전 항의 홀짝 `prev_parity`를 인자로 넘기면 판정이 O(1)이고 복원이 필요 없다.
- 제약 위반 후보는 재귀에 들어가기 전에 `continue`로 자른다. 그 가지가 만들 K^(남은 깊이)개의 경우가 통째로 사라진다.

(2) 코드 단계별

- 카운터 `cnt`는 파일 스코프 변수로 둔다. C++에는 `nonlocal`이 없어 재귀 함수가 바깥 지역 변수를 고칠 수 없기 때문이다(람다에 `[&]`로 참조 캡처하는 방법도 있다).
- `rec(depth, prev_parity)`: `depth == N`이면 수열 하나 완성 → 카운트.
- 후보 `v`를 1..K로 돌며 `v % 2 == prev_parity`면 건너뛰고, 아니면 `rec(depth + 1, v % 2)`로 내려간다. 첫 호출은 `prev_parity = -1`로 두어 첫 항이 무엇이든 통과하게 한다.

(3) 스스로 다시 짤 때 생각 순서

- 제약 문장("인접 홀짝이 다르다")을 상태 인자 하나(`prev_parity`)로 번역한다.
- 초기값은 어떤 후보와도 충돌하지 않는 값이어야 한다. 0으로 두면 첫 항에서 짝수가 잘못 금지된다. `v % 2`는 `v`가 양수이므로 항상 0 또는 1이지만, **음수에 `%`를 쓰면 결과도 음수**(`-3 % 2 == -1`)라는 것을 기억해 둔다.
- 작은 K, N으로 곱셈 공식과 대조해 검산한다(`3 2` → 4, `4 4` → 32).
```

**2) 합이 S인 부분집합 개수** · Easy

- **요구사항**: 정수 N개가 주어진다. 이 중 하나 이상을 골라 만든 부분집합(공집합 제외) 중 원소 합이 정확히 S인 것의 개수를 구하라. 같은 값이 여러 개 있어도 위치가 다르면 다른 원소로 본다.
- **입력**: 첫 줄 N S (1 ≤ N ≤ 15, −100 ≤ S ≤ 100), 둘째 줄 N개의 정수(−20 ≤ 값 ≤ 20).
- **출력**: 부분집합의 개수.
- **예제**: `3 3 / 1 2 3` → `2` · `2 0 / 5 -5` → `1` · `1 4 / 2` → `0`
- **셀프체크**: 음수가 있으므로 "합이 S를 넘으면 중단" 같은 가지치기는 쓸 수 없다(이후 음수로 다시 내려올 수 있음). 공집합을 빼려면 고른 개수를 함께 넘겨 `picked > 0`을 확인해야 한다 — S=0일 때 특히 중요(`4 0 / 0 0 0 0`은 공집합을 뺀 2⁴−1 = 15).

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int N, S;
vector<int> arr;
long long cnt = 0;

void rec(int idx, int cur_sum, int picked) {
    if (idx == N) {
        if (picked > 0 && cur_sum == S) cnt++;
        return;
    }
    rec(idx + 1, cur_sum + arr[idx], picked + 1);   // idx번째를 고른다
    rec(idx + 1, cur_sum, picked);                  // 고르지 않는다
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> N >> S;
    arr.resize(N);
    for (int i = 0; i < N; i++) cin >> arr[i];

    rec(0, 0, 0);
    cout << cnt << '\n';
    return 0;
}
@@TESTS

--IN

--OUT

--IN

@@EXPL
(1) 접근·핵심 아이디어

- 원소마다 "고른다/안 고른다" 두 갈래로 내려가는 이분 재귀로 2^N개의 부분집합을 모두 만든다. N ≤ 15이면 32,768개라 충분하다.
- 합 `cur_sum`과 고른 개수 `picked`를 인자로 넘기므로 복원이 필요 없다. 공집합 제외 조건은 `picked > 0`으로 처리한다.

(2) 코드 단계별

- 입력 배열 `arr`와 카운터 `cnt`를 파일 스코프에 두고, 재귀 함수가 인자 없이 접근하게 한다. 배열을 인자로 넘긴다면 `const vector<int>&`로 받아 매 호출 복사를 피한다.
- `rec(idx, cur_sum, picked)`: `idx == N`이면 모든 원소의 선택이 끝난 것 → `picked > 0`이고 `cur_sum == S`일 때만 카운트.
- 아니면 `arr[idx]`를 더한 갈래와 더하지 않은 갈래로 각각 내려간다. 처음 호출은 `rec(0, 0, 0)`.

(3) 스스로 다시 짤 때 생각 순서

- "부분집합 = 각 원소에 대한 포함 여부"로 보고 두 갈래 재귀를 떠올린다. `start` 루프 방식보다 이 문제에선 이쪽이 단순하다.
- 음수 원소가 있으면 합 기반 가지치기를 함부로 넣지 않는다(정답이 줄어든다).
- 값 범위가 −20..20이고 N ≤ 15라 합은 최대 300, `int`로 충분하다. 하지만 N이 40쯤 되는 변형에서는 경우의 수 자체가 `int` 범위를 넘으므로 카운터는 처음부터 `long long`으로 두는 습관이 안전하다.
```

**3) 문자 M-순열 사전순 출력** · Easy

- **요구사항**: 서로 다른 소문자 N개가 **정렬되지 않은** 순서로 주어진다. 이 중 M개를 골라 순서 있게 나열해 만든 길이 M의 문자열을 모두 사전순으로 한 줄에 하나씩 출력하라.
- **입력**: 첫 줄 N M (1 ≤ M ≤ N ≤ 6), 둘째 줄 서로 다른 소문자 N개(공백 구분).
- **출력**: 가능한 문자열 전부, 사전순으로 한 줄에 하나씩(총 P(N, M) = N!/(N−M)!줄).
- **예제**: `3 2 / c a b` → `ab / ac / ba / bc / ca / cb` · `2 2 / b a` → `ab / ba` · `1 1 / q` → `q`
- **셀프체크**: 후보를 오름차순으로 순회해야 출력이 사전순이 되는데 입력이 정렬되어 있지 않으므로 **먼저 `sort`** 했는가? `used[]` 복원과 `cur.pop_back()`을 짝지었는가? 총 줄 수가 P(N, M)인지 확인(`3 2` → 6줄, `3 1 / z y x` → `x / y / z`). 참고로 M = N일 때는 정렬 후 `do { ... } while (next_permutation(...))` 한 줄로도 같은 결과가 나오지만, M < N에는 쓸 수 없다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int N, M;
vector<char> letters;
vector<bool> used;
string cur;

void rec(int depth) {
    if (depth == M) {
        cout << cur << '\n';       // 찾는 즉시 출력(벡터에 모아 두지 않는다)
        return;
    }
    for (int i = 0; i < N; i++) {
        if (used[i]) continue;
        used[i] = true;
        cur.push_back(letters[i]);
        rec(depth + 1);
        cur.pop_back();            // 복원
        used[i] = false;
    }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> N >> M;
    letters.resize(N);
    for (int i = 0; i < N; i++) cin >> letters[i];
    sort(letters.begin(), letters.end());     // 사전순 출력을 위해 먼저 정렬
    used.assign(N, false);

    rec(0);
    return 0;
}

(1) 접근·핵심 아이디어

- 순서가 결과를 바꾸므로 순열 틀이다: 매 depth에서 아직 안 쓴 원소를 모두 후보로 삼고 `used[]`로 관리한다. M개만 뽑으므로 종료 조건은 `depth == M`.
- 사전순은 "후보를 오름차순으로 순회"하면 자동으로 보장되지만, 입력이 정렬되어 있지 않으므로 `sort`를 먼저 적용하는 것이 이 문제의 함정이다.

(2) 코드 단계별

- `cin >> letters[i]`로 `char`를 읽으면 공백·개행을 알아서 건너뛰고 문자 하나씩 들어온다. 읽은 뒤 `sort(letters.begin(), letters.end())`.
- `rec(depth)`: `depth == M`이면 현재 경로 `cur`를 바로 출력한다. 답이 최대 720줄뿐이지만, "모아서 한 번에"가 아니라 "찾는 즉시 출력"이 메모리도 복사 비용도 없다.
- 아니면 0..N-1을 돌며 안 쓴 원소를 표시 → `cur.push_back` → 재귀 → `cur.pop_back()` → 표시 해제. `string`도 `vector`처럼 `push_back`/`pop_back`이 있어 경로 버퍼로 쓰기 좋다.

(3) 스스로 다시 짤 때 생각 순서

- 조합/순열 판별: 같은 문자 집합도 순서가 다르면 다른 결과이므로 순열 → `used[]`.
- 사전순 출력이 요구되면 "입력 정렬 여부"를 먼저 확인한다. 정렬 없이 돌리면 `c a b` 입력에서 `ca`가 먼저 나온다.
- 표시 해제(`used[i] = false`)와 경로 되돌리기(`pop_back`)는 **항상 한 쌍**이다. 하나만 빠뜨리면 답의 길이나 개수가 조용히 틀어진다. 총 줄 수 P(N, M)으로 검산한다.
```

**4) 올바른 괄호 문자열 생성** · Medium

- **요구사항**: 여는 괄호 `(`와 닫는 괄호 `)`를 각각 n개씩 써서 만들 수 있는 **올바른** 괄호 문자열(어느 접두사에서도 닫는 괄호 수가 여는 괄호 수를 넘지 않는 문자열)을 모두 사전순으로 출력하라. `(`가 `)`보다 앞선다.
- **입력**: 정수 n (1 ≤ n ≤ 6).
- **출력**: 올바른 괄호 문자열 전부, 사전순으로 한 줄에 하나씩.
- **예제**: `2` → `(()) / ()()` · `1` → `()` · `3` → `((())) / (()()) / (())() / ()(()) / ()()()`
- **셀프체크**: 상태를 (지금까지 쓴 `(` 수, `)` 수)로 두면 조건은 두 줄이다: `(`는 n개 미만일 때, `)`는 열린 것보다 적을 때만 붙인다. 이 두 조건이 곧 가지치기이므로 완성된 문자열을 따로 검사할 필요가 없다. 총 줄 수는 카탈란 수(1, 2, 5, 14, 42, 132)다. `(`를 먼저 시도해야 사전순이 된다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int n;
string cur;

void rec(int opened, int closed) {
    if (opened == n && closed == n) {
        cout << cur << '\n';
        return;
    }
    if (opened < n) {              // '('는 n개까지
        cur.push_back('(');
        rec(opened + 1, closed);
        cur.pop_back();
    }
    if (closed < opened) {         // ')'는 열린 것보다 적을 때만
        cur.push_back(')');
        rec(opened, closed + 1);
        cur.pop_back();
    }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n;
    rec(0, 0);
    return 0;
}

(1) 접근·핵심 아이디어

- 길이 2n의 각 자리에 `(` 또는 `)`를 놓는 K=2, N=2n 틀이지만, "올바름" 조건을 진입 전 가지치기로 걸면 잘못된 문자열은 아예 만들어지지 않는다.
- 상태는 `(opened, closed)` 두 개면 충분하다. `(`는 `opened < n`일 때, `)`는 `closed < opened`일 때만 붙일 수 있다. 후자가 "접두사에서 닫는 괄호가 앞서지 않음"을 정확히 표현한다.

(2) 코드 단계별

- 경로 버퍼는 전역 `string cur` 하나를 재사용한다. 매 재귀에서 문자열을 새로 만들어 넘기면(`rec(cur + "(")`) 호출마다 문자열 복사가 일어나므로, `push_back`/`pop_back` 쌍이 정석이다.
- `rec(opened, closed)`: 둘 다 n이면 완성 → `cur`를 출력.
- `opened < n`이면 `(`를 붙이고 재귀한 뒤 `pop_back`. 그다음 `closed < opened`이면 `)`를 붙이고 재귀한 뒤 `pop_back`. `(` 갈래를 먼저 시도하므로 출력이 사전순으로 나온다.

(3) 스스로 다시 짤 때 생각 순서

- "완성 후 검사"가 아니라 "붙일 수 있는 조건"을 상태로 표현한다. 검사 방식은 2^(2n)개를 다 만들고 버리므로 낭비다.
- `)` 조건을 `closed < n`으로 잘못 쓰면 `)(` 같은 문자열이 나온다. 반드시 `closed < opened`.
- 두 갈래가 `if`-`if`(둘 다 시도)이지 `if`-`else`가 아님을 확인한다. `else`로 쓰면 각 자리에서 한 가지 선택만 남아 답이 1줄로 줄어든다. 총 개수를 카탈란 수와 대조해 검산한다(n=3 → 5).
```

**5) 두 상자 무게 차 최소** · Medium

- **요구사항**: 돌 N개의 무게가 주어진다. 모든 돌을 두 상자 A, B에 나누어 담을 때(한 상자가 비어도 됨), 두 상자 무게 합의 차이의 최솟값을 구하라.
- **입력**: 첫 줄 N (1 ≤ N ≤ 16), 둘째 줄 N개의 무게(1 ≤ 무게 ≤ 100).
- **출력**: 가능한 최소 차이.
- **예제**: `4 / 3 1 4 2` → `0` · `3 / 1 2 10` → `7` · `1 / 5` → `5`
- **셀프체크**: 돌마다 A/B 두 갈래이므로 2^N. 가지치기: 지금까지의 차 `|a − b|`에서 남은 돌을 전부 가벼운 쪽에 넣어도 최대 `남은 무게 합`만큼만 줄일 수 있으므로, `|a − b| − rest >= best`면 더 볼 필요가 없다. 남은 무게 합은 뒤에서부터 누적한 배열로 O(1)에 얻는다. 절댓값은 `abs`(정수용, `<cstdlib>`/`<bits/stdc++.h>`)를 쓰고 실수용 `fabs`와 섞지 않는다. `6 / 7 7 7 7 7 8`은 21 대 22로 `1`.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int N;
vector<int> w;
vector<int> rest;        // rest[i] = i번째부터 끝까지 무게 합
int total_w;
int best;

void rec(int idx, int a) {                   // a: 지금까지 상자 A에 담은 무게
    int b = total_w - rest[idx] - a;         // 지금까지 상자 B에 담은 무게
    if (abs(a - b) - rest[idx] >= best) return;   // 남은 돌을 다 써도 best를 못 깨면 중단
    if (idx == N) {
        best = abs(a - b);
        return;
    }
    rec(idx + 1, a + w[idx]);                // A에 담기
    rec(idx + 1, a);                         // B에 담기
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> N;
    w.resize(N);
    total_w = 0;
    for (int i = 0; i < N; i++) { cin >> w[i]; total_w += w[i]; }

    rest.assign(N + 1, 0);
    for (int i = N - 1; i >= 0; i--) rest[i] = rest[i + 1] + w[i];

    best = total_w;
    rec(0, 0);
    cout << best << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- 각 돌을 A 또는 B에 넣는 두 갈래 재귀로 모든 분할을 만들고, 완성 시 `|a − b|`로 최선을 갱신한다. 상태는 A의 무게 `a`만 들고, B는 `(지금까지 배정한 총 무게) − a`로 계산한다.
- 상한 가지치기: 남은 돌 무게 합 `rest[idx]`를 전부 가벼운 쪽에 넣어도 차이는 `|a − b| − rest[idx]` 아래로 못 내려간다. 이 값이 이미 `best` 이상이면 그 가지는 최선을 갱신할 수 없다.

(2) 코드 단계별

- `rest`를 뒤에서부터 누적해 두면 `total_w − rest[idx]`가 "지금까지 배정한 무게"가 된다. 크기를 `N + 1`로 잡아 `rest[N] = 0`을 두는 것이 경계 처리의 요령이다.
- `rec(idx, a)`: 먼저 가지치기 조건을 검사한다. `idx == N`이면 분할 완성 → 가지치기를 통과했으므로 `abs(a − b)`가 반드시 `best`보다 작다 → 갱신.
- 아니면 `w[idx]`를 A에 넣는 갈래, B에 넣는(= a 그대로) 갈래로 내려간다. `best`는 `total_w`(전부 A에 넣은 최악)로 초기화한다.

(3) 스스로 다시 짤 때 생각 순서

- "두 그룹으로 나눈다"는 곧 "각 원소의 소속을 정한다"이므로 이분 재귀. 그룹 크기 제한이 없으면 `start` 루프보다 이 방식이 자연스럽다.
- `best`를 `int best;`로 선언만 하고 초기화를 잊으면 전역이면 0, 지역이면 쓰레기값이라 결과가 제각각이다. **최선값은 선언과 동시에 "가능한 최악"으로 초기화**하는 습관을 들인다.
- 가지치기 부등식은 "남은 것을 다 써서 얻을 수 있는 최선"을 먼저 계산한 뒤 `>= best`로 자른다. N=1(한 상자만 채움 → 그 무게)과 총합이 짝수로 딱 나뉘는 예제(0)로 검산한다.
```

**6) 금지 칸이 있는 N-Queen** · Medium

- **요구사항**: N×N 체스판에 퀸 N개를 서로 공격하지 않게(같은 행·열·대각선에 둘 이상 없음) 놓는다. 단, `#`로 표시된 칸에는 퀸을 놓을 수 없다. 가능한 배치의 수를 구하라.
- **입력**: 첫 줄 N (1 ≤ N ≤ 8). 이어 N줄에 길이 N의 문자열(`.` 허용, `#` 금지).
- **출력**: 배치의 수.
- **예제**: `4 / .... / .... / .... / ....` → `2` · `4 / .#.. / .... / .... / ....` → `1` · `1 / #` → `0`
- **셀프체크**: 행마다 퀸 하나를 놓으므로 depth = 행. 열은 `col[c]`, ↘ 대각선은 `r − c + N`, ↙ 대각선은 `r + c`로 인덱싱해 `bool` 배열 세 개로 O(1) 판정. `r − c`는 음수가 될 수 있으므로 `+ N`으로 옮기고 배열 크기를 `2N`으로 잡았는가(음수 인덱스는 곧 범위 밖 접근)? 놓은 뒤 재귀, 돌아와서 **세 배열 모두** 복원했는가? 4×4 기본 해는 2개인데 (0,1)을 금지하면 그 칸을 쓰는 해가 사라져 1개, 5×5는 10개.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int N;
vector<string> g;
vector<bool> col, d1, d2;      // d1: r + c 대각선, d2: r - c + N 대각선
long long cnt = 0;

void rec(int r) {
    if (r == N) {
        cnt++;
        return;
    }
    for (int c = 0; c < N; c++) {
        if (g[r][c] == '#' || col[c] || d1[r + c] || d2[r - c + N]) continue;
        col[c] = true;  d1[r + c] = true;  d2[r - c + N] = true;
        rec(r + 1);
        col[c] = false; d1[r + c] = false; d2[r - c + N] = false;   // 복원
    }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> N;
    g.resize(N);
    for (int i = 0; i < N; i++) cin >> g[i];

    col.assign(N, false);
    d1.assign(2 * N, false);
    d2.assign(2 * N, false);

    rec(0);
    cout << cnt << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- N-Queen은 "행마다 열 하나를 고르는 순열"에 대각선 제약을 더한 문제다. 각 행에서 후보 열 N개를 시도하되, 열·두 대각선 중 하나라도 이미 사용 중이면 진입 전에 자른다.
- 대각선은 인덱스 하나로 식별된다: ↙ 방향은 `r + c`가 같고, ↘ 방향은 `r − c`가 같다. `r − c`의 범위가 `−(N−1) .. N−1`이라 그대로 쓰면 음수 인덱스가 되므로 `+ N`으로 옮기고 배열 크기를 `2N`으로 잡는다.

(2) 코드 단계별

- `col`, `d1`(r+c), `d2`(r−c+N)를 `vector<bool>`로 두고 `assign`으로 전부 `false` 초기화한다. `rec(r)`을 호출해 `r == N`이면 N개를 모두 놓은 것 → 카운트.
- 열 `c`를 0..N−1로 돌며 금지 칸이거나 세 배열 중 하나라도 `true`면 `continue`. 통과하면 세 배열을 `true`로 표시하고 `rec(r+1)`, 돌아와서 `false`로 복원한다.
- 금지 칸 판정은 `g[r][c] == '#'` 하나면 된다. 조건 순서를 금지 칸 → 열 → 대각선으로 두면 가장 싼 검사가 먼저 걸린다.

(3) 스스로 다시 짤 때 생각 순서

- 상태를 "행 = depth"로 잡으면 같은 행 충돌은 자동으로 없다. 남은 제약(열·대각선)을 O(1) 배열로 만든다.
- 인덱스가 음수가 될 수 있는지 항상 확인한다. C++에서 `d2[-3]`은 예외가 아니라 배열 앞쪽 메모리를 건드리는 정의되지 않은 동작이라 원인을 찾기가 매우 어렵다.
- 복원은 표시한 세 배열 전부에 대해 한다. 하나라도 빠지면 이후 가지에서 유령 퀸이 남아 답이 급감한다. 금지 칸 없는 4×4(2), 5×5(10)로 기본 로직을, 금지 칸 예제로 필터를 검산한다.
```

**7) 연산자 끼워넣기로 목표 만들기** · Medium

- **요구사항**: 정수 N개가 순서대로 주어진다. 인접한 두 수 사이의 N−1곳마다 `+`, `-`, `*` 중 하나를 넣어 식을 만들고, 연산자 우선순위를 무시하고 **왼쪽부터 차례로** 계산한다. 결과가 정확히 T가 되는 식의 개수를 구하라. N=1이면 연산자 없이 그 수 자체가 결과다.
- **입력**: 첫 줄 N T (1 ≤ N ≤ 10, −10⁶ ≤ T ≤ 10⁶), 둘째 줄 N개의 정수(1 ≤ 값 ≤ 9).
- **출력**: 결과가 T인 식의 개수.
- **예제**: `3 6 / 1 2 3` → `2` · `2 5 / 2 3` → `1` · `1 4 / 4` → `1`
- **셀프체크**: `1 2 3`으로 만드는 9개 식의 값은 6, 0, 9, 2, −4, −3, 5, −1, 6이며, `1+2+3`과 `1*2*3`만 6이다("왼쪽부터 계산"이므로 `1+2*3`은 9). 첫 수를 시작값으로 두고 `idx = 1`부터 연산자를 고르는 구조인가? **누적값을 `long long`으로 두었는가** — 9를 열 번 곱하면 34억이라 `int`(약 21억)를 넘어 조용히 음수가 된다. 값이 음수가 될 수 있으므로 T 기준 가지치기는 하지 않는다. `1 3 / 4`는 `0`, `4 0 / 1 1 1 1`은 `6`.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int N;
long long T;
vector<long long> nums;
long long cnt = 0;

void rec(int idx, long long value) {      // value: 왼쪽부터 접은 지금까지의 값
    if (idx == N) {
        if (value == T) cnt++;
        return;
    }
    rec(idx + 1, value + nums[idx]);
    rec(idx + 1, value - nums[idx]);
    rec(idx + 1, value * nums[idx]);
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> N >> T;
    nums.resize(N);
    for (int i = 0; i < N; i++) cin >> nums[i];

    rec(1, nums[0]);                      // 첫 수를 시작값으로, 두 번째 수부터 연산자 선택
    cout << cnt << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- N−1개의 자리마다 3개 후보를 고르는 K=3, N−1칸의 K^N 틀이다. 왼쪽부터 계산하므로 "지금까지의 값"만 인자로 넘기면 다음 연산 결과를 바로 구할 수 있다.
- 3^9 = 19,683가지라 완전탐색으로 충분하다. 곱셈과 뺄셈 때문에 값이 오르내리므로 T와의 비교로 중간에 자르지 않는다.

(2) 코드 단계별

- 누적값을 `long long`으로 둔다. 값이 최대 9이고 N이 10이면 곱셈만 이어져도 9¹⁰ = 3,486,784,401이 되어 `int` 최댓값 2,147,483,647을 넘는다. 넘는 순간 오버플로로 값이 음수가 되고, 컴파일 에러도 런타임 에러도 없이 **답만 조용히 틀린다.**
- `rec(idx, value)`: `idx == N`이면 식이 완성된 것 → `value == T`면 카운트. 아니면 `nums[idx]`에 대해 `+`, `-`, `*` 세 갈래로 `rec(idx+1, 새 값)`을 호출한다.
- 시작은 `rec(1, nums[0])`. N=1이면 곧바로 종료 조건에 걸려 첫 수와 T를 비교한다.

(3) 스스로 다시 짤 때 생각 순서

- "연산자 자리 = depth, 후보 = 세 연산자"로 매핑하고, 누적 상태(현재 값)를 인자로 넘겨 복원 부담을 없앤다.
- 곱셈이 들어간 완전탐색을 보면 **먼저 최댓값을 손으로 어림한다.** "값 최대 × 개수 최대"를 곱해 21억을 넘으면 `long long`이다. 중간 계산 하나만 `int`로 남아도(예: `int tmp = value * nums[idx];`) 거기서 잘린다.
- 우선순위 무시 규칙을 코드가 자연히 지키는지(왼쪽부터 접기) 확인하고, N=1(연산자 없음)과 답이 0인 입력으로 종료 조건을 검산한다.
```

**8) 장애물 격자의 경로 수** · Medium

- **요구사항**: R×C 격자(`.` 빈칸, `#` 장애물)에서 `(0, 0)`을 출발해 `(R−1, C−1)`에 도착하는 경로의 수를 구하라. 상하좌우로 한 칸씩 움직이고, 한 경로 안에서 같은 칸을 두 번 지날 수 없다. 출발 칸이나 도착 칸이 장애물이면 0이다.
- **입력**: 첫 줄 R C (1 ≤ R, C ≤ 5). 이어 R줄에 길이 C의 문자열.
- **출력**: 경로의 수.
- **예제**: `2 2 / .. / ..` → `2` · `3 3 / ... / .#. / ...` → `2` · `2 3 / ... / ...` → `4`
- **셀프체크**: 오른쪽·아래로만 가는 경로 수(격자 DP)가 아니라 **4방향 + 재방문 금지**이므로 되돌아가는 경로(`2 3`에서 아래→오른쪽→위→오른쪽→아래)도 센다. 이동 전 `visited` 표시, 재귀 후 해제를 짝지었는가? 출발 칸을 미리 방문 처리했는가? `1 1 / .`은 출발이 곧 도착이라 `1`, `2 2 / .# / #.`은 `0`. 5×5 빈 격자는 8,512개.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int R, C;
vector<string> g;
vector<vector<bool>> visited;
long long cnt = 0;

const int DR[4] = {-1, 1, 0, 0};
const int DC[4] = {0, 0, -1, 1};

void rec(int r, int c) {
    if (r == R - 1 && c == C - 1) {       // 도착: 경로 하나 완성
        cnt++;
        return;
    }
    for (int d = 0; d < 4; d++) {
        int nr = r + DR[d], nc = c + DC[d];
        if (0 <= nr && nr < R && 0 <= nc && nc < C && g[nr][nc] == '.' && !visited[nr][nc]) {
            visited[nr][nc] = true;
            rec(nr, nc);
            visited[nr][nc] = false;      // 되돌리기
        }
    }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> R >> C;
    g.resize(R);
    for (int i = 0; i < R; i++) cin >> g[i];

    if (g[0][0] == '#' || g[R - 1][C - 1] == '#') {
        cout << 0 << '\n';
        return 0;
    }

    visited.assign(R, vector<bool>(C, false));
    visited[0][0] = true;
    rec(0, 0);
    cout << cnt << '\n';
    return 0;
}

- 재방문 금지 때문에 경로는 유한하고 5×5 정도면 전수 나열이 가능하다(빈 5×5에서 8,512개). 이보다 커지면 폭발하므로 입력 제한이 작다.

(2) 코드 단계별

- 출발·도착이 장애물이면 `main`에서 곧바로 0을 출력하고 `return 0;`. 아니면 `visited`를 만들고 출발 칸을 `true`로 둔다.
- `rec(r, c)`: 도착이면 카운트하고 반환(도착점에서 더 뻗지 않는다). 아니면 4방향 이웃 중 격자 안·빈칸·미방문인 칸에 대해 `visited = true` → `rec` → `visited = false`.
- 격자·방문 배열은 파일 스코프에 두어 재귀 인자를 좌표 두 개로 줄인다. 인자로 넘긴다면 반드시 참조(`vector<vector<bool>>&`)여야 한다 — 값으로 넘기면 **호출마다 방문 배열이 복사되어** 표시가 상위 호출에 반영되지 않고, 경로 수가 폭발적으로 커진다.

(3) 스스로 다시 짤 때 생각 순서

- "경로 = 방문 순서"이므로 상태는 현재 위치 + 방문 격자. 방문 격자는 재귀에서 되돌려야 다른 경로가 같은 칸을 쓸 수 있다.
- 출발 칸의 방문 처리를 잊으면 출발점으로 되돌아오는 경로가 생겨 답이 커진다.
- 1×1(출발 = 도착 → 1)과 막힌 격자(0)로 종료 조건을 검산한다.
```

**9) 4×4 미니 스도쿠** · Hard

- **요구사항**: 4×4 판의 각 행, 각 열, 그리고 네 개의 2×2 상자에 1~4가 정확히 한 번씩 들어가야 한다. 일부 칸이 비어 있는(0) 판이 주어지면 규칙에 맞게 채운 판을 출력하라. 해는 유일함이 보장된다.
- **입력**: 4줄에 각 줄 4개의 정수(0은 빈칸, 1~4는 확정된 값).
- **출력**: 완성된 판 4줄.
- **예제**: `1 2 3 4 / 0 0 0 0 / 0 0 0 0 / 4 0 0 1` → `1 2 3 4 / 3 4 1 2 / 2 1 4 3 / 4 3 2 1` · `2 0 0 0 / 0 0 3 0 / 4 0 0 0 / 0 0 1 0` → `2 3 4 1 / 1 4 3 2 / 4 1 2 3 / 3 2 1 4`
- **셀프체크**: 칸을 0..15 번호로 일렬 순회하며, 확정 칸은 건너뛰고 빈칸에서만 1~4를 시도한다. 상자의 좌상단은 `(r / 2) * 2, (c / 2) * 2` — 정수 나눗셈이 내림이라 이 식이 성립한다(음수 좌표라면 C++의 나눗셈은 0 방향 절단이라 다르게 동작하니 주의). 해를 찾으면 `true`를 위로 전파해 즉시 멈추고, 실패하면 값을 0으로 되돌린 뒤 `false`를 반환하는 구조인가? 빈칸이 없는 판(`1 2 3 4 / 3 4 1 2 / 2 1 4 3 / 4 3 2 1`)은 그대로 출력된다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int g[4][4];

bool ok(int r, int c, int v) {
    for (int k = 0; k < 4; k++)
        if (g[r][k] == v || g[k][c] == v) return false;
    int br = (r / 2) * 2, bc = (c / 2) * 2;      // 2x2 상자의 좌상단
    for (int i = br; i < br + 2; i++)
        for (int j = bc; j < bc + 2; j++)
            if (g[i][j] == v) return false;
    return true;
}

bool rec(int pos) {
    if (pos == 16) return true;                  // 모든 칸을 채웠다
    int r = pos / 4, c = pos % 4;
    if (g[r][c] != 0) return rec(pos + 1);       // 확정 칸은 건너뛴다
    for (int v = 1; v <= 4; v++) {
        if (!ok(r, c, v)) continue;
        g[r][c] = v;
        if (rec(pos + 1)) return true;           // 성공은 위로 전파
        g[r][c] = 0;                             // 되돌리기
    }
    return false;
}

    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    for (int r = 0; r < 4; r++)
        for (int c = 0; c < 4; c++)
            cin >> g[r][c];

    rec(0);

    for (int r = 0; r < 4; r++) {
        for (int c = 0; c < 4; c++) {
            if (c) cout << ' ';
            cout << g[r][c];
        }
        cout << '\n';
    }
    return 0;
}

(1) 접근·핵심 아이디어

- 스도쿠는 "빈칸마다 후보 1~4 중 하나를 고르는" K^N 틀에 행·열·상자 유효성 검사를 가지치기로 붙인 문제다. 4×4는 후보가 적어 순수 백트래킹으로 즉시 풀린다.
- 해를 하나 찾으면 더 탐색할 필요가 없으므로 재귀가 `bool`을 반환해 성공을 위로 전파한다. 실패한 가지는 놓았던 값을 0으로 되돌린다.

(2) 코드 단계별

- 판은 크기가 고정이라 `int g[4][4];`로 둔다. **전역 배열은 0으로 초기화되지만 함수 안 지역 배열은 쓰레기값**이므로, 지역으로 옮긴다면 `int g[4][4] = {};`처럼 초기화를 붙인다.
- `ok(r, c, v)`: 같은 행·열에 `v`가 있는지, `(r/2*2, c/2*2)`에서 시작하는 2×2 상자에 `v`가 있는지 검사한다.
- `rec(pos)`: `pos == 16`이면 `true`. 확정 칸이면 다음 칸으로. 빈칸이면 1~4를 시도해 `ok`이면 놓고 재귀, 성공이면 `true`, 아니면 0으로 복원 후 다음 후보. 모든 후보가 실패하면 `false`.

(3) 스스로 다시 짤 때 생각 순서

- 칸을 1차원 번호로 순회하면 "다음 빈칸 찾기"가 `pos + 1`로 단순해진다. `pos / 4`, `pos % 4`로 좌표를 복원한다.
- 되돌리기(`g[r][c] = 0`)를 빠뜨리면 실패한 값이 남아 이후 검사가 오염된다. 성공 전파(`if (rec(pos+1)) return true;`)와 복원을 한 쌍으로 기억한다.
- `rec`의 반환값을 `main`에서 무시해도 되는 이유는 "해가 유일하게 존재"가 보장되기 때문이다. 해가 없을 수 있는 변형에서는 `if (!rec(0)) { cout << "IMPOSSIBLE\n"; return 0; }`처럼 반환값을 반드시 확인한다.
```

**10) 무게 제한 가방의 최대 가치** · Hard

- **요구사항**: 물건 N개가 각각 무게와 가치를 가진다. 무게 합이 W 이하가 되도록 물건의 부분집합을 골라 가치 합을 최대로 하라(아무것도 안 넣으면 0).
- **입력**: 첫 줄 N W (1 ≤ N ≤ 15, 1 ≤ W ≤ 100). 이어 N줄에 `무게 가치`(1 ≤ 무게 ≤ 100, 1 ≤ 가치 ≤ 100).
- **출력**: 최대 가치 합.
- **예제**: `3 5 / 2 3 / 3 4 / 4 5` → `7` · `2 1 / 2 5 / 3 6` → `0` · `1 10 / 10 100` → `100`
- **셀프체크**: 두 가지 가지치기를 모두 넣었는가? (a) 무게 초과 갈래는 시도하지 않음, (b) 상한: 현재 가치 + 남은 물건 가치 합(`rest[idx]`)이 `best` 이하면 중단. `rest`는 뒤에서부터 누적한다. 첫 예제는 (2,3)+(3,4)=무게 5, 가치 7이 최대이고 `5 10 / 5 10 / 4 40 / 6 30 / 3 50 / 2 5`는 무게 4+3+2 = 9로 가치 95.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int N, W;
vector<int> wt, val;
vector<int> rest;        // rest[i] = i번째 이후 물건 가치 합
int best = 0;

void rec(int idx, int weight, int value) {
    if (value > best) best = value;
    if (idx == N) return;
    if (value + rest[idx] <= best) return;    // 남은 걸 다 넣어도 best를 못 넘으면 중단
    if (weight + wt[idx] <= W)                // 넣는다(무게 초과면 시도조차 안 함)
        rec(idx + 1, weight + wt[idx], value + val[idx]);
    rec(idx + 1, weight, value);              // 안 넣는다
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> N >> W;
    wt.resize(N);
    val.resize(N);
    for (int i = 0; i < N; i++) cin >> wt[i] >> val[i];

    rest.assign(N + 1, 0);
    for (int i = N - 1; i >= 0; i--) rest[i] = rest[i + 1] + val[i];

    rec(0, 0, 0);
    cout << best << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- 물건마다 "넣는다/안 넣는다" 이분 재귀로 부분집합을 만들되, 무게 초과 갈래는 아예 진입하지 않는다(누적 제약). 여기까지만 해도 2^15는 충분하지만, 최적화 문제의 정석인 상한 가지치기를 함께 익힌다.
- 상한 가지치기(bound): 현재 가치에 남은 물건의 가치를 **전부** 더해도 `best`를 못 넘으면, 그 가지에서는 무엇을 해도 최선을 갱신할 수 없다.

(2) 코드 단계별

- `rest[i]`를 뒤에서부터 누적해 "i번째부터 끝까지 가치 합"을 O(1)로 얻는다. 크기는 `N + 1`.
- `rec(idx, weight, value)`: 들어올 때마다 `best`를 갱신한다(부분 선택 상태도 유효한 답이므로). `idx == N`이면 끝.
- `value + rest[idx] <= best`면 중단. 아니면 무게가 허용될 때만 "넣는다" 갈래로, 항상 "안 넣는다" 갈래로 내려간다. `best`는 "아무것도 안 넣기"가 항상 가능하므로 0으로 초기화한다.

(3) 스스로 다시 짤 때 생각 순서

- 제약 두 종류를 구분해 배치한다: 무게는 "후보 단위 필터"(넣는 갈래만 검사), 상한은 "경로 단위 컷"(진입 직후 검사).
- 무게·가치가 각각 100 이하, N ≤ 15라 합은 1,500 이하로 `int`면 충분하다. 다만 N이 30~40으로 커지는 변형에서는 가치 합이 커질 수 있으니, "최댓값 × 개수"를 어림해 `long long` 여부를 먼저 정한다.
- 아무것도 못 넣는 입력(0)과 하나만 넣는 입력으로 경계를 검산한다.
```

**11) 인접 차 제한 순열** · Hard

- **요구사항**: 1부터 N까지의 순열 중 인접한 두 수의 차의 절댓값이 모두 D 이하인 순열을 생각한다. 그런 순열의 개수와, 그중 사전순으로 가장 앞선 순열을 출력하라. 하나도 없으면 개수 0과 `NONE`을 출력한다.
- **입력**: 한 줄에 N D (1 ≤ N ≤ 8, 0 ≤ D ≤ 7).
- **출력**: 첫 줄에 개수, 둘째 줄에 사전순 첫 순열(공백 구분) 또는 `NONE`.
- **예제**: `3 1` → `2 / 1 2 3` · `4 2` → `12 / 1 2 3 4` · `3 0` → `0 / NONE`
- **셀프체크**: 후보를 1부터 오름차순으로 시도하면 처음 완성되는 순열이 곧 사전순 첫 순열이다 — 이때 `first = perm;`으로 저장하면 C++의 `vector` 대입은 **값 복사**라 파이썬의 `perm[:]` 같은 복사본 떠 두기가 따로 필요 없다(대신 원소 N개를 실제로 복사하는 비용이 든다). 인접 제약은 `perm`이 비어 있지 않을 때만 검사한다 — `perm.back()`을 빈 벡터에 부르면 정의되지 않은 동작이다. `1 0`은 순열이 하나뿐이라 `1 / 1`, `5 1`은 오름차순·내림차순 둘뿐이라 `2 / 1 2 3 4 5`.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int N, D;
vector<bool> used;
vector<int> perm;
vector<int> first_perm;      // 비어 있으면 아직 해를 못 찾음
long long cnt = 0;

void rec(int depth) {
    if (depth == N) {
        cnt++;
        if (first_perm.empty()) first_perm = perm;   // 벡터 대입 = 값 복사
        return;
    }
    for (int v = 1; v <= N; v++) {
        if (used[v]) continue;
        if (!perm.empty() && abs(perm.back() - v) > D) continue;   // 인접 차 제한
        used[v] = true;
        perm.push_back(v);
        rec(depth + 1);
        perm.pop_back();
        used[v] = false;
    }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> N >> D;
    used.assign(N + 1, false);

    rec(0);

    cout << cnt << '\n';
    if (first_perm.empty()) {
        cout << "NONE" << '\n';
    } else {
        for (int i = 0; i < (int)first_perm.size(); i++) {
            if (i) cout << ' ';
            cout << first_perm[i];
        }
        cout << '\n';
    }
    return 0;
}

(1) 접근·핵심 아이디어

- 순열 틀(`used[]`)에 국소 제약 "직전 원소와의 차 ≤ D"를 진입 전 가지치기로 붙였다. 직전 원소는 `perm.back()`으로 바로 읽을 수 있어 별도 인자가 필요 없다.
- 후보를 오름차순으로 순회하므로 완성 순서가 사전순이다. 따라서 "처음 완성된 순열"을 한 번만 기록하면 사전순 첫 순열이 된다.

(2) 코드 단계별

- `rec(depth)`: `depth == N`이면 카운트하고, `first_perm`이 비어 있으면 `first_perm = perm;`으로 저장한다. C++의 컨테이너 대입은 원소를 실제로 복사하므로, 이후 `perm`이 `pop_back`으로 바뀌어도 저장된 값은 그대로다 — 파이썬에서 `first = perm`(참조 저장)이 만들던 함정이 여기엔 없다.
- 후보 `v`를 1..N으로 돌며 이미 쓴 값, 또는 `perm`이 비어 있지 않고 `|perm.back() − v| > D`인 값은 건너뛴다. 통과하면 표시 → `push_back` → 재귀 → `pop_back` → 복원.
- 끝에 개수와 `first_perm`(비어 있으면 `NONE`)을 출력한다. "해가 없음"을 나타내는 데 파이썬의 `None` 대신 **빈 벡터**를 쓰는 것이 C++식이다.

(3) 스스로 다시 짤 때 생각 순서

- 제약이 "직전 원소"에만 의존하면 `perm.back()`으로 충분하다. 첫 원소는 직전이 없으므로 `!perm.empty()`를 **왼쪽에** 두어 단축 평가로 보호한다. 빈 벡터에 `back()`을 부르면 예외가 아니라 정의되지 않은 동작이라 쓰레기값이 나온다.
- 저장은 대입 한 줄(`first_perm = perm;`)이면 되지만, 답이 수십만 개인 문제에서 매번 전체 벡터를 복사하면 그 자체가 병목이 된다. "한 번만 저장"인지 "매번 저장"인지 먼저 확인한다.
- D=0(N ≥ 2면 불가능 → NONE)과 N=1(항상 1개)로 경계를 검산하고, D가 크면 N!과 같아지는지 확인한다.
```

**12) 급식 메뉴 짜기** · Hard

- **요구사항**: N일 동안 매일 K종의 메뉴 중 하나를 정한다. 메뉴 i는 비용 `c_i`와 만족도 `s_i`를 가진다. 제약: (a) 같은 메뉴를 이틀 연속 내지 않는다, (b) 각 메뉴는 전체 기간에 최대 L번까지만 낸다, (c) 총 비용은 B 이하여야 한다. 만족도 합의 최댓값을 구하고, 가능한 일정이 없으면 -1을 출력하라.
- **입력**: 첫 줄 N K L B (1 ≤ N ≤ 8, 1 ≤ K ≤ 5, 1 ≤ L ≤ N, 1 ≤ B ≤ 1000). 이어 K줄에 `c_i s_i`(1 ≤ c_i, s_i ≤ 100).
- **출력**: 최대 만족도 합 또는 -1.
- **예제**: `3 2 2 100 / 10 5 / 20 8` → `21` · `3 2 2 45 / 10 5 / 20 8` → `18` · `2 1 1 100 / 10 5` → `-1`
- **셀프체크**: 첫 예제는 메뉴 2-1-2(비용 50, 만족 21)가 최대이고, 예산이 45로 줄면 1-2-1(비용 40, 만족 18)만 가능하다. 세 제약을 어디에 두었는가 — 연속 금지·횟수 제한은 후보 필터(`continue`), 비용 초과도 후보 필터, 그리고 상한 가지치기(`현재 만족 + 남은 일수 × 최대 만족도 <= best`)는 진입 직후. 메뉴 횟수 배열은 재귀 뒤에 되돌려야 한다. 최대 만족도는 `*max_element(sat.begin(), sat.end())`로 구한다. `1 1 1 5 / 10 5`는 비용 초과로 `-1`.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int N, K, L, B;
vector<int> cost, sat;
vector<int> used_cnt;        // 메뉴별 사용 횟수
int max_sat;
int best = -1;

void rec(int day, int prev, int total_cost, int total_sat) {
    if (total_sat + (N - day) * max_sat <= best) return;   // 상한 가지치기
    if (day == N) {
        best = total_sat;
        return;
    }
    for (int m = 0; m < K; m++) {
        if (m == prev || used_cnt[m] == L) continue;       // 연속 금지 · 횟수 제한
        if (total_cost + cost[m] > B) continue;            // 예산 초과
        used_cnt[m]++;
        rec(day + 1, m, total_cost + cost[m], total_sat + sat[m]);
        used_cnt[m]--;                                     // 되돌리기
    }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> N >> K >> L >> B;
    cost.resize(K);
    sat.resize(K);
    for (int i = 0; i < K; i++) cin >> cost[i] >> sat[i];

    max_sat = *max_element(sat.begin(), sat.end());
    used_cnt.assign(K, 0);

    rec(0, -1, 0, 0);                 // prev = -1: 첫날은 연속 제약 없음
    cout << best << '\n';
    return 0;
}

(1) 접근·핵심 아이디어

- "N일 × K개 후보"의 K^N 틀에 이 챕터에서 배운 가지치기를 전부 결합한 문제다. 국소 제약(직전 메뉴), 개수 제약(메뉴별 횟수), 누적 제약(비용), 상한 가지치기(남은 일수로 얻을 수 있는 최대 만족도)가 각각 한 줄씩 대응된다.
- 상태는 (날짜, 직전 메뉴, 누적 비용, 누적 만족도) + 메뉴별 사용 횟수 배열. 횟수 배열만 가변 상태이므로 재귀 뒤 복원한다.

(2) 코드 단계별

- `max_sat`(하루 최대 만족도)를 `*max_element(sat.begin(), sat.end())`로 미리 구해 상한 계산에 쓴다. `max_element`는 **반복자**를 돌려주므로 `*`로 값을 꺼내야 한다.
- `best`는 -1로 시작해 일정이 하나도 완성되지 않으면 그대로 출력된다. `rec(day, prev, total_cost, total_sat)`: 진입 직후 `total_sat + (N − day) × max_sat <= best`면 중단. `day == N`이면 상한을 통과한 것이므로 곧바로 `best = total_sat`.
- 후보 메뉴 `m`을 돌며 직전과 같거나 횟수가 L에 도달했거나 예산을 넘으면 건너뛰고, 통과하면 `used_cnt[m]++` → 재귀 → `used_cnt[m]--`. 첫날은 `prev = -1`이라 어떤 메뉴와도 같지 않다.

(3) 스스로 다시 짤 때 생각 순서

- 제약 문장을 종류별로 분류한다: "연속 금지"는 `prev`, "최대 L번"은 횟수 배열, "예산"은 누적 비용, "최대화"는 상한 컷. 각각을 코드의 어느 위치(진입 직후 vs 후보 루프)에 둘지 정한다.
- 상한 컷의 등호(`<=`)는 "같은 값은 갱신이 아니므로 자른다"는 뜻이다. `day == N`에서 별도 비교 없이 대입해도 되는 이유가 이 컷 덕분임을 이해한다.
- 인자로 넘기는 상태(비용·만족도)는 복원이 필요 없지만, 공유 배열(`used_cnt`)은 반드시 복원해야 한다. 이 구분이 백트래킹 코드를 읽는 첫 번째 눈이다. K=1이고 N ≥ 2면 연속 금지 때문에 불가능(-1), 예산이 하루치보다 작아도 불가능(-1)임을 경계로 검산한다.
```
