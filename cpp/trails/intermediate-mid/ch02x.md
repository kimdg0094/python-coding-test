## L7. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch2(Shorten time Technique)의 핵심을 **반복 훈련**하고, 코딩테스트 단골 유형으로 **확장**하는 연습 세트다. 새 문법은 없다. 누적합·좌표 압축·LR·차분 배열(imos)·전처리 표·투 포인터만으로 12문제를 풀되, "나이브 O(N²)·O(NQ)를 O(N)·O(N log N)으로 끌어내린다"는 한 가지 목표를 매 문제에서 확인한다.

- **반복 훈련 개념**
- 누적합: `vector<long long> pre(n + 1)`, `pre[i] = pre[i-1] + a[i-1]`, 구간 `[l, r]`은 `pre[r] - pre[l-1]`. 값 대신 "조건을 만족하면 1"을 더하면 개수 질의가 된다. 합이 커질 수 있으므로 원소가 `int`여도 누적합은 `long long`
- 나머지 누적합: 접두합을 K로 나눈 나머지가 같은 두 지점 사이 구간은 K의 배수 — `ans += cnt[run]` 다음에 `cnt[run]++`. **C++의 `%`는 음수 피연산자에 음수를 돌려주므로** `run = ((run + x) % k + k) % k`로 반드시 보정한다
- 좌표 압축 + 이분탐색: `sort(v.begin(), v.end()); v.erase(unique(v.begin(), v.end()), v.end());`, 값 범위 `[L, R]`은 인덱스 `lower_bound(v.begin(), v.end(), L)`부터 `upper_bound(v.begin(), v.end(), R)`까지(`vector`는 임의 접근이라 전역 알고리즘이 O(log n)이다)
- LR: 접두 배열 L과 접미 배열 R을 각각 한 번씩 채우고 위치별로 결합 — `for (int i = n - 2; i >= 0; i--)`
- 차분 배열(imos)·이벤트 스위프: `diff[l] += v; diff[r+1] -= v` 후 누적합, 또는 `(시각, ±1)` 이벤트를 `vector<pair<...>>`에 모아 정렬 후 순서대로 누적
- 투 포인터: `right`를 늘리며 넣고 조건이 깨지면 `while`로 `left`를 밀어 회복, 답 갱신은 불변식이 성립한 직후

- **코딩테스트 출제 맵**: 이 챕터의 유형은 백준 「단계별로 풀어보기」의 '누적 합'·'투 포인터' 단계, NeetCode 150의 'Two Pointers'·'Sliding Window'·'Intervals', solved.ac CLASS 3~4의 구간합·나머지 합·부분합 문제에 그대로 등장한다. 이 레슨의 유형 확장 문제는 그 대표 유형의 소재·수치·조건을 새로 만들어 재구성한 것이다.

**문제**

**1) 모음 개수 구간 질의** · Easy

- **요구사항**: 소문자 문자열 s와 Q개의 질의 `(l, r)`이 주어질 때, 각 질의마다 `s[l..r]`(1-indexed) 안의 모음(a, e, i, o, u) 개수를 출력하라.
- **입력**: 첫 줄 문자열 s(길이 1 이상 200 이하). 둘째 줄 Q(1 ≤ Q ≤ 200). 이후 Q줄에 `l r`(1 ≤ l ≤ r ≤ s의 길이).
- **출력**: 질의마다 모음 개수를 한 줄씩.
- **예제**: `programming / 2 / 1 3 / 4 11` → `1 / 2` · `xyz / 1 / 2 2` → `0`
- **셀프체크**: 질의마다 부분 문자열을 세면 O(Q·N). "모음이면 1, 아니면 0"을 누적합으로 만들면 질의당 O(1)이다. `l == r`인 한 글자 질의, 모음이 하나도 없는 문자열, 전체 구간이 맞는지. `s.size()`는 `size_t`(부호 없음)이므로 `int n = (int)s.size()`로 받아 두면 뺄셈에서 사고가 없다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;
    int q;
    cin >> q;
    int n = (int)s.size();                 // size()는 unsigned이므로 int로 받는다

    vector<int> pre(n + 1, 0);             // 1-인덱스 접두합
    for (int i = 1; i <= n; i++) {
        char c = s[i - 1];
        int isVowel = (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') ? 1 : 0;
        pre[i] = pre[i - 1] + isVowel;
    }

    string out;
    for (int i = 0; i < q; i++) {
        int l, r;
        cin >> l >> r;
        out += to_string(pre[r] - pre[l - 1]);
        out += '\n';
    }
    cout << out;
    return 0;
}

(1) 접근·핵심 아이디어

- 누적합은 "수의 합"뿐 아니라 "조건을 만족하는 원소의 개수"에도 그대로 쓰인다. 각 글자를 모음이면 1, 아니면 0으로 보고 접두합을 만들면, 구간의 모음 개수는 `pre[r] - pre[l-1]` 한 번의 뺄셈이다. 전처리 O(N) + 질의당 O(1)로 전체 O(N + Q).

(2) 코드 단계별

- `pre[0] = 0`, `pre[i] = pre[i-1] + (s[i-1]이 모음이면 1 else 0)`로 1-인덱스 접두합을 채운다. `vector<int> pre(n + 1, 0)`처럼 크기와 초깃값을 함께 주면 초기화를 잊는 사고가 없다.
- 각 질의 `(l, r)`에 대해 `pre[r] - pre[l-1]`을 기록해 출력.
- 첫 예제 `programming`: 모음 위치는 3(o), 6(a), 10(i)이므로 `[1,3]`은 1개, `[4,11]`은 2개.

(3) 스스로 다시 짤 때 생각 순서

- "같은 문자열에 구간 질의가 반복" → 누적합. 무엇을 더할지(여기선 모음 여부 0/1)를 먼저 정한다.
- 1-인덱스로 `pre`를 두면 `l-1`이 음수가 되지 않는다. C++에서 `vector`의 음수 인덱스는 예외가 아니라 **정의되지 않은 동작**이라 값이 조용히 이상해질 뿐이니, 인덱스 설계를 먼저 확정하는 습관이 파이썬보다 더 중요하다.
- 경계: 한 글자 질의(`l == r`), 모음이 전혀 없을 때 0, 전체 구간 `[1, N]`은 `pre[N]`.
```

**2) 두 정렬 배열 병합** · Easy

- **요구사항**: 각각 오름차순으로 정렬된 두 정수 배열 A, B를 하나의 오름차순 배열로 합쳐 출력하라. 같은 값은 개수만큼 모두 남긴다. 두 배열을 이어 붙여 다시 정렬하지 말고 앞에서부터 한 번씩만 훑어 O(N + M)으로 풀 것.
- **입력**: 첫 줄 N M(1 ≤ N, M ≤ 300). 둘째 줄 A(N개), 셋째 줄 B(M개). 원소는 -10^9 이상 10^9 이하.
- **출력**: 합친 배열을 공백으로.
- **예제**: `3 4 / 1 4 9 / 2 4 5 10` → `1 2 4 4 5 9 10` · `1 3 / 5 / 1 2 3` → `1 2 3 5`
- **셀프체크**: 두 포인터 i, j 중 작은 쪽을 내보내고 그쪽만 전진. 한쪽이 먼저 끝나면 남은 쪽을 통째로 붙였는가? 같은 값일 때 어느 쪽을 먼저 내보내도 결과는 같다(값이 같으므로). 표준 라이브러리의 `std::merge`가 정확히 이 일을 하지만, 여기서는 손으로 짜 보는 것이 훈련 목적이다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    vector<long long> A(n), B(m);
    for (int i = 0; i < n; i++) cin >> A[i];
    for (int i = 0; i < m; i++) cin >> B[i];

    vector<long long> res;
    res.reserve(n + m);                     // 재할당을 막는다
    int i = 0, j = 0;
    while (i < n && j < m) {
        if (A[i] <= B[j]) res.push_back(A[i++]);
        else res.push_back(B[j++]);
    }
    while (i < n) res.push_back(A[i++]);    // 남은 꼬리를 잊지 말 것
    while (j < m) res.push_back(B[j++]);

    string out;
    for (size_t t = 0; t < res.size(); t++) {
        if (t) out += ' ';
        out += to_string(res[t]);
    }
    cout << out << "\n";
    return 0;
}

(1) 접근·핵심 아이디어

- 두 배열이 이미 정렬되어 있으므로, 각 배열의 "아직 안 내보낸 첫 원소" 둘 중 작은 것이 전체에서 다음으로 작은 값이다. 포인터 두 개가 각자 끝까지 한 번씩만 전진하므로 O(N + M)이며, 이어 붙여 정렬하는 O((N+M) log(N+M))보다 빠르다. 병합 정렬의 합치기 단계와 같은 골격이다.

(2) 코드 단계별

- `i = j = 0`에서 시작해 둘 다 남아 있는 동안 `A[i] <= B[j]`면 A 쪽, 아니면 B 쪽을 내보내고 그 포인터만 전진.
- 한쪽이 끝나면 남은 쪽을 순서대로 모두 붙인다(정렬되어 있으므로 그대로 이어도 됨).
- 결과를 공백으로 이어 출력. 첫 항목 앞에만 공백을 생략해 꼬리 공백이 남지 않게 한다.

(3) 스스로 다시 짤 때 생각 순서

- "정렬된 두 열을 하나로" → 같은 방향 투 포인터(병합). `sort` 호출의 유혹을 참는 것이 훈련 목적.
- 루프 종료 후 "남은 꼬리 붙이기"를 잊으면 원소가 사라진다(둘째 테스트: A가 먼저 끝남).
- `res.reserve(n + m)`으로 미리 용량을 잡아 두면 `push_back` 중 재할당·복사가 사라진다. 크기를 아는 `vector`에는 습관적으로 붙여 둘 만하다.
- 경계: 한쪽 길이 1, 전부 같은 값(중복 보존), 음수(값이 10^9까지이므로 `long long`으로 받아 두면 이후 합을 구하는 변형에도 안전하다).
```

**3) 합이 K의 배수인 구간 수** · Medium

- **요구사항**: 정수 배열에서 연속 부분 배열(길이 1 이상)의 합이 K의 배수인 것의 개수를 출력하라.
- **입력**: 첫 줄 N K(1 ≤ N ≤ 500, 1 ≤ K ≤ 500). 둘째 줄 N개의 정수(-10^6 이상 10^6 이하, 음수 가능).
- **출력**: 구간의 개수.
- **예제**: `5 3 / 1 2 3 4 5` → `7` · `3 5 / 5 5 5` → `6`
- **셀프체크**: 접두합 `pre[i] - pre[j]`가 K의 배수 ⟺ 두 접두합의 K 나머지가 같다. 나머지별 개수 배열에 `pre[0] = 0`의 나머지 0을 미리 1로 넣었는가? **C++의 `%`는 피연산자가 음수면 결과도 음수다**(`-2 % 4 == -2`) — 그대로 배열 인덱스로 쓰면 범위를 벗어난다. `((run + x) % k + k) % k`로 0 이상 K 미만으로 접어 준다. 검산(첫 예제): 접두합 0,1,3,6,10,15 → 나머지 0,1,0,0,1,0 → 0이 4개(6쌍), 1이 2개(1쌍) → 7.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    long long k;
    cin >> n >> k;

    vector<long long> cnt(k, 0);
    cnt[0] = 1;                       // pre[0] = 0 의 나머지 0을 미리 세어 둔다
    long long run = 0, ans = 0;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        run = ((run + x) % k + k) % k; // C++의 %는 음수를 그대로 음수로 낸다
        ans += cnt[run];               // '더한 뒤' 세야 자기 자신과 짝짓지 않는다
        cnt[run]++;
    }
    cout << ans << "\n";
    return 0;
}

(1) 접근·핵심 아이디어

- 구간 `(j, i]`의 합은 `pre[i] - pre[j]`이고, 이것이 K의 배수라는 것은 `pre[i] % K == pre[j] % K`와 같다. 따라서 "나머지가 같은 접두합 쌍의 수"를 세면 된다. 모든 구간을 직접 보면 O(N²)이지만, 왼쪽부터 훑으며 "지금 나머지와 같은 나머지를 가진 이전 접두합 개수"를 더하면 O(N)이다.
- 빈 접두합 `pre[0] = 0`도 후보이므로 나머지 0의 개수를 1로 시작한다 — 이것을 빠뜨리면 배열 처음부터 시작하는 구간이 전부 누락된다.

(2) 코드 단계별

- `vector<long long> cnt(k, 0)`, `cnt[0] = 1`, 현재 나머지 `run = 0`.
- 원소 x마다 `run = ((run + x) % k + k) % k`, 먼저 `ans += cnt[run]`(같은 나머지를 가진 이전 지점 수), 그다음 `cnt[run]++`.
- 마지막에 `ans` 출력. "더한 뒤 세기" 순서를 지켜야 자기 자신과 짝짓지 않는다.

(3) 스스로 다시 짤 때 생각 순서

- "합이 K의 배수인 구간 수" → 접두합 나머지의 동일 쌍 세기로 번역한다.
- 함정 — **음수 나머지.** 파이썬의 `%`는 결과 부호를 나누는 수에 맞춰 항상 0 이상을 주지만, C++(C99 이후)의 `%`는 나누어지는 수의 부호를 따른다: `-2 % 4`가 파이썬에서는 2, C++에서는 **-2**다. 이 값을 `cnt[run]`의 인덱스로 쓰면 `vector`가 범위를 검사하지 않으므로 예외 없이 엉뚱한 메모리를 읽고 쓴다 — 셋째 테스트가 정확히 이 경우다. `((a % k) + k) % k` 관용구를 음수가 섞일 수 있는 모든 나머지 계산에 붙인다.
- 함정 2 — `run`을 `int`로 두고 원소가 10^6, N이 500이면 접두합 자체는 `int` 안이지만, 원소 범위가 커지는 변형에서 바로 넘친다. 나머지만 굴리므로 `run`은 항상 작지만, `x`를 더하는 순간의 중간값을 생각해 `long long`으로 둔다.
- 접두합을 배열로 다 만들 필요 없이 나머지 하나만 굴리면 공간 O(K).
- 경계: 음수 원소, K=1(모든 구간이 정답), 원소 전부가 K의 배수(둘째 테스트처럼 모든 접두합 나머지가 0), 정답이 0인 경우.
```

**4) 큰 좌표 위 가중치 구간합** · Medium

- **요구사항**: 수직선 위에 점 N개가 있고 각 점은 좌표 x와 가중치 w를 가진다(좌표는 서로 다르고 최대 10^9). Q개의 질의 `(L, R)`마다 L ≤ x ≤ R인 점들의 가중치 합을 출력하라.
- **입력**: 첫 줄 N Q(1 ≤ N, Q ≤ 300). 이후 N줄에 `x w`(0 ≤ x ≤ 10^9, 1 ≤ w ≤ 1000). 이후 Q줄에 `L R`(0 ≤ L ≤ R ≤ 10^9).
- **출력**: 질의마다 합을 한 줄씩.
- **예제**: `4 3 / 100 5 / 3 2 / 1000000000 7 / 50 1 / 3 100 / 60 999999999 / 1 1000000000` → `8 / 5 / 15` · `1 1 / 10 4 / 11 20` → `0`
- **셀프체크**: 좌표를 배열 인덱스로 쓸 수 없으니 점을 좌표순으로 정렬해 "순위"를 인덱스로 삼는다(좌표 압축). 질의 `[L, R]`은 정렬 좌표에서 `lower_bound(xs, L)`부터 `upper_bound(xs, R)` 직전까지이고, 이 인덱스 구간의 가중치 합을 누적합으로 O(1)에 구한다. 반환값은 반복자이므로 `- xs.begin()`으로 인덱스로 바꿔야 한다. 질의 범위에 점이 하나도 없으면 두 위치가 같아 0이 나오는지.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    cin >> n >> q;
    vector<pair<long long, long long>> pts(n);
    for (int i = 0; i < n; i++) cin >> pts[i].first >> pts[i].second;
    sort(pts.begin(), pts.end());              // pair는 first 기준 사전순

    vector<long long> xs(n);
    vector<long long> pre(n + 1, 0);
    for (int i = 0; i < n; i++) {
        xs[i] = pts[i].first;
        pre[i + 1] = pre[i] + pts[i].second;
    }

    string out;
    for (int i = 0; i < q; i++) {
        long long l, r;
        cin >> l >> r;
        // vector는 임의 접근이라 전역 lower_bound/upper_bound가 O(log N)이다
        int lo = (int)(lower_bound(xs.begin(), xs.end(), l) - xs.begin());
        int hi = (int)(upper_bound(xs.begin(), xs.end(), r) - xs.begin());
        out += to_string(pre[hi] - pre[lo]);   // [lo, hi) 반열림
        out += '\n';
    }
    cout << out;
    return 0;
}

(1) 접근·핵심 아이디어

- 좌표 범위는 10^9지만 점은 N개뿐이므로 실제 값 대신 정렬 순위로 다루는 좌표 압축이 맞다. 정렬한 뒤 가중치 누적합을 만들면 질의는 "L 이상 첫 점의 순위 ~ R 이하 마지막 점의 순위" 사이의 합이고, 순위 두 개는 이분탐색으로 O(log N)에 얻는다. 질의마다 점을 전부 훑는 O(NQ) 대신 O((N + Q) log N).
- `lower_bound(xs, L)`은 L 이상 첫 위치, `upper_bound(xs, R)`은 R 초과 첫 위치라 반열림 `[lo, hi)`가 되고, 누적합 `pre[hi] - pre[lo]`와 정확히 맞물린다.

(2) 코드 단계별

- `(x, w)`를 `vector<pair<long long,long long>>`에 담아 정렬한다. `pair`의 `operator<`가 `first` 우선 사전순이라 좌표순 정렬이 공짜다.
- 좌표만 뽑은 `xs`와 가중치 접두합 `pre`를 같은 루프에서 만든다.
- 질의마다 `lower_bound`/`upper_bound`의 반환 **반복자**에서 `xs.begin()`을 빼 인덱스로 바꾸고 `pre[hi] - pre[lo]`를 출력.
- 첫 예제: 정렬 좌표 3, 50, 100, 10^9 → `[3, 100]`은 앞 세 점 2+1+5=8, `[60, 999999999]`는 100 하나 5, 전체 15.

(3) 스스로 다시 짤 때 생각 순서

- "좌표 범위는 크고 개수는 작다 + 값 범위 질의" → 압축(정렬) + 누적합 + 이분탐색의 3단 결합을 떠올린다.
- 경계 포함(≤, ≥)에 맞춰 왼쪽은 `lower_bound`, 오른쪽은 `upper_bound`를 고르고, 점이 하나도 없는 범위에서 `lo == hi`가 되어 0이 나오는지 확인한다.
- 함정 — `lower_bound`는 인덱스가 아니라 **반복자**를 돌려준다. `- xs.begin()`을 빼먹으면 컴파일 오류가 나거나(다행) 반복자 산술을 잘못 써서 엉뚱한 값이 된다. 그리고 이 문제처럼 대상이 `vector`(임의 접근)일 때만 전역 `std::lower_bound`가 O(log N)이다 — `set`/`map`에 쓰면 O(n)으로 퇴화하므로 그때는 멤버 함수를 쓴다.
- 경계: 질의 끝점이 정확히 점 좌표와 같을 때(포함), 모든 점 밖의 범위(0), 좌표 10^9(`int`로도 들어가지만 `long long`이 안전하다).
```

**5) 두 팀 분할 지점** · Medium

- **요구사항**: 정수 배열을 앞부분과 뒷부분(둘 다 길이 1 이상)으로 자른다. "앞부분의 최댓값 ≤ 뒷부분의 최솟값"이 되는 자르는 위치 중 앞부분의 길이가 가장 짧은 것을 출력하라. 없으면 -1.
- **입력**: 첫 줄 N(2 ≤ N ≤ 500). 둘째 줄 N개의 정수(-10^9 이상 10^9 이하).
- **출력**: 앞부분의 길이 p(1 ≤ p ≤ N-1) 또는 -1.
- **예제**: `6 / 5 0 3 8 6 9` → `3` · `2 / 1 1` → `1`
- **셀프체크**: 자르는 위치마다 양쪽을 다시 훑으면 O(N²). 접두 최대 `L[i] = max(a[0..i])`와 접미 최소 `R[i] = min(a[i..n-1])`를 각각 한 번에 채우면 위치 p의 조건은 `L[p-1] <= R[p]`로 O(1). 조건이 "≤"라 같은 값이 양쪽에 걸쳐도 허용된다. 접미 루프는 `for (int i = n - 2; i >= 0; i--)`처럼 **부호 있는 인덱스**로 돌려야 한다(`size_t`로 돌리면 0에서 1을 뺀 순간 거대한 양수가 되어 무한 루프). 검산(첫 예제): p=1은 5 ≤ 0 거짓, p=2는 5 ≤ 3 거짓, p=3은 5 ≤ 6 참.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<long long> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    vector<long long> L(n), R(n);
    L[0] = a[0];
    for (int i = 1; i < n; i++) L[i] = max(L[i - 1], a[i]);   // 접두 최대
    R[n - 1] = a[n - 1];
    for (int i = n - 2; i >= 0; i--) R[i] = min(R[i + 1], a[i]);  // 접미 최소 (int로!)

    for (int p = 1; p < n; p++) {
        if (L[p - 1] <= R[p]) {
            cout << p << "\n";
            return 0;
        }
    }
    cout << -1 << "\n";
    return 0;
}

(1) 접근·핵심 아이디어

- 위치 p의 판정에는 "왼쪽 전체의 최댓값"과 "오른쪽 전체의 최솟값"이 동시에 필요하다. 이것이 LR 기법의 신호다. 접두 최대 L과 접미 최소 R을 각각 한 번의 스캔으로 채우면 판정이 O(1)이 되어 전체 O(N)(나이브 O(N²)).
- 접두는 왼쪽에서 오른쪽으로 `max`, 접미는 오른쪽에서 왼쪽으로 `min`으로 누적한다는 방향 차이가 핵심이다.

(2) 코드 단계별

- `L[0] = a[0]`, `L[i] = max(L[i-1], a[i])`(자신 포함 접두 최대).
- `R[n-1] = a[n-1]`, `R[i] = min(R[i+1], a[i])`(자신 포함 접미 최소).
- p를 1부터 N-1까지 올리며 처음으로 `L[p-1] <= R[p]`인 p를 출력. 없으면 -1.

(3) 스스로 다시 짤 때 생각 순서

- "자르는 위치마다 양쪽 정보가 필요" → LR. 각 배열의 정의(자신 포함 여부)를 한 줄로 적고 시작한다.
- 가장 짧은 p를 원하므로 작은 p부터 훑다가 첫 성공에서 멈춘다.
- 함정 — **역방향 루프의 인덱스 타입.** `for (size_t i = n - 2; i >= 0; i--)`는 `size_t`가 부호 없는 타입이라 `i >= 0`이 항상 참이고, `i`가 0에서 1을 빼는 순간 약 1.8·10^19가 되어 `vector` 범위를 한참 벗어난 곳을 읽는다. 역방향 루프는 항상 `int`(또는 `long long`) 같은 부호 있는 타입으로 돌린다.
- 함정 2 — `max`/`min`은 두 인자의 타입이 같아야 한다. `max(L[i-1], a[i])`처럼 둘 다 `long long`이면 문제없지만 `max(0, someLongLong)`처럼 섞으면 컴파일 오류가 난다(`max(0LL, x)`로 맞춘다).
- 경계: N=2, 같은 값이 경계에 걸친 경우(넷째 테스트: 1 ≤ min(2,2,1)=1이라 p=1), 어떤 위치도 안 되는 감소 배열(-1).
```

**6) 버스 정원 검사** · Medium

- **요구사항**: 정류장 1..S를 순서대로 지나는 버스가 있다. 승차 기록 N개 `(f, t, c)`는 "정류장 f에서 c명이 타서 정류장 t에서 내린다"(f < t)는 뜻이다. 각 정류장을 출발할 때의 탑승 인원 중 최댓값을 구하고, 그것이 정원 C 이하이면 `OK`, 넘으면 `OVER`를 함께 출력하라. 정류장 t에서 내리는 승객은 t를 출발할 때 이미 없는 것으로 본다.
- **입력**: 첫 줄 S N C(2 ≤ S ≤ 500, 1 ≤ N ≤ 300, 1 ≤ C ≤ 10^6). 이후 N줄에 `f t c`(1 ≤ f < t ≤ S, 1 ≤ c ≤ 1000).
- **출력**: `최대 탑승 인원 OK` 또는 `최대 탑승 인원 OVER`.
- **예제**: `5 3 4 / 1 3 2 / 2 5 3 / 3 4 1` → `5 OVER` · `3 1 10 / 1 3 10` → `10 OK`
- **셀프체크**: 기록마다 정류장 f..t-1을 직접 더하면 O(N·S). 차분 배열에 `diff[f] += c`, `diff[t] -= c`만 기록하고 누적합 한 번이면 O(N + S). 구간이 반열림 `[f, t)`이므로 `-c`를 `t+1`이 아니라 `t`에 둔다 — 셋째 테스트처럼 한 팀이 내리는 정류장에서 다른 팀이 타면 겹치지 않아야 한다. 배열 크기는 `S+2`로 잡아 `diff[t]`가 범위를 벗어나지 않게 한다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int s, n;
    long long cap;
    cin >> s >> n >> cap;

    vector<long long> diff(s + 2, 0);   // t가 S일 수 있으므로 S+2 크기
    for (int i = 0; i < n; i++) {
        int f, t;
        long long c;
        cin >> f >> t >> c;
        diff[f] += c;
        diff[t] -= c;                   // 반열림 [f, t): t+1이 아니라 t
    }

    long long best = 0, run = 0;
    for (int i = 1; i <= s; i++) {
        run += diff[i];
        if (run > best) best = run;
    }
    cout << best << " " << (best <= cap ? "OK" : "OVER") << "\n";
    return 0;
}

@@EXPL
(1) 접근·핵심 아이디어

- "구간에 일괄 더하기 여러 번 + 최종 상태만 필요"는 차분 배열(imos)의 전형이다. 각 기록을 시작점 `+c`, 끝점 `-c` 두 번의 기록으로 처리하고, 마지막에 누적합으로 정류장별 탑승 인원을 복원해 최댓값을 취한다. O(N + S).
- 이 문제의 구간은 반열림 `[f, t)`다(내리는 정류장에서는 이미 없음). 그래서 `-c`를 `t`에 둔다. 폐구간이었다면 `t+1`이었을 것이다 — 구간의 열림/닫힘을 문장에서 먼저 읽어내는 것이 이 유형의 핵심 함정이다.

(2) 코드 단계별

- `diff`를 `vector<long long> diff(s + 2, 0)`으로 준비하고 기록마다 `diff[f] += c`, `diff[t] -= c`.
- 정류장 1..S를 순서대로 누적하며 탑승 인원 `run`의 최댓값 `best`를 갱신.
- `best`와 함께 `best <= C`면 `OK`, 아니면 `OVER`를 출력. 삼항 연산자의 두 갈래가 모두 `const char*`라 `cout`에 그대로 넣을 수 있다.

(3) 스스로 다시 짤 때 생각 순서

- "탈 때 +, 내릴 때 -"를 보면 차분 배열(또는 이벤트)을 떠올린다.
- 구간 끝 처리: 내리는 정류장 t는 포함하지 않으므로 `t`에 `-c`. 예제로 반드시 검산한다(셋째 테스트: 2번 정류장에서 3명이 내리고 3명이 타 최대 3).
- 함정 — **배열 크기.** 차분 배열은 항상 "쓸 수 있는 최대 인덱스 + 1"까지 잡아야 한다. 여기서는 `t`가 최대 S이므로 `S+1`이면 되지만, 폐구간 버전(`t+1`에 빼기)으로 바꿔 풀면 `S+2`가 필요하다. 습관적으로 `S+2`로 잡아 두면 두 경우 모두 안전하다. C++에서 범위를 벗어난 `vector` 접근은 예외가 아니라 조용한 메모리 오염이다.
- 함정 2 — `vector<long long> diff(s + 2)`처럼 초깃값을 생략해도 `vector`는 0으로 채워 준다. 하지만 지역 **배열**(`long long diff[502];`)은 초기화되지 않은 쓰레기값이므로 `= {}`나 `memset`이 필요하다. `vector`를 쓰는 편이 사고가 적다.
- 경계: 기록 하나가 전체 구간을 덮는 경우(둘째 테스트), 정확히 정원과 같을 때 `OK`(≤).
```

**7) k번째 빈 좌석 조회** · Medium

- **요구사항**: 좌석 N개의 상태가 `0`(빈 자리)/`1`(찬 자리) 문자열로 주어진다. Q개의 질의 `(i, k)`마다 "좌석 i부터 오른쪽으로 보았을 때 k번째 빈 좌석의 번호"를 출력하라(좌석 i 자신도 포함). 그런 좌석이 없으면 -1.
- **입력**: 첫 줄 N(1 ≤ N ≤ 500). 둘째 줄 길이 N의 0/1 문자열. 셋째 줄 Q(1 ≤ Q ≤ 500). 이후 Q줄에 `i k`(1 ≤ i ≤ N, 1 ≤ k ≤ N).
- **출력**: 질의마다 좌석 번호 또는 -1을 한 줄씩.
- **예제**: `10 / 1101001110 / 3 / 1 1 / 4 2 / 8 2` → `3 / 6 / -1` · `3 / 111 / 1 / 1 1` → `-1`
- **셀프체크**: 질의마다 i부터 훑으면 O(NQ). 빈 좌석 번호를 순서대로 담은 `vector<int> freePos`와 "좌석 i 이전(1..i-1)의 빈 좌석 수" `before[i-1]`을 미리 만들면 답은 `freePos[before[i-1] + k - 1]`로 O(1). 인덱스가 목록 크기 이상이면 -1 — 비교할 때 `freePos.size()`가 `size_t`이므로 `(int)`로 받아 비교한다. 검산(첫 예제): 빈 좌석 3, 5, 6, 10 → (4, 2)는 4 이전 빈 좌석 1개 → 목록의 2번 인덱스 6.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    string seats;
    cin >> seats;
    int q;
    cin >> q;

    vector<int> freePos;                 // 빈 좌석 번호(오름차순)
    vector<int> before(n + 1, 0);        // before[i] = 좌석 1..i 중 빈 좌석 수
    for (int i = 0; i < n; i++) {
        before[i + 1] = before[i];
        if (seats[i] == '0') {
            freePos.push_back(i + 1);
            before[i + 1]++;
        }
    }

    int total = (int)freePos.size();     // size()는 unsigned이므로 int로 받는다
    string out;
    for (int t = 0; t < q; t++) {
        int i, k;
        cin >> i >> k;
        int j = before[i - 1] + k - 1;   // i 자신을 포함하려면 before[i-1]
        out += (j < total) ? to_string(freePos[j]) : string("-1");
        out += '\n';
    }
    cout << out;
    return 0;
}

(1) 접근·핵심 아이디어

- 같은 좌석 배열에 질의가 반복되므로 "질의가 매번 하는 계산"을 표로 미리 만든다. 필요한 것은 두 가지: 빈 좌석 번호의 오름차순 목록, 그리고 "좌석 i 앞까지 빈 좌석이 몇 개였나"(누적 개수). i부터 k번째 빈 좌석은 목록에서 `before[i-1] + k - 1`번째 원소다. 전처리 O(N), 질의 O(1).
- 누적 개수 `before`는 곧 0/1 누적합이고, 목록은 그 누적합의 "역방향 조회표"다. 두 전처리를 결합해 질의를 인덱스 계산으로 바꾼 것이 요점이다.

(2) 코드 단계별

- 좌석 문자열을 왼쪽부터 훑으며 `before[i+1] = before[i]`로 복사하고, `seats[i] == '0'`이면 `freePos`에 번호를 추가하고 `before[i+1]++`.
- 질의 `(i, k)`: `j = before[i-1] + k - 1`. `j < (int)freePos.size()`면 `freePos[j]`, 아니면 -1.

(3) 스스로 다시 짤 때 생각 순서

- "고정 배열 + 같은 종류 질의 다수" → 전처리 표. 질의를 "표 조회 + 인덱스 산술"로 바꿀 수 있는지 먼저 본다.
- 좌석 i 자신을 포함해야 하므로 `before[i-1]`(i 앞까지)을 쓴다. `before[i]`를 쓰면 i가 빈 좌석일 때 건너뛴다(셋째 테스트 `4 1` → 4).
- 함정 — **`vector::size()`와 `int`의 비교.** `j < freePos.size()`는 왼쪽 `int`가 `size_t`로 승격되면서, `j`가 음수라면 거대한 양수로 바뀐다. 이 문제는 `j >= 0`이 보장되지만 습관적으로 `(int)`로 받아 비교하면 그런 사고가 원천 봉쇄된다(컴파일러의 `-Wsign-compare` 경고도 사라진다).
- 함정 2 — 문자 비교는 `seats[i] == '0'`(작은따옴표, 문자 리터럴)이다. `"0"`(큰따옴표)은 `const char*`라 `char`와 비교하면 컴파일 오류거나 주소 비교가 된다.
- 경계: 빈 좌석이 전혀 없을 때, k가 남은 빈 좌석 수보다 클 때(-1), 전부 빈 좌석일 때 k번째 그대로.
```

**8) 부분합 S 이상 최소 길이** · Medium

- **요구사항**: 양의 정수 배열에서 연속 부분 배열의 합이 S 이상이 되는 것 중 길이가 가장 짧은 것의 길이를 출력하라. 그런 부분 배열이 없으면 0.
- **입력**: 첫 줄 N S(1 ≤ N ≤ 500, 1 ≤ S ≤ 10^9). 둘째 줄 N개의 양의 정수(1 이상 10^6 이하).
- **출력**: 최소 길이 또는 0.
- **예제**: `8 15 / 5 1 3 5 10 7 4 9` → `2` · `3 100 / 1 2 3` → `0`
- **셀프체크**: 원소가 양수라 합이 단조롭다. `right`를 늘려 합을 키우고, 합이 S 이상인 동안 길이를 기록하며 `left`를 밀어 줄인다 — 답 갱신을 "줄이기 전"에 해야 한다. 한 원소만으로 S 이상이면 길이 1. 전체 합이 최대 500·10^6 = 5·10^8이라 `int` 상한(약 2.1·10^9)에 가깝다 — `cur`를 `long long`으로 두는 편이 안전하다. 검산(첫 예제): `5 10`의 합 15가 길이 2로 최소.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    long long s;
    cin >> n >> s;
    vector<long long> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    int left = 0, best = 0;
    long long cur = 0;                    // 합은 long long
    for (int right = 0; right < n; right++) {
        cur += a[right];
        while (cur >= s) {
            int len = right - left + 1;   // 조건이 참인 '지금' 기록
            if (best == 0 || len < best) best = len;
            cur -= a[left];
            left++;
        }
    }
    cout << best << "\n";
    return 0;
}

(1) 접근·핵심 아이디어

- 양수 배열이라 윈도우 합은 `right`를 늘리면 증가하고 `left`를 늘리면 감소한다(단조성). 그래서 "합이 S 이상"이 된 순간부터는 `left`를 한 칸씩 밀어 더 짧은 윈도우를 시도해도 되돌릴 필요가 없다. 각 포인터가 최대 N번 전진하므로 O(N)(모든 구간을 보는 O(N²) 대신).
- L6의 "합 ≤ K 최장" 문제와 방향이 반대다: 조건이 만족되는 동안 줄여서 최소 길이를 찾는다.

(2) 코드 단계별

- `right`마다 `cur += a[right]`.
- `cur >= S`인 동안: 현재 길이 `right - left + 1`로 `best`를 갱신(0이면 첫 갱신), 그다음 `cur -= a[left]; left++;`.
- 끝나면 `best` 출력(한 번도 갱신되지 않으면 0).

(3) 스스로 다시 짤 때 생각 순서

- "합 조건을 만족하는 최소 길이 + 양수" → 슬라이딩 윈도우. 단조성이 있는지 먼저 확인한다(음수가 섞이면 이 방법은 틀린다).
- 갱신 순서: 조건이 참인 상태에서 길이를 기록하고 나서 줄인다. 순서를 바꾸면 조건이 깨진 윈도우를 기록한다.
- 함정 — **누적 변수의 타입.** 원소가 10^6, 개수가 500이면 합이 5·10^8이라 `int`에 아슬아슬하게 들어가지만, N이나 원소 상한이 조금만 커져도 넘친다. C++의 `int` 오버플로는 정의되지 않은 동작이라 경고 없이 음수가 되고, 그러면 `cur >= s`가 거짓이 되어 윈도우가 영원히 줄지 않는다. 누적·곱셈이 들어가면 반사적으로 `long long`.
- 함정 2 — 변수 이름 `left`/`right`는 `<iomanip>`의 조작자 `std::left`, `std::right`와 이름이 겹친다. `using namespace std;` 아래에서 지역 변수로 선언하면 지역 이름이 가리므로 동작에는 문제가 없지만, 같은 이름의 조작자를 쓰려는 순간 충돌한다. 헷갈리면 `lo`/`hi`나 `l`/`r`로 바꾼다.
- 경계: 전체 합이 S 미만(0), 한 원소가 S 이상(길이 1), 전체가 딱 S(넷째 테스트: 길이 N).
```

**9) 가장 긴 산 구간** · Hard

- **요구사항**: 정수 배열에서 "산"은 길이가 3 이상이고, 어떤 봉우리까지 엄격히 증가한 뒤 끝까지 엄격히 감소하는 연속 부분 배열이다. 가장 긴 산의 길이를 출력하라. 산이 없으면 0.
- **입력**: 첫 줄 N(1 ≤ N ≤ 500). 둘째 줄 N개의 정수(0 이상 10^9 이하).
- **출력**: 최대 길이 또는 0.
- **예제**: `10 / 2 1 4 7 3 2 5 8 8 1` → `5` · `3 / 1 2 3` → `0`
- **셀프체크**: 봉우리 i마다 왼쪽으로 엄격 증가가 이어진 길이 `inc[i]`, 오른쪽으로 엄격 감소가 이어진 길이 `dec[i]`를 LR로 채우면 산의 길이는 `inc[i] + dec[i] - 1`. 단, 양쪽 모두 2 이상이어야 봉우리다(한쪽이 1이면 오르막만 또는 내리막만). 같은 값이 이어지면 run이 끊긴다(엄격). 두 배열을 `vector<int> inc(n, 1)`처럼 **1로 초기화**해 두면 "끊기면 1" 분기를 따로 쓸 필요가 없다. 검산(첫 예제): 봉우리 7에서 1,4,7 오르막(3) + 7,3,2 내리막(3) → 5. 봉우리 후보 8은 옆이 8이라 감소 run이 1이라 산이 아니다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<long long> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    vector<int> inc(n, 1), dec(n, 1);            // 초깃값 1 = "끊기면 1"
    for (int i = 1; i < n; i++)
        if (a[i] > a[i - 1]) inc[i] = inc[i - 1] + 1;
    for (int i = n - 2; i >= 0; i--)             // 역방향은 부호 있는 int로
        if (a[i] > a[i + 1]) dec[i] = dec[i + 1] + 1;

    int best = 0;
    for (int i = 0; i < n; i++) {
        if (inc[i] >= 2 && dec[i] >= 2) {        // 양쪽이 다 있어야 봉우리
            int len = inc[i] + dec[i] - 1;       // 봉우리 중복 제거
            if (len > best) best = len;
        }
    }
    cout << best << "\n";
    return 0;
}

(1) 접근·핵심 아이디어

- 산은 봉우리를 기준으로 "왼쪽 오르막 길이"와 "오른쪽 내리막 길이"가 결합된 것이다. 각 위치에 대해 양쪽 정보가 필요하므로 LR 기법: 왼쪽에서 오른쪽으로 증가 run 길이 `inc`, 오른쪽에서 왼쪽으로 감소 run 길이 `dec`를 각각 한 번에 채운다. 모든 봉우리 후보를 O(1)에 판정하므로 전체 O(N)(봉우리마다 양쪽으로 뻗어 가면 O(N²)).
- run 배열은 "조건이 이어지면 이전 값 + 1, 끊기면 1로 초기화"라는 접두/접미 누적의 변형이다. `vector<int> inc(n, 1)`로 만들어 두면 "끊기면 1"이 초깃값으로 이미 들어 있어 `else` 분기가 사라진다.

(2) 코드 단계별

- `inc[i] = inc[i-1] + 1` (단, `a[i] > a[i-1]`일 때만).
- `dec[i] = dec[i+1] + 1` (단, `a[i] > a[i+1]`일 때만, 뒤에서 앞으로).
- 각 i에서 `inc[i] >= 2 && dec[i] >= 2`일 때만 `inc[i] + dec[i] - 1`로 최댓값 갱신.

(3) 스스로 다시 짤 때 생각 순서

- "봉우리 기준 양쪽 길이" → LR run 배열. 두 배열의 정의(자신 포함, 엄격 조건)를 먼저 적는다.
- 봉우리 조건(양쪽 run ≥ 2)을 빠뜨리면 단조 증가 배열(둘째 테스트)이나 평지(셋째 테스트)에서 오답이 난다.
- 함정 — 역방향 루프 `for (int i = n - 2; i >= 0; i--)`의 `i`는 반드시 부호 있는 타입이다. `size_t`로 쓰면 0에서 한 번 더 내려가는 순간 무한 루프에 빠진다. 또 N=1이면 `n - 2 == -1`이라 루프가 한 번도 안 도는데, `size_t`였다면 여기서도 거대한 값이 되어 곧장 범위를 벗어난다.
- 함정 2 — 조건은 `>`(엄격)이지 `>=`가 아니다. 같은 값이 이어지는 평지에서 run이 끊겨야 셋째 테스트가 0이 된다.
- 경계: N < 3이면 산 없음, 같은 값 연속(엄격이라 run 끊김), 최소 산 `1 3 1`(길이 3).
```

**10) 압축 격자 점 개수 질의** · Hard

- **요구사항**: 평면 위에 점 N개가 있다(좌표는 최대 10^9, 같은 위치에 여러 점이 있을 수 있다). Q개의 직사각형 질의 `(x1, y1, x2, y2)`마다 x1 ≤ x ≤ x2, y1 ≤ y ≤ y2인 점의 개수를 출력하라.
- **입력**: 첫 줄 N Q(1 ≤ N, Q ≤ 300). 이후 N줄에 `x y`(0 ≤ x, y ≤ 10^9). 이후 Q줄에 `x1 y1 x2 y2`(x1 ≤ x2, y1 ≤ y2).
- **출력**: 질의마다 점의 개수를 한 줄씩.
- **예제**: `5 3 / 1 1 / 5 5 / 1000000000 1 / 5 1 / 3 7 / 1 1 5 5 / 6 0 1000000000 10 / 2 2 4 4` → `3 / 1 / 0` · `2 1 / 4 4 / 4 4 / 4 4 4 4` → `2`
- **셀프체크**: x, y를 각각 `sort` + `unique` + `erase`로 압축해 (서로 다른 x 수)×(서로 다른 y 수) 격자에 점 개수를 채우고 2D 누적합을 만든다. 질의 좌표는 격자에 없을 수 있으므로 `lower_bound(xo, x1)`, `upper_bound(xo, x2)`로 반열림 인덱스 구간 `[lx, rx)`로 바꾼다(y도 동일). `lx >= rx`면 그 축에 점이 없어 0. 같은 위치의 점은 한 칸에 2 이상으로 쌓인다.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    cin >> n >> q;
    vector<long long> px(n), py(n);
    for (int i = 0; i < n; i++) cin >> px[i] >> py[i];

    // 좌표 압축: 정렬 -> unique로 중복을 뒤로 몰고 -> erase로 잘라낸다
    vector<long long> xo = px, yo = py;
    sort(xo.begin(), xo.end());
    xo.erase(unique(xo.begin(), xo.end()), xo.end());
    sort(yo.begin(), yo.end());
    yo.erase(unique(yo.begin(), yo.end()), yo.end());

    int W = (int)xo.size(), H = (int)yo.size();
    vector<vector<int>> P(W + 1, vector<int>(H + 1, 0));
    for (int i = 0; i < n; i++) {
        int xi = (int)(lower_bound(xo.begin(), xo.end(), px[i]) - xo.begin());
        int yi = (int)(lower_bound(yo.begin(), yo.end(), py[i]) - yo.begin());
        P[xi + 1][yi + 1]++;                      // 같은 위치는 그대로 쌓인다
    }
    for (int i = 1; i <= W; i++)
        for (int j = 1; j <= H; j++)
            P[i][j] += P[i - 1][j] + P[i][j - 1] - P[i - 1][j - 1];

    string out;
    for (int t = 0; t < q; t++) {
        long long x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;
        int lx = (int)(lower_bound(xo.begin(), xo.end(), x1) - xo.begin());
        int rx = (int)(upper_bound(xo.begin(), xo.end(), x2) - xo.begin());
        int ly = (int)(lower_bound(yo.begin(), yo.end(), y1) - yo.begin());
        int ry = (int)(upper_bound(yo.begin(), yo.end(), y2) - yo.begin());
        if (lx >= rx || ly >= ry) {
            out += "0\n";
            continue;
        }
        out += to_string(P[rx][ry] - P[lx][ry] - P[rx][ly] + P[lx][ly]);
        out += '\n';
    }
    cout << out;
    return 0;
}

(1) 접근·핵심 아이디어

- 좌표가 10^9라 격자를 직접 만들 수 없지만 서로 다른 x, y는 각각 N개 이하다. 두 축을 따로 압축하면 최대 N×N 격자에 점 개수를 채울 수 있고, 여기에 2D 누적합을 얹으면 직사각형 개수 질의가 4항 뺄셈으로 O(1)이다. 질의마다 점을 전부 검사하는 O(NQ) 대신 전처리 O(N²) + 질의 O(log N).
- 질의의 좌표는 압축표에 없을 수 있으므로 값 → 인덱스 맵이 아니라 이분탐색으로 "x1 이상 첫 인덱스", "x2 초과 첫 인덱스"를 얻어 반열림 인덱스 구간으로 바꾼다. 이 변환이 압축 문제의 핵심 함정이다.

(2) 코드 단계별

- 좌표 압축은 C++에서 세 줄 관용구다: `sort` → `unique`(중복을 뒤로 몰고 새 끝 반복자를 반환) → `erase`(그 뒤를 잘라냄). `unique`만 부르고 `erase`를 잊으면 뒤쪽에 쓰레기가 남아 `size()`가 줄지 않는다.
- 압축된 좌표에서 각 점의 인덱스는 `lower_bound(...) - begin()`이다. 값이 반드시 있으므로 `lower_bound`가 정확한 위치를 준다.
- `P`를 (W+1)×(H+1)로 두고 `P[xi+1][yi+1]++`(같은 위치는 누적), 그다음 제자리에서 2D 누적합 `P[i][j] += P[i-1][j] + P[i][j-1] - P[i-1][j-1]`.
- 질의: `lx = lower_bound(xo, x1)`, `rx = upper_bound(xo, x2)`(y도 같은 방식). `lx >= rx` 또는 `ly >= ry`면 0. 아니면 `P[rx][ry] - P[lx][ry] - P[rx][ly] + P[lx][ly]`.

(3) 스스로 다시 짤 때 생각 순서

- "큰 좌표 + 직사각형 개수 질의 반복" → 좌표 압축 + 2D 누적합 결합. 1D(문제 4)를 축마다 적용한다고 생각한다.
- 1-인덱스 누적합 `P`와 0-인덱스 반열림 `[lx, rx)`가 자연스럽게 맞물리는지(`P[rx] - P[lx]`) 종이에 확인한다.
- 함정 — 2차원 `vector`는 `vector<vector<int>> P(W + 1, vector<int>(H + 1, 0))`처럼 **안쪽 `vector`를 명시적으로 만들어** 넘겨야 한다. `vector<vector<int>> P(W + 1)`만 쓰면 안쪽이 전부 크기 0이라 첫 접근에서 범위를 벗어난다.
- 함정 2 — 축 하나만 조기 반환 검사를 하면 나머지 축에서 잘못된 인덱스가 들어간다. `lx >= rx || ly >= ry`를 함께 본다.
- 경계: 질의 영역에 좌표가 하나도 없을 때(0), 같은 위치 점 중복(둘째 테스트), 점 하나짜리 입력.
```

**11) 최대 겹침 지속 시간** · Hard

- **요구사항**: 작업 N개가 시간 구간 `[s, e)`(s 포함, e 미포함)로 주어진다. 동시에 진행 중인 작업 수의 최댓값 M과, 동시 진행 수가 정확히 M인 시간의 총 길이를 출력하라.
- **입력**: 첫 줄 N(1 ≤ N ≤ 300). 이후 N줄에 `s e`(0 ≤ s < e ≤ 10^9).
- **출력**: `M 총길이`를 공백으로.
- **예제**: `3 / 1 5 / 3 8 / 4 6` → `3 1` · `4 / 0 10 / 2 4 / 6 9 / 20 21` → `2 5`
- **셀프체크**: 시각이 10^9라 배열 imos는 불가 → `(시각, +1)`, `(시각, -1)` 이벤트를 `vector<pair<long long,int>>`에 모아 정렬해 순서대로 누적하는 스위프. 같은 시각의 이벤트를 모두 적용한 뒤 "다음 이벤트 시각까지의 길이" 동안 그 개수가 유지된다. 반열림이라 한 작업이 끝나는 시각에 다른 작업이 시작해도 겹치지 않는다(넷째 테스트: 1 4). 최댓값이 갱신되면 길이를 새로 시작하고, 같으면 더한다. 시각 차이의 합은 최대 10^9이지만 습관적으로 `long long`.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<pair<long long, int>> ev;
    ev.reserve(2 * n);
    for (int i = 0; i < n; i++) {
        long long s, e;
        cin >> s >> e;
        ev.push_back({s, 1});
        ev.push_back({e, -1});
    }
    sort(ev.begin(), ev.end());          // pair 사전순: 시각 우선

    long long best = 0, bestLen = 0, cur = 0;
    int m = (int)ev.size();
    int i = 0;
    while (i < m) {
        long long t = ev[i].first;
        while (i < m && ev[i].first == t) {   // 같은 시각은 전부 적용한 뒤에 측정
            cur += ev[i].second;
            i++;
        }
        if (i < m) {
            long long seg = ev[i].first - t;  // 다음 이벤트까지 이 값이 유지된다
            if (cur > best) { best = cur; bestLen = seg; }
            else if (cur == best) bestLen += seg;
        }
    }
    cout << best << " " << bestLen << "\n";
    return 0;
}

(1) 접근·핵심 아이디어

- +1/-1 기법을 시각이 큰 상황에 적용하려면 배열 대신 "변화가 일어나는 시각"만 다룬다. 시작에 +1, 끝에 -1인 이벤트 2N개를 정렬해 앞에서부터 누적하면 각 시각의 동시 진행 수를 얻고, 인접한 이벤트 시각 사이에서는 그 값이 일정하므로 구간 길이를 그대로 더할 수 있다. 정렬 O(N log N) + 스위프 O(N)(좌표 압축 후 imos와 같은 결과).
- 같은 시각의 이벤트는 모두 반영한 뒤에 다음 구간을 재야 한다. 반열림 `[s, e)`에서 e에 끝나고 e에 시작하는 두 작업은 그 순간 겹치지 않는데, "전부 적용 후 측정" 방식이면 이벤트 순서를 따로 정하지 않아도 자연스럽게 맞는다.

(2) 코드 단계별

- `{s, +1}`, `{e, -1}`을 `vector<pair<long long,int>>`에 모아 `sort`한다. `pair`의 기본 비교가 `first`(시각) 우선이라 별도 비교 함수가 필요 없다.
- 같은 시각 t의 이벤트를 안쪽 `while`로 모두 `cur`에 반영한 뒤, 다음 이벤트 시각까지의 길이 `seg`를 구한다(마지막 시각 뒤에는 구간이 없으므로 `i < m` 검사로 건너뜀).
- `cur > best`면 최댓값과 길이를 새로 시작, `cur == best`면 길이를 누적. 마지막에 `best bestLen` 출력.

(3) 스스로 다시 짤 때 생각 순서

- "겹침 최대 + 큰 시각 + 그 상태가 유지되는 길이" → 이벤트 정렬 스위프. 값이 변하는 지점만 보면 된다는 imos의 본질을 떠올린다.
- "시각별 값"이 아니라 "구간별 값"을 세므로 구간 길이 `다음 시각 - 현재 시각`을 더한다. 압축 인덱스 차이가 아닌 **실제 시각 차이**를 써야 한다.
- 함정 — 바깥 `while`과 안쪽 `while`이 같은 `i`를 쓴다. 안쪽에서 `i`를 전진시키므로 바깥 루프에 별도 증가가 없어야 하고, 반대로 안쪽 조건 `ev[i].first == t`를 빠뜨리면 `i`가 늘지 않아 무한 루프가 된다. 루프를 짠 뒤 "모든 경로에서 `i`가 반드시 증가하는가"를 한 번 확인한다.
- 함정 2 — 시각을 `int`로 받으면 10^9은 들어가지만 두 시각을 더하는 변형(중간값 계산 등)에서 바로 넘친다. 입력 단계에서 `long long`으로 받아 두는 편이 낫다.
- 경계: 작업 하나(셋째 테스트), 끝과 시작이 맞닿은 경우(겹치지 않음, 넷째 테스트), 최댓값 구간이 여러 번 나뉘어 나타나는 경우(둘째 테스트: 2 + 3 = 5).
```

**12) 최대 K종류 과일 바구니** · Hard

- **요구사항**: 나무가 한 줄로 서 있고 각 나무의 과일 종류가 정수로 주어진다. 연속한 나무들에서 과일을 모두 따되 바구니에는 서로 다른 종류를 최대 K가지까지만 담을 수 있다. 딸 수 있는 나무 수(연속 구간 길이)의 최댓값을 출력하라.
- **입력**: 첫 줄 N K(1 ≤ K ≤ N ≤ 500). 둘째 줄 N개의 종류 번호(1 이상 10^9 이하).
- **출력**: 최대 구간 길이.
- **예제**: `9 2 / 1 2 1 2 3 3 3 4 4` → `5` · `3 5 / 1 2 3` → `3`
- **셀프체크**: 윈도우 안 종류별 개수를 `unordered_map<int,int>`로 유지하면 "서로 다른 종류 수 = 맵 크기". `right`를 늘려 넣고, 종류 수가 K를 넘는 동안 `left`를 밀며 개수를 줄이되 **0이 되면 `erase`로 키를 지워야** 크기가 줄어든다. 답 갱신은 조건 회복 직후. 검산(첫 예제): `3 3 3 4 4`가 종류 2가지로 길이 5.

```runner
@@SOLUTION
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, k;
    cin >> n >> k;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    unordered_map<int, int> cnt;          // 종류 -> 윈도우 안 개수
    int left = 0, best = 0;
    for (int right = 0; right < n; right++) {
        cnt[a[right]]++;                  // 없던 키는 0에서 시작해 1이 된다
        while ((int)cnt.size() > k) {
            if (--cnt[a[left]] == 0) cnt.erase(a[left]);  // 0이면 반드시 지운다
            left++;
        }
        if (right - left + 1 > best) best = right - left + 1;
    }
    cout << best << "\n";
    return 0;
}

(1) 접근·핵심 아이디어

- "연속 구간 + 서로 다른 종류 수 제한 + 최대 길이"는 슬라이딩 윈도우의 전형이다. 종류 수는 `right`를 늘리면 늘거나 같고 `left`를 늘리면 줄거나 같으므로 단조성이 있어 포인터를 되돌릴 필요가 없다. 윈도우 안 종류별 개수를 해시맵으로 두면 "종류 수"가 `cnt.size()`로 O(1)이고, 각 포인터가 N번씩만 움직여 전체 O(N)(모든 구간에 대해 집합을 만들면 O(N²)).

(2) 코드 단계별

- `right`마다 `cnt[a[right]]++`. C++의 `operator[]`는 없는 키를 0으로 만들어 넣으므로 파이썬 `get(x, 0) + 1`과 같은 역할을 한다.
- `(int)cnt.size() > K`인 동안 `--cnt[a[left]]`, 그 결과가 0이면 `cnt.erase(a[left])`, `left++`.
- 조건이 회복된 뒤 `right - left + 1`로 `best` 갱신.

(3) 스스로 다시 짤 때 생각 순서

- "종류 수 제한이 있는 연속 구간 최대" → 윈도우 + 개수 맵. 조건이 단조로운지 먼저 확인한다.
- 함정 1 — **개수가 0이 된 키를 지우지 않으면 `cnt.size()`가 줄지 않아** 윈도우가 계속 수축한다. 이 문제의 대표 함정이며 파이썬과 C++이 똑같이 걸린다. `if (--cnt[x] == 0) cnt.erase(x);` 한 줄로 붙여 둔다.
- 함정 2 — **`cnt.size()`는 `size_t`다.** `cnt.size() > k`에서 `k`가 `int`면 `k`가 부호 없는 타입으로 승격되므로 이 문제처럼 `k >= 1`이면 문제없지만, `k`가 음수가 될 수 있는 코드에서는 조건이 뒤집힌다. `(int)cnt.size() > k`로 명시하는 편이 안전하고 경고도 사라진다.
- 함정 3 — `cnt[a[left]]`를 조회하는 것만으로도 없던 키가 0으로 **생긴다.** 윈도우 밖 원소를 실수로 조회하면 `size()`가 늘어 조건이 어긋난다. 읽기만 할 때는 `find`를 쓴다.
- 경계: K가 전체 종류 수 이상(전체 길이), 종류가 한 가지뿐(셋째 테스트), 전부 다른 종류(넷째 테스트: 길이 K).
```
