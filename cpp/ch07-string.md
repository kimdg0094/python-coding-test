# Ch7. 문자열 — Codetree 101 스터디 가이드
> 언어 C++ · 1개 레슨 · 개념 1 / 문제 3

## 📌 챕터 개요
문자열(`string`)은 문자를 나열해 만든 자료형으로, C++에서 텍스트를 다룰 때 가장 자주 쓰는 기본 타입 중 하나입니다.
이 챕터에서는 문자열의 생성, 인덱싱, 크기 확인, 부분 문자열 추출, 연결·검색·치환, 그리고 이스케이프 문자를 익힙니다.
학습 목표는 (1) `string`의 각 글자를 인덱스로 읽고 쓸 수 있음을 이해하고 조작하는 감각을 기르는 것, (2) `substr`/`find`/`+` 등을 조합해 원하는 부분을 뽑거나 가공하는 것, (3) 따옴표/줄바꿈 같은 특수 문자를 올바르게 출력하는 것입니다.

## 📖 개념 정리
### 문자열 (string)
**핵심 개념**:

- 문자열은 문자의 모음이며 `<string>` 헤더를 포함한 뒤 `string` 타입으로 만듭니다. 문자열 리터럴은 큰따옴표(`" "`)로 감쌉니다(`'a'`처럼 작은따옴표는 낱개 문자 `char`용).
- C++의 `string`은 **가변(mutable)** 자료형입니다. `s[i] = 'x';`처럼 특정 위치의 글자를 직접 바꿀 수 있습니다.
- 인덱스는 0부터 시작하며 `s[i]`로 접근합니다. 마지막 글자는 `s[s.size() - 1]`입니다. 음수 인덱스는 없으므로 뒤에서부터 셀 때는 크기에서 빼서 계산합니다.

**문법/사용법**:

- 크기: `s.size()`(또는 `s.length()`) — 글자 수를 반환. 반환형이 부호 없는 정수라 `int n = s.size();`처럼 받아 두면 계산이 편합니다.
- 연결: `+`로 두 문자열을 이어붙입니다. `s += "abc";`처럼 뒤에 덧붙일 수도 있고, `s.append("abc")`도 같은 일을 합니다. 숫자는 바로 더할 수 없으므로 `to_string(n)`으로 바꿔 붙입니다.
- 부분 문자열: `s.substr(start, len)` — `start`부터 `len`글자를 잘라 반환. `len`을 생략하면 `start`부터 끝까지. ("끝 인덱스"가 아니라 "길이"를 준다는 점에 주의)
- 검색: `s.find("부분")` — 찾으면 시작 위치, 못 찾으면 `string::npos`를 반환.
- 낱개 문자: `s[i]`는 `char` 하나. `char`는 정수처럼 다룰 수 있어 `s[i] - 'a'`, `c + 1` 같은 연산이 가능합니다.
- 입력: `cin >> s;`는 공백 전까지 한 단어만 읽습니다. 공백을 포함한 한 줄 전체를 읽으려면 `getline(cin, s);`를 씁니다.
- 역순: 인덱스를 뒤에서부터(`for (int i = n - 1; i >= 0; i--)`) 돌거나, `s.rbegin()`~`s.rend()`를 이용합니다.
- 이스케이프 문자: `\n`(줄바꿈), `\t`(탭), `\\`(백슬래시), `\"`(큰따옴표), `\'`(작은따옴표).

**예시**:
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string text = "Cpp is fun";
    cout << text.substr(1, 3) << "\n";        // pp   (인덱스 1부터 3글자)
    cout << text.size() << "\n";              // 10
    cout << text.find("fun") << "\n";         // 7    (없으면 npos)
    text[0] = 'C';                            // 가변: 직접 수정 가능
    cout << text + "!" << "\n";               // Cpp is fun!

    // 다른 종류의 따옴표는 이스케이프 없이 포함 가능
    cout << "he said, \"hi\"" << "\n";        // he said, "hi"
    return 0;
}
```

**주의·흔한 실수**:

- `s.substr(a, b)`의 두 번째 인자는 "끝 인덱스"가 아니라 **길이**입니다. `s.substr(1, 4)`를 쓰면 인덱스 1~4가 아니라 인덱스 1부터 4글자입니다.
- 음수 인덱스(`s[-1]`)는 없습니다. "뒤에서 2번째"는 `s[s.size() - 2]`로 계산합니다.
- `s.size()`는 부호 없는 정수(`size_t`)라, `s.size() - 2` 같은 뺄셈을 큰 값으로 착각하지 않도록 `int n = s.size();`로 받아 두는 편이 안전합니다.
- `find`가 못 찾았을 때는 `-1`이 아니라 `string::npos`를 반환하므로 `if (s.find(x) != string::npos)`로 확인합니다.
- 큰따옴표를 문자열 안에 넣으려면 `\"`로 이스케이프합니다.

## 🧩 문제 채점용 정리
### 1) 따옴표 출력  (Easy · 10XP · 정답률 73%)
- **요구사항**: 지정된 한 문장을 그대로 출력한다.
- **입력**: 없음(입력이 주어지지 않음).
- **출력**: `He says "It's a really simple sentence".` 를 출력.
- **예제**: 입력 없음 → 출력 `He says "It's a really simple sentence".`
- **제한**: Time 5000 ms / Memory 288 MiB
- **연습 개념**: 문자열 출력, 따옴표(작은/큰) 동시 포함, 이스케이프 문자.
- **셀프체크 포인트**: 문장 안에 큰따옴표(`"`)와 작은따옴표(`'`)가 모두 들어 있음. C++ 문자열은 큰따옴표로 감싸므로 안의 큰따옴표만 `\"`로 이스케이프하면 되고, 작은따옴표는 그냥 써도 된다. 마침표(`.`)와 끝 위치, 공백까지 원문과 정확히 일치하는지 확인.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    cout << "He says \"It's a really simple sentence\"." << "\n";
    return 0;
}
@@TESTS
--IN

--OUT
He says "It's a really simple sentence".
@@EXPL
**접근 방법**: C++ 문자열 리터럴은 큰따옴표(`"`)로 감싼다. 문장 안에 큰따옴표와 작은따옴표가 둘 다 있는데, 감싸는 것과 같은 종류(큰따옴표)만 이스케이프하면 된다.

**코드 진행 과정**

- 출력할 문장 전체를 큰따옴표로 감싼다.
- 문장 안에 있는 두 개의 큰따옴표(`"It's ... sentence"`)는 감싸는 따옴표와 겹치므로 각각 `\"`로 이스케이프한다.
- 작은따옴표(`It's`의 `'`)는 감싸는 따옴표와 종류가 다르므로 이스케이프 없이 그냥 쓴다.
- `cout`으로 출력하고 끝에 `"\n"`으로 개행한다.

**다시 작성할 때 생각 순서**

- C++는 문자열을 큰따옴표로 감싼다는 사실을 먼저 떠올린다.
- 문장 안의 "큰따옴표"만 앞에 `\`를 붙여 `\"`로 바꾼다. 작은따옴표는 손대지 않는다.
- 마침표와 공백까지 원문과 똑같이 맞추고, 마지막에 개행을 잊지 않는다.
```

### 2) 더 긴 문자열  (Easy · 10XP · 정답률 83%)
- **요구사항**: 두 단어 중 길이가 더 긴 단어와 그 길이를 출력한다(길이가 같으면 `same`).
- **입력**: 첫 줄에 길이 20 이하인 두 단어가 공백으로 구분되어 주어짐.
- **출력**: 첫 줄에 더 긴 문자열과 길이를 공백으로 구분해 출력. 두 단어 길이가 같으면 `same` 출력.
- **예제**:
  - 입력 `Happy Coding` → 출력 `Coding 6`
  - 입력 `Hello World` → 출력 `same`
- **제한**: Time 1000 ms / Memory 128 MiB · 단어 길이 ≤ 20
- **연습 개념**: `cin >> a >> b`로 두 단어 받기, `.size()`로 길이 비교, 조건 분기.
- **셀프체크 포인트**: 길이가 같을 때 `same`만 출력하는 분기를 빠뜨리지 말 것. 출력은 "단어 + 공백 + 길이" 형식이며, 길이가 다를 때 어느 쪽이 더 긴지(부등호 방향)만 헷갈리지 않으면 됨.

```runner
@@SOLUTION
#include <iostream>
#include <string>
using namespace std;

int main() {
    string a, b;
    cin >> a >> b;
    if (a.size() > b.size()) {
        cout << a << " " << a.size() << "\n";
    } else if (b.size() > a.size()) {
        cout << b << " " << b.size() << "\n";
    } else {
        cout << "same" << "\n";
    }
    return 0;
}
@@TESTS
--IN
Happy Coding
--OUT
Coding 6
--IN
Hello World
--OUT
same
--IN
apple kiwi
--OUT
apple 5
@@EXPL
**접근 방법**: 두 단어를 받아 `.size()`로 길이를 비교한다. 세 가지 경우(a가 김 / b가 김 / 같음)를 조건 분기로 나눈다.

**코드 진행 과정**

- `cin >> a >> b`로 공백으로 구분된 두 단어를 각각 `a`, `b`에 담는다. `cin >>`는 공백을 기준으로 자동으로 끊어 읽는다.
- `a.size() > b.size()`이면 `a`와 그 길이를 출력한다. 값 사이에 공백을 넣으려면 `<< " " <<`를 끼운다(자동 공백이 없으므로 직접 넣는다).
- `b.size() > a.size()`이면 `b`와 그 길이를 출력한다.
- 두 조건이 모두 아니면(길이가 같으면) `same`을 출력한다.

**다시 작성할 때 생각 순서**

- 먼저 두 단어를 어떻게 나눠 받을지 정한다(`cin >> a >> b`).
- 비교는 "더 긴 쪽" 두 경우 + "같은 경우" 한 개, 총 3분기라고 먼저 그려 둔다.
- "단어 + 공백 + 길이" 출력에서는 사이에 `<< " " <<`로 공백을 직접 넣어야 한다는 점을 기억한다. 같을 때 `same`만 출력하는 분기를 빠뜨리지 않도록 마지막 `else`를 꼭 채운다.
```

### 3) a로 채워넣기  (Easy · 10XP · 정답률 87%)
- **요구사항**: 주어진 문자열에서 앞에서 2번째 문자와 뒤에서 2번째 문자를 `'a'`로 바꾼 결과를 출력한다.
- **입력**: 첫 줄에 길이 10 이상 100 이하의 문자열이 주어짐.
- **출력**: 첫 줄에 변경된 문자열을 출력.
- **예제**:
  - 입력 `leebroscode` → 출력 `laebroscoae`
  - 입력 `aaaaaaaaaaaaaaa` → 출력 `aaaaaaaaaaaaaaa`
- **제한**: Time 1000 ms / Memory 80 MiB · 10 ≤ 길이 ≤ 100
- **연습 개념**: 인덱싱(앞 2번째 = 인덱스 1, 뒤 2번째 = 인덱스 `size()-2`), `string`은 가변 → 인덱스로 직접 수정.
- **셀프체크 포인트**: "앞에서 2번째"는 인덱스 1, "뒤에서 2번째"는 인덱스 `s.size() - 2`. C++ `string`은 가변이므로 `s[1] = 'a';`처럼 직접 대입할 수 있다. 예제2처럼 이미 해당 위치가 `a`면 결과가 원문과 같을 수 있음. 두 위치가 겹치지 않는지(길이 10 이상이라 인덱스 1과 `size()-2`는 항상 다름) 확인.

```runner
@@SOLUTION
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;
    int n = s.size();
    s[1] = 'a';
    s[n - 2] = 'a';
    cout << s << "\n";
    return 0;
}
@@TESTS
--IN
leebroscode
--OUT
laebroscoae
--IN
aaaaaaaaaaaaaaa
--OUT
aaaaaaaaaaaaaaa
--IN
abcdefghij
--OUT
aacdefghaj
@@EXPL
**접근 방법**: C++ `string`은 가변이므로 바꿀 두 위치를 인덱스로 직접 대입한다. 앞에서 2번째는 인덱스 1, 뒤에서 2번째는 인덱스 `s.size() - 2`다.

**코드 진행 과정**

- `cin >> s`로 문자열을 읽는다.
- `int n = s.size();` — 길이를 정수로 받아 둔다. 뒤 위치 계산에 쓴다.
- `s[1] = 'a';` — 앞에서 2번째(인덱스 1) 글자를 `'a'`로 바꾼다.
- `s[n - 2] = 'a';` — 뒤에서 2번째(인덱스 `n - 2`) 글자를 `'a'`로 바꾼다.
- 바뀐 문자열을 그대로 출력한다.

**다시 작성할 때 생각 순서**

- 바꿔야 할 두 위치(인덱스 1, 인덱스 `n - 2`)를 먼저 계산한다. "뒤에서 2번째"는 음수 인덱스가 없으므로 크기에서 2를 빼서 구한다.
- C++ 문자열은 가변이라 새 문자열을 만들 필요 없이 두 자리를 `= 'a';`로 덮어쓰면 된다.
- 겹침 걱정은 없다(길이 10 이상이면 인덱스 1과 `n - 2`는 항상 떨어져 있음). 마지막에 바뀐 문자열을 출력한다.
```

## ✅ 마스터 체크리스트
- [ ] `<string>`을 포함하고 `string`으로 문자열을 만들 수 있다
- [ ] C++ `string`이 가변임을 이해하고 `s[i] = 'x';`로 직접 수정한다
- [ ] `s[i]` 인덱싱과 "뒤에서 k번째 = `s.size() - k`" 계산을 자유롭게 쓴다
- [ ] `+`/`+=`/`append`(연결)와 `to_string`(숫자→문자열)을 상황에 맞게 쓴다
- [ ] `size`/`substr`/`find`와 `char` 연산을 구분해 쓴다
- [ ] `\n \t \\ \" \'` 등 이스케이프 문자를 정확히 출력한다
- [ ] `cin >> a >> b`로 여러 단어를 받아 `.size()`로 비교·분기할 수 있다

## ⚠️ 자주 하는 실수
- `substr`의 두 번째 인자를 "끝 인덱스"로 착각(실제로는 길이).
- 음수 인덱스(`s[-1]`)를 쓰려다 오류 — 뒤에서 셀 때는 `s.size() - k`로 계산.
- `s.size()`가 부호 없는 정수라 뺄셈 결과를 오해 — `int n = s.size();`로 받아 두면 안전.
- 따옴표 포함 문자열에서 감싸는 큰따옴표를 이스케이프(`\"`)하지 않아 컴파일 오류나 출력이 원문과 미묘하게 달라짐(공백·마침표 포함).
- 길이 비교 문제에서 "같을 때" 처리를 누락.
- `find`가 못 찾으면 `-1`이 아니라 `string::npos`를 반환한다는 점을 혼동.
