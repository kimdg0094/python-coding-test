# Ch5. 조건문 2 — Codetree 101 스터디 가이드

> 언어 C++ · 2개 레슨 · 개념 2 / 문제 6

## 📌 챕터 개요

여러 조건을 한 번에 다루는 방법을 배웁니다. `&&`/`||` 논리 연산자로 두 개 이상의 조건을 하나의 복합 조건으로 묶는 법과, `if` 안에 다시 `if`를 넣어 조건을 단계별로 세분화하는 중첩 조건문을 익힙니다. 학습 목표는 성인 여부·윤년·중앙값처럼 조건이 얽힌 실제 문제를 논리적으로 분해하여 정확한 분기 코드로 옮기는 능력을 기르는 것입니다.

## 📖 개념 정리 (레슨별)

### L1. 논리 연산자를 이용한 조건문

**핵심 개념**

- 조건이 2개 이상일 때 `&&`(그리고)와 `||`(또는)로 여러 조건을 하나의 복합 조건으로 결합합니다.
- `&&`는 **모든** 조건이 참이어야 전체가 참, `||`는 **하나 이상**의 조건이 참이면 전체가 참입니다.
- 기본 조건은 `&&`로 묶고, "예외적으로 통과시키는" 조건은 `||`로 덧붙이는 식으로 논리를 조립하면 복잡한 규칙도 단계적으로 표현할 수 있습니다.

**문법/사용법**

- `조건1 && 조건2` : 둘 다 참일 때만 참
- `조건1 || 조건2` : 둘 중 하나라도 참이면 참
- 우선순위가 헷갈리면 각 조건을 괄호로 묶어 `(A && B) || C` 처럼 의도를 명확히 합니다.

**예시**

```cpp
#include <iostream>
using namespace std;

int main() {
    // 성인 판단: (나이 18 이상 그리고 시민권 보유) 또는 특별 허가
    int age = 20;
    bool has_citizenship = true;
    bool has_special_permission = false;

    if ((age >= 18 && has_citizenship) || has_special_permission) {
        cout << "성인입니다." << "\n";
    } else {
        cout << "미성년자입니다." << "\n";
    }

    // 윤년 판단: (4의 배수 그리고 100의 배수 아님) 또는 400의 배수
    int year = 2000;
    if ((year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)) {
        cout << "윤년" << "\n";
    }
    return 0;
}
```

**주의·흔한 실수**

- `&&`/`||`의 결합 순서를 착각해 괄호를 빠뜨리면 의도와 다른 조건이 됩니다(`&&`가 `||`보다 우선순위가 높음). 예외 조건(`||`)은 반드시 괄호로 그룹을 구분하세요.
- "18 이상"과 "18 초과"처럼 경계값 포함 여부(`>=` vs `>`)를 문제 문장에서 정확히 읽어야 합니다.
- 배수 판정은 `x % k == 0` 형태를 씁니다. "나누어떨어지지 않음"은 `x % k != 0` 입니다.

### L2. 중첩 조건문

**핵심 개념**

- 중첩 `if`는 `if` 블록 안에 또 다른 `if`를 두는 구조로, 큰 조건을 먼저 확인한 뒤 참일 때만 하위 조건을 세분화합니다.
- 복잡한 규칙을 "1단계 → 2단계"로 나누어 검사하므로 논리 흐름이 명확해집니다. (예: 여권이 유효한가? → 유효하면 비자가 필요한가?)

**문법/사용법**

```cpp
if (조건1) {
    if (조건2) {
        // 조건1, 조건2 모두 참
    } else {
        // 조건1 참, 조건2 거짓
    }
} else {
    // 조건1 거짓
}
```

- C++에서는 `else`가 짝이 되는 `if`를 중괄호 `{ }`로 명확히 묶어 구분합니다. 각 `if`/`else`의 블록 범위를 정확히 맞춰야 합니다.

**예시**

```cpp
#include <iostream>
using namespace std;

int main() {
    bool passport_valid = true;
    bool visa_required = false;

    if (passport_valid) {
        if (visa_required) {
            cout << "비자를 발급받습니다." << "\n";
        } else {
            cout << "바로 여행을 떠납니다." << "\n";
        }
    } else {
        cout << "여권을 새로 발급받습니다." << "\n";
    }
    return 0;
}
```

**주의·흔한 실수**

- `else`가 짝이 되는 `if`는 중괄호 블록으로 결정됩니다. 중괄호를 생략하면 안쪽 `if`인지 바깥 `if`인지 혼동하기 쉬우니, 중첩할 때는 `{ }`를 꼭 붙이는 습관을 들이세요.
- 많은 경우 동일한 분기를 `&&`/`||` 복합 조건이나 `else if` 로도 표현할 수 있습니다. 어느 쪽이 더 읽기 쉬운지 고민해보세요.
- 중첩이 3단계 이상 깊어지면 가독성이 떨어지므로 조건을 논리 연산자로 합칠 수 있는지 점검합니다.

## 🧩 문제 채점용 정리

### 1) 점수 비교 (Easy · 10XP · 정답률 82%)

- **요구사항**: A와 B의 수학·영어 점수를 받아 A가 B보다 두 과목 모두 점수가 높은지 판정.
- **입력**: 1번째 줄에 A의 수학·영어 점수(공백 구분), 2번째 줄에 B의 수학·영어 점수(공백 구분).
- **출력**: A의 수학·영어 점수가 **둘 다** B보다 크면 `1`, 아니면 `0`.
- **예제**: `100 85 / 98 78` → `1` · `86 93 / 86 90` → `0`
- **제한**: Time 1000 ms · Memory 80 MiB · 점수는 1~100.
- **연습 개념**: `&&` 로 두 비교 조건을 결합.
- **셀프체크 포인트**: 두 번째 예제(수학이 같음)에서 `>=`가 아니라 `>`(초과)로 비교했는지 확인.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int am, ae, bm, be;
    cin >> am >> ae;
    cin >> bm >> be;
    if (am > bm && ae > be) {
        cout << 1 << "\n";
    } else {
        cout << 0 << "\n";
    }
    return 0;
}
@@TESTS
--IN
100 85
98 78
--OUT
1
--IN
86 93
86 90
--OUT
0
--IN
90 90
80 80
--OUT
1
@@EXPL
**접근 방법**: 두 과목 모두 A가 더 높아야 하므로 두 비교 조건을 `&&`로 묶습니다. "둘 다"라는 표현이 나오면 `&&`를 떠올리세요.

**코드 진행 과정**

- 첫 줄에서 A의 수학·영어 점수를, 둘째 줄에서 B의 점수를 `cin >>`으로 차례대로 읽습니다. `cin`은 공백과 개행을 자동으로 건너뛰므로 네 값을 순서대로 받을 수 있습니다.
- `am > bm && ae > be` 를 검사합니다. 두 조건이 모두 참일 때만 전체가 참이 됩니다.
- 참이면 `1`, 아니면 `0`을 출력합니다.

**스스로 다시 짤 때**

- "두 과목 모두 초과"라는 조건을 그대로 `>`(초과) 두 개로 옮기고 `&&`로 연결한다고 생각하세요.
- 경계값 주의: 점수가 같은 경우(`==`)는 "더 높다"가 아니므로 `>=`가 아니라 `>`를 써야 합니다. 두 번째 예제가 이걸 검증합니다.
```

### 2) 정수의 조건 여부 3 (Easy · 10XP · 정답률 90%)

- **요구사항**: 정수 a가 13의 배수이거나 19의 배수이면 참, 아니면 거짓 판정.
- **입력**: 1번째 줄에 정수 a.
- **출력**: 조건 만족 시 `1`, 아니면 `0` (C++ bool 값을 그대로 출력).
- **예제**: `361` → `1` (19×19) · `100` → `0`
- **제한**: Time 1000 ms · Memory 64 MiB · 1≤a≤1,000.
- **연습 개념**: `||` 로 두 배수 조건을 결합, `a % 13 == 0`.
- **셀프체크 포인트**: C++에서 비교식(bool)을 `cout`에 넣으면 `true`/`false`가 아니라 `1`/`0`으로 출력됩니다. 비교식 결과를 그대로 출력하면 자연스럽게 맞습니다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int a;
    cin >> a;
    cout << (a % 13 == 0 || a % 19 == 0) << "\n";
    return 0;
}
@@TESTS
--IN
361
--OUT
1
--IN
100
--OUT
0
--IN
26
--OUT
1
@@EXPL
**접근 방법**: "13의 배수 이거나 19의 배수"는 두 조건 중 하나라도 참이면 되므로 `||`로 묶습니다. 배수 판정은 나머지가 0인지(`% == 0`)로 합니다.

**코드 진행 과정**

- 정수 `a`를 입력받습니다.
- `a % 13 == 0` (13의 배수)와 `a % 19 == 0` (19의 배수)를 `||`로 연결합니다.
- 이 비교식 자체가 C++의 `bool` 값이며, `cout`으로 출력하면 `true`/`false`가 아니라 정수 `1`/`0`으로 나옵니다. 그래서 별도 분기 없이 그대로 출력해도 됩니다.

**스스로 다시 짤 때**

- "이거나"라는 말이 나오면 `||`를 떠올리세요.
- 출력이 `true`/`false`가 아니라 `1`/`0`임에 주의합니다. C++에서 `bool`을 `cout`으로 내보내면 기본적으로 정수 1(참)·0(거짓)으로 표시됩니다.
```

### 3) 굉장한 수 (Easy · 10XP · 정답률 83%)

- **요구사항**: 자연수 N이 "홀수이면서 3의 배수" 또는 "짝수이면서 5의 배수"이면 굉장한 수.
- **입력**: 1번째 줄에 N.
- **출력**: 굉장한 수면 `true`, 아니면 `false` (소문자 문자열).
- **예제**: `9` → `true` (홀수∧3배수) · `18` → `false` (짝수지만 5배수 아님)
- **제한**: Time 1000 ms · Memory 80 MiB · 1≤N≤100.
- **연습 개념**: `(홀수 && 3배수) || (짝수 && 5배수)` — `&&`/`||` 혼합.
- **셀프체크 포인트**: 출력이 소문자 `true`/`false` 문자열. 앞 문제의 `1`/`0`과 표기가 다르니, `bool`을 그대로 출력하지 말고 문자열로 직접 출력해야 합니다.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    if ((n % 2 == 1 && n % 3 == 0) || (n % 2 == 0 && n % 5 == 0)) {
        cout << "true" << "\n";
    } else {
        cout << "false" << "\n";
    }
    return 0;
}
@@TESTS
--IN
9
--OUT
true
--IN
18
--OUT
false
--IN
10
--OUT
true
@@EXPL
**접근 방법**: 두 개의 묶음 조건 "홀수 그리고 3의 배수", "짝수 그리고 5의 배수" 를 각각 `&&`로 만들고, 이 둘을 `||`로 잇습니다. `&&`/`||`가 섞이므로 각 묶음을 괄호로 그룹화합니다.

**코드 진행 과정**

- `n`을 입력받습니다.
- 홀수 여부는 `n % 2 == 1`, 짝수는 `n % 2 == 0`으로 판정합니다.
- `(홀수 && 3배수) || (짝수 && 5배수)` 형태로 조건을 조립합니다.
- 참이면 소문자 문자열 `"true"`, 아니면 `"false"`를 직접 출력합니다.

**스스로 다시 짤 때**

- "A이면서 B" 는 `&&`, 두 경우를 "또는" 으로 합치는 것은 `||` 라고 대응시키세요.
- 괄호로 `(A && B)` 각 묶음을 명확히 감싸 우선순위 혼동을 막습니다(`&&`가 `||`보다 먼저 계산됩니다).
- 이 문제는 `bool` 값(1/0)이 아니라 소문자 문자열 출력이므로, 조건 결과를 `cout`으로 바로 내보내지 말고 `"true"`/`"false"` 문자열을 분기해서 출력해야 합니다.
```

### 4) 남녀노소 구분짓기 (Easy · 10XP · 정답률 80%)

- **요구사항**: 성별(남=0, 여=1)과 나이를 받아 성인/미성년 × 남/여 4분류. 19세 이상이 성인.
- **입력**: 1번째 줄에 성별 숫자(0 또는 1), 2번째 줄에 나이(자연수).
- **출력**: `MAN`(성인남), `WOMAN`(성인여), `BOY`(미성년남), `GIRL`(미성년여) 중 하나.
- **예제**: `0 / 23` → `MAN` · `1 / 13` → `GIRL`
- **제한**: Time 1000 ms · Memory 80 MiB · 1≤나이≤100.
- **연습 개념**: 중첩 `if`(먼저 성별 분기 → 안에서 나이 분기) 또는 `&&` 복합 조건.
- **셀프체크 포인트**: 성인 기준이 "19세 이상"이므로 `age >= 19`. 4가지 조합이 빠짐없이 처리되는지 확인.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int gender, age;
    cin >> gender;
    cin >> age;
    if (gender == 0) {
        if (age >= 19) {
            cout << "MAN" << "\n";
        } else {
            cout << "BOY" << "\n";
        }
    } else {
        if (age >= 19) {
            cout << "WOMAN" << "\n";
        } else {
            cout << "GIRL" << "\n";
        }
    }
    return 0;
}
@@TESTS
--IN

23
--OUT
MAN
--IN
1
13
--OUT
GIRL
--IN
0
10
--OUT

@@EXPL
**접근 방법**: 성별(2가지) × 성인 여부(2가지) = 4분류이므로, 바깥 `if`로 성별을 먼저 나누고 그 안에서 다시 나이로 나누는 중첩 조건문을 씁니다.

**코드 진행 과정**

- 첫 줄에서 성별(0=남, 1=여), 둘째 줄에서 나이를 입력받습니다.
- 바깥 `if (gender == 0)` 로 남/여를 분기합니다.
- 각 분기 안쪽에서 `if (age >= 19)` 로 성인/미성년을 다시 나눠 4가지 중 하나를 출력합니다.

**스스로 다시 짤 때**

- 먼저 큰 축(성별)으로 두 갈래, 그 안에서 작은 축(나이)으로 다시 두 갈래를 그린다고 생각하세요. 표를 그리면 4칸이 나옵니다: MAN/BOY/WOMAN/GIRL.
- 성인 기준이 "19세 이상"이므로 `>= 19`(이상)로 씁니다. `> 19`로 쓰면 19세가 미성년으로 잘못 분류됩니다.
- 안쪽 `else`가 안쪽 `if`에 짝이 되도록 중괄호 `{ }` 블록 범위를 정확히 맞춥니다.
```

### 5) 윤년인가 (Easy · 10XP · 정답률 60%)

- **요구사항**: 연도 Y가 윤년인지 판정. 4의 배수는 윤년, 단 100의 배수이면서 400의 배수가 아니면 평년.
- **입력**: 1번째 줄에 자연수 Y.
- **출력**: 윤년이면 `true`, 아니면 `false`.
- **예제**: `2020` → `true` · `2200` → `false` (100의 배수인데 400의 배수 아님)
- **제한**: Time 1000 ms · Memory 80 MiB · 1≤Y≤2222.
- **연습 개념**: `(Y%4==0 && Y%100!=0) || (Y%400==0)` — 논리 연산자 결합 또는 중첩 조건.
- **셀프체크 포인트**: 400의 배수 예외(예: 2000)를 놓치지 않았는지, 괄호로 `&&`/`||` 그룹을 정확히 묶었는지 확인.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int y;
    cin >> y;
    if ((y % 4 == 0 && y % 100 != 0) || (y % 400 == 0)) {
        cout << "true" << "\n";
    } else {
        cout << "false" << "\n";
    }
    return 0;
}
@@TESTS
--IN
2020
--OUT
true
--IN
2200
--OUT
false
--IN
2000
--OUT
true
@@EXPL
**접근 방법**: 윤년 규칙은 "4의 배수이면서 100의 배수는 아님" 또는 "400의 배수" 입니다. 앞 묶음은 `&&`, 두 경우를 잇는 것은 `||`로 표현합니다.

**코드 진행 과정**

- 연도 `y`를 입력받습니다.
- `y % 4 == 0 && y % 100 != 0` (4의 배수지만 100의 배수는 아님)을 한 묶음으로 만듭니다.
- 여기에 `|| y % 400 == 0` (400의 배수 예외)을 덧붙입니다.
- 참이면 `"true"`, 아니면 `"false"`를 출력합니다.

**스스로 다시 짤 때**

- "4의 배수" 를 기본으로 하되 "100의 배수는 평년" 예외를 `&& ... != 0`로 걸러내고, "400의 배수는 다시 윤년" 예외를 `||`로 되살린다고 순서대로 생각하세요.

### 6) 중앙값 구하기 (Easy · 10XP · 정답률 64%)

- **요구사항**: 서로 다른 세 정수 A, B, C 중 오름차순 정렬 시 가운데 값(중앙값)을 구하기.
- **입력**: 1번째 줄에 A, B, C(공백 구분).
- **출력**: 세 값 중 중앙값.
- **예제**: `26 22 30` → `26` · `-20 0 23` → `0`
- **제한**: Time 1000 ms · Memory 80 MiB · −100≤A,B,C≤100, 세 값은 서로 다름.
- **연습 개념**: 비교 조건 조합 / 중첩 조건으로 최대·최소를 제외한 값 찾기(정렬 활용도 가능).
- **셀프체크 포인트**: 음수 예제와 순서가 뒤섞인 입력에서도 맞는지, "최댓값도 최솟값도 아닌 값"을 정확히 골랐는지 확인.

```runner
@@SOLUTION
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    if ((a > b && a < c) || (a > c && a < b)) {
        cout << a << "\n";
    } else {
        if ((b > a && b < c) || (b > c && b < a)) {
            cout << b << "\n";
        } else {
            cout << c << "\n";
        }
    }
    return 0;
}
@@TESTS
--IN
26 22 30
--OUT
26
--IN
-20 0 23
--OUT
0
--IN

--OUT

@@EXPL
**접근 방법**: 중앙값은 "하나보다는 크고 다른 하나보다는 작은" 값입니다. 세 값이 서로 다르므로, 각 값이 이 조건을 만족하는지 비교로 확인합니다.

**코드 진행 과정**

- `a, b, c`를 공백으로 구분해 `cin >>`으로 차례대로 받습니다.
- `a`가 중앙값인지 검사합니다: `(a > b && a < c)` (b보다 크고 c보다 작음) 또는 순서를 뒤집은 `(a > c && a < b)`. 둘 중 하나면 `a`가 가운데입니다.
- 아니라면 같은 방식으로 `b`가 중앙값인지 검사합니다.
- 둘 다 아니면 남은 값 `c`가 중앙값이므로 출력합니다.

**스스로 다시 짤 때**

- "중앙값 = 최대도 최소도 아닌 값" 을 "한 값보다 크고 다른 한 값보다 작은 값" 으로 바꿔 생각하세요.
- 한 값(예: a)에 대해 나머지 둘과의 대소 순서는 두 가지(`b<a<c` 또는 `c<a<b`)뿐이므로 `||`로 두 경우를 묶습니다.
- 세 값이 서로 다르다는 조건 덕분에 등호(`==`)를 신경 쓰지 않아도 됩니다. a도 b도 아니면 자동으로 c가 답이라는 점을 이용해 마지막 분기를 단순화합니다.
```

## ✅ 마스터 체크리스트

- [ ] `&&`는 모든 조건, `||`는 하나 이상의 조건이 참일 때 참임을 설명할 수 있다.
- [ ] `(A && B) || C` 형태로 기본 조건과 예외 조건을 괄호로 묶어 조립할 수 있다.
- [ ] 배수/나머지 판정을 `% == 0`, `% != 0`로 정확히 쓸 수 있다.
- [ ] 경계값 포함 여부(`>=` vs `>`, "이상"/"초과")를 문제에서 정확히 읽고 반영한다.
- [ ] 중첩 `if`의 구조와 `else`가 짝이 되는 `if`를 중괄호 블록으로 구분할 수 있다.
- [ ] 윤년 규칙(4·100·400)을 논리 연산자로 정확히 구현할 수 있다.
- [ ] 세 값의 중앙값을 최대·최소 제외 논리로 구할 수 있다.
- [ ] 출력이 `1`/`0`(bool을 그대로 출력)인지 `true`/`false`(소문자 문자열)인지 문제별로 구분한다.

## ⚠️ 자주 하는 실수

- **괄호 누락**: `A && B || C`를 의도와 다르게 해석. `&&`가 `||`보다 우선순위가 높으므로, 예외 조건은 `(A && B) || C`처럼 괄호로 그룹을 명시.
- **경계값 오류**: "19세 이상 성인"을 `> 19`로 잘못 쓰는 등 `>=`/`>` 혼동.
- **출력 표기 불일치**: "정수의 조건 여부 3"은 `bool`을 그대로 출력해 `1`/`0`, "굉장한 수"·"윤년인가"는 `true`/`false`(소문자 문자열). C++에서 `bool`을 `cout`으로 내보내면 기본적으로 정수 1/0이 나온다는 점을 기억할 것.
- **윤년 400 예외 누락**: 100의 배수만 걸러내고 400의 배수 예외를 빠뜨려 2000년 같은 케이스를 틀림.
- **중첩 else 오귀속**: 중괄호를 잘못 맞춰 안쪽 `if`의 `else`가 바깥 `if`에 붙는 실수. 중첩할 때는 `{ }`를 꼭 붙일 것.
- **분류 누락**: 남녀노소·중앙값처럼 경우의 수가 많은 문제에서 일부 조합을 처리하지 않아 특정 입력에서만 오답.
