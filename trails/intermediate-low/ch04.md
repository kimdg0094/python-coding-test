> 개요: 큐(deque)를 쓰는 너비 우선 탐색으로 그래프·격자를 층별로 훑고, 간선 가중치가 모두 같을 때 "가장 먼저 도달한 순간이 곧 최단거리"라는 성질을 이용해 최단거리·최단경로 문제를 푼다.
>
> 전에 배운 것 → 이번에 새로: Ch3의 DFS는 재귀 스택으로 "일단 깊게" 파고들어 도달 가능성·연결요소를 봤다면, 이번 BFS는 자료구조를 **스택→큐(FIFO `deque`)**로 바꿔 "가까운 것부터 층 단위로" 퍼뜨린다. 이 한 가지 차이 덕분에 DFS로는 보장 못 하던 **최단거리(=최소 간선 수)**를 얻는 것이 새로 배우는 핵심이다.

## L1. BFS 탐색

**개념**

- BFS(Breadth-First Search, 너비 우선 탐색)는 시작점에서 가까운 정점부터 "층(level)" 단위로 퍼져나가며 방문하는 탐색이다. DFS가 한 방향으로 깊게 파고드는 것과 달리, BFS는 시작점에서 거리 0인 정점 → 거리 1인 정점 → 거리 2인 정점 순으로 방문한다.

- 자료구조는 **큐(FIFO)** 를 쓴다. 큐에서 정점을 하나 꺼내(pop) 그 이웃들을 살펴보고, "아직 방문 안 한 이웃"을 큐에 넣는다(push). 먼저 들어간 정점이 먼저 나오므로 자연스럽게 가까운 순서대로 처리된다.

- 핵심 규칙: **큐에 넣는 순간(push) 방문 표시를 한다.** 꺼낼 때(pop) 표시하면 같은 정점이 큐에 여러 번 중복으로 들어가 시간·메모리가 폭발하고, 거리 계산이 어긋난다.

- 언제 쓰나: (1) 연결 여부·도달 가능성, (2) 연결 요소(그룹) 세기, (3) 간선 가중치가 모두 같을 때의 최단거리(=최소 간선 수). 격자에서는 상하좌우(때로는 대각선 포함) 이동을 "간선"으로 보고 그대로 적용한다.

- 동작 단계:

    1. 시작 정점을 큐에 넣고 방문 표시.

    2. 큐가 빌 때까지 반복: 앞에서 하나 꺼낸다.

    3. 꺼낸 정점의 모든 이웃을 확인해, 미방문 이웃을 방문 표시하고 큐에 넣는다(필요하면 `dist[이웃] = dist[현재] + 1`).

```python
from collections import deque

def bfs(start, graph, n):
    dist = [-1] * (n + 1)      # -1 = 미방문
    q = deque([start])
    dist[start] = 0
    while q:
        cur = q.popleft()
        for nxt in graph[cur]:
            if dist[nxt] == -1:        # 아직 방문 안 함
                dist[nxt] = dist[cur] + 1
                q.append(nxt)          # push하는 순간 방문 확정
    return dist

# 격자 버전: 좌표 (r, c)를 큐에 넣고 4방향으로 확장
# dr, dc = (-1,1,0,0), (0,0,-1,1)
```

**접근 전략**

- 먼저 "무엇이 정점이고 무엇이 간선인가"를 정한다. 인접리스트 그래프면 정점=노드, 간선=연결. 격자면 정점=칸 `(r,c)`, 간선=인접한 이동 가능한 칸. 그다음 `visited`(또는 `dist=-1`)를 초기화하고, 시작점을 큐에 넣으며 표시한 뒤 위 뼈대를 그대로 돌린다.

- 연결 요소를 셀 때는 모든 정점을 순회하며 "아직 방문 안 한 정점"을 만날 때마다 BFS를 새로 시작하고, 시작 횟수를 센다. 격자 그룹(섬) 개수도 동일한 패턴이다.

- 여러 시작점에서 동시에 퍼뜨려야 하면(다중 소스 BFS) 시작점 전부를 처음부터 큐에 넣고 거리 0으로 두면 된다. "불이 여러 군데서 번진다", "가장 가까운 편의점까지 거리" 같은 문제가 전형.

- **복잡도**: 인접리스트 기준 시간 O(V+E), 공간 O(V). 격자(R×C)라면 정점 V=R·C, 간선은 상수배이므로 시간·공간 모두 O(R·C).

- 흔한 실수·팁:

    - `list.pop(0)`는 O(N)이라 큐로 쓰면 전체가 O(V²)로 느려진다. 반드시 `collections.deque`의 `popleft()`(O(1))를 쓴다.

    - 방문 표시를 pop 시점에 하면 중복 삽입으로 터진다 → push 시점에 표시.

    - 격자에서 좌표가 범위를 벗어나는지(0 ≤ r < R, 0 ≤ c < C) 먼저 확인하고 값을 읽어야 IndexError를 피한다.

    - `dist` 배열 하나로 방문 여부(≠-1)와 거리(값)를 동시에 관리하면 `visited`를 따로 둘 필요가 없어 깔끔하다.

**문제**

**1) 미로 최단 탈출** · Easy

- **요구사항**: `N×M` 격자에서 `1`은 이동 가능한 길, `0`은 벽이다. `(0,0)`에서 출발해 상하좌우로만 이동할 때 `(N-1, M-1)`까지 지나는 **칸의 개수**(시작·도착 칸 포함)를 출력하라. 도달할 수 없으면 `-1`을 출력한다.

- **입력**: 첫 줄에 `N M`. 다음 `N`줄에 각 `M`개의 `0/1`이 공백 없이 붙어 주어진다.

- **출력**: 최단 경로가 지나는 칸의 개수, 또는 `-1`.

- **예제**:

    - `3 3` / `111` / `010` / `111` → `5`

    - `2 2` / `10` / `01` → `-1`

- **셀프체크**: 간선 가중치가 모두 1이므로 BFS의 첫 도달이 최단이다. "칸 개수"는 `dist[도착]+1`임에 주의(간선 수 vs 칸 수). 시작 칸이 벽이거나 도착 불가한 경우를 처리했는가?

```runner
@@SOLUTION
import sys
from collections import deque

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    n, m = map(int, data[idx].split()); idx += 1
    grid = []
    for i in range(n):
        grid.append(data[idx]); idx += 1
    if grid[0][0] == '0' or grid[n-1][m-1] == '0':
        print(-1); return
    dist = [[-1]*m for _ in range(n)]
    q = deque([(0, 0)])
    dist[0][0] = 0
    dr = (-1, 1, 0, 0); dc = (0, 0, -1, 1)
    while q:
        r, c = q.popleft()
        for k in range(4):
            nr, nc = r + dr[k], c + dc[k]
            if 0 <= nr < n and 0 <= nc < m and dist[nr][nc] == -1 and grid[nr][nc] == '1':
                dist[nr][nc] = dist[r][c] + 1
                q.append((nr, nc))
    ans = dist[n-1][m-1]
    print(ans + 1 if ans != -1 else -1)

main()

(1) 접근·핵심 아이디어

- 격자에서 한 칸 이동의 비용이 모두 1이므로, 최단거리는 "최소 간선 수"이고 이는 평범한 BFS로 구할 수 있다. `(0,0)`에서 시작해 층 단위로 퍼뜨리면 `(N-1,M-1)`에 처음 도달하는 순간이 최단이다.
- 문제가 요구하는 값은 "칸의 개수"이므로 간선 수인 `dist`에 1을 더해야 한다. 예: `dist=4`면 지나는 칸은 5개.

(2) 코드 단계별

- 시작/도착 칸이 벽(`0`)이면 즉시 `-1`.
- `dist` 2차원 배열을 `-1`(미방문)로 초기화하고 시작 칸을 0으로 두며 큐에 넣는다.
- 큐가 빌 때까지 꺼내고, 4방향 이웃 중 범위 안·미방문·길(`1`)인 칸에 `dist+1`을 기록하며 push한다(push 시점 방문 확정).
- 도착 칸의 `dist`가 `-1`이면 도달 불가라 `-1`, 아니면 `dist+1`(칸 개수)을 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "정점=칸, 간선=상하좌우 이동, 비용 1" 로 문제를 번역한다.
- BFS 뼈대(`dist` 초기화 → 시작 push → popleft → 이웃 확장)를 적는다.
- 마지막에 "간선 수 vs 칸 수" 변환(+1)과 도달 불가(-1) 처리를 붙인다.
```

**2) 연결 요소의 개수** · Easy

- **요구사항**: 정점 `N`개, 간선 `M`개인 무방향 그래프에서 서로 연결된 정점 묶음(연결 요소)이 몇 개인지 세어 출력하라.

- **입력**: 첫 줄에 `N M`. 다음 `M`줄에 각 간선의 두 정점 `u v` (1-indexed).

- **출력**: 연결 요소의 개수.

- **예제**:

    - `6 4` / `1 2` / `2 3` / `4 5` / `4 6` → `2` (그룹 {1,2,3}, {4,5,6})

    - `5 0` → `5` (간선이 없으면 각 정점이 독립)

- **셀프체크**: 방문 안 한 정점에서 BFS를 시작한 횟수가 곧 답이다. 자기 자신만 있는 고립 정점도 하나의 요소다. 큐 자료구조로 `deque`를 썼는가?

```runner
@@SOLUTION
import sys
from collections import deque

def main():
    data = sys.stdin.read().split()
    it = iter(data)
    n = int(next(it)); m = int(next(it))
    graph = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        graph[u].append(v)
        graph[v].append(u)
    visited = [False] * (n + 1)
    count = 0
    for s in range(1, n + 1):
        if not visited[s]:
            count += 1
            visited[s] = True
            q = deque([s])
            while q:
                cur = q.popleft()
                for nxt in graph[cur]:
                    if not visited[nxt]:
                        visited[nxt] = True
                        q.append(nxt)
    print(count)

main()

**이 풀이의 새 문법**

- `iter(data)` / `next(it)`: `iter(리스트)`는 리스트를 처음부터 하나씩 꺼낼 수 있는 이터레이터로 만들고, `next(it)`을 호출할 때마다 다음 원소를 하나씩 반환한다. `idx`를 직접 증가시키는 것과 같은 효과를 더 짧게 낸다.

(1) 접근·핵심 아이디어

- 연결 요소의 개수 = "아직 방문 안 한 정점에서 BFS(또는 DFS)를 새로 시작한 횟수". 한 번 BFS를 돌리면 그 정점이 속한 요소 전체가 방문 처리되므로, 다음으로 미방문 정점을 만나면 그것은 새로운 요소다.
- 무방향 그래프이므로 간선 `u v`를 양쪽 인접리스트에 모두 넣는다.

(2) 코드 단계별

- 인접리스트 `graph`를 만들고 간선을 양방향으로 저장한다.
- 정점 `1..N`을 순회하며 미방문 정점을 만나면 `count += 1` 후 그 정점에서 BFS를 시작(push 시점 방문 표시)해 도달 가능한 모든 정점을 방문 처리한다.
- 순회가 끝나면 `count`가 곧 연결 요소 개수다. 고립 정점(간선 0개)도 각각 한 번씩 BFS 시작을 유발하므로 자동으로 세어진다.

(3) 스스로 다시 짤 때 생각 순서

- "요소 개수 = BFS 시작 횟수"라는 핵심을 먼저 떠올린다.
- 인접리스트 + `visited`를 준비한다(무방향이니 양방향 간선).
- 바깥 for 루프에서 미방문 정점마다 BFS를 돌리고 시작 횟수를 센다.
```

**3) 다중 소스 확산 시간** · Medium

- **요구사항**: `N×M` 격자의 각 칸은 `0`(빈칸), `1`(오염원), `-1`(벽)이다. 매 분마다 모든 오염원은 상하좌우 인접한 빈칸을 오염시킨다(그 칸도 오염원이 됨). 모든 빈칸이 오염되기까지 걸리는 **최소 분**을 출력하라. 처음부터 빈칸이 하나도 없으면 `0`, 끝까지 오염되지 못하는 빈칸이 있으면 `-1`을 출력한다.

- **입력**: 첫 줄에 `N M`. 다음 `N`줄에 각 `M`개의 정수(`0`, `1`, `-1`)가 공백으로 구분되어 주어진다.

- **출력**: 모든 빈칸 오염 완료까지의 최소 분, 또는 `0` / `-1`.

- **예제**:

    - `3 3` / `1 0 0` / `0 0 0` / `0 0 1` → `2`

    - `2 2` / `1 -1` / `-1 0` → `-1` (오른쪽 아래 빈칸은 벽에 막혀 도달 불가)

- **셀프체크**: 모든 오염원을 처음에 큐에 넣고 거리 0으로 두는 다중 소스 BFS다. 답은 도달한 빈칸들의 최대 거리. BFS 종료 후 아직 `0`으로 남은 빈칸이 있으면 `-1`. 시간복잡도 O(N·M)인가?

```runner
@@SOLUTION
import sys
from collections import deque

def main():
    data = sys.stdin.read().split()
    it = iter(data)
    n = int(next(it)); m = int(next(it))
    grid = [[int(next(it)) for _ in range(m)] for _ in range(n)]
    q = deque()
    empty = 0
    for r in range(n):
        for c in range(m):
            if grid[r][c] == 1:
                q.append((r, c, 0))
            elif grid[r][c] == 0:
                empty += 1
    dr = (-1, 1, 0, 0); dc = (0, 0, -1, 1)
    ans = 0
    filled = 0
    while q:
        r, c, t = q.popleft()
        for k in range(4):
            nr, nc = r + dr[k], c + dc[k]
            if 0 <= nr < n and 0 <= nc < m and grid[nr][nc] == 0:
                grid[nr][nc] = 1
                filled += 1
                ans = max(ans, t + 1)
                q.append((nr, nc, t + 1))
    if filled < empty:
        print(-1)
    else:
        print(ans)

main()

(1) 접근·핵심 아이디어

- 여러 오염원이 동시에 번지는 상황이므로 다중 소스 BFS다. 처음에 모든 오염원(`1`)을 거리 0으로 큐에 넣으면, BFS의 각 층이 "1분 경과"에 대응한다.
- 답은 도달한 빈칸들 중 최대 거리(가장 늦게 오염된 시각). 처음부터 빈칸이 없으면 `0`(ans 초기값), 끝까지 못 채운 빈칸이 있으면 `-1`.

(2) 코드 단계별

- 격자를 읽으며 오염원은 `(r,c,0)`으로 큐에 넣고, 빈칸(`0`)의 수 `empty`를 센다. 벽(`-1`)은 무시.
- BFS로 꺼낼 때마다 4방향의 빈칸을 오염(`grid=1`)시키고 `filled += 1`, 도달 시각 `t+1`로 `ans`를 갱신하며 push한다.
- 종료 후 `filled < empty`면 못 채운 빈칸이 있으므로 `-1`, 아니면 `ans`(빈칸이 없었다면 0)를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "동시 확산 → 시작점 여러 개를 한꺼번에 큐에 넣는 다중 소스 BFS"임을 파악한다.
- 초기 큐 구성(모든 오염원, 거리 0)과 빈칸 총수 카운트를 먼저 짠다.
- 확장하면서 최대 시각을 추적하고, 마지막에 "다 못 채웠는가"로 `-1` 여부를 판단한다.
```


## L2. 가중치가 동일한 그래프에서의 BFS

**개념**

- 모든 간선의 가중치(비용)가 **같은 값**(보통 1)일 때, "최소 비용 = 최소 간선 수"가 되므로 Dijkstra 같은 우선순위 큐 없이 **평범한 BFS 하나로 최단거리를 구할 수 있다.** 이것이 이 레슨의 핵심 관찰이다.

- 왜 성립하나: BFS는 거리가 작은 정점부터 층 단위로 확장하므로, 어떤 정점에 **처음 도달하는 순간의 거리가 곧 최단거리**다. 나중에 다른 경로로 같은 정점에 오면 거리가 같거나 더 크므로, 이미 방문했으면 무시하면 된다. (가중치가 서로 다르면 이 성질이 깨져 Dijkstra가 필요하다.)

- 최단"거리"뿐 아니라 최단"경로"도 복원할 수 있다. 각 정점을 처음 방문시킨 직전 정점을 `parent[nxt] = cur`로 기록해 두고, 도착점부터 부모를 거슬러 올라가며 경로를 뒤집으면 된다.

- 응용 확장:

    - **상태 그래프 BFS**: 정점이 좌표가 아니라 "상태"일 수 있다. 예: `(현재 수)`에서 `+1, -1, ×2` 연산 각각을 간선(비용 1)으로 보면 목표 수까지 최소 연산 횟수를 BFS로 구한다.

    - **차원 추가 BFS**: "벽을 K번 부술 수 있다" 같은 조건은 정점을 `(r, c, 남은 부수기 횟수)`로 확장한다. 같은 칸이라도 남은 횟수가 다르면 다른 상태다.

```python
from collections import deque

def bfs_shortest(start, target, graph, n):
    dist = [-1] * (n + 1)
    parent = [-1] * (n + 1)
    q = deque([start])
    dist[start] = 0
    while q:
        cur = q.popleft()
        if cur == target:
            break
        for nxt in graph[cur]:
            if dist[nxt] == -1:
                dist[nxt] = dist[cur] + 1
                parent[nxt] = cur       # 경로 복원용
                q.append(nxt)
    # 경로 복원: target에서 parent를 거슬러 올라가 뒤집기
    return dist, parent
```

**접근 전략**

- "간선 비용이 전부 같은가?"를 먼저 확인한다. 같다면 우선순위 큐(heapq)를 꺼낼 필요 없이 `deque` BFS로 충분하고 더 빠르다. 비용이 0/1 두 종류로만 갈리면 0-1 BFS(deque의 양끝 사용), 완전히 제각각이면 Dijkstra로 넘어가야 한다 — 이 판단이 문제 유형 분류의 시작이다.

- 상태 BFS는 (1) 상태를 무엇으로 정의할지, (2) 한 상태에서 갈 수 있는 다음 상태(간선)를 어떻게 만들지, (3) 방문 배열/집합의 차원을 어떻게 잡을지를 순서대로 설계한다. 상태 수 × 상태당 전이 수가 곧 복잡도다.

- 경로 복원이 필요하면 `parent`(또는 방향 기록)를 남기고, 도착점부터 역추적 후 `reverse()` 한다. 경로 길이만 필요하면 `dist` 값 하나로 끝난다.

- **복잡도**: 상태(정점) 수 V, 전이(간선) 수 E일 때 시간 O(V+E), 공간 O(V). 차원을 추가하면 V가 곱해져 커진다 — 예: `R×C×(K+1)` 격자면 O(R·C·K).

- 흔한 실수·팁:

    - **가중치가 다른데 BFS로 최단거리를 구하려는 실수**가 가장 잦다. 이때는 반드시 Dijkstra. BFS는 "가중치 동일" 전제에서만 최단을 보장한다.

    - 상태 BFS에서 방문 배열 차원을 빠뜨리면(예: 남은 부수기 횟수를 무시) 최단이 아닌 답이 나온다. 상태 정의에 포함된 모든 변수를 방문 키에 넣어야 한다.

    - 수(값) 상태 BFS는 값의 상한을 정해 배열 크기를 잡거나 `set`으로 방문 관리한다. 상한을 넘는 전이는 버린다.

    - `deque` 사용, push 시점 방문 표시 — L1과 동일한 습관을 유지한다.

**문제**

**1) 숨바꼭질 (연산 최소 횟수)** · Medium

- **요구사항**: 정수 `N`에서 시작해 한 번에 `X-1`, `X+1`, `X*2` 중 하나로 이동할 수 있다. 목표 `K`에 도달하는 **최소 연산 횟수**를 출력하라. 좌표(값)는 `0` 이상 `100000` 이하 범위에서만 이동 가능하다.

- **입력**: 한 줄에 `N K` (0 ≤ N, K ≤ 100000).

- **출력**: 최소 연산 횟수.

- **예제**:

    - `5 17` → `4` (5→10→9→18→17 또는 5→4→8→16→17)

    - `10 10` → `0`

- **셀프체크**: 각 연산이 비용 1인 상태 그래프 BFS다. `0~100000` 범위를 벗어나는 값은 큐에 넣지 않는다. `N == K`인 즉시 종료 케이스, 범위 상한(`*2`가 100000 초과)을 처리했는가? 방문은 크기 100001 배열로.

```runner
@@SOLUTION
import sys
from collections import deque

def main():
    n, k = map(int, sys.stdin.read().split())
    MAX = 100000
    dist = [-1] * (MAX + 1)
    dist[n] = 0
    q = deque([n])
    while q:
        x = q.popleft()
        if x == k:
            break
        for nx in (x - 1, x + 1, x * 2):
            if 0 <= nx <= MAX and dist[nx] == -1:
                dist[nx] = dist[x] + 1
                q.append(nx)
    print(dist[k])

main()

(1) 접근·핵심 아이디어

- 정점 = 현재 값, 간선 = `-1 / +1 / *2` 세 연산(각 비용 1)인 상태 그래프다. 모든 간선 비용이 같으므로 최소 연산 횟수 = BFS 최단거리.
- 값의 범위가 `0..100000`으로 유한하므로 크기 100001의 `dist` 배열로 방문/거리를 동시에 관리한다. 범위를 벗어나는 전이(`x-1<0`, `x*2>100000` 등)는 버린다.

(2) 코드 단계별

- `dist`를 `-1`로 초기화, 시작값 `n`을 0으로 두고 큐에 넣는다. `n==k`면 첫 pop에서 바로 종료해 0을 출력한다.
- 큐에서 `x`를 꺼내 목표면 중단. 아니면 세 연산 결과 `nx`가 범위 안이고 미방문이면 `dist[x]+1`을 기록하고 push한다.
- BFS는 층 단위 확장이라 `k`에 처음 도달한 거리가 최소 연산 횟수다. `dist[k]`를 출력.

(3) 스스로 다시 짤 때 생각 순서

- "값 = 상태, 연산 = 간선, 비용 동일 → BFS"로 문제를 상태 그래프로 번역한다.
- 방문/거리 배열 크기를 값 상한(100001)으로 잡는다.
- 전이 3가지를 나열하고 각각 범위 체크를 넣은 뒤 표준 BFS 뼈대에 끼운다.
```

**2) 벽 부수고 이동하기** · Hard

- **요구사항**: `N×M` 격자에서 `0`은 길, `1`은 벽이다. `(0,0)`에서 `(N-1,M-1)`까지 상하좌우로 이동하는데, 이동 중 **벽을 최대 1번** 부술(통과할) 수 있다. 지나는 **칸의 개수**(시작·도착 포함) 최솟값을 출력하고, 불가능하면 `-1`을 출력하라.

- **입력**: 첫 줄에 `N M`. 다음 `N`줄에 각 `M`개의 `0/1`이 공백 없이 주어진다.

- **출력**: 최단 경로의 칸 개수, 또는 `-1`.

- **예제**:

    - `3 3` / `010` / `010` / `010` → `5` (예: (0,0)→(1,0)→(2,0)→(2,1)→(2,2), 벽 안 부숨. 최단 칸 수 5)

    - `2 2` / `01` / `10` → `3` (벽 한 번 부수면 (0,0)→(0,1)→(1,1), 칸 3개)

- **셀프체크**: 상태를 `(r, c, 벽을 부순 적 있는가 0/1)`로 두는 차원 추가 BFS다. 방문 배열은 `N×M×2`. 벽 칸으로 갈 때는 아직 안 부순 상태(`0`)에서만, 그리고 부순 상태(`1`)로 전이한다. "칸 개수"이므로 거리에 +1 하는 지점을 확인하라.

```runner
@@SOLUTION
import sys
from collections import deque

def main():
    data = sys.stdin.read().split('\n')
    idx = 0
    n, m = map(int, data[idx].split()); idx += 1
    grid = []
    for i in range(n):
        grid.append(data[idx]); idx += 1
    INF = -1
    dist = [[[INF] * 2 for _ in range(m)] for _ in range(n)]
    dist[0][0][0] = 1  # 칸 개수: 시작 칸이 1
    q = deque([(0, 0, 0)])
    dr = (-1, 1, 0, 0); dc = (0, 0, -1, 1)
    while q:
        r, c, b = q.popleft()
        for k in range(4):
            nr, nc = r + dr[k], c + dc[k]
            if not (0 <= nr < n and 0 <= nc < m):
                continue
            if grid[nr][nc] == '0':
                if dist[nr][nc][b] == INF:
                    dist[nr][nc][b] = dist[r][c][b] + 1
                    q.append((nr, nc, b))
            else:  # 벽
                if b == 0 and dist[nr][nc][1] == INF:
                    dist[nr][nc][1] = dist[r][c][0] + 1
                    q.append((nr, nc, 1))
    d0 = dist[n-1][m-1][0]
    d1 = dist[n-1][m-1][1]
    cands = [d for d in (d0, d1) if d != INF]
    print(min(cands) if cands else -1)

main()

(1) 접근·핵심 아이디어

- "벽을 최대 1번 부순다"는 조건 때문에 같은 칸이라도 "아직 안 부숨(0)"과 "이미 부숨(1)"은 서로 다른 상태다. 그래서 정점을 `(r, c, b)`로 확장하는 차원 추가 BFS를 쓴다(방문 배열 `N×M×2`).
- 모든 이동 비용이 1이라 BFS로 최단거리가 나온다. 출력은 칸 개수이므로 시작 칸을 거리 1로 두고 이동할 때마다 +1 한다.

(2) 코드 단계별

- `dist[r][c][b]`를 미방문(-1)으로 두고 시작 `(0,0,0)`을 1로 초기화.
- 꺼낸 `(r,c,b)`에서 4방향을 본다. 다음 칸이 길(`0`)이면 같은 `b` 차원에서 확장. 벽(`1`)이면 아직 안 부순 상태(`b==0`)에서만 부순 상태(`1`)로 넘어가며 확장한다.
- 도착 칸의 두 상태 `dist[.][.][0]`, `dist[.][.][1]` 중 도달 가능한 값의 최솟값이 답. 둘 다 미방문이면 `-1`.

(3) 스스로 다시 짤 때 생각 순서

- "제약(부수기 횟수)이 상태를 나눈다 → 방문 차원을 하나 늘린다"를 먼저 결정한다.
- 전이 규칙을 길/벽으로 나눠 적는다(벽은 b=0→1 로만).
- 시작 거리 1(칸 수)로 두고, 마지막에 두 차원의 최솟값/도달 불가(-1)를 정리한다.
```

**3) 최단 경로 복원** · Medium

- **요구사항**: 정점 `N`, 간선 `M`인 무방향 그래프(모든 간선 비용 1)에서 정점 `1`부터 정점 `N`까지 가는 **최단 경로에 포함된 정점들을** 순서대로 출력하라. 도달 불가면 `-1` 한 줄을 출력한다. (최단 경로가 여러 개면 아무거나 하나.)

- **입력**: 첫 줄에 `N M`. 다음 `M`줄에 `u v`.

- **출력**: 정점 번호를 시작(`1`)부터 도착(`N`)까지 공백으로 구분해 한 줄에, 또는 `-1`.

- **예제**:

    - `4 4` / `1 2` / `2 4` / `1 3` / `3 4` → `1 2 4` (또는 `1 3 4`)

    - `3 1` / `1 2` → `-1` (정점 3에 도달 불가)

- **셀프체크**: BFS로 `dist`를 채우면서 `parent[nxt]=cur`를 기록하고, `N`에서 `parent`를 거슬러 올라가 `reverse()` 한다. 시작=도착(`N==1`)인 경우, 경로 복원 시 무한루프(부모가 자기 자신) 방지를 점검했는가?

```runner
@@SOLUTION
import sys
from collections import deque

def main():
    data = sys.stdin.read().split()
    it = iter(data)
    n = int(next(it)); m = int(next(it))
    graph = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        graph[u].append(v)
        graph[v].append(u)
    dist = [-1] * (n + 1)
    parent = [-1] * (n + 1)
    dist[1] = 0
    q = deque([1])
    while q:
        cur = q.popleft()
        if cur == n:
            break
        for nxt in graph[cur]:
            if dist[nxt] == -1:
                dist[nxt] = dist[cur] + 1
                parent[nxt] = cur
                q.append(nxt)
    if dist[n] == -1:
        print(-1)
        return
    path = []
    v = n
    while v != -1:
        path.append(v)
        if v == 1:
            break
        v = parent[v]
    path.reverse()
    print(' '.join(map(str, path)))

main()

(1) 접근·핵심 아이디어

- 모든 간선 비용이 1인 무방향 그래프에서 최단 경로는 BFS로 구한다. 경로 자체를 복원하려면 각 정점을 "처음 방문시킨 직전 정점"을 `parent[nxt] = cur`로 기록해 두면 된다.
- 도착점 `N`에서 `parent`를 거슬러 올라가며 정점을 모으고, 마지막에 뒤집으면 `1 → N` 순서 경로가 된다.

(2) 코드 단계별

- 인접리스트를 만들고(무방향이라 양방향) 정점 1에서 BFS를 시작한다. 미방문 이웃을 방문 처리하며 `parent`에 부모를 남긴다.
- `N`을 pop하면 조기 종료 가능. BFS 후 `dist[N] == -1`이면 도달 불가라 `-1`.
- 도달 가능하면 `v = N`에서 시작해 `path`에 담고 `v = parent[v]`로 올라간다. `v == 1`에 닿으면 멈춰(무한루프 방지) `reverse()` 후 공백으로 출력한다. `N==1`이면 경로는 `1` 하나.

(3) 스스로 다시 짤 때 생각 순서

- "경로 길이만이 아니라 경로 자체가 필요 → parent 기록"을 먼저 결정한다.
- 표준 BFS에 `parent[nxt] = cur` 한 줄을 추가한다.
- 도착점부터 부모 역추적 → 시작점에서 멈춤 → reverse → 출력, 그리고 도달 불가(-1) 처리를 붙인다.
```
