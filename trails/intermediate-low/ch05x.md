## L5. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch5(DP I)의 핵심 네 유형 — subproblem 합치기, 격자 한 칸 전진, 조건부 선택 전진, 배낭 — 을 **반복 훈련**하고, 코딩테스트 단골 DP 유형으로 **확장**하는 연습 세트다. 새 문법은 없다. 모든 문제에서 "상태 정의 → 점화식 → 기저·계산 순서" 세 줄을 먼저 적고 코드를 쓴다.

- **반복 훈련 개념**
- subproblem 합치기: 마지막 한 걸음이 무엇이었나로 경우를 나눠 더한다 — `dp[i] = dp[i-1] + dp[i-3]`, 매 덧셈마다 `% MOD`
- 격자 한 칸 전진: 이 칸으로 들어오는 방향의 dp만 모아 결합한다 — `dp[i][j] = g[i][j] + min(dp[i+1][j], dp[i][j-1])`, 3방향이면 `max(dp[j-1], dp[j], dp[j+1])`
- 조건부 선택 전진: "이 원소를 어떤 이전 상태 뒤에 붙일 수 있나"를 필터로 걸고 최적을 고른다 — `dp[i] = c[i] + min(dp[i-k:i])`, `dp[i] = max(dp[i+1], p[i] + dp[i+t[i]+1])`
- 배낭: 각 아이템을 몇 번 쓸 수 있는지로 용량 루프 방향이 갈린다 — 0/1은 `for c in range(W, w-1, -1)`, 무한은 `for a in range(sq, n+1)`, 경우의 수는 `dp[0]=1`·덧셈, 최소 개수는 `INF`·`min`
- 도달 불가 처리: 경우의 수는 `0`, 최솟값은 `INF`, 최댓값은 `-inf`로 막고 답이 그 값이면 `-1`을 출력한다

- **코딩테스트 출제 맵**: 이 챕터의 유형은 백준 「단계별로 풀어보기」의 '동적 계획법 1'·'동적 계획법 2' 단계(타일링·계단·퇴사·배낭 류), 프로그래머스 「코딩테스트 고득점 Kit」의 '동적계획법', NeetCode 150의 '1-D DP'·'2-D DP'(Decode Ways·Min Path Sum·Coin Change·Perfect Squares 류)에 그대로 등장한다. 이 레슨의 유형 확장 문제는 그 대표 유형을 소재·수치·조건을 새로 만들어 이 챕터 수준으로 재구성한 것이다.

**1) 연꽃잎 건너기 경우의 수** · Easy

- **요구사항**: 개구리가 출발점(0번)에서 연꽃잎을 밟아 n번 잎까지 간다. 한 번에 1칸 또는 3칸만 점프할 수 있다(2칸 점프는 불가). n번 잎에 도달하는 방법의 수를 1,000,000,007로 나눈 나머지를 구하라.
- **입력**: 한 줄에 정수 n (1 ≤ n ≤ 100,000)
- **출력**: 방법의 수를 MOD로 나눈 나머지
- **예제**: `3` → `2` · `5` → `4` · `10` → `28`
- **셀프체크**: 마지막 점프가 1칸이면 `dp[n-1]`, 3칸이면 `dp[n-3]` — 2칸 항이 없어야 한다. `n=2`일 때 답이 `1`(1+1)인지, `i<3`에서 음수 인덱스를 막았는지 확인. n이 10만이면 재귀 대신 반복문.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    MOD = 1_000_000_007
    # dp[i] = i번째 잎에 도달하는 방법 수 (1칸 또는 3칸 점프)
    dp = [0] * (n + 1)
    dp[0] = 1
    for i in range(1, n + 1):
        dp[i] = dp[i - 1]
        if i >= 3:
            dp[i] += dp[i - 3]
        dp[i] %= MOD
    print(dp[n])
main()
@@TESTS

--IN

@@EXPL
(1) 접근·핵심 아이디어

- 상태 `dp[i]` = 0번에서 출발해 i번 잎에 도달하는 방법 수. 마지막 점프가 무엇이었나로 경우를 나누면 두 갈래뿐이다: 1칸 점프로 왔으면 그 전에 `i-1`에 있었고(`dp[i-1]`가지), 3칸 점프로 왔으면 `i-3`에 있었다(`dp[i-3]`가지).
- 점화식 `dp[i] = dp[i-1] + dp[i-3]`, 기저 `dp[0] = 1`(출발점에 서 있는 방법 1가지). 계단 오르기(1·2칸)의 쌍둥이지만 `dp[i-2]` 항이 없다는 점이 다르다.
- 시간 O(n), 공간 O(n). 굴림 변수 3개로 O(1)도 가능.

(2) 코드 단계별

- `dp[0]=1`로 두고 `i=1..n`을 오름차순으로 채운다.
- `dp[i]`에 먼저 `dp[i-1]`을 넣고, `i>=3`일 때만 `dp[i-3]`을 더해 음수 인덱스 참조를 막는다.
- 값이 매우 커지므로 매 칸마다 `% MOD`.
- `n=3` → `1+1+1`, `3` 두 가지. `n=5` → `dp: 1,1,1,2,3,4`로 `4`. `n=2` → `1+1` 한 가지뿐이라 `1`.

(3) 스스로 다시 짤 때 생각 순서

- "마지막 점프가 1칸/3칸" → `dp[i-1] + dp[i-3]` 점화식.
- 기저 `dp[0]=1`, `i<3`일 때 3칸 항을 건너뛰는 조건.
- n 상한이 크니 반복문, 매 덧셈마다 MOD.
```

**2) 택배 최소 통행료** · Easy

- **요구사항**: n×m 격자의 각 칸에 통행료가 적혀 있다. 택배 차량은 **왼쪽 아래 칸**에서 출발해 **오른쪽 위 칸**까지 가며, 한 번에 **위** 또는 **오른쪽**으로만 한 칸 이동한다. 지나는 모든 칸(출발·도착 포함)의 통행료 합의 최솟값을 구하라.
- **입력**: 첫 줄 n, m (1 ≤ n, m ≤ 100), 이후 n줄에 m개의 통행료(0 이상 100 이하)
- **출력**: 최소 통행료 합
- **예제**: `3 3 / 1 3 1 / 1 5 1 / 4 2 1` → `9` · `1 1 / 7` → `7`
- **셀프체크**: 출발이 `(n-1, 0)`, 도착이 `(0, m-1)`이다. 이 칸으로 들어오는 방향이 "아래에서 위로"와 "왼쪽에서"이므로 참조 칸은 `dp[i+1][j]`와 `dp[i][j-1]`. 계산 순서를 **아래 행부터 위로** 돌아야 `dp[i+1]`이 먼저 채워진다. 1×1 격자면 출발 칸 값 그대로.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.buffer.read().split()
    idx = 0
    n, m = int(data[idx]), int(data[idx + 1]); idx += 2
    g = []
    for i in range(n):
        g.append([int(data[idx + j]) for j in range(m)])
        idx += m
    INF = float('inf')
    # dp[i][j] = (i,j)에 도달했을 때 최소 통행료. 출발은 왼쪽 아래 (n-1, 0)
    dp = [[INF] * m for _ in range(n)]
    for i in range(n - 1, -1, -1):          # 아래 행부터 위로
        for j in range(m):
            if i == n - 1 and j == 0:
                dp[i][j] = g[i][j]
                continue
            best = INF
            if i + 1 < n: best = min(best, dp[i + 1][j])   # 아래에서 위로 올라옴
            if j > 0: best = min(best, dp[i][j - 1])       # 왼쪽에서 옴
            dp[i][j] = best + g[i][j]
    print(dp[0][m - 1])
main()

(1) 접근·핵심 아이디어

- 상태 `dp[i][j]` = 왼쪽 아래 `(n-1, 0)`에서 출발해 `(i, j)`에 도달했을 때의 최소 통행료 합.
- `(i, j)`로 들어오는 마지막 이동은 "아래 칸에서 위로"(`dp[i+1][j]`) 또는 "왼쪽 칸에서"(`dp[i][j-1]`) 둘뿐이다. 점화식 `dp[i][j] = g[i][j] + min(dp[i+1][j], dp[i][j-1])`.
- 최소 경로 합 DP와 골격이 같지만 출발·도착과 방향이 바뀌었으니 참조 칸과 순회 순서를 다시 정해야 한다. 시간 O(n·m), 공간 O(n·m).

(2) 코드 단계별

- 격자를 읽고 `dp`를 `INF`로 채운다.
- 행을 `n-1`부터 `0`까지 **내림차순**, 열을 `0`부터 `m-1`까지 오름차순으로 돌면 참조하는 `dp[i+1][j]`(아래 행)와 `dp[i][j-1]`(같은 행 왼쪽)이 항상 먼저 채워져 있다.
- 출발 칸 `(n-1, 0)`은 `g` 값 그대로. 그 외 칸은 존재하는 방향만 `min`으로 모은 뒤 `+ g[i][j]`.
- 답은 도착 칸 `dp[0][m-1]`. 3×3 예제는 `4→2→1→1→1 = 9`, `1×1`은 `7`.

(3) 스스로 다시 짤 때 생각 순서

- 출발·도착·이동 방향을 먼저 그림으로 확인 → 들어오는 방향은 아래·왼쪽.
- 참조 칸이 먼저 채워지도록 행은 아래→위, 열은 왼→오로 순회.
- 출발 칸 기저와 경계 분기(`i+1<n`, `j>0`) 처리 후 도착 칸 출력.
```

**3) 3×n 바닥 타일 채우기** · Medium

- **요구사항**: 세로 3, 가로 n인 바닥을 2×1 크기 타일(가로·세로로 놓을 수 있음)로 빈틈없이 채우는 방법의 수를 1,000,000,007로 나눈 나머지로 구하라. n이 홀수면 칸 수가 홀수라 채울 수 없으므로 0을 출력한다.
- **입력**: 한 줄에 정수 n (1 ≤ n ≤ 1000)
- **출력**: 방법의 수를 MOD로 나눈 나머지
- **예제**: `2` → `3` · `4` → `11` · `3` → `0` · `8` → `153`
- **셀프체크**: 맨 오른쪽 블록의 폭으로 경우를 나눈다. 폭 2 블록(3×2)은 3가지, 폭 4·6·8… 중 "가운데를 세로선으로 자를 수 없는" 통짜 블록은 각각 2가지뿐이다. 그래서 `dp[n] = 3·dp[n-2] + 2·(dp[n-4] + dp[n-6] + … + dp[0])`. `dp[4]=3·3+2·1=11`이 맞는지 손으로 확인. 홀수 n 처리를 잊지 말 것.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    MOD = 1_000_000_007
    if n % 2 == 1:
        print(0); return
    # dp[i] = 3 x i 바닥을 채우는 방법 수 (i는 짝수)
    dp = [0] * (n + 1)
    dp[0] = 1
    s = 0                       # dp[0] + dp[2] + ... + dp[i-4]
    for i in range(2, n + 1, 2):
        if i >= 4:
            s = (s + dp[i - 4]) % MOD
        dp[i] = (3 * dp[i - 2] + 2 * s) % MOD
    print(dp[n])
main()
@@TESTS

--OUT

--IN

--OUT

--IN

--OUT

--IN

--OUT

@@EXPL
(1) 접근·핵심 아이디어

- 상태 `dp[i]` = 3×i 바닥을 채우는 방법 수. 2×n 타일링처럼 "맨 오른쪽 끝을 어떤 블록으로 덮었나"로 경우를 나누되, 여기서는 블록 종류가 더 많다.
- 오른쪽 끝을 세로선으로 잘라 분리되는 가장 작은 블록의 폭을 `w`라 하자. `w=2`(3×2 블록)를 채우는 방법은 3가지다: 가로 타일 3장을 위·중·아래로 쌓기, 세로 타일 2장을 나란히 두고 남은 한 줄에 가로 타일 1장 — 그 가로 줄이 맨 위에 오는 경우와 맨 아래에 오는 경우.
- `w=4, 6, 8, …`처럼 가운데 어디서도 세로선으로 자를 수 없는 "통짜 블록"은 각 폭마다 정확히 2가지(위쪽 가로줄이 튀어나오거나 아래쪽 가로줄이 튀어나오는 지그재그 모양)다.
- 따라서 점화식 `dp[i] = 3·dp[i-2] + 2·(dp[i-4] + dp[i-6] + … + dp[0])`, 기저 `dp[0]=1`. 홀수 폭은 칸 수가 홀수라 0.

(2) 코드 단계별

- `n`이 홀수면 즉시 `0` 출력.
- `dp[0]=1`로 두고 `i`를 2씩 증가시키며 채운다. 괄호 안의 합 `dp[0]+…+dp[i-4]`를 매번 다시 더하면 O(n²)이므로, 누적 변수 `s`에 `dp[i-4]`를 한 번씩만 더해 O(n)으로 만든다.
- `dp[i] = 3·dp[i-2] + 2·s`를 `% MOD`로 갱신.
- `dp[2]=3`, `dp[4]=3·3+2·1=11`, `dp[6]=3·11+2·(1+3)=41`, `dp[8]=3·41+2·(1+3+11)=153`.

(3) 스스로 다시 짤 때 생각 순서

- "맨 오른쪽에서 분리되는 최소 블록의 폭"으로 케이스 분할 → 폭 2는 3가지, 폭 4 이상 통짜는 2가지씩.
- 누적합 변수로 긴 괄호 합을 O(1)에 유지.
- 홀수 n의 0 처리, 짝수만 순회, MOD 적용.
```

**4) 내선 번호 해독 경우의 수** · Medium

- **요구사항**: 어느 사무실의 내선 번호는 1번부터 30번까지다. 누군가 내선 번호 여러 개를 이어서 눌렀는데 구분 없이 숫자열 s만 남았다. s를 내선 번호(1~30, 앞자리 0 없음)들의 나열로 해석하는 방법의 수를 1,000,000,007로 나눈 나머지로 구하라. 해석할 수 없으면 0.
- **입력**: 한 줄에 숫자로만 이루어진 문자열 s (1 ≤ 길이 ≤ 100)
- **출력**: 해석 방법의 수(MOD)
- **예제**: `12` → `2` · `3012` → `2` · `230` → `1` · `05` → `0`
- **셀프체크**: 한 자리 번호는 `'1'~'9'`(0은 불가), 두 자리 번호는 `10~30`(앞자리 0 불가, 31 이상 불가). `'0'`이 나오면 반드시 앞 글자와 묶여 10·20·30이 되어야 하고 아니면 전체가 0가지가 된다. `230`이 `2,30` 한 가지만 되는 이유(`23,0`은 0번이 없음)를 설명할 수 있는가?

```runner
@@SOLUTION
import sys
def main():
    s = sys.stdin.read().split()[0]
    n = len(s)
    MOD = 1_000_000_007
    # dp[i] = 앞 i글자를 내선 번호(1~30)들로 나누는 방법 수
    dp = [0] * (n + 1)
    dp[0] = 1
    for i in range(1, n + 1):

            dp[i] = dp[i - 1]
        if i >= 2 and s[i - 2] != '0' and int(s[i - 2:i]) <= 30:   # 두 자리 번호 10~30
            dp[i] += dp[i - 2]
        dp[i] %= MOD
    print(dp[n])

- 마지막 한 글자 `s[i-1]`가 `'1'~'9'`면 한 자리 번호로 끝날 수 있어 `dp[i-1]`가지. 마지막 두 글자 `s[i-2:i]`가 `10~30`이면 두 자리 번호로 끝날 수 있어 `dp[i-2]`가지.
- 점화식 `dp[i] = [s[i-1]≠'0']·dp[i-1] + [10 ≤ s[i-2:i] ≤ 30]·dp[i-2]`, 기저 `dp[0]=1`(빈 문자열은 아무것도 안 누른 1가지). 계단 오르기(1·2칸)의 골격에 "칸을 밟아도 되는지" 조건이 붙은 형태다.
- 시간 O(n), 공간 O(n).

(2) 코드 단계별

- `dp[0]=1`, `i=1..n`을 오름차순으로 채운다.
- `s[i-1] != '0'`이면 `dp[i-1]`을 더한다(`'0'` 하나는 번호가 아니므로 0가지).

- `12` → `1,2`·`12` = 2. `3012` → `30,1,2`·`30,12` = 2. `230` → `2,30` = 1. `05` → 0.

(3) 스스로 다시 짤 때 생각 순서

- "마지막 번호가 한 자리/두 자리" → `dp[i-1]`, `dp[i-2]` 두 항.
- 각 항의 유효 조건(0 단독 불가, 앞자리 0 불가, 30 이하)을 필터로 적는다.
```

**5) 낙하 경로 최대 점수** · Medium

- **요구사항**: n행 m열 격자의 각 칸에 점수(음수 가능)가 있다. 공은 **첫 행의 아무 열**에서 출발해 한 행씩 아래로 떨어지는데, 다음 행에서는 바로 아래·왼쪽 아래·오른쪽 아래 세 칸 중 하나로만 갈 수 있다. **마지막 행의 아무 열**에 도착할 때 지나온 칸 점수 합의 최댓값을 구하라.
- **입력**: 첫 줄 n, m (1 ≤ n, m ≤ 100), 이후 n줄에 m개의 정수(-100 이상 100 이하)
- **출력**: 최대 점수 합
- **예제**: `3 3 / 2 1 3 / 6 5 4 / 7 8 9` → `17` · `1 1 / -5` → `-5`
- **셀프체크**: 출발 열이 자유이므로 첫 행은 `dp = g[0]` 그대로, 도착 열도 자유이므로 답은 `max(dp[n-1])`이다. 맨 왼쪽·오른쪽 열은 들어오는 방향이 2개뿐이니 인덱스 범위를 막았는가? 점수가 전부 음수여도 반드시 한 경로는 골라야 하므로 0이 아니라 음수가 답이다.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.buffer.read().split()
    idx = 0
    n, m = int(data[idx]), int(data[idx + 1]); idx += 2
    g = []
    for i in range(n):
        g.append([int(data[idx + j]) for j in range(m)])
        idx += m
    NEG = float('-inf')
    dp = g[0][:]                          # 첫 행: 어느 열에서든 출발
    for i in range(1, n):
        ndp = [NEG] * m
        for j in range(m):
            best = dp[j]                              # 바로 위
            if j > 0: best = max(best, dp[j - 1])     # 왼쪽 위
            if j + 1 < m: best = max(best, dp[j + 1]) # 오른쪽 위
            ndp[j] = best + g[i][j]
        dp = ndp
    print(max(dp))
main()

(1) 접근·핵심 아이디어

- 상태 `dp[i][j]` = `(i, j)` 칸에 도착했을 때까지의 최대 점수 합. `(i, j)`로 들어오는 마지막 이동은 윗행의 `j-1`, `j`, `j+1` 세 칸 중 하나.
- 점화식 `dp[i][j] = g[i][j] + max(dp[i-1][j-1], dp[i-1][j], dp[i-1][j+1])`(존재하는 열만). 기저는 첫 행 전체 `dp[0][j] = g[0][j]` — 출발 열이 자유라서 첫 행 모든 칸이 "도달 가능"이다.
- 답은 도착 열이 자유이므로 마지막 행의 최댓값 `max(dp[n-1])`. 직전 행만 참조하므로 한 행짜리 배열을 굴려 공간 O(m), 시간 O(n·m).

(2) 코드 단계별

- `dp = g[0][:]`로 첫 행을 복사(참조 공유를 피하려고 슬라이스).
- 각 행 `i`에서 새 배열 `ndp`를 만들고, 열 `j`마다 `dp[j]`를 기본 후보로 두고 `j>0`이면 `dp[j-1]`, `j+1<m`이면 `dp[j+1]`을 `max`로 합친 뒤 `+ g[i][j]`.
- 행을 다 처리하면 `dp = ndp`로 교체.
- 3×3 예제는 `3→5→9 = 17`. 전부 음수인 2×4 예제는 `-1→-5 = -6`이 최선(0이 아님). `1×1`은 그 칸 값.

(3) 스스로 다시 짤 때 생각 순서

- "3방향 + 출발·도착 자유" → 첫 행 전체 기저, 답은 마지막 행 `max`.
- 열 경계에서 없는 방향을 `if`로 제외.
- 한 행씩 굴리며 갱신, 음수만 있어도 반드시 한 경로를 택한다.
```

**6) 돌다리 최소 비용 점프** · Medium

- **요구사항**: 일렬로 놓인 n개의 돌에 각각 밟는 비용이 있다. 1번 돌에서 출발해 n번 돌에 도착해야 하며, 한 번의 점프로 앞쪽 1칸 이상 k칸 이하 어느 돌로든 갈 수 있다. 출발 돌과 도착 돌을 포함해 밟은 돌의 비용 합의 최솟값을 구하라.
- **입력**: 첫 줄 n, k (2 ≤ n ≤ 1000, 1 ≤ k < n), 둘째 줄에 n개의 비용(0 이상 1000 이하)
- **출력**: 최소 비용 합
- **예제**: `6 2 / 1 5 2 8 3 1` → `7` · `4 3 / 4 9 9 4` → `8`
- **셀프체크**: `dp[i] = c[i] + min(dp[i-k], …, dp[i-1])`에서 `i-k`가 음수면 0으로 잘라야 한다. `k=1`이면 모든 돌을 밟으니 전체 합이 답인지 확인. 비용이 0인 돌만 골라도 출발·도착 돌은 반드시 포함된다.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.buffer.read().split()
    idx = 0
    n, k = int(data[idx]), int(data[idx + 1]); idx += 2
    c = [int(data[idx + i]) for i in range(n)]
    # dp[i] = i번 돌을 밟았을 때까지의 최소 비용 (한 번에 최대 k칸 전진)
    dp = [0] * n
    dp[0] = c[0]
    for i in range(1, n):
        best = dp[i - 1]
        for j in range(max(0, i - k), i):   # i-k .. i-1 중 최소
            if dp[j] < best:
                best = dp[j]
        dp[i] = best + c[i]
    print(dp[n - 1])
main()

(1) 접근·핵심 아이디어

- 상태 `dp[i]` = 1번 돌에서 출발해 `i`번 돌을 밟은 순간까지의 최소 비용(그 돌 비용 포함). `i`번 돌로 들어오는 마지막 점프는 `i-k`, …, `i-1` 중 한 돌에서 왔다.
- 점화식 `dp[i] = c[i] + min(dp[j] for j in [max(0, i-k), i-1])`, 기저 `dp[0] = c[0]`. 계단(1·2칸)의 "직전 두 칸 중 최소"를 "직전 k칸 중 최소"로 일반화한 조건부 선택 DP다.
- 시간 O(n·k)(n, k ≤ 1000이면 최대 100만 연산), 공간 O(n). k가 더 크면 단조 큐로 O(n)까지 줄일 수 있지만 이 범위에선 불필요.

(2) 코드 단계별

- `dp[0] = c[0]`으로 출발 돌 비용을 먼저 낸다.
- `i=1..n-1`마다 `j`를 `max(0, i-k)`부터 `i-1`까지 돌며 `dp[j]`의 최솟값을 찾고 `+ c[i]`.
- `max(0, i-k)`가 없으면 `i<k`일 때 음수 인덱스를 참조해 리스트 뒤쪽 값을 잘못 읽는다 — 파이썬은 에러 없이 틀린 답을 내므로 특히 위험.
- `[1,5,2,8,3,1]`, k=2 → `1→2→3→1`(돌 1·3·5·6)로 `7`. `[4,9,9,4]`, k=3 → 바로 끝으로 점프해 `8`. `k=1`이면 전부 밟아 `15`.

(3) 스스로 다시 짤 때 생각 순서

- "최대 k칸 점프 + 최소 비용" → `dp[i] = c[i] + min(직전 k개)`.
- 창 시작을 `max(0, i-k)`로 잘라 음수 인덱스 방지.
- 출발 돌 기저, 답은 `dp[n-1]`(도착 돌 필수 포함).
```

**7) 제곱수 합 최소 개수** · Medium

- **요구사항**: 양의 정수 N을 제곱수(1, 4, 9, 16, …)들의 합으로 나타낼 때, 사용하는 제곱수 개수의 최솟값을 구하라. 같은 제곱수를 여러 번 써도 된다.
- **입력**: 한 줄에 정수 N (1 ≤ N ≤ 10,000)
- **출력**: 최소 개수
- **예제**: `12` → `3` · `13` → `2` · `7` → `4`
- **셀프체크**: 이것은 "동전 = 제곱수, 무한 사용, 최소 개수"인 무한 배낭이다. `dp[0]=0`, 나머지 `INF`, 합 루프는 **오름차순**이어야 같은 제곱수를 재사용한다. 1이 항상 있으므로 만들 수 없는 경우는 없다. 그리디(가장 큰 제곱수부터)가 `12 = 9+1+1+1`(4개)로 틀리고 DP가 `4+4+4`(3개)를 찾는지 확인.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    INF = float('inf')
    # dp[a] = 합이 정확히 a가 되는 제곱수 개수의 최솟값 (무한 배낭: 최소 개수)
    dp = [0] + [INF] * n
    squares = []
    r = 1
    while r * r <= n:
        squares.append(r * r)
        r += 1
    for sq in squares:                       # 아이템 바깥
        for a in range(sq, n + 1):           # 합 오름차순 -> 같은 제곱수 재사용 허용
            if dp[a - sq] + 1 < dp[a]:
                dp[a] = dp[a - sq] + 1
    print(dp[n])
main()

(1) 접근·핵심 아이디어

- 아이템은 `N` 이하의 제곱수들, 각 아이템은 무한히 쓸 수 있고, 합을 **정확히** `N`으로 만들면서 개수를 최소화한다 — 동전 교환(최소 개수)과 같은 무한 배낭이며, 동전 목록을 입력 대신 직접 생성한다는 점만 다르다.
- 상태 `dp[a]` = 합이 정확히 `a`가 되는 최소 제곱수 개수. 점화식 `dp[a] = min(dp[a - sq] + 1)`(모든 제곱수 `sq ≤ a`). 기저 `dp[0]=0`(아무것도 안 쓰면 합 0), 나머지 `INF`.
- 시간 O(N·√N)(N=10,000이면 약 100만), 공간 O(N).

(2) 코드 단계별

- `r*r <= n`인 `r`을 1부터 늘리며 제곱수 목록을 만든다.
- 제곱수를 바깥 루프, 합 `a`를 `sq`부터 `n`까지 **오름차순** 안쪽 루프로 돌며 `dp[a] = min(dp[a], dp[a-sq]+1)`. 오름차순이라 방금 갱신한 `dp[a-sq]`(이미 이 제곱수를 쓴 값)를 또 써서 같은 제곱수를 여러 번 담는다.
- 1이 항상 포함되므로 `dp[n]`이 `INF`로 남는 일은 없다(만들 수 없는 경우 처리 불필요).
- `12 = 4+4+4` → 3, `13 = 9+4` → 2, `7 = 4+1+1+1` → 4, `1000 = 900+100` → 2.

(3) 스스로 다시 짤 때 생각 순서

- "제곱수 여러 번 사용 + 최소 개수" → 무한 배낭 최소 개수 골격(`INF` 초기화, `min`).
- 아이템 목록을 직접 생성(`r*r <= n`).
- 아이템 바깥·합 오름차순 안쪽 이중 루프, 답 `dp[n]`.
```

**8) 추 조합 경우의 수** · Medium

- **요구사항**: 무게가 적힌 추 n개가 있다(같은 무게의 추가 여러 개 있을 수 있으며 각 추는 서로 다른 물건으로 구분한다). 이 중 일부를 골라 무게 합이 **정확히** W가 되게 하는 방법의 수를 1,000,000,007로 나눈 나머지로 구하라. 각 추는 최대 한 번만 쓴다.
- **입력**: 첫 줄 n, W (1 ≤ n ≤ 100, 1 ≤ W ≤ 1000), 둘째 줄에 n개의 무게(1 이상 1000 이하)
- **출력**: 방법의 수(MOD). 없으면 0
- **예제**: `5 5 / 1 2 3 4 5` → `3` · `3 4 / 2 2 3` → `1` · `1 2 / 3` → `0`
- **셀프체크**: "정확히 채우기 + 경우의 수"이므로 `dp[0]=1`, 나머지 0에서 시작해 `dp[c] += dp[c-w]`. 각 추를 한 번만 쓰려면 용량 루프를 **내림차순**으로 — 오름차순으로 돌면 같은 추를 두 번 세어 `[2]`, W=4에서 1이 나온다. `2 2 3`의 답이 1(두 개의 2)인 이유를 설명할 수 있는가?

```runner
@@SOLUTION
import sys
def main():

    idx = 0

    MOD = 1_000_000_007
    # dp[c] = 지금까지 본 추들로 합이 정확히 c가 되게 고르는 방법 수
    dp = [0] * (W + 1)

        for c in range(W, w - 1, -1):        # 각 추는 최대 1번 -> 내림차순
            dp[c] = (dp[c] + dp[c - w]) % MOD

- 0/1 배낭의 "최대 가치" 자리를 "경우의 수"로 바꾼 변형이다. 상태 `dp[c]` = 지금까지 본 추들 중 일부를 골라 합이 정확히 `c`가 되는 방법 수.
- 추 `w`를 고려할 때, 합 `c`를 만드는 방법은 "이 추를 안 쓴 기존 방법(`dp[c]`)" + "이 추를 쓰고 나머지로 `c-w`를 만든 방법(`dp[c-w]`)". 점화식 `dp[c] = dp[c] + dp[c-w]`, 기저 `dp[0]=1`.
- 각 추를 최대 한 번만 쓰므로 용량 루프를 **내림차순**으로 돌아 `dp[c-w]`가 "이 추를 아직 안 쓴 값"이 되게 한다. 시간 O(n·W), 공간 O(W).

(2) 코드 단계별

- `dp[0]=1`, 나머지 0으로 초기화.
- 추마다 `c`를 `W`부터 `w`까지 내림차순으로 돌며 `dp[c] += dp[c-w]`, 매번 `% MOD`.
- 같은 무게의 추가 여러 개여도 각각 별도의 라운드로 처리되므로 "2번 추와 3번 추를 골랐다"처럼 서로 다른 물건으로 자연히 구분된다.
- `1 2 3 4 5`, W=5 → `{5}, {1,4}, {2,3}` = 3. `2 2 3`, W=4 → 2 두 개 = 1. `[3]`, W=2 → 0. `1 2 3`, W=6 → 전부 = 1.

(3) 스스로 다시 짤 때 생각 순서

- "각 물건 1번 + 정확히 합 + 경우의 수" → `dp[0]=1`·덧셈·내림차순 골격.
- 루프 범위 `range(W, w-1, -1)`로 음수 인덱스 방지.
- `dp[W]` 출력(만들 수 없으면 자연히 0).
```

**9) 연속 근무 제한 최대 수당** · Hard

- **요구사항**: n일 동안 각 날의 근무 수당이 주어진다. 어느 날이든 근무하거나 쉴 수 있지만, **연속으로 k일을 초과해 근무할 수 없다**(k일 연속까지는 허용, k+1일 연속은 금지). 받을 수 있는 수당 합의 최댓값을 구하라.
- **입력**: 첫 줄 n, k (1 ≤ n ≤ 1000, 1 ≤ k ≤ n), 둘째 줄에 n개의 수당(0 이상 1000 이하)
- **출력**: 최대 수당 합
- **예제**: `6 2 / 5 3 8 2 9 4` → `26` · `4 4 / 1 2 3 4` → `10`
- **셀프체크**: 연속 3잔 금지(k=2)를 일반 k로 확장하는 문제다. "상태 = 연속 근무 일수"로 풀면 상태가 k+1개가 되지만, **마지막으로 쉰 날**을 기준으로 잡으면 상태 하나로 된다: `f[i]` = i일을 쉴 때 그 전까지의 최대 수당, `f[i] = max(f[i-j] + (i-j, i) 사이 수당 합)`(1 ≤ j ≤ k+1). 사이 합은 누적합으로 O(1). 양 끝에 가상의 휴무일(0일·n+1일)을 붙이면 경계가 사라진다. `k ≥ n`이면 전부 근무해 전체 합이 답.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.buffer.read().split()
    idx = 0
    n, k = int(data[idx]), int(data[idx + 1]); idx += 2
    a = [int(data[idx + i]) for i in range(n)]
    # b[0], b[n+1] = 가상의 휴무일(수당 0). b[1..n] = 실제 날
    b = [0] + a + [0]
    P = [0] * (n + 3)                        # P[x] = b[0..x-1] 합
    for i in range(n + 2):
        P[i + 1] = P[i] + b[i]
    NEG = float('-inf')
    # f[i] = i일을 쉬는 날로 정했을 때, i일 이전까지 받을 수 있는 최대 수당
    f = [NEG] * (n + 2)
    f[0] = 0
    for i in range(1, n + 2):
        for j in range(1, k + 2):            # 직전 휴무일 i-j (사이에 j-1일 연속 근무, j-1 <= k)
            if i - j < 0:
                break
            cand = f[i - j] + (P[i] - P[i - j + 1])   # (i-j, i) 사이 날들 전부 근무
            if cand > f[i]:
                f[i] = cand
    print(f[n + 1])
main()

(1) 접근·핵심 아이디어

- "연속 k일 초과 금지"는 곧 "어떤 k+1일 구간에도 휴무일이 하나는 있다"는 뜻이다. 그래서 근무일 대신 **휴무일**을 기준으로 상태를 잡는다.
- 상태 `f[i]` = `i`일을 휴무로 정했을 때, `i`일 이전까지 받을 수 있는 최대 수당. 직전 휴무일을 `i-j`라 하면 그 사이 `j-1`일은 전부 근무하므로 `j-1 ≤ k`, 즉 `1 ≤ j ≤ k+1`.
- 점화식 `f[i] = max(f[i-j] + sum(b[i-j+1..i-1]))`(1 ≤ j ≤ k+1). 사이 합은 누적합 `P[i] - P[i-j+1]`로 O(1). 양 끝에 가상의 휴무일 `b[0]=b[n+1]=0`을 붙이면 "첫 휴무 전"·"마지막 휴무 후" 특수 처리가 사라지고 답은 `f[n+1]`.
- 시간 O(n·k), 공간 O(n). 수당이 음수여도 같은 식이 그대로 성립한다(휴무를 더 자주 두는 선택도 전이에 포함되므로).

(2) 코드 단계별

- `b = [0] + a + [0]`, 누적합 `P[x] = b[0..x-1]`의 합.
- `f[0]=0`(가상 휴무일 0일). `i=1..n+1`마다 `j=1..k+1`을 돌며 `i-j<0`이면 중단, 아니면 `f[i-j] + (P[i] - P[i-j+1])`로 갱신.
- `j=1`은 "어제도 쉬었다"(사이 합 0), `j=k+1`은 "정확히 k일 연속 근무 후 쉼"에 해당.
- `[5,3,8,2,9,4]`, k=2 → 2일·4일에 쉬고 `5+8+9+4=26`. k≥n이면 전부 근무 `10`. `[4,1,4,1,4]`, k=1 → 하루 걸러 `12`.

(3) 스스로 다시 짤 때 생각 순서

- "연속 k 초과 금지" → 상태를 "마지막 휴무일"로 잡고 `j ≤ k+1` 창 안에서 최대.
- 구간 합은 누적합으로, 양 끝에 가상 휴무일을 붙여 경계 제거.
- `i-j<0` 방어, 답은 `f[n+1]`.
```

**10) 장애물 있는 최소 통행료** · Hard

- **요구사항**: n×m 격자의 각 칸에 통행료(0 이상)가 있고, 일부 칸은 `-1`로 표시된 통행 불가 칸이다. 왼쪽 위 칸에서 출발해 오른쪽 아래 칸까지 오른쪽 또는 아래로만 이동할 때, 지나는 칸(출발·도착 포함)의 통행료 합의 최솟값을 구하라. 도착할 수 없으면 `-1`을 출력한다.
- **입력**: 첫 줄 n, m (1 ≤ n, m ≤ 100), 이후 n줄에 m개의 정수(통행료 0~100 또는 `-1`)
- **출력**: 최소 통행료 합 또는 `-1`
- **예제**: `3 3 / 1 2 5 / -1 -1 1 / 3 4 1` → `10` · `2 2 / 0 -1 / -1 0` → `-1`
- **셀프체크**: 경로 수 세기에서는 장애물을 `0`으로 막았지만, 최솟값 문제에서는 `INF`로 막아야 `min`에 섞이지 않는다. 출발 칸이나 도착 칸 자체가 장애물인 경우 `-1`이 나오는가? 위·왼쪽이 모두 `INF`인 칸에 `+ g`를 하면 `inf + 5 = inf`라 파이썬 float에선 문제없지만, 정수 `INF`(예: `10**9`)를 쓰면 값이 커져 오답 위험 — `best != INF` 검사로 막는 습관을 들이자.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.buffer.read().split()
    idx = 0
    n, m = int(data[idx]), int(data[idx + 1]); idx += 2
    g = []
    for i in range(n):
        g.append([int(data[idx + j]) for j in range(m)])
        idx += m
    INF = float('inf')
    dp = [[INF] * m for _ in range(n)]       # INF = 도달 불가
    for i in range(n):
        for j in range(m):
            if g[i][j] == -1:
                continue                     # 장애물: INF 그대로
            if i == 0 and j == 0:
                dp[i][j] = g[i][j]
                continue
            best = INF
            if i > 0: best = min(best, dp[i - 1][j])
            if j > 0: best = min(best, dp[i][j - 1])
            if best != INF:
                dp[i][j] = best + g[i][j]
    ans = dp[n - 1][m - 1]
    print(ans if ans != INF else -1)
main()

- 상태 `dp[i][j]` = `(0,0)`에서 `(i,j)`까지의 최소 통행료, 도달 불가면 `INF`. 장애물 칸은 `INF`로 고정, 다른 칸은 위·왼쪽 중 도달 가능한 것만 모아 `min` 후 `+ g[i][j]`.
- 도착 칸이 `INF`면 `-1`. 시간 O(n·m), 공간 O(n·m).

(2) 코드 단계별

- `dp`를 전부 `INF`로 초기화하고 위→아래·왼→오로 순회.

- 그 외 칸은 위·왼쪽의 `dp` 중 최소 `best`를 구하고, `best`가 `INF`가 아닐 때만 `best + g[i][j]`를 기록한다(도달 불가 칸에는 값을 더하지 않는다).
- 첫 예제는 둘째 행이 거의 막혀 `1→2→5→1→1 = 10` 한 경로뿐. 둘째·셋째 예제는 출발 직후 또는 출발 칸이 막혀 `-1`. 마지막 예제는 가운데만 막혀 `5`.

(3) 스스로 다시 짤 때 생각 순서

- "최소 비용 + 장애물 + 불가능 시 -1" → `INF` 초기화·장애물 INF 고정·도착 INF면 -1.
- 출발·도착 칸이 장애물인 경우가 자동으로 처리되는지 흐름을 따라가 본다.
- `best != INF`일 때만 더하는 방어 코드, 경계 분기(`i>0`, `j>0`).
```

**11) 의뢰 수락 최대 보수** · Hard

- **요구사항**: 프리랜서가 n일 동안 일한다. 날마다 그날 시작할 수 있는 의뢰가 하나씩 있는데, i일의 의뢰는 기간 t[i]일(i일부터 i+t[i]-1일까지)이 걸리고 보수 p[i]를 준다. 의뢰는 겹칠 수 없고, 마지막 날(n일) 안에 끝나야 하며, **의뢰를 끝낸 다음 날은 반드시 하루 쉬어야** 새 의뢰를 시작할 수 있다. 받을 수 있는 보수 합의 최댓값을 구하라(의뢰를 하나도 안 해도 된다).
- **입력**: 첫 줄 n (1 ≤ n ≤ 1000), 이후 n줄에 각 날의 `t p` (1 ≤ t ≤ n, 1 ≤ p ≤ 1000)
- **출력**: 최대 보수 합
- **예제**: `8 / 2 30 / 1 10 / 3 50 / 1 20 / 2 25 / 1 15 / 3 60 / 1 10` → `75` · `3 / 2 10 / 1 5 / 1 7` → `10`
- **셀프체크**: 0-indexed로 i일 의뢰를 하면 다음 시작 가능일은 `i + t[i] + 1`이다(휴식 하루). 이 값이 n을 넘으면 "더 이상 의뢰 없음"이므로 `min(n, …)`으로 잘라 `dp[n]=0`을 참조하게 하라 — 휴식일이 n일을 넘겨도 의뢰 자체는 끝났으니 유효하다. 반면 `i + t[i] > n`이면 의뢰가 기간 안에 안 끝나므로 수락 불가. 뒤에서 앞으로 채우는 이유를 설명할 수 있는가?

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(data[idx]); idx += 1
    t, p = [], []
    for _ in range(n):
        t.append(int(data[idx])); p.append(int(data[idx + 1])); idx += 2
    # dp[i] = i일부터 마지막 날까지 (i일에 새 의뢰를 시작할 수 있는 상태) 얻는 최대 보수
    dp = [0] * (n + 1)                       # dp[n] = 0 (남은 날 없음)
    for i in range(n - 1, -1, -1):
        dp[i] = dp[i + 1]                    # i일 의뢰를 거절
        end = i + t[i]                       # 의뢰가 끝난 직후의 날
        if end <= n:                         # n일 안에 끝나야 수락 가능
            nxt = min(n, end + 1)            # 하루 휴식 후 다음 시작 가능일 (범위 넘으면 n)
            dp[i] = max(dp[i], p[i] + dp[nxt])
    print(dp[0])
main()

- "i번째를 고르면 다음은 i+2부터"(인접 금지)를 일반화한 조건부 선택 DP다. 여기서는 i일 의뢰를 고르면 `t[i]`일 동안 묶이고 하루 더 쉬어야 하므로 다음 후보는 `i + t[i] + 1`일부터.
- 앞에서 뒤로 가면 "i일에 의뢰를 시작할 수 있는 상태인지"가 과거 선택에 따라 달라져 복잡하다. 대신 **뒤에서 앞으로** 채우면, 상태 `dp[i]` = "i일에 새 의뢰를 시작할 수 있는 상태에서 i일부터 끝까지 얻는 최대 보수"가 한 문장으로 정의된다.
- 점화식 `dp[i] = max(dp[i+1], p[i] + dp[min(n, i+t[i]+1)])`(단 `i+t[i] ≤ n`일 때만 둘째 항). 기저 `dp[n] = 0`. 답은 `dp[0]`. 시간 O(n), 공간 O(n).

(2) 코드 단계별

- `dp` 크기 `n+1`, `dp[n]=0`(남은 날이 없으면 보수 0).
- `i = n-1 … 0` 내림차순으로: 먼저 거절 `dp[i] = dp[i+1]`.
- `end = i + t[i]`가 `n` 이하면 기간 안에 끝나므로 수락 가능. 다음 시작일 `end+1`이 `n`을 넘을 수 있으니 `min(n, end+1)`로 잘라 `dp[n]`을 참조(휴식일이 기간 밖이어도 의뢰는 유효).
- 첫 예제: 1일(2일짜리, 30) → 휴식 → 4일(20) → 휴식 → 6일(15) → 휴식 → 8일(10) = `75`. 둘째 예제: 1일 의뢰(2일, 10) 후 휴식으로 3일 의뢰(7)는 못 하고 `10`. `2 100 / 1 1` → 첫 의뢰가 딱 2일 안에 끝나 `100`. 하루짜리 의뢰 4개는 하루 걸러 `20`.

(3) 스스로 다시 짤 때 생각 순서

- "고르면 얼마 뒤부터 다시 고를 수 있나"가 항목마다 다름 → 뒤에서 앞으로 `dp[i] = max(거절, 보수 + dp[다음 시작일])`.
- 수락 조건(`i+t[i] ≤ n`)과 다음 시작일 클램프(`min(n, …)`)를 분리해서 생각.
- `dp[n]=0` 기저, 답 `dp[0]`.
```

**12) 개수 제한 배낭** · Hard

- **요구사항**: 물건 N종류가 있고, 각 종류마다 무게 w, 가치 v, 그리고 **최대 사용 가능 개수 c**가 주어진다. 배낭의 최대 무게 W를 넘지 않게 담을 때 가치 합의 최댓값을 구하라(같은 종류를 c개까지 여러 개 담을 수 있다).
- **입력**: 첫 줄 N, W (1 ≤ N ≤ 30, 1 ≤ W ≤ 300), 이후 N줄에 `w v c` (1 ≤ w ≤ W, 1 ≤ v ≤ 1000, 1 ≤ c ≤ 20)
- **출력**: 최대 가치
- **예제**: `3 10 / 3 7 2 / 4 9 1 / 2 3 5` → `23` · `2 9 / 3 10 1 / 2 1 10` → `13`
- **셀프체크**: 0/1 배낭(각 1개)과 무한 배낭(무제한) 사이의 유형이다. 가장 단순한 방법은 "c개짜리 종류 = 같은 (w, v)인 0/1 물건 c개"로 풀어 0/1 배낭을 c번 돌리는 것(내림차순 필수). 둘째 예제에서 무한 배낭처럼 풀면 `(3,10)`을 3개 담아 30이 나오지만 개수 제한 1개 때문에 `10 + 1·3 = 13`이 정답임을 확인. 무게 합이 W를 넘는 종류(`6 100 3`, W=5)는 하나도 못 담아 0.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.buffer.read().split()
    idx = 0
    N, W = int(data[idx]), int(data[idx + 1]); idx += 2
    items = []
    for _ in range(N):
        w, v, c = int(data[idx]), int(data[idx + 1]), int(data[idx + 2]); idx += 3
        items.append((w, v, c))
    dp = [0] * (W + 1)
    for w, v, c in items:
        for _ in range(c):                   # 같은 물건을 c개의 0/1 물건으로 취급
            for cap in range(W, w - 1, -1):  # 0/1 -> 내림차순
                if dp[cap - w] + v > dp[cap]:
                    dp[cap] = dp[cap - w] + v
    print(dp[W])
main()

(1) 접근·핵심 아이디어

- 각 종류를 최대 `c`개 쓸 수 있는 **개수 제한(bounded) 배낭**. 0/1(각 1개)과 무한(무제한)의 중간이다.
- 가장 단순한 환원: 종류 `(w, v, c)`를 "무게 `w`·가치 `v`인 서로 다른 0/1 물건 `c`개"로 본다. 그러면 0/1 배낭 전이 `dp[cap] = max(dp[cap], dp[cap-w]+v)`를 종류마다 `c`번 반복하면 된다. 각 반복은 용량 **내림차순**이어야 그 라운드의 물건이 한 번만 반영된다.
- 상태 `dp[cap]` = 용량 `cap`에서의 최대 가치. 시간 O(Σc · W)(최대 30·20·300 = 18만), 공간 O(W). c가 크면 1, 2, 4, …개 묶음으로 쪼개는 이진 분할로 O(Σlog c · W)까지 줄일 수 있다.

(2) 코드 단계별

- `dp`를 크기 `W+1`, 0으로 초기화.
- 종류마다 `c`번 반복해 0/1 배낭 한 라운드(`cap`을 `W`부터 `w`까지 내림차순)를 돈다. 라운드를 오름차순으로 돌면 무한 배낭이 되어 개수 제한이 깨진다.
- 첫 예제: `3+3+4 = 10`에 `7+7+9 = 23`. 둘째: `(3,10)`은 1개뿐이라 `10 + (2,1)×3 = 13`(무한이면 30). `6 100 3`, W=5 → 무게 초과로 0. `(2,5)×3 + (1,1)×1 = 7`에 `16`.

(3) 스스로 다시 짤 때 생각 순서

- "종류당 c개까지" → 0/1 물건 c개로 풀어 쓰기(내림차순 필수).
- 개수 제한이 실제로 걸리는 테스트(둘째 예제)로 무한 배낭과 답이 다른지 확인.
- 복잡도가 빠듯하면 이진 분할, 아니면 단순 반복으로 충분.
```
