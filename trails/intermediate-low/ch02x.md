## L5. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch2(Backtracking)의 4대 틀 — K개 중 하나를 N번(중복 선택·조건부 가지치기), N개 중 M개(조합·부분집합), 순열(`used[]`) — 을 소재를 바꿔 **반복 훈련**하고, 코딩테스트 단골인 괄호 생성·N-Queen·부분집합 분할·연산자 끼워넣기·격자 경로·미니 스도쿠로 **확장**하는 연습 세트다. 모든 문제는 `itertools` 없이 재귀로 직접 짜는 것을 기본으로 한다.

- **반복 훈련 개념**
- K^N 틀 + 국소 제약: depth번째 칸에 후보를 놓되 직전 값과의 관계로 걸러 내기 — `for v in range(1, K+1): if 위반(prev, v): continue; rec(depth+1, v)`
- 누적 제약·상한 가지치기: 합/비용이 이미 넘었거나, 남은 걸 다 더해도 최선을 못 넘으면 진입 전에 자르기 — `if cur + rest[idx] <= best: return`
- 부분집합(고른다/안 고른다) 이분 재귀: 원소마다 두 갈래로 내려가 2^N 경우를 만든다 — `rec(i+1, s+a[i]); rec(i+1, s)`
- 순열 `used[]` + 복원: 쓴 원소를 표시하고 돌아올 때 반드시 되돌리기 — `used[i] = True; rec(d+1); used[i] = False`
- 격자·판 위의 되돌리기: 방문 표시나 놓은 값을 재귀 뒤에 원상복구해야 다음 가지가 깨끗하다 — `visited[nr][nc] = True; rec(nr, nc); visited[nr][nc] = False`

- **코딩테스트 출제 맵**: 이 챕터 유형은 백준 「단계별로 풀어보기」의 '백트래킹' 단계(N과 M 시리즈·N-Queen·스도쿠·연산자 끼워넣기 류), NeetCode 150의 'Backtracking'(Subsets·Permutations·Generate Parentheses·N-Queens 류), 삼성 SW 역량테스트의 '백트래킹' 유형(팀 나누기·연산자 배치 류)에 그대로 등장한다. 아래 유형 확장 문제는 그 대표 유형을 소재·수치·조건을 새로 만들어 이 챕터 수준으로 재구성한 것이다.

**문제**

**1) 홀짝 교대 수열 개수** · Easy

- **요구사항**: 1부터 K까지의 정수 중 하나를 N번 골라 길이 N인 수열을 만든다. 단, 인접한 두 항의 홀짝(짝수/홀수)이 서로 **달라야** 한다. 조건을 만족하는 수열의 개수를 구하라.
- **입력**: 한 줄에 K N (1 ≤ K ≤ 9, 1 ≤ N ≤ 8).
- **출력**: 조건을 만족하는 수열의 개수.
- **예제**: `3 2` → `4` · `1 3` → `0` · `4 1` → `4`
- **셀프체크**: 첫 항은 제약이 없으므로 초기 `prev_parity`를 0도 1도 아닌 값(예: -1)으로 넘겼는가? `3 2`는 (홀, 짝) 2×1개 + (짝, 홀) 1×2개 = 4. K=1이면 홀수뿐이라 N ≥ 2에서 0. 검산 공식: 홀수 개수 o, 짝수 개수 e일 때 N=4면 o·e·o·e + e·o·e·o = 2·o²·e²(`4 4` → 2·4·4 = 32).

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.read().split()
    K = int(data[0]); N = int(data[1])
    count = 0
    def rec(depth, prev_parity):
        nonlocal count
        if depth == N:
            count += 1
            return
        for v in range(1, K + 1):
            if v % 2 == prev_parity:      # 직전 항과 홀짝이 같으면 금지
                continue
            rec(depth + 1, v % 2)
    rec(0, -1)                            # -1: 첫 항은 제약 없음
    print(count)
main()

@@EXPL
(1) 접근·핵심 아이디어

- "K개 중 하나를 N번" 틀에 국소 제약(직전 항과의 관계)이 붙은 형태다. 직전 항의 홀짝 `prev_parity`를 인자로 넘기면 판정이 O(1)이고 복원이 필요 없다.
- 제약 위반 후보는 재귀에 들어가기 전에 `continue`로 자른다. 그 가지가 만들 K^(남은 깊이)개의 경우가 통째로 사라진다.

(2) 코드 단계별

- `rec(depth, prev_parity)`: `depth == N`이면 수열 하나 완성 → 카운트.
- 후보 `v`를 1..K로 돌며 `v % 2 == prev_parity`면 건너뛰고, 아니면 `rec(depth+1, v % 2)`로 내려간다.
- 첫 호출은 `prev_parity = -1`로 두어 첫 항이 무엇이든 통과하게 한다.

(3) 스스로 다시 짤 때 생각 순서

- 제약 문장("인접 홀짝이 다르다")을 상태 인자 하나(`prev_parity`)로 번역한다.
- 초기값은 어떤 후보와도 충돌하지 않는 값이어야 한다. 0으로 두면 첫 항에서 짝수가 잘못 금지된다.
- 작은 K, N으로 곱셈 공식과 대조해 검산한다(`3 2` → 4, `4 4` → 32).
```

**2) 합이 S인 부분집합 개수** · Easy

- **요구사항**: 정수 N개가 주어진다. 이 중 하나 이상을 골라 만든 부분집합(공집합 제외) 중 원소 합이 정확히 S인 것의 개수를 구하라. 같은 값이 여러 개 있어도 위치가 다르면 다른 원소로 본다.
- **입력**: 첫 줄 N S (1 ≤ N ≤ 15, −100 ≤ S ≤ 100), 둘째 줄 N개의 정수(−20 ≤ 값 ≤ 20).
- **출력**: 부분집합의 개수.
- **예제**: `3 3 / 1 2 3` → `2` · `2 0 / 5 -5` → `1` · `1 4 / 2` → `0`
- **셀프체크**: 음수가 있으므로 "합이 S를 넘으면 중단" 같은 가지치기는 쓸 수 없다(이후 음수로 다시 내려올 수 있음). 공집합을 빼려면 고른 개수를 함께 넘겨 `picked > 0`을 확인해야 한다 — S=0일 때 특히 중요(`4 0 / 0 0 0 0`은 공집합을 뺀 2⁴−1 = 15).

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.read().split()
    N = int(data[0]); S = int(data[1])
    arr = [int(data[2 + i]) for i in range(N)]
    count = 0
    def rec(idx, cur_sum, picked):
        nonlocal count
        if idx == N:
            if picked > 0 and cur_sum == S:
                count += 1
            return
        rec(idx + 1, cur_sum + arr[idx], picked + 1)   # idx번째를 고른다
        rec(idx + 1, cur_sum, picked)                  # 고르지 않는다
    rec(0, 0, 0)
    print(count)
main()

(1) 접근·핵심 아이디어

- 원소마다 "고른다/안 고른다" 두 갈래로 내려가는 이분 재귀로 2^N개의 부분집합을 모두 만든다. N ≤ 15이면 32,768개라 충분하다.
- 합 `cur_sum`과 고른 개수 `picked`를 인자로 넘기므로 복원이 필요 없다. 공집합 제외 조건은 `picked > 0`으로 처리한다.

(2) 코드 단계별

- `rec(idx, cur_sum, picked)`: `idx == N`이면 모든 원소의 선택이 끝난 것 → `picked > 0`이고 `cur_sum == S`일 때만 카운트.
- 아니면 `arr[idx]`를 더한 갈래와 더하지 않은 갈래로 각각 내려간다.
- 처음 호출은 `rec(0, 0, 0)`.

(3) 스스로 다시 짤 때 생각 순서

- "부분집합 = 각 원소에 대한 포함 여부"로 보고 두 갈래 재귀를 떠올린다. `start` 루프 방식보다 이 문제에선 이쪽이 단순하다.
- 음수 원소가 있으면 합 기반 가지치기를 함부로 넣지 않는다(정답이 줄어든다).
- S=0에 공집합이 섞이지 않도록 개수 조건을 넣고, 전부 0인 입력(15)으로 검산한다.
```

**3) 문자 M-순열 사전순 출력** · Easy

- **요구사항**: 서로 다른 소문자 N개가 **정렬되지 않은** 순서로 주어진다. 이 중 M개를 골라 순서 있게 나열해 만든 길이 M의 문자열을 모두 사전순으로 한 줄에 하나씩 출력하라.
- **입력**: 첫 줄 N M (1 ≤ M ≤ N ≤ 6), 둘째 줄 서로 다른 소문자 N개(공백 구분).
- **출력**: 가능한 문자열 전부, 사전순으로 한 줄에 하나씩(총 P(N, M) = N!/(N−M)!줄).
- **예제**: `3 2 / c a b` → `ab / ac / ba / bc / ca / cb` · `2 2 / b a` → `ab / ba` · `1 1 / q` → `q`
- **셀프체크**: 후보를 오름차순으로 순회해야 출력이 사전순이 되는데 입력이 정렬되어 있지 않으므로 **먼저 정렬**했는가? `used[]` 복원과 `cur.pop()`을 짝지었는가? 총 줄 수가 P(N, M)인지 확인(`3 2` → 6줄, `3 1 / z y x` → `x / y / z`).

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.read().split()
    N = int(data[0]); M = int(data[1])
    letters = sorted(data[2:2 + N])       # 사전순 출력을 위해 먼저 정렬
    used = [False] * N
    cur = []
    out = []
    def rec(depth):
        if depth == M:
            out.append(''.join(cur))
            return
        for i in range(N):
            if used[i]:
                continue
            used[i] = True
            cur.append(letters[i])
            rec(depth + 1)
            cur.pop()
            used[i] = False
    rec(0)
    print('\n'.join(out))
main()

(1) 접근·핵심 아이디어

- 순서가 결과를 바꾸므로 순열 틀이다: 매 depth에서 아직 안 쓴 원소를 모두 후보로 삼고 `used[]`로 관리한다. M개만 뽑으므로 종료 조건은 `depth == M`.
- 사전순은 "후보를 오름차순으로 순회"하면 자동으로 보장되지만, 입력이 정렬되어 있지 않으므로 `sorted`를 먼저 적용하는 것이 이 문제의 함정이다.

(2) 코드 단계별

- 문자 목록을 `sorted`로 정렬해 `letters`에 둔다. `used`, 현재 경로 `cur`, 결과 `out`을 준비한다.
- `rec(depth)`: `depth == M`이면 `cur`를 이어 붙여 결과에 추가. 아니면 0..N-1을 돌며 안 쓴 원소를 표시 → `cur`에 추가 → 재귀 → `pop` → 표시 해제.
- 끝에 결과를 개행으로 이어 한 번에 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- 조합/순열 판별: 같은 문자 집합도 순서가 다르면 다른 결과이므로 순열 → `used[]`.
- 사전순 출력이 요구되면 "입력 정렬 여부"를 먼저 확인한다. 정렬 없이 돌리면 `c a b` 입력에서 `ca`가 먼저 나온다.
- `M < N`이면 종료 조건을 `depth == M`으로 두고, 총 줄 수 P(N, M)으로 검산한다.
```

**4) 올바른 괄호 문자열 생성** · Medium

- **요구사항**: 여는 괄호 `(`와 닫는 괄호 `)`를 각각 n개씩 써서 만들 수 있는 **올바른** 괄호 문자열(어느 접두사에서도 닫는 괄호 수가 여는 괄호 수를 넘지 않는 문자열)을 모두 사전순으로 출력하라. `(`가 `)`보다 앞선다.
- **입력**: 정수 n (1 ≤ n ≤ 6).
- **출력**: 올바른 괄호 문자열 전부, 사전순으로 한 줄에 하나씩.
- **예제**: `2` → `(()) / ()()` · `1` → `()` · `3` → `((())) / (()()) / (())() / ()(()) / ()()()`
- **셀프체크**: 상태를 (지금까지 쓴 `(` 수, `)` 수)로 두면 조건은 두 줄이다: `(`는 n개 미만일 때, `)`는 열린 것보다 적을 때만 붙인다. 이 두 조건이 곧 가지치기이므로 완성된 문자열을 따로 검사할 필요가 없다. 총 줄 수는 카탈란 수(1, 2, 5, 14, 42, 132)다. `(`를 먼저 시도해야 사전순이 된다.

```runner
@@SOLUTION
import sys
def main():
    n = int(sys.stdin.read().split()[0])
    out = []
    cur = []
    def rec(opened, closed):
        if opened == n and closed == n:
            out.append(''.join(cur))
            return
        if opened < n:                    # '('는 n개까지
            cur.append('(')
            rec(opened + 1, closed)
            cur.pop()
        if closed < opened:               # ')'는 열린 것보다 적을 때만
            cur.append(')')
            rec(opened, closed + 1)
            cur.pop()
    rec(0, 0)
    print('\n'.join(out))
main()

(1) 접근·핵심 아이디어

- 길이 2n의 각 자리에 `(` 또는 `)`를 놓는 K=2, N=2n 틀이지만, "올바름" 조건을 진입 전 가지치기로 걸면 잘못된 문자열은 아예 만들어지지 않는다.
- 상태는 `(opened, closed)` 두 개면 충분하다. `(`는 `opened < n`일 때, `)`는 `closed < opened`일 때만 붙일 수 있다. 후자가 "접두사에서 닫는 괄호가 앞서지 않음"을 정확히 표현한다.

(2) 코드 단계별

- `rec(opened, closed)`: 둘 다 n이면 완성 → `cur`를 이어 결과에 추가.
- `opened < n`이면 `(`를 붙이고 재귀한 뒤 `pop`. 그다음 `closed < opened`이면 `)`를 붙이고 재귀한 뒤 `pop`.
- `(` 갈래를 `)` 갈래보다 먼저 시도하므로 결과가 사전순으로 쌓인다.

(3) 스스로 다시 짤 때 생각 순서

- "완성 후 검사"가 아니라 "붙일 수 있는 조건"을 상태로 표현한다. 검사 방식은 2^(2n)개를 다 만들고 버리므로 낭비다.
- `)` 조건을 `closed < n`으로 잘못 쓰면 `)(` 같은 문자열이 나온다. 반드시 `closed < opened`.
- 총 개수를 카탈란 수와 대조해 검산한다(n=3 → 5).
```

**5) 두 상자 무게 차 최소** · Medium

- **요구사항**: 돌 N개의 무게가 주어진다. 모든 돌을 두 상자 A, B에 나누어 담을 때(한 상자가 비어도 됨), 두 상자 무게 합의 차이의 최솟값을 구하라.
- **입력**: 첫 줄 N (1 ≤ N ≤ 16), 둘째 줄 N개의 무게(1 ≤ 무게 ≤ 100).
- **출력**: 가능한 최소 차이.
- **예제**: `4 / 3 1 4 2` → `0` · `3 / 1 2 10` → `7` · `1 / 5` → `5`
- **셀프체크**: 돌마다 A/B 두 갈래이므로 2^N. 가지치기: 지금까지의 차 `|a − b|`에서 남은 돌을 전부 가벼운 쪽에 넣어도 최대 `남은 무게 합`만큼만 줄일 수 있으므로, `|a − b| − rest >= best`면 더 볼 필요가 없다. 남은 무게 합은 뒤에서부터 누적한 배열로 O(1)에 얻는다. `6 / 7 7 7 7 7 8`은 21 대 22로 `1`.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.read().split()
    N = int(data[0])
    w = [int(data[1 + i]) for i in range(N)]
    total = sum(w)
    rest = [0] * (N + 1)                  # rest[i] = i번째부터 끝까지 무게 합
    for i in range(N - 1, -1, -1):
        rest[i] = rest[i + 1] + w[i]
    best = total
    def rec(idx, a):                      # a: 지금까지 상자 A에 담은 무게
        nonlocal best
        b = total - rest[idx] - a         # 지금까지 상자 B에 담은 무게
        if abs(a - b) - rest[idx] >= best:   # 남은 돌을 다 써도 best를 못 깨면 중단
            return
        if idx == N:
            best = abs(a - b)
            return
        rec(idx + 1, a + w[idx])          # A에 담기
        rec(idx + 1, a)                   # B에 담기
    rec(0, 0)
    print(best)
main()

(1) 접근·핵심 아이디어

- 각 돌을 A 또는 B에 넣는 두 갈래 재귀로 모든 분할을 만들고, 완성 시 `|a − b|`로 최선을 갱신한다. 상태는 A의 무게 `a`만 들고, B는 `(지금까지 배정한 총 무게) − a`로 계산한다.
- 상한 가지치기: 남은 돌 무게 합 `rest[idx]`를 전부 가벼운 쪽에 넣어도 차이는 `|a − b| − rest[idx]` 아래로 못 내려간다. 이 값이 이미 `best` 이상이면 그 가지는 최선을 갱신할 수 없다.

(2) 코드 단계별

- `rest`를 뒤에서부터 누적해 두면 `total − rest[idx]`가 "지금까지 배정한 무게"가 된다.
- `rec(idx, a)`: 먼저 가지치기 조건을 검사한다. `idx == N`이면 분할 완성 → 가지치기를 통과했으므로 `abs(a − b)`가 반드시 `best`보다 작다 → 갱신.
- 아니면 `w[idx]`를 A에 넣는 갈래, B에 넣는(= a 그대로) 갈래로 내려간다.

(3) 스스로 다시 짤 때 생각 순서

- "두 그룹으로 나눈다"는 곧 "각 원소의 소속을 정한다"이므로 이분 재귀. 그룹 크기 제한이 없으면 `start` 루프보다 이 방식이 자연스럽다.
- 가지치기 부등식은 "남은 것을 다 써서 얻을 수 있는 최선"을 먼저 계산한 뒤 `>= best`로 자른다. 등호를 빼면 같은 값을 재탐색해 느려질 뿐 답은 같다.
- N=1(한 상자만 채움 → 그 무게)과 총합이 짝수로 딱 나뉘는 예제(0)로 검산한다.
```

**6) 금지 칸이 있는 N-Queen** · Medium

- **요구사항**: N×N 체스판에 퀸 N개를 서로 공격하지 않게(같은 행·열·대각선에 둘 이상 없음) 놓는다. 단, `#`로 표시된 칸에는 퀸을 놓을 수 없다. 가능한 배치의 수를 구하라.
- **입력**: 첫 줄 N (1 ≤ N ≤ 8). 이어 N줄에 길이 N의 문자열(`.` 허용, `#` 금지).
- **출력**: 배치의 수.
- **예제**: `4 / .... / .... / .... / ....` → `2` · `4 / .#.. / .... / .... / ....` → `1` · `1 / #` → `0`
- **셀프체크**: 행마다 퀸 하나를 놓으므로 depth = 행. 열은 `col[c]`, ↘ 대각선은 `r − c + N`, ↙ 대각선은 `r + c`로 인덱싱해 boolean 배열 세 개로 O(1) 판정. 놓은 뒤 재귀, 돌아와서 **세 배열 모두** 복원했는가? 금지 칸은 후보 루프에서 `continue`로 거르면 된다. 4×4 기본 해는 2개인데 (0,1)을 금지하면 그 칸을 쓰는 해가 사라져 1개, 5×5는 10개.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.read().split()
    N = int(data[0])
    g = data[1:1 + N]
    col = [False] * N
    d1 = [False] * (2 * N)       # r + c 대각선
    d2 = [False] * (2 * N)       # r - c + N 대각선
    count = 0
    def rec(r):
        nonlocal count
        if r == N:
            count += 1
            return
        for c in range(N):
            if g[r][c] == '#' or col[c] or d1[r + c] or d2[r - c + N]:
                continue
            col[c] = d1[r + c] = d2[r - c + N] = True
            rec(r + 1)
            col[c] = d1[r + c] = d2[r - c + N] = False
    rec(0)
    print(count)
main()

(1) 접근·핵심 아이디어

- N-Queen은 "행마다 열 하나를 고르는 순열"에 대각선 제약을 더한 문제다. 각 행에서 후보 열 N개를 시도하되, 열·두 대각선 중 하나라도 이미 사용 중이면 진입 전에 자른다.
- 대각선은 인덱스 하나로 식별된다: ↙ 방향은 `r + c`가 같고, ↘ 방향은 `r − c`가 같다(음수를 피하려 `+ N`). 금지 칸은 후보 필터 하나만 추가하면 된다.

(2) 코드 단계별

- `col`, `d1`(r+c), `d2`(r−c+N) boolean 배열을 두고 `rec(r)`을 호출한다. `r == N`이면 N개를 모두 놓은 것 → 카운트.
- 열 `c`를 0..N−1로 돌며 금지 칸이거나 세 배열 중 하나라도 `True`면 `continue`. 통과하면 세 배열을 `True`로 표시하고 `rec(r+1)`, 돌아와서 `False`로 복원한다.

(3) 스스로 다시 짤 때 생각 순서

- 상태를 "행 = depth"로 잡으면 같은 행 충돌은 자동으로 없다. 남은 제약(열·대각선)을 O(1) 배열로 만든다.
- 복원은 표시한 세 배열 전부에 대해 한다. 하나라도 빠지면 이후 가지에서 유령 퀸이 남아 답이 급감한다.
- 금지 칸 없는 4×4(2), 5×5(10)로 기본 로직을, 금지 칸 예제로 필터를 검산한다.
```

**7) 연산자 끼워넣기로 목표 만들기** · Medium

- **요구사항**: 정수 N개가 순서대로 주어진다. 인접한 두 수 사이의 N−1곳마다 `+`, `-`, `*` 중 하나를 넣어 식을 만들고, 연산자 우선순위를 무시하고 **왼쪽부터 차례로** 계산한다. 결과가 정확히 T가 되는 식의 개수를 구하라. N=1이면 연산자 없이 그 수 자체가 결과다.
- **입력**: 첫 줄 N T (1 ≤ N ≤ 10, −10⁶ ≤ T ≤ 10⁶), 둘째 줄 N개의 정수(1 ≤ 값 ≤ 9).
- **출력**: 결과가 T인 식의 개수.
- **예제**: `3 6 / 1 2 3` → `2` · `2 5 / 2 3` → `1` · `1 4 / 4` → `1`
- **셀프체크**: `1 2 3`으로 만드는 9개 식의 값은 6, 0, 9, 2, −4, −3, 5, −1, 6이며, `1+2+3`과 `1*2*3`만 6이다("왼쪽부터 계산"이므로 `1+2*3`은 9). 첫 수를 시작값으로 두고 `idx = 1`부터 연산자를 고르는 구조인가? 값이 음수가 될 수 있으므로 T 기준 가지치기는 하지 않는다. `1 3 / 4`는 `0`, `4 0 / 1 1 1 1`은 `6`.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.read().split()
    N = int(data[0]); T = int(data[1])
    nums = [int(data[2 + i]) for i in range(N)]
    count = 0
    def rec(idx, value):
        nonlocal count
        if idx == N:
            if value == T:
                count += 1
            return
        rec(idx + 1, value + nums[idx])
        rec(idx + 1, value - nums[idx])
        rec(idx + 1, value * nums[idx])
    rec(1, nums[0])                    # 첫 수를 시작값으로, 두 번째 수부터 연산자 선택
    print(count)
main()

(1) 접근·핵심 아이디어

- N−1개의 자리마다 3개 후보를 고르는 K=3, N−1칸의 K^N 틀이다. 왼쪽부터 계산하므로 "지금까지의 값"만 인자로 넘기면 다음 연산 결과를 바로 구할 수 있다.
- 3^9 = 19,683가지라 완전탐색으로 충분하다. 곱셈과 뺄셈 때문에 값이 오르내리므로 T와의 비교로 중간에 자르지 않는다.

(2) 코드 단계별

- `rec(idx, value)`: `idx == N`이면 식이 완성된 것 → `value == T`면 카운트.
- 아니면 `nums[idx]`에 대해 `+`, `-`, `*` 세 갈래로 `rec(idx+1, 새 값)`을 호출한다.
- 시작은 `rec(1, nums[0])`. N=1이면 곧바로 종료 조건에 걸려 첫 수와 T를 비교한다.

(3) 스스로 다시 짤 때 생각 순서

- "연산자 자리 = depth, 후보 = 세 연산자"로 매핑하고, 누적 상태(현재 값)를 인자로 넘겨 복원 부담을 없앤다.
- 우선순위 무시 규칙을 코드가 자연히 지키는지(왼쪽부터 접기) 확인한다. 식을 문자열로 만들어 `eval`하면 우선순위가 적용되어 틀린다.
- N=1(연산자 없음)과 답이 0인 입력으로 종료 조건을 검산한다.
```

**8) 장애물 격자의 경로 수** · Medium

- **요구사항**: R×C 격자(`.` 빈칸, `#` 장애물)에서 `(0, 0)`을 출발해 `(R−1, C−1)`에 도착하는 경로의 수를 구하라. 상하좌우로 한 칸씩 움직이고, 한 경로 안에서 같은 칸을 두 번 지날 수 없다. 출발 칸이나 도착 칸이 장애물이면 0이다.
- **입력**: 첫 줄 R C (1 ≤ R, C ≤ 5). 이어 R줄에 길이 C의 문자열.
- **출력**: 경로의 수.
- **예제**: `2 2 / .. / ..` → `2` · `3 3 / ... / .#. / ...` → `2` · `2 3 / ... / ...` → `4`
- **셀프체크**: 오른쪽·아래로만 가는 경로 수(격자 DP)가 아니라 **4방향 + 재방문 금지**이므로 되돌아가는 경로(`2 3`에서 아래→오른쪽→위→오른쪽→아래)도 센다. 이동 전 `visited` 표시, 재귀 후 해제를 짝지었는가? 출발 칸을 미리 방문 처리했는가? `1 1 / .`은 출발이 곧 도착이라 `1`, `2 2 / .# / #.`은 `0`. 5×5 빈 격자는 8,512개.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.read().split()
    R = int(data[0]); C = int(data[1])
    g = data[2:2 + R]
    if g[0][0] == '#' or g[R - 1][C - 1] == '#':
        print(0)
        return
    visited = [[False] * C for _ in range(R)]
    dirs = [(-1, 0), (1, 0), (0, -1), (0, 1)]
    count = 0
    def rec(r, c):
        nonlocal count
        if r == R - 1 and c == C - 1:
            count += 1
            return
        for dr, dc in dirs:
            nr, nc = r + dr, c + dc
            if 0 <= nr < R and 0 <= nc < C and g[nr][nc] == '.' and not visited[nr][nc]:
                visited[nr][nc] = True
                rec(nr, nc)
                visited[nr][nc] = False      # 되돌리기
    visited[0][0] = True
    rec(0, 0)
    print(count)
main()

- 재방문 금지 때문에 경로는 유한하고 5×5 정도면 전수 나열이 가능하다(빈 5×5에서 8,512개). 이보다 커지면 폭발하므로 입력 제한이 작다.

(2) 코드 단계별

- 출발·도착이 장애물이면 바로 0을 출력한다. `visited`를 만들고 출발 칸을 `True`로 둔다.
- `rec(r, c)`: 도착이면 카운트. 아니면 4방향 이웃 중 격자 안·빈칸·미방문인 칸에 대해 `visited = True` → `rec` → `visited = False`.
- 처음 호출은 `rec(0, 0)`.

(3) 스스로 다시 짤 때 생각 순서

- "경로 = 방문 순서"이므로 상태는 현재 위치 + 방문 격자. 방문 격자는 재귀에서 되돌려야 다른 경로가 같은 칸을 쓸 수 있다.
- 출발 칸의 방문 처리를 잊으면 출발점으로 되돌아오는 경로가 생겨 답이 커진다.
- 1×1(출발 = 도착 → 1)과 막힌 격자(0)로 종료 조건을 검산한다.
```

**9) 4×4 미니 스도쿠** · Hard

- **요구사항**: 4×4 판의 각 행, 각 열, 그리고 네 개의 2×2 상자에 1~4가 정확히 한 번씩 들어가야 한다. 일부 칸이 비어 있는(0) 판이 주어지면 규칙에 맞게 채운 판을 출력하라. 해는 유일함이 보장된다.
- **입력**: 4줄에 각 줄 4개의 정수(0은 빈칸, 1~4는 확정된 값).
- **출력**: 완성된 판 4줄.
- **예제**: `1 2 3 4 / 0 0 0 0 / 0 0 0 0 / 4 0 0 1` → `1 2 3 4 / 3 4 1 2 / 2 1 4 3 / 4 3 2 1` · `2 0 0 0 / 0 0 3 0 / 4 0 0 0 / 0 0 1 0` → `2 3 4 1 / 1 4 3 2 / 4 1 2 3 / 3 2 1 4`
- **셀프체크**: 칸을 0..15 번호로 일렬 순회하며, 확정 칸은 건너뛰고 빈칸에서만 1~4를 시도한다. 상자의 좌상단은 `(r//2*2, c//2*2)`. 해를 찾으면 `True`를 위로 전파해 즉시 멈추고, 실패하면 값을 0으로 되돌린 뒤 `False`를 반환하는 구조인가? 빈칸이 없는 판(`1 2 3 4 / 3 4 1 2 / 2 1 4 3 / 4 3 2 1`)은 그대로 출력된다.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.read().split()
    g = [[int(data[4 * r + c]) for c in range(4)] for r in range(4)]
    def ok(r, c, v):
        for k in range(4):
            if g[r][k] == v or g[k][c] == v:

        for i in range(br, br + 2):
            for j in range(bc, bc + 2):
                if g[i][j] == v:
                    return False
        return True
    def rec(pos):
        if pos == 16:
            return True
        r, c = pos // 4, pos % 4
        if g[r][c] != 0:
            return rec(pos + 1)
        for v in range(1, 5):
            if ok(r, c, v):
                g[r][c] = v
                if rec(pos + 1):
                    return True
                g[r][c] = 0                  # 되돌리기
        return False
    rec(0)
    print('\n'.join(' '.join(map(str, row)) for row in g))
```

**10) 무게 제한 가방의 최대 가치** · Hard

- **요구사항**: 물건 N개가 각각 무게와 가치를 가진다. 무게 합이 W 이하가 되도록 물건의 부분집합을 골라 가치 합을 최대로 하라(아무것도 안 넣으면 0).
- **입력**: 첫 줄 N W (1 ≤ N ≤ 15, 1 ≤ W ≤ 100). 이어 N줄에 `무게 가치`(1 ≤ 무게 ≤ 100, 1 ≤ 가치 ≤ 100).
- **출력**: 최대 가치 합.
- **예제**: `3 5 / 2 3 / 3 4 / 4 5` → `7` · `2 1 / 2 5 / 3 6` → `0` · `1 10 / 10 100` → `100`
- **셀프체크**: 두 가지 가지치기를 모두 넣었는가? (a) 무게 초과 갈래는 시도하지 않음, (b) 상한: 현재 가치 + 남은 물건 가치 합(`rest[idx]`)이 `best` 이하면 중단. `rest`는 뒤에서부터 누적한다. 첫 예제는 (2,3)+(3,4)=무게 5, 가치 7이 최대이고 `5 10 / 5 10 / 4 40 / 6 30 / 3 50 / 2 5`는 무게 4+3+2 = 9로 가치 95.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.read().split()
    N = int(data[0]); W = int(data[1])
    items = []
    for i in range(N):
        items.append((int(data[2 + 2 * i]), int(data[3 + 2 * i])))
    rest = [0] * (N + 1)                  # rest[i] = i번째 이후 물건 가치 합
    for i in range(N - 1, -1, -1):
        rest[i] = rest[i + 1] + items[i][1]
    best = 0
    def rec(idx, weight, value):
        nonlocal best
        if value > best:
            best = value
        if idx == N:
            return
        if value + rest[idx] <= best:     # 남은 걸 다 넣어도 best를 못 넘으면 중단
            return
        w, v = items[idx]
        if weight + w <= W:               # 넣는다(무게 초과면 시도조차 안 함)
            rec(idx + 1, weight + w, value + v)
        rec(idx + 1, weight, value)       # 안 넣는다
    rec(0, 0, 0)
    print(best)
main()

- 상한 가지치기(bound): 현재 가치에 남은 물건의 가치를 **전부** 더해도 `best`를 못 넘으면, 그 가지에서는 무엇을 해도 최선을 갱신할 수 없다.

(2) 코드 단계별

- `rest[i]`를 뒤에서부터 누적해 "i번째부터 끝까지 가치 합"을 O(1)로 얻는다.
- `rec(idx, weight, value)`: 들어올 때마다 `best`를 갱신한다(부분 선택 상태도 유효한 답이므로). `idx == N`이면 끝.
- `value + rest[idx] <= best`면 중단. 아니면 무게가 허용될 때만 "넣는다" 갈래로, 항상 "안 넣는다" 갈래로 내려간다.

(3) 스스로 다시 짤 때 생각 순서

- 제약 두 종류를 구분해 배치한다: 무게는 "후보 단위 필터"(넣는 갈래만 검사), 상한은 "경로 단위 컷"(진입 직후 검사).
- `best` 갱신을 종료 조건에서만 하면 "물건을 더 넣을 수 없어 중간에 멈춘 경로"가 누락되지 않는지 확인한다. 여기선 안 넣는 갈래가 항상 끝까지 가므로 종료 시 갱신만으로도 되지만, 진입 시 갱신이 더 안전하고 가지치기도 빨라진다.
- 아무것도 못 넣는 입력(0)과 하나만 넣는 입력으로 경계를 검산한다.
```

**11) 인접 차 제한 순열** · Hard

- **요구사항**: 1부터 N까지의 순열 중 인접한 두 수의 차의 절댓값이 모두 D 이하인 순열을 생각한다. 그런 순열의 개수와, 그중 사전순으로 가장 앞선 순열을 출력하라. 하나도 없으면 개수 0과 `NONE`을 출력한다.
- **입력**: 한 줄에 N D (1 ≤ N ≤ 8, 0 ≤ D ≤ 7).
- **출력**: 첫 줄에 개수, 둘째 줄에 사전순 첫 순열(공백 구분) 또는 `NONE`.
- **예제**: `3 1` → `2 / 1 2 3` · `4 2` → `12 / 1 2 3 4` · `3 0` → `0 / NONE`
- **셀프체크**: 후보를 1부터 오름차순으로 시도하면 처음 완성되는 순열이 곧 사전순 첫 순열이다 — 이때 `perm[:]`로 **복사본**을 저장했는가(참조를 저장하면 이후 `pop`으로 비어 버린다)? 인접 제약은 `perm`이 비어 있지 않을 때만 검사한다. `1 0`은 순열이 하나뿐이라 `1 / 1`, `5 1`은 오름차순·내림차순 둘뿐이라 `2 / 1 2 3 4 5`.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.read().split()
    N = int(data[0]); D = int(data[1])
    used = [False] * (N + 1)
    perm = []
    count = 0
    first = None
    def rec(depth):
        nonlocal count, first
        if depth == N:
            count += 1
            if first is None:
                first = perm[:]           # 복사본 저장
            return
        for v in range(1, N + 1):
            if used[v]:
                continue
            if perm and abs(perm[-1] - v) > D:   # 인접 차 제한
                continue
            used[v] = True
            perm.append(v)
            rec(depth + 1)
            perm.pop()
            used[v] = False
    rec(0)
    print(count)
    if first is None:
        print('NONE')
    else:
        print(' '.join(map(str, first)))
main()

- 순열 틀(`used[]`)에 국소 제약 "직전 원소와의 차 ≤ D"를 진입 전 가지치기로 붙였다. 직전 원소는 `perm[-1]`로 바로 읽을 수 있어 별도 인자가 필요 없다.
- 후보를 오름차순으로 순회하므로 완성 순서가 사전순이다. 따라서 "처음 완성된 순열"을 한 번만 기록하면 사전순 첫 순열이 된다.

(2) 코드 단계별

- `rec(depth)`: `depth == N`이면 카운트하고, `first`가 비어 있으면 `perm[:]`를 저장한다.
- 후보 `v`를 1..N으로 돌며 이미 쓴 값, 또는 `perm`이 비어 있지 않고 `|perm[-1] − v| > D`인 값은 건너뛴다. 통과하면 표시 → `append` → 재귀 → `pop` → 복원.
- 끝에 개수와 `first`(없으면 `NONE`)를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- 결과 저장은 반드시 복사본(`perm[:]`). 참조를 저장하면 백트래킹이 진행되며 내용이 바뀐다.
- D=0(N ≥ 2면 불가능 → NONE)과 N=1(항상 1개)로 경계를 검산하고, D가 크면 N!과 같아지는지 확인한다.
```

**12) 급식 메뉴 짜기** · Hard

- **요구사항**: N일 동안 매일 K종의 메뉴 중 하나를 정한다. 메뉴 i는 비용 `c_i`와 만족도 `s_i`를 가진다. 제약: (a) 같은 메뉴를 이틀 연속 내지 않는다, (b) 각 메뉴는 전체 기간에 최대 L번까지만 낸다, (c) 총 비용은 B 이하여야 한다. 만족도 합의 최댓값을 구하고, 가능한 일정이 없으면 -1을 출력하라.
- **입력**: 첫 줄 N K L B (1 ≤ N ≤ 8, 1 ≤ K ≤ 5, 1 ≤ L ≤ N, 1 ≤ B ≤ 1000). 이어 K줄에 `c_i s_i`(1 ≤ c_i, s_i ≤ 100).
- **출력**: 최대 만족도 합 또는 -1.
- **예제**: `3 2 2 100 / 10 5 / 20 8` → `21` · `3 2 2 45 / 10 5 / 20 8` → `18` · `2 1 1 100 / 10 5` → `-1`
- **셀프체크**: 첫 예제는 메뉴 2-1-2(비용 50, 만족 21)가 최대이고, 예산이 45로 줄면 1-2-1(비용 40, 만족 18)만 가능하다. 세 제약을 어디에 두었는가 — 연속 금지·횟수 제한은 후보 필터(`continue`), 비용 초과도 후보 필터, 그리고 상한 가지치기(`현재 만족 + 남은 일수 × 최대 만족도 <= best`)는 진입 직후. 메뉴 횟수 배열은 재귀 뒤에 되돌려야 한다. `1 1 1 5 / 10 5`는 비용 초과로 `-1`.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.read().split()
    N, K, L, B = int(data[0]), int(data[1]), int(data[2]), int(data[3])
    cost = []; sat = []
    for i in range(K):
        cost.append(int(data[4 + 2 * i])); sat.append(int(data[5 + 2 * i]))
    max_sat = max(sat)
    used = [0] * K                        # 메뉴별 사용 횟수
    best = -1
    def rec(day, prev, total_cost, total_sat):
        nonlocal best
        if total_sat + (N - day) * max_sat <= best:   # 상한 가지치기
            return
        if day == N:
            best = total_sat
            return
        for m in range(K):
            if m == prev or used[m] == L:             # 연속 금지 · 횟수 제한
                continue
            if total_cost + cost[m] > B:              # 예산 초과
                continue
            used[m] += 1
            rec(day + 1, m, total_cost + cost[m], total_sat + sat[m])
            used[m] -= 1
    rec(0, -1, 0, 0)
    print(best)
main()

- 상태는 (날짜, 직전 메뉴, 누적 비용, 누적 만족도) + 메뉴별 사용 횟수 배열. 횟수 배열만 가변 상태이므로 재귀 뒤 복원한다.

(2) 코드 단계별

- `max_sat`(하루 최대 만족도)를 미리 구해 상한 계산에 쓴다. `best`는 -1로 시작해 일정이 하나도 완성되지 않으면 그대로 출력된다.
- `rec(day, prev, total_cost, total_sat)`: 진입 직후 `total_sat + (N − day) × max_sat <= best`면 중단. `day == N`이면 상한을 통과한 것이므로 곧바로 `best = total_sat`.
- 후보 메뉴 `m`을 돌며 직전과 같거나 횟수가 L에 도달했거나 예산을 넘으면 건너뛰고, 통과하면 `used[m] += 1` → 재귀 → `used[m] -= 1`.

(3) 스스로 다시 짤 때 생각 순서

- 제약 문장을 종류별로 분류한다: "연속 금지"는 `prev`, "최대 L번"은 횟수 배열, "예산"은 누적 비용, "최대화"는 상한 컷. 각각을 코드의 어느 위치(진입 직후 vs 후보 루프)에 둘지 정한다.
- 상한 컷의 등호(`<=`)는 "같은 값은 갱신이 아니므로 자른다"는 뜻이다. `day == N`에서 별도 비교 없이 대입해도 되는 이유가 이 컷 덕분임을 이해한다.
- K=1이고 N ≥ 2면 연속 금지 때문에 불가능(-1), 예산이 하루치보다 작아도 불가능(-1)임을 경계로 검산한다.
```
