## L2. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch3(DFS)의 핵심을 **반복 훈련**하고, 코딩테스트 단골 유형으로 **확장**하는 연습 세트다. 새 문법은 없다. 재귀 DFS·명시적 스택 DFS·`visited` 관리·인접리스트·4/8방향 오프셋만으로 10문제를 푼다.

- **반복 훈련 개념**
- 연결 요소 세기: 격자/그래프를 훑다가 미방문 시작점을 만날 때마다 `count += 1` 후 DFS — `if not visited[i][j]: count += 1; dfs(i, j)`
- 조건부 이동: 이웃으로 갈 수 있는지를 "범위 안 + 미방문 + 문제 조건"으로 한 줄에 검사 — `if 0 <= nr < N and 0 <= nc < M and not visited[nr][nc] and abs(h[nr][nc] - h[r][c]) <= D:`
- 트리 DFS 후위 누적: 자식 결과를 다 받은 뒤 자기 값을 확정하고 반환 — `total = 1; for nxt in adj[cur]: if nxt != parent: total += dfs(nxt, cur); return total`
- 경로 백트래킹: 한 경로를 다 본 뒤 방문 표시를 되돌려 다른 경로에서 다시 쓰게 함 — `visited[nxt] = True; dfs(nxt); visited[nxt] = False`
- 반복(스택) DFS: 재귀 깊이가 위험하면 `stack.pop()` 루프로 같은 순회를 흉내 — `stack = [(r, c)]; while stack: r, c = stack.pop(); ...`

- **코딩테스트 출제 맵**: 이 챕터의 유형은 백준 「단계별로 풀어보기」의 'DFS와 BFS' 단계(영역 세기·이분 그래프·위상 정렬의 DFS 풀이 류), NeetCode 150의 'Graphs'(Number of Islands·Max Area of Island·Pacific Atlantic Water Flow·Graph Valid Tree 류), 『이것이 취업을 위한 코딩테스트다』의 'DFS/BFS' 파트에 그대로 등장한다. 이 레슨의 유형 확장 문제는 그 대표 유형을 소재와 수치를 새로 만들어 재구성한 것이다.

**문제**

**1) 같은 색 구역의 개수** · Easy

- **요구사항**: `N×M` 격자의 각 칸에 색을 뜻하는 대문자가 하나씩 적혀 있다. 상하좌우로 인접하면서 같은 문자인 칸끼리는 같은 구역이다(대각선은 인접 아님). 구역이 모두 몇 개인지 출력하라.
- **입력**: 첫 줄에 `N M`. 다음 `N`줄에 각 `M`개의 대문자가 공백 없이 주어진다. (`1 ≤ N, M ≤ 20`)
- **출력**: 구역의 개수.
- **예제**: `3 4` / `AABB` / `ABBB` / `CCBA` → `4` · `2 2` / `AB` / `BA` → `4`
- **셀프체크**: 미방문 칸에서 DFS를 시작한 횟수가 답이다. "이웃이 같은 문자인가"를 검사할 때 시작 칸의 문자(`color`)와 비교해야지 현재 칸과 비교해도 결과는 같지만, 조건을 한 곳에 모아 두면 실수가 줄어든다. 첫 예제의 오른쪽 아래 `A`는 다른 `A`와 떨어져 있어 별도 구역이다. `1×1` 격자는 항상 `1`.

```runner
@@SOLUTION
import sys

def main():
    data = sys.stdin.read().split()
    N, M = int(data[0]), int(data[1])
    grid = data[2:2 + N]
    visited = [[False] * M for _ in range(N)]
    dr = (-1, 1, 0, 0)
    dc = (0, 0, -1, 1)

    def dfs(r, c, color):
        visited[r][c] = True
        for d in range(4):
            nr, nc = r + dr[d], c + dc[d]
            if 0 <= nr < N and 0 <= nc < M and not visited[nr][nc] and grid[nr][nc] == color:
                dfs(nr, nc, color)

    count = 0
    for i in range(N):
        for j in range(M):
            if not visited[i][j]:
                count += 1               # 새 구역 발견
                dfs(i, j, grid[i][j])
    print(count)

main()

(1) 접근·핵심 아이디어

- "같은 문자로 이어진 덩어리"는 연결 요소다. 격자를 위에서 아래, 왼쪽에서 오른쪽으로 훑다가 아직 방문하지 않은 칸을 만나면 그 칸이 새 구역의 첫 칸이므로 `count += 1` 하고, DFS로 그 구역 전체를 방문 처리한다.
- 0/1 격자의 섬 세기와 뼈대는 같지만, 이번엔 "땅인가"가 아니라 "시작 칸과 같은 문자인가"가 이동 조건이다. 조건이 바뀌어도 DFS 뼈대는 그대로라는 점이 반복 훈련의 목적이다.
- 대각선은 인접이 아니므로 두 번째 예제(`AB / BA`)는 네 칸이 전부 따로 구역이 된다.

(2) 코드 단계별

- 격자를 문자열 리스트로 두고(`grid[r][c]`로 문자 접근), `visited`를 같은 크기로 만든다.
- `dfs(r, c, color)`: 들어오자마자 방문 처리, 4방향 이웃이 범위 안·미방문·문자 `color`이면 재귀.
- 이중 for로 모든 칸을 보며 미방문이면 `count`를 올리고 `dfs(i, j, grid[i][j])` 호출. 최대 20×20이라 재귀 깊이는 400 이하로 안전하다.

(3) 스스로 다시 짤 때 생각 순서

- "구역 수 = DFS 시작 횟수"라는 연결 요소 공식을 먼저 떠올린다.
- 이동 조건을 문장으로 적는다: 범위 안, 미방문, 같은 문자.
- DFS 뼈대에 그 조건을 끼우고, 바깥 루프에서 시작 칸마다 카운트한다. 경계값(1×1, 전부 같은 문자)으로 검산한다.
```

**2) 조직도의 말단 직원과 결재 단계** · Easy

- **요구사항**: `N`명의 직원이 사장(1번)을 루트로 하는 트리 모양 조직도를 이룬다. 부하가 한 명도 없는 직원을 말단 직원이라 한다(직원이 1명뿐이면 사장이 말단). 말단 직원의 수와, 사장에서 가장 먼 직원까지의 결재 단계 수(사장은 0단계, 사장의 직속 부하는 1단계)를 출력하라.
- **입력**: 첫 줄에 `N`. 다음 `N-1`줄에 상하 관계인 두 직원 `a b`(누가 상사인지는 주어지지 않는다. 1-based). (`1 ≤ N ≤ 300`)
- **출력**: `말단 직원 수`와 `최대 결재 단계`를 공백으로 구분해 한 줄에.
- **예제**: `6` / `1 2` / `1 3` / `2 4` / `2 5` / `5 6` → `3 3` · `4` / `1 2` / `2 3` / `3 4` → `1 3`
- **셀프체크**: 간선에 방향이 없으므로 "부모로 되돌아가지 않기"만 하면 `visited` 배열 없이 트리를 순회할 수 있다(`nxt != parent`). 리프 판정은 "부모를 제외한 이웃이 0개". `N=1`이면 간선이 없고 답은 `1 0`.

```runner
@@SOLUTION
import sys

def main():
    data = sys.stdin.read().split()
    N = int(data[0])
    adj = [[] for _ in range(N + 1)]
    idx = 1
    for _ in range(N - 1):
        a, b = int(data[idx]), int(data[idx + 1])
        idx += 2
        adj[a].append(b)
        adj[b].append(a)

    leaf = 0
    deepest = 0

    def dfs(cur, parent, depth):
        nonlocal leaf, deepest
        if depth > deepest:
            deepest = depth
        child = 0
        for nxt in adj[cur]:
            if nxt != parent:        # 부모로는 되돌아가지 않는다
                child += 1
                dfs(nxt, cur, depth + 1)
        if child == 0:               # 부하가 없으면 말단
            leaf += 1

    dfs(1, 0, 0)
    print(leaf, deepest)

main()

(1) 접근·핵심 아이디어

- 트리는 사이클이 없으므로 DFS에서 "방금 온 정점(부모)"으로만 되돌아가지 않으면 같은 정점을 두 번 밟을 일이 없다. 그래서 `visited` 대신 `parent` 인자를 넘기는 것이 트리 DFS의 정석이다.
- 간선에 방향이 없어도 사장(1)에서 출발하면 "어느 쪽이 부하인가"는 자동으로 정해진다: 부모가 아닌 이웃이 곧 부하다.
- 깊이는 재귀 인자 `depth`로 전달하면 되고, 말단 여부는 "부하 수가 0"으로 판정한다.

(2) 코드 단계별

- 간선을 양방향 인접리스트에 넣는다.
- `dfs(cur, parent, depth)`: 최대 깊이를 갱신하고, 부모가 아닌 이웃마다 `child += 1` 후 재귀. 이웃을 다 본 뒤 `child == 0`이면 `leaf += 1`. 두 누적 변수는 `nonlocal`로 바깥 변수를 수정한다.
- `dfs(1, 0, 0)`으로 시작(부모 0은 존재하지 않는 번호). `N=1`이면 루프가 돌지 않아 `child = 0`, 즉 사장이 말단으로 세어져 `1 0`이 나온다.

(3) 스스로 다시 짤 때 생각 순서

- "트리 + 루트 지정 → parent 넘기는 DFS"를 먼저 결정한다.
- 필요한 값(리프 수, 최대 깊이)을 어디서 갱신할지 정한다: 깊이는 진입 시, 리프는 자식 순회가 끝난 뒤.
- 마지막으로 정점 1개짜리 트리처럼 간선이 없는 경우를 손으로 돌려 본다.
```

**3) 높이 차 D 이하 산책 구역** · Medium

- **요구사항**: `N×M` 격자의 각 칸에 높이가 적혀 있다. 어떤 칸에서 상하좌우 인접 칸으로 이동하려면 두 칸의 높이 차(절댓값)가 `D` 이하여야 한다. 시작 칸 `(sr, sc)`에서 출발해 도달할 수 있는 칸의 수(시작 칸 포함)와, 그 칸들 중 가장 높은 높이를 출력하라.
- **입력**: 첫 줄에 `N M D`. 다음 `N`줄에 각 `M`개의 높이(정수, 공백 구분). 마지막 줄에 `sr sc`(0-based). (`1 ≤ N, M ≤ 20`, `0 ≤ D ≤ 100`, `0 ≤ 높이 ≤ 1000`)
- **출력**: `도달 가능한 칸 수`와 `그중 최대 높이`를 공백으로 구분해 한 줄에.
- **예제**: `3 3 1` / `1 2 5` / `2 3 9` / `7 4 5` / `0 0` → `6 5` · `2 2 1` / `1 9` / `9 9` / `0 0` → `1 1`
- **셀프체크**: 시작점 하나에서만 DFS를 돌린다(전체 순회 아님). 이동 조건은 "이웃 높이 − 현재 높이"의 절댓값이므로 `abs()`를 빼먹으면 내리막만 허용하게 된다. `D=0`이면 같은 높이끼리만 이동. 첫 예제에서 `(0,2)`의 5는 `(0,1)`의 2와 차이가 3이라 못 가고, `(2,2)`의 5는 `(2,1)`의 4를 거쳐 닿는다.

```runner
@@SOLUTION
import sys

def main():
    data = sys.stdin.read().split()
    N, M, D = int(data[0]), int(data[1]), int(data[2])
    idx = 3
    h = []
    for _ in range(N):
        h.append([int(x) for x in data[idx:idx + M]])
        idx += M
    sr, sc = int(data[idx]), int(data[idx + 1])

    visited = [[False] * M for _ in range(N)]
    dr = (-1, 1, 0, 0)
    dc = (0, 0, -1, 1)
    cnt = 0
    best = h[sr][sc]

    def dfs(r, c):
        nonlocal cnt, best
        visited[r][c] = True
        cnt += 1
        if h[r][c] > best:
            best = h[r][c]
        for d in range(4):
            nr, nc = r + dr[d], c + dc[d]
            if 0 <= nr < N and 0 <= nc < M and not visited[nr][nc] and abs(h[nr][nc] - h[r][c]) <= D:
                dfs(nr, nc)

    dfs(sr, sc)
    print(cnt, best)

main()

(1) 접근·핵심 아이디어

- "시작점에서 갈 수 있는 칸"은 시작점이 속한 연결 요소인데, 여기서 "연결"의 정의가 값(높이 차 `D` 이하)으로 주어진다. 이동 조건만 바꾸면 도달 가능성 DFS 뼈대가 그대로 쓰인다.
- 방문한 칸 수와 최대 높이는 DFS 진입 시점에 함께 갱신하면 추가 순회가 필요 없다.
- 높이 차는 오르막·내리막 모두 해당하므로 `abs(h[nr][nc] - h[r][c]) <= D`로 검사한다.

(2) 코드 단계별

- 격자 높이를 2차원 리스트로 읽고 시작 좌표를 읽는다. `best`는 시작 칸 높이로 초기화한다(0으로 두면 높이가 전부 음수인 변형에서 틀린다).
- `dfs(r, c)`: 방문 처리 → `cnt`·`best` 갱신 → 4방향 이웃 중 범위 안·미방문·높이 차 조건을 만족하면 재귀.
- 시작 칸에서 한 번만 `dfs`를 호출하고 결과를 출력한다. 마지막 테스트처럼 `D=100`일 때 `200→301`은 차이 101이라 끊긴다.

(3) 스스로 다시 짤 때 생각 순서

- "시작점 하나 + 조건부 이동 → 도달 가능 영역"으로 문제를 분류한다.
- 이동 조건을 정확한 부등식으로 적는다(절댓값, `<=`).
- DFS 뼈대에 조건을 끼우고, 진입 시 집계값을 갱신한다. `D=0`, 고립된 시작점 같은 경계값을 검산한다.
```

**4) 부서별 인원 수** · Medium

- **요구사항**: `N`명의 직원이 사장(1번)을 루트로 하는 트리 조직도를 이룬다. 각 직원 `v`에 대해 "`v` 자신과 `v` 아래의 모든 부하"를 합친 인원 수(서브트리 크기)를 구해, 직원 1번부터 `N`번까지 순서대로 출력하라.
- **입력**: 첫 줄에 `N`. 다음 `N-1`줄에 상하 관계인 두 직원 `a b`(방향 없음, 1-based). (`1 ≤ N ≤ 300`)
- **출력**: 직원 1..N의 서브트리 크기를 공백으로 구분해 한 줄에.
- **예제**: `5` / `1 2` / `1 3` / `2 4` / `2 5` → `5 3 1 1 1` · `4` / `1 2` / `2 3` / `3 4` → `4 3 2 1`
- **셀프체크**: 자식의 크기를 모두 더한 뒤 자신(1)을 더해야 하므로 "자식 재귀가 끝난 뒤" 값을 확정하는 후위 처리다. 루트의 값은 항상 `N`인지, 리프의 값은 항상 `1`인지로 검산한다. `N=1`이면 출력은 `1`.

```runner
@@SOLUTION
import sys

def main():
    data = sys.stdin.read().split()
    N = int(data[0])
    adj = [[] for _ in range(N + 1)]
    idx = 1
    for _ in range(N - 1):
        a, b = int(data[idx]), int(data[idx + 1])
        idx += 2
        adj[a].append(b)
        adj[b].append(a)

    size = [0] * (N + 1)

    def dfs(cur, parent):
        total = 1                          # 자기 자신
        for nxt in adj[cur]:
            if nxt != parent:
                total += dfs(nxt, cur)     # 자식 서브트리 크기를 받아 더한다
        size[cur] = total
        return total

    dfs(1, 0)
    print(' '.join(str(size[v]) for v in range(1, N + 1)))

main()

- 문제 2와 같은 트리 DFS지만, 이번엔 값을 "진입 시"가 아니라 "자식을 모두 본 뒤(후위)"에 확정한다는 점이 다르다. 진입 시점에 `size[cur] = 1`만 두고 끝내면 자식이 반영되지 않는다.
- 트리이므로 `visited` 없이 `parent`만으로 역주행을 막는다.

(2) 코드 단계별

- 양방향 인접리스트를 만든다.

- `dfs(1, 0)` 한 번으로 모든 정점의 `size`가 채워진다. 1..N 순으로 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "정점 값이 자식 값들에 의존" → 반환값이 있는 후위 DFS를 고른다.
- 리프에서 무엇을 반환할지(1) 정하면 나머지는 합산이다.
- 루트 값이 `N`, 리프 값이 `1`인지로 검산하고, 간선 입력 순서가 뒤섞여도(마지막 테스트) 답이 같은지 확인한다.
```

**5) 두 팀 나누기** · Medium

- **요구사항**: `N`명의 학생과, 서로 사이가 나쁜 학생 쌍 `M`개가 주어진다. 사이가 나쁜 두 학생이 같은 팀에 들어가지 않도록 전체를 두 팀으로 나눌 수 있는지 판정하라. 가능하다면, 1번 학생과 반드시 같은 팀이어야 하는 학생의 수(1번 자신 포함)도 출력한다. 사이가 나쁜 관계로 1번과 연결되지 않은 학생은 어느 팀이든 갈 수 있으므로 세지 않는다.
- **입력**: 첫 줄에 `N M`. 다음 `M`줄에 `a b`(서로 사이가 나쁜 두 학생, 1-based, 같은 쌍은 한 번만 주어진다). (`1 ≤ N ≤ 300`, `0 ≤ M ≤ 1000`)
- **출력**: 가능하면 `YES`와 그 수를 공백으로 구분해 한 줄에, 불가능하면 `NO`.
- **예제**: `4 4` / `1 2` / `2 3` / `3 4` / `4 1` → `YES 2` · `3 3` / `1 2` / `2 3` / `3 1` → `NO`
- **셀프체크**: 정점을 0/1 두 색으로 칠하며 DFS하고, 인접 정점이 같은 색이면 실패다. 그래프가 여러 덩어리일 수 있으니 모든 미방문 정점에서 DFS를 시작해야 한다(한 덩어리만 보고 `YES`를 내는 실수). 홀수 길이 사이클이 있으면 항상 `NO`. `M=0`이면 `YES 1`.

```runner
@@SOLUTION
import sys

def main():
    data = sys.stdin.read().split()
    N, M = int(data[0]), int(data[1])
    adj = [[] for _ in range(N + 1)]
    idx = 2
    for _ in range(M):
        a, b = int(data[idx]), int(data[idx + 1])
        idx += 2
        adj[a].append(b)
        adj[b].append(a)

    color = [-1] * (N + 1)      # -1 미방문, 0/1 두 팀
    comp = [0] * (N + 1)        # 어느 덩어리(시작 정점 번호)에 속하는지

    def dfs(cur, col, cid):
        color[cur] = col
        comp[cur] = cid
        for nxt in adj[cur]:
            if color[nxt] == -1:
                if not dfs(nxt, 1 - col, cid):
                    return False
            elif color[nxt] == col:     # 이웃이 같은 색 -> 두 팀 불가
                return False
        return True

    for s in range(1, N + 1):
        if color[s] == -1:
            if not dfs(s, 0, s):
                print("NO")
                return

    cnt = 0
    for v in range(1, N + 1):
        if comp[v] == comp[1] and color[v] == color[1]:
            cnt += 1
    print("YES", cnt)

- "사이가 나쁜 쌍은 다른 팀"은 곧 "인접 정점은 다른 색"이다. 두 색으로 칠할 수 있는가(이분 그래프 판정)를 DFS로 확인한다: 시작 정점을 0으로 칠하고 이웃은 반대 색으로 칠해 내려가며, 이미 칠해진 이웃이 나와 같은 색이면 실패.
- 한 덩어리 안에서는 시작 정점의 색을 정하는 순간 나머지 색이 전부 강제된다. 그래서 "1번과 반드시 같은 팀"은 1번 덩어리 안에서 1번과 같은 색인 정점 수로 유일하게 정해진다. 다른 덩어리는 색을 통째로 뒤집어도 되므로 세지 않는다.
- 홀수 사이클(세 번째 예제의 삼각형)은 어떤 식으로 칠해도 같은 색 이웃이 생겨 `NO`.

(2) 코드 단계별

- 양방향 인접리스트, `color`(−1/0/1), `comp`(덩어리 번호 = 시작 정점)를 준비한다.
- `dfs(cur, col, cid)`: 현재 정점을 칠하고 덩어리 번호를 기록. 미방문 이웃은 `1 - col`로 재귀(실패가 올라오면 즉시 `False`), 방문된 이웃이 같은 색이면 `False`.
- 1..N을 훑으며 미방문 정점마다 `dfs(s, 0, s)`. 하나라도 실패하면 `NO` 출력 후 종료.
- 전부 성공하면 `comp[v] == comp[1]`이고 `color[v] == color[1]`인 정점을 세어 `YES cnt`.

(3) 스스로 다시 짤 때 생각 순서

- "서로 다른 그룹에 속해야 하는 쌍" → 2색 칠하기 문제로 번역한다.
- 실패 조건(같은 색 이웃)을 재귀 안에서 즉시 반환하도록 짠다.
- 덩어리가 여러 개일 수 있음을 기억하고 바깥 루프를 붙인다. 세는 값은 1번 덩어리로 한정해야 유일한 답이 된다.
```

**6) 모든 관광 경로의 수** · Medium

- **요구사항**: `N`개의 관광지와 `M`개의 양방향 길이 있다. 1번 관광지에서 출발해 `N`번 관광지에 도착하는 경로 중, 같은 관광지를 두 번 이상 지나지 않는 경로(단순 경로)의 개수를 구하라.
- **입력**: 첫 줄에 `N M`. 다음 `M`줄에 `a b`(양방향 길, 1-based, 같은 쌍은 한 번만). (`2 ≤ N ≤ 10`, `0 ≤ M ≤ 20`)
- **출력**: 경로의 개수.
- **예제**: `4 5` / `1 2` / `2 4` / `1 3` / `3 4` / `2 3` → `4` · `3 1` / `1 2` → `0`
- **셀프체크**: 한 경로를 다 탐색하고 돌아올 때 `visited`를 원래대로 되돌려야 다른 경로가 같은 정점을 쓸 수 있다(되돌리지 않으면 첫 경로만 세어진다). `N`번에 도착하면 더 이어가지 않고 즉시 카운트 후 반환한다. 첫 예제의 네 경로: `1-2-4`, `1-3-4`, `1-2-3-4`, `1-3-2-4`.

```runner
@@SOLUTION
import sys

def main():
    data = sys.stdin.read().split()
    N, M = int(data[0]), int(data[1])
    adj = [[] for _ in range(N + 1)]
    idx = 2
    for _ in range(M):
        a, b = int(data[idx]), int(data[idx + 1])
        idx += 2
        adj[a].append(b)
        adj[b].append(a)

    visited = [False] * (N + 1)
    count = 0

    def dfs(cur):
        nonlocal count
        if cur == N:                 # 도착: 경로 하나 완성
            count += 1
            return
        for nxt in adj[cur]:
            if not visited[nxt]:
                visited[nxt] = True
                dfs(nxt)
                visited[nxt] = False # 되돌리기: 다른 경로에서 다시 쓸 수 있게

    visited[1] = True
    dfs(1)
    print(count)

main()

- 방문 표시가 "현재 경로 위에 있는 정점"만을 뜻하게 되므로 같은 정점을 두 번 지나는 경로는 자동으로 배제된다.
- `N`이 10 이하로 작아 모든 단순 경로를 일일이 세어도 시간 안에 끝난다(정점 수가 커지면 지수적으로 폭발하므로 이 방식은 작은 그래프 전용이다).

(2) 코드 단계별

- 양방향 인접리스트를 만들고 `visited[1] = True`로 시작 정점을 경로에 올린다.
- `dfs(cur)`: `cur == N`이면 `count += 1` 후 반환(도착점에서 더 뻗지 않음). 아니면 미방문 이웃마다 표시 → 재귀 → 표시 해제.
- 마지막 테스트(`5 6`)에서 5번으로 가는 길이 `1-5`, `2-5`, `3-5` 세 갈래라 `1-5`, `1-2-5`, `1-3-5`, `1-2-3-5`, `1-3-2-5`의 5개가 세어진다.

(3) 스스로 다시 짤 때 생각 순서

- "경로의 개수" 또는 "모든 경로 나열" → 방문 표시를 복원하는 백트래킹 DFS로 분류한다.
- 종료 조건(도착 시 카운트·반환)과 복원 위치(재귀 직후)를 먼저 적는다.
- 되돌리기를 빠뜨리면 첫 예제가 `1`로 나온다는 것을 기억하고, 작은 예제로 손 검산한다.
```

**7) 선수 과목 순서** · Medium

- **요구사항**: `N`개의 과목과 "`a`를 들은 뒤에 `b`를 들어야 한다"는 관계 `M`개가 주어진다(사이클은 없다). 다음 규칙으로 정한 수강 순서를 출력하라: 과목 1번부터 `N`번까지 번호 순으로, 아직 방문하지 않은 과목에서 DFS를 시작한다. 각 과목에서 다음 과목(`a → b`의 `b`들)은 번호 오름차순으로 방문한다. 한 과목에서 갈 수 있는 과목을 모두 처리한 순간 그 과목을 "완료 목록"에 추가한다. 탐색이 모두 끝나면 완료 목록을 뒤집은 순서가 답이다.
- **입력**: 첫 줄에 `N M`. 다음 `M`줄에 `a b`(`a`가 `b`의 선수 과목, 1-based). (`1 ≤ N ≤ 300`, `0 ≤ M ≤ 1000`)
- **출력**: 수강 순서를 공백으로 구분해 한 줄에.
- **예제**: `4 3` / `1 2` / `1 3` / `3 2` → `4 1 3 2` · `3 0` → `3 2 1`
- **셀프체크**: 완료 목록에 넣는 시점은 "재귀 호출을 모두 마친 뒤(후위)"다. 진입 시 넣으면 선수 관계가 깨진다. 인접리스트를 정렬하지 않으면 규칙과 다른(다른 유효한) 순서가 나온다. 결과는 항상 "모든 `a → b`에 대해 `a`가 `b`보다 앞"을 만족해야 한다.

```runner
@@SOLUTION
import sys

def main():
    data = sys.stdin.read().split()
    N, M = int(data[0]), int(data[1])
    adj = [[] for _ in range(N + 1)]
    idx = 2
    for _ in range(M):
        a, b = int(data[idx]), int(data[idx + 1])
        idx += 2
        adj[a].append(b)
    for v in range(1, N + 1):
        adj[v].sort()                 # 규칙: 번호 오름차순으로 방문

    visited = [False] * (N + 1)
    finished = []

    def dfs(cur):
        visited[cur] = True
        for nxt in adj[cur]:
            if not visited[nxt]:
                dfs(nxt)
        finished.append(cur)          # 후위: 갈 곳을 다 본 뒤 기록

    for s in range(1, N + 1):
        if not visited[s]:
            dfs(s)
    finished.reverse()
    print(' '.join(map(str, finished)))

main()

(1) 접근·핵심 아이디어

- 방향 그래프에서 "갈 수 있는 곳을 모두 처리한 뒤 자신을 기록"하면, 어떤 간선 `a → b`에 대해서도 `b`가 `a`보다 먼저 기록된다(`a`를 마치기 전에 `b`를 반드시 마치므로). 따라서 완료 순서를 뒤집으면 모든 간선이 앞→뒤를 향하는 순서, 즉 위상 순서가 된다.
- 위상 순서는 보통 여러 개라 답이 유일하지 않지만, 이 문제는 "시작 정점 번호 순 + 인접 정점 오름차순"으로 탐색 순서를 못 박아 답을 하나로 만든다. 규칙을 그대로 코드로 옮기는 것이 핵심이다.
- 세 번째 예제에서 `1`을 먼저 탐색해 `5, 4, 1`이 완료된 뒤 `2`, `3`이 각각 완료되어 `5 4 1 2 3` → 뒤집어 `3 2 1 4 5`. 모든 선수 관계(`2→1`, `3→1`, `1→4`, `4→5`)가 지켜진다.

(2) 코드 단계별

- 방향 인접리스트를 만들고 각 리스트를 정렬한다.
- `dfs(cur)`: 방문 처리 후 미방문 이웃을 오름차순으로 재귀. 이웃을 다 본 뒤 `finished.append(cur)`.
- 1..N 순으로 미방문 정점에서 DFS 시작. 끝나면 `finished.reverse()` 후 출력. 간선이 없으면 `1, 2, 3` 순으로 완료되어 뒤집힌 `3 2 1`이 나온다.

(3) 스스로 다시 짤 때 생각 순서

- "선후 관계를 만족하는 순서" → 위상 정렬, 그중 DFS 버전은 "후위 순서의 역순".
- 기록 시점을 후위로 고정하고(진입 시 기록 금지), 순서 규칙(정렬·시작 순)을 반영한다.
- 출력이 모든 간선 방향을 지키는지 예제로 검산한다.
```

**8) 동굴 방 번호와 크기** · Hard

- **요구사항**: `N×M` 격자 동굴에서 `.`은 빈 칸, `#`은 바위다. 빈 칸은 상하좌우뿐 아니라 **대각선으로 인접한 빈 칸과도 이어진다**(8방향). 이어진 빈 칸의 덩어리를 "방"이라 한다. 격자를 위→아래, 왼→오른쪽으로 훑다가 아직 번호가 없는 빈 칸을 만나면 새 번호(1부터 차례로)를 붙이고 그 방 전체가 같은 번호를 갖는다. 방의 개수와, 방 1번부터 순서대로 각 방의 칸 수를 출력하라. 격자가 최대 `100×100`이고 한 줄로 길게 이어진 방이 있을 수 있으므로 재귀 대신 명시적 스택으로 DFS하라.
- **입력**: 첫 줄에 `N M`. 다음 `N`줄에 각 `M`개의 `.`/`#`이 공백 없이 주어진다. (`1 ≤ N, M ≤ 100`)
- **출력**: 첫 줄에 방의 개수 `K`. `K ≥ 1`이면 둘째 줄에 방 1..K의 칸 수를 공백으로 구분해 출력한다(`K = 0`이면 첫 줄만).
- **예제**: `4 5` / `..#..` / `.##.#` / `##..#` / `#...#` → `2` / `3 8` · `3 3` / `.#.` / `#.#` / `.#.` → `1` / `5`
- **셀프체크**: 8방향 오프셋은 `(-1,-1)`부터 `(1,1)`까지 `(0,0)`을 뺀 8개다. 4방향으로 풀면 첫 예제가 방 4개로 잘못 나온다. 스택에 넣는 순간 번호를 붙여야 같은 칸이 스택에 여러 번 들어가 크기가 부풀지 않는다. 빈 칸이 하나도 없으면 `0`만 출력. 마지막 테스트는 폭 41·높이 50의 지그재그 통로(빈 칸 1050개)라 재귀로 짜면 기본 재귀 한도(1000)에 걸린다.

```runner
import sys

def main():
    data = sys.stdin.read().split()
    N, M = int(data[0]), int(data[1])
    grid = data[2:2 + N]
    label = [[0] * M for _ in range(N)]      # 0 = 아직 번호 없음

        for j in range(M):

                            label[nr][nc] = room
                            stack.append((nr, nc))
                sizes.append(cnt)

    print(len(sizes))
    if sizes:
        print(' '.join(map(str, sizes)))
```

**9) 고리가 있는 케이블 묶음** · Hard

- **요구사항**: `N`개의 장치와 `M`개의 케이블(양방향)이 있다. 케이블로 직·간접 연결된 장치 묶음을 "네트워크"라 한다. 네트워크의 총개수와, 그중 고리(사이클)를 포함하는 네트워크의 개수를 출력하라. 같은 두 장치를 잇는 케이블이 두 개 이상 주어지거나, 한 장치가 자기 자신과 연결되는 경우는 없다.
- **입력**: 첫 줄에 `N M`. 다음 `M`줄에 `a b`(1-based). (`1 ≤ N ≤ 300`, `0 ≤ M ≤ 1000`)
- **출력**: `네트워크 수`와 `고리를 포함하는 네트워크 수`를 공백으로 구분해 한 줄에.
- **예제**: `7 5` / `1 2` / `2 3` / `3 1` / `4 5` / `5 6` → `3 1` · `4 4` / `1 2` / `2 3` / `3 4` / `4 1` → `1 1`
- **셀프체크**: 무방향 그래프의 사이클은 "방금 온 정점(부모)이 아닌데 이미 방문된 이웃"을 만나면 존재한다. 부모를 제외하지 않으면 간선 하나짜리 그래프(`1-2`)도 사이클로 오판한다. 방향 그래프의 3색 판정과 달리 무방향은 2색(방문 여부)+부모 비교로 충분하다. 각 네트워크마다 사이클 발견 플래그를 초기화해야 한다. 케이블이 없으면 `N 0`.

```runner
@@SOLUTION
import sys

def main():
    data = sys.stdin.read().split()
    N, M = int(data[0]), int(data[1])
    adj = [[] for _ in range(N + 1)]
    idx = 2
    for _ in range(M):
        a, b = int(data[idx]), int(data[idx + 1])
        idx += 2
        adj[a].append(b)
        adj[b].append(a)

    visited = [False] * (N + 1)
    found = False

    def dfs(cur, parent):
        nonlocal found
        visited[cur] = True
        for nxt in adj[cur]:
            if not visited[nxt]:
                dfs(nxt, cur)
            elif nxt != parent:       # 부모가 아닌 방문 정점 = 고리
                found = True

    comps = 0
    cyc = 0
    for s in range(1, N + 1):
        if not visited[s]:
            comps += 1
            found = False             # 네트워크마다 초기화
            dfs(s, 0)
            if found:
                cyc += 1
    print(comps, cyc)

main()

(1) 접근·핵심 아이디어

- 네트워크 수는 연결 요소 세기(미방문 시작점마다 DFS)다. 여기에 "그 요소 안에 사이클이 있는가"를 같은 DFS에서 함께 판정한다.
- 무방향 그래프에서 DFS 도중 이미 방문한 이웃을 만나면, 그 이웃이 방금 온 부모가 아닌 한 "현재 경로의 어딘가로 되돌아가는 간선"이므로 사이클이다. 부모는 간선을 되짚는 것뿐이니 제외한다. 중복 간선이 없다는 조건이 있어 이 판정이 정확하다.
- 검산용 성질: 요소 하나의 정점 수를 `v`, 간선 수를 `e`라 하면 사이클이 없을 때 `e = v - 1`, 있으면 `e ≥ v`. 네 번째 예제의 두 요소는 각각 정점 4·간선 4, 정점 4·간선 4로 둘 다 고리가 있다.

(2) 코드 단계별

- 양방향 인접리스트, `visited`, 사이클 플래그 `found`를 준비한다.
- `dfs(cur, parent)`: 방문 처리 후 이웃을 본다. 미방문이면 `dfs(nxt, cur)`, 방문됐는데 부모가 아니면 `found = True`.
- 1..N을 훑으며 미방문 정점마다 `comps += 1`, `found`를 초기화하고 DFS. 끝난 뒤 `found`면 `cyc += 1`.

(3) 스스로 다시 짤 때 생각 순서

- "연결 요소" + "사이클" → 두 개념을 한 DFS에서 처리하되 부모 인자를 넘긴다.
- 사이클 조건을 정확히 적는다: 방문됨 **그리고** 부모 아님.
- 플래그를 요소마다 초기화하고, 간선 0개·트리·홀수 사이클 같은 경계값으로 검산한다.
```

**10) 배수되는 칸의 수** · Hard

- **요구사항**: `N×M` 격자 마당의 각 칸에 높이가 적혀 있고, 높이가 `0`인 칸은 하수구다. 어떤 칸의 물은 상하좌우 인접 칸 중 높이가 **같거나 더 낮은** 칸으로 흘러갈 수 있고, 그렇게 흘러가기를 반복해 어떤 하수구에든 닿을 수 있으면 그 칸은 "배수된다"고 한다. 하수구가 아닌 칸 중 배수되는 칸의 수를 출력하라.
- **입력**: 첫 줄에 `N M`. 다음 `N`줄에 각 `M`개의 높이(정수, 공백 구분). (`1 ≤ N, M ≤ 20`, `0 ≤ 높이 ≤ 100`, `0`은 하수구)
- **출력**: 배수되는 칸(하수구 제외)의 수.
- **예제**: `3 4` / `3 2 1 0` / `4 5 2 3` / `0 1 9 1` → `9` · `1 3` / `2 2 0` → `2`
- **셀프체크**: 칸마다 "하수구에 닿는가"를 DFS하면 `O((NM)²)`이지만, 물의 흐름을 거꾸로 보면 하수구에서 출발해 "같거나 더 높은" 이웃으로 올라가는 DFS 한 번으로 끝난다(모든 하수구를 시작점으로). 조건에 등호(같은 높이)가 있으므로 평지도 흐른다. 하수구가 없으면 `0`. 첫 예제의 오른쪽 아래 `1`은 이웃이 `3`과 `9`뿐이라 물이 갇혀 배수되지 않는다.

```runner
@@SOLUTION
import sys

def main():
    data = sys.stdin.read().split()
    N, M = int(data[0]), int(data[1])
    idx = 2
    h = []
    for _ in range(N):
        h.append([int(x) for x in data[idx:idx + M]])
        idx += M

    visited = [[False] * M for _ in range(N)]
    dr = (-1, 1, 0, 0)
    dc = (0, 0, -1, 1)

    def dfs(r, c):
        # 역방향: 현재 칸으로 물을 흘려보낼 수 있는(같거나 높은) 이웃으로 올라간다
        visited[r][c] = True
        for d in range(4):
            nr, nc = r + dr[d], c + dc[d]
            if 0 <= nr < N and 0 <= nc < M and not visited[nr][nc] and h[nr][nc] >= h[r][c]:
                dfs(nr, nc)

    for i in range(N):
        for j in range(M):
            if h[i][j] == 0 and not visited[i][j]:   # 모든 하수구에서 출발
                dfs(i, j)

    cnt = 0
    for i in range(N):
        for j in range(M):
            if visited[i][j] and h[i][j] != 0:
                cnt += 1
    print(cnt)

main()

(1) 접근·핵심 아이디어

- "어떤 칸에서 하수구까지 내려갈 수 있는가"를 모든 칸에서 각각 DFS하면 느리고 코드도 길다. 흐름을 뒤집어 "하수구에서 출발해 물이 흘러 들어올 수 있는 칸"을 찾으면 된다: 물은 `h[from] ≥ h[to]`일 때 `from → to`로 흐르므로, 거꾸로 `to`에서 `h[nxt] ≥ h[cur]`인 `nxt`로 올라간다.
- 하수구가 여러 개이므로 모든 하수구를 시작점으로 DFS를 돌린다. 한 하수구에서 방문한 칸은 다른 하수구 탐색에서 건너뛰어도 결과가 같다(이미 배수됨이 확정).
- 등호가 핵심 함정이다. 같은 높이로 흐르지 못한다고 보면 두 번째 예제(`2 2 0`)의 답이 `1`로 틀린다.

(2) 코드 단계별

- 높이 격자를 읽고 `visited`를 준비한다.
- `dfs(r, c)`: 방문 처리 후 4방향 이웃 중 범위 안·미방문·`h[nr][nc] >= h[r][c]`이면 재귀.
- 모든 `0` 칸에서 `dfs`를 호출한 뒤, 방문된 칸 중 높이가 0이 아닌 칸을 센다.

(3) 스스로 다시 짤 때 생각 순서

- "여러 목적지 중 하나에 도달 가능한 출발 칸의 수" → 목적지에서 역방향으로 퍼뜨리는 다중 시작 DFS로 뒤집는다.
- 역방향 이동 조건을 원래 조건에서 정확히 유도한다(부등호 방향·등호).
- 시작점을 전부 순회하고, 하수구 자신을 답에서 빼는 것과 하수구가 없는 경우를 점검한다.
```
