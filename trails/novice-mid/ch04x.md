## L5. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch04(시뮬레이션 I)의 핵심을 **반복 훈련**하고, 코딩테스트 단골 유형으로 **확장**하는 연습 세트다. 날짜·시간 환산, 진법 변환, 1차원 구간 칠하기, 2차원 사각형 칠하기·겹침을 소재만 바꿔 여러 번 다시 짜 본다.
- **반복 훈련 개념**:
  - 시간 환산 → 정수 연산 → 복원: `total = h*60 + m`, `h = total // 60`, `m = total % 60`, 하루 감싸기 `% 1440`
  - 날짜 계산: `days_in_month(y, m)`으로 달 경계·윤년을 넘기고, 요일은 `(기준요일 + 경과일) % 7`
  - 진법 → 10진: `val = val * base + DIGITS.index(ch)`(왼쪽 자리부터 누적)
  - 1차원 칸 배열: `for x in range(a, b+1): cnt[x] += 1` 후 배열을 훑어 조건 카운트
  - 2차원 격자 칠하기와 겹침: `grid[r][c] += 1` 또는 대입, 두 사각형 교집합은 `[max(시작), min(끝)]`
- **코딩테스트 출제 맵**: 『이것이 취업을 위한 코딩테스트다』의 '구현' 파트(시각·날짜·좌표 시뮬레이션), 백준 「단계별로 풀어보기」의 '1차원 배열'·'2차원 배열' 단계(칠하기·겹침), solved.ac CLASS 2의 진법·달력 문제들.
- **문제 구성표**:

| # | 문제 | 난이도 | 반복 개념 | 유형 |
|---|------|--------|-----------|------|
| 1 | 다음 버스 시각 | Easy | 시간 환산·% 1440 | 반복 훈련 |
| 2 | 색상 코드 RGB 분해 | Easy | 16진 → 10진 누적 | 반복 훈련 |
| 3 | 가장 긴 빈 틈 | Easy | 1차원 칸 배열 + 연속 길이 | 반복 훈련 |
| 4 | 두 날짜 사이 일수 | Medium | 날짜 → 총 일수 환산 | 유형 확장 (이코테 '구현' 스타일) |
| 5 | 가장 작은 유효 진법 | Medium | 자릿값 최대 → 진법, 10진 누적 | 유형 확장 (solved.ac CLASS 2 진법 스타일) |

**문제**

**1) 다음 버스 시각** · Easy

- **요구사항**: 버스는 00:00부터 정확히 `k`분 간격으로 출발한다(00:00, 00:k, 00:2k, ...). 현재 시각이 `h`시 `m`분일 때 다음 버스의 출발 시각과 기다려야 하는 분 수를 구하라. 현재 시각에 정확히 버스가 출발하면 대기 0분이며, 다음 버스가 자정을 넘기면 00:00처럼 다음날 시각으로 출력한다.
- **입력**: 한 줄에 `h m k` (0 ≤ h < 24, 0 ≤ m < 60, 1 ≤ k ≤ 720, k는 1440의 약수).
- **출력**: `HH:MM 대기분` 한 줄. 시·분은 두 자리로 채운다.
- **예제**: `08 07 15` → `08:15 8` · `23 58 5` → `00:00 2`
- **셀프체크**: 대기 시간은 `(k - total % k) % k`로 구했는가(바깥 `% k`가 있어야 정각일 때 0이 된다). 자정을 넘는 경우 `% 1440`으로 감쌌는가. 두 자리 패딩 `f"{x:02d}"`를 시와 분 모두에 적용했는가.

```runner
@@SOLUTION
h, m, k = map(int, input().split())
total = h * 60 + m
wait = (k - total % k) % k
nxt = (total + wait) % 1440
print(f"{nxt // 60:02d}:{nxt % 60:02d} {wait}")
@@TESTS
--IN
08 07 15
--OUT
08:15 8
--IN
23 58 5
--OUT
00:00 2
--IN
10 30 15
--OUT
10:30 0
--IN
0 0 720
--OUT
00:00 0
@@EXPL
(1) 접근·핵심 아이디어

- 시:분을 "자정부터 몇 분"이라는 정수 `total`로 환산하면, 다음 버스는 "`total` 이상인 가장 작은 k의 배수"다. 나머지 `total % k`가 0이면 지금이 정각이고, 아니면 `k - 나머지`만큼 기다린다.
- 도착 시각이 1440분을 넘으면 자정을 지난 것이므로 `% 1440`으로 감싸 다음날 시각으로 돌린다.

(2) 코드 단계별

- `total = h*60 + m`으로 총 분 환산.
- `wait = (k - total % k) % k`: 정각이면 `k - 0 = k`가 되는데 바깥 `% k`가 그것을 0으로 만든다.
- `nxt = (total + wait) % 1440`으로 다음 버스 시각(분)을 구하고, `// 60`·`% 60`으로 시·분 복원 후 두 자리 패딩 출력.

(3) 스스로 다시 짤 때 생각 순서

- "총 분으로 환산 → 다음 k의 배수 → 1440 감싸기 → 복원" 순서를 그대로 코드로.
- 함정: 정각일 때 대기 0(바깥 `% k`), 23:58 + 2분 = 00:00(감싸기), `0 0 720`처럼 자정 정각도 대기 0.
```

**2) 색상 코드 RGB 분해** · Easy

- **요구사항**: 웹 색상 코드는 `#RRGGBB` 형태로, 두 자리 16진수 세 개가 각각 빨강·초록·파랑의 밝기(0~255)를 나타낸다. 색상 코드가 주어지면 세 값을 10진수로 출력하라. 16진 문자는 대문자·소문자가 섞여 올 수 있다.
- **입력**: 한 줄에 `#`으로 시작하는 7글자 색상 코드(16진 숫자 `0~9`, `a~f`, `A~F`).
- **출력**: `R G B` 세 정수를 공백으로 구분해 한 줄.
- **예제**: `#1A2B3C` → `26 43 60` · `#ffffff` → `255 255 255`
- **셀프체크**: 소문자를 `upper()`로 정규화한 뒤 `DIGITS.index`를 썼는가. `#`을 떼고 2글자씩(`s[0:2]`, `s[2:4]`, `s[4:6]`) 잘랐는가. `#000000`이 `0 0 0`으로 나오는지 확인.

```runner
@@SOLUTION
DIGITS = "0123456789ABCDEF"
s = input().strip()
if s[0] == '#':
    s = s[1:]
s = s.upper()
vals = []
for i in range(0, 6, 2):
    v = 0
    for ch in s[i:i + 2]:
        v = v * 16 + DIGITS.index(ch)
    vals.append(v)
print(*vals)
@@TESTS
--IN
#1A2B3C
--OUT
26 43 60
--IN
#ffffff
--OUT
255 255 255
--IN
#000000
--OUT
0 0 0
--IN
#0a0B10
--OUT
10 11 16
@@EXPL
(1) 접근·핵심 아이디어

- 색상 코드는 "16진수 세 개를 이어 붙인 문자열"이다. `#`을 떼고 두 글자씩 잘라 각각을 16진 → 10진으로 바꾸면 끝난다.
- 16진 → 10진은 L2의 `val = val * base + 자릿값` 누적을 base=16으로 쓴 것이다. 문자↔값 매핑은 `DIGITS.index(ch)`.

(2) 코드 단계별

- 입력에서 `#`을 제거하고 `upper()`로 소문자를 대문자로 통일한다(`DIGITS`에 대문자만 있으므로).
- `range(0, 6, 2)`로 0, 2, 4 위치에서 두 글자 `s[i:i+2]`를 잘라 각 조각을 누적 변환한다.
- 세 값을 `print(*vals)`로 공백 구분 출력.

(3) 스스로 다시 짤 때 생각 순서

- "어디서 자르나?" → 2글자씩 3조각. "어떻게 바꾸나?" → base 16 누적.
- 함정: 소문자 입력(`#ffffff`)은 정규화 없이는 `index`가 실패한다. `#000000`처럼 0이 섞여도 누적식은 그대로 동작한다.
```

**3) 가장 긴 빈 틈** · Easy

- **요구사항**: 길이 `L`의 도로(칸 1..L)에 `n`개의 공사 구간 `[a, b]`가 표시된다. 공사 구간이 하나도 없는 칸들이 연속으로 이어진 "빈 틈" 중 가장 긴 것의 길이를 출력하라. 빈 칸이 없으면 0.
- **입력**: 첫 줄 `L n` (1 ≤ L ≤ 1000, 0 ≤ n ≤ 100). 이어 `n`개 줄에 `a b` (1 ≤ a ≤ b ≤ L).
- **출력**: 가장 긴 빈 틈의 길이 한 줄.
- **예제**: `10 2` / `2 3` / `7 8` → `3` · `5 1` / `1 5` → `0`
- **셀프체크**: 칸 배열에 구간을 칠한 뒤 1..L을 훑으며 "값이 0이면 `cur += 1`, 아니면 `cur = 0`"으로 연속 길이를 세고 최댓값을 갱신했는가. `n = 0`이면 답이 `L` 전체인지, 전부 칠해지면 0이 나오는지 확인.

```runner
@@SOLUTION
L, n = map(int, input().split())
cnt = [0] * (L + 2)
for _ in range(n):
    a, b = map(int, input().split())
    for x in range(a, b + 1):
        cnt[x] += 1
best = 0
cur = 0
for x in range(1, L + 1):
    if cnt[x] == 0:
        cur += 1
        if cur > best:
            best = cur
    else:
        cur = 0
print(best)
@@TESTS
--IN
10 2
2 3
7 8
--OUT
3
--IN
5 1
1 5
--OUT
0
--IN
6 0
--OUT
6
--IN
8 3
1 1
4 4
8 8
--OUT
3
@@EXPL
(1) 접근·핵심 아이디어

- L3의 칸 배열에 구간을 그대로 칠한 뒤, 이번에는 "칠해진 칸"이 아니라 "칠해지지 않은 칸이 연속으로 몇 개 이어지는가"를 센다. 배열을 한 번 훑으며 현재 연속 길이 `cur`와 최댓값 `best`를 유지하면 된다.

(2) 코드 단계별

- `cnt = [0] * (L + 2)`를 만들고 각 구간 `a..b`에 `+1`.
- `x`를 1..L로 돌며 `cnt[x] == 0`이면 `cur += 1`하고 `best`를 갱신, 칠해진 칸을 만나면 `cur = 0`으로 끊는다.
- `best` 출력.

(3) 스스로 다시 짤 때 생각 순서

- "칠하기 → 빈 칸 연속 길이 세기"의 두 단계로 나눈다.
- 함정: `n = 0`이면 구간 입력이 없으므로 루프가 0번 돌아도 동작해야 하고 답은 `L`. 전부 칠해지면 `cur`가 한 번도 늘지 않아 0. 한 칸짜리 구간(`a == b`)도 `range(a, b+1)`이 정확히 한 칸을 칠한다.
```

**4) 두 날짜 사이 일수** · Medium

- **요구사항**: 두 날짜 `y1 m1 d1`과 `y2 m2 d2`가 주어진다(둘째 날짜가 첫째 날짜와 같거나 나중). 첫째 날짜에서 둘째 날짜까지 며칠이 지나는지 출력하라(같은 날이면 0, 다음 날이면 1). 윤년 규칙(4의 배수이면서 100의 배수가 아니거나, 400의 배수)을 따른다.
- **입력**: 두 줄에 각각 `y m d` (1 ≤ y ≤ 3000, 유효한 날짜).
- **출력**: 경과 일수 한 줄.
- **예제**: `2024 2 28` / `2024 3 1` → `2` · `2023 12 31` / `2024 1 1` → `1`
- **셀프체크**: 각 날짜를 "1년 1월 1일부터 며칠째"라는 총 일수로 환산해 빼면 달·해 경계를 따로 처리할 필요가 없다. 2024년(윤년)의 2/28 → 3/1은 2/29를 지나므로 2일, 1900년(100의 배수라 평년)의 2/28 → 3/1은 1일인지 확인.

```runner
@@SOLUTION
def is_leap(y):
    return (y % 4 == 0 and y % 100 != 0) or (y % 400 == 0)

def days_in_month(y, m):
    d = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
    if m == 2 and is_leap(y):
        return 29
    return d[m - 1]

def to_days(y, m, d):
    total = 0
    for yy in range(1, y):
        total += 366 if is_leap(yy) else 365
    for mm in range(1, m):
        total += days_in_month(y, mm)
    return total + d

y1, m1, d1 = map(int, input().split())
y2, m2, d2 = map(int, input().split())
print(to_days(y2, m2, d2) - to_days(y1, m1, d1))
@@TESTS
--IN
2024 2 28
2024 3 1
--OUT
2
--IN
2023 12 31
2024 1 1
--OUT
1
--IN
2000 1 1
2000 1 1
--OUT
0
--IN
1900 2 28
1900 3 1
--OUT
1
--IN
2023 3 15
2025 3 15
--OUT
731
@@EXPL
(1) 접근·핵심 아이디어

- L1의 "환산 → 정수 연산" 원칙을 날짜에 적용한다. 각 날짜를 "1년 1월 1일을 1일째로 하는 총 일수"로 바꾸면 두 날짜의 차이는 뺄셈 한 번이다. 달 경계·해 경계·윤년을 경우별로 나눌 필요가 없다.
- 총 일수 = (이전 해들의 일수 합) + (같은 해 이전 달들의 일수 합) + 일.

(2) 코드 단계별

- `is_leap`, `days_in_month`는 L1 그대로 재사용.
- `to_days(y, m, d)`: `1..y-1`년은 윤년 여부에 따라 366/365를 더하고, `1..m-1`월은 `days_in_month`로 더한 뒤 `d`를 더한다.
- 두 날짜의 `to_days` 차이를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "날짜 두 개 → 각각 총 일수 → 빼기". 기준일은 아무거나 좋지만 두 날짜에 같은 기준을 써야 한다.
- 함정: 2/29가 사이에 끼는지(윤년), 100의 배수 해(1900)는 평년, 같은 날이면 0. 연도 상한 3000이라 해를 하나씩 더하는 루프도 충분히 빠르다.
```

**5) 가장 작은 유효 진법** · Medium

- **요구사항**: 숫자·대문자로 이루어진 문자열 `s`가 어떤 진법의 표기라고 한다. 모든 자릿값(0~9, A=10, ..., Z=35)이 유효하려면 진법은 "가장 큰 자릿값 + 1" 이상이어야 하고, 진법은 최소 2다. `s`를 표기할 수 있는 가장 작은 진법과, 그 진법으로 읽었을 때의 10진 값을 출력하라.
- **입력**: 한 줄에 `s` (길이 1~10, `0~9`·`A~Z`로만 구성).
- **출력**: `진법 10진값` 한 줄.
- **예제**: `12` → `3 5` · `Z` → `36 35`
- **셀프체크**: 가장 큰 자릿값을 `DIGITS.index`로 찾고 `+1` 한 값이 2보다 작으면 2로 올렸는가(`0`, `1`, `10`처럼 자릿값이 0·1뿐인 경우). 10진 변환은 그 진법으로 `val = val * base + 자릿값`을 왼쪽부터 누적. `1010`은 2진법으로 10, `A0`은 11진법으로 110.

```runner
@@SOLUTION
DIGITS = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"
s = input().strip()
mx = 0
for ch in s:
    v = DIGITS.index(ch)
    if v > mx:
        mx = v
base = mx + 1
if base < 2:
    base = 2
val = 0
for ch in s:
    val = val * base + DIGITS.index(ch)
print(base, val)
@@TESTS
--IN
12
--OUT
3 5
--IN
Z
--OUT
36 35
--IN
0
--OUT
2 0
--IN
1010
--OUT
2 10
--IN
A0
--OUT
11 110
@@EXPL
(1) 접근·핵심 아이디어

- 어떤 진법 `b`에서 쓸 수 있는 자릿값은 `0..b-1`이다. 따라서 문자열 안의 가장 큰 자릿값이 `mx`이면 진법은 최소 `mx + 1`이어야 한다. 단 진법은 2 이상이므로 `mx`가 0이나 1이면 2로 올린다.
- 진법이 정해지면 L2의 왼쪽부터 누적(`val * base + 자릿값`)으로 10진 값을 만든다.

(2) 코드 단계별

- 문자열을 한 번 훑어 `DIGITS.index(ch)`의 최댓값 `mx`를 구한다.
- `base = mx + 1`, 2보다 작으면 2로 보정.
- 다시 한 번 훑으며 `val = val * base + DIGITS.index(ch)` 누적, `base val` 출력.

(3) 스스로 다시 짤 때 생각 순서

- "진법은 자릿값이 결정한다" → 최대 자릿값 찾기 → 최소 2 보정 → 누적 변환.
- 함정: `0`이나 `1010`처럼 최대 자릿값이 1이면 `mx + 1 = 2`라 괜찮지만, `0`만 있으면 `mx + 1 = 1`이므로 보정이 꼭 필요하다. `A0`처럼 큰 자릿값이 앞에 오면 `mx = 10 → base 11`, 값은 `10*11 + 0 = 110`.
```

**6) 두 직사각형 겹침 넓이** · Medium

- **요구사항**: 좌표평면에 축과 나란한 직사각형 두 개가 각각 왼쪽 아래 `(x1, y1)`과 오른쪽 위 `(x2, y2)`로 주어진다. 두 직사각형이 겹치는 부분의 넓이를 출력하라. 변이나 꼭짓점만 맞닿으면 겹침 넓이는 0이다. 좌표가 매우 커서 격자를 만들 수 없다.
- **입력**: 두 줄에 각각 `x1 y1 x2 y2` (0 ≤ x1 < x2 ≤ 10^9, 0 ≤ y1 < y2 ≤ 10^9).
- **출력**: 겹치는 넓이(정수) 한 줄.
- **예제**: `0 0 4 4` / `2 2 6 6` → `4` · `0 0 2 2` / `2 0 4 2` → `0`
- **셀프체크**: 겹치는 구간은 x축에서 `[max(x1, x3), min(x2, x4)]`, y축에서도 마찬가지다. 두 폭이 모두 양수일 때만 곱하고, 하나라도 0 이하면 0을 출력했는가(맞닿는 경우 폭이 정확히 0). 한 사각형이 다른 것 안에 완전히 들어가면 작은 쪽 넓이가 나오는지 확인.

```runner
@@SOLUTION

x3, y3, x4, y4 = map(int, input().split())
w = min(x2, x4) - max(x1, x3)
h = min(y2, y4) - max(y1, y3)
if w > 0 and h > 0:
    print(w * h)
else:
    print(0)

(1) 접근·핵심 아이디어

- 좌표가 10^9까지라 L4처럼 격자에 칠할 수 없다. 대신 L4 접근 전략에 나온 교집합 공식을 쓴다. 축에 나란한 두 사각형의 겹침은 "x 구간의 교집합 × y 구간의 교집합"이고, 각 축의 교집합은 `[max(시작), min(끝)]`이다.
- 교집합 폭이 0 이하이면 그 축에서 겹치지 않는다는 뜻이므로 넓이는 0이다.

(2) 코드 단계별

- 두 사각형을 읽고 `w = min(x2, x4) - max(x1, x3)`, `h = min(y2, y4) - max(y1, y3)`를 계산.
- `w > 0 and h > 0`일 때만 `w * h`, 아니면 0.

(3) 스스로 다시 짤 때 생각 순서

- "겹침 = 각 축 교집합의 곱". 교집합 구간은 시작은 더 큰 쪽, 끝은 더 작은 쪽.
- 함정: 변이 맞닿으면 `w`나 `h`가 정확히 0이라 0을 출력해야 하고, 서로 떨어져 있으면 음수가 나오므로 `> 0` 검사가 둘 다 필요하다. 포함 관계면 자연히 작은 사각형의 넓이. 큰 좌표의 곱도 파이썬 정수는 그대로 다룬다.
```

**7) 이중 예약 분 세기** · Medium

- **요구사항**: 회의실 예약 `n`건이 각각 시작 `h1:m1`부터 끝 `h2:m2` 직전까지(반열림 구간, 끝 시각은 포함하지 않음)로 주어진다. 하루(00:00~24:00) 중 두 건 이상이 동시에 잡혀 있는 시간이 총 몇 분인지 출력하라.
- **입력**: 첫 줄 `n` (1 ≤ n ≤ 100). 이어 `n`개 줄에 `h1 m1 h2 m2` (시작 < 끝, 0 ≤ h1 < 24, 0 ≤ h2 ≤ 24, `h2 = 24`이면 `m2 = 0`).
- **출력**: 이중 예약된 총 분 수 한 줄.
- **예제**: `2` / `9 0 10 30` / `10 0 11 0` → `30` · `3` / `9 0 12 0` / `10 0 11 0` / `10 30 13 0` → `120`

```runner
- 다 쌓은 뒤 두께가 2 이상인 칸의 개수가 곧 "이중 예약된 분 수"다.

(3) 스스로 다시 짤 때 생각 순서

- 함정: 끝 시각은 포함하지 않으므로 `range(s, e+1)`이 아니라 `range(s, e)`. 그래서 10:00에 끝나는 예약과 10:00에 시작하는 예약은 겹치지 않는다(넷째 테스트가 0). `24 0`은 `e = 1440`이라 마지막 인덱스 1439까지 정확히 칠해진다.
```

**8) k일 뒤 날짜와 요일** · Hard

- **요구사항**: 어떤 날짜 `y`년 `m`월 `d`일과 그 날의 요일 번호 `w`(0=월요일, 1=화, ..., 6=일요일)가 주어진다. 정확히 `k`일 뒤의 날짜와 요일을 구하라. 달·해 경계와 윤년을 정확히 넘겨야 한다.
- **입력**: 첫 줄 `y m d w` (1 ≤ y ≤ 3000, 유효한 날짜, 0 ≤ w ≤ 6). 둘째 줄 `k` (0 ≤ k ≤ 100000).
- **출력**: `y m d 요일`을 공백으로 구분해 한 줄. 요일은 `MON TUE WED THU FRI SAT SUN` 중 하나.
- **예제**: `2024 2 28 2` / `2` → `2024 3 1 FRI` · `2023 12 31 6` / `1` → `2024 1 1 MON`
- **셀프체크**: 요일은 날짜와 무관하게 `(w + k) % 7`로 바로 나온다. 날짜는 "이번 달에 남은 일수"보다 `k`가 크면 다음 달 1일로 점프하며 `k`를 줄이고, 그렇지 않으면 `d += k`로 끝낸다. 12월에서 다음 달로 넘어갈 때 `m = 1, y += 1`을 했는가. `k = 0`이면 입력 날짜 그대로인지, 2024-02-28에서 2일 뒤가 3월 1일(윤년)인지 확인.

```runner
@@SOLUTION

    if m == 2 and is_leap(y):

    return d[m - 1]

        k = 0
    else:

        d = 1
        m += 1
        if m == 13:
            m = 1
            y += 1
print(y, m, d, names[nw])

(1) 접근·핵심 아이디어

- 요일과 날짜를 분리해서 푼다. 요일은 7일 주기이므로 `(w + k) % 7` 한 줄로 끝난다.
- 날짜는 하루씩 세면 `k`가 10만이라도 되지만, "달 단위 점프"가 더 깔끔하다. 이번 달에 남은 일수 `remain = days_in_month - d`보다 `k`가 작거나 같으면 같은 달 안에서 끝나고, 크면 다음 달 1일로 넘어가면서 `k`에서 `remain + 1`(오늘 이후 남은 날 + 1일로 가는 하루)을 뺀다.

(2) 코드 단계별

- `nw = (w + k) % 7`로 요일 인덱스를 먼저 구해 둔다(뒤에서 `k`를 소모하므로 순서 주의).
- `while k > 0`: `remain`을 계산해 같은 달이면 `d += k`, 아니면 `k -= remain + 1; d = 1; m += 1`, 13월이 되면 `m = 1; y += 1`.
- `y m d names[nw]` 출력.

(3) 스스로 다시 짤 때 생각 순서
```

**9) 스티커 합집합의 넓이와 둘레** · Hard

- **요구사항**: `N×M` 격자(행 1..N, 열 1..M)에 `n`장의 직사각형 스티커 `(r1, c1, r2, c2)`를 붙인다. 스티커는 겹칠 수 있다. 붙이고 난 뒤 스티커로 덮인 영역의 "넓이(덮인 칸 수)"와 "둘레 길이(덮인 칸과 덮이지 않은 칸 또는 격자 밖이 맞닿는 변의 개수)"를 출력하라.
- **입력**: 첫 줄 `N M n` (1 ≤ N, M ≤ 100, 0 ≤ n ≤ 50). 이어 `n`개 줄에 `r1 c1 r2 c2` (1 ≤ r1 ≤ r2 ≤ N, 1 ≤ c1 ≤ c2 ≤ M).
- **출력**: `넓이 둘레` 한 줄.
- **예제**: `5 5 1` / `2 2 3 4` → `6 10` · `5 5 2` / `1 1 2 2` / `2 2 3 3` → `7 12`
- **셀프체크**: 격자를 `(N+2)×(M+2)`로 한 겹 크게 만들어 두면 상하좌우 이웃을 볼 때 경계 검사 없이 "밖은 0"으로 처리된다. 덮인 칸마다 네 이웃 중 0인 이웃의 수를 둘레에 더했는가. 2×3 사각형 하나는 넓이 6, 둘레 10. 두 스티커가 한 칸만 겹치는 둘째 예제는 넓이 4+4-1=7. `n = 0`이면 `0 0`.

```runner
@@SOLUTION
N, M, n = map(int, input().split())
grid = [[0] * (M + 2) for _ in range(N + 2)]
for _ in range(n):
    r1, c1, r2, c2 = map(int, input().split())
    for r in range(r1, r2 + 1):
        for c in range(c1, c2 + 1):
            grid[r][c] = 1
area = 0
perim = 0
for r in range(1, N + 1):
    for c in range(1, M + 1):
        if grid[r][c] == 1:
            area += 1
            if grid[r - 1][c] == 0:
                perim += 1
            if grid[r + 1][c] == 0:
                perim += 1
            if grid[r][c - 1] == 0:
                perim += 1
            if grid[r][c + 1] == 0:
                perim += 1
print(area, perim)
@@TESTS

(1) 접근·핵심 아이디어

- 넓이는 L4 그대로 "격자에 찍고 1인 칸을 센다". 겹친 칸은 대입(1)이므로 자동으로 한 번만 세어진다.
- 둘레는 "덮인 칸의 각 변 중, 반대편이 덮이지 않은 변"의 개수다. 덮인 칸마다 상하좌우 이웃을 보고 이웃이 0이면 그 변은 바깥 경계이므로 둘레에 1을 더한다. 겹친 스티커의 내부 경계는 양쪽이 모두 1이라 세어지지 않는다.

(2) 코드 단계별

- 격자를 `(N+2)×(M+2)`로 만들어 바깥 한 겹을 0으로 둔다 → 이웃 검사에서 인덱스 초과와 "밖은 미도색" 처리가 동시에 해결된다.
- 스티커마다 `r1..r2 × c1..c2`에 1을 대입.
- 1..N × 1..M을 훑으며 `grid[r][c] == 1`이면 `area += 1`, 네 이웃 `grid[r-1][c]`, `grid[r+1][c]`, `grid[r][c-1]`, `grid[r][c+1]`이 0인 개수를 `perim`에 더한다.

(3) 스스로 다시 짤 때 생각 순서

- "넓이 = 1인 칸 수, 둘레 = 1인 칸의 0인 이웃 변 수". 여유 테두리로 경계 검사를 없앤다.
- 함정: 격자 전체를 덮으면 둘레는 격자 테두리 `2(N+M)`(넷째 테스트 16). 떨어진 두 칸은 각각 4변씩 8. `n = 0`이면 둘 다 0. 누적(+1)이 아니라 대입(1)이어야 `== 1` 판정이 깨지지 않는다.
```

**10) 동시 점등 최장 구간** · Hard

- **요구사항**: `n`개의 조명이 각각 `h1:m1`부터 `h2:m2` 직전까지(반열림) 켜진다. 하루(00:00~24:00) 중 "동시에 켜진 조명이 `k`개 이상"인 상태가 연속으로 가장 길게 이어지는 구간을 찾아, 그 시작 시각과 길이(분)를 출력하라. 길이가 같은 구간이 여럿이면 시작 시각이 가장 이른 것을 고른다. 그런 구간이 없으면 `NONE`.
- **입력**: 첫 줄 `n k` (1 ≤ n ≤ 100, 1 ≤ k ≤ n). 이어 `n`개 줄에 `h1 m1 h2 m2` (시작 < 끝, `h2 = 24`이면 `m2 = 0`).
- **출력**: `HH:MM 길이` 한 줄(시각은 두 자리 패딩), 또는 `NONE`.
- **예제**: `3 2` / `9 0 12 0` / `10 0 11 0` / `11 30 13 0` → `10:00 60` · `2 1` / `0 0 1 0` / `23 0 24 0` → `00:00 60`
- **셀프체크**: 분 칸 배열에 두께를 쌓은 뒤, `cnt[t] >= k`인 분이 연속되는 길이를 `cur`로 세고 `cur > best`일 때만 갱신했는가(`>=`로 갱신하면 동점에서 늦은 구간이 선택된다). 시작 시각은 `t - cur + 1`. 첫 예제는 10:00~11:00(두께 2)이 60분, 11:30~12:00이 30분이라 `10:00 60`.

```runner
- 7번과 같은 "분 칸 배열"에 두께를 쌓은 뒤, 이번에는 3번처럼 "조건(두께 ≥ k)을 만족하는 칸이 연속으로 몇 개 이어지는가"를 센다. 세 개념(시간 환산·구간 칠하기·연속 길이)의 결합이다.
- 최장 구간의 시작 시각은 "현재 칸 `t`에서 길이 `cur`만큼 되돌아간 곳" `t - cur + 1`이며, 이를 다시 시:분으로 복원한다.

(2) 코드 단계별

- 조명마다 `[시작분, 끝분)`에 `+1`을 쌓는다.
- `t`를 0..1439로 돌며 `cnt[t] >= k`이면 `cur += 1`, 아니면 `cur = 0`. `cur > best`일 때만 `best`와 `best_start = t - cur + 1`을 갱신.
- `best == 0`이면 `NONE`, 아니면 `best_start`를 `// 60`, `% 60`으로 복원해 두 자리 패딩 출력.

(3) 스스로 다시 짤 때 생각 순서

- "칠하기 → 조건 칸 연속 길이 → 시작 위치 복원". 동점 규칙(가장 이른 시작)은 "엄격히 클 때만 갱신"으로 자동 처리된다.
- 함정: 둘째 예제처럼 00:00~01:00과 23:00~24:00이 같은 60분이면 먼저 만난 00:00이 남아야 한다. 넷째 테스트처럼 9:00~10:00과 10:00~11:00은 반열림이라 맞닿아 하나의 120분 구간이 된다. 조건을 만족하는 분이 하나도 없으면 `best`가 0 그대로라 `NONE`.
```
