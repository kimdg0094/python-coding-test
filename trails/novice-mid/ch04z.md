**뼈대 코드**

- (1) 시각·날짜: 환산 → 정수 연산 → 복원.

```python
DAY = 24 * 3600                     # ← 문제마다 바뀜 (분 단위면 24*60)

def to_unit(h, m, s):               # 사람이 읽는 형태 -> 정수 하나
    return h * 3600 + m * 60 + s

def from_unit(t):                   # 정수 하나 -> 사람이 읽는 형태
    days = t // DAY                 # 며칠 넘어갔나
    rest = t % DAY                  # 그날의 시각
    return days, rest // 3600, (rest % 3600) // 60, rest % 60

def is_leap(y):
    return (y % 4 == 0 and y % 100 != 0) or (y % 400 == 0)

MDAYS = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]

def day_of_year(y, m, d):
    doy = d
    for mm in range(1, m):          # 앞선 달들을 통째로 더한다
        add = MDAYS[mm - 1]
        if mm == 2 and is_leap(y):
            add = 29
        doy += add
    return doy
```

- (2) 진법: 10진을 다리로 삼는 두 함수.

```python
DIGITS = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"

def to_decimal(s, b):               # b진 문자열 -> 10진 정수
    val = 0
    for ch in s:
        val = val * b + DIGITS.index(ch)
    return val

def to_base(n, b):                  # 10진 정수 -> b진 문자열
    if n == 0:
        return "0"                  # 0은 반드시 특수 처리
    res = ""
    while n > 0:
        res = DIGITS[n % b] + res   # 나머지는 뒷자리부터 나온다
        n //= b
    return res
```

- (3) 칠하기: 1차원 칸 배열과 2차원 카운트 격자.

```python
# 1D : 좌표 1..L, 닫힌 구간 [a, b]

for a, b in intervals:

painted = sum(1 for x in range(1, L + 1) if cnt[x] > 0)
exact_k = sum(1 for x in range(1, L + 1) if cnt[x] == k)   # ← 문제마다 바뀜

# 2D : 행 1..N, 열 1..M
grid = [[0] * (M + 1) for _ in range(N + 1)]
for r1, c1, r2, c2 in rects:
    for r in range(r1, r2 + 1):
```

- (4) 이벤트 스위핑: 좌표가 커서 칸을 못 만들 때.

```python
events = []
for a, b in intervals:              # 반열림 [a, b)
    events.append((a, 1))           # 시작: 두께 +1
    events.append((b, -1))          # 끝  : 두께 -1
events.sort()

cover = 0
prev = None
covered = 0
for x, delta in events:
    if cover > 0 and prev is not None:
        covered += x - prev         # 길이는 두께를 갱신하기 '전에' 더한다
    cover += delta
    prev = x
```

- (5) 시뮬레이션 루프의 일반형: 상태 → 한 스텝 → 종료 조건.

```python
t = 0                               # 진행량(턴 수, 시각 ...)
state = start                       # ← 문제마다 바뀜: 위치·격자·남은 양

while True:
```

**언제 무엇을 쓰나**

| 상황 | 고르는 것 | 이유 | 복잡도 |
|---|---|---|---|
| 시각의 덧셈·차이·비교 | 총 초(또는 총 분)로 환산 | 자릿수 올림을 `//`와 `%`가 대신 처리 | O(1) |
| 며칠 뒤 요일 | day-of-year 뒤 `% 7` | 요일은 7주기라 나머지가 곧 답 | O(달 수) |
| 총 근무시간 누적 | 구간마다 초 차이를 합산 | 빌림이 없어 실수가 안 생김 | O(기록 수) |
| 임의의 두 진법 변환 | 10진을 다리로 | 두 함수 조합이면 모든 쌍을 처리 | O(자리 수) |
| k진 자릿수 합·판정 | `% k`, `// k` 반복 | 표기 문자열을 만들 필요가 없음 | O(log_k n) |
| 좌표가 작은 구간 칠하기 | 1차원 칸 배열 | 짧고, 어떤 질문에도 한 번 훑어 답함 | O(구간 수 × 길이) |
| 좌표가 10^9까지 큰 덮임 길이 | 이벤트 스위핑 | 두께가 변하는 지점만 보면 충분 | O(n log n) |
| 격자가 수백 규모인 사각형 칠하기 | 2차원 카운트 격자 | 겹침·색을 같은 코드로 처리 | O(n × 넓이) |
| 사각형 두 개의 겹침만 필요 | max/min 교집합 공식 | 격자를 만들지 않아도 됨 | 쌍마다 O(1) |
| 나중에 칠한 색이 이겨야 함 | 순서대로 대입(last wins) | 대입 자체가 덮어쓰기라 공짜 | O(n × 넓이) |

**✅ 마스터 체크리스트**

- [ ] 설명할 수 있다: 시:분:초를 총 초로 바꾸면 왜 계산이 쉬워지는지, `//`와 `%`가 각각 무엇을 뜻하는지.
- [ ] 설명할 수 있다: 총 분에서 "며칠 넘어갔는지"와 "그날의 시각"을 분리하는 두 식과, 그 둘이 유일하게 정해지는 이유.
- [ ] 설명할 수 있다: 윤년 조건 `(y%4==0 and y%100!=0) or y%400==0`의 세 규칙이 각각 무엇을 보정하는지.
- [ ] 설명할 수 있다: day-of-year를 구한 뒤 `(doy - 1) % 7`로 요일을 얻는 이유(왜 1을 빼는가).
- [ ] 설명할 수 있다: 호너 방식 `val = val*b + 자릿값`이 왜 자리값 거듭제곱과 같은 결과를 주는지.
- [ ] 설명할 수 있다: `n % b`가 왜 마지막 자리이고, 결과 문자열을 왜 앞에 붙여 쌓는지.
- [ ] 설명할 수 있다: `to_base`에서 `n == 0`을 특수 처리하지 않으면 무슨 일이 벌어지는지.
- [ ] 설명할 수 있다: 칸 배열이 겹침을 자동으로 한 번만 세는 이유(포함-배제를 왜 안 해도 되는지).
- [ ] 설명할 수 있다: 닫힌 구간 `[a,b]`와 반열림 구간 `[a,b)`의 길이·순회 범위 차이.
- [ ] 설명할 수 있다: 좌표가 10^9일 때 칸 배열이 불가능한 이유와, 스위핑이 왜 가능한지.
- [ ] 설명할 수 있다: 스위핑에서 길이를 더하는 시점이 두께 갱신 "전"이어야 하는 이유.
- [ ] 설명할 수 있다: 두 사각형의 교집합이 `[max(시작), min(끝)]`인 이유와, 언제 겹침이 없는지.
- [ ] 설명할 수 있다: 색칠에서 `+= 1`(누적)과 `= color`(대입)의 결과가 어떻게 달라지는지.
- [ ] 설명할 수 있다: 격자 칠하기의 복잡도를 계산하고, 언제 차이배열로 줄여야 하는지 판단하는 기준.

**⚠️ 자주 하는 실수**

**1) 닫힌 구간인데 끝을 빼먹는다**

```python
# ❌ 틀린 코드
for x in range(a, b):        # b 칸이 칠해지지 않는다
    cnt[x] += 1
```

왜: 문장이 "`a`부터 `b`까지"(양 끝 포함)인데 `range(a, b)`는 `b-1`에서 멈춘다. 구간 하나마다 정확히 한 칸씩 모자라 답이 조용히 작아진다.

```python
# ✅ 고친 코드
for x in range(a, b + 1):    # 닫힌 구간 [a, b] 는 b+1 까지
    cnt[x] += 1
```

**2) 반열림 구간의 길이를 닫힌 구간처럼 센다**

```python
# ❌ 틀린 코드
covered += (b - a + 1)       # [a, b) 인데 +1 을 붙였다
```

왜: `[a, b)`는 `b`를 포함하지 않으므로 길이가 `b - a`다. `+1`을 붙이면 구간마다 1씩 부풀고, `[0,5)`와 `[5,10)`처럼 맞닿는 경우 경계 좌표가 두 번 세어진다.

```python
# ✅ 고친 코드
covered += (b - a)           # 반열림 [a, b) 의 길이
```

**3) 윤년 조건을 `or`로 뭉뚱그린다**

```python
# ❌ 틀린 코드
def is_leap(y):
    return y % 4 == 0 or y % 400 == 0    # 1900년을 윤년으로 판정
```

왜: 100의 배수를 제외하는 규칙이 빠졌다. 1900은 4의 배수라 이 식에서는 윤년이 되지만 실제로는 평년이라, 2월 일수가 하루 어긋나고 그 뒤 모든 날짜·요일이 틀어진다.

```python
# ✅ 고친 코드
def is_leap(y):
    return (y % 4 == 0 and y % 100 != 0) or (y % 400 == 0)
```

**4) 누적 시간에 하루 나머지를 적용한다**

```python
# ❌ 틀린 코드
h = (total // 3600) % 24     # 총 근무 26시간이 2시간으로 줄어든다
```

왜: `% 24`는 "그날의 시각"을 구할 때 쓰는 연산이다. 여러 날에 걸친 누적 시간(길이)에 쓰면 하루를 넘긴 만큼이 통째로 사라진다. 시각(위치)과 시간(길이)은 다른 값이다.

```python
# ✅ 고친 코드
h = total // 3600            # 누적 길이이므로 24로 감싸지 않는다
m = (total % 3600) // 60
s = total % 60
```

**5) 진법 변환에서 0을 빠뜨린다**

```python
# ❌ 틀린 코드
def to_base(n, b):
    res = ""
    while n > 0:             # n 이 0이면 루프를 한 번도 안 돈다
        res = DIGITS[n % b] + res
        n //= b
    return res               # "" 가 반환된다
```

왜: `n = 0`이면 `while` 조건이 처음부터 거짓이라 빈 문자열이 나온다. 출력이 비어 버리거나, 이어붙인 결과가 통째로 어긋난다.

```python
# ✅ 고친 코드
def to_base(n, b):
    if n == 0:
        return "0"           # 0은 자리 하나짜리 예외
    res = ""
    while n > 0:
        res = DIGITS[n % b] + res
        n //= b
    return res
```

**6) 스위핑에서 길이를 두께 갱신 뒤에 더한다**

```python
# ❌ 틀린 코드
for x, delta in events:
    cover += delta                       # 두께를 먼저 바꿔 버렸다
    if cover > 0 and prev is not None:
        covered += x - prev
    prev = x
```

왜: `prev`부터 `x`까지 구간을 덮고 있었는지는 **이 이벤트가 일어나기 직전의 두께**로 판단해야 한다. 먼저 갱신하면 구간이 끝나는 순간(`-1`)에 그 구간의 길이를 잃고, 시작하는 순간(`+1`)에는 덮이지 않았던 앞 구간을 더해 버린다.

```python
# ✅ 고친 코드
for x, delta in events:
    if cover > 0 and prev is not None:
        covered += x - prev              # 먼저 길이를 정산하고
    cover += delta                       # 그 다음 두께를 바꾼다
    prev = x
```

**7) 1-based 격자를 크기 그대로 잡는다**

```python
# ❌ 틀린 코드
grid = [[0] * M for _ in range(N)]       # 행·열을 1..N, 1..M 로 쓸 계획인데
grid[N][M] += 1                          # IndexError
```

왜: 인덱스는 0부터 시작하므로 `1..N`을 쓰려면 칸이 `N+1`개 필요하다. 0번 행·열 하나를 버리더라도 여유를 두는 편이 좌표 변환 실수를 없앤다.

```python
# ✅ 고친 코드
grid = [[0] * (M + 1) for _ in range(N + 1)]   # 0번 줄은 버리고 1..N 사용
grid[N][M] += 1
```
