> 개요: 데이터를 정해진 기준으로 줄 세우는 "정렬"을 배운다. 단일 값 정렬에서 출발해, 여러 필드를 하나로 묶는 "객체" 표현을 익히고, 마지막에는 정렬 기준(key)을 자유자재로 지정해 다중 조건 정렬까지 다룬다.

## L1. 일반 정렬

**개념**

- 정렬(sort)은 데이터를 오름차순 또는 내림차순 등 "정해진 순서"로 재배치하는 것이다. 순위 매기기, 중앙값 찾기, 중복 제거, 이분 탐색 준비 등 수많은 문제의 첫 단추가 된다.
- 파이썬에는 두 가지 도구가 있다. `sorted(리스트)`는 정렬된 "새 리스트"를 반환하고(원본 유지), `리스트.sort()`는 원본을 그 자리에서 바꾼다(반환값은 `None`).
- 내림차순은 `reverse=True`로 지정한다. 기본은 오름차순이다.

```python
a = [5, 2, 9, 1]
b = sorted(a)              # b = [1, 2, 5, 9], a는 그대로
a.sort()                   # a 자체가 [1, 2, 5, 9]로 바뀜
c = sorted(a, reverse=True)  # [9, 5, 2, 1]
```

- 정렬 후에는 인덱스 접근이 강력해진다. `s[0]`은 최솟값, `s[-1]`은 최댓값, `s[k-1]`은 k번째로 작은 값이다.
- 중복 제거가 필요하면 `set`으로 중복을 없앤 뒤 정렬한다: `sorted(set(a))`.

**접근 전략**

- "가장 크다/작다", "k번째", "순위", "중앙값", "정렬된 상태에서 이웃끼리 비교"라는 신호가 보이면 먼저 정렬을 떠올린다. 정렬해 두면 원하는 값이 특정 인덱스에 "고정"된다.
- 전형적 절차: (1) 입력을 리스트로 받는다 → (2) `sorted`로 오름/내림 정렬한다 → (3) 필요한 인덱스나 구간(`s[:3]` 등 슬라이싱)을 뽑는다.
- 원본 순서를 나중에 다시 써야 하면 `리스트.sort()` 대신 `sorted`로 사본을 만들어 정렬한다. 실수로 원본을 뭉개지 않게 주의.
- 복잡도: 파이썬 정렬은 비교 기반으로 원소 N개에 O(N log N). N이 수십만이어도 충분히 빠르다. 정렬 후 인덱스/슬라이싱 접근은 O(1)~O(구간 길이).

**문제**

**1) 중복 없는 오름차순** · Easy

- **요구사항**: 정수 N개가 주어질 때, 중복을 제거하고 오름차순으로 출력한다.
- **입력**: 첫 줄에 N. 둘째 줄에 정수 N개(공백 구분).
- **출력**: 중복이 제거된 값들을 오름차순으로 한 줄에 공백으로 구분해 출력.
- **예제**: `6 / 5 3 3 1 5 2` → `1 2 3 5`
- **예제**: `4 / 7 7 7 7` → `7`
- **셀프체크**: 모두 같은 수면 한 개만 남는가. 출력 사이 공백 형식이 맞는가(끝에 불필요한 공백/줄바꿈 주의). `set`은 순서가 없으니 반드시 다시 정렬해야 한다.

```runner
@@SOLUTION
n = int(input())
a = list(map(int, input().split()))
print(*sorted(set(a)))
@@TESTS
--IN
6
5 3 3 1 5 2
--OUT
1 2 3 5
--IN
4
7 7 7 7
--OUT
7
@@EXPL
(1) 접근·핵심 아이디어

- 중복 제거는 `set(a)`로 한 번에 처리한다. `set`은 같은 값을 하나만 남긴다.
- 단, `set`은 순서가 없으므로 반드시 다시 정렬해야 오름차순 출력이 된다. → `sorted(set(a))`.

(2) 코드 단계별

- `n = int(input())`로 개수를 읽는다(값 자체는 쓰지 않아도 형식상 읽어 둔다).
- `a = list(map(int, input().split()))`로 정수 리스트를 만든다.
- `sorted(set(a))`로 중복 제거 + 오름차순 정렬을 동시에 끝낸다.
- `print(*리스트)`는 리스트를 공백으로 펼쳐 출력하므로 끝에 불필요한 공백이 붙지 않는다.

(3) 스스로 다시 짤 때 생각 순서

- "중복 없이" → `set` 을 떠올린다.
- "오름차순" → `set`은 순서가 없다는 함정을 기억하고 `sorted`로 감싼다.
- "공백 구분 한 줄" → `print(*...)` 로 출력 형식을 맞춘다.
```

**2) k번째로 작은 수** · Easy

- **요구사항**: 정수 N개와 k가 주어질 때, 정렬했을 때 k번째로 작은 값을 출력한다(중복도 하나의 자리로 센다).
- **입력**: 첫 줄에 N과 k. 둘째 줄에 정수 N개.
- **출력**: k번째로 작은 값 하나.
- **예제**: `6 3 / 7 2 9 4 4 1` → `4`  (정렬: 1 2 4 4 7 9, 3번째는 4)
- **예제**: `5 1 / 10 8 6 4 2` → `2`
- **셀프체크**: k는 1부터 시작하므로 인덱스는 `k-1`이다(off-by-one 함정). 중복이 있어도 자리 수로 세는지 확인. k=N일 때 최댓값이 되는가.

```runner
@@SOLUTION
n, k = map(int, input().split())
a = list(map(int, input().split()))
a.sort()
print(a[k - 1])
@@TESTS
--IN
6 3
7 2 9 4 4 1
--OUT
4
--IN
5 1
10 8 6 4 2
--OUT
2
@@EXPL
(1) 접근·핵심 아이디어

- 정렬해 두면 "k번째로 작은 값"이 특정 인덱스에 고정된다. 오름차순 정렬 후 앞에서 k번째를 뽑으면 된다.
- 핵심 함정은 인덱스다. k는 1부터 세지만 리스트 인덱스는 0부터이므로 `a[k-1]`이다.

(2) 코드 단계별

- `n, k = map(int, input().split())`로 개수와 k를 함께 읽는다.
- `a = list(map(int, input().split()))`로 정수 리스트를 만든다.
- `a.sort()`로 오름차순 정렬한다(중복은 각각 하나의 자리로 남는다).
- `a[k-1]`이 k번째로 작은 값이다. 예: 정렬 `1 2 4 4 7 9`에서 3번째는 인덱스 2 → `4`.

(3) 스스로 다시 짤 때 생각 순서

- "k번째로 작은" → 오름차순 정렬을 먼저 떠올린다.
- "1부터 세는 k" → 인덱스는 `k-1`이라는 off-by-one을 항상 확인한다.
- 검산: k=1이면 최솟값(`a[0]`), k=N이면 최댓값(`a[-1]`)이 나오는지 머릿속으로 대입해 본다.
```

**3) 상위 3개의 합** · Medium

- **요구사항**: 정수 N개 중 가장 큰 3개의 합을 출력한다. (N은 3 이상)
- **입력**: 첫 줄에 N. 둘째 줄에 정수 N개.
- **출력**: 최댓값 3개의 합.
- **예제**: `6 / 10 20 5 8 30 15` → `65`  (내림차순 30 20 15 ... 상위 3개 합 65)
- **예제**: `3 / -1 -2 -3` → `-6`
- **셀프체크**: 내림차순 정렬 후 `s[:3]`의 합을 쓰면 간단하다. 음수만 있어도 "가장 큰 3개"를 고르는 게 맞는지(값이 큰 순서). 같은 값이 여러 개여도 각각을 하나의 자리로 세는지 확인.

```runner
@@SOLUTION
n = int(input())
a = list(map(int, input().split()))
a.sort(reverse=True)
print(sum(a[:3]))
@@TESTS
--IN
6
10 20 5 8 30 15
--OUT
65
--IN
3
-1 -2 -3
--OUT
-6
@@EXPL
(1) 접근·핵심 아이디어

- "가장 큰 3개"는 내림차순 정렬 후 맨 앞 세 개다. `sort(reverse=True)` 후 `a[:3]`을 더한다.
- 음수만 있어도 "값이 큰 순서"의 상위 3개를 고르는 규칙은 동일하다. 예: `-1 -2 -3` → 상위 3개는 전부이므로 합 `-6`.

(2) 코드 단계별

- `a = list(map(int, input().split()))`로 정수 리스트를 만든다.
- `a.sort(reverse=True)`로 내림차순 정렬한다. 이제 큰 값이 앞쪽에 온다.
- 슬라이싱 `a[:3]`으로 상위 3개를 잘라 내고 `sum(...)`으로 합을 구한다.
- 같은 값이 여러 개여도 각각 하나의 자리로 세므로 그대로 더하면 된다.

(3) 스스로 다시 짤 때 생각 순서

- "가장 큰 K개" → 내림차순 정렬 + 앞에서 K개 슬라이싱을 떠올린다.
- 슬라이싱은 개수가 모자라도 에러 없이 있는 만큼만 준다는 점을 활용한다(N이 항상 3 이상이면 걱정 없음).
- 음수 케이스로 "큰 순서"의 의미를 검산한다.
```


## L2. 객체

**개념**

- 실전 데이터는 값 하나가 아니라 "여러 필드가 묶인 한 덩어리"인 경우가 많다. 예: 학생 = (이름, 점수), 상품 = (이름, 가격, 재고). 이렇게 관련된 값들을 하나로 묶은 것을 여기서는 "객체"라 부른다.
- 파이썬에서 가장 가벼운 묶음은 튜플이다. 소괄호로 여러 값을 한 덩어리로 만든다. 인덱스로 필드에 접근한다.

```python
student = ("kim", 90)     # (이름, 점수)
name  = student[0]        # "kim"
score = student[1]        # 90

students = [("kim", 90), ("lee", 85), ("park", 90)]  # 객체들의 리스트
for name, score in students:   # 언패킹으로 필드에 이름 붙여 읽기
    print(name, score)
```

- 필드를 "이름"으로 부르고 싶으면 딕셔너리를 쓴다. 키로 접근해 가독성이 좋아진다.

```python
s = {"name": "kim", "score": 90}
print(s["name"], s["score"])
```

- 딕셔너리는 "무엇이 몇 번 나왔는가" 같은 집계에도 쓴다. `d.get(키, 0)`은 키가 없으면 기본값 0을 주므로 빈도 세기에 편하다.

```python
count = {}
for w in words:
    count[w] = count.get(w, 0) + 1
```

**접근 전략**

- "여러 정보가 한 사람/한 항목에 붙어 다닌다"면 값을 따로따로 여러 리스트에 나눠 담지 말고 한 튜플로 묶어 한 리스트에 담는다. 그래야 나중에 통째로 정렬·이동해도 필드가 어긋나지 않는다.
- 필드가 2~3개고 위치가 명확하면 튜플, 필드가 많거나 이름으로 다뤄야 읽기 좋으면 딕셔너리를 고른다.
- "가장 ~한 항목"을 찾을 때는 (1) 기준 필드의 최댓/최솟값을 먼저 구하고 (2) 그 값을 가진 항목(들)을 걸러낸다. 동점 처리 규칙(예: 이름이 앞선 것)을 문제에서 반드시 확인한다.
- 빈도/집계는 딕셔너리 한 번 순회로 O(N). 그 뒤 최댓값 찾기도 O(항목 수).

**문제**

**1) 최고 점수 학생** · Easy

- **요구사항**: 학생들의 (이름, 점수)가 주어질 때, 최고 점수를 받은 학생의 이름을 출력한다. 동점이면 이름이 사전순으로 가장 앞선 학생을 출력한다.
- **입력**: 첫 줄에 N. 다음 N줄에 각 줄마다 이름과 점수.
- **출력**: 조건을 만족하는 학생 이름 하나.
- **예제**: `3 / kim 90 / lee 85 / park 90` → `kim`  (최고 90점은 kim, park 동점 → 사전순 kim)
- **예제**: `2 / bob 70 / amy 70` → `amy`
- **셀프체크**: (이름, 점수) 튜플로 묶어 리스트에 담았는가. 최고 점수를 먼저 구한 뒤 그 점수인 학생들 중에서 이름을 비교하는가. 점수를 정수로 변환했는가(문자열 비교 함정).

```runner
@@SOLUTION
n = int(input())
students = []
for _ in range(n):
    parts = input().split()
    name = parts[0]
    score = int(parts[1])
    students.append((name, score))
best = max(s[1] for s in students)
names = sorted(name for name, score in students if score == best)
print(names[0])
@@TESTS
--IN
3
kim 90
lee 85
park 90
--OUT
kim
--IN
2
bob 70
amy 70
--OUT
amy
@@EXPL
(1) 접근·핵심 아이디어

- 각 학생을 `(이름, 점수)` 튜플로 묶어 한 리스트에 담는다. 그래야 필드가 어긋나지 않는다.
- "최고 점수 + 동점이면 이름 사전순"은 두 단계로 나눈다. (1) 먼저 최고 점수를 구하고 (2) 그 점수를 가진 학생 이름들 중 사전순 첫 번째를 고른다.

(2) 코드 단계별

- N줄을 읽으며 `parts = input().split()`로 나누고, 점수는 `int(parts[1])`로 변환한다(문자열 비교 함정 방지).
- `best = max(s[1] for s in students)`로 최고 점수를 구한다.
- `sorted(name ... if score == best)`로 최고 점수를 가진 이름들만 모아 사전순 정렬한다.
- `names[0]`이 사전순으로 가장 앞선 이름이다.

(3) 스스로 다시 짤 때 생각 순서

- "가장 ~한 항목" → 기준 값(최고 점수)을 먼저 구한다.
- "동점 처리" → 그 값을 가진 후보만 걸러 두 번째 기준(이름)으로 정렬한다.
- 점수는 반드시 정수로 변환(문자열 "9" > "85" 같은 오류 방지).
```

**2) 가장 많이 나온 단어** · Medium

- **요구사항**: 단어 N개가 주어질 때, 가장 많이 등장한 단어를 출력한다. 최다 빈도가 여럿이면 사전순으로 가장 앞선 단어를 출력한다.
- **입력**: 첫 줄에 N. 다음 N개의 단어(줄 단위 또는 공백 구분).
- **출력**: 단어 하나.
- **예제**: `6 / apple banana apple cherry banana apple` → `apple`  (apple 3, banana 2, cherry 1)
- **예제**: `4 / dog cat cat dog` → `cat`  (dog 2, cat 2 동점 → 사전순 cat)
- **셀프체크**: `get`으로 빈도 딕셔너리를 만들었는가. 동점일 때 "빈도가 큰 것 우선, 같으면 이름 작은 것"이라는 두 기준을 함께 처리하는가(다음 레슨의 다중 키 정렬로도 풀 수 있다). 빈도가 아니라 등장 순서로 착각하지 않았는가.

```runner
@@SOLUTION
import sys
data = sys.stdin.read().split()
n = int(data[0])
words = data[1:1 + n]
count = {}
for w in words:
    count[w] = count.get(w, 0) + 1
best = min(count.items(), key=lambda kv: (-kv[1], kv[0]))
print(best[0])
@@TESTS
--IN
6
apple banana apple cherry banana apple
--OUT
apple
--IN
4
dog cat cat dog
--OUT
cat
@@EXPL
**이 풀이의 새 문법**

- `딕셔너리.items()`: 딕셔너리의 (키, 값) 쌍을 하나씩 꺼낼 수 있게 해 준다. `min(count.items(), key=...)`처럼 각 쌍을 통째로 비교 대상으로 쓸 때 사용한다.

(1) 접근·핵심 아이디어

- 빈도 세기는 딕셔너리 한 번 순회로 끝난다. `count[w] = count.get(w, 0) + 1` — 키가 없으면 0에서 시작.
- 우승자는 두 기준을 함께 본다: 빈도가 큰 것 우선, 같으면 이름이 사전순으로 작은 것. 이를 정렬 키 `(-빈도, 이름)`으로 표현하면 "가장 앞선" 항목이 우승자다.

(2) 코드 단계별

- 첫 토큰이 N, 그다음 N개가 단어이므로 전체를 `split()`으로 읽고 슬라이싱한다.
- 순회하며 `get`으로 빈도 딕셔너리를 채운다.
- `min(count.items(), key=lambda kv: (-kv[1], kv[0]))`: `-빈도`가 작을수록(=빈도가 클수록) 앞이고, 빈도가 같으면 이름이 작은 것이 앞이다. 그 최솟값 항목이 답.
- `best[0]`으로 단어만 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "가장 많이" → 빈도 딕셔너리부터 만든다.
- "동점 처리" → 두 기준을 튜플 키로 묶는다. 빈도는 큰 게 우선이므로 부호를 뒤집어 `-빈도`.
- `min`과 키의 방향이 헷갈리면, 작은 케이스(dog·cat 동점)로 반드시 검산한다.
```

**3) 재고 부족 상품 집계** · Medium

- **요구사항**: 상품들의 (이름, 가격, 재고)가 주어진다. 재고가 임계값 T 미만인 상품의 "개수"와 그런 상품들의 "가격 합"을 출력한다.
- **입력**: 첫 줄에 N과 T. 다음 N줄에 이름 가격 재고.
- **출력**: 부족 상품 개수와 가격 합(공백 구분).
- **예제**: `3 5 / pen 100 2 / book 300 10 / ink 50 4` → `2 150`  (재고 2, 4가 5 미만 → pen, ink / 개수 2, 가격 100+50=150)
- **예제**: `2 1 / a 10 0 / b 20 5` → `1 10`
- **셀프체크**: 각 상품을 (이름, 가격, 재고) 세 필드 튜플로 묶어 다뤘는가. "T 미만"이 `< T`인지 `<= T`인지 정확히 구분했는가(경계 함정). 조건을 만족하는 항목만 골라 개수와 합을 동시에 누적했는가.

```runner

    name = parts[0]

- 상품마다 세 필드 `(이름, 가격, 재고)`를 읽어 조건 `재고 < T`를 확인한다.
- "T 미만"은 `< T`이지 `<= T`가 아니다. 경계 함정이 핵심. 예: T=5면 재고 5는 포함되지 않고, 재고 2·4만 부족으로 센다.
- 조건을 만족하는 항목에 대해 개수와 가격 합을 동시에 누적한다.

(2) 코드 단계별

- `n, t = map(int, input().split())`로 상품 수와 임계값을 읽는다.
- 누적 변수 `cnt`, `total`을 0으로 초기화한다.
- 각 줄에서 이름·가격·재고를 나눠 읽고, 가격과 재고는 정수 변환한다.
- `if stock < t:`일 때만 `cnt += 1`, `total += price`로 함께 누적한다.
- 마지막에 `print(cnt, total)`로 공백 구분 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "조건을 만족하는 것만 집계" → 누적 변수 초기화 후 루프 안에서 `if`로 걸러 누적.
- 부등호 방향("미만" = `<`)을 문제 문장에서 그대로 옮긴다. `<=`와 혼동하지 않기.
- 개수와 합을 각각 다른 루프로 두 번 돌 필요 없이 한 번에 처리한다.
```


## L3. 객체 정렬

**개념**

- 객체(튜플·딕셔너리)를 정렬할 때, "무엇을 기준으로 줄 세울지"를 정해 주어야 한다. 이때 쓰는 것이 `key` 인자다. `key`에는 "항목 하나를 받아 비교에 쓸 값을 돌려주는 함수"를 넣는다. 보통 `lambda`로 짧게 쓴다.

```python
data = [("kim", 90), ("lee", 85), ("park", 88)]
sorted(data, key=lambda x: x[1])   # 점수 오름차순 -> lee, park, kim
```

- `lambda x: x[1]`은 "항목 `x`를 받아 `x[1]`을 돌려주는" 1회용 익명 함수다. 즉 아래와 똑같은 일을 이름 없이 한 줄로 적은 것이다.

```python
def f(x):        # lambda x: x[1] 과 완전히 동일
    return x[1]
sorted(data, key=f)
```

- 여러 기준을 동시에 쓰려면 `key`가 "튜플"을 돌려주게 한다. 파이썬은 튜플을 앞 원소부터 순서대로 비교하므로, `(1순위, 2순위, ...)`를 만들면 다중 조건 정렬이 된다.

```python
# 점수 내림차순, 점수가 같으면 이름 오름차순
sorted(data, key=lambda x: (-x[1], x[0]))
```

- 오름차순 기준을 내림차순으로 뒤집는 손쉬운 방법: 숫자는 `-값`을 key로 준다. `reverse=True`는 "모든 기준"을 한꺼번에 뒤집으므로, 기준마다 방향이 다를 때는 `-`를 섞어 쓰는 편이 안전하다.

**접근 전략**

- 문제의 정렬 규칙을 "1순위는 무엇, 같으면 2순위는 무엇, 또 같으면 3순위는 무엇" 형태로 말로 먼저 정리한다. 그 순서대로 `key`의 튜플에 나열하면 그대로 코드가 된다.
- 각 순위마다 오름차순이면 값을 그대로, 내림차순이면 앞에 `-`를 붙인다(숫자일 때). 문자열을 내림차순으로 하고 싶으면 `reverse=True`를 쓰거나 문제 범위에서 다른 기법을 고민한다.
- 언제 쓰나: 랭킹표 만들기, 동점자 처리, 구간을 시작점 기준으로 줄 세우기, "길이 먼저 그다음 사전순" 같은 복합 정렬. 실전 정렬 문제의 대부분이 이 다중 키 패턴이다.
- 주의점: `key`가 돌려주는 튜플의 "필드 위치·부호"가 규칙과 정확히 일치하는지 예제로 검산한다. 복잡도는 여전히 O(N log N)이며, `key` 계산은 항목마다 한 번씩만 이뤄진다.

**문제**

**1) 성적 순위표** · Medium

- **요구사항**: 학생들의 (이름, 점수)를 점수 내림차순으로 정렬하되, 점수가 같으면 이름 사전순(오름차순)으로 정렬해 출력한다.
- **입력**: 첫 줄에 N. 다음 N줄에 이름 점수.
- **출력**: 정렬된 순서대로 각 줄에 "이름 점수".
- **예제**: `4 / kim 90 / lee 85 / park 90 / choi 85` → `kim 90` / `park 90` / `choi 85` / `lee 85`
- **예제**: `2 / z 50 / a 50` → `a 50` / `z 50`
- **셀프체크**: `key=lambda x: (-x[1], x[0])` 처럼 1순위(점수 내림)와 2순위(이름 오름)를 튜플로 묶었는가. 점수를 정수로 변환했는가. 동점자 순서가 규칙대로 나오는지 예제로 확인했는가.

```runner
@@SOLUTION
n = int(input())
students = []
for _ in range(n):
    parts = input().split()
    students.append((parts[0], int(parts[1])))
students.sort(key=lambda x: (-x[1], x[0]))
for name, score in students:
    print(name, score)
@@TESTS

@@EXPL
(1) 접근·핵심 아이디어

- 정렬 규칙을 말로 정리한다: 1순위 점수 내림차순, 같으면 2순위 이름 오름차순.
- 방향이 서로 다르므로 `reverse=True` 하나로는 안 된다. 숫자 점수는 부호를 뒤집어 `-점수`로 내림차순을, 문자열 이름은 그대로 오름차순을 만든다.

(2) 코드 단계별

- N줄을 읽어 `(이름, 점수)` 튜플 리스트를 만든다. 점수는 `int(parts[1])`로 변환.
- `students.sort(key=lambda x: (-x[1], x[0]))`: 키 튜플의 첫 원소 `-x[1]`가 작을수록(=점수 클수록) 앞, 같으면 둘째 원소 `x[0]`(이름) 오름차순.
- 정렬된 순서대로 `print(name, score)`로 한 줄씩 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- 규칙을 "1순위 …, 같으면 2순위 …" 문장으로 먼저 적는다.
- 각 순위마다 방향을 정하고, 내림차순 숫자는 `-`, 오름차순은 그대로 → 키 튜플로 나열.
- 동점 케이스(kim·park 90 / z·a 50)로 순서가 규칙대로 나오는지 검산.
```

**2) 키·몸무게 줄 세우기** · Medium

- **요구사항**: 사람들의 (키, 몸무게)를 키 내림차순으로, 키가 같으면 몸무게 오름차순으로 정렬해 출력한다.
- **입력**: 첫 줄에 N. 다음 N줄에 키 몸무게(정수).
- **출력**: 정렬된 순서대로 각 줄에 "키 몸무게".
- **예제**: `4 / 180 75 / 175 70 / 180 70 / 175 72` → `180 70` / `180 75` / `175 70` / `175 72`
- **예제**: `2 / 170 60 / 170 55` → `170 55` / `170 60`
- **셀프체크**: 두 기준의 방향이 서로 다르다(하나는 내림, 하나는 오름). `reverse=True` 하나로는 안 되고, 키에 `-`를 붙이는 식으로 방향을 각각 맞췄는가. 같은 키에서 몸무게 순서가 오름인지 확인.

```runner
@@SOLUTION
n = int(input())
people = []
for _ in range(n):
    h, w = map(int, input().split())
    people.append((h, w))
people.sort(key=lambda x: (-x[0], x[1]))
for h, w in people:
    print(h, w)
@@TESTS

(1) 접근·핵심 아이디어

- 두 기준의 방향이 서로 다르다: 키는 내림차순, 몸무게는 오름차순.
- 숫자 키는 부호를 뒤집으면 방향이 바뀐다. 그래서 키 튜플을 `(-키, 몸무게)`로 만든다. `-키`는 내림, `몸무게`는 그대로 오름.

(2) 코드 단계별

- N줄에서 `h, w = map(int, ...)`로 두 정수를 읽어 `(키, 몸무게)` 튜플 리스트를 만든다.
- `people.sort(key=lambda x: (-x[0], x[1]))`: 1순위 `-x[0]`(키 내림), 2순위 `x[1]`(몸무게 오름).
- 정렬된 순서대로 `print(h, w)`로 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- 규칙: 1순위 키 내림, 2순위 몸무게 오름.
- 방향이 엇갈리면 `reverse=True` 하나로는 불가능 → 숫자마다 `-`로 방향을 개별 지정.
- 같은 키(180끼리, 175끼리)에서 몸무게가 오름차순으로 나오는지 예제로 검산.
```

**3) 단어 정렬: 길이 먼저, 같으면 사전순** · Medium

- **요구사항**: 단어 N개를 길이 오름차순으로, 길이가 같으면 사전순으로 정렬해 출력한다.
- **입력**: 첫 줄에 N. 다음 N개의 단어.
- **출력**: 정렬된 순서대로 각 단어를 한 줄에 하나씩(또는 공백 구분) 출력.
- **예제**: `5 / banana apple kiwi fig pear` → `fig kiwi pear apple banana`  (길이 3,4,4,5,6 / 길이 4인 kiwi·pear는 사전순)
- **예제**: `3 / bb aa cc` → `aa bb cc`  (모두 길이 2 → 사전순)
- **셀프체크**: `key=lambda w: (len(w), w)` 형태로 "길이 → 사전순" 순서를 지켰는가. 길이가 같은 단어들끼리만 사전순이 되는지 예제로 확인. 중복 단어가 있으면 각각을 그대로 출력하는가(중복 제거 요구가 없음에 주의).

```runner
@@SOLUTION
import sys
data = sys.stdin.read().split()
n = int(data[0])
words = data[1:1 + n]
words.sort(key=lambda w: (len(w), w))
print(*words)
@@TESTS
--IN
5
banana apple kiwi fig pear
--OUT
fig kiwi pear apple banana
--IN
3
bb aa cc
--OUT
aa bb cc
@@EXPL
(1) 접근·핵심 아이디어

- 정렬 규칙: 1순위 길이 오름차순, 같으면 2순위 사전순(오름차순). 둘 다 오름차순이라 부호 뒤집기가 필요 없다.
- 키 튜플을 `(len(w), w)`로 만들면 파이썬이 앞 원소(길이)부터 비교하고, 같을 때만 뒤 원소(단어 자체)를 비교한다 — 정확히 원하는 순서다.

(2) 코드 단계별

- 첫 토큰 N, 이후 N개가 단어이므로 전체를 `split()`으로 읽고 슬라이싱한다.
- `words.sort(key=lambda w: (len(w), w))`로 "길이 → 사전순" 정렬한다.
- `print(*words)`로 공백 구분 한 줄 출력한다(중복 제거 요구가 없으므로 그대로 둔다).

(3) 스스로 다시 짤 때 생각 순서

- 규칙을 "길이 먼저, 같으면 사전순"으로 적고 그대로 키 튜플 `(len(w), w)`에 옮긴다.
- 둘 다 오름차순이면 부호를 건드릴 필요가 없다는 점을 확인한다.
- 길이 4인 `kiwi`·`pear`가 사전순으로 나오는지 예제로 검산한다.
```
