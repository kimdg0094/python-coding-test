## L3. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch08(완전탐색 III)의 핵심 — "상황 하나를 가정하고 끝까지 진행해 검증하는" 완전탐색과 "탐색의 기준을 더 작은 축으로 새로 잡는" 완전탐색 — 을 **반복 훈련**하고, 시뮬레이션형 코딩테스트 단골 유형으로 **확장**하는 연습 세트다.
- **반복 훈련 개념**:
  - 시작값 가정 → 도미노 전개 → 검증: `for x in range(1, H + 1): cur = x; for d in diffs: cur += d; if 범위 밖: break`
  - 시작점·방향을 전부 시도한 뒤 시뮬레이션: `for start in ...: for d in range(4): x, y = start; while 진행 가능: x += dx[d]; y += dy[d]`
  - 첫 선택만 가정하면 나머지가 결정: `for first in (0, 1): ... for i in range(1, N): 앞칸 상태를 보고 강제 결정`
  - 기준 좌표·기준 값을 입력에서 뽑아 고정: `for i in range(N): x0 = xs[i]; ... 나머지는 세기만`
  - 기준을 "어떤 원소가 최솟값인가"로 바꾸기: `for i in range(N): 왼쪽·오른쪽으로 h[i] 이상인 동안 확장`
- **코딩테스트 출제 맵**: 삼성 SW 역량테스트의 '시뮬레이션' 유형(격자 위 이동·회전), 백준 「단계별로 풀어보기」의 '브루트 포스' 단계, NeetCode 150의 'Greedy'(원형 주유소)에서 이 유형이 등장한다.
- **문제 구성표**:

|---|------|--------|-----------|------|

**문제**

**1) 차이 목록으로 수열 복원** · Easy

- **요구사항**: 길이 n인 수열이 있는데 첫 항만 모른다. 대신 이웃한 항의 차이 목록 d_1, ..., d_(n-1)이 주어진다(`a[i+1] = a[i] + d_i`). 모든 항이 **1 이상 H 이하**가 되도록 하는 **첫 항 a[1]의 후보 개수**를 구하라.
- **입력**: 첫 줄에 n과 H (2 ≤ n ≤ 100, 1 ≤ H ≤ 1000). 둘째 줄에 n-1개의 정수 d_i (각 |값| ≤ 100).
- **출력**: 조건을 만족하는 첫 항의 개수.
- **예제**: `4 10 / 3 -5 4` → `5` (첫 항 x면 수열은 x, x+3, x-2, x+2 → x는 3~7) · `3 5 / 10 -10` → `0`
- **셀프체크**: 차이의 부호가 섞여 있으면 수열이 단조가 아니므로 양 끝만 검사하면 틀린다 — 가정마다 항을 **끝까지 전개**하며 모든 항을 검사해야 한다. 도중에 범위를 벗어나면 즉시 `break`로 버린다. 차이가 전부 0이면 첫 항 1..H 전부가 답(넷째 테스트).

```runner
@@SOLUTION
def main():
    import sys
    data = sys.stdin.read().split()
    n = int(data[0]); H = int(data[1])
    d = [int(data[2 + i]) for i in range(n - 1)]
    count = 0
    for x in range(1, H + 1):
        cur = x
        ok = True
        for i in range(n - 1):
            cur += d[i]
            if cur < 1 or cur > H:
                ok = False
                break
        if ok:
            count += 1
    print(count)

main()

@@EXPL
(1) 접근·핵심 아이디어

- 첫 항 x 하나만 정하면 나머지 항은 차이 목록으로 도미노처럼 전부 정해진다. 그러니 가정할 미지수는 첫 항 하나이고, 후보는 1..H다.
- 앞 챕터의 등차수열과 달리 차이의 부호가 섞이므로 수열이 단조가 아니다. 양 끝만 봐서는 안 되고, 각 가정마다 실제로 항을 전개하며 모든 항이 1..H인지 검사한다.

(2) 코드 단계별

- n, H와 차이 배열 `d`를 읽고 `count = 0`으로 시작한다.
- `x`를 1..H로 가정하고 `cur = x`에서 출발해 `d[i]`를 차례로 더한다.
- 더할 때마다 `cur < 1 or cur > H`이면 이 가정은 실패이므로 `ok = False`로 두고 `break`.
- 끝까지 살아남으면 `count += 1`. 마지막에 `count` 출력.

(3) 스스로 다시 짤 때 생각 순서

- "하나만 정하면 나머지가 다 정해지는 값" → 첫 항. 후보 범위 1..H.
- 단조가 아니므로 항을 끝까지 전개해 전부 검사(O(H·n)).
- 차이가 전부 0(답 H), 도저히 못 맞추는 경우(답 0)로 경계 검산.
```

**2) 복도 청소 로봇의 방향 고르기** · Easy

- **요구사항**: 일직선 복도가 문자열로 주어진다. `S`는 로봇의 시작 칸(정확히 하나), `D`는 먼지, `#`은 벽, `.`은 빈 칸이다. 로봇은 **왼쪽 또는 오른쪽 중 한 방향**을 골라 그 방향으로만 직진하며, 벽을 만나거나 복도 끝에 닿으면 멈춘다. 지나간 칸의 먼지를 모두 치울 때, 치울 수 있는 먼지 수의 **최댓값**을 구하라.
- **입력**: 한 줄에 복도 문자열 (길이 1 이상 100 이하, `S`·`D`·`#`·`.`로만 구성).
- **출력**: 치울 수 있는 먼지 수의 최댓값.
- **예제**: `D.D#S.DDD` → `3` (왼쪽은 바로 벽, 오른쪽으로 3개) · `DD.S.#DD` → `2` (오른쪽은 벽 너머 먼지를 못 치움)
- **셀프체크**: 방향 두 가지를 모두 가정해 각각 시뮬레이션하고 더 큰 쪽을 답으로 한다. 직진은 "인덱스가 범위 안이고 벽이 아닌 동안"이라는 두 조건을 동시에 확인해야 한다(범위 검사를 먼저 해야 인덱스 오류가 없다). `S`만 있거나 양쪽이 벽이면 0.

```runner
@@SOLUTION
def main():
    import sys
    s = sys.stdin.read().split()[0]
    n = len(s)
    start = 0
    for i in range(n):
        if s[i] == 'S':
            start = i
    best = 0
    for step in (-1, 1):
        pos = start + step
        cnt = 0
        while 0 <= pos < n and s[pos] != '#':
            if s[pos] == 'D':
                cnt += 1
            pos += step
        if cnt > best:
            best = cnt
    print(best)

main()

@@EXPL
(1) 접근·핵심 아이디어

- 답을 좌우하는 선택은 "어느 방향으로 갈 것인가" 하나뿐이고 경우는 왼쪽/오른쪽 둘이다. 각 방향을 가정한 뒤 규칙대로 끝까지 직진하는 시뮬레이션을 돌려 결과를 비교한다.
- 직진은 `pos`를 `step`(-1 또는 +1)만큼 반복해서 옮기는 것이며, 멈춤 조건은 "복도 밖" 또는 "벽"이다.

(2) 코드 단계별

- 문자열 `s`를 읽고 `S`의 위치 `start`를 한 번 훑어 찾는다.
- `step`을 -1(왼쪽), +1(오른쪽)로 가정하고, `pos = start + step`부터 `0 <= pos < n and s[pos] != '#'`인 동안 전진한다.
- 지나는 칸이 `D`면 `cnt`를 올리고, 방향별 결과 중 큰 값을 `best`에 남긴다.
- `best`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "가정할 것" = 방향(2가지). 각 가정마다 시뮬레이션.
- while 조건에서 범위 검사를 벽 검사보다 먼저 써야 인덱스 오류가 없다.
- 양쪽이 모두 벽이거나 시작 칸이 끝에 붙어 있는 경우(0)로 경계 검산.
```

**3) 가장 많은 점을 지나는 세로선** · Easy

- **요구사항**: 좌표평면 위 N개의 점이 주어진다. 세로선 `x = c` 하나를 그어 그 위에 놓이는 점의 개수를 **최대**로 만들고 싶다. 최대 개수를 만드는 c와 그 개수를 출력하라. 최대를 만드는 c가 여러 개면 **가장 작은 c**를 택한다.
- **입력**: 첫 줄에 N (1 ≤ N ≤ 200). 이어 N줄에 각 점의 x y (각 |값| ≤ 1000).
- **출력**: `c 개수`를 공백으로 구분해 한 줄에.
- **예제**: `5 / 1 2 / 3 4 / 1 7 / 3 1 / 3 3` → `3 3` · `4 / 2 0 / 5 0 / 2 9 / 5 9` → `2 2` (x=2와 x=5가 2개씩이라 작은 2)
- **셀프체크**: c의 후보는 실수 전체가 아니라 **점들의 x좌표뿐**이다(점이 없는 x에 선을 그으면 0개). 후보마다 같은 x를 가진 점을 세면 O(N^2). 동률일 때 더 작은 c로 바꾸는 조건을 빠뜨리지 않았는가? N=1이면 그 점의 x와 1.

```runner
@@SOLUTION
def main():
    import sys
    data = sys.stdin.read().split()
    N = int(data[0])
    xs = []
    ys = []
    idx = 1
    for _ in range(N):
        xs.append(int(data[idx])); idx += 1
        ys.append(int(data[idx])); idx += 1
    best_c = None
    best = 0
    for i in range(N):
        c = xs[i]
        cnt = 0
        for j in range(N):
            if xs[j] == c:
                cnt += 1
        if cnt > best or (cnt == best and c < best_c):
            best = cnt
            best_c = c
    print(best_c, best)

main()

(1) 접근·핵심 아이디어

- "어느 c에 선을 긋나"를 실수 전체에서 찾을 수는 없다. 하지만 점이 하나도 없는 c는 답이 될 수 없으므로, 기준 값 c의 후보를 **입력에 등장한 x좌표들**로 새로 잡으면 후보가 N개로 줄어든다.
- 각 후보 c를 고정하면 나머지는 "x가 c인 점 세기"라는 단순 계산이다.

(2) 코드 단계별

- N과 각 점의 `xs`, `ys`를 읽는다(y는 이 문제에서 쓰이지 않지만 입력 형식대로 읽는다).
- 각 점 i의 `xs[i]`를 후보 `c`로 고정하고, 모든 점 j에 대해 `xs[j] == c`인 개수 `cnt`를 센다.
- `cnt > best`이거나, `cnt == best`인데 `c`가 더 작으면 `best`, `best_c`를 갱신한다.
- `best_c best`를 출력한다. 첫 후보에서 `best`가 0에서 반드시 갱신되므로 `best_c`가 `None`으로 남지 않는다.

(3) 스스로 다시 짤 때 생각 순서

- 탐색 축을 "실수 c"에서 "입력에 있는 x값"으로 갈아끼운다.
- 후보를 고정한 뒤 세기만 하면 됨 → O(N^2).
- 동률 규칙(가장 작은 c)을 갱신 조건에 명시하고, N=1로 검산.
```

**4) 원형 주유소 출발점 찾기** · Medium

- **요구사항**: 원형 도로에 1번부터 N번까지 주유소가 순서대로 있다. i번 주유소에서는 gas_i만큼 주유할 수 있고, i번에서 다음 주유소(N번 다음은 1번)까지 가는 데 cost_i만큼의 연료가 든다. 빈 탱크로 어떤 주유소에서 출발해 도착할 때마다 주유하며 **한 바퀴 돌아 출발점으로 돌아올 수 있는** 출발 주유소 번호 중 **가장 작은 것**을 구하라. 불가능하면 `-1`.
- **입력**: 첫 줄에 N (1 ≤ N ≤ 100). 둘째 줄에 N개의 gas_i, 셋째 줄에 N개의 cost_i (각 0 이상 1000 이하).
- **출력**: 가장 작은 출발 번호. 없으면 `-1`.
- **예제**: `5 / 1 2 3 4 5 / 3 4 5 1 2` → `4` · `3 / 2 3 4 / 3 4 3` → `-1`
- **셀프체크**: 출발점을 1..N으로 **하나씩 가정**하고, 각 가정에서 N칸을 진행하며 탱크가 음수가 되는 순간 실패로 버린다. 원형이므로 인덱스는 `(start + step) % N`. 오름차순으로 가정하다 첫 성공에서 멈추면 "가장 작은 번호"가 보장된다. N=1이면 gas ≥ cost인지만 보면 된다.

```runner
@@SOLUTION
def main():
    import sys
    data = sys.stdin.read().split()
    N = int(data[0])
    gas = [int(data[1 + i]) for i in range(N)]
    cost = [int(data[1 + N + i]) for i in range(N)]
    ans = -1
    for start in range(N):
        tank = 0
        ok = True
        for step in range(N):
            i = (start + step) % N
            tank += gas[i] - cost[i]
            if tank < 0:
                ok = False
                break
        if ok:
            ans = start + 1
            break
    print(ans)

main()

(1) 접근·핵심 아이디어

- 답을 좌우하는 미지수는 "어디서 출발하나" 하나다. 출발점을 정하면 나머지는 규칙대로 N칸을 진행하는 시뮬레이션으로 자동 결정된다.
- 그래서 출발점 N가지를 전부 가정하고, 각 가정마다 탱크를 0에서 시작해 주유·소비를 반복하며 음수가 되는지 검사한다. 전체 O(N^2)으로 N ≤ 100이면 충분하다.

(2) 코드 단계별

- N, `gas`, `cost`를 읽고 `ans = -1`로 시작한다.
- `start`를 0..N-1로 가정한다. `tank = 0`에서 `step`을 0..N-1로 돌며 `i = (start + step) % N`번 주유소에서 `tank += gas[i] - cost[i]`.
- `tank < 0`이 되면 이 출발점은 실패(`ok = False`, `break`).
- N칸을 모두 통과하면 `ans = start + 1`로 두고 바깥 반복도 `break`. 오름차순 가정이므로 첫 성공이 최소 번호다.

(3) 스스로 다시 짤 때 생각 순서

- "가정할 것" = 출발점(N가지). 각 가정 = 한 바퀴 시뮬레이션.
- 원형 인덱스 `% N`, 도중 음수 즉시 실패.
- 가장 작은 번호가 필요하니 오름차순으로 훑다 첫 성공에서 멈춘다. 불가능(-1)·N=1 검산.
```

**5) 격자 직진 코인 줍기** · Medium

- **요구사항**: N×M 격자가 주어진다. `.`은 빈 칸, `#`은 벽, `C`는 코인이 놓인 칸이다. 로봇을 **벽이 아닌 아무 칸**에 놓고 **상·하·좌·우 중 한 방향**을 정하면, 로봇은 그 방향으로 벽이나 격자 밖에 닿을 때까지 직진하며 지나는 칸(시작 칸 포함)의 코인을 모두 줍는다. 시작 칸과 방향을 잘 골랐을 때 주울 수 있는 코인 수의 **최댓값**을 구하라.
- **입력**: 첫 줄에 N과 M (1 ≤ N, M ≤ 10). 이어 N줄에 길이 M의 문자열.
- **출력**: 코인 수의 최댓값. 놓을 수 있는 칸이 없으면 0.
- **예제**: `3 4 / C.C# / .#C. / CCCC` → `4` (셋째 행 왼쪽 끝에서 오른쪽으로) · `2 2 / ## / ##` → `0`
- **셀프체크**: 시작 칸(벽 제외) × 방향 4가지를 **전부** 시도한다. 직진은 dx/dy 배열로 `x += dx[d]`, `y += dy[d]`를 반복하고, 멈춤 조건은 "격자 밖" 또는 "벽" — 범위 검사를 먼저 해야 인덱스 오류가 없다. 시작 칸의 코인도 세야 한다(넷째 테스트: 대각선은 안 되므로 1).

```runner
@@SOLUTION
def main():
    import sys
    data = sys.stdin.read().split()
    N = int(data[0]); M = int(data[1])
    g = [data[2 + i] for i in range(N)]
    dx = [-1, 1, 0, 0]
    dy = [0, 0, -1, 1]
    best = 0
    for r in range(N):
        for c in range(M):
            if g[r][c] == '#':
                continue
            for d in range(4):
                x, y = r, c
                cnt = 0
                while 0 <= x < N and 0 <= y < M and g[x][y] != '#':
                    if g[x][y] == 'C':
                        cnt += 1
                    x += dx[d]
                    y += dy[d]
                if cnt > best:
                    best = cnt
    print(best)

main()

- 직진 시뮬레이션은 dx/dy 기법 그대로다. 현재 칸이 격자 안이고 벽이 아닌 동안 코인을 세고 한 칸 전진한다.

(2) 코드 단계별

- N, M과 격자 `g`를 읽고 방향 배열 `dx`, `dy`(상·하·좌·우)를 둔다.
- 모든 칸 (r, c) 중 벽이 아닌 칸을 시작 칸으로 가정한다.
- 방향 d마다 `(x, y) = (r, c)`에서 출발해 `while 범위 안 and 벽 아님` 동안 코인이면 `cnt += 1`, 그다음 `x += dx[d]`, `y += dy[d]`.
- 각 시뮬레이션의 `cnt`로 `best`를 갱신하고 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- 한 가정의 처리 = dx/dy 직진 while. 범위 검사 → 벽 검사 순서.
- 시작 칸 코인 포함, 벽뿐인 격자(0), 1행 격자로 검산.
```

**6) K×K 정사각형 안의 점 최대** · Medium

- **요구사항**: 좌표평면 위 N개의 점이 있다. 한 변의 길이가 K인 정사각형(변이 축과 평행, 경계 포함)을 하나 놓아 **안에 들어오는 점의 개수를 최대**로 만들어라. 정사각형의 왼쪽 아래 꼭짓점 (x0, y0)은 **어떤 점의 x좌표**와 **어떤 점의 y좌표**(서로 다른 점이어도 됨)로 잡는 것으로 충분하다.
- **입력**: 첫 줄에 N과 K (1 ≤ N ≤ 100, 1 ≤ K ≤ 1000). 이어 N줄에 각 점의 x y (각 0 이상 1000 이하).
- **출력**: 정사각형 안에 들어오는 점 수의 최댓값.
- **예제**: `5 2 / 0 0 / 1 1 / 2 2 / 5 5 / 6 6` → `3` · `3 5 / 0 5 / 5 0 / 5 5` → `3` (x0는 첫째 점, y0는 둘째 점에서 가져와 (0,0)에 놓는다)
- **셀프체크**: 기준 좌표 후보를 "점들의 x좌표 × 점들의 y좌표"로 잡아야 한다 — x와 y를 같은 점에서만 가져오면 둘째 예제처럼 답을 놓친다. 판정은 `x0 <= x <= x0+K`와 `y0 <= y <= y0+K`를 **둘 다** 만족(경계 포함). 점이 K보다 멀리 떨어져 있으면 답은 1(셋째 테스트).

```runner
def main():
    import sys
    data = sys.stdin.read().split()

            y0 = ys[j]
            cnt = 0
            for p in range(N):
                if x0 <= xs[p] <= x0 + K and y0 <= ys[p] <= y0 + K:
                    cnt += 1
            if cnt > best:
                best = cnt
    print(best)

- 기준을 고정하면 나머지는 "정사각형 안에 있는 점 세기"라는 단순 계산이다. 전체 O(N^3)으로 N ≤ 100이면 충분하다.

(2) 코드 단계별

- N, K와 각 점의 `xs`, `ys`를 읽는다.
- 모든 i, j에 대해 `x0 = xs[i]`, `y0 = ys[j]`를 정사각형의 왼쪽 아래 꼭짓점으로 고정한다.
- 모든 점 p에 대해 `x0 <= xs[p] <= x0+K`이고 `y0 <= ys[p] <= y0+K`이면 `cnt += 1`.
- `cnt`의 최댓값 `best`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "어디에 놓나"라는 무한한 축을 "점들의 x × 점들의 y"라는 유한한 기준으로 갈아끼운다.
- x와 y 후보는 서로 다른 점에서 가져와도 된다는 점을 놓치지 않는다(둘째 예제).
- 경계 포함(≤)과 K가 작아 점 하나만 들어가는 경우(답 1)로 검산.
```

**7) 가장 넓은 직사각형: 최소 막대를 기준으로** · Medium

- **요구사항**: 너비 1인 막대 N개가 나란히 서 있고 높이가 주어진다. **연속한 막대들**을 골라 그 안에 완전히 들어가는 직사각형을 그리면, 넓이는 `(고른 구간의 최소 높이) × (구간 길이)`다. 만들 수 있는 직사각형 넓이의 **최댓값**을 구하라. 구간을 전부 나열하지 말고 "어떤 막대가 최솟값이 되는가"를 기준으로 생각해 보라.
- **입력**: 첫 줄에 N (1 ≤ N ≤ 200). 둘째 줄에 N개의 높이 (각 1 이상 1000 이하).
- **출력**: 직사각형 넓이의 최댓값.
- **예제**: `6 / 2 1 5 6 2 3` → `10` (높이 5·6 두 개로 5×2) · `3 / 4 4 4` → `12`
- **셀프체크**: 막대 i를 "구간의 최솟값"으로 고정하면, 그 구간은 i에서 왼쪽·오른쪽으로 **높이가 h[i] 이상인 동안** 최대한 넓힌 것이 가장 넓다. 같은 높이(`>=`)도 포함해 넓혀야 둘째 예제가 12가 된다. 확장 시 인덱스 범위 검사를 먼저 하는지 확인. N=1이면 그 막대 높이가 답.

```runner
@@SOLUTION
def main():
    import sys
    data = sys.stdin.read().split()
    N = int(data[0])
    h = [int(data[1 + i]) for i in range(N)]
    best = 0
    for i in range(N):
        l = i
        while l - 1 >= 0 and h[l - 1] >= h[i]:
            l -= 1
        r = i
        while r + 1 < N and h[r + 1] >= h[i]:
            r += 1
        area = h[i] * (r - l + 1)
        if area > best:
            best = area
    print(best)

main()

- 구간(시작, 끝)을 전부 나열하고 각 구간의 최솟값을 구하면 O(N^3)이다. 축을 바꾼다: 모든 직사각형은 "어떤 막대 하나가 최솟값 역할"을 하므로, **최솟값이 되는 막대 i**를 기준으로 잡으면 후보는 N개뿐이다.
- 막대 i가 최솟값이면 구간은 i에서 좌우로 `h >= h[i]`인 동안 최대한 넓혀야 가장 넓다. 그러면 넓이는 `h[i] × 길이`로 바로 나온다. 전체 O(N^2).

(2) 코드 단계별

- N과 높이 배열 `h`를 읽고 `best = 0`으로 시작한다.
- 각 i에 대해 `l = i`에서 `h[l-1] >= h[i]`인 동안 왼쪽으로, `r = i`에서 `h[r+1] >= h[i]`인 동안 오른쪽으로 넓힌다(범위 검사를 먼저).
- `area = h[i] * (r - l + 1)`로 `best`를 갱신한다.
- `best`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- 기준을 고정하면 좌우 확장은 while 두 개.
- 같은 높이 포함(`>=`), N=1, 단조 감소 배열로 검산.
```

**8) 램프 전부 켜기: 첫 스위치만 가정** · Hard

- **요구사항**: 일렬로 놓인 N개의 램프 상태가 0(꺼짐)/1(켜짐) 문자열로 주어진다. i번 스위치(1 ≤ i ≤ N)를 누르면 **i-1, i, i+1번 램프**의 상태가 뒤집힌다(범위 밖은 무시). 스위치를 눌러 **모든 램프를 켜는 최소 누름 횟수**를 구하라. 불가능하면 `-1`. (같은 스위치를 두 번 누르는 것은 의미가 없다.)
- **입력**: 한 줄에 램프 상태 문자열 (길이 1 이상 100 이하, `0`과 `1`로만 구성).
- **출력**: 최소 누름 횟수. 불가능하면 `-1`.
- **예제**: `1001` → `4` · `0000` → `2` (1번과 4번 스위치)
- **셀프체크**: 1번 스위치를 누를지 말지 **두 가지만 가정**하면, 그다음부터는 "i-1번 램프가 꺼져 있으면 i번 스위치를 반드시 눌러야 한다"는 규칙으로 나머지 선택이 도미노처럼 강제된다(i번 램프 왼쪽을 고칠 수 있는 마지막 스위치가 i번이므로). 끝까지 진행한 뒤 **마지막 램프**가 켜져 있는지로 성공을 판정한다. 두 가정 모두 실패하면 `-1`, 이미 전부 켜져 있으면 0(셋째 테스트).

```runner
@@SOLUTION
def main():
    import sys
    s = sys.stdin.read().split()[0]
    N = len(s)
    best = -1
    for first in (0, 1):
        state = [int(ch) for ch in s]
        presses = 0
        if first == 1:
            presses = 1
            for k in (0, 1):
                if k < N:
                    state[k] = 1 - state[k]
        for i in range(1, N):
            if state[i - 1] == 0:
                presses += 1
                for k in (i - 1, i, i + 1):
                    if k < N:
                        state[k] = 1 - state[k]
        if state[N - 1] == 1:
            if best == -1 or presses < best:
                best = presses
    print(best)

main()

(1) 접근·핵심 아이디어

- 스위치 N개를 누를지 말지 전부 가정하면 2^N이라 너무 많다. 그런데 **1번 스위치만 가정**하면 나머지는 자동으로 정해진다: i번 스위치를 정할 차례에 i-1번 램프가 꺼져 있다면, 그 램프를 뒤집을 수 있는 스위치는 이제 i번뿐이므로 반드시 눌러야 하고, 켜져 있다면 누르면 안 된다.
- 즉 가정은 2가지(1번을 누른다/안 누른다)뿐이고, 각 가정을 왼쪽에서 오른쪽으로 전개한 뒤 마지막 램프가 켜져 있는지로 검증한다. 두 가정 중 성공한 것들의 최소 횟수가 답이다.

(2) 코드 단계별

- 문자열을 정수 리스트 `state`로 복사한다(가정마다 새로 복사해야 서로 섞이지 않는다).
- `first == 1`이면 1번 스위치를 눌러 램프 0, 1번(0부터 셈)을 뒤집고 `presses = 1`.
- i를 1..N-1로 돌며 `state[i-1] == 0`이면 i번 스위치를 눌러 `i-1, i, i+1`을 뒤집고(범위 검사) `presses += 1`.
- 전개가 끝난 뒤 `state[N-1] == 1`이면 성공 — `best`를 더 작은 값으로 갱신. 두 가정 모두 실패면 `best`는 `-1` 그대로.

(3) 스스로 다시 짤 때 생각 순서

- "하나만 정하면 나머지가 강제되는 선택"을 찾는다 → 1번 스위치.
- 가정 2개 × 왼쪽부터 강제 전개 O(N) → 전체 O(N).
- 마지막 램프로 성공 판정, 상태 배열은 가정마다 새로 복사, 길이 1·이미 전부 켜짐 검산.
```

**9) 구슬 굴리기: 막히면 오른쪽으로** · Hard

- **요구사항**: N×M 격자(`.` 빈 칸, `#` 벽)에 구슬을 **빈 칸 아무 곳**에 놓고 **상·우·하·좌 중 한 방향**으로 굴린다. 구슬은 한 번에 한 칸씩, 최대 K번 이동한다. 이동 규칙: 현재 방향의 다음 칸이 격자 안의 빈 칸이면 그 칸으로 이동(이동 1회 소모). 아니면 **시계 방향으로 90도 회전**(상→우→하→좌→상)하며, 회전은 이동 횟수를 소모하지 않는다. 한 칸에서 네 방향 모두 막혀 4번 연속 회전하면 그 자리에서 멈춘다. 시작 칸과 방향을 잘 골랐을 때, 구슬이 **지나간 서로 다른 칸의 수**(시작 칸 포함)의 최댓값을 구하라.
- **입력**: 첫 줄에 N, M, K (1 ≤ N, M ≤ 8, 0 ≤ K ≤ 50). 이어 N줄에 길이 M의 문자열.
- **출력**: 서로 다른 방문 칸 수의 최댓값. 빈 칸이 없으면 0.
- **예제**: `3 3 5 / ... / .#. / ...` → `6` · `1 4 10 / ....` → `4` (왕복하지만 서로 다른 칸은 4개)
- **셀프체크**: 시작 칸 × 방향 4가지를 전부 시도하고, 각 시도마다 **방문 배열을 새로** 만든다. 종료 조건은 "이동 K회 소모" 또는 "연속 회전 4회"이며, 이동에 성공하면 연속 회전 횟수를 0으로 되돌려야 한다(안 그러면 한 번 막혔던 이력이 남아 조기 종료된다). 되돌아온 칸은 다시 세지 않는다. K=0이면 답은 1(셋째 테스트).

```runner
@@SOLUTION
def main():
    import sys
    data = sys.stdin.read().split()
    N = int(data[0]); M = int(data[1]); K = int(data[2])
    g = [data[3 + i] for i in range(N)]
    dx = [-1, 0, 1, 0]
    dy = [0, 1, 0, -1]
    best = 0
    for sr in range(N):
        for sc in range(M):
            if g[sr][sc] == '#':
                continue
            for sd in range(4):
                visited = [[False] * M for _ in range(N)]
                x, y, d = sr, sc, sd
                visited[x][y] = True
                cnt = 1
                moves = 0
                turns = 0
                while moves < K and turns < 4:
                    nx = x + dx[d]
                    ny = y + dy[d]
                    if 0 <= nx < N and 0 <= ny < M and g[nx][ny] == '.':
                        x, y = nx, ny
                        moves += 1
                        turns = 0
                        if not visited[x][y]:
                            visited[x][y] = True
                            cnt += 1
                    else:
                        d = (d + 1) % 4
                        turns += 1
                if cnt > best:
                    best = cnt
    print(best)

main()

(1) 접근·핵심 아이디어

- 결과를 좌우하는 것은 "시작 칸"과 "시작 방향"인데 후보가 작다(칸 ≤ 64, 방향 4). 모든 조합을 가정하고 규칙대로 K번 이동하는 시뮬레이션을 돌려 최댓값을 취하는 삼성 스타일 문제의 축소판이다.
- 시뮬레이션의 핵심은 규칙을 정확히 옮기는 것이다: 다음 칸이 갈 수 있으면 이동(이동 횟수 +1, 연속 회전 0으로 초기화), 아니면 시계 방향 회전(연속 회전 +1). 종료는 이동 K회 또는 연속 회전 4회.

(2) 코드 단계별

- N, M, K와 격자를 읽고 방향 배열을 시계 방향 순서(상·우·하·좌)로 둔다. 오른쪽 회전은 `d = (d + 1) % 4`.
- 빈 칸마다, 방향마다 `visited`를 새로 만들고 시작 칸을 방문 처리(`cnt = 1`).
- `moves < K and turns < 4`인 동안: 다음 칸이 격자 안의 `.`이면 이동하고 `moves += 1`, `turns = 0`, 새 칸이면 `cnt += 1`. 아니면 회전하고 `turns += 1`.
- 각 시도의 `cnt`로 `best`를 갱신해 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "가정할 것" = 시작 칸 × 방향. 각 가정 = 규칙 시뮬레이션.
- 방향 배열을 회전 순서대로 두면 회전이 `(d+1) % 4` 한 줄이 된다.
- 이동 성공 시 연속 회전 리셋, 방문 배열은 시도마다 새로, K=0(답 1)·전부 벽(답 0)으로 검산.
```

**10) 한 직선 위에 놓인 점의 최대 개수** · Hard

- **요구사항**: 좌표평면 위 서로 다른 N개의 점이 주어진다. 한 직선 위에 놓이는 점의 개수의 **최댓값**을 구하라. 모든 점 쌍으로 직선을 만들지 말고, **기준점 하나를 고정**한 뒤 다른 점들을 "기준점에서 본 방향"으로 묶어 세는 방식으로 풀라.
- **입력**: 첫 줄에 N (1 ≤ N ≤ 100). 이어 N줄에 각 점의 x y (각 |값| ≤ 1000, 모든 점은 서로 다름).
- **출력**: 한 직선 위에 놓이는 점 수의 최댓값 (N=1이면 1).
- **예제**: `5 / 0 0 / 1 1 / 2 2 / 3 1 / 4 0` → `3` · `4 / 0 0 / 0 5 / 0 9 / 3 3` → `3` (세로선 x=0)
- **셀프체크**: 기준점 i에서 점 j로의 방향 (dx, dy)는 최대공약수로 나눠 기약 형태로 만들어야 (2,4)와 (1,2)가 같은 방향으로 묶인다. 또 기준점 양쪽에 있는 점은 (1,1)과 (-1,-1)처럼 부호만 다르므로 **부호를 통일**(dx>0, 또는 dx=0이면 dy>0)해야 같은 직선으로 묶인다(셋째 테스트). 세로선은 dx=0이라 나눗셈 없이 처리되는지 확인. 최댓값은 "같은 방향 점 수 + 기준점 1".

```runner
@@SOLUTION
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a

def main():
    import sys
    data = sys.stdin.read().split()
    N = int(data[0])
    xs = []
    ys = []
    idx = 1
    for _ in range(N):
        xs.append(int(data[idx])); idx += 1
        ys.append(int(data[idx])); idx += 1
    best = 1
    for i in range(N):
        count = {}
        for j in range(N):
            if j == i:
                continue
            dx = xs[j] - xs[i]
            dy = ys[j] - ys[i]
            g = gcd(abs(dx), abs(dy))
            dx //= g
            dy //= g
            if dx < 0 or (dx == 0 and dy < 0):
                dx = -dx
                dy = -dy
            key = (dx, dy)
            count[key] = count.get(key, 0) + 1
            if count[key] + 1 > best:
                best = count[key] + 1
    print(best)

main()

(1) 접근·핵심 아이디어

- "어느 두 점이 직선을 만드나"를 축으로 잡고 나머지 점의 일직선 여부를 검사하면 O(N^3)이다. 축을 **기준점 하나**로 바꾸면, 기준점을 지나는 직선은 "기준점에서 본 방향"으로 구별되므로, 다른 점들을 방향별로 묶어 세기만 하면 된다. 전체 O(N^2).
- 방향 (dx, dy)는 최대공약수로 나눠 기약 형태로 만들고(같은 직선 위의 점은 배율만 다르다), 기준점 양쪽 점이 (1,1)·(-1,-1)로 갈리지 않도록 부호를 통일한다. 한 방향의 점 수 + 1(기준점)이 그 직선 위의 점 수다.

(2) 코드 단계별

- 유클리드 호제법으로 `gcd`를 만든다(0과 양수의 gcd는 그 양수이므로 세로·가로 방향도 안전).
- 기준점 i마다 빈 딕셔너리 `count`를 만들고, 다른 점 j에 대해 `(dx, dy)`를 구해 gcd로 나눈다.
- `dx < 0` 또는 `dx == 0 and dy < 0`이면 부호를 뒤집어 통일한 뒤, `count[(dx, dy)]`를 1 올린다.
- `count[key] + 1`로 `best`를 갱신한다. `best`는 1에서 시작하므로 N=1도 처리된다.

(3) 스스로 다시 짤 때 생각 순서

- 축을 "점 쌍"에서 "기준점 + 방향"으로 갈아끼운다.
- 방향 정규화 = gcd로 나누기 + 부호 통일. 둘 중 하나라도 빠지면 같은 직선이 갈라진다.
- 세로선(dx=0), 기준점 양쪽에 점이 있는 경우, N=1로 검산.
```
