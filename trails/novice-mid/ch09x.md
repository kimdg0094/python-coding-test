## L5. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch09(케이스별로 나누기)의 핵심 — 겹치는 경우 정리, 결과로부터 원인 추론, 좋은 전략만 추려내기, 가능한 상황 나열 — 을 **반복 훈련**하고, 조건 분기가 핵심인 코딩테스트 단골 유형으로 **확장**하는 연습 세트다.
- **반복 훈련 개념**:
  - 구간의 교집합·합집합: 교집합 길이 `max(0, min(e) - max(s))`, 합집합은 정렬 후 `if s <= cur_e: cur_e = max(cur_e, e)`
  - 포함-배제: `|A∪B∪C| = |A|+|B|+|C| - |A∩B| - |B∩C| - |A∩C| + |A∩B∩C|`, 배수 개수는 `N // lcm`
  - 역추론 + 검증: 식을 미지수에 대해 풀고(`a = (S + D) // 2`) 정수·범위 조건을 마지막에 확인
  - 좋은 전략 추리기: 극단(정렬 후 양 끝)만 후보 — `max(a[-1]*a[-2]*a[-3], a[0]*a[1]*a[-1])`
  - 가능한 상황 나열: 서로 배타적이고 전부를 덮는 `if / elif / else` 사슬, 검사 순서가 곧 정의
- **코딩테스트 출제 맵**: NeetCode 150의 'Intervals'(구간 병합·겹침), 『이것이 취업을 위한 코딩테스트다』의 '구현'·'그리디' 파트, solved.ac CLASS 2의 조건 분기·수학 문제에서 이 유형이 등장한다.

**문제**

**1) 전원이 동시에 접속한 시간** · Easy

- **요구사항**: N명이 각각 접속 시각 s부터 종료 시각 e까지 온라인이다(분 단위, 구간 [s, e]). **N명 모두가 동시에** 온라인인 시간의 길이(분)를 구하라. 그런 시간이 없으면 0.
- **입력**: 첫 줄에 N (1 ≤ N ≤ 50). 이어 N줄에 s e (0 ≤ s < e ≤ 1440).
- **출력**: 전원 동시 접속 시간의 길이.
- **예제**: `3 / 60 180 / 120 240 / 100 200` → `60` (120~180) · `2 / 0 100 / 100 200` → `0` (한 점에서 맞닿아도 길이는 0)
- **셀프체크**: 여러 구간의 교집합은 "가장 늦은 시작 ~ 가장 이른 끝"이다. 끝이 시작보다 앞서면 음수가 되므로 `max(0, ...)`로 막아야 한다. N=1이면 그 구간 길이 그대로.

```runner
@@SOLUTION
import sys
def solve():
    data = sys.stdin.read().split()
    N = int(data[0])
    idx = 1
    lo = int(data[1]); hi = int(data[2])
    for _ in range(N):
        s = int(data[idx]); e = int(data[idx + 1]); idx += 2
        if s > lo:
            lo = s
        if e < hi:
            hi = e
    print(max(0, hi - lo))
solve()

(1) 접근·핵심 아이디어

- 모두가 동시에 온라인인 시간 = 모든 구간의 교집합이다. 교집합의 시작은 "가장 늦은 시작", 끝은 "가장 이른 끝"이므로 구간을 하나씩 보며 `max(s)`와 `min(e)`만 유지하면 된다.
- 겹치지 않는 경우 `min(e) < max(s)`가 되어 길이가 음수로 나오므로, `max(0, 길이)`로 잘라 0을 답한다. 한 점에서 맞닿는 경우(둘째 예제)도 길이 0이다.

(2) 코드 단계별

- N을 읽고 `lo`, `hi`를 첫 구간의 s, e로 초기화한다.
- 구간을 차례로 읽으며 `s > lo`면 `lo = s`, `e < hi`면 `hi = e`로 갱신한다.
- `max(0, hi - lo)`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "겹치는 부분"을 구하는 문제 → 교집합 = [max 시작, min 끝].
- 교집합이 비면 길이가 음수 → 0으로 절단하는 것이 함정.
- 맞닿는 경우(0)와 N=1(구간 길이 그대로)로 검산.
```

**2) 합과 차로 두 자연수 복원** · Easy

- **요구사항**: 두 자연수 a, b(각 1 이상)가 있었는데 값을 잊어버렸고, 합 S = a + b와 차 D = a − b만 기억한다. a와 b를 복원하라. 조건을 만족하는 자연수 쌍이 없으면 `-1`.
- **입력**: 한 줄에 S와 D (2 ≤ S ≤ 10^9, |D| ≤ 10^9).
- **출력**: `a b`를 공백으로 구분해 한 줄에. 불가능하면 `-1`.
- **예제**: `10 4` → `7 3` · `7 2` → `-1` (S+D가 홀수라 정수 해가 없음)
- **셀프체크**: 두 식을 더하면 `2a = S + D`, 빼면 `2b = S − D`. S+D가 홀수면 정수 해가 없고, 짝수여도 a나 b가 0 이하이면 자연수가 아니다(셋째 테스트: b=0). D가 음수면 a < b인 정상적인 경우다(넷째 테스트).

```runner
@@SOLUTION
import sys
def solve():
    data = sys.stdin.read().split()
    S, D = int(data[0]), int(data[1])
    if (S + D) % 2 != 0:
        print(-1)
        return
    a = (S + D) // 2
    b = (S - D) // 2
    if a >= 1 and b >= 1:
        print(a, b)
    else:
        print(-1)
solve()

(1) 접근·핵심 아이디어

- 관찰(합과 차)로부터 원인(원래 두 수)을 역으로 알아내는 추론 문제다. 정방향 규칙 `S = a + b`, `D = a − b`를 미지수에 대해 풀면 `a = (S + D) / 2`, `b = (S − D) / 2`로 후보가 단 하나 나온다.
- 후보가 나왔다고 끝이 아니다. 문제의 도메인 제약(정수이고 1 이상)을 통과하는지 검증해야 하며, 어긋나면 "복원 불가(-1)"다.

(2) 코드 단계별

- S, D를 읽고 `(S + D) % 2 != 0`이면 정수 해가 없으므로 `-1`.
- `a = (S + D) // 2`, `b = (S − D) // 2`를 계산한다(S+D가 짝수면 S−D도 짝수).
- `a >= 1 and b >= 1`이면 `a b` 출력, 아니면 `-1`.

(3) 스스로 다시 짤 때 생각 순서

- 관찰 → 식 세우기 → 미지수에 대해 풀기.
- 정수 조건(홀짝)과 범위 조건(≥ 1)을 순서대로 검증하는 것이 함정.
- D가 음수인 경우와 b=0이 되는 경계로 검산.
```

**3) 곱의 부호만 알아내기** · Easy

- **요구사항**: N개의 정수를 모두 곱한 값의 **부호**만 알아내라. 실제로 곱하지 말고 케이스를 나누어 판정한다.
- **입력**: 첫 줄에 N (1 ≤ N ≤ 50). 둘째 줄에 N개의 정수 (각 |값| ≤ 10^9).
- **출력**: 곱이 0이면 `0`, 양수면 `+`, 음수면 `-`.
- **예제**: `3 / -2 5 -3` → `+` · `4 / 1 -1 0 9` → `0`
- **셀프체크**: 케이스는 "0이 하나라도 있음 / 없으면 음수 개수가 홀수 / 짝수" 세 가지로 서로 배타적이고 전부를 덮는다. 0 검사를 **먼저** 해야 한다(0이 있으면 음수 개수와 무관). 양수는 부호에 영향이 없으므로 세지 않아도 된다.

```runner
@@SOLUTION
import sys
def solve():
    data = sys.stdin.read().split()
    N = int(data[0])
    a = [int(data[1 + i]) for i in range(N)]
    neg = 0
    zero = False
    for x in a:
        if x == 0:
            zero = True
        elif x < 0:
            neg += 1
    if zero:
        print(0)
    elif neg % 2 == 1:
        print("-")
    else:
        print("+")
solve()

(1) 접근·핵심 아이디어

- 곱의 부호는 두 정보로 결정된다: 0이 포함되어 있는가, 음수가 몇 개인가(홀수면 음수, 짝수면 양수). 양수는 부호를 바꾸지 않는다.
- 케이스를 "0 있음 → 0", "음수 홀수 → −", "그 외 → +"로 나누면 배타적이고 빠짐없다. 0 판정이 다른 두 케이스보다 우선한다는 순서가 핵심이다.

(2) 코드 단계별

- 배열을 한 번 훑으며 0이 있으면 `zero = True`, 음수면 `neg += 1`.
- `zero`면 `0`, 아니면 `neg % 2`로 `-`/`+`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "케이스를 가르는 축"을 먼저 정한다 → 0의 존재, 음수 개수의 홀짝.
- 검사 순서: 0 → 홀짝. 순서가 바뀌면 `0 × (음수)`가 `-`로 잘못 나온다.
- N=1(음수 하나)·양수만 있는 경우로 검산.
```

**4) 겹치는 예약 덩어리 세기** · Medium

- **요구사항**: 수직선 위에 N개의 예약 구간 [s, e]가 있다. 서로 겹치거나 **끝점이 맞닿는** 구간들은 하나의 덩어리로 이어진다. 덩어리의 **개수**와 **가장 긴 덩어리의 길이**를 구하라.
- **입력**: 첫 줄에 N (1 ≤ N ≤ 100). 이어 N줄에 s e (0 ≤ s < e ≤ 10^4).
- **출력**: `덩어리수 최장길이`를 공백으로 구분해 한 줄에.
- **예제**: `4 / 1 3 / 2 6 / 8 10 / 15 18` → `3 5` ([1,6], [8,10], [15,18]) · `3 / 0 5 / 5 9 / 9 12` → `1 12` (맞닿아 하나로 이어짐)
- **셀프체크**: 시작 기준 정렬 후 "현재 덩어리의 끝 `cur_e`"를 유지하며, 새 구간의 시작이 `cur_e` **이하**(맞닿음 포함)면 병합하고 끝을 `max`로 늘린다. 완전히 포함되는 구간([1,10] 안의 [2,3])은 끝을 줄이면 안 된다(넷째 테스트). 마지막 덩어리를 반복이 끝난 뒤 한 번 더 집계하는 것을 잊지 말 것.

```runner
@@SOLUTION
import sys
def solve():
    data = sys.stdin.read().split()
    N = int(data[0])
    segs = []
    idx = 1
    for _ in range(N):
        s = int(data[idx]); e = int(data[idx + 1]); idx += 2
        segs.append((s, e))
    segs.sort()
    groups = 0
    longest = 0
    cur_s, cur_e = segs[0]
    for i in range(1, N):
        s, e = segs[i]
        if s <= cur_e:
            if e > cur_e:
                cur_e = e
        else:
            groups += 1
            if cur_e - cur_s > longest:
                longest = cur_e - cur_s
            cur_s, cur_e = s, e
    groups += 1
    if cur_e - cur_s > longest:
        longest = cur_e - cur_s
    print(groups, longest)
solve()

(1) 접근·핵심 아이디어

- 겹치는 구간을 하나로 합치는 합집합 문제다. 시작점 기준으로 정렬하면, 각 구간은 "현재 덩어리에 붙는다" 또는 "새 덩어리를 시작한다" 둘 중 하나의 케이스로만 떨어진다.
- 붙는 조건은 `s <= cur_e`(맞닿음 포함). 붙을 때 덩어리의 끝은 `max(cur_e, e)`로만 늘려야 하고, 완전히 포함된 구간 때문에 끝이 줄어들면 안 된다.

(2) 코드 단계별

- 구간을 `(s, e)`로 읽어 정렬하고, 첫 구간을 현재 덩어리 `[cur_s, cur_e]`로 둔다.
- 두 번째 구간부터: `s <= cur_e`면 `cur_e = max(cur_e, e)`. 아니면 현재 덩어리를 집계(개수 +1, 최장 갱신)하고 새 덩어리로 교체.
- 반복이 끝난 뒤 마지막 덩어리를 한 번 더 집계하고 `groups longest`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- 정렬 → 스위핑 → "붙는다 / 새로 시작" 두 케이스.
- 맞닿음 포함(`<=`), 끝은 `max`로만 갱신, 마지막 덩어리 집계 — 세 가지 함정.
- N=1과 하나에 전부 포함되는 경우로 검산.
```

**5) 어느 배수도 아닌 수 세기** · Medium

- **요구사항**: 1 이상 N 이하의 정수 중 a의 배수도, b의 배수도, c의 배수도 **아닌** 수의 개수를 구하라. N이 크므로 반복문으로 세지 말고 포함-배제로 계산한다.
- **입력**: 한 줄에 N a b c (1 ≤ N ≤ 10^9, 1 ≤ a, b, c ≤ 1000).
- **출력**: 조건을 만족하는 수의 개수.
- **예제**: `10 2 3 5` → `2` (1, 7) · `20 4 6 10` → `12`
- **셀프체크**: 세 집합의 합집합 크기는 `|A|+|B|+|C| − |A∩B| − |B∩C| − |A∩C| + |A∩B∩C|`. 교집합의 배수 개수는 곱이 아니라 **최소공배수**로 나눠야 한다(4와 6의 공배수는 24가 아니라 12의 배수). a=b=c처럼 같은 수가 들어와도 식이 그대로 맞는지(넷째 테스트), 전부 1이면 답이 0인지(셋째 테스트) 확인.

```runner
@@SOLUTION
import sys, math
def solve():
    data = sys.stdin.read().split()
    N, a, b, c = int(data[0]), int(data[1]), int(data[2]), int(data[3])
    def lcm(x, y):
        return x * y // math.gcd(x, y)
    ab = lcm(a, b); bc = lcm(b, c); ac = lcm(a, c)
    abc = lcm(ab, c)
    bad = N // a + N // b + N // c - N // ab - N // bc - N // ac + N // abc
    print(N - bad)
solve()
@@TESTS

@@EXPL
(1) 접근·핵심 아이디어

- "어느 배수도 아닌 수" = N − (a·b·c 중 하나라도의 배수인 수). 후자는 세 집합의 합집합이라 단순 합산하면 겹치는 수가 여러 번 세어진다. 3집합 포함-배제로 겹침을 정리한다.
- k의 배수 개수는 `N // k`이고, 두 수의 공배수는 lcm의 배수이므로 교집합 항은 `N // lcm`으로 계산한다. N이 10^9라도 전부 O(1) 계산이다.

(2) 코드 단계별

- `lcm(x, y) = x * y // gcd(x, y)`를 정의한다.
- 쌍의 lcm 세 개와 셋의 lcm(`lcm(lcm(a, b), c)`)을 구한다.
- `bad = N//a + N//b + N//c − N//ab − N//bc − N//ac + N//abc`.
- `N − bad`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "하나라도 해당"은 합집합 → 포함-배제, 3집합이면 항이 7개.
- 교집합은 곱이 아닌 lcm — 가장 흔한 실수.
- 같은 수가 반복되거나 전부 1인 경계로 검산.
```

**6) 뒤집힌 구간 찾기** · Medium

- **요구사항**: 서로 다른 정수로 이루어진 오름차순 배열이 있었는데, 누군가 **연속한 구간 하나를 뒤집어** 지금의 배열 B가 되었다(구간 길이 1이면 변화 없음). B를 보고 원래대로 되돌리기 위해 뒤집어야 할 구간 `[l, r]`(1부터 시작하는 번호)을 찾아라. B가 이미 오름차순이면 `0 0`, 구간 하나를 뒤집어서는 정렬이 안 되면 `-1`.
- **입력**: 첫 줄에 N (1 ≤ N ≤ 100). 둘째 줄에 서로 다른 N개의 정수.
- **출력**: `l r` 또는 `0 0` 또는 `-1`.
- **예제**: `6 / 1 5 4 3 2 6` → `2 5` · `5 / 3 1 2 5 4` → `-1`
- **셀프체크**: 원래 배열은 `sorted(B)`로 복원된다. 정렬본과 다른 **첫 위치 l과 마지막 위치 r**을 찾으면 후보 구간은 그것뿐이다 — 하지만 그 구간을 실제로 뒤집어 정렬본과 같은지 **재현 검증**해야 한다(둘째 예제는 다른 위치가 [1,5]이지만 뒤집어도 정렬이 안 된다). 다른 위치가 없으면 `0 0`.

```runner
@@SOLUTION
import sys
def solve():
    data = sys.stdin.read().split()
    N = int(data[0])
    B = [int(data[1 + i]) for i in range(N)]
    S = sorted(B)
    l = 0
    while l < N and B[l] == S[l]:
        l += 1
    if l == N:
        print(0, 0)
        return
    r = N - 1
    while B[r] == S[r]:
        r -= 1
    seg = B[l:r + 1]
    seg.reverse()
    if B[:l] + seg + B[r + 1:] == S:
        print(l + 1, r + 1)
    else:
        print(-1)
solve()

(1) 접근·핵심 아이디어

- 결과 B에서 "무슨 일이 있었나"를 역으로 추론한다. 원래 상태는 정렬본 S이므로, B와 S가 다른 자리들이 곧 뒤집힌 구간의 흔적이다. 다른 자리의 첫 위치 l과 마지막 위치 r 사이가 유일한 후보다.
- 후보를 얻었다고 끝이 아니다. `[l, r]`을 실제로 뒤집어 S와 같아지는지 재현 검증해야 한다. 다른 자리가 l..r 안에 있어도 그 안의 순서가 "정확히 뒤집힌 형태"가 아닐 수 있기 때문이다(둘째 예제).

(2) 코드 단계별

- `S = sorted(B)`로 원래 배열을 복원한다.
- 앞에서부터 `B[l] == S[l]`인 동안 l을 올린다. `l == N`이면 이미 정렬 → `0 0`.
- 뒤에서부터 `B[r] == S[r]`인 동안 r을 내린다(l에서 이미 다른 자리가 있으므로 r ≥ l에서 멈춘다).
- `B[l:r+1]`을 뒤집어 앞뒤와 이어 붙인 결과가 S와 같으면 `l+1 r+1`, 아니면 `-1`.

(3) 스스로 다시 짤 때 생각 순서

- "원래 상태"를 먼저 복원(정렬)하고 관찰과 비교해 달라진 범위를 찾는다.
- 후보는 하나뿐이지만 반드시 재현해서 검증한다.
- 이미 정렬(0 0), 전체 뒤집힘(1 N), 검증 실패(-1)로 검산.
```

**7) 세 수의 곱 최대: 후보는 양 끝뿐** · Medium

- **요구사항**: N개의 정수(음수 포함 가능) 중 **서로 다른 세 개**를 골라 곱을 최대로 만들어라. 모든 세 개 조합을 보지 말고, 정렬 후 "좋은 후보"만 비교해서 풀라.
- **입력**: 첫 줄에 N (3 ≤ N ≤ 200). 둘째 줄에 N개의 정수 (각 |값| ≤ 1000).
- **출력**: 세 수 곱의 최댓값.
- **예제**: `5 / 1 2 3 4 5` → `60` · `5 / -10 -9 1 2 3` → `270` (음수 둘 × 가장 큰 양수)
- **셀프체크**: 최대 곱은 "가장 큰 세 수의 곱" 또는 "가장 작은 두 수(큰 음수 둘) × 가장 큰 수" 둘 중 하나다 — 다른 조합은 이 둘 중 하나에 지배당한다. 전부 음수면 "가장 큰 세 수"(절댓값이 작은 셋)가 답(셋째 테스트). 0이 섞이면 0이 답일 수 있다(넷째 테스트).

```runner
@@SOLUTION
import sys
def solve():
    data = sys.stdin.read().split()
    N = int(data[0])
    a = sorted(int(data[1 + i]) for i in range(N))
    c1 = a[-1] * a[-2] * a[-3]
    c2 = a[0] * a[1] * a[-1]
    print(max(c1, c2))
solve()

(1) 접근·핵심 아이디어

- 세 개 조합을 전부 보면 O(N^3)이지만, 곱을 최대로 만드는 조합은 극단값에서만 나온다. 양수끼리 크게 만들려면 가장 큰 셋, 음수 둘을 곱해 양수로 만들려면 가장 작은 둘 + 가장 큰 하나. 이 두 후보 외의 조합은 둘 중 하나로 바꿔도 손해가 없으므로(교환 논증) 볼 필요가 없다.
- 전부 음수일 때도 "가장 큰 셋"(절댓값이 가장 작은 셋)이 후보 1에 들어 있어 같은 식으로 처리된다.

(2) 코드 단계별

- 배열을 오름차순 정렬한다.
- `c1 = a[-1]*a[-2]*a[-3]`(최대 셋), `c2 = a[0]*a[1]*a[-1]`(최소 둘 × 최대 하나).
- `max(c1, c2)`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "좋은 후보만 남기기": 정렬 후 양 끝 조합 두 개만.
- 음수 둘의 곱이 양수라는 점 때문에 후보 2가 필요함을 잊지 않는다.
- 전부 음수(답이 음수), 0 포함, N=3(두 후보가 같은 조합)으로 검산.
```

**8) 두 구간의 관계 분류** · Hard

- **요구사항**: 닫힌 구간 A = [a1, b1]과 B = [a2, b2] 쌍이 Q개 주어진다. 각 쌍의 관계를 다음 여섯 가지 중 정확히 하나로 분류하라. `SAME`(완전히 같음), `APART`(떨어져 있음, 공통점 없음), `TOUCH`(끝점 하나에서만 만남), `CONTAIN`(A가 B를 포함, 같지는 않음), `INSIDE`(A가 B 안에 포함, 같지는 않음), `CROSS`(일부만 겹침).
- **입력**: 첫 줄에 Q (1 ≤ Q ≤ 50). 이어 Q줄에 a1 b1 a2 b2 (0 ≤ a1 < b1 ≤ 1000, 0 ≤ a2 < b2 ≤ 1000).
- **출력**: Q줄에 각 쌍의 분류 문자열.
- **예제**: `3 / 1 4 3 8 / 1 5 5 9 / 2 4 1 9` → `CROSS / TOUCH / INSIDE` · `3 / 1 5 1 5 / 1 5 2 5 / 1 2 5 7` → `SAME / CONTAIN / APART`
- **셀프체크**: 여섯 케이스가 배타적이고 전부를 덮게 하려면 **검사 순서**가 정의의 일부다: 같음 → 떨어짐 → 맞닿음 → 포함 → 안에 포함 → 나머지(부분 겹침). 예를 들어 [1,5]와 [2,5]는 끝점 5를 공유하지만 맞닿음(`b1 == a2` 또는 `b2 == a1`)이 아니라 포함이다. 같음을 포함보다 먼저 검사해야 `CONTAIN`으로 새지 않는다.

```runner
@@SOLUTION
import sys
def solve():
    data = sys.stdin.read().split()
    Q = int(data[0])
    idx = 1
    out = []
    for _ in range(Q):
        a1, b1 = int(data[idx]), int(data[idx + 1])
        a2, b2 = int(data[idx + 2]), int(data[idx + 3])
        idx += 4
        if a1 == a2 and b1 == b2:
            out.append("SAME")
        elif b1 < a2 or b2 < a1:
            out.append("APART")
        elif b1 == a2 or b2 == a1:
            out.append("TOUCH")
        elif a1 <= a2 and b2 <= b1:
            out.append("CONTAIN")
        elif a2 <= a1 and b1 <= b2:
            out.append("INSIDE")
        else:
            out.append("CROSS")
    print("\n".join(out))
solve()

(1) 접근·핵심 아이디어

- 두 구간의 위치 관계는 겹침 판정(`b1 < a2 or b2 < a1`이면 안 겹침)에서 출발해, 겹치는 경우를 다시 "끝점만 공유 / 한쪽이 다른 쪽을 포함 / 일부만 겹침"으로 세분하는 케이스 나열 문제다.
- 여섯 케이스가 서로 배타적이면서 전부를 덮도록 만드는 열쇠는 검사 순서다. 앞 조건에서 걸러진 것을 전제로 뒤 조건을 단순하게 쓸 수 있다: 같음을 먼저 빼면 포함 조건에 `<=`를 써도 `SAME`과 겹치지 않고, 떨어짐·맞닿음을 먼저 빼면 마지막 `else`가 정확히 "일부만 겹침"이 된다.

(2) 코드 단계별

- 각 쌍에 대해 `a1 == a2 and b1 == b2`면 `SAME`.
- `b1 < a2 or b2 < a1`이면 `APART`(공통점 없음).
- `b1 == a2 or b2 == a1`이면 `TOUCH`(앞에서 떨어짐이 걸러졌으므로 이 등호는 정확히 한 점 공유).
- `a1 <= a2 and b2 <= b1`이면 `CONTAIN`, `a2 <= a1 and b1 <= b2`면 `INSIDE`, 나머지는 `CROSS`.
- 결과를 줄마다 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- 큰 분기: 안 겹침(떨어짐/맞닿음) vs 겹침(같음/포함/부분).
- 검사 순서를 정의의 일부로 삼고, 각 단계에서 "앞에서 무엇이 걸러졌나"를 의식한다.
- [1,5]·[2,5]처럼 끝점을 공유하지만 포함인 경우, 한 점 맞닿음, 완전 동일로 검산.
```

**9) 영수증으로 주차 시간 범위 추론** · Hard

- **요구사항**: 주차장 요금은 이렇다. 주차 시간이 **30분 이하**면 기본요금 B원. 30분을 넘기면 초과분 **10분마다**(10분 미만도 10분으로 올림) U원씩 추가된다. 단, 하루 요금은 **최대 M원**을 넘지 않는다. 영수증에 요금 F원이 찍혀 있을 때, 주차 시간(1분 이상 1440분 이하의 정수)으로 가능한 **최솟값과 최댓값**을 구하라. 그런 시간이 없으면 `-1`.
- **입력**: 한 줄에 B U M F (1 ≤ B ≤ M ≤ 10^5, 1 ≤ U ≤ 10^4, 0 ≤ F ≤ 10^6).
- **출력**: `최소분 최대분`을 공백으로 구분해 한 줄에. 불가능하면 `-1`.
- **예제**: `1000 500 5000 2000` → `41 50` (초과 2단위: 초과분 11~20분) · `1000 500 5000 5000` → `101 1440` (상한 도달)
- **셀프체크**: 정방향 규칙(시간 → 요금)을 케이스 세 개(기본 / 초과 단위 계산 / 상한 절단)로 정확히 세운 뒤, 시간 후보 1..1440을 **전부 대입해 요금이 F인 것의 최소·최대**를 취하는 역추론이다. 올림은 `(t − 30 + 9) // 10`. 기본요금과 같은 F는 1~30분(셋째 테스트), 어느 단위에도 안 맞는 F는 `-1`(넷째 테스트).

```runner
@@SOLUTION
import sys
def solve():
    data = sys.stdin.read().split()
    B, U, M, F = int(data[0]), int(data[1]), int(data[2]), int(data[3])
    lo = -1
    hi = -1
    for t in range(1, 1441):
        if t <= 30:
            fee = B
        else:
            units = (t - 30 + 9) // 10
            fee = B + units * U
            if fee > M:
                fee = M
        if fee == F:
            if lo == -1:
                lo = t
            hi = t
    if lo == -1:
        print(-1)
    else:
        print(lo, hi)
solve()

(1) 접근·핵심 아이디어

- 관찰(요금 F)로부터 원인(주차 시간)을 추론한다. 요금 규칙을 역으로 풀어 식으로 만들 수도 있지만 케이스(기본/초과/상한)마다 식이 달라 실수하기 쉽다. 대신 원인의 후보가 1..1440분으로 유한하므로, **정방향 규칙을 정확히 세운 뒤 모든 후보를 대입해 검증**하는 것이 안전하다.
- 정방향 규칙은 세 케이스다: 30분 이하는 B, 초과분은 10분 단위 올림 × U를 더하되, M을 넘으면 M으로 절단.

(2) 코드 단계별

- B, U, M, F를 읽고 `lo = hi = -1`로 시작한다.
- t를 1..1440으로 돌며 요금을 계산한다: `t <= 30`이면 B, 아니면 `units = (t − 30 + 9) // 10`, `fee = min(M, B + units*U)`.
- `fee == F`이면 첫 t를 `lo`에, 매번 `hi`를 갱신한다(오름차순이므로 마지막이 최대).
- `lo`가 -1이면 불가능, 아니면 `lo hi` 출력.

(3) 스스로 다시 짤 때 생각 순서

- 정방향 규칙을 케이스별로 먼저 정확히 세운다(올림, 상한).
- 후보가 유한하면 역산 대신 전수 대입으로 검증하는 것이 안전.
- 기본요금 구간(1~30), 상한 구간(끝이 1440), 불가능(-1)으로 검산.
```

**10) 상점 하나 건너뛰기 최소 이동** · Hard

- **요구사항**: 수직선 위 원점 0에서 출발해 N개의 상점(좌표 x_i)을 방문한다. 순서는 자유이고 마지막에 돌아올 필요는 없다. 단, **최대 한 곳은 건너뛰어도** 된다. 필요한 **최소 이동 거리**를 구하라. 모든 건너뛰기 후보를 보지 말고 "좋은 후보"만 비교해서 풀라.
- **입력**: 첫 줄에 N (1 ≤ N ≤ 100). 둘째 줄에 N개의 정수 좌표 (각 |값| ≤ 10^4).
- **출력**: 최소 이동 거리.
- **예제**: `4 / -3 5 -8 2` → `11` (−8을 건너뛰고 −3 → 5: 3+3+5) · `3 / 4 9 1` → `4` (9를 건너뛰면 4까지만)
- **셀프체크**: 가장 왼쪽 상점 L(≤ 0)과 가장 오른쪽 상점 R(≥ 0)이 정해지면 최소 거리는 `min(2|L| + R, 2R + |L|)`(가까운 쪽을 먼저 다녀온다)이다. 중간 상점을 건너뛰어도 L, R이 그대로라 이득이 없으므로, 건너뛸 후보는 **가장 왼쪽 또는 가장 오른쪽** 둘뿐이다. 모든 상점이 한쪽에만 있으면 L 또는 R이 0이 되어 식이 자연스럽게 "가장 먼 상점까지"가 된다. N=1이면 그 하나를 건너뛰어 0.

```runner
@@SOLUTION
import sys
def solve():
    data = sys.stdin.read().split()
    N = int(data[0])
    xs = sorted(int(data[1 + i]) for i in range(N))
    def cost(pts):
        if len(pts) == 0:
            return 0
        L = min(0, pts[0])
        R = max(0, pts[-1])
        return min(2 * (-L) + R, 2 * R + (-L))
    print(min(cost(xs[1:]), cost(xs[:-1])))
solve()

(1) 접근·핵심 아이디어

- 상점 집합이 정해지면 이동 거리는 양 끝 L, R로만 결정된다: 한쪽을 먼저 갔다 돌아와 반대쪽으로 가므로 `min(2|L| + R, 2R + |L|)`. 이 값은 |L|과 R이 작을수록 좋다.
- "무엇을 건너뛸까"는 N가지지만, 중간 상점을 건너뛰면 L, R이 안 바뀌어 이득이 없다. 즉 가장 왼쪽 또는 가장 오른쪽을 건너뛰는 두 전략만 좋은 후보이고, 나머지는 지배당하므로 버린다. 건너뛰기는 손해가 없으므로 "안 건너뛰기"도 볼 필요가 없다.

(2) 코드 단계별

- 좌표를 정렬한다.
- `cost(pts)`: 비어 있으면 0, 아니면 `L = min(0, 최소)`, `R = max(0, 최대)`로 두고 `min(2·(−L) + R, 2R + (−L))`.
- `xs[1:]`(가장 왼쪽 제외)과 `xs[:-1]`(가장 오른쪽 제외) 두 후보의 `cost` 중 작은 값을 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- 결과를 결정하는 요소(L, R)를 먼저 찾고 비용식을 세운다.
- 후보 N개 중 지배당하는 것(중간 상점)을 논리로 제거해 2개만 남긴다.
- 한쪽에만 있는 경우(L 또는 R이 0), N=1(0), 양쪽 대칭으로 검산.
```
