## L3. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch07(완전탐색 II)의 핵심 — "물체를 고르는" 완전탐색과 "정답 값을 직접 대입하는" 완전탐색 — 을 **반복 훈련**하고, 코딩테스트 단골 유형으로 **확장**하는 연습 세트다.
- **반복 훈련 개념**:
  - 하나 빼기: N개 중 하나를 제외한 나머지를 평가 — `for skip in range(N): ... if i != skip`
  - 둘 고르기: 서로 다른 두 위치 `i<j`의 모든 쌍 — `for i in range(N): for j in range(i + 1, N)`
  - 셋 고르기: 삼중 중첩 for로 모든 세 개 조합 — `for k in range(j + 1, N)`
  - 부분집합(비트마스크): 2^N개 조합 — `for mask in range(1 << N): if mask & (1 << i)`
  - 값 기준 완전탐색: 답이 될 값 v를 [lo, hi]에서 훑으며 판정 — `for v in range(lo, hi + 1): if check(v): ans = v`
- **코딩테스트 출제 맵**: 백준 「단계별로 풀어보기」의 '브루트 포스' 단계, 프로그래머스 「코딩테스트 고득점 Kit」의 '완전탐색', 『이것이 취업을 위한 코딩테스트다』의 '구현' 파트에서 이 유형이 그대로 등장한다.
- **문제 구성표**:

| # | 문제 | 난이도 | 반복 개념 | 유형 |
|---|------|--------|-----------|------|
| 1 | 한 장을 빼면 합이 딱 맞는다 | Easy | 하나 빼기 | 반복 훈련 |

**문제**

**1) 한 장을 빼면 합이 딱 맞는다** · Easy

- **요구사항**: N장의 카드에 정수가 적혀 있다. 정확히 **한 장을 빼서** 남은 카드 합이 T가 되게 하려 한다. 빼야 하는 카드의 번호(1부터 시작)를 구하라. 가능한 카드가 여러 장이면 **가장 작은 번호**, 불가능하면 `-1`.
- **입력**: 첫 줄에 N과 T (1 ≤ N ≤ 100, |T| ≤ 10^6). 둘째 줄에 N개의 정수 (각 |값| ≤ 10^4).
- **출력**: 빼야 하는 카드 번호. 없으면 `-1`.
- **예제**: `5 10 / 1 2 3 4 5` → `5` (전체 15에서 5를 빼면 10) · `4 6 / 2 2 2 2` → `1` (아무 장이나 되지만 가장 작은 번호)
- **셀프체크**: 매번 N-1개를 다시 더하지 말고 `전체합 - a[skip]`으로 O(1)에 판정하는가? 조건을 만족하는 첫 번호에서 멈추면 "가장 작은 번호"가 자동으로 보장된다. N=1이면 한 장을 빼고 남은 합은 0이다.

```runner
@@SOLUTION
import sys

def main():
    data = sys.stdin.read().split()
    N = int(data[0]); T = int(data[1])
    a = [int(data[2 + i]) for i in range(N)]
    total = sum(a)
    ans = -1
    for skip in range(N):
        if total - a[skip] == T:
            ans = skip + 1
            break
    print(ans)

main()
@@TESTS

1 2 3 4 5
--OUT

--IN

--OUT

--IN

--OUT

--IN

--OUT

@@EXPL
(1) 접근·핵심 아이디어

- "하나를 뺀다"는 N가지 경우뿐이다. 빼는 카드 `skip`을 0부터 N-1까지 하나씩 가정하고, 그때 남는 합이 T인지 검사하는 물체 단위 완전탐색이다.
- 남는 합은 매번 다시 더할 필요 없이 `전체합 - a[skip]`으로 즉시 계산된다. 이렇게 하면 전체 O(N)이다.

(2) 코드 단계별

- N, T와 카드 배열 `a`, 그리고 `total = sum(a)`를 준비한다.
- `skip`을 0..N-1로 돌며 `total - a[skip] == T`이면 `ans = skip + 1`(1부터 시작하는 번호)로 두고 `break`한다.
- 앞에서부터 훑다가 처음 만족하는 곳에서 멈추므로 자동으로 가장 작은 번호가 된다. 끝까지 없으면 `ans`는 `-1` 그대로.

(3) 스스로 다시 짤 때 생각 순서

- "빼는 카드 하나"가 완전탐색의 대상 → 후보 N개.
- 각 후보의 평가는 `total - a[skip]` 한 번의 뺄셈.
- 가장 작은 번호가 필요하면 오름차순으로 훑다 첫 성공에서 멈추고, 실패 시 `-1`을 잊지 않는다. N=1(남는 합 0)도 자연스럽게 처리되는지 확인.
```

**2) 곱이 정확히 K인 카드 쌍** · Easy

- **요구사항**: N개의 양의 정수가 적힌 카드가 있다. **서로 다른 두 장(위치 기준)** 을 골라 두 수의 곱이 정확히 K가 되는 **쌍의 개수**를 구하라. 같은 값이 여러 장이면 각각 다른 카드로 센다.
- **입력**: 첫 줄에 N과 K (2 ≤ N ≤ 200, 1 ≤ K ≤ 10^6). 둘째 줄에 N개의 정수 (각 1 이상 1000 이하).
- **출력**: 곱이 K인 쌍의 개수.
- **예제**: `5 12 / 3 4 2 6 12` → `2` (3×4, 2×6) · `4 4 / 2 2 2 1` → `3` (2가 세 장이라 2×2 쌍이 3개)
- **셀프체크**: `j`를 `i + 1`부터 돌려 (i, j)와 (j, i)를 두 번 세지 않았는가? 같은 카드를 두 번 쓰는 (i, i)는 제외해야 한다. 값이 같은 카드도 위치가 다르면 서로 다른 쌍이다.

```runner
@@SOLUTION
import sys

def main():
    data = sys.stdin.read().split()
    N = int(data[0]); K = int(data[1])
    a = [int(data[2 + i]) for i in range(N)]
    cnt = 0
    for i in range(N):
        for j in range(i + 1, N):
            if a[i] * a[j] == K:
                cnt += 1
    print(cnt)

main()

@@EXPL
(1) 접근·핵심 아이디어

- 두 장을 고르는 모든 방법은 N(N-1)/2가지뿐이다. 중첩 for로 i<j인 모든 쌍을 나열하고 곱이 K인지 검사하는 "둘 고르기" 완전탐색이다.
- 곱은 순서가 없으므로 (i, j)와 (j, i)는 같은 쌍이다. 안쪽 반복을 `i + 1`부터 시작하면 중복 없이 한 번씩만 본다.

(2) 코드 단계별

- N, K와 배열 `a`를 읽는다.
- 바깥 `i`는 0..N-1, 안쪽 `j`는 `i + 1`..N-1로 돌며 `a[i] * a[j] == K`이면 `cnt`를 1 올린다.
- 마지막에 `cnt`를 출력한다. N=2이면 쌍이 하나뿐이고, 곱이 K가 아니면 0이다.

(3) 스스로 다시 짤 때 생각 순서

- "서로 다른 두 장" → 위치 쌍 (i, j), i<j.
- 안쪽 반복 시작을 `i + 1`로 두어 중복·자기 자신 제거.
- 값이 같아도 위치가 다르면 별개 쌍임을 기억한다(둘째 예제의 3개).
```

**3) M개 이상을 나누는 가장 큰 수** · Easy

- **요구사항**: N개의 양의 정수가 있다. 정수 v(1 이상)를 고르면 "v의 배수"인 원소들이 v로 나누어떨어진다. 나누어떨어지는 원소가 **M개 이상**이 되는 v 중 **가장 큰 값**을 구하라. (v=1은 항상 모든 원소를 나누므로 답은 반드시 존재한다.)
- **입력**: 첫 줄에 N과 M (1 ≤ M ≤ N ≤ 100). 둘째 줄에 N개의 정수 (각 1 이상 1000 이하).
- **출력**: 조건을 만족하는 가장 큰 v.
- **예제**: `5 3 / 12 18 6 9 7` → `6` (v=6이면 12, 18, 6의 3개) · `4 2 / 5 7 11 13` → `1`
- **셀프체크**: v의 후보 범위를 1..max(a)로 잡았는가(그보다 큰 v는 아무것도 못 나눈다)? 조건은 "M개 **이상**"이라 등호를 포함해야 한다. M=N이면 답은 모든 수의 최대공약수와 같아진다(넷째 테스트).

```runner
@@SOLUTION
import sys

def main():
    data = sys.stdin.read().split()
    N = int(data[0]); M = int(data[1])
    a = [int(data[2 + i]) for i in range(N)]
    ans = 1
    for v in range(1, max(a) + 1):
        cnt = 0
        for x in a:
            if x % v == 0:
                cnt += 1
        if cnt >= M:
            ans = v
    print(ans)

main()
@@TESTS

--IN

--OUT

--IN

20
--OUT

--IN

--OUT

@@EXPL
(1) 접근·핵심 아이디어

- 답은 조합이 아니라 "하나의 값 v"다. v가 정해지면 배열을 한 번 훑어 배수 개수를 세는 것으로 판정이 끝나므로, 값 기준 완전탐색이 맞는다.
- v의 후보는 1부터 배열의 최댓값까지면 충분하다. 최댓값보다 큰 v는 어떤 원소도 나누지 못한다.

(2) 코드 단계별

- N, M과 배열 `a`를 읽고 `ans = 1`로 시작한다(v=1은 항상 조건을 만족).
- `v`를 1..max(a)로 훑으며 `x % v == 0`인 원소 수 `cnt`를 센다.
- `cnt >= M`이면 `ans = v`로 덮어쓴다. 오름차순으로 훑으므로 마지막에 남는 값이 조건을 만족하는 최대 v다.
- `ans`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "답 = 값 하나(v)"임을 알아채고 후보 범위 [1, max]를 정한다.
- 판정 함수: v의 배수 개수 ≥ M (등호 포함).
- 최대를 원하니 오름차순으로 훑으며 만족할 때마다 덮어쓴다. M=N이면 최대공약수가 나오는지로 검산.
```

**4) 세 상자 무게 한도 맞추기** · Medium

- **요구사항**: N개의 상자 무게가 주어진다. **정확히 3개**를 골라 무게 합이 한도 W **이하**이면서 **최대**가 되게 하라. 그 최대 합과, 그 합을 만드는 **조합의 개수**(위치가 다르면 다른 조합)를 함께 출력한다. 세 개를 골라 W 이하가 되는 방법이 하나도 없으면 `-1`만 출력한다.
- **입력**: 첫 줄에 N과 W (3 ≤ N ≤ 30, 1 ≤ W ≤ 10^5). 둘째 줄에 N개의 무게 (각 1 이상 10^4 이하).
- **출력**: `최대합 조합수`를 공백으로 구분해 한 줄에. 불가능하면 `-1`.
- **예제**: `5 20 / 5 6 7 8 9` → `20 2` (5+6+9, 5+7+8) · `4 10 / 4 4 4 4` → `-1`
- **셀프체크**: 삼중 for의 시작을 `j = i+1`, `k = j+1`로 두어 같은 상자를 두 번 쓰거나 순서만 다른 조합을 중복 세지 않았는가? "더 큰 합"을 찾으면 개수를 1로 **리셋**하고, "같은 합"이면 개수만 올려야 한다. 같은 무게의 상자 여러 개는 위치별로 다른 조합이다(셋째 테스트: 4가 네 개면 4+4+4 조합이 4가지).

```runner
@@SOLUTION
import sys

def main():
    data = sys.stdin.read().split()
    N = int(data[0]); W = int(data[1])
    w = [int(data[2 + i]) for i in range(N)]
    best = -1
    ways = 0
    for i in range(N):
        for j in range(i + 1, N):
            for k in range(j + 1, N):
                s = w[i] + w[j] + w[k]
                if s > W:
                    continue
                if s > best:
                    best = s
                    ways = 1
                elif s == best:
                    ways += 1
    if best == -1:
        print(-1)
    else:
        print(best, ways)

main()
@@TESTS

--OUT

--IN

4 4 4 4
--OUT
-1
--IN

4 4 4 4 1 2
--OUT
12 4
--IN
4 100
1 2 3 4
--OUT

@@EXPL
(1) 접근·핵심 아이디어

- 세 개를 고르는 조합은 N(N-1)(N-2)/6개로, N ≤ 30이면 4060개뿐이다. 삼중 for로 i<j<k인 모든 조합을 나열하는 "셋 고르기" 완전탐색이다.
- 제약(합 ≤ W)으로 거른 뒤, 목표(합 최대)를 갱신하되 "최댓값을 만드는 조합의 개수"도 함께 관리한다. 최댓값이 바뀌면 개수를 1로 리셋, 같으면 1을 더한다.

(2) 코드 단계별

- N, W와 무게 배열 `w`를 읽고 `best = -1`, `ways = 0`으로 시작한다.
- `i < j < k` 삼중 반복으로 세 상자 합 `s`를 만든다. `s > W`면 `continue`로 버린다.
- `s > best`면 새 최댓값이므로 `best = s`, `ways = 1`. `s == best`면 `ways += 1`.
- 끝까지 `best`가 -1이면 조합이 없었던 것이므로 `-1`, 아니면 `best ways`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "정확히 3개" → 삼중 for, 각 반복의 시작을 앞 인덱스 +1로.
- 제약과 목표를 분리: 한도 초과는 스킵, 통과한 것 중 최대 갱신.
- 최대와 개수를 함께 갱신할 때 "리셋 vs 증가" 두 갈래를 정확히 나눈다. 전부 초과하는 경우의 `-1` 처리도 잊지 않는다.
```

**5) 하나를 빼서 오름차순 만들기** · Medium

- **요구사항**: 길이 N의 수열이 있다. **정확히 한 원소를 제거**해서 남은 수열이 **순증가**(각 원소가 바로 앞 원소보다 큼)가 되게 하려 한다. 제거했을 때 조건을 만족하는 **위치의 개수**를 구하라.
- **입력**: 첫 줄에 N (2 ≤ N ≤ 200). 둘째 줄에 N개의 정수 (각 |값| ≤ 10^4).
- **출력**: 조건을 만족하는 제거 위치의 개수.
- **예제**: `5 / 1 3 2 4 5` → `2` (3을 빼거나 2를 빼면 됨) · `4 / 1 2 3 4` → `4` (어느 것을 빼도 순증가)
- **셀프체크**: 판정은 "순증가"이므로 같은 값이 이어지면 실패다(`>=`로 검사). 이미 순증가인 수열은 어느 원소를 빼도 만족하므로 답이 N이 된다. N=2이면 하나를 빼고 남는 원소가 1개뿐이라 항상 순증가 → 답 2(넷째 테스트, 값이 같아도).

```runner
@@SOLUTION
import sys

def main():
    data = sys.stdin.read().split()
    N = int(data[0])
    a = [int(data[1 + i]) for i in range(N)]
    cnt = 0
    for skip in range(N):
        b = []
        for i in range(N):
            if i != skip:
                b.append(a[i])
        ok = True
        for i in range(1, len(b)):
            if b[i - 1] >= b[i]:
                ok = False
                break
        if ok:
            cnt += 1
    print(cnt)

main()

(1) 접근·핵심 아이디어

- 제거할 위치 `skip`은 N가지뿐이다. 각 가정마다 그 원소를 뺀 새 수열 `b`를 만들고, 인접한 원소가 모두 `앞 < 뒤`인지 한 번 훑어 판정하는 "하나 빼기 + 판정 함수" 완전탐색이다.
- 전체 비용은 N(가정) × N(판정) = O(N^2)으로, N ≤ 200이면 충분하다.

(2) 코드 단계별

- `skip`을 0..N-1로 돌며, `i != skip`인 원소만 `b`에 모은다.
- `b`의 인접쌍을 검사해 `b[i-1] >= b[i]`가 하나라도 있으면 `ok = False`로 실패 처리한다.
- 실패 없이 끝나면 `cnt += 1`. 마지막에 `cnt`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "정확히 하나 제거" → 제거 위치가 완전탐색 대상, 후보 N개.
- 각 후보의 판정은 "순증가인가?" — 인접쌍 전부 `<`, 같으면 실패.
- 이미 정렬된 수열(답 N), 완전 역순(답 0), 길이 2(항상 답 2) 같은 경계로 검산한다.
```

**6) 두 선수 시너지 최대** · Medium

- **요구사항**: N명의 선수가 있고 각 선수는 공격력 a와 수비력 b를 가진다. **서로 다른 두 명**을 골라 팀을 만들면 시너지는 `(첫째 공격력 × 둘째 수비력) + (둘째 공격력 × 첫째 수비력)`이다. 가능한 두 명 조합 중 시너지의 **최댓값**을 구하라.
- **입력**: 첫 줄에 N (2 ≤ N ≤ 100). 이어 N줄에 각 선수의 a와 b (각 0 이상 100 이하).
- **출력**: 시너지의 최댓값.
- **예제**: `3 / 1 5 / 4 2 / 3 3` → `22` (1번·2번: 1×2 + 4×5) · `2 / 0 0 / 5 5` → `0`
- **셀프체크**: 시너지 식은 두 사람을 바꿔도 같은 값이므로 `i<j`만 보면 된다. 최댓값 초기값을 0으로 두면 모든 값이 0인 경우와 구별이 안 되니 `None`으로 시작해 첫 쌍에서 반드시 갱신되게 한다. 두 속성(a, b)을 각각 리스트로 읽는 입력 처리에 주의.

```runner
@@SOLUTION
import sys

def main():
    data = sys.stdin.read().split()
    N = int(data[0])
    a = []
    b = []
    idx = 1
    for _ in range(N):
        a.append(int(data[idx])); idx += 1
        b.append(int(data[idx])); idx += 1
    best = None
    for i in range(N):
        for j in range(i + 1, N):
            s = a[i] * b[j] + a[j] * b[i]
            if best is None or s > best:
                best = s
    print(best)

main()

(1) 접근·핵심 아이디어

- 두 명을 고르는 조합 N(N-1)/2개를 전부 나열하고 각 조합의 시너지를 계산하는 "둘 고르기" 완전탐색이다. N ≤ 100이면 약 5000쌍으로 충분히 빠르다.
- 시너지 식 `a[i]*b[j] + a[j]*b[i]`는 i와 j를 바꿔도 값이 같으므로 i<j인 쌍만 보면 중복 없이 전부 본 것이다.

(2) 코드 단계별

- N을 읽고, 이어지는 N줄에서 `a[i]`, `b[i]`를 각각의 리스트에 담는다.
- `best = None`으로 시작해, `i < j` 이중 반복에서 시너지 `s`를 계산한다.
- `best is None or s > best`일 때 `best = s`로 갱신한다. 첫 쌍에서 반드시 값이 들어가므로 전부 0인 경우도 0이 정확히 출력된다.
- `best`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "서로 다른 두 명" → 위치 쌍 (i, j), i<j.
- 각 쌍의 평가식을 문제 그대로 옮긴다(교차 곱의 합).
- 최댓값 초기값은 `None`(또는 첫 쌍 값)으로 두어 0·음수 상황에서도 안전하게.
```

**7) 화분 물 배급 상한 정하기** · Medium

- **요구사항**: N개의 화분이 각각 r_i만큼의 물을 원한다. 물탱크에는 B만큼의 물이 있다. **상한 v**(0 이상 정수)를 정하면 각 화분에는 `min(r_i, v)`만큼 준다. 준 물의 총량이 **B 이하**가 되는 v 중 **가장 큰 값**을 구하라. 단, v가 모든 요구량 이상이면 결과는 같으므로 답은 `max(r_i)`를 넘지 않는 것으로 한다.
- **입력**: 첫 줄에 N과 B (1 ≤ N ≤ 100, 0 ≤ B ≤ 10^5). 둘째 줄에 N개의 요구량 (각 1 이상 1000 이하).
- **출력**: 총량 ≤ B를 만족하는 가장 큰 상한 v.
- **예제**: `4 30 / 20 5 15 10` → `8` (v=8: 8+5+8+8=29 ≤ 30, v=9: 32 초과) · `3 100 / 10 20 30` → `30` (전부 다 줘도 60 ≤ 100)
- **셀프체크**: 각 화분의 기여는 `min(r_i, v)`다 — 요구량보다 많이 주지 않도록 절단했는가? v의 후보는 0..max(r)이며, B=0이면 v=0만 가능(셋째 테스트). v를 올릴수록 총량은 줄지 않으므로 "만족하는 가장 큰 v"를 오름차순 덮어쓰기로 찾을 수 있다.

```runner
@@SOLUTION
import sys

def main():
    data = sys.stdin.read().split()
    N = int(data[0]); B = int(data[1])
    r = [int(data[2 + i]) for i in range(N)]
    ans = 0
    for v in range(0, max(r) + 1):
        total = 0
        for x in r:
            total += min(x, v)
        if total <= B:
            ans = v
    print(ans)

main()

(1) 접근·핵심 아이디어

- 답은 "상한 v"라는 하나의 정수 값이다. v를 정하면 총량은 `sum(min(r_i, v))`로 단순 계산되므로, 후보 v를 0부터 max(r)까지 직접 대입하는 값 기준 완전탐색이 맞는다.
- v가 커질수록 총량은 단조 증가(줄지 않음)한다. 따라서 "총량 ≤ B"를 만족하는 v는 앞쪽에 몰려 있고, 그중 가장 큰 값이 답이다. 이 단조성은 나중에 이분탐색으로 v 범위를 줄일 때의 발판이 된다.

(2) 코드 단계별

- N, B와 요구량 배열 `r`을 읽고 `ans = 0`으로 시작한다(v=0은 총량 0이라 항상 만족).
- `v`를 0..max(r)로 훑으며, 각 화분에 `min(x, v)`를 더해 `total`을 만든다.
- `total <= B`이면 `ans = v`로 덮어쓴다. 오름차순이므로 마지막 덮어쓴 값이 최대 v.
- `ans`를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "답 = 상한 값 하나"를 알아채고 후보 범위 [0, max(r)]를 잡는다.
- 판정: `sum(min(r_i, v)) <= B` — 요구량을 넘겨 주지 않도록 `min` 절단.
- 만족하는 최대 v를 오름차순 덮어쓰기로 찾고, B=0·전부 다 줄 수 있는 경우를 경계로 검산.
```

**8) 서로 싫어하는 쌍 없이 최대 초대** · Hard

- **요구사항**: 1번부터 N번까지 N명의 친구가 있고, 서로 싫어하는 M쌍이 주어진다. 파티에 초대할 사람들을 고르되, **싫어하는 두 사람을 동시에 초대할 수 없다**. 초대할 수 있는 **최대 인원**과, 그 인원을 달성하는 **초대 집합의 개수**를 구하라.
- **입력**: 첫 줄에 N과 M (1 ≤ N ≤ 12, 0 ≤ M ≤ 30). 이어 M줄에 서로 싫어하는 두 사람의 번호 x y (x ≠ y, 같은 쌍은 한 번만 주어진다).
- **출력**: `최대인원 집합수`를 공백으로 구분해 한 줄에.
- **예제**: `4 2 / 1 2 / 3 4` → `2 4` ({1,3}, {1,4}, {2,3}, {2,4}) · `5 2 / 1 5 / 2 3` → `3 4`
- **셀프체크**: 부분집합(mask)마다 M쌍을 전부 검사해 "둘 다 켜진 쌍"이 하나라도 있으면 버려야 한다. 인원 수는 켜진 비트 수. 최대 인원이 갱신되면 집합 수를 1로 리셋하고, 같으면 1을 더한다. M=0이면 전원 초대가 유일한 답(넷째 테스트). 모두가 서로 싫어하면 1명씩 N가지(셋째 테스트).

```runner
@@SOLUTION
import sys

def main():
    data = sys.stdin.read().split()
    N = int(data[0]); M = int(data[1])
    pairs = []
    idx = 2
    for _ in range(M):
        x = int(data[idx]) - 1; idx += 1
        y = int(data[idx]) - 1; idx += 1
        pairs.append((x, y))
    best = 0
    ways = 0
    for mask in range(1 << N):
        ok = True
        for x, y in pairs:
            if (mask & (1 << x)) and (mask & (1 << y)):
                ok = False
                break
        if not ok:
            continue
        size = 0
        for i in range(N):
            if mask & (1 << i):
                size += 1
        if size > best:
            best = size
            ways = 1
        elif size == best:
            ways += 1
    print(best, ways)

main()

(1) 접근·핵심 아이디어

- "각 사람을 초대한다/안 한다"는 부분집합 선택이므로 비트마스크로 2^N개를 전부 나열한다. N ≤ 12면 4096개뿐이다.
- 각 mask에 대해 (a) 제약 검사: 싫어하는 쌍 (x, y)의 두 비트가 모두 켜져 있으면 무효, (b) 통과한 mask의 인원(켜진 비트 수)으로 최대 인원과 그 개수를 갱신한다. 세 요소(부분집합 나열·제약 검사·최대와 개수 동시 갱신)가 결합된 문제다.

(2) 코드 단계별

- N, M을 읽고 싫어하는 쌍을 0부터 시작하는 번호 `(x, y)`로 `pairs`에 담는다.
- `mask`를 0..2^N-1로 돌며, 모든 쌍에 대해 `(mask & (1<<x)) and (mask & (1<<y))`이면 `ok = False`로 버린다.
- 통과한 mask는 켜진 비트를 세어 `size`를 구하고, `size > best`면 `best = size, ways = 1`, `size == best`면 `ways += 1`.
- `best ways`를 출력한다. mask=0(아무도 초대 안 함)도 후보에 들어가지만, 1명짜리 집합이 항상 유효하므로 최종 best는 1 이상이다.

(3) 스스로 다시 짤 때 생각 순서

- "초대한다/안 한다" → 부분집합 → 비트마스크 순회.
- 제약은 "쌍의 두 비트가 동시에 켜짐"이 없어야 함 — 쌍 목록을 한 번씩 검사.
- 최대와 개수를 함께 갱신할 때 "리셋 vs 증가"를 구분하고, M=0(전원)·완전 충돌(1명씩)로 검산한다.
```

**9) 우표로 만들 수 없는 최소 요금** · Hard

- **요구사항**: N장의 우표가 있고 각 우표의 액면가가 주어진다. 우표를 **골라 붙여**(각 우표는 최대 한 번, 하나도 안 붙이면 요금 0) 만들 수 있는 요금이 있다. 우표 조합으로 **만들 수 없는 가장 작은 양의 정수 요금**을 구하라.
- **입력**: 첫 줄에 N (1 ≤ N ≤ 12). 둘째 줄에 N개의 액면가 (각 1 이상 100 이하).
- **출력**: 만들 수 없는 가장 작은 양의 정수.
- **예제**: `4 / 1 2 2 6` → `12` (1~11은 전부 가능, 전체 합이 11) · `3 / 2 3 5` → `1`
- **셀프체크**: 먼저 모든 부분집합의 합을 표시하고(불리언 배열), 그다음 1부터 올라가며 처음 만들 수 없는 값을 찾는 두 단계다. 배열 크기를 전체 합 + 2로 잡아야 "전체 합 + 1"(모든 값이 가능한 경우의 답)까지 인덱스가 존재한다. 액면가에 1이 없으면 답은 1이다.

```runner
@@SOLUTION
import sys

def main():
    data = sys.stdin.read().split()
    N = int(data[0])
    a = [int(data[1 + i]) for i in range(N)]
    total = sum(a)
    can = [False] * (total + 2)
    for mask in range(1 << N):
        s = 0
        for i in range(N):
            if mask & (1 << i):
                s += a[i]
        can[s] = True
    v = 1
    while can[v]:
        v += 1
    print(v)

main()

(1) 접근·핵심 아이디어

- "어떤 우표를 붙이나"는 부분집합 선택이므로 비트마스크로 2^N개 조합의 합을 전부 구할 수 있다. 여기까지가 물체 단위 완전탐색이다.
- 그다음 "만들 수 없는 최소 양의 정수"는 값 v를 1부터 올라가며 `can[v]`를 확인하는 값 기준 탐색이다. 두 완전탐색을 이어 붙인 구조라 Hard로 분류했다.

(2) 코드 단계별

- N과 액면가 배열 `a`, 전체 합 `total`을 준비하고 길이 `total + 2`의 불리언 배열 `can`을 만든다.
- `mask`마다 켜진 비트의 액면가를 더해 합 `s`를 만들고 `can[s] = True`로 표시한다(mask=0은 합 0).
- `v = 1`부터 `can[v]`가 참인 동안 1씩 올린다. 처음 거짓이 되는 `v`가 답이다.
- 모든 값이 가능하면 `v`는 `total + 1`에서 멈추는데, 배열 크기를 `total + 2`로 잡았으므로 인덱스 초과가 없다.

(3) 스스로 다시 짤 때 생각 순서

- 1단계: 부분집합 합을 전부 표시(2^N × N).
- 2단계: 1부터 값을 훑어 첫 구멍을 찾기.
- 배열 크기(전체 합 + 2)와 "1이 없으면 답 1", "전부 가능하면 답 total + 1" 경계를 확인한다.
```

**10) 부호를 붙여 목표 만들기** · Hard

- **요구사항**: N개의 양의 정수가 순서대로 있다. 각 수 앞에 `+` 또는 `-`를 하나씩 붙여 전체를 더한 결과가 정확히 T가 되게 하려 한다. 단, **`-`를 붙이는 수는 최대 K개**까지만 허용한다. 조건을 만족하는 부호 배치의 **개수**를 구하라.
- **입력**: 첫 줄에 N, K, T (1 ≤ N ≤ 12, 0 ≤ K ≤ N, |T| ≤ 10^4). 둘째 줄에 N개의 정수 (각 1 이상 100 이하).
- **출력**: 조건을 만족하는 부호 배치의 개수.
- **예제**: `3 3 2 / 1 2 3` → `1` (+1 -2 +3) · `4 4 0 / 1 1 1 1` → `6` (넷 중 둘에 `-`를 붙이는 방법 수)
- **셀프체크**: "각 수에 `-`를 붙인다/안 붙인다"는 부분집합 선택이다 — mask의 켜진 비트를 `-`로 해석하면 된다. 켜진 비트 수(`-`의 개수)가 K를 넘으면 무효. T가 음수인 경우(넷째 테스트)와 K=0(전부 `+`만 가능)도 같은 코드로 처리되는지 확인.

```runner
@@SOLUTION
import sys

def main():
    data = sys.stdin.read().split()
    N = int(data[0]); K = int(data[1]); T = int(data[2])
    a = [int(data[3 + i]) for i in range(N)]
    cnt = 0
    for mask in range(1 << N):
        s = 0
        neg = 0
        for i in range(N):
            if mask & (1 << i):
                s -= a[i]
                neg += 1
            else:
                s += a[i]
        if neg <= K and s == T:
            cnt += 1
    print(cnt)

main()

(1) 접근·핵심 아이디어

- 부호 배치는 수마다 두 갈래(`+`/`-`)이므로 총 2^N가지다. "`-`를 붙일 수의 집합"을 고른다고 보면 부분집합 문제이고, mask의 i번째 비트가 켜지면 `a[i]`를 빼고 꺼지면 더하는 것으로 재해석할 수 있다.
- 여기에 "`-` 개수 ≤ K"라는 제약이 추가된다. 켜진 비트 수를 같이 세어 K를 넘는 mask는 버린다. 부분집합 나열 + 합 계산 + 개수 제약이 결합된 문제다.

(2) 코드 단계별

- N, K, T와 배열 `a`를 읽고 `cnt = 0`으로 시작한다.
- `mask`마다 `s`(부호 적용 합)와 `neg`(`-` 개수)를 0에서 시작해, 비트가 켜진 i는 `s -= a[i]`, `neg += 1`, 꺼진 i는 `s += a[i]`로 누적한다.
- `neg <= K`이고 `s == T`이면 `cnt += 1`.
- `cnt`를 출력한다. T가 음수여도 `s`는 음수가 될 수 있으므로 별도 처리는 필요 없다.

(3) 스스로 다시 짤 때 생각 순서

- "각 수에 부호 하나" → 2^N → `-`를 붙일 집합을 비트마스크로.
- 각 mask에서 합과 `-` 개수를 동시에 누적.
- 제약(개수 ≤ K)과 목표(합 == T)를 둘 다 통과할 때만 센다. K=0·T 음수·N=1로 검산.
```
