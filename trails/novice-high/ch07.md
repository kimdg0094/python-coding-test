> 개요: 이 챕터에서는 키를 배열 인덱스로 바꿔 평균 O(1)에 저장·조회하는 해시 테이블의 원리(해시 함수·충돌 처리)와, 파이썬의 dict/set을 이용한 실전 활용을 배운다.

## L1. 해싱

**개념**

- **해싱(hashing)**은 임의의 키(문자열·숫자·튜플 등)를 정수로 바꾸는 **해시 함수**를 이용해, 그 정수를 배열의 인덱스로 삼아 데이터를 저장·조회하는 기법이다. 정렬이나 비교 없이 "키 → 위치"를 곧바로 계산하므로 **평균 O(1)** 에 삽입·검색·삭제가 된다.
- 왜 쓰는가: "이 값이 이미 있었나?", "이 키에 매핑된 값은?", "각 원소가 몇 번 나왔나?" 같은 질문에 반복 탐색(O(n)) 대신 상수 시간으로 답하기 위해서다. 이진탐색(O(log n))보다도 빠르고, 데이터가 정렬돼 있을 필요도 없다.
- 동작 원리를 단계로:

  1. 크기 `m`인 배열(버킷 배열)을 준비한다.

  2. 키 `k`에 대해 `h = hash(k) % m`을 계산해 들어갈 버킷 번호를 얻는다.

  3. 그 버킷에 (키, 값)을 저장한다. 조회는 같은 계산으로 버킷을 찾아 꺼낸다.

- **충돌(collision)**: 서로 다른 키가 같은 버킷 번호를 가질 수 있다. 이를 처리하는 두 방식이 있다.

  - **체이닝(chaining)**: 각 버킷을 리스트로 두고, 충돌한 키들을 그 리스트에 이어 붙인다. 조회 시 그 리스트만 선형 탐색한다.

  - **개방 주소법(open addressing)**: 버킷이 차 있으면 다음 빈 칸을 규칙(선형 탐사 등)대로 찾아 넣는다.

- **적재율(load factor) α = 원소 수 / 버킷 수**. α가 커지면 충돌이 잦아져 느려지므로, 보통 임계치를 넘으면 배열을 키우고 전부 다시 넣는(**리해싱**) 방식으로 α를 낮게 유지한다. 파이썬 dict/set이 내부적으로 이 일을 자동으로 해준다.

```python
# 체이닝 방식 해시 셋의 뼈대 (원리 이해용)
class HashSet:
    def __init__(self, m=8):
        self.m = m
        self.buckets = [[] for _ in range(m)]

    def _idx(self, key):
        return hash(key) % self.m   # 해시 함수 + 나머지로 버킷 선택

    def add(self, key):
        b = self.buckets[self._idx(key)]
        if key not in b:            # 이미 있으면 중복 저장 안 함
            b.append(key)

    def contains(self, key):
        b = self.buckets[self._idx(key)]
        return key in b             # 같은 버킷 안에서만 탐색

# 실전에서는 그냥 파이썬 내장을 쓴다
s = set()          # 원소 존재 여부
s.add(3); print(3 in s)   # True

from collections import Counter, defaultdict
cnt = Counter("banana")   # {'a':3,'b':1,'n':2}
d = defaultdict(list)     # 없는 키 접근 시 자동으로 빈 리스트
d[0].append("x")
```

**접근 전략**

- **핵심 아이디어**: "존재 여부·개수·매핑"을 물으면 해시를 떠올린다. 리스트에 `in`으로 매번 찾으면 O(n)이지만, `set`/`dict`에 담아 두면 조회가 평균 O(1)이라 전체가 O(n)으로 떨어진다.
- **전형적 패턴**:

  - **중복/존재 판정**: `set`에 넣으며 이미 있는지 확인 (예: 첫 중복 원소, 두 수의 합 문제의 `target - x` 찾기).

  - **빈도 세기**: `Counter`나 `dict`로 `d[x] += 1`. 애너그램 판정, 최빈값, 조건에 맞는 개수 세기 등.

  - **키→값 매핑/그룹화**: `defaultdict(list)`로 같은 기준을 가진 원소를 모으기(그룹 애너그램 등).

  - **불변 키만 가능**: 리스트는 키로 못 쓴다(가변). 대신 `tuple`이나 `frozenset`, 정렬된 문자열 등으로 바꿔 키로 삼는다.

- **언제 고르나**: 순서가 중요하지 않고 "빠른 조회"만 필요할 때. 반대로 "정렬된 순서로 순회", "범위 질의(x 이상 y 이하)"가 필요하면 해시가 아니라 정렬/이진탐색/BST가 맞다.
- **복잡도**: 삽입·검색·삭제 평균 **O(1)**, 최악 **O(n)**(모든 키가 한 버킷에 몰릴 때). 공간 **O(n)**. 파이썬 dict/set은 리해싱으로 평균 O(1)을 사실상 보장한다.
- **흔한 실수·주의**: (1) `dict`는 파이썬 3.7+에서 삽입 순서를 유지하지만, "정렬 순서"는 아니다 — 정렬이 필요하면 `sorted()`를 따로 써야 한다. (2) 없는 키를 `d[k]`로 읽으면 `KeyError` — `d.get(k, 기본값)`이나 `defaultdict`를 쓴다. (3) `hash()`가 상수시간이라는 전제는 짧은 키에서다. 아주 긴 문자열을 키로 반복 해싱하면 해시 계산 자체가 비용이 된다.

**문제**

**1) 두 수의 합 존재 여부** · Easy

- **요구사항**: 정수 배열과 목표값 `T`가 주어질 때, 서로 다른 두 원소의 합이 `T`가 되는 쌍이 존재하면 `YES`, 없으면 `NO`를 출력한다. 배열을 한 번만 훑어 평균 O(n)에 해결하라(이중 반복 금지).
- **입력**: 첫 줄에 `n`과 `T`, 둘째 줄에 정수 `n`개.
- **출력**: `YES` 또는 `NO`.
- **예제**:

  - `4 9` / `2 7 11 15` → `YES`  (2 + 7 = 9)

  - `3 6` / `1 2 4` → `NO`  (1+2=3, 1+4=5, 2+4=6? → 6이므로 사실 YES)

  > 검산: {1,2,4}에서 2+4=6=T이므로 이 예제의 정답은 `YES`다. 아래로 교체한다.

  - `3 10` / `1 2 4` → `NO`  (합은 3,5,6뿐, 10 없음)

- **셀프체크**: 원소 `x`를 볼 때 `T - x`가 이미 `set`에 있는지 먼저 확인하고, 없으면 `x`를 넣는다(자기 자신과 더하는 오류 방지). 같은 값이 두 번 있어야 하는 경우(예: `T=8`, 배열에 4가 두 개)도 순서대로 넣으면 자연히 처리됨을 확인하라.

```runner
@@SOLUTION
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    n = int(data[idx]); idx += 1
    T = int(data[idx]); idx += 1
    arr = [int(data[idx + i]) for i in range(n)]
    seen = set()
    for x in arr:
        if (T - x) in seen:
            print("YES")
            return
        seen.add(x)
    print("NO")

main()
@@TESTS
--IN
4 9
2 7 11 15
--OUT
YES
--IN
5 8
1 4 3 4 9
--OUT
YES
@@EXPL
(1) 접근·핵심 아이디어

- 이중 반복(모든 쌍 검사)은 O(n^2). 대신 지나온 원소를 `set`에 담아 두고, 현재 원소 `x`를 볼 때 "`T - x`가 이미 나왔는가?"만 O(1)로 물으면 전체가 O(n)이 된다.
- 확인을 먼저 하고 그 다음에 `x`를 넣기 때문에, 같은 인덱스를 자기 자신과 더하는 실수가 생기지 않는다.

(2) 코드 단계별

- 입력을 한꺼번에 읽어 `n`, `T`, 배열을 파싱한다.
- 빈 `set` `seen`을 만든다.
- 각 `x`마다 `T - x`가 `seen`에 있으면 즉시 `YES`를 출력하고 종료.
- 없으면 `x`를 `seen`에 추가하고 계속.
- 끝까지 못 찾으면 `NO`.

(3) 스스로 다시 짤 때 생각 순서

- "합이 T인 쌍" → 각 원소에 대해 필요한 짝은 `T - x`로 유일하게 정해진다는 점을 먼저 떠올린다.
- 짝을 빠르게 찾으려면 이미 본 값들을 조회 가능한 자료구조(`set`)에 넣어야 함을 연결한다.
- 자기 자신 중복 더하기를 막으려면 "확인 → 추가" 순서가 핵심임을 기억한다.
- 같은 값이 두 번 필요한 경우(예: 4+4=8)는 첫 4를 넣은 뒤 둘째 4에서 `T-4=4`가 이미 있어 자연히 처리됨을 확인한다.
```

**2) 최빈 단어** · Medium

- **요구사항**: 공백으로 구분된 단어들이 주어질 때, 가장 많이 등장한 단어를 출력한다. 최다 빈도가 여러 개면 그중 **사전순으로 가장 앞선** 단어를 출력한다.
- **입력**: 한 줄에 단어들이 공백으로 구분되어 주어진다.
- **출력**: 단어 하나.
- **예제**:

  - `apple banana apple cherry banana apple` → `apple`  (apple 3, banana 2, cherry 1)

  - `red blue blue red green` → `blue`  (red 2, blue 2, green 1 → 동점이면 사전순 앞: blue < red)

- **셀프체크**: `Counter`로 빈도를 센 뒤, 정렬 키를 `(-빈도, 단어)`로 두면 "빈도 내림차순, 같으면 사전순 오름차순"이 한 번에 처리됨을 확인하라. 빈도만으로 `max`를 쓰면 동점 시 사전순 규칙을 놓치기 쉽다.

```runner
@@SOLUTION
import sys
from collections import Counter

def main():
    words = sys.stdin.read().split()
    cnt = Counter(words)
    best = min(cnt.items(), key=lambda kv: (-kv[1], kv[0]))
    print(best[0])

main()
@@TESTS
--IN
apple banana apple cherry banana apple
--OUT
apple
--IN
red blue blue red green
--OUT
blue
@@EXPL
(1) 접근·핵심 아이디어

- 빈도 세기는 해시(`Counter`/`dict`)의 대표 용도. `Counter(words)`가 단어→등장 횟수를 O(n)에 만든다.
- 동점 규칙("사전순 가장 앞")을 함께 처리하려면 정렬 키를 `(-빈도, 단어)`로 둔다. 빈도는 큰 것이 앞서야 하므로 음수로 뒤집고, 단어는 사전순 오름차순이 그대로 맞다.
- 이 키에서 가장 작은 항목이 정답이므로 `min(..., key=...)` 한 번이면 된다.

(2) 코드 단계별

- 입력 전체를 읽어 공백 기준으로 나눠 단어 리스트를 만든다.
- `Counter`로 각 단어의 빈도를 센다.
- `cnt.items()`(단어, 빈도 쌍들) 중에서 키 `(-빈도, 단어)`가 최소인 항목을 `min`으로 고른다.
- 그 항목의 단어(`best[0]`)를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "가장 많이 나온 것" → 먼저 빈도표를 만든다(`Counter`).
- 동점 시 규칙을 정렬 키로 번역한다: "빈도 큰 것 우선"은 `-빈도`, "사전순 앞"은 단어 그대로.
- 최댓값 하나만 필요하면 전체 정렬 대신 `min`/`max` + `key`로 O(n)에 끝낼 수 있음을 떠올린다.
- 빈도만으로 `max`를 쓰면 동점에서 어느 것이 나올지 보장이 없으니, 반드시 2차 기준(단어)을 키에 포함한다.
```

**3) 그룹 애너그램 개수** · Medium

- **요구사항**: 문자열 여러 개가 주어질 때, 서로 애너그램(구성 글자와 개수가 같은)인 것끼리 한 그룹으로 묶는다. 만들어지는 **그룹의 개수**를 출력하라.
- **입력**: 첫 줄에 `n`, 다음 `n`줄에 소문자 문자열이 하나씩.
- **출력**: 그룹 개수(정수).
- **예제**:

  - `6` / `eat` / `tea` / `tan` / `ate` / `nat` / `bat` → `3`  ({eat,tea,ate}, {tan,nat}, {bat})

  - `3` / `abc` / `bca` / `xy` → `2`  ({abc,bca}, {xy})

- **셀프체크**: 각 문자열을 **정렬한 문자열**(예: `"eat"→"aet"`)을 키로 삼아 `set`(또는 `dict`)에 넣으면, 서로 애너그램인 것들은 같은 키가 된다. 최종 서로 다른 키의 수가 곧 그룹 수다. 정렬 키 대신 글자 빈도 튜플(길이 26)을 키로 써도 되며, 이 경우 정렬 O(k log k)를 O(k)로 줄일 수 있음을 확인하라(k=문자열 길이).

```runner
@@SOLUTION
import sys

def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    strs = data[1:1 + n]
    keys = set()
    for s in strs:
        keys.add("".join(sorted(s)))
    print(len(keys))

main()
@@TESTS
--IN
6
eat
tea
tan
ate
nat
bat
--OUT
3
--IN
3
abc
bca
xy
--OUT
2
@@EXPL
(1) 접근·핵심 아이디어

- 애너그램끼리는 "글자를 정렬하면 같은 문자열"이 된다(`eat`, `tea`, `ate` → 모두 `aet`). 이 정렬 문자열을 **정규화 키**로 삼는다.
- 그룹의 개수만 필요하므로 각 키를 `set`에 넣고, 마지막에 서로 다른 키의 수(`len`)를 세면 된다. 각 그룹 내부 원소를 실제로 모을 필요가 없다.

(2) 코드 단계별

- 입력을 읽어 `n`과 문자열 `n`개를 파싱한다.
- 빈 `set` `keys`를 만든다.
- 각 문자열 `s`에 대해 `sorted(s)`로 글자를 정렬하고 `"".join(...)`으로 다시 문자열로 만들어 키로 추가한다.
- 서로 애너그램인 문자열들은 같은 키가 되어 `set`에서 자동으로 하나로 합쳐진다.
- 최종 `len(keys)`가 그룹 수다.

(3) 스스로 다시 짤 때 생각 순서

- "애너그램끼리 묶기" → 애너그램을 하나의 표준형으로 바꾸는 방법을 먼저 찾는다: 글자 정렬(또는 길이 26 빈도 튜플).
- 표준형이 같으면 같은 그룹 → 표준형을 키로 쓰는 해시 구조를 떠올린다.
- 개수만 물었으므로 그룹 내용은 버리고 서로 다른 키만 세면 됨을 인식(`set` + `len`).
- 성능이 중요하면 정렬 키(O(k log k)) 대신 각 글자 개수를 담은 튜플(O(k))을 키로 쓸 수 있음을 기억한다(k=문자열 길이).
```
