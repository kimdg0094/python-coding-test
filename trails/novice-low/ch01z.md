## L10. 정리 — 개념 지도·체크리스트·자주 하는 실수

**개념**

이 챕터에서 배운 것을 한자리에 모아 정리한다. 새 문법은 없다. 대신 **어디에 무엇이 있는지 지도를 그리고**, 실제로 코드를 쓸 때 바로 꺼내 쓸 뼈대를 정리하고, 입문자가 반드시 한 번은 겪는 실수를 미리 겪어 본다.

**개념 지도**

Ch01은 결국 세 단계다. **값을 만들고 → 상자에 담고 → 화면에 보여 준다.** 각 단계에 어떤 레슨이 붙어 있는지 확인해 두자.

```text
  make a value    ->    keep it in a box    ->    show it

  +------------+        +--------------+          +----------------+
  | 5          |  ====> |   name       |  =====>  | print(x)       |
  | 5.0        | assign |   +------+   |   read   | print(a, b)    |
  | 'five'     |        |   |  5   |   |          | f'{x:.2f}'     |
  +------------+        |   +------+   |          +----------------+
     L1  L2             +--------------+             L1  L3  L4
                         L2 L5 L6 L7 L8
```

가운데 "상자" 단계가 이 챕터의 절반을 차지한다. 상자 안 값이 바뀌는 방법이 레슨 순서대로 하나씩 늘어난다.

```text
  how a box changes                              lesson
  -------------------------------------------    ------
  x = 20                 overwrite               L5
  x = x + 5              read, compute, store    L5
  x += 5                 same thing, shorter     L5
  b = a                  copy from another box   L6
  c = a + b              build a new value       L6
  temp = a; a = b; b = temp    swap with a spare box   L7
  a, b = b, a            swap in one line        L8
  x = y = 0              same value into 2 boxes L8
```

출력 단계의 갈림길은 하나뿐이다. **띄울 것인가, 붙일 것인가.**

```text
  two things on one line

           print(a, b)                    print(a + b)
                |                               |
        comma: ONE space                 + : glued, no space
                |                               |
        any types are fine              both sides must be the
                |                       SAME type
                |                               |
    'Age:' , 20   -> Age: 20        'Sea' + 'side' -> Seaside
                                    'Age:' + 20    -> TypeError
```

**뼈대 코드**

이 챕터 유형을 만나면 아래 다섯 개 중 하나를 골라 값만 바꾸면 된다.

```python
# 1) 정해진 문장을 그대로 출력하기
print('first line')            # ← 문제마다 바뀜
print('second line')           # ← 문제마다 바뀜
# 문장 안에 " 가 있으면 바깥은 ' 로, ' 가 있으면 바깥은 " 로 감싼다
```

```python
# 2) 값을 변수에 담고 라벨을 붙여 출력하기
name = 'Pen'                   # ← 문제마다 바뀜 (문자열)
price = 1200                   # ← 문제마다 바뀜 (정수)
weight = 8.5                   # ← 문제마다 바뀜 (실수)
print('Item:', name)           # 쉼표가 공백 한 칸을 넣어 준다
print('Price:', price)
print('Weight:', weight)
```

```python
# 3) 계산한 뒤 소수점 자릿수를 고정해 출력하기
total = 1200 * 3               # ← 문제마다 바뀜
pay = total * 0.9              # 실수를 곱하면 결과도 실수가 된다
print(total)                   # 정수는 그대로 (.0 이 붙지 않는다)
print(f'{pay:.1f}')            # ← 자릿수도 문제마다 바뀜 (.1f / .2f / .3f)
```

```python
# 4) 같은 변수를 덮어쓰며 여러 줄 출력하기 (케이스 형식)
a, b = 3, 4                    # ← 문제마다 바뀜
print('Case #1:', a + b)
a, b = 10, 5                   # 새 변수를 만들지 않고 덮어쓴다
print('Case #2:', a + b)
```

```python
# 5) 두 값 교환 — 두 가지 방법
temp = a                       # 방법 A: 임시 변수 (원리가 눈에 보인다)
a = b
b = temp

a, b = b, a                    # 방법 B: 동시 대입 한 줄 (실전에서는 이쪽)
```

**언제 무엇을 쓰나**

| 상황 | 고르는 것 | 이유 | 복잡도 |
|------|-----------|------|--------|
| 여러 값을 공백으로 띄워 한 줄에 | `print(a, b)` | 쉼표가 공백 한 칸을 자동으로 넣는다. 자료형이 섞여도 된다 | O(1) |
| 값을 빈틈없이 붙여서 | `print(a + b)` | `+` 는 문자열을 그대로 이어 붙인다 | O(1) |
| 값 사이 구분자를 바꿔야 할 때 | `print(a, b, sep='-')` | 쉼표가 넣는 공백만 다른 문자로 교체된다 | O(1) |
| 줄바꿈 없이 이어 찍을 때 | `print(a, end='')` | 끝에 자동으로 붙는 줄바꿈을 없앤다 | O(1) |
| 소수점 자릿수를 맞춰야 할 때 | `f'{x:.2f}'` | 반올림하고 부족한 자리는 `0` 으로 채운다 | O(1) |
| 정수를 있는 그대로 보여 줄 때 | `print(n)` | `.0` 이 붙으면 안 되는 문제에서 안전하다 | O(1) |
| 같은 값을 여러 번 쓸 때 | 변수에 담아 두기 | 값을 바꿀 때 한 곳만 고치면 된다 | O(1) |
| 값을 통째로 새 값으로 | `x = 새 값` | 이전 값은 덮어써져 사라진다 | O(1) |
| 지금 값을 이용해 바꿀 때 | `x += 1` (= `x = x + 1`) | 오른쪽을 먼저 계산한 뒤 다시 담는다 | O(1) |
| 두 값을 맞바꿀 때 | `a, b = b, a` | 오른쪽이 옛 값으로 먼저 준비되어 섞이지 않는다 | O(1) |
| 교환 "원리"를 보여야 할 때 | `temp` 를 쓴 3줄 | 어떤 값이 사라지는지 눈에 보인다 | O(1) |
| 여러 변수에 같은 값을 넣을 때 | `x = y = 0` | 두 변수를 연결하는 게 아니라 값을 각각 넣는다 | O(1) |

**✅ 마스터 체크리스트**

- [ ] 설명할 수 있다: `print` 한 번이 하는 두 가지 일(값 찍기 + 줄바꿈)은 무엇인가.
- [ ] 설명할 수 있다: 왜 `print("It's a book")` 은 되고 `print('It's a book')` 은 오류인가.
- [ ] 설명할 수 있다: `5`, `5.0`, `'5'` 는 각각 어떤 자료형이며 화면에는 어떻게 보이는가.
- [ ] 설명할 수 있다: `=` 가 "같다"가 아니라 무엇을 뜻하며, 왜 `5 = x` 는 오류인가.
- [ ] 설명할 수 있다: `print(a, b)` 와 `print(a + b)` 의 결과가 어떻게 다른가.
- [ ] 설명할 수 있다: `'Age:' + 20` 이 왜 오류이고, 같은 뜻을 어떻게 안전하게 쓰는가.
- [ ] 설명할 수 있다: `f'{x:.2f}'` 가 반올림하는 기준 자리는 어디이며, 자리가 모자라면 어떻게 되는가.
- [ ] 설명할 수 있다: `0.1 + 0.2` 가 왜 정확히 `0.3` 이 아닌가.
- [ ] 설명할 수 있다: `x = x + 1` 이 실행되는 순서를 두 단계로 나누면 무엇과 무엇인가.
- [ ] 설명할 수 있다: `b = a` 뒤에 `a` 를 바꾸면 왜 `b` 는 그대로인가.
- [ ] 설명할 수 있다: 교환할 때 임시 변수가 왜 필요하며, 무엇을 지키기 위한 것인가.
- [ ] 설명할 수 있다: `a, b = b, a` 가 임시 변수 없이도 되는 이유를 2단계로.
- [ ] 설명할 수 있다: `a, b = b, a + b` 에서 `a + b` 는 어느 시점의 값으로 계산되는가.
- [ ] 설명할 수 있다: `x = y = 0` 이 두 변수를 연결하는 것이 아닌 이유는 무엇인가.

**⚠️ 자주 하는 실수**

**(1) 따옴표 짝이 안 맞는다**

```python
# ❌ 틀린 코드
print('It's a book')
```

왜: 파이썬은 두 번째 `'`(즉 `It` 뒤의 것)에서 문자열이 끝났다고 판단한다. 남은 `s a book'` 은 해석할 수 없어 오류(SyntaxError)가 난다.

```python
# ✅ 고친 코드
print("It's a book")     # 안에 ' 가 있으면 바깥은 "
```

**(2) 문자열과 숫자를 `+` 로 잇는다**

```python
# ❌ 틀린 코드
age = 20
print('Age: ' + age)     # TypeError
```

왜: `+` 는 양쪽이 같은 자료형일 때만 뜻이 정해진다. 문자열과 정수를 섞으면 파이썬이 어느 쪽으로 맞출지 정할 근거가 없어 오류를 낸다.

```python
# ✅ 고친 코드
age = 20
print('Age:', age)       # 쉼표는 자료형이 섞여도 된다
```

**(3) 라벨 뒤 공백이 두 칸이 된다**

```python
# ❌ 틀린 코드
temp = 36
print('Temperature: ', temp)     # "Temperature:  36" (공백 2칸)
```

왜: 쉼표가 이미 공백 한 칸을 넣어 준다. 문자열 끝에 공백을 또 넣으면 두 칸이 되어 정답과 한 글자가 어긋난다.

```python
# ✅ 고친 코드
temp = 36
print('Temperature:', temp)      # "Temperature: 36"
```

**(4) 숫자를 따옴표로 감싼다**

```python
# ❌ 틀린 코드
a = '10'
b = '20'
print(a + b)             # 1020
```

왜: 따옴표를 붙이는 순간 값은 "계산할 수"가 아니라 "그렇게 생긴 글자"가 된다. 문자열끼리의 `+` 는 덧셈이 아니라 이어 붙이기다.

```python
# ✅ 고친 코드
a = 10
b = 20
print(a + b)             # 30
```

**(5) 임시 변수 없이 교환한다**

```python
# ❌ 틀린 코드
a = 10
b = 20
a = b                    # 여기서 10이 사라진다
b = a                    # b 에는 20이 다시 들어간다
print(a, b)              # 20 20
```

왜: 대입은 덮어쓰기다. `a = b` 를 하는 순간 `a` 의 10은 복사본이 없어 되찾을 수 없다.

```python
# ✅ 고친 코드
a = 10
b = 20
temp = a                 # 사라질 값을 먼저 보관
a = b
b = temp
print(a, b)              # 20 10
```

**(6) 동시 대입을 "한 개씩 차례로"라고 생각한다**

```python
# ❌ 틀린 생각 (손으로 계산할 때)
a, b = 1, 2
a, b = b, a + b
# a 가 먼저 2가 되고 -> b = 2 + 2 = 4  라고 계산해 "2 4" 라고 답함
```

왜: 오른쪽 `b, a + b` 는 **그 줄이 시작될 때의 옛 값**으로 전부 먼저 계산되어 `(2, 3)` 이 된다. 그 뒤에야 왼쪽에 부어진다.

```python
# ✅ 올바른 계산
a, b = 1, 2
a, b = b, a + b          # 오른쪽 = (2, 1+2) = (2, 3)
print(a, b)              # 2 3
```

**(7) f-문자열의 `f` 를 빠뜨린다**

```python
# ❌ 틀린 코드
pi = 3.141592
print('{pi:.2f}')        # {pi:.2f} 라는 글자가 그대로 나온다
```

왜: 앞에 `f` 가 없으면 그냥 평범한 문자열이다. `{ }` 안이 값으로 바뀌는 것은 `f` 를 붙였을 때만 일어난다.

```python
# ✅ 고친 코드
pi = 3.141592
print(f'{pi:.2f}')       # 3.14
```

**(8) 계산만 하고 다시 담지 않는다**

```python
# ❌ 틀린 코드
count = 0
count + 1                # 계산만 하고 버린다
print(count)             # 0
```

왜: 값이 바뀌는 순간은 그 변수가 `=` 의 **왼쪽**에 나올 때뿐이다. 오른쪽에서만 쓰인 계산 결과는 어디에도 담기지 않고 사라진다.

```python
# ✅ 고친 코드
count = 0
count = count + 1        # 또는 count += 1
print(count)             # 1
```

**다음 챕터로**

- Ch01에서는 값을 **코드 안에 직접 적었다.** Ch02에서는 그 값을 사람이 키보드로 넣어 준다(`input()`).
- 이때 들어오는 값은 언제나 문자열이므로, 이 챕터에서 익힌 "자료형이 다르면 `+` 의 뜻이 달라진다"는 감각이 곧바로 필요해진다.
- 출력 쪽 도구(`print` 의 쉼표 나열, `f'{x:.2f}'`)는 이후 모든 챕터에서 그대로 쓰인다. 지금 확실히 굳혀 두면 다시 배울 일이 없다.
