> 개요: 이 챕터에서는 숫자를 계산하는 연산자(더하기, 빼기, 곱하기, 나누기, 나눗셈의 몫과 나머지)를 배우고, 이를 이용해 여러 값의 합과 평균을 구하는 방법을 익힙니다.

## L1. 사칙연산

**개념**

- 사칙연산은 컴퓨터에게 계산을 시키는 가장 기본 도구입니다. 파이썬은 숫자와 연산자만 있으면 우리 대신 계산을 해 줍니다.
- 기본 연산자는 다음과 같습니다.

- `+` : 더하기 (덧셈)
- `-` : 빼기 (뺄셈)
- `*` : 곱하기 (곱셈), 학교에서 쓰던 `×` 대신 별표를 씁니다.
- `/` : 나누기, 결과가 항상 실수(소수)로 나옵니다. 예: `10 / 2`의 결과는 `5`가 아니라 `5.0`입니다.

- 나눗셈에는 두 가지가 더 있습니다. 정수끼리 딱 나눌 때 유용합니다.

- `//` : 몫만 구하기 (소수점 아래를 버림). 예: `7 // 2`는 `3`.
- `%` : 나머지 구하기. 예: `7 % 2`는 `1`.

- 곱셈·나눗셈이 덧셈·뺄셈보다 먼저 계산됩니다. 순서를 바꾸고 싶으면 소괄호 `( )`로 묶습니다. 예: `2 + 3 * 4`는 `14`, `(2 + 3) * 4`는 `20`.

```python
a = 7
b = 3
print(a + b)   # 10
print(a - b)   # 4
print(a * b)   # 21
print(a / b)   # 2.3333333333333335
print(a // b)  # 2  (몫)
print(a % b)   # 1  (나머지)
```

- `/`와 `//`의 차이를 꼭 기억하세요. `/`는 소수 결과(`2.5`), `//`는 몫만(`2`)을 줍니다.

> 선행: 입력값을 정수로 받을 때는 `n = int(input())` 형태를 씁니다(Ch2에서 배움). 한 줄에 두 값을 공백으로 받을 때는 `a, b = input().split()` 로 나눈 뒤 `a = int(a); b = int(b)` 로 하나씩 정수로 바꿔 씁니다(Ch2에서 배움). 더 짧게 쓰는 방법은 뒤 챕터에서 배웁니다.

**그림으로 보기**

나눗셈 하나에서 세 가지 답이 나옵니다. 어느 부분을 가져오느냐만 다릅니다.

```text
  7 divided by 3

          2        <- 7 // 3  : the quotient, decimals dropped
        +------
    3   |  7
        |  6       # 3 * 2
        +------
        |  1       <- 7 % 3   : the remainder

  7 / 3   ->  2.3333333333333335     # keeps everything, always float
  7 // 3  ->  2                      # int
  7 % 3   ->  1                      # int
```

`//` 는 "버림"이 아니라 **"내림"** 입니다. 수직선에서 왼쪽(작은 쪽)으로 내려갑니다. 양수에서는 차이가 안 보이지만 음수에서 갈립니다.

```text
  -7 / 2 = -3.5

  ... -5    -4    -3.5    -3    -2 ...
            ^      ^
            |      + the exact value of -7 / 2
            + // moves DOWN to the next whole number  ->  -4

  -7 // 2    ->  -4          # floor: goes to the smaller side
  int(-3.5)  ->  -3          # int(): cuts toward zero
   7 // 2    ->   3          # positive: both give the same 3
```

**왜 이렇게 되는가**

- `/` 가 항상 실수인 이유: 만약 `6 / 3` 은 정수 `2`, `7 / 3` 은 실수 `2.333…` 을 준다면, 같은 연산자가 입력값에 따라 자료형을 바꿔 버립니다. 그러면 뒤 코드가 어떤 자료형을 받을지 예측할 수 없습니다. 그래서 파이썬은 `/` 의 결과를 **무조건 실수로 통일**했고, 정수 결과가 필요하면 `//` 를 쓰도록 나눠 두었습니다.
- `//` 가 내림인 이유: 나눗셈을 "몇 묶음 만들 수 있는가"로 보면 답은 언제나 하나입니다. `-7` 을 2씩 묶는 경우 `-4` 묶음과 남는 `1` 로 보아야 `-4 × 2 + 1 = -7` 이 성립합니다. `-3` 묶음으로 보면 남는 값이 `-1` 이 되어 "나머지는 0 이상"이라는 약속이 깨집니다.
- 그래서 `%` 의 값은 몫이 정해지면 따라옵니다. 공식은 `a % b = a - (a // b) * b` 입니다. `-7 % 2` 는 `-7 - (-4) × 2 = 1` 이 됩니다.
- 주의할 대비: `int()` 는 0 쪽으로 자르므로 `int(-7 / 2)` 는 `-3`, `-7 // 2` 는 `-4` 로 **결과가 다릅니다.** 음수가 섞이는 문제에서는 둘 중 무엇을 쓸지 반드시 정해야 합니다.
- 괄호가 필요한 이유도 같은 맥락입니다. `2 + 3 * 4` 에서 곱셈이 먼저인 것은 수학의 약속을 그대로 가져온 것이고, 파이썬은 그 약속을 어기지 않습니다. 순서를 바꾸고 싶으면 `( )` 로 "여기부터 먼저"라고 표시해 줍니다.

**문제**

**1) 두 수의 계산기** · Easy

- **요구사항**: 두 정수를 입력받아 합, 차, 곱을 차례로 출력하는 프로그램을 작성합니다.
- **입력**: 한 줄에 두 정수가 공백으로 구분되어 주어집니다.
- **출력**: 첫째 줄에 두 수의 합, 둘째 줄에 차(앞의 수 - 뒤의 수), 셋째 줄에 곱을 출력합니다.
- **예제**: `7 3` → `10` / `4` / `21` (세 줄)
- **예제**: `10 4` → `14` / `6` / `40` (세 줄)
- **셀프체크**: 차는 "뒤 - 앞"이 아니라 "앞 - 뒤" 순서인지 확인하세요. 곱셈 기호는 `×`가 아니라 `*`입니다.

```runner
@@SOLUTION
a, b = input().split()
a = int(a)
b = int(b)
print(a + b)
print(a - b)
print(a * b)
@@TESTS
--IN
7 3
--OUT
10
4
21
--IN
10 4
--OUT
14
6
40
@@EXPL
접근: 한 줄에 두 정수가 공백으로 들어오므로 나눠 받은 뒤 각각 정수로 바꾸고, 합·차·곱을 순서대로 한 줄씩 출력합니다.

- `input().split()`: 입력 한 줄을 공백 기준으로 잘라 두 조각(문자열)으로 나눠 `a`, `b`에 담습니다.
- `int(a)`, `int(b)`: 문자열이라 그대로 더하면 이어붙여지므로, 계산 전에 정수로 바꿉니다.
- `print(a + b)` → 합, `print(a - b)` → 차(앞의 수 - 뒤의 수), `print(a * b)` → 곱을 각각 한 줄씩 출력합니다.

재작성 순서: (1) 두 값을 공백으로 나눠 받는다 → (2) 둘 다 `int`로 변환한다 → (3) 합·차·곱을 순서대로 `print` 세 번 한다. 차는 반드시 `a - b`(앞 - 뒤), 곱셈 기호는 `*`를 씁니다.
```

**2) 몫과 나머지** · Medium

- **요구사항**: 사탕 개수와 사람 수를 입력받아, 한 사람이 몇 개씩 가질 수 있는지와 남는 사탕이 몇 개인지 출력합니다.
- **입력**: 한 줄에 사탕 개수와 사람 수가 공백으로 구분되어 주어집니다. (사람 수는 1 이상)
- **출력**: 첫째 줄에 한 사람이 갖는 사탕 수, 둘째 줄에 남는 사탕 수를 출력합니다.
- **예제**: `17 5` → `3` / `2` (두 줄)
- **예제**: `20 4` → `5` / `0` (두 줄)
- **셀프체크**: 한 사람이 갖는 개수는 `/`(소수)가 아니라 `//`(몫)로 구합니다. 남는 개수는 `%`로 구합니다. 딱 나누어떨어지면 나머지가 `0`이어야 합니다.

```runner
@@SOLUTION
a, b = input().split()
a = int(a)
b = int(b)
print(a // b)
print(a % b)
@@TESTS
--IN
17 5
--OUT
3
2
--IN
20 4
--OUT
5
0
@@EXPL
접근: 사탕을 사람 수로 똑같이 나눌 때, 한 사람이 갖는 개수는 "몫"이고 남는 사탕은 "나머지"입니다. 몫은 `//`, 나머지는 `%`로 구합니다.

- `input().split()`으로 사탕 개수와 사람 수를 두 조각으로 나눈 뒤 `int`로 정수 변환합니다.
- `a // b`: 소수점 아래를 버린 몫이라 "한 사람이 온전히 갖는 개수"가 됩니다.
- `a % b`: 나눈 뒤 남는 값이라 "남는 사탕 수"가 됩니다. 딱 나누어떨어지면 `0`이 나옵니다.
- 몫을 먼저, 나머지를 그다음 줄에 출력합니다.

재작성 순서: (1) 두 수를 공백으로 나눠 정수로 받는다 → (2) `//`로 몫을 구해 출력 → (3) `%`로 나머지를 구해 출력. `/`(소수 나눗셈)와 헷갈리지 않도록 주의합니다.
```

**3) 온도 변환** · Medium

```runner
- `c = int(input())`: 섭씨 온도를 한 개 정수로 받습니다.

- `print(f)`: 계산 결과를 출력하면 `77.0`처럼 끝에 `.0`이 붙은 실수로 나옵니다.

```

## L2. 합과 평균

**개념**

- 여러 개의 값을 다룰 때 가장 많이 하는 계산이 "합(모두 더한 값)"과 "평균(합을 개수로 나눈 값)"입니다.
- 합은 `+`로 모두 더하면 됩니다. 예: 세 수 `a, b, c`의 합은 `a + b + c`.
- 평균은 "합 ÷ 개수"입니다. 개수가 3개면 합을 `3`으로 나눕니다.

- 평균을 구할 때 나눗셈 종류를 상황에 맞게 고릅니다.

- 소수까지 정확한 평균이 필요하면 `/`를 씁니다. 예: `(a + b + c) / 3`.
- 소수를 버리고 정수 평균만 필요하면 `//`를 씁니다.

- 괄호가 중요합니다. `a + b + c / 3`은 `c`만 3으로 나누므로 틀립니다. 반드시 `(a + b + c) / 3`처럼 합 전체를 괄호로 묶으세요.

```python
a, b, c = 10, 20, 30
total = a + b + c      # 60
avg = total / 3        # 20.0
print(total)           # 60
print(avg)             # 20.0
```

- 합을 먼저 변수에 담아 두면(`total`) 평균을 구할 때 다시 쓸 수 있어 편리하고 실수도 줄어듭니다.

**그림으로 보기**

괄호가 있고 없고에 따라 **나눗셈이 잡아먹는 범위**가 달라집니다. 아래 밑줄이 "먼저 계산되는 덩어리"입니다.

```text
  a = 10   b = 20   c = 30

  (a + b + c) / 3
   +---+---+
       60  ->  60 / 3 = 20.0            # correct average

  a + b + c / 3
          +-+-+
           10.0  ->  10 + 20 + 10.0 = 40.0    # only c was divided
```

평균에서 `/` 와 `//` 중 무엇을 고르느냐에 따라 결과의 자료형과 값이 함께 달라집니다.

```text
  numbers: 3  5  8  4        total = 20        count = 4

  total / 4    ->  5.0       # float, decimal point always shown
  total // 4   ->  5         # int, decimals dropped

  numbers: 1  2  4           total = 7         count = 3

  total / 3    ->  2.3333333333333335
  total // 3   ->  2         # 0.333... is thrown away
```

**손으로 따라가기**

입력 `3 5 8 4` 로 합과 정수 평균을 구하는 과정입니다. 값이 언제 문자열에서 정수로 바뀌는지도 함께 봅니다.

| 단계 | 실행한 줄 | `total` | `avg` | 설명 |
|------|-----------|---------|-------|------|
| 1 | `a, b, c, d = input().split()` | — | — | 네 조각 모두 아직 문자열 |
| 2 | `a = int(a)` … `d = int(d)` | — | — | `3 5 8 4` 네 정수가 준비됨 |
| 3 | `total = a + b + c + d` | `20` | — | `3+5=8`, `+8=16`, `+4=20` 순서로 더해짐 |
| 4 | `avg = total // 4` | `20` | `5` | `20 // 4 = 5`, 소수점 아래가 없어 딱 떨어짐 |
| 5 | `print(total)` / `print(avg)` | `20` | `5` | 두 줄에 `20`, `5` 출력 |

4단계에서 `/` 를 썼다면 `avg` 는 `5.0` 이 되어 출력이 `5` 가 아니라 `5.0` 이 됩니다. 문제가 요구하는 모양을 먼저 확인해야 하는 이유입니다.

**왜 이렇게 되는가**

- 괄호가 필요한 이유: 파이썬은 `/` 를 `+` 보다 먼저 계산합니다. 그래서 `a + b + c / 3` 은 "`c` 를 3으로 나눈 뒤 나머지를 더하라"로 읽힙니다. 사람이 말로 한 "합을 3으로 나눠라"와 순서가 다릅니다.
- 괄호는 그 순서를 사람 쪽으로 되돌리는 표시입니다. `(a + b + c)` 라고 쓰면 "이 덩어리를 먼저 하나의 값으로 만들라"는 뜻이 되어, 그다음에야 `/ 3` 이 적용됩니다.
- 합을 `total` 변수에 먼저 담는 방법이 더 안전한 이유도 여기 있습니다. `total / 3` 에는 나눌 덩어리가 이미 하나의 값이라 **괄호를 빠뜨릴 자리 자체가 없습니다.**
- 나누는 수는 언제나 "값의 개수"입니다. 값이 3개면 3, 4개면 4입니다. 개수를 잘못 세면 식은 맞아도 답이 틀립니다.
- `//` 를 쓸지 `/` 를 쓸지는 문제가 요구하는 **출력 모양**이 정합니다. "정수 평균"이면 `//`, "소수까지"면 `/` 입니다. `/` 결과에는 딱 떨어져도 `.0` 이 붙는다는 점을 예제 출력과 대조해 확인합니다.

**문제**

**1) 세 수의 합과 평균** · Easy

- **요구사항**: 세 정수를 입력받아 합과 평균을 출력합니다. 평균은 소수까지 정확하게 구합니다.
- **입력**: 한 줄에 세 정수가 공백으로 구분되어 주어집니다.
- **출력**: 첫째 줄에 세 수의 합, 둘째 줄에 평균을 출력합니다.
- **예제**: `10 20 30` → `60` / `20.0` (두 줄)
- **예제**: `1 2 4` → `7` / `2.3333333333333335` (두 줄)
- **셀프체크**: 평균은 합 전체를 괄호로 묶어 `(a + b + c) / 3`로 계산했는지 확인하세요. `/`를 썼으므로 딱 떨어지는 경우에도 `20.0`처럼 실수로 출력됩니다.

```runner
@@SOLUTION
a, b, c = input().split()
a = int(a)
b = int(b)
c = int(c)
total = a + b + c
avg = total / 3
print(total)
print(avg)
@@TESTS
--IN
10 20 30
--OUT
60
20.0
--IN
1 2 4
--OUT
7
2.3333333333333335
@@EXPL
접근: 세 정수를 받아 먼저 합을 구해 변수에 담고, 그 합을 개수 3으로 나눠 평균을 구합니다. 소수까지 정확한 평균이 필요하므로 `/`를 씁니다.

- `input().split()`으로 세 조각으로 나눈 뒤 각각 `int`로 변환합니다.
- `total = a + b + c`: 세 수를 모두 더한 합을 변수에 담아 둡니다.
- `avg = total / 3`: 합을 개수 3으로 나눕니다. `total`이 이미 합 전체이므로 `(a + b + c) / 3`과 같은 결과이고, `/`라서 실수로 나옵니다.
```

**2) 두 과목 평균 점수** · Easy

- **요구사항**: 국어 점수와 영어 점수를 입력받아 두 과목의 평균을 출력합니다.
- **입력**: 한 줄에 두 정수(국어, 영어)가 공백으로 구분되어 주어집니다.
- **출력**: 두 과목 평균을 한 줄에 출력합니다.
- **예제**: `90 80` → `85.0`
- **예제**: `85 100` → `92.5`
- **셀프체크**: 개수가 2개이므로 `2`로 나눕니다. `(k + e) / 2` 형태로 괄호를 빠뜨리지 않았는지 확인하세요.

```runner
@@SOLUTION
k, e = input().split()
k = int(k)
e = int(e)
avg = (k + e) / 2
print(avg)
@@TESTS
--IN
90 80
--OUT
85.0
--IN
85 100
--OUT
92.5
@@EXPL
접근: 두 점수를 받아 합을 개수 2로 나눠 평균을 구합니다. 소수 평균이 필요하므로 `/`를 쓰고, 합 전체를 괄호로 묶습니다.

- `input().split()`으로 국어·영어 점수를 나눠 받은 뒤 각각 `int`로 변환합니다.
- `(k + e) / 2`: 두 점수를 먼저 더한 뒤 2로 나눕니다. 괄호가 없으면 `e`만 2로 나눠지므로 괄호가 꼭 필요합니다.
- `print(avg)`: 평균을 출력합니다. `/`라서 `85.0`, `92.5`처럼 실수로 나옵니다.

재작성 순서: (1) 두 점수를 공백으로 나눠 정수로 받는다 → (2) `(k + e) / 2`로 평균을 구한다 → (3) 출력한다. 나누는 수는 값의 개수인 2이고, 합 전체를 괄호로 감싸는 것을 잊지 않습니다.
```

**3) 네 수의 합과 정수 평균** · Medium

- **요구사항**: 네 정수를 입력받아 합과 "정수 평균(소수점 아래를 버린 평균)"을 출력합니다.
- **입력**: 한 줄에 네 정수가 공백으로 구분되어 주어집니다.
- **출력**: 첫째 줄에 네 수의 합, 둘째 줄에 정수 평균을 출력합니다.
- **예제**: `10 20 30 40` → `100` / `25`
- **예제**: `3 5 8 4` → `20` / `5`
- **셀프체크**: 정수 평균이므로 `/`가 아니라 `//`를 써서 `(a + b + c + d) // 4`로 구합니다. `//`로 구한 값에는 `.0`이 붙지 않아야 합니다(예: `25`, `5`).

```runner
@@SOLUTION
a, b, c, d = input().split()
a = int(a)
b = int(b)
c = int(c)
d = int(d)
total = a + b + c + d
avg = total // 4
print(total)
print(avg)
@@TESTS
--IN
10 20 30 40
--OUT
100
25
--IN
3 5 8 4
--OUT
20
5
@@EXPL
접근: 네 정수의 합을 구한 뒤, 소수점 아래를 버린 정수 평균이 필요하므로 `/` 대신 `//`로 나눕니다.

- `input().split()`으로 네 조각으로 나눈 뒤 각각 `int`로 변환합니다.
- `total = a + b + c + d`: 네 수를 모두 더해 합을 변수에 담습니다.
- `avg = total // 4`: 합을 개수 4로 몫 나눗셈합니다. `//`라서 결과에 `.0`이 붙지 않는 정수가 됩니다.
- 합을 먼저, 정수 평균을 그다음 줄에 출력합니다.

재작성 순서: (1) 네 수를 공백으로 나눠 정수로 받는다 → (2) 합을 `total`에 담는다 → (3) `total // 4`로 정수 평균을 구한다 → (4) 합, 평균 순으로 출력한다. 소수를 버려야 하므로 `/`가 아니라 `//`를 쓰는 점이 핵심입니다.
```
