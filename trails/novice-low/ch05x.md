## L19. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch5(단순 반복문)의 핵심을 **반복 훈련**하고, 코딩테스트 단골 유형으로 **확장**하는 연습 세트다. 새 문법은 없다. `for / range`, `while`, 누적 변수(`cnt`·`total`·`prod`), `continue / break`, `while True` + 종료 신호, 플래그(하나라도 / 모두)만으로 16문제를 푼다. 중첩 반복문과 리스트는 쓰지 않는다.

- **반복 훈련 개념**
- `range` 시작·끝·간격: 끝은 포함되지 않고, 거꾸로 갈 때는 간격을 음수로 — `for i in range(n, 0, -3):`
- 누적 세 형제: 개수는 `cnt = 0` 에 `+= 1`, 합은 `total = 0` 에 `+= 값`, 곱은 `prod = 1` 에 `*= 값` — 초기값이 각각 0, 0, **1**
- `continue` 와 `break`: "이번 회차만 건너뛰기"는 `continue`, "반복 자체를 끝내기"는 `break` — `if i % 10 == k: continue`
- 종료 신호(센티넬): 몇 개가 올지 모르는 입력은 `while True:` 안에서 `input()` 하고 약속된 값에 `break` — `if x < 0: break`
- 플래그와 이전 값 기억: "모두"는 `True` 로 시작해 어기면 `False`, "하나라도"는 `False` 로 시작해 만나면 `True`. 앞 값과 비교하려면 `prev` 변수에 직전 값을 담아 둔다 — `prev = cur`

- **코딩테스트 출제 맵**: 이 챕터의 유형은 백준 「단계별로 풀어보기」의 '반복문' 단계(구구단·합 구하기 류)와 solved.ac CLASS 1~2(약수·자릿수 합·최대공약수·완전수 류)에 그대로 등장한다. 이 레슨의 유형 확장 문제는 그 대표 유형을 소재와 수치를 새로 만들어 이 챕터 수준으로 재구성한 것이다.

**1) 구구단 한 단 출력** · Easy

- **요구사항**: 정수 `n` 을 입력받아 구구단 `n` 단을 1부터 9까지 한 줄에 하나씩 출력하라. 각 줄은 `n * i = 결과` 형태로, 기호 양옆에 공백 한 칸씩 둔다.
- **입력**: 정수 `n` 한 개 (1 ≤ n ≤ 9)
- **출력**: `n * 1 = n` 부터 `n * 9 = 9n` 까지 총 9줄
- **예제**: `2` → `2 * 1 = 2` / `2 * 2 = 4` / `2 * 3 = 6` / `2 * 4 = 8` / `2 * 5 = 10` / `2 * 6 = 12` / `2 * 7 = 14` / `2 * 8 = 16` / `2 * 9 = 18` (9줄) · `9` → `9 * 1 = 9` / … / `9 * 9 = 81` (9줄)
- **셀프체크**: 9까지 포함하려면 `range(1, 10)`. `print(n, "*", i, "=", n * i)` 처럼 쉼표로 나열하면 값 사이에 공백이 자동으로 들어가 형식이 맞는다. 곱셈 기호는 문자열 `"*"` 로 출력하고, 실제 계산은 `n * i` 로 한다.

```runner
n = int(input())
for i in range(1, 10):
    print(n, "*", i, "=", n * i)

(1) 접근·핵심 아이디어

- 곱하는 수 `i` 가 1부터 9까지 정확히 9번 바뀌므로 `for i in range(1, 10)` 이 딱 맞는다. 끝값 10은 포함되지 않아 마지막은 9다.
- 한 줄에 여러 조각(수, 기호, 수, 기호, 결과)을 공백으로 띄워 찍어야 한다. `print` 에 쉼표로 여러 값을 넘기면 사이에 공백이 하나씩 들어가므로(Ch1에서 배움) 형식을 손으로 맞출 필요가 없다.

(2) 코드 단계별

- `n = int(input())` 로 단을 읽는다.
- `for i in range(1, 10):` — i가 1, 2, …, 9로 9번 돈다.
- `print(n, "*", i, "=", n * i)` — 다섯 조각을 쉼표로 나열한다. `"*"` 와 `"="` 는 화면에 보이는 기호이므로 문자열로 넣고, 마지막 `n * i` 는 실제 곱셈이라 따옴표 없이 쓴다.

(3) 스스로 다시 짤 때 생각 순서

- 출력 한 줄의 모양을 먼저 적어 본다: `2 * 3 = 6` → 조각 다섯 개.
- 그중 바뀌는 조각(`i`, `n * i`)과 고정 조각(`n`, 기호)을 구분하고, 바뀌는 조각을 반복 변수로 만든다.
- `range(1, 10)` 이 9까지인지, `range(1, 9)` 로 잘못 써서 8단까지만 나오지 않는지 마지막 줄을 확인한다.
```

**2) 세 칸씩 뒤로 걷기** · Easy

- **요구사항**: 출발 위치 `N` 에서 시작해 3칸씩 뒤로(값이 3씩 줄어들게) 이동하며 매 위치를 한 줄에 하나씩 출력하라. 위치가 0 이하가 되면 출력하지 않고 멈춘다.
- **입력**: 정수 `N` 한 개 (1 ≤ N ≤ 100)
- **출력**: N, N−3, N−6, … 중 1 이상인 값을 한 줄에 하나씩
- **예제**: `10` → `10` / `7` / `4` / `1` · `9` → `9` / `6` / `3` · `2` → `2`
- **셀프체크**: 감소 반복은 `range(N, 0, -3)`. 끝값 0은 포함되지 않으므로 1까지는 나오고 0은 안 나온다. 간격 `-3` 을 빠뜨리면 아무것도 출력되지 않는다.

```runner
@@SOLUTION
n = int(input())
for i in range(n, 0, -3):
    print(i)
@@TESTS

10
--OUT
10
7
4
1
--IN
9
--OUT
9
6
3
--IN
2
--OUT

@@EXPL
(1) 접근·핵심 아이디어

- "N부터 3씩 줄이며 0 이하가 되기 전까지"는 `range` 의 세 값으로 그대로 옮길 수 있다. 시작 `N`, 끝 `0`(포함 안 됨), 간격 `-3`.
- 지금까지는 1씩 감소만 다뤘지만, 간격은 어떤 음수든 가능하다. 마지막에 도달하는 값은 N을 3으로 나눈 나머지에 따라 1, 2, 3 중 하나가 된다.

(2) 코드 단계별

- `n = int(input())` 로 출발 위치를 읽는다.
- `for i in range(n, 0, -3):` — n, n−3, n−6, … 을 만들다가 0 이하가 되는 값은 만들지 않는다. 끝 0이 열려 있으므로 정확히 "1 이상"만 나온다.
- 반복 안에서 `print(i)` 로 현재 위치를 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- "어디서 시작(N) → 얼마씩(−3) → 어디까지(0은 제외)"를 `range` 세 값으로 옮긴다.
- 감소 반복에서는 간격이 음수인지, 끝값이 시작값보다 작은지 두 가지를 확인한다.
- `10` (마지막 1), `9` (마지막 3), `2` (한 번만) 세 경우로 마지막 값이 0 이하로 새지 않는지 검산한다.
```

**3) 나머지가 R인 수 세기** · Easy

- **요구사항**: 1부터 `N` 까지의 정수 중에서 `K` 로 나눈 나머지가 정확히 `R` 인 수가 몇 개인지 세어 출력하라.
- **입력**: 한 줄에 정수 세 개 `N K R` (1 ≤ N ≤ 1000, 2 ≤ K ≤ 20, 0 ≤ R ≤ 19)
- **출력**: 조건을 만족하는 수의 개수 한 줄
- **예제**: `10 3 1` → `4` · `10 4 0` → `2` · `5 3 5` → `0`
- **셀프체크**: 배수 세기(`% K == 0`)의 확장판이다. 조건은 `i % K == R`. 함정: 나머지는 항상 K보다 작으므로 `R >= K` 이면(예: `5 3 5`) 만족하는 수가 없어 0이 나와야 하고, 코드 그대로 두면 자연히 0이 된다.

```runner
@@SOLUTION
n, k, r = input().split()
n = int(n)
k = int(k)
r = int(r)
cnt = 0
for i in range(1, n + 1):
    if i % k == r:
        cnt += 1
print(cnt)
@@TESTS
--IN
10 3 1
--OUT
4
--IN
10 4 0
--OUT
2
--IN
5 3 5
--OUT
0
@@EXPL
(1) 접근·핵심 아이디어

- "몇 개인지"는 `cnt` 누적이다. 1부터 N까지 훑으며 조건이 참일 때만 `cnt` 를 1 늘린다.
- 조건은 배수 판정 `i % k == 0` 에서 0 자리를 `r` 로 바꾼 `i % k == r` 이다. `10 3 1` 이면 1, 4, 7, 10이 3으로 나눈 나머지가 1이라 4개다.
- 나머지는 0 이상 K−1 이하만 가능하다. R이 K 이상이면 조건이 한 번도 참이 되지 않아 0이 되는데, 이는 오류가 아니라 정답이다.

(2) 코드 단계별

- 세 수를 `split()` 으로 나눠 각각 정수로 바꾼다.
- `cnt = 0` 을 반복 **밖**에서 준비한다.
- `for i in range(1, n + 1):` 로 1부터 N까지(포함) 돈다.
- `if i % k == r:` 이 참이면 `cnt += 1`.
- 반복이 끝난 뒤 `print(cnt)`.

(3) 스스로 다시 짤 때 생각 순서

- 세는 변수 0 준비 → 범위 훑기 → 조건 만족 시 +1 → 끝나고 출력, 네 단계를 순서대로 쓴다.
- `range(1, n)` 으로 쓰면 N이 빠진다. `10 3 1` 에서 10이 세어져야 4가 되므로 끝값 `n + 1` 을 확인한다.
- R이 K 이상인 입력(`5 3 5`)에서 0이 나오는지 넣어 본다.
```

**4) 구간 안의 배수 합** · Easy

- **요구사항**: `A` 이상 `B` 이하의 정수 중 `K` 의 배수만 골라 그 합을 출력하라.
- **입력**: 한 줄에 정수 세 개 `A B K` (1 ≤ A ≤ B ≤ 1000, 1 ≤ K ≤ 100)
- **출력**: 배수들의 합 한 줄 (배수가 없으면 `0`)
- **예제**: `1 10 3` → `18` · `7 9 5` → `0` · `5 5 5` → `5`
- **셀프체크**: 합 변수는 반복 밖에서 `0` 으로 시작. `cnt` 처럼 `+1` 이 아니라 그 수 자체(`+i`)를 더한다. 끝 B를 포함하려면 `range(A, B + 1)`. 구간에 배수가 하나도 없으면 0이 그대로 출력된다.

```runner
@@SOLUTION
a, b, k = input().split()
a = int(a)
b = int(b)
k = int(k)
total = 0
for i in range(a, b + 1):
    if i % k == 0:
        total += i
print(total)
@@TESTS
--IN
1 10 3
--OUT
18
--IN
7 9 5
--OUT
0
--IN
5 5 5
--OUT
5
@@EXPL
(1) 접근·핵심 아이디어

- "골라서 더하기"는 `sum` 누적에 `if` 를 얹은 패턴이다. 구간을 훑으며 K의 배수일 때만 `total` 에 그 값을 더한다.
- 앞 문제(개수 세기)와 구조가 같고, 반복 안에서 `cnt += 1` 대신 `total += i` 를 쓴다는 점만 다르다. 이 차이를 몸에 익히는 것이 목적이다.

(2) 코드 단계별

- 세 수를 `split()` 으로 나눠 각각 정수로 바꾼다.
- `total = 0` 을 반복 밖에서 준비한다.
- `for i in range(a, b + 1):` 로 A부터 B까지(포함) 돈다.
- `if i % k == 0:` 이면 `total += i` 로 그 수를 더한다.
- 반복이 끝난 뒤 `print(total)`. `7 9 5` 처럼 배수가 없으면 한 번도 더하지 않아 0이 나온다.

(3) 스스로 다시 짤 때 생각 순서

- "무엇을 더하나?" → 값 자체(`i`). "언제 더하나?" → K의 배수일 때. 이 두 답을 `if` 와 `+=` 로 옮긴다.
- 구간이 A부터이므로 시작값을 1이 아니라 `a` 로 두는 것을 잊지 않는다.
- `5 5 5` (구간이 한 점이고 그 값이 배수)와 `7 9 5` (배수 없음)로 경계를 검산한다.
```

**5) 홀수만 곱하기** · Easy

- **요구사항**: 1부터 `N` 이하의 홀수를 모두 곱한 값을 출력하라. (1 × 3 × 5 × … )
- **입력**: 정수 `N` 한 개 (1 ≤ N ≤ 15)
- **출력**: N 이하 홀수들의 곱 한 줄
- **예제**: `5` → `15` · `7` → `105` · `2` → `1`
- **셀프체크**: 곱의 시작값은 0이 아니라 **1**이다. 홀수만 훑으려면 `range(1, N + 1, 2)`. N이 2이면 홀수는 1뿐이라 답은 1이다.

```runner
@@SOLUTION
n = int(input())
prod = 1
for i in range(1, n + 1, 2):
    prod *= i
print(prod)
@@TESTS
--IN
5
--OUT
15
--IN
7
--OUT
105
--IN
2
--OUT
1
@@EXPL
(1) 접근·핵심 아이디어

- 곱을 누적하는 `prod` 패턴이다. 합과 달리 시작값이 1이어야 한다. 0으로 시작하면 무엇을 곱해도 0이 되어 버린다.
- 홀수만 곱하려면 `if i % 2 == 1` 로 걸러도 되지만, `range` 의 간격을 2로 주면 처음부터 홀수만 만들어져 조건문이 필요 없다.

(2) 코드 단계별

- `n = int(input())` 로 N을 읽는다.
- `prod = 1` 로 곱 변수를 준비한다(반드시 1).
- `for i in range(1, n + 1, 2):` — 1, 3, 5, … 중 N 이하인 값을 만든다. 끝을 `n + 1` 로 둬야 N이 홀수일 때 N도 포함된다.
- `prod *= i` 로 매번 곱한다. `prod = prod * i` 와 같은 뜻이다.
- 반복 후 `print(prod)`.

(3) 스스로 다시 짤 때 생각 순서
```

**8) 약수의 개수** · Medium

- **출력**: 약수의 개수 한 줄
- **예제**: `12` → `6` · `7` → `2` · `1` → `1`

```runner

(1) 접근·핵심 아이디어

- 약수는 "N을 나누어떨어지게 하는 수"이므로, 1부터 N까지 후보를 하나씩 넣어 `n % i == 0` 인지 확인하면 된다. 참인 횟수를 세면 약수의 개수다.
```

**9) 각 자리 숫자의 합** · Medium

- **요구사항**: 양의 정수 `N` 의 각 자리 숫자를 모두 더한 값을 출력하라. 예를 들어 1234는 1+2+3+4 = 10 이다.
- **입력**: 정수 `N` 한 개 (1 ≤ N ≤ 1,000,000,000)
- **출력**: 자리 숫자의 합 한 줄
- **예제**: `1234` → `10` · `1005` → `6` · `9` → `9`
- **셀프체크**: 맨 끝 자리는 `N % 10`, 그 자리를 떼어 내는 것은 `N //= 10`. N이 0이 될 때까지 반복하며 끝자리를 합에 더한다. 중간에 0이 있는 수(1005)는 0을 더하는 셈이라 문제없이 6이 나온다.

```runner
@@SOLUTION
n = int(input())
total = 0
while n > 0:
    total += n % 10
    n //= 10
print(total)
@@TESTS
--IN
1234
--OUT
10
--IN
1005
--OUT
6
--IN
9
--OUT
9
@@EXPL
(1) 접근·핵심 아이디어

- 자릿수 세기(L4·L15)에서 "10으로 나누면 끝자리가 사라진다"를 배웠다. 이번엔 사라지기 전에 그 끝자리(`n % 10`)를 합에 더해 두면 자리 숫자의 합이 된다.
- 합을 담는 `total` 은 0에서 시작하고, N이 0이 되면 더 볼 자리가 없으므로 `while n > 0` 으로 반복한다.

(2) 코드 단계별

- `n = int(input())` 로 N을 읽고 `total = 0` 을 준비한다.
- `while n > 0:` — 자리가 남아 있는 동안 반복.
- `total += n % 10` — 현재 끝자리를 더한다. 1234면 첫 회차에 4.
- `n //= 10` — 끝자리를 떼어 낸다. 1234 → 123 → 12 → 1 → 0.
- 반복이 끝나면 `print(total)`.

(3) 스스로 다시 짤 때 생각 순서

- "끝자리 얻기(`% 10`) → 끝자리 버리기(`// 10`)"를 한 회차로 묶고, 얻은 끝자리를 어디에 쓸지(더하기) 정한다.
- 더하기를 버리기보다 **먼저** 해야 그 자리가 합에 들어간다. 순서를 바꾸면 첫 자리가 빠진다.
- `9` (한 자리)와 `1005` (가운데 0)로 경계를 검산한다.
```

**10) 최대공약수 반복법** · Medium

- **요구사항**: 두 양의 정수 `A`, `B` 의 최대공약수를 구하라. 방법: `B` 가 0이 될 때까지 "A를 B로 나눈 나머지"를 구해 A 자리에 B를, B 자리에 나머지를 넣는 일을 반복한다. B가 0이 되었을 때의 A가 최대공약수다.
- **입력**: 한 줄에 정수 두 개 `A B` (1 ≤ A, B ≤ 100000)
- **출력**: 최대공약수 한 줄
- **예제**: `12 18` → `6` · `7 5` → `1` · `20 100` → `20` · `9 9` → `9`
- **셀프체크**: 회차마다 세 줄 — 나머지를 임시 변수에 저장 → A에 B를 넣기 → B에 나머지를 넣기. 순서를 바꾸면 값이 덮여 사라진다. A가 B보다 작아도(`20 100`) 첫 회차에서 자동으로 자리가 바뀌므로 따로 처리하지 않아도 된다.

```runner
@@SOLUTION
a, b = input().split()
a = int(a)
b = int(b)
while b != 0:
    r = a % b
    a = b
    b = r
print(a)
@@TESTS
--IN
12 18
--OUT
6
--IN
7 5
--OUT
1
--IN
20 100
--OUT
20
--IN
9 9
--OUT
9
@@EXPL
(1) 접근·핵심 아이디어

- "두 수의 최대공약수는 (작은 수)와 (큰 수를 작은 수로 나눈 나머지)의 최대공약수와 같다"는 성질을 반복해서 쓰면, 나머지가 0이 되는 순간 남은 수가 답이다. 이를 유클리드 호제법이라 부르며, 코딩테스트에서 매우 자주 쓰인다.
- 12와 18이면 18 % 12 = 6 → 12 % 6 = 0 → 답 6. 매 회차 수가 빠르게 작아지므로 반복 횟수는 아주 적다.

(2) 코드 단계별

- 두 수를 `split()` 으로 나눠 정수 `a`, `b` 로 만든다.
- `while b != 0:` — 나머지가 0이 될 때까지 반복.
- `r = a % b` 로 나머지를 임시 변수에 담는다. 이 값을 먼저 구해 두어야 다음 줄에서 `a` 를 덮어써도 잃지 않는다.
- `a = b`, `b = r` 로 자리를 옮긴다. `20 100` 이면 첫 회차에 r = 20, a = 100, b = 20 이 되어 큰 수·작은 수 순서가 저절로 맞춰진다.
- 반복이 끝나면(`b == 0`) `print(a)`.

(3) 스스로 다시 짤 때 생각 순서

- "나머지가 0이 될 때까지"가 종료 조건이므로 `while b != 0`.
- 한 회차에 값 세 개(나머지, 새 a, 새 b)가 움직인다. 임시 변수 `r` 을 먼저 만들고 그다음 a, b를 갱신하는 순서를 고정한다.
- `7 5` (서로소 → 1), `9 9` (같은 수 → 자기 자신), `20 100` (앞이 더 작음)으로 검산한다.
```

**11) 등차수열의 합** · Medium

- **요구사항**: 첫째 항 `a`, 공차 `d`, 항의 개수 `n` 을 입력받아 등차수열의 첫 `n` 개 항을 모두 더한 값을 출력하라. 공식을 쓰지 말고 반복으로 항을 하나씩 만들어 더한다.
- **입력**: 한 줄에 정수 세 개 `a d n` (−100 ≤ a ≤ 100, −100 ≤ d ≤ 100, 1 ≤ n ≤ 100)
- **출력**: 첫 n개 항의 합 한 줄
- **예제**: `1 2 5` → `25` · `10 -3 4` → `22` · `5 0 3` → `15`
- **셀프체크**: 변수 두 개가 필요하다 — 현재 항 `term` (a에서 시작해 매번 d씩 변함)과 합 `total` (0에서 시작). "더한 뒤에 다음 항으로 넘어가는" 순서를 지켜야 첫째 항이 빠지지 않는다. 공차가 음수(`10 -3 4`)면 항이 줄어든다.

```runner
@@SOLUTION
a, d, n = input().split()
a = int(a)
d = int(d)
n = int(n)
total = 0
term = a
for i in range(n):
    total += term
    term += d
print(total)
@@TESTS
--IN
1 2 5
--OUT
25
--IN
10 -3 4
--OUT
22
--IN
5 0 3
--OUT
15
@@EXPL
(1) 접근·핵심 아이디어

- 등차수열은 "앞 항에 d를 더하면 다음 항"이다. 그래서 현재 항을 담는 변수 `term` 을 a로 시작해 매 회차 d씩 키우면 항이 차례로 만들어진다.
- 항을 몇 개 만들지는 정확히 n번이므로 `range(n)` 으로 n번 반복하고, 만들어진 항을 `total` 에 누적한다. 반복 변수 `i` 의 값은 쓰지 않는다.

(2) 코드 단계별

- 세 수를 `split()` 으로 나눠 정수로 바꾼다.
- `total = 0` (합), `term = a` (첫째 항) 두 변수를 준비한다.
- `for i in range(n):` 안에서 먼저 `total += term` 으로 현재 항을 더하고, 그다음 `term += d` 로 다음 항을 만든다.
- 순서가 중요하다. 더하기 전에 `term += d` 를 하면 첫째 항 a가 합에서 빠지고 n+1번째 항이 들어간다.
- 반복 후 `print(total)`. `1 2 5` 는 1+3+5+7+9 = 25.

(3) 스스로 다시 짤 때 생각 순서

- "각 항을 어떻게 만들까?" → 이전 항 + d → 갱신되는 변수 `term`.
- "몇 번 반복?" → n번 → `range(n)`.
- 회차 안에서 "더하기 → 갱신" 순서를 고정하고, `5 0 3` (공차 0이면 a를 n번 더한 값)과 `10 -3 4` (음수 공차)로 검산한다.
```

**12) 전 과목 과락 없음** · Medium

- **요구사항**: 과목 수 `n` 을 먼저 입력받고, 이어서 `n` 개의 점수를 한 줄에 하나씩 입력받는다. 모든 과목이 40점 이상이면 `PASS`, 한 과목이라도 40점 미만이면 `FAIL` 을 출력하라.
- **입력**: 첫 줄에 정수 `n` (1 ≤ n ≤ 100). 다음 n줄에 각각 점수(0 이상 100 이하의 정수) 하나씩.

```runner
- 입력이 n줄로 개수가 정해져 있으므로 `for i in range(n)` 으로 n번 읽는다. 어기는 값을 만나도 `break` 하지 않고 계속 읽어도 결과는 같다. 플래그는 한 번 `False` 가 되면 다시 `True` 로 돌아가지 않기 때문이다.

(2) 코드 단계별

(3) 스스로 다시 짤 때 생각 순서

- "모두"라는 말을 보면 플래그를 `True` 로 시작하고 어기는 조건을 찾는다.

- `1 / 40` (과목 하나, 경계값)과 `90 39 100` (가운데 하나만 미달)으로 검산한다.
```

**13) 같은 수가 연달아 나오는가** · Medium

- **요구사항**: 정수 `n` 개가 한 줄에 하나씩 순서대로 주어진다. 바로 앞의 수와 같은 수가 한 번이라도 나오면 `YES`, 그런 일이 없으면 `NO` 를 출력하라. (같은 수가 있어도 연달아 있지 않으면 `NO`)
- **입력**: 첫 줄에 정수 `n` (1 ≤ n ≤ 100). 다음 n줄에 각각 정수 하나씩 (−1000 이상 1000 이하).
- **출력**: `YES` 또는 `NO` 한 줄
- **예제**: `4` / `3` / `5` / `5` / `1` → `YES` · `3` / `2` / `4` / `2` → `NO` · `1` / `7` → `NO`
- **셀프체크**: 리스트 없이 풀려면 "직전 값"을 변수 `prev` 에 기억해 두고, 새 값 `cur` 를 읽을 때마다 비교한 뒤 `prev = cur` 로 갱신한다. 첫 값은 비교 상대가 없으므로 반복 전에 따로 읽어 `prev` 로 둔다. n이 1이면 비교할 쌍이 없어 `NO`.

```runner
    print("YES")
else:
    print("NO")

(1) 접근·핵심 아이디어

- "하나라도" 패턴이다. `found = False` 로 시작해 조건을 만족하는 쌍을 만나면 `True` 로 켠다.
- 이번 조건은 "바로 앞 값과 같은가"라 직전 값이 필요하다. 리스트 없이도 변수 하나(`prev`)에 직전 값을 담아 두고, 새 값을 읽을 때마다 비교한 뒤 `prev` 를 새 값으로 바꾸면 된다. 이 "이전 값 기억" 기법은 뒤 챕터에서도 계속 쓰인다.

(2) 코드 단계별

- `n` 을 읽고, 첫 값을 `prev = int(input())` 로 반복 밖에서 따로 읽는다. 첫 값은 비교 상대가 없기 때문이다.
- 남은 값은 n−1개이므로 `for i in range(n - 1):` 로 돈다.
- 회차마다 `cur = int(input())` 로 새 값을 읽고 `if cur == prev: found = True`.
- 비교가 끝나면 `prev = cur` 로 직전 값을 갱신한다. 이 줄을 빼면 계속 첫 값과만 비교한다.
- 반복 후 `found` 에 따라 `YES` / `NO`.

(3) 스스로 다시 짤 때 생각 순서

- "앞 값과 비교"가 나오면 `prev` 변수를 떠올리고, 첫 값을 반복 밖에서 읽는다.
- 반복 횟수가 n이 아니라 n−1이라는 점을 확인한다(첫 값을 이미 읽었으므로).
- `2 4 2` (같은 수가 있지만 떨어져 있음 → NO)와 `n = 1` (반복 0번 → NO)로 검산한다.
```

**14) 완전수 판별** · Hard

- **요구사항**: 자기 자신을 제외한 약수들의 합이 자기 자신과 같은 수를 완전수라 한다(예: 6 = 1 + 2 + 3). 양의 정수 `N` 이 완전수이면 `YES`, 아니면 `NO` 를 출력하라.
- **입력**: 정수 `N` 한 개 (1 ≤ N ≤ 10000)
- **출력**: `YES` 또는 `NO` 한 줄
- **예제**: `6` → `YES` · `28` → `YES` · `12` → `NO` · `1` → `NO`
- **셀프체크**: 약수 합을 구하되 N 자신은 빼야 하므로 후보 범위는 `range(1, N)` (N 미포함). 합 변수는 0으로 시작. N이 1이면 자기 자신을 뺀 약수가 없어 합이 0이라 `NO`. 12는 1+2+3+4+6 = 16 ≠ 12 라 `NO`.

```runner
@@SOLUTION
n = int(input())
total = 0
for i in range(1, n):
    if n % i == 0:
        total += i
if total == n:
    print("YES")
else:
    print("NO")
@@TESTS

@@EXPL
(1) 접근·핵심 아이디어

- 약수 개수(8번)와 자리 숫자 합(9번)을 합친 문제다. 후보를 훑으며 약수이면 **개수가 아니라 그 값**을 더하고, 마지막에 합이 N과 같은지 비교한다.
- "자기 자신을 제외한"이 핵심 조건이다. 범위를 `range(1, n + 1)` 로 두면 N이 합에 들어가 절대 같아질 수 없으므로, 끝을 `n` 으로 둬 N을 빼야 한다.

(2) 코드 단계별

- `n = int(input())` 로 N을 읽고 `total = 0` 을 준비한다.
- `for i in range(1, n):` — 1부터 N−1까지 후보를 돈다.
- `if n % i == 0:` 이면 약수이므로 `total += i`.
- 반복 후 `if total == n:` 이면 `YES`, 아니면 `NO`.
- N = 1 이면 `range(1, 1)` 이 비어 반복이 돌지 않고 `total` 은 0, `0 == 1` 은 거짓 → `NO`.

(3) 스스로 다시 짤 때 생각 순서

- "약수의 합"을 먼저 만들고(8번 문제에서 `cnt += 1` 을 `total += i` 로), 그다음 "N을 뺀"을 범위 끝으로 처리한다.
- 합과 N을 비교하는 `if` 는 반복이 끝난 뒤(들여쓰기 밖)에 둔다.
- `6`, `28` (완전수)뿐 아니라 `12` (약수 합이 더 큼)와 `1` (약수 합 0)로 두 방향의 `NO` 를 검산한다.
```

**15) 우박수 단계 세기** · Hard

- **요구사항**: 양의 정수 `N` 에 다음 규칙을 1이 될 때까지 반복 적용한다. 짝수이면 2로 나누고, 홀수이면 3을 곱한 뒤 1을 더한다. 1이 될 때까지 규칙을 적용한 횟수를 출력하라. N이 처음부터 1이면 0이다.
- **입력**: 정수 `N` 한 개 (1 ≤ N ≤ 10000)
- **출력**: 1이 될 때까지 적용한 횟수 한 줄
- **예제**: `6` → `8` · `1` → `0` · `7` → `16`
- **셀프체크**: 6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1 로 8번이다. 종료 조건은 `n != 1`. 반복 안에서 짝수/홀수에 따라 `n` 을 바꾸고, 어느 쪽이든 횟수를 1 늘린다. `n //= 2` (정수 나눗셈)를 써야 정수가 유지된다.

```runner
@@SOLUTION
n = int(input())
cnt = 0
while n != 1:
    if n % 2 == 0:
        n //= 2
    else:
        n = n * 3 + 1
    cnt += 1
print(cnt)
@@TESTS
--IN
6
--OUT
8
--IN
1
--OUT
0
--IN
7
--OUT
16
@@EXPL
(1) 접근·핵심 아이디어

- 언제 끝날지 미리 알 수 없고 "1이 될 때까지"라는 조건만 있으므로 `while n != 1` 이 자연스럽다. 회차마다 규칙 하나를 적용하고 횟수를 센다.
- 규칙이 짝수/홀수로 갈리므로 반복 안에 `if / else` 를 넣는다. 어느 갈래든 한 번 적용한 것이므로 `cnt += 1` 은 `if / else` 바깥, 반복문 안에 둔다.
- N이 1이면 조건이 처음부터 거짓이라 반복이 0번 돌고 0이 출력된다. 이 경계를 위해 `while True` + 즉시 검사보다 조건을 앞에 두는 `while` 이 편하다.

(2) 코드 단계별

- `n = int(input())` 로 N을 읽고 `cnt = 0` 을 준비한다.
- `while n != 1:` — 1이 아닌 동안 반복.
- `if n % 2 == 0: n //= 2` — 짝수면 절반. `else: n = n * 3 + 1` — 홀수면 3배 더하기 1.
- `cnt += 1` — 갈래와 상관없이 한 번 적용했음을 센다.
- 반복이 끝나면 `print(cnt)`.

(3) 스스로 다시 짤 때 생각 순서

- 종료 조건("1이 되면")을 `while` 조건으로 옮긴다.
- 한 회차 = 규칙 적용 1회 + 횟수 1 증가. 규칙의 갈래는 `if / else`, 횟수는 갈래 밖.
- `1` (0번)과 `6` (8번, 손으로 따라가 보기)으로 검산한다. 나눗셈을 `/` 로 쓰면 3.0 같은 실수가 되어 `% 2` 판정이 꼬일 수 있으니 반드시 `//`.
```

**16) 연속 상승 최장 기록** · Hard

- **요구사항**: `n` 일 동안의 기온이 한 줄에 하나씩 주어진다. "전날보다 기온이 높은 날"이 연달아 이어진 최대 일수를 출력하라. 예를 들어 기온이 3, 5, 7, 6, 8 이면 5와 7은 연속 상승 2일, 6에서 끊기고, 8은 상승 1일이므로 답은 2다. 상승한 날이 하루도 없으면 0.
- **입력**: 첫 줄에 정수 `n` (1 ≤ n ≤ 100). 다음 n줄에 각각 기온(−50 이상 50 이하의 정수) 하나씩.
- **출력**: 연속 상승의 최대 일수 한 줄
- **예제**: `5` / `3` / `5` / `7` / `6` / `8` → `2` · `4` / `9` / `7` / `5` / `5` → `0` · `4` / `1` / `2` / `3` / `4` → `3`
- **셀프체크**: 변수 세 개 — 직전 값 `prev`, 현재 연속 길이 `streak`, 지금까지의 최댓값 `best`. 새 값이 직전보다 크면 `streak` 를 1 늘리고 `best` 와 비교해 갱신, 크지 않으면(같아도) `streak` 를 0으로 되돌린다. 매 회차 끝에 `prev = cur`. n이 1이면 비교할 날이 없어 0.

```runner
@@SOLUTION

    cur = int(input())

        if streak > best:
            best = streak
    else:
        streak = 0
    prev = cur
print(best)

(1) 접근·핵심 아이디어

- 13번 문제의 "이전 값 기억"에 두 가지 누적을 더한 문제다. 상승이 이어지는 동안은 `streak` 를 1씩 키우고, 끊기면 0으로 되돌린다. 그리고 `streak` 가 커질 때마다 최댓값 `best` 를 갱신해 두면 반복이 끝났을 때 `best` 가 답이다.
- 최댓값 갱신은 "지금 값이 기록보다 크면 기록을 바꾼다"는 `if` 하나로 충분하다. 끊기는 순간 `streak` 를 0으로 되돌려도 `best` 는 남아 있으므로 기록이 사라지지 않는다.
- "전날보다 높은"이므로 같은 기온(`5 5`)은 상승이 아니다. 조건은 `>=` 가 아니라 `>`.

(2) 코드 단계별

- `n` 을 읽고 첫 기온을 `prev` 로 반복 밖에서 읽는다. `streak = 0`, `best = 0` 을 준비한다.
- `for i in range(n - 1):` 로 남은 n−1일을 돈다. 회차마다 `cur = int(input())`.
- `if cur > prev:` — 상승이면 `streak += 1`, 그리고 `if streak > best: best = streak` 로 기록 갱신.
- `else:` — 상승이 아니면 `streak = 0` 으로 초기화.
- 회차 끝에 `prev = cur` 로 직전 값을 바꾼다. 반복 후 `print(best)`.

(3) 스스로 다시 짤 때 생각 순서

- 필요한 변수를 먼저 정한다: 직전 값, 현재 연속 길이, 최대 기록. 각각의 초기값(첫 입력, 0, 0)도 함께.
- 회차 안 흐름을 "비교 → 길이 갱신/초기화 → 기록 갱신 → 직전 값 갱신" 순서로 고정한다. `prev = cur` 를 `if` 안에 넣으면 하락한 날의 값이 기억되지 않으니 반드시 `if / else` 바깥에 둔다.
- `3 5 7 6 8` (끊긴 뒤 다시 시작해도 기록 2 유지), `9 7 5 5` (상승 없음 → 0), `1 2 3 4` (끝까지 상승 → 3), `n = 1` (0)로 검산한다.
```
