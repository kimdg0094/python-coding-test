## L15. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch9(문자열)의 핵심을 **반복 훈련**하고, 코딩테스트 단골 유형으로 **확장**하는 연습 세트다. 문자열을 한 글자씩 순회하며 세고·판별하고·새 문자열을 만들어 내는 기본기를 소재만 바꿔 여러 번 다시 쓴 뒤, 카이사르 암호·연속 글자 압축·최다 빈도 글자·아나그램 같은 단골 유형까지 이어 간다.

- **반복 훈련 개념**:
  - 순회하며 세기: `for c in s:` 안에서 `if c in "aeiou": cnt += 1`
  - 글자 종류 판별: 소문자 `"a" <= c <= "z"`, 대문자 `"A" <= c <= "Z"`, 숫자 `"0" <= c <= "9"`
  - 새 문자열 만들기(문자열은 불변): `result = ""`에서 시작해 `result = result + 글자`
  - 아스키 계산: `chr((ord(c) - ord("a") + k) % 26 + ord("a"))`처럼 `ord`로 번호를 얻고 `chr`로 되돌린다
  - 슬라이싱·비교·변환: `s[i:i+len(p)] == p`, `s[::-1]`, `int(c)`, `str(cnt)`

- **코딩테스트 출제 맵**: 백준 「단계별로 풀어보기」의 '문자열' 단계(글자 세기·아스키·단어 다루기), solved.ac CLASS 1~2의 문자열 문제, NeetCode 150의 'Arrays & Hashing'(아나그램·빈도 세기를 이 수준에서는 26칸 리스트로 푼다), 프로그래머스 「코딩테스트 고득점 Kit」 '해시' 유형의 입문 형태가 여기서 시작된다.

**문제**

**1) 모음 개수 세기** · Easy

- **요구사항**: 소문자로만 이루어진 문자열을 입력받아, 모음(`a`, `e`, `i`, `o`, `u`)이 모두 몇 번 나오는지 출력한다.
- **입력**: 한 줄에 공백 없는 소문자 문자열 `s`(길이 1 이상 100 이하).
- **출력**: 모음의 개수(정수).
- **예제**: `banana` → `3` · `rhythm` → `0`
- **셀프체크**: 모음 다섯 개를 `if c == "a" or c == "e" or ...`로 늘어놓아도 되지만 `c in "aeiou"`가 훨씬 짧다. 모음이 하나도 없으면 0이 나와야 하므로 `cnt`는 0에서 시작.

```runner
@@SOLUTION
s = input()
cnt = 0
for c in s:
    if c in "aeiou":
        cnt += 1
print(cnt)
@@TESTS
--IN
banana
--OUT
3
--IN
rhythm
--OUT
0
--IN
aeiou
--OUT
5
@@EXPL
(1) 접근·핵심 아이디어

- "특정 글자 개수 세기"의 확장으로, 찾는 글자가 한 개가 아니라 다섯 개(모음)다. 글자마다 "이 글자가 모음인가?"를 물어 참이면 센다.
- `in`은 "어떤 문자열 안에 이 글자가 있는가"를 묻는 연산이다. `c in "aeiou"`는 `c`가 다섯 모음 중 하나이면 참이므로, 조건 다섯 개를 `or`로 잇는 것과 같다.

(2) 코드 단계별

- 문자열 `s`를 받고 `cnt = 0`으로 시작한다.
- `for c in s:`로 글자를 하나씩 꺼내며 `c in "aeiou"`이면 `cnt += 1`.
- 순회가 끝나면 `cnt`를 출력한다. `rhythm`처럼 모음이 없으면 0이 그대로 남는다.

(3) 스스로 다시 짤 때 생각 순서

- 무엇을 세나 → 모음인 글자. 카운터 0에서 시작.
- 모음 판별을 어떻게 짧게 쓰나 → `c in "aeiou"`. 대문자 모음은 이 문제에서 나오지 않지만, 나온다면 `"AEIOU"`도 함께 봐야 한다.
- 언제 찍나 → 순회가 끝난 뒤 한 번.
```

**2) 섞인 문자열의 숫자 합** · Easy

- **요구사항**: 영문자와 숫자가 섞인 문자열에서 숫자 글자만 골라, 그 값들을 모두 더해 출력한다. 숫자 글자가 하나도 없으면 `0`을 출력한다.
- **입력**: 한 줄에 공백 없는 문자열 `s`(길이 1 이상 100 이하, 영문자와 숫자만 포함).
- **출력**: 숫자 글자 값의 합(정수).
- **예제**: `a1b2c3` → `6` · `abc` → `0`
- **셀프체크**: 숫자 글자인지 판별은 `"0" <= c <= "9"`. 판별 없이 `int(c)`를 하면 영문자에서 오류가 난다. `"9"`는 글자이므로 더하기 전에 `int`로 바꿔야 한다(안 바꾸면 문자열끼리 이어붙는다).

```runner
@@SOLUTION
s = input()
total = 0
for c in s:
    if "0" <= c <= "9":
        total += int(c)
print(total)
@@TESTS
--IN
a1b2c3
--OUT
6
--IN
abc
--OUT
0
--IN
9x9
--OUT
18
@@EXPL
(1) 접근·핵심 아이디어

- 각 자리 숫자의 합(L12)과 같은 누적이지만, 이번엔 영문자가 섞여 있어 "숫자 글자인가?"를 먼저 걸러야 한다. 거른 글자만 정수로 바꿔 더한다.
- 숫자 글자 판별은 아스키 순서를 이용한 범위 비교 `"0" <= c <= "9"`다. `'0'`부터 `'9'`까지 코드가 이어져 있으므로 이 비교 하나로 열 개의 숫자 글자를 모두 잡는다.

(2) 코드 단계별

- 문자열 `s`를 받고 `total = 0`으로 시작한다.
- `for c in s:`로 글자를 하나씩 꺼내, `"0" <= c <= "9"`일 때만 `total += int(c)`.
- 영문자는 조건에 걸리지 않아 건너뛴다. 순회 후 `total`을 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- 무엇을 더하나 → 숫자 글자의 값. 그러니 "판별 → 변환 → 누적" 세 단계.
- 판별을 빼먹으면 → `int("a")`에서 오류. 변환을 빼먹으면 → 문자열 이어붙이기가 되어 오류.
- 숫자가 없으면 → `total`이 0으로 남아 그대로 정답.
```

**3) 대문자와 소문자 개수** · Easy

- **요구사항**: 문장을 입력받아 대문자의 개수와 소문자의 개수를 공백으로 구분해 한 줄에 출력한다. 공백·숫자·기호는 어느 쪽에도 세지 않는다.
- **입력**: 한 줄에 문자열 `s`(길이 1 이상 100 이하, 공백 포함 가능).
- **출력**: `대문자개수 소문자개수` 형태의 한 줄.
- **예제**: `Hello World` → `2 8` · `12345` → `0 0`
- **셀프체크**: 대문자는 `"A" <= c <= "Z"`, 소문자는 `"a" <= c <= "z"`. 공백은 둘 다 아니므로 자동으로 빠진다. 두 카운터를 `print(up, low)`처럼 공백 구분으로 한 줄에 찍는다.

```runner
@@SOLUTION
s = input()
up = 0
low = 0
for c in s:
    if "A" <= c <= "Z":
        up += 1
    elif "a" <= c <= "z":
        low += 1
print(up, low)
@@TESTS
--IN
Hello World
--OUT
2 8
--IN
12345
--OUT
0 0
--IN
ABC
--OUT
3 0
@@EXPL
(1) 접근·핵심 아이디어

- 글자마다 "대문자인가, 소문자인가, 둘 다 아닌가"를 판별해 해당 카운터를 올린다. 한 글자는 세 경우 중 하나에만 속하므로 `if / elif`로 이어 쓴다.
- 대문자와 소문자는 아스키 범위가 따로 있다(`'A'`=65~`'Z'`=90, `'a'`=97~`'z'`=122). 범위 비교 두 개로 판별한다.

(2) 코드 단계별

- 문자열 `s`를 받고 카운터 `up = 0`, `low = 0`을 준비한다.
- `for c in s:`로 글자를 순회하며 `"A" <= c <= "Z"`면 `up += 1`, 아니고 `"a" <= c <= "z"`면 `low += 1`.
- 공백·숫자는 두 조건 모두 거짓이라 아무것도 하지 않는다.
- `print(up, low)`로 두 수를 공백으로 구분해 한 줄에 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- 카운터가 몇 개 필요한가 → 두 개(대·소). 셋째 경우는 그냥 무시.
- 판별 범위를 어떻게 쓰나 → `"A" <= c <= "Z"`, `"a" <= c <= "z"`(따옴표 안 글자 자체로 비교).
- 출력 형식 → `print(up, low)`가 자동으로 사이에 공백 하나를 넣는다.
```

**4) 양 끝 글자 맞바꾸기** · Easy

- **요구사항**: 공백 없는 문자열의 첫 글자와 마지막 글자를 서로 맞바꾼 결과를 출력한다. 길이가 1이면 원래 문자열을 그대로 출력한다.
- **입력**: 한 줄에 공백 없는 문자열 `s`(길이 1 이상 50 이하).
- **출력**: 양 끝 글자를 맞바꾼 문자열.
- **예제**: `apple` → `eppla` · `ab` → `ba`
- **셀프체크**: 파이썬 문자열은 `s[0] = ...`처럼 직접 못 바꾸니 조각을 이어 새로 만든다: `s[-1] + s[1:-1] + s[0]`. 길이 2면 가운데 조각 `s[1:-1]`이 빈 문자열이 되어 정상이다. 하지만 길이 1이면 같은 글자가 두 번 붙어 `xx`가 되는 함정이 있으므로 따로 처리한다.

```runner
@@SOLUTION
s = input()
if len(s) == 1:
    print(s)
else:
    print(s[-1] + s[1:-1] + s[0])
@@TESTS
--IN
apple
--OUT
eppla
--IN
ab
--OUT
ba
--IN
x
--OUT
x
@@EXPL
(1) 접근·핵심 아이디어

- 문자열은 불변이므로 "맞바꾼 새 문자열"을 조각 세 개로 조립한다: 마지막 글자 + 가운데 부분 + 첫 글자.
- 가운데 부분은 슬라이싱 `s[1:-1]`(둘째 글자부터 마지막 글자 직전까지)이다. 길이 2면 이 조각이 빈 문자열이라 자연스럽게 두 글자만 바뀐다.

(2) 코드 단계별

- 문자열 `s`를 받는다.
- `len(s) == 1`이면 바꿀 상대가 없으니 그대로 출력한다. 이 예외를 빼면 `s[-1] + "" + s[0]`가 같은 글자 두 개가 되어 `x` → `xx`로 틀린다.
- 그 외에는 `s[-1] + s[1:-1] + s[0]`을 출력한다. `apple`이면 `e` + `ppl` + `a`.

(3) 스스로 다시 짤 때 생각 순서

- 결과의 모양을 조각으로 그려 본다 → [끝 글자][가운데][첫 글자].
- 각 조각의 슬라이싱 → `s[-1]`, `s[1:-1]`, `s[0]`.
- 가장 짧은 입력에서 확인 → 길이 2는 자연스럽게 되고, 길이 1은 따로 처리해야 한다.
```

**5) 붙어 있는 같은 글자 쌍** · Easy

- **요구사항**: 문자열에서 바로 옆 글자와 같은 자리가 몇 곳인지 센다. 즉 `s[i]`와 `s[i+1]`이 같은 `i`의 개수를 출력한다.
- **입력**: 한 줄에 공백 없는 문자열 `s`(길이 1 이상 100 이하).
- **출력**: 같은 글자가 붙어 있는 쌍의 개수.
- **예제**: `aabbcc` → `3` · `abc` → `0`
- **셀프체크**: `s[i+1]`을 보므로 `i`는 `len(s) - 2`까지만 가야 한다. 반복은 `range(len(s) - 1)`. `aaaa`는 (0,1), (1,2), (2,3) 세 쌍이라 3이다. 길이 1이면 반복이 한 번도 돌지 않아 0.

```runner
@@SOLUTION
s = input()
cnt = 0
for i in range(len(s) - 1):
    if s[i] == s[i + 1]:
        cnt += 1
print(cnt)
@@TESTS
--IN
aabbcc
--OUT
3
--IN
abc
--OUT
0
--IN
aaaa
--OUT
3
--IN
a
--OUT
0
@@EXPL
(1) 접근·핵심 아이디어

- 이웃한 두 글자를 비교해야 하므로 `for c in s`(글자만 꺼냄)로는 부족하고, 인덱스 `i`로 돌며 `s[i]`와 `s[i+1]`을 함께 봐야 한다.
- 마지막 글자는 오른쪽 이웃이 없다. 그래서 `i`의 범위를 하나 줄여 `range(len(s) - 1)`로 두는 것이 이 문제의 핵심 경계 처리다.

(2) 코드 단계별

- 문자열 `s`를 받고 `cnt = 0`.
- `for i in range(len(s) - 1)`: `i`는 0부터 `len(s) - 2`까지. `s[i] == s[i + 1]`이면 `cnt += 1`.
- 순회 후 `cnt` 출력. `aaaa`는 겹치는 쌍을 각각 세어 3이 된다.

(3) 스스로 다시 짤 때 생각 순서

- 비교 대상이 "이웃 두 글자" → 인덱스 순회 필요.
- 마지막 인덱스에서 `s[i+1]`이 터지지 않게 → 범위를 `len(s) - 1`로.
- 길이 1 입력 → `range(0)`이라 반복 없음, 0 출력. 오류가 안 나는지 확인.
```

**6) 카이사르 암호** · Medium

- **요구사항**: 소문자와 공백으로 된 문장과 정수 `k`를 입력받아, 각 소문자를 알파벳에서 `k`칸 뒤 글자로 바꾼 암호문을 출력한다. `z`를 넘어가면 `a`부터 다시 이어진다(예: `y`를 3칸 밀면 `b`). 공백은 그대로 둔다.
- **입력**: 첫 줄에 문장 `s`(길이 1 이상 100 이하, 소문자와 공백), 둘째 줄에 정수 `k`(0 ≤ k ≤ 25).
- **출력**: 암호문 한 줄.
- **예제**: `abc xyz` / `3` → `def abc` · `hello` / `0` → `hello`
- **셀프체크**: `chr(ord(c) + k)`만 쓰면 `z` 근처에서 알파벳 밖 기호가 나온다. `a`를 0으로 보는 번호 `ord(c) - ord("a")`에 `k`를 더하고 `% 26`으로 한 바퀴 돌린 뒤 다시 `ord("a")`를 더해 글자로 되돌린다. 공백은 조건으로 걸러 그대로 붙인다.

```runner
@@SOLUTION
s = input()
k = int(input())
result = ""
for c in s:
    if "a" <= c <= "z":
        result = result + chr((ord(c) - ord("a") + k) % 26 + ord("a"))
    else:
        result = result + c
print(result)
@@TESTS
--IN
abc xyz
3
--OUT
def abc
--IN
hello
0
--OUT
hello
--IN
z
1
--OUT
a
@@EXPL
(1) 접근·핵심 아이디어

- 글자를 밀려면 글자를 숫자로 바꿔야 한다(`ord`). 다만 `z`(122) 다음이 `a`(97)로 이어지게 하려면 "알파벳 안에서의 번호"(`a`=0 ~ `z`=25)로 바꾼 뒤 `% 26`을 적용해야 한다.
- 즉 한 글자의 변환은 네 단계다: 번호 만들기 `ord(c) - ord("a")` → `k` 더하기 → `% 26`으로 되돌리기 → `+ ord("a")` 후 `chr`로 글자 복원.

(2) 코드 단계별

- 문장 `s`와 `k`를 받고, 결과를 담을 `result = ""`를 준비한다(문자열은 불변이므로 새로 만든다).
- `for c in s:`에서 `"a" <= c <= "z"`인 글자만 `chr((ord(c) - ord("a") + k) % 26 + ord("a"))`로 바꿔 붙인다.
- 공백 같은 나머지 글자는 `else`에서 그대로 붙인다.
- 예제 1의 `x`: 번호 23 + 3 = 26 → `26 % 26 = 0` → `a`. `k = 0`이면 모든 글자가 제자리라 원문 그대로다.

(3) 스스로 다시 짤 때 생각 순서

- 글자를 밀려면 → 숫자로 변환. 어떤 숫자로 → `a`를 0으로 두는 번호(`% 26`을 쓰기 위해).
- 되돌아가는 처리 → `% 26`. 이걸 빼면 `z + 1`이 `{`가 된다.
- 바꾸지 않을 글자 → 조건으로 걸러 그대로 concat. 결과는 새 문자열에 쌓는다.
```

**7) 연속 글자 압축** · Medium

- **요구사항**: 문자열에서 같은 글자가 연속으로 이어진 구간을 `글자+개수`로 줄여 쓴 압축 문자열을 출력한다. 개수가 1이어도 `1`을 붙인다.
- **입력**: 한 줄에 공백 없는 소문자 문자열 `s`(길이 1 이상 100 이하).
- **출력**: 압축된 문자열 한 줄.
- **예제**: `aaabbc` → `a3b2c1` · `abc` → `a1b1c1`
- **셀프체크**: "현재 글자"와 "몇 개째인지"를 변수로 들고 다니다가 다른 글자를 만나면 그때까지의 결과를 붙인다. 순회가 끝난 뒤 **마지막 구간은 아직 안 붙어 있으므로** 반복 밖에서 한 번 더 붙여야 한다. 개수는 정수라 `str(cnt)`로 바꿔 이어 붙인다. `aabaa`는 `a2b1a2`로, 떨어진 같은 글자는 합치지 않는다.

```runner
@@SOLUTION
s = input()
result = ""
cur = s[0]
cnt = 1
for i in range(1, len(s)):
    if s[i] == cur:
        cnt += 1
    else:
        result = result + cur + str(cnt)
        cur = s[i]
        cnt = 1
result = result + cur + str(cnt)
print(result)
@@TESTS
--IN
aaabbc
--OUT
a3b2c1
--IN
abc
--OUT
a1b1c1
--IN
zzzz
--OUT
z4
--IN
aabaa
--OUT
a2b1a2
@@EXPL
(1) 접근·핵심 아이디어

- 문자열을 앞에서부터 읽으며 "지금 이어지고 있는 글자 `cur`"와 "그 글자가 몇 개째인지 `cnt`"를 기억한다. 같은 글자면 `cnt`만 늘리고, 다른 글자를 만나면 지금까지의 구간을 `cur + str(cnt)`로 결과에 붙인 뒤 새 구간을 시작한다.
- 구간은 "다음 글자가 다를 때" 마무리되므로, 맨 마지막 구간은 반복 안에서 절대 붙지 않는다. 반복이 끝난 뒤 한 번 더 붙이는 것이 이 유형의 대표 함정이다.

(2) 코드 단계별

- `result = ""`, `cur = s[0]`, `cnt = 1`로 시작한다(첫 글자는 이미 한 개 세어 둔 상태).
- `for i in range(1, len(s))`: 둘째 글자부터. `s[i] == cur`면 `cnt += 1`, 아니면 `result = result + cur + str(cnt)` 후 `cur = s[i]`, `cnt = 1`.
- 반복이 끝나면 남아 있는 마지막 구간을 `result = result + cur + str(cnt)`로 붙인다.
- `result`를 출력한다. `zzzz`는 반복 안에서 한 번도 붙이지 않고 마지막 처리에서 `z4`가 된다.

(3) 스스로 다시 짤 때 생각 순서

- 무엇을 기억하며 읽나 → 현재 글자와 연속 개수.
- 언제 결과에 붙이나 → 글자가 바뀌는 순간 + 반복 끝난 뒤 한 번.
- 개수를 붙일 때 → 정수를 `str`로 바꿔야 `+`가 된다. `str` 없이 붙이면 오류.
```

**8) 가장 많이 나온 글자** · Medium

- **요구사항**: 소문자 문자열에서 가장 많이 등장한 글자와 그 횟수를 출력한다. 횟수가 같은 글자가 여러 개면 알파벳 순으로 가장 앞선 글자를 답한다.
- **입력**: 한 줄에 공백 없는 소문자 문자열 `s`(길이 1 이상 100 이하).
- **출력**: `글자 횟수` 형태의 한 줄.
- **예제**: `banana` → `a 3` · `zzyy` → `y 2`
- **셀프체크**: 글자별 횟수를 담을 26칸 리스트 `cnt = [0] * 26`을 만들고, 글자 `c`의 칸 번호는 `ord(c) - ord("a")`다. 최댓값을 찾을 때 `a`부터 `z` 순으로 보며 `>`(초과)로만 갱신하면 동률일 때 먼저 본 글자(알파벳 앞)가 남는다. 칸 번호를 글자로 되돌릴 땐 `chr(번호 + ord("a"))`.

```runner
@@SOLUTION
s = input()
cnt = [0] * 26
for c in s:
    cnt[ord(c) - ord("a")] += 1
best = 0
for i in range(1, 26):
    if cnt[i] > cnt[best]:
        best = i
print(chr(best + ord("a")), cnt[best])
@@TESTS
--IN
banana
--OUT
a 3
--IN
zzyy
--OUT
y 2
--IN
abc
--OUT
a 1
@@EXPL
(1) 접근·핵심 아이디어

- Ch7에서 배운 "숫자별 등장 횟수" 리스트를 글자에 적용한다. 소문자는 26종이므로 26칸 리스트를 두고, 글자를 `ord(c) - ord("a")`로 0~25 번호로 바꿔 그 칸을 1씩 올린다.
- 다 센 뒤 26칸 중 최댓값 칸을 찾는다. 칸 번호가 곧 알파벳 순서이므로 0번부터 보며 `>`로만 갱신하면 동률에서 앞 글자가 자동으로 선택된다.

(2) 코드 단계별

- `cnt = [0] * 26`을 만들고 `for c in s:`로 `cnt[ord(c) - ord("a")] += 1`.
- `best = 0`(a 칸)에서 시작해 `for i in range(1, 26)`으로 돌며 `cnt[i] > cnt[best]`일 때만 `best = i`.
- `chr(best + ord("a"))`로 칸 번호를 글자로 되돌리고, `cnt[best]`와 함께 출력한다.
- `zzyy`는 y·z가 2번씩이지만 y(24번 칸)를 먼저 보고 z(25번)는 `>`가 아니라 갱신되지 않아 `y 2`.

(3) 스스로 다시 짤 때 생각 순서

- 횟수를 어디에 담나 → 글자 종류 수(26)만큼의 리스트. 칸 번호 = `ord(c) - ord("a")`.
- 최댓값 칸 찾기 → 0번부터 순서대로, 동률 규칙에 맞춰 `>` 또는 `>=` 선택(앞 글자면 `>`).
- 번호를 글자로 되돌리기 → `chr(번호 + ord("a"))`. 횟수는 리스트 값 그대로.
```

**9) 단어마다 뒤집기** · Medium

- **요구사항**: 공백 하나로 구분된 여러 단어로 된 문장을 입력받아, 단어의 순서는 그대로 두고 각 단어의 글자 순서만 뒤집어 출력한다.
- **입력**: 한 줄에 문장 `s`(단어 1개 이상 20개 이하, 단어는 소문자, 단어 사이 공백 하나).
- **출력**: 각 단어를 뒤집은 문장 한 줄(단어 사이 공백 하나).
- **예제**: `hello world` → `olleh dlrow` · `abc` → `cba`
- **셀프체크**: `input().split()`으로 단어 리스트를 만들고, 단어 하나는 `[::-1]`로 뒤집는다. 결과를 이어 붙일 때 첫 단어 앞이나 마지막 단어 뒤에 공백이 남지 않도록, 둘째 단어부터만 앞에 공백을 붙인다.

```runner
@@SOLUTION
words = input().split()
result = ""
for i in range(len(words)):
    if i > 0:
        result = result + " "
    result = result + words[i][::-1]
print(result)
@@TESTS
--IN
hello world
--OUT
olleh dlrow
--IN
abc
--OUT
cba
--IN
ab cd ef
--OUT
ba dc fe
@@EXPL
(1) 접근·핵심 아이디어

- 문장 전체를 뒤집으면 단어 순서까지 바뀌므로, 먼저 단어로 쪼갠 뒤 단어 하나씩만 뒤집어야 한다. `split()`이 공백 기준으로 단어 리스트를 만들어 준다(Ch7에서 숫자 입력에 쓰던 그 `split`이다).
- 뒤집기는 슬라이싱 `[::-1]`(L5). 뒤집은 단어들을 공백 하나로 이어 새 문장을 만든다.

(2) 코드 단계별

- `words = input().split()`으로 단어 리스트를 만든다. `hello world` → `["hello", "world"]`.
- `result = ""`에서 시작해 `for i in range(len(words))`로 단어를 순서대로 본다.
- `i > 0`일 때만 먼저 공백을 붙인다. 이렇게 하면 첫 단어 앞에는 공백이 없고 단어 사이에만 공백이 하나씩 들어간다.
- `words[i][::-1]`로 뒤집은 단어를 붙인다. 끝나면 `result` 출력.

(3) 스스로 다시 짤 때 생각 순서

- 무엇을 뒤집나 → 단어 각각. 그러니 먼저 단어로 쪼갠다.
- 공백을 언제 넣나 → 단어와 단어 "사이"에만. 둘째 단어부터 앞에 붙이는 방식이 가장 간단.
- 단어가 하나뿐이면 → 공백이 한 번도 안 붙어 뒤집은 단어만 나온다.
```

**10) 두 문자열의 공통 글자** · Medium

```runner
@@SOLUTION
a = input()
b = input()
result = ""
for i in range(26):
    c = chr(ord("a") + i)

(2) 코드 단계별

- 출력 순서 조건이 있으면 → 그 순서대로 "후보"를 돌리는 방법을 먼저 생각한다.
- 후보 만들기 → `chr(ord("a") + i)`. 확인 → `in` 두 번을 `and`로.
- 빈 결과 처리 → `""`과 비교해 `NONE`. 빈 문자열을 그냥 출력하면 빈 줄이 나와 틀린다.
```

**11) 부분 문자열 등장 횟수** · Medium

- **요구사항**: 문자열 `s`와 찾을 문자열 `p`를 입력받아, `s` 안에서 `p`가 몇 번 나타나는지 출력한다. 겹치는 경우도 각각 센다(`aaaa`에서 `aa`는 3번).
- **입력**: 첫 줄에 문자열 `s`, 둘째 줄에 문자열 `p`(둘 다 공백 없는 소문자, 길이 1 이상 100 이하).
- **출력**: 등장 횟수(정수). `p`가 `s`보다 길면 `0`.
- **예제**: `aaaa` / `aa` → `3` · `banana` / `ana` → `2`
- **셀프체크**: 시작 위치 `i`마다 `s[i:i+len(p)]`를 잘라 `p`와 비교한다. 시작 위치는 `0`부터 `len(s) - len(p)`까지이므로 반복은 `range(len(s) - len(p) + 1)`. `p`가 더 길면 이 범위가 비어 반복이 안 돌고 0이 나온다.

```runner
@@SOLUTION
s = input()
p = input()
cnt = 0
for i in range(len(s) - len(p) + 1):
    if s[i:i + len(p)] == p:
        cnt += 1
print(cnt)
@@TESTS
--IN
aaaa
aa
--OUT
3
--IN
banana
ana
--OUT
2
--IN
abc
d
--OUT
0
--IN
ab
abc
--OUT
0
@@EXPL
(1) 접근·핵심 아이디어

- 한 글자 찾기(L6)를 여러 글자로 확장한 것이다. 시작 위치 `i`를 하나씩 옮기며 `p`와 같은 길이의 조각 `s[i:i+len(p)]`를 잘라 `==`로 비교한다.
- 겹침도 세야 하므로 찾았다고 `len(p)`만큼 건너뛰지 않고 `i`를 항상 1씩 옮긴다.

(2) 코드 단계별

- `s`, `p`를 받고 `cnt = 0`.
- `for i in range(len(s) - len(p) + 1)`: 마지막 시작 위치는 `len(s) - len(p)`(거기서 `len(p)`글자를 자르면 딱 끝에 닿는다). `+ 1`은 `range`가 끝값을 포함하지 않기 때문.
- `s[i:i + len(p)] == p`이면 `cnt += 1`.
- 반복 후 `cnt` 출력. `banana`/`ana`는 `i = 1`과 `i = 3`에서 일치해 2.

(3) 스스로 다시 짤 때 생각 순서

- 비교 단위 → 길이 `len(p)`의 조각. 슬라이싱으로 자른다.
- 시작 위치 범위 → `0 ~ len(s) - len(p)`. 범위를 넘기면 조각이 짧아져 비교는 되지만 낭비고, 조각 길이를 따로 검사하지 않으려면 범위를 정확히 잡는다.
- `p`가 더 긴 경우 → 범위가 음수라 `range`가 비어 자연히 0.
```

**12) 글 속 숫자 덩어리의 합** · Hard

- **요구사항**: 영문자와 숫자가 섞인 문자열에서, 연속으로 붙어 있는 숫자 글자들을 하나의 수로 본다(`ab12cd3x`에는 12와 3이 있다). 그런 수들을 모두 더한 값을 출력한다. 숫자가 하나도 없으면 `0`.
- **입력**: 한 줄에 공백 없는 문자열 `s`(길이 1 이상 100 이하, 영문자와 숫자만 포함).
- **출력**: 숫자 덩어리들의 합(정수).
- **예제**: `ab12cd3x` → `15` · `abc` → `0`
- **셀프체크**: 숫자 글자를 만날 때마다 지금 만들고 있는 수 `num`을 `num * 10 + int(c)`로 키운다(`1` 다음 `2`를 만나면 `1*10 + 2 = 12`). 영문자를 만나면 `num`을 합에 넣고 `num = 0`으로 되돌린다. 문자열이 숫자로 끝나면 마지막 수가 아직 합에 안 들어갔으므로 **반복이 끝난 뒤 한 번 더** 넣는다. `07`처럼 앞에 0이 붙어도 이 계산은 7이 된다.

```runner
@@SOLUTION
s = input()
total = 0
num = 0
for c in s:
    if "0" <= c <= "9":
        num = num * 10 + int(c)
    else:
        total += num
        num = 0
total += num
print(total)
@@TESTS
--IN
ab12cd3x
--OUT
15
--IN
abc
--OUT
0
--IN
100
--OUT
100
--IN
7a07b
--OUT
14
@@EXPL
(1) 접근·핵심 아이디어

- 2번 문제(숫자 글자 합)와 다른 점은 붙어 있는 숫자들이 한 개의 수라는 것이다. 그래서 글자 하나를 바로 더하지 않고, "만드는 중인 수"에 자릿수로 붙여 나간다: 새 숫자 글자가 오면 `num = num * 10 + int(c)`.
- 수가 끝나는 시점은 "숫자가 아닌 글자를 만났을 때"와 "문자열이 끝났을 때" 두 가지다. 후자를 놓치면 `100`처럼 숫자로 끝나는 입력에서 0이 나온다.

(2) 코드 단계별

- `total = 0`(합), `num = 0`(만드는 중인 수)로 시작한다.
- `for c in s:`에서 숫자 글자면 `num = num * 10 + int(c)`, 아니면 `total += num` 후 `num = 0`.
- 영문자가 연달아 나오면 `num`이 0인 채로 더해져 합이 변하지 않는다(문제없음).
- 반복이 끝난 뒤 `total += num`으로 마지막 수를 반영하고 출력한다. `7a07b`는 7, 07(=7), 그리고 끝의 0이 더해져 14.

(3) 스스로 다시 짤 때 생각 순서

- 여러 자리 수를 어떻게 만들까 → 왼쪽 자리부터 `*10` 하며 붙이기.
- 수가 끝나는 순간은 언제인가 → 숫자 아닌 글자 + 문자열 끝. 두 곳 모두에서 합에 넣고 0으로 초기화.
- 검산 → `100`(숫자로 끝남), `abc`(숫자 없음), `7a07b`(앞자리 0)로 세 경우를 확인.
```

**13) 아나그램 판정** · Hard

- **요구사항**: 소문자 문자열 두 개를 입력받아, 한쪽의 글자 순서를 재배열해 다른 쪽과 똑같이 만들 수 있으면(같은 글자를 같은 개수만큼 가지면) `YES`, 아니면 `NO`를 출력한다.
- **입력**: 두 줄에 각각 공백 없는 소문자 문자열 `a`, `b`(길이 1 이상 100 이하, 길이가 서로 다를 수 있음).
- **출력**: `YES` 또는 `NO`.
- **예제**: `listen` / `silent` → `YES` · `aab` / `abb` → `NO`
- **셀프체크**: 글자별 개수가 모두 같은지 보면 된다. 26칸 리스트 하나에 `a`의 글자는 `+1`, `b`의 글자는 `-1` 하면, 아나그램일 때 모든 칸이 0이 된다. 길이가 다르면 어느 칸인가 0이 아니게 되어 자동으로 `NO`. 정렬을 배우기 전이라도 이 방법이면 충분하다.

```runner
@@SOLUTION
a = input()
b = input()
cnt = [0] * 26
for c in a:
    cnt[ord(c) - ord("a")] += 1
for c in b:
    cnt[ord(c) - ord("a")] -= 1
ok = True
for i in range(26):
    if cnt[i] != 0:
        ok = False
if ok:
    print("YES")
else:
    print("NO")
@@TESTS
--IN
listen
silent
--OUT
YES
--IN
aab
abb
--OUT
NO
--IN
a
a
--OUT
YES
--IN
ab
abc
--OUT
NO
@@EXPL
(1) 접근·핵심 아이디어

- 아나그램은 "글자의 순서만 다르고 종류와 개수는 같다"는 뜻이다. 그러니 순서는 무시하고 글자별 개수만 비교하면 된다.
- 개수 비교는 8번 문제의 26칸 리스트를 재활용한다. 리스트를 두 개 만들어 칸마다 비교해도 되지만, 하나에 `+1`/`-1`로 상쇄시키면 "전부 0인가"만 확인하면 되어 더 간단하다.

(2) 코드 단계별

- `cnt = [0] * 26`. `a`의 글자는 `cnt[ord(c) - ord("a")] += 1`, `b`의 글자는 같은 칸에 `-= 1`.
- `ok = True`로 두고 `for i in range(26)`으로 26칸을 모두 보며 `cnt[i] != 0`인 칸이 하나라도 있으면 `ok = False`.
- `ok`에 따라 `YES`/`NO` 출력. `aab`/`abb`는 a 칸이 +1, b 칸이 -1로 남아 `NO`.
- 길이가 다른 `ab`/`abc`는 c 칸이 -1로 남아 자연스럽게 `NO`가 된다(길이 비교를 따로 하지 않아도 된다).

(3) 스스로 다시 짤 때 생각 순서

- 순서를 무시하고 비교하려면 → 개수로 바꿔 비교.
- 두 개수 표를 어떻게 비교하나 → 한 표에 더하고 빼서 0인지 확인(또는 두 표를 칸마다 `==`).
- 판정 변수 → `ok = True`로 시작해 하나라도 어긋나면 `False`. 반복 끝난 뒤 한 번만 출력.
```

**14) 가장 긴 연속 구간** · Hard

- **요구사항**: 문자열에서 같은 글자가 끊기지 않고 가장 길게 이어진 구간을 찾아, 그 글자와 길이를 출력한다. 가장 긴 길이가 여러 구간에서 나오면 먼저 나온 구간을 답한다.
- **입력**: 한 줄에 공백 없는 소문자 문자열 `s`(길이 1 이상 100 이하).
- **출력**: `글자 길이` 형태의 한 줄.
- **예제**: `aabbbcc` → `b 3` · `aabb` → `a 2`
- **셀프체크**: 7번 압축 문제처럼 "현재 글자·현재 연속 길이"를 추적하면서, 한 글자를 처리할 때마다 현재 길이가 지금까지의 최대를 **초과**하는지 확인해 최대 글자·길이를 갱신한다. `>=`로 쓰면 동률에서 뒤 구간이 이겨 버린다. 길이 1 입력은 첫 글자가 곧 답(`z` → `z 1`).

```runner
@@SOLUTION
s = input()
best_c = s[0]
best_len = 1
cur_c = s[0]
cur_len = 1
for i in range(1, len(s)):
    if s[i] == cur_c:
        cur_len += 1
    else:
        cur_c = s[i]
        cur_len = 1
    if cur_len > best_len:
        best_len = cur_len
        best_c = cur_c
print(best_c, best_len)
@@TESTS
--IN
aabbbcc
--OUT
b 3
--IN
aabb
--OUT
a 2
--IN
abc
--OUT
a 1
--IN
z
--OUT
z 1
@@EXPL
(1) 접근·핵심 아이디어

- 연속 구간을 추적하는 방법은 압축 문제와 같다: 현재 글자 `cur_c`와 현재 연속 길이 `cur_len`을 들고 가며, 같은 글자면 길이를 늘리고 다른 글자면 새 구간을 시작한다.
- 여기에 "최대 갱신"을 결합한다. 매 글자마다 `cur_len`이 `best_len`보다 크면 최대를 바꾼다. 동률에서 먼저 나온 구간을 지키려면 `>`(초과)로만 갱신한다.

(2) 코드 단계별

- 첫 글자로 `best_c`, `cur_c`를, 길이 1로 `best_len`, `cur_len`을 초기화한다. 이렇게 하면 길이 1 입력도 반복 없이 정답이 준비된다.
- `for i in range(1, len(s))`: `s[i] == cur_c`면 `cur_len += 1`, 아니면 `cur_c = s[i]`, `cur_len = 1`.
- 같은 반복 안에서 바로 `cur_len > best_len`을 확인해 `best_len`, `best_c`를 함께 갱신한다. 구간이 끝나기를 기다릴 필요 없이 길이가 늘 때마다 확인하면 마지막 구간도 놓치지 않는다.
- 반복 후 `print(best_c, best_len)`.

(3) 스스로 다시 짤 때 생각 순서

- 상태 변수 4개 → 현재 글자·현재 길이, 최대 글자·최대 길이. 초기값은 첫 글자와 1.
- 갱신 시점 → 글자를 처리한 직후 매번(마지막 구간 누락 방지). 갱신 조건 → 동률 규칙에 맞춰 `>`.
- 검산 → `aabb`(동률은 앞 구간), `abc`(전부 길이 1이면 첫 글자), `z`(길이 1).
```
