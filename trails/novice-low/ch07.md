> 개요: 여러 개의 값을 하나의 이름으로 묶어 다루는 "1차원 배열(리스트)"을 배운다. 한 줄에 여러 값을 입력받아 리스트에 담고, 인덱스로 원하는 값을 꺼내며, 개수 세기·탐색·최댓값/최솟값 같은 기본 처리를 익힌다.

## L1. 한 줄에 여러 개 입력

**개념**

- 지금까지는 값을 하나씩 입력받았지만, 이제 한 줄에 공백으로 구분된 여러 값을 한꺼번에 받아 "리스트"에 담는다.

- 리스트(list)는 여러 값을 순서대로 묶어 하나의 이름으로 다루는 상자다. 예: `[10, 20, 30]`

- `input().split()`은 한 줄을 읽어 공백을 기준으로 잘라 여러 조각(문자열)의 리스트를 만든다.

- 조각들이 숫자라면 정수로 바꿔야 계산할 수 있다. `list(map(int, input().split()))`을 쓰면 각 조각을 한꺼번에 정수로 바꿔 리스트로 만든다.

- 리스트에 값이 몇 개 들어 있는지는 `len(리스트)`로 알 수 있다.

- 리스트를 그냥 `print(arr)`로 출력하면 대괄호가 함께 나온다(`[3, 5, 7]`). 대괄호 없이 원소만 공백으로 띄워 출력하려면 `print(*arr)`를 쓴다. 여기서 별표 `*`는 리스트의 원소를 하나하나 펼쳐 놓는 역할을 한다. `for v in arr: print(v, end=" ")` 처럼 하나씩 출력해도 된다.

```python
# "3 5 7" 을 입력하면
arr = list(map(int, input().split()))
print(arr)        # [3, 5, 7]
print(len(arr))   # 3
print(*arr)       # 3 5 7  (대괄호 없이 공백으로)
```

> 선행: `map(int, ...)`은 "여러 조각을 각각 int로 바꿔라"라는 뜻이고, 그 결과를 `list(...)`로 감싸 리스트로 완성한다고 이해하면 된다.

**그림으로 보기**

한 줄의 입력이 정수 리스트가 되기까지의 변환 단계다. 각 화살표가 함수 하나에 대응한다.

```text
   input()                 "3 5 7"        # 한 줄 통째로 , 문자열
      |
      |  .split()
      v
   ["3", "5", "7"]                        # 조각들 , 아직 문자열
      |
      |  map(int, ...)  +  list(...)
      v
   [3, 5, 7]                              # 계산 가능한 정수 리스트
      |
      +--  len(arr)    ->  3
      +--  print(arr)  ->  [3, 5, 7]
      +--  print(*arr) ->  3 5 7
```

**왜 이렇게 되는가**

- `.split()`이 만든 것은 **문자열** 조각이다. 문자열끼리 `+`를 하면 `"3" + "5"`가 `"35"`가 되어 버리므로, 계산하기 전에 반드시 정수로 바꿔야 한다.
- `map(int, ...)`는 "각 조각에 `int`를 적용하라"는 지시다. 그 결과를 `list(...)`로 감싸야 인덱스로 꺼내고 `len`으로 셀 수 있는 리스트가 된다.
- `print(arr)`와 `print(*arr)`가 다른 이유는 넘기는 값의 **개수**가 다르기 때문이다. 앞은 리스트 한 개를 넘기므로 파이썬이 리스트 모양 그대로(대괄호·쉼표 포함) 보여 준다. 뒤는 별표가 원소를 펼쳐 값 세 개를 넘기므로 `print`가 값 사이에 공백을 넣어 준다.
- 그래서 채점에서 대괄호가 나와 틀렸다면 별표를 빠뜨린 것이다.
- 값이 몇 개 들어올지 몰라도 상관없다. `.split()`이 조각 수만큼 리스트를 만들고 `len`이 그 개수를 알려 준다. 값이 하나뿐이어도 `[7]`이라는 리스트가 되어 `len`은 `1`이다.

**문제**

**1) 세 수 그대로 출력** · Easy

- **요구사항**: 한 줄에 공백으로 구분된 정수 3개를 입력받아, 리스트에 담은 뒤 그대로 다시 출력하는 프로그램을 작성한다.
- **입력**: 첫 줄에 정수 3개가 공백으로 구분되어 주어진다.
- **출력**: 입력받은 세 수를 공백으로 구분해 한 줄에 출력한다.
- **예제**: `10 20 30` → `10 20 30`   /   `-1 0 5` → `-1 0 5`
- **셀프체크**: 리스트를 그대로 출력하면 `[10, 20, 30]`처럼 대괄호가 나온다. 대괄호 없이 `10 20 30`으로 출력하려면 값들을 공백으로 이어 붙여야 한다.

```runner
@@SOLUTION
arr = list(map(int, input().split()))
print(*arr)
@@TESTS
--IN
10 20 30
--OUT
10 20 30
--IN
-1 0 5
--OUT
-1 0 5
@@EXPL
접근: 한 줄에 붙어 있는 값들을 리스트로 받아, 그대로 다시 공백으로 이어 출력하면 된다.

코드 진행

- `input()`으로 한 줄("10 20 30")을 통째로 읽는다.
- `.split()`이 공백을 기준으로 잘라 `["10", "20", "30"]`(문자열 조각)을 만든다.
- `map(int, ...)`가 각 조각을 정수로 바꾸고, `list(...)`로 감싸 `[10, 20, 30]` 리스트를 완성한다.
- `print(*arr)`의 별표 `*`는 리스트 원소를 하나하나 펼쳐 놓아, 대괄호 없이 공백으로 띄운 `10 20 30`을 출력한다.

재작성 사고 순서

- 먼저 "한 줄 → 리스트"로 받는 정해진 문장(`list(map(int, input().split()))`)을 떠올린다.
- 그다음 "대괄호 없이 공백 출력"은 `print(*arr)` 한 줄이면 된다는 걸 기억한다.
- 대괄호가 나온다면 `print(arr)`를 쓴 것이니 별표를 붙였는지 확인한다.
```

**2) 입력 개수 세기** · Easy

- **요구사항**: 한 줄에 공백으로 구분된 정수들이 주어진다(몇 개인지 미리 알 수 없다). 몇 개가 입력되었는지 세어 출력한다.
- **입력**: 첫 줄에 정수 여러 개가 공백으로 구분되어 주어진다.
- **출력**: 입력된 정수의 개수를 출력한다.
- **예제**: `4 8 15 16 23 42` → `6`   /   `7` → `1`
- **셀프체크**: 개수를 직접 세지 말고 `len`을 활용한다. 값이 하나만 들어와도 리스트로 만들어지므로 개수는 1이다.

```runner
@@SOLUTION
arr = list(map(int, input().split()))
print(len(arr))
@@TESTS
--IN
4 8 15 16 23 42
--OUT
6
--IN
7
--OUT
1
@@EXPL
접근: 몇 개가 들어올지 미리 모르지만, 리스트로 받아 두면 `len`이 개수를 대신 세어 준다.

코드 진행

- `list(map(int, input().split()))`로 한 줄의 값들을 정수 리스트로 만든다.
- `len(arr)`는 리스트에 담긴 원소의 개수를 돌려준다.
- 값이 6개면 `6`, 값이 1개("7")여도 리스트 `[7]`이 되어 `len`은 `1`이 된다.

재작성 사고 순서

- "개수를 센다"는 말이 나오면 반복해서 하나씩 세기보다 `len`을 먼저 떠올린다.
- 입력을 리스트로만 만들어 두면 나머지는 `print(len(...))` 한 줄이다.
- 값이 1개일 때도 리스트가 되므로 특별히 예외 처리를 하지 않아도 된다.
```

**3) 전부 더하기** · Medium

- **요구사항**: 한 줄에 공백으로 구분된 정수들을 입력받아, 모든 수의 합을 출력한다.
- **입력**: 첫 줄에 정수 여러 개가 공백으로 구분되어 주어진다.
- **출력**: 모든 수를 더한 값을 출력한다.
- **예제**: `1 2 3 4` → `10`   /   `-5 5 10` → `10`
- **셀프체크**: 합을 담을 변수를 0으로 시작해 리스트의 값을 하나씩 더한다. 음수가 섞여도 그대로 더하면 된다.

```runner
@@SOLUTION
arr = list(map(int, input().split()))
total = 0
for v in arr:
    total += v
print(total)
@@TESTS
--IN
1 2 3 4
--OUT
10
--IN
-5 5 10
--OUT
10
@@EXPL
접근: 합을 담을 그릇(변수)을 0으로 준비하고, 리스트를 돌며 값을 하나씩 그릇에 더한다.

코드 진행

- `list(map(int, input().split()))`로 정수 리스트를 만든다.
- `total = 0`으로 합을 0에서 시작한다(아직 아무것도 안 더한 상태).
- `for v in arr:`로 원소를 순서대로 꺼내 `total += v`로 누적한다.
- 반복이 끝나면 `total`에 전체 합이 남고, 그것을 출력한다.
- `-5 + 5 + 10`처럼 음수가 섞여도 `+=`가 그대로 처리해 `10`이 된다.

재작성 사고 순서

- "모두 더하기"는 누적 변수 패턴이다: 0으로 시작 → 반복하며 더하기 → 출력.
- 시작값을 0으로 두는 것이 핵심이다(1로 두면 답이 어긋난다).
- 반복 안에서 새 값을 더하고, 반복 밖에서 결과를 출력한다는 위치 구분을 챙긴다.
```

## L2. 인덱스 참조

**개념**

- 리스트의 각 값에는 순서 번호가 붙어 있는데, 이 번호를 인덱스(index)라 한다.

- 인덱스는 0부터 시작한다. `arr = [10, 20, 30]`이면 `arr[0]`은 10, `arr[1]`은 20, `arr[2]`는 30이다.

- 마지막 값의 인덱스는 `len(arr) - 1`이다. 위 예에서 마지막은 `arr[2]` (= `arr[len(arr)-1]`).

- 음수 인덱스도 쓸 수 있다. `arr[-1]`은 맨 뒤, `arr[-2]`는 뒤에서 두 번째다.

- 없는 인덱스를 참조하면 오류가 난다. 크기가 3인 리스트에서 `arr[3]`은 존재하지 않아 에러다.

- 인덱스로 값을 바꿀 수도 있다. `arr[1] = 99`는 두 번째 값을 99로 교체한다.

```python
arr = [10, 20, 30]
print(arr[0])    # 10
print(arr[-1])   # 30
arr[1] = 99
print(arr)       # [10, 99, 30]
```

**그림으로 보기**

리스트는 칸이 늘어선 상자다. 같은 칸을 가리키는 번호가 위아래로 두 벌 붙어 있다.

```text
   index  :     0      1      2      3
              ┌──────┬──────┬──────┬──────┐
   value  :   │  10  │  20  │  30  │  40  │
              └──────┴──────┴──────┴──────┘
   index  :    -4     -3     -2     -1

   len(arr) = 4
   arr[0] = 10 = arr[-4]          arr[3] = 40 = arr[-1]
   arr[4] -> IndexError           # 4 번 칸은 존재하지 않는다
```

**왜 이렇게 되는가**

- 칸이 `n`개일 때 번호를 0부터 붙이면 `0, 1, …, n-1`로 정확히 `n`개가 나온다. 그래서 마지막 칸은 `n - 1`, 곧 `len(arr) - 1`이다.
- 1부터 붙였다면 마지막이 `n`이 되어 보기에는 깔끔하지만, "앞에 몇 칸이 지나갔는가"를 세는 계산이 어긋난다. 0-기준에서는 `arr[i]` 앞에 정확히 `i`칸이 있다는 성질이 언제나 성립한다.
- 음수 인덱스는 "뒤에서부터"다. `arr[-k]`는 `arr[len(arr) - k]`와 같은 칸을 가리킨다. `-1`이 마지막인 이유도 `len - 1`이 마지막이기 때문이다.
- 사람이 "K번째"라고 말할 때는 1부터 세므로 인덱스는 `K - 1`이다. 이 1칸 차이가 배열 문제에서 가장 흔한 오차다. `arr[k]`라고 쓰면 한 칸씩 밀린 답이 나온다.
- 인덱스는 값을 꺼내는 것뿐 아니라 넣는 데도 쓴다. `arr[1] = 99`처럼 왼쪽에 쓰면 그 칸의 값이 교체된다. 두 칸을 맞바꿀 때 임시 변수가 필요한 이유가 여기 있다. 한쪽을 먼저 덮어쓰면 원래 값이 사라지기 때문이다.

**문제**

**1) 첫 값과 끝 값** · Easy

- **요구사항**: 한 줄에 공백으로 구분된 정수들을 입력받아, 첫 번째 값과 마지막 값을 한 줄에 공백으로 구분해 출력한다.
- **입력**: 첫 줄에 정수 여러 개가 공백으로 구분되어 주어진다(최소 1개).
- **출력**: 첫 번째 값과 마지막 값을 공백으로 구분해 출력한다.
- **예제**: `3 6 9 12` → `3 12`   /   `7` → `7 7`
- **셀프체크**: 마지막 값의 인덱스는 `len-1` 또는 `-1`. 값이 하나뿐이면 첫 값과 끝 값이 같은 값이다.

```runner
@@SOLUTION
arr = list(map(int, input().split()))
print(arr[0], arr[len(arr) - 1])
@@TESTS
--IN
3 6 9 12
--OUT
3 12
--IN
7
--OUT
7 7
@@EXPL
접근: 첫 값은 인덱스 0, 마지막 값은 인덱스 `len(arr) - 1`로 바로 꺼낸다.

코드 진행

- `list(map(int, input().split()))`로 정수 리스트를 만든다.
- `arr[0]`은 언제나 첫 번째 값이다.
- 마지막 값의 인덱스는 개수보다 1 작으므로 `arr[len(arr) - 1]`로 꺼낸다.
- `print(a, b)`는 두 값을 자동으로 공백 하나로 띄워 출력한다.
- 값이 1개면 `arr[0]`과 `arr[len(arr)-1]`이 같은 자리를 가리켜 `7 7`이 나온다.

재작성 사고 순서

- "첫 값과 끝 값"을 각각 어떤 인덱스로 부를지 먼저 정한다: 0과 `len-1`.
- 끝 값 인덱스를 `len(arr) - 1`로 쓰면 값이 몇 개든 자동으로 맞는다.
- `-1` 이라는 음수 인덱스로 마지막을 가리켜도 되지만, `len-1`로 익히면 다른 문제에도 넓게 쓸 수 있다.
```

**2) K번째 값 꺼내기** · Medium

- **요구사항**: 정수 여러 개와 위치 번호 K가 주어진다. 앞에서 K번째 값을 출력한다(1번째, 2번째 … 처럼 사람이 세는 방식).
- **입력**: 첫 줄에 정수 여러 개가 공백으로 구분되어 주어진다. 둘째 줄에 정수 K가 주어진다(1 이상, 개수 이하).
- **출력**: 앞에서 K번째 값을 출력한다.
- **예제**: `10 20 30 40`(줄1) `3`(줄2) → `30`   /   `5 8 13`(줄1) `1`(줄2) → `5`
- **셀프체크**: 사람이 세는 "K번째"는 인덱스로는 `K-1`이다. 이 1칸 차이를 놓치면 엉뚱한 값이 나온다.

```runner
@@SOLUTION
arr = list(map(int, input().split()))
k = int(input())
print(arr[k - 1])
@@TESTS
--IN
10 20 30 40
3
--OUT
30
--IN
5 8 13
1
--OUT
5
@@EXPL
접근: 사람이 세는 "K번째"와 컴퓨터의 인덱스는 1칸 차이가 난다. 인덱스는 0부터 시작하므로 K번째는 `arr[K-1]`이다.

코드 진행

- 첫 줄을 `list(map(int, input().split()))`로 정수 리스트로 만든다.
- 둘째 줄의 K는 값이 하나뿐이므로 `int(input())`로 받는다.
- K번째 값은 인덱스 `K-1`에 있으므로 `arr[k - 1]`로 꺼내 출력한다.
- 예: K가 3이면 `arr[2]`인 30, K가 1이면 `arr[0]`인 5.

재작성 사고 순서

- 먼저 입력이 두 줄임을 확인한다: 리스트 한 줄, K 한 줄.
- "1부터 세는 위치 → 인덱스"는 항상 1을 빼는 것으로 기억한다.
- `arr[k]`로 쓰면 한 칸씩 밀려 틀리므로 `k - 1`을 꼭 챙긴다.
```

**3) 양 끝 값 교환** · Medium

- **요구사항**: 정수 여러 개를 입력받아, 첫 값과 마지막 값의 자리를 서로 바꾼 뒤 전체를 공백으로 구분해 출력한다.
- **입력**: 첫 줄에 정수 여러 개(최소 2개)가 공백으로 구분되어 주어진다.

```runner
@@SOLUTION
arr = list(map(int, input().split()))
temp = arr[0]
arr[0] = arr[len(arr) - 1]
arr[len(arr) - 1] = temp
print(*arr)
@@TESTS
--IN
1 2 3 4 5
--OUT
5 2 3 4 1
--IN
8 9
--OUT
9 8
@@EXPL
접근: 두 자리 값을 맞바꾸려면, 한쪽 값을 임시 상자에 잠깐 넣어 두고 옮긴다.

코드 진행

- `list(map(int, input().split()))`로 정수 리스트를 만든다.
- `temp = arr[0]`으로 첫 값을 임시로 보관한다(안 하면 덮어써져 사라진다).
- `arr[0] = arr[len(arr) - 1]`로 첫 자리에 마지막 값을 넣는다.
- `arr[len(arr) - 1] = temp`로 마지막 자리에 보관해 둔 옛 첫 값을 넣는다.
- `print(*arr)`로 바뀐 리스트를 공백으로 출력한다.

- 두 값 교환은 "임시 변수에 대피 → 한쪽 덮기 → 대피본으로 반대쪽 채우기" 3단계다.
- 임시 변수 없이 `arr[0] = arr[-1]` 부터 하면 첫 값을 잃어버린다는 점을 기억한다.
- 값이 2개뿐이어도 인덱스 0과 `len-1`(=1)이 서로 다른 자리라 그대로 동작한다.
```

## L3. 배열 만들기

**개념**

- 처음부터 값이 정해진 리스트뿐 아니라, 계산으로 새 리스트를 "만들어" 채울 수도 있다.

- 빈 리스트는 `arr = []`로 시작한다. 여기에 `arr.append(값)`을 하면 맨 뒤에 값이 하나씩 추가된다.

- 정해진 개수만큼 채울 때는 반복문과 함께 쓴다. `for`로 돌면서 `append`하면 리스트가 점점 커진다.

- 같은 값으로 채운 리스트를 한 번에 만들 수도 있다. `[0] * 5`는 `[0, 0, 0, 0, 0]`이다.

```python
arr = []
for i in range(1, 4):
    arr.append(i * i)
print(arr)          # [1, 4, 9]

zeros = [0] * 5
print(zeros)        # [0, 0, 0, 0, 0]
```

**그림으로 보기**

`append`는 언제나 맨 뒤에 한 칸을 붙인다. 앞쪽 칸의 인덱스는 그대로 유지된다.

```text
   arr = []                  [ ]
   arr.append(1)             [ 1 ]
   arr.append(4)             [ 1 , 4 ]
   arr.append(9)             [ 1 , 4 , 9 ]
                               ^   ^   ^
                               0   1   2       # 인덱스는 그대로
```

**왜 이렇게 되는가**

- `[0] * n`은 정수 `0`을 `n`칸에 넣는다. 정수는 값 자체가 칸에 들어가므로 한 칸을 바꿔도 다른 칸은 영향을 받지 않는다. 그래서 카운트 배열을 만들 때 안전하다.
- 그런데 곱셈의 대상이 리스트가 되면 이야기가 달라진다. `*`는 **같은 것을 여러 번 가리키게** 할 뿐, 복제하지 않는다.

```text
   [0] * 3         ->   [ 0 , 0 , 0 ]       # 정수는 값이 각각 들어감

   row  = [0] * 3
   grid = [row] * 2
        grid[0] ──┐
                  ├──>  [ 0 , 0 , 0 ]       # 리스트는 한 개를 공유
        grid[1] ──┘
   grid[0][0] = 9    ->    grid[1][0] == 9  # 둘 다 바뀐다
```

- 그래서 표 모양(2차원)을 `[[0]*n]*m`으로 만들면 한 줄만 고쳐도 모든 줄이 같이 바뀐다. 2차원 배열은 뒤 챕터에서 본격적으로 다루지만, "리스트 곱셈은 복제가 아니다"라는 사실만은 지금 기억해 두면 된다.
- 안전한 방법은 반복문으로 매번 새 리스트를 만들어 `append`하는 것이다. 반복이 돌 때마다 `[0] * n`이 새로 실행되므로 서로 다른 리스트가 만들어진다.
- 같은 이유로, 리스트를 복사하려고 `b = a`라고 쓰면 복사가 아니라 **같은 리스트에 이름을 하나 더 붙인 것**이다. `b`를 고치면 `a`도 바뀐다.

**문제**

**1) 제곱 리스트 만들기** · Easy

- **요구사항**: 정수 N을 입력받아, 1부터 N까지 각 수의 제곱을 순서대로 담은 리스트를 만들어 공백으로 구분해 출력한다.
- **입력**: 첫 줄에 정수 N이 주어진다(1 이상).
- **출력**: 1², 2², …, N²을 공백으로 구분해 한 줄에 출력한다.
- **예제**: `4` → `1 4 9 16`   /   `1` → `1`
- **셀프체크**: 빈 리스트에서 시작해 `append`로 채운다. N이 1이면 값이 1개만 나와야 한다.

```runner
@@SOLUTION
n = int(input())
arr = []
for i in range(1, n + 1):
    arr.append(i * i)
print(*arr)
@@TESTS
--IN
4
--OUT
1 4 9 16
--IN
1
--OUT
1
@@EXPL
접근: 빈 리스트에서 시작해 1부터 N까지 각 수의 제곱을 차례로 뒤에 붙여 나간다.

코드 진행

- `n = int(input())`으로 개수 N을 받는다.
- `arr = []`로 아직 비어 있는 리스트를 준비한다.
- `for i in range(1, n + 1)`은 i가 1, 2, …, N을 차례로 돈다(끝값 N을 포함하려고 `n + 1`).
- 매 반복마다 `arr.append(i * i)`로 제곱값을 리스트 뒤에 추가한다.
- 반복이 끝나면 `print(*arr)`로 공백으로 띄워 출력한다.

재작성 사고 순서

- "1부터 N까지"를 반복하려면 `range(1, n + 1)`이 필요하다는 걸 먼저 떠올린다.
- 값을 하나씩 만들어 담을 때는 빈 리스트 + `append` 패턴을 쓴다.
- 제곱은 `i * i`(또는 `i ** 2`). N이 1이면 반복이 한 번 돌아 `1` 하나만 나온다.
```

**2) 입력값을 두 배로** · Medium

```runner
@@SOLUTION

@@TESTS

코드 진행

- `list(map(int, input().split()))`로 입력을 정수 리스트로 만든다.
- 결과를 담을 빈 리스트 `result = []`를 준비한다.
```

## L4. Count 배열

**개념**

- "각 값이 몇 번 나왔는지"를 세고 싶을 때, 값 자체를 인덱스로 삼는 세기용 리스트(카운트 배열)를 쓴다.

- 예를 들어 0~5 사이 숫자만 나온다면 크기 6인 리스트를 `[0]*6`으로 만들고, 값 v가 나올 때마다 `cnt[v] += 1`을 한다.

- 이렇게 하면 `cnt[3]`은 "3이 몇 번 나왔는가"를 뜻하게 된다.

- 카운트 배열의 크기는 "나올 수 있는 가장 큰 값 + 1" 이상이어야 그 값을 인덱스로 쓸 수 있다.

```python
data = [1, 3, 3, 5, 1, 3]
cnt = [0] * 6          # 인덱스 0~5 사용
for v in data:
    cnt[v] += 1
print(cnt)             # [0, 2, 0, 3, 0, 1]
print(cnt[3])          # 3  (3이 세 번)
```

**그림으로 보기**

값 자체를 인덱스로 삼는다. 값 `v`를 만나면 `cnt[v]` 칸을 1 늘린다.

```text
   data   :  1  3  3  5  1  3       # 값 v 마다 cnt[v] += 1

   index  :      0     1     2     3     4     5
              ┌─────┬─────┬─────┬─────┬─────┬─────┐
   cnt    :   │  0  │  2  │  0  │  3  │  0  │  1  │
              └─────┴─────┴─────┴─────┴─────┴─────┘

   cnt[1] = 2      cnt[3] = 3      cnt[5] = 1
   cnt[0] = cnt[2] = cnt[4] = 0    ( never appeared )
```

**손으로 따라가기**

`data = [1, 3, 3, 5, 1, 3]`, `cnt = [0] * 6`으로 시작한다.

| 단계 | v | 늘리는 칸 | 그 직후 cnt |
| --- | --- | --- | --- |
| 시작 | — | — | `[0, 0, 0, 0, 0, 0]` |
| 1 | 1 | `cnt[1]` | `[0, 1, 0, 0, 0, 0]` |
| 2 | 3 | `cnt[3]` | `[0, 1, 0, 1, 0, 0]` |
| 3 | 3 | `cnt[3]` | `[0, 1, 0, 2, 0, 0]` |
| 4 | 5 | `cnt[5]` | `[0, 1, 0, 2, 0, 1]` |
| 5 | 1 | `cnt[1]` | `[0, 2, 0, 2, 0, 1]` |
| 6 | 3 | `cnt[3]` | `[0, 2, 0, 3, 0, 1]` |

원소를 한 번씩만 보고도 모든 값의 등장 횟수를 동시에 얻었다.

**왜 이렇게 되는가**

- 값 `v`가 몇 번 나왔는지 알려면 보통 리스트 전체를 다시 훑어야 한다. 값을 인덱스로 쓰면 `cnt[v]`라는 **한 번의 접근**으로 끝난다. 이것이 카운트 배열의 이점이다.
- 대신 조건이 붙는다. 값이 인덱스가 되어야 하므로 값은 0 이상의 정수여야 하고, 배열 크기는 "나올 수 있는 최댓값 + 1" 이상이어야 한다. 최댓값이 100이면 인덱스 100을 써야 하므로 크기는 101이다.
- 한 번도 안 나온 값의 칸에는 `[0] * n`으로 만들 때 넣어 둔 0이 그대로 남는다. 그래서 "0번 등장"이 따로 처리하지 않아도 저절로 표현된다.
- 최다 등장 값을 찾을 때 인덱스 0부터 훑고 갱신 조건을 `>`(같으면 갱신 안 함)로 두면, 동점일 때 먼저 본 작은 숫자가 그대로 남는다. "동점이면 작은 값"이라는 조건이 부등호 하나로 지켜진다.
- 원소가 `m`개, 배열 크기가 `S`일 때 세는 데 `m`번, 결과를 훑는 데 `S`번이면 끝난다.

**문제**

**1) 숫자별 등장 횟수** · Medium

- **요구사항**: 0 이상 9 이하의 정수들이 한 줄에 공백으로 주어진다. 0부터 9까지 각 숫자가 몇 번 나왔는지 순서대로 출력한다.
- **입력**: 첫 줄에 0~9 사이 정수 여러 개가 공백으로 구분되어 주어진다.
- **출력**: 0이 나온 횟수부터 9가 나온 횟수까지, 총 10개의 수를 공백으로 구분해 한 줄에 출력한다.
- **예제**: `1 3 3 5 1` → `0 2 0 2 0 1 0 0 0 0`   /   `9 9 9` → `0 0 0 0 0 0 0 0 0 3`
- **셀프체크**: 크기 10인 카운트 배열을 0으로 초기화한다. 한 번도 안 나온 숫자의 자리는 0이 그대로 남아야 한다.

```runner
@@SOLUTION
arr = list(map(int, input().split()))
cnt = [0] * 10
for v in arr:
    cnt[v] += 1
print(*cnt)
@@TESTS
--IN
1 3 3 5 1
--OUT
0 2 0 2 0 1 0 0 0 0
--IN
9 9 9
--OUT
0 0 0 0 0 0 0 0 0 3
@@EXPL
접근: 값 자체를 인덱스로 삼는 "세기용 리스트"를 만들어, 값이 나올 때마다 그 자리를 1 늘린다.

코드 진행

- `list(map(int, input().split()))`로 정수 리스트를 만든다.
- `cnt = [0] * 10`으로 0부터 9까지 셀 자리 10칸을 모두 0으로 준비한다.
- `for v in arr:`로 값을 하나씩 꺼내 `cnt[v] += 1`로 그 값의 칸을 1 늘린다(예: v가 3이면 `cnt[3]`이 증가).
- 반복이 끝나면 `cnt`에는 각 숫자의 등장 횟수가 담긴다.
- `print(*cnt)`로 0의 횟수부터 9의 횟수까지 10개를 공백으로 출력한다. 안 나온 자리는 0 그대로다.

재작성 사고 순서

- "각 숫자가 몇 번?"이라는 질문은 카운트 배열 패턴이다: 0으로 채운 리스트 → 값 자리 +1.
- 셀 수 있는 최대 숫자가 9이므로 크기는 `9 + 1 = 10`이어야 한다.
- 값을 인덱스로 바로 쓰는 `cnt[v] += 1`이 핵심이다. 출력은 리스트 전체를 펼치면 된다.
```

**2) 가장 많이 나온 숫자** · Hard

- **요구사항**: 0 이상 9 이하의 정수들이 주어진다. 가장 많이 등장한 숫자를 출력한다. 최다 등장 숫자가 여럿이면 그중 가장 작은 숫자를 출력한다.
- **입력**: 첫 줄에 0~9 사이 정수 여러 개가 공백으로 구분되어 주어진다.
- **출력**: 가장 많이 나온 숫자를 출력한다.
- **예제**: `1 3 3 5 1 3` → `3`   /   `2 2 7 7 1` → `2`
- **셀프체크**: 카운트 배열을 만든 뒤 인덱스 0부터 훑어 최대 횟수를 찾는다. 0부터 순서대로 보면 "동점이면 작은 숫자"가 자연히 지켜진다.

```runner
@@SOLUTION
arr = list(map(int, input().split()))
cnt = [0] * 10
for v in arr:
    cnt[v] += 1
best = 0
for d in range(10):
    if cnt[d] > cnt[best]:
        best = d
print(best)
@@TESTS
--IN
1 3 3 5 1 3
--OUT
3
--IN
2 2 7 7 1
--OUT
2
@@EXPL
접근: 먼저 카운트 배열로 각 숫자의 횟수를 센 뒤, 0부터 훑으며 가장 큰 횟수를 가진 숫자를 고른다.

코드 진행

- `list(map(int, input().split()))`로 정수 리스트를 만든다.
- `cnt = [0] * 10`을 만들고 `cnt[v] += 1`로 0~9의 등장 횟수를 센다.
- `best = 0`으로 "지금까지 가장 많은 숫자"를 0번으로 가정한다.
- `for d in range(10)`으로 0부터 9까지 보며, `cnt[d] > cnt[best]`(더 많으면)일 때만 `best = d`로 갱신한다.
- 부등호가 "더 클 때"만 갱신이므로, 횟수가 같으면 먼저 본(더 작은) 숫자가 그대로 남는다. 그래서 동점이면 작은 숫자가 답이 된다.
- 마지막에 `best`를 출력한다.

재작성 사고 순서

- "가장 많이 나온 값"은 카운트 → 최대 찾기 두 단계로 나눈다.
- 최대 찾기는 후보 하나(`best`)를 두고 더 나은 것이 오면 갈아끼우는 패턴이다.
- 동점 시 작은 값을 원하면 인덱스를 0부터 훑고, 부등호를 `>`(같으면 갱신 안 함)로 두면 자연히 지켜진다.
```

**3) 중복 여부 판정** · Hard

- **요구사항**: 0 이상 100 이하의 정수들이 주어진다. 같은 수가 두 번 이상 나온 적이 있으면 `YES`, 모든 수가 서로 다르면 `NO`를 출력한다.
- **입력**: 첫 줄에 0~100 사이 정수 여러 개가 공백으로 구분되어 주어진다.
- **출력**: 중복이 있으면 `YES`, 없으면 `NO`를 출력한다.
- **예제**: `3 1 4 1 5` → `YES`   /   `3 1 4 5` → `NO`
- **셀프체크**: 값이 100까지 나올 수 있으니 카운트 배열 크기는 101이어야 한다. 세는 도중 어떤 값의 횟수가 2가 되는 순간 중복이다.

```runner
@@SOLUTION
arr = list(map(int, input().split()))
cnt = [0] * 101
dup = False
for v in arr:
    cnt[v] += 1
    if cnt[v] >= 2:
        dup = True
if dup:
    print("YES")
else:
    print("NO")
@@TESTS
--IN
3 1 4 1 5
--OUT
YES
--IN
3 1 4 5
--OUT
NO
@@EXPL
접근: 값이 나올 때마다 카운트 배열에서 세고, 어떤 값의 횟수가 2가 되는 순간 "중복 있음"으로 기록한다.

코드 진행

- `list(map(int, input().split()))`로 정수 리스트를 만든다.
- 값이 0~100까지 가능하므로 `cnt = [0] * 101`(크기 101)을 준비한다.
- `dup = False`로 "아직 중복 못 봄" 표시를 둔다.
- `for v in arr:` 안에서 `cnt[v] += 1`로 세고, 바로 `if cnt[v] >= 2:`로 확인해 2 이상이면 `dup = True`.
- 반복이 끝난 뒤 `dup`이 참이면 `YES`, 아니면 `NO`를 출력한다.

재작성 사고 순서

- "중복이 있나?"는 각 값의 횟수를 세다가 2가 되는지 보는 문제다.
- 카운트 배열 크기는 나올 수 있는 최댓값 + 1이어야 한다(100까지면 101).
- 참/거짓 깃발(`dup`) 변수를 두고, 한 번이라도 조건을 만족하면 True로 바꿔 끝에서 판정하는 패턴을 익힌다.
```

## L5. 탐색

**개념**

- 탐색은 리스트를 처음부터 하나씩 살펴보며 원하는 값을 찾는 것이다.

- 특정 값 x가 리스트에 있는지, 있다면 몇 번째(인덱스)에 있는지를 반복문으로 확인한다.

- 인덱스가 필요하면 `for i in range(len(arr))`로 돌며 `arr[i]`를 x와 비교한다. 처음 찾은 위치를 기억하고 멈추면 된다.

- 값을 못 찾는 경우도 반드시 생각한다. 끝까지 봐도 없으면 "없음"으로 처리한다.

- 조건에 맞는 값의 개수를 세는 것도 일종의 탐색이다(예: 짝수의 개수).

```python
arr = [10, 20, 30, 40]
x = 30
pos = -1                     # 못 찾았다는 표시로 -1 사용
for i in range(len(arr)):
    if arr[i] == x:
        pos = i
        break
print(pos)                   # 2
```

**그림으로 보기**

`break`가 있느냐 없느냐가 "처음"과 "마지막"을 가른다. `arr = [7, 3, 7, 1, 7]`, `x = 7`인 경우다.

```text
   arr :  7  3  7  1  7
   idx :  0  1  2  3  4
          ^     ^     ^        # x 와 같은 값이 있는 자리
          |           |
          |           +-- no break : pos is overwritten -> 4+1 = 5
          +-- with break : stops right here             -> 0+1 = 1
```

**손으로 따라가기**

`arr = [10, 20, 30, 20]`, `x = 20`으로 "처음 위치"를 찾는다.

| 단계 | i | arr[i] | `arr[i] == x` | pos | 다음 동작 |
| --- | --- | --- | --- | --- | --- |
| 시작 | — | — | — | -1 | 반복 시작 |
| 1 | 0 | 10 | 거짓 | -1 | 계속 |
| 2 | 1 | 20 | 참 | 2 | `break` |

답은 `2`. `break`를 빼면 인덱스 3에서 조건이 다시 참이 되어 `pos`가 `4`로 덮이고, 그것이 곧 "마지막 위치" 풀이가 된다.

**왜 이렇게 되는가**

- "못 찾음"을 `-1`로 표시하는 이유는 그 값이 **정답으로는 절대 나올 수 없기** 때문이다. 위치를 1부터 세면 답은 1 이상이므로 `-1`과 겹치지 않는다. 만약 `0`을 못 찾음 표시로 쓴다면, 위치를 0부터 세는 문제에서는 진짜 답과 구별되지 않는다.
- 값을 꺼내기만 하면 되는 순회는 `for v in arr`가 짧고 안전하다. 하지만 **위치가 필요하면** `for i in range(len(arr))`로 돌아야 한다. `arr[i]`로 값을, `i`로 위치를 동시에 쓸 수 있기 때문이다.
- 개수 세기는 `break` 없이 끝까지 돌아야 한다. 조건에 맞는 것을 하나 찾고 멈추면 나머지를 세지 못한다. "찾으면 멈춘다"와 "끝까지 센다"는 목적이 다르므로 `break`의 유무로 구분된다.
- 부등호도 문제 문장 그대로 옮긴다. "보다 크다(초과)"는 `>`, "이상"은 `>=`다. 기준값과 같은 값을 세느냐 마느냐가 여기서 갈린다.

**문제**

**1) 값의 위치 찾기** · Medium

- **요구사항**: 정수 여러 개와 찾을 값 x가 주어진다. x가 처음 나타나는 위치(1부터 세는 번째)를 출력하고, 없으면 `-1`을 출력한다.
- **입력**: 첫 줄에 정수 여러 개가 공백으로 구분되어 주어진다. 둘째 줄에 찾을 값 x가 주어진다.
- **출력**: x가 처음 나오는 위치(1번째부터). 없으면 `-1`.
- **예제**: `10 20 30 20`(줄1) `20`(줄2) → `2`   /   `1 2 3`(줄1) `9`(줄2) → `-1`
- **셀프체크**: 인덱스 i에서 찾으면 사람이 세는 위치는 `i+1`이다. 같은 값이 여러 번 있어도 "처음" 위치에서 멈춰야 한다.

```runner
@@SOLUTION
arr = list(map(int, input().split()))
x = int(input())
pos = -1
for i in range(len(arr)):
    if arr[i] == x:
        pos = i + 1
        break
print(pos)
@@TESTS
--IN
10 20 30 20
20
--OUT
2
--IN
1 2 3
9
--OUT
-1
@@EXPL
접근: 처음부터 인덱스 순서로 훑다가 x와 같은 값을 만나면 그 위치를 기록하고 곧바로 멈춘다.

코드 진행

- 첫 줄을 리스트로, 둘째 줄의 x를 `int(input())`으로 받는다.
- `pos = -1`로 "아직 못 찾음"을 표시한다(끝까지 없으면 이 값이 답).
- `for i in range(len(arr))`로 인덱스 0부터 순서대로 본다.
- `arr[i] == x`이면 사람이 세는 위치 `i + 1`을 `pos`에 넣고 `break`로 반복을 멈춘다(처음 위치만 필요하므로).
- 마지막에 `pos`를 출력한다.

재작성 사고 순서

- "처음 위치 찾기"는 못 찾음 표시(-1)로 시작 → 순서대로 비교 → 첫 일치에서 멈춤 순서다.
- 인덱스 i를 사람 위치로 바꿀 때 `+1`을 잊지 않는다.
- `break`가 있어야 같은 값이 뒤에 또 있어도 "처음" 위치를 지킨다.
```

**2) 조건에 맞는 개수 세기** · Medium

- **요구사항**: 정수 여러 개와 기준값 t가 주어진다. t보다 큰 값이 몇 개인지 세어 출력한다.
- **입력**: 첫 줄에 정수 여러 개가 공백으로 구분되어 주어진다. 둘째 줄에 기준값 t가 주어진다.
- **출력**: t보다 큰 값의 개수를 출력한다.
- **예제**: `5 10 15 20`(줄1) `10`(줄2) → `2`   /   `1 2 3`(줄1) `100`(줄2) → `0`
- **셀프체크**: t와 "같은" 값은 세지 않는다(초과만). 조건에 맞는 값이 하나도 없으면 0이 나와야 한다.

```runner
@@SOLUTION
arr = list(map(int, input().split()))
t = int(input())
count = 0
for v in arr:
    if v > t:
        count += 1
print(count)
@@TESTS
--IN
5 10 15 20
10
--OUT
2
--IN
1 2 3
100
--OUT
0
@@EXPL
접근: 리스트를 하나씩 보며 기준값 t보다 "큰" 값일 때만 세는 변수를 1 늘린다.

코드 진행

- 첫 줄을 정수 리스트로, 둘째 줄의 t를 `int(input())`으로 받는다.
- `count = 0`으로 세기 변수를 0에서 시작한다.
- `for v in arr:`로 값을 하나씩 꺼내 `if v > t:`(초과일 때만) `count += 1`.
- 조건은 `>`이므로 t와 같은 값은 세지 않는다(예: t가 10이면 15와 20만 세어 2).
- 하나도 맞지 않으면 `count`는 0 그대로다.

재작성 사고 순서

- "조건에 맞는 개수"는 0에서 시작하는 세기 변수 + 조건 만족 시 +1 패턴이다.
- "보다 크다(초과)"는 `>`, "이상"은 `>=`로 부등호를 정확히 고른다.
- 조건에 맞는 값이 없어도 시작값 0이 그대로 답이 되므로 예외 처리가 필요 없다.
```

**3) 특정 값이 마지막으로 나온 위치** · Hard

- **셀프체크**: 처음 만나면 멈추지 말고 끝까지 훑으며 찾을 때마다 위치를 갱신한다. 그래야 "마지막" 위치가 남는다.

```runner
코드 진행

- 첫 줄을 리스트로, 둘째 줄의 x를 `int(input())`으로 받는다.

- 반복이 끝나면 마지막에 만난 위치가 `pos`에 남고, 그것을 출력한다.
```

## L6. Min/Max

**개념**

- 리스트에서 가장 작은 값(최솟값)과 가장 큰 값(최댓값)을 찾는 기본 처리다.

- 직접 찾으려면 첫 값을 "현재 최댓값/최솟값"으로 두고, 나머지를 하나씩 비교하며 더 크면(또는 더 작으면) 갱신한다.

- 처음 기준을 아주 큰 수나 아주 작은 수로 잡는 대신 "리스트의 첫 값"으로 두면 안전하다.

- 파이썬은 `max(리스트)`, `min(리스트)` 함수로도 바로 구할 수 있다.

```python
arr = [4, 9, 2, 7]
mx = arr[0]
for v in arr:
    if v > mx:
        mx = v
print(mx)          # 9
print(min(arr))    # 2
```

**손으로 따라가기**

`arr = [4, 9, 2, 7]`에서 최댓값과 최솟값을 한 번의 순회로 함께 갱신한다.

| 단계 | v | `v > mx` | `v < mn` | mx | mn |
| --- | --- | --- | --- | --- | --- |
| 시작 | — | — | — | 4 | 4 |
| 1 | 4 | 거짓 | 거짓 | 4 | 4 |
| 2 | 9 | 참 → 갱신 | 거짓 | 9 | 4 |
| 3 | 2 | 거짓 | 참 → 갱신 | 9 | 2 |
| 4 | 7 | 거짓 | 거짓 | 9 | 2 |

최댓값 9, 최솟값 2. 차는 `9 - 2 = 7`이다.

**그림으로 보기**

시작 기준을 무엇으로 잡느냐가 정답을 가른다. 모두 음수인 리스트에서 확인해 보자.

```text
   arr = [-3, -8, -1]

   mx = 0        ->  no value is > 0   ->  mx stays 0     # 틀린 답
   mx = 999999   ->  no value is > it  ->  mx stays big   # 틀린 답
   mx = arr[0]   ->  -3  ...  -1       ->  mx = -1        # 맞는 답
```

**왜 이렇게 되는가**

- 시작 기준을 `arr[0]`으로 두는 이유는 그 값이 **실제로 리스트 안에 있는 값**이기 때문이다. 답이 리스트 밖의 값으로 새어 나갈 수 없다.
- 상수로 시작하면 그 상수보다 모든 값이 작거나 큰 경우에 답이 상수 그대로 남는다. 리스트에 없던 값이 답이 되어 버리는 것이다. 입력 범위를 안다면 상수도 쓸 수 있지만, `arr[0]`은 범위를 몰라도 언제나 안전하다.
- 갱신 조건을 `>`로 두면 같은 값이 와도 바꾸지 않으므로, 최댓값이 여러 번 나올 때 **처음** 위치가 살아남는다. `>=`로 바꾸면 마지막 위치가 남는다. L5의 `break` 유무와 같은 구조의 선택이다.
- 최댓값과 최솟값을 각각 따로 구하면 리스트를 두 바퀴 돌아야 하지만, 두 `if`를 한 반복 안에 넣으면 한 바퀴로 끝난다. 원소가 `n`개면 비교는 `2n`번이다.
- 값이 하나뿐이면 반복이 한 번 돌면서 자기 자신과 비교하므로 최댓값과 최솟값이 같아진다. 예외 처리를 따로 넣지 않아도 되는 이유다.

**문제**

**1) 최댓값과 최솟값** · Easy

- **요구사항**: 정수 여러 개를 입력받아, 최댓값과 최솟값을 한 줄에 공백으로 구분해 출력한다.
- **입력**: 첫 줄에 정수 여러 개(최소 1개)가 공백으로 구분되어 주어진다.
- **출력**: 최댓값과 최솟값을 공백으로 구분해 출력한다.
- **예제**: `4 9 2 7` → `9 2`   /   `-3 -8 -1` → `-1 -8`
- **셀프체크**: 값이 모두 음수여도 올바르게 나오는지 확인한다. 값이 1개면 최댓값과 최솟값이 같다.

```runner
@@SOLUTION
arr = list(map(int, input().split()))
mx = arr[0]
mn = arr[0]
for v in arr:
    if v > mx:
        mx = v
    if v < mn:
        mn = v
print(mx, mn)
@@TESTS
--IN
4 9 2 7
--OUT
9 2
--IN
-3 -8 -1
--OUT
-1 -8
@@EXPL
접근: 첫 값을 최댓값이자 최솟값의 시작 기준으로 두고, 나머지를 비교하며 더 크면 최댓값을, 더 작으면 최솟값을 갱신한다.

코드 진행

- `list(map(int, input().split()))`로 정수 리스트를 만든다.
- `mx = arr[0]`, `mn = arr[0]`으로 둘 다 첫 값으로 시작한다(실제 값 중 하나라 안전하다).
- `for v in arr:` 안에서 `if v > mx: mx = v`(더 크면 최댓값 갱신), `if v < mn: mn = v`(더 작으면 최솟값 갱신).
- 반복이 끝나면 `mx`에 최댓값, `mn`에 최솟값이 남는다.
- `print(mx, mn)`으로 공백을 두고 함께 출력한다. 값이 모두 음수여도 `-1 -8`처럼 올바르게 나온다.

재작성 사고 순서

- 최댓/최솟값 찾기는 "첫 값을 기준으로 잡고, 더 나은 값이 오면 갱신"하는 패턴이다.
- 시작 기준을 아주 큰/작은 상수 대신 `arr[0]`으로 두면 음수만 있어도 안전하다.
- 최댓값과 최솟값 갱신을 같은 반복 안에서 각각 `if`로 처리하면 한 번의 순회로 둘 다 구한다.
```

**2) 최댓값의 위치** · Medium

- **요구사항**: 정수 여러 개를 입력받아, 최댓값이 처음 나타나는 위치(1부터 세는 번째)를 출력한다.
- **입력**: 첫 줄에 정수 여러 개(최소 1개)가 공백으로 구분되어 주어진다.
- **출력**: 최댓값이 처음 나오는 위치(1번째부터)를 출력한다.
- **예제**: `3 8 5 8 1` → `2`   /   `10` → `1`
- **셀프체크**: 최댓값을 먼저 구한 뒤 그 값이 처음 나오는 위치를 찾는다. 최댓값이 여러 번 있어도 "처음" 위치여야 한다.

```runner
@@SOLUTION
arr = list(map(int, input().split()))
mx = arr[0]
for v in arr:
    if v > mx:
        mx = v
pos = 0
for i in range(len(arr)):
    if arr[i] == mx:
        pos = i + 1
        break
print(pos)
@@TESTS
--IN
3 8 5 8 1
--OUT
2
--IN
10
--OUT
1
@@EXPL
접근: 두 단계로 나눈다. 먼저 최댓값이 얼마인지 구하고, 그다음 그 값이 처음 나오는 위치를 찾는다.

코드 진행

- `list(map(int, input().split()))`로 정수 리스트를 만든다.
- `mx = arr[0]`으로 시작해 `if v > mx: mx = v`로 최댓값을 구한다.
- 위치 찾기: `for i in range(len(arr))`로 인덱스를 훑다가 `arr[i] == mx`이면 `pos = i + 1`을 넣고 `break`로 멈춘다(처음 위치만 필요).
- 예: `3 8 5 8 1`의 최댓값은 8, 처음 8은 인덱스 1이므로 위치 2.
- 값이 1개면 그 값이 최댓값이고 위치는 1이 된다.

재작성 사고 순서

- "최댓값의 위치"는 값 구하기 + 위치 찾기 두 단계로 쪼갠다.
- 위치 찾기는 처음 일치에서 `break`로 멈춰야 "처음" 위치가 된다.
- 인덱스 i를 사람 위치로 바꿀 때 `+1`을 잊지 않는다.
```

**3) 최댓값과 최솟값의 차** · Medium

- **요구사항**: 정수 여러 개를 입력받아, 최댓값에서 최솟값을 뺀 값을 출력한다.
- **입력**: 첫 줄에 정수 여러 개(최소 1개)가 공백으로 구분되어 주어진다.
- **출력**: (최댓값 − 최솟값)을 출력한다.
- **예제**: `4 9 2 7` → `7`   /   `5 5 5` → `0`
- **셀프체크**: 모든 값이 같으면 차가 0이다. 음수가 섞여도 (큰 값 − 작은 값)이라 결과는 0 이상이다.

```runner
@@SOLUTION
arr = list(map(int, input().split()))
mx = arr[0]
mn = arr[0]
for v in arr:
    if v > mx:
        mx = v
    if v < mn:
        mn = v
print(mx - mn)
@@TESTS
--IN
4 9 2 7
--OUT
7
--IN
5 5 5
--OUT
0
@@EXPL
접근: 최댓값과 최솟값을 각각 구한 뒤, 큰 값에서 작은 값을 빼면 된다.

코드 진행

- `list(map(int, input().split()))`로 정수 리스트를 만든다.
- `mx`, `mn`을 모두 `arr[0]`으로 시작한다.
- `for v in arr:` 안에서 `if v > mx: mx = v`로 최댓값을, `if v < mn: mn = v`로 최솟값을 갱신한다.
- 한 번의 순회로 두 값을 모두 구한 뒤 `print(mx - mn)`으로 차를 출력한다.
- `4 9 2 7`이면 최댓 9, 최솟 2라 `9 - 2 = 7`. 모든 값이 같으면(`5 5 5`) 최댓=최솟=5라 차가 0.

재작성 사고 순서

- "차"를 구하려면 최댓값과 최솟값이 먼저 필요하다는 걸 떠올린다.
- 둘 다 `arr[0]`을 기준으로 시작해 한 번의 반복 안에서 각각 갱신한다.
- 결과는 항상 큰 값에서 작은 값을 빼므로 0 이상이 된다(모두 같으면 0).
```
