## L16. 정리 — 개념 지도·체크리스트·자주 하는 실수

**개념**

- 이 레슨은 새 문제를 풀지 않는다. Ch9에서 배운 도구들이 어떤 뼈대 위에 놓여 있는지 한 장으로 정리하고, 바로 꺼내 쓸 템플릿과 자주 밟는 지뢰를 모아 둔다.

- 이 챕터를 관통하는 사실은 하나다. **파이썬 문자열은 불변이다.** 그래서 "고친다·지운다·민다"는 말은 전부 "원본을 보고 새 문자열을 만든다"로 바뀐다.

**개념 지도**

문자열 문제는 크게 네 갈래로 갈라졌다가, 결과를 만들어 낼 때 다시 "새 문자열 조립"으로 모인다.

```text
            string : a fixed row of letter boxes  (immutable)
                                  |
    +---------------+-------------+-------------+---------------+
    |               |                           |               |
 L1/L2 input     L4 scan                 L5/L8/L9 slice    L10-L13 convert
 s = input()     for c in s              s[a:b] , s[::-1]  ord <-> chr
 len(s)          for i in range(len(s))  delete , rotate   int <-> str
    |               |                           |               |
    +---------------+-------------+-------------+---------------+
                                  |
                L7 "edit" = build a NEW string, box by box
                   result = ""
                   for i in range(len(s)):
                       result = result + (new piece or s[i])
                                  |
                   L14 compare :  ==   <   >   (ascii order)
```

왼쪽 두 갈래는 **읽기**(세기·찾기·판별), 오른쪽 두 갈래는 **만들기**(자르기·붙이기·변환)다. 읽기만 하면 원본 하나로 끝나고, 만들기가 섞이면 결과를 담을 변수가 따로 필요하다.

번호 체계가 두 벌(글자 번호와 자르는 지점)이라는 점이 이 챕터에서 가장 자주 헷갈리는 곳이다.

```text
 s = "apple"
      ┌───┬───┬───┬───┬───┐
      │ a │ p │ p │ l │ e │
      └───┴───┴───┴───┴───┘
  +i    0   1   2   3   4      s[i]   : one letter
  -i   -5  -4  -3  -2  -1      s[-1]  : the last letter
 cut  0   1   2   3   4   5    s[a:b] : b is NOT included
 len(s) = 5  ->  index 0 .. 4 are valid , cut 0 .. 5 are valid
```

**뼈대 코드**

```python
# 1) 순회하며 세기 / 판별하기 (읽기 전용)
s = input()
cnt = 0
for c in s:                    # 자리 번호가 필요 없으면 이 형태
    if c == "a":               # ← 문제마다 바뀜 (세는 조건)
        cnt += 1
print(cnt)
```

```python
# 2) 인덱스로 순회하며 새 문자열 만들기 (수정·치환)
s = input()
result = ""                    # 빈 문자열에서 시작
for i in range(len(s)):        # 자리 번호가 조건에 들어가면 이 형태
    if i % 2 == 0:             # ← 문제마다 바뀜 (i == p / s[i] == a 등)
        result = result + "*"  # ← 문제마다 바뀜 (넣을 글자)
    else:
        result = result + s[i]
print(result)
```

```python
# 3) 위치 찾기 (첫 등장 / 마지막 등장)
s = input()
target = input()
pos = -1                       # 못 찾았을 때의 답
for i in range(len(s)):
    if s[i] == target:
        pos = i
        break                  # ← 마지막 등장을 원하면 이 줄만 지운다
print(pos)
```

```python
# 4) 슬라이싱으로 조립 (삭제 · 밀기)
s = input()
i = int(input())
n = len(s)
print(s[:i] + s[i+1:])         # i번째 글자 삭제
k = 2
k = k % n                      # 큰 k를 길이 안으로 줄인다
print(s[k:] + s[:k])           # 왼쪽 k칸 밀기
print(s[n-k:] + s[:n-k])       # 오른쪽 k칸 밀기
```

```python
# 5) 변환 (글자 <-> 코드, 글자 <-> 수)
s = input()
result = ""
for c in s:
    if "a" <= c <= "z":            # 구간 검사부터 (아닌 글자는 손대지 않는다)
        result = result + chr(ord(c) - 32)   # 소문자 → 대문자
    else:
        result = result + c
print(result)
print(len(str(12345)))             # 자릿수 = 문자열 길이
print(int("007") + 1)              # 앞의 0은 정수로 바꾸면 사라진다
```

**언제 무엇을 쓰나**

| 상황 | 고르는 것 | 이유 | 복잡도 |
| --- | --- | --- | --- |
| 글자 값만 필요 | `for c in s` | 자리 번호가 필요 없음 | O(n) |
| 자리 번호가 조건에 들어감 | `for i in range(len(s))` | `i == p`, `i % 2` 같은 조건 | O(n) |
| 있는지만 알면 됨 | `c in s` | 참/거짓 하나면 충분 | O(n) |
| 처음 등장 위치 | 순회 + `break` | 찾는 즉시 멈춰야 첫 위치 | O(n) |
| 마지막 등장 위치 | 순회 + 계속 갱신 | 끝까지 가야 마지막이 남음 | O(n) |
| 연속한 한 덩어리 | 슬라이싱 `s[a:b]` | 반복 없이 통째로 자름 | O(자른 길이) |
| 한 글자 삭제 | `s[:i] + s[i+1:]` | 좌우 조각을 다시 붙임 | O(n) |
| 특정 글자 전부 치환 | `s.replace(a, b)` | 순회를 직접 안 써도 됨 | O(n) |
| 자리마다 규칙이 다름 | 순회 + `result = result + ...` | `replace`로 표현 못 하는 규칙 | O(n²) |
| 문자열 회전 | `k % n` 후 슬라이싱 2조각 | 길이마다 제자리로 돌아옴 | O(n) |
| 글자 ↔ 코드 | `ord` / `chr` | 구간 안에서 번호가 이어짐 | O(1) |
| 수 ↔ 글자 | `int` / `str` | 계산은 수, 자르기·세기는 글자 | O(자릿수) |
| 두 문자열의 순서 | `<`, `>` (필요하면 `lower()` 후) | 앞 글자부터 코드 비교 | O(n) |

**✅ 마스터 체크리스트**

- [ ] 설명할 수 있다: `input()`이 언제나 문자열을 돌려준다는 것과, `int()`를 언제 씌우고 언제 씌우지 말아야 하는지.
- [ ] 설명할 수 있다: `len(s)`와 마지막 인덱스의 관계, 그리고 `s[len(s)]`가 오류인 이유.
- [ ] 설명할 수 있다: 양수 인덱스와 음수 인덱스가 같은 글자를 가리키는 대응 관계.
- [ ] 설명할 수 있다: `s[a:b]`가 `b`를 포함하지 않는 이유와, 그 덕에 길이가 `b - a`가 되는 것.
- [ ] 설명할 수 있다: `for c in s`와 `for i in range(len(s))` 중 무엇을 고를지 판단하는 기준.
- [ ] 설명할 수 있다: 문자열이 불변이라는 말의 뜻과, `s[0] = "x"`가 오류인 이유.
- [ ] 설명할 수 있다: `replace`나 `upper`가 원본을 바꾸지 않고 새 문자열을 돌려준다는 사실이 코드에 주는 영향.
- [ ] 설명할 수 있다: 첫 등장 찾기와 마지막 등장 찾기의 코드 차이가 `break` 한 줄인 이유.
- [ ] 설명할 수 있다: 문자열 밀기에서 `k % n`이 필요한 이유와, 빠뜨렸을 때 왜 원본이 그대로 나오는지.
- [ ] 설명할 수 있다: `ord`/`chr`로 대소문자를 바꿀 때 32를 더하고 빼는 근거.
- [ ] 설명할 수 있다: `"a" <= c <= "z"`가 소문자 판별이 되는 이유.
- [ ] 설명할 수 있다: 문자열 크기 비교가 사전 순이 되는 두 규칙(처음 다른 자리, 그리고 접두사일 때).
- [ ] 설명할 수 있다: `result = result + 조각`을 아주 긴 문자열에서 반복하면 왜 비용이 길이의 제곱에 가까워지는지.

**⚠️ 자주 하는 실수**

**(1) 문자열을 제자리에서 고치려 한다**

```python
# ❌ 틀린 코드
s = input()
s[0] = "h"        # TypeError : 문자열은 항목 대입을 지원하지 않는다
print(s)
```

왜: 문자열은 불변이라 특정 자리의 글자를 갈아 끼울 수 없다. 리스트에서 되던 `a[0] = x`가 문자열에서는 그대로 오류다.

```python
# ✅ 고친 코드
s = input()
result = ""
for i in range(len(s)):
    if i == 0:
        result = result + "h"
    else:
        result = result + s[i]
print(result)
```

**(2) 메서드의 결과를 받지 않고 버린다**

```python
# ❌ 틀린 코드
s = input()
s.upper()              # 결과를 아무 데도 담지 않았다
s.replace("a", "")     # 이 줄도 마찬가지
print(s)               # 원본이 그대로 출력된다
```

왜: `upper`·`lower`·`replace`는 원본을 바꾸는 것이 아니라 **새 문자열을 돌려주는** 도구다. 돌려준 값을 변수에 담거나 바로 출력해야 의미가 있다.

```python
# ✅ 고친 코드
s = input()
s = s.upper()                  # 다시 담거나
print(s.replace("a", ""))      # 반환값을 바로 쓴다
```

**(3) 마지막 인덱스를 `len(s)`로 착각한다**

```python
# ❌ 틀린 코드
s = input()
print(s[len(s)])       # IndexError : 유효한 인덱스는 0 .. len(s)-1
```

왜: 길이가 5면 상자는 5개지만 번호는 0부터 시작해 4에서 끝난다. 번호 개수와 마지막 번호가 1 차이 난다.

```python
# ✅ 고친 코드
s = input()
print(s[len(s) - 1])   # 또는 s[-1]
```

**(4) 슬라이싱의 끝이 포함된다고 생각한다**

```python
# ❌ 틀린 코드
s = "apple"
print(s[0:len(s) - 1])   # 전체를 얻으려 했지만 "appl" : 마지막 글자가 빠진다
print(s[1:3])            # 인덱스 1,2,3 을 기대했지만 "pp"
```

왜: `s[a:b]`는 `b` 바로 앞까지다. 그래서 전체는 `s[0:len(s)]`이고, 인덱스 1~3을 원하면 `b`를 하나 더 크게 잡아야 한다.

```python
# ✅ 고친 코드
s = "apple"
print(s[0:len(s)])       # "apple"  (그냥 s 와 같다)
print(s[1:4])            # "ppl"    (1, 2, 3)
```

**(5) 숫자 문자열을 변환하지 않고 더한다**

```python
# ❌ 틀린 코드
a = input()
b = input()
print(a + b)       # "12" 와 "3" 이면 "123" 이 나온다
```

왜: `+`의 뜻은 양쪽 자료형이 정한다. 문자열끼리면 이어붙이기, 정수끼리면 덧셈이다. 입력은 언제나 문자열이므로 계산하려면 먼저 `int()`로 바꿔야 한다.

```python
# ✅ 고친 코드
a = int(input())
b = int(input())
print(a + b)       # 15
```

**(6) 큰 `k`로 밀면서 `k % n`을 빠뜨린다**

```python
# ❌ 틀린 코드
s = input()          # 예: "abcde"
k = int(input())     # 예: 7
print(s[k:] + s[:k])   # s[7:] 는 오류가 아니라 "" → "abcde" 가 그대로 나온다
```

왜: 범위를 넘는 슬라이싱은 오류가 아니라 빈 문자열이다. 그래서 "밀지 않은 원본"이 조용히 출력되어, 틀린 줄도 모르고 넘어가기 쉽다.

```python
# ✅ 고친 코드
s = input()
k = int(input())
n = len(s)
k = k % n            # 한 바퀴(=n칸)는 제자리이므로 나머지만 남긴다
print(s[k:] + s[:k])
```

**(7) 대소문자 무시 비교에서 사본을 출력한다**

```python
# ❌ 틀린 코드
a = input()          # 예: "cat"
b = input()          # 예: "Car"
a = a.lower()
b = b.lower()        # 원본을 덮어써 버렸다
if a < b:
    print(a)
else:
    print(b)         # "car" 가 출력된다 (기대: "Car")
```

왜: 비교용으로 만든 소문자 사본을 원본 변수에 덮어쓰면, 출력할 원래 대소문자가 사라진다. 비교와 출력은 서로 다른 값을 쓴다.

```python
# ✅ 고친 코드
a = input()
b = input()
la = a.lower()       # 비교용 사본은 따로 둔다
lb = b.lower()
if la < lb:
    print(a)         # 출력은 언제나 원본
else:
    print(b)
```

**다음 챕터로**

- "원본을 두고 새 결과를 만든다"는 감각은 이후 배열 가공·정렬·집계에서 그대로 쓰인다.

- 한 글자씩 훑으며 세고 판별하는 순회 뼈대는 문자열 압축·암호·빈도 세기 같은 단골 유형의 공통 출발점이다.
