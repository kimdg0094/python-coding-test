## L7. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch02(입출력)의 핵심을 **반복 훈련**하고, 코딩테스트 단골 유형으로 **확장**하는 연습 세트다. 입력을 "어떤 모양으로 받아 어떤 자료형으로 바꿀지"를 매 문제마다 먼저 정하는 습관을 들인다.
- **반복 훈련 개념**: 아래 다섯 가지를 소재만 바꿔 여러 번 다시 쓴다.

- 정수·실수 한 개 — `n = int(input())`, `x = float(input())`. `input()` 은 항상 문자열을 주므로 계산 전에 반드시 바꾼다.
- 한 줄에 여러 값 — `a, b = input().split()` 으로 나눈 뒤 `a = int(a)`, `b = int(b)` 처럼 하나씩 바꾼다.
- 여러 줄 — `input()` 은 한 번에 한 줄만 읽으므로 줄 수만큼 부른다. 읽는 순서가 곧 변수 순서다.
- 문자열 — 변환 없이 `s = input()`. 첫 글자는 `s[0]`, 이어 붙이기는 `+`.
- 특정 구분자 — `a, b = input().split(':')` 처럼 괄호 안에 구분 문자를 준다. 구분 문자는 결과에서 사라진다.

- **코딩테스트 출제 맵**: 백준 「단계별로 풀어보기」의 '입출력과 사칙연산' 단계(A+B, 자릿수 계산, 시간 계산)와 '문자열' 단계의 앞부분, solved.ac CLASS 1의 입출력 문제가 이 챕터 수준이다. 조건문·반복문 없이 "읽고 → 바꾸고 → 계산하고 → 출력"만으로 푼다.
- **문제 구성표**:

|---|------|--------|-----------|------|
| 1 | 만 원 내고 거스름돈 | Easy | `int(input())`·뺄셈 순서 | 반복 훈련 |
| 2 | 정사각형 넓이 | Easy | `float(input())`·`.0` 출력 | 반복 훈련 |

| 4 | 성과 이름 순서 바꿔 출력 | Easy | 여러 줄 문자열 입력·쉼표 출력 | 반복 훈련 |

**문제**

**1) 만 원 내고 거스름돈** · Easy

- **요구사항**: 물건 값을 입력받아, 10000원을 냈을 때 받을 거스름돈을 출력한다.
- **입력**: 1 이상 10000 이하의 정수(물건 값) 하나가 한 줄에 주어진다.
- **출력**: `10000 - 물건값` 을 한 줄에 출력한다.
- **예제**: `3500` → `6500` / `10000` → `0`
- **셀프체크**: `int()` 로 바꾼 뒤 뺐는가? 빼는 순서가 "낸 돈 - 물건 값"인가? 물건 값이 딱 10000이면 `0` 이 나오는가?

```runner
@@SOLUTION
price = int(input())
print(10000 - price)
@@TESTS
--IN
3500
--OUT
6500
--IN
10000
--OUT
0
--IN
1
--OUT
9999
@@EXPL
(1) 접근·핵심 아이디어

- 거스름돈은 "낸 돈에서 물건 값을 뺀 값"이다. 낸 돈 10000은 고정이므로 입력은 물건 값 하나뿐이다.
- `input()` 이 주는 `"3500"` 은 글자라서 뺄셈을 할 수 없다. 먼저 `int` 로 바꿔야 한다.
- 뺄셈은 순서가 중요하다. `price - 10000` 으로 쓰면 부호가 반대가 된다.

(2) 코드 단계별

- `price = int(input())` — 한 줄을 읽어 정수로 바꿔 담는다.
- `print(10000 - price)` — 고정된 10000에서 물건 값을 뺀 결과를 출력한다. `3500` 이면 `6500`, `10000` 이면 `0`, `1` 이면 `9999`.

(3) 스스로 다시 짤 때 생각 순서

- "입력이 몇 개, 어떤 자료형?" → 정수 하나 → `int(input())`.
- "무엇에서 무엇을 빼지?" → 낸 돈에서 물건 값을. 고정값 10000은 코드에 직접 적는다.
- 경계값(물건 값 10000, 1)에서 결과가 `0`, `9999` 로 자연스러운지 확인한다.
```

**2) 정사각형 넓이** · Easy

- **요구사항**: 정사각형 한 변의 길이(실수)를 입력받아 넓이(한 변 × 한 변)를 출력한다.
- **입력**: 0보다 크고 100 이하인 실수 하나가 한 줄에 주어진다. 소수점이 없는 형태(예: `3`)로 들어올 수도 있다.
- **출력**: 넓이를 한 줄에 출력한다.
- **예제**: `2.5` → `6.25` / `3` → `9.0`
- **셀프체크**: `float()` 로 받았는가? 입력 `3` 의 결과가 `9` 가 아니라 `9.0` 으로 나오는 이유(실수끼리의 곱)를 설명할 수 있는가?

```runner
@@SOLUTION
side = float(input())
print(side * side)
@@TESTS
--IN
2.5
--OUT
6.25
--IN
3
--OUT
9.0
--IN
0.5
--OUT
0.25
@@EXPL
(1) 접근·핵심 아이디어

- 정사각형 넓이는 한 변을 두 번 곱한 값이다. 입력 하나를 실수로 받아 자기 자신과 곱한다.
- 소수점이 있을 수도, 없을 수도 있는 입력은 `float` 으로 받아야 안전하다. `int` 로 받으면 `2.5` 에서 오류가 난다.

(2) 코드 단계별

- `side = float(input())` — `"2.5"` 는 `2.5` 로, `"3"` 은 `3.0` 으로 바뀐다.
- `print(side * side)` — 실수끼리 곱하므로 결과도 실수다. `2.5 * 2.5 = 6.25`, `3.0 * 3.0 = 9.0`, `0.5 * 0.5 = 0.25`.

(3) 스스로 다시 짤 때 생각 순서

- "소수점이 올 수 있나?" → 그렇다 → `float(input())`.
- 넓이 공식을 그대로 옮긴다: `side * side`.
- 정수처럼 보이는 입력도 `9.0` 처럼 `.0` 이 붙어 나오는 것이 정상임을 미리 예상한다.
```

**3) 직사각형 넓이와 둘레** · Easy

- **요구사항**: 직사각형의 가로와 세로(정수)를 한 줄에 입력받아, 첫 줄에 넓이, 둘째 줄에 둘레를 출력한다. 둘레는 `2 × (가로 + 세로)` 다.
- **입력**: 1 이상 100 이하의 정수 두 개(가로, 세로)가 공백을 사이에 두고 한 줄에 주어진다.
- **출력**: 첫째 줄에 넓이, 둘째 줄에 둘레를 출력한다.
- **예제**: `3 4` → `12` / `14` (두 줄)
- **예제**: `5 5` → `25` / `20` (두 줄)
- **셀프체크**: `split()` 뒤 두 변수를 각각 `int` 로 바꿨는가? 둘레에서 `2 * (w + h)` 처럼 괄호를 썼는가(괄호가 없으면 `2 * w + h` 가 되어 틀린다)?

```runner
@@SOLUTION
w, h = input().split()
w = int(w)
h = int(h)
print(w * h)
print(2 * (w + h))
@@TESTS
--IN
3 4
--OUT
12
14
--IN
5 5
--OUT
25
20
--IN
1 1
--OUT
1
4
@@EXPL
(1) 접근·핵심 아이디어

- 한 줄에 두 값이 공백으로 들어오므로 `split()` 으로 나눠 두 변수에 받고, 각각 정수로 바꾼다.
- 넓이는 곱, 둘레는 "두 변의 합의 2배"다. 합을 먼저 계산해야 하므로 괄호로 묶는다.

(2) 코드 단계별

- `w, h = input().split()` — `"3 4"` 를 `"3"`, `"4"` 로 나눠 받는다. 아직 문자열이다.
- `w = int(w)`, `h = int(h)` — 계산 전에 정수로 바꾼다.
- `print(w * h)` — 넓이 `12`. `print(2 * (w + h))` — 괄호 안 `3 + 4 = 7` 을 먼저 구한 뒤 2배 → `14`.
- `1 1` 처럼 가장 작은 입력에서도 넓이 `1`, 둘레 `4` 가 정상적으로 나온다.

(3) 스스로 다시 짤 때 생각 순서

- "값이 몇 개, 한 줄인가?" → 두 개, 한 줄 → `split()` 으로 두 변수에.
- 두 변수 모두 `int` 로 바꾼다(하나만 바꾸면 곱할 때 오류).
- 둘레 공식을 옮길 때 덧셈이 곱셈보다 먼저 되도록 괄호를 넣는다.
```

**4) 성과 이름 순서 바꿔 출력** · Easy

- **요구사항**: 첫째 줄에 성, 둘째 줄에 이름이 주어진다. `이름 성` 순서로 공백 한 칸을 두고 한 줄에 출력한다.
- **입력**: 첫째 줄에 성(공백 없는 문자열), 둘째 줄에 이름(공백 없는 문자열)이 주어진다.
- **출력**: 이름, 성 순서로 공백 하나를 두고 한 줄에 출력한다.
- **예제**: `Kim`(줄1) `Minsu`(줄2) → `Minsu Kim` / `Lee`(줄1) `A`(줄2) → `A Lee`
- **셀프체크**: `input()` 을 두 번 불렀는가? 문자열이므로 `int` 로 감싸지 않았는가? 먼저 읽은 것이 성, 나중에 읽은 것이 이름인데 출력 순서를 뒤집었는가?

```runner
@@SOLUTION
last = input()
first = input()
print(first, last)
@@TESTS
--IN
Kim
Minsu
--OUT
Minsu Kim
--IN
Lee
A
--OUT
A Lee
--IN
Park
Jiwoo
--OUT
Jiwoo Park
@@EXPL
(1) 접근·핵심 아이디어

- 두 줄에 하나씩 들어오므로 `input()` 을 두 번 부른다. 첫 호출이 성, 두 번째 호출이 이름이다.
- 글자는 이미 문자열이므로 변환하지 않는다. `int` 로 감싸면 오류가 난다.
- 출력은 읽은 순서와 반대(이름 → 성)다. `print` 에 쉼표로 나열하면 사이에 공백 한 칸이 들어간다.

(2) 코드 단계별

- `last = input()` — 첫째 줄(성)을 문자열로 받는다.
- `first = input()` — 둘째 줄(이름)을 문자열로 받는다.
- `print(first, last)` — 이름을 앞에, 성을 뒤에 두고 쉼표로 이어 `Minsu Kim`. 한 글자짜리 이름 `A` 도 똑같이 동작한다.

(3) 스스로 다시 짤 때 생각 순서

- "줄이 두 개" → `input()` 두 번, 변수 이름은 뜻이 드러나게 `last`, `first`.
- "숫자로 쓸 일이 있나?" → 없다 → 변환하지 않는다.
- 출력 순서만 바꿔 쉼표로 나열한다. 직접 공백을 넣어 `+ ' ' +` 로 붙여도 되지만 쉼표가 더 간단하다.
```

**5) 두 단어 붙여 하나로** · Easy

- **요구사항**: 한 줄에 공백으로 구분된 두 단어를 입력받아, 두 단어를 빈틈없이 붙인 한 단어를 출력한다.
- **입력**: 공백 없는 두 단어가 공백 하나를 사이에 두고 한 줄에 주어진다.
- **출력**: 두 단어를 이어 붙인 문자열을 한 줄에 출력한다.
- **예제**: `sun flower` → `sunflower` / `note book` → `notebook`
- **셀프체크**: `split()` 으로 나눈 조각을 `int` 로 바꾸지 않았는가(글자다)? 쉼표(`print(a, b)`)가 아니라 `+` 로 붙였는가? 결과에 공백이 남아 있지 않은가?

```runner
@@SOLUTION
a, b = input().split()
print(a + b)
@@TESTS
--IN
sun flower
--OUT
sunflower
--IN
note book
--OUT
notebook
--IN
a b
--OUT
ab
@@EXPL
(1) 접근·핵심 아이디어

- `split()` 은 숫자만을 위한 것이 아니다. 공백으로 나뉜 글자 조각도 똑같이 나눠 준다. 나눈 조각은 문자열이므로 그대로 쓴다.
- "빈틈없이 붙이기"는 문자열 `+` 다. 쉼표로 나열하면 공백이 끼어들어 `sun flower` 가 되어 틀린다.

(2) 코드 단계별

- `a, b = input().split()` — `"sun flower"` 를 `"sun"`, `"flower"` 로 나눠 받는다.
- `print(a + b)` — 두 문자열을 이어 `sunflower`. 한 글자짜리 `a b` 도 `ab` 로 붙는다.

(3) 스스로 다시 짤 때 생각 순서

- "한 줄에 두 조각" → `split()` 으로 두 변수에.
- "숫자 계산이 필요한가?" → 아니다 → 변환 없이 문자열로 둔다.
- "띄울까 붙일까?" → 붙인다 → `+`. 띄우려면 쉼표였다(Ch01 L3).
```

**6) 두 자리 수 뒤집기** · Medium

- **요구사항**: 두 자리 정수를 입력받아 십의 자리와 일의 자리를 서로 바꾼 수를 출력한다. 예를 들어 `72` 는 `27` 이 된다. 일의 자리가 `0` 인 `40` 은 뒤집으면 `04` 이므로 앞의 0이 사라진 `4` 를 출력한다.
- **입력**: 10 이상 99 이하의 정수 하나가 한 줄에 주어진다.
- **출력**: 자릿수를 뒤집은 정수를 한 줄에 출력한다.
- **예제**: `72` → `27` / `40` → `4`
- **셀프체크**: 십의 자리는 `n // 10`, 일의 자리는 `n % 10` 이다. 뒤집은 수는 `(일의 자리) × 10 + (십의 자리)` 로 다시 조립한다. 글자를 뒤집는 것이 아니라 숫자를 계산으로 만들기 때문에 `40` 이 `04` 가 아니라 `4` 가 되는가?

```runner
@@SOLUTION
n = int(input())
tens = n // 10
ones = n % 10
print(ones * 10 + tens)
@@TESTS
--IN
72
--OUT
27
--IN
40
--OUT
4
--IN
99
--OUT
99
--IN
10
--OUT
1
@@EXPL
(1) 접근·핵심 아이디어

- 두 자리 수를 "십의 자리"와 "일의 자리"로 분리한 뒤, 역할을 바꿔 다시 조립한다. 분리는 `//`(몫)와 `%`(나머지), 조립은 `× 10 + `다.
- 글자를 뒤집는 것이 아니라 숫자를 계산으로 만들기 때문에, 일의 자리가 0이면 뒤집은 수의 십의 자리가 0이 되어 자연스럽게 사라진다(`0 * 10 + 4 = 4`).

(2) 코드 단계별

- `n = int(input())` — 정수로 읽는다.
- `tens = n // 10` — `72 // 10 = 7`(십의 자리). `ones = n % 10` — `72 % 10 = 2`(일의 자리).
- `print(ones * 10 + tens)` — `2 * 10 + 7 = 27`. `40` 은 `0 * 10 + 4 = 4`, `99` 는 `9 * 10 + 9 = 99`, `10` 은 `0 * 10 + 1 = 1`.

(3) 스스로 다시 짤 때 생각 순서

- "자릿수를 다루는 문제" → `// 10` 과 `% 10` 부터 떠올린다.
- 분리한 두 값을 변수에 담아 두면 조립식이 읽기 쉽다.
- 경계값 `10`, `40`(일의 자리 0)과 `99`(두 자리 같음)를 손으로 검산한다.
```

**7) 시각을 분으로** · Medium

- **요구사항**: `시:분` 형태의 시각을 입력받아 자정(0:00)부터 몇 분이 지났는지 출력한다.

- **예제**: `2:30` → `150` / `0:0` → `0`
- **셀프체크**: `split(':')` 으로 나눴는가? 두 조각을 모두 `int` 로 바꿨는가? 시에 60을 곱한 뒤 분을 더했는가(반대로 하면 틀린다)?

```runner
@@SOLUTION
h, m = input().split(':')

m = int(m)
print(h * 60 + m)
@@TESTS
--IN
2:30
--OUT
150
--IN
0:0
--OUT
0
--IN
23:59
--OUT
1439
@@EXPL
(1) 접근·핵심 아이디어

- 시각을 분으로 바꾸려면 "1시간 = 60분"이므로 시에 60을 곱하고 분을 더한다.
- 입력이 공백이 아니라 `:` 로 나뉘어 있으므로 `split(':')` 을 쓴다. 나눈 조각은 문자열이라 계산 전에 `int` 로 바꾼다.

(2) 코드 단계별

- `h, m = input().split(':')` — `"2:30"` 을 `"2"`, `"30"` 으로 나눈다. 콜론은 결과에서 사라진다.
- `h = int(h)`, `m = int(m)` — 정수로 바꾼다.
- `print(h * 60 + m)` — `2 * 60 + 30 = 150`. `0:0` 은 `0`, 하루의 마지막 `23:59` 는 `23 * 60 + 59 = 1439`.

(3) 스스로 다시 짤 때 생각 순서

- "구분 문자가 무엇?" → `:` → `split(':')`.
- 조각 두 개를 두 변수에 받고 둘 다 `int`.
- 단위 변환 공식(시 × 60 + 분)을 그대로 옮긴다. 곱셈이 덧셈보다 먼저 계산되므로 괄호는 필요 없다.
```

**8) 체중 변화량 한 자리로** · Medium

- **요구사항**: 지난달 몸무게와 이번 달 몸무게(실수)를 두 줄로 입력받아, "이번 달 - 지난달"을 소수점 아래 첫째 자리까지 출력한다. 줄었으면 음수가 나온다.

```runner
@@SOLUTION
before = float(input())

@@TESTS

--OUT
0.5
--IN

- 실수끼리 빼면 컴퓨터의 저장 방식 때문에 `0.5000000000000071` 처럼 아주 작은 오차가 생긴다. Ch01에서 배운 `.1f` 로 소수점 아래 첫째 자리까지만 보여 주면 깔끔해진다.

(2) 코드 단계별

- `before = float(input())` — 첫째 줄(지난달). `after = float(input())` — 둘째 줄(이번 달).

(3) 스스로 다시 짤 때 생각 순서

- "줄이 두 개, 실수" → `float(input())` 두 번.
```

**9) 이름 이니셜 만들기** · Medium

- **요구사항**: 한 줄에 공백으로 구분된 이름과 성을 입력받아, 각각의 첫 글자 뒤에 마침표를 붙인 이니셜을 출력한다. 예를 들어 `Minsu Kim` 은 `M.K.` 이다.
- **입력**: 공백 없는 두 단어(이름, 성)가 공백 하나를 사이에 두고 한 줄에 주어진다. 각 단어는 최소 한 글자다.
- **출력**: `이름첫글자.성첫글자.` 형태의 문자열을 한 줄에 출력한다.
- **예제**: `Minsu Kim` → `M.K.` / `ann lee` → `a.l.`
- **셀프체크**: 첫 글자는 `[0]` 으로 꺼낸다(1이 아니다). 마침표 `'.'` 도 문자열로 취급해 `+` 로 이었는가? 대소문자는 입력 그대로인가? 한 글자짜리 단어에서도 되는가?

```runner
@@SOLUTION
first, last = input().split()
print(first[0] + '.' + last[0] + '.')
@@TESTS
--IN
Minsu Kim
--OUT
M.K.
--IN
ann lee
--OUT
a.l.
--IN
X Y
--OUT
X.Y.
@@EXPL
(1) 접근·핵심 아이디어

- 한 줄의 두 단어를 `split()` 으로 나누고, 각 단어의 첫 글자를 `[0]` 으로 꺼낸다.
- 꺼낸 글자와 마침표 문자열 `'.'` 을 `+` 로 순서대로 이어 붙이면 이니셜이 된다. 마침표도 글자이므로 따옴표로 감싼다.

(2) 코드 단계별

- `first, last = input().split()` — `"Minsu Kim"` 을 `"Minsu"`, `"Kim"` 으로 나눠 받는다. 문자열이므로 변환하지 않는다.
- `first[0]` 은 `'M'`, `last[0]` 은 `'K'`.
- `print(first[0] + '.' + last[0] + '.')` — `'M' + '.' + 'K' + '.'` 을 이어 `M.K.`. 소문자 `ann lee` 는 그대로 `a.l.`, 한 글자 `X Y` 도 `X.Y.`.

(3) 스스로 다시 짤 때 생각 순서

- "두 단어 한 줄" → `split()` 으로 두 변수.
- "각 단어의 첫 글자" → `[0]`. 인덱스는 0부터 시작한다.
- 출력 모양을 조각으로 나눠 본다: 글자, 마침표, 글자, 마침표 → 네 조각을 `+` 로 잇는다.
```

**10) 주문서 한 줄 처리** · Hard

- **요구사항**: 첫째 줄에 `상품명,수량,단가` 가 쉼표로 구분되어 주어지고, 둘째 줄에 할인율(실수)이 주어진다. 첫 줄에는 `상품명 금액`(금액 = 수량 × 단가, 정수)을 공백으로 띄워 출력하고, 둘째 줄에는 할인을 적용한 금액(금액 × (1 - 할인율))을 소수점 아래 첫째 자리까지 출력한다.
- **입력**: 첫째 줄은 `Pen,3,500` 처럼 상품명(공백 없는 문자열), 수량(정수), 단가(정수)가 쉼표로 구분된다. 쉼표 앞뒤에 공백은 없다. 둘째 줄은 0.0 이상 0.9 이하의 실수 할인율이며 `0` 처럼 소수점 없이 올 수도 있다.
- **출력**: 첫째 줄에 `상품명 금액`, 둘째 줄에 할인 후 금액을 소수점 아래 첫째 자리까지 출력한다.
- **예제**: `Pen,3,500`(줄1) `0.1`(줄2) → `Pen 1500` / `1350.0` (두 줄)
- **예제**: `Milk,2,2500`(줄1) `0`(줄2) → `Milk 5000` / `5000.0` (두 줄)
- **셀프체크**: 세 조각 중 상품명은 문자열로 두고 수량·단가만 `int` 로 바꿨는가(상품명을 `int` 로 바꾸면 오류)? 둘째 줄은 `float` 으로 받았는가? `1 - rate` 를 괄호로 묶어 먼저 계산했는가? 할인율 `0` 일 때 둘째 줄이 `5000` 이 아니라 `5000.0` 인가?

```runner
@@SOLUTION
item, qty, price = input().split(',')
qty = int(qty)
price = int(price)
rate = float(input())
amount = qty * price
pay = amount * (1 - rate)
print(item, amount)
print(f'{pay:.1f}')
@@TESTS
--IN
Pen,3,500
0.1
--OUT
Pen 1500
1350.0
--IN
Milk,2,2500
0
--OUT
Milk 5000
5000.0
--IN
Bag,1,30000
0.5
--OUT
Bag 30000
15000.0
@@EXPL
(1) 접근·핵심 아이디어

- 한 줄 안에 문자열과 숫자가 섞여 있다. `split(',')` 으로 세 조각을 나눈 뒤, "숫자로 쓸 조각만" `int` 로 바꾼다. 상품명은 글자이므로 그대로 둔다.
- 할인율은 둘째 줄에 따로 오므로 `input()` 을 한 번 더 부르고, 소수가 있으니 `float` 으로 받는다.
- 할인 후 금액은 "금액 × (1 - 할인율)"이다. `1 - rate` 를 먼저 계산해야 하므로 괄호가 필요하다. 실수를 곱했으니 결과는 실수이고, `.1f` 로 모양을 고정한다.

(2) 코드 단계별

- `item, qty, price = input().split(',')` — `"Pen,3,500"` 을 `"Pen"`, `"3"`, `"500"` 으로 나눈다.
- `qty = int(qty)`, `price = int(price)` — 숫자 조각 둘만 정수로. `item` 은 문자열 그대로.
- `rate = float(input())` — 둘째 줄 할인율. `"0"` 도 `0.0` 으로 잘 받는다.
- `amount = qty * price` → `1500`(정수). `pay = amount * (1 - rate)` → `1500 * 0.9 = 1350.0`(실수).
- `print(item, amount)` → `Pen 1500`. `print(f'{pay:.1f}')` → `1350.0`. 할인율 `0` 이면 `5000.0`, `0.5` 면 `15000.0`.

(3) 스스로 다시 짤 때 생각 순서

- 입력 모양을 먼저 그린다: 줄1은 쉼표 구분 세 조각(글자·수·수), 줄2는 실수 하나.
- 조각마다 "글자인가 숫자인가?" 를 정해 숫자만 변환한다.
- 계산은 금액 → 할인 후 금액 순서로 변수에 담고, 정수 줄과 실수 줄의 출력 모양을 각각 확인한다.
```
