## L13. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch4(조건문)의 핵심을 **반복 훈련**하고, 코딩테스트 단골 유형으로 **확장**하는 연습 세트다. 새 문법은 없다. 지금까지 배운 `if / elif / else`, 삼항 연산자, `and / or`, 중첩 조건문만으로 14문제를 푼다.

- **반복 훈련 개념**
- `if / else` 두 갈래: 조건이 참이면 위, 아니면 아래 — `if m >= p:` … `else:` …
- 삼항 연산자: 값 하나를 한 줄로 고르기 — `print("ride" if h >= 140 else "wait")`
- `elif` 사슬: 구간을 **한쪽 방향으로** 차례로 걸러 각 줄은 경계 하나만 신경 쓰기 — `if t >= 28: … elif t >= 20: … elif t >= 10: … else: …`
- `and / or` 혼합: "그리고"는 `and`, "또는"은 `or`, 섞이면 **괄호**로 묶기 — `(y % 4 == 0 and y % 100 != 0) or y % 400 == 0`
- 중첩 조건문: 먼저 큰 갈래를 나누고 그 안에서 다시 세분 — `if avg >= 70:` 안에 `if inc <= 3:` …

- **코딩테스트 출제 맵**: 이 챕터의 유형은 백준 「단계별로 풀어보기」의 '조건문' 단계(윤년·알람 시계·사분면·시험 성적 류)와 solved.ac CLASS 1(세 수 비교·날짜 계산 류)에 그대로 등장한다. 이 레슨의 유형 확장 문제는 그 대표 유형을 소재와 수치를 새로 만들어 재구성한 것이다.

**문제**

**1) 거스름돈 계산** · Easy

- **요구사항**: 물건 가격과 손님이 낸 돈을 입력받는다. 낸 돈이 가격 이상이면 거스름돈(낸 돈 − 가격)을 출력하고, 낸 돈이 부족하면 `short` 를 출력하라.
- **입력**: 한 줄에 정수 두 개 `p m` (가격 `p`, 낸 돈 `m`, 공백으로 구분, 0 ≤ p, m ≤ 100000)
- **출력**: 거스름돈(정수) 또는 `short` 한 줄
- **예제**: `3500 5000` → `1500` · `4000 4000` → `0` · `5000 3000` → `short`
- **셀프체크**: 딱 맞게 냈을 때(`4000 4000`)는 부족이 아니라 거스름돈 `0` 이다. 조건에 `>` 가 아니라 `>=` 를 썼는가? 출력이 숫자일 때는 따옴표 없이, 문자열일 때만 따옴표를 쓴다.

```runner
@@SOLUTION
p, m = input().split()
p = int(p)
m = int(m)
if m >= p:
    print(m - p)
else:
    print("short")
@@TESTS
--IN
3500 5000
--OUT
1500
--IN
4000 4000
--OUT
0
--IN
5000 3000
--OUT
short
@@EXPL
(1) 접근·핵심 아이디어

- "낼 수 있다 / 없다" 두 갈래뿐이므로 `if / else` 하나로 끝난다. 갈래를 가르는 기준은 "낸 돈이 가격 이상인가"다.
- 함정은 경계값이다. 낸 돈과 가격이 같으면 부족한 게 아니라 거스름돈이 0원인 정상 상황이므로, 조건은 `m >= p` 여야 한다.

(2) 코드 단계별

- 한 줄에 두 수가 오므로 `input().split()` 으로 나눈 뒤 각각 `int()` 로 정수로 바꾼다.
- `if m >= p:` 가 참이면 `print(m - p)` 로 거스름돈을 계산해 숫자로 출력한다.
- 거짓이면 `else:` 에서 `print("short")` 로 문자열을 출력한다. 숫자와 문자열의 따옴표 유무가 다르다는 점에 주의한다.

(3) 스스로 다시 짤 때 생각 순서

- 결과가 두 종류(숫자 / 문자열)임을 확인하고 `if / else` 로 정한다.
- "같을 때"를 어느 쪽에 넣을지 먼저 결정한다 → 거스름돈 0 쪽이므로 `>=`.
- `4000 4000` 을 넣어 `0` 이 나오는지 검산하면 부등호 실수를 바로 잡을 수 있다.
```

**2) 놀이기구 탑승 안내** · Easy

- **요구사항**: 놀이기구의 키 제한은 140cm 이상이다. 키를 입력받아 탈 수 있으면 `ride`, 아니면 `wait` 를 출력하라. 반드시 삼항 연산자를 사용한다.
- **입력**: 정수 `h` 한 개 (키, cm 단위, 50 ≤ h ≤ 250)
- **출력**: `ride` 또는 `wait` 한 줄
- **예제**: `152` → `ride` · `139` → `wait` · `140` → `ride`
- **셀프체크**: 삼항 연산자는 `참일_때 if 조건 else 거짓일_때` 순서다. 조건을 가운데 쓰는 것을 잊지 않았는가? 경계 140은 "이상"이므로 탈 수 있다(`>=`).

```runner
@@SOLUTION
h = int(input())
print("ride" if h >= 140 else "wait")
@@TESTS
--IN
152
--OUT
ride
--IN
139
--OUT
wait
--IN
140
--OUT
ride
@@EXPL
(1) 접근·핵심 아이디어

- 결과가 두 문자열 중 하나이므로 삼항 연산자로 값을 골라 바로 `print` 에 넣을 수 있다. `if / else` 네 줄이 한 줄로 줄어든다.
- "140 이상"이라는 말은 경계 140을 포함한다. 그래서 조건은 `h > 140` 이 아니라 `h >= 140` 이다.

(2) 코드 단계별

- `h = int(input())` 로 키를 정수로 읽는다.
- `"ride" if h >= 140 else "wait"` — 조건이 참이면 왼쪽 값 `"ride"`, 거짓이면 오른쪽 값 `"wait"` 가 선택된다.
- 이 표현식 전체가 값 하나가 되므로 그대로 `print(...)` 안에 넣는다.

(3) 스스로 다시 짤 때 생각 순서

- "결과가 값 두 개 중 하나"이면 삼항 연산자를 떠올린다.
- 조건을 먼저 정한다(`h >= 140`). 그다음 참일 때 값을 `if` 왼쪽에, 거짓일 때 값을 `else` 오른쪽에 둔다.
- 경계 140과 바로 아래 139를 넣어 결과가 갈리는지 확인한다.
```

**3) 두 수의 차이** · Easy

- **요구사항**: 정수 두 개를 입력받아 큰 수에서 작은 수를 뺀 값(두 수의 차이, 항상 0 이상)을 출력하라. 삼항 연산자를 사용한다.
- **입력**: 한 줄에 정수 두 개 `a b` (공백 구분, −1000 ≤ a, b ≤ 1000)
- **출력**: 두 수의 차이(0 이상의 정수) 한 줄
- **예제**: `3 10` → `7` · `10 3` → `7` · `-4 -9` → `5` · `6 6` → `0`
- **셀프체크**: 어느 쪽이 큰지에 따라 빼는 순서가 바뀐다. 음수끼리(`-4 -9`)도 큰 수(−4)에서 작은 수(−9)를 빼야 `5` 가 나온다. 같은 수면 0이다.

```runner
@@SOLUTION
a, b = input().split()
a = int(a)
b = int(b)
print(a - b if a >= b else b - a)
@@TESTS
--IN
3 10
--OUT
7
--IN
10 3
--OUT
7
--IN
-4 -9
--OUT
5
--IN
6 6
--OUT
0
@@EXPL
(1) 접근·핵심 아이디어

- "큰 수 − 작은 수"는 어느 쪽이 큰지에 따라 계산식이 두 가지다. `a` 가 크거나 같으면 `a - b`, 아니면 `b - a`. 값 두 개 중 하나를 고르는 상황이므로 삼항 연산자가 딱 맞는다.
- 두 수가 같을 때는 어느 식을 써도 0이므로 `>=` 와 `>` 둘 다 정답이 되지만, 같은 경우까지 명시적으로 왼쪽 식에 포함시키는 `>=` 가 읽기에 안전하다.

(2) 코드 단계별

- `input().split()` 으로 두 조각을 나누고 각각 `int()` 로 정수로 바꾼다. 음수 문자열 `"-4"` 도 `int` 가 정상적으로 변환한다.
- `a - b if a >= b else b - a` — `a >= b` 가 참이면 `a - b`, 거짓이면 `b - a` 가 값으로 선택된다.
- 그 값을 바로 `print` 한다. 결과는 항상 0 이상이다.

(3) 스스로 다시 짤 때 생각 순서

- "빼는 순서가 조건에 따라 달라진다"를 인식하고, 두 식을 먼저 써 둔다.
- 조건(`a >= b`)을 가운데 두고 양옆에 두 식을 배치한다.
- 음수 예제 `-4 -9` 로 검산한다. −4가 더 크므로 `-4 - (-9) = 5` 가 맞는지 손으로 확인한다.
```

**4) 기온별 옷차림 안내** · Easy

- **요구사항**: 기온을 입력받아 옷차림을 안내한다. 28도 이상이면 `hot`, 20도 이상 28도 미만이면 `warm`, 10도 이상 20도 미만이면 `cool`, 10도 미만이면 `cold` 를 출력하라.
- **입력**: 정수 `t` 한 개 (기온, −30 ≤ t ≤ 45)
- **출력**: `hot`, `warm`, `cool`, `cold` 중 한 줄
- **예제**: `31` → `hot` · `20` → `warm` · `10` → `cool` · `-5` → `cold`
- **셀프체크**: 높은 기온부터 `>=` 로 검사하면 각 줄에 하한만 쓰면 된다. 경계값 28·20·10이 각각 위쪽 구간에 속하는지 확인. 낮은 기온부터 `>=` 로 쓰면 모든 값이 첫 조건에 걸려 오답이 난다.

```runner
@@SOLUTION
t = int(input())
if t >= 28:
    print("hot")
elif t >= 20:
    print("warm")
elif t >= 10:
    print("cool")
else:
    print("cold")
@@TESTS
--IN
31
--OUT
hot
--IN
20
--OUT
warm
--IN
10
--OUT
cool
--IN
-5
--OUT
cold
@@EXPL
(1) 접근·핵심 아이디어

- 구간이 넷이므로 `if / elif / elif / else` 사슬로 나눈다. 핵심은 **높은 기온부터** 검사하는 것이다. 그러면 앞 조건에서 걸러진 값은 자동으로 제외되어 각 줄에 하한 조건 하나만 쓰면 된다.
- 예를 들어 두 번째 줄 `elif t >= 20:` 에 도달한 값은 이미 `t >= 28` 이 거짓이었으므로 자연히 20 이상 28 미만이다. "28 미만"을 따로 쓸 필요가 없다.

(2) 코드 단계별

- `t = int(input())` 로 기온을 읽는다. 음수 기온도 정수로 잘 읽힌다.
- `if t >= 28:` → `hot`. 여기서 참이면 나머지 줄은 검사조차 하지 않는다.
- `elif t >= 20:` → `warm`, `elif t >= 10:` → `cool`. 각각 위 조건이 거짓이었던 값만 도달한다.
- 셋 다 거짓이면(10 미만) `else:` 에서 `cold`.

(3) 스스로 다시 짤 때 생각 순서

- 구간의 경계(28, 20, 10)를 큰 순서로 나열한다.
- 위에서부터 `t >= 경계` 를 `if / elif` 로 잇고, 마지막 남은 구간은 `else` 로 처리한다.
- 경계값 세 개(28, 20, 10)를 하나씩 넣어 각각 위쪽 구간(`hot`, `warm`, `cool`)에 들어가는지 검산한다. 순서를 거꾸로(10부터) 쓰면 31도도 `cool` 이 되어 버리는 점이 함정이다.
```

**5) 우산과 외투** · Easy

- **요구사항**: 비 예보(1이면 비, 0이면 맑음)와 추위 예보(1이면 추움, 0이면 안 추움)를 입력받는다. 비가 오면 `umbrella`, 추우면 `coat` 를 각각 한 줄씩 출력하라. 둘 다 해당하면 두 줄(우산 먼저), 둘 다 아니면 아무것도 출력하지 않는다.
- **입력**: 한 줄에 정수 두 개 `rain cold` (각각 0 또는 1)
- **출력**: 해당하는 준비물을 각각 한 줄씩 (없으면 출력 없음)
- **예제**: `1 1` → `umbrella` / `coat` (두 줄) · `0 1` → `coat` · `0 0` → (출력 없음) · `1 0` → `umbrella`
- **셀프체크**: 두 판단은 서로 독립이다. `elif` 로 이으면 `1 1` 에서 `coat` 가 빠진다. 반드시 별개의 `if` 두 개를 쓰고, 순서는 우산 → 외투.

```runner
@@SOLUTION
rain, cold = input().split()
rain = int(rain)
cold = int(cold)
if rain == 1:
    print("umbrella")
if cold == 1:
    print("coat")
@@TESTS
--IN
1 1
--OUT
umbrella
coat
--IN
0 1
--OUT
coat
--IN
0 0
--OUT
--IN
1 0
--OUT
umbrella
@@EXPL
(1) 접근·핵심 아이디어

- "비가 오는가"와 "추운가"는 동시에 참일 수 있고, 각각 따로 판단해야 한다. 이런 상황은 `if / elif` 가 아니라 **독립된 `if` 두 개**다. `elif` 는 위 조건이 참이면 아래를 건너뛰기 때문에 `1 1` 에서 외투가 사라진다.
- 둘 다 0이면 두 `if` 가 모두 거짓이라 아무것도 출력되지 않는다. 이것이 정상 동작이며 `else` 를 붙일 필요가 없다.

(2) 코드 단계별

- 두 값을 `split()` 으로 나눠 각각 `int()` 로 바꾼다.
- 첫 번째 `if rain == 1:` 이 참이면 `umbrella` 를 출력한다.
- 두 번째 `if cold == 1:` 은 첫 번째 결과와 상관없이 **다시** 검사되어 참이면 `coat` 를 출력한다.
- 출력 순서는 코드의 순서(우산 → 외투)를 그대로 따른다.

(3) 스스로 다시 짤 때 생각 순서

- "두 조건이 동시에 참일 수 있는가?"를 먼저 묻는다 → 그렇다면 `elif` 금지, 독립 `if`.
- 요구된 출력 순서대로 `if` 를 배치한다.
- `1 1` 로 두 줄이 모두 나오는지, `0 0` 으로 아무것도 안 나오는지 두 극단을 검산한다.
```

**6) 운전면허 필기·실기** · Easy

- **요구사항**: 운전면허 필기 점수와 실기 점수를 입력받아, 두 과목 **모두** 60점 이상이면 `pass`, 하나라도 60점 미만이면 `fail` 을 출력하라.
- **입력**: 한 줄에 정수 두 개 `written practical` (각각 0 이상 100 이하)
- **출력**: `pass` 또는 `fail` 한 줄
- **예제**: `70 65` → `pass` · `60 60` → `pass` · `90 59` → `fail` · `59 100` → `fail`

**10) 세 수의 중간값** · Medium

- **요구사항**: 서로 다른 정수 세 개를 입력받아, 크기 순으로 나열했을 때 가운데에 오는 수(두 번째로 큰 수)를 출력하라.

if (a > b and a < c) or (a < b and a > c):

@@TESTS

--IN

--IN
-1 -8 -3

- 세 수를 `split()` 으로 나눠 각각 정수로 바꾼다.

(3) 스스로 다시 짤 때 생각 순서

- `a` 가 답인 경우, `b` 가 답인 경우, `c` 가 답인 경우(예: `3 9 5`)를 하나씩 넣어 세 갈래가 모두 실행되는지 검산한다.

**12) 삼각형 각도 판별** · Medium

- **요구사항**: 삼각형의 세 각을 입력받는다. 세 각의 합이 180이 아니면 `error` 를 출력한다. 합이 180이면, 세 각이 모두 60이면 `equilateral`, 두 각만 같으면 `isosceles`, 세 각이 모두 다르면 `scalene` 을 출력하라.
- **입력**: 한 줄에 정수 세 개 `a b c` (각각 1 이상 178 이하)
- **출력**: `error`, `equilateral`, `isosceles`, `scalene` 중 한 줄
- **예제**: `60 60 60` → `equilateral` · `50 50 80` → `isosceles` · `30 60 90` → `scalene` · `60 70 60` → `error`
- **셀프체크**: 합 검사를 **맨 먼저** 해야 한다. `60 70 60` 은 두 각이 같지만 합이 190이라 `error` 다. 정삼각형 검사(`and` 셋)를 이등변 검사(`or` 셋)보다 위에 둬야 한다. 순서를 바꾸면 정삼각형도 이등변으로 잡힌다.

```runner
@@SOLUTION
a, b, c = input().split()
a = int(a)
b = int(b)
c = int(c)
if a + b + c != 180:
    print("error")
elif a == 60 and b == 60 and c == 60:
    print("equilateral")
elif a == b or b == c or a == c:
    print("isosceles")
else:
    print("scalene")
@@TESTS
--IN
60 60 60
--OUT
equilateral
--IN
50 50 80
--OUT
isosceles
--IN
30 60 90
--OUT
scalene
--IN
60 70 60
--OUT
error
@@EXPL
(1) 접근·핵심 아이디어

- 판단 순서가 결과를 좌우한다. 먼저 "삼각형이 맞는가(합 180)"를 걸러야 하고, 그다음 좁은 조건(정삼각형: 세 각 모두 60)부터 넓은 조건(이등변: 두 각만 같음) 순서로 검사한다.
- 정삼각형은 세 각이 **모두** 60이므로 `and`, 이등변은 어느 두 각이든 **하나라도** 같으면 되므로 `or` 다. 정삼각형은 이등변 조건도 만족하므로 반드시 정삼각형을 위에 둔다.

(2) 코드 단계별

- 세 수를 `split()` 으로 나눠 정수로 바꾼다.
- `if a + b + c != 180:` → `error`. 이 줄이 맨 위에 있어야 `60 70 60` 같은 입력이 이등변으로 새지 않는다.
- `elif a == 60 and b == 60 and c == 60:` → `equilateral`.
- `elif a == b or b == c or a == c:` → `isosceles`. 세 쌍(a·b, b·c, a·c)을 모두 비교해야 한다.
- 남은 경우는 세 각이 모두 다르므로 `else:` → `scalene`.

(3) 스스로 다시 짤 때 생각 순서

- "조건이 겹치는가"를 먼저 본다 → 정삼각형 ⊂ 이등변이므로 좁은 쪽을 위에.
- 무효 입력(`error`)을 맨 앞에서 걸러 나머지 갈래가 유효한 삼각형만 다루게 한다.
- `60 70 60` (같은 각이 있지만 합이 틀림)과 `60 60 60` (이등변 조건도 참이지만 정삼각형이어야 함)으로 순서가 맞는지 검산한다.
```

**13) 장학금 심사** · Hard

- **요구사항**: 평균 점수 `avg`, 봉사 시간 `vol`, 소득 분위 `inc`(1~10, 숫자가 작을수록 저소득)를 입력받아 장학금 종류를 출력한다. 평균이 70 미만이면 무조건 `none`. 평균이 70 이상이면 소득 분위가 3 이하일 때 `full`, 그렇지 않으면 평균이 90 이상이거나 봉사 시간이 30 이상일 때 `half`, 둘 다 아니면 `none`.
- **입력**: 한 줄에 정수 세 개 `avg vol inc` (0 ≤ avg ≤ 100, 0 ≤ vol ≤ 200, 1 ≤ inc ≤ 10)
- **출력**: `full`, `half`, `none` 중 한 줄
- **예제**: `75 10 2` → `full` · `92 0 6` → `half` · `80 10 8` → `none` · `69 50 1` → `none`
- **셀프체크**: 바깥 조건(평균 70 이상)을 통과한 사람만 안쪽 심사를 받는다. `69 50 1` 은 소득 분위도 낮고 봉사도 많지만 평균이 미달이라 `none` 이다. 안쪽 `half` 조건은 "이거나"이므로 `or`. 경계 70, 90, 30, 3을 각각 검산.

```runner
@@SOLUTION
avg, vol, inc = input().split()
avg = int(avg)
vol = int(vol)
inc = int(inc)
if avg >= 70:
    if inc <= 3:
        print("full")
    elif avg >= 90 or vol >= 30:
        print("half")
    else:
        print("none")
else:
    print("none")
@@TESTS
--IN
75 10 2
--OUT
full
--IN
92 0 6
--OUT
half
--IN
80 10 8
--OUT
none
--IN
69 50 1
--OUT
none
@@EXPL
(1) 접근·핵심 아이디어

- 규칙이 "먼저 평균으로 자격을 거르고, 자격자 안에서 다시 등급을 나눈다"는 2단계 구조다. 이런 단계형 판단은 바깥 `if` 안에 `if / elif / else` 를 넣는 중첩 조건문이 가장 읽기 쉽다.
- 안쪽 등급은 좁은 조건(`full`: 소득 분위 3 이하)을 먼저, 그다음 `half` 조건을 검사한다. `half` 조건은 "평균 90 이상 **이거나** 봉사 30 이상"이므로 `or` 로 잇는다.
- 함정은 바깥 조건이다. 안쪽 조건을 아무리 잘 만족해도 평균이 70 미만이면 안쪽에 들어가지도 못한다(`69 50 1`).

(2) 코드 단계별

- 세 수를 `split()` 으로 나눠 각각 정수로 바꾼다.
- 바깥 `if avg >= 70:` 으로 자격을 가른다. 거짓이면 바깥 `else:` 에서 바로 `none`.
- 자격자 안에서 `if inc <= 3:` → `full`. 이 조건이 참이면 아래 `half` 는 검사하지 않는다.
- `elif avg >= 90 or vol >= 30:` → `half`. 둘 중 하나만 만족해도 된다.
- 둘 다 아니면 안쪽 `else:` 에서 `none`. 안쪽 블록은 바깥보다 한 단계 더 들여쓴다.

(3) 스스로 다시 짤 때 생각 순서

- 규칙을 "자격 조건 → 등급 조건" 두 층으로 나눠 적는다.
- 바깥 `if / else` 로 자격을 가르고, 자격 통과 블록 안에 등급 `if / elif / else` 를 한 단계 들여 넣는다.
- 안쪽 조건의 "이거나"를 `or` 로 옮기고, `92 0 6` (평균만으로 half), `80 10 8` (둘 다 미달 → none), `69 50 1` (바깥 탈락)으로 각 경로를 검산한다.
```

**14) 다음 날 날짜** · Hard

- **요구사항**: 월 `m` 과 일 `d` 를 입력받아 그 다음 날의 월과 일을 출력하라. 윤년은 고려하지 않는다(2월은 28일까지). 1·3·5·7·8·10·12월은 31일, 4·6·9·11월은 30일까지 있다. 12월 31일의 다음 날은 1월 1일이다.
- **입력**: 한 줄에 정수 두 개 `m d` (1 ≤ m ≤ 12, 1 ≤ d ≤ 그 달의 마지막 날)
- **출력**: 다음 날의 `월 일` 을 공백으로 구분해 한 줄에 출력
- **예제**: `3 15` → `3 16` · `4 30` → `5 1` · `2 28` → `3 1` · `12 31` → `1 1`
- **셀프체크**: 먼저 "이번 달의 마지막 날"을 월에 따라 정하고(2월 → 28, 30일 달은 `or` 로 묶기, 나머지 → 31), 그다음 `d` 가 마지막 날보다 작으면 일만 +1, 마지막 날이면 다음 달 1일로 넘긴다. 12월만 예외로 1월 1일(중첩). `4 30` 이 `4 31` 이 되지 않는지 검산.

```runner
@@SOLUTION
m, d = input().split()
m = int(m)
d = int(d)
if m == 2:
    last = 28
elif m == 4 or m == 6 or m == 9 or m == 11:
    last = 30
else:
    last = 31
if d < last:
    print(m, d + 1)
else:
    if m == 12:
        print(1, 1)
    else:
        print(m + 1, 1)
@@TESTS
--IN
3 15
--OUT
3 16
--IN
4 30
--OUT
5 1
--IN
2 28
--OUT
3 1
--IN
12 31
--OUT
1 1
@@EXPL
(1) 접근·핵심 아이디어

- 문제를 두 단계로 쪼갠다. (a) 이번 달은 며칠까지 있는가 → 변수 `last` 에 담는다. (b) 오늘이 마지막 날인가 → 아니면 일만 1 늘리고, 맞으면 다음 달 1일로 넘긴다.
- (a)에서 30일까지인 달은 4, 6, 9, 11월 네 개라 "이거나"가 반복되므로 `or` 로 묶는다. 2월은 따로, 나머지는 모두 31일이라 `else` 로 처리하면 조건이 짧아진다.
- (b)에서 달을 넘길 때 12월만 예외(다음 해 1월)라 중첩 `if / else` 가 필요하다.

(2) 코드 단계별

- 두 수를 `split()` 으로 나눠 정수 `m`, `d` 로 만든다.
- `if m == 2:` → `last = 28`. `elif m == 4 or m == 6 or m == 9 or m == 11:` → `last = 30`. `else:` → `last = 31`. 각 비교에 `m ==` 를 빠짐없이 붙인다.
- `if d < last:` 이면 같은 달이므로 `print(m, d + 1)`.
- 아니면(마지막 날) 안쪽에서 `if m == 12:` → `print(1, 1)`, `else:` → `print(m + 1, 1)`.

(3) 스스로 다시 짤 때 생각 순서

- "마지막 날을 먼저 구한다"는 중간 변수를 두는 발상이 핵심이다. 조건을 한 번에 다 쓰려 하지 말고 `last` 로 나눠 생각한다.
- 마지막 날 판정은 `d < last` 와 그 반대로 두 갈래, 그 안에서 12월 예외를 중첩으로 처리한다.
- 네 가지 경계를 검산한다: 평범한 날(`3 15`), 30일 달의 끝(`4 30`), 2월 끝(`2 28`), 연말(`12 31`). `or` 목록에서 달 하나를 빠뜨리면 `4 30` 이 `4 31` 로 나오는 것이 이 문제의 함정이다.
```
