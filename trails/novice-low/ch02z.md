## L8. 정리 — 개념 지도·체크리스트·자주 하는 실수

**개념**

Ch02는 문법이 많은 챕터가 아니다. 도구는 `input()`, `split()`, `int()`, `float()` 네 개뿐이다. 어려운 것은 **"이 문제의 입력이 어떤 모양인가"를 읽고 그 모양에 맞는 조합을 고르는 일**이다. 그 판단을 지도와 표로 굳혀 둔다.

**개념 지도**

입력을 다루는 과정은 언제나 같은 네 칸을 지난다. 어느 칸까지가 아직 "글자"인지가 핵심이다.

```text
  read a line   ->   cut it   ->   convert   ->   compute & print

  ┌───────────┐    ┌───────────┐   ┌────────────┐   ┌──────────┐
  │ input()   │ -> │ split()   │ ->│ int()      │ ->│ + - * // │
  │ one line  │    │ pieces    │   │ float()    │   │ print()  │
  │ (string)  │    │ (strings) │   │ or keep    │   │          │
  └───────────┘    └───────────┘   └────────────┘   └──────────┘
     L1 L4 L5         L3 L6           L1 L2 L5          L1..L6
                                  # everything left
                                  # of here is TEXT
```

문제를 읽고 가장 먼저 정할 것은 "값이 몇 개이고 어디에 놓여 있는가"다. 네 가지 모양뿐이다.

```text
  input shape                  what to write
  --------------------------   ----------------------------------
  one value, one line          n = int(input())
      12                       x = float(input())
                               s = input()

  several values, one line     a, b = input().split()
      3 5                      a = int(a)
                               b = int(b)

  several values, separator    y, m, d = input().split('-')
      2026-07-01               y = int(y) ...

  several values, many lines   a = int(input())
      4                        b = int(input())
      9
```

값을 받은 다음에는 "이 값으로 계산할 것인가, 그냥 보여 주거나 자를 것인가"만 결정하면 된다.

```text
                value arrives as a STRING
                          │
          ┌───────────────┴───────────────┐
     compute with it?                just show / cut it?
          │                               │
     int() or float()                keep the string
          │                               │
   int   : digits and sign         s[0]  ,  s + '!'  ,  split()
   float : digits, sign and '.'
```

**뼈대 코드**

입력 모양을 확인했으면 아래 다섯 개 중 하나를 골라 이름과 개수만 바꾼다.

```python
# 1) 값 하나를 한 줄로 받기
n = int(input())               # ← 실수면 float(input()), 글자면 input()
print(n + 1)                   # ← 문제마다 바뀜
```

```python
# 2) 한 줄에 공백으로 붙어 온 여러 값 받기
a, b = input().split()         # ← 값 개수만큼 변수 이름을 늘린다
a = int(a)
b = int(b)
print(a + b)                   # ← 문제마다 바뀜
```

```python
# 3) 정해진 문자로 구분된 값 받기
y, m, d = input().split('-')   # ← 구분자와 개수가 문제마다 바뀜
y = int(y)
m = int(m)
d = int(d)
print(y, m, d)
```

```python
# 4) 여러 줄에 걸쳐 값 받기
a = int(input())               # 첫째 줄
b = int(input())               # 둘째 줄
c = int(input())               # ← 줄 수만큼 input() 을 늘린다
print(a, b * 2, c)             # ← 문제마다 바뀜
```

```python
# 5) 글자를 받아 그대로 다루기
s = input()                    # 변환하지 않는다
print(s[0])                    # 첫 글자
print('[' + s + ']')           # ← 앞뒤에 붙일 글자는 문제마다 바뀜
```

**언제 무엇을 쓰나**

| 상황 | 고르는 것 | 이유 | 복잡도 |
|------|-----------|------|--------|
| 정수 하나가 한 줄에 | `int(input())` | 계산에 쓰려면 글자를 수로 바꿔야 한다 | O(1) |
| 소수점이 들어올 수 있다 | `float(input())` | `int()` 는 `'4.2'` 에서 오류가 난다 | O(1) |
| 글자·단어를 받는다 | `input()` 그대로 | 이미 문자열이라 변환이 필요 없다 | O(1) |
| 한 줄에 값이 여러 개(공백) | `input().split()` | 공백이 몇 칸이든 알아서 잘라 준다 | O(길이) |
| 한 줄에 값이 여러 개(`-`, `:`, `,`) | `input().split('-')` | 그 문자가 정확히 경계가 된다 | O(길이) |
| 값이 줄마다 하나씩 | `input()` 을 줄 수만큼 | 한 번 호출에 한 줄만 읽는다 | O(줄 수) |
| 자른 조각을 계산에 쓴다 | 조각마다 `int()` | `split` 은 자르기만 하고 변환하지 않는다 | O(1) |
| 앞의 `0` 을 없애고 싶다 | `int('07')` → `7` | 수로 읽으면 앞의 0은 값에 기여하지 않는다 | O(1) |
| 앞의 `0` 을 유지해야 한다 | 문자열 그대로 둔다 | 정수로 바꾸는 순간 모양이 사라진다 | O(1) |
| 첫 글자만 필요하다 | `s[0]` | 인덱스는 0부터 시작한다 | O(1) |
| 글자를 앞뒤로 붙인다 | `'[' + s + ']'` | 문자열끼리의 `+` 는 이어 붙이기다 | O(길이) |
| 값 사이를 공백으로 출력 | `print(a, b)` | 쉼표가 공백 한 칸을 넣어 준다 | O(1) |

**✅ 마스터 체크리스트**

- [ ] 설명할 수 있다: `input()` 이 왜 항상 문자열을 돌려주는가.
- [ ] 설명할 수 있다: `"3" + "4"` 와 `3 + 4` 의 결과가 왜 다른가.
- [ ] 설명할 수 있다: `int()` 와 `float()` 중 무엇을 쓸지 어떤 기준으로 정하는가.
- [ ] 설명할 수 있다: `int('4.2')` 는 오류인데 `float('4')` 는 왜 괜찮은가.
- [ ] 설명할 수 있다: `float` 으로 받은 값이 왜 `4.0` 처럼 보이는가.
- [ ] 설명할 수 있다: `input().split()` 이 무엇을 잘라 무엇을 돌려주는가.
- [ ] 설명할 수 있다: `split()` 의 결과가 왜 아직 문자열인가.
- [ ] 설명할 수 있다: 변수 개수와 조각 개수가 다르면 왜 오류가 나는가.
- [ ] 설명할 수 있다: `input()` 을 두 번 부르면 어느 줄이 어디로 들어가는가.
- [ ] 설명할 수 있다: 같은 두 값이 한 줄에 있을 때와 두 줄에 있을 때 코드가 어떻게 달라지는가.
- [ ] 설명할 수 있다: `split(':')` 처럼 구분자를 준 경우와 그냥 `split()` 의 규칙 차이는 무엇인가.
- [ ] 설명할 수 있다: `int('07')` 이 왜 `7` 이 되는가.
- [ ] 설명할 수 있다: 문자열의 첫 글자가 왜 `s[1]` 이 아니라 `s[0]` 인가.
- [ ] 설명할 수 있다: `72 // 10` 과 `72 % 10` 이 각각 어느 자리 숫자를 주는가.

**⚠️ 자주 하는 실수**

**(1) `int()` 를 통째로 씌운다**

```python
# ❌ 틀린 코드
a, b = int(input().split())
```

왜: `input().split()` 의 결과는 조각 **여러 개**(리스트)다. `int()` 는 값 하나만 바꿀 수 있어 여기서 오류(TypeError)가 난다.

```python
# ✅ 고친 코드
a, b = input().split()
a = int(a)
b = int(b)
```

**(2) `int()` 를 아예 빠뜨린다**

```python
# ❌ 틀린 코드
a, b = input().split()
print(a + b)             # 입력 "3 5" -> 35
```

왜: 오류가 나지 않고 **조용히 틀린 답**이 나오기 때문에 더 위험하다. 문자열끼리의 `+` 는 덧셈이 아니라 이어 붙이기다.

```python
# ✅ 고친 코드
a, b = input().split()
a = int(a)
b = int(b)
print(a + b)             # 8
```

**(3) `sep` 과 `split` 을 헷갈린다**

```python
# ❌ 틀린 코드
y, m, d = input().split('-')
print(y, m, d, split='-')    # TypeError
```

왜: `split` 은 **입력을 자르는** 도구이고, `sep` 은 **출력할 때 값 사이에 넣을 문자**를 정하는 옵션이다. 방향이 반대다.

```python
# ✅ 고친 코드
y, m, d = input().split('-')     # 입력을 자를 때는 split
print(y, m, d, sep='-')          # 출력을 이을 때는 sep
```

**(4) 변수 개수를 입력값 개수와 다르게 쓴다**

```python
# ❌ 틀린 코드
a, b = input().split()   # 입력이 "1 2 3" 이면 ValueError
```

왜: 조각은 3개인데 받을 이름이 2개다. 동시 대입은 양쪽 개수가 정확히 같아야 한다.

```python
# ✅ 고친 코드
a, b, c = input().split()
```

**(5) 여러 줄 입력을 한 번에 받으려 한다**

```python
# ❌ 틀린 코드
a, b = input().split()   # 입력이 두 줄이면 ValueError
# 4
# 9
```

왜: `input()` 은 한 번에 **한 줄**만 읽는다. 둘째 줄은 아직 읽히지도 않았으므로 자를 것이 하나뿐이다.

```python
# ✅ 고친 코드
a = int(input())
b = int(input())
```

**(6) 소수가 들어올 수 있는데 `int` 로 받는다**

```python
# ❌ 틀린 코드
x = int(input())         # 입력 "4.2" -> ValueError
```

왜: `int()` 는 "글자로 적힌 정수"만 읽는다. 점을 만나면 정수 표기가 아니라고 판단하고 멈춘다.

```python
# ✅ 고친 코드
x = float(input())       # "4" 도 "4.2" 도 받아 준다
```

**(7) 인덱스를 1부터 센다**

```python
# ❌ 틀린 코드
s = input()              # 예: cat
print(s[1])              # a  (둘째 글자)
```

왜: 인덱스는 "맨 앞에서 몇 칸 떨어져 있는가"라서 첫 글자가 0번이다. 길이가 3이면 마지막은 `s[2]` 이고 `s[3]` 은 오류다.

```python
# ✅ 고친 코드
s = input()
print(s[0])              # c
```

**(8) 구분자를 지정하지 않고 자른다**

```python
# ❌ 틀린 코드
a, b = input().split()   # 입력 "12:30" -> ValueError
```

왜: 인자 없는 `split()` 은 **공백**만 찾는다. `12:30` 에는 공백이 없으므로 자를 곳이 없어 조각이 하나뿐이다.

```python
# ✅ 고친 코드
a, b = input().split(':')
a = int(a)
b = int(b)
```
