> 개요: 반복문 안에 또 반복문을 넣는 "다중 반복문(중첩 반복문)"으로 별과 숫자를 여러 줄에 걸쳐 규칙적으로 출력하는 법을 배운다. 바깥 반복문은 "행(줄)"을, 안쪽 반복문은 "한 줄 안의 칸"을 담당한다는 감각을 익힌다.

## L1. 사각형 별 출력

**개념**

- 다중 반복문(중첩 반복문)은 반복문 안에 또 다른 반복문을 넣은 구조다.
- 바깥 반복문은 "몇 번째 줄인지(행)", 안쪽 반복문은 "그 줄에서 별을 몇 개 찍는지(열)"를 담당한다.
- 안쪽 반복문에서 `print("*", end="")` 로 줄바꿈 없이 별을 옆으로 이어 찍는다.
- 한 줄을 다 찍은 뒤, 안쪽 반복문 밖에서 `print()` 를 한 번 호출해 줄을 바꾼다.
- 사각형은 모든 줄의 별 개수가 똑같다. 즉 안쪽 반복 횟수가 항상 고정이다.

```python
n = 3   # 3줄, 한 줄에 별 4개
for i in range(n):        # 바깥: 줄
    for j in range(4):    # 안쪽: 한 줄의 별
        print("*", end="")
    print()               # 줄바꿈
```

위 코드는 `*`가 4개인 줄을 3줄 출력한다.

> 선행: `print("*", end="")` 의 `end=""` 는 출력 후 줄바꿈 대신 아무것도 붙이지 말라는 뜻이다. 그래서 별이 옆으로 이어진다.

**그림으로 보기**

`h = 3`, `w = 4`인 사각형에서 두 반복문이 칸을 훑는 순서다. 칸 안의 번호가 방문 순서(= `print("*", end="")`가 실행되는 순서)다.

```text
         j=0   j=1   j=2   j=3
       ┌─────┬─────┬─────┬─────┐
  i=0  │  1  │  2  │  3  │  4  │  -> print()   # 여기서 줄바꿈
       ├─────┼─────┼─────┼─────┤
  i=1  │  5  │  6  │  7  │  8  │  -> print()
       ├─────┼─────┼─────┼─────┤
  i=2  │  9  │ 10  │ 11  │ 12  │  -> print()
       └─────┴─────┴─────┴─────┘
```

바깥 `i`가 한 칸 내려갈 때마다 안쪽 `j`는 `0`부터 다시 시작한다. 그래서 번호가 왼쪽에서 오른쪽으로 가다가, 줄이 바뀌면 다시 맨 왼쪽으로 돌아온다.

**왜 이렇게 되는가**

- 바깥 반복이 `h`번 돌고, 그 한 번마다 안쪽 반복이 `w`번 돈다. 그래서 `print("*", end="")`는 정확히 `h × w`번 실행된다.
- 줄바꿈 `print()`는 안쪽 반복 **밖**에 있으므로 바깥 한 바퀴에 한 번씩, 총 `h`번 실행된다. 이 횟수가 곧 줄 수다.
- 즉 "몇 줄인가"는 바깥이, "한 줄에 몇 개인가"는 안쪽이 정한다. 두 숫자를 만드는 반복문이 서로 다르다는 점이 다중 반복문의 출발점이다.
- `h = 20`, `w = 20`이면 별은 400개다. 이 정도 규모에서는 속도를 걱정할 필요가 없다.

## L2. 직각삼각형 별 출력

**개념**

- 직각삼각형은 줄마다 별 개수가 달라진다. 보통 첫 줄 1개, 둘째 줄 2개, ... 처럼 줄이 내려갈수록 늘어난다.
- 핵심은 "안쪽 반복 횟수를 바깥 반복 변수에 연동"하는 것이다.
- 바깥 변수 `i`가 `0, 1, 2, ...` 로 바뀔 때, 그 줄의 별 개수를 `i`로 계산한다.

```python
n = 4
for i in range(n):            # i = 0,1,2,3
    for j in range(i + 1):    # 별 개수 = i+1 → 1,2,3,4
        print("*", end="")
    print()
```

출력:
```
*
**
***
****
```

- 별 개수가 줄어드는 삼각형은 안쪽 반복 횟수를 `n - i` 처럼 잡으면 된다.

**그림으로 보기**

바깥 변수 `i`와 그 줄에 찍히는 별 개수의 대응이다. 안쪽 반복 범위가 `i`에 매달려 있다.

```text
   i     inner : range(i + 1)      output
  ---    --------------------      ------
   0     j = 0                     *
   1     j = 0,1                   **
   2     j = 0,1,2                 ***
   3     j = 0,1,2,3               ****
```

줄어드는 삼각형은 안쪽 범위만 `range(n - i)`로 바꾼 것이다. 모양이 뒤집혔을 뿐 구조는 같다.

```text
   i     inner : range(n - i)      output      # n = 4
  ---    --------------------      ------
   0     j = 0,1,2,3               ****
   1     j = 0,1,2                 ***
   2     j = 0,1                   **
   3     j = 0                     *
```

**손으로 따라가기**

`n = 3`인 늘어나는 삼각형을 회차별로 따라간다.

| 단계 | i | j | 실행되는 문장 | 화면(누적) |
| --- | --- | --- | --- | --- |
| 1 | 0 | 0 | `print("*", end="")` | `*` |
| 2 | 0 | — | `print()` | 1번째 줄 완성 |
| 3 | 1 | 0 | `print("*", end="")` | 2번째 줄 `*` |
| 4 | 1 | 1 | `print("*", end="")` | 2번째 줄 `**` |
| 5 | 1 | — | `print()` | 2번째 줄 완성 |
| 6 | 2 | 0 | `print("*", end="")` | 3번째 줄 `*` |
| 7 | 2 | 1 | `print("*", end="")` | 3번째 줄 `**` |
| 8 | 2 | 2 | `print("*", end="")` | 3번째 줄 `***` |
| 9 | 2 | — | `print()` | 3번째 줄 완성 |

별은 `1 + 2 + 3 = 6`개, 줄바꿈은 3번. 그래서 3줄짜리 삼각형이 된다.

**왜 이렇게 되는가**

- 안쪽 반복 횟수가 `i`에 따라 변하므로 총 실행 횟수는 고정이 아니다. `i = 0, 1, …, n-1`에서 각각 `i+1`번이니 총합은 `1 + 2 + … + n`이다.
- 이 합은 손으로 세지 않고 한 번에 구할 수 있다. 같은 합을 순서만 뒤집어 아래에 한 번 더 쓰고 세로로 더한다.

```text
   S  =   1   +   2   + ... + (n-1) +   n
   S  =   n   + (n-1) + ... +   2   +   1
  ------------------------------------------
  2S  = (n+1) + (n+1) + ... + (n+1) + (n+1)     # (n+1) 이 n 개
  2S  = n * (n + 1)        ->        S = n(n+1)/2
```

- 그래서 `n`이 2배가 되면 별 개수는 약 4배가 된다. `n = 20`이면 `20 × 21 / 2 = 210`개다.
- 사각형(`n × n`)과 비교하면 삼각형은 정확히 그 절반보다 조금 많다. 대각선 한 줄만큼이 더 붙는 셈이다.

```runner
코드 진행

- 바깥 `for i in range(n)`에서 `i`는 `0`부터 `n-1`까지.
```

## L3. 행에 대해 대칭인 별 출력

**개념**

- "행에 대해 대칭"은 위아래(가로선 기준)로 뒤집어도 같은 모양이라는 뜻이다.
- 위쪽은 별이 늘어나고, 가운데를 지나면 다시 줄어드는 마름모/피라미드 같은 세로 대칭 모양을 만든다.
- 만드는 방법 1: 늘어나는 부분과 줄어드는 부분을 반복문 두 개로 나눠서 이어 출력한다.
- 만드는 방법 2: 각 줄의 별 개수를 "가운데에서 얼마나 떨어졌는가"로 계산한다.

```python
n = 3   # 가운데 줄까지 늘었다가 줄어듦
for i in range(n):        # 위쪽: 1,2,3
    print("*" * (i + 1))
for i in range(n - 1):    # 아래쪽: 2,1
    print("*" * (n - 1 - i))
```

출력:
```
*
**
***
**
*
```

> 선행: `"*" * k` 는 별 문자를 `k`번 이어붙인 문자열을 만든다. 예를 들어 `"*" * 3` 은 `"***"` 이다. 안쪽 반복문 대신 이 방법으로 한 줄을 한 번에 만들 수도 있다.

**그림으로 보기**

행마다 별 개수가 어떻게 변하는지, 그리고 그 개수를 어느 반복문이 만드는지 한눈에 본 것이다(`n = 3`).

```text
  row   output   made by             count
  ---   ------   -------             -----
   1    *        1st for , i=0       i + 1     = 1
   2    **       1st for , i=1       i + 1     = 2
   3    ***      1st for , i=2       i + 1     = 3   <- peak
   4    **       2nd for , i=0       n - 1 - i = 2
   5    *        2nd for , i=1       n - 1 - i = 1
```

가운데 줄(별 `n`개)은 첫 번째 반복이 이미 찍었다. 두 번째 반복은 그 아래부터 이어받는다.

**왜 이렇게 되는가**

- 두 번째 반복이 다시 `n`개부터 시작하면 가장 넓은 줄이 두 번 나와 위아래 대칭이 깨진다. 그래서 `n-1`개부터 시작해야 한다.
- 회차 수도 `n`이 아니라 `n-1`이다. `range(n-1)`이면 `i = 0 … n-2`이고, 별 개수 `n-1-i`는 `n-1`에서 `1`까지 정확히 내려간다.
- 전체 줄 수는 `n + (n-1) = 2n - 1`이다. 항상 홀수이므로 "가운데 줄"이 정확히 하나 존재한다. 대칭 도형에서 줄 수가 짝수로 나왔다면 어딘가에서 가운데를 두 번 찍은 것이다.
- `n = 1`이면 위쪽 반복이 1줄을 찍고 아래쪽은 `range(0)`이라 한 번도 돌지 않는다. 별 하나짜리 한 줄이라는 정답이 자동으로 나온다.

**문제**

## L4. 열에 대해 대칭인 별 출력

**개념**

- "열에 대해 대칭"은 좌우(세로선 기준)로 뒤집어도 같은 모양이라는 뜻이다.
- 한 줄을 [왼쪽 공백들] + [별들] 로 나눠서 생각한다. 별 덩어리가 가운데로 오도록 앞에 공백을 넣는다.
- 왼쪽 공백 개수 + 별 개수의 관계를 줄마다 계산하는 것이 핵심이다.
- 가운데 정렬 삼각형에서, 별이 `1, 3, 5, ...` 처럼 홀수로 늘면 완벽한 좌우 대칭이 된다.

```python
n = 3
for i in range(n):                 # i = 0,1,2
    spaces = " " * (n - 1 - i)     # 앞 공백: 2,1,0
    stars  = "*" * (2 * i + 1)     # 별: 1,3,5
    print(spaces + stars)
```

출력(맨 앞 공백 포함):
```
  *
 ***
*****
```

- 공백도 하나의 문자다. 앞 공백 개수를 줄마다 정확히 맞춰야 좌우 대칭이 된다.

**그림으로 보기**

한 줄을 [앞 공백] + [별] 두 덩어리로 쪼갠 그림이다. `.`은 실제로는 공백이다(`n = 3`).

```text
   col :  0 1 2 3 4
          ---------
  i=0     . . * . .    spaces = n-1-i = 2 , stars = 2i+1 = 1
  i=1     . * * * .    spaces = 1         , stars = 3
  i=2     * * * * *    spaces = 0         , stars = 5
          ---------
              ^
              +--- always column n-1 = 2      # 별 덩어리의 한가운데
```

어느 줄이든 별 덩어리의 한가운데가 같은 열에 놓인다. 그래서 세로 축이 하나로 서고 좌우 대칭이 된다.

**왜 이렇게 되는가**

- 앞 공백이 `n-1-i`개이므로, 그 줄에서 별이 시작하는 열은 `n-1-i`다.
- 별은 `2i+1`개(홀수)라 덩어리의 한가운데는 시작 열에서 `i`칸 뒤다. 그 열은 `(n-1-i) + i = n-1`이다.
- 식에서 `i`가 사라졌다. 즉 **줄 번호와 무관하게** 한가운데가 항상 열 `n-1`이다. 이것이 가운데 정렬이 성립하는 이유다.
- 별 개수가 짝수라면 "한가운데 한 칸"이라는 것이 없어 축을 세울 수 없다. 그래서 가운데 정렬 도형은 별을 `2i+1`처럼 홀수 개로 잡는다.
- 오른쪽 맞춤 삼각형은 축이 아니라 오른쪽 끝을 맞춘다. 그때는 `공백 + 별 = n`이 되도록 공백을 `n-i`, 별을 `i`로 잡으면 된다. 두 덩어리 개수의 합이 일정한지 확인하는 것이 검산법이다.

**문제**

## L5. 행, 열에 대해 대칭인 별 출력

**개념**

- "행·열 모두 대칭"은 위아래로도, 좌우로도 뒤집어도 같은 모양이다. 대표 예가 마름모(다이아몬드)다.
- 마름모는 위쪽 피라미드(별이 홀수로 늘어남)와 아래쪽 뒤집힌 피라미드(별이 홀수로 줄어듦)를 이어 붙인 것이다.
- 각 줄을 [앞 공백] + [별] 로 나누고, 위/아래 부분에서 공백과 별 개수를 각각 계산한다.

```python
n = 3
for i in range(n):                   # 위쪽 포함 가운데까지: 별 1,3,5
    print(" " * (n - 1 - i) + "*" * (2 * i + 1))
for i in range(n - 1):               # 아래쪽: 별 3,1
    print(" " * (i + 1) + "*" * (2 * (n - 1 - i) - 1))
```

출력:
```
  *
 ***
*****
 ***
  *
```

- 가운데 가장 넓은 줄(별 `2n-1`개)은 한 번만 나와야 한다.

**그림으로 보기**

마름모는 가운데 정렬 피라미드를 위·아래로 이어 붙인 것이다. `.`은 공백이다(`n = 3`).

```text
   col :  0 1 2 3 4
  i=0     . . * . .   up   : sp = n-1-i = 2 , st = 2i+1 = 1
  i=1     . * * * .   up   : sp = 1         , st = 3
  i=2     * * * * *   up   : sp = 0         , st = 5   <- once only
  i=0     . * * * .   down : sp = i+1 = 1   , st = 2(n-1-i)-1 = 3
  i=1     . . * . .   down : sp = 2         , st = 1
```

속이 빈 사각형은 모양이 아니라 **조건**으로 만든다. 모든 칸을 훑되 테두리인지 아닌지만 판정한다.

```text
  n = 4 , cell (i, j) is a border cell when
      i == 0  or  i == n-1  or  j == 0  or  j == n-1

          j=0  j=1  j=2  j=3
   i=0     B    B    B    B        B -> print("*", end="")
   i=1     B    .    .    B        . -> print(" ", end="")
   i=2     B    .    .    B
   i=3     B    B    B    B
```

**왜 이렇게 되는가**

- 마름모의 아래쪽 반복이 `range(n-1)`인 이유는 L3과 같다. 가장 넓은 줄을 위쪽이 이미 찍었으므로 아래쪽은 그다음 줄부터 시작해야 한다.
- 아래쪽에서 공백이 `i+1`, 별이 `2(n-1-i)-1`인 것도 같은 계산이다. `i = 0`일 때 공백 1개·별 `2n-3`개로 가운데 바로 아랫줄이 되고, `i = n-2`일 때 공백 `n-1`개·별 1개로 꼭짓점이 된다.
- 속이 빈 사각형에서 안쪽 칸에도 공백을 반드시 찍어야 하는 이유: 한 칸을 건너뛰면 오른쪽 별이 왼쪽으로 밀려 열이 어긋난다. `if`의 두 가지 모두에서 **정확히 한 글자씩** 찍어야 폭이 유지된다.
- `n = 1`이면 유일한 칸이 네 조건을 모두 만족해 별 하나가 찍힌다. `n = 2`면 네 칸이 전부 테두리라 속이 빈 부분이 없다. 작은 값에서 조건식이 무너지지 않는지 이렇게 확인한다.

## L6. 행에 따라 다른 별 출력

**개념**

- 지금까지는 줄마다 별 "개수"만 달랐다. 이번엔 줄마다 별의 "위치·모양·간격"이 규칙적으로 달라지는 경우다.
- 바깥 변수 `i`(행 번호)에 따라, 각 열 `j`에 별을 찍을지 공백을 찍을지 조건으로 정한다.
- "행에 따라 다른" 문제는 대부분 `for i` 안에서 `for j`를 돌며 `if`로 별/공백을 결정하는 구조다.

```python
n = 4
for i in range(n):
    for j in range(n):
        if i == j:            # 대각선 위치에만 별
            print("*", end="")
        else:
            print(" ", end="")
    print()
```

출력(대각선):
```
*
 *
  *
   *
```

> 선행: Ch5에서 배운 "반복문 안의 if"를 여기서 본격적으로 쓴다. 안쪽 반복 `for j` 안에서 별을 찍을 조건을 `if`로 판단한다.

**그림으로 보기**

이제 모양이 아니라 좌표 `(i, j)`가 주인공이다. 모든 칸을 훑되, 조건이 참인 칸에만 별을 찍는다(`n = 4`).

```text
         j=0  j=1  j=2  j=3
       ┌────┬────┬────┬────┐
  i=0  │ *  │    │    │    │    i == j      -> "*"
       ├────┼────┼────┼────┤    otherwise   -> " "
  i=1  │    │ *  │    │    │
       ├────┼────┼────┼────┤
  i=2  │    │    │ *  │    │
       ├────┼────┼────┼────┤
  i=3  │    │    │    │ *  │
       └────┴────┴────┴────┘
```

반대 대각선은 열 번호가 `n-1-i`인 칸이고, X자는 두 조건을 `or`로 묶은 것이다.

```text
  main diagonal  :  j == i          # i 와 j 가 같은 칸
  anti diagonal  :  j == n - 1 - i  # i + j 가 n-1 인 칸
  X shape        :  j == i  or  j == n - 1 - i
```

**손으로 따라가기**

`n = 3`인 대각선 별. 한 행을 한 줄로 묶어 세 칸의 판정을 함께 본다.

| i | j=0 | j=1 | j=2 | 그 줄의 출력 |
| --- | --- | --- | --- | --- |
| 0 | 참 → `*` | 거짓 → 공백 | 거짓 → 공백 | `*` 뒤에 공백 2칸 |
| 1 | 거짓 → 공백 | 참 → `*` | 거짓 → 공백 | 공백 1칸 뒤 `*` |
| 2 | 거짓 → 공백 | 거짓 → 공백 | 참 → `*` | 공백 2칸 뒤 `*` |

각 줄에서 조건이 참인 칸은 정확히 하나뿐이라 별도 하나씩만 찍힌다.

**왜 이렇게 되는가**

- `i == j`가 왼쪽 위에서 오른쪽 아래 대각선인 이유: 한 칸 아래로 가면 `i`가 1 늘고, 한 칸 오른쪽으로 가면 `j`가 1 는다. 둘을 함께 1씩 늘리면 대각선 방향으로 움직인다.
- 반대 대각선은 `i`가 1 늘 때 `j`가 1 줄어드는 방향이다. 그래서 `i + j`가 일정하고, 그 값이 `n-1`인 칸들이 오른쪽 위에서 왼쪽 아래로 이어진다.
- `n`이 홀수면 두 대각선이 정중앙에서 만난다. 그 칸은 두 조건이 모두 참이지만 `if`는 한 번만 실행되므로 별도 한 번만 찍힌다. `or`로 묶었기 때문에 중복 출력 걱정이 없다.

## L7. 모양과 관계 없는 별 출력

**개념**

- 앞의 문제들은 삼각형·마름모처럼 정해진 도형이었다. 이번엔 "정해진 도형 없이" 규칙에 따라 별과 공백을 찍는 연습이다.
- 핵심은 늘 같다: 각 위치 `(i, j)`에서 "여기에 별을 찍을 조건은 무엇인가?"를 `if`로 표현하는 것.
- 조건은 나머지 연산 `%`, 비교, `and`/`or` 등을 조합해 만든다.

```python
n = 4
for i in range(n):
    for j in range(n):
        if (i + j) % 2 == 0:   # 체크무늬
            print("*", end="")
        else:
            print(" ", end="")
    print()
```

출력(체스판 무늬):
```
* * 
 * *
* * 
 * *
```

> 선행: Ch4의 `and`/`or`, Ch5에서 다룬 `%`(나머지)와 조건 판단을 조합한다. 특정 위치에 별을 찍는 조건을 스스로 세우는 게 목표다.

**그림으로 보기**

칸마다 `i + j`를 계산해 홀짝으로 나눈다. 왼쪽이 계산값, 오른쪽이 그 결과다(`n = 4`).

```text
   i + j  values                    result
       j:  0 1 2 3                      j:  0 1 2 3
  i=0      0 1 2 3               i=0        * . * .
  i=1      1 2 3 4               i=1        . * . *
  i=2      2 3 4 5               i=2        * . * .
  i=3      3 4 5 6               i=3        . * . *
                                 # '.' 는 실제로는 공백
```

**왜 이렇게 되는가**

- 오른쪽 옆 칸은 `j`가 1 늘어 `i+j`가 1 커지고, 아래 칸은 `i`가 1 늘어 역시 1 커진다. 1이 커지면 홀짝은 **반드시** 뒤집힌다.
- 그래서 `(i+j) % 2`로 두 부류를 나누면, 맞닿은 칸끼리는 언제나 서로 다른 부류가 된다. 체스판 무늬가 나오는 이유가 이것이다.
- `(0, 0)`은 합이 0(짝수)이므로 왼쪽 위가 별로 시작한다. 시작을 뒤집고 싶으면 조건을 `% 2 == 1`로 바꾸면 된다.
- 조건식에 `i`가 아예 없으면(`j % 2 == 0`) 모든 줄이 똑같아져 세로 줄무늬가 되고, `j`가 없으면 줄 전체가 통째로 별이거나 공백이라 가로 줄무늬가 된다. **조건에 어떤 변수가 들어 있느냐가 무늬의 방향을 정한다.**
- 조건을 `or`로 여러 개 이으면 "이유가 하나라도 있으면 별"이 된다. 테두리 네 조건과 대각선 조건을 함께 묶어도 겹치는 칸에서 별이 두 번 찍히지 않는 것은, `if`가 참·거짓 하나만 판정하기 때문이다.

## L8. 일반적인 순서로 숫자 출력

**개념**

- 별 대신 숫자를 찍는 것도 중첩 반복문으로 한다. 별을 찍던 자리에 숫자를 넣으면 된다.
- "일반적인 순서"란 `1, 2, 3, ...` 처럼 자연스러운 증가 순서를 말한다.
- 방법 A: 안쪽 변수 `j`(예: `range(1, k+1)`)를 그대로 숫자로 출력한다. 줄마다 다시 1부터 시작한다.
- 방법 B: 별도의 카운터 변수를 하나 두고, 칸을 지날 때마다 1씩 늘리면 전체가 이어지는 번호가 된다.
- 숫자를 옆으로 이어 찍을 때도 `print(j, end="")` 처럼 `end=""` 를 쓴다. 필요하면 `print(j, end=" ")` 로 공백을 넣는다.

```python
n = 3
for i in range(n):                # 각 줄마다 1부터
    for j in range(1, n + 1):     # j = 1,2,3
        print(j, end="")
    print()
```

출력:
```
123
123
123
```

**그림으로 보기**

같은 이중 반복이라도 "무엇을 찍느냐"에 따라 결과가 갈린다. 왼쪽은 안쪽 변수 `j`를 그대로, 오른쪽은 카운터를 찍은 것이다.

```text
  A) print(j)                     B) print(count) , count += 1
     j restarts every row            count never restarts

       ┌───┬───┬───┐                 ┌───┬───┬───┐
       │ 1 │ 2 │ 3 │                 │ 1 │ 2 │ 3 │
       ├───┼───┼───┤                 ├───┼───┼───┤
       │ 1 │ 2 │ 3 │                 │ 4 │ 5 │ 6 │
       ├───┼───┼───┤                 ├───┼───┼───┤
       │ 1 │ 2 │ 3 │                 │ 7 │ 8 │ 9 │
       └───┴───┴───┘                 └───┴───┴───┘
```

**손으로 따라가기**

`h = 2`, `w = 3`인 이어지는 번호. `count`는 반복문 밖에서 `1`로 시작한다.

| 단계 | i | j | 찍는 값 | 실행 후 count |
| --- | --- | --- | --- | --- |
| 1 | 0 | 0 | 1 | 2 |
| 2 | 0 | 1 | 2 | 3 |
| 3 | 0 | 2 | 3 | 4 |
| — | 0 | — | 줄바꿈 | 4 (그대로) |
| 4 | 1 | 0 | 4 | 5 |
| 5 | 1 | 1 | 5 | 6 |
| 6 | 1 | 2 | 6 | 7 |
| — | 1 | — | 줄바꿈 | 7 (그대로) |

줄바꿈은 `count`를 건드리지 않는다. 그래서 번호가 줄을 넘어 이어진다.

**왜 이렇게 되는가**

- 안쪽 변수 `j`는 안쪽 반복이 시작될 때마다 처음 값으로 되돌아간다. 그래서 `j`만으로는 "줄을 넘어 이어지는 번호"를 만들 수 없다.
- 카운터를 반복문 밖에 두면 초기화가 딱 한 번이므로 값이 끊기지 않는다. 반대로 안쪽에 두면 매 줄 다시 1부터 시작한다. **초기화 위치가 곧 초기화 횟수다.**
- 세로 우선 번호는 카운터로 이어 세기 어렵다. 출력은 가로로 해야 하는데 번호는 세로로 커지기 때문이다. 이럴 때는 칸의 값을 직접 구하는 공식을 세운다.
- `(i, j)` 칸 앞에 몇 칸이 지나갔는지 센다. 세로 우선이면 `0 … j-1`열이 통째로 지나갔으므로 `j × h`칸, 그 열 안에서 위로 `i`칸이 더 지나갔으므로 `+ i`, 번호를 1부터 세니 `+ 1`. 합쳐서 `value = j*h + i + 1`이다.
- 검산: `h = 2`에서 `(0행, 1열)`은 `1*2 + 0 + 1 = 3`이다. 예제의 `1 3 5 / 2 4 6`과 맞는다.

```runner
- 한 줄의 내용을 정한다: `1`부터 `n`까지 붙여 쓰기.
- 안쪽 반복 변수를 1부터 시작하려고 `range(1, n+1)`을 쓴다.
- 숫자 사이 공백이 없어야 하므로 `end=""`. 줄마다 안쪽 반복이 다시 1부터라 매 줄 같은 내용.
```

**2) 이어지는 번호 매기기** · Medium

- **요구사항**: 정수 `h`와 `w`를 입력받아 `1`부터 시작해 왼쪽에서 오른쪽으로, 위에서 아래로 칸마다 1씩 커지는 번호를 `h × w` 격자에 채워 출력한다. 숫자는 공백 한 칸으로 구분한다.
- **입력**: 두 정수 `h w` (1 ≤ h, w ≤ 5)
- **출력**: `h`줄, 각 줄에 `w`개의 숫자를 공백으로 구분. 번호는 전체에 걸쳐 이어진다.
- **예제**: `2 3` → 
```
1 2 3
4 5 6
```
- **예제**: `3 2` → 
```
1 2
3 4
5 6
```
- **셀프체크**: 줄이 바뀌어도 번호가 초기화되지 않고 계속 이어져야 한다. 카운터 변수 하나를 반복문 밖에서 만들어 두고 칸마다 1씩 올린다.

```runner
@@SOLUTION
h, w = map(int, input().split())
count = 1
for i in range(h):
    for j in range(w):
        print(count, end=" ")
        count = count + 1
    print()
@@TESTS
--IN
2 3
--OUT
1 2 3
4 5 6
--IN
3 2
--OUT
1 2
3 4
5 6
@@EXPL
접근

- 번호가 줄이 바뀌어도 이어지려면 카운터 변수 하나를 반복문 밖에서 만들어 두고, 칸을 지날 때마다 1씩 올린다. 안쪽 변수 `j`로는 이어지는 번호를 만들 수 없다(줄마다 다시 0부터라서).

코드 진행

- `h, w`를 입력받고, 반복 밖에서 `count = 1`로 시작한다.
- 바깥 `for i`(행), 안쪽 `for j`(열)로 격자를 훑는다.
- 각 칸에서 `print(count, end=" ")`로 현재 번호를 찍고 `count = count + 1`로 올린다.
- 한 행이 끝나면 `print()`. `count`는 초기화하지 않으므로 다음 줄로 이어진다.

재작성 사고 순서

- "번호가 전체에 걸쳐 이어져야 한다" → 카운터를 반복 밖에 둔다.
- 칸마다 출력 후 `count`를 1 증가.
- 숫자 뒤에 공백 구분이 필요하니 `end=" "`. 줄 끝 공백은 채점에 무방.
```

**3) 세로로 세는 번호** · Hard

- **요구사항**: 정수 `h`와 `w`를 입력받아, `1`부터 시작하되 위에서 아래로(같은 열을 먼저) 세어 내려간 뒤 다음 열로 넘어가는 순서로 번호를 매겨 `h × w` 격자로 출력한다. 숫자는 공백으로 구분한다.
- **입력**: 두 정수 `h w` (1 ≤ h, w ≤ 5)
- **출력**: `(i행, j열)` 칸의 값이 세로 우선 순서의 번호. 각 줄에 `w`개 숫자를 공백으로 구분.
- **예제**: `2 3` → 
```
1 3 5
2 4 6
```
- **예제**: `3 2` → 
```
1 4
2 5
3 6
```
- **셀프체크**: 번호가 아래로 먼저 증가한다. `(i, j)` 칸의 값을 카운터 대신 공식 `j*h + i + 1` 로도 계산할 수 있는지 생각해 본다. 예: `h=2`에서 `(0행,1열)` = `1*2+0+1 = 3`, 예제와 일치.

```runner
@@SOLUTION
h, w = map(int, input().split())
for i in range(h):
    for j in range(w):
        value = j * h + i + 1
        print(value, end=" ")
    print()
@@TESTS
--IN
2 3
--OUT
1 3 5
2 4 6
--IN
3 2
--OUT
1 4
2 5
3 6
@@EXPL
접근

- 이번엔 번호를 세로로(같은 열을 먼저 위→아래) 센다. 출력은 여전히 가로로 한 줄씩 해야 하므로, 각 칸 `(i, j)`의 값을 직접 계산하는 공식이 편하다. `j`열은 앞에 `j`개 열이 꽉 찼다는 뜻이라 `j*h`개를 지났고, 그 열 안에서 `i`행이면 `+i`, 1부터 세니 `+1` → `value = j*h + i + 1`.

코드 진행

- `h, w`를 입력받는다.
- 바깥 `for i`(행), 안쪽 `for j`(열)로 출력 순서대로 격자를 훑는다.
- 각 칸에서 `value = j * h + i + 1`로 세로 우선 번호를 계산해 `print(value, end=" ")`.
- 한 행이 끝나면 `print()`.

재작성 사고 순서

- 출력은 가로 한 줄씩이지만 번호는 세로로 먼저 증가한다는 걸 구분한다.
- 카운터로 이어 세기 어려우니 `(i, j)` 칸의 값을 공식으로 구한다.
- `j`열까지 지난 칸 수 `j*h`, 그 열 안 위치 `i`, 1부터 시작 `+1` → `j*h + i + 1`. 예제로 검산한다.
```
