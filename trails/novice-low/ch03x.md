## L3. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch03(연산자)의 핵심을 **반복 훈련**하고, 코딩테스트 단골 유형으로 **확장**하는 연습 세트입니다. 조건문·반복문 없이 연산자만으로 답을 만드는 문제들입니다.
- **반복 훈련 개념**: 아래 다섯 가지를 소재만 바꿔 여러 번 다시 씁니다.

- 사칙연산 — `a + b`, `a - b`, `a * b`, `a / b`. 나눗셈 `/` 의 결과는 항상 실수(`6 / 3` 은 `2.0`)입니다.
- 몫과 나머지 — `a // b` 는 소수점 아래를 버린 몫, `a % b` 는 나머지. "몇 묶음과 몇 개가 남는가"를 셀 때 씁니다.
- 우선순위와 괄호 — 곱셈·나눗셈이 덧셈·뺄셈보다 먼저. 순서를 바꾸려면 `(a + b) * c` 처럼 괄호로 묶습니다.
- 합과 평균 — `total = a + b + c` 로 합을 먼저 담고, `total / 3` 으로 평균을 구합니다. 나누는 수는 값의 개수입니다.
- 소수점 출력(Ch01) — `print(f'{x:.2f}')` 로 소수점 아래 자릿수를 고정해 출력합니다.

- **코딩테스트 출제 맵**: 백준 「단계별로 풀어보기」의 '입출력과 사칙연산' 단계(A/B, 나머지, 사칙연산, 시간 계산)와 solved.ac CLASS 1이 이 챕터 수준입니다. 『이것이 취업을 위한 코딩테스트다』 '그리디' 파트의 거스름돈 문제도 조건문·반복문 없이 `//`·`%` 만으로 축소해 연습합니다.
- **문제 구성표**:

| # | 문제 | 난이도 | 반복 개념 | 유형 |
|---|------|--------|-----------|------|
| 1 | 나눗셈 두 가지 | Easy | `/` 와 `//` 의 차이 | 반복 훈련 |
| 2 | 초를 분과 초로 | Easy | `//`·`%` 로 단위 나누기 | 유형 확장 (백준 '입출력과 사칙연산' 단계의 시간 계산 스타일) |
| 3 | 평균 속력 | Easy | `/` 실수 나눗셈 출력 | 유형 확장 (백준 '입출력과 사칙연산' 단계의 A/B 스타일) |
| 4 | 체질량지수 두 자리 | Easy | 실수 입력·괄호·`.2f` | 반복 훈련 |
| 5 | 다섯 명의 키 합과 평균 | Medium | 합 → 평균·`.1f` | 반복 훈련 |
| 6 | 정육면체 부피와 겉넓이 | Medium | `**` 거듭제곱·우선순위 | 유형 확장 (백준 '입출력과 사칙연산' 단계의 거듭제곱 계산 스타일) |
| 7 | 괄호가 바꾸는 결과 | Medium | 우선순위·괄호 | 반복 훈련 |
| 8 | 동전 최소 개수 | Hard | `//`·`%` 연쇄·변수 갱신 | 유형 확장 (이코테 '그리디' 파트 거스름돈 문제의 조건문 없는 축소판) |

> 선행: 6번에서 쓰는 `a ** 3` 은 "`a` 를 세 번 곱한 값(거듭제곱)"을 뜻하는 연산자입니다. `a * a * a` 와 같은 결과이며, `**` 는 `*` 보다 먼저 계산됩니다. 아직 정식으로 배우지 않았으니 이 정도로만 알고 쓰면 됩니다.

**문제**

**1) 나눗셈 두 가지** · Easy

- **요구사항**: 두 정수를 입력받아 첫째 줄에 실수 나눗셈 결과(`/`), 둘째 줄에 몫(`//`)을 출력합니다.
- **입력**: 한 줄에 두 정수 `a b` 가 공백으로 구분되어 주어집니다. (`b` 는 1 이상)
- **출력**: 첫째 줄에 `a / b`, 둘째 줄에 `a // b` 를 출력합니다.
- **예제**: `7 2` → `3.5` / `3` (두 줄)
- **예제**: `8 4` → `2.0` / `2` (두 줄)
- **셀프체크**: 딱 나누어떨어지는 `8 4` 에서도 첫째 줄은 `2.0`(실수), 둘째 줄은 `2`(정수)로 모양이 다른가? 두 값을 모두 `int` 로 바꾼 뒤 계산했는가?

```runner
@@SOLUTION
a, b = input().split()
a = int(a)
b = int(b)
print(a / b)
print(a // b)
@@TESTS
--IN
7 2
--OUT
3.5
3
--IN
8 4
--OUT
2.0
2
--IN
1 3
--OUT
0.3333333333333333
0
@@EXPL
(1) 접근·핵심 아이디어

- 파이썬의 나눗셈은 두 종류입니다. `/` 는 소수까지 계산한 실수를 주고, `//` 는 소수점 아래를 버린 정수 몫을 줍니다.
- 같은 두 수로 둘을 나란히 출력해 모양의 차이를 눈으로 확인하는 문제입니다. 나누어떨어져도 `/` 는 `2.0` 처럼 `.0` 을 붙입니다.

(2) 코드 단계별

- `a, b = input().split()` 뒤 `int(a)`, `int(b)` — 두 정수를 받습니다.
- `print(a / b)` — `7 / 2 = 3.5`, `8 / 4 = 2.0`, `1 / 3 = 0.3333333333333333`.
- `print(a // b)` — `7 // 2 = 3`, `8 // 4 = 2`, `1 // 3 = 0`(1을 3으로 나누면 몫이 0).

(3) 스스로 다시 짤 때 생각 순서

- "소수가 필요한가, 몫만 필요한가?" 를 문제마다 먼저 정합니다. 여기서는 둘 다 출력합니다.
- 두 값을 정수로 바꾼 뒤 `/`, `//` 를 각각 한 줄씩 출력합니다.
- `1 3` 처럼 앞이 작은 경우 `//` 가 `0` 이 되는 것도 정상임을 확인합니다.
```

**2) 초를 분과 초로** · Easy

- **요구사항**: 초 단위 시간을 입력받아 "몇 분 몇 초"인지 두 값을 공백으로 구분해 출력합니다.
- **입력**: 0 이상 10000 이하의 정수(초)가 한 줄에 주어집니다.
- **출력**: 분과 초를 공백 하나를 두고 한 줄에 출력합니다.
- **예제**: `150` → `2 30` / `59` → `0 59`
- **셀프체크**: 분은 `n // 60`(몫), 초는 `n % 60`(나머지)입니다. 60초 미만이면 분이 `0` 인가? `3600` 처럼 딱 떨어지면 초가 `0` 인가?

```runner
@@SOLUTION
n = int(input())
print(n // 60, n % 60)
@@TESTS
--IN
150
--OUT
2 30
--IN
59
--OUT
0 59
--IN
3600
--OUT
60 0
--IN
0
--OUT
0 0
@@EXPL
(1) 접근·핵심 아이디어

- 1분은 60초입니다. 초를 60으로 나눈 몫이 "분", 나머지가 "남은 초"입니다.
- "몇 묶음이 되고 몇 개가 남는가"는 `//` 와 `%` 의 대표 쓰임입니다. 조건문 없이 두 연산자만으로 답이 나옵니다.

(2) 코드 단계별

- `n = int(input())` — 초를 정수로 받습니다.
- `n // 60` — `150 // 60 = 2`(분). `n % 60` — `150 % 60 = 30`(초).
- `print(n // 60, n % 60)` — 쉼표로 넘겨 `2 30`. `59` 는 `0 59`, `3600` 은 `60 0`, `0` 은 `0 0` 이 됩니다.

(3) 스스로 다시 짤 때 생각 순서

- "단위가 큰 쪽(분)은 몫, 작은 쪽(초)은 나머지"로 정리합니다.
- 나누는 수는 단위 사이의 배수(60)입니다.
- 경계값: 60 미만(분이 0), 60의 배수(초가 0), 0(둘 다 0)을 손으로 검산합니다.
```

**3) 평균 속력** · Easy

- **요구사항**: 이동 거리(km)와 걸린 시간(시간)을 입력받아 평균 속력(거리 ÷ 시간)을 출력합니다.
- **입력**: 한 줄에 두 정수 `거리 시간` 이 공백으로 구분되어 주어집니다. (시간은 1 이상)
- **출력**: 거리를 시간으로 나눈 값을 한 줄에 출력합니다.
- **예제**: `150 2` → `75.0` / `100 3` → `33.333333333333336`
- **셀프체크**: 속력은 소수까지 필요하므로 `//` 가 아니라 `/` 를 씁니다. 딱 나누어떨어져도 `75.0` 처럼 실수로 나오는가? `100 / 3` 의 긴 소수도 그대로 출력하는가(이 문제는 자릿수를 정하지 않았습니다)?

```runner
@@SOLUTION
d, t = input().split()
d = int(d)
t = int(t)
print(d / t)
@@TESTS
--IN
150 2
--OUT
75.0
--IN
100 3
--OUT
33.333333333333336
--IN
0 5
--OUT
0.0
@@EXPL
(1) 접근·핵심 아이디어

- 평균 속력은 "거리 ÷ 시간"입니다. 소수가 나올 수 있으므로 실수 나눗셈 `/` 를 씁니다.
- 자릿수를 정하지 않은 문제에서는 `/` 의 결과를 그대로 출력합니다. `100 / 3` 처럼 무한히 이어지는 소수는 컴퓨터가 저장할 수 있는 만큼(약 16자리)만 보입니다.

(2) 코드 단계별

- `d, t = input().split()` 뒤 `int(d)`, `int(t)` — 거리와 시간을 정수로 받습니다.
- `print(d / t)` — `150 / 2 = 75.0`, `100 / 3 = 33.333333333333336`, `0 / 5 = 0.0`.

(3) 스스로 다시 짤 때 생각 순서

- "결과가 소수일 수 있나?" → 그렇다 → `/`.
- 나누는 순서(거리 ÷ 시간)를 확인합니다. 반대로 하면 뜻이 달라집니다.
- 거리 `0` 이면 결과도 `0.0`(실수)이라는 점, 시간은 0이 아니라는 조건(0으로 나누면 오류)을 확인합니다.
```

**4) 체질량지수 두 자리** · Easy

- **요구사항**: 키(m, 실수)와 몸무게(kg, 실수)를 입력받아 체질량지수 `몸무게 ÷ (키 × 키)` 를 소수점 아래 둘째 자리까지 출력합니다.
- **입력**: 한 줄에 실수 두 개 `키 몸무게` 가 공백으로 구분되어 주어집니다. (키는 0보다 큼, 소수점 없는 형태로 올 수도 있음)
- **출력**: 체질량지수를 소수점 아래 둘째 자리까지 한 줄에 출력합니다.
- **예제**: `1.75 70` → `22.86` / `1.6 51.2` → `20.00`
- **셀프체크**: 두 값 모두 `float` 으로 받았는가? `w / (h * h)` 처럼 분모를 괄호로 묶었는가(괄호가 없으면 `w / h * h` 가 되어 `w` 만 남는다)? 결과가 딱 20이어도 `20.00` 으로 두 자리를 채우는가?

```runner
@@SOLUTION
h, w = input().split()
h = float(h)
w = float(w)
bmi = w / (h * h)
print(f'{bmi:.2f}')
@@TESTS
--IN
1.75 70
--OUT
22.86
--IN
1.6 51.2
--OUT
20.00
--IN
1.8 90
--OUT
27.78
@@EXPL
(1) 접근·핵심 아이디어

- 공식 "몸무게 ÷ (키 × 키)"를 그대로 옮깁니다. 분모가 곱셈이므로 먼저 계산되도록 괄호로 묶어야 합니다.
- 결과는 긴 소수가 되므로 Ch01의 `.2f` 로 둘째 자리까지 고정해 출력합니다.

(2) 코드 단계별

- `h, w = input().split()` 뒤 `float(h)`, `float(w)` — 소수가 있으니 둘 다 실수로 바꿉니다. `70` 처럼 소수점이 없어도 `float` 이면 문제없습니다.
- `bmi = w / (h * h)` — `70 / (1.75 * 1.75) = 70 / 3.0625 = 22.857...`.
- `print(f'{bmi:.2f}')` — 셋째 자리에서 반올림해 `22.86`. `1.6 51.2` 는 `20.00`, `1.8 90` 은 `27.78`.

(3) 스스로 다시 짤 때 생각 순서

- "입력이 실수인가?" → 그렇다 → `float`.
- 공식의 분모가 여러 항이면 괄호로 묶어 나눗셈보다 먼저 계산되게 합니다.
- 출력 자릿수가 정해져 있으면 `.Nf`. `20.0` 이 아니라 `20.00` 이어야 합니다.
```

**5) 다섯 명의 키 합과 평균** · Medium

- **요구사항**: 다섯 명의 키(cm, 실수)를 한 줄에 입력받아 첫째 줄에 합, 둘째 줄에 평균을 각각 소수점 아래 첫째 자리까지 출력합니다.
- **입력**: 한 줄에 실수 다섯 개가 공백으로 구분되어 주어집니다. (소수점 없는 형태로 올 수도 있음)
- **출력**: 첫째 줄에 합, 둘째 줄에 평균을 소수점 아래 첫째 자리까지 출력합니다.
- **예제**: `160.5 172.3 158.0 181.2 165.0` → `837.0` / `167.4` (두 줄)
- **예제**: `170 170 170 170 170` → `850.0` / `170.0` (두 줄)
- **셀프체크**: 변수 다섯 개로 받아 모두 `float` 으로 바꿨는가? 합을 먼저 변수에 담고 그 변수를 5로 나눴는가? 나누는 수가 값의 개수 5인가? 두 줄 모두 `.1f` 를 적용했는가?

```runner
@@SOLUTION
a, b, c, d, e = input().split()
a = float(a)
b = float(b)
c = float(c)
d = float(d)
e = float(e)
total = a + b + c + d + e
avg = total / 5
print(f'{total:.1f}')
print(f'{avg:.1f}')
@@TESTS
--IN
160.5 172.3 158.0 181.2 165.0
--OUT
837.0
167.4
--IN
170 170 170 170 170
--OUT
850.0
170.0
--IN
150.1 150.2 150.3 150.4 150.5
--OUT
751.5
150.3
@@EXPL
(1) 접근·핵심 아이디어

- 합은 다섯 값을 모두 더한 것, 평균은 그 합을 개수 5로 나눈 것입니다. 합을 변수 `total` 에 먼저 담아 두면 평균을 구할 때도, 출력할 때도 다시 쓸 수 있습니다.
- 실수를 여러 번 더하면 `836.9999999` 같은 작은 오차가 생길 수 있습니다. `.1f` 로 자릿수를 고정하면 이런 오차가 감춰져 `837.0` 으로 깔끔하게 나옵니다.

(2) 코드 단계별

- `a, b, c, d, e = input().split()` — 다섯 조각을 다섯 변수에 받습니다. 값 개수와 변수 개수가 같아야 합니다.
- 다섯 변수를 각각 `float` 으로 바꿉니다. `170` 처럼 소수점이 없어도 괜찮습니다.
- `total = a + b + c + d + e` → `837.0`. `avg = total / 5` → `167.4`.
- `print(f'{total:.1f}')`, `print(f'{avg:.1f}')` — 두 줄 모두 첫째 자리까지. 모두 같은 값 `170` 이면 합 `850.0`, 평균 `170.0`.

(3) 스스로 다시 짤 때 생각 순서

- "값이 몇 개?" → 다섯 → 변수 다섯, 변환 다섯 번.
- 합 → 평균 순서로 변수에 담습니다. 나누는 수는 개수 5.
- 출력 형식(`.1f`)을 두 줄에 모두 적용했는지 확인합니다.
```

**6) 정육면체 부피와 겉넓이** · Medium

- **요구사항**: 정육면체 한 변의 길이(정수)를 입력받아 첫째 줄에 부피(한 변의 세제곱), 둘째 줄에 겉넓이(한 변의 제곱 × 6)를 출력합니다. 거듭제곱은 `**` 연산자를 씁니다(`a ** 3` 은 `a * a * a`).
- **입력**: 1 이상 100 이하의 정수 하나가 한 줄에 주어집니다.
- **출력**: 첫째 줄에 부피, 둘째 줄에 겉넓이를 출력합니다.
- **예제**: `3` → `27` / `54` (두 줄)
- **예제**: `1` → `1` / `6` (두 줄)
- **셀프체크**: `a ** 3` 과 `6 * a ** 2` 를 썼는가? `**` 는 `*` 보다 먼저 계산되므로 `6 * a ** 2` 는 `6 * (a * a)` 이다. `(6 * a) ** 2` 로 잘못 묶지 않았는가? 정수 입력이므로 결과에 `.0` 이 붙지 않아야 합니다.

```runner
`**` 는 아직 정식으로 배우지 않은 거듭제곱 연산자로, `a ** 3` 은 `a * a * a` 와 같습니다.

(1) 접근·핵심 아이디어

- 정육면체의 부피는 한 변을 세 번 곱한 값, 겉넓이는 정사각형 면(한 변의 제곱) 여섯 개의 합입니다.
- 같은 수를 여러 번 곱할 때는 `**` 로 짧게 씁니다. `**` 는 `*` 보다 먼저 계산되므로 `6 * a ** 2` 는 "제곱을 먼저, 그다음 6배"입니다.

(2) 코드 단계별

- `a = int(input())` — 한 변의 길이를 정수로 받습니다.
- `print(a ** 3)` — `3 ** 3 = 27`, `1 ** 3 = 1`, `10 ** 3 = 1000`.
- `print(6 * a ** 2)` — `3 ** 2 = 9` 를 먼저 구한 뒤 `6 * 9 = 54`. `1` 이면 `6`, `10` 이면 `600`.
- 정수끼리의 `**` 결과는 정수이므로 `.0` 이 붙지 않습니다.

(3) 스스로 다시 짤 때 생각 순서

- "같은 수를 몇 번 곱하나?" → 세제곱은 `** 3`, 제곱은 `** 2`.
- 곱셈과 거듭제곱이 섞이면 거듭제곱이 먼저라는 순서를 확인합니다. 헷갈리면 `6 * (a ** 2)` 처럼 괄호를 써도 됩니다.
- 한 변이 `1` 인 가장 작은 경우에 부피 `1`, 겉넓이 `6` 이 나오는지 검산합니다.
```

**7) 괄호가 바꾸는 결과** · Medium

- **요구사항**: 세 정수 `a b c` 를 입력받아 세 가지 식의 값을 한 줄씩 출력합니다. 첫째 줄 `(a + b) * c`, 둘째 줄 `a + b * c`, 셋째 줄 `a - (b - c)`.
- **입력**: 한 줄에 세 정수 `a b c` 가 공백으로 구분되어 주어집니다.
- **출력**: 세 식의 값을 순서대로 한 줄씩 출력합니다.
- **예제**: `2 3 4` → `20` / `14` / `3` (세 줄)
- **예제**: `1 1 1` → `2` / `2` / `1` (세 줄)
- **셀프체크**: 첫째 줄과 둘째 줄이 다른 이유(괄호 유무)를 설명할 수 있는가? 셋째 줄 `a - (b - c)` 는 `a - b - c` 와 다르다(`2 - (3 - 4) = 3`, `2 - 3 - 4 = -5`). 괄호를 정확히 옮겼는가?

```runner
@@SOLUTION
a, b, c = input().split()
a = int(a)
b = int(b)
c = int(c)
print((a + b) * c)
print(a + b * c)
print(a - (b - c))
@@TESTS

--OUT

--IN

--OUT

--IN

--OUT

@@EXPL
(1) 접근·핵심 아이디어

- 곱셈은 덧셈보다 먼저 계산됩니다. `a + b * c` 는 `b * c` 가 먼저이고, `(a + b) * c` 는 괄호 안 덧셈이 먼저입니다. 같은 세 수라도 괄호에 따라 값이 달라집니다.
- 뺄셈도 마찬가지입니다. `a - (b - c)` 는 괄호 안을 먼저 계산하므로 왼쪽부터 차례로 빼는 `a - b - c` 와 다릅니다.

(2) 코드 단계별

- `a, b, c = input().split()` 뒤 각각 `int` — 세 정수를 받습니다.
- `print((a + b) * c)` — `(2 + 3) * 4 = 20`. 바깥 괄호는 `print` 의 괄호, 안쪽 괄호는 계산 순서용입니다.
- `print(a + b * c)` — `2 + 3 * 4 = 2 + 12 = 14`.
- `print(a - (b - c))` — `2 - (3 - 4) = 2 - (-1) = 3`. `0 5 2` 이면 `0 - 3 = -3` 으로 음수가 나옵니다.

(3) 스스로 다시 짤 때 생각 순서

- 식을 옮길 때 "무엇이 먼저 계산되어야 하나?" 를 정하고, 먼저 계산할 부분을 괄호로 묶습니다.
- 곱셈·나눗셈이 덧셈·뺄셈보다 먼저라는 규칙을 기억하되, 헷갈리면 괄호를 더 쓰는 편이 안전합니다.
- `1 1 1` 처럼 값이 같으면 첫째·둘째 줄이 우연히 같아질 수 있으니 `2 3 4` 같은 예제로 차이를 확인합니다.
```

**8) 동전 최소 개수** · Hard

- **요구사항**: 거스름돈(10의 배수)을 입력받아 500원, 100원, 10원 동전으로 거슬러 줄 때 각 동전의 최소 개수를 출력합니다. 큰 동전부터 최대한 많이 쓰면 개수가 최소가 됩니다. 조건문과 반복문 없이 `//` 와 `%` 만으로 풉니다.
- **입력**: 0 이상 100000 이하이며 10의 배수인 정수 하나가 한 줄에 주어집니다.
- **출력**: 500원 개수, 100원 개수, 10원 개수를 공백으로 구분해 한 줄에 출력합니다.
- **예제**: `1730` → `3 2 3` / `990` → `1 4 9`
- **셀프체크**: 500원 개수는 `n // 500`, 그다음 남은 돈은 `n % 500` 입니다. 남은 돈으로 100원 개수와 나머지를 구하고, 마지막 남은 돈으로 10원 개수를 구합니다. 매 단계 "남은 돈"을 변수에 다시 담았는가? `0` 이면 `0 0 0`, `500` 이면 `1 0 0` 인가?

```runner
@@SOLUTION

c10 = n // 10

(1) 접근·핵심 아이디어

- 동전 개수를 최소로 하려면 큰 동전부터 최대한 많이 씁니다. "최대한 몇 개"는 몫 `//`, "그러고 남은 돈"은 나머지 `%` 입니다.
- 이 과정을 500 → 100 → 10 순서로 세 번 반복합니다. 반복문 없이도 같은 두 줄을 세 번 쓰면 됩니다. 핵심은 매 단계 남은 돈을 변수 `n` 에 다시 담아(Ch01 값 변경) 다음 단계가 그 값을 쓰게 하는 것입니다.

(2) 코드 단계별

- `n = int(input())` — 거스름돈 `1730`.
- `c500 = n // 500` → `3`. `n = n % 500` → 남은 돈 `230`.
- `c100 = n // 100` → `2`. `n = n % 100` → 남은 돈 `30`.
- `c10 = n // 10` → `3`. 10의 배수이므로 더 남는 돈은 없습니다.
- `print(c500, c100, c10)` → `3 2 3`. `990` 은 `1`, 남은 `490` → `4`, 남은 `90` → `9`. `0` 은 모든 단계가 `0`, `500` 은 `1 0 0`.

(3) 스스로 다시 짤 때 생각 순서

- 동전을 큰 것부터 나열하고, 각 동전마다 "개수 = 남은 돈 // 동전", "남은 돈 = 남은 돈 % 동전" 두 줄을 씁니다.
- 남은 돈을 새 변수가 아니라 같은 `n` 에 덮어써야 다음 단계가 이어집니다. 원래 `n` 으로 계속 계산하면 개수가 중복됩니다.
- 경계값 `0`(모두 0)과 `500`(첫 동전 하나로 끝)을 손으로 검산합니다.
```
