> 개요: 이 챕터에서는 프로그램이 사용자로부터 값을 받아오는 "입력"을 배운다. 정수·실수·문자열을 어떻게 읽고, 한 줄에 여러 값이 있을 때나 여러 줄에 걸쳐 있을 때 어떻게 나눠 받는지 익힌다.

## L1. 정수 입력

**개념**

- 프로그램이 사용자가 키보드로 넣어 준 값을 받아오는 것을 "입력"이라고 한다.
- 파이썬에서는 `input()` 함수로 한 줄을 읽는다. 그런데 `input()`이 돌려주는 값은 항상 "문자열"이다.
- 문자열 `"3"`은 숫자 3이 아니라 글자 3이다. 그래서 계산에 쓰려면 정수로 바꿔야 한다.
- 문자열을 정수로 바꾸려면 `int(...)` 로 감싼다. 그래서 정수 하나를 입력받는 표준 형태는 `int(input())` 이다.

```python
n = int(input())   # 한 줄을 읽어서 정수로 변환해 n에 저장
print(n + 1)       # 이제 숫자처럼 계산할 수 있다
```

- 만약 `int(...)` 없이 그냥 `input()`으로 받으면 `+`는 덧셈이 아니라 문자열을 이어붙이는 동작이 된다. (예: `"3" + "4"`는 `"34"`)

- 자리 숫자를 뽑을 때 쓰는 연산 두 가지: `//`는 나눗셈의 몫(소수점 아래 버림), `%`는 나머지다. 예: `72 // 10`은 `7`(십의 자리), `72 % 10`은 `2`(일의 자리).

**그림으로 보기**

키보드로 친 것은 언제나 "글자"다. `int()` 는 그 글자를 "수"로 바꿔 주는 다리 역할을 한다.

```text
  you type:      7 2 [ENTER]

  input()   ->   "72"      # a string: two letters side by side
                  ^^
  int(...)  ->    72       # a number: can be added, multiplied

  "72" + 1   ->  error         # letters + number: python refuses
   72  + 1   ->  73            # number + number: real addition
  "72" * 3   ->  "727272"      # letters repeated, NOT 216
```

`//` 와 `%` 는 초등학교 나눗셈 그림 그대로다. 위에 남는 것이 몫, 아래에 남는 것이 나머지다.

```text
  72 divided by 10

          7        <- 72 // 10  : the quotient  -> the tens digit
        ┌──────
   10   │  72
        │  70      # 10 * 7
        ├──────
        │   2      <- 72 % 10   : the remainder -> the ones digit
```

**왜 이렇게 되는가**

- `input()` 이 왜 문자열을 주는가: 사용자가 친 줄이 수인지, 이름인지, 문장인지 파이썬은 알 수 없다. 그래서 **추측하지 않고** 친 그대로 글자로 돌려준다. 무엇으로 볼지는 사람이 `int()`·`float()` 로 정한다.
- `"72"` 와 `72` 는 생김새만 같을 뿐 완전히 다른 값이다. 앞의 것은 글자 두 개, 뒤의 것은 수 하나다. 그래서 `*` 도 뜻이 달라진다.
- `//` 로 십의 자리가 나오는 이유: 두 자리 수 `72` 는 `10 × 7 + 2` 로 쓸 수 있다. 10으로 나눈 몫이 곧 "10이 몇 묶음 들어 있는가"이므로 십의 자리 숫자와 같아진다.
- `%` 로 일의 자리가 나오는 이유도 같다. 10묶음을 모두 덜어내고 남은 것이 곧 일의 자리다. 세 자리 수라면 `% 10` 은 여전히 일의 자리, `// 100` 은 백의 자리가 된다.

**문제**

**1) 다음 수 출력** · Easy

- **요구사항**: 정수 하나를 입력받아, 그 수보다 1 큰 수를 출력하는 프로그램을 작성한다.
- **입력**: 정수 하나가 한 줄에 주어진다.
- **출력**: 입력한 수보다 1 큰 정수를 한 줄에 출력한다.
- **예제**: `7` → `8` / `-1` → `0`
- **셀프체크**: `input()` 결과를 `int()`로 바꿨는가? 음수 입력에서도 잘 되는가?

```runner
@@SOLUTION
n = int(input())
print(n + 1)
@@TESTS
--IN
7
--OUT
8
--IN
-1
--OUT
0
--IN
100
--OUT
101
@@EXPL
접근: 한 줄로 들어온 값을 정수로 바꾼 뒤 1을 더해 출력한다.

- `input()`은 항상 문자열을 준다. `"7"`에 1을 더하려 하면 오류가 나거나 뜻이 달라지므로 먼저 숫자로 바꿔야 한다.
- `int(input())`으로 감싸 정수 `n`을 얻는다.
- `print(n + 1)`로 1 큰 수를 출력한다. 음수 `-1`도 정수라서 `-1 + 1 = 0`이 정상 계산된다.

다시 짤 때 순서: (1) 한 줄을 정수로 읽는다 → (2) 1을 더한 값을 만든다 → (3) 그 값을 출력한다.
```

- **입력**: 정수 하나가 한 줄에 주어진다.

- **셀프체크**: `int()`를 빠뜨리면 `"5" * 3`이 `"555"`가 된다. 결과가 숫자인지 확인.

```runner
@@SOLUTION

@@TESTS
--IN
5
--OUT
15
--IN
0
--OUT
0
--IN
-2
--OUT
-6
@@EXPL
접근: 정수로 바꾼 값에 3을 곱해 출력한다.

- 문자열 `"5"`에 `* 3`을 하면 `"555"`가 되어 뜻이 달라진다. 그래서 먼저 `int(input())`으로 숫자를 만든다.
- `print(n * 3)`으로 3배를 출력한다.
- `0`은 3배도 `0`, 음수 `-2`는 `-6`으로 그대로 계산된다.

```

**3) 십의 자리와 일의 자리** · Medium

- **요구사항**: 두 자리 정수 하나를 입력받아, 십의 자리 숫자와 일의 자리 숫자를 공백을 두고 출력한다.

- **출력**: 십의 자리 숫자와 일의 자리 숫자를 공백으로 구분해 한 줄에 출력한다.
- **예제**: `72` → `7 2` / `40` → `4 0`
- **셀프체크**: 몫(`//`)과 나머지(`%`)를 떠올려 보자. 입력을 반드시 정수로 바꾼 뒤 계산했는가?

```runner
@@SOLUTION

@@TESTS
--IN
72
--OUT
7 2
--IN
40
--OUT
4 0
--IN
19
--OUT

@@EXPL

- `72 // 10`은 `7`(십의 자리), `72 % 10`은 `2`(일의 자리)다.
- `print`에 값 두 개를 쉼표로 넘기면 자동으로 그 사이에 공백 하나가 들어간다. 그래서 `print(n // 10, n % 10)`이 `7 2`처럼 출력된다.

다시 짤 때 순서: (1) 정수로 읽는다 → (2) 십의 자리는 `// 10` → (3) 일의 자리는 `% 10` → (4) 두 값을 쉼표로 한 번에 출력한다.
```

## L2. 실수 입력

**개념**

- 소수점이 있는 수(예: 3.14, 0.5)를 "실수"라고 한다.
- 실수를 입력받으려면 정수 때의 `int` 대신 `float`을 쓴다. 즉 `float(input())`.
- `input()`은 여전히 문자열을 주므로, `float(...)`으로 감싸야 소수 계산을 할 수 있다.

```python
x = float(input())   # "3.5" 같은 줄을 실수 3.5로 변환
print(x * 2)         # 7.0
```

- 주의: `float`으로 받으면 정수를 넣어도 소수 형태가 된다. 예를 들어 입력이 `4`라도 `float`으로 받으면 값은 `4.0`이고, `print` 하면 `4.0`처럼 보일 수 있다.
- 안심: 실수 계산 결과에 `.0`이 붙어 `5.0`처럼 나오는 것은 오류가 아니라 정상이다. 실수형은 값이 딱 떨어져도 소수점을 함께 보여 줄 뿐, `5`와 크기가 같다.

**그림으로 보기**

같은 한 줄을 `int` 로 받느냐 `float` 으로 받느냐에 따라 결과가 이렇게 갈린다. **`float` 이 받아 주는 범위가 더 넓다.**

```text
  the line you type      int(input())        float(input())
  -------------------    ----------------    ----------------
  4                      4                   4.0
  4.2                    error               4.2
  -3                     -3                  -3.0
  0                      0                   0.0

  # int() only accepts digits (and a sign). A '.' stops it.
```

`float` 은 값이 딱 떨어져도 소수점 자리를 늘 데리고 다닌다. 자료형이 다를 뿐 크기는 같다.

```text
  4          ┌───────┐        4.0        ┌─────────┐
  as int     │   4   │        as float   │   4.0   │
             └───────┘                   └─────────┘
             # same size on the number line, different type
```

**왜 이렇게 되는가**

- `int('4.2')` 가 오류인 이유: `int()` 는 "글자로 적힌 **정수**"만 읽는다. 점을 만나는 순간 정수 표기가 아니라고 판단하고 멈춘다. 반올림이나 버림을 대신 해 주지 않는다.
- 헷갈리기 쉬운 대비: `int(4.2)`(따옴표 없음)는 이미 수인 값을 받아 소수점 아래를 버려 `4` 를 준다. **글자 `'4.2'` 와 수 `4.2` 는 다르다**는 것이 핵심이다.
- 그래서 소수점이 섞여 들어올 수 있는 입력은 무조건 `float(input())` 으로 받는 편이 안전하다. 정수만 들어오는 경우에도 `float` 은 오류 없이 받아 준다.
- `5.0` 처럼 `.0` 이 붙어 보이는 이유: 실수형은 "소수점을 가진 수"라는 사실 자체를 값의 일부로 갖고 있다. 그래서 딱 떨어져도 소수점 자리를 지우지 않고 그대로 보여 준다. 정수 모양으로 보이고 싶으면 출력 형식을 바꾸거나 정수로 계산해야 한다.

**문제**

**1) 반지름으로 지름 구하기** · Easy

- **출력**: 지름을 한 줄에 출력한다.
- **예제**: `2.5` → `5.0` / `1.0` → `2.0`
- **셀프체크**: `float()`로 받았는가? 결과에 `.0`이 붙는 형태를 예상했는가?

```runner
@@SOLUTION

@@TESTS

--IN

@@EXPL
접근: 반지름을 실수로 받아 2를 곱하면 지름이다.

- 실수 입력이므로 `int`가 아니라 `float(input())`으로 받는다. `"2.5"`가 실수 `2.5`가 된다.
- `print(r * 2)`로 2배를 출력한다.
- 실수끼리의 곱은 결과에 소수점이 붙는다. 그래서 `2.5 * 2`는 `5.0`, `1.0 * 2`는 `2.0`처럼 `.0`이 붙는 것이 정상이다.
```


## L3. 공백을 사이에 두고 입력

**개념**

- 한 줄에 값이 여러 개, 공백으로 나뉘어 들어오는 경우가 많다. 예: `3 5`.
- `input()`은 이 줄 전체를 문자열 `"3 5"`로 준다. 이걸 공백 기준으로 잘라야 한다.
- `.split()`은 문자열을 공백 기준으로 잘라 여러 조각의 리스트로 만든다. `"3 5".split()`는 `["3", "5"]`.
- 이렇게 나눈 값들을 각각의 변수에 한 번에 받을 수 있다: `a, b = input().split()`. 단, 이때 `a`, `b`는 아직 문자열이다.
- 숫자로 쓰려면 각각 `int`로 바꾼다. 자주 쓰는 형태는 다음과 같다.

```python
a, b = input().split()       # a="3", b="5" (문자열)
a = int(a)
b = int(b)
print(a + b)                 # 8
```

- 변수 개수와 입력값 개수가 다르면 오류가 난다. 값이 2개면 변수도 2개로 받아야 한다.

> 선행: `map`을 쓰면 더 짧게 쓸 수 있지만(예: `map(int, input().split())`) 아직 배우지 않았으니, 위처럼 하나씩 `int`로 바꾸는 방식을 쓴다.

**그림으로 보기**

한 줄이 두 값으로 갈라져 두 변수에 들어가기까지, 값은 **네 단계**를 거친다. 어느 단계까지가 아직 문자열인지 눈으로 확인해 두자.

```text
  you type:        3   5
                    ^ a space

  input()          "3 5"                  # ONE string, 3 letters
                     |
                     |  .split()  -> cut wherever there are spaces
                     v
                   ┌─────┬─────┐
                   │ "3" │ "5" │          # a list of 2 pieces
                   └─────┴─────┘
                      |     |
  a, b = ...          v     v
                      a     b             # still strings!
                      |     |
  a = int(a)          v     v
  b = int(b)          3     5             # now numbers, ready to add
```

조각의 개수와 변수의 개수는 반드시 같아야 한다. 다르면 그 줄에서 바로 오류가 난다.

```text
  "1 2 3".split()   ->  ["1", "2", "3"]        3 pieces

  a, b    = ...     ->  error       # 2 names for 3 pieces
  a, b, c = ...     ->  ok          # 3 names for 3 pieces
```

**손으로 따라가기**

입력 `10 -4` 로 합을 구하는 과정이다. 각 줄이 끝난 뒤 변수에 무엇이 들어 있는지, 그리고 그것이 **글자인지 수인지**를 함께 적는다.

| 단계 | 실행한 줄 | `a` | `b` | 자료형 |
|------|-----------|-----|-----|--------|
| 1 | `a, b = input().split()` | `"10"` | `"-4"` | 둘 다 문자열 |
| 2 | `a = int(a)` | `10` | `"-4"` | `a` 만 정수 |
| 3 | `b = int(b)` | `10` | `-4` | 둘 다 정수 |
| 4 | `print(a + b)` | `10` | `-4` | `10 + (-4) = 6` 출력 |

2단계에서 멈추고 `a + b` 를 했다면 정수와 문자열을 더하는 셈이라 오류가 난다. **모든 조각을 바꾼 뒤에** 계산한다.

**왜 이렇게 되는가**

- `.split()` 은 왜 공백 개수를 신경 쓰지 않는가: 인자 없이 쓴 `split()` 은 "공백이 몇 칸이든 한 덩어리 구분자로 보고, 줄 양 끝의 공백은 버린다"는 규칙으로 자른다. 그래서 `"  3   5 ".split()` 도 결과가 `["3", "5"]` 로 똑같다.
- 코딩테스트 입력에 공백이 두 칸 들어 있어도 이 방식이면 안전한 이유다.
- 조각이 문자열로 남는 이유: `split` 은 "자르는" 일만 한다. 자른 조각이 수인지 이름인지는 판단하지 않는다. 판단은 `int()` 를 부르는 사람의 몫이다.
- `a, b = ["3", "5"]` 처럼 여러 값을 여러 이름에 한 번에 나눠 담는 것은 Ch01 L8의 동시 대입과 같은 문법이다. 오른쪽 개수와 왼쪽 개수가 맞아야 한다는 규칙도 그대로다.

**문제**

**1) 두 수의 합** · Easy

- **출력**: 두 수의 합을 한 줄에 출력한다.
- **예제**: `3 5` → `8` / `10 -4` → `6`
- **셀프체크**: `split()`으로 나눈 뒤 각각 `int`로 바꿨는가? 두 값을 두 변수로 받았는가?

```runner
@@SOLUTION

@@TESTS

--OUT

--IN

- `input().split()`은 `"3 5"`를 공백 기준으로 잘라 `["3", "5"]`를 만든다. 이를 `a, b`에 한 번에 받는다. 이때 `a`, `b`는 아직 문자열이다.
```

## L4. 2개의 줄에 걸쳐 입력

**개념**

- 값이 한 줄이 아니라 여러 줄에 나뉘어 들어올 때가 있다. 예를 들어 첫 줄에 하나, 둘째 줄에 하나.
- `input()`은 한 번 호출할 때마다 딱 "한 줄"을 읽는다. 그래서 두 줄을 받으려면 `input()`을 두 번 부른다.

```python
a = int(input())   # 첫째 줄을 읽어 a에
b = int(input())   # 둘째 줄을 읽어 b에
print(a + b)
```

- 호출 순서대로 위에서 아래 줄을 차례로 읽는다는 점이 핵심이다.
- 줄마다 값이 하나씩이면 `split` 없이 바로 `int(input())`으로 받으면 된다.

**그림으로 보기**

입력은 위에서 아래로 쌓인 줄 더미이고, `input()` 은 그 더미에서 **맨 위 한 줄을 떼어 가는** 동작이다. 한 번 떼어 간 줄은 다시 읽히지 않는다.

```text
  input lines            what each call takes

  ┌──────────┐
  │ 4        │  <--  1st input()   ->  "4"   ->  a = 4
  ├──────────┤
  │ 9        │  <--  2nd input()   ->  "9"   ->  b = 9
  ├──────────┤
  │ 2        │       (3rd call not made: this line stays unread)
  └──────────┘
```

같은 두 값이라도 **한 줄에 있느냐 두 줄에 있느냐**에 따라 읽는 방법이 완전히 달라진다.

```text
  3 5          on ONE line    ->   a, b = input().split()
                                   # 1 call, then cut into 2

  3
  5            on TWO lines   ->   a = input()
                                   b = input()
                                   # 2 calls, no cutting needed
```

**왜 이렇게 되는가**

- `input()` 은 "지금까지 읽은 위치" 표시(커서)를 하나 갖고 있다. 호출될 때마다 그 위치에서 줄바꿈까지를 잘라 돌려주고, 커서를 다음 줄 맨 앞으로 옮긴다.
- 그래서 **호출 순서가 곧 줄 순서**다. 첫 호출이 첫째 줄, 두 번째 호출이 둘째 줄이다. 코드에서 `input()` 을 부른 차례와 문제의 줄 번호를 일대일로 맞추면 헷갈릴 일이 없다.
- 필요한 것보다 적게 부르면 남은 줄은 그냥 읽히지 않은 채 남는다(오류는 나지 않는다). 반대로 더 많이 부르면 읽을 줄이 없어 오류(EOFError)가 난다.
- 그래서 문제를 읽을 때 **"입력이 몇 줄인가"** 를 먼저 세는 것이 코드를 쓰기 전 첫 단계가 된다. 줄 수만큼 `input()` 이 있어야 한다.
- 줄 끝의 줄바꿈은 `input()` 이 떼어 내고 준다. 그래서 `"4\n"` 이 아니라 `"4"` 가 돌아오고, 바로 `int()` 로 바꿀 수 있다.

**문제**

**1) 두 줄의 합** · Easy

- **요구사항**: 첫째 줄과 둘째 줄에 각각 정수가 하나씩 주어진다. 두 수의 합을 출력한다.
- **입력**: 첫째 줄에 정수 하나, 둘째 줄에 정수 하나.
- **출력**: 두 수의 합을 한 줄에 출력한다.
- **예제**: `4`(줄1) `9`(줄2) → `13` / `-3`(줄1) `3`(줄2) → `0`
- **셀프체크**: `input()`을 두 번 불렀는가? 각각 `int`로 바꿨는가?

```runner
@@SOLUTION

@@TESTS
--IN
4
9
--OUT
13
--IN
-3
3
--OUT

--IN

--OUT

@@EXPL
접근: 두 줄에 하나씩 들어오므로 `input()`을 두 번 부른다.

- `input()`은 한 번 호출할 때마다 딱 한 줄을 읽는다. 첫 호출이 첫째 줄, 두 번째 호출이 둘째 줄을 읽는다.
- 각 줄을 `int(input())`으로 받아 `a`, `b`에 저장한다.
- `print(a + b)`로 합을 출력한다.

다시 짤 때 순서: (1) 첫 줄을 정수로 읽어 `a` → (2) 둘째 줄을 정수로 읽어 `b` → (3) 두 수를 더해 출력한다. 줄이 두 개면 `input()`도 두 번이라는 점을 기억한다.
```

**2) 두 줄의 차** · Easy

## L5. 문자, 문자열 입력

**개념**

- 숫자가 아니라 글자나 단어를 받을 때는 변환할 필요 없이 `input()` 결과를 그대로 쓴다. 이미 문자열이기 때문이다.
- "문자열"은 글자들이 이어진 값이고(예: `"apple"`), "문자"는 그중 한 글자를 뜻한다.

```python
s = input()        # 한 줄을 문자열 그대로 받는다
print(s)           # 받은 그대로 출력
```

- `input()`은 한 줄 전체를 읽되, 줄 끝의 줄바꿈은 빼고 준다. 그래서 `apple`을 넣으면 `s`는 `"apple"`.
- 문자열의 몇 번째 글자를 꺼내려면 대괄호와 번호(인덱스)를 쓴다. 번호는 0부터 시작한다: 첫 글자는 `s[0]`.

```python
s = input()        # 예: cat
print(s[0])        # c (첫 글자)
```

> 선행: 인덱스로 글자를 꺼내는 것은 뒤 챕터에서 더 자세히 다룬다. 여기서는 "첫 글자 = `s[0]`" 정도만 사용한다.

**그림으로 보기**

문자열은 글자가 한 칸씩 늘어선 줄이고, 각 칸에는 **0부터 시작하는 번호**가 붙어 있다.

```text
  s = 'apple'

  ┌───┬───┬───┬───┬───┐
  │ a │ p │ p │ l │ e │
  └───┴───┴───┴───┴───┘
    0   1   2   3   4        <- index (starts at 0, not 1)
    ^               ^
    s[0] = 'a'      s[4] = 'e'      # 5 letters -> last index is 4
```

숫자로 쓸 값과 글자로 쓸 값은 받는 방법이 다르다. 글자에는 `int()` 를 씌우면 안 된다.

```text
  typed line     s = input()        n = int(input())
  ------------   ----------------   ------------------
  cat            "cat"   ok         error
  7              "7"     ok         7       ok
                 # "7" here is a letter, not a number
```

**왜 이렇게 되는가**

- 인덱스가 1이 아니라 0에서 시작하는 이유: 번호를 "몇 번째"가 아니라 **"맨 앞에서 몇 칸 떨어져 있는가(거리)"** 로 읽으면 자연스럽다. 첫 글자는 0칸 떨어져 있으므로 0번이다.
- 이 규칙 덕분에 길이가 5인 문자열의 마지막 번호는 5가 아니라 **4** 가 된다. `s[5]` 를 쓰면 존재하지 않는 칸을 가리켜 오류(IndexError)가 난다. 뒤 챕터의 반복문에서 이 한 칸 차이가 가장 흔한 실수가 된다.
- 문자열에 `int()` 를 씌우면 안 되는 이유: `int()` 는 "수로 읽을 수 있는 글자"만 받는다. `'cat'` 은 수로 읽을 방법이 없어 그 자리에서 오류가 난다.
- 반대로 숫자 문제에서 `int()` 를 빠뜨리면 오류가 나지 않고 **조용히 틀린 답**이 나온다는 점이 더 위험하다(`"3" + "4"` 가 `"34"`). 그래서 값을 받을 때마다 "이 값은 계산에 쓸 것인가, 보여 줄 글자인가"를 먼저 정한다.

## L6. 특정 문자를 사이에 두고 입력

**개념**

- 값들이 공백이 아니라 다른 특정 문자로 나뉘어 들어올 때가 있다. 예를 들어 날짜 `2026-07-01`은 `-`로, 시간 `12:30`은 `:`로 구분된다.
- `.split()`을 그냥 쓰면 공백 기준으로 자른다. 다른 문자를 기준으로 자르려면 그 문자를 괄호 안에 넣는다: `.split("-")`, `.split(":")`.
- 자른 결과는 여전히 문자열 조각들이므로, 숫자로 쓰려면 각각 `int`로 바꾼다.

```python
a, b = input().split(":")    # "12:30" -> a="12", b="30"
a = int(a)
b = int(b)
print(a + b)                 # 42
```

- 구분자로 넣은 문자 자체는 결과에서 사라진다. `"12:30".split(":")`는 `["12", "30"]`이고 `:`는 남지 않는다.

**그림으로 보기**

괄호에 넣은 문자는 "여기서 자르라"는 가위 표시다. 자른 뒤 그 문자는 결과에서 사라진다.

```text
  "2026-07-01".split("-")

    2026   -   07   -   01
           ^        ^            # cut here; the '-' disappears

  ┌────────┬──────┬──────┐
  │ "2026" │ "07" │ "01" │       # 3 pieces, still strings
  └────────┴──────┴──────┘
      |       |      |
      v       v      v
     2026     7      1           # after int(): the leading 0 is gone
```

구분자를 무엇으로 주느냐에 따라 자르는 자리가 달라진다.

```text
  "12:30".split()      ->  ["12:30"]       # no space -> nothing to cut
  "12:30".split(":")   ->  ["12", "30"]
  "12 30".split(":")   ->  ["12 30"]       # no ':' -> nothing to cut
  "1--2".split("-")    ->  ["1", "", "2"]  # "" = an empty piece
```

**왜 이렇게 되는가**

- 인자 없는 `split()` 과 구분자를 준 `split('-')` 은 규칙이 다르다. 앞의 것은 "공백 덩어리 전체"를 하나의 구분자로 보고 양 끝 공백도 버린다. 뒤의 것은 **그 문자 하나하나가 정확히 경계**다.
- 그래서 구분자가 연달아 붙어 있으면 그 사이에 아무 글자도 없는 빈 조각 `''` 이 생긴다. `int('')` 은 오류이므로, 입력 형식이 정확하다고 문제에 적혀 있는지 확인하는 습관이 필요하다.
- `int('07')` 이 `7` 이 되는 이유: `'07'` 은 글자 두 개지만, **수로 읽으면 맨 앞의 0은 크기에 아무 기여를 하지 않는다.** 그래서 정수가 되는 순간 값은 7이고, 다시 출력하면 `07` 이 아니라 `7` 로 나온다.
- 자리 맞춤이 있는 `07` 모양을 그대로 유지해야 한다면 정수로 바꾸지 말고 문자열로 두면 된다. 계산이 필요하면 정수로, 모양이 중요하면 문자열로 — 목적에 따라 고른다.

**문제**


**3) 쉼표로 나눈 세 수 중 최댓값 위치는?** · Hard

- **요구사항**: `,`로 구분된 세 정수를 입력받아, 가장 큰 값을 출력한다.
- **입력**: `a,b,c` 형태로 세 정수가 쉼표로 구분되어 한 줄에 주어진다. (쉼표 앞뒤에 공백은 없다)
- **출력**: 세 수 중 가장 큰 값을 한 줄에 출력한다.
- **예제**: `3,9,5` → `9` / `-1,-4,-2` → `-1`
- **셀프체크**: `split(",")`로 세 조각을 얻고 각각 `int`로 바꾼다. 셋 중 최댓값 비교는 크기를 하나씩 견주면 된다. 음수만 있을 때도 맞는지 확인.

```runner
@@SOLUTION
a, b, c = input().split(",")
a = int(a)
b = int(b)
c = int(c)
biggest = a
if b > biggest:
    biggest = b
if c > biggest:
    biggest = c
print(biggest)
@@TESTS
--IN
3,9,5
--OUT
9
--IN
-1,-4,-2
--OUT
-1
--IN
7,7,2
--OUT
7
@@EXPL
접근: `,`로 세 값을 나눠 정수로 바꾼 뒤, 크기를 하나씩 견주며 최댓값을 갱신한다.

- `input().split(",")`으로 `"3,9,5"`를 `["3", "9", "5"]`로 나눠 `a, b, c`에 받고 각각 `int`로 바꾼다.
- 먼저 첫 값 `a`를 임시 최댓값 `biggest`로 둔다.
- `if b > biggest`이면 `biggest`를 `b`로 바꾸고, 다시 `if c > biggest`이면 `c`로 바꾼다. 이렇게 하나씩 견주면 셋 중 가장 큰 값이 남는다. 음수만 있는 `-1,-4,-2`에서도 가장 큰 `-1`이 잘 남는다.
- `print(biggest)`로 출력한다.

다시 짤 때 순서: (1) `split(",")`으로 세 값을 받아 정수로 바꾼다 → (2) 첫 값을 최댓값 후보로 잡는다 → (3) 나머지를 하나씩 비교해 더 크면 후보를 갱신한다 → (4) 최종 후보를 출력한다.
```
