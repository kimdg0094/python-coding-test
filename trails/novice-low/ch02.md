> 개요: 이 챕터에서는 프로그램이 사용자로부터 값을 받아오는 "입력"을 배운다. 정수·실수·문자열을 어떻게 읽고, 한 줄에 여러 값이 있을 때나 여러 줄에 걸쳐 있을 때 어떻게 나눠 받는지 익힌다.

## L1. 정수 입력

**개념**

- 프로그램이 사용자가 키보드로 넣어 준 값을 받아오는 것을 "입력"이라고 한다.
- 파이썬에서는 `input()` 함수로 한 줄을 읽는다. 그런데 `input()`이 돌려주는 값은 항상 "문자열"이다.
- 문자열 `"3"`은 숫자 3이 아니라 글자 3이다. 그래서 계산에 쓰려면 정수로 바꿔야 한다.
- 문자열을 정수로 바꾸려면 `int(...)` 로 감싼다. 그래서 정수 하나를 입력받는 표준 형태는 `int(input())` 이다.

```python
n = int(input())   # 한 줄을 읽어서 정수로 변환해 n에 저장
print(n + 1)       # 이제 숫자처럼 계산할 수 있다
```

- 만약 `int(...)` 없이 그냥 `input()`으로 받으면 `+`는 덧셈이 아니라 문자열을 이어붙이는 동작이 된다. (예: `"3" + "4"`는 `"34"`)

- 자리 숫자를 뽑을 때 쓰는 연산 두 가지: `//`는 나눗셈의 몫(소수점 아래 버림), `%`는 나머지다. 예: `72 // 10`은 `7`(십의 자리), `72 % 10`은 `2`(일의 자리).

**문제**

**1) 다음 수 출력** · Easy

- **요구사항**: 정수 하나를 입력받아, 그 수보다 1 큰 수를 출력하는 프로그램을 작성한다.
- **입력**: 정수 하나가 한 줄에 주어진다.
- **출력**: 입력한 수보다 1 큰 정수를 한 줄에 출력한다.
- **예제**: `7` → `8` / `-1` → `0`
- **셀프체크**: `input()` 결과를 `int()`로 바꿨는가? 음수 입력에서도 잘 되는가?

```runner
@@SOLUTION
n = int(input())
print(n + 1)
@@TESTS
--IN
7
--OUT
8
--IN
-1
--OUT
0
--IN
100
--OUT
101
@@EXPL
접근: 한 줄로 들어온 값을 정수로 바꾼 뒤 1을 더해 출력한다.

- `input()`은 항상 문자열을 준다. `"7"`에 1을 더하려 하면 오류가 나거나 뜻이 달라지므로 먼저 숫자로 바꿔야 한다.
- `int(input())`으로 감싸 정수 `n`을 얻는다.
- `print(n + 1)`로 1 큰 수를 출력한다. 음수 `-1`도 정수라서 `-1 + 1 = 0`이 정상 계산된다.

다시 짤 때 순서: (1) 한 줄을 정수로 읽는다 → (2) 1을 더한 값을 만든다 → (3) 그 값을 출력한다.
```

**2) 세 배 만들기** · Easy

- **요구사항**: 정수 하나를 입력받아, 그 수의 3배를 출력한다.
- **입력**: 정수 하나가 한 줄에 주어진다.
- **출력**: 입력한 수의 3배를 한 줄에 출력한다.
- **예제**: `5` → `15` / `0` → `0`
- **셀프체크**: `int()`를 빠뜨리면 `"5" * 3`이 `"555"`가 된다. 결과가 숫자인지 확인.

```runner
@@SOLUTION
n = int(input())
print(n * 3)
@@TESTS
--IN
5
--OUT
15
--IN
0
--OUT
0
--IN
-2
--OUT
-6
@@EXPL
접근: 정수로 바꾼 값에 3을 곱해 출력한다.

- 문자열 `"5"`에 `* 3`을 하면 `"555"`가 되어 뜻이 달라진다. 그래서 먼저 `int(input())`으로 숫자를 만든다.
- `print(n * 3)`으로 3배를 출력한다.
- `0`은 3배도 `0`, 음수 `-2`는 `-6`으로 그대로 계산된다.

다시 짤 때 순서: (1) 한 줄을 정수로 읽는다 → (2) 3을 곱한다 → (3) 출력한다. 곱셈 전에 반드시 정수 변환을 했는지 확인한다.
```

**3) 십의 자리와 일의 자리** · Medium

- **요구사항**: 두 자리 정수 하나를 입력받아, 십의 자리 숫자와 일의 자리 숫자를 공백을 두고 출력한다.
- **입력**: 10 이상 99 이하의 정수 하나가 주어진다.
- **출력**: 십의 자리 숫자와 일의 자리 숫자를 공백으로 구분해 한 줄에 출력한다.
- **예제**: `72` → `7 2` / `40` → `4 0`
- **셀프체크**: 몫(`//`)과 나머지(`%`)를 떠올려 보자. 입력을 반드시 정수로 바꾼 뒤 계산했는가?

```runner
@@SOLUTION
n = int(input())
print(n // 10, n % 10)
@@TESTS
--IN
72
--OUT
7 2
--IN
40
--OUT
4 0
--IN
19
--OUT
1 9
@@EXPL
접근: 두 자리 수를 10으로 나눈 몫이 십의 자리, 10으로 나눈 나머지가 일의 자리다.

- `72 // 10`은 `7`(십의 자리), `72 % 10`은 `2`(일의 자리)다.
- `print`에 값 두 개를 쉼표로 넘기면 자동으로 그 사이에 공백 하나가 들어간다. 그래서 `print(n // 10, n % 10)`이 `7 2`처럼 출력된다.
- `40`은 몫 `4`, 나머지 `0`이라 `4 0`이 된다.

다시 짤 때 순서: (1) 정수로 읽는다 → (2) 십의 자리는 `// 10` → (3) 일의 자리는 `% 10` → (4) 두 값을 쉼표로 한 번에 출력한다.
```

## L2. 실수 입력

**개념**

- 소수점이 있는 수(예: 3.14, 0.5)를 "실수"라고 한다.
- 실수를 입력받으려면 정수 때의 `int` 대신 `float`을 쓴다. 즉 `float(input())`.
- `input()`은 여전히 문자열을 주므로, `float(...)`으로 감싸야 소수 계산을 할 수 있다.

```python
x = float(input())   # "3.5" 같은 줄을 실수 3.5로 변환
print(x * 2)         # 7.0
```

- 주의: `float`으로 받으면 정수를 넣어도 소수 형태가 된다. 예를 들어 입력이 `4`라도 `float`으로 받으면 값은 `4.0`이고, `print` 하면 `4.0`처럼 보일 수 있다.
- 안심: 실수 계산 결과에 `.0`이 붙어 `5.0`처럼 나오는 것은 오류가 아니라 정상이다. 실수형은 값이 딱 떨어져도 소수점을 함께 보여 줄 뿐, `5`와 크기가 같다.

**문제**

**1) 반지름으로 지름 구하기** · Easy

- **요구사항**: 원의 반지름(실수)을 입력받아 지름(반지름의 2배)을 출력한다.
- **입력**: 실수 하나가 한 줄에 주어진다.
- **출력**: 지름을 한 줄에 출력한다.
- **예제**: `2.5` → `5.0` / `1.0` → `2.0`
- **셀프체크**: `float()`로 받았는가? 결과에 `.0`이 붙는 형태를 예상했는가?

```runner
@@SOLUTION
r = float(input())
print(r * 2)
@@TESTS
--IN
2.5
--OUT
5.0
--IN
1.0
--OUT
2.0
--IN
3.5
--OUT
7.0
@@EXPL
접근: 반지름을 실수로 받아 2를 곱하면 지름이다.

- 실수 입력이므로 `int`가 아니라 `float(input())`으로 받는다. `"2.5"`가 실수 `2.5`가 된다.
- `print(r * 2)`로 2배를 출력한다.
- 실수끼리의 곱은 결과에 소수점이 붙는다. 그래서 `2.5 * 2`는 `5.0`, `1.0 * 2`는 `2.0`처럼 `.0`이 붙는 것이 정상이다.

다시 짤 때 순서: (1) `float`으로 한 줄을 읽는다 → (2) 2를 곱한다 → (3) 출력한다. 결과에 `.0`이 붙는 형태를 미리 예상해 둔다.
```

## L3. 공백을 사이에 두고 입력

**개념**

- 한 줄에 값이 여러 개, 공백으로 나뉘어 들어오는 경우가 많다. 예: `3 5`.
- `input()`은 이 줄 전체를 문자열 `"3 5"`로 준다. 이걸 공백 기준으로 잘라야 한다.
- `.split()`은 문자열을 공백 기준으로 잘라 여러 조각의 리스트로 만든다. `"3 5".split()`는 `["3", "5"]`.
- 이렇게 나눈 값들을 각각의 변수에 한 번에 받을 수 있다: `a, b = input().split()`. 단, 이때 `a`, `b`는 아직 문자열이다.
- 숫자로 쓰려면 각각 `int`로 바꾼다. 자주 쓰는 형태는 다음과 같다.

```python
a, b = input().split()       # a="3", b="5" (문자열)
a = int(a)
b = int(b)
print(a + b)                 # 8
```

- 변수 개수와 입력값 개수가 다르면 오류가 난다. 값이 2개면 변수도 2개로 받아야 한다.

> 선행: `map`을 쓰면 더 짧게 쓸 수 있지만(예: `map(int, input().split())`) 아직 배우지 않았으니, 위처럼 하나씩 `int`로 바꾸는 방식을 쓴다.

**문제**

**1) 두 수의 합** · Easy

- **요구사항**: 한 줄에 공백으로 구분된 두 정수를 입력받아 그 합을 출력한다.
- **입력**: 두 정수가 공백을 사이에 두고 한 줄에 주어진다.
- **출력**: 두 수의 합을 한 줄에 출력한다.
- **예제**: `3 5` → `8` / `10 -4` → `6`
- **셀프체크**: `split()`으로 나눈 뒤 각각 `int`로 바꿨는가? 두 값을 두 변수로 받았는가?

```runner
@@SOLUTION
a, b = input().split()
a = int(a)
b = int(b)
print(a + b)
@@TESTS
--IN
3 5
--OUT
8
--IN
10 -4
--OUT
6
--IN
100 200
--OUT
300
@@EXPL
접근: 한 줄에 공백으로 붙어 온 두 값을 나눠 각각 정수로 바꾼 뒤 더한다.

- `input().split()`은 `"3 5"`를 공백 기준으로 잘라 `["3", "5"]`를 만든다. 이를 `a, b`에 한 번에 받는다. 이때 `a`, `b`는 아직 문자열이다.
- 각각 `int(a)`, `int(b)`로 정수로 바꾼다.
- `print(a + b)`로 합을 출력한다. 음수 `-4`도 문자열에서 정수로 잘 바뀐다.

다시 짤 때 순서: (1) `split()`으로 두 조각을 두 변수에 받는다 → (2) 두 변수를 각각 `int`로 바꾼다 → (3) 더해서 출력한다.
```

**2) 두 수의 곱** · Easy

- **입력**: 두 정수가 공백으로 구분되어 주어진다.
- **출력**: 두 수의 곱을 한 줄에 출력한다.
- **예제**: `4 6` → `24` / `7 0` → `0`
- **셀프체크**: 문자열끼리 곱하려 하지 않았는지 확인. 반드시 정수 변환 후 곱한다.

```runner
@@SOLUTION

@@TESTS
--IN
4 6
--OUT
24
--IN
7 0
--OUT

- 문자열끼리 `*`를 하면 곱셈이 아니라 반복 동작이 되므로, 먼저 `int(a)`, `int(b)`로 정수로 바꾼다.
- `print(a * b)`로 곱을 출력한다. 한쪽이 `0`이면 곱도 `0`, 음수가 섞이면 부호도 그대로 반영된다.

```

**3) 순서 바꿔 출력** · Medium

- **요구사항**: 한 줄에 공백으로 구분된 세 정수를 입력받아, 순서를 거꾸로 하여 공백으로 구분해 출력한다.
- **입력**: 세 정수가 공백으로 구분되어 한 줄에 주어진다.
- **출력**: 입력의 역순으로 세 정수를 공백을 두고 한 줄에 출력한다.
- **예제**: `1 2 3` → `3 2 1` / `10 20 30` → `30 20 10`
- **셀프체크**: 변수 3개로 받았는가? 출력에서도 값 사이에 공백 하나만 들어가는지 확인.

```runner
@@SOLUTION
a, b, c = input().split()
a = int(a)
b = int(b)
c = int(c)
print(c, b, a)
@@TESTS
--IN
1 2 3
--OUT
3 2 1
--IN
10 20 30
--OUT
30 20 10
--IN
5 5 9
--OUT
9 5 5
@@EXPL
접근: 세 값을 세 변수로 받고, 출력 순서만 거꾸로 놓는다.

- `input().split()`은 `"1 2 3"`을 세 조각으로 나눈다. 값이 3개이므로 변수도 `a, b, c` 3개로 받아야 한다.
- 각각 `int`로 바꾼다(출력 순서만 바꾸므로 사실 정수 변환은 없어도 되지만, 숫자로 다룬다는 습관을 위해 바꿔 둔다).
- `print(c, b, a)`처럼 순서를 뒤집어 넘기면 값 사이에 공백 하나가 들어가 `3 2 1`이 된다.

다시 짤 때 순서: (1) `split()`으로 세 변수에 받는다 → (2) 각각 `int` → (3) 마지막·가운데·처음 순서로 쉼표로 넘겨 출력한다.
```

## L4. 2개의 줄에 걸쳐 입력

**개념**

- 값이 한 줄이 아니라 여러 줄에 나뉘어 들어올 때가 있다. 예를 들어 첫 줄에 하나, 둘째 줄에 하나.

## L5. 문자, 문자열 입력

**개념**

- 숫자가 아니라 글자나 단어를 받을 때는 변환할 필요 없이 `input()` 결과를 그대로 쓴다. 이미 문자열이기 때문이다.
- "문자열"은 글자들이 이어진 값이고(예: `"apple"`), "문자"는 그중 한 글자를 뜻한다.

```python
s = input()        # 한 줄을 문자열 그대로 받는다
print(s)           # 받은 그대로 출력
```

- `input()`은 한 줄 전체를 읽되, 줄 끝의 줄바꿈은 빼고 준다. 그래서 `apple`을 넣으면 `s`는 `"apple"`.
- 문자열의 몇 번째 글자를 꺼내려면 대괄호와 번호(인덱스)를 쓴다. 번호는 0부터 시작한다: 첫 글자는 `s[0]`.

```python
s = input()        # 예: cat
print(s[0])        # c (첫 글자)
```

> 선행: 인덱스로 글자를 꺼내는 것은 뒤 챕터에서 더 자세히 다룬다. 여기서는 "첫 글자 = `s[0]`" 정도만 사용한다.

**문제**

- **입력**: 공백이 없는 문자열 하나가 한 줄에 주어진다.
- **출력**: 입력받은 문자열을 그대로 한 줄에 출력한다.
- **예제**: `hello` → `hello` / `Codetree` → `Codetree`
- **셀프체크**: 문자열은 변환이 필요 없다. `int`나 `float`으로 감싸지 않았는지 확인.

```runner
@@SOLUTION

@@TESTS

--OUT

--IN

--OUT

--IN

--OUT

@@EXPL
접근: 글자는 이미 문자열이므로 변환 없이 받은 그대로 출력한다.

- `input()`은 한 줄을 문자열로 준다. 글자나 단어를 다룰 때는 `int`나 `float`으로 감싸면 안 된다.
- 받은 문자열을 `s`에 담고 `print(s)`로 그대로 출력한다.
- 줄 끝의 줄바꿈은 `input()`이 이미 떼어 주므로 신경 쓰지 않아도 된다.

다시 짤 때 순서: (1) `input()`으로 한 줄을 문자열로 받는다 → (2) 변환 없이 그대로 출력한다.
```

## L6. 특정 문자를 사이에 두고 입력

**개념**

- 값들이 공백이 아니라 다른 특정 문자로 나뉘어 들어올 때가 있다. 예를 들어 날짜 `2026-07-01`은 `-`로, 시간 `12:30`은 `:`로 구분된다.
- `.split()`을 그냥 쓰면 공백 기준으로 자른다. 다른 문자를 기준으로 자르려면 그 문자를 괄호 안에 넣는다: `.split("-")`, `.split(":")`.
- 자른 결과는 여전히 문자열 조각들이므로, 숫자로 쓰려면 각각 `int`로 바꾼다.

```python
a, b = input().split(":")    # "12:30" -> a="12", b="30"
a = int(a)
b = int(b)
print(a + b)                 # 42
```

- 구분자로 넣은 문자 자체는 결과에서 사라진다. `"12:30".split(":")`는 `["12", "30"]`이고 `:`는 남지 않는다.

**문제**

**1) 콜론으로 나눈 두 수의 합** · Easy

- **요구사항**: `:`로 구분된 두 정수를 입력받아 합을 출력한다.
- **입력**: `a:b` 형태로 두 정수가 콜론을 사이에 두고 한 줄에 주어진다.
- **출력**: 두 수의 합을 한 줄에 출력한다.
- **예제**: `3:5` → `8` / `12:30` → `42`
- **셀프체크**: `split(":")`로 나눴는가? 각 조각을 `int`로 바꿨는가?

```runner
@@SOLUTION
a, b = input().split(":")
a = int(a)
b = int(b)
print(a + b)
@@TESTS
--IN
3:5
--OUT
8
--IN
12:30
--OUT
42
--IN
0:0
--OUT
0
@@EXPL
접근: 구분자가 공백이 아니라 `:`이므로 `split(":")`으로 나눈다.

- `.split()`을 그냥 쓰면 공백 기준이다. `:`로 나누려면 그 문자를 괄호에 넣어 `input().split(":")`으로 쓴다. `"3:5"`가 `["3", "5"]`가 된다.
- 나눈 조각은 여전히 문자열이므로 각각 `int(a)`, `int(b)`로 바꾼다.
- `print(a + b)`로 합을 출력한다. 구분자 `:`는 결과에서 사라지므로 계산에 끼어들지 않는다.

다시 짤 때 순서: (1) `split(":")`으로 두 조각을 받는다 → (2) 각각 `int` → (3) 더해서 출력한다.
```

**2) 날짜 분리** · Medium

- **출력**: 연, 월, 일을 공백으로 구분해 한 줄에 출력한다.
- **예제**: `2026-07-01` → `2026 7 1` / `1999-12-25` → `1999 12 25`
- **셀프체크**: `07`을 `int`로 바꾸면 `7`이 된다(앞의 0이 사라짐). 예제 출력이 `7`, `1`인 이유를 확인.

```runner
- 각각 `int`로 바꾼다. 이때 `"07"`은 `7`, `"01"`은 `1`이 된다(앞의 0이 사라짐). 그래서 예제 출력이 `7`, `1`이다.

```

**3) 쉼표로 나눈 세 수 중 최댓값 위치는?** · Hard

- **출력**: 세 수 중 가장 큰 값을 한 줄에 출력한다.

```runner
- `input().split(",")`으로 `"3,9,5"`를 `["3", "9", "5"]`로 나눠 `a, b, c`에 받고 각각 `int`로 바꾼다.

- `if b > biggest`이면 `biggest`를 `b`로 바꾸고, 다시 `if c > biggest`이면 `c`로 바꾼다. 이렇게 하나씩 견주면 셋 중 가장 큰 값이 남는다. 음수만 있는 `-1,-4,-2`에서도 가장 큰 `-1`이 잘 남는다.
- `print(biggest)`로 출력한다.

다시 짤 때 순서: (1) `split(",")`으로 세 값을 받아 정수로 바꾼다 → (2) 첫 값을 최댓값 후보로 잡는다 → (3) 나머지를 하나씩 비교해 더 크면 후보를 갱신한다 → (4) 최종 후보를 출력한다.
```
