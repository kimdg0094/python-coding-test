## L9. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch01(출력)의 핵심을 **반복 훈련**하고, 코딩테스트 단골 유형으로 **확장**하는 연습 세트다. 입력은 여전히 없고, 값은 코드 안에 직접 정한다.
- **반복 훈련 개념**: 아래 다섯 가지를 소재만 바꿔 여러 번 다시 쓴다.

- 따옴표 선택 — 문장 안에 `"` 가 있으면 `'...'` 로, `'` 가 있으면 `"..."` 로 감싼다.
- 쉼표 나열과 문자열 잇기 — `print(a, b)` 는 사이에 공백 한 칸, `print(a + b)` 는 빈틈없이 붙인다(`+` 는 문자열끼리만).
- 소수점 자릿수 — `print(f'{x:.2f}')` 는 소수점 아래 2자리로 반올림해 보여 준다.
- 값 변경 — `x += 1`, `x -= 3`, `x *= 2` 는 "지금 값으로 계산한 결과를 다시 담기"다.
- 동시 대입 — `a, b = 1, 2`, `a, b = b, a`(교환), `x = y = 0`(같은 값 넣기). 오른쪽이 모두 먼저 계산된다.

- **코딩테스트 출제 맵**: 백준 「단계별로 풀어보기」의 '입출력과 사칙연산' 단계(정해진 문장·그림을 한 글자도 틀리지 않게 출력, 실수 형식 출력)와 solved.ac CLASS 1의 출력 문제들이 이 챕터 수준이다. 뒤 단계의 `Case #k:` 형식 출력도 지금 문법으로 미리 연습한다.
- **문제 구성표**:

| # | 문제 | 난이도 | 반복 개념 | 유형 |
|---|------|--------|-----------|------|
| 1 | 서점 안내문 출력 | Easy | 기본 출력·따옴표 선택 | 반복 훈련 |
| 2 | 상품 정보 카드 | Easy | 변수·자료형·라벨 출력 | 반복 훈련 |
| 3 | 글자 덧셈과 숫자 덧셈 | Easy | 자료형에 따라 달라지는 `+` | 반복 훈련 |
| 4 | 같은 값, 다른 자릿수 | Easy | `.Nf` 자릿수 지정 | 반복 훈련 |
| 5 | 용돈 잔액 계산 | Easy | `+=`·`-=` 값 변경 | 반복 훈련 |
| 6 | 케이스 번호 붙여 출력 | Easy | 변수 덮어쓰기·라벨 출력 | 유형 확장 (백준 '반복문' 단계의 `Case #k:` 형식 출력 스타일) |
| 7 | 같은 값을 두 변수에 | Medium | `x = y = 값`·복사 독립성 | 반복 훈련 |
| 8 | 0.1 더하기 0.2의 정체 | Medium | 실수 오차·`.Nf` | 유형 확장 (백준 '입출력과 사칙연산' 단계의 실수 출력 스타일) |
| 9 | 날짜와 시각 구분자 출력 | Medium | `sep` 로 구분 문자 바꾸기 | 유형 확장 (백준 '입출력과 사칙연산' 단계의 형식 출력 스타일) |
| 10 | 로봇 명함 출력 | Medium | 변수 재사용·따옴표·공백 맞추기 | 유형 확장 (백준 '입출력과 사칙연산' 단계의 고정 그림 출력 스타일) |
| 11 | 장바구니 영수증 | Hard | 변수 계산·라벨·`.Nf` 결합 | 유형 확장 (백준 '입출력과 사칙연산' 단계의 계산·형식 출력 스타일) |
| 12 | 동시 대입 두 단계 추적 | Hard | 동시 대입·옛 값으로 계산 | 반복 훈련 |

> 선행: 9번에서 쓰는 `print(a, b, sep='-')` 는 쉼표 자리에 들어가는 공백을 다른 문자(`-`)로 바꾸는 방법이다. 아직 정식으로 배우지 않았으니 "쉼표 사이 공백을 바꾸는 옵션" 정도로만 알고 쓰면 된다.

**문제**

**1) 서점 안내문 출력** · Easy

- **요구사항**: 서점 입구에 붙일 안내문 세 줄을 화면에 그대로 출력하라. 첫째 줄에 큰따옴표가 들어 있다는 점에 주의한다.
- **입력**: 없음
- **출력**: 아래 세 줄을 순서대로, 기호·공백·대소문자까지 똑같이
- **예제**: (입력 없음) → 
```
Welcome to "Book Corner"
Open 10:00 - 20:00
Closed on Monday
```
- **셀프체크**: 큰따옴표가 들어 있는 줄을 작은따옴표로 감쌌는가? `10:00 - 20:00` 의 하이픈 앞뒤 공백이 한 칸씩인가? 세 문장이 각각 다른 줄에 나오는가?

```runner
@@SOLUTION
print('Welcome to "Book Corner"')
print('Open 10:00 - 20:00')
print('Closed on Monday')
@@TESTS
--IN

--OUT
Welcome to "Book Corner"
Open 10:00 - 20:00
Closed on Monday
--IN

--OUT
Welcome to "Book Corner"
Open 10:00 - 20:00
Closed on Monday
@@EXPL
(1) 접근·핵심 아이디어

- 정해진 문장을 그대로 보여 주는 문제이므로 줄 수만큼 `print` 를 쓴다.
- 첫째 줄 안에 큰따옴표 `"` 가 들어 있다. 문자열을 큰따옴표로 감싸면 파이썬이 `"Welcome to "` 에서 문자열이 끝났다고 착각해 오류가 난다. 그래서 바깥은 반대 종류인 작은따옴표로 감싼다.
- 나머지 두 줄은 따옴표가 없으니 어느 쪽으로 감싸도 된다.

(2) 코드 단계별

- `print('Welcome to "Book Corner"')` — 바깥은 `'`, 안쪽 `"` 는 그냥 글자로 취급된다.
- `print('Open 10:00 - 20:00')` — 콜론과 하이픈은 문자열 안에서 특별한 뜻이 없다. 공백 개수만 예시와 맞춘다.
- `print('Closed on Monday')` — 셋째 줄. `print` 가 줄을 자동으로 바꾸므로 세 줄이 된다.

(3) 스스로 다시 짤 때 생각 순서

- "몇 줄?" → 세 줄 → `print` 세 번.
- "각 줄 안에 따옴표가 있나?" → 첫째 줄에 `"` 가 있으니 그 줄만 `'...'` 로 감싼다.
- 출력 결과를 예시와 한 글자씩 대조한다. 특히 공백과 대문자.
```

**2) 상품 정보 카드** · Easy

- **요구사항**: 상품 이름 `Pen`(문자열), 가격 `1200`(정수), 무게 `8.5`(실수)를 각각 변수 `name`, `price`, `weight` 에 담고, 라벨을 붙여 세 줄로 출력하라.
- **입력**: 없음 (값은 코드 안에 직접 정한다)
- **출력**: 첫 줄 `Item: Pen`, 둘째 줄 `Price: 1200`, 셋째 줄 `Weight: 8.5`
- **예제**: (입력 없음) → 
```
Item: Pen
Price: 1200
Weight: 8.5
```
- **셀프체크**: 세 값을 자료형에 맞게 담았는가(이름은 따옴표, 가격은 정수, 무게는 소수점)? 라벨과 값 사이 공백은 쉼표가 넣어 주는 한 칸뿐인가? `print` 안에 값을 직접 쓰지 않고 변수 이름을 썼는가?

```runner
@@SOLUTION
name = 'Pen'
price = 1200
weight = 8.5
print('Item:', name)
print('Price:', price)
print('Weight:', weight)
@@TESTS
--IN

--OUT
Item: Pen
Price: 1200
Weight: 8.5
--IN

--OUT
Item: Pen
Price: 1200
Weight: 8.5
@@EXPL
(1) 접근·핵심 아이디어

- 값 세 개를 각각 변수에 담고, 출력할 때는 라벨 문자열과 변수를 쉼표로 나열한다.
- 쉼표로 나열하면 값 사이에 공백이 한 칸 자동으로 들어간다. 그래서 라벨은 `'Item:'` 처럼 콜론까지만 쓰고 뒤에 공백을 넣지 않는다.
- 문자열·정수·실수가 섞여 있어도 쉼표 나열은 자료형을 가리지 않는다(`+` 는 섞으면 오류).

(2) 코드 단계별

- `name = 'Pen'` — 글자이므로 따옴표로 감싼 문자열.
- `price = 1200` — 소수점 없는 정수. `weight = 8.5` — 소수점 있는 실수.
- `print('Item:', name)` — 라벨과 변수를 쉼표로 이어 `Item: Pen`. 같은 방식으로 나머지 두 줄을 출력한다.

(3) 스스로 다시 짤 때 생각 순서

- 담을 값이 셋 → 변수 셋, 각각 자료형에 맞게.
- "라벨 뒤 공백은 누가 넣지?" → 쉼표가 넣는다. 문자열 끝에 공백을 또 넣으면 두 칸이 된다.
- 세 줄이니 `print` 세 번, 각 줄에 라벨과 변수 한 쌍.
```

**3) 글자 덧셈과 숫자 덧셈** · Easy

- **요구사항**: 문자열 `'7'` 과 `'3'` 을 변수 `s1`, `s2` 에, 정수 `7` 과 `3` 을 변수 `n1`, `n2` 에 담아라. 첫 줄에 `s1 + s2` 의 결과를, 둘째 줄에 `n1 + n2` 의 결과를 출력하라.
- **입력**: 없음
- **출력**: 첫 줄은 문자열끼리 더한 결과, 둘째 줄은 정수끼리 더한 결과
- **예제**: (입력 없음) → 
```
73
10
```
- **셀프체크**: 같은 `+` 인데 결과가 `73` 과 `10` 으로 다른 이유를 설명할 수 있는가? 문자열과 정수를 섞어 `s1 + n1` 처럼 더하면 오류가 난다는 점을 확인했는가?

```runner
@@SOLUTION
s1 = '7'
s2 = '3'
n1 = 7
n2 = 3
print(s1 + s2)
print(n1 + n2)
@@TESTS
--IN

--OUT
73
10
--IN

--OUT
73
10
@@EXPL
(1) 접근·핵심 아이디어

- `+` 는 양쪽 값의 자료형에 따라 다르게 동작한다. 문자열끼리는 "이어 붙이기", 숫자끼리는 "덧셈"이다.
- `'7' + '3'` 은 글자 `7` 뒤에 글자 `3` 을 붙여 `'73'` 이 되고, `7 + 3` 은 계산되어 `10` 이 된다.
- 화면에 `7` 로 똑같이 보여도 따옴표 유무에 따라 전혀 다른 값이라는 점이 핵심이다.

(2) 코드 단계별

- `s1 = '7'`, `s2 = '3'` — 따옴표가 있으니 문자열.
- `n1 = 7`, `n2 = 3` — 따옴표가 없으니 정수.
- `print(s1 + s2)` — 문자열 잇기 → `73`. `print(n1 + n2)` — 정수 덧셈 → `10`.

(3) 스스로 다시 짤 때 생각 순서

- 값을 담기 전에 "이건 글자인가 숫자인가?" 를 먼저 정한다.
- `+` 를 쓸 때 양쪽 자료형이 같은지 확인한다. 문자열과 정수를 섞으면 오류.
- 결과가 `73` 인지 `10` 인지 보고, 자료형을 반대로 담지 않았는지 검산한다.
```

**4) 같은 값, 다른 자릿수** · Easy

- **요구사항**: 변수 `speed` 에 `12.3456` 을 담고, 첫 줄에는 소수점 아래 첫째 자리까지, 둘째 줄에는 소수점 아래 셋째 자리까지 출력하라.
- **입력**: 없음
- **출력**: 첫 줄 `.1f` 형식, 둘째 줄 `.3f` 형식
- **예제**: (입력 없음) → 
```
12.3
12.346
```
- **셀프체크**: 둘째 줄은 넷째 자리 `6` 때문에 셋째 자리가 `5` 에서 `6` 으로 올라간다. `12.345` 라고 적지 않았는가? 첫 줄은 둘째 자리 `4` 가 5 미만이라 그대로 `12.3` 인가?

```runner
@@SOLUTION
speed = 12.3456
print(f'{speed:.1f}')
print(f'{speed:.3f}')
@@TESTS
--IN

--OUT
12.3
12.346
--IN

--OUT
12.3
12.346
@@EXPL
(1) 접근·핵심 아이디어

- 값은 하나지만 보여 주는 자릿수만 다르게 한다. 변수는 그대로 두고 f-문자열의 `.Nf` 만 바꾼다.
- `.Nf` 는 "잘라 버리기"가 아니라 "반올림"이다. 잘려 나가는 첫 자리가 5 이상이면 위 자리가 하나 올라간다.

(2) 코드 단계별

- `speed = 12.3456` — 실수를 담는다.
- `print(f'{speed:.1f}')` — 소수점 아래 1자리. 둘째 자리 `4` 는 5 미만이라 `12.3`.
- `print(f'{speed:.3f}')` — 소수점 아래 3자리. 넷째 자리 `6` 은 5 이상이라 셋째 자리 `5` 가 `6` 으로 올라 `12.346`.

(3) 스스로 다시 짤 때 생각 순서

- "몇 자리까지?" 를 줄마다 정한다 → `.1f`, `.3f`.
- 자릿수를 바꿔도 변수 값은 변하지 않는다. 보이는 모습만 다르다.
- 잘려 나가는 첫 자리를 보고 반올림 여부를 손으로 검산한다.
```

**5) 용돈 잔액 계산** · Easy

- **요구사항**: 변수 `balance` 를 `5000` 으로 시작해, 간식으로 `1200` 을 쓰고(빼기), 심부름 값으로 `300` 을 받은(더하기) 뒤, `Balance:` 라벨을 붙여 최종 잔액을 출력하라. 값 변경은 `-=`, `+=` 를 사용한다.
- **입력**: 없음
- **출력**: `Balance: 최종잔액` 한 줄
- **예제**: (입력 없음) → `Balance: 4100`
- **셀프체크**: `5000 - 1200 = 3800`, `3800 + 300 = 4100` 순서로 따라갔는가? `balance = 1200` 처럼 대입해 버려 잔액이 사라지지 않았는가?

```runner
@@SOLUTION
balance = 5000
balance -= 1200
balance += 300
print('Balance:', balance)
@@TESTS
--IN

--OUT
Balance: 4100
--IN

--OUT
Balance: 4100
@@EXPL
(1) 접근·핵심 아이디어

- 잔액은 "지금 값에서 빼고 더한 결과를 다시 담는" 방식으로 바뀐다. `balance -= 1200` 은 `balance = balance - 1200` 의 축약이다.
- 새 값으로 덮어쓰는 `balance = 1200` 과는 완전히 다르다. 축약형은 옛 값을 계산에 쓴다.

(2) 코드 단계별

- `balance = 5000` — 시작 잔액.
- `balance -= 1200` — 오른쪽 `5000 - 1200 = 3800` 을 계산해 다시 담는다.
- `balance += 300` — `3800 + 300 = 4100` 을 다시 담는다.
- `print('Balance:', balance)` — 라벨과 변수를 쉼표로 이어 `Balance: 4100`.

(3) 스스로 다시 짤 때 생각 순서

- 지시문의 "쓰고, 받고" 순서를 그대로 코드 줄 순서로 옮긴다.
- 각 줄에서 값이 어떻게 변하는지 `5000 → 3800 → 4100` 으로 따라가 본다.
- 마지막에 라벨을 붙여 출력할 때 쉼표가 공백을 넣어 준다는 점을 떠올린다.
```

**6) 케이스 번호 붙여 출력** · Easy

- **요구사항**: 변수 `a`, `b` 를 세 번 다시 정하면서, 매번 `Case #번호: 합` 형식으로 두 수의 합을 출력하라. 첫 번째는 `a, b = 3, 4`, 두 번째는 `a, b = 10, 5`, 세 번째는 `a, b = -2, 2` 로 정한다. 새 변수를 만들지 말고 같은 `a`, `b` 를 덮어써서 쓴다.
- **입력**: 없음
- **출력**: 세 줄, 각각 `Case #1: 7`, `Case #2: 15`, `Case #3: 0`
- **예제**: (입력 없음) → 
```
Case #1: 7
Case #2: 15
Case #3: 0
```
- **셀프체크**: `Case #1:` 뒤 공백은 쉼표가 넣어 주는 한 칸뿐인가? 세 번째 합이 `0` 으로 제대로 나오는가(음수와 양수의 합)? 변수를 덮어쓴 뒤 출력했는가?

```runner
@@SOLUTION
a, b = 3, 4
print('Case #1:', a + b)
a, b = 10, 5
print('Case #2:', a + b)
a, b = -2, 2
```

- **셀프체크**: 규칙 A에서 `x * y` 는 옛 값 `3 * 5 = 15` 로 계산되는가(새 `x` 인 5를 쓰면 `25` 로 틀린다)? 규칙 B에서 새 `y` 는 이미 바뀐 `x` 가 아니라 규칙 B 직전의 `x`(=5)인가? 두 단계의 값을 표로 따라가 보았는가?

```runner
(1) 접근·핵심 아이디어

- 동시 대입은 "오른쪽을 전부 옛 값으로 먼저 계산 → 그 결과를 왼쪽에 순서대로 대입" 2단계로 동작한다. 왼쪽 변수가 하나씩 차례로 바뀌는 것이 아니다.
- 그래서 오른쪽에 같은 변수가 여러 번 나와도 모두 "그 줄이 시작될 때의 값"을 쓴다. 이 점을 두 단계에 걸쳐 확인하는 문제다.

(2) 코드 단계별

- `x, y = 3, 5` — 시작값.
- 규칙 A `x, y = y, x * y` — 오른쪽을 옛 값으로 계산: `y` 는 5, `x * y` 는 `3 * 5 = 15`. 오른쪽은 `(5, 15)`. 이를 담으면 `x` 는 5, `y` 는 15. `print(x, y)` → `5 15`.
- 규칙 B `x, y = x + y, x` — 지금 `x` 는 5, `y` 는 15. 오른쪽은 `(5 + 15, 5) = (20, 5)`. 담으면 `x` 는 20, `y` 는 5. `print(x, y)` → `20 5`.

(3) 스스로 다시 짤 때 생각 순서

- 각 동시 대입 줄마다 "이 줄 시작 시점의 `x`, `y`" 를 먼저 적는다.
- 오른쪽 식을 그 값으로 모두 계산해 괄호 안에 적은 뒤, 왼쪽에 순서대로 넣는다.
- 규칙 A에서 `25` 가 나왔다면 새 `x` 로 곱한 착각이고, 규칙 B에서 `20 20` 이 나왔다면 새 `x` 를 `y` 에 넣은 착각이다.
```
