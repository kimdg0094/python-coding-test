> 개요: 이 챕터에서는 화면에 값을 보여 주는 `print`를 익히고, 값을 담아 두는 변수와 기본 자료형, 여러 값을 원하는 형식으로 출력하는 법, 그리고 변수의 값을 바꾸고 옮기고 서로 교환하는 방법까지 배운다.

## L1. 기본 출력

**개념**

- 프로그램이 만든 결과를 사람이 볼 수 있게 화면에 보여 주는 것을 "출력"이라고 한다.
- 파이썬에서는 `print(...)` 함수로 출력한다. 괄호 안에 보여 주고 싶은 값을 넣는다.
- 글자(문자열)를 그대로 출력하려면 작은따옴표 `'...'` 나 큰따옴표 `"..."` 로 감싼다.
- 숫자는 따옴표 없이 그대로 쓴다. `print(10)` 은 `10` 을 출력한다.
- `print` 는 한 번 호출될 때마다 자동으로 줄을 바꾼다. 그래서 `print` 를 두 번 쓰면 두 줄로 나온다.

```python
print('Hello')
print(2025)
```

위 코드의 출력:

```
Hello
2025
```

## L2. 변수와 자료형

**개념**

- 변수는 값을 담아 두는 "이름표가 붙은 상자"다. `x = 5` 는 `x` 라는 이름에 값 `5` 를 넣는 것이다.
- `=` 는 "같다"가 아니라 "오른쪽 값을 왼쪽 이름에 넣어라"라는 뜻이다. (이걸 대입이라 한다.)
- 변수에 담긴 값은 그 이름만 써서 다시 꺼내 쓸 수 있다. `print(x)` 는 `x` 가 담고 있는 값을 출력한다.
- 값에는 종류가 있고 이를 "자료형"이라 한다. 기초 자료형 세 가지:

- 정수형(int): 소수점이 없는 수. 예: `3`, `-7`, `0`
- 실수형(float): 소수점이 있는 수. 예: `3.14`, `-0.5`, `2.0`
- 문자열(str): 따옴표로 감싼 글자. 예: `'hi'`, `"12"`

- 같은 겉모습이라도 자료형이 다를 수 있다. `5` 는 정수, `5.0` 은 실수, `'5'` 는 문자열이다.

```python
age = 20
pi = 3.14
name = 'Ann'
print(name)
print(age)
```

출력:

```
Ann
20
```

## L3. 출력 형식

**개념**

- 한 줄에 여러 값을 함께 보여 주고 싶을 때, `print` 괄호 안에 값을 쉼표 `,` 로 나열하면 된다.
- 쉼표로 나열하면 값 사이에 자동으로 공백 한 칸이 들어간다. 예: `print('a', 'b')` → `a b`
- 문자열과 숫자를 섞어서 나열해도 된다. 자료형이 달라도 쉼표로 이으면 함께 출력된다.
- 문자열끼리는 `+` 로 이어 붙일 수도 있다. 이때는 공백이 자동으로 들어가지 않는다. 예: `print('a' + 'b')` → `ab`
- 정리하면, 쉼표는 "공백을 넣어 나란히", `+` 는 "빈틈없이 붙여서"이다. (`+` 는 문자열끼리만, 숫자끼리만 가능하며 서로 섞으면 오류가 난다.)

```python
name = 'Ann'
age = 20
print(name, age)
print('Age:', age)
```

출력:

```
Ann 20
Age: 20
```

**문제**

**1) 이름과 점수 한 줄에** · Easy

- **요구사항**: 이름과 점수를 한 줄에 공백으로 띄워 출력하라. 이름 `Kim`, 점수 `95` 를 변수에 담아 사용한다.
- **입력**: 없음
- **출력**: 이름과 점수를 공백 한 칸을 두고 한 줄에
- **예제**: (입력 없음) → `Kim 95`
- **셀프체크**: 쉼표로 나열하면 공백이 자동으로 하나 들어간다. 공백을 두 칸 넣지 않았는가?

```runner
@@SOLUTION
name = 'Kim'
score = 95
print(name, score)
@@TESTS
--IN

--OUT
Kim 95
@@EXPL
(1) 접근 개념: 두 값을 한 줄에 나란히 보여 준다. `print` 괄호 안에 값을 쉼표로 나열하면 값 사이에 공백 한 칸이 자동으로 들어간다.

(2) 코드 진행

- `name = 'Kim'`, `score = 95` 로 이름과 점수를 각각 변수에 담는다.
- `print(name, score)` 에서 쉼표로 두 변수를 나열하면 `Kim 95` 처럼 사이에 공백 한 칸이 들어간다.

(3) 재작성 사고 순서

- "한 줄에 여러 값?" → 쉼표로 나열.
- 쉼표가 공백을 하나 자동으로 넣으니, 직접 공백을 추가하면 두 칸이 되어 틀린다.
- 값 대신 변수 이름을 나열한다.
```

- **입력**: 없음
- **출력**: `Temperature: 36`
- **예제**: (입력 없음) → `Temperature: 36`
- **셀프체크**: `Temperature:` 와 `36` 사이 공백은 몇 칸인가? 쉼표로 이으면 콜론 뒤에 이미 공백이 하나 생긴다. 문자열 안에 콜론 뒤 공백을 또 넣으면 두 칸이 된다.

```runner

@@TESTS
--IN

--OUT

@@EXPL
(1) 접근 개념: 값 앞에 안내 문구(라벨)를 붙여 출력한다. 문자열 라벨과 숫자 값을 쉼표로 이으면 사이에 공백 한 칸이 자동으로 들어간다.

(2) 코드 진행

- `temp = 36` 으로 값을 변수에 담는다.
- `print('Temperature:', temp)` — 라벨 문자열 `'Temperature:'` 와 변수 `temp`를 쉼표로 나열한다.
- 콜론 뒤에는 문자열 안에 공백을 넣지 않는다. 쉼표가 이미 공백 한 칸을 넣어 주기 때문이다. 결과는 `Temperature: 36`.

(3) 재작성 사고 순서

- 라벨은 따옴표로 감싼 문자열, 값은 변수.
- 둘을 쉼표로 이어 한 줄에 출력한다.
- "공백이 몇 칸?" → 쉼표가 하나 넣으니, 문자열 끝에 공백을 또 넣지 않도록 주의한다.
```

**3) 붙여 쓰기 vs 띄워 쓰기** · Hard

## L4. 소수점 맞춰 출력

**개념**

- 실수를 출력할 때 소수점 아래 자릿수를 정해서 깔끔하게 보여 주고 싶을 때가 있다.
- 이때 f-문자열(f-string)을 쓴다. 문자열 앞에 `f` 를 붙이고, 값을 넣을 자리에 `{ }` 를 쓴다.
- `{값:.2f}` 는 "이 값을 소수점 아래 2자리 실수로 출력하라"는 뜻이다. `.` 뒤 숫자가 자릿수, 끝의 `f` 는 실수(float) 형식을 뜻한다.
- 지정한 자릿수에 맞춰 반올림된다. 예: `3.14159` 를 `.2f` 로 하면 `3.14`, `2.005` 는 상황에 따라 반올림된다.
- 정해진 자릿수보다 짧으면 `0` 으로 채운다. 예: `2.5` 를 `.3f` 로 하면 `2.500`.

```python
pi = 3.14159
print(f'{pi:.2f}')
print(f'{pi:.4f}')
```

출력:

```
3.14
3.1416
```

> 선행: `{ }` 안에 변수를 넣으면 그 값이 문자열 안으로 들어간다. 지금은 "소수점 자릿수 맞추기" 용도로만 쓴다.

**문제**

- **출력**: 소수점 아래 2자리로 반올림한 값
- **예제**: (입력 없음) → `3.14`
- **셀프체크**: 셋째 자리 `1` 은 버림, 결과가 `3.14` 인가? `.2f` 를 정확히 썼는가?

```runner
@@SOLUTION

@@TESTS
--IN

--OUT
3.14
@@EXPL
(1) 접근 개념: 실수를 소수점 아래 정해진 자릿수까지만 보여 준다. f-문자열의 `{값:.2f}` 형식을 쓰면 소수점 아래 2자리로 반올림해 출력한다.

(2) 코드 진행

- `pi = 3.141592` 로 값을 담는다.
- `print(f'{pi:.2f}')` — 문자열 앞에 `f`를 붙이고 `{pi:.2f}` 로 자릿수를 지정한다.

(3) 재작성 사고 순서

- "몇 자리까지 보여 줘야 하지?" → 2자리 → `.2f`.
- f-문자열은 앞에 `f`, 값 자리에 `{ }`.
```

## L5. 변수 값 변경

**개념**

- 변수에는 값을 다시 대입해서 언제든 바꿀 수 있다. 상자에 들어 있던 값을 빼고 새 값을 넣는 것과 같다.
- 나중에 대입한 값이 이전 값을 덮어쓴다. 마지막으로 넣은 값만 남는다.
- 같은 변수를 계산에 써서 새 값을 만들 수도 있다. `x = x + 1` 은 "지금 `x` 값에 1을 더한 결과를 다시 `x` 에 넣어라"라는 뜻이다.
- 이때 오른쪽이 먼저 계산되고, 그 결과가 왼쪽 변수에 대입된다.
- 자주 쓰는 축약: `x += 1` 은 `x = x + 1` 과 같다. `-=`, `*=` 도 같은 방식이다.

```python
x = 10
x = 20      # 값이 20으로 바뀜
x = x + 5   # 20 + 5 = 25
print(x)
```

출력:

```
25
```

**문제**

**1) 값 덮어쓰기** · Easy

- **요구사항**: 변수 `n` 에 `3` 을 넣은 뒤, 다시 `8` 을 넣고, 최종 값을 출력하라.
- **입력**: 없음
- **출력**: 마지막으로 대입된 값
- **예제**: (입력 없음) → `8`
- **셀프체크**: 마지막에 넣은 값만 남는다. `3` 이 출력되면 순서나 대입이 잘못된 것이다.

```runner
@@SOLUTION
n = 3
n = 8
print(n)
@@TESTS
--IN

--OUT
8
@@EXPL
(1) 접근 개념: 같은 변수에 값을 다시 대입하면 이전 값이 덮어써진다. 마지막으로 넣은 값만 남는다는 사실을 확인한다.

(2) 코드 진행

- `n = 3` — 변수 `n`에 `3`이 들어간다.
- `n = 8` — 같은 `n`에 `8`을 넣으면 이전의 `3`은 사라진다.
- `print(n)` — 현재 `n`의 값 `8`이 출력된다.

(3) 재작성 사고 순서

- 대입은 "상자의 내용을 새 값으로 교체"하는 동작이다.
- 여러 번 대입하면 순서상 마지막 값만 남는다.
- 출력 시점에 변수가 어떤 값을 담고 있는지 따라간다.
```

**2) 자기 자신을 이용해 증가** · Medium

- **요구사항**: 변수 `count` 를 `0` 으로 시작해, 값을 1씩 세 번 더한 뒤 최종 값을 출력하라.
- **입력**: 없음
- **출력**: 세 번 더한 최종 값
- **예제**: (입력 없음) → `3`
- **셀프체크**: `count = count + 1` (또는 `count += 1`)을 세 번 실행하면 `0→1→2→3`. 결과가 `3` 인가?

```runner
@@SOLUTION

count = count + 1
count = count + 1
print(count)
@@TESTS
--IN

--OUT
3
@@EXPL
(1) 접근 개념: 변수 자기 자신을 계산에 써서 값을 늘린다. `count = count + 1` 은 "지금 값에 1을 더한 결과를 다시 담아라"라는 뜻이다. 오른쪽이 먼저 계산된다.

(2) 코드 진행

- `count = 0` 으로 시작한다.
- 첫 번째 `count = count + 1` → 오른쪽 `0 + 1 = 1` 을 계산해 `count`에 넣는다. `count`는 1.
- 두 번째 → `1 + 1 = 2`. 세 번째 → `2 + 1 = 3`.
- `print(count)` 로 최종값 `3`을 출력한다.

(3) 재작성 사고 순서

- "1씩 세 번 늘린다" → 같은 대입을 세 번 반복.
- 각 줄에서 오른쪽(옛 값 + 1)을 먼저 계산하고 그 결과를 다시 변수에 넣는다.
- `0→1→2→3` 처럼 값의 흐름을 손으로 따라가 본다.
```

## L6. 다른 변수로부터 값 변경

**개념**

- 한 변수의 값을 다른 변수에 그대로 옮겨 담을 수 있다. `b = a` 는 "`a` 의 현재 값을 `b` 에 넣어라"라는 뜻이다.
- 이때 값이 복사되어 들어간다. 대입 이후 `a` 가 바뀌어도 이미 복사된 `b` 는 영향을 받지 않는다.
- 여러 변수를 조합해 새 값을 만들 수도 있다. `c = a + b` 는 `a` 와 `b` 의 값을 더해 `c` 에 넣는다.
- 오른쪽 식이 먼저 계산되고, 그 결과가 왼쪽 변수에 대입된다는 원칙은 항상 같다.

```python
a = 5
b = a       # b에 5가 복사됨
a = 100     # a만 바뀜
print(a)
print(b)
```

출력:

```
100
5
```

**문제**

**1) 값 옮겨 담기** · Easy

- **요구사항**: 변수 `a` 에 `7` 을 넣고, `b` 에 `a` 의 값을 복사한 뒤 `b` 를 출력하라.
- **입력**: 없음
- **출력**: `b` 의 값
- **예제**: (입력 없음) → `7`
- **셀프체크**: `b = a` 는 `a` 의 값을 `b` 로 옮긴다. `b` 에 직접 `7` 을 쓰지 말고 `a` 로부터 받아 오는가?

```runner
@@SOLUTION
a = 7
b = a
print(b)
@@TESTS
--IN

--OUT
7
@@EXPL
(1) 접근 개념: 한 변수의 값을 다른 변수로 옮겨 담는다. `b = a` 는 "`a`의 현재 값을 `b`에 넣어라"라는 뜻이다.

(2) 코드 진행

- `a = 7` 로 값을 담는다.
- `b = a` — `a`가 담고 있는 `7`이 `b`로 복사된다.
- `print(b)` — `b`의 값 `7`을 출력한다.

(3) 재작성 사고 순서

- "어디서 값을 가져오지?" → `a`로부터.
- `b`에 숫자를 직접 쓰지 말고 `b = a` 로 받아 온다(변수로부터 옮기는 연습).
- 그 다음 `b`를 출력한다.
```

- **요구사항**: 변수 `a = 6`, `b = 4` 에서 두 값의 합을 `c` 에 담아 출력하라.

- **예제**: (입력 없음) → `10`

```runner
(2) 코드 진행

- `a = 6`, `b = 4` 로 두 값을 담는다.
- `c = a + b` — 오른쪽 `6 + 4 = 10` 을 먼저 계산해 `c`에 넣는다.

- 결과 변수를 출력한다.
```

## L7. 두 변수 값을 교환

**개념**

- 두 변수의 값을 맞바꾸는 것을 "교환(swap)"이라 한다. `a` 에는 `b` 의 값, `b` 에는 `a` 의 값이 들어가게 만든다.
- 그냥 `a = b` 를 먼저 하면 `a` 의 원래 값이 사라져서 잃어버린다. 그래서 임시 변수가 필요하다.
- 방법: 임시 변수 `temp` 에 `a` 를 잠시 넣어 두고 → `a = b` → `b = temp` 순서로 옮긴다.
- 임시 변수는 값을 잠깐 보관하는 "임시 상자"다. 교환이 끝나면 더는 신경 쓰지 않아도 된다.

```python
a = 1
b = 2
temp = a    # temp에 1을 보관
a = b       # a는 이제 2
b = temp    # b는 보관해 둔 1
print(a, b)
```

출력:

```
2 1
```

**문제**

**1) 두 값 맞바꾸기** · Easy

- **요구사항**: 변수 `a = 10`, `b = 20` 의 값을 서로 교환한 뒤 한 줄에 공백으로 띄워 출력하라.
- **입력**: 없음
- **출력**: 교환된 `a`, `b` 를 공백 한 칸을 두고 한 줄에
- **예제**: (입력 없음) → `20 10`
- **셀프체크**: 임시 변수를 썼는가? `a = b` 를 먼저 해서 `10` 을 잃어버리지 않았는가?

```runner
@@SOLUTION
a = 10
b = 20
temp = a
a = b
b = temp
print(a, b)
@@TESTS
--IN

--OUT
20 10
@@EXPL
(1) 접근 개념: 두 변수의 값을 맞바꾼다(교환). 그냥 `a = b`를 먼저 하면 `a`의 원래 값이 사라지므로, 임시 변수에 잠깐 보관해 둔다.

(2) 코드 진행

- `a = 10`, `b = 20` 으로 시작한다.
- `temp = a` — `a`의 값 `10`을 임시 변수에 보관한다.
- `a = b` — `a`에 `b`의 값 `20`을 넣는다. 원래 `10`은 `temp`에 안전히 있다.
- `b = temp` — `b`에 보관해 둔 `10`을 넣는다.
- `print(a, b)` — `20 10`.

(3) 재작성 사고 순서

- "덮어쓰면 잃어버리는 값"이 무엇인지 찾는다 → `a`.
- 그 값을 임시 변수에 먼저 보관한다.
- `a ← b`, `b ← temp` 순으로 옮긴다.
```

## L8. 변수값 동시에 복사

**개념**

- 파이썬은 여러 변수에 값을 한 번에 대입할 수 있다. `a, b = 1, 2` 는 `a` 에 `1`, `b` 에 `2` 를 동시에 넣는다.
- 이 방식의 규칙: 오른쪽 값들이 "모두 먼저" 계산된 다음, 왼쪽 변수들에 순서대로 담긴다.
- 2단계로 생각하면 쉽다. ① 오른쪽을 먼저 계산해 임시 상자에 담아 둔다 → ② 그 담아 둔 값을 왼쪽 변수에 순서대로 붓는다. 오른쪽을 다 담은 뒤에 붓기 때문에, 붓는 도중 값이 서로 섞이지 않는다.
- 그래서 교환도 한 줄로 된다. `a, b = b, a` 는 임시 변수 없이 두 값을 맞바꾼다(오른쪽 `b, a` 를 먼저 상자에 담아 두기 때문).
- 같은 원리로 여러 변수에 같은 값을 한꺼번에 넣을 수도 있다. `x = y = 0` 은 `x` 와 `y` 를 모두 `0` 으로 만든다.

```python
a, b = 3, 7
a, b = b, a     # 임시 변수 없이 교환
print(a, b)
```

출력:

```
7 3
```

- **셀프체크**: `a, b = 5, 9` 처럼 왼쪽·오른쪽 개수가 같은가? 순서대로 짝지어 들어갔는가?

**3) 동시 대입의 함정** · Hard

- **요구사항**: `a = 1`, `b = 2` 로 시작한다. 한 줄의 동시 대입 `a, b = b, a + b` 를 실행한 뒤, `a` 와 `b` 를 한 줄에 공백으로 띄워 출력하라.
- **입력**: 없음
- **출력**: 대입 후의 `a`, `b` 를 공백을 두고 한 줄에
- **예제**: (입력 없음) → `2 3`
- **셀프체크**: 오른쪽 `b, a + b` 가 "옛날 값"으로 먼저 계산된다. 즉 `b`(=2)와 `a+b`(=1+2=3)를 먼저 구한 뒤 `a=2`, `b=3` 이 된다. 만약 `a` 를 먼저 바꾼 뒤 계산했다면 틀린 결과가 나온다.

```runner
@@SOLUTION
a = 1
b = 2
a, b = b, a + b
print(a, b)
@@TESTS
--IN

--OUT
2 3
@@EXPL
(1) 접근 개념: 동시 대입에서 오른쪽 식은 모두 "옛 값"으로 먼저 계산된 뒤에 왼쪽에 담긴다. 그래서 `a`가 바뀌기 전 값으로 `a + b`가 계산된다.

(2) 코드 진행

- `a = 1`, `b = 2` 로 시작한다.
- `a, b = b, a + b` — 오른쪽을 먼저 계산한다. 이때 `b`는 2, `a + b`는 `1 + 2 = 3`. 즉 오른쪽은 `(2, 3)`.
- 그 값을 왼쪽에 담는다. `a`는 2, `b`는 3.
- `print(a, b)` — `2 3`.

(3) 재작성 사고 순서

- 동시 대입은 "오른쪽 전부 먼저 계산 → 왼쪽에 순서대로 대입" 2단계로 생각한다.
- 오른쪽 계산에는 아직 바뀌지 않은 옛 값을 쓴다.
- `a`가 먼저 2로 바뀐 뒤 `a+b`를 계산했다면 `2+2=4`가 되어 틀린다. 그런 착오가 없는지 확인한다.
```
