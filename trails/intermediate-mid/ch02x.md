## L7. 추가 연습 — 핵심 반복 × 유형 확장

**개념**

- 이 레슨은 Ch2(Shorten time Technique)의 핵심을 **반복 훈련**하고, 코딩테스트 단골 유형으로 **확장**하는 연습 세트다. 새 문법은 없다. 누적합·좌표 압축·LR·차분 배열(imos)·전처리 표·투 포인터만으로 12문제를 풀되, "나이브 O(N²)·O(NQ)를 O(N)·O(N log N)으로 끌어내린다"는 한 가지 목표를 매 문제에서 확인한다.

- **반복 훈련 개념**
- 누적합: 1-인덱스 `pre[i] = pre[i-1] + a[i-1]`, 구간 `[l, r]`은 `pre[r] - pre[l-1]`. 값 대신 "조건을 만족하면 1"을 더하면 개수 질의가 된다
- 나머지 누적합: 접두합을 K로 나눈 나머지가 같은 두 지점 사이 구간은 K의 배수 — `cnt[run] += 1` 전에 `ans += cnt[run]`
- 좌표 압축 + 이분탐색: `order = sorted(set(xs))`, 값 범위 `[L, R]`은 인덱스 `bisect_left(order, L) .. bisect_right(order, R)`
- LR: 접두 배열 L과 접미 배열 R을 각각 한 번씩 채우고 위치별로 결합 — `for i in range(n-2, -1, -1)`
- 차분 배열(imos)·이벤트 스위프: `diff[l] += v; diff[r+1] -= v` 후 누적합, 또는 `(시각, ±1)` 이벤트 정렬 후 순서대로 누적
- 투 포인터: `right`를 늘리며 넣고 조건이 깨지면 `while`로 `left`를 밀어 회복, 답 갱신은 불변식이 성립한 직후

- **코딩테스트 출제 맵**: 이 챕터의 유형은 백준 「단계별로 풀어보기」의 '누적 합'·'투 포인터' 단계, NeetCode 150의 'Two Pointers'·'Sliding Window'·'Intervals', solved.ac CLASS 3~4의 구간합·나머지 합·부분합 문제에 그대로 등장한다. 이 레슨의 유형 확장 문제는 그 대표 유형의 소재·수치·조건을 새로 만들어 재구성한 것이다.

**문제**

**1) 모음 개수 구간 질의** · Easy

- **요구사항**: 소문자 문자열 s와 Q개의 질의 `(l, r)`이 주어질 때, 각 질의마다 `s[l..r]`(1-indexed) 안의 모음(a, e, i, o, u) 개수를 출력하라.
- **입력**: 첫 줄 문자열 s(길이 1 이상 200 이하). 둘째 줄 Q(1 ≤ Q ≤ 200). 이후 Q줄에 `l r`(1 ≤ l ≤ r ≤ len(s)).
- **출력**: 질의마다 모음 개수를 한 줄씩.
- **예제**: `programming / 2 / 1 3 / 4 11` → `1 / 2` · `xyz / 1 / 2 2` → `0`
- **셀프체크**: 질의마다 부분 문자열을 세면 O(Q·N). "모음이면 1, 아니면 0"을 누적합으로 만들면 질의당 O(1)이다. `l == r`인 한 글자 질의, 모음이 하나도 없는 문자열, 전체 구간이 맞는지.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.read().split()
    s = data[0]
    q = int(data[1])
    n = len(s)
    pre = [0] * (n + 1)
    for i in range(1, n + 1):
        pre[i] = pre[i - 1] + (1 if s[i - 1] in "aeiou" else 0)
    out = []
    idx = 2
    for _ in range(q):
        l = int(data[idx]); r = int(data[idx + 1]); idx += 2
        out.append(str(pre[r] - pre[l - 1]))
    print("\n".join(out))
main()

(1) 접근·핵심 아이디어

- 누적합은 "수의 합"뿐 아니라 "조건을 만족하는 원소의 개수"에도 그대로 쓰인다. 각 글자를 모음이면 1, 아니면 0으로 보고 접두합을 만들면, 구간의 모음 개수는 `pre[r] - pre[l-1]` 한 번의 뺄셈이다. 전처리 O(N) + 질의당 O(1)로 전체 O(N + Q).

(2) 코드 단계별

- `pre[0] = 0`, `pre[i] = pre[i-1] + (s[i-1]가 모음이면 1 else 0)`로 1-인덱스 접두합을 채운다.
- 각 질의 `(l, r)`에 대해 `pre[r] - pre[l-1]`을 기록해 출력.
- 첫 예제 `programming`: 모음 위치는 3(o), 6(a), 10(i)이므로 `[1,3]`은 1개, `[4,11]`은 2개.

(3) 스스로 다시 짤 때 생각 순서

- "같은 문자열에 구간 질의가 반복" → 누적합. 무엇을 더할지(여기선 모음 여부 0/1)를 먼저 정한다.
- 1-인덱스로 `pre`를 두면 `l-1`이 음수가 되지 않는다.
- 경계: 한 글자 질의(`l == r`), 모음이 전혀 없을 때 0, 전체 구간 `[1, N]`은 `pre[N]`.
```

**2) 두 정렬 배열 병합** · Easy

- **요구사항**: 각각 오름차순으로 정렬된 두 정수 배열 A, B를 하나의 오름차순 배열로 합쳐 출력하라. 같은 값은 개수만큼 모두 남긴다. 두 배열을 이어 붙여 다시 정렬하지 말고 앞에서부터 한 번씩만 훑어 O(N + M)으로 풀 것.
- **입력**: 첫 줄 N M(1 ≤ N, M ≤ 300). 둘째 줄 A(N개), 셋째 줄 B(M개). 원소는 -10^9 이상 10^9 이하.
- **출력**: 합친 배열을 공백으로.
- **예제**: `3 4 / 1 4 9 / 2 4 5 10` → `1 2 4 4 5 9 10` · `1 3 / 5 / 1 2 3` → `1 2 3 5`
- **셀프체크**: 두 포인터 i, j 중 작은 쪽을 내보내고 그쪽만 전진. 한쪽이 먼저 끝나면 남은 쪽을 통째로 붙였는가? 같은 값일 때 어느 쪽을 먼저 내보내도 결과는 같다(값이 같으므로).

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.read().split()
    idx = 0
    n = int(data[idx]); m = int(data[idx + 1]); idx += 2
    A = [int(data[idx + i]) for i in range(n)]; idx += n
    B = [int(data[idx + i]) for i in range(m)]; idx += m
    i = 0; j = 0
    out = []
    while i < n and j < m:
        if A[i] <= B[j]:
            out.append(A[i]); i += 1
        else:
            out.append(B[j]); j += 1
    while i < n:
        out.append(A[i]); i += 1
    while j < m:
        out.append(B[j]); j += 1
    print(" ".join(str(x) for x in out))
main()

(1) 접근·핵심 아이디어

- 두 배열이 이미 정렬되어 있으므로, 각 배열의 "아직 안 내보낸 첫 원소" 둘 중 작은 것이 전체에서 다음으로 작은 값이다. 포인터 두 개가 각자 끝까지 한 번씩만 전진하므로 O(N + M)이며, 이어 붙여 정렬하는 O((N+M) log(N+M))보다 빠르다. 병합 정렬의 합치기 단계와 같은 골격이다.

(2) 코드 단계별

- `i = j = 0`에서 시작해 둘 다 남아 있는 동안 `A[i] <= B[j]`면 A 쪽, 아니면 B 쪽을 내보내고 그 포인터만 전진.
- 한쪽이 끝나면 남은 쪽을 순서대로 모두 붙인다(정렬되어 있으므로 그대로 이어도 됨).
- 결과를 공백으로 출력.

(3) 스스로 다시 짤 때 생각 순서

- "정렬된 두 열을 하나로" → 같은 방향 투 포인터(병합). 정렬 함수의 유혹을 참는 것이 훈련 목적.
- 루프 종료 후 "남은 꼬리 붙이기"를 잊으면 원소가 사라진다(둘째 테스트: A가 먼저 끝남).
- 경계: 한쪽 길이 1, 전부 같은 값(중복 보존), 음수.
```

**3) 합이 K의 배수인 구간 수** · Medium

- **요구사항**: 정수 배열에서 연속 부분 배열(길이 1 이상)의 합이 K의 배수인 것의 개수를 출력하라.
- **입력**: 첫 줄 N K(1 ≤ N ≤ 500, 1 ≤ K ≤ 500). 둘째 줄 N개의 정수(-10^6 이상 10^6 이하, 음수 가능).
- **출력**: 구간의 개수.
- **예제**: `5 3 / 1 2 3 4 5` → `7` · `3 5 / 5 5 5` → `6`
- **셀프체크**: 접두합 `pre[i] - pre[j]`가 K의 배수 ⟺ 두 접두합의 K 나머지가 같다. 나머지별 개수 배열에 `pre[0] = 0`의 나머지 0을 미리 1로 넣었는가? 파이썬의 `%`는 음수에도 0 이상 K 미만을 주므로 별도 보정이 필요 없다. 검산(첫 예제): 접두합 0,1,3,6,10,15 → 나머지 0,1,0,0,1,0 → 0이 4개(6쌍), 1이 2개(1쌍) → 7.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.read().split()
    n = int(data[0]); k = int(data[1])
    a = [int(x) for x in data[2:2 + n]]
    cnt = [0] * k
    cnt[0] = 1
    run = 0
    ans = 0
    for x in a:
        run = (run + x) % k
        ans += cnt[run]
        cnt[run] += 1
    print(ans)
main()
@@TESTS

(1) 접근·핵심 아이디어

- 구간 `(j, i]`의 합은 `pre[i] - pre[j]`이고, 이것이 K의 배수라는 것은 `pre[i] % K == pre[j] % K`와 같다. 따라서 "나머지가 같은 접두합 쌍의 수"를 세면 된다. 모든 구간을 직접 보면 O(N²)이지만, 왼쪽부터 훑으며 "지금 나머지와 같은 나머지를 가진 이전 접두합 개수"를 더하면 O(N)이다.
- 빈 접두합 `pre[0] = 0`도 후보이므로 나머지 0의 개수를 1로 시작한다 — 이것을 빠뜨리면 배열 처음부터 시작하는 구간이 전부 누락된다.

(2) 코드 단계별

- `cnt = [0] * K`, `cnt[0] = 1`, 현재 나머지 `run = 0`.
- 원소 x마다 `run = (run + x) % K`, 먼저 `ans += cnt[run]`(같은 나머지를 가진 이전 지점 수), 그다음 `cnt[run] += 1`.
- 마지막에 `ans` 출력. "더한 뒤 세기" 순서를 지켜야 자기 자신과 짝짓지 않는다.

(3) 스스로 다시 짤 때 생각 순서

- "합이 K의 배수인 구간 수" → 접두합 나머지의 동일 쌍 세기로 번역한다.
- 접두합을 배열로 다 만들 필요 없이 나머지 하나만 굴리면 공간 O(K).
- 경계: 음수 원소(파이썬 `%`는 항상 0 이상), K=1(모든 구간이 정답), 원소 전부가 K의 배수(셋째·둘째 테스트처럼 모든 접두합 나머지가 0), 정답이 0인 경우.
```

**4) 큰 좌표 위 가중치 구간합** · Medium

- **요구사항**: 수직선 위에 점 N개가 있고 각 점은 좌표 x와 가중치 w를 가진다(좌표는 서로 다르고 최대 10^9). Q개의 질의 `(L, R)`마다 L ≤ x ≤ R인 점들의 가중치 합을 출력하라.
- **입력**: 첫 줄 N Q(1 ≤ N, Q ≤ 300). 이후 N줄에 `x w`(0 ≤ x ≤ 10^9, 1 ≤ w ≤ 1000). 이후 Q줄에 `L R`(0 ≤ L ≤ R ≤ 10^9).
- **출력**: 질의마다 합을 한 줄씩.
- **예제**: `4 3 / 100 5 / 3 2 / 1000000000 7 / 50 1 / 3 100 / 60 999999999 / 1 1000000000` → `8 / 5 / 15` · `1 1 / 10 4 / 11 20` → `0`
- **셀프체크**: 좌표를 배열 인덱스로 쓸 수 없으니 점을 좌표순으로 정렬해 "순위"를 인덱스로 삼는다(좌표 압축). 질의 `[L, R]`은 정렬 좌표에서 `bisect_left(xs, L)`부터 `bisect_right(xs, R)` 직전까지이고, 이 인덱스 구간의 가중치 합을 누적합으로 O(1)에 구한다. 질의 범위에 점이 하나도 없으면 두 위치가 같아 0이 나오는지.

```runner
@@SOLUTION
import sys, bisect
def main():
    data = sys.stdin.read().split()
    idx = 0
    n = int(data[idx]); q = int(data[idx + 1]); idx += 2
    pts = []
    for _ in range(n):
        x = int(data[idx]); w = int(data[idx + 1]); idx += 2
        pts.append((x, w))
    pts.sort()
    xs = [x for x, _ in pts]
    pre = [0] * (n + 1)
    for i in range(1, n + 1):
        pre[i] = pre[i - 1] + pts[i - 1][1]
    out = []
    for _ in range(q):
        l = int(data[idx]); r = int(data[idx + 1]); idx += 2
        lo = bisect.bisect_left(xs, l)
        hi = bisect.bisect_right(xs, r)
        out.append(str(pre[hi] - pre[lo]))
    print("\n".join(out))
main()

(1) 접근·핵심 아이디어

- 좌표 범위는 10^9지만 점은 N개뿐이므로 실제 값 대신 정렬 순위로 다루는 좌표 압축이 맞다. 정렬한 뒤 가중치 누적합을 만들면 질의는 "L 이상 첫 점의 순위 ~ R 이하 마지막 점의 순위" 사이의 합이고, 순위 두 개는 bisect로 O(log N)에 얻는다. 질의마다 점을 전부 훑는 O(NQ) 대신 O((N + Q) log N).
- `bisect_left(xs, L)`은 L 이상 첫 위치, `bisect_right(xs, R)`은 R 초과 첫 위치라 반열림 `[lo, hi)`가 되고, 누적합 `pre[hi] - pre[lo]`와 정확히 맞물린다.

(2) 코드 단계별

- `(x, w)` 튜플을 좌표순 정렬하고 좌표만 뽑은 `xs`, 가중치 접두합 `pre`를 만든다.
- 질의마다 `lo = bisect_left(xs, L)`, `hi = bisect_right(xs, R)`를 구해 `pre[hi] - pre[lo]`를 출력.
- 첫 예제: 정렬 좌표 3, 50, 100, 10^9 → `[3, 100]`은 앞 세 점 2+1+5=8, `[60, 999999999]`는 100 하나 5, 전체 15.

(3) 스스로 다시 짤 때 생각 순서

- "좌표 범위는 크고 개수는 작다 + 값 범위 질의" → 압축(정렬) + 누적합 + bisect의 3단 결합을 떠올린다.
- 경계 포함(≤, ≥)에 맞춰 왼쪽은 left, 오른쪽은 right를 고르고, 점이 하나도 없는 범위에서 `lo == hi`가 되어 0이 나오는지 확인한다.
- 경계: 질의 끝점이 정확히 점 좌표와 같을 때(포함), 모든 점 밖의 범위(0), 좌표 10^9.
```

**5) 두 팀 분할 지점** · Medium

- **요구사항**: 정수 배열을 앞부분과 뒷부분(둘 다 길이 1 이상)으로 자른다. "앞부분의 최댓값 ≤ 뒷부분의 최솟값"이 되는 자르는 위치 중 앞부분의 길이가 가장 짧은 것을 출력하라. 없으면 -1.
- **입력**: 첫 줄 N(2 ≤ N ≤ 500). 둘째 줄 N개의 정수(-10^9 이상 10^9 이하).
- **출력**: 앞부분의 길이 p(1 ≤ p ≤ N-1) 또는 -1.
- **예제**: `6 / 5 0 3 8 6 9` → `3` · `2 / 1 1` → `1`
- **셀프체크**: 자르는 위치마다 양쪽을 다시 훑으면 O(N²). 접두 최대 `L[i] = max(a[0..i])`와 접미 최소 `R[i] = min(a[i..n-1])`를 각각 한 번에 채우면 위치 p의 조건은 `L[p-1] <= R[p]`로 O(1). 조건이 "≤"라 같은 값이 양쪽에 걸쳐도 허용된다. 검산(첫 예제): p=1은 5 ≤ 0 거짓, p=2는 5 ≤ 3 거짓, p=3은 5 ≤ 6 참.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    a = [int(x) for x in data[1:1 + n]]
    L = [0] * n
    L[0] = a[0]
    for i in range(1, n):
        L[i] = max(L[i - 1], a[i])
    R = [0] * n
    R[n - 1] = a[n - 1]
    for i in range(n - 2, -1, -1):
        R[i] = min(R[i + 1], a[i])
    for p in range(1, n):
        if L[p - 1] <= R[p]:
            print(p); return
    print(-1)
main()

(1) 접근·핵심 아이디어

- 위치 p의 판정에는 "왼쪽 전체의 최댓값"과 "오른쪽 전체의 최솟값"이 동시에 필요하다. 이것이 LR 기법의 신호다. 접두 최대 L과 접미 최소 R을 각각 한 번의 스캔으로 채우면 판정이 O(1)이 되어 전체 O(N)(나이브 O(N²)).
- 접두는 왼쪽에서 오른쪽으로 `max`, 접미는 오른쪽에서 왼쪽으로 `min`으로 누적한다는 방향 차이가 핵심이다.

(2) 코드 단계별

- `L[0] = a[0]`, `L[i] = max(L[i-1], a[i])`(자신 포함 접두 최대).
- `R[n-1] = a[n-1]`, `R[i] = min(R[i+1], a[i])`(자신 포함 접미 최소).
- p를 1부터 N-1까지 올리며 처음으로 `L[p-1] <= R[p]`인 p를 출력. 없으면 -1.

(3) 스스로 다시 짤 때 생각 순서

- "자르는 위치마다 양쪽 정보가 필요" → LR. 각 배열의 정의(자신 포함 여부)를 한 줄로 적고 시작한다.
- 가장 짧은 p를 원하므로 작은 p부터 훑다가 첫 성공에서 멈춘다.
- 경계: N=2, 같은 값이 경계에 걸친 경우(넷째 테스트: 1 ≤ min(2,2,1)=1이라 p=1), 어떤 위치도 안 되는 감소 배열(-1).
```

**6) 버스 정원 검사** · Medium

- **요구사항**: 정류장 1..S를 순서대로 지나는 버스가 있다. 승차 기록 N개 `(f, t, c)`는 "정류장 f에서 c명이 타서 정류장 t에서 내린다"(f < t)는 뜻이다. 각 정류장을 출발할 때의 탑승 인원 중 최댓값을 구하고, 그것이 정원 C 이하이면 `OK`, 넘으면 `OVER`를 함께 출력하라. 정류장 t에서 내리는 승객은 t를 출발할 때 이미 없는 것으로 본다.
- **입력**: 첫 줄 S N C(2 ≤ S ≤ 500, 1 ≤ N ≤ 300, 1 ≤ C ≤ 10^6). 이후 N줄에 `f t c`(1 ≤ f < t ≤ S, 1 ≤ c ≤ 1000).
- **출력**: `최대 탑승 인원 OK` 또는 `최대 탑승 인원 OVER`.
- **예제**: `5 3 4 / 1 3 2 / 2 5 3 / 3 4 1` → `5 OVER` · `3 1 10 / 1 3 10` → `10 OK`
- **셀프체크**: 기록마다 정류장 f..t-1을 직접 더하면 O(N·S). 차분 배열에 `diff[f] += c`, `diff[t] -= c`만 기록하고 누적합 한 번이면 O(N + S). 구간이 반열림 `[f, t)`이므로 `-c`를 `t+1`이 아니라 `t`에 둔다 — 셋째 테스트처럼 한 팀이 내리는 정류장에서 다른 팀이 타면 겹치지 않아야 한다.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.read().split()
    s = int(data[0]); n = int(data[1]); cap = int(data[2])
    idx = 3
    diff = [0] * (s + 2)
    for _ in range(n):
        f = int(data[idx]); t = int(data[idx + 1]); c = int(data[idx + 2]); idx += 3
        diff[f] += c
        diff[t] -= c
    best = 0; run = 0
    for i in range(1, s + 1):
        run += diff[i]
        if run > best:
            best = run
    print(best, "OK" if best <= cap else "OVER")
main()

(1) 접근·핵심 아이디어

- "구간에 일괄 더하기 여러 번 + 최종 상태만 필요"는 차분 배열(imos)의 전형이다. 각 기록을 시작점 `+c`, 끝점 `-c` 두 번의 기록으로 처리하고, 마지막에 누적합으로 정류장별 탑승 인원을 복원해 최댓값을 취한다. O(N + S).
- 이 문제의 구간은 반열림 `[f, t)`다(내리는 정류장에서는 이미 없음). 그래서 `-c`를 `t`에 둔다. 폐구간이었다면 `t+1`이었을 것이다 — 구간의 열림/닫힘을 문장에서 먼저 읽어내는 것이 이 유형의 핵심 함정이다.

(2) 코드 단계별

- `diff`를 S+2 크기로 준비하고 기록마다 `diff[f] += c`, `diff[t] -= c`.
- 정류장 1..S를 순서대로 누적하며 탑승 인원 `run`의 최댓값 `best`를 갱신.
- `best`와 함께 `best <= C`면 `OK`, 아니면 `OVER`를 출력.

(3) 스스로 다시 짤 때 생각 순서

- "탈 때 +, 내릴 때 -"를 보면 차분 배열(또는 이벤트)을 떠올린다.
- 구간 끝 처리: 내리는 정류장 t는 포함하지 않으므로 `t`에 `-c`. 예제로 반드시 검산한다(셋째 테스트: 2번 정류장에서 3명이 내리고 3명이 타 최대 3).
- 경계: 기록 하나가 전체 구간을 덮는 경우(둘째 테스트), 정확히 정원과 같을 때 `OK`(≤).
```

**7) k번째 빈 좌석 조회** · Medium

- **요구사항**: 좌석 N개의 상태가 `0`(빈 자리)/`1`(찬 자리) 문자열로 주어진다. Q개의 질의 `(i, k)`마다 "좌석 i부터 오른쪽으로 보았을 때 k번째 빈 좌석의 번호"를 출력하라(좌석 i 자신도 포함). 그런 좌석이 없으면 -1.
- **입력**: 첫 줄 N(1 ≤ N ≤ 500). 둘째 줄 길이 N의 0/1 문자열. 셋째 줄 Q(1 ≤ Q ≤ 500). 이후 Q줄에 `i k`(1 ≤ i ≤ N, 1 ≤ k ≤ N).
- **출력**: 질의마다 좌석 번호 또는 -1을 한 줄씩.
- **예제**: `10 / 1101001110 / 3 / 1 1 / 4 2 / 8 2` → `3 / 6 / -1` · `3 / 111 / 1 / 1 1` → `-1`
- **셀프체크**: 질의마다 i부터 훑으면 O(NQ). 빈 좌석 번호를 순서대로 담은 목록 `free_pos`와 "좌석 i 이전(1..i-1)의 빈 좌석 수" `before[i-1]`을 미리 만들면 답은 `free_pos[before[i-1] + k - 1]`로 O(1). 인덱스가 목록 길이를 넘으면 -1. 검산(첫 예제): 빈 좌석 3, 5, 6, 10 → (4, 2)는 4 이전 빈 좌석 1개 → 목록의 2번 인덱스 6.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    seats = data[1]
    q = int(data[2])
    free_pos = []
    before = [0] * (n + 1)
    for i in range(n):
        before[i + 1] = before[i]
        if seats[i] == '0':
            free_pos.append(i + 1)
            before[i + 1] += 1
    out = []
    idx = 3
    for _ in range(q):
        i = int(data[idx]); k = int(data[idx + 1]); idx += 2
        j = before[i - 1] + k - 1
        out.append(str(free_pos[j]) if j < len(free_pos) else "-1")
    print("\n".join(out))
main()

(1) 접근·핵심 아이디어

- 같은 좌석 배열에 질의가 반복되므로 "질의가 매번 하는 계산"을 표로 미리 만든다. 필요한 것은 두 가지: 빈 좌석 번호의 오름차순 목록, 그리고 "좌석 i 앞까지 빈 좌석이 몇 개였나"(누적 개수). i부터 k번째 빈 좌석은 목록에서 `before[i-1] + k - 1`번째 원소다. 전처리 O(N), 질의 O(1).
- 누적 개수 `before`는 곧 0/1 누적합이고, 목록은 그 누적합의 "역방향 조회표"다. 두 전처리를 결합해 질의를 인덱스 계산으로 바꾼 것이 요점이다.

(2) 코드 단계별

- 좌석을 왼쪽부터 훑으며 `before[i+1] = before[i]`로 복사하고, 빈 좌석이면 `free_pos`에 번호를 추가하고 `before[i+1] += 1`.
- 질의 `(i, k)`: `j = before[i-1] + k - 1`. `j < len(free_pos)`면 `free_pos[j]`, 아니면 -1.

(3) 스스로 다시 짤 때 생각 순서

- "고정 배열 + 같은 종류 질의 다수" → 전처리 표. 질의를 "표 조회 + 인덱스 산술"로 바꿀 수 있는지 먼저 본다.
- 좌석 i 자신을 포함해야 하므로 `before[i-1]`(i 앞까지)을 쓴다. `before[i]`를 쓰면 i가 빈 좌석일 때 건너뛴다(셋째 테스트 `4 1` → 4).
- 경계: 빈 좌석이 전혀 없을 때, k가 남은 빈 좌석 수보다 클 때(-1), 전부 빈 좌석일 때 k번째 그대로.
```

**8) 부분합 S 이상 최소 길이** · Medium

- **요구사항**: 양의 정수 배열에서 연속 부분 배열의 합이 S 이상이 되는 것 중 길이가 가장 짧은 것의 길이를 출력하라. 그런 부분 배열이 없으면 0.
- **입력**: 첫 줄 N S(1 ≤ N ≤ 500, 1 ≤ S ≤ 10^9). 둘째 줄 N개의 양의 정수(1 이상 10^6 이하).
- **출력**: 최소 길이 또는 0.
- **예제**: `8 15 / 5 1 3 5 10 7 4 9` → `2` · `3 100 / 1 2 3` → `0`
- **셀프체크**: 원소가 양수라 합이 단조롭다. `right`를 늘려 합을 키우고, 합이 S 이상인 동안 길이를 기록하며 `left`를 밀어 줄인다 — 답 갱신을 "줄이기 전"에 해야 한다. 한 원소만으로 S 이상이면 길이 1. 검산(첫 예제): `5 10`의 합 15가 길이 2로 최소.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.read().split()
    n = int(data[0]); s = int(data[1])
    a = [int(x) for x in data[2:2 + n]]
    left = 0; cur = 0; best = 0
    for right in range(n):
        cur += a[right]
        while cur >= s:
            length = right - left + 1
            if best == 0 or length < best:
                best = length
            cur -= a[left]; left += 1
    print(best)
main()

(1) 접근·핵심 아이디어

- 양수 배열이라 윈도우 합은 `right`를 늘리면 증가하고 `left`를 늘리면 감소한다(단조성). 그래서 "합이 S 이상"이 된 순간부터는 `left`를 한 칸씩 밀어 더 짧은 윈도우를 시도해도 되돌릴 필요가 없다. 각 포인터가 최대 N번 전진하므로 O(N)(모든 구간을 보는 O(N²) 대신).
- L6의 "합 ≤ K 최장" 문제와 방향이 반대다: 조건이 만족되는 동안 줄여서 최소 길이를 찾는다.

(2) 코드 단계별

- `right`마다 `cur += a[right]`.
- `cur >= S`인 동안: 현재 길이 `right - left + 1`로 `best`를 갱신(0이면 첫 갱신), 그다음 `cur -= a[left]; left += 1`.
- 끝나면 `best` 출력(한 번도 갱신되지 않으면 0).

(3) 스스로 다시 짤 때 생각 순서

- "합 조건을 만족하는 최소 길이 + 양수" → 슬라이딩 윈도우. 단조성이 있는지 먼저 확인한다(음수가 섞이면 이 방법은 틀린다).
- 갱신 순서: 조건이 참인 상태에서 길이를 기록하고 나서 줄인다. 순서를 바꾸면 조건이 깨진 윈도우를 기록한다.
- 경계: 전체 합이 S 미만(0), 한 원소가 S 이상(길이 1), 전체가 딱 S(넷째 테스트: 길이 N).
```

**9) 가장 긴 산 구간** · Hard

- **요구사항**: 정수 배열에서 "산"은 길이가 3 이상이고, 어떤 봉우리까지 엄격히 증가한 뒤 끝까지 엄격히 감소하는 연속 부분 배열이다. 가장 긴 산의 길이를 출력하라. 산이 없으면 0.
- **입력**: 첫 줄 N(1 ≤ N ≤ 500). 둘째 줄 N개의 정수(0 이상 10^9 이하).
- **출력**: 최대 길이 또는 0.
- **예제**: `10 / 2 1 4 7 3 2 5 8 8 1` → `5` · `3 / 1 2 3` → `0`
- **셀프체크**: 봉우리 i마다 왼쪽으로 엄격 증가가 이어진 길이 `inc[i]`, 오른쪽으로 엄격 감소가 이어진 길이 `dec[i]`를 LR로 채우면 산의 길이는 `inc[i] + dec[i] - 1`. 단, 양쪽 모두 2 이상이어야 봉우리다(한쪽이 1이면 오르막만 또는 내리막만). 같은 값이 이어지면 run이 끊긴다(엄격). 검산(첫 예제): 봉우리 7에서 1,4,7 오르막(3) + 7,3,2 내리막(3) → 5. 봉우리 후보 8은 옆이 8이라 감소 run이 1이라 산이 아니다.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    a = [int(x) for x in data[1:1 + n]]
    inc = [1] * n
    for i in range(1, n):
        if a[i] > a[i - 1]:
            inc[i] = inc[i - 1] + 1
    dec = [1] * n
    for i in range(n - 2, -1, -1):
        if a[i] > a[i + 1]:
            dec[i] = dec[i + 1] + 1
    best = 0
    for i in range(n):
        if inc[i] >= 2 and dec[i] >= 2:
            length = inc[i] + dec[i] - 1
            if length > best:

(3) 스스로 다시 짤 때 생각 순서

- "봉우리 기준 양쪽 길이" → LR run 배열. 두 배열의 정의(자신 포함, 엄격 조건)를 먼저 적는다.
- 봉우리 조건(양쪽 run ≥ 2)을 빠뜨리면 단조 증가 배열(둘째 테스트)이나 평지(셋째 테스트)에서 오답이 난다.
- 경계: N < 3이면 산 없음, 같은 값 연속(엄격이라 run 끊김), 최소 산 `1 3 1`(길이 3).
```

**10) 압축 격자 점 개수 질의** · Hard

- **요구사항**: 평면 위에 점 N개가 있다(좌표는 최대 10^9, 같은 위치에 여러 점이 있을 수 있다). Q개의 직사각형 질의 `(x1, y1, x2, y2)`마다 x1 ≤ x ≤ x2, y1 ≤ y ≤ y2인 점의 개수를 출력하라.
- **입력**: 첫 줄 N Q(1 ≤ N, Q ≤ 300). 이후 N줄에 `x y`(0 ≤ x, y ≤ 10^9). 이후 Q줄에 `x1 y1 x2 y2`(x1 ≤ x2, y1 ≤ y2).
- **출력**: 질의마다 점의 개수를 한 줄씩.
- **예제**: `5 3 / 1 1 / 5 5 / 1000000000 1 / 5 1 / 3 7 / 1 1 5 5 / 6 0 1000000000 10 / 2 2 4 4` → `3 / 1 / 0` · `2 1 / 4 4 / 4 4 / 4 4 4 4` → `2`
- **셀프체크**: x, y를 각각 압축해 (서로 다른 x 수)×(서로 다른 y 수) 격자에 점 개수를 채우고 2D 누적합을 만든다. 질의 좌표는 격자 인덱스가 아니므로 `bisect_left(xo, x1)`, `bisect_right(xo, x2)`로 반열림 인덱스 구간 `[lx, rx)`로 바꾼다(y도 동일). `lx >= rx`면 그 축에 점이 없어 0. 같은 위치의 점은 한 칸에 2 이상으로 쌓인다.

```runner
@@SOLUTION
import sys, bisect
def main():
    data = sys.stdin.read().split()
    idx = 0
    n = int(data[idx]); q = int(data[idx + 1]); idx += 2
    pts = []
    for _ in range(n):
        x = int(data[idx]); y = int(data[idx + 1]); idx += 2
        pts.append((x, y))
    xo = sorted(set(x for x, _ in pts))
    yo = sorted(set(y for _, y in pts))
    xr = {v: i for i, v in enumerate(xo)}
    yr = {v: i for i, v in enumerate(yo)}
    W = len(xo); H = len(yo)
    P = [[0] * (H + 1) for _ in range(W + 1)]
    for x, y in pts:
        P[xr[x] + 1][yr[y] + 1] += 1
    for i in range(1, W + 1):
        for j in range(1, H + 1):
            P[i][j] += P[i - 1][j] + P[i][j - 1] - P[i - 1][j - 1]
    out = []
    for _ in range(q):
        x1 = int(data[idx]); y1 = int(data[idx + 1]); x2 = int(data[idx + 2]); y2 = int(data[idx + 3]); idx += 4
        lx = bisect.bisect_left(xo, x1); rx = bisect.bisect_right(xo, x2)
        ly = bisect.bisect_left(yo, y1); ry = bisect.bisect_right(yo, y2)
        if lx >= rx or ly >= ry:
            out.append("0"); continue
        out.append(str(P[rx][ry] - P[lx][ry] - P[rx][ly] + P[lx][ly]))
    print("\n".join(out))
main()

(1) 접근·핵심 아이디어

- 좌표가 10^9라 격자를 직접 만들 수 없지만 서로 다른 x, y는 각각 N개 이하다. 두 축을 따로 압축하면 최대 N×N 격자에 점 개수를 채울 수 있고, 여기에 2D 누적합을 얹으면 직사각형 개수 질의가 4항 뺄셈으로 O(1)이다. 질의마다 점을 전부 검사하는 O(NQ) 대신 전처리 O(N² + N log N) + 질의 O(log N).
- 질의의 좌표는 압축표에 없을 수 있으므로 dict 대신 bisect로 "x1 이상 첫 인덱스", "x2 초과 첫 인덱스"를 얻어 반열림 인덱스 구간으로 바꾼다. 이 변환이 압축 문제의 핵심 함정이다.

(2) 코드 단계별

- `xo`, `yo` = 서로 다른 좌표의 정렬 목록, `xr`, `yr` = 좌표 → 인덱스.
- `P`를 (W+1)×(H+1)로 두고 각 점을 `P[xr[x]+1][yr[y]+1] += 1`(같은 위치는 누적), 그다음 제자리에서 2D 누적합.
- 질의: `lx = bisect_left(xo, x1)`, `rx = bisect_right(xo, x2)`(y도 같은 방식). `lx >= rx` 또는 `ly >= ry`면 0. 아니면 `P[rx][ry] - P[lx][ry] - P[rx][ly] + P[lx][ly]`.

(3) 스스로 다시 짤 때 생각 순서

- "큰 좌표 + 직사각형 개수 질의 반복" → 좌표 압축 + 2D 누적합 결합. 1D(문제 4)를 축마다 적용한다고 생각한다.
- 1-인덱스 누적합 `P`와 0-인덱스 반열림 `[lx, rx)`가 자연스럽게 맞물리는지(`P[rx] - P[lx]`) 종이에 확인한다.
- 경계: 질의 영역에 좌표가 하나도 없을 때(0으로 조기 반환하지 않으면 `P[lx][...]`에 잘못된 인덱스가 들어간다), 같은 위치 점 중복(둘째 테스트), 점 하나짜리 입력.
```

**11) 최대 겹침 지속 시간** · Hard

- **요구사항**: 작업 N개가 시간 구간 `[s, e)`(s 포함, e 미포함)로 주어진다. 동시에 진행 중인 작업 수의 최댓값 M과, 동시 진행 수가 정확히 M인 시간의 총 길이를 출력하라.
- **입력**: 첫 줄 N(1 ≤ N ≤ 300). 이후 N줄에 `s e`(0 ≤ s < e ≤ 10^9).
- **출력**: `M 총길이`를 공백으로.
- **예제**: `3 / 1 5 / 3 8 / 4 6` → `3 1` · `4 / 0 10 / 2 4 / 6 9 / 20 21` → `2 5`
- **셀프체크**: 시각이 10^9라 배열 imos는 불가 → `(시각, +1)`, `(시각, -1)` 이벤트를 정렬해 순서대로 누적하는 스위프. 같은 시각의 이벤트를 모두 적용한 뒤 "다음 이벤트 시각까지의 길이" 동안 그 개수가 유지된다. 반열림이라 한 작업이 끝나는 시각에 다른 작업이 시작해도 겹치지 않는다(넷째 테스트: 1 4). 최댓값이 갱신되면 길이를 새로 시작하고, 같으면 더한다.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    events = []
    for i in range(n):
        s = int(data[1 + 2 * i]); e = int(data[2 + 2 * i])
        events.append((s, 1))
        events.append((e, -1))
    events.sort()
    best = 0; best_len = 0
    cur = 0
    i = 0
    m = len(events)
    while i < m:
        t = events[i][0]
        while i < m and events[i][0] == t:
            cur += events[i][1]; i += 1
        if i < m:
            seg = events[i][0] - t
            if cur > best:
                best = cur; best_len = seg
            elif cur == best:
                best_len += seg
    print(best, best_len)
main()

- +1/-1 기법을 시각이 큰 상황에 적용하려면 배열 대신 "변화가 일어나는 시각"만 다룬다. 시작에 +1, 끝에 -1인 이벤트 2N개를 정렬해 앞에서부터 누적하면 각 시각의 동시 진행 수를 얻고, 인접한 이벤트 시각 사이에서는 그 값이 일정하므로 구간 길이를 그대로 더할 수 있다. 정렬 O(N log N) + 스위프 O(N)(좌표 압축 후 imos와 같은 결과).
- 같은 시각의 이벤트는 모두 반영한 뒤에 다음 구간을 재야 한다. 반열림 `[s, e)`에서 e에 끝나고 e에 시작하는 두 작업은 그 순간 겹치지 않는데, "전부 적용 후 측정" 방식이면 순서를 따로 정하지 않아도 자연스럽게 맞는다.

(2) 코드 단계별

- `(s, +1)`, `(e, -1)`을 모아 정렬한다.
- 같은 시각 t의 이벤트를 모두 `cur`에 반영한 뒤, 다음 이벤트 시각까지의 길이 `seg`를 구한다(마지막 시각 뒤에는 구간이 없으므로 건너뜀).
- `cur > best`면 최댓값과 길이를 새로 시작, `cur == best`면 길이를 누적. 마지막에 `best best_len` 출력.

(3) 스스로 다시 짤 때 생각 순서

- "겹침 최대 + 큰 시각 + 그 상태가 유지되는 길이" → 이벤트 정렬 스위프. 값이 변하는 지점만 보면 된다는 imos의 본질을 떠올린다.
- "시각별 값"이 아니라 "구간별 값"을 세므로 구간 길이 `다음 시각 - 현재 시각`을 곱(더)한다. 압축 인덱스 차이가 아닌 실제 시각 차이를 써야 한다.
- 경계: 작업 하나(둘째·셋째 테스트), 끝과 시작이 맞닿은 경우(겹치지 않음), 최댓값 구간이 여러 번 나뉘어 나타나는 경우(둘째 테스트: 2 + 3 = 5).
```

**12) 최대 K종류 과일 바구니** · Hard

- **요구사항**: 나무가 한 줄로 서 있고 각 나무의 과일 종류가 정수로 주어진다. 연속한 나무들에서 과일을 모두 따되 바구니에는 서로 다른 종류를 최대 K가지까지만 담을 수 있다. 딸 수 있는 나무 수(연속 구간 길이)의 최댓값을 출력하라.
- **입력**: 첫 줄 N K(1 ≤ K ≤ N ≤ 500). 둘째 줄 N개의 종류 번호(1 이상 10^9 이하).
- **출력**: 최대 구간 길이.
- **예제**: `9 2 / 1 2 1 2 3 3 3 4 4` → `5` · `3 5 / 1 2 3` → `3`
- **셀프체크**: 윈도우 안 종류별 개수를 dict로 유지하면 "서로 다른 종류 수 = dict 크기". `right`를 늘려 넣고, 종류 수가 K를 넘는 동안 `left`를 밀며 개수를 줄이되 0이 되면 키를 삭제해야 크기가 줄어든다. 답 갱신은 조건 회복 직후. 검산(첫 예제): `3 3 3 4 4`가 종류 2가지로 길이 5.

```runner
@@SOLUTION
import sys
def main():
    data = sys.stdin.read().split()
    n = int(data[0]); k = int(data[1])
    a = [int(x) for x in data[2:2 + n]]
    cnt = {}
    left = 0; best = 0
    for right in range(n):
        cnt[a[right]] = cnt.get(a[right], 0) + 1
        while len(cnt) > k:
            cnt[a[left]] -= 1
            if cnt[a[left]] == 0:
                del cnt[a[left]]
            left += 1
        if right - left + 1 > best:
            best = right - left + 1
    print(best)
main()

(1) 접근·핵심 아이디어

- "연속 구간 + 서로 다른 종류 수 제한 + 최대 길이"는 슬라이딩 윈도우의 전형이다. 종류 수는 `right`를 늘리면 늘거나 같고 `left`를 늘리면 줄거나 같으므로 단조성이 있어 포인터를 되돌릴 필요가 없다. 윈도우 안 종류별 개수를 dict로 두면 "종류 수"가 `len(cnt)`로 O(1)이고, 각 포인터가 N번씩만 움직여 전체 O(N)(모든 구간에 대해 set을 만들면 O(N²)).

(2) 코드 단계별

- `right`마다 `cnt[a[right]] += 1`(없으면 1).
- `len(cnt) > K`인 동안 `cnt[a[left]] -= 1`, 0이 되면 `del`로 키 제거, `left += 1`.
- 조건이 회복된 뒤 `right - left + 1`로 `best` 갱신.

(3) 스스로 다시 짤 때 생각 순서

- "종류 수 제한이 있는 연속 구간 최대" → 윈도우 + 개수 dict. 조건이 단조로운지 먼저 확인한다.
- 개수가 0이 된 키를 지우지 않으면 `len(cnt)`가 줄지 않아 윈도우가 계속 수축한다 — 이 문제의 대표 함정.
- 경계: K가 전체 종류 수 이상(전체 길이), 종류가 한 가지뿐(셋째 테스트), 전부 다른 종류(넷째 테스트: 길이 K).
```
