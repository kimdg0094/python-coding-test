## 🎯 권장 학습 순서와 난이도 흐름

개념이 앞에서 뒤로 누적되도록 설계되어 있으므로, 아래 순서대로 진행하는 것을 권장합니다.

```
기본 → 입출력 → 조건문1 → 단순반복문1 → 조건문2
     → 1차원배열 → 문자열 → 단순반복문2 → 다중반복문 → 2차원배열
```

1. **기본 → 입출력**: 출력·변수·자료형·연산자로 코드의 최소 단위를 익히고, 입력을 받아 형 변환·포맷 출력까지 연결합니다.
2. **조건문1 → 단순반복문1 → 조건문2**: 흐름 제어의 두 축인 분기(`if`)와 반복(`for`/`while`)을 배우고, 논리 연산자·중첩으로 조건을 확장합니다.
3. **1차원 배열 → 문자열**: 여러 값을 담는 리스트와, 문자의 시퀀스인 문자열을 다루며 인덱싱·슬라이싱 감각을 기릅니다.
4. **단순반복문2 → 다중반복문 → 2차원배열**: 반복을 조건·제어문과 결합하고(`continue`/`break`/누적), 2중 반복으로 패턴을 만든 뒤, 2차원 배열에서 순회·집계·패턴 출력까지 종합합니다.

> 흐름 요약: 단순 출력 → 조건/반복 → 자료구조(1차원) → 반복 심화 → 자료구조(2차원). 뒤 챕터는 앞 챕터의 개념(인덱싱, `cnt`/`total`, 홀짝 판정 등)을 그대로 재사용합니다.

## 📚 챕터별 요약 및 링크

### [Ch1. 기본](ch01-basics.md)
프로그래밍의 최소 단위를 다룹니다. `print()`로 값을 출력하고, 변수에 값을 저장·덮어쓰며, int/float/bool 자료형과 형 변환(특히 `int()`의 버림), 산술·비교·논리·증감대입 연산자를 익힙니다.

### [Ch2. 입출력](ch02-io.md)
출력 형식을 조정하는 `sep`·`end`·f-문자열·소수점 포맷·이스케이프 시퀀스와, `input()`을 통한 입력 처리(형 변환, 여러 줄 입력, `split()`, `map()`)를 배웁니다. 합·평균 계산 같은 실전 입출력으로 마무리합니다.

### [Ch3. 조건문 1](ch03-conditionals-1.md)
참/거짓 조건식을 세우고 `if` / `if-else` / `if-elif-else`로 코드 흐름을 분기합니다. 들여쓰기 규칙, 경계값 처리(`>=` vs `>`), 다중 분기에서 조건 순서(좁은 조건 먼저)를 정확히 다루는 것이 핵심입니다.

### [Ch4. 단순 반복문 1](ch04-loops-1.md)
같은 작업을 되풀이하는 `for`문과 `while`문을 처음 배웁니다. `range(start, stop, step)`로 횟수·범위·증감을 제어하고(끝값 미포함, 음수 step), 횟수가 정해지지 않은 반복은 `while`로 처리하며 무한 루프를 피합니다.

### [Ch5. 조건문 2](ch05-conditionals-2.md)
`and`/`or` 논리 연산자로 여러 조건을 하나로 묶고, `if` 안에 `if`를 넣는 중첩 조건문을 익힙니다. 성인 여부·윤년(4·100·400)·중앙값처럼 조건이 얽힌 문제를 논리적으로 분해해 정확한 분기 코드로 옮깁니다.

### [Ch6. 1차원 배열](ch06-array-1d.md)
여러 값을 순서대로 담는 리스트를 배웁니다. 생성·인덱싱(0부터, 음수 인덱스)·수정과 주요 메서드(append/insert/remove/pop/sort 등)를 익히고, `list(map(int, input().split()))`·for문·컴프리헨션으로 배열을 순회·가공합니다.

### [Ch7. 문자열](ch07-string.md)
문자의 시퀀스인 문자열(str)을 다룹니다. 문자열이 **불변**임을 이해하고, 인덱싱·슬라이싱과 주요 메서드(upper/strip/replace/split/join/find 등), 이스케이프 문자를 조합해 원하는 부분을 뽑거나 가공합니다.

### [Ch8. 단순 반복문 2](ch08-loops-2.md)
반복문을 조건문·제어문과 결합합니다. `if`로 요소를 걸러내고, `continue`/`break`로 흐름을 제어하며, `cnt`/`total` 누적 변수로 개수·합을 구합니다. `while True` + `break`로 종료 시점이 미정인 입력도 처리합니다.

### [Ch9. 다중 반복문](ch09-nested-loops.md)
for문 안에 for문을 넣는 2중(중첩) 반복문을 다룹니다. 외부=행·내부=열의 원리로 별찍기·삼각형·구구단·숫자 피라미드 패턴을 만들고, 변수 선언 위치(전체 누적 vs 행별 초기화)와 중첩에서의 `continue`/`break` 동작을 익힙니다.

### [Ch10. 2차원 배열](ch10-array-2d.md)
행·열을 가진 2차원 배열(리스트의 리스트)을 배웁니다. `matrix[i][j]` 인덱싱, 이중 for문 순회·집계(`cnt`/`total`), 인덱스 홀짝을 이용한 지그재그 패턴 출력을 다루며, `[[0]*n]*n` 얕은 복사 함정을 컴프리헨션으로 피하는 법도 익힙니다.
